## 这一卷是什么

本卷收的是第四爱、GB（女攻男受）、女尊这三个圈子的词。三个圈子挨着，但不重合。从 BL 圈、BDSM 圈、同人圈和网文行业借进 GB 的词，也收了一些。

收词先看「圈内实际在用」，再看「书面规范」，所以缩写、隐语和吐槽用的词收了很多。

## 标注约定

- 有些词圈里没有统一标准，正文不替谁拍板，只标「用法不统一」，把几派的说法并排列出来。女尊称谓体系里这种词尤其多。
- 「用法示例」收的是圈里人交流时真会说的话，出自 tag、评论区、推文帖、避雷说明这些地方。小说正文不收。
- 地域和平台的差别随条标注。陆是大陆通行，台是台湾通行。标晋江、海棠、废文、AO3、LOFTER 的，指这个平台独有、或在这个平台意思不同的用法。
- 一个词从别处借来、意思又变了，才会有「在 GB 语境中的特殊含义」这一栏。GB 圈大约三分之一的词搬自 BL 圈或字母圈，搬过来以后几乎都变了味。

## 一句话读者须知

> GB 圈子小，词义变得快，各地方的用法又各有各的。同一个词，放在豆瓣小组、晋江评论区和废文 tag 里，意思可能都不一样。
> 本卷只记到编纂时为止的主流用法和主要分歧，不定规范。

## 编纂说明

材料来自好几个地方：萌娘百科、豆瓣GB小组、晋江论坛推文帖、知乎专栏、四爱圈科普文、女尊设定群（易次元、贴吧），还有《上海文化》《中国作家网》。

有六条用法不统一，都标了「用法不统一」，圈里怎么吵就怎么摆，不站队。这六条是：精神四爱算不算，骨科划到哪一层，女尊称谓分几派，假女尊和真女尊怎么分，女帝这个词能不能用，雄堕怎么写。各派说法并排放着，不下结论。

## 附：平台标签体系实测对照（2026-08）

GB 作品在各平台的标注方式如下。

| 平台 | GB 是不是官方标签 | 实际情况 |
|---|---|---|
| 长佩文学 | ✅ 是 | `gb` / `女攻男受` / `第四爱` / `4i` / `女A男O` / `身份倒置` 都算同一类，是大陆商业站里对 GB 最友好的 |
| 镜文学（台） | ✅ 是 | 「女攻男受」是正式标签，旁边还能看到 `#gb` `#第四愛` |
| 话本小说 | ✅ 是 | 站里专门有个分类叫「第四爱-女攻男受文」 |
| 露西弗俱乐部 | ✅ 是 | 性向筛选项有 BL / GL / BG / GB / 女尊 / 综合 / 无CP。全站只有它把 GB 和女尊并排当一级性向，制度上就说明「GB 是配对维度、女尊是世界观维度」 |
| 晋江文学城 | ❌ 否 | 官方只给了「女尊」标签。GB 只能塞进书名或「其它」栏自己填。已有《ABO炮灰，但万人迷[GB]》等签约文，说明 GB 能公开挂书名过审，但没进正式词表 |
| PO18（台） | ❌ 否 | 官方标签表有 BG / BL / 百合 / futa / 女尊，就是没有 GB。台湾那边最接近的说法是「女尊」 |
| 海棠 | ❌ 否 | 站方字段只到「性向：男女/男男/女女/混和」。GB 只出现在作者自己起的书名里。圈内公认的 GB 产地，但站方从不这么分 |
| 废文网 | ❓ 待核实 | 有「性向」单选标签，标签靠用户提名，但公开提名楼里没见 GB 提名记录，得登录+等级够才能查全 |
| 寒武纪年 | ❌ 无 | 纯 BL 站，全站找不到 GB/女攻/四爱 |
| AO3 | ⚠️ 特殊 | 没有 GB 标签，靠 Additional Tags 手动打。中文 tag 实测使用量：`四爱` 840、`第四爱` 813、`女攻男受` 746 |

标签最省力的三个站是长佩、镜文学、话本。晋江得把 GB 写进书名。海棠、PO18 就只能靠书名和文案自救。具体看 [08-平台生态](../08-平台生态/01-平台生态与发文指南.md)。
