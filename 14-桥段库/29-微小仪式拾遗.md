# 微小仪式拾遗

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族收的是五分钟以内的小场面：耳机、跳舞、剥虾、拧瓶盖。由谁来做，老规矩都给过标准答案，他们一个个重新答。

## 拾遗的意思

这些事太小，单拎出来撑不起一个类型，可又太扎眼，丢了可惜。一副耳机、一支舞、一个拧不开的瓶盖，前面几卷按生活场景分类时都落进了缝里。跳舞谁带、虾谁剥、瓶盖谁开，老规矩里都有现成的答案。

| 节拍族 | 占比 |
|---|---:|
| 歌舞 | 25.7% |
| 外食 | 15.0% |
| 理发 | 9.5% |
| 置装 | 6.8% |

「歌舞」占 25.7%，在全部情境族里排在中上，KTV 和舞池的场面在语料里随处可见，之前一直没地方放。

## 一 · 分享耳机

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.9%

**骨架**｜一人一只耳机。有线的年代，线多长两人就隔多远，换成无线，靠不靠近就得看自己愿不愿意了。

#### 节拍链

一方在听 → 另一方好奇 → 摘下一只递过去 → 接过戴上 → 被迫（有线）或自愿（无线）的靠近 → 同一首歌的三分钟 → 摘下，还是没摘

#### 时间轴

一首歌也就三四分钟，进度条摆在那儿，两个人都知道这一段什么时候结束。到点了还没摘，就是想再待一会儿。

#### 有线与无线的两种语法

| | 有线 | 无线 |
|---|---|---|
| 距离 | 线就那么长，拽着走 | 蓝牙范围大，近不近看心情 |
| 递出动作 | 递的是「过来」 | 递的是「给你一半」 |
| 经典画面 | 挤一个座，头快挨上 | 各坐一边，同一首歌里对眼 |
| 事故 | 线一扯掉，俩人一起「哎」 | 一只没电，换着戴同一只 |

一只没电了换着戴，同一只耳机在两人耳朵之间来回，比有线那根线还近。

#### 可用细节

| 类 | 内容 |
|---|---|
| 递出 | 擦了两下才递过去，他讲究 · 直接塞过来，她就这脾气 |
| 歌 | 他歌单里存着她那个年代的歌，接 [27-年龄差与姐弟 · 参照系错位](27-年龄差与姐弟.md#三--参照系错位) · 她歌单里有首暴露心事的 |
| 三分钟 | 都假装在看别处 · 副歌时有人跟着轻轻晃，被对方偷偷看在眼里 |
| 结尾 | 「下一首也好听」，想接着听就这么说 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 通勤地铁 ✓ | 长途航班／病房陪护 |
| 谁递 | 他 | 她，她递过来就是让他进她的频道，少见，分量也更重 |
| 歌的信息量 | 无 | 那首歌有故事，替她把没说的事讲了 |
| 结尾 | 摘下归还 | 「这只送你」，耳机就成了信物 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他递之前擦耳机那两下 | 她的歌单和她本人的反差 |
| 内心 | 这歌单不像她的风格 | 副歌她晃了一下。记住了。 |
| 好的处理 | 她听完只说旋律好听，没问那首歌的事 | 他那句「下一首也好听」说得笨，反倒成了 |
| 写崩 | 写成借歌表白 | 把歌单一首首拆开讲 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 一张琴两个人听，她弹到一半，让他按住一根弦，弦的震动顺着指尖传上来 |
| 修仙 | 用传音入密一起听一段旧录音，灵识并在一处的那三分钟，比双修还近 |
| 星际 | 舱内公共频道切成双人频道，歌单同步权限一开，就是星际版的「这只送你」 |

#### 写崩的三种方式

1. 靠歌词递话。 歌只管那三分钟，话另外说。
2. 三分钟写成三页。 一首歌的事，就写一首歌那么长。
3. 忽略终点。 副歌总会唱完，要写的是没摘耳机的那一下。

> 他把右耳那只摘下来，在袖子上擦了两下，递过去。

## 二 · 学跳舞

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：歌舞 25.7%

**骨架**｜商务晚宴要跳舞。学舞先得分工，一个带一个跟，教材默认男带女跟。两人对着教材愣了三秒。

#### 节拍链

跳舞需求出现 → 报班或自学 → 「谁领」的第一课 → 试两种分工 → 找到他们的答案 → 晚宴实战 → 舞池里只有他们知道的秘密

#### 时间轴

**按练习次数算。** 第一次互相踩脚，第三次能转起来了，到第七次，教练已经不纠正谁领谁跟，因为看不出来了。

#### 「谁领」的三轮实验

| 轮 | 分工 | 结果 |
|---|---|---|
| 第一轮 | 按教材：他领 | 他领得心虚，信号给得犹犹豫豫，两人老是撞拍，他不会发号施令 |
| 第二轮 | 换过来：她领 | 顺得出奇，她手一搭他就懂，可这舞姿在旁人看来「不合惯例」，晚宴上会招眼 |
| 第三轮 | 混合：进门他领，人少处换她 | 外循环他领（给世界看），内循环她领（给自己跳） |

#### 可用细节

| 类 | 内容 |
|---|---|
| 练习 | 客厅茶几推开 · 手机 ✓ 外放舞曲 · 踩了脚，道歉从客气到随便到干脆不吭声 |
| 领舞的手 | 信号全在掌根，推半寸，收半寸，她给得轻，他接得准（接 [11-初遇与确立 · 她教他](11-初遇与确立.md#六--她教他)的镜像：这门课他学得最快） |
| 晚宴 | 全场都照老规矩跳，只有他俩转着转着悄悄换了三回领跟，谁也没看出来 |
| 秘密 | 跳完有人夸「他领得真稳」，两人对看一眼笑了，到底谁稳，他们自己清楚 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 起因 | 就是接个商务活 | 图个开心（婚礼头一支舞先拿这儿练手，接 [23-婚嫁](23-婚嫁.md#七--当天)） |
| 学习曲线 | 俩人都没底 | 她会他不会（她正经学过，为什么学，就引出了她小时候的事，接 [30-她的世界](30-她的世界.md#六--她的少女时代)) |
| 答案 | 按老规矩来 | 干脆不跳套路，跳只有他俩会的那种，婚礼上那支舞全场都看愣了 |
| 秘密归宿 | 没人知道 | 被内行一眼看破，对方举杯朝她晃了晃，什么也没说，懂行的人就这么打招呼 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 掌根信号被接住的第一次 | 「他领得真稳」那句夸奖的荒诞 |
| 内心 | 他跟着我走，比我领得还顺——这话越品越像我们俩 | 外圈我领。她交代的事，我办得漂亮。 |
| 好的处理 | 她领得不动声色，晚宴上把「被领」演得滴水不漏 | 他不觉得跟着走就是输，跟一个好领舞，是舞池里最舒服的事 |
| 写崩 | 写成她当众抢风头 | 写成他学舞学出屈辱感 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 宫宴上按规矩该妻主先伸手，私宴上他们换了一套跳法，乐师看见了，悄悄把节拍改了半分跟上 |
| 修仙 | 双修剑舞的剑谱写的是男带女，他俩改了批注，那一页传回门中，后来竟成了新的范本 |
| 星际 | 授勋舞会的舞步全写在礼仪程序里，他俩申请了「自定义模式」，审批官盖章时嘴角没绷住 |

#### 写崩的三种方式

1. 第一轮就换她领。 他先领砸一回，要老老实实写出来给人看。
2. 两套规矩跟外人讲透了，舞池里那点秘密就全露了底。
3. 领跟写成谁压谁。 好的领跟像搭话。

## 三 · KTV他唱给她

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：歌舞 25.7% ＋ 聚会 11.7%

**骨架**｜包厢里轮到他点歌，前奏一响她就愣住了。这首歌她太熟了，比他大十岁那年就听烂了。

#### 节拍链

聚会进包厢 → 他一直没点歌，憋大招 → 前奏起 → 她认出的那半秒 → 他开口，练过的痕迹藏不住 → 全场起哄 → 唱完的处理

#### 时间轴

**前史长达数周**。他偷偷练歌的那些晚上，洗澡时压着嗓子唱，通勤路上单曲循环，全都压在前奏响起的那三秒里。写的时候把前史放到后面，先让他唱，再让她一点点拼出他练过的证据。

#### 麦克风的权力学

KTV 就是个小舞台，谁拿着麦，全场的注意力就暂时归谁：

| 现象 | 说明 |
|---|---|
| 他平时从不抢麦 | 低调是常态 |
| 这首歌他提前两小时就切了歌 | 蓄谋 |
| 唱给她但眼睛不看她 | 一直盯着屏幕唱，到副歌最后一句才转过头，那一眼就算告白了 |
| 起哄声中他把麦放下 | 说一句「跑调了别笑」，拿自嘲把全场的起哄接下来，替她挡住难堪 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 破绽 | 转音和原唱不一样，和她手机里那个 live 版一模一样，他练的正是她听的那一版 |
| 她的反应 | 别人看她笑着，只有她自己知道那口气堵在哪 |
| 起哄 | 「再来一个」他死活不唱，那首是唱给她的，再唱就成了表演 |
| 归途 | 车里她问「练了多久」，他说「没练」，等红灯时她放出那首 live 版，他耳朵红了 |

她爱这首歌他知道，她爱的是哪一版他也知道。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 朋友聚会 | 只有他们俩的包厢，没人起哄，安静得多，也沉得多 |
| 唱功 | 一听就是练过的 | 真跑调，跑调的版本更好：她听完说「难听死了」，回头把他这段录音循环了一个礼拜 ✓ |
| 方向 | 他唱给她 | 她唱给他。她平时很少开口，一年也就唱一回，点的是他那个年代的歌，年代对不上，心意他收到了 |
| 归宿 | 回去路上对质 | 那首歌成了两人的暗号，前奏一响就互相看一眼，接 [19-玩闹与网络 · 只有他们懂的梗](19-玩闹与网络.md#六--只有他们懂的梗) |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 副歌最后一句他转头的时间差 | 前奏响起时她脸上那半秒的空白 |
| 内心 | 这版……他怎么知道这版 | 三十七个晚上。值了。 |
| 好的处理 | 她一直忍着没哭，出了包厢才在洗手间缓了一分钟 | 他不想返场，直接拒了 |
| 写崩 | 写成她当场哭出来 | 写成他满场炫技 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 家宴上他弹了一支她及笄那年流行的老曲子，大家都在感慨，她只盯着他拨弦的手，那指法是照她旧琴谱上的批注练出来的 |
| 修仙 | 门中小聚，他吹了一段她还是凡人时听过的家乡小调，这调子是他专程去她老家蹲了半个月学来的 |
| 星际 | 舰上晚会他唱了一首地球老歌，伴奏是他自己扒谱敲进系统的，曲库里根本没有这首 |

#### 写崩的三种方式

1. 前史先铺。 练歌经过挪到后面，当证据用。
2. 唱功写成演唱会。 有点破绽，偶尔跑个调，比唱得完美更动人。
3. 唱完直接告白。 歌已经替他说完了，再开口就多了。

## 四 · 她带他买衣服

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：置装 6.8%

**骨架**｜她说他这件该换了。半小时后，他站在试衣间里，听她和店员讨论他肩膀有多宽。

#### 节拍链

起因是一件旧衣或一个场合 → 进店 → 她选他试 → 试衣间门开合若干轮 → 店员的站队 → 定夺 → 结账的攻防 → 穿出门

#### 时间轴

**按试衣间门开合的轮数算。** 门每开一次就是一轮评审。第一轮她摇头，第三轮她一声不吭绕着他走了半圈，第五轮她说「就这件」。

#### 「被打扮」的权力语法

她给他挑衣服，和 [06-身体接触 · 系扣子](06-身体接触.md#七--系扣子)是一路的，只是拉得更长：

| 环节 | 怎么写 |
|---|---|
| 她的选法 | 不问「你喜欢吗」，只问「你穿多大」，好不好看她直接说了算 |
| 他的配合 | 站直、转身、抬手，配合得像量体，心里其实挺受用 |
| 唯一的否决权 | 有一件他是真穿不惯，说了句「这件不行」，她停下来看了他两秒，把那件放了回去。审美她管，否决权她不碰，这条线划得清清楚楚 |
| 店员视角 | 三轮下来店员就摸清了该跟谁说，介绍面料时眼睛看着她，外人很快就看出谁说了算 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 试衣间 ✓ | 门缝里递进去的下一件 · 他换到第四件时求饶：「跟第二件有区别吗」「袖口。闭嘴，穿。」 |
| 她的绕行 | 她绕他走半圈，打量一遍，他后颈发烫 |
| 镜子 ✓ | 镜子里的自己他有点认不出来，她挑的比他平时穿的高一档，而且挑得准 |
| 结账 | 他要抢着付，被她按住：「这是我给自己买的。」「这是我穿的。」「给我自己看的。」他绕不出来，闭了嘴 |

她嘴上说「给自己置景」，心里清楚意思是「给我自己看的」。接 [12-工作与金钱 · 她给钱他不要](12-工作与金钱.md#四--她给钱他不要)，到了买衣服这里，她的办法是把「给他花钱」换成这么个由头，他的自尊照顾到了，话也说得通。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 起因 | 日常换季 | 大场合前专门置办，见家长、她的年会，场合越重要，试衣间的门开一次关一次都不轻松 |
| 方向 | 她带他 | 他带她：他攒了三个月私房钱，就为带她进那家她看了三回都没进去的店，进门那一步他偷偷练过 |
| 否决权 | 用过一回 | 从来没用过，这就不对了：他什么都顺着，把自己顺没了，是她先觉察的 |
| 归宿 | 那件成了他「她选的」系列头一件 | 那件他只在见她的时候穿，衣服也分场合，这一点她后来才琢磨出来 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他说出「这件不行」后，她那两秒没吭声 | 她绕了半圈，他后颈那阵热 |
| 内心 | 他站那儿的样子，比模特强，因为是我的 | 被她挑着挑着，心里反而踏实 |
| 好的处理 | 她管归管，最后拿主意的还是他 | 他一年就说一回「不行」，说在点子上 |
| 写崩 | 写成她什么都管，他啥也不用干 | 写成他随便她怎么弄，没一点脾气 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 裁缝上门量体，她坐在一旁定料子、定绣样，只有腰封的花样他非要自己挑，她点了头 |

#### 写崩的三种方式

1. 试衣轮数不够。 起码五轮，从第一轮摇头到第五轮「就这件」，才写得出来。
2. 省掉否决权。 没有那句「这件不行」，就成了她什么都管。
3. 结账攻防别写成吵架。 那是个逻辑游戏，得笑着打完。

## 五 · 剪头发

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：理发 9.5%

**骨架**｜她一句“头发该剪了”，像下了通知，当天就得办。

#### 节拍链

她的一句判定 → 他摸头发（自我评估失效）→ 执行方案：理发店或她动手 → 剪的过程 → 完工验收 → 「验收标准」的谜底

#### 时间轴

**从判定到执行不超过 48 小时**。他剪个头发能纠结三周，她说一句「剪了」，当天他就坐进了理发店。

#### 两种执行方案

| 方案 | 戏 |
|---|---|
| 理发店 | 她跟着去，坐在等候区翻杂志，其实一直盯着，跟发型师对眼神，说了两次「后面再短一点」。他从镜子里看着两人拿他的脑袋谈判，插不上嘴 |
| 她动手 | 在家里阳台，推子是新买的。她剪得特别认真，像在做项目，他围着床单坐在凳子上。剪坏了一小块，她盯着那块半天没出声，最后来了句「行，挺个性，别照镜子」 |

她难得失手，失手后嘴硬也难得。

#### 可用细节

| 类 | 内容 |
|---|---|
| 验收 | 剪完她绕到后面看了一眼，手指在他后颈碰了一下，拂掉碎发，这一下算是整个过程里藏着的福利（接 [06-身体接触 · 后颈](06-身体接触.md#三--后颈)) |

| 碎发 | 床单上的碎发他抖了三回也没抖干净，之后一周家里到处都是，剪头发的余震全落在这上面 |

## 六 · 常去的那家店

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：外食 15.1%

**骨架**｜「老样子？」老板娘问。两人一起点头。这一声「老样子」，是两年攒出来的。

#### 节拍链

第一次进店（偶然）→ 第二次（顺路）→ 第 N 次（老板娘记住了）→ 「老样子」的诞生 → 店成为据点 → 某次变故（关店·搬迁·涨价）→ 据点的意义显形

#### 时间轴

时间看店家怎么认人：从「两位里面请」到「还坐老位置？」再到「老样子？」，最后只来了一个，老板娘会问「今天就一位？」。

#### 「老样子」的内容考古

| 层 | 内容 |
|---|---|
| 表层 | 固定菜色：她的少辣、他的多香菜、共享的那份主食 |
| 中层 | 固定座位：靠窗那桌，谁坐里侧。他习惯把外侧留给她，方便她出去接电话，这事两人从没商量过，自然就这么定了 |
| 深层 | 固定分工：他剥虾她吃（见 [八 · 剥虾](#八--剥虾)），她的醋碟他来调。微辣多蒜，她只说过一次，他照着配了两年 |

#### 可用细节

## 七 · 拧瓶盖与够高处

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：投喂 25.3%

**骨架**｜瓶盖拧不开就递给他，高处的碗够不着也叫他拿。力气上的事，这段关系里早就有了默认的规矩，两个人都觉得理所当然。

#### 节拍链

来了个瓶盖。她拧一下，两下，递过去，眼睛不看他，手伸过去就行。他拧开，递回来。一句话都没有。这已经是第一千次了。

#### 时间轴

按次数算，每一回都谈不上时长。头一次她还说了句「帮我拧下」，后来话都省了，递过去就行，从热恋一直到老夫老妻都是这样。

#### 力气分工的政治学

这一卷都在改老脚本，只有这一条照旧，照旧得理直气壮：

| 现象 | 解读 |
|---|---|
| 她开公司不开瓶盖 | 权力多大和手劲多大是两码事，递个瓶盖她根本不当回事 |
| 他专职瓶盖与高处 | 家里凡是要力气的活都归他，就这一份差事，他干得还挺乐呵 |
| 传说中的「假装拧不开” | 她从来不装，拧不开就是拧不开，装弱她学不会 |
| 他偷偷预拧 | 从超市回来，他把每个新瓶子都先拧松半圈，**活儿提前干了**，她一直没发现 |

她总以为自己「差一点就拧开了」，那半圈是他先拧的。

| 高处 | 她踮着脚够柜顶，才三秒他就过来了：「叫一声能死啊」「你不是来了嘛」 |
| 反例 | 他不在的那一周，她自己搬凳子把高处够了个遍，常用的东西全挪到了顺手的地方，**她其实什么都能干，平时只是懒得动**，这里要写上一笔 |

## 八 · 剥虾

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：外食 15.1% ＋ 投喂 25.3%

**骨架**｜虾一上桌，他的手先伸了过去，剥好第一只放进她碟里。满桌人看着，他不觉得有什么不对。

#### 节拍链

虾上桌 → 他动手剥 → 第一只放进她碟里 → 旁人的反应（有的话）→ 她吃着他剥着，节奏一直不乱 → 末了他匆匆吃上两只 → 洗手（柠檬水那一下）

#### 时间轴

**一盘虾吃完，这场戏就完。** 他照她吃的快慢来剥，她碟里一直留着一只。

#### 这个动作的语义场

剥虾在中文饭桌上是出了名的「伺候型」动作，谁给谁剥向来敏感：

| 场景 | 怎么看 |
|---|---|
| 私下 | 平常事，没人往深里想，顺手而已 |
| 她的商务局 | 他剥虾，满桌人都读成「这男人听她的」，他手上照样不停。她的合作方愣了两秒，她若无其事地夹起那只虾：**饭桌上摆出来的态度，比嘴上说一百句都管用**（接 [05-占有与吃醋 · 当众宣示](05-占有与吃醋.md#八--当众宣示)） |
| 他的兄弟局 | 兄弟们起哄「怕老婆实锤」，他把手里那只剥完才抬头：「羡慕就直说」，一句话把起哄的噎了回去（接 [14-社交与公开 · 被起哄](14-社交与公开.md#一--被起哄)) |
| 长辈桌 | 这一桌最悬。有位长辈脸色变了，她把话接过来：「他手快，我手笨」，把「伺候人」说成了「搭把手」，一句就圆过去 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 手法 | 掐头，两指捏住壳一旋，虾线挑干净。这是练出来的手艺，练了多久没人知道，他自己也不承认练过 |
| 库存管理 | 她碟里快空时，下一只准到 · 她吃慢了他就停手，从不往她碟里堆，**过日子讲的是分寸** |
| 反向流动 | 鱼归她管：她挑刺手快，鱼肚子上最嫩的那块总夹给他。**虾归他，鱼归她**，饭桌上各走一条道。光他剥虾只算伺候，两头都有了，才成了家里的规矩 |
| 尾声 | 他在柠檬水里洗手，她递过纸巾，事就这么收了，谁也没说谢 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 私下 | 四种饭局轮着写一遍，同一个动作有四种读法，一条能当四条用 |
| 她的态度 | 坦然受之 | 有一回她剥了一只给他，他愣得连虾都不会吃了，难得一回，所以金贵 |
| 过敏 | —— | 她的过敏史露了底：她对虾有点过敏，可又爱吃，一直自己控制着量。他知道以后，就替她管起了数：三只封顶，第四只没收 |
| 手的细节 | 常规 | 他手上带伤那回（接 [16-危机与保护](16-危机与保护.md#三--他受伤了)），她按下他伸向虾盘的手，自己来剥，剥得稀烂，他吃得一点不剩 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 商务局上她面不改色夹起的那只虾 | 她反过来给他剥的那只烂虾 |
| 内心 | 全桌都在重新掂量我们，掂量吧 | 三只封顶。她瞪我也就三只。 |
| 好的处理 | 她从来不拦一句「不用剥」，拦了反倒生分 | 那三只的数他管得死死的，她瞪眼也没用 |
| 写崩 | 写成她理所当然到没感觉 | 写成他低三下四伺候人 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 席间布菜本有规矩，他偏抢了侍者的活，亲手替她剔蟹，满座看傻了眼。她只说一句「他剔得干净」，事就这么定下了 |
| 修仙 | 灵果有刺，他空手剥了三百年，指尖哪里起了茧，只有她摸得出 |
| 星际 | 合成蛋白虾也带壳，仿得跟真的一样。他嘴上念叨「都合成了还带什么壳」，手上照剥，嘴里嫌弃手上不停，星际时代也还是这么疼人 |

#### 写崩的三种方式

1. 只写一个方向。鱼归她这条也要写。
2. 把四种饭局搅在一块写。每一场各有各的意思，要分开，一场写一场。
3. 乱用过敏设定。轻微过敏配上替她管数正合适，写到送急诊就过头了。

## 九 · 她把他堵在墙边

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：歌舞 25.7% ＋ 留痕 46.0%

**骨架**｜吵到一半他扭头要走，她一步跨上去，手撑在他耳边的墙上。他比她高一个头，这时候却像被钉在了原地。

#### 节拍链

吵起来或想躲（他转身要走）→ 她跨出一步 → 手拍上墙那一声轻响 → 身高差显得滑稽，也不顶用了 → 对视 → 隔着这点距离把话重新说 → 撤手，或者不撤

#### 时间轴

**从撑墙到撤手，通常不超过两分钟**。这姿势本来就撑不久，也用不着久，这两分钟里说的话，抵得上平时说两小时。

#### 高度差的物理学与心理学

常见的壁咚都是高个子堵矮个子。倒过来以后，每一样都跟着变了：

| 参数 | 常规版 | 她堵他版 |
|---|---|---|
| 视线 | 高的俯视 | 她仰着头，他低着头，仰头的反倒占了上风。谁高谁低一眼就看得出，气势却全在她这边 |
| 手的位置 | 与头齐平 | 她的手撑在他耳边，略微偏低，再高她够不着，也不需要够 |
| 逃逸路线 | 矮的钻不出去 | 他想走随时能走，门也没锁，他就是不走。能堵住，全凭他自己愿意（跟 [08-规训日常版](08-规训日常版.md)一个道理） |
| 滑稽风险 | 低 | 高。别躲，让两人都觉出好笑，再谁都不笑，这一幕就立住了 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 那一步 | 她那一步迈得干脆，和开会拍板时一样 |
| 他的双手 | 举在半空，不知道该往哪放，最后老老实实垂下来，就是投降的样子 |
| 距离内的话 | 声音压成了气声，说的却是刚才吼半天都没讲清的那件事。**离得越近，话反倒越说得开** |
| 撤手 | 话说完，她收手转身就走，他靠在墙边缓了三秒才跟上去 · 或者不收手，那就成了另一场戏（这里的分级到此为止，后面的去看 [17-同居与身体日常](17-同居与身体日常.md)) |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场景 | 吵架后一方要走，另一方拦 | 闹着玩：他抢了她的东西举高，她不跳，直接堵上去：「自己放下来」。个子高没用，被她一挡就白搭 |
| 反向 | —— | 他堵她的时候很少，得有正经理由才行：她一连三天躲着某个话题，他用这一招逼她给句准话。他撑墙的手在抖，她看见了，于是答了 |
| 观众 | 没人看见 | 有人看见：在公司走廊被同事撞了个正着。两人弹开有多快、事后怎么对口供，都当喜剧来写 |
| 语料频次注 | 「留痕 45%」这个窗口里，堵墙类肢体动作出现得多 | —— |

他堵人时手在抖，那是豁出去赌一把，谈不上拿权压人。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他双手垂下来的那一刻 | 仰视被堵，荒诞和心跳一起来 |
| 内心 | 高一个头有什么用，会自己低头就行 | 出得去。不出去。 |
| 好的处理 | 她堵的只是他要躲的话题，不为赢 | 他「不出去」是自己拿的主意，没被吓住 |
| 写崩 | 写成暴力压制 | 写成他吓到发抖 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他退到廊柱边，被她一把拦住，垂下的袖子挡住两人侧脸，古代自带帘子 |
| 修仙 | 他要跑，她一道结界封住三尺之地，里外的声音全隔断了，修仙的连隔音都不用操心 |
| 星际 | 舱道窄，本就只容一人过，她往那儿一站，通道就堵死了，船体都帮着她 |

#### 写崩的三种方式

1. 回避滑稽感。身高差明明好笑，两个人都心知肚明，却谁也不提，装作没这回事。
2. 把堵墙写成家常便饭。这招一年最多用两次，是压箱底的，平时别拿出来。
3. 漏掉「出得去」。他明明走得了，是自己不走。

## 十 · 电话里的声音

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：失联 23.2% ＋ 社交网 33.9%

**骨架**｜光听他打电话，猜不出是同一个人。接工作的、接她的、接他妈的，是三种完全不同的腔调。

#### 节拍链

她不知不觉听了很多回（无意识）→ 某天她发觉「频道切换」→ 开始攒证据 → 当面指出他的「她专属声线」→ 他不认 → 拿出铁证（录音 ✓ 对比）→ 这副嗓音被摆到明面上

#### 时间轴

**时间是一通一通电话攒起来的**，散在日常的无数通电话里。转折出在某天：她站在他背后，听他接她打来的电话，她拿的是同事的手机，亲耳听见他那声「喂」软了下来。

#### 声线频谱图

| 对象 | 他的声线 | 特征 |
|---|---|---|
| 工作 | 标准商务音 | 语速快上半档，尾音收得干净 |
| 兄弟 | 放飞音 | 音量高出三度，笑起来毫不收着 |
| 他妈 | 儿子音 | 嫌烦又黏人，带点撒娇 |
| 她 | **专属频道** | 接起来那声「喂」就软了半截，他自己都没发觉。**电话一通声音就变了，快得像压根没切换过** |

她也有一张声线图，方向反过来。她的「他专属频道」是语速慢下来：对谁说话都雷厉风行，只在这一个号码上放慢。

#### 可用细节

| 类 | 内容 |
|---|---|
| 指认现场 | 「你刚才接电话声音不一样。」「哪里不一样。」「你自己听。」她放了两段录音，一段是他接客户，一段是他接她。他听完不说话了：证据就摆着，何况他自己确实从没注意过 |
| 反向指认 | 他也放了两段她的录音。这回她沉默得更久，**她平时比他藏得还深，一露馅就更显分量** |
| 异地应用 | 两地分开的时候（接 [02-等待与错过 · 时差与异地](02-等待与错过.md#十--时差与异地)），能抓住的只剩声音。她从他那声「喂」里就听得出他今天累不累，**光凭声音就能判断**，基本没出过错 |
| 只打不视频 | 有些晚上他只肯打语音，不肯开视频：声音还放得开，脸上却挂不住 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 指认方向 | 她指认他 | 互相指认，两边都被抓了现行，两个人一起乱套 |
| 应用 | 音色诊断 | 把声音存下来：她偷偷存了他的一段语音 ✓ 拿来当闹钟。被他发现那天，他专门去录了一段正式的：「起床。再睡迟到了。……到点了，姐。」（接 [27-年龄差与姐弟 · 「姐」这个字](27-年龄差与姐弟.md#二--姐这个字)的三层楼应用） |
| 失效场景 | —— | 吵架时的电话：专属声线没了，换成了商务腔，冷战还没说出口，声音先冷了 |
| 终极形态 | —— | 多年以后她耳朵背了些，别人的话都得说两遍，只有他那声「喂」一遍就听得清，耳朵把他记了一辈子 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 用「同事手机」打的那通电话，她亲耳听见专属声线冒出来 | 闹钟里他自己的声音，还有补录的那声「姐」 |
| 内心 | 他自己都不知道。这种不知道最致命。 | 哪天商务音冒出来，比她说「我们谈谈」还吓人 |
| 好的处理 | 她听声辨人只为关心他，从不拿来审他 | 他那段闹钟录音改了三版，每版的结尾都不同 |
| 写崩 | 写成声纹监控 | 写成土味语音轰炸 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 隔着屏风帘子，话主要靠声音传。他在院墙那边喊一声「主君」，那个调子，府里下人怎么学也学不像 |
| 修仙 | 传音入密带着各人的声纹，她的话落进他识海，力道比落给别人的轻三分。他问过师兄，师兄说「传音哪有什么轻重」，他才知道只有自己听到的不一样 |
| 星际 | 通讯一有延迟，声音就成了家书（接 [21-世界设定专属 · 通讯延迟](21-世界设定专属.md#八--通讯延迟)），他这些年喊过的「喂」被她剪成一条音轨，跃迁静默期间来回地放 |

#### 写崩的三种方式

1. 把声线写成技巧。该写的是「本人毫无自觉」。
2. 拿录音实锤去吵架。实锤只能拿来甜，拿去吵就成了监控。
3. 漏写声音先变的那回。商务音冒出来那次必须写。
