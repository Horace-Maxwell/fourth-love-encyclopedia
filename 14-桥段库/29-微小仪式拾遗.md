> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）

## 拾遗的意思

前面几卷都是按生活场景分类的，但总有那么些场面卡在缝里：一副耳机、一支舞、一个拧不开的瓶盖。这些事太小，单独拎出来撑不起一个类型；但又太扎眼，扔了舍不得——**每一件都是性别脚本的微型考场**。跳舞谁带、虾谁剥、瓶盖谁开，老规矩里全都有默认答案，这一卷十条，就是十次重新答题。

| 节拍族 | 占比 |
|---|---:|
| 歌舞 | 25.7% |
| 外食 | 15.0% |
| 理发 | 9.5% |
| 置装 | 6.8% |

「歌舞」25.7% 排进全情境族前列：KTV 与舞池的场面语料里遍地都是，此前一直没有归处。

## 一 · 分享耳机

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.0%

**骨架**｜一人一只耳机，以前有线的时候线长就是距离，现在无线了，得自己乐意凑近才行。

#### 节拍链

一方在听 → 另一方好奇 → 摘下一只递过去 → 接过戴上 → 被迫（有线）或自愿（无线）的靠近 → 同一首歌的三分钟 → 摘下，还是没摘

#### 时间轴

一首歌就三四分钟，进度条摆在那，双方都清楚这场共享啥时候结束。时间到了还没摘，那意思就是明说了：再续一会儿。

#### 有线与无线的两种语法

| | 有线 | 无线 |
|---|---|---|
| 距离 | 线就那么长，拽着走 | 蓝牙范围大，近不近看心情 |
| 递出动作 | 递的是「过来」 | 递的是「给你一半」 |
| 经典画面 | 挤一个座，头快挨上 | 各坐一边，同一首歌里对眼 |
| 事故 | 线一扯掉，俩人一起「哎」 | 一只没电，换着戴同一只 |

「换着听同一只」是无线时代的新经典：一只耳机在两只耳朵间往返，比有线那根线更近。

#### 可用细节

| 类 | 内容 |
|---|---|
| 递出 | 擦了两下才递过去（他讲究）· 直接塞过来（她就这脾气） |
| 歌 | 他歌单里存着她那个年代的歌（接 [27-年龄差与姐弟 · 参照系错位](27-年龄差与姐弟.md#三--参照系错位)）· 她歌单里有首暴露心事的 |
| 三分钟 | 都假装在看别处 · 副歌时有人跟着轻轻晃，被对方偷偷看在眼里 |
| 结尾 | 「下一首也好听」——想续摊就这么说 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 通勤地铁 ✓ | 长途航班／病房陪护（地方越沉，耳机越轻） |
| 谁递 | 他 | 她（她递=她放你进她的频道，少见，分量重） |
| 歌的信息量 | 无 | 那首歌有故事（歌替她把没说的事讲了） |
| 结尾 | 摘下归还 | 「这只送你」——耳机从物件变成信物 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他递之前擦耳机的那两下 | 她的歌单和她本人的反差 |
| 内心 | 这歌单不像她的风格 | 副歌她晃了一下。记住了。 |
| 好的处理 | 她听完只说旋律好听，没问那首歌的事 | 他那句「下一首也好听」说得笨，反倒成了 |
| 写崩 | 写成借歌表白 | 把歌单一首首拆开讲 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 一张琴两个人听；她弹到一半让他按住一根弦——那根弦的震动从指尖传上来 |
| 修仙 | 传音入密共享一段旧录音；灵识并行的那三分钟，比任何双修都近 |
| 星际 | 舱内公共频道切成双人频道；歌单同步权限，星际版的「这只送你」 |

#### 写崩的三种方式

1. 靠歌词递话。 歌只负责制造三分钟，话另说。
2. 三分钟写成三页。 一首歌的事就是一首歌的篇幅。
3. 忽略终点。 副歌会完，没摘耳机那一下才是正文。

#### 示例（本库自撰，可直接改写）

> 「听什么呢，笑成这样。」
> 他把右耳那只摘下来，在袖子上擦了两下，递过去。
> 地铁正好进站，轰隆声里她把耳机塞进耳朵，前奏刚起就愣了一下——这歌比他大十岁。
> 「你怎么会听这个？」
> 「好听啊。」他说得理所当然，「你高中是不是天天听？」

> 副歌起来的时候，她的脚尖跟着点了两下。他盯着窗外，把这两下记在了别人看不见的地方。

## 二 · 学跳舞

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：歌舞 25.7%

**骨架**｜商务晚宴要跳舞。学舞第一步就是分工：一个带，一个跟。教材默认男带女跟。他俩盯着教材愣了三秒。

#### 节拍链

跳舞需求出现 → 报班或自学 → 「谁领」的第一课 → 试两种分工 → 找到他们的答案 → 晚宴实战 → 舞池里只有他们知道的秘密

#### 时间轴

**以练习次数计。** 第一次互相踩脚，第三次能转起来，到第七次，教练不再纠正他们谁领谁跟了，因为看不出来了。

#### 「谁领」的三轮实验

| 轮 | 分工 | 结果 |
|---|---|---|
| 第一轮 | 按教材：他领 | 他领得心虚，指令迟疑，两人频频撞拍——**发号施令对他是外语** |
| 第二轮 | 换过来：她领 | 顺畅得惊人，她的手一搭他就懂——但舞姿在旁人眼里「不合惯例」，晚宴上会被看 |
| 第三轮 | 混合：进门他领，人少处换她 | 外循环他领（给世界看），内循环她领（给自己跳）——**一支舞两套制度**，正是这段关系的微缩模型 |

「一支舞两套制度」：他们对付传统脚本的总方案，被一支华尔兹跳了出来。

#### 可用细节

| 类 | 内容 |
|---|---|
| 练习 | 客厅茶几推开 · 手机 ✓ 外放舞曲 · 踩了脚，道歉从客气到随便到干脆不吭声 |
| 领舞的手 | 信号全在手掌根：推半寸、收半寸——她给得轻，他接得准（接 [11-初遇与确立 · 她教他](11-初遇与确立.md#六--她教他)的镜像：这门课他学得最快） |
| 晚宴 | 全场都按老规矩跳；只有他俩转着转着，悄悄换了三次领跟，没人看出来 |
| 秘密 | 跳完有人夸「他领得真稳」，两人对视一笑——稳的是谁，心里有数就行 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 起因 | 就是接个商务活 | 图个开心（婚礼头一支舞先拿这儿练手，接 [23-婚嫁](23-婚嫁.md#七--当天)） |
| 学习曲线 | 俩人都没底 | 她会他不会（她正经学过——为啥学的，引出她小时候的事，接 [30-她的世界](30-她的世界.md#六--她的少女时代)) |
| 答案 | 按老规矩来 | 干脆不跳套路，跳只有他俩会的（婚礼上那支舞把全场看愣了） |
| 秘密归宿 | 没人知道 | 被内行一眼认出（对方举杯冲她晃了晃，啥也没说——懂行的打招呼） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 掌根信号被接住的第一次 | 「他领得真稳」那句夸奖的荒诞 |
| 内心 | 他跟着我走，比我领得还顺——这话怎么越品越像我们俩 | 外圈我领。她交代的事，我办得漂亮。 |
| 好的处理 | 她领得不动声色，晚宴上把「被领」演得滴水不漏 | 他不觉得跟着走是输——跟个好领舞，是舞池里最舒服的事 |
| 写崩 | 写成她当众抢风头 | 写成他学舞学出屈辱感 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 宫宴上按规矩得是妻主先伸手；私宴上他们换了套跳法，乐师瞅见了，悄悄把节拍改了半分跟着走 |
| 修仙 | 双修剑舞，剑谱里写的是男带女；他俩把批注改了，那页传回门里，后来竟成了新范本 |
| 星际 | 授勋舞会的舞步全写在礼仪程序里；他俩申请了「自定义模式」，审批官盖章时嘴角没绷住 |

#### 写崩的三种方式

1. 第一轮就换她领。他领砸了，得先老老实实让人看见。
2. 这两套规矩跟外人说透了，舞池里那点事就全漏底了。
3. 领跟别写成谁压谁。好的领跟是搭话，不是下命令。

## 三 · KTV他唱给她

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：歌舞 25.7% ＋ 聚会 12.0%

**骨架**｜包厢轮到他点歌，前奏一响她就愣了——这歌她熟，比他大十岁那年就听烂了。

#### 节拍链

聚会进包厢 → 他一直没点歌（憋大招）→ 前奏起 → 她认出的那半秒 → 他开口（练过的痕迹藏不住）→ 全场起哄 → 唱完的处理

#### 时间轴

**这条的前史长达数周**：他偷偷练歌的那些晚上（洗澡时压着嗓子、通勤路上单曲循环）全部折叠在前奏响起的那三秒里。写作时前史后置：先唱，再让她拼出他练过的证据。

#### 麦克风的权力学

KTV 是个微型舞台，拿麦的人临时持有全场注意力：

| 现象 | 说明 |
|---|---|
| 他平时从不抢麦 | 低调是常态 |
| 这首歌他提前两小时就切了歌 | 蓄谋 |
| 唱给她但眼睛不看她 | 盯着屏幕唱完，副歌最后一句才转头——**目光落下的时机，就是告白的话** |
| 起哄声中他把麦放下 | 说「跑调了别笑」——用自嘲接住全场起哄，护住她的难堪 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 破绽 | 转音跟原唱不一样，跟她手机里那个 live 版一模一样——他练的就是她听的那版 |
| 她的反应 | 别人看她笑着，只有她自己知道那口气堵在哪 |
| 起哄 | 「再来一个」他死活不干——那首是唱给她的，再唱就成演出了 |
| 归途 | 车里她问「练了多久」，他说「没练」；等红灯时她放出那首 live 版，他耳朵红了 |

「练的是她听的版本」，比唱歌本身重的是版本考据：他不但知道她爱这首歌，还知道她爱哪一版。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 朋友聚会 | 就俩人待着的包厢（没人起哄，安静多了，也沉多了） |
| 唱功 | 一听就是练过的 | 真跑调（跑调版更好：她听完说「难听死了」，然后把他这段录音循环了一礼拜 ✓） |
| 方向 | 他唱给她 | 她唱给他（她平时不怎么开口，一年也就唱一回；她点的是他那个年代的歌——时间对不上，但这份心意他接住了） |
| 归宿 | 回去路上对质 | 那首歌成了俩人之间的暗号（前奏一响就对视，接 [19-玩闹与网络 · 只有他们懂的梗](19-玩闹与网络.md#六--只有他们懂的梗)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 副歌最后一句他转头的时间差 | 前奏响起时她脸上那半秒的空白 |
| 内心 | 这版……他怎么知道这版 | 三十七个晚上。值了。 |
| 好的处理 | 她一直忍着没哭，出了包厢才在洗手间缓了一分钟 | 他不想返场，直接拒了 |
| 写崩 | 写成她当场哭出来 | 写成他满场炫技 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 家宴上他弹了支她及笄那年流行的老曲子；大伙儿光顾着感慨，她盯着他拨弦的手——那指法，是按她旧琴谱上的批注练的 |
| 修仙 | 门里小聚他吹了段她当凡人时听过的乡音小调；那调子，是他专门去她老家蹲了半个月学来的 |
| 星际 | 舰上晚会他唱了首地球老歌；伴奏是他自己扒谱敲进系统的——系统曲库里压根没这首 |

「曲库里根本没有这首」，星际版的三十七个晚上。

#### 写崩的三种方式

1. 前史先铺。 练歌过程必须后置成考据。
2. 唱功写成演唱会。 破绽和跑调比完美动人。
3. 唱完直接告白。 那首歌已经是了，再说话就重复了。

## 四 · 她带他买衣服

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：置装 6.8%

**骨架**｜她说你这件该换了。半小时后他站在试衣间里，听她跟店员聊他肩多宽。

#### 节拍链

起因（一件旧衣或一个场合）→ 进店 → 她选他试 → 试衣间门开合若干轮 → 店员的站队 → 定夺 → 结账的攻防 → 穿出门

#### 时间轴

**以试衣间门开合的轮数计。** 每开一次门就是一次评审：第一轮她摇头，第三轮她沉默地绕他走了半圈，第五轮她说「就这件」，门每开合一次，心跳就跟着走一格。

#### 「被打扮」的权力语法

她给他选衣服，与 [06-身体接触 · 系扣子](06-身体接触.md#七--系扣子)同一族谱，但战线更长：

| 环节 | 机关 |
|---|---|
| 她的选法 | 不问「你喜欢吗」，问「你穿多大」——审美这事她直接说了算 |
| 他的配合 | 站直、转身、抬手，配合得像量体，心里其实挺受用 |
| 唯一的否决权 | 他对某件真心不适的说了「这件不行」——她停下来看了他两秒，把那件放回去了。**接管审美不接管否决权**，这条线划得清清楚楚 |
| 店员视角 | 店员三轮后就摸清了跟谁汇报，介绍面料时眼睛看她——外人很快看懂了谁说了算 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 试衣间 ✓ | 门缝里递进去的下一件 · 他换到第四件时的求饶：「跟第二件有区别吗」「袖口。闭嘴，穿。」 |
| 她的绕行 | 绕他走半圈的那次打量，他后颈发烫 |
| 镜子 ✓ | 他看镜里的自己有点认不出——她挑的比他平时穿的高一档，还准 |
| 结账 | 他抢单被按住：「这是我给自己买的。」「这是我穿的。」「给我自己看的。」——绕不出来了，他闭嘴 |

「给我自己看的」，她把「给他花钱」重新包装成「给自己置景」，他的自尊被这个说法照顾得妥妥帖帖（接 [12-工作与金钱 · 她给钱他不要](12-工作与金钱.md#四--她给钱他不要)的衣装特化解法）。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 起因 | 日常换季 | 大场合前专门备衣服（见家长／她的年会——场合多重要，门一开一关都压着分量） |
| 方向 | 她带他 | 他带她（少见：他攒了仨月私房钱，就为带她进那家她看了三回没进去的店——进门那步他偷偷练过） |
| 否决权 | 用过一回 | 从没用过（不对劲：什么都顺着不是配合，是把自己弄没了，她先觉出来） |
| 归宿 | 那件成了他「她选的」系列头一件 | 那件他只见她时才穿——衣服分场合，她后来才咂摸出来 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她冒出「这件不行」前，那两秒没吭声 | 他绕了半圈，后颈那阵热 |
| 内心 | 他站那儿的样子，比模特强——因为是我的 | 被她挑着挑着，心里反而踏实 |
| 好的处理 | 她管归管，最后拿主意的还是他 | 他一年就说一回「不行」，说在点子上 |
| 写崩 | 写成她什么都管，他啥也不用干 | 写成他随便她怎么弄，没一点脾气 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 裁缝上门量体；她坐旁边定料子、定绣样，就腰封花样他非要自己挑——她点头了 |
| 修仙 | 她给他炼法衣；灵材配色她定，防御阵纹他自己画——各管一摊，都写在衣服上 |
| 星际 | 制服定制终端前她调参数；最后一项「个性徽记」的编辑权她让给了他 |

三个换皮同一个结构：**她定整体，留一处他的自留地**：那一处是这条的文眼。

#### 写崩的三种方式

1. 试衣轮数不够。至少得试五轮，门的心跳图才画得出来。
2. 否决权不能少。少了那次「这件不行」，接管就成吞并了。
3. 结账攻防别写成吵架。那是逻辑游戏，笑着打完才算数。

## 五 · 剪头发

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：理发 9.5%

**骨架**｜她说“头发该剪了”，这话跟下文件似的，当天就得执行。

#### 节拍链

她的一句判定 → 他摸头发（自我评估失效）→ 执行方案（理发店或她动手）→ 剪的过程 → 完工验收 → 「验收标准」的谜底

#### 时间轴

**从判定到执行不超过 48 小时**：这速度本身就是关系的注脚——他剪个头发能纠结三周，她一句“剪了”当天就坐进理发店。

#### 两种执行方案

| 方案 | 戏 |
|---|---|
| 理发店 | 她跟着去，坐等候区翻杂志——其实全程盯着：跟发型师对眼神，两次说「后面再短一点」。他从镜子里看这场拿他脑袋当谈判桌的戏，插不上嘴 |
| 她动手 | 家里阳台，推子是新的。她剪得特认真（跟做项目似的），他坐凳子上围着床单——剪坏一小块，她盯着那块半天没说话，最后来了句「行，挺个性，别照镜子」 |

「剪坏了不许照镜子」是家庭理发的传世笑点，**她极少失手，失手后的嘴硬是稀有画面**。

#### 可用细节

| 类 | 内容 |
|---|---|
| 验收 | 剪完她绕后看了一眼，手指在他后颈 ✓ 碰了一下拂掉碎发——这一下是全流程的隐藏福利（接 [06-身体接触 · 后颈](06-身体接触.md#三--后颈)) |
| 谜底 | 「为什么突然要我剪头发？」「上周同学会有人说你头发长了显小。」——**她这么在意，其实是怕外头人闲话**（接 [27-年龄差与姐弟](27-年龄差与姐弟.md#四--被认成姐弟)) |
| 反向 | 她要剪短发那次，他罕见地表达了强烈意见：「别。」「理由？」「……自私的理由。」她留了长发，谁都没再提 |
| 碎发 | 床单上的碎发他抖了三次没抖干净，接下来一周家里各处都是——理发的余震全落在这儿了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 执行方案 | 理发店遥控 | 亲手（亲手版的信任浓度另算：推子贴着头皮，他闭着眼一动不动） |
| 谜底 | 外部评论清剿 | 没有谜底，纯粹手痒——「就是想看看你短发的样子」，任性版的她 |
| 反向意见 | 他行使了一次 | 他没拦住（她剪了短发，他适应了三天，第四天承认「也好看」——审美的服软过程完整记录） |
| 失手 | 小块 | 大型翻车（第二天他戴着帽子上班，同事问起，他说「她剪的」，语气里没有一点抱怨还有点得意——翻车变炫耀） |
| 工具升级 | 推子 | 剃刀（她替他刮脸：刃口贴着喉咙的信任仪式，全程他仰着头一动不敢动；古代版是替他修面，与他替她篦头互为回礼） |

「翻车变炫耀」，帽子下的失败发型是他的勋章，这一心理只有这个类型的读者秒懂。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 拂后颈碎发那一下的指尖 | 「别照镜子」的心虚 |
| 内心 | 剪坏了。嘴上不能认。 | 她拿我的头当项目管理，进度还挺赶 |
| 好的处理 | 她的失手写实：技术翻车，态度嘴硬，补救认真（第二天预约了 tony 老师返工） | 他的「自私的理由」不展开——四个字够了 |
| 写崩 | 写成她完美 tony | 写成他发型焦虑 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 身体发肤，剪头发是天大的事；她给他篦头、束发、戴冠——梳头这活儿看着不起眼，可比剪发金贵多了（接 [01-日常照料 · 洗头与吹头发](01-日常照料.md#八--洗头与吹头发)) |

| 星际 | 舱里那个自动理发舱她信不过：「机器哪懂什么叫好看。」干脆手动，她亲自上手 |

1. 判定到执行拖一周。48 小时是这条的制度速度。
2. 失手当无事发生。嘴硬和返工预约都要有。
3. 「自私的理由」写透。四个字的留白是他一年的情话额度。

## 六 · 常去的那家店

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：外食 15.0%

**骨架**｜「老样子？」老板娘问。俩人一块儿点头。这声“老样子”，他们攒了两年。

#### 节拍链

第一次进店（偶然）→ 第二次（顺路）→ 第 N 次（老板娘记住了）→ 「老样子」的诞生 → 店成为据点 → 某次变故（关店·搬迁·涨价）→ 据点的意义显形

#### 时间轴

**以「店认人的本事」来看**：从「两位里面请」到「还坐老位置？」到「老样子？」到最后——他们没到，老板娘会问「今天就一位?」，**店成了他俩关系的存档点**。

#### 「老样子」的内容考古

| 层 | 内容 |
|---|---|
| 表层 | 固定菜色：她的少辣、他的多香菜、共享的那份主食 |
| 中层 | 固定座位：靠窗那桌，谁坐里侧（他，习惯把外侧留给她——外侧方便她接电话进出，这个安排从没讨论过，自动成形） |
| 深层 | 固定分工：他剥虾她吃（见 [八 · 剥虾](#八--剥虾)），她的醋碟他调（微辣多蒜，她口述过一次，他配了两年） |

#### 可用细节

| 类 | 内容 |
|---|---|
| 老板娘 | 全店就她从头看到尾：头一回俩人客气得不行，冷战那阵各来各的（她全看在眼里，一个字没问），后来俩人一块儿回来了——她多送了碟小菜，啥也没说 |
| 熟客特权 | 快打烊了也让进 · 新菜先紧着他们尝 · 有年墙上贴了张「本店招牌：xx」，那道菜就是他们吃出来的 |
| 变故 | 店要搬走那晚，俩人专门去吃了顿「散伙饭」，老板娘把新地址写在纸条上递过去——那纸条被他好好收进了钱包 |
| 存档功能 | 冷战那阵他一个人去过一次；老板娘上菜时把「她那份」的位子空着没摆碗筷——空着的那块比啥劝和的话都管用 |

「空位没收」，老板娘的沉默劝和，第三方存档的最高操作。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 店的档次 | 苍蝇馆子（推荐——迷路捡来的那家，接 [25-意外与困境 · 迷路](25-意外与困境.md#六--迷路)) | 有点贵的（那是纪念日专属店，另一套「老样子」） |
| 变故 | 搬迁 | 永久关店（两人站在贴着转让告示的卷帘门前，像丢了一间自己的房） |
| 老板娘 | 沉默见证者 | 多话型（每次都问「什么时候办事啊」，成了外部催婚的分店，接 [13-家庭与亲属 · 催](13-家庭与亲属.md#三--催)) |
| 存档调用 | 日常 | 多年后带孩子来：「爸爸妈妈以前总坐这桌」——存档移交下一代 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 那个自动成形的里外侧座位安排 | 醋碟配了两年没配错过 |
| 内心 | 这家店知道我们多少事 | 她的「老样子」有七项参数，我全记着 |
| 好的处理 | 她对老板娘的信任写在细节里：唯一敢当外人面卸下三分总裁架子的地方 | 他的记性不显摆，露馅是某次她口味变了他先察觉 |
| 写崩 | 写成美食探店文 | 写成他背菜单炫技 |

|---|---|
| 古代女尊 | 街角那家馄饨摊；摊主看着他们从便服私会吃到带着仪仗来——碗还是那种粗瓷碗，她要求的 |
| 修仙 | 山下凡人镇的那家酒肆；掌柜的孙子都接班了，他们容颜未改——「二位仙长，还是老位置」成了三代传承的接头暗号 |

1. 店写成布景板。 老板娘必须有眼睛有判断。
2. 「老样子」不给内容。 七项参数至少露三项。
3. 变故不发生。 据点要经历一次动摇，意义才显形。

## 七 · 拧瓶盖与够高处

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：投喂 24.0%

**骨架**｜瓶盖拧不开就递给他，高处的碗够不着就他来拿。力气这事儿，在这段关系里就按老规矩来，俩人都觉得理所当然。

#### 节拍链

瓶盖出现 → 她拧（一下·两下）→ 递过去（不看他，手伸过去就行）→ 他拧开递回 → 全程无话 → 这套流程的第一千次执行

#### 时间轴

这条没有单场时长，只有执行次数。从第一次的「帮我拧下」到后来的免言语递送，流程熟到成了反射。反射本身就是热恋期到老夫老妻的换算表。

#### 力气分工的政治学

这一卷都在改写传统脚本，唯独这条原样保留，保留得理直气壮：

| 现象 | 解读 |
|---|---|
| 她开公司不开瓶盖 | 权力大小跟手劲没关系，她压根没觉得递个瓶盖算什么事 |
| 他专职瓶盖与高处 | 家里所有跟力气沾边的活儿都归他，就这一个岗位，干得还挺乐呵 |
| 传说中的「假装拧不开” | 她从来不装——拧不开就是拧不开，装弱这招她学不来 |
| 他偷偷预拧 | 超市回来他把每个新瓶子都先拧松半圈——**提前把活儿干了**，她一直没发现 |

「他偷偷预拧」是这条的糖芯：她以为自己每次都「差一点就拧开了」，那半圈是他埋的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 递送 | 她眼睛盯着屏幕，手往旁边一伸，他活儿没停，拧开瓶盖递回去，她接过来就喝——俩人各干各的，配合得一点不差 |
| 高处 | 她踮脚够柜顶那三秒他就过来了——「叫一声能死啊」「你不是来了嘛」 |
| 反例 | 他不在那周，她自己搬凳子把高处够了个遍，常用的东西全挪到顺手的地方——**她其实啥都能干，就是平时懒得动**，这地方得写一笔 |
| 穿帮 | 有天她拧开一瓶新果酱，愣了下——手感不对，太松了。当晚她把全屋瓶瓶罐罐挨个拧了一遍，发现全被人提前拧松过，他给按沙发上交代干了多久：「……三年。」 |

| 轴 | 一端 | 另一端 |
|---|---|---|
| 曝光 | 三年后穿帮 | 永不曝光（读者知道，她不知道——留给读者的私藏糖） |
| 反向 | —— | 也有他够不着的：情绪的高处。她替他够——这条的抒情转译，点到即止 |
| 力气对比 | 常规 | 她其实力气不小（拎行李箱那位，接 [24-校园与青涩 · 学姐](24-校园与青涩.md#一--学姐)）——拧不开瓶盖纯粹是握力点位问题，物理学还她清白 |

「开瓶器进抽屉最深处」，工具能替代功能，替代不了流程。流程是他们的。

| 写崩 | 写成她装柔弱 | 写成大男子主义秀场 |

「以后拧四分之三圈」，她给地下工程发了正式编制，并附技术标准。

## 八 · 剥虾

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：外食 15.0% ＋ 投喂 24.0%

**骨架**｜一盘虾端上来，他手自己就过去了，剥了第一只放她碟子里。一桌人都看着，他也没觉得咋的。

#### 节拍链

虾上桌 → 他开剥 → 第一只入她碟 → 旁观者反应（如果有）→ 她吃他剥，节奏稳定 → 最后他匆匆吃两只 → 洗手（柠檬水那一下）

#### 时间轴

**一盘虾的量就是时长。** 剥的速度与她吃的速度之间有个稳定比值。他维持着「她碟中常有一只」的库存水位，像个尽职的供应链。

#### 这个动作的语义场

剥虾在中文饭桌语义里位置特殊：它是最著名的「伺候型」动作，方向历来敏感：

| 场景 | 语义 |
|---|---|
| 私下 | 纯日常，没人多想，就是顺手 |
| 她的商务局 | 他剥虾，全桌都看成「这男人听她的」——他照剥。她合作方愣了两秒，她没事人一样夹起那只虾：**饭桌上亮态度，比嘴上说一百句都顶用**（接 [05-占有与吃醋 · 当众宣示](05-占有与吃醋.md#八--当众宣示)） |
| 他的兄弟局 | 兄弟起哄「怕老婆实锤」；他剥完那只才抬头：「羡慕就直说」——起哄被一句话噎回去（接 [14-社交与公开 · 被起哄](14-社交与公开.md#一--被起哄)) |
| 长辈桌 | 最悬的一桌：某位长辈脸色变了；她接住：「他手快，我手笨」——把「伺候人」说成「搭把手」，一句话圆过去 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 手法 | 掐头、两指捏壳一旋、虾线挑净——这手艺是练出来的，练了多久没人知道（他自己不认） |
| 库存管理 | 她碟里快空了，新的一只准到 · 她吃慢了他就停，绝不堆着——**过日子讲的是分寸，不是囤货** |
| 反向流动 | 鱼是她的地盘：挑刺快得很，鱼肚子最嫩那块永远夹给他——**虾归他，鱼归她**，饭桌上两条道 |
| 尾声 | 柠檬水里他洗手，她递纸巾——事就这么收尾，谁也没多说一句谢 |

「虾向东，鱼向西」是这条的题眼：单向剥虾是伺候，双向供应链是制度。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 私下 | 四种饭局挨个来一遍（同一动作四种说法，一条顶四条） |
| 她的态度 | 坦然受之 | 有一次她剥了只给他——他愣得虾都不会吃了（反过来，越难得越金贵） |
| 供应链危机 | —— | 她过敏史曝光：其实她对虾轻微过敏但爱吃，一直控制量——他知道后接管了配额管理：三只封顶，第四只没收。**供应商兼管账的** |
| 手的细节 | 常规 | 他手上有伤那次（接 [16-危机与保护](16-危机与保护.md#三--他受伤了)），她按住他伸向虾盘的手，自己剥——剥得稀烂，他吃得干净 |

「剥得稀烂他吃得干净」，技术不重要，方向变了才重要。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 商务局上那只面不改色夹起的虾 | 她反向剥的那只烂虾 |
| 内心 | 全桌都在重新掂量我们，掂量吧 | 三只封顶。她瞪我也就三只。 |
| 好的处理 | 她从不拦着说「不用剥」——一拦就见外了 | 他管配额管得死严，她瞪也没用 |
| 写崩 | 写成她理所当然到没感觉 | 写成他低三下四伺候人 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 席上布菜有规矩；他抢了侍者的活，亲手给她剔蟹——满座都看傻了，她一句「他剔得干净」，这事就定了 |
| 修仙 | 灵果带刺；他徒手剥了三百年，指尖的茧长在哪，只有她摸得出来 |
| 星际 | 合成蛋白虾还带壳（拟真度拉满）；他嘴上说「都合成了还带什么壳」，手上照剥——嘴上嫌弃，手上不停，这就是星际时代的爱 |

#### 写崩的三种方式

1. 只写单向。鱼往西边送的那条供应链，必须得打通。
2. 四种饭局混着写。一场一个意思，别搅在一起，一场一场来。
3. 过敏设定别乱用。轻微过敏配个配额管理正好，写成送急诊就过了。

## 九 · 她把他堵在墙边

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：歌舞 25.7% ＋ 留痕 45.0%

**骨架**｜吵到一半他要走，她一步跨过去，手撑在他耳边的墙上。他比她高一个头，这会儿却跟钉住了一样。

#### 节拍链

争执或逃避（他转身要走）→ 她的一步 → 手撑墙的那声轻响 → 高度差的滑稽与失效 → 对视 → 话到了这个距离上重新说 → 撤手或不撤

#### 时间轴

**从撑墙到撤手，通常不超过两分钟**：这个姿势撑不了更久，也不需要更久——两分钟内说的话，密度顶平时两小时。

#### 高度差的物理学与心理学

壁咚的经典构图默认高的堵矮的。反过来之后每个参数都变了：

| 参数 | 常规版 | 她堵他版 |
|---|---|---|
| 视线 | 高的俯视 | 她仰头，他低头——**仰头的人反而占上风**，谁高谁低一看就懂，但气势全在她那边 |
| 手的位置 | 与头齐平 | 她手撑在他耳朵旁边，稍微偏下一点——够不着更高的地方，也用不着够 |
| 逃逸路线 | 矮的钻不出去 | 他随时能走——**门没锁，他就是不走**：这堵全靠他乐意，不是堵得住（跟 [08-规训日常版](08-规训日常版.md)那套一个理） |
| 滑稽风险 | 低 | 高——别躲，让俩人都觉得好笑，然后谁都不笑，这事就稳了 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 那一步 | 她跨步的果断和她开会拍板一个样 |
| 他的双手 | 举在半空不知往哪放，最后老实垂下——投降的标准姿势 |
| 距离内的话 | 音量压到气声，说的却是刚才吼着讲不清的那件——**离得越近，话反而说得开** |
| 撤手 | 说完她撤手转身走人，他在墙边缓了三秒才跟上 · 或者不撤——转成另一场戏（分级就到这里，后面走 [17-同居与身体日常](17-同居与身体日常.md)) |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场景 | 吵架后一方要走，另一方拦 | 闹着玩（他抢了她东西举高——她不跳，直接堵：「自己放下来」；个子高没用，人墙一挡啥都白搭） |
| 反向 | —— | 他堵她（很少见，除非有正当理由：她连着三天躲一个话题，他拿这招逼她给个准话——他堵人的手在抖，她看见了，就答了） |
| 观众 | 没人看见 | 有人看见（公司走廊，被同事撞见——俩人弹开的速度和事后对口供，当喜剧写） |
| 语料频次注 | 「留痕 45%」窗口里堵墙类肢体动作写得多 | —— |

「他堵人的手在抖」，他版壁咚的全部合法性来自这个抖：这是孤注一掷，不是权力动作。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他垂下双手的那个瞬间 | 仰视着被堵的荒诞与心跳同时到账 |
| 内心 | 高一个头有什么用，会自己低头就行 | 出得去。不出去。 |
| 好的处理 | 她的堵只用于截住要逃的话题，不用于赢 | 他的「不出去」写成选择而非慑服 |
| 写崩 | 写成暴力压制 | 写成他吓到发抖 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他退到廊柱，她一把拦住；袖子垂下来挡住两人侧脸——古代版自带帘子 |
| 修仙 | 他想跑，她一道结界封住三尺地；里头外头声音全断——修仙版连隔音都省了 |
| 星际 | 舱道窄，本来就一人过；她往那一站，通道自动锁死——船体结构都帮她 |

#### 写崩的三种方式

1. 滑稽感回避。 身高差这事，俩人都知道挺好笑，但谁都不提，当它不存在。
2. 堵墙常态化。 一年最多用两回。这招是压箱底的大招，不是没事就甩的日常台词。
3. 忽略「出得去」。 他明明能走，却选择不走——这条线全部的劲儿都在这。

## 十 · 电话里的声音

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：失联 23.0% ＋ 社交网 33.0%

**骨架**｜他打电话时，你光听声音，根本想不到是同一个人。接工作电话、接她电话、接他妈电话，完全是三种腔调。

#### 节拍链

声音样本采集期（无意识）→ 某天她发现「频道切换」→ 开始收集证据 → 他的「她专属声线」被指认 → 他不承认 → 实锤（录音 ✓ 对比）→ 声线的公开化

#### 时间轴

**这条以「音色样本」积累计**，横跨日常无数通电话。转折点是她某天在他背后听他接起她打的电话（她用了同事手机），亲耳听见自己专属声线的诞生现场。

#### 声线频谱图

| 对象 | 他的声线 | 特征 |
|---|---|---|
| 工作 | 标准商务音 | 语速快半档，尾音干净 |
| 兄弟 | 放飞音 | 音量大三度，笑声不加掩饰 |
| 他妈 | 儿子音 | 又烦又黏，混着撒娇 |
| 她 | **专属频道** | 接起电话那声「喂」就软了半截，自己都没察觉——**一接通就变，快得跟没切换似的** |

她的声线图谱也有，而且是反着来的：她的「他专属频道」特征是语速降下来：对全世界雷厉风行的语速，只对一个号码放慢。

#### 可用细节

| 类 | 内容 |
|---|---|
| 指认现场 | 「你刚才接电话声音不一样。」「哪里不一样。」「你自己听。」她放了两段录音——一段他接客户，一段接她。他听完沉默了：证据摆在那，而且他自己真没留意过 |
| 反向指认 | 他反过来放她的两段。她沉默得更久——**她平时藏得比他还深，这一露馅，分量更重** |
| 异地应用 | 异地时（接 [02-等待与错过 · 时差与异地](02-等待与错过.md#十--时差与异地)）声音是唯一能抓得住的东西；她开始能从他那声「喂」里听出今天累不累——**光听声就能断人**，基本没跑偏过 |
| 只打不视频 | 有的晚上他只肯语音不肯视频——声音放得开，脸上挂不住 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 指认方向 | 她指认他 | 互相指认（两边都实锤了，两台失控现场） |
| 应用 | 音色诊断 | 声音的保存：她偷偷存了他一段语音 ✓ 当闹钟——被他发现那天，他去录了段正式版：「起床。再睡迟到了。……到点了，姐。」（接 [27-年龄差与姐弟 · 「姐」这个字](27-年龄差与姐弟.md#二--姐这个字)的三层楼应用） |
| 失效场景 | —— | 吵架期电话：专属声线没了，变成商务腔——**声线降级比冷战宣言还早一步** |
| 终极形态 | —— | 多年后她耳朵有点背，别人说话都得重复，就他的「喂」一遍就听清——耳朵替他记了一辈子 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 亲耳听见专属声线诞生的那通「同事手机」电话 | 闹钟里自己的声音，和那句补录的「姐」 |
| 内心 | 他自己都不知道。这种不知道最致命。 | 商务音上线的那天，比她说「我们谈谈」还可怕 |
| 好的处理 | 她的音色诊断只用于关心，不用于审讯 | 他的录音闹钟版本迭代了三次，每版结尾都不一样 |
| 写崩 | 写成声纹监控 | 写成土味语音轰炸 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 隔着屏风和帘子，声音就是传话的主道；他在院墙那头喊一声「主君」，那调子府里下人学都学不像 |
| 修仙 | 传音入密自带声纹；她的话落进他识海里，力道比对别人轻三分——他问过师兄，师兄说「传音哪有什么轻重」——原来只有他的不一样 |
| 星际 | 通讯一延迟，声音就成了家书（接 [21-世界设定专属 · 通讯延迟](21-世界设定专属.md#八--通讯延迟)）；她把他这些年喊的「喂」剪成一条音轨，跃迁静默那阵子翻来覆去地放 |

「传音哪有轻重——原来只有他的有」：修仙版一句话写完全条。

#### 写崩的三种方式

1. 声线写成技巧。 全部价值在「本人毫无自觉」。
2. 录音实锤用于吵架。 实锤只能用于甜，用于吵就成了监控。
3. 预警系统不启用。 商务音上线那次必须写，它是声音版的冷战前哨。
