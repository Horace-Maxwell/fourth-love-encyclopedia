# 宫廷与朝堂

> **分级** 分级见各条，分级上限 `M` ｜ 预警 ⚠️示众（第九条） ｜ 亚型 古代女尊（宫廷／世家）
> 频次来源：宫宴 22.1% ＋ 请安 26.6%（13-07），基数 2,894 部独立作品；文案标签口径见 [10-藏书索引-公开/语料统计](../10-藏书索引-公开/语料统计.md)。本族未单独跑挖掘，各条频次栏标注最近的邻族
> 这一族的共同机关：**朝堂上没有私事。她给他的每一样东西，第二天都会变成别人手里的一个数。**

## 这一族补的是什么

女尊制度场景与制度进阶两族写的是制度怎么运转，这一族写的是权力最高处的那一格：在那里，宠爱本身就是一道政令，而政令有人接、有人抄、有人拿去用。

## 一 · 选侍

`M` ｜ ⚠️示众 ｜ 古代女尊 ｜ 语料频次：宫宴 22.1% ＋ 请安 26.6%（13-07）

**骨架**｜他排在队里，被看的时间比说话的时间长。她从头到尾只点了一次头，第二天他升了位份。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 选侍大典，新入宫的侍君按家世排成一列，由她过目 |
| 2 | 前面几个报了名字、家世、才艺，她只嗯一声 |
| 3 | 到他，她没问话，看了他大约三息 |
| 4 | 她转头和掌事女官说了句什么，声音很低 |
| 5 | 当晚旨意下来，他越过了排在他前面的两个人 |
| 6 | 同批的人来贺，话里话外问他那天说了什么。他说他什么都没说 |

#### 时间轴

宫漏换了两回水，香灰落了第三寸。他数着前面人的后颈，数到第七个时，掌事女官手里的名册翻到了他那一页。

| 类 | 内容 |

| 她这边 | 前面几个她连眼皮都没抬 · 到他时她手里的茶盏停了一下 · 她问掌事女官「那个穿青灰的叫什么」 |
| 物件 | 那件青灰礼服后来压在箱底，没扔也没再穿 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她为什么选他 | 他长得合她眼缘 | 她看中他站姿里那股稳当，像能办事的人 |
| 他知不知道 | 他隐约知道她看的是他腰间的旧伤（替人挡过一箭） | 他完全不知道为什么，被选中的当晚一夜没睡 |
| 后续 | 他从此被叫去御前伺候笔墨，真能办点事 | 他被选中的原因成了悬案，同批人猜了半年 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她选人不需要理由，但选了他之后她开始留意这个人配不配 | 他什么都没做，只是站在那里，被看见了 |
| 内心 | 她在想：这人站在队里像棵不晃的树，也许能挪到跟前用 | 他在想：她看我的时间比看别人长，我记住了那个时长 |
| 好的处理 | 她后来问他「那天怎么不报才艺」，他说「妻主没问」 | 他不去打听原因，只是把那三息当成一个起点，从此做事格外用心 |
| 写崩 | 写成她一见钟情，当晚就召寝 | 写他受宠若惊，跪下来谢恩时红了眼眶 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 指套敲了三下桌沿／抬眼打量他袖口针脚／当晚升了位份 |
| 修仙 | 神念扫过他灵根三息／指尖点了一下玉简／次日他洞府挪到内峰 |
| 星际 | 光屏上他的档案停留三秒／转椅扶手敲了两下／当晚调令到舰桥 |

#### 写崩的三种方式

1. 让他说「谢妻主垂青」。 选侍的规矩是「领旨谢恩」，不是「谢垂青」。他要真说出这种话，等于把私情摆到台面上，反而显得不懂规矩。他该说的是「领旨」，其余咽回去。
2. **把她把她写成「一眼万年」。置决定了她不能凭一眼做决定。她可以看三息，但这一眼背后有考量——家世、性情、有没有用。写崩都是写成了纯心动，忘了她是在挑人办事。
3. 把同批人的嫉妒写成恶毒女配。 同批的人酸几句、探几句口风是常态，写成下药陷害就过了。这条戏的紧张感来自「他为什么被选中」的悬疑，不是来自宫斗。保持所有人在猜，比让一个人动手更耐看。

#### 可串接

前接：宫廷与朝堂（选侍的规矩和位份体系）
后接：宫廷与朝堂（升位份之后的请安与侍奉）
对照：市井与江湖（那边被人看是要钱的，这边被看是要命的）

#### 示例（本库自撰，可直接改写）

> 侍君们按家世站成三排，他排第二排靠右。前面的人报完名字和才艺，她坐在案后嗯一声，茶盖碰了碰杯沿。轮到他时，她没问话，目光在他身上停了大约三息，转头对掌事女官说了句什么，声音低得连近旁的人都只看见她嘴唇动了两下。
> 当晚旨意下来，他越过了排在他前面的两个人，升了侍君的位份。同批的人来贺，笑着问他那天说了什么。他说他什么都没说。
> 掌事女官后来送了一方砚台来，说是她的意思。砚台是旧的，边角磨得圆润，他翻过来看，底上刻着一个小字，像是名字里那个字的偏旁。
> 次日清晨他照例去请安，她正在案前批折子，抬头看了他一眼，只说了一句「站着吧」，又低头写她的字。他站了一炷香，退出来时袖口沾了案边的一点朱砂。
> 傍晚他问掌事女官，那方砚台原来是谁用的。女官没答话，只把茶盏收走，走远了才说了一句「你留着就是」。

## 二 · 和亲来的他

`M` ｜ ⚠️示众 ｜ 古代女尊 ｜ 语料频次：宫宴 22.1% ＋ 请安 26.6%（13-07）

**骨架**｜他是一份条约的附件，附件的附件里写了他这个人。她第一次见他是在议和宴上，他坐在席末，像一册还没翻译的文书。这条戏的重量全在她意识到他正在被众人「估价」的那一刻。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 议和宴上他按礼制被送来，她按礼制收下 |
| 2 | 宫宴上他坐在她下首，满朝都在看他——看他是否受宠，看条约是不是真能落地 |
| 3 | 他恪守礼数，比她的女官还准确，准确得像件贡品 |
| 4 | 有人试探他，敬酒，问话，拿他母族的旧事投石问路 |
| 5 | 她开口挡了，没发火，只是说了一句「本宫的人，不答外朝的问」 |
| 6 | 他低头谢恩，袖子里手在抖。她看见了，没说 |

#### 时间轴

酒盏撤了三巡，银箸搁下的次数是钟。她数他谢恩的俯身，每回脊背弯到同一个角度，像漏壶滴下的水珠，不多不少。外朝的问话像风掀帘子，他袖口的褶子始终没乱，直到她说那句「本宫的人」，他指尖掐进掌心，那褶子才裂开一道缝。宴散时，他起身比女官慢半拍，那半拍就是这场戏的最后一滴漏。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他这边 | 按她母族的礼节学的请安，每日一次，不早不晚 · 宫宴上只动面前三道菜 · 袖口内衬缝着母族的地契碎片 |
| 她这边 | 收下他当晚没召见，第二天才见 · 让人把他的用度按侧君份例走，不克扣也不抬举 · 挡完那杯酒之后没再看他 |
| 物件 | 那份条约副本，他名字那一行有涂改痕迹 · 他带来的嫁妆单子，第一页是粮种清单，最后一页是他自己的名字 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她挡不挡 | 当场挡回去，明示「这是我的人」 | 不挡，事后单独处置那个试探的人 |
| 他接不接 | 低头受着，把谢恩说得标准 | 抬头看她一眼，那一眼里有一丝别的 |
| 朝堂怎么解读 | 解读成她对这个和亲对象上心 | 解读成她在维护条约本身，跟人无关 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她的维护是手段也是表态，她分得清，但他未必需要分清 | 他第一次发现条约里没写的那部分——她可以选不挡 |
| 内心 | 她在算这一挡的代价，朝堂上每一句话都有人记价 | 他在记她开口那一刻的用词，逐字逐句地记 |
| 好的处理 | 她挡完就忘了，隔天照常办公，不把这事当恩典 | 他不谢恩，也不靠近，只是第二天请安时声音稳了一点 |
| 写崩 | 写成她当众表白护夫 | 写成他当场泪眼婆娑 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 和亲质子按礼跪拜／他献上母族铸的玉璧／她回赐一把匕首，鞘上刻她封号 |
| 修仙 | 他作为炉鼎送上宗门／他递上灵根图谱／她扔给他一枚本命剑穗，说「系好」 |
| 星际 | 战败方送来的协调官／他交出母星矿脉坐标／她推给他一杯水，杯底压着调令章 |

#### 写崩的三种方式

1. **让她「霸气护夫」。** 当众搂肩、放狠话、掀桌子，那是戏文里的女帝，不是朝堂上的君主。她的权力不需要用这种姿势证明，一个语气就够了。
2. **让他「柔弱不能自理」。** 他是条约的一部分，条约能签下来，他母族就还有活路。他不需要被拯救，他需要被尊重——哪怕这份尊重名义上叫「不闻不问」。
3. **把整条写成宫斗开篇。** 这条是在做定位。朝堂上没有私事，她收下他是一笔账，她维护他又是另一笔账。别把账本写成话本。

#### 可串接

前接：和亲与盟约
后接：朝堂博弈
对照：后宫日常（同一个屋檐，那边是真的家，这边是驻外使馆）

#### 示例（本库自撰，可直接改写）

> 议和宴设在含元殿，他坐在席末，面前一碟鹿脯没动过，酒盏倒是满的。她隔着两排烛火看他，他袖口绣的暗纹是北境那边的草叶样式，认得出，是降族才用的图样。
> 她按礼制收下他，当晚就有人往他宫里送了一对玉璧，说是贺礼，其实是探路。第二日宫宴，他坐在她下首，满朝的目光落在他身上，像称量一匹绸缎的成色。他端坐，举箸，饮茶，动作比她的女官还准，准得不像活人。
> 酒过三巡，礼部侍郎举杯到他面前，笑着问起他母族旧地的收成。他指尖在盏沿上顿了一下，正要开口，她搁下银箸，声音不高：「本宫的人，不答外朝的问。」
> 满殿安静了一瞬。他低头，起身，谢恩，袖口垂下去时她看见他指尖攥着袖缘，指节发白。她没说话，端起茶盏，茶汤晃了一下，又稳住了。

## 三 · 朝堂上提到他

`M` ｜ ⚠️示众 ｜ 古代女尊 ｜ 语料频次：宫宴 22.1% ＋ 请安 26.6%（13-07）

**骨架**｜议事时有人拿他当例子，拿他当筹码，拿他当靶子。她当场接的那句话，决定了满朝文武明天怎么看他。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 议事到一半，有人提起他的名字，语气里带着试探 |
| 2 | 满殿安静，等她表态，等她说出对这个人的态度 |
| 3 | 她没按惯例接话，也没有不接，她选择了第三种 |
| 4 | 那句话说出去，殿上的人都在重新掂量他的分量 |
| 5 | 散朝后，他得到的待遇立刻变了 |
| 6 | 他后来问她，那话是有意还是无意；她回了一句让他不再问的 |

#### 时间轴

香炉里的三炷签香依次燃尽，灰白的香灰在黄铜炉沿上叠成三道薄棱。第一炷燃到半截时，有人提了他的名字，满殿的呼吸声都跟着那缕烟矮下去。第二炷刚折腰，她接了话，声音不高不低，像拿茶盖刮过碗沿，说「他做的河工图，比工部往年任何一版都经得起踩」。第三炷还没落灰，殿角已经有人悄悄把袖里的弹章往回收。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他这边 | 站在殿上自己那格位置，从头到尾没抬头 · 袖口里攥着半块旧玉蝉 · 散朝时同僚第一次对他行了平礼 |
| 她这边 | 手里的朱笔没停，语气跟批折子一样平 · 说的是公事，但用词里带了个谁都知道的私称 · 说完就岔去下一件，不给任何人追问的机会 |
| 物件 | 那封被人递上来的、拿他作由头的折子，散朝后没退回内阁，也没留中，直接进了火盆 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她怎么接 | 当场撇清，说这事与他无关 | 当众认了，说这人是我的人 |
| 她的情绪 | 语气冷，殿上人听不出喜怒 | 语气里带笑，殿上人反而更不敢接话 |
| 他听不听见 | 他就在殿上，听得一字不落 | 他在外殿候着，是别人转述给他听 |
| 后果 | 从此没人再拿他做文章 | 从此拿他做文章的人改了口，叫他一声“那位” |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她一句话定了他在这朝堂上的活法 | 他站在殿上，发现自己成了她的软肋，也成了她的铠甲 |
| 内心 | 她在算这话说出去，多少人会改呈文，谁会连夜递牌子 | 他在数自己身上哪一处能被拿去伤她，数完发现没有，他才站得稳 |
| 好的处理 | 说完那话她直接议事，散朝后不解释、不邀功 | 他事后不追问，只把那天殿上每一个人的眼神记下来 |
| 写崩 | 写成她当场护夫、情话连篇 | 写成他当场腿软、泪眼汪汪 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她端起茶盏没喝／他跪在殿外候旨／散朝后内侍往他府上送了半斤新茶 |
| 修仙 | 她拂尘一摆没落／他立在阶下听宣／散场后守山童子给他换了间朝阳洞府 |
| 星际 | 她指尖停在全息屏上／他站在舱门边待命／散会后副官把他调去主舰驾驶位 |

#### 写崩的三种方式

1. **让她当场翻脸拍案。** 她真发了火，那就把朝堂戏写成了言情剧。她是这个局里最会算的人，当场发火等于告诉所有人他确实是弱点，她不会这么干。
2. **让他事后追问细节。** 他问“你那句话是什么意思”，问出来就矮了。他该做的是自己品，品出味来，然后行为上做出改变。
3. **把这一场写成全书高潮。** 这一场是垫步不是落步，它的用处是让后面那些“他被人敬着”“她被人试探”有来处。写得太满，后面没得写。

#### 可串接

前接：宫廷与朝堂
后接：宫廷与朝堂
对照：宫廷与朝堂（同是朝堂上有人拿他说事，那边她选择沉默，这边她开了口）

## 四 · 册立

`M` ｜ ⚠️示众 ｜ 古代女尊 ｜ 语料频次：宫宴 22.1% ＋ 请安 26.6%（13-07）

**骨架**｜一道旨意把私下的关系变成了公文。这条戏的全部重量在她落笔之前，满殿的人都在等她写那个名字。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 她事先跟他说过，但只说了半句，没说要给什么名分 |
| 2 | 旨意拟好，内侍念到一半，满殿人都听出来了 |
| 3 | 他跪在下面，礼制上不该抬头，但他抬了 |
| 4 | 她没看他，看着案上的笔，笔尖悬着 |
| 5 | 殿上静得能听见灯花爆 |
| 6 | 她落笔，盖玺。从此他不再是她的私藏，是她的属官 |

#### 时间轴

香炉里的那炷细香是钟。内侍念到「着即册为」时，香灰恰好断落一截，他跪在阶下，石板缝里的冷气顺着膝盖往上爬。她捏着笔管，笔尖悬在绢帛上方，墨汁凝成一颗将坠未坠的珠子——香烧完第二炷时，那颗珠子才落下去，洇开一个「属」字。盖玺的铜钮压进朱砂，满殿的呼吸跟着那一声闷响，齐齐停了半拍。

#### 可用细节

| 类 | 内容 |
|---|---|

| 内心 | 她在算这三个月值不值，算完发现亏了 | 他在算她的怒气是冲事还是冲人 |
| 好的处理 | 她加封他母亲那笔写得很淡，但所有人都知道这是给谁看的 | 他接旨时多磕了一个头，她看见了，没问 |
| 写崩 | 写成她虐完他之后心疼落泪 | 写成他郁郁寡欢、形销骨立 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 免了晨昏定省／内务府撤掉两道膳／他照旧给母亲抄经／加封母亲诰命／叩首时袖口空了一截 |
| 修仙 | 撤了守山禁令／洞府月例灵石减半／他照常打理药园／赐他母亲筑基丹／接丹时指尖有药茧 |
| 星际 | 取消通讯权限／后勤部调低营养剂配额／他照常检修机甲／授予母亲荣誉公民衔／敬礼时腕骨凸出 |

#### 写崩的三种方式

1. 让他失态。 写他醉后失态、跪在殿外求见，就把这场冷落写成了争宠。他该做的是一件事都不做错，错的是她，她要自己找台阶。
2. 让她低头认错。 女尊文里她不需要道歉，她只需要换一个方式把他接回来。加封他母亲是最好的写法，比亲口说软话更有力。
3. 把冷落写成误会。 她不是误会他，她就是故意的，这才叫冷落。写成误会就变成了「她不知道真相」，整场戏的主动权就没了。

#### 可串接

前接：恩宠族
后接：赏赐族
对照：宫斗族（那边是妃嫔争宠，这边是她一个人说了算）

#### 写崩的三种方式

1. 让她当众说“孤赏你，是因为中意你”。 制度里没有这句话，她说了就变成戏文里的风流女帝，不再是朝堂上那个算账的人。她要赏得让人猜不透，才坐得稳那把椅子。
2. 让他跪谢时抬头和她对视，眉来眼去。 满殿都是眼睛，他示弱只该示给该看的人看。这一眼若当众递了，明天弹劾的折子就压上案头。
3. 把赏赐写成终点，以为这条用完了。 这柄如意只是开个头——她到底为什么赏、赏了之后收不收回、收回时换了什么，每一样都够写三章。写实了，才算把“示众”两个字吃透。

## 十 · 退位之后

**骨架**｜她最后一次穿着朝服在正殿坐了整夜，他在偏殿等了一夜。天亮时她走出来，身上没有冠冕，他行了个旧礼，她没受。这条戏的全部重量在两个人都不再知道该怎么站。

#### 写崩的三种方式

1. **让她哭。** 退位是她自己的选择，她不后悔。哭等于把权力失去演成悲剧，这条戏的劲儿在「两个人都不适应」而不是「她难过」。
2. **让他急表忠心。** 什么「臣永远追随妻主」这种话一出来就完了。他要是真这么想，就不会在她说「以后别这样了」时站着不动。
3. **让新关系立刻成形。** 退位第一天就找到舒服的相处方式，不可能。这条戏的收成在别扭——她不知道让他端什么，他不知道自己是谁，这个「不知道」才是两个人真正的开始。
