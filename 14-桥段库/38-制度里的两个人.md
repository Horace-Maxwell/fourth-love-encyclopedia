# 制度里的两个人

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 现代（现实性别制度）
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。柜台与表格类场面在语料里未单列成族，选目走 [README](README.md) 的缺口清扫路线；文中引用的族占比为编写时实测，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**制度不针对他们，制度只是没想到他们。** 恶意有人负责，默认值没有人负责，所以这种摩擦是钝的，磨的是日常。

## 这一族收的是没有对手的摩擦

[14-社交与公开](14-社交与公开.md) 写熟人，写的是那种有来有回的摩擦——同事起哄、邻居嚼舌根、长辈拿老一套来套你。每一句都有脸，有名有姓，你还能怼回去。这一篇写的是另一种现场：签字栏、下拉框、柜台的惯性提问。你找不到一个具体的人来生气，护士就是照流程喊一声“家属来签个字”，表格上印的还是上个时代的规矩。

| | 熟人场（14 卷） | 制度场（这一族） |
|---|---|---|
| 摩擦来源 | 具体的人与话 | 默认设置 |
| 有没有对手 | 有，可以回敬 | 没有，回敬会落空 |
| 情绪形态 | 尖的，当场起 | 钝的，回家路上才冒头 |
| 好的收法 | 谁接话、怎么接 | 谁把那一栏改掉、怎么改 |

跟这一族最接近的实测族是偏见（28.1%）和议论（21.0%，均 13-07），这两族写的都是人。柜台不议论，柜台只是复核三遍。十条共用一条判据：**对面无恶人。** 谁都没做错，他们也过得下去，只是每一步都要多按一下、多解释一句。

双向是这种场面的富矿：同一个窗口，她那头是决策者的坦然或疲惫，他那头是被制度略过的刺或松，两个视角就是两场完全不同的戏。十条「双向写法」都按这个路子填。

## 一 · 手术单上的名字

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（缺口清扫增补；陪床场面见 [09-分离与重逢](09-分离与重逢.md#四--陪床)）

**骨架**｜他做个微创小手术，签字的时候护士在走廊喊家属，找的是他。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 术前谈话通知下来了：几点、在哪、家属得来 |
| 2 | 走廊长椅，护士探身喊「三十六床家属」 |
| 3 | 她应声站起来，对面那人却越过她，往她身后看 |
| 4 | 半秒。身后没人，目光才落回来 |
| 5 | 风险条款一条条念，最后问「您能做主吗」 |
| 6 | 递笔。笔拴着链子，她接过来，签得稳稳当当 |
| 7 | 坐回长椅，才觉出满手心的汗 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 纸面 | 知情同意书 · 「跟患者啥关系」那栏 · 复印件 · 风险条款第几条 |
| 物件 | 拴绳子的笔 · 玻璃窗底下递东西的槽 · 走廊那排椅子 · 手术室门口亮着的灯 |
| 那半秒 | 看她一眼 → 身后没人 → 眼神收回来 → 话还是那个调 |
| 台词类型 | 「您说了算吗？」「我说了算。」再没别的话 |
| 公私分界 | **柜台前撑得住，坐下才露怯。** 这顺序不能乱 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 躺着的是谁 | 他手术，她签字 | 她手术，医生默认找她老公谈，风险他一条条听完 |
| 那半秒 | 她看懂了，没接话 | 她压根没留意，早习惯了 |
| 他知不知道 | 出院那天翻材料，才看见她签过字 | 到死都不知道走廊里那半秒的事 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 笔递过来之前那半秒的目光 | 推进去前，听见走廊里她应「家属」的那一声 |
| 内心 | 条款第七条她读了两遍 | 在这栋楼里，她是他的什么，要靠一张表说明 |
| 好的处理 | 不跟护士较劲，签完字才让自己抖 | 他把签名那页从出院材料里抽出来收好 |
| 写崩 | 当场纠正对方怎么找 | 写成他觉得下不来台 |

#### 写崩的三种方式

1. 给护士写立场。她只是照惯性喊人，一有立场就成了恶人，钝感就没了。
2. 让她在窗口发言。这场戏她只有两个字的台词，多一句都是演讲。
3. 把手术写重。中等的手术刚好，太重就成了生死戏，那半秒会被淹掉。

## 二 · 售楼处只看她

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（缺口清扫增补）

**骨架**｜看房。三句话后，销售就只冲她一个人说了。他有两套话术：一套让你舒服，一套让你扎心。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 进门，销售迎上来，第一句话是对他说的 |
| 2 | 她问贷款和梯户比，他在看沙盘 |
| 3 | 第三句起，销售已经转过身冲她说话了 |
| 4 | 样板间：她看总价单，他试水压、摸插座位置 |
| 5 | 谈折扣，计算器推过去，往她那边推 |
| 6 | 他去接水的两分钟里，首付方案已经谈妥了 |
| 7 | 出门他说厨房动线不对，她折回去，把这条写进合同 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 目光迁移 | 喊“哥”变喊“姐”· 身子往哪边转 · 单子朝谁递 |
| 道具 | 沙盘 · 计算器 · 纸杯水 · 认购意向单 · 样板间的假书 |
| 他的领域 | 水压 · 插座 · 动线 · 窗外噪音。**他看的没一样在价格单上** |
| 台词类型 | 「姐，这个价我得请示经理」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的版本 | 舒服：不用再装内行 | 扎心：他被踢出谈判了，称呼没变，就是没人搭理他 |
| 迁移速度 | 三句话内 | 到了样板间才反应过来 |
| 钱的实情 | 全是她的 | 他也掏了一份，但没人问过 |
| 收法 | 他提的意见写进了合同 | 他全程闭嘴，回家才开口 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 计算器推过来那一下，她顺手接住 | 销售第三次越过他之后，他开始看窗外 |
| 内心 | 她注意到他在阳台站了很久 | 舒服版：这两个小时归她。刺版：我连坐标都没有 |
| 好的处理 | 她把一个问题原样转给他：「这个你看。」 | 他接住了，答得内行 |
| 写崩 | 写成她享受他被略过 | 写成自尊当场塌方 |

#### 写崩的三种方式

1. 把销售写成势利眼。目光迁移是职业判断，跟着钱走，一势利就有了恶人。
2. 两个版本混着写。舒服和刺是两种人设，一场戏只能选一个。
3. 让刺当场发作。刺要延迟，回家路上才冒头，当场发作就成了另一场吵架。

## 三 · 家长会谁去

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：孩子 24.8% 衍生（13-07 实测）

**骨架**｜学校通知写的是“请妈妈们抽空来”，结果去的是他。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 班级群通知，写的是「请妈妈们」 |
| 2 | 家里一直是他管学校，他顺手接了龙 |
| 3 | 教室后排，一屋子妈妈，外加两位爷爷 |
| 4 | 老师开口就是「各位妈妈」，说顺了嘴 |
| 5 | 点到他家孩子，老师下意识往妈妈堆里看，他举手 |
| 6 | 会后单独聊，三句话里两次「回去跟妈妈商量」 |
| 7 | 他说：这事我定就行。老师愣了一下，把话头转了过来 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 纸面 | 家校联系册上「家长（母亲）签名」那一栏 · 群里都叫「××妈妈」，他改成「××爸爸」，就他一个 |
| 现场 | 小板凳 · 教室后头贴的作文展 · 孩子桌洞里露半截的橡皮 |
| 称呼 | 「各位妈妈」·「平时孩子都是妈妈管吧」 |
| 那句夸 | 「爸爸带得这么细，真不多见」。**一样的事，搁她们身上是应该，搁他这儿就成了稀奇** |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 老师的反应 | 顺口就说了，没多想 | 当面夸「难得」，夸就是点你 |
| 他的接法 | 顺手把联络册那栏改了 | 懒得改，孩子知道找谁就行 |
| 她那边 | 全交给老师 | 回家细问，发现孩子在学校的事她只能听转述 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 开会歇口气，他发来一张照片：孩子的卷子贴在墙上 | 满场「妈妈」里安坐 |
| 内心 | 那张卷子她头一回见 | 被夸「少见」那一下，心里有点不自在 |
| 好的处理 | 她不哄也不觉得亏欠，下回还是他去 | 他把「母亲」划掉，写上「父亲」，字写得稳稳当当 |
| 写崩 | 写成她愧疚得不行，哭天抹泪 | 写成他在妈妈堆里混得风生水起的搞笑桥段 |

#### 写崩的三种方式

1. 把夸他那句写成甜头。「少见」是这条钝刺的位置，写成得意就丢了。
2. 妈妈们围观他。猎奇会把制度戏变成相亲角段子。
3. 孩子全程没有台词。孩子说一句就够，但要有，孩子不是道具。

## 四 · 表格里没有他们

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（缺口清扫增补）

**骨架**｜领证那天下午集中办手续，三张表，三种套路，全在问谁说了算。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 取号，一叠表，一支笔 |
| 2 | 联名账户：「主账户人」那栏，他想都没想就填了她的名字 |
| 3 | 车位合同：经办人那栏销售早填好了他的名，她划掉重写 |
| 4 | 家属体检套餐：「配偶」后头印着「先生」，他圈掉，改成「女士」 |
| 5 | 柜员一张张看，在改过的地方停了下，没吭声，盖了章 |
| 6 | 出来，他把回执按顺序理好，收进文件袋 |

#### 字段清单

| 字段 | 预设 | 他们的实况 |
|---|---|---|
| 主贷人 | 「一般写先生」 | 谁挣得多写谁，结果是她 |

| 称谓下拉框 | 先生排在第一项 | 每次都得往下多划一下 |
| 「家属」 | 固定写一个人 | 看哪张表：她单位填他，医院填她 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 纸面 | 预印字 · 圈改的笔迹 · 骑缝章 · 回执 |
| 柜台 | 「都行，一般写先生」· 复核时问一遍「确定吗」 |
| 动作 | 划掉 · 圈改 · 复核的停顿 · 文件袋按顺序收纳 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 表的年代 | 纸印好了，改不了 | 新系统里下拉框多出好几项 |
| 他的态度 | 顺手改，也不多说 | 把这些栏目攒着，凑够了讲给她当笑话 |
| 分工 | 医院单子他签，银行单子她签 | 谁在谁签，反倒回回得跟人解释 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「都行」在柜台那儿到底咋用的 | 「家属」这词头一回落自己头上 |
| 内心 | 她头回成了别人表里默认勾的那项 | 不难受。难受的是有一栏他停了三秒，最后填了「其他」 |
| 好的处理 | 把「谁是谁家属」说成搭伙过日子，一人管一半柜台 | **圈改的笔迹工整，像批作业** |
| 写崩 | 对着表格自个儿念叨 | 写成他每一栏都疼 |

#### 写崩的三种方式

1. 对表格发议论。表格不回嘴，议论落不到人身上，只能落到读者头上，那是说教。
2. 每一栏都展开。挑一栏写足，其余进清单。
3. 复核的停顿带表情。柜员的停顿要无辜，长着流程的脸。

## 五 · 出入境柜台

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（缺口清扫增补）

**骨架**｜她外派，他跟着搬。签证上写得很清楚：她是主申请人，他是家属。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 外派定下来了，材料清单也发了：她那边一厚沓，他就一页纸 |
| 2 | 他那页就两样东西：关系公证，还有无犯罪记录证明 |
| 3 | 面签的时候，问题全冲着她来。轮到他就问了一个 |
| 4 | 「以前干啥的？」她想张嘴替他答，他抬手拦住了 |
| 5 | 他说：在家带孩子，顺便学学那边的菜。签证官乐了，章一盖 |
| 6 | 签证下来，类别栏那串代码，尾巴跟她的不一样 |
| 7 | 入境那天分两条道：她走人才通道，他排家属队，隔着栏杆并排走 |
| 8 | 落地头一周，他就去办了张图书证 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 纸面 | 材料厚薄不一样 · 签证上那串代码 · 入境卡上「职业」那栏他愣了下 · 各种编号带个「-2」尾巴 |
| 现场 | 两条道中间一米高的栏杆 · 叫号屏 · 护照从窗口递进去的那个方向 |
| 图书证 | **落地后头一张只写他自己名字的卡。** 不问你俩啥关系，也不问谁说了算 |
| 台词类型 | 「主申请人是哪个？」「她。」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的心态 | 松：总算能名正言顺歇一阵 | 悬：他留在这儿的资格押在她合同上，她续签他才算合法 |
| 她的心态 | 一直觉得亏欠他 | 压根没往那想，被他一句玩笑点破 |
| 后续 | 他在当地重新考了执照，编号换成了不带尾缀的 | 一直是「-2」，他干脆拿它当俩人之间的昵称 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他那句「学做那边的菜」，比她准备的一页话都顶用 | 围栏那一米，隔出去的一段路 |
| 内心 | 他靠她才有底气，这事她比他先看明白 | 「-2」不难听，难的是每张表都得再提一遍 |
| 好的处理 | 她把续签日期设成两个人一起记着 | 他先去办了图书证，再去办别的 |
| 写崩 | 写成她光顾着自责 | 写成移民卖惨 |

#### 写崩的三种方式

1. 把家属身份写成屈辱。他丢的只是那个排在前面的人的位置，人本身没掉价。
2. 签证官刁难。程序上的问题就得按程序问，一刁难，戏就变味了。
3. 别写纸面上那些。代码、通道、尾缀，这类的戏全在手续上。

## 六 · 两家谈钱

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：婚仪 38.8% 衍生（13-07 实测）

**骨架**｜十分钟就把数谈定了。谈不拢的是这笔钱该叫啥——她家给他家的，翻遍字典也找不着个正经名儿。

制度特写版。[23-婚嫁 · 两家坐下来谈](23-婚嫁.md#二--两家坐下来谈) 写人怎么谈，这条拍词不够用。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 两家坐下，茶喝了一轮，开始一条条过事 |
| 2 | 钱上痛快：两边都拿得出，也都没抠门 |
| 3 | 卡住了：她家给的那笔，说成「彩礼」，他爸接不了这个话 |
| 4 | 桌上换着说法：「安家费」「添置」「心意」，怎么讲都不对味 |
| 5 | 他妈开口：那我们陪的这份，算不算嫁妆。一桌人都不吭声 |
| 6 | 他爷爷搁下茶杯：这不就是老辈子说的招婿么，老话里有讲法 |
| 7 | 谁也没提老词，可疙瘩解开了。两笔钱都归进「办事的钱」，不叫名目 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 纸面 | 转账备注空着没填 · 红包上印的「囍」不分正反 · 记账用红皮本 |
| 桌面 | 茶杯转半圈不喝 · 果盘没人碰 · 谁给谁倒水 |
| 词 | 彩礼 · 嫁妆 · 聘礼 · 陪嫁。**每个词都带方向，方向全拧巴** |
| 台词类型 | 「这钱算啥名头？」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 卡点 | 词：叫什么 | 流向：谁给谁，数目反而没人争 |
| 代际 | 父母辈最难过关 | 祖辈反而看得开，老规矩里本来就有他们的位置 |
| 解法 | 拿酒席账目当幌子 | 两家各掏一份「成家的钱」，新说法是他们自己编的 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 卡住的全是词，数字从头到尾没吵过 | 全桌都在争他家那笔钱算啥 |
| 内心 | 爸妈要的只是那句话能说出口 | 该他开口了 |
| 好的处理 | 她把新名目说成两边长辈的意思 | 他提的法子让两边都有台阶，那晚他说话最管用 |
| 写崩 | 写成她拍桌定音 | 写成他成了桌上被摆弄的物件，从头到尾没吭声 |

#### 写崩的三种方式

1. 写成数目之争。钱三分钟就谈拢了，这场的戏全在名目上扯皮。
2. 新词一次就成。词得试错三个，第一个就通过等于白写。
3. 重拍 23 卷那场。人物冲突归 [23-婚嫁 · 两家坐下来谈](23-婚嫁.md#二--两家坐下来谈)，这条只拍桌面上那些词。

## 七 · 他辞职那年

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（[家庭主夫](../02-术语百科/03-人设与套路标签.md) 标签见 02-术语百科）

**骨架**｜辞职这事是我们俩一起算出来的。手续是他自己去办的：社保、空窗期、亲戚怎么问，制度换了三种方式问他到底是谁。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 账算下来：她挣得不少，孩子老人也得有人管，他回去更划算 |
| 2 | 离职那天，HR 问社保咋办，他头回听说“灵活就业”这说法 |
| 3 | 政务 App 里选身份，下拉菜单翻半天没他这档，最像的叫“无业” |
| 4 | 每月自己交社保，回执单都塞进一个文件夹 |
| 5 | 年夜饭，亲戚问话一年比一年刁 |
| 6 | 接孩子时认识的家长问他干啥的，他说：管后勤 |
| 7 | 年底他把家里收支理成一张表，跟年终汇报似的 |

#### 亲戚问法的演变

| 年份 | 问法 | 实际含义 |
|---|---|---|
| 第一年 | 「最近忙啥呢」 | 探探口风 |
| 第二年 | 「还没碰上对眼的？」 | 心里已经认定他挑 |
| 第三年 | 「一个人扛着家也不容易」 | 话冲她说，刀子递给他 |
| 第四年 | 不问了 | 定死了。不问比问还扎人 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 纸面 | 灵活就业窗口的号 · 社保单据一沓 · 简历上那两年怎么写（他后来写了「家庭项目管理」，被 HR 当段子转发） |
| 家里 | 记账 App 的年报 · 他给自己排的课表 · 冰箱上的采买清单 |
| 台词类型 | 「社保自己缴，还是想办法挂单位？」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 决定的性质 | 算出来的 | 他本来就想退，账只是台阶 |
| 出口 | 两年后重返职场，面试官盯着空窗期 | 不返，他把家管成了长期的事 |
| 亲戚层 | 他爸妈最难过 | 她爸妈先替他挡 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 发钱那天，转账备注她改成「工资」 | 下拉框停在「无业」上的三秒 |
| 内心 | 备注改了，他收不收是另一回事 | 这类小事他不讲，攒着 |
| 好的处理 | 她在家庭账户里给他开了最高权限 | **他管那沓社保单据叫工资条** |
| 写崩 | 让她说出「我养你」 | 写成他日渐枯萎 |

#### 写崩的三种方式

1. 写成失业。他是辞的，把主动权写丢，这条就塌成 [12-工作与金钱 · 他失业了](12-工作与金钱.md#七--他失业了)。
2. 「我养你」出口。在 12 卷是雷，在这里也是，它把分工判成了收养。
3. 亲戚全员恶人。多数人只是没词，恶意要给具体的人，别摊给整张桌子。

前接：[12-工作与金钱 · 他失业了](12-工作与金钱.md#七--他失业了)（非自愿版对照） · [五 · 出入境柜台](#五--出入境柜台)

## 八 · 保险受益人

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（缺口清扫增补）

**骨架**｜她给自己买了份保险，受益人写的是他，比例那栏填了100%。柜员来回核了三遍。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 年底盘账，她顺手把保险也定了 |
| 2 | 保额按年收入算了个数，念出来那会儿，屋里没人吭声 |
| 3 | 受益人那栏，她写了他，指定，不走法定继承 |
| 4 | 核对第一遍：“你跟她什么关系？” |
| 5 | 第二遍：“就写一个人？”第三遍：“全给他？” |
| 6 | 签字页底下那行小字：身故保险金受益人。他看见“身故”俩字 |
| 7 | 回家路上他一直没吭声。晚上他说：把我的也办一份，受益人写她 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 三遍复核 | 关系 → 人数 → 比例。**每看一遍是一道手续，三遍叠起来就是在掂量人** |
| 纸面 | 「身故」那行字多大 · 保额是收入的几倍 · 承保短信 |
| 家里 | 两张保单塞进同一个抽屉 · 钱数不一样，但比例对得上 |
| 台词类型 | 「比例全给他？」「全给他。」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他在不在场 | 在场，听着自己被写进她身后 | 不在，收到承保短信才知道 |
| 他的反应 | 当晚要求她也给自己保一份 | 推让：写咱妈吧。推让的理跟 12 卷拒钱一样，只是挪到了身后事上 |
| 那三遍 | 走个过场 | 第三遍时抬眼看了看他们俩 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 填比例那一栏，笔没停 | 「身故」两个字进眼睛的那一下 |
| 内心 | 她怕的只有他看见那两个字 | 有一份文件，他不在场也生效，内容是她把自己折成了数 |
| 好的处理 | 她不解释保额，只说是安排 | 他的对策是对等的一张：金额小，比例一样是一百 |
| 写崩 | 写成生死预告 | 写成推拒闹剧 |

#### 写崩的三种方式

1. 拿保单当伏笔。这条的分量就在它多半一辈子用不上，一用上就换了书。
2. 绕过「身故」两个字。钝的就是那一下，绕过去等于没写。
3. 把三遍复核写成歧视现场。那是柜台的肌肉记忆，长着流程的脸。

## 九 · 户口本

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（缺口清扫增补）

**骨架**｜迁户那天，户主写的是她。民警照例问了一句，多说了俩字：也行。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 婚后迁户口，取号排队，站窗口 |
| 2 | “户主写谁？”办事员先看他一眼 |
| 3 | “写她。”“行，也行。” |
| 4 | 录信息，打印机出纸。第一页是她，第二页是他 |
| 5 | “与户主关系”那栏打出来：配偶 |
| 6 | 民警多说一句：以后孩子上户口，材料跟着户主走 |
| 7 | 出了门，他把本子收进证件包。那包一直是他收着 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 那个词 | 「一般写男方」「也行」。**制度让步的方式：不拦，但要提醒一句「一般」** |
| 纸面 | 首页与第二页的顺序 · 老版「夫」与新版「配偶」的一字之差 · 骑缝的红章 |
| 物件 | 窗口玻璃的传递槽 · 打印机 · 家里的证件包 |
| 台词类型 | 「户主写哪位？」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 惯性问题落点 | 问户主 | 问孩子随谁姓，这一问更深 |
| 后续成本 | 没有 | 某天他办事要多开一张证明，排队时他算了算这页纸的价钱 |
| 版本 | 新式「配偶」 | 老式打出来一个「夫」字，他盯着看了两秒 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 不算好，也不算坏，就卡在中间那块 | 每次办事，窗口都先看她那页 |
| 内心 | 没人拦她，但她知道自己被单拎出来了 | 他习惯把本子翻到要用的那页再递进去 |
| 好的处理 | 她不庆祝。户主栏上没写她名字，她也不当回事 | 「翻好再递」，他把规矩变成了自己的顺手 |
| 写崩 | 写成她赢了 | 把「夫」字写得像在受气 |

#### 写崩的三种方式

1. 民警多说一个字。「也行」就是全部台词，再多就成了立场。
2. 写成她赢了。庆祝等于承认那是场比赛，这个家里没人在跟他比。
3. 别写物件层。页序、红章、证件包，这条的戏全在纸和塑料皮上。

## 十 · 制度追上来之前

<!-- gb-nonscene -->
`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：不单独计（收束条）

**骨架**｜这条不是戏，是根跨年的线：日子早过上了，表格几年后才改过来。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 头几年靠涂改：把印好的字划掉，跟柜台的人多解释一句 |
| 2 | 某年政务系统更新，下拉框里多了一个选项，没人跟他们提过 |
| 3 | 学校通知从「请妈妈们」改成了「请家长」 |
| 4 | 孩子的入学表印着「监护人一／监护人二」，后面没加括号 |
| 5 | 他们填的时候没犹豫，顺手就用，像这东西早该有了 |
| 6 | 孩子那一辈会以为表格从来就长这样 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 三个版本 | 同一张表：预印「（母亲）」的 → 括号删掉的 → 只写「监护人」的 |
| 痕迹 | 涂改液 · 圈改笔迹 · 没人看的更新日志 |
| 留存 | 他把旧版那张留了一份。**家里管表的人，最先发现字段改了，也最记得旧的长什么样** |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 发现新选项的人 | 他，管表的人 | 孩子：「这有什么好留的？」 |
| 改动的速度 | 一项一项，慢 | 某年集中改了一批，他们反而不适应 |
| 情绪 | 没什么情绪，就是注意到了 | 那晚多聊了十分钟当年的柜台 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她瞧见新选项那回，想喊他看，他正剥豆子，她没吭声 | 旧表叠了两折，压在证件包最底下 |
| 内心 | 改了，但不是为他们改的，这样正好 | 用过旧表的人，才晓得新表省了哪几笔 |
| 好的处理 | 不念叨。日子在前头，表格在后头，本来就该这样 | 孩子问起，他只说：以前格式不一样 |
| 写崩 | 写成给制度唱赞歌 | 写成控诉大会总结 |

#### 写崩的三种方式

1. 写成制度的感恩戏。表格改了没有为他们改，把因果挂上去就假了。
2. 写成总结陈词。这条收的是前九条的余温，宣言会把余温烧糊。
3. 让改动一次到位。制度慢半拍，慢就要慢得零碎、不成典礼。
