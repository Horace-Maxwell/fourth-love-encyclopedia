# 制度里的两个人

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 现代（现实性别制度）
> 频次来源是 [13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。语料里没有把柜台、表格这类场面单列成一族，选目按 [README](README.md) 的缺口清扫路线来。文中引的族占比是编写时实测的，现在的数字以 13-07 为准（`run.py mine` 重跑会更新）
> 这一族写的是柜台前、表格前的戏。对面没有坏人，只是表格上没有他们的位置，摩擦是钝的，一点点磨在日常里。

## 和熟人场的分别

[14-社交与公开](14-社交与公开.md) 写的是熟人，本卷的签字栏、下拉框、柜台上顺嘴的问话是另一种现场。护士照流程喊一声“家属来签个字”，表格上印的还是上个时代的规矩，找不到哪个具体的人可以生气。熟人那篇的摩擦有来有回——同事起哄、邻居嚼舌根、长辈拿老一套来套人，每句话背后都有张脸，有名有姓，能怼回去。两篇对着看，熟人那篇有对手，这篇没有。

| | 熟人场（14 卷） | 制度场（这一族） |
|---|---|---|
| 摩擦来源 | 具体的人与话 | 默认设置 |
| 有没有对手 | 有，能还嘴 | 没有，还嘴也找不着人 |
| 情绪形态 | 尖，当场就起来 | 钝，走在回家路上才冒出来 |
| 好的收法 | 谁接话、怎么接 | 谁把那一栏改掉、怎么改 |

实测里离这一族最近的是偏见（28.1%）和议论（21.0%，均 13-07），这两族写的都是人。柜台不会议论谁，它只会复核三遍。十条用的是同一条判据：**对面无恶人。** 谁都没做错，日子也过得下去，只是每一步都得多按一下，多解释一句。

同一个窗口前，她那边是拿主意的人的坦然或疲惫，他那边是被制度跳过去的那点刺，或者松快。从两头写，是两场完全不同的戏。

## 一 · 手术单上的名字

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（缺口清扫增补；陪床场面见 [09-分离与重逢](09-分离与重逢.md#四--陪床)）

**骨架**｜他要做个微创小手术。签字时护士在走廊里喊家属，喊的是他。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 术前谈话的通知到了：几点，在哪，要家属到场 |
| 2 | 走廊长椅上，护士探出身喊「三十六床家属」 |
| 3 | 她应着站起来，对方的目光却越过她，往她身后找 |
| 4 | 半秒后，见身后没人，目光才落回来 |
| 5 | 风险条款一条一条念完，末了问「您能做主吗」 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 纸面 | 知情同意书 · 「跟患者啥关系」那栏 · 复印件 · 风险条款第几条 |
| 物件 | 拴绳子的笔 · 玻璃窗底下递东西的槽 · 走廊那排椅子 · 手术室门口亮着的灯 |
| 那半秒 | 看她一眼 → 身后没人 → 眼神收回来 → 话还是那个调 |
| 台词类型 | 「您说了算吗？」「我说了算。」就这两句，没别的 |
| 公私分界 | **柜台前撑得住，坐下才露怯。** 先后不能颠倒 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 躺着的是谁 | 他做手术，她签字 | 她做手术，医生想当然去找她老公谈，风险由他一条条听完 |
| 那半秒 | 她看明白了，没吭声 | 她根本没注意，早就习惯了 |
| 他知不知道 | 出院那天翻材料，才发现是她签的字 | 走廊里那半秒，他到死都不知道 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 递笔之前，那半秒的目光 | 被推进去之前，听见她在走廊里应了一声「家属」 |
| 内心 | 第七条条款她看了两遍 | 在这栋楼里，她是他的什么人，得靠一张表来证明 |
| 好的处理 | 不跟护士较真，签完字才容许自己发抖 | 他从出院材料里抽出有她签名的那一页，收好 |
| 写崩 | 当场纠正对方该找谁 | 写成他觉得丢了面子 |

#### 写崩的三种方式

1. 给护士安个立场。 她只是顺着习惯喊人，一有立场就成了恶人，钝感也没了。
2. 让她在窗口发言。 她在这场戏里只有两个字的台词，多一句就成了演讲。
3. 手术写得太重。 中等的手术正合适，一重就成了生死戏，那半秒就被淹没了。

## 二 · 售楼处只看她

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（缺口清扫增补）

**骨架**｜看房。三句话过后，销售就只对着她一个人说了。这件事落到他身上有两个版本，一个让人舒服，一个让人扎心。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 一进门销售就迎上来，头一句是冲他说的 |
| 2 | 她问贷款和梯户比时，他盯着沙盘 |
| 3 | 从第三句开始，销售整个人已经转向她 |
| 4 | 到了样板间，她看总价单，他去试水压、看插座在哪 |
| 5 | 谈到折扣，计算器推了过去，推向她 |
| 6 | 他去接杯水，两分钟的工夫，首付方案已经谈定 |
| 7 | 出门他说厨房动线有问题，她折回去把这条加进合同 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 目光迁移 | 喊“哥”变喊“姐”· 身子往哪边转 · 单子朝谁递 |
| 道具 | 沙盘 · 计算器 · 纸杯水 · 认购意向单 · 样板间的假书 |
| 他的领域 | 水压 · 插座 · 动线 · 窗外噪音。**他看的东西价格单上一样都没有** |
| 台词类型 | 「姐，这个价我得请示经理」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的版本 | 舒服：总算不用装懂行 | 扎心：称呼没变，可谈判里已经没他了，没人搭理他 |
| 迁移速度 | 三句话之内 | 进了样板间才回过味来 |
| 钱的实情 | 全是她出的 | 他也出了一份，只是没人问过他 |
| 收法 | 他的意见进了合同 | 他一路没说话，到家才开口 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 计算器推过来，她顺手接住的那一下 | 销售第三次绕过他以后，他转头去看窗外 |
| 内心 | 她留意到他在阳台上站了好一阵 | 舒服版：这两个小时交给她。扎心版：没人看我 |
| 好的处理 | 她把一个问题原封不动转给他：「这个你看。」 | 他接过去，答得很内行 |
| 写崩 | 写她乐于看他被晾着 | 写他自尊当场垮掉 |

#### 写崩的三种方式

1. 把销售写成势利眼。 目光往哪边移是职业判断，跟着钱走，写成势利就多出一个恶人。
2. 两个版本掺在一起写。 舒服和扎心是两种人设，一场戏里只能挑一种。
3. 让那根刺当场发作。 刺要晚来，回家路上才冒头，当场发作就成了另一场吵架。

## 三 · 家长会谁去

| 轴 | 一端 | 另一端 |

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 开会歇口气时，收到他发的照片：孩子的卷子贴在墙上 | 满场「妈妈」里坐得安稳 |

#### 写崩的三种方式

1. 把夸他那句写成甜头。 钝刺就扎在「少见」上，写成他得意，刺就没了。
2. 让妈妈们围观他。 一猎奇，制度戏就成了相亲角的段子。
3. 孩子从头到尾没台词。 一句就够，但得有，孩子不能当道具用。

| 轴 | 一端 | 另一端 |
|---|---|---|
| 表的年代 | 纸面印死了，改不了 | 新系统里，下拉框多出好几个选项 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 柜员说的那句「都行，一般写先生」 | 「家属」两个字头一回落到自己身上 |
| 内心 | 她第一次成了别人表格里默认勾选的那一项 | 有一栏他停了三秒，最后填的是「其他」 |

| 写崩 | 对着表格自己嘀咕 | 写他每一栏都在疼 |

#### 写崩的三种方式

1. 对着表格发议论。 表格不会回嘴，议论找不到人，最后全落在读者头上，成了说教。
2. 每栏都展开。 挑一栏写透，其余列进清单。
3. 复核停顿带了表情。 柜员停那一下得是无辜的，一脸流程。

## 五 · 出入境柜台

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|

| 后续 | 他在当地重考了执照，换到一个不带尾缀的编号 | 始终是「-2」，他索性把它当成两人之间的昵称 |

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|

| 好的处理 | 续签日期她设成两人一起提醒 | 他头一件办的是图书证，其他的往后排 |
| 写崩 | 她只顾着自责 | 写成移民诉苦 |

#### 写崩的三种方式

1. 把家属身份写成屈辱。 他失去的只是排在前头的那个位置，他这个人没有掉价。
2. 让签证官刁难。 程序上的问题就得照程序问，一刁难戏就变了味。
3. 纸面上的东西不写。 代码、通道、尾缀，这类戏都在手续里。

## 六 · 两家谈钱

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：婚仪 38.8% 衍生（13-07 实测）

**骨架**｜数目十分钟就谈定了，谈不拢的是这笔钱叫什么。她家给他家的钱，字典翻遍也找不到一个正经名字。

人怎么谈，归 [23-婚嫁 · 两家坐下来谈](23-婚嫁.md#二--两家坐下来谈)。这里只写饭桌上少了一个词。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 两家人落座，喝过一轮茶，开始一件件过 |
| 2 | 钱的事痛快，两边都拿得出，谁也不小气 |
| 3 | 卡在她家给的那笔上：叫「彩礼」，他爸这话接不下去 |
| 4 | 一桌人换着说「安家费」「添置」「心意」，哪个都不对味 |
| 5 | 他妈问，那我们陪的这份算不算嫁妆。满桌没人出声 |
| 6 | 他爷爷放下茶杯，说这就是老辈人讲的招婿，老话里有说法 |
| 7 | 老词谁也没再提，疙瘩却解开了。两笔钱都算「办事的钱」，不另起名目 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 纸面 | 转账备注空着没填 · 红包上印的「囍」不分正反 · 记账用红皮本 |
| 桌面 | 茶杯转半圈不喝 · 果盘没人碰 · 谁给谁倒水 |
| 词 | 彩礼 · 嫁妆 · 聘礼 · 陪嫁。每个词都有流向，放到这儿全拧着 |
| 台词类型 | 「这钱算啥名头？」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 卡点 | 词：叫什么 | 流向：谁给谁，钱数倒没人争 |
| 代际 | 父母这一辈最难过关 | 祖辈倒看得开，老规矩里本来就给他们留了位置 |
| 解法 | 借酒席的账目遮过去 | 两家各出一份「成家的钱」，这个说法是他们自己想的 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 卡住的都是词，数字一直没人吵 | 一桌人都在争他家那笔钱算什么 |
| 内心 | 爸妈只要那句话说得出口 | 轮到他说话了 |
| 好的处理 | 她说新名目是两边长辈的意思 | 他出的主意给了两边台阶，那晚数他的话最管用 |
| 写崩 | 她一拍桌子定了 | 他成了桌上被人摆弄的物件，一声没吭 |

#### 写崩的三种方式

1. 写成数目之争。 钱十分钟就谈拢了，要写的是为名目扯皮。
2. 新词一试就成。 至少要试错三个词，头一个就过等于白写。
3. 把 23 卷那场再拍一遍。 人物冲突交给 [23-婚嫁 · 两家坐下来谈](23-婚嫁.md#二--两家坐下来谈)，这里只拍桌上那几个词。

## 七 · 他辞职那年

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（[家庭主夫](../02-术语百科/03-人设与套路标签.md) 标签见 02-术语百科）

**骨架**｜辞不辞是两个人一起算的，手续是他一个人跑的。社保、空窗期、亲戚的盘问，制度换着三种法子问他到底算什么人。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 一算账，她收入不低，孩子老人又得有人照看，他回家更合算 |
| 2 | 离职那天 HR 问他社保怎么办，“灵活就业”这个说法他头一回听 |
| 3 | 在政务 App 上选身份，下拉菜单翻半天找不到他这种，最接近的是“无业” |
| 4 | 社保每月自己交，回执全收在一个文件夹里 |
| 5 | 年夜饭上，亲戚问得一年比一年刁 |
| 6 | 接孩子认识的家长问他做什么的，他说管后勤 |
| 7 | 年底他把家里的收支做成一张表，像交年终汇报 |

#### 亲戚问法的演变

| 年份 | 问法 | 实际含义 |
|---|---|---|
| 第一年 | 「最近忙啥呢」 | 探探口风 |
| 第二年 | 「还没碰上对眼的？」 | 心里认准是他挑 |
| 第三年 | 「一个人扛着家也不容易」 | 话是对她说的，刀子却递给了他 |
| 第四年 | 不问了 | 已经认定了，不问比问更扎人 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 纸面 | 灵活就业窗口的号 · 一沓社保单据 · 简历上那两年他写了「家庭项目管理」，被 HR 当段子转发 |
| 家里 | 记账 App 的年报 · 他给自己排的课表 · 冰箱上的采买清单 |
| 台词类型 | 「社保自己缴，还是想办法挂单位？」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 决定的性质 | 算出来的 | 他原本就想退下来，算账只是个台阶 |
| 出口 | 两年后回职场，面试官揪着空窗期问 | 不回去了，管家成了他长期做下去的事 |
| 亲戚层 | 他爸妈最过不去 | 她爸妈抢先替他挡着 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 发钱那天，她把转账备注改成「工资」 | 下拉框在「无业」上停住的那三秒 |
| 内心 | 备注她改了，他收不收是另一回事 | 这种小事他不说，都攒着 |
| 好的处理 | 家庭账户里她给了他最高权限 | **他管那沓社保单据叫工资条** |
| 写崩 | 让她说出「我养你」 | 他一天天蔫下去 |

#### 写崩的三种方式

1. 写成失业。 他是自己辞的，主动权一丢，这条就塌成了 [12-工作与金钱 · 他失业了](12-工作与金钱.md#七--他失业了)。
2. 让「我养你」说出口。 在 12 卷是雷，在这里还是，它把分工说成了收养。
3. 亲戚个个是恶人。 多数人只是找不着话，恶意要落到具体的人身上，别摊给整桌。

#### 可串接

前接：[12-工作与金钱 · 他失业了](12-工作与金钱.md#七--他失业了)（非自愿版对照） · [五 · 出入境柜台](#五--出入境柜台)

## 八 · 保险受益人

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（缺口清扫增补）

**骨架**｜她给自己买了一份保险，受益人填他，比例一栏写100%，柜员前后核了三遍。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 年底理账，她顺便把保险也办了 |
| 2 | 保额照年收入算出一个数，念出来的时候屋里一片安静 |
| 3 | 受益人一栏她写了他，指定受益，不走法定继承 |
| 4 | 第一遍核对：“你跟她什么关系？” |
| 5 | 第二遍：“就写一个人？”第三遍：“全给他？” |
| 6 | 签字页下方一行小字：身故保险金受益人。他看到了“身故”两个字 |
| 7 | 回去的路上他一句话没说。到了晚上，他说把他的也办一份，受益人写她 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 三遍复核 | 关系 → 人数 → 比例。**单看每一遍都是手续，三遍加在一起就是在掂量人** |
| 纸面 | 「身故」那行字多大 · 保额是收入的几倍 · 承保短信 |
| 家里 | 两张保单放在同一个抽屉 · 金额不同，比例一样 |
| 台词类型 | 「比例全给他？」「全给他。」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他在不在场 | 在场，听着自己被写进她的身后事 | 不在场，接到承保短信才知道 |
| 他的反应 | 当晚就要她也给自己保一份 | 推让：写咱妈吧。推的理由和 12 卷拒钱一样，只是搬到了身后事上 |
| 那三遍 | 走过场 | 到第三遍，柜员抬眼看了看他俩 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 填比例那栏时笔没停 | 「身故」两个字撞进眼里的那一下 |
| 内心 | 她只怕他看到那两个字 | 有份文件他不在场也照样生效，写的是她把自己折算成一个数 |
| 好的处理 | 保额她不解释，只说是个安排 | 他回了对等的一张，金额小些，比例同样是一百 |
| 写崩 | 写成生死预告 | 写成推拒闹剧 |

#### 写崩的三种方式

1. 把保单当伏笔埋。 这张保单多半一辈子都用不着，真用上了就是另一本书。
2. 绕开「身故」两个字。 钝痛就在那一下，绕开了等于没写。
3. 把三遍复核写成歧视现场。 那是柜台练出来的习惯动作。

## 九 · 户口本

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（缺口清扫增补）

**骨架**｜迁户口那天，户主填的是她。民警按惯例问了一句，又多加了两个字：也行。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 婚后迁户口，取号排队，站到窗口前 |
| 2 | “户主写谁？”办事员先朝他看了一眼 |
| 3 | “写她。”“行，也行。” |
| 4 | 录完信息，打印机吐纸，第一页是她，第二页是他 |
| 5 | “与户主关系”一栏打出来的是：配偶 |
| 6 | 民警又补了一句，以后孩子落户，材料跟户主走 |
| 7 | 出门后他把户口本放进证件包，那个包一向由他管 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 那个词 | 「一般写男方」「也行」。制度让了步，不拦着，只是提一句「一般」 |
| 纸面 | 首页与第二页的顺序 · 老版「夫」与新版「配偶」的一字之差 · 骑缝的红章 |
| 物件 | 窗口玻璃的传递槽 · 打印机 · 家里的证件包 |
| 台词类型 | 「户主写哪位？」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 惯性问题问到哪 | 问户主 | 问孩子跟谁姓，这一问扎得更深 |
| 后续麻烦 | 没有 | 有一天他办事得多开一张证明，排着队算了算这页纸值多少钱 |
| 版本 | 新式「配偶」 | 老式的打出一个「夫」字，他盯着看了两秒 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 民警说的「也行」 | 每回办事，窗口都先翻她那页 |
| 内心 | 没人拦她，可她清楚自己被单独拎了出来 | 他习惯先把本子翻到要用的那页，再递进去 |
| 好的处理 | 她不庆祝，户主栏上没写她名字她也不在意 | 「翻好再递」，规矩被他变成了自己的顺手 |
| 写崩 | 写她赢了 | 把「夫」字写成受气 |

#### 写崩的三种方式

1. 民警多说了一个字。 他的台词只有「也行」，再多一个字就有了立场。
2. 写成她赢了。 一庆祝就等于认了这是场比赛，可这个家里没人在跟他比。
3. 不写物件。 页序、红章、证件包，这场戏都在纸和塑料皮上。

## 十 · 制度追上来之前

<!-- gb-nonscene -->
`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：不单独计（收束条）

**骨架**｜这里没有单独一场戏，时间跨了好几年。日子早过起来了，表格过几年才改。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 头几年靠涂改，划掉印好的字，跟柜台多解释一句 |
| 2 | 有一年政务系统更新，下拉框多出一个选项，没人告诉过他们 |
| 3 | 学校的通知由「请妈妈们」换成「请家长」 |
| 4 | 孩子的入学表上印的是「监护人一／监护人二」，后头没有括号 |
| 5 | 他们填得毫不犹豫，拿来就用，好像它早该在那儿 |
| 6 | 孩子这一代会以为表格一直都是这样 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 三个版本 | 同一张表：预印「（母亲）」的 → 括号删掉的 → 只写「监护人」的 |
| 痕迹 | 涂改液 · 圈改笔迹 · 没人看的更新日志 |
| 留存 | 旧版那张他留了一份。**家里管表的人最先发现字段改了，也最记得旧表的样子** |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 发现新选项的人 | 他，管表的人 | 孩子：「这有什么好留的？」 |
| 改动的速度 | 一项一项地改，很慢 | 有一年一下子改了一批，他们倒不习惯了 |
| 情绪 | 谈不上情绪，只是看到了 | 那天晚上多聊了十分钟当年的柜台 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看到新选项那次想叫他来看，他在剥豆子，她就没出声 | 旧表折了两折，压在证件包最底层 |
| 内心 | 改是改了，可不是为他们改的，这样正好 | 只有用过旧表的人才知道新表省掉了哪几笔 |
| 好的处理 | 不念叨，表格改了就接着用 | 孩子问起来，他就一句：以前格式不一样 |
| 写崩 | 写成给制度唱赞歌 | 写成控诉大会总结 |

#### 写崩的三种方式

1. 写成对制度感恩戴德。 表格是改了，可不是为他们改的，硬把因果挂上去就假了。
2. 写成总结陈词。 只要一发宣言，前九条的钝感就散了。
3. 让改动一步到位。 制度慢半拍，慢就要慢得零碎，凑不成典礼。
