# 制度里的两个人

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 现代（现实性别制度）
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。柜台与表格类场面在语料里未单列成族，选目走 [README](README.md) 的缺口清扫路线；文中引用的族占比为编写时实测，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**制度不针对他们，制度只是没想到他们。** 恶意有人负责，默认值没有人负责，所以这种摩擦是钝的，磨的是日常。

---

## 这一族收的是没有对手的摩擦

[14-社交与公开](14-社交与公开.md) 写熟人：起哄的同事、议论的邻居、带旧框架的长辈。那些摩擦有脸、有名字、有一句可以回敬的话。这一族写另一类现场：签字栏、下拉框、柜台的惯性提问。对面没有人可以生气，护士只是照惯性去找男家属，表格只是印着上一个时代的分工。

| | 熟人场（14 卷） | 制度场（这一族） |
|---|---|---|
| 摩擦来源 | 具体的人与话 | 默认设置 |
| 有没有对手 | 有，可以回敬 | 没有，回敬会落空 |
| 情绪形态 | 尖的，当场起 | 钝的，回家路上才冒头 |
| 好的收法 | 谁接话、怎么接 | 谁把那一栏改掉、怎么改 |

与这一族最近的实测族是偏见（28.1%）与议论（21.0%，均 13-07），两族写的都是人。柜台不议论，柜台只是复核三遍。十条共用一条判据：**对面无恶人。** 谁都没做错，他们也过得下去，只是每一步都要多按一下、多解释一句。

双向是这类场面的富矿：同一个窗口，她那侧是被预设为决策者的坦然或疲惫，他那侧是被制度略过的刺或松，两个视角是两场完全不同的戏。十条的「双向写法」都按这个口径填。

## 一 · 手术单上的名字

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（缺口清扫增补；陪床场面见 [09-分离与重逢](09-分离与重逢.md#四--陪床)）

**骨架**｜他要做个小手术。签字环节，走廊里被喊的是「家属」，被找的是男人。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 术前谈话通知下来：时间、地点、家属到场 |
| 2 | 走廊长椅，护士探身喊「三十六床家属」 |
| 3 | 她应声起身，对面的目光越过她，往她身后找 |
| 4 | 半秒。身后没有别人，目光落回来 |
| 5 | 风险条款逐条念，问的是「您能做主吗」 |
| 6 | 递笔。拴着链子的圆珠笔，她接住，签得很稳 |
| 7 | 坐回长椅，她才发现手心全是汗 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 纸面 | 知情同意书 · 「与患者关系」一栏 · 复印件 · 风险条款的编号 |
| 物件 | 拴链子的笔 · 玻璃窗下的传递槽 · 走廊长椅 · 手术室门口的灯 |
| 那半秒 | 目光越过她 → 身后没人 → 落回来 → 语气不变 |
| 台词类型 | 「您能做主吗」「我能。」没有第三句 |
| 公私分界 | **柜台前稳，坐下才抖。** 顺序不能反 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 躺着的是谁 | 他手术，她签 | 她手术，谈话对象默认是他，风险他一条条听完 |
| 那半秒 | 她读出来了，没接 | 她根本没注意，习惯了 |
| 他知不知道 | 术后在出院材料里看见她的签名 | 一直不知道走廊那半秒 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 笔递过来之前那半秒的目光 | 推进去前，听见走廊里她应「家属」的那一声 |
| 内心 | 条款第七条她读了两遍 | 在这栋楼里，她是他的什么，要靠一张表说明 |
| 好的处理 | 不与护士计较，签完字才允许自己抖 | 他把签名那页从出院材料里抽出来收好 |
| 写崩 | 当场纠正对方的找法 | 写成他觉得没面子 |

#### 写崩的三种方式

1. 给护士写立场。她只是照惯性喊人，一有立场就有了恶人，钝感就没了。
2. 让她在窗口发言。这场戏她只有两个字的台词，多一句都是演讲。
3. 把手术写重。中等的手术刚好，太重就成了生死戏，那半秒会被淹掉。

## 二 · 售楼处只看她

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（缺口清扫增补）

**骨架**｜看房。开场三句之后，销售完成了目光迁移，全程对她讲。他有两个版本：舒服，或者刺。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 进门，销售迎上来，第一句话对着他说 |
| 2 | 她问了贷款和梯户比，他在看沙盘 |
| 3 | 第三句起，销售的身体已经转向她 |
| 4 | 样板间：她看总价单，他试水压、摸插座位置 |
| 5 | 谈折扣，计算器推过去，推向她那一侧 |
| 6 | 他去接水的两分钟里，首付方案谈完了 |
| 7 | 出门他说了一句厨房动线不对，她折回去，把这条砍进合同 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 目光迁移 | 称呼从「哥」换成「姐」· 身体的朝向 · 递单页的方向 |
| 道具 | 沙盘 · 计算器 · 纸杯水 · 认购意向单 · 样板间的假书 |
| 他的领域 | 水压 · 插座 · 动线 · 窗外噪音。**他看的没一样在价格单上** |
| 台词类型 | 「姐，这个价我得请示经理」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的版本 | 舒服：不用再演懂行 | 刺：他被从谈判里划掉了，称呼都对，就是没人问他 |
| 迁移速度 | 三句话内 | 到样板间才完成 |
| 钱的实情 | 全是她的 | 他也出了一份，但没人问 |
| 收法 | 他的意见进了合同 | 他全程没说话，回家才说 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 计算器推过来那一下，她顺手接住 | 销售第三次越过他之后，他开始看窗外 |
| 内心 | 她注意到他在阳台站了很久 | 舒服版：这两个小时归她。刺版：我连坐标都没有 |
| 好的处理 | 她把一个问题原样转给他：「这个你看。」 | 他接住了，答得内行 |
| 写崩 | 写成她享受他被略过 | 写成自尊当场塌方 |

#### 写崩的三种方式

1. 把销售写成势利眼。目光迁移是职业判断，跟着钱走，一势利就有了恶人。
2. 两个版本混着写。舒服和刺是两种人设，一场戏只能选一个。
3. 让刺当场发作。刺要延迟，回家路上才冒头，当场发作就成了另一场吵架。

## 三 · 家长会谁去

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：孩子 24.8% 衍生（13-07 实测）

**骨架**｜学校的通知写着「请妈妈们抽空」。去的是他。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 班级群通知，措辞是「请妈妈们」 |
| 2 | 家里的分工本来就是他管学校，他接龙报名 |
| 3 | 教室后排，一屋子妈妈，外加两位爷爷 |
| 4 | 老师开场「各位妈妈」，说顺了口 |
| 5 | 点到他家孩子，老师下意识往妈妈堆里看，他举手 |
| 6 | 会后单独交流，三句话里两次「回去跟妈妈商量」 |
| 7 | 他说：这事我定就行。老师顿了顿，把话头改了过来 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 纸面 | 家校联系册的「家长（母亲）签名」栏 · 群昵称格式「××妈妈」，他改成「××爸爸」，全群一个 |
| 现场 | 小板凳 · 后墙的作文展 · 孩子桌肚里的橡皮 |
| 称呼 | 「各位妈妈」·「孩子平时妈妈管得多吧」 |
| 那句夸 | 「爸爸带得这么细，少见」。**同一件事，她们是应该，他是少见** |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 老师的反应 | 顺口的惯性，无意识 | 当面夸「难得」，夸本身就是提醒 |
| 他的接法 | 顺手改联络册那一栏 | 懒得改，孩子知道找谁就行 |
| 她那边 | 完全放权 | 回家追问细节，发现孩子的学校生活她只有转述版 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 开会间隙收到他拍的照片：孩子的卷子贴在墙上 | 满场「妈妈」里安坐 |
| 内心 | 墙上那张卷子她是第一次见 | 被夸「少见」的那一下别扭 |
| 好的处理 | 她不补偿不内疚，下次照旧他去 | 他把「母亲」两个字划掉，写上「父亲」，笔画很平 |
| 写崩 | 写成她的愧疚大发作 | 写成他在妈妈群里如鱼得水的喜剧 |

#### 写崩的三种方式

1. 把那句夸写成甜头。「少见」是这条钝刺的位置，写成得意就丢了。
2. 妈妈们围观他。猎奇会把制度戏变成相亲角段子。
3. 孩子全程没有台词。孩子说一句就够，但要有，孩子不是道具。

## 四 · 表格里没有他们

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（缺口清扫增补）

**骨架**｜领证后集中办手续的一个下午。三张表用三种方式预设了谁是主、谁是附。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 取号，一叠表，一支笔 |
| 2 | 联名账户：「主账户人」一栏，他不假思索写了她的名字 |
| 3 | 车位合同：经办人栏被销售提前填了他的名，她划掉重签 |
| 4 | 家属体检套餐：「配偶」后面预印着「先生」，他圈掉，写「女士」 |
| 5 | 柜员逐张复核，在改动处停了一下，没说什么，盖章 |
| 6 | 出来，他把回执按办理顺序理好，收进文件袋 |
| 7 | 最后一张表两人同时伸手，笔尖停在半空。这一栏没有对错，只有先后 |

#### 字段清单

| 字段 | 预设 | 他们的实况 |
|---|---|---|
| 主贷人 | 「一般写先生」 | 收入高的那个，是她 |
| 紧急联系人 | 各写各的父母 | 互为第一顺位 |
| 称谓下拉框 | 先生排在第一项 | 每次多按一下 |
| 「家属」 | 一个固定的谁 | 看哪张表：她单位的表里他是家属，医院的单子上她是 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 纸面 | 预印字 · 圈改的笔迹 · 骑缝章 · 回执 |
| 柜台 | 「都行，一般写先生」· 复核时问一遍「确定吗」 |
| 动作 | 划掉 · 圈改 · 复核的停顿 · 文件袋按顺序收纳 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 表的年代 | 纸质预印，改不动 | 新系统下拉框已经多了选项 |
| 他的态度 | 顺手改，不评论 | 收集这些栏目，攒够了当笑话讲给她听 |
| 分工 | 医院的单他签，银行的单她签 | 谁在场谁签，反而每次都要解释 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「都行」在柜台语言里的真实用法 | 「家属」这个词第一次落在自己头上 |
| 内心 | 她第一次成为别人表格里的默认答案 | 不难受。难受的是有一栏他停了三秒，最后选了「其他」 |
| 好的处理 | 把「谁当谁的家属」变成分工，一人认领一半柜台 | **圈改的笔迹工整，像批作业** |
| 写崩 | 对着表格独白控诉 | 写成他每一栏都疼 |

#### 写崩的三种方式

1. 对表格发议论。表格不回嘴，议论落不到人身上，只能落到读者头上，那是说教。
2. 每一栏都展开。挑一栏写足，其余进清单。
3. 复核的停顿带表情。柜员的停顿要无辜，长着流程的脸。

## 五 · 出入境柜台

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（缺口清扫增补）

**骨架**｜她外派，他随迁。签证类别替他定了身份：主申请人的配偶。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 外派定了，材料清单下来：她的一沓，他的一页 |
| 2 | 他那页只要两样：关系公证，无犯罪证明 |
| 3 | 面签窗口，问题全部对她。落到他身上的只有一个 |
| 4 | 「过去做什么？」她想替他答，被抬手止住 |

| 类 | 内容 |
|---|---|
| 纸面 | 材料厚度差 · 签证类别代码 · 入境卡「职业」栏他停了三秒 · 各种编号的「-2」尾缀 |

| 台词类型 | 「主申请人是？」「她。」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的心态 | 松：名正言顺歇一段 | 悬：居留押在她的合同上，她续签他才合法 |
| 她的心态 | 全程内疚 | 没想过这层，被他一句玩笑点破 |
| 后续 | 他在当地重新考了执照，编号换成不带尾缀的 | 一直是「-2」，他把它用成了两人之间的昵称 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他那句「学做那边的菜」，比她准备的一页口径都好 | 围栏那一米，隔出去的一段路 |
| 内心 | 他的合法性以她为条件，这件事她比他先想到 | 「-2」不难听，难的是每张表都会再说一遍 |
| 好的处理 | 她把续签日期设成两个人的共同提醒 | 他先去办了图书证，再去办别的 |
| 写崩 | 写成她的负罪感专场 | 写成移民苦情戏 |

#### 写崩的三种方式

1. 把家属身份写成屈辱。他失去的只是排在前面的位置，人格还在原处。
2. 签证官刁难。程序性的问题要程序性地问，一刁难就换了戏种。
3. 跳过纸面层。代码、通道、尾缀，这条的戏全部长在手续上。

## 六 · 两家谈钱

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：婚仪 38.8% 衍生（13-07 实测）

**骨架**｜数目十分钟就谈拢了。谈不拢的是名目：她家给他家的那笔钱，字典里没有名字。

制度特写版。[23-婚嫁 · 两家坐下来谈](23-婚嫁.md#二--两家坐下来谈) 写人怎么谈，这条拍词不够用。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 两家坐定，茶过一巡，逐项过议程 |
| 2 | 数目很快：两家都出得起，也都不小气 |
| 3 | 卡住：她家出的那笔，按「彩礼」走，他爸收不下手 |
| 4 | 桌上试词：「安家费」「添置」「心意」，一个个都不对 |
| 5 | 他妈问：那我们陪的那份，算嫁妆吗。半桌沉默 |
| 6 | 他爷爷放下茶杯：这不就是当年的招婿么，老规矩里有词 |
| 7 | 谁也没用老词，但僵局散了。两笔钱都记进「办事的钱」，不叫名字 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 纸面 | 转账备注栏空着 · 红包封面的「囍」不分方向 · 记账的红本 |
| 桌面 | 茶杯转了半圈没喝 · 果盘没人动 · 谁给谁续水 |
| 词 | 彩礼 · 嫁妆 · 聘 · 陪送。**每个词都自带箭头，箭头都不对** |
| 台词类型 | 「这钱按什么名目走？」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 卡点 | 词：叫什么 | 流向：谁给谁，数目反而没人争 |
| 代际 | 父母辈最难过关 | 祖辈反而通达，旧制度里有现成的位置 |
| 解法 | 借酒席账目做壳 | 两家各出一份「成家的钱」，新词是他们自己造的 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 卡住的全是词，数字从头到尾没吵过 | 全桌都在定义他家那笔钱的性质 |
| 内心 | 爸妈要的只是说出去的那句话 | 该他开口了 |
| 好的处理 | 她把新名目包装成两边长辈的主意 | 他提的方案让两边都有词说，那一晚是他的主场 |
| 写崩 | 写成她拍桌定音 | 写成他是桌上的标的物，全程无发言 |

#### 写崩的三种方式

1. 写成数目之争。钱三分钟谈完，这条的戏全部在名目上。
2. 新词一次就成。词要试错三个，第一个就通过等于没写。
3. 重拍 23 卷那场。人物冲突归 [23-婚嫁 · 两家坐下来谈](23-婚嫁.md#二--两家坐下来谈)，这条只拍桌面上的词。

前接：[13-家庭与亲属 · 她家里人怎么看他](13-家庭与亲属.md#二--她家里人怎么看他)
后接：[23-婚嫁 · 领证那天](23-婚嫁.md#三--领证那天) · [九 · 户口本](#九--户口本)

## 七 · 他辞职那年

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（[家庭主夫](../02-术语百科/03-人设与套路标签.md) 标签见 02-术语百科）

**骨架**｜辞职是两个人算出来的决定。手续是他一个人办的：社保、空窗、亲戚的问法，制度用三种口径问他是谁。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 账算下来：她的机会、老人孩子、两份收入的差，他回家划算 |
| 2 | 离职那天，HR 问社保怎么转，他第一次听说「灵活就业」（社保系统对无雇主人员的类目名）这个词 |
| 3 | 政务 App 里选参保身份，下拉框里没有他这一行，挨得最近的叫「无业」 |
| 4 | 每月自己缴社保，单据攒进一个夹子 |
| 5 | 年夜饭，亲戚的问法一年一变 |
| 6 | 接送孩子认识的家长问他做哪行，他答：管后勤 |
| 7 | 年底他把家里的账做成一张年表，像述职 |

#### 亲戚问法的演变

| 年份 | 问法 | 实际含义 |
|---|---|---|
| 第一年 | 「最近忙什么呢」 | 探 |
| 第二年 | 「还没找到合适的？」 | 已经替他定性成「找不到」 |
| 第三年 | 「一个人养家也辛苦」 | 话对着她说，刀口对着他 |
| 第四年 | 不问了 | 定型。不问比问更响 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 纸面 | 灵活就业窗口的号 · 社保单据一沓 · 简历上那两年怎么写（他后来写了「家庭项目管理」，被 HR 当段子转发） |
| 家里 | 记账 App 的年报 · 他给自己排的课表 · 冰箱上的采买清单 |
| 台词类型 | 「社保自己缴，还是想办法挂单位？」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 决定的性质 | 算出来的 | 他本来就想退，账只是台阶 |
| 出口 | 两年后重返职场，面试官盯着空窗期 | 不返，他把家管成了长期的事 |
| 亲戚层 | 他爸妈最难过 | 她爸妈先替他挡 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 发钱那天，转账备注她改成「工资」 | 下拉框停在「无业」上的三秒 |
| 内心 | 备注改了，他收不收是另一回事 | 这类小事他不讲，攒着 |
| 好的处理 | 她在家庭账户里给他开了最高权限 | **他管那沓社保单据叫工资条** |
| 写崩 | 让她说出「我养你」 | 写成他日渐枯萎 |

#### 写崩的三种方式

1. 写成失业。他是辞的，把主动权写丢，这条就塌成 [12-工作与金钱 · 他失业了](12-工作与金钱.md#七--他失业了)。
2. 「我养你」出口。在 12 卷是雷，在这里也是，它把分工判成了收养。
3. 亲戚全员恶人。多数人只是没词，恶意要给具体的人，别摊给整张桌子。

#### 可串接

前接：[12-工作与金钱 · 他失业了](12-工作与金钱.md#七--他失业了)（非自愿版对照） · [五 · 出入境柜台](#五--出入境柜台)
后接：[12-工作与金钱 · 她给钱，他不要](12-工作与金钱.md#四--她给钱他不要) · [01-日常照料 · 学着做饭](01-日常照料.md#一--学着做饭)
设定接口：[03-世界观设定/04-非女尊设定下的权力来源设计](../03-世界观设定/04-非女尊设定下的权力来源设计.md)（职务权归零后，落差怎么转移）

#### 示例（本库自撰，可直接改写）

> 参保身份那一栏是个下拉框。
> 在职、灵活就业、学生、退休、无业。
> 他把列表拉到底，又拉回来。没有一行是他。指头悬了三秒，点了「无业」。
> 系统跳出一行绿字：变更成功。
> 晚上她问手续办得顺不顺。挺顺，他说，一次就过了。
> 那个下拉框他没提。这类事他都攒着，攒到哪天够当笑话讲了，再讲。

## 八 · 保险受益人

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（缺口清扫增补）

**骨架**｜她给自己投保，身故受益人写他，比例一栏填了 100。柜员复核了三遍。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 年度财务安排，她顺手约了保险 |
| 2 | 保额按收入倍数算出来，数字念出来那一刻，屋里静了一下 |
| 3 | 受益人栏，她写他的名字，指定，不走法定 |
| 4 | 复核第一遍：「与被保险人关系？」 |
| 5 | 第二遍：「就写一位？」第三遍：「比例都给他？」 |
| 6 | 签字页那行小字：身故保险金受益人。他读到「身故」两个字 |
| 7 | 回家路上他没说话。晚上他说：把我的也办一份，受益人写她 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 三遍复核 | 关系 → 人数 → 比例。**每一遍都是流程，叠在一起就是打量** |
| 纸面 | 「身故」的字号 · 保额与收入的倍数关系 · 承保短信 |
| 家里 | 两张保单进同一个抽屉 · 金额不对称，比例对称 |
| 台词类型 | 「比例都给他？」「都给他。」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他在不在场 | 在场，听着自己被登记进她的身后 | 不在，收到承保短信才知道 |
| 他的反应 | 当晚要求对等投保 | 推让：写咱妈吧。推让的逻辑同 12 卷的拒钱，只是挪到了身后层 |
| 那三遍 | 纯流程 | 第三遍时抬眼看了看他们俩 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 填比例那一栏，笔没停 | 「身故」两个字进眼睛的那一下 |
| 内心 | 她怕的只有他看见那两个字 | 有一份文件，他不在场也生效，内容是她把自己折成了数 |
| 好的处理 | 她不解释保额，只说是安排 | 他的对策是对等的一张：金额小，比例一样是一百 |
| 写崩 | 写成生死预告 | 写成推拒闹剧 |

#### 写崩的三种方式

1. 拿保单当伏笔。这条的分量就在它多半一辈子用不上，一用上就换了书。
2. 绕过「身故」两个字。钝的就是那一下，绕过去等于没写。
3. 把三遍复核写成歧视现场。那是柜台的肌肉记忆，长着流程的脸。

## 九 · 户口本

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列（缺口清扫增补）

**骨架**｜迁户那天，户主一栏是她。民警的惯性提问只有一句，多出来的词是「也行」。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 婚后迁户，取号，窗口 |
| 2 | 「户主写哪位？」目光先落在他脸上 |
| 3 | 「写她。」「哦，也行。」 |
| 4 | 录入，打印机吐页。首页是她，第二页是他 |
| 5 | 「与户主关系」一栏打出来：配偶 |
| 6 | 民警提醒：以后孩子落户，材料跟户主页走 |
| 7 | 出门，他把本子收进证件包。那个包一直是他管的 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 那个词 | 「一般写男方」「也行」。**制度让步的方式：不拦，但要提醒一句「一般」** |
| 纸面 | 首页与第二页的顺序 · 老版「夫」与新版「配偶」的一字之差 · 骑缝的红章 |
| 物件 | 窗口玻璃的传递槽 · 打印机 · 家里的证件包 |
| 台词类型 | 「户主写哪位？」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 惯性问题落点 | 问户主 | 问孩子随谁姓，这一问更深 |
| 后续成本 | 没有 | 某天他办事要多开一张证明，排队时他算了算这页纸的价钱 |
| 版本 | 新式「配偶」 | 老式打出来一个「夫」字，他盯着看了两秒 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「一般」和「也行」之间那条缝 | 每次办事，窗口都先看她那页 |
| 内心 | 制度没拦她，但记下了她是例外 | 他习惯把本子翻到要用的那页再递进去 |
| 好的处理 | 她不庆祝。户主栏没有奖品 | 「翻好再递」，他把制度的顺序用成了自己的熟练 |
| 写崩 | 写成一场胜利 | 把「夫」字写成屈辱 |

#### 写崩的三种方式

1. 民警多说一个字。「也行」就是全部台词，再多就成了立场。
2. 写成她的胜利。庆祝等于承认那是场比赛，这个家里没人在跟他比。
3. 丢掉物件层。页序、红章、证件包，这条的戏全在纸和塑料皮上。

## 十 · 制度追上来之前

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：不单独计（收束条）

**骨架**｜这条不是一场戏。它是一根跨年的线：他们先把日子过成了，表格几年后才改过来。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 头几年靠涂改：圈掉预印的字，向柜台多解释一句 |
| 2 | 某年政务系统更新，某个下拉框多了一个选项，没人通知他们 |
| 3 | 学校通知的措辞从「请妈妈们」改成「请家长」 |
| 4 | 孩子的入学表印着「监护人一／监护人二」，后面没有括号 |
| 5 | 他们填的时候没停顿，用得像一件早就该在的东西 |
| 6 | 孩子那一辈会以为表格从来就长这样 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 三个版本 | 同一张表：预印「（母亲）」的 → 括号删掉的 → 只写「监护人」的 |
| 痕迹 | 涂改液 · 圈改笔迹 · 没人读的系统更新日志 |
| 留存 | 他把旧版那张留了一份。**家里管表的人，最先发现字段改了，也最记得旧的长什么样** |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 发现新选项的人 | 他，管表的人 | 孩子：「这有什么好留的？」 |
| 改动的速度 | 一项一项，慢 | 某年集中改了一批，他们反而不适应 |
| 情绪 | 没什么情绪，就是注意到了 | 那晚多聊了十分钟当年的柜台 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她注意到新选项那次，想指给他看，他在剥豆子，她没说 | 旧表折了两折，压在证件包最底层 |
| 内心 | 改了，但没有为他们改，这样正好 | 过过旧表的人，才知道新表省了哪一笔 |
| 好的处理 | 不感慨。生活在前，表格在后，顺序本来就该这样 | 孩子问起，他只说：以前格式不一样 |
| 写崩 | 写成对制度的谢幕致辞 | 写成控诉总结陈词 |

#### 写崩的三种方式

1. 写成制度的感恩戏。表格改了没有为他们改，把因果挂上去就假了。
2. 写成总结陈词。这条收的是前九条的余温，宣言会把余温烧糊。
3. 让改动一次到位。制度慢半拍，慢就要慢得零碎、不成典礼。
