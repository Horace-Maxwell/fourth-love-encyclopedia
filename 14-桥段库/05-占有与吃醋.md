# 占有与吃醋

> **分级** 分级见各条，分级上限 `M`（第四条「留痕」）｜ 预警 ⚠️亲密接触 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**占有欲在弱势方身上是不合法的，所以他只能用别的形式表达。**

## 这一族的特殊难度

在传统言情里，男主吃醋可以直接上手：查手机、赶走情敌、宣布主权。但这套动作放到这类文里全废了——他压根没那个身份。

他吃醋了能做什么？

| 他能做的 | 他不能做的 |
|---|---|
| 安静下来 | 质问 |
| 拐弯抹角地问 | 禁止 |
| 更黏她一点 | 发火 |
| 自己去查 | 摊牌 |
| 什么都不做，但她看得出来 | 要求她解释 |

这个限制正是这一族的写作乐趣。 一个人有强烈的情绪却没有表达它的合法渠道，那些情绪就会从各种奇怪的地方漏出来。写那些漏出来的地方，比写质问有意思得多。

反过来，她这占有欲是明摆着合法的。她想宣示就宣示，想留记号就留记号，想把人带走就直接带走。同样一种情绪，搁她身上能摊开晒，搁别人身上只能藏着掖着。写这一族，每一条都得把这个不对称写明白。

| 查岗吃醋 | 1,088 | 37.6% |

## 一 · 那个人是谁

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：查岗吃醋 37.6%，吃醋＋等待 5.9%

**骨架**｜他想问，又张不开嘴；等真问出来了，话已经绕了三道弯。

#### 节拍链

发现（一个名字／一条消息／一个人）→ 起意 → 忍 → 试探 → 问 → 她的回答 → 他信不信

#### 时间轴

他问话的方式就是一条时间线。一开始是「你今天见谁了」，后来变成「那个人是你同事吗」，最后憋出一句「他挺好的」。每改一次，就是退一步。

| 版本 | 他实际想说的 |
|---|---|
| 「今天顺利吗」 | 你今天跟谁在一起 |
| 「那个人也去了？」 | 他是谁 |
| 「他挺好的。」 | 我不好受 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 触发物 | 手机 ✓ 屏幕上闪过一个名字 · 她身上的味道 · 她提起某人时那口气 · 一张照片 ✓ |
| 他的忍耐动作 | 碗洗个没完 · 突然开始收拾屋子 · 手机 ✓ 拿起来又放下 |
| 试探的伪装 | 装着随口问一句 · 挑她心情好的时候 · 夹在别的话里带出来 |
| 破绽 | 问完不敢看她 · 语气太稳了，反而假 |
| 她的三种回答 | 好好解释 · 一句话带过 · 反问「你吃醋了？」（他肯定不认） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他问不问 | 问了 | 一直没问，自己憋着 |
| 她的态度 | 主动说清楚 | 先让他难受一阵（危险，得有原因） |
| 真相 | 压根没关系 | 确实有过往 |
| 收尾 | 她把话挑明了 | 就这么吊着 |

「她给了明确的界限」是这个类型里最受欢迎的收法：强势方主动划界，比弱势方索要保证有力得多。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他今晚一直在洗碗 | 问出口之前的三次改稿 |
| 内心 | 他到底想问什么，还是我先说 | 我没有资格问 |
| 好的处理 | 她不等他问就说了 | 他问得很难看，但他问了 |
| 写崩 | 写成她享受他的嫉妒 | 写成阴阳怪气 |

「她不等他问就说了」是四爱女角色的高级操作。主动交代跟被审问是两回事，它替对方省下一次难堪。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 新收的侍君／她书房里多出一方砚／宫里赏下来的人 |
| 修仙 | 双修的道侣／她以前那个旧人／同门里谁的名字 |
| 星际 | 副手名单／她终端上那个加密频道 |

古代女尊文里，妻主多夫是明摆着的事，法律都认。所以男主的醋，只能算「不该有的」。这反而让他忍得更有理由，戏也就更好写。具体规矩看 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。

#### 写崩的三种方式

1. 让他直接质问。 那不是这一条，那是权力翻转。真这么写，后面怎么收场先得想清楚。
2. 让她刻意吊着。 没个正当理由，读者肯定站他那边，你这就是找骂。
3. 一问就解决。 这条的核心就是忍的过程，忍得住才有戏。

#### 示例（本库自撰，可直接改写）

> 水一直开着。碗其实早就洗完了。
> 他把那只已经冲过两遍的碗又冲了一遍，放进架子，然后没有关水。
> 「今天……顺利吗。」他背对着她说的。
> 「挺顺利的。」
> 他关了水，手在围裙上擦，擦得比需要的时间长。
> 「他挺好的。」
> 说完他自己也知道这句不对劲。可是收不回来了，水龙头上还挂着一滴，很久才落下去。

## 二 · 查手机

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：查岗吃醋 37.6%

**骨架**｜他拿起她手机看了看，又放下了。也可能没放。

#### 节拍链

屏幕亮起 → 他看见了 → 拿起来 → 那三秒 → 放下／解锁 → 把手机摆回原来的角度

#### 时间轴

那三秒就是整条视频的时长，前面后面各有一段余波。
拿起手机之前的犹豫，能铺一整段戏；但拿起之后，最多三秒——超过三秒，那就是下定决心了。
真正的余波在后面：他把手机放回原处、还摆回原来那个角度的动作，说明这三秒，他能记一辈子。

#### 这条的道德坡度

查手机是这一族唯一一条明确越界的动作。写法上有三档，选错档位会让人物崩掉：

| 档 | 动作 | 读者接受度 |
|---|---|---|
| 一 | 屏幕亮了，他看见了，没有点开 | 高 |
| 二 | 他拿起来，看了锁屏，放下 | 中 |
| 三 | 他解锁，翻了 | 低，需要后续代价 |

一档的信息量其实最大。 一条推送通知能给出的东西，和翻完整个聊天记录差不多，但人物是干净的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓ · 屏幕 ✓ · 消息 ✓ · 微信 ✓ · 充电 ✓（手机在充电，所以在客厅） |
| 一档细节 | 屏幕亮那一下他正好在旁边 · 他扭头装没看见，其实已经瞄到了 · 名字后面那个括号 |
| 三档的后果 | 她发现了 · 或者更糟：她没发现，但他从此知道自己是会干这种事的人 |
| 他放下时的动作 | 把手机放回原样，角度都没变 |

「把手机摆回原来的角度」是这条最好的一个细节：他连自己动过都想抹掉，说明他知道这不对。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他查不查 | 忍住了 | 查了 |
| 她知不知道 | 不知道 | 知道，也没设密码（这就是她的态度） |
| 他查到什么 | 啥也没有 | 一件他更不想知道的小事 |
| 后果 | 没事 | 他自己心里那道坎过不去 |

「她没有设密码」这个设定值得单独用一整场。她的开放不等于无所谓，那是一种明确的给予。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现手机被人动过 | 拿起来那一秒 |
| 好的处理 | 她不问，只说「你想看就看」 | 他没看，也没提自己没看 |
| 写崩 | 写她当场发火 | 写成理直气壮翻手机 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她案上的书信／她的名帖／门房记录的来客 |
| 修仙 | 传讯玉简／她的储物袋／识海里的印记 |
| 星际 | 通讯日志／她的权限记录 |

#### 写崩的三种方式

1. 让查手机变成常态。 一次是失控，两次是人格。
2. 不给代价。 三档必须有代价，否则文本就是在认可这个行为。
3. 查出大秘密。 那是悬疑线不是日常戏。查出一件小事更好。

## 三 · 闻到别人的味道

`T` ｜ 无预警 ｜ 全谱系（女A男O 尤强）｜ 语料频次：查岗吃醋 37.6%

**骨架**｜他没有证据，只有一个气味。而气味无法被引用。

#### 节拍链

靠近时停住 → 说不出口 → 半夜起来洗那件衣服 → 加倍黏她 → 她发现衣服被洗了

#### 时间轴

从闻到到洗掉，中间隔一个整晚。气味这东西没法举证，所以他连发作的资格都没有；只能憋着，憋的时间按小时算：晚饭时闻到，十一点开始翻来覆去，两点爬起来把那件衣服扔进洗衣机。洗衣机转起来的声音，就是这条线的钟摆。

#### 为什么气味特别好用

因为它没法证明。他闻到了，但说不出口，说出来别人只会觉得他有病。这种「知道但没法说」的憋屈劲儿，才是这一族最要命的地方。

在女A男O的设定里，信息素一出来，这事儿就有了物理根据，也顺理成章了。同一个桥段，搁普通设定里是疑神疑鬼，放ABO里就是明摆着的生理反应。

#### 可用细节

| 类 | 内容 |
|---|---|
| 气味载体 | 外套 ✓ 的领口 · 围巾 ✓ · 头发 · 车 ✓ 里 · 她的手腕 ✓ |
| 他的反应 | 靠近时停住 · 帮她挂外套时多停了两秒 · 半夜起来把那件衣服洗了 |
| 他的动作 | 把自己的味道盖上去（抱、蹭、换她的洗发水） |
| 他不能说的 | 「你身上有别人的味道」这句话说出来就输了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 味道来源 | 没啥味儿（同事的车、餐厅） | 有来头 |
| 他说不说 | 不说，光做（洗衣服、加倍黏） | 开口了 |
| 她察觉没 | 没感觉 | 闻到了，自己先提 |
| 设定 | 普通现代 | 女A男O（走 [03-世界观设定](../03-世界观设定/) 的信息素规则） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现那件外套被洗了 | 靠近时那一下停顿 |
| 好的处理 | 她没问为啥洗，换了条路回家 | 他洗了衣服，这事不提了 |
| 写崩 | 写成她故意留痕迹来试他 | 写成他闻着味儿就上头了 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 熏香味道不对／衣服上有别的脂粉气／她换了佩囊 |
| 修仙 | 身上沾了别人的灵息／剑穗上带着别人的气 |
| 星际 | 舱里空气循环记录／她制服上查出的微粒 |
| 女A男O | 信息素残留 · 标记深浅 · 腺体反应 |

#### 写崩的三种方式

1. 让他直接闻她。 动作太露骨会滑向失控。
2. 让气味变成实锤。 气味的价值就在于它不是证据。
3. 让她故意留味道。 那是操控，除非文本对它有判断。

## 四 · 留痕

`M` ｜ ⚠️亲密接触 ｜ 全谱系 ｜ 语料频次：身上留痕 40.8%，留痕＋睡着 10.3%

**骨架**｜留个别人能看见的记号。这是这一族里唯一两边都不越界的动作。

#### 节拍链

留下 → 拇指按一下 → 第二天照镜子 → 遮或不遮 → 出门 → 第三人的一个眼神

#### 时间轴

痕迹这东西，自带保质期，会慢慢消。从留下的那天起，颜色一天比一天浅，每天早上都得重新决定一次：是遮住，还是露出来。等它快消没了，谁先开口说“补一个”，谁就输了这场无声的较量，但也算赢了。

#### 双向的不对称

| | 她留在他身上 | 他留在她身上 |
|---|---|---|
| 性质 | 盖章，告诉别人这人归我 | 求个念想，盼她认账 |
| 位置 | 明面上（脖子、锁骨那块） | 暗地里（她随手能盖住的地方） |
| 他／她的反应 | 他嘴上嫌，其实没躲 | 她兴许压根没当回事 |
| 读感 | 拿捏 | 憋屈 |

第二列是这一族里最好用、也最少人写的一栏。他偷偷在她看不见的地方留了个记号，还不敢留太显眼的地方，这个不对称本身就是全部意思。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 领口 ✓ · 衬衫 ✓ · 围巾 ✓ · 镜子 ✓ · 遮瑕（他买的） · 后颈 ✓ · 锁骨 ✓ · 手腕 ✓ |
| 她的动作 | 留完之后拿拇指按了一下 · 帮他把领子立起来（又放下） |
| 他的处理 | 对着镜子看了老半天 · 换了高领 · 换完又觉得太刻意，又换回来 |
| 第三人的反应 | 同事瞟了一眼 · 没人说破，但都看在眼里 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁留给谁 | 她给他 | 他给她 |
| 位置 | 遮不住 | 只有他们知道 |
| 意图 | 故意的 | 没控制住 |
| 他的态度 | 遮 | 不遮（这是他的宣示，很重） |

「他选择不遮」这一端在四爱男读者那里评价极高：被标记不等于被动，公开承认是他自己的选择。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 第二天看见他没穿高领 | 早上照镜子那一下 |
| 内心 | 我是不是留得太明显了 | 我要不要遮 |
| 好的处理 | 她注意到他没遮，什么也没说 | 他自己做了决定 |
| 写崩 | 写成刻意炫耀 | 写成羞耻表演 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 赐的玉佩／腕上的红绳／她亲手系的带子 |
| 修仙 | 契印／神识烙印／剑穗 |
| 星际 | 舰徽／她给的权限章／腕带 |
| 女A男O | 标记 · 临时标记和永久标记有啥不一样（看 [03-世界观设定](../03-世界观设定/)） |

古代版的信物系统比现代版丰富得多：玉佩、红绳、荷包、腰带都是可见的、可被旁人读懂的标记。

#### 安全与边界

留痕涉及身体接触与可见痕迹。写作时的两条线：

| 线 | 说明 |
|---|---|
| 同意 | 双方都是成年人且自愿。留痕不能作为惩罚手段出现在非自愿情境里 |
| 与训诫的分层 | 本条是亲密行为的痕迹，不是伤害。带伤的走 [06-尺度与写法](../06-尺度与写法/)，并按那一卷的安全框架处理 |

#### 写崩的三种方式

1. 把留痕当成惩罚。 那是另一个性质，且必须带安全框架。
2. 写成公开羞辱。 判据同 [01-日常照料 · 一口一口喂](01-日常照料.md#二--一口一口喂)：她有没有在意他的难堪。
3. 只写她留他。 反向那一栏才是这个类型的特色。

## 五 · 日常版雄竞

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：查岗吃醋 37.6%

**骨架**｜两个男的在她面前暗暗较劲，可谁都不敢让人看出来。

#### 节拍链

三人同场 → 无声计分（谁递纸巾、谁记得忌口）→ 她无意中一句话定胜负 → 她全程没察觉 → 他回家后特别安静

#### 时间轴

一顿饭的时长，按五分钟一轮来算。递纸巾、抢着倒水、报出她的忌口——就这么来回推进，全程没人挑明。结束是她随口一句话；散场后他一直安静到晚上，那段安静就是加时赛。

#### 与 05 卷「雄竞现场」的区别

[05-剧情套路/02-名场面结构库](../05-剧情套路/02-名场面结构库.md) 里写的「雄竞现场」，那是权力戏，得公开、得有观众、得分出个输赢。这条不一样，是日常版：饭桌上、客厅里，或者就是普普通通三个人一块儿走两步路，照样能较劲。

| | 名场面版 | 日常版 |
|---|---|---|
| 场合 | 宴会、比试、正式场合 | 饭桌、车里、走路 |
| 手段 | 直接压制 | 谁给她盛汤、谁走在她哪一侧、谁知道她不吃什么 |
| 胜负 | 明确 | 双方都觉得自己赢了／输了 |
| 她的角色 | 裁判 | 完全没注意到 |

「她完全没注意到」是日常版的关键。 一旦她注意到并处理，这条就升格成名场面了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 较劲的形式 | 谁记得她不吃啥 · 谁坐得离她近 · 谁先递纸巾 · 谁知道她那点事 |
| 隐形比分 | 她随口一句「还是你懂我」 |
| 他的破绽 | 夹菜的手顿了一下 · 话变多了 · 或者变少了 |
| 对手的形态 | 前任 · 她手底下的人 · 她朋友 · 一个看着没威胁但更合适的人 |

「一个完全无害但更合适的人」是最难对付的对手：没有敌意，所以没有战场。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 对手的意图 | 故意冲着她来 | 压根没往那想 |
| 她的察觉 | 一直蒙在鼓里 | 完事才咂摸过味来 |
| 结果 | 他小赢一把 | 他栽了，还只有自己知道 |
| 他的处理 | 回家后更缠她了 | 回家后一声不吭 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她后来才想起饭桌上气氛有点怪 | 每一回合谁赢谁输 |
| 好的处理 | 她得选具体点（比如伸手接谁递的） | 他没对对手下黑手 |
| 写崩 | 写成她爱看人抢她 | 写成他暗地里使坏 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 同席的侍君／谁替她布菜／谁的位次在前 |
| 修仙 | 同门较技／谁替她挡了那一剑 |
| 星际 | 谁被排进她的班／谁的建议被她采纳 |

#### 写崩的三种方式

1. 让她当裁判。 那就是名场面版了。
2. 让对手变坏人。 无害的对手更难缠。
3. 给出明确胜负。 日常版没有胜负，只有各自的心里账。

## 六 · 翻旧账

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：查岗吃醋 37.6%

**骨架**｜他提了三个月前那点小事，说明他一直搁心里呢。

#### 节拍链

当前冲突 → 他忽然提起旧事 → 她愣住（她完全不记得）→ 他发现她不记得 → 这才是真正的伤口

#### 时间轴

「她不记得」这件事，比旧账本身重得多。 旧账可以解决，记忆的不对称不能。

#### 可用细节

| 类 | 内容 |
|---|---|
| 旧账的规格 | 必须小。她某次没接电话 ✓、某次先走了、某次说了一句话 |
| 他记得的精度 | 具体到日期、地点、那天她穿的什么 |
| 她的反应 | 「有这回事吗」（最伤人的五个字） |
| 他的收场 | 「算了」（意思是没算） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 旧账真假 | 真有其事 | 他记岔了（更尴尬也更真实） |
| 她记不记得 | 记得 | 早忘光了 |
| 她的处理 | 好好道歉 | 「都多久的事了」（这句直接炸） |
| 结果 | 说开了 | 他更确定自己在意得多 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他连这种小事都记得 | 她随口一句「有这回事吗」 |
| 好的处理 | 她不说「我不记得」，她说「你讲讲看」 | 他话一出口就后悔了 |
| 写崩 | 写成她嫌烦 | 写成他翻旧账 |

「你说说」是这个类型里最好用的三个字。不承认也不否认，先听他说完。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 三年前她随手赏的东西／某年某月撂下的一句话 |
| 修仙 | 百年前那点小事（隔得越久，越显得不对等） |
| 星际 | 他把那天的通话记录翻了出来 |

修仙版有天然优势：寿元差让「他记了三百年，她早忘了」成为物理事实。

#### 写崩的三种方式

1. 让旧账太大。 大事记得住是正常的，小事记得住才可怕。
2. 让她马上想起来。 想不起来才是这条的内容。
3. 写成算总账。 一件。只提一件。

## 七 · 他删了那个人

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：查岗吃醋 37.6%

**骨架**｜他偷偷干了件小事，谁都没说。

#### 节拍链

他决定 → 他做了 → 没告诉她 → 她某天发现 → 她问 → 他说没什么

#### 时间轴

动作只要一秒，瞒的时长以月计。 删除发生在某个普通的下午；从那天到她发现，隔了三个月。这三个月里他一次都没提，问就是没什么。时长越长，那一秒的重量越大。

#### 为什么这条好用

它是闷声不响的宣示。他没法拦着她不见谁，但他能管住自己这边。这动作说白了就是单方面使劲，不图回报，也不想让她知道。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他删的东西 | 前任联系方式 · 某个社交账号 · 一张旧照片 ✓ · 游戏里的一个好友 |
| 或者他加的 | 改了她的备注 · 把她置顶 · 换了锁屏 |
| 她发现的方式 | 无意中看到 · 听别人说 · 她想找那人时发现他也删了 |
| 他的解释 | 「不怎么联系了」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他删的是谁 | 随便一个路人 | 其实对他挺重要的人 |
| 她知不知道 | 一直蒙在鼓里 | 知道了，心里一动 |
| 她的回应 | 也跟着删了 | 啥也没干（也说得通） |
| 时机 | 俩人已经在一起了 | 还没挑明之前（更戳人） |

「关系确立前」这一端最好：在没有名分的时候单方面清场，是最纯粹的表态。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现的那一刻 | 按下删除之前停了三秒 |
| 好的处理 | 她不大张旗鼓，自己也悄悄做了 | 他不提，也不后悔 |
| 写崩 | 写成她逼他删 | 写成他删完还发朋友圈 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 烧了旧信／退了亲事／把那方帕子还了回去 |
| 修仙 | 断了旧契／散了那道印记 |
| 星际 | 注销了旧频道权限 |

#### 写崩的三种方式

1. 让她要求他删。 要求了就不是这条了。
2. 让他昭告天下。 这条的价值在于没人知道。
3. 删得毫不犹豫。 那三秒要写出来。

## 八 · 当众宣示

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：查岗吃醋 37.6%

**骨架**｜她当着所有人的面，把他的身份说了出来。就五个字，全场都安静了。

#### 节拍链

有人为难他 → 她放下筷子 → 一个动作（不解释）→ 全场半秒安静 → 她立刻转开话题 → 回家路上他一句话不说 → 进门扑上来。

#### 时间轴

半秒安静＋一晚上的回味。 现场的钟极短：她放筷子、开口、转开话题，前后不到二十秒；他的钟极长：回家路上一路无话，进门那一下扑上来——把二十秒回放了一整路。

#### 宣示的三种规格

| 规格 | 说法 | 力度 |
|---|---|---|
| 低 | 「这是我朋友」 | 他会难受 |
| 中 | 报出关系名词 | 标准 |
| 高 | 一个动作而非一句话（伸手过去，或者她的位置站在他前面） | 最强 |

高规格的关键：不解释。 解释是在向别人交代，动作是在替他挡。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 同事聚会 · 家里吃饭 · 有人追她 · 有人对他甩脸子 |
| 她的动作 | 把他往身边拉了一步 · 手搭在他后背 · 替他接了那句话 · 端起他那杯酒 |
| 他的反应 | 耳朵红 ✓ · 手心 ✓ 冒汗 · 谁都不敢看 · 但没挪窝 |
| 后续 | 回家路上他一声不吭，进了门直接扑上来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她说的话 | 把关系挑明 | 光做，不说 |
| 场合的敌意 | 没人针对他 | 有人当面给他难堪 |
| 他的反应 | 臊得慌 | 腰杆挺得笔直 |
| 事后 | 谁也没再提 | 他追着问「你刚那话啥意思」 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 我是不是该把话挑明 | 她说话那会儿我光顾着数谁在看我 |
| 好的处理 | 她说完就岔开话头，没人能接茬 | 他站直了 |
| 写崩 | 写成当众显摆她说了算 | 写成当众把他当物件摆弄 |

「说完就转开话题」是这条的技术核心。 宣示之后立刻恢复日常，才显得那是事实而不是表演。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 当众唤他的封号／让他坐她身侧／赐座 |
| 修仙 | 当着众人替他挡下／报出道侣名分 |
| 星际 | 在公开频道用了他的全名和职衔 |

古代版最强：位次与称谓在礼制上就是公开宣示，说一个词等于下一道令。

#### 写崩的三种方式

1. 写成撑腰爽文。重点是他被人认了，压别人只是顺带的事。
2. 让他没反应。那一下必须得窘。
3. 别写太长。五个字比五句话顶用。

## 九 · 她的醋

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：查岗吃醋 37.6%（女方向罕见）

**骨架**｜她也会吃醋，但她的吃法是直接上手解决事，不是在那儿闹情绪。

#### 节拍链

有人对他过分热情 → 她的第一反应是处理 → 提前出现／直接划界 → 「我没吃醋」→ 手一直没拿开

#### 时间轴

她吃醋从冒念头到解决，前后不超过一小时。别人吃醋是越憋越浓，她不是，她是直接上手——察觉、判断、露面、把界线划清楚，一套搞完跟处理一单活儿似的。唯一超时的是那只没挪开的手——事都办完了，它还多搁了一晚上。

#### 她与他的吃醋对比

| | 他吃醋 | 她吃醋 |
|---|---|---|
| 第一反应 | 憋着 | 摊开 |
| 表现 | 情绪往肚里咽 | 动作全写在脸上 |
| 手段 | 撒娇、旁敲侧击、黏得更紧 | 当面问、划清界限、拉走人 |
| 事后 | 自己缓一缓 | 压根没觉得要交代 |
| 破绽 | 突然话少 | 反应太快 |

「太快」是她的破绽。 她处理得太利落，说明她没打算给自己留反应的时间。

#### 可用细节

| 类 | 内容 |
|---|---|
| 触发 | 有人对他有意思 · 他老提起某个人 · 他手机 ✓ 上弹出一条消息 ✓ |
| 她的处理 | 人直接到场 · 一句话把事说死 · 把人拽走 · 或者就搭一下手 |
| 她不承认 | 「我没吃醋」（说这话时她正忙着干别的） |
| 他的发现 | 她今天来得特别早 · 她手一直没松开 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她承不承认 | 承认，坦荡 | 死不承认 |
| 处理方式 | 直接 | 绕弯子（更少见，也更有意思） |
| 他知不知道 | 察觉了，挺高兴 | 压根没往那想 |
| 力度 | 一个动作 | 把话说开 |

「他察觉了，很高兴」这一端要写好：弱势方最想要的确认，就是发现对方也会不安。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她突然明白自己已经这么在乎了 | 发现她吃醋时那一下偷着乐 |
| 好的处理 | 她认了，也不觉得丢脸 | 他不说穿，但心里记下了 |
| 写崩 | 写成她撒泼打滚 | 写成他尾巴翘上天 |

「她承认且不觉得丢人」是这条最好的处理。强势不等于无欲，坦然承认在意才是真正的强。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她把那人调走了／她赏了他一件旁人没有的东西 |
| 修仙 | 她重新加固了契印 |
| 星际 | 她把他调进了自己的直属编制 |

#### 写崩的三种方式

1. 让她泼辣。 泼辣是另一种人设，反而会把她写low。
2. 让她跟人争。 她根本不用争，她一句话就能定生死。
3. 完全不写她吃醋。 那她就成了工具人，没血没肉。

## 十 · 独占欲的边界

<!-- gb-nonscene -->
`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：查岗吃醋 37.6%

**骨架**｜这条不是戏，是这族的收束条：占有欲啥时候成了毛病。

#### 判据表

这一族的每一条都在占有欲的合法区间内。越过这条线，桥段就变成了另一种东西：

| 行为 | 桥段 | 越界 |
|---|---|---|
| 想知道她见了谁 | 随口问问 | 到点必须报行踪 |
| 不喜欢某个人 | 心里别扭 | 逼她跟那人断交 |
| 想被承认 | 盼着她主动提 | 逼她公开 |
| 留痕 | 你情我愿 | 拿来当罚人的招 |
| 查看 | 忍住了没看 | 天天盯着查岗 |
| 她的处理 | 把话挑明 | 把他朋友全挡在外头 |

判据是一句话：占有欲指向自己的情绪时是桥段，指向对方的自由时是控制。

#### 为什么要在素材库里写这个

这一族在语料里的写法差别挺大的，有不少人把控制行为当深情写。素材库嘛，收进来、标清楚、跟其他类型分开，比假装没看见有用。

写作时可以写越界的一方，但读者得看得出来你对这事有态度：越界之后要么让他付出代价，要么让他清醒过来自己反抗。要是越界了啥事没有，还白捡好处，那才是真出问题。

#### 现实与虚构的分界

以上聊的是**怎么写**，不是教你怎么处对象。小说里那种要命的占有欲，是拿来造冲突的工具，跟现实里正不正常是两码事。写什么关人、盯人、不让出门的桥段，那是虚构里的矛盾调料，别当成现实操作指南。

BDSM 与训诫类的强控制情节另有一套框架，走 [06-尺度与写法](../06-尺度与写法/) 并遵守那一卷的自愿、安全、知情原则。

#### 可串接

本条不独立成场，是这一族每一条的判据附注。
