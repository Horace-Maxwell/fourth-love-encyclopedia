## 吃醋的不对称

传统言情的男主吃醋能直接动手：查手机，赶走情敌，宣布主权。这套放到这类文里全用不上。他没有那个身份。

他吃醋了能做什么？

| 他能做的 | 他不能做的 |
|---|---|
| 安静下来 | 质问 |
| 拐弯抹角地问 | 禁止 |
| 更黏她一点 | 发火 |
| 自己去查 | 摊牌 |
| 什么都不做，但她看得出来 | 要求她解释 |

情绪从意想不到的地方漏出来的那一下，比写质问痛快得多。一个人心里翻腾得厉害，又没有名正言顺的路子说出来，这些情绪就会自己找口子钻出去。

她的占有欲是摆在明面上的，名正言顺。想宣示就宣示，想留记号就留，想把人带走就直接带走。这一族每一条都要把这种不对称写清楚。同样的情绪，放在她身上可以摊开来，放在他身上只能藏着掖着。

## 一 · 那个人是谁

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：查岗吃醋 43.1%，吃醋＋等待 7.1%

**骨架**｜他想问又张不开嘴，好不容易问出口，那句话已经绕了三道弯。

#### 节拍链

看到一个名字／一条消息／一个人 → 想问 → 忍住 → 试探 → 问出口 → 她怎么答 → 他信不信

#### 时间轴

时间看他怎么问。起先是「你今天见谁了」，后来成了「那个人是你同事吗」，最后只憋出一句「他挺好的」。改一次，退一步。

| 版本 | 他实际想说的 |
|---|---|
| 「今天顺利吗」 | 你今天跟谁在一起 |
| 「那个人也去了？」 | 他是谁 |
| 「他挺好的。」 | 我不好受 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 触发物 | 手机 ✓ 屏幕上闪过一个名字 · 她身上的味道 · 她提起某人时那口气 · 一张照片 ✓ |
| 他的忍耐动作 | 碗洗个没完 · 突然开始收拾屋子 · 手机 ✓ 拿起来又放下 |
| 试探的伪装 | 装着随口问一句 · 挑她心情好的时候 · 夹在别的话里带出来 |
| 破绽 | 问完不敢看她 · 语气太稳了，反而假 |
| 她的三种回答 | 好好解释 · 一句话带过 · 反问「你吃醋了？」他肯定不认 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他问不问 | 问了 | 一直没问，自己憋着 |
| 她的态度 | 主动说清楚 | 先让他难受一阵（危险，得有原因） |
| 真相 | 压根没关系 | 确实有过往 |
| 收尾 | 她把话挑明了 | 就这么吊着 |

「她把话挑明了」，强势方自己划界，比弱势方去讨保证有力得多。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发觉他今晚洗碗洗个没完 | 话问出口前改了三遍 |
| 内心 | 他究竟想问什么，要不我先说 | 我没资格问 |
| 好的处理 | 她不等他问就说了 | 他问得很难看，但他问了 |
| 写崩 | 写成她享受他的嫉妒 | 写成阴阳怪气 |

「她不等他问就说了」，自己交代和被人审问差得远，她替他免了一回难堪。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 新收的侍君／她书房里多出一方砚／宫里赏下来的人 |
| 修仙 | 双修的道侣／她以前那个旧人／同门里谁的名字 |
| 星际 | 副手名单／她终端上那个加密频道 |

按女尊文这套律法，男主吃醋本来就不合规矩。正因为这份醋「不该有」，他才多了一层忍着的理由，戏也更足。妻主多夫在律法里是常例，具体规矩见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。

#### 写崩的三种方式

1. 让他当面质问。 这就把权力翻过来了。真要这么写，得先想好后面怎么收。
2. 让她故意吊着他。 没有正当理由，读者一定站到他那边去。
3. 一问就解决。 要写的就是他怎么忍，忍得住才有戏。

#### 示例（本库自撰，可直接改写）

> 水一直开着。碗其实早就洗完了。
> 他把那只已经冲过两遍的碗又冲了一遍，放进架子，然后没有关水。
> 「今天……顺利吗。」他背对着她说的。
> 「挺顺利的。」
> 他关了水，手在围裙上擦，擦得比需要的时间长。
> 「他挺好的。」
> 说完他自己也知道这句不对劲。可是收不回来了，水龙头上还挂着一滴，很久才落下去。

## 二 · 查手机

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：查岗吃醋 43.1%

**骨架**｜他拿起她的手机看了一眼，又放回去了。也可能没放。

#### 节拍链

屏幕一亮 → 他看到了 → 拿起来 → 那三秒 → 放下／解锁 → 把手机摆回原来的角度

#### 时间轴

要紧的是后头那段余波。他把手机放回原处，连角度都摆得跟原来一样，就这一个动作，看得出那三秒他忘不掉。

时间只有这三秒。前面一段铺垫，后面一段余波。

拿起手机前那点犹豫，够写一整段。真拿起来了，顶多三秒。超过三秒就是下了狠心。

#### 这条的道德坡度

这一族里，明明白白越界的动作只有查手机。写法分三档，档位选错，人物就崩了：

| 档 | 动作 | 读者接受度 |
|---|---|---|
| 一 | 屏幕亮了，他看到了，没点开 | 高 |
| 二 | 他拿起来瞄了眼锁屏，又放下 | 中 |
| 三 | 他解了锁，翻看 | 低，后面得付出代价 |

一档反而信息最多。一条推送就够读者去猜，人物也还干干净净。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓ · 屏幕 ✓ · 消息 ✓ · 微信 ✓ · 充电 ✓，手机在充电，人在客厅 |
| 一档细节 | 屏幕亮那一下他正好在旁边 · 他扭头装没看见，其实已经瞄到了 · 名字后面那个括号 |
| 三档的后果 | 她发现了 · 或者更糟：她没发现，但他从此知道自己会干这种事 |
| 他放下时的动作 | 原样放回去，连角度都没动 |

「把手机摆回原来的角度」，他连自己碰过都想抹掉，可见他心里知道这样不对。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他查不查 | 忍住了 | 查了 |
| 她知不知道 | 不知道 | 知道，照样没设密码，这就是她的态度 |
| 他查到什么 | 啥也没有 | 一件他更不想知道的小事 |
| 后果 | 没事 | 他自己心里那道坎过不去 |

「她没有设密码」这个设定值得单独写一整场。她不设密码，就是有意让他看。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现手机被人动过 | 拿起来那一秒 |
| 好的处理 | 她不问，只说「你想看就看」 | 他没看，也没提自己没看 |
| 写崩 | 写她当场发火 | 写成理直气壮翻手机 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她案上的书信／她的名帖／门房记录的来客 |
| 修仙 | 传讯玉简／她的储物袋／识海里的印记 |
| 星际 | 通讯日志／她的权限记录 |

#### 写崩的三种方式

1. 查手机成了家常便饭。 一次算失控，两次就是他这个人有问题。
2. 不付代价。 三档必须付出代价，不然文本就等于默许这种做法。
3. 查出个大秘密。 那就成悬疑线了。查出一件小事更好。

## 三 · 闻到别人的味道

`T` ｜ 无预警 ｜ 全谱系（女A男O 尤强）｜ 语料频次：查岗吃醋 43.1%

**骨架**｜他手里没证据，只有一股味道。味道算不得证据。

#### 节拍链

凑近时顿住 → 开不了口 → 半夜爬起来洗那件衣服 → 加倍黏她 → 她发现衣服洗过了

#### 时间轴

晚饭时闻到，十一点开始翻来覆去，两点爬起来把那件衣服丢进洗衣机。从闻到到洗掉隔了一整晚，他一小时一小时地憋着。气味拿不出来当证据，他连发作的资格都没有，只能憋。

#### 为什么气味特别好用

气味证明不了什么。他闻到了，可说不出口。一说，别人只当他有病。最要命的就是这种「知道但没法说」的憋屈。

到了女A男O的设定里，有了信息素，这件事就有了实打实的依据，也说得通了。同一个桥段，放在普通设定里是疑神疑鬼，放进ABO就是明摆着的生理反应。

#### 可用细节

| 类 | 内容 |
|---|---|
| 气味载体 | 外套 ✓ 的领口 · 围巾 ✓ · 头发 · 车 ✓ 里 · 她的手腕 ✓ |
| 他的反应 | 靠近时停住 · 帮她挂外套时多停了两秒 · 半夜起来把那件衣服洗了 |
| 他的动作 | 把自己的味道盖上去，抱、蹭、换她的洗发水 |
| 他不能说的 | 「你身上有别人的味道」，这句一出口他就输了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 味道来源 | 没来头（同事的车、餐厅） | 有来头 |
| 他说不说 | 不说，光做（洗衣服、加倍黏） | 开口了 |
| 她察觉没 | 没感觉 | 闻到了，自己先提 |
| 设定 | 普通现代 | 女A男O（信息素规则见 [03-世界观设定](../03-世界观设定/)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现外套被洗了 | 靠近时那一下停顿 |
| 好的处理 | 她没问他为什么洗，回家换了条路 | 衣服他洗了，这事就不再提 |
| 写崩 | 写成她故意留痕迹试他 | 写成他闻着味儿就上头了 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 熏香味道不对／衣服上有别的脂粉气／她换了佩囊 |
| 修仙 | 身上沾了别人的灵息／剑穗上带着别人的气 |
| 星际 | 舱里空气循环记录／她制服上查出的微粒 |
| 女A男O | 信息素残留 · 标记深浅 · 腺体反应 |

#### 写崩的三种方式

1. 让他凑上去闻她。 动作一露骨就往失控滑。
2. 让气味成了铁证。 气味当不了证据，这条才立得住。
3. 让她故意带着味道回来。 那是操控，除非文里对此有态度。

## 四 · 留痕

`M` ｜ ⚠️亲密接触 ｜ 全谱系 ｜ 语料频次：身上留痕 46.0%，留痕＋睡着 9.5%

**骨架**｜留一个别人看得见的记号，这件事对两边都不算越界。

#### 节拍链

留下印子 → 拇指按一下 → 第二天照镜子 → 遮还是不遮 → 出门 → 旁人看过来一眼

#### 时间轴

印子一天比一天淡。每天早上都得再选一次，遮还是露。等它快消了，谁先说“补一个”，谁就先认了在乎，这一局算输，也算赢。

#### 双向的不对称

| | 她留在他身上 | 他留在她身上 |
|---|---|---|
| 性质 | 盖个章，告诉旁人这人是我的 | 留个念想，盼着她认 |
| 位置 | 显眼处，脖子、锁骨一带 | 隐蔽处，她随手就能遮住的地方 |
| 他／她的反应 | 他嘴上嫌弃，人却没躲 | 她可能根本没在意 |
| 读着像 | 拿捏 | 憋屈 |

「他留在她身上」这一栏写的人最少。他偷偷在她看不见的地方留个记号，还不敢留在太显眼的地方。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 领口 ✓ · 衬衫 ✓ · 围巾 ✓ · 镜子 ✓ · 遮瑕（他买的） · 后颈 ✓ · 锁骨 ✓ · 手腕 ✓ |
| 她的动作 | 留完之后用拇指按了一下 · 帮他把领子立起来，又放下 |
| 他的处理 | 对着镜子看了老半天 · 换了高领 · 换完又觉得太刻意，又换回来 |
| 第三人的反应 | 同事瞟了一眼 · 没人说破，但都看在眼里 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁留给谁 | 她给他 | 他给她 |
| 位置 | 遮不住 | 只有他们知道 |
| 意图 | 故意的 | 没控制住 |
| 他的态度 | 遮 | 不遮，这是他的宣示，很重 |

「不遮」这一头里，被标记的他并不被动，让人看见是他自己选的。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 第二天看见他没穿高领 | 早上照镜子那一下 |
| 内心 | 我是不是留得太明显了 | 我要不要遮 |
| 好的处理 | 她注意到他没遮，什么也没说 | 他自己做了决定 |
| 写崩 | 写成刻意炫耀 | 写成羞耻表演 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 赐的玉佩／腕上的红绳／她亲手系的带子 |
| 修仙 | 契印／神识烙印／剑穗 |
| 星际 | 舰徽／她给的权限章／腕带 |
| 女A男O | 标记 · 临时标记和永久标记的区别（见 [03-世界观设定](../03-世界观设定/)） |

古代版能用的信物比现代版多得多，玉佩、红绳、荷包、腰带，都是戴在身上、旁人一看就懂的记号。

#### 安全与边界

留痕牵涉身体接触，会留下看得见的印子。写时守两条线：

| 线 | 说明 |
|---|---|
| 同意 | 两人都是成年人，都自愿。留痕只能出现在自愿的情境里，不能拿来惩罚人 |
| 与训诫的分层 | 本条是亲密行为的痕迹，不是伤害。带伤的走 [06-尺度与写法](../06-尺度与写法/)，按那一卷的安全框架处理 |

#### 写崩的三种方式

1. 把留痕当成惩罚。 那是另一个性质，且必须带安全框架。
2. 写成当众羞辱。 判断方法和 [01-日常照料 · 一口一口喂](01-日常照料.md#二--一口一口喂) 一样：看她在不在意他难不难堪。
3. 只写她在他身上留。 反过来那栏才是这类型的特色。

## 五 · 日常版雄竞

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：查岗吃醋 43.1%

**骨架**｜两个男人当着她的面暗中较劲，谁都不敢摆到明面上。

#### 节拍链

三个人在一处 → 暗里记分，谁递了纸巾，谁记得她忌口 → 她随口一句话分了输赢 → 她从头到尾没察觉 → 他回家以后格外安静

#### 时间轴

一顿饭的工夫，五分钟一个回合。递纸巾，抢着倒水，报出她忌什么口，一来一回，谁都不挑明。最后她随口说了一句，散场以后他一直安静到晚上。

#### 与 05 卷「雄竞现场」的区别

「雄竞现场」不只有[05-剧情套路/02-名场面结构库](../05-剧情套路/02-名场面结构库.md)里那种权力戏——要当众、要有人看、要分出输赢。饭桌上，客厅里，三个人一起走几步路，照样能较劲，这就是日常版。

| | 名场面版 | 日常版 |
|---|---|---|
| 场合 | 宴会、比试、正式场合 | 饭桌、车里、走路 |
| 手段 | 直接压制 | 谁给她盛汤、谁走在她哪一侧、谁知道她不吃什么 |
| 胜负 | 明确 | 双方都觉得自己赢了／输了 |
| 她的角色 | 裁判 | 完全没注意到 |

日常版的要害在「她完全没注意到」。 她一旦注意到并出手处理，就升成名场面了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 较劲的形式 | 谁记得她不吃啥 · 谁坐得离她近 · 谁先递纸巾 · 谁知道她那点事 |
| 隐形比分 | 她随口一句「还是你懂我」 |
| 他的破绽 | 夹菜的手顿了一下 · 话变多了 · 或者变少了 |
| 对手的形态 | 前任 · 她手底下的人 · 她朋友 · 一个看着没威胁但更合适的人 |

最难对付的是「一个看着没威胁但更合适的人」，他连发作都找不到理由。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 对手的意图 | 故意冲着她来 | 压根没往那想 |
| 她的察觉 | 一直蒙在鼓里 | 完事才咂摸过味来 |
| 结果 | 他小赢一把 | 他栽了，还只有自己知道 |
| 他的处理 | 回家后更缠她了 | 回家后一声不吭 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 事后她才想起饭桌上气氛不太对 | 每个回合的输赢 |
| 好的处理 | 她的选择要具体，比如伸手接了谁递来的东西 | 他没对对手使阴招 |
| 写崩 | 写成她爱看人抢她 | 写成他暗地里使坏 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 同席的侍君／谁替她布菜／谁的位次在前 |
| 修仙 | 同门较技／谁替她挡了那一剑 |
| 星际 | 谁被排进她的班／谁的建议被她采纳 |

#### 写崩的三种方式

1. 让她来当裁判。 那就成了名场面版。
2. 把对手写成坏人。 无害的对手更难缠。
3. 分出明确的输赢。 日常版不分胜负，输赢各在各人心里。

## 六 · 翻旧账

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：查岗吃醋 43.1%

**骨架**｜他提起三个月前的一件小事，可见他一直放在心上。

#### 节拍链

眼下吵起来 → 他突然翻出旧事 → 她一愣（她根本不记得）→ 他看出她不记得 → 伤就伤在这里

#### 时间轴

无。这条靠她不记得往前推，这比旧账本身更伤他。

#### 可用细节

| 类 | 内容 |
|---|---|
| 旧账多大 | 必须是小事：她有一回没接电话 ✓，有一回先走了，有一回说了句话 |
| 他记得的精度 | 具体到日期、地点、那天她穿的什么 |
| 她的反应 | 「有这回事吗」，这五个字最伤人 |
| 他的收场 | 「算了」（意思是没算） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 旧账真假 | 真有其事 | 他记岔了，更尴尬也更真实 |
| 她记不记得 | 记得 | 早忘光了 |
| 她的处理 | 认真道歉 | 「都多久的事了」，一说就炸 |
| 结果 | 说开了 | 他更确定自己在意得多 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他连这种小事都记得 | 她随口一句「有这回事吗」 |
| 好的处理 | 她不说「我不记得」，改说「你讲讲看」 | 话一出口他就后悔了 |
| 写崩 | 写成她嫌烦 | 写成他翻旧账 |

「你讲讲看」这句，既不认也不否，先让他把话说完。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 三年前她随手赏的东西／某年某月撂下的一句话 |
| 修仙 | 百年前那点小事，隔得越久越显得不对等 |
| 星际 | 他把那天的通话记录翻了出来 |

修仙版里两人寿元不同，「他记了三百年，她早忘了」也说得通。

#### 写崩的三种方式

1. 旧账翻得太大。 大事记得住很正常，小事都记得才吓人。
2. 让她一下就想起来。 想不起来才疼。
3. 写成算总账。 一件。只提一件。

## 七 · 他删了那个人

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：查岗吃醋 43.1%

**骨架**｜他悄悄做了一件小事，跟谁都没提。

#### 节拍链

他拿定主意 → 做了 → 没跟她说 → 某天她发现了 → 她问 → 他说没什么

#### 时间轴

删是在某个平常的下午，一秒钟的事，瞒却瞒了几个月。她发现的那天，往回数正好三个月，在这段日子的尽头。三个月里他一次也没提。问起来就说没什么。

#### 为什么这条好用

这是一种不出声的宣示。她见谁他拦不住，他自己这边却管得住。他一个人使劲，不图回报，也不打算让她知道。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他删的东西 | 前任联系方式 · 某个社交账号 · 一张旧照片 ✓ · 游戏里的一个好友 |
| 或者他加的 | 改了她的备注 · 把她置顶 · 换了锁屏 |
| 她发现的方式 | 无意中看到 · 听别人说 · 她想找那人时发现他也删了 |
| 他的解释 | 「不怎么联系了」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他删的是谁 | 随便一个路人 | 其实对他挺重要的人 |
| 她知不知道 | 一直蒙在鼓里 | 知道了，心里一动 |
| 她的回应 | 也跟着删了 | 啥也没干（也说得通） |
| 时机 | 俩人已经在一起了 | 还没挑明之前（更戳人） |

「还没挑明之前」这一头，他连名分都没有，就先把人删了，什么也不图。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现的那一刻 | 按下删除之前停了三秒 |
| 好的处理 | 她不声张，自己也照样悄悄做了 | 他不提，也不后悔 |
| 写崩 | 写成她逼他删 | 写成他删完还发朋友圈 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 烧了旧信／退了亲事／把那方帕子还了回去 |
| 修仙 | 断了旧契／散了那道印记 |
| 星际 | 注销了旧频道权限 |

#### 写崩的三种方式

1. 让她开口要他删。 她一要求，就成了另一条。
2. 让他弄得人尽皆知。 这一条写的就是没人知道。
3. 删得一点不犹豫。 那三秒要写出来。

## 八 · 当众宣示

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：查岗吃醋 43.1%

**骨架**｜她当着所有人的面挑明了他的身份。只用五个字，满场都静了。

#### 节拍链

有人给他难堪 → 她搁下筷子 → 只一个动作，不解释 → 满场静了半秒 → 她马上岔开话题 → 回家路上他一言不发 → 一进门就扑上来。

#### 时间轴

她放筷子、开口、岔开话题，前后不到二十秒。回家一路没说话，他把那二十秒在心里放了一路，进门就扑了上来。

#### 宣示的三种规格

| 档 | 说法 | 力度 |
|---|---|---|
| 低 | 「这是我朋友」 | 他会难受 |
| 中 | 报出关系名词 | 标准 |
| 高 | 用动作，不用话：伸手过去，或者站到他前面 | 最强 |

最高一档不解释，伸手替他挡一下就行。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 同事聚会 · 家里吃饭 · 有人追她 · 有人对他甩脸子 |
| 她的动作 | 把他往身边拉了一步 · 手搭在他后背 · 替他接了那句话 · 端起他那杯酒 |
| 他的反应 | 耳朵红 ✓ · 手心 ✓ 冒汗 · 谁都不敢看 · 但没挪窝 |
| 后续 | 回去的路上他一句话没有，进门就扑上来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她说的话 | 把关系挑明 | 光做，不说 |
| 场合的敌意 | 没人针对他 | 有人当面给他难堪 |
| 他的反应 | 臊得慌 | 腰杆挺得笔直 |
| 事后 | 谁也没再提 | 他追着问「你刚那话啥意思」 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 要不要把话挑明 | 她说话的时候，我只顾着数有几个人在看我 |
| 好的处理 | 她说完马上换话题，谁也接不上茬 | 他站直了 |
| 写崩 | 写成当众显摆她说了算 | 写成当众把他当物件摆弄 |

宣示完马上岔开话题，这件事才显得天经地义。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 当众唤他的封号／让他坐她身侧／赐座 |
| 修仙 | 当着众人替他挡下／报出道侣名分 |
| 星际 | 在公开频道用了他的全名和职衔 |

古代版的礼制里，位次和称呼本身就是当众宣示，说出一个词就等于下了一道令。

#### 写崩的三种方式

1. 写成撑腰爽文。 要写的是他被认了，压住别人只是顺手。
2. 让他毫无反应。 那一下他必须窘。
3. 写得太长。 五个字顶得过五句话。

## 九 · 她的醋

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：查岗吃醋 43.1%（女方向罕见）

**骨架**｜她也吃醋，但她的办法是直接动手解决。

#### 节拍链

有人对他热情过头 → 她头一个念头是处理掉 → 提早露面／当场划界 → 「我没吃醋」→ 手一直搭着没拿开

#### 时间轴

她吃一回醋，从起念到收手，前后不到一小时。别人的醋越压越沉，她是察觉、判断、露面、划界，一套下来干脆利落，像办完一件差事。只有那只手，事都办完了，还搭了一整晚才拿开。

#### 她与他的吃醋对比

| | 他吃醋 | 她吃醋 |
|---|---|---|
| 第一反应 | 憋着 | 摊开 |
| 表现 | 情绪往肚里咽 | 动作全写在脸上 |
| 手段 | 撒娇、旁敲侧击、黏得更紧 | 当面问、划清界限、拉走人 |
| 事后 | 自己缓一缓 | 压根没觉得要交代 |
| 破绽 | 突然话少 | 反应太快 |

她的破绽就在「太快」。 处理得这么利落，说明她压根没打算给自己留反应的工夫。

#### 可用细节

| 类 | 内容 |
|---|---|
| 触发 | 有人对他有意思 · 他老提起某个人 · 他手机 ✓ 上弹出一条消息 ✓ |
| 她的处理 | 人直接到场 · 一句话把事说死 · 把人拽走 · 或者就搭一下手 |
| 她不承认 | 「我没吃醋」——说这话时她正忙着干别的 |
| 他的发现 | 她今天来得特别早 · 她手一直没松开 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她承不承认 | 承认，坦荡 | 死不承认 |
| 处理方式 | 直接 | 绕弯子，更少见也更有意思 |
| 他知不知道 | 察觉了，挺高兴 | 压根没往那想 |
| 力度 | 一个动作 | 把话说开 |

「察觉了，挺高兴」这一头要写好。弱势的一方最想确认的，就是对方也会不安。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她猛地意识到自己已经这么在乎他 | 看出她吃醋时，他偷偷乐了一下 |
| 好的处理 | 她认了，不觉得丢人 | 他不点破，心里记下了 |
| 写崩 | 写成她撒泼打滚 | 写成他尾巴翘上天 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她把那人调走了／她赏了他一件旁人没有的东西 |
| 修仙 | 她重新加固了契印 |
| 星际 | 她把他调进了自己的直属编制 |

#### 写崩的三种方式

1. 把她写得泼辣。 泼辣是另一种人设，反倒写掉价了。
2. 让她跟人去争。 她用不着争。一句话就能定生死。
3. 一点不写她吃醋。 那她就是个没血没肉的工具人。

## 十 · 独占欲的边界

<!-- gb-nonscene -->
`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：查岗吃醋 43.1%

**骨架**｜占有欲走到哪一步就成病了。

#### 判据表

这一族每一条都在占有欲说得过去的范围里。线一越过去，桥段就成了别的东西：

| 行为 | 桥段 | 越界 |
|---|---|---|
| 想知道她见了谁 | 随口问问 | 到点必须报行踪 |
| 不喜欢某个人 | 心里别扭 | 逼她跟那人断交 |
| 想被承认 | 盼着她主动提 | 逼她公开 |
| 留痕 | 你情我愿 | 拿来当罚人的招 |
| 查看 | 忍住了没看 | 天天盯着查岗 |
| 她的处理 | 把话挑明 | 把他朋友全挡在外头 |

怎么分：管的是自己心里的难受，算桥段。管到对方去哪、见谁，就是控制。

#### 为什么要在素材库里写这个

这一族在语料里写法差得很远，不少人把控制当成深情来写。素材库把它收进来，标清楚，和别的类型分开放，比装作没看见有用。

越界也可以写，但写的时候要让读者看出作者的立场：要么让越界的人付出代价，要么让他自己醒悟、主动反抗。最怕的是越了界不但没事，还占尽便宜。那才真出问题。

#### 现实与虚构的分界

小说里写关人、盯人、不让出门，那种占有欲浓到要命的桥段，说到底就是给冲突加码的调料。虚构归虚构，跟现实里正不正常搭不上边。前面聊的这些都落在**怎么写**上，不是照着做的操作指南。

BDSM 和训诫类的强控制情节是另一套框架，直接走 [06-尺度与写法](../06-尺度与写法/)，按那一卷的原则来：自愿、安全、知情。

#### 可串接

这一条不单独成场，是这一族每条的判断附注。
