# 占有与吃醋

> **分级** 分级见各条，分级上限 `M`（第四条「留痕」）｜ 预警 ⚠️亲密接触 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**占有欲在弱势方身上是不合法的，所以他只能用别的形式表达。**

---

## 这一族的特殊难度

在传统言情里，男主吃醋可以直接表现为控制：查手机、赶走情敌、宣布主权。那套动作到了这一类里全部失效，因为他没有那个位置。

他吃醋了能做什么？

| 他能做的 | 他不能做的 |
|---|---|
| 安静下来 | 质问 |
| 拐弯抹角地问 | 禁止 |
| 更黏她一点 | 发火 |
| 自己去查 | 摊牌 |
| 什么都不做，但她看得出来 | 要求她解释 |

这个限制正是这一族的写作乐趣。 一个人有强烈的情绪却没有表达它的合法渠道，那些情绪就会从各种奇怪的地方漏出来。写那些漏出来的地方，比写质问有意思得多。

反过来，她的占有欲是合法的。她可以直接宣示、直接留痕、直接把人带走。同一种情绪，两个方向，一个要藏一个可以摆。 这一族每一条都要把这个不对称写出来。

|---|---:|---:|
| 身上留痕 | 1,180 | 40.8% |
| 查岗吃醋 | 1,088 | 37.6% |

## 一 · 那个人是谁

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：查岗吃醋 37.6%，吃醋＋等待 5.9%

**骨架**｜他想问，问不出口；等他终于问了，问法已经改了三遍。

#### 节拍链

发现（一个名字／一条消息／一个人）→ 起意 → 忍 → 试探 → 问 → 她的回答 → 他信不信

#### 时间轴

他改问法的过程就是时间轴。 从「你今天见谁了」到「那个人是你同事吗」到最后憋出的「他挺好的」，每一次修改都是一次退让。

| 版本 | 他实际想说的 |
|---|---|
| 「今天顺利吗」 | 你今天跟谁在一起 |
| 「那个人也去了？」 | 他是谁 |
| 「他挺好的。」 | 我不好受 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 触发物 | 手机 ✓ 屏幕上一闪而过的名字 · 她衣服上的味道 · 她提起某人时的语气 · 一张照片 ✓ |
| 他的忍耐动作 | 洗碗洗得特别久 · 突然开始收拾房间 · 手机 ✓ 拿起来放下 |
| 试探的伪装 | 装作随口一问 · 挑在她心情好的时候 · 混在别的话题里 |
| 破绽 | 问完之后他不看她 · 语气太平了 |
| 她的三种回答 | 认真解释 · 一句带过 · 反问「你在吃醋？」（他会否认） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他问不问 | 问了 | 一直没问，自己消化 |
| 她的态度 | 主动解释 | 让他难受一会儿（危险，需要理由） |
| 真相 | 完全无关 | 确实有过去 |
| 收尾 | 她给了明确的界限 | 悬着 |

「她给了明确的界限」是这个类型里最受欢迎的收法：强势方主动划界，比弱势方索要保证有力得多。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他今晚一直在洗碗 | 问出口之前的三次改稿 |
| 内心 | 他到底想问什么，还是我先说 | 我没有资格问 |
| 好的处理 | 她不等他问就说了 | 他问得很难看，但他问了 |
| 写崩 | 写成她享受他的嫉妒 | 写成阴阳怪气 |

「她不等他问就说了」是四爱女角色的高级操作。主动交代跟被审问是两回事，它替对方省下一次难堪。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 新纳的侍君／她书房里多出的一方砚／宫中赐下的人 |
| 修仙 | 双修伴侣／她的旧道侣／同门中人的名字 |
| 星际 | 副手名单／她终端上的加密频道 |

古代女尊版有制度性优势：多人配置是合法的，所以他的醋是「不该有的」。 这让忍耐有了正当性来源，戏更足。见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。

#### 写崩的三种方式

1. 让他直接质问。 那不是这一条，那是权力翻转。若真要写，得处理它的后果。
2. 让她刻意吊着。 除非有明确的理由，否则读者会站他。
3. 一问就解决。 忍的过程是这条的主体。

#### 示例（本库自撰，可直接改写）

> 水一直开着。碗其实早就洗完了。
> 他把那只已经冲过两遍的碗又冲了一遍，放进架子，然后没有关水。
> 「今天……顺利吗。」他背对着她说的。
> 「挺顺利的。」
> 他关了水，手在围裙上擦，擦得比需要的时间长。
> 「他挺好的。」
> 说完他自己也知道这句不对劲。可是收不回来了，水龙头上还挂着一滴，很久才落下去。

## 二 · 查手机

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：查岗吃醋 37.6%

**骨架**｜他拿起了她的手机，然后放下了。或者没放下。

#### 节拍链

屏幕亮起 → 他看见了 → 拿起来 → 那三秒 → 放下／解锁 → 把手机摆回原来的角度

#### 时间轴

那三秒是全条的时长，前后各有一条长尾。 拿起之前的挣扎可以给一整段；拿起之后只有三秒——超过三秒就不是挣扎是决定。长尾在后面：他把手机摆回原角度的那个动作，说明这三秒他会记很久。

#### 这条的道德坡度

查手机是这一族唯一一条明确越界的动作。写法上有三档，选错档位会让人物崩掉：

| 档 | 动作 | 读者接受度 |
|---|---|---|
| 一 | 屏幕亮了，他看见了，没有点开 | 高 |
| 二 | 他拿起来，看了锁屏，放下 | 中 |
| 三 | 他解锁，翻了 | 低，需要后续代价 |

一档的信息量其实最大。 一条推送通知能给出的东西，和翻完整个聊天记录差不多，但人物是干净的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓ · 屏幕 ✓ · 消息 ✓ · 微信 ✓ · 充电 ✓（手机在充电，所以在客厅） |
| 一档细节 | 屏幕亮起的那一下他刚好在旁边 · 他别开眼但已经看见了 · 名字后面那个括号 |
| 三档的后果 | 她发现了 · 或者更糟：她没发现，但他从此知道了自己会做这种事 |
| 他放下时的动作 | 把手机摆回原来的角度 |

「把手机摆回原来的角度」是这条最好的一个细节：他连自己动过都想抹掉，说明他知道这不对。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他查不查 | 忍住了 | 查了 |
| 她知不知道 | 不知道 | 知道，且没有设密码（这是她的态度） |
| 他查到什么 | 什么都没有 | 一件他更不想知道的小事 |
| 后果 | 无 | 他自己心里过不去 |

「她没有设密码」这个设定值得单独用一整场。她的开放不等于无所谓，那是一种明确的给予。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她注意到手机的位置变了 | 拿起来那一秒 |
| 好的处理 | 她不追究，但她说了「你想看就看」 | 他没看，且他没告诉她自己没看 |
| 写崩 | 写成她大发雷霆 | 写成理直气壮的查岗 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她案上的书信／她的名帖／门房记录的来客 |
| 修仙 | 传讯玉简／她的储物袋／识海里的印记 |
| 星际 | 通讯日志／她的权限记录 |

#### 写崩的三种方式

1. 让查手机变成常态。 一次是失控，两次是人格。
2. 不给代价。 三档必须有代价，否则文本就是在认可这个行为。
3. 查出大秘密。 那是悬疑线不是日常戏。查出一件小事更好。

## 三 · 闻到别人的味道

`T` ｜ 无预警 ｜ 全谱系（女A男O 尤强）｜ 语料频次：查岗吃醋 37.6%

**骨架**｜他没有证据，只有一个气味。而气味无法被引用。

#### 节拍链

靠近时停住 → 说不出口 → 半夜起来洗那件衣服 → 加倍黏她 → 她发现衣服被洗了

#### 时间轴

从闻到到洗掉，中间隔一个整晚。 气味无法举证，所以他连发作的资格都没有；憋的时长按小时走：晚饭时闻到，十一点辗转，两点起来把那件衣服丢进洗衣机。洗衣机的运转声是这条的钟摆。

#### 为什么气味特别好用

因为它不可举证。他闻到了，但他说不出来，说出来就显得荒唐。这个「知道但无法主张」的处境，正是这一族的核心困境的最纯粹形态。

而在女A男O 设定里，信息素让这件事有了物理依据，也就有了正当性。同一个桥段，普通设定里是疑神疑鬼，ABO 设定里是生理事实。

#### 可用细节

| 类 | 内容 |
|---|---|
| 气味载体 | 外套 ✓ 的领口 · 围巾 ✓ · 头发 · 车 ✓ 里 · 她的手腕 ✓ |
| 他的反应 | 靠近时停住 · 帮她挂外套时多停了两秒 · 半夜起来把那件衣服洗了 |
| 他的动作 | 把自己的味道盖上去（抱、蹭、换她的洗发水） |
| 他不能说的 | 「你身上有别人的味道」这句话说出来就输了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 味道来源 | 完全无害（同事的车、餐厅） | 有来源 |
| 他说不说 | 不说，只做（洗衣服、加倍黏） | 说了 |
| 她察觉没 | 没有 | 察觉了，主动说明 |
| 设定 | 普通现代 | 女A男O（走 [03-世界观设定](../03-世界观设定/) 的信息素规则） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现那件外套被洗了 | 靠近时那一下停顿 |
| 好的处理 | 她不问为什么洗，她换了一条路线回家 | 他洗了衣服，没提这件事 |
| 写崩 | 写成她刻意留下痕迹试探 | 写成他嗅探式的失控 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 熏香不对／衣上有别的脂粉气／她换了佩囊 |
| 修仙 | 她身上沾了别人的灵息／剑穗上不属于她的气 |
| 星际 | 舱内空气循环记录／她制服上的微粒分析 |
| 女A男O | 信息素残留 · 标记浓度 · 腺体反应 |

#### 写崩的三种方式

1. 让他直接闻她。 动作太露骨会滑向失控。
2. 让气味变成实锤。 气味的价值就在于它不是证据。
3. 让她故意留味道。 那是操控，除非文本对它有判断。

## 四 · 留痕

`M` ｜ ⚠️亲密接触 ｜ 全谱系 ｜ 语料频次：身上留痕 40.8%，留痕＋睡着 10.3%

**骨架**｜留下一个别人看得见的记号。这是这一族里唯一双向都合法的动作。

#### 节拍链

留下 → 拇指按一下 → 第二天照镜子 → 遮或不遮 → 出门 → 第三人的一个眼神

#### 时间轴

痕迹自带倒计时：它会消。 从留下那天起颜色一天天变浅，遮与不遮的选择每天早上做一次；快消完的那天谁提议「补一个」，谁就输了这场无声的较量，也赢了。

#### 双向的不对称

| | 她留在他身上 | 他留在她身上 |
|---|---|---|
| 性质 | 标记，宣示所有权 | 请求，希望被承认 |
| 位置 | 显眼处（颈侧、锁骨上沿） | 隐蔽处（她能遮住的地方） |
| 他／她的反应 | 他遮，但没有真的遮住 | 她可能根本没在意 |
| 读感 | 掌控 | 心酸 |

第二列是这一族最好用也最少被写的一栏。 他小心翼翼地在她看不见的地方留一个记号，且不敢留在显眼处，这个不对称本身就是全部内容。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 领口 ✓ · 衬衫 ✓ · 围巾 ✓ · 镜子 ✓ · 遮瑕（他买的） · 后颈 ✓ · 锁骨 ✓ · 手腕 ✓ |
| 她的动作 | 留完之后用拇指按了一下 · 帮他把领子立起来（又放下） |
| 他的处理 | 对着镜子看了很久 · 换了高领 · 换完又觉得刻意，换回来 |
| 第三人的反应 | 同事的一个眼神 · 没人说破，但都看见了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁留给谁 | 她给他 | 他给她 |
| 位置 | 遮不住 | 只有他们知道 |
| 意图 | 故意的 | 没控制住 |
| 他的态度 | 遮 | 不遮（这是他的宣示，很重） |

「他选择不遮」这一端在四爱男读者那里评价极高：被标记不等于被动，公开承认是他自己的选择。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 第二天看见他没穿高领 | 早上照镜子那一下 |
| 内心 | 我是不是留得太明显了 | 我要不要遮 |
| 好的处理 | 她注意到他没遮，什么也没说 | 他自己做了决定 |
| 写崩 | 写成刻意炫耀 | 写成羞耻表演 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 赐的玉佩／腕上的红绳／她亲手系的带子 |
| 修仙 | 契印／神识烙印／剑穗 |
| 星际 | 舰徽／她给的权限章／腕带 |
| 女A男O | 标记 · 临时标记与永久标记的区别（走 [03-世界观设定](../03-世界观设定/)） |

古代版的信物系统比现代版丰富得多：玉佩、红绳、荷包、腰带都是可见的、可被旁人读懂的标记。

#### 安全与边界

留痕涉及身体接触与可见痕迹。写作时的两条线：

| 线 | 说明 |
|---|---|
| 同意 | 双方都是成年人且自愿。留痕不能作为惩罚手段出现在非自愿情境里 |
| 与训诫的分层 | 本条是亲密行为的痕迹，不是伤害。带伤的走 [06-尺度与写法](../06-尺度与写法/)，并按那一卷的安全框架处理 |

#### 写崩的三种方式

1. 把留痕当成惩罚。 那是另一个性质，且必须带安全框架。
2. 写成公开羞辱。 判据同 [01-日常照料 · 一口一口喂](01-日常照料.md#二--一口一口喂)：她有没有在意他的难堪。
3. 只写她留他。 反向那一栏才是这个类型的特色。

## 五 · 日常版雄竞

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：查岗吃醋 37.6%

**骨架**｜两个男性在她面前较劲，但谁都不能表现出在较劲。

#### 节拍链

三人同场 → 无声计分（谁递纸巾、谁记得忌口）→ 她无意中一句话定胜负 → 她全程没察觉 → 他回家后特别安静

#### 时间轴

一顿饭的时长，计分每五分钟一轮。 递纸巾、抢着倒水、报出她的忌口——回合制推进，全程无宣战。终场哨是她无意的一句话；散场后他的安静要持续到当晚，那段安静是加时赛。

#### 与 05 卷「雄竞现场」的区别

[05-剧情套路/02-名场面结构库](../05-剧情套路/02-名场面结构库.md) 里的「雄竞现场」是权力戏：公开、有观众、有胜负。这一条是它的日常版：在饭桌上、在客厅里、在一次普通的三人同行中。

| | 名场面版 | 日常版 |
|---|---|---|
| 场合 | 宴会、比试、正式场合 | 饭桌、车里、走路 |
| 手段 | 直接压制 | 谁给她盛汤、谁走在她哪一侧、谁知道她不吃什么 |
| 胜负 | 明确 | 双方都觉得自己赢了／输了 |
| 她的角色 | 裁判 | 完全没注意到 |

「她完全没注意到」是日常版的关键。 一旦她注意到并处理，这条就升格成名场面了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 较劲的形式 | 谁记得她的忌口 · 谁的位置离她近 · 谁先递纸巾 · 谁知道她那件事 |
| 隐形比分 | 她无意中的一句「还是你懂我」 |
| 他的破绽 | 夹菜的手停了一下 · 话说得比平时多 · 或者比平时少 |
| 对手的形态 | 前任 · 她的下属 · 她的朋友 · 一个完全无害但更合适的人 |

「一个完全无害但更合适的人」是最难对付的对手：没有敌意，所以没有战场。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 对手的意图 | 有意 | 完全无意 |
| 她的察觉 | 全程没察觉 | 事后才反应过来 |
| 结果 | 他赢了一个小回合 | 他输了，且只有他知道 |
| 他的处理 | 回家后加倍黏她 | 回家后特别安静 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她后来才想起饭桌上气氛有点怪 | 每一个回合的计分 |
| 好的处理 | 她的选择要具体（她伸手拿了谁递的） | 他没有攻击对手 |
| 写崩 | 写成她享受被争 | 写成他背后使绊 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 同席的侍君／谁替她布菜／谁的位次在前 |
| 修仙 | 同门较技／谁替她挡了那一剑 |
| 星际 | 谁被排进她的班／谁的建议被她采纳 |

#### 写崩的三种方式

1. 让她当裁判。 那就是名场面版了。
2. 让对手变坏人。 无害的对手更难缠。
3. 给出明确胜负。 日常版没有胜负，只有各自的心里账。

## 六 · 翻旧账

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：查岗吃醋 37.6%

**骨架**｜他提起了三个月前的一件小事，说明他一直记着。

#### 节拍链

当前冲突 → 他忽然提起旧事 → 她愣住（她完全不记得）→ 他发现她不记得 → 这才是真正的伤口

#### 时间轴

「她不记得」这件事，比旧账本身重得多。 旧账可以解决，记忆的不对称不能。

#### 可用细节

| 类 | 内容 |
|---|---|
| 旧账的规格 | 必须小。她某次没接电话 ✓、某次先走了、某次说了一句话 |
| 他记得的精度 | 具体到日期、地点、那天她穿的什么 |
| 她的反应 | 「有这回事吗」（最伤人的五个字） |
| 他的收场 | 「算了」（意思是没算） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 旧账真假 | 确有其事 | 他记岔了（更尴尬也更真实） |
| 她记不记得 | 记得 | 完全不记得 |
| 她的处理 | 认真道歉 | 「都过去多久了」（这句会引爆） |
| 结果 | 解开 | 他更确认了自己在意得更多 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他记得那么细 | 她说「有这回事吗」的那一下 |
| 好的处理 | 她不推诿「我不记得」，她说「你说说」 | 他说完就后悔了 |
| 写崩 | 写成她不耐烦 | 写成他清算 |

「你说说」是这个类型里最好用的三个字。不承认也不否认，先听他说完。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 三年前她赏下去的东西／某年某月的一句话 |
| 修仙 | 百年前的一件小事（时间跨度让不对称更极端） |
| 星际 | 他调出了那天的通讯记录 |

修仙版有天然优势：寿元差让「他记了三百年，她早忘了」成为物理事实。

#### 写崩的三种方式

1. 让旧账太大。 大事记得住是正常的，小事记得住才可怕。
2. 让她马上想起来。 想不起来才是这条的内容。
3. 写成算总账。 一件。只提一件。

## 七 · 他删了那个人

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：查岗吃醋 37.6%

**骨架**｜他做了一件很小的、单方面的、没告诉任何人的事。

#### 节拍链

他决定 → 他做了 → 没告诉她 → 她某天发现 → 她问 → 他说没什么

#### 时间轴

动作只要一秒，瞒的时长以月计。 删除发生在某个普通的下午；从那天到她发现，隔了三个月。这三个月里他一次都没提，问就是没什么。时长越长，那一秒的重量越大。

#### 为什么这条好用

它是沉默的宣示。他不能要求她不见谁，但他可以处理自己这一边。这个动作的全部意义在于它是单方面的、不求回报的、也不打算被知道的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他删的东西 | 前任的联系方式 · 某个社交账号 · 一张旧照片 ✓ · 一个游戏里的好友 |
| 或者他加的 | 把她的备注改了 · 把她设成置顶 · 换了锁屏 |
| 她发现的方式 | 无意中看见 · 别人提起 · 她想找那个人时发现他也删了 |
| 他的解释 | 「不常联系了」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他删的是谁 | 无关紧要的人 | 对他其实有意义的人 |
| 她知不知道 | 一直不知道 | 知道了，且被触动 |
| 她的回应 | 也做了同样的事 | 什么都没做（也成立） |
| 时机 | 关系确立后 | 关系确立前（更重） |

「关系确立前」这一端最好：在没有名分的时候单方面清场，是最纯粹的表态。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现的那一刻 | 按下删除之前停了三秒 |
| 好的处理 | 她不大张旗鼓，她也悄悄做了一件 | 他不说，也不后悔 |
| 写崩 | 写成她要求他删 | 写成他删完发朋友圈 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 烧了旧信／退了亲事／把那方帕子还了回去 |
| 修仙 | 断了旧契／散了那道印记 |
| 星际 | 注销了旧频道权限 |

#### 写崩的三种方式

1. 让她要求他删。 要求了就不是这条了。
2. 让他昭告天下。 这条的价值在于没人知道。
3. 删得毫不犹豫。 那三秒要写出来。

## 八 · 当众宣示

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：查岗吃醋 37.6%

**骨架**｜她在别人面前说明了他的身份。一句话，五个字，全场安静。

#### 节拍链

有人为难他 → 她放下筷子 → 一个动作（不解释）→ 全场半秒安静 → 她立刻转开话题 → 回家路上他一句话不说 → 进门扑上来

#### 时间轴

半秒安静＋一晚上的回味。 现场的钟极短：她放筷子、开口、转开话题，前后不到二十秒；他的钟极长：回家路上一路无话，进门那一下扑上来——把二十秒回放了一整路。

#### 宣示的三种规格

| 规格 | 说法 | 力度 |
|---|---|---|
| 低 | 「这是我朋友」 | 他会难受 |
| 中 | 报出关系名词 | 标准 |
| 高 | 一个动作而非一句话（伸手过去，或者她的位置站在他前面） | 最强 |

高规格的关键：不解释。 解释是在向别人交代，动作是在替他挡。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 同事聚会 · 家庭场合 · 有人在追她 · 有人对他不客气 |
| 她的动作 | 把他往身边带一步 · 手搭在他背上 · 替他答了那句话 · 端起他面前那杯酒 |
| 他的反应 | 耳朵红 ✓ · 手心 ✓ 出汗 · 不敢看任何人 · 但站着没动 |
| 后续 | 回家路上他一句话不说，进门后扑上来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她说的话 | 明确的关系词 | 一个动作，什么都没说 |
| 场合的敌意 | 无 | 有人在为难他 |
| 他的反应 | 窘 | 挺直了背 |
| 事后 | 两人都不提 | 他问「你刚才为什么那么说」 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 我要不要说得更明确一点 | 她说的时候我在数有几个人在看 |
| 好的处理 | 她说完就转开话题，不给别人接话的机会 | 他站直了 |
| 写崩 | 写成炫耀式的公开占有 | 写成他被公开物化 |

「说完就转开话题」是这条的技术核心。 宣示之后立刻恢复日常，才显得那是事实而不是表演。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 当众唤他的封号／让他坐她身侧／赐座 |
| 修仙 | 当着众人替他挡下／报出道侣名分 |
| 星际 | 在公开频道用了他的全名和职衔 |

古代版最强：位次与称谓在礼制上就是公开宣示，说一个词等于下一道令。

#### 写崩的三种方式

1. 写成撑腰爽文。 重点在他被承认，压倒别人只是顺带。
2. 让他毫无反应。 那一下窘是必须的。
3. 说得太长。 五个字比五句话重。

## 九 · 她的醋

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：查岗吃醋 37.6%（女方向罕见）

**骨架**｜她也会吃醋。而她吃醋的方式是解决问题，不是表达情绪。

#### 节拍链

有人对他过分热情 → 她的第一反应是处理 → 提前出现／直接划界 → 「我没吃醋」→ 手一直没拿开

#### 时间轴

她的醋从起意到处理完毕不超过一小时。 别人的醋靠发酵，她的靠执行：察觉、评估、出现、划界，一套流程走完像处理一单业务。唯一超时的是那只没拿开的手——流程结束后它多停了一晚上。

#### 她与他的吃醋对比

| | 他吃醋 | 她吃醋 |
|---|---|---|
| 第一反应 | 忍 | 处理 |
| 表现 | 情绪往里收 | 行动往外走 |
| 手段 | 撒娇、试探、加倍黏 | 直接问、直接划界、直接带走 |
| 事后 | 他自己消化 | 她不觉得需要解释 |
| 破绽 | 太安静 | 太快 |

「太快」是她的破绽。 她处理得太利落，说明她没打算给自己留反应的时间。

#### 可用细节

| 类 | 内容 |
|---|---|
| 触发 | 有人对他表现出兴趣 · 他提到某个人的次数多了 · 他手机 ✓ 上的一条消息 ✓ |
| 她的处理 | 直接出现在场 · 一句话划界 · 把他带走 · 或者只是把手搭上去 |
| 她不承认 | 「我没吃醋」（说这句时她在做别的事） |
| 他的发现 | 她今天来得特别早 · 她一直没松手 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她承不承认 | 承认，坦荡 | 死不承认 |
| 处理方式 | 直接 | 迂回（更少见，也更有意思） |
| 他知不知道 | 察觉了，很高兴 | 完全没察觉 |
| 力度 | 一个动作 | 一次明确的谈话 |

「他察觉了，很高兴」这一端要写好：弱势方最想要的确认，就是发现对方也会不安。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她意识到自己在意到这个地步 | 发现她吃醋时那一下窃喜 |
| 好的处理 | 她承认，且不觉得丢人 | 他不点破，但他记住了 |
| 写崩 | 写成她泼辣撒泼 | 写成他得意洋洋 |

「她承认且不觉得丢人」是这条最好的处理。强势不等于无欲，坦然承认在意才是真正的强。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她把那人调走了／她赏了他一件旁人没有的东西 |
| 修仙 | 她重新加固了契印 |
| 星际 | 她把他调进了自己的直属编制 |

#### 写崩的三种方式

1. 让她泼辣。 泼辣是另一种人设，且会削弱她的位置。
2. 让她跟人争。 她不需要争，她可以直接决定。
3. 完全不写她吃醋。 那她就成了没有情感需求的功能角色。

## 十 · 独占欲的边界

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：查岗吃醋 37.6%

**骨架**｜这条不是一场戏。它是这一族的收束条：什么时候占有欲变成了问题。

#### 判据表

这一族的每一条都在占有欲的合法区间内。越过这条线，桥段就变成了另一种东西：

| 行为 | 桥段 | 越界 |
|---|---|---|
| 想知道她见了谁 | 试探着问 | 要求报备行踪 |
| 不喜欢某个人 | 自己难受 | 要求她断绝往来 |
| 想被承认 | 期待她宣示 | 强迫公开 |
| 留痕 | 双方自愿 | 作为惩罚 |
| 查看 | 忍住了 | 常态化监控 |
| 她的处理 | 划界 | 隔离他的社交 |

判据是一句话：占有欲指向自己的情绪时是桥段，指向对方的自由时是控制。

#### 为什么要在素材库里写这个

这一族在语料里的写法参差很大，有相当一部分把控制行为当成深情来展示。作为素材库，收录它、标注它、区分它，比回避它有用。

写作时可以写越界的一方，但文本要能被看出对它有判断：越界之后必须有代价，或者有清醒的反抗。 让越界毫无后果地被奖赏，才是真正的问题。

#### 现实与虚构的分界

以上讨论的是**写法**，不是关系建议。小说里的强烈占有欲是情感张力装置，与现实中的健康关系不是一回事。涉及限制人身自由、监控、隔离社交的情节，属于虚构中的冲突素材，不构成对现实行为的推荐。

BDSM 与训诫类的强控制情节另有一套框架，走 [06-尺度与写法](../06-尺度与写法/) 并遵守那一卷的自愿、安全、知情原则。

本条不独立成场，是这一族每一条的判据附注。
