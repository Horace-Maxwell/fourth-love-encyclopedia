> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用

## 这一族为什么关键

关系确立之后的桥段（等门、撒娇、吃醋）都建立在一个前提上：她在上，他在下，双方都接受。

那个前提是怎么来的？就在这一族里。

GB 关系的开局有一道别处没有的难题：男方要接受一个通常不被期待接受的位置，而这件事得在几场戏里完成，不能靠说教。

| 节拍族 | 作品数 | 占比 |
|---|---:|---:|
| 约会 | 1,215 | 42.0% |
| 初见 | 1,101 | 38.0% |
| 改口 | 869 | 30.0% |
| 要联系 | 521 | 18.0% |
| 教导 | 405 | 14.0% |
| 表白 | 347 | 12.0% |

「表白」只有 12%，是全族最低的一项。低出自类型本身：GB 的关系确立往往不靠一次表白，靠一连串的默认。 见第十条。

## 一 · 第一眼

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：初见 38.0%

**骨架**｜她先看见他。看的方式就是全部信息。

#### 节拍链

她注意到他 → 打量（从哪儿开始看）→ 他察觉被看 → 他的反应 → 她移开视线（或者没有）

#### 时间轴

几秒钟的事，目光的路径就是时间轴。 她的打量有顺序（先看手，再看侧脸，最后看整个人），每一站停留半秒；他察觉被看的时点决定戏的走向，第一站就察觉是敏锐，最后一站才察觉是迟钝，两种都可爱。

#### 视线的语法

这条的全部内容是谁在看谁。传统言情的默认是男看女，这一条要反过来，而反过来之后每个细节都变了含义：

| 观察点 | 读作 |
|---|---|
| 她的视线从哪儿开始 | 脸是欣赏，手是评估，肩背是掂量 |
| 看了多久 | 超过三秒就不再是随意 |
| 他察觉之后 | 躲开是没准备好，迎上来是有底气 |
| 谁先移开 | 移开的那个人先输了一步 |
| 她移开之后还回头 | 这一下比前面全部都重 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 面试 · 应酬 · 校门口 · 被人引荐 · 他在做事她在旁边看 |
| 她的动作 | 上下扫一遍 · 目光停在某处 · 手指敲了一下桌面 · 挑眉 |
| 他的反应 | 别开眼 · 站直了 · 耳朵 ✓ 先红 · 手不知道往哪儿放 |
| 环境 | 隔着人群 · 隔着玻璃 · 逆光 · 他没看见她但她看见了他 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先看见 | 她 | 他（但她后知后觉） |
| 场合 | 正式（面试、引荐） | 偶然（撞见、路过） |
| 他的状态 | 落魄 | 光鲜 |
| 结果 | 当场认识 | 各走各的，很久以后再遇 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她意识到自己看了太久 | 有人在看我，而我不敢确认 |
| 内心 | 有意思 | 她是在看我吗 |
| 好的处理 | 她不掩饰看，也不解释 | 他没躲，但他也没敢回看 |
| 写崩 | 写成一见钟情的心跳描写 | 写成他自作多情 |

她不掩饰也不解释，是这条最省力的定调法。 一个不解释自己视线的人，权力关系已经说完了。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 隔着屏风／掀帘那一眼／她坐着他站着／堂上一望 |
| 修仙 | 神识扫过／剑光下抬眼／她在高处他在低处 |
| 星际 | 隔着舷窗／检阅时那一眼／她在指挥席上 |

古代版与星际版共享一个现代版没有的优势：高度差是制度给的，她坐着或站在高处不需要理由。

#### 写崩的三种方式

1. 写成外貌描写大会。 看什么不重要，怎么看才重要。
2. 让他立刻迎上视线。 那一下躲闪是他这个位置的证明。
3. 加心跳加速。 心跳是所有言情的通用件，用了就浪费了这一条。

#### 示例（本库自撰，可直接改写）

> 会议室的门开着，她从走廊经过，脚步慢了半拍。
> 里面那个人正弯腰在收拾投影线，衬衫的后背绷出一道线。
> 她看的不是脸。是他把线一圈一圈绕起来的手法，绕得很整齐，最后压在自己拇指下面。
> 他直起身，回头，正撞上。
> 他先别开了眼。半秒之后又抬起来，这次没有躲。
> 她笑了一下，走了。

## 二 · 要联系方式

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：要联系 18.0%

**骨架**｜谁开的口，这一局就定了。

#### 节拍链

场合散了 → 她说「手机给我」（或他找了个借口开口）→ 递与存 → 各自写下备注名 → 当晚第一条消息发不发

#### 时间轴

窗口期只有散场前的几分钟。 人还没走完，开口显得急；人走光了，机会就没了，这个倒计时压着开口的人。存号码的十几秒里两个人都在看那块屏幕；当晚第一条消息发不发、几点发，是这条的延长赛（十点前是礼貌，十二点后是心事）。

#### 四种要法与它们的含义

| 谁开口 | 怎么说 | 读作 |
|---|---|---|
| 她 · 直接 | 「手机给我」 | 命令。不问要不要 |
| 她 · 迂回 | 「以后有事找你」 | 给了台阶，也给了余地 |
| 他 · 直接 | 「能加个微信吗」 | 有勇气，但把决定权交出去了 |
| 他 · 迂回 | 找一个必须联系的理由 | 最像他的做法 |

第一行是这个类型的标志性写法。 「手机给我」四个字，不问、不解释、不给拒绝的语法空间，而他把手机递过去了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓（谁的手在谁手上）· 屏幕 ✓ · 备注名 · 二维码 |
| 她的动作 | 直接拿过来 · 自己输 · 存完顺手拨了一下（响的是她自己的） |
| 备注 | 她给他存的是什么 · 他给她存的是什么 · 两个备注的差距 |
| 他的动作 | 解锁太快 · 存完之后一直没敢发消息 |

两个备注名的差距是这条最好用的一个细节。 她存「小李」，他存「……」，这个不对称可以埋很久。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁开口 | 她 | 他 |
| 理由 | 有（工作、还东西） | 没有 |
| 之后 | 当天就聊上了 | 他攥着号码三天没发 |
| 备注 | 全名 | 一个只有他自己懂的名字 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他递手机的速度 | 三天里删掉的十七条草稿 |
| 内心 | 存个号码而已 | 她会不会觉得我烦 |
| 好的处理 | 她当场拨一下，让他也有她的 | 他发的第一条是最没营养的那种 |
| 写崩 | 写成她高高在上地施舍 | 写成他卑微乞讨 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 递名帖／问府邸／她说「你可来寻我」／给了信物 |
| 修仙 | 留传讯符／她的一缕神识／宗门牌子 |
| 星际 | 私人频段／权限码／她把自己的编号报了 |

#### 写崩的三种方式

1. 一要就给且毫无波澜。 递手机的那一下要有内容。
2. 让他反复纠结。 三天没发是好的，三章没发就腻了。
3. 省略备注名。 那是这条最省字的信息载体。

## 三 · 第一次约

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：约会 42.0%，约会＋做饭／夜深高频同现

**骨架**｜谁定的时间地点，谁付的钱，谁送谁回家。三件事就是全部。

#### 节拍链

谁开的口 → 定时间地点 → 他提前到 → 席间（点菜·话题·结账）→ 送 → 到楼下那几秒 → 「下次」说没说

#### 时间轴

三个小时的饭，三个决策点。 点菜（谁做主）、结账（谁伸手快）、散场（送不送），每个点前后不过一分钟，其余时间都是铺垫。「下次」两个字说在告别前的最后十秒：说早了显得急，不说就没有下次。

#### 三个决定权

| 项 | 她做 | 他做 | 含义 |
|---|---|---|---|
| 定时间地点 | 常态 | 他费了很大劲才敢定 | 议程权 |
| 付钱 | 常态 | 他坚持要付 | 经济姿态，见 [12 卷](12-工作与金钱.md) |
| 送回家 | 她送他 | 他送她 | 保护姿态的方向 |

三件都由她做，关系明确但没有张力；三件里他抢到一件，戏就有了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的准备 | 提前踩了点 · 换了三次衣服 ✓ · 提前四十分钟到 · 手心 ✓ 出汗 |
| 她的从容 | 准时或略晚 · 点菜不问他 · 或者只问一句「你不吃什么」 |
| 破绽 | 他记得她随口说过的口味 · 她没注意到他记得 |
| 结账 | 她已经付过了（他去洗手间的时候）· 他愣在那儿 |
| 送 | 谁上谁的车 · 到楼下之后那几秒 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁约的 | 她 | 他（鼓了很久勇气） |
| 算不算约会 | 双方都知道是 | 他以为是，她以为不是 |
| 结账 | 她付 | 他抢到了 |
| 结束 | 说了下次 | 什么都没说，但两人都知道有下次 |
| 场合来路 | 自然认识后的约 | 相亲桌（长辈安排的开局：介绍人吹的版本与本人对不上，两人先联手应付完介绍人，反而结成了同盟——错位开局自带破冰机关） |

「他以为是，她以为不是」是这条最有戏的一个拨法，且它不需要任何人做错事。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他提前很久到了 | 从出门到见面之间的两小时 |
| 内心 | 他今天有点不一样 | 这算不算约会 |
| 好的处理 | 她把结账的事做得毫不声张 | 他没有为付不了钱而自卑 |
| 写崩 | 写成她全程掌控毫无破绽 | 写成他手足无措到滑稽 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 邀他游湖／灯会／她备了车马／他备了一样小东西 |
| 修仙 | 同去秘境／她带他御剑／看一场日出 |
| 星际 | 带他上舰／舷窗外的星图／配额里挤出的一顿真食 |

#### 写崩的三种方式

1. 写成完美约会。 一个小意外（下雨、订错位、他紧张说错话）比全程顺利有用。
2. 让她全程主导且他毫无动作。 他要抢到一件事。
3. 结尾表白。 太早了。见第十条。

## 四 · 谁送谁回家

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：约会 42.0% ＋ 接送 37.0%

**骨架**｜到了楼下，车还没熄火，两个人都没动。

#### 节拍链

上车 → 路上（谁开车·谁选歌）→ 到楼下 → 熄不熄火 → 那几秒 → 谁先动 → 上去或离开

#### 时间轴

车程是正片，楼下那几秒是结尾彩蛋。 二十分钟车程的话题密度前松后紧，越接近目的地，话越少。到楼下熄不熄火是个声明：熄了是「不急」，没熄是「就送到这」。那几秒的静默有保质期，超过十秒必须有人动。

#### 为什么单独成条

送回家这件事在 GB 里有一个特殊张力：保护的方向被倒置了。

传统脚本是男送女，理由是安全。这一条里往往是她送他，而「安全」这个理由用不上——她送他，是想多待一会儿，或者纯粹因为她可以。

于是这个动作失去了借口，变成了纯粹的意愿表达。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 车 ✓ · 安全带 ✓ · 没熄的火 · 楼道灯 ✓ · 副驾 ✓ 上他放着的东西 |
| 那几秒 | 谁先解安全带 · 谁先说「那我上去了」· 谁没动 |
| 他的拖延 | 手放在门把上没拧 · 说了一句无关的话 · 又坐回去 |
| 她的处理 | 等着 · 或者直接说「下车」 · 或者伸手替他解安全带 |

「她伸手替他解安全带」是这条最强的一个动作：越过了他的空间，且他没有拒绝。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁送谁 | 她送他 | 他送她（他会一路把她送到门口） |
| 下不下车 | 他自己上去了 | 她也下了车 |
| 那几秒 | 什么都没发生 | 有一件小事发生了 |
| 天气 | 晴 | 下雨（他没伞，她有） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他的手在门把上停了两秒 | 我要不要请她上去坐坐 |
| 内心 | 他不想下车 | 这句话说出口会不会太快 |
| 好的处理 | 她没催，也没主动 | 他最后还是下车了 |
| 写崩 | 写成她强势邀请 | 写成他扭捏半天 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 送到府门／车驾停在巷口／她掀帘看他进门才走 |
| 修仙 | 送到山门／她的剑停在洞府外 |
| 星际 | 送到舱门／权限刷开了但他没进 |

#### 写崩的三种方式

1. 让车里发生太多。 这条的力量在克制。
2. 省略那几秒。 那几秒就是全条。
3. 让她强行留人。 越界会毁掉前面三条的铺垫。

## 五 · 改口

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：改口 30.0%

**骨架**｜他换了一个称呼。这件事比任何表白都硬。

#### 节拍链

旧称呼用了很久 → 一个触发点 → 卡在喉咙里 → 说出口（声音很小）→ 她应了一声 → 之后越叫越顺

#### 时间轴

旧称呼用了几个月，新称呼卡了几周。 他在心里排练的时长远超实际使用，第一次说出口音量只有平时一半，说完立刻接别的话岔开。她应那一声只用了一秒，但这一秒把他几周的排练全部结清。之后一周内使用频率暴涨，像补偿。

#### 称谓的阶梯

改口是这个类型里成本最低、信息量最大的动作。因为称呼是公开可听见的，改了就等于宣布了。

| 阶 | 称呼 | 关系 |
|---|---|---|
| 0 | 全名 / 职衔 | 无关系或纯公事 |
| 1 | 姓 + 姐 / 老师 | 有距离的尊敬 |
| 2 | 名字 | 熟了 |
| 3 | 姐 | 亲密，且承认位置 |
| 4 | 昵称 / 叠字 | 私人领域 |
| 5 | 只有他们两个懂的那个 | 排他 |
| ↓ | 连名带姓 | **降级信号，出事了** |

最后一行值得单独用。 一个平时叫「姐」的人突然叫全名，读者立刻知道出事了，一个字都不用解释。

#### 可用细节

| 类 | 内容 |
|---|---|
| 触发 | 她要求 · 别人叫了他跟着叫 · 他失控时脱口而出 · 醉了 |
| 第一次改口 | 卡在喉咙里 · 声音很小 · 说完不敢看她 |
| 她的反应 | 「嗯」（最好）· 没听见（他要再说一次）· 笑了 |
| 场合差 | 私下叫这个，人前叫那个 · 某天在人前叫错了 |

「某天在人前叫错了」是这条最好的一次性爆点。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提的 | 她要求 | 他自己改的 |
| 方向 | 升级（更亲密） | 降级（连名带姓，出事了） |
| 场合 | 私下 | 当众 |
| 她的态度 | 明确接受 | 装作没注意（他会更慌） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听见那两个字时手上的动作停了一下 | 说出口之前在心里练了很多遍 |
| 内心 | 他改口了 | 她会不会觉得我僭越 |
| 好的处理 | 她只应了一声，什么都没说 | 他说完就转开话题 |
| 写崩 | 写成她纠正他叫法的教学戏 | 写成他刻意讨好 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 从「主君」到封号到闺名／当众唤名是逾矩／她赐他叫她的字 |
| 修仙 | 从「师尊」到道号到本名／结契后的称呼 |
| 星际 | 从军衔到姓氏到名字／私人频道里的叫法 |

古代版最厚。称谓在礼制里是硬性的，改口算身份事件，不算感情事件。 见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。

#### 写崩的三种方式

1. 让他一次就改成功。 卡壳、说小声、被追问「你说什么」，这些才是内容。
2. 只写升级不写降级。 连名带姓那一版更有用。
3. 大段解释这个称呼的意义。 让读者自己听出来。

## 六 · 她教他

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：教导 14.0%，教导＋初见高频同现

**骨架**｜她会一样他不会的东西。教的过程里，位置被自然地建立了。

#### 节拍链

起因（他不会）→ 她说「我教你」→ 手把手 → 他学不会或装学不会 → 她纠正 → 「行了」→ 他还想再练一次

#### 时间轴

教学以「次」推进，进度故意不线性。 第一次他真不会，第三次他会了但装不会，装的成分她第几次看穿，是这条的暗线。「行了」是毕业令，他那句「再练一次」是赖着不毕业；她准了，两个人都清楚这门课教的不是那门手艺。

#### 为什么这是最省力的定调法

它不需要任何人宣布权力关系。教与被教本身就是一个位置差，而且这个位置差正当、临时，也不伤自尊。

现代设定里「她凭什么在上」不好写，这一条是最低成本的解法。见 [03-世界观设定/04-非女尊设定下的权力来源设计](../03-世界观设定/04-非女尊设定下的权力来源设计.md)。

#### 教什么

| 教的内容 | 权力质地 | 备注 |
|---|---|---|
| 开车 | 身体接触自然发生 | 副驾与驾驶座的位置差 |
| 游泳 | 他必须信任她 | 水里失去自主 |
| 工作技能 | 专业权威 | 最不伤自尊的一种 |
| 打架 / 用枪 | 她比他强这件事被具象化 | 落差最大 |
| 乐器 / 书法 | 手把手，距离最近 | 古代版首选 |
| 做菜 | 反向：他教她（也成立） | 见 [01 卷](01-日常照料.md) |

#### 可用细节

| 类 | 内容 |
|---|---|
| 姿势 | 她在他身后 · 手覆在他手上 · 她比他矮所以要靠近 |
| 她的语气 | 不哄、不夸、只纠正 · 「再来一遍」 |
| 他的状态 | 学不会时的烦躁 · 学会时看她的眼神 · 故意学不会 |
| 结束 | 她说「行了」 · 他还想再练一次 |

「他故意学不会」是这条最好的拨法：为了多待一会儿而拖延，且两个人都知道。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他学得快慢 | 快（她有点意外） | 慢（真的慢） |
| 他装不装 | 认真学 | 装笨 |
| 她察觉没 | 没察觉 | 察觉了，配合他 |
| 后来 | 他超过她了 | 他一直没学会（也可以） |

「他超过她了」可以接 [20 卷的成长线](12-工作与金钱.md)：学生超过老师之后，关系要重新谈。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他今天学得特别慢 | 她的手覆上来的那一下 |
| 内心 | 教一遍就会的人，怎么今天要三遍 | 再学不会一次 |
| 好的处理 | 她配合他装笨，不说破 | 他没有真的滥用这个 |
| 写崩 | 写成师生调情套路 | 写成撒娇工具 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 教他握笔／教他骑射／她的手覆在他手背上 |
| 修仙 | 授功法／引气入体／她的灵力在他经脉里走一遍 |
| 星际 | 教他操舰／模拟舱／她在他身后看仪表 |

#### 写崩的三种方式

1. 教的东西太抽象。 要能用手做的。
2. 她一边教一边夸。 只纠正不夸，位置才立得住。
3. 让他一次学会。 学不会才有第二次。

## 七 · 试探边界

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：约会 42.0% 衍生

**骨架**｜他想知道自己能走到哪一步，于是他往前伸了一点点。

#### 节拍链

站得近一点 → 没被躲开 → 帮拿包 → 问一句私人的 → 送回家 → 碰一下手 → 有一次她退开了 → 隔很久再试

#### 时间轴

以「次」为单位的长期工程，每次只进一寸。 站近一点到碰一下手，跨度以月计；每次试探之间的间隔是他的安全边际。她退开的那一次是里程碑，之后他隔了很久才再试，那段「很久」的长度，就是他把她的边界当真的证明。

#### 这条是这一族的真正核心

关系确立靠的是一连串小的越界被默许，一次表白完成不了。

| 他的试探 | 她的默许方式 | 累积效果 |
|---|---|---|
| 站得近一点 | 没退开 | 空间被让出来了 |
| 帮她拿包 | 给了 | 服务被接受了 |
| 问一句私人的事 | 答了 | 边界被打开一格 |
| 送她回家 | 让他送了 | 时间被给出来了 |
| 碰一下手 | 没抽开 | 身体被允许了 |

每一次「没有拒绝」都是一次授权。 写这一族的关键是让读者看见授权在累积，而不是等一句「我们在一起吧」。

#### 可用细节

| 类 | 内容 |
|---|---|
| 试探的形态 | 越来越具体、越来越难收回 |
| 他的自我保护 | 每次都留了一条可以退回去的路 |
| 她的信号 | 不点破、不阻止、也不主动 |
| 失败的那次 | 有一次她退开了 · 他立刻收回 · 之后隔了很久才敢再试 |

「有一次她退开了」是必须写的。全部成功的试探等于没有试探。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她知不知道 | 一直知道，在等他自己走完 | 后知后觉 |
| 速度 | 快 | 慢到旁人都急了 |
| 有没有退回 | 一路向前 | 中间退过一次 |
| 谁先说破 | 她 | 他 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她注意到他每次都比上次近一点 | 这次她会不会退开 |
| 内心 | 我要不要帮他一把 | 到哪儿为止 |
| 好的处理 | 她在他退回去的那次没有嘲笑 | 他退回去之后没有赌气 |
| 写崩 | 写成她玩弄试探 | 写成他步步紧逼 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 逾矩的每一小步／越礼一分／她没斥责就是准了 |
| 修仙 | 神识每次多探一寸／她没有屏蔽 |
| 星际 | 每次多申请一级权限／她批了 |

古代版的「她没斥责就是准了」把这条讲到了极致：在有明确规矩的世界里，不惩罚就是许可。

#### 写崩的三种方式

1. 让每次试探都成功。 要有一次失败。
2. 写成套路化的攻略流程。 他是在冒险，不是在闯关。
3. 用一次表白替代整个过程。 那正是这一条要避免的。

## 八 · 他先动心

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：约会 42.0% ＋ 初见 38.0%

**骨架**｜他已经陷进去了，她还在正常生活。圈内通称的暗恋期、单箭头，写的就是这一段。

#### 节拍链

意识到 → 开始留意她的一切 → 难受 → 藏不住 → 第三人点破或她自己看懂 → 她做决定

#### 时间轴

陷落有确切的一天，暴露是缓慢的渗漏。 意识到的那一刻很短（某个普通瞬间，她低头签字的侧影）；之后的隐瞒期以月计，破绽积累：视线停留超时、记住的细节过多。第三人点破往往比她察觉早，旁观者清，是这条的标准配置。

#### 时间差是这条的全部

GB 的开局有一个高频结构：他先，她后。 而这段时间差里，他是一个人在承担全部的重量。

| 阶段 | 他 | 她 |
|---|---|---|
| 一 | 意识到了 | 完全不知道 |
| 二 | 开始注意她的一切 | 觉得他最近挺勤快 |
| 三 | 开始难受 | 察觉到一点异常 |
| 四 | 藏不住了 | 开始想这件事 |
| 五 | — | 做出决定 |

第四阶段到第五阶段之间那段空白，是这条最疼的地方。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的表现 | 记住她说过的每一句 · 改变自己的作息去配合她 · 手机 ✓ 里存了她的照片 ✓ |
| 破绽 | 别人提到她时他的反应 · 他知道太多本不该知道的细节 |
| 她的迟钝 | 把他的殷勤当成好同事／好朋友 |
| 第三人 | 旁边总有一个先看出来的人 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时间差 | 几周 | 几年 |
| 他说不说 | 忍着 | 忍不住了 |
| 她的发现方式 | 别人点破 | 自己突然看懂了某个细节 |
| 结果 | 接受 | 她需要时间 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她某天忽然看懂了一件旧事 | 每一天都在计算能不能说 |
| 内心 | 他是从什么时候开始的 | 说了就全没了 |
| 好的处理 | 她回头把过去的细节重新读了一遍 | 他没有用付出施压 |
| 写崩 | 写成她迟钝到不合理 | 写成他默默付出的苦情 |

「他没有用付出施压」是这条的红线。 一旦他开始暗示「我为你做了这么多」，读者会立刻站到她那边。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他记得她每一次经过的时辰／默默做了三年的事 |
| 修仙 | 他为她挡过的劫她不知道／百年守候 |
| 星际 | 他调岗只为跟她同一班／航线记录里的痕迹 |

#### 写崩的三种方式

1. 让她迟钝到不合理。 她可以没在想这件事，不能是傻。
2. 让他默默付出并等待回报。 那是道德绑架不是喜欢。
3. 时间差太长。 几年可以，十年要给理由。

## 九 · 她先动心

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：约会 42.0%（女方向少见）

**骨架**｜她发现自己在意了。而她的第一反应是把这件事处理掉。

#### 节拍链

察觉自己在意 → 分析它 → 克制（见面变少）→ 一件小事破防 → 想清楚 → 一句话说完

#### 时间轴

从察觉到处理完毕，她给自己排了期。 第一周分析（这是什么、从哪来的），第二周执行克制方案（见面减半），第三周方案破产，破产在一件计划外的小事上。想清楚只用了一晚，说出口只用了一句：她的钟前段冗长后段干脆，跟她做事一个样。

#### 与上一条的对称与不对称

| | 他先动心 | 她先动心 |
|---|---|---|
| 第一反应 | 藏起来 | 分析它 |
| 处理方式 | 忍 | 决定要不要 |
| 表现 | 殷勤变多 | 行为变少（她在克制） |
| 破绽 | 他知道太多 | 她突然对某件事特别在意 |
| 说破的方式 | 忍不住 | 想清楚了之后直接说 |

她的破绽是「变少」不是「变多」，这一点与他完全相反，也是这条最容易写崩的地方。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的克制 | 减少见面 · 说话变得公事化 · 把他调走 · 给自己找理由 |
| 真实的迹象 | 她记住了他的作息 · 她替他挡过一次麻烦但没说 |
| 转折 | 一件小事让她意识到自己不能不管 |
| 她的处理 | 想清楚 → 直接说 → 不给自己留退路 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的处理 | 立刻确认 | 先推开（更常见） |
| 推开的方式 | 冷淡 | 调走／断联 |
| 他的反应 | 不明白发生了什么 | 他猜到了 |
| 收场 | 她回来找他 | 他去找她 |

「先推开」这一端要小心：推开必须有她自己的理由（身份、责任、怕伤到他），不能只是别扭。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己在替他考虑一件不必考虑的事 | 她这周为什么都没找我 |
| 内心 | 这不合适 | 我是不是做错了什么 |
| 好的处理 | 她想明白之后一句话说完 | 他在被冷落时没有立刻放弃 |
| 写崩 | 写成她矫情纠结十章 | 写成他自我怀疑到崩溃 |

「一句话说完」是四爱女角色最好的表白方式。 想清楚了就说，不铺垫、不试探、不给自己留退路。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她把他调离身边／却又打听他的近况 |
| 修仙 | 她断了传讯／但护山大阵留着他的权限 |
| 星际 | 她把他调去另一艘舰／航线还是挨着 |

三个换皮共享同一个结构：表面切断，实际留门。

#### 写崩的三种方式

1. 让她纠结太久。 她的特点是决断，纠结十章会毁人设。
2. 让她推开且不给理由。 理由必须成立。
3. 让她表白得很含蓄。 含蓄是他的写法，不是她的。

## 十 · 没有表白

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：表白 12.0%（全族最低）

**骨架**｜关系确立了，但没有人说过那句话。

#### 节拍链

试探的累积 → 钥匙给了 → 「我们」说出口 → 别人默认 → 谁都没宣布 → 多年后答不上「哪天在一起的」

#### 时间轴

没有起点日，只有一串里程碑。 钥匙给出的那天、「我们」第一次出口的那天、外人开始默认的那天，每个里程碑单独看都不算数，连起来就是确立。多年后回答不出「哪天在一起的」，两个人各报了一个日期，还不一样，这个分歧本身就是答案。

#### 为什么这一条要单独写

「表白」在语料里只有 12%，是这一族最低的一项。这是结构特征，不是数据问题：

GB 的关系确立更常靠一连串的默认，而不是一次宣告。

原因不难理解。表白是一个平权动作：我把我的感情交给你，你来决定。而 GB 的关系里，位置从一开始就不对称——他不觉得自己有资格发起，她不觉得这件事需要仪式。

于是关系就在没有任何人宣布的情况下成立了。

#### 关系已经确立的六个信号

不用一句台词，用这些：

| 信号 | 说明 |
|---|---|
| 他有她家的钥匙 ✓ | 空间 |
| 她的备注名改了 | 身份 |
| 他不再说「我走了」而说「我回来」 | 归属 |
| 别人默认他们是一起的，两人都没否认 | 公开 |
| 他开始拒绝别人的邀约且不解释 | 排他 |
| 她安排事情时自动把他算进去 | 未来 |

最后一行最重。 她说「下个月我们……」的那一刻，关系就成立了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 确立的时刻 | 通常很平常：一起买菜、他随手接过她的包、她说了「我们」 |
| 事后追认 | 很久以后有人问「你们什么时候在一起的」，两人答不上来 |
| 缺失的仪式 | 他偶尔会想要一句明确的话 |
| 补上 | 很久以后她突然说了 · 或者一直没说 |

「有人问『你们什么时候在一起的』，两人答不上来」是这条最好的一场戏。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 有没有补上 | 后来她说了 | 一直没有 |
| 他介不介意 | 不介意 | 介意，但不说 |
| 谁先用「我们」 | 她 | 他（他会先试探性地用一次） |
| 外人的确认 | 别人先说破 | 一直没人问 |

「他介意但不说」可以接 [04-委屈与破防 · 我是不是不够好](04-委屈与破防.md#九--我是不是不够好)：没有名分这件事会在很久以后发作。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她某天发现自己说了「我们」 | 他数得清她用过几次「我们」 |
| 内心 | 这算是在一起了吧 | 我算什么 |
| 好的处理 | 她在某个平常的时刻把话说明白了 | 他没有讨要名分 |
| 写崩 | 写成她逃避承诺 | 写成他患得患失一整卷 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 没有名分但住进了正院／族谱上没有他／她带他赴宴等于宣告 |
| 修仙 | 没有结契但共用洞府／她的护山阵认他 |
| 星际 | 没有登记但共享最高权限 |

古代版最狠：名分在礼制社会里是实体的，「住在正院但族谱上没有他」这个状态可以撑起整卷冲突。

#### 写崩的三种方式

1. 补一场迟到的盛大表白。 那会把前面全部的克制兑现掉。
2. 让他完全不在意名分。 他可以不要，但他要想过。
3. 让确立的时刻很隆重。 越平常越好。
