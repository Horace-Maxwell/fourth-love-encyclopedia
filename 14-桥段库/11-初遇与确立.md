# 初遇与确立

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**权力关系是在这几场戏里被谈成的，不是一开始就有的。**

## 这一族为什么关键

关系确立之后的桥段（等门、撒娇、吃醋）都建立在一个前提上：她在上，他在下，双方都接受。

那个前提是怎么来的？就在这一族里。

GB关系开局最难的地方在于，男方得先接受一个平时没人愿意待的位置。这个心理转变，需要在几场戏里演出来，不能靠角色自己讲道理。

| 节拍族 | 作品数 | 占比 |
|---|---:|---:|
| 约会 | 1,215 | 42.0% |
| 初见 | 1,101 | 38.0% |
| 改口 | 869 | 30.0% |
| 要联系 | 521 | 18.0% |
| 教导 | 405 | 14.0% |
| 表白 | 347 | 12.0% |

「表白」只有 12%，是全族最低的一项。低出自类型本身：GB 的关系确立往往不靠一次表白，靠一连串的默认。 见第十条。

## 一 · 第一眼

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：初见 38.0%

**骨架**｜她先瞅见了他。咋瞅的，啥都说明白了。

#### 节拍链

她注意到他 → 打量（从哪儿开始看）→ 他察觉被看 → 他的反应 → 她移开视线（或者没有）

#### 时间轴

几秒钟的事，她看他的顺序就是一条时间轴。先看手，再看侧脸，最后才看整个人，每处停个半秒。他什么时候发现她在看，戏就往哪个方向走——第一眼就察觉，是敏锐；等看到最后一眼才反应过来，是迟钝。两种都挺招人喜欢。

#### 视线的语法

这条的全部内容是谁在看谁。传统言情的默认是男看女，这一条要反过来，而反过来之后每个细节都变了含义：

| 观察点 | 读作 |
|---|---|
| 她的视线从哪儿开始 | 看脸是喜欢，看手是打量，看肩背是掂量 |
| 看了多久 | 超过三秒就不是随便看看了 |
| 他察觉之后 | 躲开是还没想好，迎上来是心里有底 |
| 谁先移开 | 先移开的人先露了怯 |
| 她移开之后还回头 | 这一眼比之前所有加起来都重 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 面试 · 饭局 · 校门口 · 被人介绍认识 · 他正忙，她在边上看着 |
| 她的动作 | 把人从头到脚看了一遍 · 眼神在某处停住 · 拿指头敲了下桌子 · 挑了下眉 |
| 他的反应 | 把脸转开 · 身子绷直 · 耳朵先红 · 手没地方搁 |
| 环境 | 人堆里隔着段距离 · 隔了层玻璃 · 背着光 · 他没瞅见她，她倒把他看清楚了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先看见 | 她 | 他（但她后知后觉） |
| 场合 | 正式（面试、引荐） | 偶然（撞见、路过） |
| 他的状态 | 落魄 | 光鲜 |
| 结果 | 当场认识 | 各走各的，很久以后再遇 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己看入神了 | 有人盯着我，我不敢抬头确认 |
| 内心 | 挺有意思 | 她是不是在看我 |
| 好的处理 | 她没藏视线，也没找补 | 他没躲，但也没敢迎上去 |
| 写崩 | 写成第一眼就心动 | 写成他单方面想多了 |

她不掩饰也不解释，是这条最省力的定调法。 一个不解释自己视线的人，权力关系已经说完了。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 隔着屏风／掀帘那一眼／她坐着他站着／堂上一望 |
| 修仙 | 神识扫过／剑光下抬眼／她在高处他在低处 |
| 星际 | 隔着舷窗／检阅时那一眼／她在指挥席上 |

古代版与星际版共享一个现代版没有的优势：高度差是制度给的，她坐着或站在高处不需要理由。

#### 写崩的三种方式

1. 别把外貌从头写到脚。写他看什么，不如写他怎么偷看、怎么躲、怎么假装不经意。
2. 让他一抬眼正好撞上对方的视线。那一下没躲开，比什么身份说明都管用。
3. 别一见面就心跳加速。这招所有言情都在用，你再用，等于白写。

#### 示例（本库自撰，可直接改写）

> 会议室的门开着，她从走廊经过，脚步慢了半拍。
> 里面那个人正弯腰在收拾投影线，衬衫的后背绷出一道线。
> 她看的不是脸。是他把线一圈一圈绕起来的手法，绕得很整齐，最后压在自己拇指下面。
> 他直起身，回头，正撞上。
> 他先别开了眼。半秒之后又抬起来，这次没有躲。
> 她笑了一下，走了。

## 二 · 要联系方式

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：要联系 18.0%

**骨架**｜谁开的口，这一局就定了。

#### 节拍链

场合散了 → 她说「手机给我」（或他找了个借口开口）→ 递与存 → 各自写下备注名 → 当晚第一条消息发不发

#### 时间轴

窗口期就散场前那几分钟。人还没走完，你开口显得急；人走光了，机会也就没了，这个倒计时压得人喘不过气。存号码那十几秒，两个人都在盯那块屏幕；当晚第一条消息发不发、几点发，就是这场戏的加时赛（十点前是礼貌，十二点后是心事）。

#### 四种要法与它们的含义

| 谁开口 | 怎么说 | 读作 |
|---|---|---|
| 她 · 直接 | 「手机给我」 | 命令。不问要不要 |
| 她 · 迂回 | 「以后有事找你」 | 给了台阶，也留了退路 |
| 他 · 直接 | 「能加个微信吗」 | 有胆，但把话递到人嘴边 |
| 他 · 迂回 | 找个由头非联系不可 | 最像他干的事 |

第一行是这个类型的标志性写法。 「手机给我」四个字，不问、不解释、不给拒绝的语法空间，而他把手机递过去了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓（谁拿着、谁在看）· 屏幕 ✓ · 备注名 · 二维码 |
| 她的动作 | 直接拿过来 · 自己输 · 存完顺手拨了一下（响的是她自己的） |
| 备注 | 她给他存了什么 · 他给她存了什么 · 俩备注差在哪儿 |
| 他的动作 | 解锁太快 · 存完之后一直没敢发消息 |

两个备注名的差距是这条最好用的一个细节。 她存「小李」，他存「……」，这个不对称可以埋很久。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁开口 | 她 | 他 |
| 理由 | 有（工作、还东西） | 没有 |
| 之后 | 当天就聊上了 | 他攥着号码三天没发 |
| 备注 | 全名 | 一个只有他自己懂的名字 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他递手机的速度 | 三天里删掉的十七条草稿 |
| 内心 | 存个号码而已 | 她会不会觉得我烦 |
| 好的处理 | 她当场拨一下，让他也有她的 | 他发的第一条是最没营养的那种 |
| 写崩 | 写成她高高在上地施舍 | 写成他卑微乞讨 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 递名帖／问府邸／她说「你可来寻我」／给了信物 |
| 修仙 | 留传讯符／她的一缕神识／宗门牌子 |
| 星际 | 私人频段／权限码／她把自己的编号报了 |

#### 写崩的三种方式

1. 一要就给，还一点反应都没有。递手机那一下，得有点东西。
2. 让他自己来回琢磨。三天不发消息是好的，三章不发，读者就跑了。
3. 备注名别写。那是这条线里最省字的信息点。

## 三 · 第一次约

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：约会 42.0%，约会＋做饭／夜深高频同现

**骨架**｜谁定的时间地点，谁掏的钱，谁送谁回家。就这三件事。

#### 节拍链

谁开的口 → 定时间地点 → 他提前到 → 席间（点菜·话题·结账）→ 送 → 到楼下那几秒 → 「下次」说没说

#### 时间轴

三个小时的饭，真正的关键就三个瞬间：点菜时谁拿主意，结账时谁先掏手机，散场时送不送人。每个瞬间前后就一分钟，其他时间全是铺垫。真正决定有没有下次的，是告别前最后十秒里那句「下次」——说早了显得太急，不说就等于没下次。

#### 三个决定权

| 项 | 她做 | 他做 | 含义 |
|---|---|---|---|
| 定时间地点 | 常态 | 他鼓起勇气才开口定 | 谁说了算 |
| 付钱 | 常态 | 他抢着付 | 经济姿态，见 [12 卷](12-工作与金钱.md) |
| 送回家 | 她送他 | 他送她 | 谁护着谁 |

三件都由她做，关系明确但没有张力；三件里他抢到一件，戏就有了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的准备 | 提前踩了点 · 换了三次衣服 ✓ · 提前四十分钟到 · 手心 ✓ 出汗 |
| 她的从容 | 准时或略晚 · 点菜不问他 · 或者只问一句「你不吃什么」 |
| 破绽 | 他记得她随口说过的口味 · 她没注意到他记得 |
| 结账 | 她已经付过了（他去洗手间的时候）· 他愣在那儿 |
| 送 | 谁上谁的车 · 到楼下之后那几秒 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁约的 | 她 | 他（憋了好几天才开口） |
| 算不算约会 | 两人心里都门清 | 他当是，她没当 |
| 结账 | 她掏的钱 | 他抢着付了 |
| 结束 | 说了句下次见 | 谁都没提，但都知道还有下回 |
| 场合来路 | 认识后自然约出来的 | 相亲桌上认识的（长辈牵的线：介绍人说的和本人对不上，两人先一块儿把介绍人应付过去，反倒聊到了一块儿——开头就拧着，反而省了客套） |

「他以为是，她以为不是」是这条最有戏的一个拨法，且它不需要任何人做错事。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他提前很久到了 | 从出门到见面之间的两小时 |
| 内心 | 他今天有点不一样 | 这算不算约会 |
| 好的处理 | 她把结账的事做得毫不声张 | 他没有为付不了钱而自卑 |
| 写崩 | 写成她全程掌控毫无破绽 | 写成他手足无措到滑稽 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 邀他游湖／灯会／她备了车马／他备了一样小东西 |
| 修仙 | 同去秘境／她带他御剑／看一场日出 |
| 星际 | 带他上舰／舷窗外的星图／配额里省下的一顿真食 |

#### 写崩的三种方式

1. 写成完美约会。 中途出点小岔子（下雨、订错位、他紧张说错话）比全程顺顺当当管用。
2. 让她全程主导，他一点动静没有。 他得抢着干成一件事。
3. 结尾就表白。 太早了。看第十条。

## 四 · 谁送谁回家

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：约会 42.0% ＋ 接送 37.0%

**骨架**｜车还在楼下没熄火，俩人都坐着没动。

#### 节拍链

上车 → 路上（谁开车·谁选歌）→ 到楼下 → 熄不熄火 → 那几秒 → 谁先动 → 上去或离开

#### 时间轴

车程才是正片，楼下那几秒顶多算彩蛋。二十分钟的路，话题密度前松后紧，越快到地方话越少。到楼下熄不熄火，这就是个态度：熄了是「不急」，没熄是「就送到这」。那几秒谁都不说话，但憋不过十秒，十秒一过，总得有人先动。

#### 为什么单独成条

送回家这件事在 GB 里有一个特殊张力：保护的方向被倒置了。

传统脚本里都是男送女，理由是“安全”。但这一条反过来，她送他，安全这个理由根本不成立——她送他，就是想多待一会儿，或者单纯因为她乐意。

于是这个动作失去了借口，变成了纯粹的意愿表达。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 车 ✓ · 安全带 ✓ · 火没灭 · 楼道灯 ✓ · 副驾 ✓ 上搁着他的东西 |
| 那几秒 | 谁先解安全带 · 谁先说「那我上去了」· 谁没动 |
| 他的拖延 | 手搭在门把上不拧 · 没话找话说了句 · 又坐回去 |
| 她的处理 | 等着 · 或者直接说「下车」 · 或者伸手替他解安全带 |

「她伸手替他解安全带」是这条最强的一个动作：越过了他的空间，且他没有拒绝。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁送谁 | 她送他 | 他送她（他会一路把她送到门口） |
| 下不下车 | 他自己上去了 | 她也下了车 |
| 那几秒 | 什么都没发生 | 有一件小事发生了 |
| 天气 | 晴 | 下雨（他没伞，她有） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他手在门把上顿了一下 | 要不要请她上来坐坐 |
| 内心 | 他不想下车 | 这话说出口是不是太早了 |
| 好的处理 | 她没催，也没先动 | 他最后还是下车了 |
| 写崩 | 写成她硬拉人上来 | 写成他磨蹭个没完 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 送到府门／车驾停在巷口／她掀帘看他进门才走 |
| 修仙 | 送到山门／她的剑停在洞府外 |
| 星际 | 送到舱门／权限刷开了但他没进 |

#### 写崩的三种方式

1. 车里别塞太满。 这条的劲儿全在收着写。
2. 把那几秒跳过去。 那几秒才是整段的命。
3. 让她硬把人留住。 一越界，前面三条全白搭。

## 五 · 改口

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：改口 30.0%

**骨架**｜他换了个叫法。这比啥表白都顶用。

#### 节拍链

旧称呼用了很久 → 一个触发点 → 卡在喉咙里 → 说出口（声音很小）→ 她应了一声 → 之后越叫越顺

#### 时间轴

旧称呼喊了几个月，新称呼憋了几周。他脑子里排练了不知道多少遍，真到嘴边的时候，声音比平时小了一半，喊完马上扯别的话打岔。她应那一声就一秒，但这一秒把他几周的折腾全给值回来了。接下来一周他逮着机会就叫，跟还债似的。

#### 称谓的阶梯

改口是这个类型里成本最低、信息量最大的动作。因为称呼是公开可听见的，改了就等于宣布了。

| 阶 | 称呼 | 关系 |
|---|---|---|
| 0 | 全名 / 职衔 | 不熟，或者纯粹谈事 |
| 1 | 姓 + 姐 / 老师 | 敬着点，但还不近 |
| 2 | 名字 | 处熟了 |
| 3 | 姐 | 亲近，也认她说了算 |
| 4 | 昵称 / 叠字 | 自己人，私下才这么叫 |
| 5 | 只有他俩懂的那个 | 别人插不进来 |
| ↓ | 连名带姓 | **要翻脸了，出大事了** |

最后一行值得单独用。 一个平时叫「姐」的人突然叫全名，读者立刻知道出事了，一个字都不用解释。

#### 可用细节

| 类 | 内容 |
|---|---|
| 触发 | 她提的要求 · 别人这么叫他也跟着叫 · 脑子一热说漏嘴 · 喝多了 |
| 第一次改口 | 话到嘴边又咽回去 · 声音发虚 · 说完不敢瞅她 |
| 她的反应 | 「嗯」（最省事）· 装没听见（逼他再喊一遍）· 乐了 |
| 场合差 | 俩人时这么喊，有外人在就换 · 哪天当着人面喊岔了 |

「某天在人前叫错了」是这条最好的一次性爆点。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提的 | 她要求 | 他自己改的 |
| 方向 | 升级（更亲密） | 降级（连名带姓，出事了） |
| 场合 | 私下 | 当众 |
| 她的态度 | 明确接受 | 装作没注意（他会更慌） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听见那两个字时手上的动作停了一下 | 说出口之前在心里练了很多遍 |
| 内心 | 他改口了 | 她会不会觉得我僭越 |
| 好的处理 | 她只应了一声，什么都没说 | 他说完就转开话题 |
| 写崩 | 写成她纠正他叫法的教学戏 | 写成他刻意讨好 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 从「主君」到封号到闺名／当众喊名字算越界／她赏他叫她的字 |
| 修仙 | 从「师尊」到道号到本名／结契之后怎么叫 |
| 星际 | 从军衔到姓到名／私下频道里怎么喊 |

古代版最厚。称呼在古代是规矩，不能乱叫，改口等于身份变了，不是感情变了。见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。

#### 写崩的三种方式

1. 让他一次就改对。 卡壳、说小声、被追问「你说什么」，这些才是读者要看的。
2. 只写升级不写降级。 连名带姓叫那一版，更有用。
3. 别大段解释这个称呼有啥意义。 让读者自己听出来。

## 六 · 她教他

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：教导 14.0%，教导＋初见高频同现

**骨架**｜她会一样他不会的东西，教着教着，位置就自然摆正了。

#### 节拍链

起因（他不会）→ 她说「我教你」→ 手把手 → 他学不会或装学不会 → 她纠正 → 「行了」→ 他还想再练一次

#### 时间轴

教学是按“次”来算的，进度故意不走直线。第一次他是真不会，第三次他会了但装不会——她到底第几次看穿他装的，这条线才是暗线。她一句“行了”，就是放他毕业；他那句“再练一次”，就是赖着不走。她准了，两个人都心知肚明，这门课教的本来就不是那门手艺。

#### 为什么这是最省力的定调法

它不需要任何人宣布权力关系。教与被教本身就是一个位置差，而且这个位置差正当、临时，也不伤自尊。

现代文里「她凭什么在上」这个事，确实不好弄。但这一招是最省事的解法，具体怎么设计，看 [03-世界观设定/04-非女尊设定下的权力来源设计](../03-世界观设定/04-非女尊设定下的权力来源设计.md)。

#### 教什么

| 教的内容 | 权力质地 | 备注 |
|---|---|---|
| 开车 | 身体接触自然发生 | 副驾和驾驶座那点距离差 |
| 游泳 | 他只能信她 | 水里人使不上劲 |
| 工作技能 | 专业上说了算 | 最不伤面子的一种 |
| 打架 / 用枪 | 她比他强，明摆着 | 落差最大 |
| 乐器 / 书法 | 手把手，挨得最近 | 古代篇首选 |
| 做菜 | 反过来：他教她（也行） | 见 [01 卷](01-日常照料.md) |

#### 可用细节

| 类 | 内容 |
|---|---|
| 姿势 | 她站他后头 · 手搭在他手上 · 她个子矮得踮脚凑近 |
| 她的语气 | 不哄也不夸，光挑毛病 · 「再来一遍」 |
| 他的状态 | 学不会就烦 · 会了以后老看她 · 有时候是装的学不会 |
| 结束 | 她来一句「行了」 · 他还想多练几回 |

「他故意学不会」是这条最好的拨法：为了多待一会儿而拖延，且两个人都知道。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他学得快慢 | 快（她有点意外） | 慢（真的慢） |
| 他装不装 | 认真学 | 装笨 |
| 她察觉没 | 没察觉 | 察觉了，配合他 |
| 后来 | 他超过她了 | 他一直没学会（也可以） |

「他超过她了」可以接 [20 卷的成长线](12-工作与金钱.md)：学生超过老师之后，关系要重新谈。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他今天学得特别慢 | 她的手覆上来的那一下 |
| 内心 | 教一遍就会的人，怎么今天要三遍 | 再学不会一次 |
| 好的处理 | 她配合他装笨，不说破 | 他没有真的滥用这个 |
| 写崩 | 写成师生调情套路 | 写成撒娇工具 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 教他握笔／教他骑射／她的手覆在他手背上 |
| 修仙 | 授功法／引气入体／她的灵力在他经脉里走一遍 |
| 星际 | 教他操舰／模拟舱／她在他身后看仪表 |

#### 写崩的三种方式

1. 教的东西别整太玄。得能上手练的。
2. 她边教边夸。光纠错不夸人，这老师当不稳。
3. 让他一次就学会。学不会才有下一回。

## 七 · 试探边界

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：约会 42.0% 衍生

**骨架**｜他想试试自己到底能走多远，就往前挪了一步。

#### 节拍链

站得近一点 → 没被躲开 → 帮拿包 → 问一句私人的 → 送回家 → 碰一下手 → 有一次她退开了 → 隔很久再试

#### 时间轴

以“次”为单位慢慢磨，一次只推进一寸。从站着不动到能碰一下手，中间隔了好几个月；每一次试探之间隔多久，就是他给自己留的安全距离。她退开的那一次是大事，之后他隔了很久才敢再试，那段时间拖得越长，越说明他是真把她的底线当回事。

#### 这条是这一族的真正核心

关系确立靠的是一连串小的越界被默许，一次表白完成不了。

| 他的试探 | 她的默许方式 | 累积效果 |
|---|---|---|
| 站得近一点 | 没退开 | 她没躲，距离就拉近了 |
| 帮她拿包 | 给了 | 她接了这个好 |
| 问一句私人的事 | 答了 | 话匣子开了一条缝 |
| 送她回家 | 让他送了 | 愿意多待一会儿 |
| 碰一下手 | 没抽开 | 身体这关过了 |

每一次「没有拒绝」都是一次授权。 写这一族的关键是让读者看见授权在累积，而不是等一句「我们在一起吧」。

#### 可用细节

| 类 | 内容 |
|---|---|
| 试探的形态 | 越问越细、越说越死，自己都收不回来 |
| 他的自我保护 | 每次都会给自己留条后路，能退就退 |
| 她的信号 | 不挑明、不拦着、也不往前凑 |
| 失败的那次 | 有一回她躲开了 · 他马上缩回去 · 隔了好久才敢再试 |

「有一次她退开了」是必须写的。全部成功的试探等于没有试探。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她知不知道 | 一直知道，在等他自己走完 | 后知后觉 |
| 速度 | 快 | 慢到旁人都急了 |
| 有没有退回 | 一路向前 | 中间退过一次 |
| 谁先说破 | 她 | 他 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他这回又往前挪了点 | 这次她会不会躲开 |
| 内心 | 我要不要拉他一把 | 能走到哪一步 |
| 好的处理 | 他缩回去那回，她没笑话他 | 他退回去以后，没闹别扭 |
| 写崩 | 写成她逗着玩、试来试去 | 写成他一个劲往前顶 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 逾矩的每一小步／越礼一分／她没斥责就是准了 |
| 修仙 | 神识每次多探一寸／她没有屏蔽 |
| 星际 | 每次多申请一级权限／她批了 |

古代版的「她没斥责就是准了」把这条讲到了极致：在有明确规矩的世界里，不惩罚就是许可。

#### 写崩的三种方式

1. 让每次试探都成功。
   得有一次失败。

2. 写成套路化的攻略流程。
   他是在冒险，不是在闯关。

3. 用一次表白替代整个过程。
   那正是这一条要避免的。

## 八 · 他先动心

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：约会 42.0% ＋ 初见 38.0%

**骨架**｜他已经陷进去了，她还跟没事人一样。圈里说的暗恋期、单箭头，说的就是这段。

#### 节拍链

意识到 → 开始留意她的一切 → 难受 → 藏不住 → 第三人点破或她自己看懂 → 她做决定

#### 时间轴

陷落那天是具体的，暴露却是慢慢漏出来的。她意识到的时候很短，就是某个普通瞬间，她低头签字的侧影。之后瞒了几个月，破绽越攒越多：视线停太久、记的细节太细。往往旁边人先看出来，她自己还蒙着。旁观者清，这条就这样。

#### 时间差是这条的全部

GB 的开局有一个高频结构：他先，她后。 而这段时间差里，他是一个人在承担全部的重量。

| 阶段 | 他 | 她 |
|---|---|---|
| 一 | 意识到了 | 完全不知道 |
| 二 | 开始注意她的一切 | 觉得他最近挺勤快 |
| 三 | 开始难受 | 察觉到一点异常 |
| 四 | 藏不住了 | 开始想这件事 |
| 五 | — | 做出决定 |

第四阶段到第五阶段之间那段空白，是这条最疼的地方。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的表现 | 她说过的话全记得 · 为了她改了自己的作息 · 手机里存着她的照片 ✓ |
| 破绽 | 别人一提她他就绷不住 · 他知道的太多了，不该知道的都知道 |
| 她的迟钝 | 他这么上心，她还当人家是同事／朋友 |
| 第三人 | 旁边总有人先看明白 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时间差 | 几周 | 几年 |
| 他说不说 | 忍着 | 忍不住了 |
| 她的发现方式 | 别人点破 | 自己突然看懂了某个细节 |
| 结果 | 接受 | 她需要时间 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她某天忽然想明白了一件事 | 他每天盘算这话能不能开口 |
| 内心 | 他到底从哪天开始的 | 一开口就全完了 |
| 好的处理 | 她回头把旧事又翻出来看了一遍 | 他没拿付出当筹码 |
| 写崩 | 写成她傻得不像话 | 写成他光吃苦不说 |

「他没有用付出施压」是这条的红线。 一旦他开始暗示「我为你做了这么多」，读者会立刻站到她那边。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她每次路过他都记着时辰／闷头干了三年没吭声 |
| 修仙 | 他替她挡的劫她压根不知道／一等就是一百年 |
| 星际 | 他特意调班就为跟她一趟船／航线记录里全是他的痕迹 |

#### 写崩的三种方式

1. 让她迟钝到不合理。 她可以没在想这件事，不能是傻。
2. 让他默默付出并等着回报。 那是道德绑架，不是喜欢。
3. 时间差拉得太长。 几年还行，十年得给个理由。

## 九 · 她先动心

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：约会 42.0%（女方向少见）

**骨架**｜她在意了。而她第一反应是，把这事儿赶紧了结掉。

#### 节拍链

察觉自己在意 → 分析它 → 克制（见面变少）→ 一件小事破防 → 想清楚 → 一句话说完

#### 时间轴

从发现到处理完，她给自己排了个时间表。第一周先搞清楚这是什么情况、怎么来的，第二周开始克制，见面次数减半，结果第三周就崩了，崩在一件完全没想到的小事上。想明白其实就花了一晚上，说出口也就一句话：她的钟前面拖拖拉拉，后面利利索索，跟她做事一个样。

#### 与上一条的对称与不对称

| | 他先动心 | 她先动心 |
|---|---|---|
| 第一反应 | 藏着不说 | 心里琢磨 |
| 处理方式 | 硬扛着 | 想清楚再定 |
| 表现 | 献殷勤变勤 | 动作变少（她憋着） |
| 破绽 | 啥都打听 | 突然对某件事特别上心 |
| 说破的方式 | 憋不住 | 想明白了直接摊牌 |

她的破绽是「变少」不是「变多」，这一点与他完全相反，也是这条最容易写崩的地方。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的克制 | 少见面 · 说话变客气 · 把他调远点 · 自己找借口 |
| 真实的迹象 | 她记得他几点睡 · 她帮他挡过一回事，没吭声 |
| 转折 | 出了件小事，她发现自己没法撒手不管 |
| 她的处理 | 想明白 → 摊开说 → 不给自己留后路 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的处理 | 立刻确认 | 先推开（更常见） |
| 推开的方式 | 冷淡 | 调走／断联 |
| 他的反应 | 不明白发生了什么 | 他猜到了 |
| 收场 | 她回来找他 | 他去找她 |

「先推开」这一端要小心：推开必须有她自己的理由（身份、责任、怕伤到他），不能只是别扭。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己瞎操心，管了件不用管的事 | 她这周怎么一直没找我 |
| 内心 | 这事不对 | 我是不是哪惹她不高兴了 |
| 好的处理 | 她想通了，一句话把话说透 | 他晾着也没走，没急着翻脸 |
| 写崩 | 写她磨磨唧唧闹别扭闹十来回 | 写他越想越慌，整个人垮掉 |

「一句话说完」是四爱女角色最好的表白方式。 想清楚了就说，不铺垫、不试探、不给自己留退路。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她把他调离身边／却又打听他的近况 |
| 修仙 | 她断了传讯／但护山大阵留着他的权限 |
| 星际 | 她把他调去另一艘舰／航线还是挨着 |

三个换皮共享同一个结构：表面切断，实际留门。

#### 写崩的三种方式

1. 让她纠结太久。 她的特点是干脆，纠结十章人设就崩了。
2. 让她推开且不给理由。 理由必须站得住脚。
3. 让她表白得很含蓄。 含蓄是他的风格，不是她的。

## 十 · 没有表白

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：表白 12.0%（全族最低）

**骨架**｜关系确立了，但没有人说过那句话。

#### 节拍链

试探的累积 → 钥匙给了 → 「我们」说出口 → 别人默认 → 谁都没宣布 → 多年后答不上「哪天在一起的」

#### 时间轴

没有起点日，只有一串里程碑。钥匙交出去那天、「我们」第一次说出口那天、外人开始默认那天，单个拎出来都不算数，串起来就是确定关系。多年后有人问「哪天在一起的」，俩人各说一个日子，还对不上，这分歧本身就是答案。

#### 为什么这一条要单独写

「表白」在语料里只有 12%，是这一族最低的一项。这是结构特征，不是数据问题：

GB 的关系确立更常靠一连串的默认，而不是一次宣告。

原因不难理解。表白是一个平权动作：我把我的感情交给你，你来决定。而 GB 的关系里，位置从一开始就不对称——他不觉得自己有资格发起，她不觉得这件事需要仪式。

于是关系就在没有任何人宣布的情况下成立了。

#### 关系已经确立的六个信号

不用一句台词，用这些：

| 信号 | 说明 |
|---|---|
| 他有她家的钥匙 ✓ | 空间 |
| 她的备注名改了 | 身份 |
| 他不再说「我走了」而说「我回来」 | 归属 |
| 别人默认他们是一起的，两人都没否认 | 公开 |
| 他开始拒绝别人的邀约且不解释 | 排他 |
| 她安排事情时自动把他算进去 | 未来 |

最后一行最重。 她说「下个月我们……」的那一刻，关系就成立了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 确立的时刻 | 一般没啥特别的：一块儿买个菜、他顺手接过她的包、她嘴里蹦出个「我们」 |
| 事后追认 | 后来有人问「你俩啥时候好上的」，俩人都说不上来 |
| 缺失的仪式 | 他偶尔会盼着有个准话 |
| 补上 | 过了很久她冷不丁说了 · 要么就一直没提 |

「有人问『你们什么时候在一起的』，两人答不上来」是这条最好的一场戏。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 有没有补上 | 后来她提了 | 一直没动静 |
| 他介不介意 | 不介意 | 心里介意，嘴上不说 |
| 谁先用「我们」 | 她 | 他（他会先试着用一回） |
| 外人的确认 | 别人先点破 | 一直没人吭声 |

「他介意但不说」这情绪，能直接接上 [04-委屈与破防 · 我是不是不够好](04-委屈与破防.md#九--我是不是不够好)：当时没名没分，他嘴上不吭声，心里记着呢，早晚有一天得炸。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她某天发现自己说了「我们」 | 他数得清她用过几次「我们」 |
| 内心 | 这算是在一起了吧 | 我算什么 |
| 好的处理 | 她在某个平常时刻把话挑明了 | 他没去要那个名分 |
| 写崩 | 写成她躲着不接话 | 写成他整卷都在瞎琢磨 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 没名分却住进正院／族谱上没他／她带他赴宴，就是明摆着的事 |
| 修仙 | 没结契却同住一个洞府／她的护山阵认他 |
| 星际 | 没登记但最高权限分他一份 |

古代版最狠：名分在礼制社会里是实体的，「住在正院但族谱上没有他」这个状态可以撑起整卷冲突。

#### 写崩的三种方式

1. 补一场迟到的盛大表白。 那会把前面憋的所有克制一次全兑现掉。
2. 让他完全不在意名分。 他可以不要，但他心里得想过这事。
3. 让确立的时刻很隆重。 但场面越平常越好。
