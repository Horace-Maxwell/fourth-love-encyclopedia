# 初遇与确立

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测。节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族收的是两个人从第一眼走到确定关系的那些场面：要联系方式、第一次约、改口、试探、谁先动心，还有没表白就在一起的。谁上谁下，开头并没有定，是在这几场戏里一点点谈出来的。

## 那个前提怎么来的

关系定下来以后的桥段，比如等门、撒娇、吃醋，都默认了一件事：她在上，他在下，两个人都认。

这件事是怎么定下来的，就写在这一族里。

GB 的关系一开头，最难的是男方得先接受一个平时没人愿意待的位置。他心里怎么转过这个弯，要在几场戏里演出来，不能让角色自己站出来讲道理。

| 节拍族 | 作品数 | 占比 |

| 约会 | 1,250 | 43.2% |

「表白」只占 12.9%，在这一族里垫底。这跟类型本身有关：GB 的关系多半是一连串默认下来的，往往没人正式开口。见第十条。

## 一 · 第一眼

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：初见 39.9%

**骨架**｜她先看见他。她这一眼怎么看，两人的关系就交代清楚了。

#### 节拍链

她注意到他 → 打量（从哪儿开始看）→ 他察觉被看 → 他的反应 → 她移开视线（或者没有）

#### 时间轴

跟着她的视线走：侧脸、手、整个人，每处停半秒，顺序基本不变。他第一眼就察觉，算敏锐，到最后一眼才发觉，是迟钝。哪种都可爱。

#### 视线的语法

这条写的是谁在看谁。传统言情里默认男的看女的，这里换成她看他，一换过来，每个细节的意思都跟着变了。

| 观察点 | 读作 |
|---|---|
| 她的视线从哪儿开始 | 看脸是喜欢，看手是打量，看肩背是掂量 |
| 看了多久 | 超过三秒就不是随便看看了 |
| 他察觉之后 | 躲开是还没想好，迎上来是心里有底 |
| 谁先移开 | 先移开的人先露了怯 |
| 她移开之后还回头 | 说明她是真上心了 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 面试 · 饭局 · 校门口 · 被人介绍认识 · 他正忙，她在边上看着 |
| 她的动作 | 把人从头到脚看了一遍 · 眼神在某处停住 · 拿指头敲了下桌子 · 挑了下眉 |
| 他的反应 | 把脸转开 · 身子绷直 · 耳朵先红 · 手没地方搁 |
| 环境 | 人堆里隔着段距离 · 隔了层玻璃 · 背着光 · 他没瞅见她，她倒把他看清楚了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先看见 | 她 | 他（但她后知后觉） |
| 场合 | 正式（面试、引荐） | 偶然（撞见、路过） |
| 他的状态 | 落魄 | 光鲜 |
| 结果 | 当场认识 | 各走各的，很久以后再遇 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己看入神了 | 有人盯着我，我不敢抬头确认 |
| 内心 | 挺有意思 | 她是不是在看我 |
| 好的处理 | 她没藏视线，也没找补 | 他没躲，但也没敢迎上去 |
| 写崩 | 写成第一眼就心动 | 写成他单方面想多了 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 隔着屏风／掀帘那一眼／她坐着他站着／堂上一望 |
| 修仙 | 神识扫过／剑光下抬眼／她在高处他在低处 |
| 星际 | 隔着舷窗／检阅时那一眼／她在指挥席上 |

古代版和星际版比现代版多一样便利：高低是制度排好的，她坐着也好、站在高处也好，都用不着交代为什么。

#### 写崩的三种方式

1. 从头到脚描外貌。 笔墨该花在他怎么偷看、怎么躲、怎么装作不经意上。
2. 漏写他一抬眼正撞上对方视线的那一下。 那一下没躲开。比写多少身份说明都管用。
3. 一见面就心跳加速。 所有言情都用过这招。再用就是白写。

#### 示例（本库自撰，可直接改写）

> 会议室的门开着，她从走廊经过，脚步慢了半拍。
> 里面那个人正弯腰在收拾投影线，衬衫的后背绷出一道线。
> 她看的不是脸。是他把线一圈一圈绕起来的手法，绕得很整齐，最后压在自己拇指下面。
> 他直起身，回头，正撞上。
> 他先别开了眼。半秒之后又抬起来，这次没有躲。
> 她笑了一下，走了。

## 二 · 要联系方式

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：要联系 19.0%

**骨架**｜谁先开的口，这局就定了输赢。

#### 节拍链

场合散了 → 她说「手机给我」，或他找了个借口开口 → 递与存 → 各自写下备注名 → 当晚第一条消息发不发

#### 时间轴

能开口的只有散场前那几分钟。人还没走完就要，显得急，等人走光了，也就没机会了。存号码那十几秒，两个人的眼睛都在那块屏幕上。当晚第一条消息发不发、几点发，也归这一条管：十点前发是客气，过了十二点才发，就是心里有事。

#### 四种要法与它们的含义

| 谁开口 | 怎么说 | 读作 |
|---|---|---|
| 她 · 直接 | 「手机给我」 | 命令。不问要不要 |
| 她 · 迂回 | 「以后有事找你」 | 给了台阶，也留了退路 |
| 他 · 直接 | 「能加个微信吗」 | 有胆，但把话递到人嘴边 |
| 他 · 迂回 | 找个由头非联系不可 | 最像他干的事 |

第一行最能代表这个类型。「手机给我」四个字，没问他，没解释，也没给他留拒绝的余地，他还是把手机递了过去。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓（谁拿着、谁在看）· 屏幕 ✓ · 备注名 · 二维码 |
| 她的动作 | 直接拿过来 · 自己输 · 存完顺手拨了一下，响的是她自己的 |
| 备注 | 她给他存了什么 · 他给她存了什么 · 俩备注差在哪儿 |
| 他的动作 | 解锁太快 · 存完之后一直没敢发消息 |

她存的是「小李」，他存的是「……」，两个备注差在哪儿，能埋很久。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁开口 | 她 | 他 |
| 理由 | 有（工作、还东西） | 没有 |
| 之后 | 当天就聊上了 | 他攥着号码三天没发 |
| 备注 | 全名 | 一个只有他自己懂的名字 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他递手机的速度 | 三天里删掉的十七条草稿 |
| 内心 | 存个号码而已 | 她会不会觉得我烦 |
| 好的处理 | 她当场拨一下，让他也有她的 | 他发的第一条最没营养 |
| 写崩 | 写成她高高在上地施舍 | 写成他卑微乞讨 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 递名帖／问府邸／她说「你可来寻我」／给了信物 |
| 修仙 | 留传讯符／她的一缕神识／宗门牌子 |
| 星际 | 私人频段／权限码／她把自己的编号报了 |

#### 写崩的三种方式

1. 一要就给，脸上什么都没有。 递手机那一下，总得有点动静。
2. 让他一个人来回琢磨。 三天不发消息是好的，拖到三章不发，读者就走了。
3. 漏写备注名。 两人怎么存对方，关系就写在那儿。

## 三 · 第一次约

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：约会 43.2%，约会＋做饭／夜深高频同现

**骨架**｜看三件事：时间地点谁定，钱谁掏，谁送谁回去。

#### 节拍链

谁开的口 → 定时间地点 → 他提前到 → 席间（点菜·话题·结账）→ 送 → 到楼下那几秒 → 「下次」说没说

#### 时间轴

一顿饭吃三个小时，其余时间都在垫场子，要紧的只有三个瞬间：点菜时谁拿主意，结账时谁先掏手机，散场时送不送。每个瞬间前后不过一分钟。有没有下一次，看告别前最后十秒里那句「下次」说没说。说早了显得急。不说就没有下次。

#### 三个决定权

| 项 | 她做 | 他做 | 含义 |
|---|---|---|---|
| 定时间地点 | 常态 | 他鼓起勇气才开口定 | 谁说了算 |
| 付钱 | 常态 | 他抢着付 | 经济姿态，见 [12 卷](12-工作与金钱.md) |
| 送回家 | 她送他 | 他送她 | 谁护着谁 |

三件都是她定。关系清楚，可没戏。让他抢到其中一件，戏就有了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的准备 | 提前踩了点 · 换了三次衣服 ✓ · 提前四十分钟到 · 手心 ✓ 出汗 |
| 她的从容 | 准时或略晚 · 点菜不问他 · 或者只问一句「你不吃什么」 |
| 破绽 | 他记得她随口说过的口味 · 她没注意到他记得 |
| 结账 | 他去洗手间时她已经付过了 · 他愣在那儿 |
| 送 | 谁上谁的车 · 到楼下之后那几秒 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁约的 | 她 | 他憋了好几天才开口 |
| 算不算约会 | 两人心里都门清 | 他当是，她没当 |
| 结账 | 她掏的钱 | 他抢着付了 |
| 结束 | 说了句下次见 | 谁都没提，但都知道还有下回 |
| 场合来路 | 认识后自然约出来的 | 相亲桌上认识、长辈牵的线：介绍人嘴里的和本人对不上，两人先联手把介绍人打发了，倒聊到了一块儿。开头就别扭，客套反倒省了 |

写「他当是，她没当」这一版，用不着安排谁做错事。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他提前很久到了 | 从出门到见面之间的两小时 |
| 内心 | 他今天有点不一样 | 这算不算约会 |
| 好的处理 | 她结账时没声张 | 他没因付不了钱自卑 |
| 写崩 | 她全程掌控，毫无破绽 | 他手足无措到滑稽 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 邀他游湖／灯会／她备了车马／他备了一样小东西 |
| 修仙 | 同去秘境／她带他御剑／看一场日出 |
| 星际 | 带他上舰／舷窗外的星图／配额里省下的一顿真食 |

#### 写崩的三种方式

1. 约会顺得一点毛病没有。 中间出点小岔子更好，下雨、订错位子、他一紧张说错话，都比从头顺到尾强。
2. 全程她说了算，他一点动静没有。 至少让他抢下一件事办成。
3. 约会一散就表白。 太早。见第十条。

## 四 · 谁送谁回家

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：约会 43.2% ＋ 接送 37.1%

**骨架**｜车停在楼下，火没熄，两个人谁都没动。

#### 节拍链

上车 → 路上（谁开车·谁选歌）→ 到楼下 → 熄不熄火 → 那几秒 → 谁先动 → 上去或离开

#### 时间轴

路上二十分钟。开头聊得松，越接近地方话越少。到了楼下，熄不熄火就是态度：不熄是「就送到这」，熄了是「不急」。接下来那几秒谁都不说话，可撑不过十秒，十秒一到，总有一个人先动。

#### 为什么单独成条

在 GB 里，送人回家这件事，谁护着谁倒过来了。

传统脚本里都是男的送女的，理由是“安全”。这里换成她送他，安全就说不通了。她送他，要么是想多待一会儿，要么就是她乐意。

所以这一送找不到别的借口，就是她想送。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 车 ✓ · 安全带 ✓ · 火没灭 · 楼道灯 ✓ · 副驾 ✓ 上搁着他的东西 |
| 那几秒 | 谁先解安全带 · 谁先说「那我上去了」· 谁没动 |
| 他的拖延 | 手搭在门把上不拧 · 没话找话说了句 · 又坐回去 |
| 她的处理 | 等着 · 或者直接说「下车」 · 或者伸手替他解安全带 |

「伸手替他解安全带」，她的手伸进了他的地盘，他也没拦。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁送谁 | 她送他 | 他送她，一路送到门口 |
| 下不下车 | 他自己上去了 | 她也下了车 |
| 那几秒 | 什么都没发生 | 有一件小事发生了 |
| 天气 | 晴 | 下雨，他没伞，她有 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他手在门把上顿了一下 | 要不要请她上来坐坐 |
| 内心 | 他不想下车 | 这话说出口是不是太早了 |
| 好的处理 | 她没催，也没先动 | 他最后还是下车了 |
| 写崩 | 写成她硬拉人上来 | 写成他磨蹭个没完 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 送到府门／车驾停在巷口／她掀帘看他进门才走 |
| 修仙 | 送到山门／她的剑停在洞府外 |
| 星际 | 送到舱门／权限刷开了但他没进 |

#### 写崩的三种方式

1. 车里的戏写得太满。 这段得收着。
2. 跳过那几秒。 这几秒一秒都省不得。
3. 她硬把人留下。 这一步越了界，前面三条就白写了。

## 五 · 改口

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：改口 30.1%

**骨架**｜他换了个叫法。

#### 节拍链

旧称呼用了很久 → 一个触发点 → 卡在喉咙里 → 说出口（声音很小）→ 她应了一声 → 之后越叫越顺

#### 时间轴

旧称呼喊了几个月，新的在嘴里憋了几周，心里不知道过了多少遍。真开口那次，声音比平时低一半，喊完马上换话题，不敢让场面空下来。她应了一声。一秒钟的事，他前几周的纠结就都值了。之后那一周，他逮着机会就喊，像在补前面欠下的。这才喊顺了口。

#### 称谓的阶梯

在这个类型里，改口花的力气最少，透出的东西最多。称呼是叫给别人听的，一改就等于当众宣布。

| 阶 | 称呼 | 关系 |
|---|---|---|
| 0 | 全名 / 职衔 | 不熟，或者纯粹谈事 |
| 1 | 姓 + 姐 / 老师 | 敬着点，但还不近 |
| 2 | 名字 | 处熟了 |
| 3 | 姐 | 亲近，也认她说了算 |
| 4 | 昵称 / 叠字 | 自己人，私下才这么叫 |
| 5 | 只有他俩懂的那个 | 别人插不进来 |
| ↓ | 连名带姓 | **要翻脸了，出大事了** |

最后一行值得拎出来单用。 平时叫「姐」的人忽然连名带姓地叫，读者马上明白出事了，一个字都不用解释。

#### 可用细节

| 类 | 内容 |
|---|---|
| 触发 | 她提的要求 · 别人这么叫他也跟着叫 · 脑子一热说漏嘴 · 喝多了 |
| 第一次改口 | 话到嘴边又咽回去 · 声音发虚 · 说完不敢瞅她 |
| 她的反应 | 「嗯」（最省事）· 装没听见，逼他再喊一遍 · 乐了 |
| 场合差 | 俩人时这么喊，有外人在就换 · 哪天当着人面喊岔了 |

「哪天当着人面喊岔了」能炸一下，可只能炸一次。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提的 | 她要求 | 他自己改的 |
| 方向 | 升级（更亲密） | 降级，连名带姓，出事了 |
| 场合 | 私下 | 当众 |
| 她的态度 | 明确接受 | 装作没注意（他会更慌） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听见那两个字，手上的动作停了一下 | 说出口之前在心里练了很多遍 |
| 内心 | 他改口了 | 她会不会觉得我僭越 |
| 好的处理 | 她只应了一声，什么都没说 | 他说完就转开话题 |
| 写崩 | 写成她纠正他叫法的教学戏 | 写成他刻意讨好 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 从「主君」到封号到闺名／当众喊名字算越界／她赏他叫她的字 |
| 修仙 | 从「师尊」到道号到本名／结契之后怎么叫 |
| 星际 | 从军衔到姓到名／私下频道里怎么喊 |

古代版能写的东西最多。那时候称呼是规矩，乱叫不得，改了口就是身份变了。见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。

#### 写崩的三种方式

1. 让他头一回就改得顺顺当当。 读者要看的是他卡壳、声音小、被追问「你说什么」。
2. 只写升级，不写降级。 连名带姓那一版用处更大。
3. 花大段解释这个称呼意味着什么。 留给读者自己听。

## 六 · 她教他

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：教导 14.5%，教导＋初见高频同现

**骨架**｜她会的他不会，教着教着，两人谁高谁低也就自然摆好了。

#### 节拍链

起因（他不会）→ 她说「我教你」→ 手把手 → 他学不会或装学不会 → 她纠正 → 「行了」→ 他还想再练一次

#### 时间轴

这门课按「次」算，进度故意走得弯弯绕绕。第一次他是真不会，到第三次已经会了。却还装不会。她第几次看穿的，是这段的暗线，两个人心里都清楚，教的本来就不是那门手艺。最后他赖着不走，说要「再练一次」。她准了。她看他一眼，说一句「行了」，这就算放他毕业。

#### 为什么这是最省力的定调法

这一招用不着谁出来宣布谁听谁的。教的和学的，本来就差一个位置，这位置正当，是临时的，也不伤自尊。

现代文里，「她凭什么在上」确实难办，教他一样东西算是最省事的办法。具体怎么设计，参考 [03-世界观设定/04-非女尊设定下的权力来源设计](../03-世界观设定/04-非女尊设定下的权力来源设计.md)。

#### 教什么

| 教的内容 | 好处 | 备注 |
|---|---|---|
| 开车 | 身体接触自然发生 | 副驾和驾驶座那点距离差 |
| 游泳 | 他只能信她 | 水里人使不上劲 |
| 工作技能 | 专业上说了算 | 最不伤面子的一种 |
| 打架 / 用枪 | 她比他强，明摆着 | 差得最大 |
| 乐器 / 书法 | 手把手，挨得最近 | 古代篇首选 |
| 做菜 | 反过来，他教她也行 | 见 [01 卷](01-日常照料.md) |

#### 可用细节

| 类 | 内容 |
|---|---|
| 姿势 | 她站他后头 · 手搭在他手上 · 她个子矮得踮脚凑近 |
| 她的语气 | 不哄也不夸，光挑毛病 · 「再来一遍」 |
| 他的状态 | 学不会就烦 · 会了以后老看她 · 有时候是装的学不会 |
| 结束 | 她来一句「行了」 · 他还想多练几回 |

「他故意学不会」，是想多待一会儿才拖着，这一点两个人都清楚。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他学得快慢 | 快（她有点意外） | 慢（真的慢） |
| 他装不装 | 认真学 | 装笨 |
| 她察觉没 | 没察觉 | 察觉了，配合他 |
| 后来 | 他超过她了 | 他一直没学会（也可以） |

「他超过她了」可以接 [12 卷的成长线](12-工作与金钱.md)：学生超过了老师，关系就得重新谈。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他今天学得特别慢 | 她的手覆上来的那一下 |
| 内心 | 教一遍就会的人，今天怎么要三遍 | 再学不会一次 |
| 好的处理 | 她配合他装笨，不说破 | 他没有真的滥用这个 |
| 写崩 | 写成师生调情套路 | 写成撒娇工具 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 教他握笔／教他骑射／她的手覆在他手背上 |
| 修仙 | 授功法／引气入体／她的灵力在他经脉里走一遍 |
| 星际 | 教他操舰／模拟舱／她在他身后看仪表 |

#### 写崩的三种方式

1. 教的东西太玄。 得是能上手练的。
2. 她只挑错，从不夸。 这样的老师当不稳。
3. 让他一学就会。 学不会，才有下一回课。

## 七 · 试探边界

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：约会 43.2% 衍生

**骨架**｜他往前挪一步，想看看自己到底能走多远。

#### 节拍链

站得近一点 → 没被躲开 → 帮拿包 → 问一句私人的 → 送回家 → 碰一下手 → 有一次她退开了 → 隔很久再试

#### 时间轴

每次只往前一寸。从站着不动到能碰一下她的手，中间隔了好几个月。她退开的那一回是件大事，他过了很久才敢再试。两次试探隔多久，就是他给自己留的余地，隔得越长，越见得他真把她的底线放在心上。

#### 这条是这一族的真正核心

关系能定下来，靠一次次小越界被默许。一次表白办不到。

| 他的试探 | 她的默许方式 | 累积效果 |
|---|---|---|
| 站得近一点 | 没退开 | 她没躲，距离就拉近了 |
| 帮她拿包 | 给了 | 她接了这个好 |
| 问一句私人的事 | 答了 | 话匣子开了一条缝 |
| 送她回家 | 让他送了 | 愿意多待一会儿 |
| 碰一下手 | 没抽开 | 身体这关过了 |

她每「没有拒绝」一次，就等于点了一次头。写这一族，要让读者看着这些点头一次次攒起来，别干等那句「我们在一起吧」。

#### 可用细节

| 类 | 内容 |
|---|---|
| 试探的形态 | 越问越细、越说越死，自己都收不回来 |
| 他的自我保护 | 每次都会给自己留条后路，能退就退 |
| 她的信号 | 不挑明、不拦着、也不往前凑 |
| 失败的那次 | 有一回她躲开了 · 他马上缩回去 · 隔了好久才敢再试 |

「有一次她退开了」这一笔必须写。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她知不知道 | 一直知道，在等他自己走完 | 后知后觉 |
| 速度 | 快 | 慢到旁人都急了 |
| 有没有退回 | 一路向前 | 中间退过一次 |
| 谁先说破 | 她 | 他 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他这回又往前挪了点 | 这次她会不会躲开 |
| 内心 | 我要不要拉他一把 | 能走到哪一步 |
| 好的处理 | 他缩回去那回，她没笑话他 | 他退回去以后，没闹别扭 |
| 写崩 | 写成她逗着玩、试来试去 | 写成他一个劲往前顶 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 逾矩的每一小步／越礼一分／她没斥责就是准了 |
| 修仙 | 神识每次多探一寸／她没有屏蔽 |
| 星际 | 每次多申请一级权限／她批了 |

古代版里有一句「她没斥责就是准了」。规矩写得明明白白的世界，不罚就等于允许。

#### 写崩的三种方式

1. 每一回试探都成了。 至少要败一回。

2. 写成按套路走的攻略。 他是在冒险。

3. 一次表白就把这一路都省了。 这正是要躲开的写法。

## 八 · 他先动心

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：约会 43.2% ＋ 初见 39.9%

**骨架**｜他已经陷进去，她还像个没事人。圈里叫暗恋期、单箭头的，就是这一段。

#### 节拍链

意识到 → 开始留意她的一切 → 难受 → 藏不住 → 第三人点破或她自己看懂 → 她做决定

#### 时间轴

暴露是一点点漏出来的。陷落是具体的某一天，可她自己往往蒙在鼓里。旁边的人都看出来了，她还低着头签字。侧影落在纸上，这才忽然意识到哪里不对。视线停得太久，细节记得太细，破绽攒了几个月。越攒越多。

#### 时间差是这条的全部

GB 开局常常是他先动心。她在后头。中间这段时间差，只有他一个人扛。

| 阶段 | 他 | 她 |
|---|---|---|
| 一 | 意识到了 | 完全不知道 |
| 二 | 开始注意她的一切 | 觉得他最近挺勤快 |
| 三 | 开始难受 | 察觉到一点异常 |
| 四 | 藏不住了 | 开始想这件事 |
| 五 | — | 做出决定 |

最疼的是第四阶段和第五阶段中间那段空白。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的表现 | 她说过的话全记得 · 为了她改了自己的作息 · 手机里存着她的照片 ✓ |
| 破绽 | 别人一提她他就绷不住 · 他知道的太多了，不该知道的都知道 |
| 她的迟钝 | 他这么上心，她还当人家是同事／朋友 |
| 第三人 | 旁边总有人先看明白 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时间差 | 几周 | 几年 |
| 他说不说 | 忍着 | 忍不住了 |
| 她的发现方式 | 别人点破 | 自己突然看懂了某个细节 |
| 结果 | 接受 | 她需要时间 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她某天忽然想明白了一件事 | 他每天盘算这话能不能开口 |
| 内心 | 他到底从哪天开始的 | 一开口就全完了 |
| 好的处理 | 她回头把旧事又翻出来看了一遍 | 他没拿付出当筹码 |
| 写崩 | 写成她傻得不像话 | 写成他光吃苦不说 |

「他没拿付出当筹码」这条线不能破。他只要开始暗示「我为你做了这么多」，读者马上就站到她那边去了。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她每次路过他都记着时辰／闷头干了三年没吭声 |
| 修仙 | 他替她挡的劫她压根不知道／一等就是一百年 |
| 星际 | 他特意调班就为跟她一趟船／航线记录里全是他的痕迹 |

#### 写崩的三种方式

1. 让她迟钝得说不过去。 她可以没往这上头想，但不能傻。
2. 他闷头付出，心里等着回报。 这就成了道德绑架。
3. 时间差拖得太长。 几年可以。拖到十年就得给个说法。

## 九 · 她先动心

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：约会 43.2%（女方向少见）

**骨架**｜她发觉自己在意了，第一念头就是赶紧了结。

#### 节拍链

察觉自己在意 → 分析它 → 克制（见面变少）→ 一件小事破防 → 想清楚 → 一句话说完

#### 时间轴

她从发现到处理完，是给自己排了日程的。第一周弄清楚这是怎么回事、从哪儿来的。第二周开始克制。见面少一半。结果第三周就破了功，破在一件根本没想到的小事上。想明白只用了一个晚上，说出口也就一句话。前头拖拖拉拉，后头干净利落，跟她做事一个路数。

#### 与上一条的对称与不对称

| | 他先动心 | 她先动心 |
|---|---|---|
| 第一反应 | 藏着不说 | 心里琢磨 |
| 处理方式 | 硬扛着 | 想清楚再定 |
| 表现 | 献殷勤变勤 | 动作变少，她憋着 |
| 破绽 | 啥都打听 | 突然对某件事特别上心 |
| 说破的方式 | 憋不住 | 想明白了直接摊牌 |

她露馅的方式是动作变少，正好跟他反着来，这里也最容易写崩。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的克制 | 少见面 · 说话变客气 · 把他调远点 · 自己找借口 |
| 真实的迹象 | 她记得他几点睡 · 她帮他挡过一回事，没吭声 |
| 转折 | 出了件小事，她发现自己没法撒手不管 |
| 她的处理 | 想明白 → 摊开说 → 不给自己留后路 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的处理 | 立刻确认 | 先推开（更常见） |
| 推开的方式 | 冷淡 | 调走／断联 |
| 他的反应 | 不明白发生了什么 | 他猜到了 |
| 收场 | 她回来找他 | 他去找她 |

写「先推开」这一端，她推开必须有自己的理由，身份、责任、怕伤着他都行，光是别扭不够。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己瞎操心，管了件不用管的事 | 她这周怎么一直没找我 |
| 内心 | 这事不对 | 我是不是哪惹她不高兴了 |
| 好的处理 | 她想通了，一句话把话说透 | 他晾着也没走，没急着翻脸 |
| 写崩 | 写她磨磨唧唧闹别扭闹十来回 | 写他越想越慌，整个人垮掉 |

「一句话说完」：想清楚就开口，不铺垫，不试探，不给自己留后路。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她把他调离身边／却又打听他的近况 |
| 修仙 | 她断了传讯／但护山大阵留着他的权限 |
| 星际 | 她把他调去另一艘舰／航线还是挨着 |

三种换皮都是明面上断，暗里留门。

#### 写崩的三种方式

1. 让她纠结太久。 她是干脆的人。纠结上十章，人设就塌了。
2. 让她推开，又不给理由。 得有理由。而且必须站得住。
3. 让她表白得含含蓄蓄。 含蓄是他的路数。

## 十 · 没有表白

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：表白 12.9%（全族最低）

**骨架**｜关系已经定了，那句话却谁也没说过。

#### 节拍链

试探的累积 → 钥匙给了 → 「我们」说出口 → 别人默认 → 谁都没宣布 → 多年后答不上「哪天在一起的」

#### 时间轴

问他们「哪天在一起的」，两个人各报一个日子。还对不上。外人开始默认的那天，钥匙交出去的那天，「我们」第一次出口的那天，单拎哪一个都不算数。说不出来，是因为本来就没有那一天，只有一串节点，连起来才是在一起了。

#### 为什么这一条要单独写

语料里写「表白」的只有 12.9%，这一族里数它最少。

GB 的关系多半是一点点默认下来的，很少有人一次说破。

原因不难想。表白预设两人平起平坐：我把心意交给你，由你来定。GB 的关系从一开始就一高一低，他觉得自己没资格先开口，她又觉得这事用不着什么仪式。

所以谁也没宣布，关系就这么成了。

#### 关系已经确立的六个信号

不用一句台词，用这些：

| 信号 | 说明 |
|---|---|
| 他有她家的钥匙 ✓ | 空间 |
| 她的备注名改了 | 身份 |
| 他不再说「我走了」而说「我回来」 | 归属 |
| 别人默认他们是一起的，两人都没否认 | 公开 |
| 他开始拒绝别人的邀约且不解释 | 排他 |
| 她安排事情时自动把他算进去 | 未来 |

她说出「下个月我们……」那一刻，关系就算成了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 确立的时刻 | 一般没啥特别的：一块儿买个菜、他顺手接过她的包、她嘴里蹦出个「我们」 |
| 事后追认 | 后来有人问「你俩啥时候好上的」，俩人都说不上来 |
| 缺失的仪式 | 他偶尔会盼着有个准话 |
| 补上 | 过了很久她冷不丁说了 · 要么就一直没提 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 有没有补上 | 后来她提了 | 一直没动静 |
| 他介不介意 | 不介意 | 心里介意，嘴上不说 |
| 谁先用「我们」 | 她 | 他会先试着用一回 |
| 外人的确认 | 别人先点破 | 一直没人吭声 |

「心里介意，嘴上不说」这情绪，能直接接上 [04-委屈与破防 · 我是不是不够好](04-委屈与破防.md#九--我是不是不够好)。当时没名没分。他嘴上不吭声，心里记着呢。早晚有一天得炸。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她某天发现自己说了「我们」 | 他数得清她用过几次「我们」 |
| 内心 | 这算是在一起了吧 | 我算什么 |
| 好的处理 | 她在某个平常时刻把话挑明 | 他没去要那个名分 |
| 写崩 | 写成她躲着不接话 | 写成他整卷都在瞎琢磨 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 没名分却住进正院／族谱上没他／她带他赴宴，就是明摆着的事 |
| 修仙 | 没结契却同住一个洞府／她的护山阵认他 |
| 星际 | 没登记但最高权限分他一份 |

古代版下手最重的是名分。讲礼制的地方，名分是实打实的。「住在正院但族谱上没有他」，单这一样，就够写满一整卷的冲突。

#### 写崩的三种方式

1. 最后补一场盛大的迟到表白。 憋了那么久，一下子全兑现，这条也就白写了。
2. 让他对名分毫不在意。 他可以不要，但得在心里掂量过。
3. 把确立那一刻写得隆重。 场面越家常越好。
