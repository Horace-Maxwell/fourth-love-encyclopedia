# 岁月与身后

> **分级** 分级见各条，分级上限 `T` ｜ 预警 ⚠️BE·死亡向（限第七至十条，预警置于条目分级行行首）｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**长线以一天为单位——把十年挂在一个具体的日子上。**

## 这一族补哪一段

[18-节令与天候](18-节令与天候.md) 的钟走到 [一年过去了](18-节令与天候.md#九--一年过去了) 为止，再往后没有刻度：第五年、第十年、退休、身后，整段空白。离世在语料里出现率 29.4%（13-07 实测），这个量级的题材，已有的落点没有一个写「彼此」：

| 已有落点 | 写的是 | 缺的是 |
|---|---|---|
| [13-家庭与亲属 · 送走它](13-家庭与亲属.md#九--送走它) | 宠物走了 | 走的是人 |
| [13-家庭与亲属 · 亲人离世](13-家庭与亲属.md#十--亲人离世) | 第三方走了，两个人怎么撑 | 走的是彼此 |
| [21-世界设定专属 · 寿元差](21-世界设定专属.md#五--寿元差) | 设定层的算术（八百年对六十年） | 现实层的过法 |

这一族十条按时间排：一至六条是岁月（第五年到病床），七至十条是身后。三十年摊开写谁都写不动，所以每条只选一天——第五年的一个晚上、立遗嘱的一个下午、祭日的一个上午。年份挂在那一天的物件上（工牌、砂锅、闹钟），日子立住了，年份自动到账。

后四条统一带 ⚠️BE（Bad Ending，悲剧收束）·死亡向，预警置于条目分级行行首；停在第六条，就是 HE（Happy Ending，圆满收束）侧的完整弧线。后四条动笔前先答一道题：**留下的人是谁。** 留下的人是谁，戏就是谁的；走的人只以物件和预案出场，不回头说话。

可用细节表沿用 13-07 的高频物件标记 ✓；身后段没有逐场提升度实测，一律不标数字。

## 一 · 第五年

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：同居 21.1% ＋ 夜深 37.5%（第五年段无独立族）

**骨架**｜激情退潮后的第一站。没话说有两种：一种要救，一种要守。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 一个普通的晚上，没有事件（这天什么都不是，选它就因为它什么都不是） |
| 2 | 晚饭桌上安静，他察觉这种安静已经持续一阵了 |
| 3 | 试探：他说了一句没头没尾的话（楼下那只猫换了睡觉的地方） |
| 4 | 她接住了，或者只应了一声 |
| 5 | 各自做各自的事，客厅里两盏灯各亮各的 |
| 6 | 睡前她也说了句没头没尾的（明天降温） |
| 7 | 关灯。两个人都没觉得这一晚缺了什么，或者有一个人觉得缺了 |

第 3、4 拍是测量仪：没头没尾的话有人应，是不必说话；说出去没人捡，是没话找话。

#### 可用细节

| 类 | 内容 |
|---|---|
| 沉默的判据 | 没头没尾的话随时说得出口 / 要想一下才找得到题目 · 背对着也知道对方在哪 / 各自刷手机像合租 · 路过顺手碰一下 / 碰之前先想了一下 · 谁先睡都行 / 等对方先睡 |
| 道具 | 手机 ✓（各自在跟谁说话） · 沙发两头各自的凹陷 · 一副耳机他只戴一只 · 各亮各的两盏灯 |
| 声音 | 洗碗的水声 · 他哼歌哼半句停了，没人问 · 冰箱夜里的嗡声 |
| 动作 | 路过顺手把她的杯子续上 · 她翻页时把脚搭到他腿上 · 换台不用商量 |
| 台词类型 | 没头没尾的观察句（猫、天气、楼下的新店），这种话只对同住五年的人说得出口 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 安静的质地 | 不必说话 | 真的没话了（转 [三 · 痒](#三--痒)） |
| 谁先察觉退潮 | 她 | 他 |
| 有没有慌 | 都不慌 | 有一个人半夜睡不着 |
| 处理 | 不处理，让它待着 | 有人提议出去走走（老办法，管用） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己在家不再需要任何姿态 | 他那句没头没尾的话，她接住了 |
| 内心 | 从前怕冷场，现在冷场是家具的一部分 | 说话之前不用打草稿了 |
| 好的处理 | 她把「今晚很好」这类总结咽回去 | 他哼歌哼半句停了，她把下半句哼完 |
| 写崩 | 写成她开始怀念心动 | 写成他惶恐地找话 |

#### 写崩的三种方式

1. 把退潮写成危机的前奏。 退潮是水位正常化，后面不欠一场风暴。
2. 用甜话把安静填满。 第五年的甜在动作里，台词一多就假。
3. 跳过去。 「五年后」三个字一带而过，长线就断了；这一晚要写足写实。

#### 可串接

前接：[18-节令与天候 · 一年过去了](18-节令与天候.md#九--一年过去了)（同一技法，量程放大）
后接：[二 · 第十年的重述](#二--第十年的重述) · [三 · 痒](#三--痒)
对照：[17-同居与身体日常 · 两个人的作息](17-同居与身体日常.md#九--两个人的作息) · [36-亲密的完整结构](36-亲密的完整结构.md)（退潮后亲密的去处）

#### 示例（本库自撰，可直接改写）

> 洗碗的水声停了。他擦着手出来，客厅只开了她那盏灯。
> 「楼下那只猫，」他说，「搬到快递柜顶上睡了。」
> 「暖和。」她没抬头，翻了一页。
> 他坐到沙发另一头，捡起自己那本书。第五年了，猫的事有人接，晚上就不算安静。
> 十点半她先去洗漱，路过时把他滑下去的毯子拎起来，盖回他腿上。谁都没说晚安，晚安从第三年起就是多余的。

## 二 · 第十年的重述

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：节日 33.3%（周年夜）

**骨架**｜周年夜讲起当年，两个版本对不上，而且两个都是真的。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 第十年的周年夜，老地方或者在家 |
| 2 | 讲起初见（每年都讲，已经有固定台词） |
| 3 | 今年岔了：一个细节两人记得不一样（那天有没有下雨、谁先开口） |
| 4 | 各自坚持，笑着争 |
| 5 | 找证据，或者不找（照片翻到半路停下了） |
| 6 | 一方让了，或者两版并存 |
| 7 | 从此讲的是合并后的版本，谁也没宣布过 |

#### 记忆的合并整理

十年讲同一段往事，讲的次数早就超过了事件本身的长度，每讲一次修一点。对不上的细节不说明谁记错了，说明两个人当年站的位置不同：

| 对不上的点 | 她的版本 | 他的版本 |
|---|---|---|
| 谁先开口 | 他 | 她（他紧张到没意识到自己先说了话） |
| 天气 | 没下雨 | 下了（他等在外面，淋到了） |
| 她当时的样子 | 狼狈 | 好看 |
| 动心的时刻 | 第三次见面 | 第一眼 |

第三行是通例：他的版本里，她永远比她记得的自己好。争到这一行，就争不动了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 老照片 ✓ · 翻不到底的聊天记录 · 第一次约会那家店（还在不在） · 电影票根这类物证 |
| 争的方式 | 笑着争 · 拉第三人当裁判（闺蜜记得的是第三个版本） · 打赌 |
| 停下的位置 | 照片翻到某一张，两个人都不说话了 |
| 台词类型 | 「明明是……」开头 · 「好好好，按你说的」（不是认输，是收藏） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 对不上的量级 | 一个细节 | 一整段（谁追的谁） |
| 查证 | 翻出物证 | 故意不查 |
| 收法 | 采用他的版本 | 两版并存，每年轮流讲 |
| 底色 | 全程笑着 | 争到一半发现有一段她完全空白（她那年太忙了） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他版本里的她，比她记得的自己好 | 她记得的比他以为的多 |
| 内心 | 他把那天保存得比我仔细 | 原来她也留着这一段 |
| 好的处理 | 她让了，采用他的版本，理由没说出口 | 他只坚持那个对她有利的细节，别的都让 |
| 写崩 | 写成她记性差的梗 | 写成他委屈地翻旧账 |

#### 写崩的三种方式

1. 写成罗生门。 对不上是甜的，一较真就成了悬疑，情绪货币不对。
2. 判对错。 拿出决定性证据宣布谁赢，合并就不会发生了；证据也要模糊。
3. 大段闪回。 当年的事用今晚的对话转述；镜头一切回去，十年的距离感就没了。

#### 可串接

前接：[一 · 第五年](#一--第五年) · [11-初遇与确立 · 第一眼](11-初遇与确立.md#一--第一眼)（被重述的就是这一场）
后接：[27-年龄差与姐弟 · 十年后还差几岁](27-年龄差与姐弟.md#十--十年后还差几岁) · [07-馈赠与仪式 · 一个只属于他们的仪式](07-馈赠与仪式.md#十--一个只属于他们的仪式)

## 三 · 痒

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：无独立族（13-07 未单列倦怠）

**骨架**｜第七年上下，注意力开始漏。痒与出轨预备是两回事，先分清再动笔。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 他发现自己饭桌上看手机的时间超过了看她 |
| 2 | 自查，吓了一跳（什么时候开始的，查无起点） |
| 3 | 观察她：她也在走神（两个人漏的方向不同，谁也没漏向某个具体的人） |
| 4 | 忍着没说，别扭了几天 |
| 5 | 说破，用的是玩笑口吻（「我们是不是老夫老妻了」） |
| 6 | 一次小校准：换一家没去过的店，或者重走当年那条路 |
| 7 | 痒退了，退得和来的时候一样没有日期 |

#### 痒还是引信

倦怠必然通向危机，这个等式在语料里写滥了。判据摆出来，两回事一眼可分：

| 观察点 | 痒（这一条） | 引信（[34-NTR与出轨危机](34-NTR与出轨危机.md) 的领域） |
|---|---|---|
| 涣散的方向 | 四面八方，落不到人 | 有具体对象 |
| 能不能说 | 说出来就散了 | 说不出口，越藏越沉 |
| 对方在场时 | 走神，但人在 | 开始避免两人独处 |
| 处理成本 | 一顿新馆子 | 一整卷 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 走神的形态 | 手机 ✓ · 他答非所问被抓到 · 她把同一件事讲了第二遍，他才发现上次没听 |
| 自查的痕迹 | 他翻两人早年的聊天记录翻到凌晨 · 相册里今年的合照数量 |
| 说破的口吻 | 玩笑 · 半真半假 · 主语用「我们」，别用「你」 |
| 校准动作 | 新馆子 · 当年那条路 · 把每周某晚定成不带手机的晚饭 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先痒 | 他 | 她（少被写，写出来更疼也更真） |
| 说不说破 | 玩笑里说了 | 各自校准，谁都没提 |
| 校准之后 | 退了 | 退了又来，来了再校（常态） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己把他讲的事听漏了 | 他数了这个月的合照：三张，全是拍外卖 |
| 内心 | 走神吓不到她，瞒着才会 | 这不是不爱了，那这是什么 |
| 好的处理 | 她当晚就说了，口吻像聊天气 | 他提议去新馆子，没解释为什么 |
| 写崩 | 写成她开始审视这段关系 | 写成他愧疚到失眠 |

#### 写崩的三种方式

1. 把痒写成引信。 涣散一给对象，这条就改姓了；上表四行判据要全过。
2. 用大浪漫治疗。 求婚式的补救对付不了注意力问题，校准要小而日常。
3. 道德化。 走神没有过错方，一开审判庭，两个人都成了被告。

## 四 · 空巢

`G` ｜ 无预警 ｜ 全谱系（有孩设定） ｜ 语料频次：孩子 24.8%（离巢段无独立族）

**骨架**｜孩子走了，房子还回来两个人。独处要重新学，老手艺捡回来会生疏。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 送走那天（宿舍楼下/机场），仪式感做得很足 |
| 2 | 回程的车里没人说话，广播响着 |
| 3 | 第一顿两个人的饭，菜做了三人份（手改不过来） |
| 4 | 那间房的门，开着还是关上，两人默契地都不提 |
| 5 | 一周后发现：两个人单独吃饭没话了（这些年话都从孩子身上走） |
| 6 | 有一个人先迈步：一次约会式的出门，像多年前那样生疏 |
| 7 | 老规矩一件件回来，包括当年她立的和他讨的 |

#### 收复失地

带孩子的那些年，称呼和位置都让给了爹娘的角色：她管孩子，他管她和孩子，两个人互相叫「他妈」「他爸」。孩子一走，让出去的东西要一样样收回来。空巢戏别只写想孩子，写这一场收复：

| 收回来的 | 具体形态 |
|---|---|
| 称呼 | 从「他爸」改回名字，第一次叫出口两个人都停了一下 |
| 她的规矩 | 家规当年为孩子松了绑，现在她重新立起来，他配合得比当年快 |
| 他的撒娇 | 当着孩子忍了二十年，现在没观众了 |
| 时间 | 周末第一次完整属于两个人，大得不知道怎么花 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 三人份的菜量 · 那间房的门 · 家庭群（孩子头像置顶） · 冰箱上的课程表没人撕 |
| 动作 | 她把课程表撕下来，抚平，收进抽屉 · 他做饭前愣在米缸前（量米的手不知道抓几把） |
| 声音 | 房子忽然变大的那种静 · 群里孩子报平安的提示音，两个人同时看手机 |
| 台词类型 | 「想不想他」这句谁都不问；问的是「今晚吃什么」，两个人都听懂了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 空的程度 | 本地上学，周末回 | 出国，一年一面 |
| 谁更空 | 她（她自己也意外） | 他（预期内，他带得多） |
| 那间房 | 原样封存 | 慢慢变成两个人的新领地（书房/茶室） |
| 关系存量 | 底子厚，很快回温 | 这些年全靠孩子粘着，现在要重新追一遍 |

「重新追一遍」那一端可以把 [11-初遇与确立](11-初遇与确立.md) 整卷重跑一轮：人还是那两个人，追法全变了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现这些年她跟他说的话，一半是借孩子转达的 | 米缸前那一愣 |
| 内心 | 房子空了，她先清点的却是他 | 没了观众，撒娇差点忘了怎么起头 |
| 好的处理 | 她先改的口，叫回了他的名字 | 他把三人份吃完，第二天就改了量 |
| 写崩 | 写成她空虚抑郁 | 写成他黏成孩子的替身 |

#### 写崩的三种方式

1. 只写想孩子。 想孩子是背景音，主戏是两个人重新认领彼此。
2. 无缝衔接二人世界。 生疏要写够，多年的角色不会一顿饭就卸掉。
3. 把生疏写成危机。 生疏与感情无关，手艺放久了都这样，捡起来就好。

## 五 · 退休那天

`T` ｜ 无预警 ｜ 现代都市（古代致仕、修仙卸位同构） ｜ 语料频次：职场 33.9%（退休段无独立族）

**骨架**｜她交出工牌。权力没有退休，只是没了辖区；他的活是给它找一块新的。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 最后一天：交工牌、清工位，纸箱比想象的小 |
| 2 | 欢送会上她致辞，得体，零波动（他在台下看出来那是撑的） |
| 3 | 回家路上她说「以后天天做饭给你吃」，两人都笑了，都没当真 |
| 4 | 第二天六点半，闹钟没定，她照样醒了 |
| 5 | 一周内，家被管成了部门：冰箱有了库存表，他的作息被排进日程 |
| 6 | 摩擦一次（他的东西被「优化」了） |
| 7 | 他的安置：把一块真实领地正式移交给她 |
| 8 | 新秩序落成。六点半她还醒，醒来有事做 |

#### 权力惯性的家用安置

三十年的指挥系统不会因为一张离职证明关机。硬关（劝她歇着）等于告诉她这个家用不上她的长处。可用的安置法：

| 安置法 | 做法 | 效果 |
|---|---|---|
| 划辖区 | 把一件真实大事全权移交（家里的账、一次装修、老家的大事），亏了也认 | 权力有处可去 |
| 拜师 | 他把自己做了三十年的事（做饭/养花）摆出来请她入门，她从新兵做起 | 权力换向，她体验被管 |
| 立宪 | 两个人把家事分了界：她管战略，他管日常 | 摩擦有法可依 |

第二行藏着一个彩蛋：强势方在一件小事上心甘情愿当学徒，身份感松开的那一刻，比任何告白都亲。

#### 可用细节

| 类 | 内容 |

| 道具 | 工牌（上交那一下的手感） · 装了三十年的纸箱 · 六点半的生物钟 · 冰箱上的库存表 · 老花镜压着日程本 |
| 动作 | 她把他的调料罐按使用频率重排，他找不到盐 · 她平日白天第一次出现在菜市场，砍价砍赢了摊主 |
| 摩擦点 | 他的旧衣服被列入淘汰清单 · 他做菜的火候被现场指导 |
| 台词类型 | 她：「这个流程不对。」他：「这个家没有流程。」（说完两个人都笑了） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的落差 | 如释重负 | 夜里睡不着（白天看不出来） |

| 内心 | 我这双手空下来了 | 她的本事不能烂在家务里 |

#### 写崩的三种方式

1. 写成失落崩塌。 她的落差走细节（六点半、纸箱），一写成颓丧，人设三十年白建了。
2. 无缝衔接新生活。 第二天就跳广场舞，权力惯性这道题就没了。
3. 让他劝。 「歇着吧」「想开点」是把她的长处当病治；他的正确动作是移交，然后闭嘴。

**骨架**｜强势方倒下。她不会当病人，他要照顾一个不肯被照顾的人。

#### 节拍链

| 拍 | 内容 |

#### 与陪床条的反转

[09-分离与重逢 · 陪床](09-分离与重逢.md#四--陪床) 里躺着的是他，第五天他开始赶她回家，赶人是撒娇的余项。这里躺着的是她，赶人是认真的：每一个照顾动作都在提醒她控制权在流失。他的解法在第 6 拍——照顾做成申报制，决定权还她，体力活归他。

| 观察点 | 09-04 陪床（他躺） | 这一条（她躺） |
|---|---|---|
| 赶人 | 赶不动，也没想赶动 | 赶动了，她又失落 |
| 病房秩序 | 她把日常搬进来 | 她建立管理 |
| 转折 | 病人开始心疼陪的人 | 病人第一次交出签字权 |

| 她的病人风格 | 纠正护士的胶布贴法 · 把邻床的家属都指挥顺了 · 疼不按铃，忍到查房一并汇报 |
| 他的照顾语言 | 清单请她核 · 探视的人他排了班（她见谁、每人十分钟，规矩她定，他执行） · 她睡着后他才削水果 |
| 转折信号 | 她说「你决定吧」，说得很轻，他手里的单子重了一倍 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 病的量级 | 一场手术，能好 | 长期慢性，从此同行 |
| 她交权的度 | 只交了一支笔 | 连脾气都交了（他反而慌） |
| 探病的人面前 | 她坐直，撑全场 | 她第一次当众靠在他身上 |

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 病床视角的天花板，她头一回从这个角度看自己的家人 | 签字那一笔，他写得比结婚登记还慢 |
| 内心 | 原来被照顾这么难学 | 她赶我，我得走；她赶我，我也得回来 |
| 好的处理 | 她核清单时挑了个错，他高兴了一晚上（她还在） | 他不说加油不说没事，只汇报：今天的药、明天的检查 |
| 写崩 | 写成她秒变乖病人 | 写成他趁虚接管一切 |

#### 写崩的三种方式

1. 让她一病就乖。 强势方的病人课要一节节上，三天学会等于人设注销。
2. 往病危里写。 生死是另一层戏（第七条起）；这条要的是权力在病房里的换手。
3. 让他接管。 他多做一寸她就少一寸；申报制的分寸丢了，照顾就成了夺权。

## 七 · 遗嘱

`T` ｜ ⚠️BE·死亡向 ｜ 全谱系 ｜ 语料频次：离世 29.4%（前段）

**骨架**｜立遗嘱的下午。财产清单读到后来全是来历，法律文书变成定情史的倒叙。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 起因：同龄人的一场葬礼，或她病愈后的决定。她提的，口吻像安排年会 |
| 2 | 拖了两个月，律师的模板在邮箱里躺着 |
| 3 | 那个下午：餐桌摊开表格，茶泡上，像做一份家庭作业 |
| 4 | 大项走得快：房、存款，半小时填完 |
| 5 | 卡在小项：「其他物品」一栏，一只砂锅写了二十分钟（得先讲清它是哪年谁买的） |
| 6 | 有些东西给不出去（合照给谁都不对） |
| 7 | 他那栏只写了「都给她」，她说这不合规范，他说那你教我 |

#### 清单的读法

财产清单按价值排序，来历清单按年头排序，两张单子在同一张纸上打架。写这场戏，把每件物品当出土文物处理：

| 物品 | 表格里的身份 | 讲出来的来历 |
|---|---|---|
| 砂锅 | 其他物品，残值忽略 | 第一个冬天买的，炖了十几年 |
| 一套茶具 | 礼品，未拆封 | 拆不拆的争论持续了八年，成了梗 |
| 他的全名 | 立遗嘱人 | 她一辈子叫他小名，文书上第一次念他全名，两个人都愣了半秒 |

第三行接 [05-剧情套路 · 临终改称谓](../05-剧情套路/01-经典套路库.md#临终改称谓)：称谓的换轨在文书里预演了一次。这里是笑着的，那里不是。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 律师模板（「其他物品」栏太小） · 两副老花镜 · 打印店装订的塑料圈 · 那只砂锅 |
| 动作 | 她念条款，他补来历 · 写错一处，她拿修正带，他说重打一份吧，她说改了就行（她也开始留旧） |
| 卡壳点 | 合照 · 对方送的第一件礼物（互相写给对方，等于没分） · 宠物（它的年纪算下来，送不走谁） |
| 台词类型 | 「这个归你」「我不要，你留着」（都知道留不住，还是这么说） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先提 | 她（大概率） | 他（他提，她那一秒的表情要单独写） |
| 写没写完 | 当天签了 | 「其他物品」一栏至今没填完，成了每年添一笔的活文书 |
| 形式 | 各立一份 | 同一个下午背对背写，写完交换看 |

「每年添一笔的活文书」那一端，把遗嘱写成了年度仪式，接 [十 · 周年祭](#十--周年祭) 的固定动作逻辑，是 BE 土壤里长出来的 HE 用法。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 法律语言她全懂，砂锅那一栏她写不下去 | 他那栏的「都给她」，落笔没有犹豫 |
| 内心 | 我安排了一辈子，这是最后一份安排 | 纸上这些东西，哪一件都比不过写它们的这个下午 |
| 好的处理 | 她把「身后」两个字念得和「明天」一样平 | 他不回避，他给每件东西讲来历，讲得有说有笑 |
| 写崩 | 写成她含泪托付 | 写成他拒绝面对，拉着不肯写 |

#### 写崩的三种方式

1. 写成哭戏。 这个下午的正确气氛是平静里带笑；眼泪要留给第八、九条，这里流了，后面就没得流。
2. 清单抽象化。 「全部财产」一笔带过等于没写；戏眼全在具体物件的来历上。
3. 埋纠纷伏笔。 遗嘱一涉及第三方争产就滑进家斗剧；这一族的身后没有反派。

## 八 · 她先走了

`T` ｜ ⚠️BE·死亡向 ｜ 全谱系 ｜ 语料频次：离世 29.4%

**骨架**｜他料理她的身后。所有人等他垮，他把每件事办完了，用的全是她的办法。

留下的人是他，这就是他的戏；她只以预案和物件出场。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 事发。不写抢救，从事务写起：他打的第一个电话，声音是稳的 |
| 2 | 他撑事：列清单、排顺序。亲友惊讶，这做派眼熟，全是她的 |
| 3 | 她的预案浮出：密码、名单、该找谁办什么，她早写好了（[七 · 遗嘱](#七--遗嘱) 的回收） |
| 4 | 告别式。悼词里全是她的头衔；轮到他，他只说了她的名字 |
| 5 | 人散。亲友要留下陪，他说不用。这句是这几天他仅有的任性 |
| 6 | 第一晚的空床 |
| 7 | 第二天早上六点半，她的闹钟照常响了。他走过去，没关，听完 |

第 4 拍反用 [临终改称谓](../05-剧情套路/01-经典套路库.md#临终改称谓)：制度念它的头衔，他念他的名字。一句就够，不重复。

#### 空床的物理学

第一晚不写哭，写空间。床是两个人睡了几十年的秤，少了一边，重量全错了：

| 观察点 | 内容 |
|---|---|
| 他睡哪边 | 自己那半边，不占她的（占了等于承认那边空了） |
| 她那半边 | 枕头原样 · 睡衣在枕下，叠法是她的 |
| 声音 | 少了一个人的呼吸，静得像耳鸣 · 空调还开着她要的温度 |
| 他的动作 | 和衣躺下 · 半夜伸手到床中线，停住，收回来 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 事务清单 | 电话 · 证件 · 讣告措辞（他改了三稿，删掉了「不幸」） · 她的手机怎么办（第一件难题，他充上电，搁下了） |
| 她的预案 | 密码册 · 名单（谁必须通知，谁不必） · 最后一条是给他的：「哭可以，饭要吃。」 |
| 告别式 | 花是他坚持换的（她讨厌白色） · 签到簿他后来一页页看完 |
| 之后的第一批小事 | 她的会员自动续费，他续着 · 快递到了，收件人是她，他签了字，站了很久 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 有没有预案 | 有（她式的周全，等于她还在指挥） | 没有（事发突然，他从零学她） |
| 他撑的成色 | 全程稳，事后垮在一件小事上 | 中途垮过一次，爬起来接着办 |
| 亲友的位置 | 都在，他谢绝 | 只剩他一个，静到底 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她的预案被一步步执行：她算到了一切，没算到他会把闹钟听完 | 空床的中线，他的手停在那里 |
| 内心 | （预案里的口吻）他会乱，写细一点 | 她把最后一次照顾也做完了，剩下是我的部分 |
| 好的处理 | 预案的最后一条是家常话，不写成情书 | 他大事办得漂亮，垮在续费提示这种小事上 |
| 写崩 | 写成遗书大段抒情 | 写成他当场崩溃住院 |

#### 写崩的三种方式

1. 哭量堆积。 眼泪要省着用：大场面不哭，垮在小事上，刀才进得深。
2. 让他垮掉不能办事。 他办得好才见她的痕迹；垮掉的版本里，她这三十年白教了。
3. 遗物一次清完。 她的东西要留着慢慢处理，[十 · 周年祭](#十--周年祭) 的年度动作要从这里长出去。

| 2 | 她撑。当然她撑，她一辈子都是撑的那个；这次身后没人再接她 |
| 3 | 所有人等她哭。她不哭，她办事，办得比任何一次都精确 |
| 4 | 事毕。房子静下来，悲伤的钟这才开始走 |
| 5 | 几周后，触发物引爆（一件极小的东西） |
| 6 | 她允许了自己一次，一次就够 |
| 7 | 之后她怎么活：他管的事一件件接过来，用她的方式 |

第 1 拍的「收了尾才动身」是这条独有的刀：职业素养替她做了决定，那十分钟她会记一辈子。

#### 哀悼形态对照

她是立了几十万字的人，哀悼没有通用模板，只有她的方式（原型名从 [04-人设原型/01-女主原型谱](../04-人设原型/01-女主原型谱.md) 取）：

| 原型 | 哀悼形态 | 崩点位置 |
|---|---|---|
| 能力型女 Alpha | 项目化：流程完美，亲友挑不出错 | 几周后，冰箱里他冻的最后一批饺子 |
| 清冷寡言型 | 零变形：作息不变，话更少了 | 没有崩点。某天饭桌多摆了一副筷子，她看了很久，收回去 |
| 温柔主导型 | 她替所有人扛：安慰完每一个来吊唁的 | 深夜给他手机发消息，发现自己在等回复 |
| 女帝／权力顶端型 | 制度化：追封、立祠，把私痛做成公事 | 退朝后殿里只剩她，她叫了一声他的小名，没人应 |
| 疯批女攻 | 危险的平静，亲友最怕的一种 | 崩点不定，动笔前先给她备一个活下去的锚 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 他留下的 | 他的东西本来就少（他一辈子把空间让给她），清点起来快得让她生气 · 围裙 · 写满备注的家电说明（他知道她不会用柔洗模式） · 冰箱里最后一批冻饺子 |
| 她的执行 | 讣告她亲手写，写完检查了三遍格式 · 谁来吊唁她都记得，回礼一家不落 |
| 触发物候选 | 饺子吃到最后一份，吃还是留 · 洗衣机响了，提示音是他设的 · 他的拖鞋她一直没收，保洁挪了位置 |
| 她的继续 | 他管的事她一件件学（浇花的量、腌菜的日子），学会一件，祭日汇报一件（接 [十 · 周年祭](#十--周年祭)） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的形态 | 上表五选一 | 复合（外用清冷，内里项目化） |
| 触发物 | 食物（有保质期，倒计时自带） | 声音（不定时，防不住） |
| 那一次崩 | 有人看见（孩子、闺蜜，转 [30-她的世界 · 她的闺蜜](30-她的世界.md#三--她的闺蜜)） | 无人看见（她自己也不承认发生过） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 最后一份饺子，她的手悬在冰箱门上 | （他生前的视角）说明书每页的备注，写的时候就知道是写给以后的她 |
| 内心 | 他把我照顾到了他不在之后 | （预案口吻）她不哭给人看，多冻几份，让她慢慢来 |
| 好的处理 | 她把最后一份留住了，冰箱从此有一个不动格 | 他的准备全是家务颗粒度，没有长信（他知道长信她受不了） |
| 写崩 | 写成她一夜白头 | 写成他留了煽情遗书逼哭全场 |

#### 写崩的三种方式

1. 让她无坚不摧到底。 撑是她的性格，崩那一次是她的人；两样缺一样，人物都不完整。
2. 让她跟着去。 殉情收尾等于宣布她这个人只剩这段关系；她要带着他留下的方法活下去。
3. 哀悼通用化。 换一个女主也能用的哀悼，等于全书人设作废；对着上表按原型挑。

## 十 · 周年祭

`T` ｜ ⚠️BE·死亡向 ｜ 全谱系 ｜ 语料频次：离世 29.4% ＋ 旧地 16.9%

**骨架**｜之后的每一年。祭日的固定动作是活着的人的钟，钟还走，日子就还在走。

#### 节拍链

| 年 | 内容 |
|---|---|
| 第一年 | 生手。带什么、说什么都没谱，在碑前站了两小时，大半时间沉默 |
| 第二年 | 流程定了：几点出门、买哪家的花、擦碑的布、说话的顺序 |
| 第三年 | 第一次笑着讲完一件事（哀悼在换挡） |
| 第五年 | 差点忘了。想起来那一刻的惊惶，比任何一年的悲伤都重 |
| 某一年 | 带了大消息去说（孩子的婚事、搬家），说完等了一会儿，像在等回复 |
| 很多年后 | 动作简化到一个：放下花，坐一会儿，走 |
| 最后 | 谁陪着来，谁接着来（孩子接过流程，连那块布都接了过去） |

#### 祭日的固定动作

[18-节令与天候](18-节令与天候.md) 的年度循环到这里换了轴心：活人的节令看天，这一条的节令看碑。固定动作是给悲伤上的夹板，动作不变，人才能变：

| 动作 | 内容 | 作用 |
|---|---|---|
| 采买 | 花固定那一家，老板娘从不多问 · 吃食带走的人爱的那样 | 路径即仪式 |
| 擦碑 | 专用的布，放在车里固定的格 | 碑比家里的桌子干净 |
| 汇报 | 今年学会了对方管的哪件事 · 家里大事小事，按走的人爱听的顺序讲 | 年报，单向，照常执行 |
| 收尾 | 每年同一句话结束（每家不同，自家固定） | 钟走完一圈 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 那块擦碑布 · 固定品种的花 · 保温杯里带的茶，倒一杯在碑前 · 碑上的字（谁定的，当年怎么争的） |
| 说话的姿势 | 蹲着（早年） · 后来带上了马扎 · 站着说完就走（清冷版） |
| 变化的刻度 | 上山的台阶越走越慢 · 汇报越来越短，坐的时间越来越长 |
| 陪的人 | 孩子在几步外等 · 后来孩子替她拿包，再后来孩子扶着她 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁在碑下 | 她（他来祭，汇报学会的事） | 他（她来祭，说只讲给他的那些话） |
| 频率 | 只有祭日来 | 常来，顺路就来（把「祭」过成了「看」） |
| 陪同 | 一直一个人 | 孩子接班 · 新的人在山下等（重的一笔，写不写都成立） |
| 收法 | 写到她也走（合葬，碑上补名） | 写到某个平常年份为止，不写终点 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她跟他讲话的口吻和生前一样，命令句照旧：「下辈子早点来报到。」 | 他每年汇报一件学会的事。今年是腌菜，咸了，他如实说了 |
| 内心 | 这块碑前是她仅剩的不用撑着的地方 | 她的规矩他还守着；守着规矩，人就像还在 |
| 好的处理 | 她骂他，骂完坐到日头偏西 | 他擦完碑，说完话，不多待（她生前就不爱看他耗着） |
| 写崩 | 写成她年年崩溃 | 写成他的余生只剩祭日 |

#### 写崩的三种方式

1. 每年哭一遍。 第一年的沉默、第五年的差点忘，层次全在变化里；年年同一副哭相，十年就白写了。
2. 蒙太奇跳年份。 「一晃十年」跳不出重量；挑三个年份，每个都落成具体的一天。
3. 靠梦和显灵收尾。 回应一出现，单向汇报的重量就没了；那杯茶凉了就是凉了。
