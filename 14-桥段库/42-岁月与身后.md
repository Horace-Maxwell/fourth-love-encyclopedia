# 岁月与身后

> **分级** 分级见各条，分级上限 `T` ｜ 预警 ⚠️BE·死亡向（限第七至十条，预警置于条目分级行行首）｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**长线以一天为单位——把十年挂在一个具体的日子上。**

## 这一族补哪一段

[18-节令与天候](18-节令与天候.md) 的时间线到 [一年过去了](18-节令与天候.md#九--一年过去了) 就断了，后面没刻度了。第五年、第十年、退休、人没了，全是空白。写死人的，语料里出现率 29.4%（13-07 实测），这量级的题材，现有的写法没一个写「彼此」的：

| 已有落点 | 写的是 | 缺的是 |
|---|---|---|
| [13-家庭与亲属 · 送走它](13-家庭与亲属.md#九--送走它) | 宠物没了 | 走的是人 |
| [13-家庭与亲属 · 亲人离世](13-家庭与亲属.md#十--亲人离世) | 外人走了，俩口子怎么熬 | 走的是对方 |
| [21-世界设定专属 · 寿元差](21-世界设定专属.md#五--寿元差) | 设定上算得清，八百年对六十年 | 日子怎么过 |

十条的次序固定，按时间排。前六条落在生前的不同时段，从第五年一路走到病床前。后四条写身后。三十年整段铺开没法写，每条只取一天，比如第五年某个夜晚、立遗嘱的午后、祭日的清早。年份不单列，挂在当天的物件上，工牌、砂锅、闹钟，物件立得住，年份也就有了。

后四条动笔前先想明白一件事：**谁被留下了。** 被留下的那个人，戏就是他的；走掉的人只靠遗物和提前安排露面，不回头说话。写到第六条停，就是 HE（圆满收尾）这边的完整故事线。后四条统一标 ⚠️BE（悲剧收尾）·死亡向，预警放在分级那一行的最前面。

可用细节表沿用 13-07 的高频物件标记 ✓，身后段没有逐场提升度实测，一律不标数字。

## 一 · 第五年

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：同居 21.1% ＋ 夜深 37.5%（第五年段无独立族）

**骨架**｜激情凉了之后，第一件事就是没话聊。没话聊分两种，一种得哄，一种得熬。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 一个普通晚上，啥事没有，选它就因为太平常 |
| 2 | 吃晚饭时没人说话，他发觉这安静不是一天两天了 |
| 3 | 他试着开口，说了句没头没脑的话，楼下那只猫换地方睡了 |
| 4 | 她接了一句，或者就“嗯”了一声 |
| 5 | 各忙各的，客厅里两盏灯各亮各的，谁也不挨谁 |
| 6 | 睡前她也冒出一句没头没脑的，说明天降温 |
| 7 | 灯关了。两人都没觉得这晚上少了啥，也可能有一个心里空了一下 |

第 3、4 拍是测量仪：没头没尾的话有人应，是不必说话。说出去没人捡，是没话找话。

#### 可用细节

| 类 | 内容 |
|---|---|
| 沉默的判据 | 有的废话不用过脑子就能说 / 得想一想才找得到话头 · 背过身也知道对方在哪儿 / 各刷各的手机像合租 · 路过顺手碰一下 / 碰之前犹豫了一下 · 谁先睡都行 / 等对方先睡 |
| 道具 | 手机 ✓（各聊各的） · 沙发两头各坐出一个坑 · 一副耳机他只戴一边 · 床头各亮各的灯 |
| 声音 | 洗碗的水声 · 他哼歌哼半截停了，没人接话 · 冰箱夜里嗡嗡响 |
| 动作 | 路过顺手给她杯子添水 · 她翻书时把脚搭他腿上 · 换台不用问 |
| 台词类型 | 没头没尾的闲话，聊猫、聊天气、聊楼下新开的店，这种话只有住一块儿五年的人才说得出口 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 安静的质地 | 不必说话 | 真的没话了（转 [三 · 痒](#三--痒)） |
| 谁先察觉退潮 | 她 | 他 |
| 有没有慌 | 都不慌 | 有一个人半夜睡不着 |
| 处理 | 不处理，让它待着 | 有人提议出去走走，老办法，管用 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现回家不用再端着 | 他那句没头没尾的话，她接住了 |
| 内心 | 以前怕冷场，现在冷场也不别扭 | 说话之前不用打草稿了 |
| 好的处理 | 她把「今晚很好」这类话咽回去 | 他哼歌哼半句停了，她把下半句哼完 |
| 写崩 | 写成她开始怀念心动 | 写成他慌着找话聊 |

#### 写崩的三种方式

1. 「五年后」三个字一带而过，长线就断了，这一晚得写足写实。
2. 退潮不用硬凑成危机的前奏。水位正常了，后面不一定有风暴。
3. 第五年的甜都在动作里，台词一多就假。用甜话把安静填满，这招最容易翻车。

后接：[二 · 第十年的重述](#二--第十年的重述) · [三 · 痒](#三--痒)

#### 示例（本库自撰，可直接改写）

> 洗碗的水声停了。他擦着手出来，客厅只开了她那盏灯。
> 「楼下那只猫，」他说，「搬到快递柜顶上睡了。」
> 「暖和。」她没抬头，翻了一页。
> 他坐到沙发另一头，捡起自己那本书。第五年了，猫的事有人接，晚上就不算安静。
> 十点半她先去洗漱，路过时把他滑下去的毯子拎起来，盖回他腿上。谁都没说晚安，晚安从第三年起就是多余的。

## 二 · 第十年的重述

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：节日 33.3%（周年夜）

**骨架**｜周年夜聊起当年，两人说的对不上，可偏偏都是真事。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 第十年的周年夜，老地方或者在家 |
| 2 | 聊起初见，每年都聊，台词都背下来了 |
| 3 | 今年岔了：一个细节两人记得不一样，比如那天到底下没下雨、谁先开的口 |
| 4 | 谁也不服谁，笑着抬杠 |
| 5 | 翻旧账，或者不翻了，照片翻到一半就停手 |
| 6 | 有个人先松口，或者两个说法都留着 |
| 7 | 往后只讲合并后的那版，谁也没正式说过这事 |

#### 记忆的合并整理

十年讲同一段往事，讲得次数比那事儿本身还长，每回讲都顺手修一修。对不上的地方，别急着说谁记岔了——那只能说明，当年俩人站的地儿不一样。

| 对不上的点 | 她的版本 | 他的版本 |
|---|---|---|
| 谁先开口 | 他 | 她，他紧张到没发觉是自己先搭的话 |
| 天气 | 没下雨 | 下了，他在外面等着，淋了个透 |
| 她当时的样子 | 挺狼狈的 | 特别好看 |
| 动心的时刻 | 见第三回才动心 | 头一眼就栽了 |

第三行是通例：他的版本里，她永远比她记得的自己好。争到这一行，就争不动了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 老照片 ✓ · 翻不到底的聊天记录 · 第一次约会那家店 · 电影票根这类物证 |
| 争的方式 | 笑着争 · 拉第三人当裁判，闺蜜记得的是第三个版本 · 打赌 |
| 停下的位置 | 照片翻到某一张，两个人都不说话了 |
| 台词类型 | 「明明是……」开头 · 「好好好，按你说的」，不是认输，是收藏 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 对不上的量级 | 一个细节 | 一整段（谁追的谁） |
| 查证 | 翻出物证 | 故意不查 |
| 收法 | 采用他的版本 | 两版并存，每年轮流讲 |
| 底色 | 全程笑着 | 争到一半发现有一段她完全空白，那年她太忙了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他眼里的她，比她以为的自己强 | 她记下的，比他想的还多 |
| 内心 | 那天的事，他记得比我还清 | 原来那段，她也一直留着 |
| 好的处理 | 她没争，照他的说法来，原因没讲 | 他就咬住那个对她好的点，别的全让 |
| 写崩 | 写成她记性不好，拿来逗乐 | 写成他憋屈，翻老账没完 |

#### 写崩的三种方式

1. 大段闪回。当年的事用今晚的对话转述，镜头一切回去，十年的距离感就没了。
2. 写成罗生门。对不上是甜的，一较真就成了悬疑，情绪货币不对。
3. 判对错。拿出决定性证据宣布谁赢，合并就不会发生了，证据也要模糊。

前接：[一 · 第五年](#一--第五年) · [11-初遇与确立 · 第一眼](11-初遇与确立.md#一--第一眼)，被重述的就是这一场
后接：[27-年龄差与姐弟 · 十年后还差几岁](27-年龄差与姐弟.md#十--十年后还差几岁) · [07-馈赠与仪式 · 一个只属于他们的仪式](07-馈赠与仪式.md#十--一个只属于他们的仪式)

## 三 · 痒

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：无独立族（13-07 未单列倦怠）

**骨架**｜第七年上下，注意力开始漏。痒和出轨预备是两码事，先分清再写。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 他发现自己吃饭时老看手机，不怎么看她了 |
| 2 | 自己一琢磨，吓了一跳，想不起啥时候开始的 |
| 3 | 留意她：她也在走神，两人各想各的，谁也没往谁身上看 |
| 4 | 憋着没说，心里别扭了好几天 |
| 5 | 后来开玩笑似的挑明了，问是不是成老夫老妻了 |
| 6 | 稍微调整一下：换家没吃过的馆子，或者把当年那条路再走一遍 |
| 7 | 那股痒劲儿过去了，跟来的时候一样，说不清是哪天没的 |

#### 痒还是引信

倦怠必然通向危机，这个等式在语料里写滥了。判据摆出来，两回事一眼可分：

| 观察点 | 痒（这一条） | 引信（[34-NTR与出轨危机](34-NTR与出轨危机.md) 的领域） |
|---|---|---|
| 涣散的方向 | 到处飘，落不到人身上 | 盯准了某个人 |
| 能不能说 | 一说就没了 | 说不出口，越瞒越重 |
| 对方在场时 | 走神，但人还在 | 开始躲着不单独待 |
| 处理成本 | 吃顿好的就缓过来 | 得写一整卷 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 走神的形态 | 手机 ✓ · 他答非所问被抓到 · 她把同一件事讲第二遍，他才发现上次没听 |
| 自查的痕迹 | 他翻两人早年聊天记录翻到凌晨 · 相册里今年合照有几张 |
| 说破的口吻 | 玩笑 · 半真半假 · 主语用「我们」，不用「你」 |
| 校准动作 | 新馆子 · 当年那条路 · 每周某晚定为不带手机的晚饭 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先痒 | 他 | 她少被写，写出来更疼也更真 |
| 说不说破 | 玩笑里说了 | 各自校准，谁都没提 |
| 校准之后 | 退了 | 退了又来，来了再校（常态） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己把他讲的事听漏了 | 他数了这个月的合照：三张，全是拍外卖 |
| 内心 | 走神吓不到她，瞒着才会 | 这不是不爱了，那这是什么 |
| 好的处理 | 她当晚就说了，口吻像聊天气 | 他提议去新馆子，没解释为什么 |
| 写崩 | 写成她开始琢磨这段感情 | 写成他内疚得整宿睡不着 |

#### 写崩的三种方式

1. 把痒写成引信。涣散一给对象，这条就改姓了。上表四行判据要全过。
2. 用大浪漫治疗。求婚式的补救对付不了注意力问题，校准要小而日常。
3. 道德化。走神没有过错方。一开审判庭，两个人都成了被告。

## 四 · 空巢

`G` ｜ 无预警 ｜ 全谱系（有孩设定） ｜ 语料频次：孩子 24.8%，离巢段无独立族

**骨架**｜孩子走了，房子又剩俩人。独处得重新适应，老手艺拾起来手生。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 送走那天，宿舍楼下或机场，场面整得挺像回事 |
| 2 | 回程车里谁都没吭声，广播一直响着 |
| 3 | 第一顿两个人的饭，菜做了三人份，手一顺手就改不过来 |
| 4 | 那间房的门，开着还是关上，两人都装没这回事 |
| 5 | 一周后发现：两个人单独吃饭没话了，这些年话全让孩子说完了 |
| 6 | 有一个人先动：一次约会式的出门，像多年前那样生分 |
| 7 | 老规矩一件件捡回来，包括当年她定的和他求的 |

#### 收复失地

空巢这段日子，家里头一回没了主心骨。孩子在家那会儿，谁管谁早定了，她管孩子，他管她和孩子，互相叫「他妈」「他爸」。如今孩子一走，这套秩序全得重来。别急着写想孩子，先写这场地盘争夺战。让出去的那些，得一件件收回来。

| 收回来的 | 具体形态 |
|---|---|
| 称呼 | 从「他爸」改回名字，头一回喊出口，俩人都愣了下 |
| 她的规矩 | 家规当年为孩子放宽，如今她重新捡起来，他比当年配合得还快 |
| 他的撒娇 | 孩子面前憋了二十年，现在没人看了，放开了 |
| 时间 | 头一个周末全归俩人，空得不知道拿啥填 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 够三个人吃的菜 · 那间房的门 · 家庭群，孩子头像在最上面 · 冰箱上贴着课程表，没人去撕 |
| 动作 | 她把课程表撕下来，抹平，收进抽屉 · 他做饭前在米缸前发愣，手抓了一把又放下，不知道抓几把 |
| 声音 | 房子空得发慌的那种静 · 群里孩子说“到了”的提示音，两个人同时低头看手机 |
| 台词类型 | 「想不想他」谁都不提。说的是「今晚吃什么」，两个人都听懂了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 空的程度 | 本地上学，周末回 | 出国，一年见一面 |
| 谁更空 | 她，自己也没想到 | 他，早就料到，一直带得多 |
| 那间房 | 原样锁着，谁也不动 | 慢慢住成两个人的新地方，书房或茶室 |
| 关系存量 | 底子厚，没几天就缓过来了 | 这几年全靠孩子拴着，现在得从头追 |

「重新追一遍」那一端可以把 [11-初遇与确立](11-初遇与确立.md) 整卷重跑一轮：人还是那两个人，追法全变了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现这些年跟他说话，一半得靠孩子传话 | 米缸前那一愣 |
| 内心 | 房子空了，她先收拾的却是他的东西 | 没人看了，撒娇都快忘了怎么开头 |
| 好的处理 | 她先改口，喊回他的名字 | 他把三人份吃光，第二天就少做了 |
| 写崩 | 写成她整天闷着难受 | 写成他粘人，活像孩子的影子 |

#### 写崩的三种方式

1. 只写想孩子。想孩子是背景音，主戏是两个人重新认领彼此。
2. 无缝衔接二人世界。生疏要写够，多年的角色不会一顿饭就卸掉。
3. 把生疏写成危机。生疏跟感情没关系，手艺放久了都这样，捡起来就好。

## 五 · 退休那天

`T` ｜ 无预警 ｜ 现代都市（古代致仕、修仙卸位同构） ｜ 语料频次：职场 33.9%（退休段无独立族）

#### 权力惯性的家用安置

三十年的指挥系统，不会因为一张离职证明就关机。硬关，也就是劝她歇着，等于告诉她这个家用不上她的长处。能用的安置法：

| 安置法 | 做法 | 效果 |
|---|---|---|
| 划辖区 | 把一件真事整个交给她管，家里的账、一次装修、老家的大事都算，赔了也不往回拿 | 权力有地方去 |
| 拜师 | 他把自己干了三十年的事摊开请她学，做饭养花都行，她从零开始上手 | 权力换边，她尝尝被管着啥滋味 |
| 立宪 | 俩人把家事划好线，她拿主意，他管琐事 | 吵架有规矩可讲 |

第二行藏着一个彩蛋：强势方在一件小事上心甘情愿当学徒，身份感松开的那一刻，比任何告白都亲。

#### 清单的读法

| 物品 | 表格里的身份 | 讲出来的来历 |
|---|---|---|
| 砂锅 | 其他物品，残值忽略 | 头年冬天买的，炖了十来年 |
| 一套茶具 | 礼品，未拆封 | 拆不拆吵了八年，后来谁都不提了，就当个笑话搁着 |
| 他的全名 | 立遗嘱人 | 她这辈子都喊他小名，遗嘱上第一次见他全名，俩人当场都愣了下 |

第三行接 [05-剧情套路 · 临终改称谓](../05-剧情套路/01-经典套路库.md#临终改称谓)：文书里已经提前换过一回称谓了，那边是笑着改的，这边不是。

> 他坐着，看窗帘边上亮起来的那一条。今天要去银行，要给殡仪馆送照片。清单压在餐桌上，前三项是她的字，第四项起是他的。
> 他把她那半边的被角抚平，下楼煮了粥，只盛了一个人的量。锅里剩下的，他盖上了盖子。

## 九 · 他先走了

`T` ｜ ⚠️BE·死亡向 ｜ 全谱系 ｜ 语料频次：离世 29.4%

**骨架**｜她哭得不像哭丧，像走个过场。全书立了什么人设，这儿就照单把人送走。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 事发。她接电话时正忙着，说了句「知道了」，把手上的事弄完才出门 |
| 2 | 她扛。当然她扛，她这辈子都是扛的那个，这回身后没人再接着她 |
| 3 | 大家都等着她哭。她不哭，她办事，办得比哪回都细 |
| 4 | 事完了。屋里静下来，悲伤的钟这才开始走 |
| 5 | 过了几周，一个小东西把事勾起来 |
| 6 | 她让自己哭了一回，就一回 |
| 7 | 往后她怎么过：他管的事她一件件接过来，按她的法子来 |

第 1 拍的「收了尾才动身」是这条独有的刀：职业素养替她做了决定，那十分钟她会记一辈子。

#### 哀悼形态对照

她是写了几十万字的人，丧事没有标准流程，只能按她自己的方式来。原型名从 [04-人设原型/01-女主原型谱](../04-人设原型/01-女主原型谱.md) 里拿：

| 原型 | 哀悼形态 | 崩点位置 |
|---|---|---|
| 能力型女 Alpha | 把后事当项目做，流程挑不出毛病，谁看了都说体面 | 几周后，冰箱里他冻的最后一批饺子 |
| 清冷寡言型 | 日子照旧，话更少了，看不出什么变化 | 没有崩点。某天饭桌多摆了一副筷子，她看了很久，收回去 |
| 温柔主导型 | 她扛着所有人，挨个安慰来吊唁的 | 深夜给他手机发消息，发现自己在等回复 |
| 女帝／权力顶端型 | 追封、立祠，把私痛做成公事，按规矩来 | 退朝后殿里只剩她，她叫了一声他的小名，没人应 |
| 疯批女攻 | 平静得吓人，亲友反而最怕她这样 | 崩点不定，动笔前先给她备一个活下去的锚 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 他留下的 | 他的东西本来就没几样，一辈子都把地方让给她，收拾起来快得让她来气 · 围裙 · 写满备注的家电说明书，他知道她不会用柔洗模式 · 冰箱里最后一袋冻饺子 |
| 她的执行 | 讣告她亲手写，写完检查了三遍格式 · 谁来吊唁她都记得，回礼一家没落下 |
| 触发物候选 | 饺子吃到最后一顿，吃还是留 · 洗衣机响了，提示音是他设的 · 他的拖鞋她一直没收，保洁挪了地方 |
| 她的继续 | 他管的事她一件件学，浇花浇多少、腌菜哪天腌，学会一件，祭日跟他讲一件，接 [十 · 周年祭](#十--周年祭) |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的形态 | 上表五选一 | 复合，外表清冷，里头全是项目 |
| 触发物 | 吃的，有保质期，自带倒计时 | 声音（不定时，躲不开） |
| 那一次崩 | 有人撞见（孩子、闺蜜，转 [30-她的世界 · 她的闺蜜](30-她的世界.md#三--她的闺蜜)） | 没人看见，她自己也不认账 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 最后一份饺子，她的手悬在冰箱门上 | 他生前的视角，说明书每页的备注，写的时候就知道是写给以后的她 |
| 内心 | 他把我照顾到了他不在之后 | 预案口吻，她不哭给人看，多冻几份，让她慢慢来 |
| 好的处理 | 她把最后一份留住了，冰箱从此有一个不动格 | 他的准备全是家务颗粒度，没有长信，他知道长信她受不了 |
| 写崩 | 写成她一夜白头 | 写成他留了煽情遗书逼哭全场 |

#### 写崩的三种方式

1. 崩那一次是她的人，撑是她的性格，这两样缺一样，人物都不完整。让她无坚不摧到底。
2. 她得带着他留下的方法活下去。殉情收尾等于宣布她这个人只剩这段关系。让她跟着去。
3. 对着上表按原型挑，别把哀悼写成换一个女主也能用的通用版，那等于全书人设作废。

## 十 · 周年祭

`T` ｜ ⚠️BE·死亡向 ｜ 全谱系 ｜ 语料频次：离世 29.4% ＋ 旧地 16.9%

**骨架**｜之后的每一年，祭日那天活着的人照常过日子，钟还在走，日子就没停。

#### 节拍链

| 年 | 内容 |
|---|---|
| 第一年 | 新手。带啥、说啥全没数，在碑前杵了两小时，大半时候闷着 |
| 第二年 | 流程定了：几点出门、买哪家花、擦碑的布、说话顺序 |
| 第三年 | 头一回笑着讲完一件事，哀悼在换挡 |
| 第五年 | 差点忘了。想起来那一下的慌，比哪年都沉 |
| 某一年 | 带了个大消息去说，孩子婚事、搬家，说完等了一会儿，像等回话 |
| 很多年后 | 动作就剩一个：放下花，坐一会儿，走 |
| 最后 | 谁陪着来，谁接着来。孩子接过流程，连那块布都接了过去 |

#### 祭日的固定动作

[18-节令与天候](18-节令与天候.md) 的年度循环到这儿就换了个轴心。活人的节令看天，这一条的节令看碑。固定动作是给悲伤上的夹板，动作不变，人才能变：

| 动作 | 内容 | 作用 |
|---|---|---|
| 采买 | 老去那一家，老板娘也不多问 · 带走的都是他爱吃的 | 走这一趟就是念想 |
| 擦碑 | 有块专门的布，搁车里老地方 | 碑比家里桌子还干净 |
| 汇报 | 今年学会了啥，是他以前管的 · 家里大事小事，捡他爱听的顺序说 | 一年一回，单向，照旧 |
| 收尾 | 每年都用同一句话收，各家有各家的，自家不变 | 像钟走完一圈 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 那块擦碑布 · 固定品种的花 · 保温杯里带茶，倒一杯在碑前 · 碑上的字，谁定的，当年怎么争的 |
| 说话的姿势 | 蹲着（早年） · 后来带上了马扎 · 站着说完就走（清冷版） |
| 变化的刻度 | 上山的台阶越走越慢 · 汇报越来越短，坐的时间越来越长 |
| 陪的人 | 孩子在几步外等 · 后来孩子替她拿包，再后来孩子扶着她 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁在碑下 | 她他来祭，说说学会的事 | 他她来祭，说只讲给他的那些话 |
| 频率 | 只有祭日来 | 常来，顺路就上来（把「祭」过成了「看」） |
| 陪同 | 一直一个人 | 孩子接班 · 新的人在山下等，重的一笔，写不写都成立 |
| 收法 | 写到她也走（合葬，碑上补名） | 写到某个平常年份为止，不写终点 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她跟他说话的口吻和生前一样，还是命令句：「下辈子早点来报到。」 | 他每年汇报一件学会的事。今年是腌菜，咸了，他照实说了 |
| 内心 | 这块碑前是她唯一不用硬撑的地方 | 她的规矩他还守着，守着规矩，人就像还在 |
| 好的处理 | 她骂他，骂完坐到日头偏西 | 他擦完碑，说完话，不多待。她生前就不爱看他耗着 |
| 写崩 | 写成她年年崩溃 | 写成他的余生只剩祭日 |

#### 写崩的三种方式

1. 第五年差点忘了这日子，第一年却哭不出来。这种变化才是人话，要是年年哭得一模一样，那这十年等于白写。每年哭一遍，哭不出来和差点忘了，都比硬撑着一模一样的哭法强。
2. 「一晃十年」听着就虚，年份别一笔带过。挑三个年份，每个都写出具体某一天发生的事。
3. 那杯茶凉了就是凉了，别整复活那套。对方一回应，之前那种单方面惦记的分量就全没了。别靠做梦、显灵来收尾。
