## 一年过去以后

[18-节令与天候](18-节令与天候.md) 的时间线写到 [一年过去了](18-节令与天候.md#九--一年过去了) 就停了，再往后没有刻度。第五年、第十年、退休、有人走了，都没人写。语料里写到死亡的占 29.4%（13-07 实测），题材这么常见，现有条目里却没有一条写两个人之间的生离死别：

| 已有条目 | 写的是 | 缺的是 |
|---|---|---|
| [13-家庭与亲属 · 送走它](13-家庭与亲属.md#九--送走它) | 宠物没了 | 走的是人 |
| [13-家庭与亲属 · 亲人离世](13-家庭与亲属.md#十--亲人离世) | 外人走了，俩口子怎么熬 | 走的是对方 |
| [21-世界设定专属 · 寿元差](21-世界设定专属.md#五--寿元差) | 设定上算得清，八百年对六十年 | 日子怎么过 |

十条按时间排，次序不变。前六条写两人都在世的几个时段，从第五年一直写到病床前，后四条写身后。三十年没法整段铺开，所以每条只取一天，比如第五年的某个夜里、立遗嘱的那个下午、祭日的清早。年份不另外写，落在当天的物件上，工牌、砂锅、闹钟，物件写实了，是哪一年也就清楚了。

写后四条之前，先想清楚**谁被留下了。** 戏归留下的那个人。走了的人只通过遗物和生前的安排出场，不回过头来说话。写到第六条就停，是一条完整的 HE（圆满收尾）线。后四条一律标 ⚠️BE（悲剧收尾）·死亡向，预警写在分级那一行最前面。

可用细节表照 13-07 的做法给高频物件标 ✓。身后几条没有逐场的提升度实测，都不标数字。

## 一 · 第五年

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：同居 21.1% ＋ 夜深 37.5%（第五年段无独立族）

**骨架**｜热乎劲过去以后，头一件事是没话说。没话说有两种，一种要哄，一种要熬。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 一个什么事都没有的普通晚上，挑它就是因为平常 |
| 2 | 晚饭桌上没人说话，他发觉这样安静已经有一阵子了 |
| 3 | 他想开个头，说了句没头没脑的：楼下那只猫换地方睡了 |
| 4 | 她接一句话，或者只“嗯”一声 |
| 5 | 各干各的，客厅两盏灯各亮各的，人也不挨着 |
| 6 | 睡前她也来了一句没头没脑的：明天降温 |
| 7 | 关灯。两人都不觉得这晚少了什么，也可能有一个心里空了一下 |

第 3、4 拍是测量仪：没头没尾的话有人应，是不必说话。说出去没人捡，是没话找话。

#### 可用细节

| 类 | 内容 |
|---|---|
| 沉默的判据 | 有的废话不用过脑子就能说 / 得想一想才找得到话头 · 背过身也知道对方在哪儿 / 各刷各的手机像合租 · 路过顺手碰一下 / 碰之前犹豫了一下 · 谁先睡都行 / 等对方先睡 |
| 道具 | 手机 ✓（各聊各的） · 沙发两头各坐出一个坑 · 一副耳机他只戴一边 · 床头各亮各的灯 |
| 声音 | 洗碗的水声 · 他哼歌哼半截停了，没人接话 · 冰箱夜里嗡嗡响 |
| 动作 | 路过顺手给她杯子添水 · 她翻书时把脚搭他腿上 · 换台不用问 |
| 台词类型 | 没头没尾的闲话，猫、天气、楼下新开的店，住在一起五年的人才说得出这种话 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 安静是哪种 | 不必说话 | 真的没话了（转 [三 · 痒](#三--痒)） |
| 谁先察觉退潮 | 她 | 他 |
| 有没有慌 | 都不慌 | 有一个人半夜睡不着 |
| 处理 | 不管，由它去 | 有人说出去走走，老法子，有用 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发觉回家已经不用端着了 | 他没头没尾的那句，她接上了 |
| 内心 | 从前怕冷场，现在冷场了也不尴尬 | 开口前不用再打草稿 |
| 好的处理 | 「今晚很好」这种话，她咽了回去 | 他哼到半句停下，她接着把后半句哼完 |
| 写崩 | 写成她开始怀念心动 | 写成他慌着找话聊 |

#### 写崩的三种方式

1. 把退潮当成危机的前兆来写。 退潮只是水位回到正常，后面未必有风暴，别硬往上凑。
2. 拿甜话把安静塞满。 到第五年，甜都在动作里，台词一多就假，这么写最容易翻车。
3. 直接跳过。 拿「五年后」三个字带过去，长线就断了，这一晚得实打实写满。

#### 可串接

前接：[18-节令与天候 · 一年过去了](18-节令与天候.md#九--一年过去了)，同样的写法，这回拉到最长
后接：[二 · 第十年的重述](#二--第十年的重述) · [三 · 痒](#三--痒)
对照：[17-同居与身体日常 · 两个人的作息](17-同居与身体日常.md#九--两个人的作息) · [36-亲密的完整结构](36-亲密的完整结构.md)，热乎劲过了以后，亲密还剩下什么。

#### 示例（本库自撰，可直接改写）

> 洗碗的水声停了。他擦着手出来，客厅只开了她那盏灯。
> 「楼下那只猫，」他说，「搬到快递柜顶上睡了。」
> 「暖和。」她没抬头，翻了一页。
> 他坐到沙发另一头，捡起自己那本书。第五年了，猫的事有人接，晚上就不算安静。
> 十点半她先去洗漱，路过时把他滑下去的毯子拎起来，盖回他腿上。谁都没说晚安，晚安从第三年起就是多余的。

## 二 · 第十年的重述

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：节日 33.3%（周年夜）

**骨架**｜周年那晚聊起当年，两人的说法对不上，偏偏又都是真的。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 第十个周年的晚上，在老地方或者在家 |
| 2 | 聊起初见，年年都聊，词都背熟了 |
| 3 | 今年聊岔了：有个细节两人记得不同，比如那天到底下没下雨，是谁先开的口 |
| 4 | 谁也不服谁，笑着抬杠 |
| 5 | 翻旧账查证，或者算了，照片翻到一半停下 |
| 6 | 有一个先松口，或者两种说法都留下 |
| 7 | 以后只讲合起来的那个版本，这事谁也没明说过 |

#### 记忆的合并整理

同一段往事讲了十年，讲的时间比那天本身还长，每讲一回都顺手改一点。对不上的地方先别判谁记错了，当年两个人站的位置不同。

| 对不上的点 | 她的版本 | 他的版本 |
|---|---|---|
| 谁先开口 | 他 | 她，他紧张到没发觉是自己先搭的话 |
| 天气 | 没下雨 | 下了，他在外面等着，淋了个透 |
| 她当时的样子 | 挺狼狈的 | 特别好看 |
| 动心的时刻 | 见第三回才动心 | 头一眼就栽了 |

第三行几乎每对都一样：他记得的她，总比她记得的自己好。争到这一行就争不下去了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 老照片 ✓ · 翻不到底的聊天记录 · 第一次约会那家店 · 电影票根这类物证 |
| 争的方式 | 笑着争 · 拉第三人当裁判，闺蜜记得的是第三个版本 · 打赌 |
| 停下的位置 | 翻到某一张照片，两人都没声了 |
| 台词类型 | 「明明是……」开头 · 「好好好，按你说的」，不是认输，是收藏 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 对不上的量级 | 一个细节 | 一整段（谁追的谁） |
| 查证 | 翻出物证 | 故意不查 |
| 收法 | 采用他的版本 | 两版并存，每年轮流讲 |
| 气氛 | 从头笑到尾 | 争到一半，发现有一段她什么都不记得，那年她太忙 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他看到的她，比她自以为的要强 | 她记住的，比他以为的还多 |
| 内心 | 那天的事他比我记得还清楚 | 原来那一段她也一直记着 |
| 好的处理 | 她不争了，按他的说法来，也不说为什么 | 他只咬定对她好的那一点，其余全让 |
| 写崩 | 写成她记性差，拿这个逗乐 | 写成他受委屈，翻起老账没完没了 |

#### 写崩的三种方式

1. 写成罗生门。 说法对不上本来是甜的，一较真就变成悬疑，味道全变了。
2. 判出对错。 掏出铁证宣布谁赢，两个版本就合不到一起了，所以证据也要模糊。
3. 大段闪回。 当年的事要靠今晚的对话讲出来，镜头一切回当年，隔着十年的那种远就没了。

前接：[一 · 第五年](#一--第五年) · [11-初遇与确立 · 第一眼](11-初遇与确立.md#一--第一眼)，被重述的就是这一场
后接：[27-年龄差与姐弟 · 十年后还差几岁](27-年龄差与姐弟.md#十--十年后还差几岁) · [07-馈赠与仪式 · 一个只属于他们的仪式](07-馈赠与仪式.md#十--一个只属于他们的仪式)

## 三 · 痒

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：无独立族（13-07 未单列倦怠）

**骨架**｜第七年前后，注意力开始漏。痒和出轨的前奏是两回事，先分清楚再动笔。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 他发觉自己吃饭时总看手机，很少看她了 |
| 2 | 他一琢磨吓了一跳，想不起是从什么时候开始的 |
| 3 | 再看她：她也在走神，两个人各想各的，谁都没看谁 |
| 4 | 他憋着没提，心里别扭了好些天 |
| 5 | 后来半开玩笑地说破了：是不是成老夫老妻了 |
| 6 | 小小调一下：去家没吃过的馆子，或者把当年那条路再走一回 |
| 7 | 痒劲过去了，跟来时一样，说不上是哪天没的 |

#### 痒还是引信

倦怠一定走到危机，语料里这么写的太多了。判断标准摆出来，两回事一眼分开：

| 观察点 | 痒（这一条） | 引信（[34-NTR与出轨危机](34-NTR与出轨危机.md) 的领域） |
|---|---|---|
| 涣散的方向 | 到处飘，落不到人身上 | 盯准了某个人 |
| 能不能说 | 一说就没了 | 说不出口，越瞒越重 |
| 对方在场时 | 走神，但人还在 | 开始躲着不单独待 |
| 怎么处理 | 吃顿好的就缓过来 | 得写一整卷 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 走神的形态 | 手机 ✓ · 他答非所问被抓到 · 她把同一件事讲第二遍，他才发现上次没听 |
| 自查的痕迹 | 他翻两人早年聊天记录翻到凌晨 · 相册里今年合照有几张 |
| 说破的口吻 | 玩笑 · 半真半假 · 主语用「我们」，不用「你」 |
| 校准动作 | 新馆子 · 当年那条路 · 每周某晚定为不带手机的晚饭 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先痒 | 他 | 她，很少有人写，写出来更疼，也更真 |
| 说不说破 | 玩笑里说了 | 各自校准，谁都没提 |
| 校准之后 | 退了 | 退了又来，来了再校（常态） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发觉他讲的事自己没听进去 | 他数这个月的合照：三张，拍的都是外卖 |
| 内心 | 走神吓不到她，瞒着才会 | 这不是不爱了，那这是什么 |
| 好的处理 | 她当晚就说了，语气像在聊天气 | 他说去家新馆子，没说为什么 |
| 写崩 | 写成她开始琢磨这段感情 | 写成他内疚得整宿睡不着 |

#### 写崩的三种方式

1. 把痒写成引信。 心思一落到某个人身上，就成了别的桥段。上表四行判据都得过。
2. 拿大浪漫来治。 求婚那种规模的补救治不了走神，调整要小，要日常。
3. 道德化。 走神没有过错方。

## 四 · 空巢

`G` ｜ 无预警 ｜ 全谱系（有孩设定） ｜ 语料频次：孩子 24.8%，离巢段无独立族

**骨架**｜孩子走了，家里又剩两个人。单独过得重新适应，老手艺捡起来手生。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 送孩子那天，在宿舍楼下或者机场，场面办得挺像样 |
| 2 | 回来的车上谁也没出声，广播开着一直没关 |
| 3 | 头一顿只有两个人的饭，菜还是做了三人份，手顺惯了改不过来 |
| 4 | 那间房的门开着还是关着，两人都装作没这回事 |
| 5 | 一周后才发现：两个人单独吃饭没话说，这些年的话都是孩子在说 |
| 6 | 有一个人先动：像约会那样出一趟门，跟多年前一样生分 |
| 7 | 老规矩一样样捡回来，当年她定的、他求的都在里面 |

#### 收复失地

孩子走了，家里头一回没了中心。孩子在的时候，谁管谁早有定数：她管孩子，他管她和孩子，两人互相喊「他妈」「他爸」。孩子一走，这一套全得重新排。先别急着写想孩子，先写两人怎么重新划地盘，当年让出去的，要一件一件收回来。

| 收回来的 | 具体形态 |
|---|---|
| 称呼 | 「他爸」改回叫名字，第一次叫出口，两人都愣了一下 |
| 她的规矩 | 家规当年为了孩子松过，现在她重新立起来，他配合得比当年还快 |
| 他的撒娇 | 当着孩子憋了二十年，如今没人看着，就放开了 |
| 时间 | 第一个周末整个归两人，空得不知道做什么好 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 够三个人吃的菜 · 那间房的门 · 家庭群，孩子头像在最上面 · 冰箱上贴着课程表，没人去撕 |
| 动作 | 她把课程表撕下来，抹平，收进抽屉 · 他做饭前在米缸前发愣，手抓了一把又放下，不知道抓几把 |
| 声音 | 房子空得发慌的那种静 · 群里孩子说“到了”的提示音，两个人同时低头看手机 |
| 台词类型 | 谁也不提「想不想他」，嘴上说「今晚吃什么」，两人都懂 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 空的程度 | 本地上学，周末回 | 出国，一年见一面 |
| 谁更空 | 她，自己也没想到 | 他，早就料到，一直带得多 |
| 那间房 | 原样锁着，谁也不动 | 慢慢住成两个人的新地方，书房或茶室 |
| 关系底子 | 底子厚，几天就缓过来 | 这些年全靠孩子拴在一起，现在得从头再追 |

走「重新追一遍」这条路的，可以把 [11-初遇与确立](11-初遇与确立.md) 整卷再走一遍：还是那两个人，追的法子全换了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发觉这些年和他说话，一半是孩子在中间传 | 米缸前那一愣 |
| 内心 | 房子空下来，她头一个收拾的倒是他的东西 | 没人看了，撒娇反倒快不会开头了 |
| 好的处理 | 她先改了口，叫回他的名字 | 三人份他全吃完，第二天就少做了 |
| 写崩 | 写成她整天闷着难受 | 写成他粘人，活像孩子的影子 |

#### 写崩的三种方式

1. 只写想孩子。 想孩子垫在底下，正戏是两个人重新认回对方。
2. 一下子就接上二人世界。 生疏得写够，当了多年的角色，一顿饭卸不下来。
3. 把生疏写成危机。 生疏只是手艺放久了，谁都会这样，感情没出毛病，捡起来就好。

## 五 · 退休那天

#### 清单的读法

|---|---|---|
| 砂锅 | 其他物品，残值忽略 | 头年冬天买的，炖了十来年 |
| 一套茶具 | 礼品，未拆封 | 为拆不拆吵了八年，后来都不提了，成了个搁着的笑话 |
| 他的全名 | 立遗嘱人 | 她一辈子都叫他小名，头一回在遗嘱上看到他的全名，两人当场都愣住了 |

> 是她那只，床头柜上。铃声是她自己录的音，录到第三遍才满意，一句「起床啦」，尾音上挑。
> 他从自己那半边坐起来，没有伸手去按。四十秒，铃声自己停了。
> 他坐着，看窗帘边上亮起来的那一条。今天要去银行，要给殡仪馆送照片。清单压在餐桌上，前三项是她的字，第四项起是他的。
> 他把她那半边的被角抚平，下楼煮了粥，只盛了一个人的量。锅里剩下的，他盖上了盖子。

## 九 · 他先走了

`T` ｜ ⚠️BE·死亡向 ｜ 全谱系 ｜ 语料频次：离世 29.4%

**骨架**｜她哭得不像哭丧，像走个过场。全书立了什么人设，这儿送走他时就是什么样子。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 出事了。电话打来时她正忙，说了句「知道了」，把手头的事做完才出门 |
| 2 | 她扛着。当然是她扛，她这辈子一直是扛事的那个，这回身后再没人接着她 |
| 3 | 所有人都在等她哭。她没哭，她去办事，办得比哪一回都细 |
| 4 | 事完了。屋里静下来，悲伤的钟这才开始走 |
| 5 | 几周以后，一样小东西把这事勾了起来 |
| 6 | 她让自己哭了一回，就一回 |
| 7 | 往后的日子：他管过的事她一件件接过来，照她的法子办 |

第 1 拍的「收了尾才动身」是这条独有的刀：职业素养替她做了决定，那十分钟她会记一辈子。

#### 哀悼形态对照

她是写了几十万字的人，丧事没有标准流程，只能按她自己的方式来。原型名从 [04-人设原型/01-女主原型谱](../04-人设原型/01-女主原型谱.md) 里拿：

| 原型 | 哀悼形态 | 崩点位置 |
|---|---|---|
| 能力型女 Alpha | 把后事当项目做，流程挑不出毛病，谁看了都说体面 | 几周后，冰箱里他冻的最后一批饺子 |
| 清冷寡言型 | 日子照旧，话更少了，看不出什么变化 | 没有崩点。某天饭桌多摆了一副筷子，她看了很久，收回去 |
| 温柔主导型 | 她扛着所有人，挨个安慰来吊唁的 | 深夜给他手机发消息，发现自己在等回复 |
| 女帝／权力顶端型 | 追封、立祠，把私痛做成公事，按规矩来 | 退朝后殿里只剩她，她叫了一声他的小名，没人应 |
| 疯批女攻 | 平静得吓人，亲友反而最怕她这样 | 崩点不定，动笔前先给她备一个活下去的锚 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 他留下的 | 他的东西本来就没几样，一辈子都把地方让给她，收拾起来快得让她来气 · 围裙 · 写满备注的家电说明书，他知道她不会用柔洗模式 · 冰箱里最后一袋冻饺子 |
| 她的执行 | 讣告她亲手写，写完检查了三遍格式 · 谁来吊唁她都记得，回礼一家没落下 |
| 触发物候选 | 饺子吃到最后一顿，吃还是留 · 洗衣机响了，提示音是他设的 · 他的拖鞋她一直没收，保洁挪了地方 |
| 她的继续 | 他管的事她一样样学，花浇多少水、菜哪天腌，学会一样，祭日就跟他说一样，接 [十 · 周年祭](#十--周年祭) |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的形态 | 上表五选一 | 复合，外表清冷，里头全是项目 |
| 触发物 | 吃的，有保质期，自带倒计时 | 声音（不定时，躲不开） |
| 那一次崩 | 被人撞见了（孩子、闺蜜，转 [30-她的世界 · 她的闺蜜](30-她的世界.md#三--她的闺蜜)） | 没人看见，她自己也不承认 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 最后一份饺子，她的手停在冰箱门上 | 换到他生前的视角：说明书每页的备注，他写的时候就知道是写给以后的她 |
| 内心 | 他把我照顾到了他不在之后 | 他知道她不哭给人看，就多冻了几份，让她慢慢吃 |
| 好的处理 | 最后一份她留着没吃，冰箱从此有一格不动 | 他留下的都是家务小事，没写长信，他知道她受不了长信 |
| 写崩 | 写成她一夜白头 | 写成他留了煽情遗书逼哭全场 |

#### 写崩的三种方式

1. 让她从头硬到尾。 撑得住是她的性格，崩的那一次也得有，少了哪样人物都不全。
2. 让她跟着走。 拿殉情收尾，就是说她这个人除了这段关系什么都没有。她得带着他留下的那些法子活下去。
3. 哀悼写得千篇一律。 换个女主也照样能用的哀悼，全书的人设就白立了。照上表按她的原型挑。

## 十 · 周年祭

`T` ｜ ⚠️BE·死亡向 ｜ 全谱系 ｜ 语料频次：离世 29.4% ＋ 旧地 16.9%

**骨架**｜往后每一年的祭日，活着的人照常过日子，钟还在走，日子也没停。

#### 节拍链

| 年 | 内容 |
|---|---|
| 第一年 | 头一回。带啥说啥都没底，碑前站了两小时，大半时间闷着 |
| 第二年 | 流程定了：几点出门、买哪家花、擦碑的布、说话顺序 |
| 第三年 | 头一回笑着讲完一件事，哀悼在换挡 |
| 第五年 | 差点忘了。想起来那一下的慌，比哪一年都重 |
| 某一年 | 带着件大事去说，孩子结婚或者搬家，说完停了一会儿，像在等回话 |
| 很多年后 | 只剩一套动作：放下花，坐一会儿，走 |
| 最后 | 谁陪着来，往后就谁接着来。孩子接过了这一套，连那块布也一起接走 |

#### 祭日的固定动作

[18-节令与天候](18-节令与天候.md) 的一年一轮，到这里换了个中心。活人过节令看天，这里的节令看碑。每年做的事都一样，人就这样慢慢缓过来了：

| 动作 | 内容 | 作用 |
|---|---|---|
| 采买 | 总去同一家，老板娘也不多问 · 买的都是他爱吃的 | 跑这一趟本身就是念想 |
| 擦碑 | 有块专用的布，放车里老位置 | 碑比家里的桌子还干净 |
| 汇报 | 今年学会了什么，都是他从前管的 · 家里大小事，按他爱听的顺序说 | 一年一次，只有一头在说，照旧 |
| 收尾 | 每年用同一句话收尾，每家的那句不同，自家那句不变 | 像钟走完了一圈 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 那块擦碑布 · 固定品种的花 · 保温杯里带茶，倒一杯在碑前 · 碑上的字，谁定的，当年怎么争的 |
| 说话的姿势 | 蹲着（早年） · 后来带上了马扎 · 站着说完就走（清冷版） |
| 变化的刻度 | 上山的台阶越走越慢 · 汇报越来越短，坐的时间越来越长 |
| 陪的人 | 孩子在几步外等 · 后来孩子替她拿包，再后来孩子扶着她 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁在碑下 | 她在碑下，他来祭，讲讲新学会的事 | 他在碑下，她来祭，说那些只对他说的话 |
| 频率 | 只在祭日来 | 常来，路过就上去（「祭」慢慢变成了「看」） |
| 陪同 | 始终一个人 | 孩子接班 · 有新的人在山下等，这一笔很重，写不写都说得通 |
| 收法 | 写到她也走了（合葬，碑上补刻名字） | 停在某个平常的年份，终点不写 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她对他说话还是生前的口吻，命令句：「下辈子早点来报到。」 | 他每年报一件新学会的事。今年是腌菜，腌咸了，他照实说 |
| 内心 | 只有在这块碑前她不用硬撑 | 她的规矩他还守着，守着规矩，人就像还在 |
| 好的处理 | 她骂他，骂完一直坐到太阳偏西 | 他擦好碑，说完话就走，不多留。她活着时就不爱看他磨蹭 |
| 写崩 | 写成她年年崩溃 | 写成他的余生只剩祭日 |

#### 写崩的三种方式

1. 年年哭一场。 第一年哭不出来，第五年差点把日子忘了，人就是这么变的。年年哭得一个样，这十年就白写了。
2. 年份一笔带过。 「一晃十年」一听就虚。挑三个年份，每年写清楚某一天具体发生了什么。
3. 拿做梦、显灵收尾。 对方一有回应，那份只有一头的惦记就没了。那杯茶凉了就让它凉着，别搞复活那一套。
