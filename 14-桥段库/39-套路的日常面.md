## 安全框架（本卷统一说明，先读这一节）

预警只挂在第一条：[一 · 圈养的一天](#一--圈养的一天) 带 ⚠️囚禁。框架照 [08-规训日常版](08-规训日常版.md) 和 [06-尺度与写法](../06-尺度与写法/) 的通用底线，放在卷首。

| 缩写 | 全称 | 含义 |
|---|---|---|
| SSC | Safe, Sane, Consensual | 安全、理智、双方同意 |
| RACK | Risk-Aware Consensual Kink | 知晓风险前提下的双方同意 |
| PRICK | Personal Responsibility, Informed Consensual Kink | 个人责任前提下的知情同意 |

三条社群共识的公约数：同意必须是知情的、可撤回的、由具备判断能力的成年人做出的。

小说里的圈养，说白了就是个**幻想装置**：它活在作者说了算的世界里，一切后果作者兜着，用来写两个人之间那种绷着的劲儿。圈养条写的是这个幻想装置平时怎么转，现实里限制他人人身自由是犯罪。别拿「他后来爱上她」当借口，虚构和现实这道线不会因为这句话就挪窝。本卷所有条目的角色都是成年人；本卷不写任何能照着做的细节，也不是现实指南。

## 一 · 圈养的一天

`M` ｜ ⚠️囚禁 ｜ 全谱系 ｜ 语料频次：囚禁 0.4%（05-01 词频）

**骨架**｜谁说了算，全写在一张作息表上。

圈养（GB 圈对囚禁向的通行叫法：人养在布置妥当的地方，吃穿不缺，只是不能走，方向反转的说明见 05-01）。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 六点四十她出门，门一关，表就开始走 |
| 2 | 上午两格，阳台待一小时，书房随便用。到没到点，他自己看钟 |
| 3 | 午后一格雷打不动，是每天必须做完的事，抄写、练琴或者侍弄花，表头写着这一格和谁约好 |
| 4 | 四点开始他把屋子复原：杯子归位，椅背掰回原角度，书签夹回原页 |
| 5 | 六点半她到家，两人对表：她看水杯和花土猜他这一天，他看她的鞋跟和领口猜她的 |
| 6 | 晚上倒垃圾，门开两分钟。他把袋子放到门外，退回屋里，亲手把门带上 |

第 6 拍是 05-01 那道硬要求能走而不走的时刻的日常剂量：不写心理活动，只写动作。

#### 时间轴

按表上的格子，她六点四十出门，六点半回来。每一格实际用了多久，和表上差多少，往哪头差，对表时都要点到。差得少，读者看到的是「听话了」，差得多，就是「在试探」。

#### 可用细节

| 类 | 内容 |
|---|---|
| 表本体 | 贴在冰箱门上／夹在台历里 · 第几版 · 有一格字迹不同，是他求来的 |
| 她的核对 | 不问，只看：水杯放在哪 · 书签 ✓ 挪了几页 · 花土干没干 |
| 例外日 | 来客那天表作废，他反而坐立不安 |
| 要圆的谎 | 他不露面，由谁顶着 · 快递 ✓ 收件人写谁 · 一个总来追问的朋友 |

他朋友来问，得想个说法；快递堆在门口，得替他签收；半年不见人影，邻居打听，还得现编个理由。关一个人从来不是锁上门就完事。这些烂摊子本身就是戏，05-01 那条也是这么说的。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 合法性来源 | 一张他签了字的纸 | 一句没人核实的「他愿意」，写这边得带着态度 |
| 表的作者 | 她独自定的 | 从第三版起他也往表里添格子 |
| 门 | 上锁 | 不上锁，锁写在表里，比真锁更压人 |
| 尽头 | 表撤了，他反倒睡不着 | 表留着，格子一条条改成两人的 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她在办公室抬手看表，这个点他该在阳台 | 表上的空格，他数起来最慢 |
| 内心 | 她把核对叫作「确认他平安」，这叫法骗得过她自己 | 他分不清自己是在守那张表，还是在等她回家 |
| 好的处理 | 他看到她的日程，她的格子里写着他的饭点 | 门开的两分钟里，他只惦记垃圾袋会不会漏 |
| 写崩 | 写成受人称赞的温柔看守 | 写他感激这张表 |

#### 写崩的三种方式

1. 写成纯甜宠。 吃穿再周全，也盖不住他没得选。要是没人看出问题，圈养就成了一桩装修体面的失踪案。文里得留一双看得见问题的眼睛，可以是起了疑的旧友，也可以是他夜里的那一眼。
2. 表成了摆设。 通篇没有哪一格真被执行过、出过误差、讨过价，挂着的套路就只剩个标签。
3. 靠加码往前推。 格子排得越密，人只会越麻木。按 05-01 的「恩典的收回」，哪天把一个惯例格不动声色地停掉，比多加三格管用。

## 二 · 替身的破绽

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：替身 0.3%（05-01 词频）

**骨架**｜他学得再像，日常里也总有三处露了底。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 家里还是原来那人在时的摆法：杯子、相框、门口那双拖鞋 |
| 2 | 头一处破绽出在资料没写的地方：他用右手接杯子，那人一向用左手 |
| 3 | 她不点破，开始在日常里试他：旧牌子换成新的，看他接不接得住 |
| 4 | 第二处破绽在题目以外：周二的垃圾车，楼下咖啡放几块糖。资料他答对了，生活答错了 |
| 5 | 第三处破绽出现那天，她转身进屋，收起一件旧物 |
| 6 | 旧物一件件少下去，少了什么他数得出来，却不敢问 |

#### 时间轴

看旧物。每收一件，正主就淡一分。腾出来的位置摆了别的，还是一直空着，读者一眼就能看出她走到了哪一步。

#### 可用细节

| 类 | 内容 |
|---|---|
| 破绽形态 | 惯用手 · 忌口说反了 · 那首歌响起他没接下一句 · 上台阶他扶的是另一侧 |
| 正主遗留物 | 相框 ✓ · 杯子 · 拖鞋 · 一件她一直没送洗的外套 |
| 她的设题 | 换掉旧牌子 · 提一个旧地名 · 把座位换到当年的另一边 |
| 收物的顺序 | 先收显眼的，她随身那件留到最后，她一点点松动就是按这个顺序 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他知不知情 | 知情，照着资料演 | 不知情，破绽都是自然露出来的（更疼） |
| 破绽方向 | 他不如正主的地方 | 他比正主多的地方，她留下他就从这头开始 |
| 她的动机 | 为了他收 | 为了让自己死心收 |
| 第三个破绽 | 她点破 | 她装作没看见，从此不再出题 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 第三处破绽那天，她是松了口气还是心往下沉，决定全篇往哪走 | 他背熟的资料里没有「周二的垃圾车」 |
| 内心 | 她开始留心那些对不上的地方，它们比对得上的更像个活人 | 他演砸的地方她一处都没罚，这比罚还吓人 |
| 好的处理 | 收旧物不作解释，节奏平稳 | 他故意露个破绽，赌她怎么反应，对应 05-01 的偏离拍 |
| 写崩 | 写成审替身的猎人 | 写成毫无自我的空壳 |

#### 写崩的三种方式

1. 破绽当天就得摊牌。 三处破绽中间隔着的日子就是正文，要拆开写，每处破绽后面都得接一段她怎么处理。
2. 正主没有人格。 照 05-01 的要求，正主至少要有一个具体的缺点，否则她对着一个符号吃醋，读者根本跟不上。
3. 只剩标签。 设定挂的是替身，日常却和普通同居一个样，旧物、资料、出题一样都没写。

## 三 · 下课之后

`T` ｜ 无预警 ｜ 现代高校 · 全员成年 ｜ 语料频次：师生 0.5%（05-01 词频）

**骨架**｜讲台上一个叫法，讲台下另一个，教室一空，两人就换回另一套称呼。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 他坐最后一排，举手提问，敬称一个字不差，问题里藏着只有两人懂的暗话 |
| 2 | 下课铃响，人走空得多快，决定今天几时换回那层关系 |
| 3 | 她拔投影线、合上电脑，他留下来擦板书，慢吞吞的 |
| 4 | 走廊里谁也不喊谁，打招呼只用「哎」和眼神，跟临时停火似的 |
| 5 | 出校门的头一句，称呼已经换了。先蹦出来的是哪个词，今天就由谁说了算 |
| 6 | 晚上他翻她第二天的讲义，挑出一处错。第二天她在课上改了，只说「有人提的」，没说是谁 |

第 6 拍对的是 05-01 的硬拍，她得被证明错一次。放到日常里，讲义错一处就够。

#### 时间轴

从铃响到走廊尽头大约三分钟。这三分钟里称呼悬着，两个身份都不在。这三分钟值得写慢。

#### 可用细节

| 类 | 内容 |
|---|---|
| 切换的物理标志 | 卷好的那圈投影线 · 教室后门 · 校门口那棵树，两人认的「过线」标志各不相同 |
| 险情 | 走廊上碰到同事，称呼赶紧切回去，他比她接得快 |
| 合规动作 | 他的卷子她交给同事盲改 · 选课前她照规程报了利益回避 |
| 他的小动作 | 拍板书时把她的手也拍进了一角 · 提问之前在讲义上折的那个角 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时序 | 先是师生，后成恋人 | 先在一起，他后来才选了她的课，怎么避开程序就是剧情 |
| 公开度 | 谁也不知道 | 按规矩向系里报备了，公开但没人张扬 |
| 称谓方案 | 上课喊老师，下课喊名字 | 他私下也叫「老师」，是故意的，两人都懂那是什么意思 |
| 险情等级 | 同事多瞧了一眼 | 学生起哄，她当场搬出规程压住场面 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 课下怎么叫都不如课上那声敬称让她在意 | 什么时候改口，他掐得特别准 |
| 内心 | 讲台上她有权威，下了讲台交出去一半 | 「老师」两个字被他练成了双关 |
| 好的处理 | 讲义出错她当堂就认，认得痛快 | 他用她教的方法，在她的地盘上赢了一回合 |
| 写崩 | 拿分数送人情 | 课上课下两副面孔说换就换 |

#### 写崩的三种方式

1. 称呼一步改到位。 通篇叫昵称等于拆了楼梯，切换那一下没了，两套身份也没了。
2. 教学写空了。 按 05-01 的判法，没有一场具体的答疑，没有纠正和被纠正，师生就只剩个称呼。
3. 利益回避蒸发。 她批他的卷子还打高分，这段关系就成了特权，其实一笔盲改和报备就能立住。

## 四 · 家宴上的姐弟

`T` ｜ ⚠️骨科（限血缘向；主线口径为伪骨科，即无血缘的继亲／养亲姐弟；写血缘向按 `M` 对待并明标）｜ 全谱系 ｜ 语料频次：骨科 1.8%（05-01 词频）

**骨架**｜在全家人面前演一场恩爱，真话藏在桌子底下。

tag 怎么打，先看 [02-术语百科/05-易混淆词辨析](../02-术语百科/05-易混淆词辨析.md)，那里分了四派，也讲了 tag 的打法。要紧的是把「亲」「继」「养」标清楚，别让读者猜。圈内说骨科，指的是血亲恋爱，别弄混。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 进门之前在车里最后对一遍词：今天叫什么，坐哪儿，谁先进 |
| 2 | 入座。座次就是一张摊平的族谱，两人中间隔了个堂妹 |
| 3 | 开演：她给他夹菜，长辈看成姐姐疼弟弟，看得很安心 |

#### 写崩的三种方式

## 七 · 合同第七条

`T` ｜ 无预警 ｜ 现代都市（古代换婚书契书） ｜ 语料频次：契约关系 0.2%（05-01 词频，该卷注明此项口径漏抓、实际更高）

**骨架**｜条款生效那天，两人还装作真的不熟，结果第七条先破了功。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 台历上每月十五画了圈，是对外出席日。第七条写着：对外须执手同行 |
| 2 | 出门前互相查看穿着，跟剧组核对道具一样，谁也不看谁的眼睛 |
| 3 | 执行时十指相扣。条款没写扣多久，多久全凭自由裁量 |
| 4 | 收工上了车，照惯例该松手了，今天谁也没先松 |
| 5 | 她在合同背面记履行情况，这一栏头一回空着 |
| 6 | 离到期还剩四个月，两人都在数，谁也不提续约 |

#### 时间轴

执行日按月算，到期日按年算。同一条款，执行得一回比一回不像履约。到期日在后面压着倒计时。

#### 可用细节

| 类 | 内容 |
|---|---|
| 文本层 | 第七条原文怎么写，稿子是她起草的，后来卡住她的正是自己这行字 · 签字页上两人的手印 |
| 执行层 | 手心出汗不算违约 · 对外称呼有规定，语气没规定 |
| 记录层 | 履行记录那栏 · 空着的格子 · 后补的，谁补的、补哪天的 |
| 倒计时 | 台历上画 ✓ 的圈 · 押金、退租这些跟着到期走的事，合同外的日子也在倒数 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 第七条内容 | 执手 | 称呼／同住，越贴身的条款越先失守 |
| 擦边方向 | 他守着字面，违了本意：没人的地方也不松手，理由是「条款没限定场合」 | 她多加执行日：把「每月」解释成「每月至少」 |
| 到期处理 | 重签，新条款由他来拟 | 明知没必要，还是履行到最后一天（05-01 提过这种收法） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 那格空着的履行栏她看了很久，没补 | 他把第七条读了一遍又一遍，想找出「可以不松手」的解释 |
| 内心 | 起草时她给自己留的退路都在纸上，纸外一条没有 | 字面上他占理，赢得心虚 |
| 好的处理 | 她承认擦边成立，照新解释办 | 他钻空子只往靠近的方向钻，从不为脱身钻 |
| 写崩 | 写成霸道甲方 | 写成纯工具人乙方 |

#### 写崩的三种方式

1. 条款写得太虚。 像「多陪陪我」，对方想违约都违不了，戏就出不来。照 05-01 的标准，条款要具体到能逐条核对。
2. 感情到了，合同就没人再提。 到期那天必须有个动作，重签、撕掉，或者硬撑到最后一秒。要是悄无声息过去，这份合同就白签了。
3. 每次执行都一样。 执行日得有点不同。履行记录栏就是刻度，空着没填、事后补上、字迹时好时坏，都是戏。

| 落点 | 线是她划的，也是她先越过去，在他那层放了盒药 | 他把婚姻过成了排班表，排着排着，开始给她留灯 |
| 内心 | 演夫妻的那三分钟，她比领证那天还像回事 | 挪牛奶之前他想了半天该说什么，最后一句没说 |
| 好的处理 | 越了界不解释，下回照旧 | 他让步都让在东西上，嘴上不提 |
| 写崩 | 她单方面伺候他 | 他上赶着讨好 |

#### 写崩的三种方式

1. 婚姻只当背景。 物业、亲戚、单位，没有一个第三方因为「已婚」露过面，这个结构就白搭了。按 05-01 的判法，把有立场的配角配齐。
2. 分区一夜之间没了。 边界得一格一格地塌，便利贴不能直接跳到同床。
3. 两个人用同一个理由。 都是「家里逼的」，就撞不出什么。一个守一个攻，撞上的那天才有正戏。

## 九 · 复仇者的假期

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：复仇 0.6%（05-01 词频）

**骨架**｜计划表排到了明年，只有这个下午表上没有，是偷来的。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 上午她刚办完清单上的一件事，对应 05-01 复仇条第 1 拍「仇的定价」，日常里只露一角：一封寄出的函，一次约见 |
| 2 | 他提议去个和这些破事都不沾边的地方，菜市场、江边，或者老城的糖水铺 |
| 3 | 她关机两小时，这是五年来第一次，手指按下去时停了一下 |
| 4 | 下午过得很慢。喝完一碗糖水，江风来回吹几趟，事情少得像什么都没发生 |
| 5 | 裂缝：她笑出了声，忽然觉得自己不该这么放松，笑收得太急，他都看见了 |
| 6 | 夜里坐回计划表前，把今天标成「歇一天」，想了想又划掉，留成空白 |

#### 时间轴

计划表按年排，这个下午按小时算。两头差得越多，这个下午越难得。

#### 可用细节

| 类 | 内容 |
|---|---|
| 计划的实体 | 进度墙／加密文件夹 · 台历 ✓ 上只有她懂的记号 |
| 下午的实体 | 关机的手机 ✓ · 糖水 · 他拍的一张她没删的照片 |
| 裂缝的形态 | 笑收得太快 · 在江边她下意识看表，手腕上是空的 |
| 空白的意思 | 「休整」是写给计划看的，空白是留给自己的，这三小时计划管不着 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他知情否 | 不知道，下午照常过 | 知道，这个下午是他手里的牌，用日子换下她的刀 |
| 下午的代价 | 没有 | 清单上有一格误了点，她认了（照 05-01 的规矩，代价她主动给） |
| 频率 | 只有一次 | 每月一个，慢慢成了谁都不点破的规矩 |
| 尽头 | 清算那天，她只想把下午要回来 | 他和仇家那边纠缠不清，下午倒成了两边都不碰的地方 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「空白」那一格，划掉「休整」的那一下 | 上午的事他从来不问，只把糖水往她面前推 |
| 内心 | 关机那两小时她看了三次时间，后来就不看了 | 他早看出她的日程不归她自己，所以只抢一个下午 |
| 好的处理 | 裂缝那一下不解释，笑收了就收了 | 他的温柔都在日子里，没有一句大话 |
| 写崩 | 写她为爱速通，放下屠刀 | 写他是蒙在鼓里的傻白甜男友 |

#### 写崩的三种方式

1. 这个下午来得没代价。 它一定要卡掉某个时机，错过某一格，白捡来的松快没什么可写。
2. 两条线各走各的。 复仇线和感情线要焊在一起。按 05-01 的解法，让他和仇家之间有一层她切不断的关系。
3. 只剩标签。 复仇只出现在人物小传里，日常中一次也没露出她手上在办的事，那就和这个套路没关系了。

## 十 · 救赎的进度条

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：救赎 0.8%（05-01 词频）

**骨架**｜他在好转，看得见，有三个刻度，走得慢，还会倒退。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 先摸底。她不问原因，只记三样：夜灯总开着，有样东西他怎么都不吃，有个名字他总绕开 |
| 2 | 第一格有了动静：夜灯从一直亮变成偶尔亮。她记下日期，没说话 |
| 3 | 停了两个月，毫无变化。她照记，不催 |
| 4 | 倒退：一夜之间回到原样，灯全亮着，他自己关的。那一格她如实画上 |
| 5 | 他翻到那张表，第一次看到自己被画成一条会好起来的线 |
| 6 | 他在表上加了第四行，写的是她：她哭不出来的毛病，从这天起也有人记数了 |

#### 时间轴

按月记。慢慢往上走才可信，一路直线上升是假的。退回去的那几格也得画上。

#### 可用细节

| 类 | 内容 |
|---|---|
| 三个刻度 | 睡眠：夜灯 ✓ 亮不亮，他敢不敢背过身去睡 · 食物：从前忌口的东西，如今他点单时自己会点 · 语言：那个名字从绕开不提，到能顺口说出来 |
| 记录载体 | 手账的最后几页 · 贴在冰箱侧面的格子纸，她故意写得潦草，怕人看出她上心 |
| 复发夜 | 灯全开 · 他抱着她的外套坐到天亮 · 第二天照常上班，装得像没事人 |
| 第四行 | 他的字迹 · 刻度名是他起的：「她这个月哭过几回」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 记录的公开度 | 她偷着记 | 两人一起记，平时就是一张合写的表，即 05-01 说的双向救赎 |
| 复发处理 | 她一慌，进度归零 | 她如实画格，只要没掉到基线以下，就还在曲线上 |
| 第三个刻度 | 说话 | 身体：敢背对她睡，肯当着她的面吃药 |
| 第四行内容 | 她哭 | 她加班，他拿她来量自己，用的是她量他的法子 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 平台期里她学会了「没退」也要记一笔 | 第一眼看到记录，他先找复发那格她画了没有 |
| 内心 | 她只看那条线 | 画了，和别的格子一样画得平平的。他把本子放了回去 |
| 好的处理 | 复发那晚她一句没提记录，只陪他把灯亮到天明 | 第四行他加得不动声色，照着她的格式写 |
| 写崩 | 写成治疗师人格 | 写成创伤即人设 |

#### 写崩的三种方式

1. 靠一件事痊愈。 告白一场，大哭一场，病就好了。好转是慢的，至少画三个月，快的一看就假。
2. 跳过复发。 05-01 有个硬拍，他要主动退一次，退了也要记进表里。跳过去，曲线就成了广告图。
3. 单方面治疗。 通篇他没为她做过一件事。第四行必须有，而且要在他自己的曲线还没走完时加上。
