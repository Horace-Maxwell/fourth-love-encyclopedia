## 安全框架（本卷统一说明，先读这一节）

预警只挂在第一条：[一 · 圈养的一天](#一--圈养的一天) 带 ⚠️囚禁。框架照 [08-规训日常版](08-规训日常版.md) 与 [06-尺度与写法](../06-尺度与写法/) 的通用底线立在卷首。

| 缩写 | 全称 | 含义 |
|---|---|---|
| SSC | Safe, Sane, Consensual | 安全、理智、双方同意 |
| RACK | Risk-Aware Consensual Kink | 知晓风险前提下的双方同意 |
| PRICK | Personal Responsibility, Informed Consensual Kink | 个人责任前提下的知情同意 |

三条社群共识的公约数：同意必须是知情的、可撤回的、由具备判断能力的成年人做出的。

小说里的圈养是**幻想装置**：它运行在作者控制的、后果可控的世界里，服务于关系张力的表达。圈养条写的是幻想装置的日常运转，现实中限制他人人身自由是犯罪。虚构与现实的这道分界不因「他后来爱上她」而移动。本卷全部条目的角色均为成年人；本卷不提供任何可复现的实施细节，也不是现实指南。

## 一 · 圈养的一天

`M` ｜ ⚠️囚禁 ｜ 全谱系 ｜ 语料频次：囚禁 0.4%（05-01 词频）

**骨架**｜一张作息表就是权力结构图。安全框架见卷首。

圈养（GB 语境对囚禁向的通行叫法：养在布置周全的空间里，衣食周全，不能走，方向反转说明见 05-01）。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 六点四十她出门。表的第一行从关门声开始生效 |
| 2 | 上午两格：阳台一小时、书房自由支配。格与格之间他自己看钟 |
| 3 | 午后的必修格：每天必须完成的那一件事（抄写／练琴／照料花草），表头注着这格出自哪份约定 |
| 4 | 四点起他把一天摆回原样：杯子归位、椅背的角度、书签的位置 |
| 5 | 六点半她回来。互相对表：她看水杯和花土读他的一天，他看她的鞋跟和领口读她的一天 |
| 6 | 晚上倒垃圾，门开两分钟。他把袋子放到门外，退回来，门在他自己手里合上 |

第 6 拍是 05-01 那道硬要求（能走而不走的时刻）的日常剂量：不写心理活动，只写动作。

#### 时间轴

作息表是明钟。暗钟是执行误差：各格的实际时间与表定时间差多少、误差朝哪个方向走。误差收窄读作驯顺，误差放宽读作试探，两种都要写进对表那一拍。

#### 可用细节

| 类 | 内容 |
|---|---|
| 表本体 | 贴在冰箱侧面／夹在台历里 · 第几版 · 有一格的笔迹与其余不同（那格是他讨来的） |
| 她的核对 | 不提问，只看：水杯的位置 · 书签 ✓ 挪了几页 · 花土干湿 |
| 例外日 | 有客来访那天全表作废，他反而坐立不安 |
| 圈养的账单 | 对外的圆法：他的社交空缺谁在解释 · 快递 ✓ 收件人写谁 · 一个会追问的旧友 |

「圈养的账单」承 05-01 的写法：关一个人有成本，成本会自动生成情节。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 合法性来源 | 一纸他签过的约 | 一句无人核对的「他自愿」（文本要对这端有判断） |
| 表的作者 | 她单方颁布 | 第三版起有他添的格 |
| 门 | 有锁 | 没锁（锁写进了表里，更重） |
| 尽头 | 表撤了，他失眠 | 表还在，格慢慢全改成了两个人的 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她在办公室抬腕看表：这个点他在阳台 | 表上的空白格他过得最慢 |
| 内心 | 她把核对叫「确认他平安」，叫法骗得过自己 | 他分不清守的是表，还是等的是人 |
| 好的处理 | 她自己的日程被他看见：她的格里写着他的饭点 | 门开两分钟，他想的只有垃圾袋会不会漏 |
| 写崩 | 写成被歌颂的温柔狱卒 | 写成他感谢这张表 |

#### 写崩的三种方式

1. 写成纯甜宠。 衣食周全盖不住他没得选这件事；伦理层一蒸发，圈养就成了装修体面的失踪案。文内要留一双看得见问题的眼睛：一个起疑的旧友，或他夜里那一眼。
2. 表只剩道具。 全篇没有一格被执行、被误差、被讨价还价，挂靠的套路只剩标签。
3. 靠加码推进。 格越排越密只会麻木；照 05-01 的「恩典的收回」来，某个惯例格某天不给，一格不动声色，比加三格都响。

## 二 · 替身的破绽

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：替身 0.3%（05-01 词频）

**骨架**｜他学得再像，日常里总有三个细节对不上。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 家维持着正主（被替代的那个人）留下的原样：杯子、相框、一双拖鞋 |
| 2 | 第一个破绽：资料没写的地方露了馅。他接杯子用右手，那个人惯用左 |
| 3 | 她没说破，开始在日常里设题：把旧牌子换成新的，看他接不接得住 |
| 4 | 第二个破绽出在题外：周二的垃圾车、楼下咖啡的糖数，他答对了资料，答错了生活 |
| 5 | 第三个破绽那天她转身进屋，收起一件旧物 |
| 6 | 旧物一件件变少。他数得出少了什么，不敢问 |

#### 时间轴

家里旧物的存量就是钟。每收起一件，正主淡一分；空出的位置摆了什么、还是空着，读者一眼读出她走到哪一步。

#### 可用细节

| 类 | 内容 |
|---|---|
| 破绽形态 | 惯用手 · 忌口的方向反了 · 那首歌响起他没接下一句 · 台阶上他扶的是另一侧 |
| 正主遗留物 | 相框 ✓ · 杯子 · 拖鞋 · 一件她一直没送洗的外套 |
| 她的设题 | 换掉旧牌子 · 提一个旧地名 · 把座位换到当年的另一边 |
| 收物的顺序 | 先收看得见的，最后收她随身的那件（顺序就是她的松动史） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他知不知情 | 知情，照资料演 | 不知情，破绽全是天然的（更疼） |
| 破绽方向 | 他不如正主的地方 | 他多出来的地方（她留他，从这端开始） |
| 她的动机 | 为他收 | 为自己死心而收 |
| 第三个破绽 | 她说破 | 她装没看见，从此不再设题 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 第三个破绽那天，她松了口气还是沉了心，定全篇走向 | 他背下的资料里没有「周二的垃圾车」 |
| 内心 | 对不上的那些，比对上的更像一个活人 | 演砸的地方她都没罚，这比罚可怕 |
| 好的处理 | 收旧物不解释，节奏稳定 | 他故意露一个破绽，赌她的反应（05-01 的偏离拍） |
| 写崩 | 写成审替身的猎人 | 写成毫无自我的空壳 |

#### 写崩的三种方式

1. 破绽当天摊牌。 三个破绽的间隔就是正文；隔开写，每个破绽各带一次她的处理。
2. 正主没有人格。 照 05-01 的要求给正主至少一个具体缺点，为符号吃醋读者跟不上。
3. 只剩标签。 挂着替身设定，日常与普通同居无异，旧物、资料、设题一样都没有。

前接：[15-秘密与坦白 · 他有一件事没说](15-秘密与坦白.md#一--他有一件事没说)
后接：[28-误会与信任 · 解开的成本](28-误会与信任.md#八--解开的成本)
对照：[01-日常照料 · 他记得她所有的忌口](01-日常照料.md#十--他记得她所有的忌口)（记对与记错互为镜像）

#### 示例（本库自撰，可直接改写）

> 绿萝浇水是周四。他记成周三了。水从盆底渗出来，他蹲在阳台擦了很久。
> 她站在门口看。资料上没有这盆绿萝。资料上只有咖啡的糖数和领带的宽窄。
> 晚上她把相框收进箱子。箱子里已经躺着一副手套、一只杯子。
> 他数得出这个家少了什么。少一件，就是她多看了他一眼。他不敢问，怕一问她就不收了。

## 三 · 下课之后

`T` ｜ 无预警 ｜ 现代高校 · 全员成年 ｜ 语料频次：师生 0.5%（05-01 词频）

**骨架**｜讲台上下两套称谓，切换点在教室清空的那三分钟。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 最后一排的他举手提问，敬称标准，问题里埋着只有两人听得懂的所指 |
| 2 | 下课铃响。教室清空的速度决定今天的切换时刻 |
| 3 | 她拔投影线、合电脑，他留下来擦板书，动作放得很慢 |
| 4 | 走廊是悬置带：谁都不称呼谁，说话全用「哎」和眼神起头 |
| 5 | 出了校门第一句，改口。哪个字先出口，今天谁主动就定了 |
| 6 | 晚上他核她明天的讲义，挑出一处错。她第二天当堂改了，注明出处不注明人 |

第 6 拍接 05-01 的硬拍（她被证明错过一次）：日常剂量下，错一处讲义就够。

#### 时间轴

铃声到走廊尽头，约三分钟。三分钟里称谓悬空，两个身份都不在场；写慢这三分钟，比写十场约会都密。

#### 可用细节

| 类 | 内容 |
|---|---|
| 切换的物理标志 | 投影线卷好的那一圈 · 教室后门 · 校门口那棵树（两人各自认的「过线」参照物不同） |
| 险情 | 走廊撞见同事，称谓紧急切回，他接得比她快 |
| 合规动作 | 他的卷子她交给同事盲改 · 选课前她按规程报备了利益回避 |
| 他的小动作 | 拍板书时把她的手也拍进去一角 · 提问前在讲义上折的角 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时序 | 先师生后恋人 | 先恋人，他后来选进了她的课（回避流程本身成为剧情） |
| 公开度 | 全瞒 | 系里按规程报备，公开但低调 |
| 称谓方案 | 课上敬称课下名字 | 他私下也叫「老师」，故意的，两个人都知道那是另一种话 |
| 险情等级 | 同事一瞥 | 学生起哄，她当堂用规程压场 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 课上那声敬称比课下任何称呼都烫 | 改口的时机他掐得极准，从不失手 |
| 内心 | 权威在讲台上，讲台下她交出去一半 | 他把「老师」两个字练成了双关 |
| 好的处理 | 讲义的错她当堂认，认得干脆 | 他在她的领域赢一回合，用她教的方法 |
| 写崩 | 写成以成绩做人情 | 写成课上课下两副人格无缝切换 |

#### 写崩的三种方式

1. 称谓一步到位。 全程昵称等于拆了楼梯，切换瞬间没了，两套身份也没了。
2. 教学是空的。 照 05-01 的判法：没有一场具体的答疑、纠正与被纠正，师生只剩称呼。
3. 利益回避蒸发。 她改他的卷子还给高分，关系就写成了特权；盲改与报备一笔就能立住。

## 四 · 家宴上的姐弟

`T` ｜ ⚠️骨科（限血缘向；主线口径为伪骨科，即无血缘的继亲／养亲姐弟；写血缘向按 `M` 对待并明标）｜ 全谱系 ｜ 语料频次：骨科 1.8%（05-01 词频）

**骨架**｜全家面前的称谓表演，桌下才是真话。

术语口径：骨科即血缘系恋爱的圈内代称，四派范围之分与打 tag 的规矩见 [02-术语百科/05-易混淆词辨析](../02-术语百科/05-易混淆词辨析.md)；tag 要写清「亲」「继」「养」。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 进门前，车里最后一次对词：今天叫什么、坐哪、谁先进门 |
| 2 | 落座。座次是族谱的平面图，他们中间隔着一个堂妹 |
| 3 | 表演时段：她给他夹菜，长辈读作姐姐疼弟弟，读得心安理得 |
| 4 | 酒过中巡，探针来了：「什么时候给弟弟也找一个？」 |
| 5 | 桌下两只手在桌布下面碰了一下，又分开。桌上她笑着替他挡了话 |
| 6 | 散席。厨房只剩他们收拾碗筷，水声盖着，称谓换回真名 |

#### 时间轴

一顿饭三巡：头道菜行规矩，中段的酒生险情，尾声的水果给台阶。险情固定出在第二巡之后，酒是探针的燃料。

#### 可用细节

| 类 | 内容 |
|---|---|

## 七 · 合同第七条

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 台历上圈着每月十五：对外出席日。第七条写着：对外须执手同行 |

| 倒计时 | 台历 ✓ 的圈 · 押金退租这类到期联动项，合同外的日子也在算 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|

2. 感情到位合同蒸发。 到期那天必须有动作：重签、撕毁、或履行到最后一秒；合同悄悄没人提，等于扔了最大的结构资产。

> 便利贴还贴在层板上，边角翘起来。她没撕。也没把牛奶挪回去。
> 第二天早上，牛奶少了一格。他也没说话。
> 那张便利贴又撑了十一天。最后是搬保鲜盒的时候蹭掉的，掉进冷藏灯照不到的缝里。谁都没有再写一张。

## 九 · 复仇者的假期

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：复仇 0.6%（05-01 词频）

**骨架**｜计划表排到明年，只有这个下午在表外，偷来的。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 上午她刚办完账单上的一件（05-01 的仇之账单，日常只露一角：一封发出去的函、一个约见） |
| 2 | 他提议去一个与一切无关的地方：菜市场、江边、老城的糖水铺 |
| 3 | 她关机两小时。五年来第一次，指节按下去时停了一秒 |
| 4 | 下午本身：慢。一碗糖水的时长、一段江风的来回，事件密度降到零 |
| 5 | 裂缝：她笑出声的那一瞬想起自己不该这么松，笑收得太快，被他看见 |
| 6 | 夜里回到计划表前，把今天标成「休整」，想了想又划掉，改成空白 |

#### 时间轴

计划表以年计，这个下午以小时计。两种时间的比值就是她的病：比值越悬殊，下午越贵。

#### 可用细节

| 类 | 内容 |
|---|---|
| 计划的实体 | 进度墙／加密文件夹 · 台历 ✓ 上只有她懂的记号 |
| 下午的实体 | 关机的手机 ✓ · 糖水 · 他拍的一张她没删的照片 |
| 裂缝的形态 | 笑收得太快 · 江边她下意识看表，腕上没戴 |
| 空白的语义 | 「休整」是给计划的交代，空白是给自己的：这三小时不上账 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他知情否 | 不知，下午是他的日常 | 知道，下午是他的谈判筹码：用日子换她的刀 |
| 下午的代价 | 无 | 账单上一格窗口期错过了，她认了（代价照 05-01 的规矩由她主动交出） |
| 频率 | 仅此一次 | 每月一个，成了不说破的制度 |
| 尽头 | 清算日她只想赎回那些下午 | 他与仇局有她切不断的关系，下午成了唯一的中立区 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「空白」那一格，划掉「休整」的那一笔 | 他从不问上午的事，只把糖水往她那边推 |
| 内心 | 关机的两小时她数过三次时间，后来不数了 | 他早看出她的日程不属于她，所以只抢下午 |
| 好的处理 | 裂缝那一瞬不解释，收笑就收笑 | 他的温柔全部日常化，一句大词没有 |
| 写崩 | 写成因爱速通放下屠刀 | 写成不知情的傻白甜男友 |

#### 写崩的三种方式

1. 假期免费。 下午必须占用某个窗口、错过某一格，白捡的松弛写不出重量。
2. 两条线各走各的。 复仇线与感情线要焊死；照 05-01 的解法，让他与仇局有一层她无法切割的关系。
3. 只剩标签。 复仇只写在人物小传里，日常里看不见账单的一角，那就与套路无关了。

## 十 · 救赎的进度条

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：救赎 0.8%（05-01 词频）

**骨架**｜救赎按斜率读：他的好转是三个可测的刻度，缓慢、会回退。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 立基线。她不问病因，先记三样：夜灯常亮、有一样东西他从不吃、有一个名字他绕着说 |
| 2 | 第一格动了：夜灯从常亮改成偶尔亮。她记下日期，没庆祝 |
| 3 | 平台期两个月，纹丝不动。她照记，不催 |
| 4 | 复发：一夜回到基线，灯全亮，他自己退的。表上那格她照实画 |
| 5 | 他翻到那张记录，第一次看见自己被画成一条会好起来的曲线 |
| 6 | 他在表上添了第四行，记的是她：她哭不出来的毛病，从这天起也有了刻度 |

#### 时间轴

以月为单位。斜率平缓才可信，直线上升是假的；回退画进表里，曲线才配叫曲线。

#### 可用细节

| 类 | 内容 |
|---|---|
| 三个刻度 | 睡眠：夜灯 ✓ 的亮灭、他敢背对她睡了 · 食物：忌口那样出现在他自己点的单里 · 语言：那个名字从绕行到能说出口 |
| 记录载体 | 手账最后几页 · 冰箱侧面的格子纸（她记得潦草，怕被看出郑重） |
| 复发夜 | 灯全亮 · 他抱着她的外套坐到天亮 · 次日照常上班，装得很好 |
| 第四行 | 他的笔迹 · 刻度名他起的：「她这个月哭出来过几次」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 记录的公开度 | 她偷偷记 | 两人共同记（05-01 提的双向救赎，日常形态就是一张共写的表） |
| 复发处理 | 她慌了，进度作废 | 她照实画格：没退到基线以下，就还在曲线上 |
| 第三个刻度 | 语言 | 身体（背对她睡、肯当着她吃药） |
| 第四行内容 | 她的哭 | 她的加班（他量她，用她量他的办法） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 平台期她学会给「没退」也记一笔 | 看见记录的第一眼，他先找复发那格她画没画 |
| 内心 | 她信斜率，斜率不骗人也不哄人 | 画了，画得和别的格一样平。他把本子放了回去 |
| 好的处理 | 复发夜她没提记录，只把灯陪他亮到天明 | 第四行他添得不动声色，笔迹学她的格式 |
| 写崩 | 写成治疗师人格 | 写成创伤即人设 |

#### 写崩的三种方式

1. 事件式痊愈。 一场告白一场大哭病就好了；斜率要三个月起画，快线全是假线。
2. 复发被跳过。 05-01 的硬拍：他要主动退一次，退也入表；跳过它，曲线成了广告图。
3. 单方治疗。 全篇没有一件事他为她做；第四行是硬性的，且要添在他自己还没走完曲线的时候。
