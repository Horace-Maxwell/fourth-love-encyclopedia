# 工作与金钱

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 现代都市为主
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测。节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族收的是没有女尊制度的世界里，跟钱和职位沾边的场面：面试、她当上司、她给钱他不要、她提拔他、他失业、他比她强了，还有加班和出差。没了制度撑腰，两人的高低主要靠钱和职位拉开，这两样最结实，也最容易伤人。

## 她凭什么在上

写现代 GB，总要撞上一个问题：她凭什么在上？

古代女尊有制度兜着，ABO 有生理设定兜着。放到现代，制度和设定都没了，能拿出来比的基本只剩个人条件，个人条件里最硬的又是职位和钱，几乎躲不开。

男主在这一族里最容易写崩。读者一看到「吃软饭」「倒插门」「小白脸」这类词，脑子里自动就开始评判，拦都拦不住。现实里骂男人靠女人的词，现成的一大堆。

所以这一族着重写的是，他待在那个位置上，怎么还能守住自己。

| 节拍族 | 作品数 | 占比 |
|---|---:|---:|
| 职场 | 980 | 33.9% |
| 上下级 | 506 | 17.5% |
| 提携 | 410 | 14.2% |
| 给钱 | 101 | 3.5% |
| 拒钱 | 160 | 5.5% |
| 受挫 | 231 | 8.0% |

语料里写「拒钱」的篇数，差不多是写「给钱」的两倍，写「他不要」的场面远比写「她给」的多。详见第四条。

## 一 · 面试

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：职场 33.9%，初见＋职场高频同现

**骨架**｜隔着一张桌子，她问，他答，两个人都坐着。

#### 节拍链

简历先到她手里 → 隔桌而坐 → 她问了简历外的问题 → 他稳住了 → 「回去等通知」或「明天来上班」

#### 时间轴

面试半小时。头十分钟双方都端着，照套路走，她问得密，节奏全攥在她手里。然后空气停了两秒，她抛出那个简历上没有的问题，这是转折。后面二十分钟是真刀真枪。「回去等通知」一出口，暂且收场。通知真来要隔两天，这两天他每小时掏一次手机。

#### 为什么面试是最好的开局

它一次性给齐了三样东西：

| 给的 | 怎么给的 |
|---|---|
| 位置差 | 制度性的，不需要解释 |
| 信息差 | 她看过他的简历，他对她一无所知 |
| 时限 | 面试会结束，所以有紧迫感 |

这个高低还是临时的、正当的，后面能变，出身和家产那种可就定死了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 空间 | 桌子多宽 · 她有靠背椅子他没有 · 落地窗在她背后，逆光 |
| 道具 | 简历，她翻得多快 · 笔，她敲桌面 · 水，倒不倒给他 |
| 她的动作 | 不翻简历直接问 · 问个简历上没有的事 · 问到一半停下来看他 |
| 他的动作 | 手搁膝盖上 · 第一句嗓子发紧 · 后面慢慢稳了 |
| 结束 | 她说「回去等通知」还是「明天来上班」 |

「问个简历上没有的事」，说明她早查过他，他还蒙在鼓里。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的状态 | 就指着这份工资活 | 其实家里有矿，纯来体验生活 |
| 她的态度 | 按规矩走流程 | 头一回见面就琢磨怎么把人留下 |
| 结果 | 录了 | 没录，但偷偷塞了张名片 |
| 后来 | 他归她管 | 他去了别家，隔了挺久又撞上 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他答到第三个问题时松下来了 | 她翻简历的手停在第二页 |
| 内心 | 这人能用 | 她是不是已经把我摸透了 |
| 好的处理 | 她招他是因为他真行 | 他答得漂亮，也不巴结人 |
| 写崩 | 写成她看脸才要人 | 写成他靠那张脸混进去 |

她招他，只能是因为他行。招人的理由一旦是私情，后面的职场戏就全立不住了。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 堂前问话／她隔着帘子打量／选侍时的甄别／科考殿试 |
| 修仙 | 收徒试炼／她探他的根骨／宗门大比 |
| 星际 | 入舰考核／她调他的档案／模拟测试成绩 |

#### 写崩的三种方式

1. 写成职场调情。 面试立得住全靠“正当”二字，一调情就塌了。
2. 让她问私事。 一越界，她就不像来办事的，像来搅局的。
3. 不写空间安排。 桌子、椅子、光从哪边来，这场戏的布景就齐了。

## 二 · 她是我上司

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：上下级 17.5%

**骨架**｜她白天是上司，下了班就不是，戏都在切换的那一下。

#### 节拍链

电梯门开（公司模式）→ 白天全名与汇报 → 下班那一步 → 切换 → 家里另一套 → 某天切换失败

#### 时间轴

早上电梯门一开，上班那套就上了身。晚上迈出公司大门那一步，就卸下了，工作身份留在门里。这两个点中间，他是被叫全名、要汇报的那个人，出了这两个点，换成另一个人。一天两个身份，切换就卡在具体的地方，那扇电梯门，或者公司门口的台阶。也有切不过来的时候，在家顺嘴喊了句「张总」，开会时差点把昵称秃噜出来。

#### 双重身份的四种处理

| 处理 | 说明 | 风险 |
|---|---|---|
| 严格分离 | 公司里只谈公事，私下是另一副样子 | 最常见，也最有戏 |
| 完全不分 | 私下也端着上班那套 | 会让关系显得单薄 |
| 他分不清 | 他在公司里没切换过来 | 尴尬，也可爱 |
| 她分不清 | 她在家还跟下属似的下命令 | 更少见，值得写 |

切不过来是什么样：他在会议室差点喊出私下的叫法，或者她回了家，说话还是公司那个腔调。

#### 可用细节

| 类 | 内容 |
|---|---|
| 公司里 | 她喊他全名 · 他站着回话她坐着 · 汇报时隔多远 · 她当面把他方案否了 |
| 私下 | 还是这俩人，动作全变样 |
| 切换点 | 电梯门一关 · 车门一关 · 迈出公司大门那一步 |
| 破绽 | 她手在会议桌底下 · 他递文件多停半秒 · 同事来一句「你俩挺熟啊」 |
| 制度问题 | 公司管不管办公室恋爱 · 有人捅上去 · HR 喊去谈话 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 公开程度 | 全公司都瞧见了 | 谁也没察觉 |
| 她的处理 | 工作上对他更狠 | 工作上对他松手，准出事 |
| 他的处理 | 拿成绩说话 | 自己提出来调走 |
| 冲突 | 当众把他方案否了 | 有一回她得在他和团队里挑一个 |

「工作上对他更狠」在这类文里写得多，这么写也对。她要是对他更宽，他在公司就站不住脚，读者也不服。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她当众否掉他方案后的那个下午 | 被否掉时心里那一下 |
| 内心 | 我是不是对他太狠了 | 她是对事不对人，我知道，但还是难受 |
| 好的处理 | 她私下不道歉，但给他改的机会 | 他改了，改得比谁都好 |
| 写崩 | 写成她公私不分 | 写成他借关系走捷径 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 朝堂与内院／她在堂上训他／回府后换了副面孔 |
| 修仙 | 师徒／宗门大比她判他输／私下里给他治伤 |
| 星际 | 舰长和副手／出任务她发号施令／回了舱她摘掉军衔 |

#### 写崩的三种方式

1. 让她公事上偏着他。 偏一次，他就毁了。
2. 跳过切换点。 电梯门合上那一秒要写出来。
3. 同事一个都没察觉。 起码得有一人看出来。

## 三 · 她当众否掉他

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：职场 33.9% ＋ 受挫 8.0%

**骨架**｜满会议室的人，她一句「不行」。

#### 节拍链

他上台 → 她说「不行」→ 会议室安静 → 他收材料 → 会后各走各的 → 晚上谁都不提 → 他改到凌晨

#### 时间轴

会议室里只有十秒，从她说「不行」到他收好材料，不超过十秒。会议室外是一整晚：回家两个人都不提，越不提，他改方案就改到越晚。第二天她看到新版本，这件事就算过去了。公事和私事各了各的，两边不许互相求情。

#### 这条的两难

方案确实不行，她必须否。可她怎么否，这段关系就往哪边走：

| 否法 | 效果 |
|---|---|
| 「不行，重做」 | 干脆，但当众落他面子 |
| 「这里有问题，你再看看」 | 给了台阶 |
| 会后单独说 | 保住面子，但同事会觉得她在护他 |
| 让别人来否 | 最坏，等于她不敢管 |

没有完美选项。

#### 可用细节

| 类 | 内容 |
|---|---|
| 会议室 | 投影开着 · 他站在屏幕边上 · 她坐长桌那头 · 没人吭声 |
| 她的措辞 | 就事论事不点名 · 要么直接点人 |
| 他的反应 | 手指攥得发白 · 语气没变 · 「我明天改完给你」 |
| 会后 | 谁先出门 · 有没有人拍他一下 |
| 晚上 | 俩人都没提这事，或者他先开口了 |

「俩人都没提这事」，比她道歉强。工作上的事就在工作上了，这样是尊重他的专业身份。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 方案 | 确实不行 | 行，但她有别的打算 |
| 她的方式 | 当众直说 | 私下单独聊 |
| 他的反应 | 接受 | 当场顶回去（更有戏） |
| 结局 | 他改了 | 他证明自己没错 |

「当场顶回去」这一端，四爱男读者评价很高：他听她的，可专业上的判断他自己有。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她说完不敢看他 | 手指关节发白，声音没变 |
| 内心 | 我必须这么说，可我知道他难受 | 她是对的，这才最难受 |
| 好的处理 | 她不在私下补偿 | 他改出来了，还改得更好 |
| 写崩 | 写成她借机立威 | 写成他委屈到影响工作 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 堂上驳回他的谏言／众臣面前 |
| 修仙 | 大比上她判他不合格／当着满门 |
| 星际 | 战术会议上她否掉他的方案 |

#### 写崩的三种方式

1. 让她趁机立威。 职场戏就变成了权力戏。
2. 让他背后发牢骚。 一抱怨，他专业的样子就没了。
3. 让她回头私下道歉。 公司的事别带回家。

## 四 · 她给钱，他不要

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拒钱 5.5% > 给钱 3.5%

**骨架**｜她把钱推过去，他推回来，来回几下，事就定了。

#### 节拍链

她转账或塞卡 → 他发现 → 原路退回 → 她问为什么 → 他给理由 → 改成借与记账 → 立了字据

#### 时间轴

转钱、退回、再转、再退，每个回合隔一天，推了三个回合，两人才坐下来谈。一说「借」，就算停手了，先写欠条，再签字。签完还没完：什么时候还，他心里有数，每个月还一格，她从来不催。她要是催上一次，这张欠条就白签了。

#### 实测发现：「不要」比「给」写得多

| 节拍族 | 篇数 | 占比 |
|---|---:|---:|
| 拒钱 | 160 | 5.5% |
| 给钱 | 101 | 3.5% |

差不多两倍。这类语料里，写他怎么拒绝的，比写她怎么给的多。

她给钱是家常便饭，撑不起戏。他怎么拒，直接决定读者怎么看他。

#### 拒绝的四档，从差到好

| 档 | 说法 | 读者观感 |
|---|---|---|
| 差 | 「我不是吃软饭的」 | 把骂人的话写出来了 |
| 一般 | 「我自己有」 | 干净但有点冷 |
| 好 | 没吭声，把东西推回去，第二天又偷偷多接了个活 | 用事说话 |
| 最好 | 收下了，心里记着账，她也看得出来 | 两边都不丢面子 |

最后一档，差距还在，两人照样过得下去。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 工资卡 ✓ · 存折 ✓ · 转账记录 · 他自己记的本子 · 信封 |
| 她的给法 | 直接转 · 塞进他外套 ✓ 口袋 ✓ · 替他付掉某笔 · 不说 |
| 他的发现 | 账单已经结清 · 房租有人交过 |
| 他的处理 | 原路退回 · 打工还上 · 收下但记账 |
| 她的反应 | 生气，觉得他见外 · 或者她懂 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 金额 | 小（一顿饭） | 大（房子、医药费） |
| 紧急度 | 他不缺 | 他家里出事，急需 |
| 他的选择 | 收 | 不收 |
| 她的态度 | 尊重他的拒绝 | 强行给（会伤人） |
| 结果 | 找到平衡 | 这件事成了长期心结 |

「他家里出事，急需」这一端最难写：尊严和现实顶在一起，怎么写都没有标准答案。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 钱被推回来的那一下 | 数字看见的那一秒 |
| 内心 | 我又不是施舍，他干嘛这样 | 收了我就完了 |
| 好的处理 | 她换个法子给（借、投资、算工钱） | 他把不收的原因讲明白 |
| 写崩 | 写成她拿钱砸人 | 写成他面子大过天，油盐不进 |

「她换个法子给」，送改成借，或者改成买卖，差距没变，尊严保住了。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 赏赐／月例／赏的东西他收着不用／她给他买房置地 |
| 修仙 | 灵石／丹药／她送的法器他舍不得用 |
| 星际 | 配额／军饷／她把自己的那份划给他 |
| 末世 | 物资／她偷偷多留的那几罐罐头 |

末世版最狠，物资就是命，在那种世界里不收就是找死。

#### 写崩的三种方式

1. 让骂人的词写进正文。 「吃软饭」这类词一出现，读者就会拿外面那套眼光去看他。
2. 他为了面子不管家里人。 这就成了犟。
3. 她硬塞，还不懂他。 她得懂他，只是不同意。

#### 示例（本库自撰，可直接改写）

> 转账记录在他手机上停了一整晚，红色的那个数字他看了很多遍。
> 第二天早上他原路退了回去，没有附言。
> 她中午打来电话：「你什么意思。」
> 「我自己有。」
> 「你妈住院要多少你自己有？」
> 他没说话。听筒里有她那边的键盘声，敲了几下，停了。
> 「算我借你的。」她说，「写个条，按你说的利息。」
> 他愣了很久，说：「好。」

## 五 · 他要证明自己

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：受挫 8.0% ＋ 提携 14.2%

**骨架**｜他要干成一件事，不靠她。

#### 节拍链

他推掉她的安排 → 自己接了一件事 → 瞒着做 → 她想帮忍住了 → 成或败 → 他回来说结果

#### 时间轴

那几个月里，她好几回想伸手，又硬缩回来。看着他熬夜，听他说又碰了壁，一忍再忍。他也是两头硬扛，先找借口推掉她的安排，最后一口气全摊开。瞒得越久，押上的就越多。到了她“总算不用再装了”的那天，两个人都松了口气。

#### 为什么这条必须有

他要是从头到尾都躲在她底下，这个人就立不起来，两人也成了她单方面养着他。

他得有一件自己的事。 成不成都行，但必须是他自己的。

#### 三种版本

| 版本 | 做法 | 结局 |
|---|---|---|
| 成功版 | 他自己办成了，没靠别人 | 两人重新站到一块儿 |
| 失败版 | 事没办成，灰溜溜回来 | 更接地气，但也更考验笔力 |
| 半成版 | 办到一半卡住了，她悄悄搭了把手 | 最耐看，但也最不好写 |

半成版的看点在他知不知道她出过手。他知道以后怎么办，就是高潮。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他做的事 | 自己接的活 · 考证 · 创业 · 回老家办事 · 打一场比赛 |
| 他的准备 | 熬夜 · 瞒着她 · 把她给的机会推了 |
| 她的克制 | 想帮又忍住 · 或者背地里帮一回 |
| 他发现她帮过 | 一个签名 · 一个电话 · 谁的一句话 |
| 他的反应 | 生气 → 缓过来 → 懂了她的意思 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她帮不帮 | 完全不帮 | 偷偷帮了一回 |
| 他知不知道 | 一直蒙在鼓里 | 知道了 |
| 结果 | 成了 | 没成 |
| 之后 | 他还是老样子 | 他收下了她的东西，但跟以前不一样了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把拨通的电话挂了 | 我要靠自己一次 |
| 内心 | 我能一句话解决，但不能说 | 输了也是我自己的 |
| 好的处理 | 她忍住不帮，也不提这茬 | 他栽了跟头，没冲别人发火 |
| 写崩 | 写成她从头管到尾 | 写成他赌气式的自立 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他去考功名／从军／不用她的荫封／自请外放 |
| 修仙 | 他自己去闯秘境／不用她给的法器 |
| 星际 | 他申请独立任务／不挂她的编制 |

#### 写崩的三种方式

1. 非让他赢不可。 让他输一回，读者反倒更认。
2. 她从头包到尾。 那这件事就不算他的了。
3. 让他为了「做自己」把这段关系推开。 想独立又离不开人，两样可以同时成立。

## 六 · 她提拔他

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：提携 14.2%

**骨架**｜她给了他一个机会，人人都想问一句凭啥。

#### 节拍链

名单上有他的名字 → 会上定了 → 同事的眼神 → 他问「为什么是我」→ 他拼命做 → 外部认可到来

#### 时间轴

任命一天就下来了，服众要一年。名单一公布，闲话就跟着来了。他当面问她「为什么是我」，她没急着回答，后来花了十二个月答给所有人看：客户点名要她，奖颁了下来，对手来挖人。外头的人认了，这事才算翻篇，名单上那点事从此没人再提。

#### 这条的核心难题

提拔这件事本身没毛病，麻烦出在旁人怎么看。她再公正，只要两人有这层关系，提拔就会被看成偏心。

他自己也会怀疑，这更麻烦。

| 谁在怀疑 | 表现 |
|---|---|
| 同事 | 眼神、议论、不配合 |
| 他 | 半夜想这件事 · 拼命做出成绩来证明 |
| 她 | 复盘自己是不是真的公正 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 决定的场合 | 开会时 · 她一句话拍板 · 或者她故意让别人开口 |
| 他的反应 | 没马上乐出来 · 先问「怎么是我」 |
| 同事 | 有人恭喜得过头 · 有人一声不吭 |
| 他的证明 | 天天加班 · 把活干到挑不出毛病 · 她后来想照顾他，他全躲开 |
| 收束 | 外面有人认了这事，客户、评审、别的领导都算，才算翻篇 |

最后要靠外人认可。她说十遍「你是靠实力」，抵不上一个不相干的人说一句。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 是否公正 | 完全公正 | 她确实偏了一点 |
| 他接不接 | 接了 | 拒绝，他要自己升上去 |
| 旁人 | 有人明说 | 没人说但气氛变了 |
| 收场 | 他做出了成绩 | 他离职去了别处 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她回头琢磨自己那件事办得公不公道 | 「怎么偏偏是我」 |
| 内心 | 我要是装没看见他，那才叫不公平 | 我不想欠人家的 |
| 好的处理 | 她让外人来评这个理 | 他做到让人挑不出毛病 |
| 写崩 | 写成她不许别人说话硬来 | 写成他占便宜还觉得应该 |

人明明够格，她却因为两人的关系不敢用，这也是偏私。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 荐他入朝／破格提拔／御史参她任人唯亲 |
| 修仙 | 传他核心功法／立他为亲传／门内不服 |
| 星际 | 把他调进核心组／人事系统标了红 |

#### 写崩的三种方式

1. 让他心安理得地接下。 他得问那句「为什么是我」。
2. 她把异议全压下去。 异议得留着。
3. 靠她出面辩解收场。 得靠外人认可。

## 七 · 他失业了

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：受挫 8.0%

**骨架**｜他丢了工作，没马上说，每天照常出门装样子。

#### 为什么更重

在这段关系里，只有工作是他不靠她得来的。两人本来就有差距，工作一丢，差得更多了。

#### 节拍链

被裁／项目黄 → 他没有立刻说 → 假装照常出门 → 被发现 → 那一场对话 → 之后的日子

「假装照常出门」，就是每天准点出门，在外头熬到下班的点再回家。

#### 时间轴

数的是他「假装照常出门」的天数。第一天他真去面试了，第三天开始在图书馆坐一整天，第七天被发现。多瞒一天，摊牌就难一倍。之后的日子按周走，节奏必须是他的：第一周她忍着不替他安排，第二周他自己找到了方向。

#### 可用细节

| 类 | 内容 |
|---|---|
| 隐瞒的痕迹 | 白天开过定位 · 咖啡馆小票没扔 · 手机 ✓ 电掉得不对劲 |
| 被发现的方式 | 她突然回家 · 他公司发来邮件 · 朋友嘴快说漏了 |
| 那场对话 | 她开口第一句，后面全看这口气 |
| 之后 | 他开始抢着干活 · 起得比鸡早 · 钱的事再也不碰 |
| 转折 | 他另找了路子 · 或者干脆换条道走 |

#### 她的第一句话，四个版本

| 说法 | 效果 |
|---|---|
| 「怎么不告诉我」 | 听着像怪罪，哪怕本意是关心 |
| 「没事，我养你」 | 好心，但最戳人 |
| 「先歇一阵」 | 话软，可没顾上他心里那道坎 |
| 「明天陪我去个地方」 | 最聪明，不提这事，给他找点事干 |

「我养你」在 GB 里碰不得。 传统言情拿它当承诺，到这里就成了说他没用。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 瞒了多久 | 三天 | 两个月 |
| 原因 | 公司裁员（非他之过） | 他自己搞砸的 |
| 她的处理 | 给钱 | 给事做 |
| 他的恢复 | 很快 | 一直没缓过来 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他这周每天七点出门，但公司没考勤 | 在咖啡馆坐到五点半 |
| 内心 | 我说什么都不对 | 我不能让她知道 |
| 好的处理 | 她不提钱，只给他一件具体的事 | 他自己开口说了 |
| 写崩 | 写成她说「我养你」 | 写成他自暴自弃 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 落第／罢官／被逐出师门／断了俸禄 |
| 修仙 | 修为跌境／被废丹田／灵根出问题 |
| 星际 | 被降级／调离一线／体检不达标 |

修仙版最狠：修为跌了境就回不去，「暂时失业」成了「永久失去」。

#### 写崩的三种方式

1. 用「我养你」收场。 见上。
2. 让他马上振作起来。 他得先消沉一阵。
3. 她一手包办，他只管接着。 他得自己迈出一步。

## 八 · 他比她强了

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：受挫 8.0% ＋ 提携 14.2% 的反向

**骨架**｜他成了事，成得比她还大，两个人得重新谈。

#### 节拍链

一次她习惯性买单他已付 → 变化累积 → 她的一点失落 → 谁先提出来谈 → 重新谈定 → 新的样子

#### 时间轴

变是慢慢变的，发现却是一下子。
账单、饭局、别人对她的称呼，半年里一点点变了味，两个人都装没看见。她心里那点不舒服，到某个时刻忽然清楚了，比如她习惯性掏手机买单，才发现他早付过了。
从看清到坐下来把话说开，隔得越短，越有救。拖过一个月，就别磨蹭了，直接去 [28-误会与信任](28-误会与信任.md) 报到。

#### 这条是这个类型最难写的一条

它碰到了根上的问题：差距要是没了，这段关系还算不算数？

三种答案，都成立：

| 答案 | 说法 | 后果 |
|---|---|---|
| 差距从来不算核心 | 他俩这关系，是自己选的 | 最稳，但前面得铺够 |
| 差距换了来源 | 钱上拉平了，别的地方还差着 | 最实在 |
| 关系确实变了 | 俩人重新聊，聊出个新活法 | 最真，也最考验笔头 |

这个问题不能躲。 他发达了，两人却一点没变，读者会觉得假。

#### 可用细节

| 类 | 内容 |
|---|---|
| 变化的信号 | 他开始抢着付钱 · 他给她买东西 · 他有了自己的朋友 · 别人开始喊他老板 |
| 她的不适 | 有一回她习惯性掏钱，他已经付了 · 她愣在那儿 |
| 他的试探 | 他会不会慢慢换一种处法 |
| 关键一场 | 碰到事，看谁拿主意 |
| 收束 | 俩人把话说开，或者一个动作定了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的态度 | 完全没变 | 开始想改变位置 |
| 她的态度 | 高兴 | 高兴里混着一点失落 |
| 结局 | 关系不变 | 关系变了，但两人都接受 |
| 谁先谈 | 她 | 他 |

「高兴里混着一点失落」必须写。 少了它，她就成了没有内心的工具人。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己有点别扭 | 我现在能给她买这个了 |
| 内心 | 我是不是盼着他别太强 | 我要不要改改自己 |
| 好的处理 | 她老实认了那点失落 | 他问她要不要变 |
| 写崩 | 写成她心里不痛快就冲他撒气 | 写成他一有钱就摆谱 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他官至她之上／军功盖过／族中地位反超 |
| 修仙 | 他修为超过她／她卡在瓶颈 |
| 星际 | 他升了将衔／她还在原岗 |

#### 写崩的三种方式

1. 两人关系一点没变。 读者看得出作者在躲。
2. 他一发达就翻身当家。 那就是另一个故事了。
3. 她因此打压他。 前面把她立起来的那些，一打压就全毁了。

## 九 · 加班到深夜的办公室

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：职场 33.9% ＋ 夜深 37.5% ＋ 加班 25.4%

**骨架**｜整层楼就剩一盏灯，灯下两个人。

#### 节拍链

整层只剩两盏灯 → 各忙各的 → 空调停了 → 一件小事（外套·咖啡）→ 收工 → 谁送谁

#### 时间轴

十点还亮着一半，到十一点，整层就剩他们这一盏。什么时候收工，活干没干完说了不算，要看谁先抬头，先抬头的那个就是今晚熬不住、想逃回家的。十二点一到，空调停了，整栋楼像断了电，一层层暗下去。两人谁也没开口，人却越坐越近。

#### 为什么这个场景高频

这个场景三样都占了：独处、正当理由、时间紧。也不用谁开口邀，两人都在加班，事情自己就来了。

#### 可用细节

| 声音 | 键盘声 · 打印机响 · 电梯“叮”一声，有人上来？ |
| 道具 | 外卖盒 · 咖啡 · 她外套撂椅背上 ✓ · 高跟鞋脱在桌子底下 |
| 时间 | 十点 → 十一点 → 空调停了 → 开始冷 |
| 契机 | 她冻着了 · 他把外套递过去 · 或者他干脆去把空调摁开 |

| 有没有人来 | 没人 | 保洁／同事半路折回来拿东西 |
| 发生了什么 | 啥也没发生 | 出了点小岔子 |

## 十 · 出差同行

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：出差 44.2% ＋ 职场 33.9%

**骨架**｜两个人出趟差，几天里躲不开地待在一块儿。

#### 节拍链

定行程 → 路上 → 订房那一步 → 白天工作模式 → 晚上私人模式 → 一个意外 → 回程有件事不一样了

#### 时间轴

白天照行程走，开会、拜访，公事公办，互相叫职务，三天两夜排得满满的。晚上没有行程，酒店走廊里道晚安那几分钟，透出来的东西比白天八个钟头还多。到了回程的航班上，有件事跟去的时候不一样了。

#### 为什么出差是浓缩装置

出差把两人平常的关系整个搬进一个封闭的地方，平时能躲一躲的家、朋友、各自的房间，全没了。

| 环节 | 会暴露什么 |
|---|---|
| 定行程 | 谁说了算 |
| 同行的路上 | 谁坐哪、谁靠着谁睡 |
| 订房 | 几间房，后面全看这一步 |
| 工作时 | 谁管谁 |
| 饭桌上 | 私下怎么处 |
| 意外：航班延误、下雨、他病了 | 真出事时啥样 |
| 回程 | 关系有没有变 |

订一间还是两间、谁订的、订错了怎么办，后面怎么走，都看这一步。

#### 可用细节

| 类 | 内容 |
|---|---|
| 路上 | 他睡着脑袋歪过来 · 她把外套 ✓ 给他盖上 · 行李谁拎 |
| 酒店 | 房卡 ✓ · 隔壁洗澡的水声 · 走廊地毯 · 她敲他门 |
| 工作时 | 跟平时完全两个人 |
| 意外 | 他闹肚子 · 航班取消 · 只剩一间房 |
| 回程 | 座位换了 · 要么一路没吭声 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 房 | 两间 | 只剩一间，老套但管用 |
| 出没出事 | 啥事没有 | 出了点小事 |
| 谁照顾谁 | 他水土不服她照顾 | 她累倒他照顾 |
| 回来后 | 跟以前一样 | 有件事变了但谁都不提 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 飞机上他睡着了头歪过来 | 隔着一堵墙 |
| 内心 | 出差这几天他不太一样 | 这几天不用装 |
| 好的处理 | 她工作时该干嘛干嘛 | 他没借着出差得寸进尺 |
| 写崩 | 写成公费旅游谈恋爱 | 写成他趁机找机会 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 随她外放／同赴任／驿站只剩一间上房 |
| 修仙 | 同去历练／秘境里只能同守一夜 |
| 星际 | 同一次任务／舱位只有一个 |

#### 写崩的三种方式

1. 光靠「只剩一间房」。 这招最省事，可前后的戏都得圆上。
2. 工作写着写着没了影。 他俩是出差去的，别忘了。
3. 回程跟去程一个样。 起码得有一件事变了。
