# 工作与金钱

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 现代都市为主
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**在没有女尊制度的世界里，钱和职位是权力落差最结实的来源，也是最容易伤人的。**

---

## 这一族为什么难写

现代 GB 有一个绕不开的问题：她凭什么在上？

古代女尊靠的是制度，ABO 靠的是生理，到了现代背景，就只能拼个人条件了。而个人条件里最硬的两样，就是职位和钱。所以绝大多数现代 GB 文，都绕不开这一套。

但这一族也最容易把男主写崩。现实里骂男人靠女人，词儿都是现成的：吃软饭、倒插门、小白脸。这些词一出来，读者立马自动代入那套评判，根本拦不住。

所以这一族的写作核心是他怎么在那个位置上还保住自己，不是她多有钱。

| 节拍族 | 作品数 | 占比 |
|---|---:|---:|
| 职场 | 955 | 33.0% |
| 上下级 | 492 | 17.0% |
| 提携 | 405 | 14.0% |
| 给钱 | 116 | 4.0% |
| 拒钱 | 222 | 7.7% |
| 受挫 | 310 | 10.7% |

「拒钱」的篇数几乎是「给钱」的两倍。这个差距是这一族里最醒目的实测结果：语料里写「他不要」的场面，比写「她给」的场面多得多。具体看第四条。

## 一 · 面试

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：职场 33.0%，初见＋职场高频同现

**骨架**｜桌子两边。她坐着提问，他坐着回答。

#### 节拍链

简历先到她手里 → 隔桌而坐 → 她问了简历外的问题 → 他稳住了 → 「回去等通知」或「明天来上班」

#### 时间轴

半小时的面试，节奏全看她问得多密。头十分钟按套路走，两边都在装。中间那个简历外的问题是个变道，空气卡了两秒。后面二十分钟才是真刀真枪。那句“回去等通知”到通知真来，中间那两天，他每小时掏一次手机。这两天就是这场面试的加时赛。

#### 为什么面试是最好的开局

它一次性给齐了三样东西：

| 给的 | 怎么给的 |
|---|---|
| 位置差 | 制度性的，不需要解释 |
| 信息差 | 她看过他的简历，他对她一无所知 |
| 时限 | 面试会结束，所以有紧迫感 |

而且这个位置差是临时的、正当的、可以被后续改变的，不像出身或财富那样固化。

#### 可用细节

| 类 | 内容 |
|---|---|
| 空间 | 桌子多宽 · 她有靠背椅子他没有 · 落地窗在她背后，逆光 |
| 道具 | 简历，她翻得多快 · 笔，她敲桌面 · 水，倒不倒给他 |
| 她的动作 | 不翻简历直接问 · 问个简历上没有的事 · 问到一半停下来看他 |
| 他的动作 | 手搁膝盖上 · 第一句嗓子发紧 · 后面慢慢稳了 |
| 结束 | 她说「回去等通知」还是「明天来上班」 |

「她问一个简历上没有的问题」是这条的技术核心：她已经查过他了，而他不知道。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的状态 | 就指着这份工资活 | 其实家里有矿，纯来体验生活 |
| 她的态度 | 按规矩走流程 | 头一回见面就琢磨怎么把人留下 |
| 结果 | 录了 | 没录，但偷偷塞了张名片 |
| 后来 | 他归她管 | 他去了别家，隔了挺久又撞上 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他答到第三个问题时松下来了 | 她翻简历的手停在第二页 |
| 内心 | 这人能用 | 她是不是已经把我摸透了 |
| 好的处理 | 她招他是因为他真行，不是图他好看 | 他答得漂亮，也不巴结人 |
| 写崩 | 写成她看脸才要人 | 写成他靠那张脸混进去 |

「因为他行」是这一族的通用底线。 一旦录用理由是私情，后面所有的职场戏都会失去分量。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 堂前问话／她隔着帘子打量／选侍时的甄别／科考殿试 |
| 修仙 | 收徒试炼／她探他的根骨／宗门大比 |
| 星际 | 入舰考核／她调他的档案／模拟测试成绩 |

#### 写崩的三种方式

1. 写成职场调情。面试的底气在“正当”俩字，一调情全完了。
2. 让她问点私事。越界了，她就不像个干活的，倒像个来搅局的。
3. 别写空间安排。桌子、椅子、光打哪儿来，这场戏的布景就齐了。

## 二 · 她是我上司

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：上下级 17.0%

**骨架**｜白天她是上司，晚上不是，切换的那一下，就是全部。

#### 节拍链

电梯门开（公司模式）→ 白天全名与汇报 → 下班那一步 → 切换 → 家里另一套 → 某天切换失败

#### 时间轴

一天两个身份，切换的开关卡在某个具体地点。早上电梯门一开，就是上班模式的启动键。晚上迈出公司大门那一步，直接关机。两点之间，你是全名加汇报。两点之外，你是另一个人。切换翻车的时候，比如家里顺嘴喊了句「张总」，或者开会差点把昵称秃噜出来，那就是这条线的车祸现场，一年来一次就够受的。

#### 双重身份的四种处理

| 处理 | 说明 | 风险 |
|---|---|---|
| 严格分离 | 公司里只谈公事，私下是另一副样子 | 最常见，也最有戏 |
| 完全不分 | 私下也端着上班那套 | 会让关系显得单薄 |
| 他分不清 | 他在公司里没切换过来 | 尴尬，也可爱 |
| 她分不清 | 她在家还跟下属似的下命令 | 更少见，值得写 |

「切换失败」是这条最好用的素材。他在会议室里差点叫出私下的称呼，或者她在家说话还带着公司的语气。

#### 可用细节

| 类 | 内容 |
|---|---|
| 公司里 | 她喊他全名 · 他站着回话她坐着 · 汇报时隔多远 · 她当面把他方案否了 |
| 私下 | 还是这俩人，动作全变样 |
| 切换点 | 电梯门一关 · 车门一关 · 迈出公司大门那一步 |
| 破绽 | 她手在会议桌底下 · 他递文件多停半秒 · 同事来一句「你俩挺熟啊」 |
| 制度问题 | 公司管不管办公室恋爱 · 有人捅上去 · HR 喊去谈话 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 公开程度 | 全公司都瞧见了 | 谁也没察觉 |
| 她的处理 | 工作上对他更狠 | 工作上对他松手，准出事 |
| 他的处理 | 拿成绩说话 | 自己提出来调走 |
| 冲突 | 当众把他方案否了 | 有一回她得在他和团队里挑一个 |

「工作上对他更严」是这个类型的高频且正确的选择。 更宽会让他失去职场立足点，也会让读者不服。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她当众否掉他方案后的那个下午 | 被否掉时心里那一下 |
| 内心 | 我是不是对他太狠了 | 她是对事不对人，我知道，但还是难受 |
| 好的处理 | 她私下不道歉，但给他改的机会 | 他改了，改得比谁都好 |
| 写崩 | 写成她公私不分 | 写成他借关系走捷径 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 朝堂与内院／她在堂上训他／回府后换了副面孔 |
| 修仙 | 师徒／宗门大比她判他输／私下里给他治伤 |
| 星际 | 舰长和副手／出任务她发号施令／回了舱她摘掉军衔 |

#### 写崩的三种方式

1. 让她在公事上偏袒。 一次就够毁掉他。
2. 省略切换点。 电梯门关上那一秒是这条的招牌镜头。
3. 让同事全程无感。 至少要有一个人看出来。

## 三 · 她当众否掉他

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：职场 33.0% ＋ 受挫 10.7%

**骨架**｜会议室，一桌子人，她说「不行」。

#### 节拍链

他上台 → 她说「不行」→ 会议室安静 → 他收材料 → 会后各走各的 → 晚上谁都不提 → 他改到凌晨

#### 时间轴

会议室里十秒，会议室外一整晚。「不行」两个字到他收起材料，不超过十秒。晚上回家谁都不提，不提的时长越长，凌晨那盏改方案的灯越亮。第二天她看到新版本的时点，就是这条的收束点。公私两条线各自了结，不许互相求情。

#### 这条的两难

她必须否掉，因为方案确实不行。但否掉的方式决定了这段关系的质地：

| 否法 | 效果 |
|---|---|
| 「不行，重做」 | 干脆，但当众落他面子 |
| 「这里有问题，你再看看」 | 给了台阶 |
| 会后单独说 | 保住面子，但同事会觉得她在护他 |
| 让别人来否 | 最坏，等于她不敢管 |

没有完美选项，这就是这条的价值。

#### 可用细节

| 类 | 内容 |
|---|---|
| 会议室 | 投影开着 · 他站在屏幕边上 · 她坐长桌那头 · 没人吭声 |
| 她的措辞 | 就事论事不点名 · 要么直接点人 |
| 他的反应 | 手指攥得发白 · 语气没变 · 「我明天改完给你」 |
| 会后 | 谁先出门 · 有没有人拍他一下 |
| 晚上 | 俩人都没提这事，或者他先开口了 |

「晚上两个人都不提」比「她道歉」好：工作上的事在工作上了结，是对他专业身份的尊重。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 方案 | 确实不行 | 行，但她有别的打算 |
| 她的方式 | 当众直说 | 私下单独聊 |
| 他的反应 | 接受 | 当场顶回去（更有戏） |
| 结局 | 他改了 | 他证明自己没错 |

「他当场反驳」这一端在四爱男读者那里评价很高：顺从不等于没有专业判断。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她说完不敢看他 | 手指关节发白，声音没变 |
| 内心 | 我必须这么说，可我知道他难受 | 她是对的，这才最难受 |
| 好的处理 | 她不在私下补偿 | 他改出来了，还改得更好 |
| 写崩 | 写成她借机立威 | 写成他委屈到影响工作 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 堂上驳回他的谏言／众臣面前 |
| 修仙 | 大比上她判他不合格／当着满门 |
| 星际 | 战术会议上她否掉他的方案 |

#### 写崩的三种方式

1. 让她借机立威。那会把职场戏变成权力戏。
2. 让他私下抱怨。抱怨会毁掉他的专业形象。
3. 让她私下道歉。工作的事别带回家。

## 四 · 她给钱，他不要

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拒钱 7.7% > 给钱 4.0%

**骨架**｜她把钱推过去，他又推回来。推来推去那几下，事就定了。

#### 节拍链

她转账或塞卡 → 他发现 → 原路退回 → 她问为什么 → 他给理由 → 改成借与记账 → 立了字据

#### 时间轴

推拒按回合算，一回合隔一天。转钱、退回去、再转、再退，三个回合完了才坐下谈。说「借」、写欠条，那就是停战。欠条签了不算完。他啥时候还钱，自己心里有数，每个月一格，她从来不催。催一次，欠条等于白签。

#### 实测发现：「不要」比「给」写得多

| 节拍族 | 篇数 | 占比 |
|---|---:|---:|
| 拒钱 | 222 | 7.7% |
| 给钱 | 116 | 4.0% |

近两倍。这个类型的语料更关心他怎么拒绝，而不是她怎么给。

原因不难理解：给钱是她的日常动作，不构成戏，而他拒绝的方式，直接决定了读者对他的评价。

#### 拒绝的四档，从差到好

| 档 | 说法 | 读者观感 |
|---|---|---|
| 差 | 「我不是吃软饭的」 | 把骂人的话写出来了 |
| 一般 | 「我自己有」 | 干净但有点冷 |
| 好 | 没吭声，把东西推回去，第二天又偷偷多接了个活 | 用事说话 |
| 最好 | 收下了，心里记着账，她也看得出来 | 两边都不丢面子 |

最后一档是这一族的最优解。 它不否认落差，但它给了这段关系一个可持续的形状。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 工资卡 ✓ · 存折 ✓ · 转账记录 · 他自己记的本子 · 信封 |
| 她的给法 | 直接转 · 塞进他外套 ✓ 口袋 ✓ · 替他付掉某笔 · 不说 |
| 他的发现 | 账单已经结清 · 房租有人交过 |
| 他的处理 | 原路退回 · 打工还上 · 收下但记账 |
| 她的反应 | 生气，觉得他见外 · 或者她懂 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 金额 | 小（一顿饭） | 大（房子、医药费） |
| 紧急度 | 他不缺 | 他家里出事，急需 |
| 他的选择 | 收 | 不收 |
| 她的态度 | 尊重他的拒绝 | 强行给（会伤人） |
| 结果 | 找到平衡 | 这件事成了长期心结 |

「他家里出事急需」这一端是这条的最高难度。 尊严与现实冲突，且没有正确答案。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 钱被推回来的那一下 | 数字看见的那一秒 |
| 内心 | 我又不是施舍，他干嘛这样 | 收了我就完了 |
| 好的处理 | 她换个法子给（借、投资、算工钱） | 他把不收的原因讲明白 |
| 写崩 | 写成她拿钱砸人 | 写成他面子大过天，油盐不进 |

「换一种给法」是她能做的最体面的事： 把赠予改成借贷或交易，落差还在，但尊严保住了。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 赏赐／月例／赏的东西他收着不用／她给他买房置地 |
| 修仙 | 灵石／丹药／她送的法器他舍不得用 |
| 星际 | 配额／军饷／她把自己的那份划给他 |
| 末世 | 物资／她偷偷多留的那几罐罐头 |

末世版最狠：物资就是命。在这个世界里，拒绝接受等于选择死亡，「不要」这两个字，才真正有了重量。

#### 写崩的三种方式

1. 让羞辱词进正文。「吃软饭」这类词一出来，读者自己就会带入外部评价体系。
2. 让他为了自尊把家人扔一边。那是执拗，不是骨气。
3. 让她强行给，且不理解他。她要懂，只是不同意。

#### 示例（本库自撰，可直接改写）

> 转账记录在他手机上停了一整晚，红色的那个数字他看了很多遍。
> 第二天早上他原路退了回去，没有附言。
> 她中午打来电话：「你什么意思。」
> 「我自己有。」
> 「你妈住院要多少你自己有？」
> 他没说话。听筒里有她那边的键盘声，敲了几下，停了。
> 「算我借你的。」她说，「写个条，按你说的利息。」
> 他愣了很久，说：「好。」

## 五 · 他要证明自己

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：受挫 10.7% ＋ 提携 14.0%

**骨架**｜他去做一件不靠她也能成的事。

#### 节拍链

他推掉她的安排 → 自己接了一件事 → 瞒着做 → 她想帮忍住了 → 成或败 → 他回来说结果

#### 时间轴

瞒多久，赌注就下多大。从找借口推掉她的安排，到最后一口气摊牌，中间那几个月他两头硬扛。她好几次想伸手帮一把，又硬生生缩回去。看他熬夜，听他说碰壁，忍了又忍。等真相揭晓那天，俩人心里那根弦都松了，但松的劲儿不一样。他松的是输赢，她松的是“总算不用再装了”。

#### 为什么这条必须有

如果他从头到尾都在她的荫蔽下，这个角色就没有独立的价值，关系也就变成了单向供养。

他需要一件属于自己的事。 这件事不一定要成功，但必须是他自己的。

#### 三种版本

| 版本 | 做法 | 结局 |
|---|---|---|
| 成功版 | 他自己办成了，没靠别人 | 两人重新站到一块儿 |
| 失败版 | 事没办成，灰溜溜回来 | 更接地气，但也更考验笔力 |
| 半成版 | 办到一半卡住了，她悄悄搭了把手 | 最耐看，但也最不好写 |

半成版的关键是他知不知道她帮过。 知道了怎么办，是这条的高潮。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他做的事 | 自己接的活 · 考证 · 创业 · 回老家办事 · 打一场比赛 |
| 他的准备 | 熬夜 · 瞒着她 · 把她给的机会推了 |
| 她的克制 | 想帮又忍住 · 或者背地里帮一回 |
| 他发现她帮过 | 一个签名 · 一个电话 · 谁的一句话 |
| 他的反应 | 生气 → 缓过来 → 懂了她的意思 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她帮不帮 | 完全不帮 | 偷偷帮了一回 |
| 他知不知道 | 一直蒙在鼓里 | 知道了 |
| 结果 | 成了 | 没成 |
| 之后 | 他还是老样子 | 他收下了她的东西，但跟以前不一样了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把拨通的电话挂了 | 我要靠自己一次 |
| 内心 | 我能一句话解决，但不能说 | 输了也是我自己的 |
| 好的处理 | 她忍住不帮，也不提这茬 | 他栽了跟头，没冲别人发火 |
| 写崩 | 写成她从头管到尾 | 写成他赌气式的自立 |

「她把已经拨通的电话挂掉了」是这条最好的一个动作。 忍住不帮，比帮了更难。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他去考功名／从军／不用她的荫封／自请外放 |
| 修仙 | 他自己去闯秘境／不用她给的法器 |
| 星际 | 他申请独立任务／不挂她的编制 |

#### 写崩的三种方式

1. 让他必须赢。写他输一次，读者更买账。
2. 让她从头管到尾。那这事就跟他没关系了。
3. 让他为了「做自己」把关系推开。可人一边想独立，一边又离不开人，这不矛盾。

## 六 · 她提拔他

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：提携 14.0%

**骨架**｜她给了他一个机会，可所有人都想问，凭啥。

#### 节拍链

名单上有他的名字 → 会上定了 → 同事的眼神 → 他问「为什么是我」→ 他拼命做 → 外部认可到来

#### 时间轴

任命只要一天，服众要一年。名单公布那天，闲话就跟着来了。他当面问了她一句「为什么是我」，之后用十二个月回答所有人。等外面的人认了，客户点名要她，奖颁下来了，对手来挖人了，这事才算翻篇。从那天起，名单上那点事再没人提。

#### 这条的核心难题

提拔本身没问题，问题是旁人的解释。哪怕她完全公正，只要关系存在，这个动作就会被读成偏私。

而更麻烦的是：他自己也会怀疑。

| 谁在怀疑 | 表现 |
|---|---|
| 同事 | 眼神、议论、不配合 |
| 他 | 半夜想这件事 · 拼命做出成绩来证明 |
| 她 | 复盘自己是不是真的公正 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 决定的场合 | 开会时 · 她一句话拍板 · 或者她故意让别人开口 |
| 他的反应 | 没马上乐出来 · 先问「怎么是我」 |
| 同事 | 有人恭喜得过头 · 有人一声不吭 |
| 他的证明 | 天天加班 · 把活干到挑不出毛病 · 她后来想照顾他，他全躲开 |
| 收束 | 外面有人认了这事，客户、评审、别的领导都算，才算翻篇 |

「外部的认可」是唯一能真正解决这条的东西。她说十遍「你是靠实力」，都不如一个不相干的人说一句。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 是否公正 | 完全公正 | 她确实偏了一点 |
| 他接不接 | 接了 | 拒绝，他要自己升上去 |
| 旁人 | 有人明说 | 没人说但气氛变了 |
| 收场 | 他做出了成绩 | 他离职去了别处 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她回头琢磨自己那件事办得公不公道 | 「怎么偏偏是我」 |
| 内心 | 我要是装没看见他，那才叫不公平 | 我不想欠人家的 |
| 好的处理 | 她让外人来评这个理 | 他做到让人挑不出毛病 |
| 写崩 | 写成她不许别人说话硬来 | 写成他占便宜还觉得应该 |

「我要是不提他，反而是另一种不公」是这条最好的一句内心戏。因为关系而不敢用一个合格的人，这同样是偏私。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 荐他入朝／破格提拔／御史参她任人唯亲 |
| 修仙 | 传他核心功法／立他为亲传／门内不服 |
| 星际 | 把他调进核心组／人事系统标了红 |

#### 写崩的三种方式

1. 让他毫无负担地接受。那句「为什么是我」是这条的门。
2. 让她压下所有异议。异议要留着。
3. 靠她的辩解收场。要靠外部认可。

前接：[五 · 他要证明自己](#五--他要证明自己)

## 七 · 他失业了

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：受挫 10.7%

**骨架**｜他失业了。在这个题材里，这件事的分量比别的类型重得多。

#### 为什么更重

因为工作是他在这段关系里唯一的独立支点。落差本来就在，工作没了，落差就变成了悬崖。

#### 节拍链

被裁／项目黄 → 他没有立刻说 → 假装照常出门 → 被发现 → 那一场对话 → 之后的日子

「假装照常出门」是这条的招牌镜头。 他每天准点出门，在外面待到下班时间再回来。

#### 时间轴

「假装照常出门」的天数，是这条的核心计时。第一天他真去面试了，第三天开始在图书馆坐一天，第七天被发现。每多瞒一天，摊牌的难度就翻一倍。之后的日子按周走。第一周她忍着不安排，第二周他自己有了方向，节奏必须是他的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 隐瞒的痕迹 | 白天开过定位 · 咖啡馆小票没扔 · 手机 ✓ 电掉得不对劲 |
| 被发现的方式 | 她突然回家 · 他公司发来邮件 · 朋友嘴快说漏了 |
| 那场对话 | 她开口第一句，后面全看这口气 |
| 之后 | 他开始抢着干活 · 起得比鸡早 · 钱的事再也不碰 |
| 转折 | 他另找了路子 · 或者干脆换条道走 |

#### 她的第一句话，四个版本

| 说法 | 效果 |
|---|---|
| 「怎么不告诉我」 | 听着像怪罪，哪怕本意是关心 |
| 「没事，我养你」 | 好心，但最戳人 |
| 「先歇一阵」 | 话软，可没顾上他心里那道坎 |
| 「明天陪我去个地方」 | 最聪明，不提这事，给他找点事干 |

「我养你」这句在 GB 里是雷。 传统言情里它是承诺，这里它是判决。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 瞒了多久 | 三天 | 两个月 |
| 原因 | 公司裁员（非他之过） | 他自己搞砸的 |
| 她的处理 | 给钱 | 给事做 |
| 他的恢复 | 很快 | 一直没缓过来 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他这周每天七点出门，但公司没考勤 | 在咖啡馆坐到五点半 |
| 内心 | 我说什么都不对 | 我不能让她知道 |
| 好的处理 | 她不提钱，只给他一件具体的事 | 他自己开口说了 |
| 写崩 | 写成她说「我养你」 | 写成他自暴自弃 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 落第／罢官／被逐出师门／断了俸禄 |
| 修仙 | 修为跌境／被废丹田／灵根出问题 |
| 星际 | 被降级／调离一线／体检不达标 |

修仙版最狠：修为跌境是不可逆的，它把「暂时失业」变成了「永久失去」，写好了极重。

#### 写崩的三种方式

1. 用「我养你」收场。见上。
2. 让他立刻振作。得先有一段沉下去的时间。
3. 让她全程处理，他被动接受。他得自己走出来一步。

## 八 · 他比她强了

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：受挫 10.7% ＋ 提携 14.0% 的反向

**骨架**｜他干成了，还干得比她大。这关系，得重新谈。

#### 节拍链

一次她习惯性买单他已付 → 变化累积 → 她的一点失落 → 谁先提出来谈 → 重新谈定 → 新的样子

#### 时间轴

变化是慢慢来的，可发现是一下子的。
账单、饭局、别人怎么喊她，半年里一点点变味，两个人都装没看见。她那点不舒服，在某个瞬间突然对上焦了——比如习惯性掏手机买单，发现他早付完了。
从对上焦到坐下来把话说开，隔得越短，这段关系越有救。拖过一个月，那就别磨蹭了，直接去 [28-误会与信任](28-误会与信任.md) 报到吧。

#### 这条是这个类型最难写的一条

因为它触到了根：如果落差消失了，这段关系还成立吗？

三种答案，都成立：

| 答案 | 说法 | 后果 |
|---|---|---|
| 落差从来不是核心 | 他俩这关系，是自己选的，不是谁配不上谁 | 最稳，但前面得铺够 |
| 落差换了来源 | 钱上拉平了，别的地方还差着 | 最实在 |
| 关系确实变了 | 俩人重新聊，聊出个新活法 | 最真，也最考验笔头 |

不能回避这个问题。 让他发达之后关系毫无变化，读者会觉得假。

#### 可用细节

| 类 | 内容 |
|---|---|
| 变化的信号 | 他开始抢着付钱 · 他给她买东西 · 他有了自己的朋友 · 别人开始喊他老板 |
| 她的不适 | 有一回她习惯性掏钱，他已经付了 · 她愣在那儿 |
| 他的试探 | 他会不会慢慢换一种处法 |
| 关键一场 | 碰到事，看谁拿主意 |
| 收束 | 俩人把话说开，或者一个动作定了 |

「一次她习惯性买单，他已经付了」是这条的开场镜头。 一个动作说明了全部变化。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的态度 | 完全没变 | 开始想改变位置 |
| 她的态度 | 高兴 | 高兴里混着一点失落 |
| 结局 | 关系不变 | 关系变了，但两人都接受 |
| 谁先谈 | 她 | 他 |

「高兴里混着一点失落」这句必须写。 不写它，她就成了没有内心的功能角色。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己有点别扭 | 我现在能给她买这个了 |
| 内心 | 我是不是盼着他别太强 | 我要不要改改自己 |
| 好的处理 | 她老实认了那点失落 | 他问她要不要变 |
| 写崩 | 写成她心里不痛快就冲他撒气 | 写成他一有钱就摆谱 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他官至她之上／军功盖过／族中地位反超 |
| 修仙 | 他修为超过她／她卡在瓶颈 |
| 星际 | 他升了将衔／她还在原岗 |

#### 写崩的三种方式

1. 让关系毫无变化。读者看得出来你在回避问题。
2. 让他一发达就翻身做主。那是另一个故事了。
3. 让她因此打压他。打压会毁掉前面所有的正面塑造。

## 九 · 加班到深夜的办公室

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：职场 33.0% ＋ 夜深 37.0% ＋ 加班 25.0%

**骨架**｜整层楼只剩两个人和一盏灯。

#### 节拍链

整层只剩两盏灯 → 各忙各的 → 空调停了 → 一件小事（外套·咖啡）→ 收工 → 谁送谁

#### 时间轴

整层楼的灯就是钟。十点还亮着一半，十一点就剩他们俩这盏了，十二点空调一停，整栋楼跟关机似的，一层一层暗下去。两个人谁也没说话，但距离越坐越近。收工不看活干完没干完，看谁先抬头——谁先抬头，谁就是今晚熬不住、想逃回家那个。

#### 为什么这个场景高频

它同时满足三件事：独处、正当理由、时间压力。而且不需要任何人开口邀请，两个人都在加班，这事就自然发生了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 空间 | 就她这片还亮着 · 旁边工位全黑了 · 保洁早走了 · 空调也到点停了 |
| 声音 | 键盘声 · 打印机响 · 电梯“叮”一声，有人上来？ |
| 道具 | 外卖盒 · 咖啡 · 她外套撂椅背上 ✓ · 高跟鞋脱在桌子底下 |
| 时间 | 十点 → 十一点 → 空调停了 → 开始冷 |
| 契机 | 她冻着了 · 他把外套递过去 · 或者他干脆去把空调摁开 |

「她的高跟鞋脱在桌下」是这条的一个高效细节：卸下装备的那一刻，上司身份也松了一格。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁陪谁 | 他陪她（他其实忙完了） | 她陪他 |
| 有没有人来 | 没人 | 保洁／同事半路折回来拿东西 |
| 发生了什么 | 啥也没发生 | 出了点小岔子 |
| 结束 | 各走各的 | 她送他回去 |

「他其实做完了但没走」是这条最省事的动机交代。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她抬头发现只剩他还亮着灯 | 她还没走，我就不走 |
| 内心 | 他做完了为什么不走 | 别让她一个人在这儿 |
| 好的处理 | 她没赶他，也没留他 | 他没说为啥还在 |
| 写崩 | 写成办公室暧昧套路 | 写成他故意找机会 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 书房批文到三更／他在外间守着／换了两回烛 |
| 修仙 | 议事殿只剩两人／灯烛与阵光 |
| 星际 | 舰桥夜班／只有仪表灯 |

#### 写崩的三种方式

1. 直接进入暧昧。这条的价值在克制。
2. 省略时间推进。空调定时停了这类细节就是钟。
3. 让他刻意制造独处。自然发生才好。

## 十 · 出差同行

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：出差 43.0% ＋ 职场 33.0%

**骨架**｜两个人，出趟差，几个小时躲不开得待一块儿。

#### 节拍链

定行程 → 路上 → 订房那一步 → 白天工作模式 → 晚上私人模式 → 一个意外 → 回程有件事不一样了

#### 时间轴

三天两夜，白天和晚上是两套时间。白天按行程表走，开会、拜访，公事公办，互相称呼职务。晚上没有表，酒店走廊里道晚安的那几分钟，比白天八小时的信息量都大。回程航班上，有件事和去程不一样了。具体是什么，写的人自己挑。

#### 为什么出差是浓缩装置

它把日常关系打包搬到一个封闭空间里，且去掉了所有日常的缓冲，比如家、朋友、各自的房间。

| 环节 | 会暴露什么 |
|---|---|
| 定行程 | 谁说了算 |
| 同行的路上 | 谁坐哪、谁靠着谁睡 |
| 订房 | 几间房，这一步是整场戏的钥匙 |
| 工作时 | 谁管谁 |
| 饭桌上 | 私下怎么处 |
| 意外：航班延误、下雨、他病了 | 真出事时啥样 |
| 回程 | 关系有没有变 |

「订房」是这条的开关。 一间还是两间、谁订的、订错了怎么办，这一个动作决定了后面全部的走向。

#### 可用细节

| 类 | 内容 |
|---|---|
| 路上 | 他睡着脑袋歪过来 · 她把外套 ✓ 给他盖上 · 行李谁拎 |
| 酒店 | 房卡 ✓ · 隔壁洗澡的水声 · 走廊地毯 · 她敲他门 |
| 工作时 | 跟平时完全两个人 |
| 意外 | 他闹肚子 · 航班取消 · 只剩一间房 |
| 回程 | 座位换了 · 要么一路没吭声 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 房 | 两间 | 只剩一间，老套但管用 |
| 出没出事 | 啥事没有 | 出了点小事 |
| 谁照顾谁 | 他水土不服她照顾 | 她累倒他照顾 |
| 回来后 | 跟以前一样 | 有件事变了但谁都不提 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 飞机上他睡着了头歪过来 | 隔着一堵墙 |
| 内心 | 出差这几天他不太一样 | 这几天不用装 |
| 好的处理 | 她工作时该干嘛干嘛 | 他没借着出差得寸进尺 |
| 写崩 | 写成公费旅游谈恋爱 | 写成他趁机找机会 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 随她外放／同赴任／驿站只剩一间上房 |
| 修仙 | 同去历练／秘境里只能同守一夜 |
| 星际 | 同一次任务／舱位只有一个 |

#### 写崩的三种方式

1. 只写「只剩一间房」。 最省事，但前后都得把戏圆上。
2. 让工作彻底没影。 他俩是去出差的，别写着写着忘了。
3. 回程别跟去时一个样。 好歹留一件事变了。
