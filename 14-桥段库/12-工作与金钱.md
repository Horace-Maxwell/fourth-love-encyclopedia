# 工作与金钱

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 现代都市为主
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**在没有女尊制度的世界里，钱和职位是权力落差最结实的来源，也是最容易伤人的。**

---

## 这一族为什么难写

现代 GB 有一个绕不开的问题：她凭什么在上？

古代女尊靠制度，ABO 靠生理，现代只能靠个人条件——而个人条件里最硬的两样就是职位和钱。于是绝大多数现代 GB 都会用到这一族。

但这一族同时是最容易把男主写崩的地方。现实社会对「男性靠女人」有一整套现成的羞辱词：吃软饭、倒插门、小白脸。这些词一旦进入文本，读者会自动带入那套评价体系。

所以这一族的写作核心是他怎么在那个位置上还保住自己，不是她多有钱。

| 节拍族 | 作品数 | 占比 |
|---|---:|---:|
| 职场 | 955 | 33.0% |
| 上下级 | 492 | 17.0% |
| 提携 | 405 | 14.0% |
| 给钱 | 116 | 4.0% |
| 拒钱 | 222 | 7.7% |
| 受挫 | 310 | 10.7% |

「拒钱」的篇数几乎是「给钱」的两倍。 这个不对称是这一族最重要的实测发现：语料里写「他不要」的场面，多于写「她给」的场面。见第四条。

## 一 · 面试

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：职场 33.0%，初见＋职场高频同现

**骨架**｜桌子两边。她坐着提问，他坐着回答。

#### 节拍链

简历先到她手里 → 隔桌而坐 → 她问了简历外的问题 → 他稳住了 → 「回去等通知」或「明天来上班」

#### 时间轴

半小时的面试，节奏由她的提问密度控制。 前十分钟按流程走（双方都在演），中间那个简历外的问题是变速点，空气停两秒；之后的二十分钟是真面试。「回去等通知」到通知抵达之间的那两天，他每小时看一次手机，这两天是这条的延长赛。

#### 为什么面试是最好的开局

它一次性给齐了三样东西：

| 给的 | 怎么给的 |
|---|---|
| 位置差 | 制度性的，不需要解释 |
| 信息差 | 她看过他的简历，他对她一无所知 |
| 时限 | 面试会结束，所以有紧迫感 |

而且这个位置差是临时的、正当的、可以被后续改变的，不像出身或财富那样固化。

#### 可用细节

| 类 | 内容 |
|---|---|
| 空间 | 桌子的宽度 · 她的椅子有靠背他的没有 · 落地窗在她背后（逆光） |
| 道具 | 简历（她翻的速度）· 笔（她敲桌面）· 水（给不给他倒） |
| 她的动作 | 不看简历直接问 · 问一个简历上没有的问题 · 中途停下来看他 |
| 他的动作 | 手放在膝盖上 · 声音第一句发紧 · 后来稳住了 |
| 结束 | 她说「回去等通知」还是「明天来上班」 |

「她问一个简历上没有的问题」是这条的技术核心：她已经查过他了，而他不知道。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的状态 | 需要这份工作 | 他其实不缺，来试试 |
| 她的态度 | 公事公办 | 从第一眼就想留他 |
| 结果 | 录用 | 不录用（但留了联系方式） |
| 后来 | 他成了她下属 | 他去了别处，很久以后再遇 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他答到第三个问题时松下来了 | 她翻简历的手停在第二页 |
| 内心 | 这个人能用 | 她已经知道我什么了 |
| 好的处理 | 她录用他是因为他行，不是因为好看 | 他答得好，且不谄媚 |
| 写崩 | 写成她因私情录用 | 写成他靠脸上位 |

「因为他行」是这一族的通用底线。 一旦录用理由是私情，后面所有的职场戏都会失去分量。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 堂前问话／她隔着帘子／选侍时的甄别／科考殿试 |
| 修仙 | 收徒试炼／她看他的根骨／宗门大比 |
| 星际 | 入舰考核／她调他的档案／模拟测试成绩 |

#### 写崩的三种方式

1. 写成职场调情。 面试的力量在正当性，一调情就废了。
2. 让她问私人问题。 越界会让她显得不专业。
3. 省略空间安排。 桌子、椅子、光的方向就是这场戏的全部布景。

## 二 · 她是我上司

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：上下级 17.0%

**骨架**｜白天她是上司，晚上不是。切换的那个瞬间是全部内容。

#### 节拍链

电梯门开（公司模式）→ 白天全名与汇报 → 下班那一步 → 切换 → 家里另一套 → 某天切换失败

#### 时间轴

一天两次切换，切换点精确到某个物理位置。 早上电梯门开是上班模式的开机键，晚上出公司大门那一步是关机键，两点之间全名与汇报，两点之外另一套。切换失败的那次（家里喊了句「张总」，或会上差点说漏昵称）是这条的事故现场，一年一次就够。

#### 双重身份的四种处理

| 处理 | 说明 | 风险 |
|---|---|---|
| 严格分离 | 公司里绝对公事，私下完全不同 | 最常见，也最有戏 |
| 完全不分 | 私下也是那一套 | 会让关系显得单薄 |
| 他分不清 | 他在公司里没能切换过来 | 尴尬，也可爱 |
| 她分不清 | 她在家里还在下命令 | 更少见，值得写 |

「切换失败」是这条最好用的素材。 他在会议室里差点叫出私下的称呼，或者她在家里说话还带着公司的语气。

#### 可用细节

| 类 | 内容 |
|---|---|
| 公司里 | 她叫他全名 · 他站着她坐着 · 汇报时的距离 · 她当众否掉他的方案 |
| 私下 | 同样两个人，动作完全不同 |
| 切换点 | 电梯门关上 · 车门关上 · 走出公司大门那一步 |
| 破绽 | 她的手在会议桌下 · 他递文件时多停了半秒 · 同事说「你俩挺熟啊」 |
| 制度问题 | 公司禁不禁办公室恋情 · 有人举报 · HR 找谈话 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 公开程度 | 全公司都知道 | 一个人都不知道 |
| 她的处理 | 工作上对他更严 | 工作上对他更宽（会出事） |
| 他的处理 | 靠实绩证明自己 | 主动申请调离 |
| 冲突 | 一次公开否决他的方案 | 一次她必须在他和团队之间选 |

「工作上对他更严」是这个类型的高频且正确的选择。 更宽会让他失去职场立足点，也会让读者不服。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她当众否掉他方案后的那个下午 | 被否掉的时候心里那一下 |
| 内心 | 我是不是对他太狠了 | 她是对事不对人，我知道，但还是难受 |
| 好的处理 | 她私下也不道歉，但她给了他改的机会 | 他改了，改得比谁都好 |
| 写崩 | 写成她公私不分 | 写成他借关系走捷径 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 朝堂与内院／她在堂上斥他／回府后是另一副样子 |
| 修仙 | 师徒／宗门大比上她判他输／私下替他疗伤 |
| 星际 | 舰长与副手／任务中她下命令／舱内她卸下军衔 |

#### 写崩的三种方式

1. 让她在公事上偏袒。 一次就够毁掉他。
2. 省略切换点。 电梯门关上那一秒是这条的招牌镜头。
3. 让同事全程无感。 至少要有一个人看出来。

## 三 · 她当众否掉他

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：职场 33.0% ＋ 受挫 10.7%

**骨架**｜会议室，一桌子人，她说「不行」。

#### 节拍链

他上台 → 她说「不行」→ 会议室安静 → 他收材料 → 会后各走各的 → 晚上谁都不提 → 他改到凌晨

#### 时间轴

会议室里十秒，会议室外一整晚。 「不行」两个字到他收起材料，不超过十秒；晚上回家谁都不提，不提的时长越长，凌晨那盏改方案的灯越亮。第二天她看到新版本的时点，是这条的收束点：公私两条线各自了结，不许互相求情。

#### 这条的两难

她必须否掉，因为方案确实不行。但否掉的方式决定了这段关系的质地：

| 否法 | 效果 |
|---|---|
| 「不行，重做」 | 干脆，但当众落他面子 |
| 「这里有问题，你再看看」 | 给了台阶 |
| 会后单独说 | 保住面子，但同事会觉得她在护他 |
| 让别人来否 | 最坏，等于她不敢管 |

没有完美选项，这就是这条的价值。

#### 可用细节

| 类 | 内容 |
|---|---|
| 会议室 | 投影 · 他站在屏幕旁 · 她坐在长桌另一端 · 其他人不敢出声 |
| 她的措辞 | 只说问题不说人 · 或者点名 |
| 他的反应 | 手指关节发白 · 声音没变 · 「我明天改出来」 |
| 会后 | 谁先走出会议室 · 有没有人拍他肩膀 |
| 晚上 | 两个人都不提这件事，或者他先提了 |

「晚上两个人都不提」比「她道歉」好：工作上的事在工作上了结，是对他专业身份的尊重。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 方案 | 确实不行 | 行，但她另有考量 |
| 她的方式 | 当众直说 | 会后单独说 |
| 他的反应 | 接受 | 当场反驳（更有戏） |
| 结局 | 他改好了 | 他证明了自己是对的 |

「他当场反驳」这一端在四爱男读者那里评价很高：顺从不等于没有专业判断。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她说完之后不敢看他 | 手指关节发白但声音没变 |
| 内心 | 我必须这么说，但我知道他难受 | 她是对的，这才是最难受的 |
| 好的处理 | 她不在私下补偿这件事 | 他改出来了，改得更好 |
| 写崩 | 写成她借机立威 | 写成他委屈到影响工作 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 堂上驳回他的谏言／众臣面前 |
| 修仙 | 大比上她判他不合格／当着满门 |
| 星际 | 战术会议上她否掉他的方案 |

#### 写崩的三种方式

1. 让她借机立威。 那会把职场戏变成权力戏。
2. 让他私下抱怨。 抱怨会毁掉他的专业形象。
3. 让她私下道歉。 工作的事别带回家。

## 四 · 她给钱，他不要

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拒钱 7.7% > 给钱 4.0%

**骨架**｜她把钱推过去，他推回来。推来推去的那几个回合就是全部。

#### 节拍链

她转账或塞卡 → 他发现 → 原路退回 → 她问为什么 → 他给理由 → 改成借与记账 → 立了字据

#### 时间轴

推拒以回合计，每回合隔一天。 转账、退回、再转、再退，三个回合后进入谈判；「借」与字据是停战协议。字据签完这条没完：他还钱的进度表贴在他心里，每月一格，她从不催，催一次，字据就白签了。

#### 实测发现：「不要」比「给」写得多

| 节拍族 | 篇数 | 占比 |
|---|---:|---:|
| 拒钱 | 222 | 7.7% |
| 给钱 | 116 | 4.0% |

近两倍。这个类型的语料更关心他怎么拒绝，而不是她怎么给。

原因不难理解：给钱是她的日常动作，不构成戏；而他拒绝的方式，直接决定了读者对他的评价。

#### 拒绝的四档，从差到好

| 档 | 说法 | 读者观感 |
|---|---|---|
| 差 | 「我不是吃软饭的」 | 把羞辱词请进了文本 |
| 一般 | 「我自己有」 | 干净但生硬 |
| 好 | 沉默地推回去，然后第二天多接了一份活 | 用行动 |
| 最好 | 收下，但记账，且她知道他在记 | 既接受了她，也保住了自己 |

最后一档是这一族的最优解。 它不否认落差，但它给了这段关系一个可持续的形状。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 工资卡 ✓ · 存折 ✓ · 转账记录 · 一个他自己记的本子 · 信封 |
| 她的给法 | 直接转 · 塞进他外套 ✓ 口袋 ✓ · 替他付掉某笔 · 不说 |
| 他的发现 | 账单已经结清了 · 房租有人交过了 |
| 他的处理 | 原路退回 · 打工还上 · 收下但记账 |
| 她的反应 | 生气（觉得他见外）· 或者她懂 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 金额 | 小（一顿饭） | 大（房子、医药费） |
| 紧急度 | 他不缺 | 他家里出事，急需 |
| 他的选择 | 收 | 不收 |
| 她的态度 | 尊重他的拒绝 | 强行给（会伤人） |
| 结果 | 找到平衡 | 这件事成了长期心结 |

「他家里出事急需」这一端是这条的最高难度。 尊严与现实冲突，且没有正确答案。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 钱被推回来的那一下 | 数字看见的那一秒 |
| 内心 | 我又不是施舍，他为什么这样 | 收了我就没了 |
| 好的处理 | 她换一种给法（借、投资、算工资） | 他说清楚为什么不能收 |
| 写崩 | 写成她用钱压人 | 写成他自尊过剩到不通情理 |

「换一种给法」是她能做的最体面的事： 把赠予改成借贷或交易，落差还在，但尊严保住了。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 赏赐／月例／他把赏的东西封存不用／她给他置产 |
| 修仙 | 灵石／丹药／她给的法器他不肯用 |
| 星际 | 配额／军饷／她把自己的份额划给他 |
| 末世 | 物资／她多留的那份罐头 |

末世版最狠：在物资即生命的世界里，拒绝接受等于选择死亡，这让「不要」这个动作有了真正的重量。

#### 写崩的三种方式

1. 让羞辱词进正文。 「吃软饭」这类词一旦出现，读者会自动带入外部评价体系。
2. 让他为了自尊置家人于不顾。 那是执拗，不是骨气。
3. 让她强行给且不理解他。 她要懂，只是不同意。

#### 示例（本库自撰，可直接改写）

> 转账记录在他手机上停了一整晚，红色的那个数字他看了很多遍。
> 第二天早上他原路退了回去，没有附言。
> 她中午打来电话：「你什么意思。」
> 「我自己有。」
> 「你妈住院要多少你自己有？」
> 他没说话。听筒里有她那边的键盘声，敲了几下，停了。
> 「算我借你的。」她说，「写个条，按你说的利息。」
> 他愣了很久，说：「好。」

## 五 · 他要证明自己

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：受挫 10.7% ＋ 提携 14.0%

**骨架**｜他去做一件不靠她也能成的事。

#### 节拍链

他推掉她的安排 → 自己接了一件事 → 瞒着做 → 她想帮忍住了 → 成或败 → 他回来说结果

#### 时间轴

瞒的时长就是他压上的赌注。 从推掉她的安排到摊牌，中间几个月他两头烧；她「想帮而忍住」的每一次都有时刻，看到他熬夜、听到他碰壁，手伸到一半收回来。结果揭晓那天，两个人各自松的那口气，长度不一样：他松的是成败，她松的是终于不用再忍。

#### 为什么这条必须有

如果他从头到尾都在她的荫蔽下，这个角色就没有独立的价值，关系也就变成了单向供养。

他需要一件属于自己的事。 这件事不一定要成功，但必须是他自己的。

#### 三种版本

| 版本 | 做法 | 结局 |
|---|---|---|
| 成功版 | 他做成了，且是靠自己 | 关系重新平衡 |
| 失败版 | 他没做成，狼狈回来 | 更真实，也更需要功力 |
| 半成版 | 做成了一半，中间她暗中帮了一次 | 最有味道，也最难处理 |

半成版的关键是他知不知道她帮过。 知道了怎么办，是这条的高潮。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他做的事 | 自己接的项目 · 考证 · 创业 · 回老家处理一件事 · 一场比赛 |
| 他的准备 | 熬夜 · 瞒着她 · 推掉了她安排的机会 |
| 她的克制 | 想帮但忍住 · 或者暗中出手一次 |
| 他发现她帮过 | 一个签名 · 一通电话 · 某个人的一句话 |
| 他的反应 | 愤怒 → 冷静 → 明白她的用意 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她帮不帮 | 完全不帮 | 暗中帮了一次 |
| 他知不知道 | 一直不知道 | 知道了 |
| 结果 | 成了 | 没成 |
| 之后 | 他继续做自己的 | 他接受了她的资源，但方式变了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把已经拨通的电话挂掉了 | 我要靠自己一次 |
| 内心 | 我能一句话解决，但我不能说 | 输了也是我自己的 |
| 好的处理 | 她忍住不帮，且不邀功 | 他失败之后没有迁怒 |
| 写崩 | 写成她全程操控 | 写成他赌气式的自立 |

「她把已经拨通的电话挂掉了」是这条最好的一个动作。 忍住不帮，比帮了更难。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他去考功名／从军／不用她的荫封／自请外放 |
| 修仙 | 他自己去闯秘境／不用她给的法器 |
| 星际 | 他申请独立任务／不挂她的编制 |

#### 写崩的三种方式

1. 让他必然成功。 失败版更有价值。
2. 让她全程操控。 那这件事就不是他的了。
3. 让他为了自立而否定关系。 独立与依恋不冲突。

## 六 · 她提拔他

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：提携 14.0%

**骨架**｜她给了他一个机会。而所有人都会问：是因为什么。

#### 节拍链

名单上有他的名字 → 会上定了 → 同事的眼神 → 他问「为什么是我」→ 他拼命做 → 外部认可到来

#### 时间轴

任命只要一天，服众要一年。 名单公布那天流言同步起跑；他用「为什么是我」问了她一次，之后用十二个月回答所有人。外部认可到来的那一刻（客户点名、奖项、对手挖角）才是这条的终点，从那天起，没人再提名单上的事。

#### 这条的核心难题

提拔本身没问题，问题是旁人的解释。哪怕她完全公正，只要关系存在，这个动作就会被读成偏私。

而更麻烦的是：他自己也会怀疑。

| 谁在怀疑 | 表现 |
|---|---|
| 同事 | 眼神、议论、不配合 |
| 他 | 半夜想这件事 · 拼命做出成绩来证明 |
| 她 | 复盘自己是不是真的公正 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 决定的场合 | 会上 · 她一句话定了 · 或者她刻意让别人来提 |
| 他的反应 | 没有立刻高兴 · 第一句是「为什么是我」 |
| 同事 | 有人恭喜得太热情 · 有人不说话 |
| 他的证明 | 加班 · 把事情做到无可挑剔 · 拒绝她后续的任何照顾 |
| 收束 | 一次外部的认可（客户、评审、别的领导）洗清了这件事 |

「外部的认可」是唯一能真正解决这条的东西。 她说十遍「你是靠实力」都不如一个不相干的人说一句。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 是否公正 | 完全公正 | 她确实偏了一点 |
| 他接不接 | 接了 | 拒绝（他要自己升上去） |
| 旁人 | 有人明说 | 没人说但气氛变了 |
| 收场 | 他做出了成绩 | 他离职去了别处 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她复盘自己的决定是不是真的公正 | 「为什么是我」 |
| 内心 | 我要是不提他，反而是另一种不公 | 我不想欠这个 |
| 好的处理 | 她把评判交给第三方 | 他做到无可挑剔 |
| 写崩 | 写成她排除异议强推 | 写成他理直气壮地享受 |

「我要是不提他，反而是另一种不公」是这条最好的一句内心戏：因为关系而不敢用一个合格的人，同样是偏私。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 荐他入朝／破格提拔／御史参她任人唯亲 |
| 修仙 | 传他核心功法／立他为亲传／门内不服 |
| 星际 | 把他调进核心组／人事系统标了红 |

#### 写崩的三种方式

1. 让他毫无负担地接受。 那一句「为什么是我」是这条的门。
2. 让她压下所有异议。 异议要留着。
3. 靠她的辩解收场。 要靠外部认可。

前接：[五 · 他要证明自己](#五--他要证明自己)

## 七 · 他失业了

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：受挫 10.7%

**骨架**｜他丢了工作。这件事在这一类里的重量，比在别的类型里大得多。

#### 为什么更重

因为工作是他在这段关系里唯一的独立支点。落差本来就在，工作没了，落差就变成了悬崖。

#### 节拍链

被裁／项目黄 → 他没有立刻说 → 假装照常出门 → 被发现 → 那一场对话 → 之后的日子

「假装照常出门」是这条的招牌镜头。 他每天准点出门，在外面待到下班时间再回来。

#### 时间轴

「假装照常出门」的天数是这条的核心计时。 第一天他真去面试了，第三天开始在图书馆坐一天，第七天被发现，每多瞒一天，摊牌的难度翻一倍。之后的日子按周走：第一周她忍着不安排，第二周他自己有了方向，节奏必须是他的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 隐瞒的痕迹 | 白天的定位 · 咖啡馆的小票 · 手机 ✓ 电量掉得比平时快 |
| 被发现的方式 | 她提前回家 · 收到他公司的邮件 · 朋友说漏嘴 |
| 那场对话 | 她的第一句话决定一切 |
| 之后 | 他开始做家务 · 他更早起 · 他不再提钱的事 |
| 转折 | 他找到了新的 · 或者他决定换一条路 |

#### 她的第一句话，四个版本

| 说法 | 效果 |
|---|---|
| 「怎么不告诉我」 | 责备，哪怕出于关心 |
| 「没事，我养你」 | 最伤人的好意 |
| 「先歇一阵」 | 温和，但没解决自尊问题 |
| 「明天陪我去个地方」 | 最好——不谈这件事，给他一件别的事做 |

「我养你」这句在 GB 里是雷。 传统言情里它是承诺，这里它是判决。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 瞒了多久 | 三天 | 两个月 |
| 原因 | 公司裁员（非他之过） | 他自己搞砸的 |
| 她的处理 | 给钱 | 给事做 |
| 他的恢复 | 很快 | 一直没缓过来 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他这周每天七点出门但公司没考勤 | 在咖啡馆坐到五点半 |
| 内心 | 我说什么都不对 | 我不能让她知道 |
| 好的处理 | 她不提钱，只给他一件具体的事 | 他自己开口说了 |
| 写崩 | 写成她说「我养你」 | 写成他自暴自弃 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 落第／罢官／被逐出师门／断了俸禄 |
| 修仙 | 修为跌境／被废丹田／灵根出问题 |
| 星际 | 被降级／调离一线／体检不达标 |

修仙版最狠：修为跌境是不可逆的，它把「暂时失业」变成了「永久失去」，写好了极重。

#### 写崩的三种方式

1. 用「我养你」收场。 见上。
2. 让他立刻振作。 要有一段沉下去的时间。
3. 让她全程处理，他被动接受。 他要自己走出来一步。

## 八 · 他比她强了

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：受挫 10.7% ＋ 提携 14.0% 的反向

**骨架**｜他做成了，而且做得比她大。关系要重新谈一次。

#### 节拍链

一次她习惯性买单他已付 → 变化累积 → 她的一点失落 → 谁先提出来谈 → 重新谈定 → 新的样子

#### 时间轴

变化是渐进的，察觉是突然的。 账单、应酬、别人的称呼，半年里一点点换位，两个人都没正视；她那一点失落在某个瞬间对焦（习惯性买单发现他已付）。从对焦到坐下来谈，拖的时间越短，这段关系的成色越好，拖过一个月，就该去 [28-误会与信任](28-误会与信任.md) 报到了。

#### 这条是这个类型最难写的一条

因为它触到了根：如果落差消失了，这段关系还成立吗？

三种答案，都成立：

| 答案 | 说法 | 后果 |
|---|---|---|
| 落差从来不是核心 | 权力关系是他们选的，不是条件给的 | 最健康，但要前文支撑 |
| 落差换了来源 | 钱没了差距，别的方面还在 | 最实际 |
| 关系确实变了 | 两人重新谈，谈成新的样子 | 最诚实，也最需要功力 |

不能回避这个问题。 让他发达之后关系毫无变化，读者会觉得假。

#### 可用细节

| 类 | 内容 |
|---|---|
| 变化的信号 | 他开始付账 · 他给她买东西 · 他有了自己的圈子 · 别人开始叫他老板 |
| 她的不适 | 一次她习惯性地要买单，他已经付了 · 她愣了一下 |
| 他的试探 | 他会不会开始改变相处方式 |
| 关键一场 | 一次决策由谁做 |
| 收束 | 两人明确谈一次，或者用一个动作确认 |

「一次她习惯性买单，他已经付了」是这条的开场镜头。 一个动作说明了全部变化。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的态度 | 完全没变 | 开始想改变位置 |
| 她的态度 | 高兴 | 高兴里混着一点失落 |
| 结局 | 关系不变 | 关系变了，但两人都接受 |
| 谁先谈 | 她 | 他 |

「高兴里混着一点失落」这句必须写。 不写它，她就成了没有内心的功能角色。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她意识到自己有一点不习惯 | 我现在可以给她买这个了 |
| 内心 | 我是不是需要他弱一点 | 我要不要变 |
| 好的处理 | 她诚实地承认那一点失落 | 他问她想不想变 |
| 写崩 | 写成她失落到打压他 | 写成他一发达就翻身 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他官至她之上／军功盖过／族中地位反超 |
| 修仙 | 他修为超过她／她卡在瓶颈 |
| 星际 | 他升了将衔／她还在原岗 |

#### 写崩的三种方式

1. 让关系毫无变化。 回避问题读者看得出来。
2. 让他一发达就翻身做主。 那是另一个故事。
3. 让她因此打压他。 打压会毁掉前面所有的正面塑造。

## 九 · 加班到深夜的办公室

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：职场 33.0% ＋ 夜深 37.0% ＋ 加班 25.0%

**骨架**｜整层楼只剩两个人和一盏灯。

#### 节拍链

整层只剩两盏灯 → 各忙各的 → 空调停了 → 一件小事（外套·咖啡）→ 收工 → 谁送谁

#### 时间轴

以整层楼的灯为钟。 十点整层还亮着一半，十一点只剩他们两盏，十二点空调停了，大楼在逐层关机，两个人的距离随灯的减少而缩短。收工时刻不由工作量定，由谁先抬头定；谁先抬头，谁就是今晚先扛不住想回家的那个。

#### 为什么这个场景高频

它同时满足三件事：独处、正当理由、时间压力。而且它不需要任何人邀请谁——两个人都在加班，是自然发生的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 空间 | 只有一片区域亮着 · 其他工位黑着 · 保洁走了 · 空调停了（定时） |
| 声音 | 键盘 · 打印机 · 电梯到达的提示音（有人来了？） |
| 道具 | 外卖盒 · 咖啡 · 她脱掉的外套 ✓ 搭在椅背 · 她的高跟鞋脱在桌下 |
| 时间 | 十点 → 十一点 → 空调停了 → 冷 |
| 契机 | 她冷了 · 他把外套给她 · 或者他去把空调重新打开 |

「她的高跟鞋脱在桌下」是这条的一个高效细节：卸下装备的那一刻，上司身份也松了一格。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁陪谁 | 他陪她（他其实做完了） | 她陪他 |
| 有没有人来 | 没有 | 保洁／同事突然回来拿东西 |
| 发生了什么 | 什么都没有 | 一件小事 |
| 结束 | 各回各家 | 她送他 |

「他其实做完了但没走」是这条最省事的动机交代。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她抬头发现只剩他还亮着灯 | 她还没走，我就不走 |
| 内心 | 他做完了为什么不走 | 别让她一个人在这儿 |
| 好的处理 | 她没有让他走，也没有留他 | 他没有解释为什么还在 |
| 写崩 | 写成办公室暧昧套路 | 写成他刻意制造机会 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 书房批文到三更／他在外间守着／换了两回烛 |
| 修仙 | 议事殿只剩两人／灯烛与阵光 |
| 星际 | 舰桥夜班／只有仪表灯 |

#### 写崩的三种方式

1. 直接进入暧昧。 这条的价值在克制。
2. 省略时间推进。 空调定时停了这类细节就是钟。
3. 让他刻意制造独处。 自然发生才好。

## 十 · 出差同行

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：出差 43.0% ＋ 职场 33.0%

**骨架**｜两个人，一趟差，若干个必须共处的小时。

#### 节拍链

定行程 → 路上 → 订房那一步 → 白天工作模式 → 晚上私人模式 → 一个意外 → 回程有件事不一样了

#### 时间轴

三天两夜，白天与晚上是两套时间。 白天的钟按行程表走（会议、拜访，公事公办到互称职务）；晚上的钟没有表，酒店走廊道晚安的那几分钟，比白天八小时的信息量都大。回程航班上有件事和去程不一样了，具体是什么，写的人自己挑。

#### 为什么出差是浓缩装置

它把日常关系打包搬到一个封闭空间里，且去掉了所有日常的缓冲（家、朋友、各自的房间）。

| 环节 | 会暴露什么 |
|---|---|
| 定行程 | 谁做决定 |
| 同行的路上 | 谁坐哪、谁靠着谁睡 |
| 订房 | 几间房。这一步是整条戏的开关 |
| 工作时 | 上下级模式 |
| 饭桌上 | 私人模式 |
| 意外（航班延误、下雨、他病了） | 真实的相处方式 |
| 回程 | 有没有变化 |

「订房」是这条的开关。 一间还是两间、谁订的、订错了怎么办，这一个动作决定了后面全部的走向。

#### 可用细节

| 类 | 内容 |
|---|---|
| 路上 | 他睡着头歪过来 · 她把外套 ✓ 盖上 · 行李谁拿 |
| 酒店 | 房卡 ✓ · 隔壁房间的水声 · 走廊的地毯 · 她敲他门 |
| 工作时 | 完全换了一副样子 |
| 意外 | 他水土不服 · 航班取消 · 只剩一间房 |
| 回程 | 座位换了 · 或者一路没说话 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 房 | 两间 | 只剩一间（老套但有效） |
| 出没出事 | 什么都没有 | 一件小事 |
| 谁照顾谁 | 他水土不服她照顾 | 她累倒他照顾 |
| 回来后 | 一切照旧 | 有件事不一样了但谁都不提 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 飞机上他睡着了头歪过来 | 隔着一堵墙 |
| 内心 | 出差这几天他不太一样 | 这几天不用装 |
| 好的处理 | 她在工作时该怎样还怎样 | 他没有借出差得寸进尺 |
| 写崩 | 写成公费旅行谈恋爱 | 写成他趁机造机会 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 随她外放／同赴任／驿站只剩一间上房 |
| 修仙 | 同去历练／秘境里只能同守一夜 |
| 星际 | 同一次任务／舱位只有一个 |

#### 写崩的三种方式

1. 只写「只剩一间房」。 那是最偷懒的一步，前后都得有戏。
2. 让工作完全消失。 他们是去出差的。
3. 回程毫无变化。 至少留一件事不一样。
