## 设定接口：一张表管三种世界

双性日常、女尊异世子嗣、ABO生育规则分属不同设定页，各自归口统一处理。女尊制度见 [37-女尊制度进阶](37-女尊制度进阶.md)，ABO 生育对应 [03-世界观设定/02-GB-ABO设定设计手册](../03-世界观设定/02-GB-ABO设定设计手册.md)（2.14 生育四解法），常规双性日常走 [33-双性设定日常](33-双性设定日常.md)。所有机制写法一致，条目中的「验出／建档／进产房」按下表换算。

| 节点 | 现代 ABO | 双性（现代或古风） | 女尊异世 |
|---|---|---|---|
| 验出 | 验孕棒＋查腺体 | 验孕棒／请大夫 | 请平安脉，医女说句「有喜了」 |
| 建档产检 | 医院建档，男 O 有专门门诊 | 医院，他是科室里的特例 | 医馆安胎，男人生孩子是常事 |
| 生产 | 产科／手术室 | 手术室 | 产房，有稳婆接生 |
| 哺乳 | 能自己喂，看设定 | 看设定 | 自己喂或找奶妈 |
| 失败线 | 指标不行／流了 | 一样 | 「没生出来」就变成位份话 |

候诊室里坐着的一排孕夫，个个来自女尊异世，只有他是男的。ABO 和双性设定里，他成了唯一的男性。孤立感也好，制度感也罢，两种处境都说得通。可一旦选定，全书就得保持一致，换算时只需盯住一处：**他是例外还是常态**。

边界三条：全员成年；产检、用药、产程只写关系结构，不做医学指南；九的丧失线交代事实与后果，不写过程细节。

## 一 · 要不要

`T` ｜ ⚠️生子 ｜ 通用 ｜ 语料频次：孩子 24.8% ＋ 催 15.9%（13-07 实测）

**骨架**｜想要的人怀不上，怀上的人不吭声。这场谈话就一个规矩，身体在谁那儿，谁说了算。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 起意，她抱过一次别人的孩子／族里的话传进了门 |
| 2 | 她开口，开成了问句。问句和通知的差别，他一耳朵就能听出来。 |
| 3 | 他要了几天。不是矜持，他在算身体的账：易感期、军役、铺子，哪一样停得起。 |
| 4 | 两张单子对在一起。她列的是钱和人手，他列的是月份和身体。 |
| 5 | 否决权归位。她先说的：「你说不要，这事就没有」 |
| 6 | 定或缓。缓要给日期，不给日期的缓等于把话吞了。 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 别在床上聊，床上说的不算，俩人都门儿清 · 饭桌收了碗再提 · 女尊版：把下人都打发走 |
| 他的单子 | 月份表 · 要停的事 · 医嘱或脉案 · 上一辈孕夫的旧事，他自己偷偷查过 |
| 她的单子 | 钱 · 人手 · 她能腾出来的空 · 单子最后一行小字：随他 |
| 外部干扰 | 「子嗣是他的本分」这话从门外飘进来过，谈正事先把这话堵回去 |
| 收尾 | 定了不庆祝，缓了不冷场，两种都得有下句话接住 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁想要 | 她想要，他掏钱，这一族的主形 | 他想要，她怕他掏 |
| 否决权 | 明说出口 | 心里有数，从没挑明，迟早得挑明 |
| 谈的结果 | 定了 | 缓了，缓到哪天说死了 |
| 外部压力 | 还没影 | 已经堵门口，催 15.9%，13-07 |

**她想要，而他付身体**，这就是把 [13-家庭与亲属 · 要不要孩子](13-家庭与亲属.md#四--要不要孩子) 里那道「想要的人不承担代价」的题整个翻了过来。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她差点把「我们要个孩子」说成「我要」，一个字的差别她自己听见了 | 单子写到第七行，他发现她的单子上早替他列好了前六行 |
| 内心 | 我出的是钱，他出的是身体，这账怎么算平 | 这一次，答应或不答应都真的在我 |
| 好的处理 | 她先把否决权亮出来，再开口劝 | 他没马上答，说要走几天想想 |
| 写崩 | 写成她说了算，他照办 | 写成他拿身体当筹码谈条件 |

#### 写崩的三种方式

1. 身体主权交出去了，后面九条全崩。她单方面拍板，他感动点头。
2. 跟13-04第一条崩法一样，换了个壳照样翻车。拿一次意外怀孕把谈话糊弄过去。
3. 赢了的人抱回一个输了的枕边人。把谈话搞成辩论赛，列数据、驳论点、分输赢。

## 二 · 验出来那天

`T` ｜ ⚠️生子 ｜ 通用 ｜ 语料频次：生子标签 3.4%（文案口径，08-缺口调研）

**骨架**｜谁先知道、谁后知道，往外说时先提谁，这两张单子就是这家的规矩。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 迹象：早上起来不对劲、腺体指标、脉象，他自己先起了疑 |
| 2 | 验：自己验，或被医者一句话点破，单子到手 |
| 3 | 独知期：短则一小时，长则两天，他揣着这事找机会 |
| 4 | 告诉她，单子推过去／一句话／让她自己撞见，三种人三种做法 |
| 5 | 她的第一句，这句定全书调子 |
| 6 | 排报喜顺序，先跟谁说后跟谁说，两人当场对了一遍 |
| 7 | 当晚灯灭了谁都没睡着，各想各的心事 |

05-01 生子↺的拍 2 写明：他先知道、她后知道，信息差就是这一段全部的戏。日常层的用法是把差压短——**他独自知道的那两天干了什么**，比宣布那一刻更有内容。

#### 可用细节

| 类 | 内容 |
|---|---|
| 单据等价物 | 两道杠／化验单／脉案／手机弹窗，按设定接口表换算 |
| 独知期动作 | 单据夹书里 · 推掉一趟远差 · 查“头三个月”查到后半夜 · 对着镜子愣了一会儿 |
| 告诉她的方式 | 单据压在她水杯底下 · 饭做到一半说的 · 什么都没说，她收外套时摸到了 |
| 她的第一句候选 | 「你想留吗」·「先坐下」·「什么时候的事」 |
| 报喜顺序 | 谁排第一，她妈／他家／上司，先谁都不说· 顺序为这事吵过一次 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先知道 | 他一个人先知道两天 | 俩人一块儿看结果，单据一人捏一角 |
| 计划内外 | 谈定后的计划内 | 计划外，回到 [一 · 要不要](#一--要不要) 补谈，顺序反了程序不能省 |
| 他的第一情绪 | 喜 | 慌，喜是后来才追上来的 |
| 泄露事故 | 没有 | 长辈先知道了，医馆的人嘴快，报喜变成补报 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看了推过来的单据才晓得，先看的却是他的脸 | 单据在袖袋里放了两天，边角都软了 |
| 内心 | 他瞒了两天，这两天他一个人在想什么 | 想挑一个她不累的晚上，结果她哪天都累 |
| 好的处理 | 她开口第一句是问话 | 他说出口时把「大概」「可能」全去掉了 |
| 写崩 | 写成她当场泪崩转圈 | 写成他忐忑到卑微，怕她不要 |

#### 写崩的三种方式

1. 报喜的顺序没跟对方商量就发出去了，等于把家里的章交给别人盖。这条线划在[15-秘密与坦白](15-秘密与坦白.md)。
2. 光激动没用，激动半天一个具体问题都问不出来，那叫文案。她得至少问出一件实事儿来。
3. 独知期拖成隐瞒，两天是分寸，两个月是欺骗，过线就换戏了。

## 三 · 产检日

`T` ｜ ⚠️生子 ｜ 通用 ｜ 语料频次：孩子 24.8%（13-07 实测）

**骨架**｜候诊室就他一个男的。表格上没他的选项，叫号也不知道喊他啥。他整个上午都在给系统补漏。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 挂号，号挂在谁名下，系统头一回卡壳 |
| 2 | 候诊室，大家瞄一眼手机又放下，谁也没吱声 |
| 3 | 叫号，喊「X 女士家属」还是喊他名字，护士愣了下 |
| 4 | 建档表格，填到「母亲姓名」那栏，笔停住了 |
| 5 | 诊室（数据是他的，话却冲她说） |
| 6 | 下次预约记在谁的日历上，谁得请假 |
| 7 | 回程，俩人开口聊的第一句，多半是笑那半秒的愣 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 表格 | 「母亲姓名」那栏，他把「母」字划掉，写了自己的名字 · 系统下拉菜单里翻不到他 · 签字的地方，她让他签（呼应 [七 · 生产](#七--生产)） |
| 候诊室 | 连排椅，他两边都没人坐 · 有个孕妇多看他两眼，又低头翻册子 · 女尊版反过来：满屋都是孕夫，被人打量的成了她 |
| 医生措辞 | 「让爱人平时多注意」，他本人就坐旁边· 会来事的医生，直接跟他交代，病历本也递到他手里 |
| 数据 | 孕周和指标记在谁手机上 · 他记得比她细，她记得比他严 |
| 日程 | 产检日在她日历上标红 · 她漏过一次，那回的单子，他没主动给她看 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 系统适配度 | 制度已经全接上了（ABO 常态化，有男 O 门诊） | 就他一个例外（表格全得手改） |
| 医生 | 绕开她直接跟他说 | 只跟他讲，把她晾一边，她头一回尝到这滋味 |
| 她在不在 | 回回都在 | 缺了一回，补的办法比说对不起管用 |
| 他的应对 | 自己答，答得挺稳 | 让她答，等回家路上才说「下回让我自己来」 |

**措辞的钝比人的坏真实**：医生不是反派，系统才是没给他留位置的那一方。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 护士喊「家属」时她站起来，愣了下才明白今天轮到自己了 | 表格第三栏，笔悬着那两秒 |
| 内心 | 陪诊坐这儿原来是这滋味，坐着也像多余的 | 一屋子人里，连表格都觉得我不该待这儿 |
| 好的处理 | 她把「家属」俩字咽回去，坐下，让他自己进去 | 他把改好的表格推回窗口，语气跟没事人似的 |
| 写崩 | 写成她当场翻脸，替他出头闹事 | 写成他被盯得发毛，缩在椅子上头都不敢抬 |

#### 写崩的三种方式

1. 浓度一高，反而假了。候诊室里堆满恶意台词，光靠眼神还不够，再补几句指指点点，直接变批斗现场。
2. 把账算在某个医生头上，那就太浅了。制度迟钝，那说得通，医生写成反派，反倒失真。
3. 建档之后再不进戏，产检只出现一次，机制又回设定卡里睡觉去了。05-01 生子↺第二崩法。

| 走廊 | 缴费单攥皱了没人去交 · 广播喊下一个号，俩人谁也没动 · 她包掉了，东西撒一地，俩人蹲着捡，捡完接着坐 |
| 安慰的错位 | 话全冲着她去（「再要就是」），可他才是那个失去的人，她站旁边跟个外人似的 · 反过来：大伙全围着他，没人记得她也少了一块 |
| 女尊异世版 | 「无出」是老礼法的话，指没生下孩子，进了位份的说法，族里那点心思全摆桌面上（接 [37-女尊制度进阶](37-女尊制度进阶.md)，这轮一起写） |
| 试管线 | 一趟趟跑医院的日子 · 成功率那数字听多了就麻了 · 说不做的那天，跟说做那天一样沉 |
| 时差 | 他身体先缓过来了，可缓过来这事反倒让他难受 · 她半夜去阳台，以为他早睡了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 形态 | 一直没等到（不育／试管屡败） | 等到过，没保住（流产） |
| 归因的诱惑 | 两人都不提这茬 | 有一方偷偷往自己身上揽，得靠另一方接住 |
| 旁人 | 错位安慰（见上表） | 沉默的体贴，嫂子把满月请帖压下来没发 |
| 之后 | 再试，流程从头走一遍 | 不再试，两人真把这话接住了（13-04 那一端的续写） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她守到他睡熟才去阳台，回来时他呼吸不对，两个人都在装睡 | 身体一天天轻回去，像什么都没发生过，这份轻是最重的 |
| 内心 | 我连难过都要排在他后面，可我也失去了 | 他们安慰她的时候，我在想那是从我身上走的 |
| 好的处理 | 她把「都会好的」换成了「我也难受」 | 他允许她看见他不好，没有撑成没事人 |
| 写崩 | 写成她全程冷静主持大局 | 写成他一蹶不振，等她拯救 |

#### 写崩的三种方式

1. 空窗期才是丧失本来的形状，有人用下一胎把它填平，冲喜式怀孕把情绪账一笔勾销，欠下的却永远烂在肚子里。
2. 把归因摆上法庭，追谁的错、哪一步错，丧失戏码变成责任事故调查，两败俱伤也没个结论。
3. 哀伤只落在一个人身上，时差允许，缺席不行。两个人的失去压缩成一个人的，另一个就退成背景板。

## 十 · 二胎与继子女

`T` ｜ ⚠️生子 ｜ 通用 ｜ 语料频次：孩子 24.8%（13-07 实测）

**骨架**｜再来一次，或者带着孩子重新过日子。大人之间的事都好说，老大那边才是真正的坎。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 起头：二胎线旧话重提，重组线第一次带孩子见面 |
| 2 | 老大的第一反应是清点自己的东西，或盯着那个大人看 |
| 3 | 大人重走程序，一 的谈话再来一遍，这回桌上多了旧账与前史 |
| 4 | 老大的试探，试探性的称呼，或故意犯一条规矩看新家长敢不敢管 |
| 5 | 一次事件：小的出生、继子女生病，各人的位置在事件里各就各位 |
| 6 | 老大的接纳仪式，自己发明的，大人只能等 |
| 7 | 新家庭图定稿，称呼、房间、规矩，三样都换了版 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 老大（二胎线） | 上来先问「他睡哪」，地盘的事比感情要紧 · 半夜偷偷去看小的 · 把旧玩具拿一件出来，又收回去，再拿出来 |
| 老大（重组线） | 试着叫了一声，谁都没接话，又硬着头皮叫了一声 · 拿两边的规矩互相顶（「我妈说可以」） |
| 旧账 | 上次生孩子的旧事翻出来（[七 · 生产](#七--生产) 或 [九 · 没等到的](#九--没等到的) 那点尾巴） · 前任的影子还在，照片、抚养费、接送那天 |
| 大人的错 | 偏心偏得明晃晃 · 逼老大说「喜不喜欢」 |
| 女尊版 | 位分和族谱：嫡的庶的、继子算不算她家的人，规矩上的事接 [37-女尊制度进阶](37-女尊制度进阶.md)（这轮在写） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 线 | 二胎 | 重组：她带女儿，或他带前段的孩子 |
| 老大年龄 | 啥都听得懂（试探更精） | 半懂不懂，反应全在动作上 |
| 老大态度 | 防着 | 装出来的欢迎（更难写也更真） |
| 上一段的影子 | 淡 | 浓，九的没了或前任，都算 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 继女那声称呼落地时，她答应得太快了，快得两个人都愣住 | 老大凑过来小声问「这次还疼吗」，他才知道上次的事孩子都听见了 |
| 内心 | 我在跟一个孩子谈判，还处于下风 | 手心手背的说法是假的，偏一次心里就记一笔 |
| 好的处理 | 她不拿礼物买接纳，等老大自己发明仪式 | 他跟老大单独谈了一次，像跟大人谈 |
| 写崩 | 写成她用礼物铺路一路通关 | 写成他夹在孩子中间和稀泥 |

#### 写崩的三种方式

1. 戏眼没了，这条线就只剩大人来回念叨。老大从头到尾只要负责可爱就行，背景板当得稳稳当当。
2. 九个月等于白过，旧账不提，二胎谈话照搬一胎。这场谈话该比上次难一点，也得比上次快一点。
3. 要么苦情忍着，要么恶毒防着，后妈后爹的老套路，这两个方向都是别的类型玩剩下的。
