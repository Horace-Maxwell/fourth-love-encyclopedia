## 一 · 要不要

`T` ｜ ⚠️生子 ｜ 通用 ｜ 语料频次：孩子 24.8% ＋ 催 15.9%（13-07 实测）

**骨架**｜想要的人不怀，怀的人还没说话。这场谈话的规矩只有一条：身体在谁身上，否决权就在谁手里。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 起意（她抱过一次别人的孩子／族里的话传进了门） |
| 2 | 她开口，开成了问句（问句和通知的差别，他一耳朵就能听出来） |
| 3 | 他要了几天（不是矜持，他在算身体的账：易感期、军役、铺子，哪一样停得起） |
| 4 | 两张单子对在一起（她列的是钱和人手，他列的是月份和身体） |
| 5 | 否决权归位（她先说的：「你说不要，这事就没有」） |
| 6 | 定或缓（缓要给日期，不给日期的缓等于把话吞了） |

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 不在床上谈（床上说的不作数，两人都懂）· 饭桌收了碗再谈 · 女尊版：屏退下人 |
| 他的单子 | 月份表 · 要停掉的事 · 医嘱或脉案 · 上一辈孕夫的旧事（他自己打听过） |
| 她的单子 | 钱 · 人手 · 她挪得出来的时段 · 单子末尾一行小字：随他 |
| 外部干扰 | 「子嗣是他的本分」这句话从门外飘进来过，谈话第一步是把它请出去 |
| 收尾 | 定了不庆祝，缓了不冷场，两种都要有下一句 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁想要 | 她想要，代价他付（这一族的主形） | 他想要，她怕他付 |
| 否决权 | 明说出口 | 默认存在，从没说破（迟早要补说） |
| 谈的结果 | 定了 | 缓了，且缓有日期 |
| 外部压力 | 还没来 | 已经压进门（催 15.9%，13-07） |

**她想要而他付身体**，把 [13-家庭与亲属 · 要不要孩子](13-家庭与亲属.md#四--要不要孩子) 那道「想要的人不承担代价」的题原样翻了个面。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她差点把「我们要个孩子」说成「我要」，一个字的差别她自己听见了 | 单子写到第七行，他发现她的单子上早替他列好了前六行 |
| 内心 | 我出的是钱，他出的是身体，这账怎么算平 | 这一次，答应或不答应都真的在我 |
| 好的处理 | 她把否决权先说出口，再开始劝 | 他没有立刻答，他要走了几天 |
| 写崩 | 写成她拍板他配合 | 写成他拿身体当谈判筹码 |

#### 写崩的三种方式

1. 她单方面决定，他感动接受。身体主权没了，后面九条全塌。
2. 用一次意外怀孕跳过谈话。同 13-04 的第一崩法，机制版一样适用。
3. 谈成辩论赛。列数据、驳论点、分胜负，赢的那方抱回来一个输了的枕边人。

#### 可串接

前接：[13-家庭与亲属 · 催](13-家庭与亲属.md#三--催) · [13-家庭与亲属 · 要不要孩子](13-家庭与亲属.md#四--要不要孩子)（现实生理版）
后接：[二 · 验出来那天](#二--验出来那天)
制度面：[38-制度里的两个人](38-制度里的两个人.md)（同轮在写）

## 二 · 验出来那天

`T` ｜ ⚠️生子 ｜ 通用 ｜ 语料频次：生子标签 3.4%（文案口径，08-缺口调研）

**骨架**｜他先知道还是一起知道，往外报的顺序先排谁，两张顺序表都是这个家的权力图。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 迹象（晨起的不对、腺体指标、脉象，他自己先起了疑） |
| 2 | 验（自己验，或被医者一句话砸中；单据到手） |
| 3 | 独知期（短则一小时，长则两天，他揣着这件事挑时机） |
| 4 | 告诉她（单据推过去／一句话／让她自己发现，三种方式三种人） |
| 5 | 她的第一句（这句定全书基调） |
| 6 | 排报喜顺序（先谁后谁，两人当场对了一遍） |
| 7 | 当晚（灯关了以后谁都没睡着，各想各的那一份） |

05-01 生子↺的拍 2 写明：他先知道、她后知道，信息差就是这一段的全部戏。日常层的用法是把差压短——**独知的那两天他做了什么**，比宣布那一刻更有内容。

#### 可用细节

| 类 | 内容 |
|---|---|
| 单据等价物 | 两道杠／化验单／脉案／终端弹窗（按设定接口表换算） |
| 独知期动作 | 单据夹进书里 · 推掉一趟远差 · 查「头三个月」查到后半夜 · 对着镜子站了一会儿 |
| 告诉她的方式 | 单据压在她水杯底下 · 饭做到一半说的 · 什么都没说，她收外套时摸到了 |
| 她的第一句候选 | 「你想留吗」（把否决权还回去）·「先坐下」·「什么时候的事」 |
| 报喜顺序 | 谁排第一（她母亲／他家里／上司／暂时谁都不告诉）· 顺序谈崩过一次 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先知道 | 他独知两天 | 一起看结果（单据两人各捏一角） |
| 计划内外 | 一 谈定后的计划内 | 计划外（回到 [一 · 要不要](#一--要不要) 补谈，顺序反了程序不能省） |
| 他的第一情绪 | 喜 | 慌（喜是后来才追上来的） |
| 泄露事故 | 没有 | 长辈先知道了（医馆的人嘴快），报喜变成补报 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她是从推过来的单据知道的，先看的却是他的脸 | 单据在袖袋里放了两天，边角都软了 |
| 内心 | 他瞒了两天，这两天他一个人在想什么 | 想挑一个她不累的晚上，结果她哪天都累 |
| 好的处理 | 她的第一句是问句 | 他说出口时把「大概」「可能」全去掉了 |
| 写崩 | 写成她当场泪崩转圈 | 写成他忐忑到卑微，怕她不要 |

#### 写崩的三种方式

1. 独知期拖成隐瞒。两天是分寸，两个月是欺骗，过线就换戏了（[15-秘密与坦白](15-秘密与坦白.md) 的地界）。
2. 她的反应只有激动。没有一个问句的激动是文案，她要问出至少一件具体的事。
3. 报喜跳过两人对表。顺序没商量就发了出去，等于把家里的章交给别人盖。

后接：[三 · 产检日](#三--产检日) · [五 · 显怀](#五--显怀)
对照：[15-秘密与坦白](15-秘密与坦白.md)（独知期过线之后）

## 三 · 产检日

`T` ｜ ⚠️生子 ｜ 通用 ｜ 语料频次：孩子 24.8%（13-07 实测）

**骨架**｜候诊室里唯一的男性。表格没给他留格，叫号没给他留称呼，他一上午都在替系统当例外。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 挂号（号挂在谁名下，系统第一次卡壳） |
| 2 | 候诊室（目光从手机上抬起来又落回去，没人说话） |
| 3 | 叫号（叫「X 女士家属」还是他的名字，护士顿了半秒） |
| 4 | 建档表格（「母亲姓名」那一栏，笔停住） |
| 5 | 诊室（数据是他的，话冲着她说） |
| 6 | 下次预约（写进谁的日历，谁请假） |
| 7 | 回程（两人复盘的第一句，往往是笑那半秒的顿） |

#### 可用细节

| 类 | 内容 |
|---|---|
| 表格 | 「母亲姓名」栏他划掉「母」字写自己名 · 系统下拉菜单里没有他的选项 · 签名处让她签（回声在 [七 · 生产](#七--生产)） |
| 候诊室 | 连排椅上他两侧空着 · 有孕妇多看了两眼，又低头翻自己的册子 · 女尊版反转：满堂孕夫，被打量的换成她 |
| 医生措辞 | 「让爱人平时多注意」（他就坐在跟前）· 好的那种：直接对他说，病历本也递给他 |
| 数据 | 孕周与指标记在谁手机里 · 他记得比她细，她记得比他严 |
| 日程 | 产检日在她日历上是红的 · 她缺席过一次，那次的单据他没主动给她看 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 系统适配度 | 制度已适配（ABO 常态化，有男 O 门诊） | 他是全院例外（表格全要手改） |
| 医生 | 绕过他对她说 | 只对他说，把她当陪客（她第一次尝到这个位置） |
| 她在不在 | 每次都在 | 缺席一次（补救方式比愧疚台词有用） |
| 他的应对 | 自己答，答得平静 | 让她答，回家路上才说「下次让我自己来」 |

**措辞的钝比人的坏真实**：医生不是反派，系统才是没给他留位置的那一方。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 护士叫「家属」时她起了身，才反应过来今天她才是家属 | 表格第三栏，笔尖悬着的那两秒 |
| 内心 | 陪诊的位置原来是这个滋味，坐着也像多余 | 一屋子人里，连表格都觉得我不该在 |
| 好的处理 | 她把「家属」两个字咽回去，坐下，让他自己走进去 | 他把改好的表格推回窗口，语气平常 |
| 写崩 | 写成她当场发作替他维权 | 写成他被目光钉在椅子上抬不起头 |

#### 写崩的三种方式

1. 候诊室堆满恶意台词。目光够用了，加上指点的台词就成了批斗现场，浓度一高反而假。
2. 医生写成反派。钝感安在制度上成立，安在人头上就浅了。
3. 产检只出现一次。建档之后再不进戏，机制又回设定卡里睡觉去了（05-01 生子↺第二崩法）。

## 四 · 孕吐与口味

`T` ｜ ⚠️生子 ｜ 通用 ｜ 语料频次：下厨备饭 43.9% ＋ 孩子 24.8%（13-07 实测）

**骨架**｜家里掌勺的人进不了厨房了。这回轮到她学做饭，他扶着门框听声辨位。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 第一次吐（清晨，他没叫她，她是被水声弄醒的） |
| 2 | 油烟成了敌人（他闻不得，厨房易主） |
| 3 | 她接手（第一顿的成色，参照 01 卷学着做饭的全部惨状） |
| 4 | 口味清单成形（想吃的与闻不得的，两张单子天天改版） |
| 5 | 半夜想吃（凌晨的那一样东西，她去弄来了） |
| 6 | 他偷偷进厨房被抓（想指挥，被请出去） |
| 7 | 分工重排落定（不止饭：买菜、汤药、倒垃圾，全家的味道都归她管了） |

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的身体 | 吐完扶着台面缓的那一分钟 · 嗓子哑到中午 · 牙膏都换了味道 · 吐出经验了，能算出今天是轻是重 |
| 口味突变 | 原来最爱的那道闻不得了 · 原来不碰的酸东西半夜想 · 只认她做糊的那一版（糊味认人） |
| 她的学习 | 手机里的菜谱收藏从零涨起来，和 01 卷他那份收藏成对 · 隔着门问他步骤 |
| 隔门指挥 | 「先放姜」「火小一点」· 她把他往屋里推：「闻见了又该吐了」 |
| 旁证 | 外卖软件常点的那家换了 · 灶台上多了一条她的围裙 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 反转彻底度 | 她全接（饭难吃但他全吃了，01 卷的镜像句） | 两人重排分工，他保留口述权 |
| 他的接受度 | 顺着受照顾 | 憋着想干活，偷进厨房三次被抓三次 |
| 孕吐轻重 | 轻，成了两人的玩笑 | 重到挂水（转 [01-日常照料 · 半夜发烧](01-日常照料.md#三--半夜发烧) 的守夜结构） |
| 想吃的东西 | 买得到 | 买不到（她凌晨跑了三家店／让人快马去邻县） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 门外听他吐，她站了几秒才敢敲门（进去帮不上，不进去更难受） | 她端出来的东西糊了边，他吃完了，顺手把「少放盐」咽回去又吐出来 |
| 内心 | 他吐他的，我连陪着难受都不会 | 身体不归我管了，连口味都是它说了算 |
| 好的处理 | 她不问「想吃什么」，她报菜名让他挑（开放题他答不动） | 他照实指出咸淡，受照顾不等于当哑巴 |
| 写崩 | 写成她全程只负责心疼，灶台前站着的还是他 | 写成他吐两声就翻篇，身体没有后续 |

#### 写崩的三种方式

1. 照料反转没发生。她激动了十个月，围裙还在他身上，这一族就白写了。
2. 孕吐一句带过。他的身体感受是十个条目共用的地基，省了地基，楼是文案搭的。
3. 她一学就会。01 卷学着做饭的第一崩法原样适用，笨拙的过程才是给他看的诚意。

## 五 · 显怀

`T` ｜ ⚠️生子 ｜ 通用 ｜ 语料频次：公开 33.4%（13-07 实测）

**骨架**｜衣服比人先招供。藏到哪天、先跟谁说、口径谁定，公开的节奏表就是两人的信任表。

#### 节拍链

|---|---|
| 1 | 扣子先知道（某天早上第三颗扣子扣不上了） |

| 3 | 第一个看破的人（往往不在计划名单上：保洁阿姨、府里的老嬷嬷） |

| 身体感受 | 腰上多出来的那一圈是陌生的 · 也有踏实的时刻，两种交替才像人 |
| 目光 | 街上第一次被让座 · 他愣了一下才坐 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 公开主动权 | 自己按表说 | 被看破（事故公关，表作废重排） |
| 节奏 | 先小圈后大圈 | 一步到位（省事，但把适应期全压给了他） |
| 他对身体 | 陌生大于踏实 | 踏实大于陌生 |

| 内心 | 藏与说都该他定，我只管把表排顺 | 身体在往前走，名单还停在上个月 |

#### 写崩的三种方式

1. 孕期只当催泪装置。肚子只在需要观众哭的时候出镜，他的身体感受全程缺席。
2. 公开写成发布会爽文。当众宣布、全场震撼、打脸质疑，一套下来把日常戏的尺度全烧了。

## 六 · 胎动那晚

`T` ｜ ⚠️生子 ｜ 通用 ｜ 语料频次：孩子 24.8%（13-07 实测）

**骨架**｜他几天前就感觉到了，一直没说。那晚他叫她过来，她的手放上去，等了四十分钟。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 他先知道（轻得像气泡，好几天了，他捂着没说，想等一次大的） |
| 2 | 那晚动得清楚，他叫她 |
| 3 | 手放上去，里面不动了 |
| 4 | 等（说话降成气音，谁都不肯先挪） |
| 5 | 她说去倒杯水，手没动，人也没起 |
| 6 | 四十分钟，那一下来了 |
| 7 | 之后（谁都没说话，或者她说了一句很小的话） |

#### 时间轴

四十分钟就是全部内容。填法同 [01-日常照料 · 守着不睡](01-日常照料.md#六--守着不睡)：拿小动作分段。手心出汗了换个位置、腿麻了没敢动、窗外过一辆车、他快睡着了又撑开眼。每一段之间，等待厚一层。

#### 可用细节

| 类 | 内容 |
|---|---|
| 不对称 | 胎动对他是身体里面的事，对她隔着一层，这一层就是两人今晚的距离 |
| 他的私心 | 头几天的轻动他捂着没说，想让她第一次就摸到一个结实的 |
| 等待中 | 她的手心出汗 · 两人的呼吸压到最低 · 他看她的时间比感觉肚子的时间长 |
| 那一下之后 | 她的手指跳了一下 · 「踢我了」三个字说得像什么机密 |
| 落空版 | 那晚到底没等到，她趴着睡着了；后半夜动了，他没舍得叫醒她 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 等的结果 | 等到了 | 没等到（落空版更疼一点） |
| 他说没说 | 捂了几天（私心版） | 第一下就喊她（她没赶上，遗憾攒到这晚） |
| 她的状态 | 全程醒着等 | 等着等着睡着（他守着两个） |
| 之后 | 一句很小的话 | 什么都没说，灯一直没关 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 四十分钟里她把一天的事全想完了，最后什么都没想，就剩下等 | 他其实一直隐约觉得到，他不说，他在等它给她一次 |
| 内心 | 隔着一层，我只能排队 | 里面那个和外面这个，都在等对方 |
| 好的处理 | 她不肯挪手也不催，等成了她自己的事 | 那一下来时，他先看的是她的脸 |
| 写崩 | 写成她对着肚子发表长篇感言 | 写成他全程只当传感器，没有自己的感受 |

#### 写崩的三种方式

1. 手一放就动。等待是这一晚的全部资产，一秒兑现等于白来。
2. 加满内心独白。四十分钟要空着过，填满了就没有等了。
3. 写成异物恐怖。身体的陌生感有它的位置（[五 · 显怀](#五--显怀) 与 [41-他的身体与年岁](41-他的身体与年岁.md)），这一晚不是。

#### 可串接

前接：[五 · 显怀](#五--显怀)
同族：[06-身体接触](06-身体接触.md)（手的位置学）
后接：[七 · 生产](#七--生产)

#### 示例（本库自撰，可直接改写）

## 七 · 生产

`M` ｜ ⚠️生子 ｜ 通用（门外机位，过程留白） ｜ 语料频次：生子标签 3.4%（文案口径，08-缺口调研）

**骨架**｜门内的事留白，门外的事写满。她这辈子第一次站在「只能等」的那一边。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 发动（时点专挑不方便：她在开董事会，或在千里外） |
| 2 | 进门前（他反过来安慰她：「你手比我还抖」） |
| 3 | 门的分界（他进去，她被留下，身份从主事人改成等的人） |
| 4 | 签字（风险告知递出来，那支笔；她签「配偶」栏，女尊版签「正妻」） |
| 5 | 门外的时间（以声音和脚步计，不以钟表计） |
| 6 | 中途一次告知（出来的人说了三句，她只记住了第一句） |
| 7 | 门开（她先找的是他的脸，襁褓在第二眼） |

#### 可用细节

| 类 | 内容 |
|---|---|
| 那支笔 | 笔尖在「与患者关系」一栏停了半秒 · 女尊版是画押 · 签字权的制度面归 [38-制度里的两个人](38-制度里的两个人.md)（同轮在写），此处只写她握笔的手 |
| 门外的钟 | 走廊灯换过一次 · 保温壶里的水凉了两回 · 脚步声每次靠近她都站起来 |
| 她的失序 | 平时签一个亿都不抖的手 · 进来的电话她挂了三个 · 有人递椅子，她坐了又站 |
| 中途告知 | 术语一个都没听懂，只听懂了「稳定」 · 她点头点得太快 |
| 门开之后 | 他先说的是「吵醒你了吧」这种没道理的话 · 她走过去先摸的是他的额头 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 顺与不顺 | 顺（门外戏全靠她的失序撑） | 不顺（签第二次字；结账逻辑见 05-01 生子↺第 5 拍） |
| 她在哪 | 门外全程 | 赶路（最后一程在走廊上跑，进门时已经生完） |
| 门开第一眼 | 她先看他 | 他先找她（两边对齐：人先于孩子） |
| 世界差 | 手术室灯牌 | 产房外的廊柱与稳婆（女尊版） |

**门外者无权**，是她头一回坐进他平时的位置：等，且指挥不了任何人。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 门外那几个小时，她把「等」这个字从头学了一遍 | 进门前那段：疼里居然分出神来安慰她，他自己也觉得奇怪 |
| 内心 | 里面每一声她都在换算，换算不出来就更怕 | 门要关上那一刻，他回头说了句「外面冷，穿上外套」 |
| 好的处理 | 她不指挥任何人，这是她唯一指挥不了的房间 | 门内不写，他的戏在门关上之前与门打开之后 |
| 写崩 | 写成她踹门冲进去的大女主戏 | 写成门内实况直播 |

#### 写崩的三种方式

1. 鬼门关煽情模板。血崩、暴雨、「保大保小」三件套齐上，旧脚本借尸还魂；风险要写就走 05-01 的结账写法，结完账行为要变。
2. 门内过程实写。留白破了，分级也兜不住，这一条的机位固定在走廊。
3. 孩子一生下来，前账全清。产检时的表格、签字时的归属、排了九个月的班，产房门一开全忘了，机制文只剩机制。

## 八 · 哺乳与夜奶

#### 节拍链

| 拍 | 内容 |
|---|---|

| 4 | 旁人嘴开张（长辈、族亲、邻里，三句话各有出处） |

|---|---|---|

## 九 · 没等到的

`M` ｜ ⚠️生子 ⚠️BE·丧失向（BE＝悲剧向结局，圈内缩写） ｜ 通用 ｜ 语料频次：丧失线未单测；生子标签 3.4% 为全线口径（08-缺口调研）

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 坏消息（三种形态：一直验不出／指标不好／已经没了） |
| 2 | 告知（医生的话对谁说，另一人从握着的手的松紧知道的） |
| 3 | 走廊那一坐（连排椅，中间扶手隔着，手从扶手底下牵过去） |
| 4 | 回家的路（绕了远，谁都没提为什么绕） |
| 5 | 家里预备下的东西（那间房的门、写了一半的名字本，收进最深的抽屉） |
| 6 | 各自的哀伤时差（一个先缓过来，先缓的那个不敢表现出缓） |
| 7 | 谈不谈下一次（回到 [一 · 要不要](#一--要不要) 的程序，或者不回去了） |

#### 可用细节

| 类 | 内容 |
|---|---|
| 走廊 | 缴费单捏皱了没人去缴 · 广播叫下一个号，两人都没动 · 她的包滑到地上，东西撒了，一起捡，捡完接着坐 |
| 安慰的错位 | 话都冲着她来（「再要就是」），失去发生在他身体里，他站在旁边像个家属 · 反过来的版本：全体围着他，没人想起她也失去了 |
| 女尊异世版 | 「无出」（旧礼法语，指没有生下子嗣）进了位份语言，族里的算盘打到明面上（接 [37-女尊制度进阶](37-女尊制度进阶.md)，同轮在写） |
| 试管线 | 一次一次的时间表 · 成功率数字听得人麻木 · 停下来的决定和开始的决定一样重 |
| 时差 | 他的身体先好起来，好这件事本身让他愧疚 · 她夜里去阳台，以为他睡着 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 形态 | 一直没等到（不育／试管屡败） | 等到过，没保住（流产） |
| 归因的诱惑 | 两人都没接这个题 | 有一方偷偷归因给自己（要被另一方接住） |
| 旁人 | 错位安慰（见上表） | 沉默的体贴（嫂子把满月请帖压下没发来） |
| 之后 | 再试（程序重走） | 不再试，两人真的接过这个答案（13-04 那一端的续写） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她守到他睡熟才去阳台；回来时他呼吸不对，两个人都在装睡 | 身体一天天轻回去，像什么都没发生过，这份轻是最重的 |
| 内心 | 我连难过都要排在他后面，可我也失去了 | 他们安慰她的时候，我在想那是从我身上走的 |
| 好的处理 | 她把「都会好的」换成了「我也难受」 | 他允许她看见他不好，没有撑成没事人 |
| 写崩 | 写成她全程冷静主持大局 | 写成他一蹶不振，等她拯救 |

#### 写崩的三种方式

1. 用下一胎翻篇。空着的那段时间才是丧失的形状，冲喜式怀孕把它抹平了，欠下的情绪账永远烂着。
2. 开归因法庭。追查谁的错、哪一步错，丧失戏变成责任事故调查，两败俱伤还查不出结果。
3. 哀伤只写一个人。时差可以有，缺席不行；两个人的失去写成一个人的，另一个就成了背景板。

## 十 · 二胎与继子女

`T` ｜ ⚠️生子 ｜ 通用 ｜ 语料频次：孩子 24.8%（13-07 实测）

**骨架**｜再来一次，或带着孩子重组。大人的账都好算，老大的反应才是新的戏眼。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 起头（二胎线：旧话重提；重组线：第一次带孩子见面） |
| 2 | 老大的第一反应（是具体动作：清点自己的东西，或盯着那个大人看） |
| 3 | 大人重走程序（一 的谈话再来一遍，这回桌上多了旧账与前史） |
| 4 | 老大的试探（试探性的称呼，或故意犯一条规矩看新家长敢不敢管） |
| 5 | 一次事件（小的出生、继子女生病，各人的位置在事件里各就各位） |
| 6 | 老大的接纳仪式（自己发明的，大人只能等） |
| 7 | 新家庭图定稿（称呼、房间、规矩，三样都换了版） |

#### 可用细节

| 类 | 内容 |
|---|---|
| 老大（二胎线） | 先问的是「他睡哪」，领土问题先于感情问题 · 半夜偷偷去看小的 · 把旧玩具分出来一件，又要回去，又分出来 |
| 老大（重组线） | 称呼实验：第一声含在嘴里，谁都装作没听清，又叫了一声 · 拿两边的规矩互相钻空子（「妈妈那边可以」） |
| 旧账 | 上一次生产的旧事上桌（[七 · 生产](#七--生产) 或 [九 · 没等到的](#九--没等到的) 的余波） · 前任的在场感（照片、抚养费、接送日） |
| 大人的错 | 补偿式偏心 · 逼老大表态「喜不喜欢」 |
| 女尊版 | 位序与族谱：嫡庶、继子上不上她的谱，制度面接 [37-女尊制度进阶](37-女尊制度进阶.md)（同轮在写） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 线 | 二胎 | 重组（她带着女儿，或他带着前一段的孩子） |
| 老大年龄 | 能听懂全部（试探更精） | 半懂（反应全在动作上） |
| 老大态度 | 戒备 | 表演出来的欢迎（更难写也更真） |
| 上一段的影子 | 淡 | 浓（九 的丧失或前任，都算） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 继女那声称呼落地时，她答应得太快了，快得两个人都愣住 | 老大凑过来小声问「这次还疼吗」，他才知道上次的事孩子都听见了 |
| 内心 | 我在跟一个孩子谈判，还处于下风 | 手心手背的说法是假的，偏一次心里就记一笔 |
| 好的处理 | 她不拿礼物买接纳，等老大自己发明仪式 | 他跟老大单独谈了一次，像跟大人谈 |
| 写崩 | 写成她用礼物铺路一路通关 | 写成他夹在孩子中间和稀泥 |

#### 写崩的三种方式

1. 老大是背景娃娃。全程只负责可爱，戏眼瞎了，这条就剩大人的复读。
2. 后妈后爹旧脚本。苦情隐忍或恶毒防备，两个方向都是别的类型的存货。
3. 二胎谈话复制一胎。旧账不上桌，九个月白经历；这场谈话该比上次难一点，也快一点。
