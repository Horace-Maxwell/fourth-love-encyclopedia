## 设定接口：一张表管三种世界

双性日常、女尊异世的子嗣、ABO 的生育规则各在不同的设定页，分头归口处理。女尊制度看 [37-女尊制度进阶](37-女尊制度进阶.md)，ABO 生育看 [03-世界观设定/02-GB-ABO设定设计手册](../03-世界观设定/02-GB-ABO设定设计手册.md)（2.14 生育四解法），常规的双性日常看 [33-双性设定日常](33-双性设定日常.md)。机制写法都一样，条目里的「验出／建档／进产房」照下表换算。

## 一 · 要不要

`T` ｜ ⚠️生子 ｜ 通用 ｜ 语料频次：孩子 24.8% ＋ 催 15.9%（13-07 实测）

**骨架**｜想要孩子的人不用怀，要怀的人还没表态。这场谈话只有一条规矩：身体在谁那儿，谁说了算。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 动了念头：她抱过一回别人的孩子／族里的话传进了家门 |
| 2 | 她开了口，用的是问句。是问还是通知，他一听就分得出。 |
| 3 | 他要了几天。不是矜持，他在算身体的账：易感期、军役、铺子，哪一样停得起。 |
| 4 | 两张单子摆到一起，她列的是钱和人手，他列的是月份和身体。 |
| 5 | 否决权交回去。她先开口：「你说不要，这事就没有」 |
| 6 | 定，或者缓。缓要给日子，不给日子的缓就是把话咽了。 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 不在床上谈，床上说的不作数，两人都清楚 · 收了碗再提 · 女尊版：先把下人都支开 |
| 他的单子 | 月份表 · 要停下的事 · 医嘱或脉案 · 上一辈孕夫的旧事，他私下查过 |
| 她的单子 | 钱 · 人手 · 她能腾出来的空 · 单子最后一行小字：随他 |
| 外部干扰 | 门外传进来过「子嗣是他的本分」，谈正事前先把这话挡回去 |
| 收尾 | 定了不庆祝，缓了也不冷场，哪种都要有下一句接上 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁想要 | 她想要，他掏钱，这一族的主形 | 他想要，她怕他掏 |
| 否决权 | 说出口 | 心里都有数，只是从没挑明，早晚要挑明 |
| 谈的结果 | 定了 | 缓了，缓到哪一天已经说定 |
| 外部压力 | 还没影 | 已经堵到门口，催 15.9%，13-07 |

**她想要，而他付身体**，[13-家庭与亲属 · 要不要孩子](13-家庭与亲属.md#四--要不要孩子) 里那道「想要的人不承担代价」的题，到这里整个反了过来。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「我们要个孩子」她差点说成「我要」，一个字的差别她自己听出来了 | 他的单子写到第七行，才发现她那张上早替他列好了前六行 |
| 内心 | 我出钱，他出身体，这怎么算得平 | 这一回，答应不答应真的由我 |
| 好的处理 | 她先亮出否决权，再开口劝 | 他没当场答，说要走开几天想一想 |
| 写崩 | 她说了算，他照办 | 他拿身体当筹码讲条件 |

#### 写崩的三种方式

1. 她一个人拍板，他感动地点头。 身体的主权一交出去，后面九条全塌。
2. 用一次意外怀孕把谈话糊弄过去。 和 13-04 的第一种崩法是一回事，换了层壳照样翻车。
3. 把谈话弄成辩论赛。 摆数据，驳论点，分输赢，赢的那个抱回家的是个输了的枕边人。

## 二 · 验出来那天

`T` ｜ ⚠️生子 ｜ 通用 ｜ 语料频次：生子标签 3.4%（文案口径，08-缺口调研）

**骨架**｜谁先知道谁后知道，对外先告诉谁，这两张单子就是这个家的规矩。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 迹象：早起不舒服、腺体指标、脉象，他自己先起了疑 |
| 2 | 验：自己验，或者被医者一句话点破，拿到单子 |
| 3 | 独知期：短的一小时，长的两天，他揣着这件事等机会 |
| 4 | 告诉她：推过去一张单子／一句话／让她自己撞见，三种人三种做法 |
| 5 | 她说的头一句，定下全书的调子 |
| 6 | 排报喜的顺序，先告诉谁后告诉谁，两人当场对了一遍 |
| 7 | 当晚关了灯，两人都没睡着，各想各的 |

05-01 生子↺的拍 2 写得清楚：他先知道，她后知道，这一段的戏全在这个信息差上。落到日常，就把这个差压短——**他独自知道的那两天干了什么**，比宣布那一刻更有东西可写。

#### 可用细节

| 类 | 内容 |
|---|---|
| 单据等价物 | 两道杠／化验单／脉案／手机弹窗，按设定接口表换算 |
| 独知期动作 | 单据夹书里 · 推掉一趟远差 · 查“头三个月”查到后半夜 · 对着镜子愣了一会儿 |
| 告诉她的方式 | 单据压在她水杯底下 · 饭做到一半说的 · 什么都没说，她收外套时摸到了 |
| 她的第一句候选 | 「你想留吗」·「先坐下」·「什么时候的事」 |
| 报喜顺序 | 谁排第一个，她妈／他家／上司，或者先谁都不说 · 为顺序吵过一回 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先知道 | 他一个人早知道两天 | 两人一起看结果，单子一人捏着一角 |
| 计划内外 | 谈好之后，在计划内 | 计划外，回到 [一 · 要不要](#一--要不要) 补谈，顺序颠倒了，程序也不能省 |
| 他的第一情绪 | 喜 | 慌，喜是后来才跟上来的 |
| 泄露事故 | 没有 | 医馆的人嘴快，长辈先知道了，报喜成了补报 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看了推过来的单子才知道，可先看的是他的脸 | 单子在袖袋里揣了两天，边角都软了 |
| 内心 | 他瞒了两天，这两天他一个人在想些什么 | 想挑个她不累的晚上，可她天天都累 |
| 好的处理 | 她开口的第一句是个问题 | 他说的时候把「大概」「可能」都去掉了 |
| 写崩 | 她当场泪崩，原地转圈 | 他忐忑得卑微，生怕她不要 |

#### 写崩的三种方式

1. 独知期拖成了隐瞒。 瞒两天可以，瞒两个月就是欺骗，过了线就是另一场戏，线划在[15-秘密与坦白](15-秘密与坦白.md)。
2. 她只顾着激动。 激动了半天，一个具体的问题都没问，那是文案。她至少得问出一件实在的事。
3. 报喜前没跟对方对过。 顺序都没商量就说出去，等于把家里的章交给外人去盖。

## 三 · 产检日

`T` ｜ ⚠️生子 ｜ 通用 ｜ 语料频次：孩子 24.8%（13-07 实测）

**骨架**｜候诊室里只有他一个男的。表格里没有他的选项，叫号也不知道该喊他什么。一上午他都在替系统补漏。

| 4 | 填建档表，到「母亲姓名」一栏，笔停了 |

| 6 | 下回的预约记进谁的日历，谁去请假 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 表格 | 「母亲姓名」一栏，他划掉「母」字，写上自己的名字 · 系统下拉菜单里找不到他 · 签字处她让他来签（呼应 [七 · 生产](#七--生产)） |

| 数据 | 孕周和指标记在谁手机上 · 他记得比她细，她记得比他严 |
| 日程 | 她的日历上产检日标着红 · 她错过一次，那次的单子他没主动拿给她看 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 系统适配度 | 制度都接上了（ABO 已成常态，有男 O 门诊） | 只有他一个例外（表格都得手改） |
| 医生 | 绕过她，直接跟他说 | 只对他讲，把她晾在一边，她第一次尝到这种滋味 |
| 她在不在 | 每次都在 | 缺过一次，怎么补比道歉管用 |
| 他的应对 | 自己回答，答得很稳 | 让她答，回家路上才说「下回让我自己来」 |

医生没恶意，只是措辞钝，系统里也没他的位置。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 护士喊「家属」，她站起来，愣了一下才明白今天轮到自己了 | 表格第三栏，笔悬在上面的那两秒 |
| 内心 | 原来陪诊是这种滋味，坐着都像多出来的 | 满屋的人里，连表格都觉得我不该在这 |
| 好的处理 | 她把「家属」两个字咽回去，坐下，让他自己进去 | 他把改好的表推回窗口，语气像没事人一样 |
| 写崩 | 她当场翻脸，替他出头闹起来 | 他被看得发毛，缩在椅子上头都不敢抬 |

#### 写崩的三种方式

1. 候诊室里塞满恶意台词。 有眼神就够了，再加几句指指点点，就成了批斗会。浓度一高反倒假。
2. 把医生写成反派。 说制度迟钝说得通，怪到哪个医生头上就写浅了。
3. 产检只出现一次。 建完档就再也不进戏，机制又回设定卡里躺着了。这是 05-01 生子↺的第二种崩法。

| 好的处理 | 她不问「想吃什么」，报菜名让他挑，开放题他答不上来 | 咸淡他照实说，被照顾不等于当哑巴 |
| 写崩 | 她从头到尾只管心疼，站在灶台前的还是他 | 他吐两下就翻篇，身体再没下文 |

#### 写崩的三种方式

1. 照料没反过来。 她激动了十个月，围裙却还系在他身上，这一族就白写了。
2. 孕吐一笔带过。 十个条目都要用到他的身体感受，省掉了，十条就都是空的。
3. 她一学就会。 01 卷学着做饭的第一种崩法照样适用，她手忙脚乱的那几顿得写出来，他从这份笨拙里看得到她的诚意。

#### 写崩的三种方式

1. 孕期只拿来催泪。 肚子只在读者该哭的时候露一下脸，他身上什么感受，一个字也没写。

2. 把公开怀孕写成新闻发布会。 当众宣布，全场傻眼，打脸质疑的人，一套走下来，日常戏的底子就烧光了。

## 六 · 胎动那晚

`T` ｜ ⚠️生子 ｜ 通用 ｜ 语料频次：孩子 24.8%（13-07 实测）

**骨架**｜他前两天就有感觉了，一直没说。那天晚上他叫她过来，她把手放上去，等了四十分钟。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 他先感觉到，轻得像气泡，好几天了，一直憋着没说，想等一回大的 |

| 3 | 手搁上去，里头没动静了 |
| 4 | 等着，说话只剩气声，谁都不好意思先动 |
| 5 | 她说要去倒杯水，手没挪开，人也没起来 |
| 6 | 熬过四十分钟，那一下终于来了 |
| 7 | 过后两人都没出声，或者她说了一句很轻的话 |

#### 时间轴

他快睡着了又硬撑开眼，窗外过了一辆车，腿麻了也不敢动，手心出了汗就挪个位置。一段和一段之间，隔得越来越久。四十分钟里就这么点事，靠小动作切成一段段来填，和 [01-日常照料 · 守着不睡](01-日常照料.md#六--守着不睡) 一样。

#### 可用细节

| 类 | 内容 |
|---|---|
| 不对称 | 胎动在他身体里，她只能隔着肚皮去感受，这层肚皮就是两人今晚的距离 |
| 他的私心 | 前几天的动静他瞒着，想让她头一回摸到的就是实实在在的 |
| 等待中 | 她手心出汗 · 两人都屏着气 · 他看她的时间比留意肚子还长 |
| 那一下之后 | 她手指一抖 · 「踢我了」三个字说得像在讲秘密 |
| 落空版 | 那晚终究没等到，她趴着睡着了。后半夜动了，他没舍得叫醒她 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 等的结果 | 等到了 | 没等到，落了空更扎心 |
| 他说没说 | 憋了几天，自己偷着乐 | 一有动静就喊她，她没赶上，遗憾留到了晚上 |
| 她的状态 | 醒着等到底 | 等着等着睡着了，他守着两个 |
| 之后 | 说了句很小声的话 | 什么都没说，灯亮了一夜 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 四十分钟里她把一天的事想了个遍，到最后什么都不想了，只剩下等 | 其实他一直隐隐有感觉，他不说，是在等它给她一次 |
| 内心 | 隔着一层，我只能排着队等 | 里头那个和外头这个，都在等着对方 |
| 好的处理 | 她不肯挪手，也不催，等成了她自己的事 | 那一下来的时候，他先看的是她的脸 |
| 写崩 | 她对着肚子发表长篇感言 | 他从头到尾只是个传感器，没有自己的感受 |

#### 写崩的三种方式

1. 手刚放上去就动了。 这一晚就是在等那一秒，等到了才作数，等不到就是白熬。
2. 内心戏塞满。 那四十分钟得空着过，全填满就不叫等了。
3. 写成恐怖片。 身体变陌生是另一回事，[五 · 显怀](#五--显怀) 和 [41-他的身体与年岁](41-他的身体与年岁.md)里写过，这一晚不写那个。

## 七 · 生产

`M` ｜ ⚠️生子 ｜ 通用（门外机位，过程留白） ｜ 语料频次：生子标签 3.4%（文案口径，08-缺口调研）

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 偏偏在她走不开的时候发动，她正开着董事会，或者人在千里之外 |

| 3 | 一道门分开两人，他进去，她留在外面，从拿主意的人成了干等的人 |

| 5 | 门外的时间靠脚步声和说话声来数，不看表 |
| 6 | 中途出来告知一次，那人说了三句，她只记住第一句 |

#### 可用细节

| 轴 | 一端 | 另一端 |
|---|---|---|
| 顺与不顺 | 顺，门外那场戏全靠她乱了阵脚撑起来 | 不顺（第二次签字，写法见 05-01 生子↺第 5 拍） |
| 她在哪 | 一直守在门外 | 在赶路，最后一段是跑过走廊的，进门时孩子已经出来了 |
| 门开第一眼 | 她先看他 | 他先找她，两边对上了：先看人，后看孩子 |
| 世界差 | 手术室灯牌 | 产房外的廊柱和稳婆（女尊版） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 门外那几个小时，她头一回只能等 | 进门前那一段，疼成那样还分出神来安慰她，他自己都觉得奇怪 |
| 内心 | 里头每一点声音她都在算，算不出来就更怕 | 门快关上时，他回头说了句「外面冷，穿上外套」 |
| 好的处理 | 她谁也不指挥，唯独这间房她指挥不了 | 门里不写，他的戏在门关上之前和门打开之后 |
| 写崩 | 她一脚踹门冲进去，成了大女主戏 | 门里的情形现场直播 |

#### 写崩的三种方式

1. 套鬼门关的煽情模板。 血崩、暴雨、「保大保小」三样一起上，旧剧本又借尸还魂。要写风险就按 05-01 的写法，过了这一关，人的行为得跟着变。
2. 把门里的过程实写出来。 留白一破，分级也兜不住，这里的机位就定在走廊。
3. 孩子一落地，前面的事全清零。 产检时的表格、签字时的归属、排了九个月的班，产房门一开就全忘了，机制文只剩下机制。

| 走廊 | 缴费单攥皱了，没人去交 · 广播叫下一个号，两人都没动 · 她的包掉了，东西撒了一地，两人蹲下去捡，捡完又坐回去 |
| 安慰的错位 | 话都是冲她说的（「再要就是」），可失去的人是他，她站在一旁像个外人 · 反过来：大家都围着他，没人记得她也少了一块 |
| 女尊异世版 | 「无出」是老礼法里的话，指没生下孩子，一进了位份的说法，族里那点心思就全摆上桌面（接 [37-女尊制度进阶](37-女尊制度进阶.md)） |
| 试管线 | 一趟一趟跑医院的日子 · 成功率的数字听多了就麻木了 · 说不做的那天，和说做的那天一样沉 |
| 时差 | 他的身体先恢复了，可恢复本身反倒让他难受 · 她半夜去阳台，以为他早睡了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 形态 | 一直没等到（不育／试管屡败） | 等到过，没保住（流产） |
| 归因的诱惑 | 两人都不提这件事 | 一方偷偷往自己身上揽，要靠另一方接住 |
| 旁人 | 错位的安慰（见上表） | 不出声的体贴，嫂子把满月请帖压着没发 |
| 之后 | 再试，流程从头再走一遍 | 不再试了，两人真接住了这句话（13-04 那一头的续写） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她等他睡熟了才去阳台，回来时他呼吸不对，两个人都在装睡 | 身体一天天轻回去，好像什么都没发生过，他受不了这个 |
| 内心 | 我连难过都得排在他后面，可我也失去了 | 他们安慰她时，我想的是，那是从我身上走的 |
| 好的处理 | 她不说「都会好的」，改说「我也难受」 | 他让她看见他不好，没硬撑成没事人 |
| 写崩 | 她从头到尾冷静地主持大局 | 他一蹶不振，等着她来救 |

#### 写崩的三种方式

1. 拿下一胎翻篇。 冲喜一样再怀上，把空着的那段日子抹平了，难过就没地方放。
2. 开一场归因法庭。 追究是谁的错、错在哪一步，丧失戏就成了事故责任调查，两败俱伤，还查不出结果。
3. 哀伤只写一个人。 两人缓过来的快慢可以不同，可两个人的失去写成一个人的，另一个就成了背景板。

## 十 · 二胎与继子女

`T` ｜ ⚠️生子 ｜ 通用 ｜ 语料频次：孩子 24.8%（13-07 实测）

**骨架**｜再要一个，或者带着孩子重新组一个家。大人之间的事都好商量，真正的坎在老大那里。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 开头：二胎线是旧话重提，重组线是头一回带孩子见面 |
| 2 | 老大的第一反应，是清点自己的东西，或者盯着那个大人看 |
| 3 | 大人重走程序，一 · 要不要的谈话再来一遍，这回桌上多了旧账和前史 |
| 4 | 老大开始试探：叫一声试探的称呼，或者故意犯一条规矩，看新家长敢不敢管 |
| 5 | 出一件事：小的出生、继子女生病，每个人在这件事里站到自己的位置上 |
| 6 | 老大自己发明了接纳的仪式，大人只能等 |
| 7 | 新的家庭图定下来，称呼、房间、规矩，三样都换了新版 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 老大（二胎线） | 开口先问「他睡哪」，地盘比感情要紧 · 半夜偷偷去看小的 · 拿出一件旧玩具，又收回去，再拿出来 |
| 老大（重组线） | 试着叫了一声，没人接，又硬着头皮再叫一声 · 拿两边的规矩互相顶（「我妈说可以」） |
| 旧账 | 翻出上次生孩子的旧事（[七 · 生产](#七--生产) 或 [九 · 没等到的](#九--没等到的) 留下的尾巴） · 前任的影子还在：照片、抚养费、接送的日子 |
| 大人的错 | 偏心偏得明晃晃 · 逼老大说「喜不喜欢」 |
| 女尊版 | 位分和族谱：嫡出庶出，继子算不算她家的人，规矩方面接 [37-女尊制度进阶](37-女尊制度进阶.md) |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 线 | 二胎 | 重组：她带着女儿，或他带着前段的孩子 |
| 老大年龄 | 什么都听得懂（试探更精） | 似懂非懂，反应都在动作上 |
| 老大态度 | 防着 | 装出来的欢迎（更难写也更真） |
| 上一段的影子 | 淡 | 浓，九里没保住的，或前任，都算 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 继女那声称呼一出口，她应得太快，快到两个人都愣了 | 老大凑过来小声问「这次还疼吗」，他这才知道上回的事孩子全听见了 |
| 内心 | 我在跟一个孩子谈判，还谈不赢 | 手心手背的说法是假的，偏一回心，心里就记一笔 |
| 好的处理 | 她不用礼物换接纳，等老大自己想出仪式 | 他和老大单独谈了一回，像跟大人谈那样 |
| 写崩 | 她靠礼物铺路，一路通关 | 他夹在孩子之间和稀泥 |

#### 写崩的三种方式

1. 老大只是个背景板。 从头到尾只负责可爱，这条线就只剩大人翻来覆去地念叨。
2. 套后妈后爹的老路子。 要么苦情地忍，要么恶毒地防，两条路都被别的类型走烂了。
3. 二胎的谈话照搬头一胎。 不提旧账，那九个月就等于白过。这场谈话应当比上回难一点，也要比上回快一点。
