# 委屈与破防

> **分级** `T` ｜ 预警 无 ｜ 亚型 全谱系通用（分级见各条）
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**忍到最后一秒才破，破的那一下才值钱。**

---

## 破防的经济学

哭是这个类型里流通量最大的货币，也是最容易贬值的。

| 反应族 | 作品数 | 占比 |
|---|---:|---:|
| 拥抱 | 1,862 | 64.3% |
| 哭 | 1,822 | 63.0% |
| 委屈 | 1,581 | 54.6% |

六成以上的作品写了哭。用得越多，单次的价值越低。 一部作品里男主哭三次，第三次读者就麻木了。

控制通胀的两个办法：

| 办法 | 做法 |
|---|---|
| 提高门槛 | 前面写足他忍的能力，后面的破才有落差 |
| 换货币 | 不写哭，写别的破防形态（见下表） |

### 破防的七种形态，按烈度排

| 形态 | 表现 | 适合 |
|---|---|---|
| 一 沉默 | 该说话的时候不说 | 最克制，也最经用 |
| 二 走开 | 起身去阳台／厨房／洗手间 | 需要一个物理出口 |
| 三 手抖 | 拿东西的时候抖了一下 | 身体先于情绪 |
| 四 声音变了 | 说话时喉咙里的那个卡顿 | 电话戏专用 |
| 五 红眼眶 | 憋回去了 | 比哭出来更有力 |
| 六 哭 | 常规 | 通胀最严重 |
| 七 哭到失控 | 抽噎、说不出话 | 一部作品一次 |

五和六之间是分水岭。 憋回去的那一下，读者会替他哭。

## 一 · 哭着睡着

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：生病＋睡着 12.2%，做饭＋睡着 12.0%，归家＋睡着 10.2%

**骨架**｜他等不到、忍不住、哭了，然后哭累了睡着。她回来看见的是结果不是过程。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 撑到某个具体时刻 |
| 2 | 有一个很小的东西压垮了他（不是大事） |
| 3 | 哭 |
| 4 | 哭到累 |
| 5 | 睡着 |
| 6 | 她回来，看见 |

第 2 拍是这条的技术核心。压垮他的必须是小事：微波炉停了、消息没回、灯泡闪了一下。大事会让读者觉得他应该哭，小事才让读者心疼。

#### 时间轴

哭到睡着需要真实的时长，这个过程要有物质记录：

| 记录物 | 显示什么 |
|---|---|
| 抽了几张纸巾，堆在哪里 | 哭了多久 |
| 手机屏幕从亮到暗到再亮 | 他中途看了几次 |
| 身上的姿势（越来越蜷） | 从坐到躺的过程 |
| 睡着的位置不是床 | 他本来是在等 |

最后一行最关键。他睡在沙发上、地上、餐桌边，不在床上。一个细节说完了一切。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 沙发 ✓ · 被子 ✓（没盖）· 枕头 ✓（抱着的是抱枕不是枕头）· 手机 ✓（还攥在手里）· 餐桌 ✓ |
| 睡姿 | 蜷着 · 脸埋在臂弯 · 一只手还搭在桌上 · 身上还穿着外套 ✓ |
| 哭过的痕迹 | 眼角 ✓ 的干痕 · 睫毛 ✓ 结在一起 · 呼吸还带着一顿一顿的抽 · 鼻尖红 |
| 环境 | 灯 ✓ 还亮着 · 电视还开着播着无声的东西 · 饭菜 ✓ 还在桌上 |
| 她的动作 | 站住 · 不敢出声 · 蹲下来看 · 手伸到一半停住 |

「呼吸还带着一顿一顿的抽」是这条最好用的一个细节：它证明了她错过的那一段，不用任何叙述。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的处理 | 抱他回房，他没醒 | 她坐在旁边，等他自己醒 |
| 他醒后 | 装作不知道自己哭过 | 直接扑过来 |
| 她说不说破 | 什么都不问 | 第二天问了 |
| 谁哭 | 他 | 她（少见，且需要更强的铺垫） |

「她坐在旁边等他醒」比「抱回房」更好：抱回房是处理问题，坐着等是承担后果。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 进入点 | 开门看见沙发上那一团 | 撑不住的那一下 |
| 情绪 | 一种来不及的钝痛 | 我不想被看见 |
| 内心难点 | 我要不要叫醒他 | 醒来发现她在的那一秒 |
| 好的处理 | 她先关掉电视，再蹲下来 | 他没有邀功，也没有掩饰 |
| 写崩 | 写成她当场崩溃自责 | 写成他等着被发现 |

「他等着被发现」是这条最大的陷阱。只要他有一丝表演成分，全条就毁了。 他要真的以为没人会看见。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 伏在案上睡着／守着凉透的炭盆／衣裳没换就睡了 |
| 修仙 | 打坐入不了定，靠着石壁睡过去／灵力乱了一夜 |
| 星际 | 在观察窗前睡着／终端还停在给她的那条未发送的消息 |
| 末世 | 守着门睡着，刀还在手里 |

星际版里「未发送的消息」这一版最强：她能看见他写了又没发的那句话。

#### 写崩的三种方式

1. 让压垮他的是大事。 大事让他哭是理所当然，理所当然就不动人。
2. 让他醒着等她发现。 见上。
3. 她一进门就大喊他的名字。 那一刻的安静比任何反应都重。

## 二 · 憋着不说

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 54.6%

**骨架**｜他难受，她问了，他说没事。这条戏的全部内容就是那两个字。

#### 节拍链

他不对劲 → 她察觉 → 她问 → 他说没事 → 她再问／不再问 → 结果

#### 时间轴

憋的时长决定后面破的当量。 憋一晚上是撒娇，憋一个月是问题。

写法：用她问的次数分段。第一次问他说没事，第二次他说真的没事，第三次她不问了。第三次她不问，是这条最疼的地方。

#### 可用细节

| 类 | 内容 |
|---|---|
| 不对劲的表现 | 话变少 · 玩手机 ✓ 的时间变长 · 睡觉背对着 · 吃得少 · 不撒娇了 |
| 她的察觉方式 | 他今天没有蹭她 · 碗里剩了 · 他洗澡洗了很久 |
| 他的挡箭牌 | 「没事」「有点累」「工作上的事」 |
| 破口的时机 | 她放弃追问之后 · 或者一件完全无关的小事上突然爆发 |

「不撒娇了」是这一族的通用警报器，前面 [03 卷](03-撒娇与讨哄.md) 也用它。一个平时黏人的人突然不黏了，就是出事了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他为什么憋 | 怕她烦 | 他觉得说了也没用 |
| 她的应对 | 追问到底 | 不问，但守着 |
| 破口方式 | 她逼出来的 | 他自己说的 |
| 内容 | 就是那件事 | 说出来的是另一件（真正的那件更深） |

「说出来的是另一件」这个拨法很高级：人在开口时往往先说次要的那件，作为试探。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 难点 | 追问是关心还是逼迫 | 说出来会不会显得小气 |
| 好的处理 | 她说「不想说就不说，我在」 | 他说了，且说得不好听 |
| 写崩 | 写成她冷漠 | 写成他矫情 |

「不想说就不说，我在」这句是四爱女角色最好的一张牌：不逼迫的陪伴，比追问更接近权力的本质。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 侍立时垂着眼／她问他答「无事」／夜里她听见他没睡 |
| 修仙 | 灵力运转紊乱他自己压下去／她探脉他躲开 |
| 星际 | 心率数据异常他自己删了记录 |

#### 写崩的三种方式

1. 让他憋得毫无破绽。 破绽是给读者的，不是给她的。
2. 让她一问就破。 至少要三次。
3. 憋的内容太小。 憋一个月的事不能是「她忘了买他要的零食」。

#### 示例（本库自撰，可直接改写）

> 「没事。」
> 他说得很快，快到像是准备好的。手机还在手里，屏幕早暗了，他没有点亮。
> 「就是有点累。」
> 她没再问。厨房的水池里堆着碗，这三天都是他洗的，今天没洗。
> 睡觉的时候他背对着她，被子拉到肩膀。
> 她躺了很久，忽然想起来一件事：这三天他一次都没有蹭过她。

## 三 · 躲起来哭

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：哭 63.0%

**骨架**｜他不肯当着她哭，于是他找了个地方。她找到了他。

#### 节拍链

憋不住 → 找借口离席 → 挑一个有掩护声的地方 → 哭 → 洗脸 → 出来 → 两人都装作没事

#### 时间轴

他离席的时长就是警报等级。 十分钟以内是「去洗手间」，二十分钟她放下手里的事，半小时她起身找人。找到的时点决定痛感的位置：哭到一半被撞见最疼，哭完洗了脸、只剩眼睛红，是另一种疼。

#### 藏身处的语义

躲在哪里，说明了他和这个家的关系：

| 地点 | 含义 |
|---|---|
| 洗手间 | 最常见。有借口（水声），有锁 |
| 阳台 | 半公开，他其实没打算藏太严 |
| 车里 | 属于他自己的空间，且可以开走 |
| 楼梯间 | 他已经出了这个家 |
| 被子里 | 就在她旁边，但他假装睡着了 |
| 厨房 | 他还在做事，说明他在用忙碌压住 |

最后一行最好用。 一边切菜一边掉眼泪，比躲进厕所更难写也更有力。

#### 可用细节

| 类 | 内容 |
|---|---|
| 掩护 | 水声 · 抽油烟机 ✓ · 电视 · 他说他去拿个东西 |
| 破绽 | 出来时眼睛 ✓ 是肿的 · 声音哑 · 洗了脸但眼角 ✓ 还红 · 在里面待太久了 |
| 她的处理 | 敲门 · 不敲，在门外坐下 · 什么都不做，等他出来 |
| 出来之后 | 两个人都装作没事 · 她递水／递纸 · 她只是把手放在他背上 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她找不找 | 立刻去找 | 知道他在哪，不去 |
| 他知不知道被听见 | 不知道 | 知道，所以哭得更小声 |
| 出来后 | 谁都不提 | 她提了 |
| 谁躲 | 他 | 她（这一版更难得，也更有力） |

「她躲起来哭，被他找到」在语料里罕见。四爱女读者对「强势方也会崩」的需求是真实的，且几乎没有人在写。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 隔着门听见的那个声音 | 咬着手背不让声音出来 |
| 难点 | 进去还是不进去 | 出去之后要怎么装 |
| 好的处理 | 她在门外坐下来，不说话 | 他洗了脸，但没洗掉 |
| 写崩 | 写成她破门而入 | 写成他哭给她听 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 廊下／柴房／井边／她的马车外 |
| 修仙 | 后山／剑冢／他的洞府最里那间 |
| 星际 | 货舱／观察窗前／逃生舱（他没打算走，但他坐进去了） |

#### 写崩的三种方式

1. 让她立刻破门而入。 门外那段等待是这条的价值。
2. 让他哭得声音很大。 藏就要藏严实。破绽留在出来之后。
3. 哭完就和好。 出来之后各自装没事，比当场解决更真实。

## 四 · 被忽略

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 54.6%

**骨架**｜没有人对他做错什么。他只是在那儿，而没有人转过头。

#### 节拍链

他有一个微小的期待 → 场合发生 → 期待毫无恶意地落空 → 他继续做事 → 回家路上一句话不说

#### 时间轴

这条按次数计，不按分钟计。 单独任何一次落空都构不成事件——第一次他自己消化了，第二次他笑笑过去了，第三次回家路上一句话不说。写作时前两次必须埋出来，否则第三次的沉默没有来处。

#### 为什么这条最难写也最真实

它没有反派、没有冲突、没有事件。它的全部内容是「什么都没发生」。

写法上只有一个着力处：给他一个具体而微小的期待，然后让那个期待落空，且落空得毫无恶意。

| 微小的期待 | 落空的方式 |
|---|---|
| 她会问他今天怎么样 | 她问了别人 |
| 她会注意到他换了发型 | 她注意到了，但说的是别的事 |
| 饭桌上她会问他要不要 | 她给所有人都盛了，跳过了他（因为他碗里还有） |
| 出门时她会等他 | 她走在前面，正常速度 |

每一条都完全合理。残忍就在这里。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 一桌子人 · 她和朋友聊天 · 她在忙工作 · 家庭聚会 |
| 他的位置 | 在场，但在边缘 · 坐得离她一个位置 · 站在门口没进来 |
| 他做的事 | 玩手机 ✓（装的）· 给所有人倒水 · 收拾碗筷 · 一直在做事，因为做事的人不需要参与对话 |
| 她的无心之举 | 介绍别人时跳过了他 · 说「我们」的时候不包括他 |
| 破口 | 回家路上他一句话不说 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她有没有意识到 | 完全没有 | 事后想起来了 |
| 场合 | 私下 | 有第三方（更疼） |
| 他的反应 | 憋着 | 提前离场 |
| 后续 | 她发现并弥补 | 这件事沉底了，在很久以后浮上来 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她某个瞬间发现他不在座位上了 | 她说「我们」的时候他数了一下人头 |
| 好的处理 | 她想起来的时候不是道歉，是行动 | 他不指责，因为确实没人做错 |
| 写崩 | 写成她故意冷落 | 写成他小肚鸡肠 |

**这条的红线：不能有恶意。** 一旦她是故意的，这条就变成冷暴力。性质完全不同。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 席上没有他的位次／她的赏赐一一分下去漏了他／通名时他排在最后 |
| 修仙 | 门中大比她只看了大弟子／他的名字不在名录上 |
| 星际 | 任务简报的人员名单里没有他 |

古代版有制度加持：位次、名录、称谓，全是可见的排序。 这让「被忽略」有了物理形式。

#### 写崩的三种方式

1. 给她加上恶意。 见上。
2. 让他当场发作。 发作了就变成吵架戏。
3. 写得太长。 这条是钝刀，点到为止，靠积累。

## 五 · 被比较

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 54.6% ＋ 吃醋 37.6%

**骨架**｜有人提到了另一个人，而那个人在某方面比他强。

#### 节拍链

触发物出现 → 他问了一句 → 后悔问了 → 自己去查 → 更努力 → 心结留下

#### 时间轴

当场只有几秒，下沉期以周计。 他问那一句只花了三秒，后悔用了一晚上，之后是长长的沉降：查那个人、悄悄加练、再不主动提起。比较的伤不在当天，在之后每次相关物出现时那半拍的停顿。

#### 比较的三个来源

| 来源 | 杀伤力 | 说明 |
|---|---|---|
| 外人比 | 低 | 他可以不在乎 |
| 她无意中比 | 高 | 她只是在陈述事实 |
| 他自己比 | 最高 | 没有人说什么，他自己在比 |

第三种最好用。 全程没有人说过一句伤人的话。

#### 可用细节

| 类 | 内容 |
|---|---|
| 比较的维度 | 能力 · 出身 · 与她相处的时长 · 她提起对方时的语气 · 对方能陪她做的事 |
| 触发物 | 一张旧照片 ✓ · 她手机 ✓ 里的旧联系人 · 别人一句「你还不如」· 她随口说的「他以前……」 |
| 他的反应 | 问了一句，然后后悔问了 · 什么都没问，去查了 · 更努力（这个最疼） |
| 她的迟钝 | 她完全没意识到那句话有杀伤力 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 对方是谁 | 前任 | 她的挚友／同僚（更难处理） |
| 她的态度 | 她根本没在比 | 她确实有一瞬间比了 |
| 他的反应 | 说出来 | 自己消化 |
| 结果 | 她及时发现并明确表态 | 这成为他长期的心结 |

「她确实有一瞬间比了」这一端更真实，也更需要功力：人是会比的，重要的是比完之后她选了谁。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 难点 | 她要怎么表态而不显得敷衍 | 问出口就输了 |
| 好的处理 | 她给出具体的、只属于他的理由 | 他把这个心结自己解决了一半 |
| 写崩 | 写成她大段深情表白 | 写成他自卑到底 |

具体才行。「我喜欢的是你」是空话；「你煮的粥要放两次盐我才知道你在用心」是理由。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 正君与侧君的位次／旧人／她少年时的伴读 |
| 修仙 | 前任道侣／她的同门师兄／双修伴侣的资质排序 |
| 星际 | 她上一任副手／匹配度数据 |

女尊设定自带比较系统：位次即排序，排序即比较。 见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。

#### 写崩的三种方式

1. 让对方成为真反派。 那是三角恋情节，不是这一条。
2. 让她大段表白。 一个具体的细节抵三段情话。
3. 让他一次就释怀。 心结要留。

## 六 · 忍到最后一秒

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 54.6% ＋ 哭 63.0%

**骨架**｜他撑住了全场，然后在最安全的那一刻塌下来。

#### 节拍链

出事 → 他处理 → 他一直很稳 → 事情结束 → 独处／她出现 → 塌

#### 时间轴

塌的位置是这条的全部技术。 塌得太早是脆弱，塌得太晚是麻木。最佳位置是「危险刚过去的那一分钟」。

| 塌的位置 | 效果 |
|---|---|
| 事情进行中 | 显得他撑不住，减分 |
| 事情刚结束，独处时 | 标准解 |
| 事情刚结束，她过来时 | 最优解 |
| 很久以后 | 需要额外的触发物 |

「她过来时」最优，因为它把塌的原因归给了她的到场：事情没打垮他，她一到，他就不用撑了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 撑住的表现 | 声音很稳 · 手很稳 · 安排得井井有条 · 别人都以为他没事 |
| 撑不住的先兆 | 手开始抖（在没人看见的时候）· 需要扶一下门框 · 说话开始有一秒的延迟 |
| 塌的形态 | 蹲下去 · 靠着墙滑下来 · 说话说到一半停住 · 什么都没有，只是不动了 |
| 她的动作 | 不问发生了什么 · 直接抱住 · 或者先什么都不做，坐到他旁边 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 出的什么事 | 外部危机 | 他自己的事（家里、身体） |
| 谁在场 | 只有他们两个 | 还有别人（他要撑更久） |
| 她的到场 | 及时 | 晚了一步（他已经自己撑过去了，更疼） |
| 事后 | 他解释 | 他一句都不说 |

「她晚了一步」这个拨法很狠：他自己撑过去了，说明下次他也会自己撑过去。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看见他站得笔直，然后看见他手在抖 | 撑住的每一分钟 |
| 好的处理 | 她不夸他坚强，她只是在场 | 他塌的时候没有说话 |
| 写崩 | 写成她的英雄救美 | 写成他从头到尾很惨 |

不要夸他坚强。 夸了就等于要求他下次继续坚强。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 撑完丧仪／撑完对簿公堂／回到房里才跪坐下去 |
| 修仙 | 硬扛完雷劫／她赶到时他刚好松了那口气 |
| 星际 | 指挥完撤离／舱门关上之后靠着舱壁滑下去 |

#### 写崩的三种方式

1. 让他中途崩。 那前面的撑就白写了。
2. 让她一路陪着。 他必须独自撑过大部分。
3. 让他事后详细复盘。 塌了就是塌了，不需要解释。

## 七 · 说了狠话

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 54.6% ＋ 道歉 49.0%

**骨架**｜他说了一句他自己都不信的话，然后房间安静了。

#### 节拍链

积压 → 触发 → 说出口 → 那一秒的空白 → 他想收回 → 收不回 → 后果

#### 时间轴

说出口之后的那三秒是这条的心脏。 那三秒里两个人都没动，都在等对方先反应。

写法：把那三秒里的环境音写出来。冰箱、钟、楼下的车、水龙头没关紧的滴答。声音越琐碎，安静越重。

#### 可用细节

| 类 | 内容 |
|---|---|
| 狠话的类型 | 「你根本不在乎」· 「那你去找她好了」· 「我算什么」· 「你走啊」 |
| 说出口的信号 | 声音突然大了 · 或者声音突然很轻（更狠） |
| 那三秒 | 环境音 · 两个人都没动 · 他的手还举着 |
| 想收回的动作 | 张了张嘴 · 往前迈了半步 · 又停住 |
| 她的反应 | 沉默 · 转身走 · 或者走过去抱住（最难写也最好） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 狠话真假 | 反话（他其实想要她留下） | 真心话，压了很久 |
| 她怎么接 | 走了 | 没走 |
| 他多久道歉 | 当场 | 三天后 |
| 修复 | 完全修复 | 留了痕（更真实） |

「留了痕」是成年人关系的真相。说出去的话可以被原谅，但不会被忘记。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 那三秒 | 她在判断这句话是不是真的 | 他在数她会不会走 |
| 好的处理 | 她没走，但她也没马上原谅 | 他道歉时不解释动机 |
| 写崩 | 写成她一巴掌／夺门而出 | 写成他跪下来求 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 顶撞了她／当着人说了不该说的／摔了她给的东西 |
| 修仙 | 说要断了契／剑指向她 |
| 星际 | 申请调离／在公开频道说了那句话 |

#### 写崩的三种方式

1. 让狠话太重。 重到不可原谅，就没有后面的戏了。
2. 让他立刻跪下认错。 那三秒的空白是最贵的，别急着填。
3. 一句话就和好。 至少要留一章的余震。

## 八 · 冷战

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 54.6%

**骨架**｜两个人住在一起，但谁都不先开口。

#### 节拍链

爆点 → 各自不开口 → 日常动作还在做 → 出现一件必须合作的小事 → 一句功能性的话 → 第二句

#### 时间轴

进度不看天数，看话量。 从零句，到一句「递一下酱油」，到两句——功能性对话的密度就是解冻曲线。背景钟是照常运转的日常：他照常做饭她照常吃，生活在走，话停着，两者的反差越久越响。

#### 冷战的物理学

冷战的写法不在情绪在动线：

| 观察点 | 显示什么 |
|---|---|
| 谁先起床 | 谁在躲 |
| 饭是不是还做 | 关系有没有真断 |
| 两份饭是分开吃还是一起吃 | 冷的程度 |
| 谁睡沙发／谁睡里面 | 谁在赌气 |
| 灯谁关的 | 谁最后睡的（谁在等） |
| 早上的水杯是不是还倒了两杯 | 习惯有没有断 |

最后一行是冷战戏最好用的一条：手还在做，人不肯说。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 沙发 ✓ · 被子 ✓（多出来的那一床）· 餐桌 ✓ · 两个水杯 · 玄关 ✓ 的拖鞋摆向 · 灯 ✓ |
| 破冰的契机 | 一件必须合作的小事（家里跳闸、他手够不到、快递要签收） |
| 谁先开口 | 通常不是道歉，是一句功能性的话（「盐在哪」） |
| 和好的信号 | 第一句话之后的第二句 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时长 | 一晚 | 一周 |
| 谁在维持 | 他（她想和好） | 她（更少见，也更有张力） |
| 破冰方式 | 事件推动 | 有人先低头 |
| 结果 | 和好 | 表面和好，实际有东西变了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 我不该先低头，但我想先低头 | 她今天又倒了两杯水 |
| 好的处理 | 她用行动而不是语言 | 他注意到了，但还没准备好 |
| 写崩 | 写成她理直气壮 | 写成他消极攻击 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 分房／他不去正房请安／她的赏赐照送但没有话 |
| 修仙 | 各自闭关／契约还在但传音不通 |
| 星际 | 排班错开／但他还是给她留了热食 |

#### 写崩的三种方式

1. 写成互相伤害。 冷战的本质是都不想伤害，所以什么都不说。
2. 让某一方彻底不管。 有人还在做那些小事，才叫冷战。
3. 靠第三人调解。 第三人插手会削弱两人的关系强度。

## 九 · 我是不是不够好

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 54.6%

**骨架**｜他把问题归到自己身上，而这恰恰是最难反驳的。

#### 节拍链

触发 → 他绕着问 → 没问出结果 → 他开始自我改造 → 突然变懂事 → 她某天发现他不黏了

#### 时间轴

自我改造按周推进。 第一周不再抢遥控器，第二周报备变短，第三周不黏了——他把自己一点点删减，删的速度慢到不易察觉。她发现异常的时点越晚，改造越深，拆起来越难；这条的钟是「她多久才发现」。

#### 为什么这条难处理

「你是不是不喜欢我了」可以被否认。「是不是我不够好」不能，因为否认它等于否认他的感受。

反驳没有用。她的正确应对是改变问题的框架：不回答「你够不够好」，而回答「我要的是什么」。

| 她的回答 | 效果 |
|---|---|
| 「你很好啊」 | 无效，太轻 |
| 「不是你的问题」 | 更糟，等于承认有问题 |
| 「我最近确实忽略你了」 | 有效，承认事实 |
| 「我要的不是好，我要的是你」 | 最优，但要有前文支撑才不显廉价 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 触发 | 被比较之后 · 撒娇失败之后 · 她连续加班之后 |
| 他的问法 | 不会直接问，会绕：「你今天怎么了」「我是不是太黏人了」 |
| 他的自我改造 | 减少撒娇 · 变得懂事 · 主动说「你忙你的」（这才是警报） |
| 她的察觉 | 他突然变懂事了 |

「他突然变懂事了」是这个类型里最重的警报。 懂事是弱势方放弃索取的信号。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他问不问 | 问了 | 没问，直接开始改造自己 |
| 她察不察觉 | 及时察觉 | 很久以后才发现他不撒娇了 |
| 她的回应 | 语言 | 行动（推掉一件事，早回家一次） |
| 结果 | 修复 | 他从此收敛（这是最坏的结局，且很多现实关系就是这样） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他这周一次都没黏过她 | 我是不是该少要一点 |
| 好的处理 | 她主动要求他黏 | 他终于问出口 |
| 写崩 | 写成她大段安慰 | 写成他自我厌弃 |

「她主动要求他黏」是最漂亮的解法：把索取变成她的需求，他就不用愧疚了。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他开始守规矩守得过分／不再讨赏／请安分毫不差 |
| 修仙 | 他开始拼命修炼／不再来找她 |
| 星际 | 他把私人通讯频率调低了 |

#### 写崩的三种方式

1. 让她长篇安慰。 安慰越长，越像在处理麻烦。
2. 让他自我厌弃到底。 那是另一种病理，不是这一条。
3. 忽略「变懂事」这个信号。 这是全条最有价值的观察。

## 十 · 她也会哭

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：哭 63.0%（女方向罕见）

**骨架**｜强势的那一方崩了一次。整部作品最多一次。

#### 为什么必须有这一条

如果她从头到尾不会崩，她就成了功能，算不上人。而且他的处境会变成永久的弱势，那就成了设定，不再是关系。

一次就够。一次让整个关系从「照顾与被照顾」变成「互相支撑」。

#### 节拍链

她一直很稳 → 出事 → 她还是很稳 → 独处／他在 → 崩 → 他的反应 → 之后两人都不提

#### 时间轴

同 [六 · 忍到最后一秒](#六--忍到最后一秒)，但门槛更高：她要撑得比他久得多，崩得比他浅得多。

她的崩不需要嚎啕。一滴眼泪、一次呼吸乱掉、一句说到一半的话，就足够。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的破绽 | 手停在半空 · 转过身去 · 一句话说了两遍 · 眼角 ✓ 有一下 |
| 他的反应梯度 | 愣住 → 不知所措 → 走过去 → 抱住 → 什么也没说 |
| 角色反转 | 这一刻他是照料方，且他做得笨拙 |
| 事后 | 她第二天照常 · 他知道那件事发生过 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 起因 | 外部（工作、家人、失去） | 因为他（她怕自己给不了他要的） |
| 他在不在 | 他撞见 | 她主动让他看见（这需要极强的关系基础） |
| 他的处理 | 抱住 | 什么都不做，坐在旁边（更好） |
| 之后 | 提了 | 谁都不提，但关系变了 |

「她主动让他看见」是这条的最高形态：主动示弱是强势方能给出的最大让渡。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己撑不住了，且他在旁边 | 第一次看见她这样 |
| 内心 | 我不能在他面前这样／我为什么不能 | 我该做什么，我从来没做过这个 |
| 好的处理 | 她没有解释为什么哭 | 他笨拙但没有走开 |
| 写崩 | 写成她瞬间变柔弱 | 写成他趁机上位 |

「趁机上位」是这条最大的雷。 她崩了不等于关系翻转。第二天她还是她。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 卸了钗环坐在榻边／批折子批到停笔／他进来时她没抬头 |
| 修仙 | 她的剑第一次没握稳／灵力散了一瞬 |
| 星际 | 她在指挥席上停了三秒／他是唯一看见的人 |

#### 写崩的三种方式

1. 写超过一次。 一次是深度，两次是人设动摇。
2. 让他趁机翻身。 见上。
3. 让她哭得很厉害。 她的崩要浅，浅才符合她。
