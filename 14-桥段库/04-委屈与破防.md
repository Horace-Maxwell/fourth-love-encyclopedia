# 委屈与破防

> **分级** `T` ｜ 预警 无 ｜ 亚型 全谱系通用（分级见各条）
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**忍到最后一秒才破，破的那一下才值钱。**

---

## 破防的经济学

哭是这个类型里流通量最大的货币，也是最容易贬值的。

| 反应族 | 作品数 | 占比 |
|---|---:|---:|
| 拥抱 | 1,862 | 64.3% |
| 哭 | 1,822 | 63.0% |
| 委屈 | 1,581 | 54.6% |

六成以上的作品写了哭。用得越多，单次的价值越低。一部作品里男主哭三次，第三次读者就麻木了。

控制通胀的两个办法：

| 办法 | 做法 |
|---|---|
| 提高门槛 | 前面写足他忍的能力，后面的破才有落差 |
| 换货币 | 不写哭，写别的破防形态（见下表） |

### 破防的七种形态，按烈度排

| 形态 | 表现 | 适合 |
|---|---|---|
| 一 沉默 | 该接话的时候不接 | 最省事，也最耐看 |
| 二 走开 | 起身去阳台／厨房／洗手间 | 得找个地方缓缓 |
| 三 手抖 | 拿东西时手不听使唤 | 身体比嘴先漏底 |
| 四 声音变了 | 说话时嗓子眼堵了一下 | 电话戏专用 |
| 五 红眼眶 | 眼泪硬憋回去 | 比哭出来更扎心 |
| 六 哭 | 正常哭 | 用多了就不值钱 |
| 七 哭到失控 | 抽噎、说不出整话 | 一部作品用一次就够 |

五和六之间是分水岭。 憋回去的那一下，读者会替他哭。

## 一 · 哭着睡着

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：生病＋睡着 12.2%，做饭＋睡着 12.0%，归家＋睡着 10.2%

**骨架**｜他实在等不到她回来，绷不住哭到睡着。她回来时，只看见他睡着了，没看见他哭。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 撑到某个具体时刻 |
| 2 | 有一个很小的东西压垮了他（不是大事） |
| 3 | 哭 |
| 4 | 哭到累 |
| 5 | 睡着 |
| 6 | 她回来，看见 |

第 2 拍是这条的技术核心。压垮他的必须是小事：微波炉停了、消息没回、灯泡闪了一下。大事会让读者觉得他应该哭，小事才让读者心疼。

#### 时间轴

哭到睡着需要真实的时长，这个过程要有物质记录：

| 记录物 | 显示什么 |
|---|---|
| 抽了几张纸巾，堆在哪里 | 哭了多久 |
| 手机屏幕从亮到暗到再亮 | 他中途看了几次 |
| 身上的姿势（越来越蜷） | 从坐到躺的过程 |
| 睡着的位置不是床 | 他本来是在等 |

最后一行最关键。他睡在沙发上、地上、餐桌边，不在床上。一个细节说完了一切。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 沙发 ✓ · 被子 ✓（没盖）· 枕头 ✓（抱的是抱枕）· 手机 ✓（还攥在手里）· 餐桌 ✓ |
| 睡姿 | 蜷着 · 脸埋在臂弯 · 一只手搭在桌上 · 身上还穿着外套 ✓ |
| 哭过的痕迹 | 眼角 ✓ 有干痕 · 睫毛 ✓ 粘在一起 · 呼吸还一抽一抽的 · 鼻尖红 |
| 环境 | 灯 ✓ 还亮着 · 电视开着但没声 · 饭菜 ✓ 还在桌上 |
| 她的动作 | 站住 · 不敢出声 · 蹲下来看 · 手伸到一半又停住 |

「呼吸还带着一顿一顿的抽」是这条最好用的一个细节：它证明了她错过的那一段，不用任何叙述。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的处理 | 抱他回房，他没醒 | 她坐床边，等他睁眼 |
| 他醒后 | 装没事，当没哭过 | 直接扑过来 |
| 她说不说破 | 一个字不提 | 第二天开口问了 |
| 谁哭 | 他 | 她少见，铺垫要更足 |

「她坐在旁边等他醒」比「抱回房」更好：抱回房是处理问题，坐着等是承担后果。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 进入点 | 开门看见沙发上那一团 | 撑不住的那一下 |
| 情绪 | 疼都来不及疼 | 我不想让人看见 |
| 内心难点 | 要不要叫醒他 | 醒来发现她还在 |
| 好的处理 | 她先关电视，再蹲下来 | 他没显摆，也没藏 |
| 写崩 | 她当场崩了，怪自己 | 他等着她来发现 |

「他等着被发现」是这条最大的陷阱。只要他有一丝表演成分，全条就毁了。 他要真的以为没人会看见。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 趴在桌上睡着了／炭盆早凉了／衣服也没换就躺下 |
| 修仙 | 想打坐却静不下心，靠着墙睡过去／灵力翻腾了一整夜 |
| 星际 | 在舷窗前睡着／终端上还留着没发出去的消息 |
| 末世 | 靠着门睡死过去，手里还攥着刀 |

星际版里「未发送的消息」这一版最强：她能看见他写了又没发的那句话。

#### 写崩的三种方式

1. 压垮他的得是大事。大事让他哭，谁看了都觉得该哭，那就不动人了。
2. 让他醒着，等她发现。跟上面一个道理。
3. 她一进门就喊他名字。别写别的，就写那一刻的安静，比写他哭、他闹都重。

> 桌上的菜还盖着保鲜膜。她数了一下，四个盘子，一个都没动过。

## 二 · 憋着不说

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 54.6%

**骨架**｜他难受，她问了一句，他说没事，整场戏就靠这俩字撑着。

#### 节拍链

他不对劲 → 她察觉 → 她问 → 他说没事 → 她再问／不再问 → 结果

#### 时间轴

憋的时长决定后面破的当量。 憋一晚上是撒娇，憋一个月是问题。

写法：按她问的次数来分段。第一次问，他说没事。第二次问，他说真的没事。第三次她不问了。她不问，才是最疼的地方。

#### 可用细节

| 类 | 内容 |
|---|---|
| 不对劲的表现 | 话变少 · 玩手机 ✓ 的时间变长 · 睡觉背对着 · 吃得少 · 不撒娇了 |
| 她的察觉方式 | 他今天没蹭她 · 碗里剩了饭 · 他洗澡洗了很久 |
| 他的挡箭牌 | 「没事」「有点累」「工作上的事」 |
| 破口的时机 | 她不再追问之后 · 或者为一件不相干的小事突然炸了 |

「不撒娇了」是这一族的通用警报器，前面 [03 卷](03-撒娇与讨哄.md) 也用过。平时黏人的人突然不黏了，那就是出事了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他为什么憋 | 怕她烦 | 觉得说了也白说 |
| 她的应对 | 追着问 | 不问，就守着 |
| 破口方式 | 她逼出来的 | 他自己开口 |
| 内容 | 就那件事 | 说的是另一件，真正那件更沉 |

「说出来的是另一件」这个拨法很高级：人在开口时往往先说次要的那件，作为试探。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 难点 | 分不清是关心还是逼问 | 怕开口显得自己计较 |
| 好的处理 | 她说「不想说就不说，我陪着你」 | 他讲了，哪怕讲得难听 |
| 写崩 | 把她写得太冷 | 把他写得太作 |

「不想说就不说，我在」这句是四爱女角色最好的一张牌：不逼迫的陪伴，比追问更接近权力的本质。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 站着不敢抬头／她问啥他都说“没事”／夜里她听见他翻来覆去 |
| 修仙 | 灵力乱了硬撑着不吭声／她伸手把脉他往后躲 |
| 星际 | 心率不对他自己把记录删了 |

#### 写崩的三种方式

1. 让他憋得毫无破绽。破绽是给读者的，不是给她的。
2. 让她一问就破。至少要三次。
3. 憋的内容太小。憋一个月的事不能是「她忘了买他要的零食」。

#### 示例（本库自撰，可直接改写）

> 「没事。」
> 他说得很快，快到像是准备好的。手机还在手里，屏幕早暗了，他没有点亮。
> 「就是有点累。」
> 她没再问。厨房的水池里堆着碗，这三天都是他洗的，今天没洗。
> 睡觉的时候他背对着她，被子拉到肩膀。
> 她躺了很久，忽然想起来一件事：这三天他一次都没有蹭过她。

## 三 · 躲起来哭

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：哭 63.0%

**骨架**｜他死活不肯当着她的面哭，躲到别处去。她还是找着他了。

#### 节拍链

憋不住 → 找借口离席 → 挑一个有掩护声的地方 → 哭 → 洗脸 → 出来 → 两人都装作没事

#### 时间轴

他离开二十分钟之后，她把手里的活儿放下来。超过半小时，她干脆起身去找人。十分钟以内，算「去洗手间」，不用管。警报的级别，跟着他离开的时长走。正哭到一半被撞见，最难受。眼睛红着，脸也洗了，那是另一种难受。什么时候找到，疼的地方不一样。

#### 藏身处的语义

躲在哪里，说明了他和这个家的关系：

| 地点 | 含义 |
|---|---|
| 洗手间 | 最常见。有水声当借口，还有锁 |
| 阳台 | 半公开，他其实没打算藏太严 |
| 车里 | 他自己的地方，而且能开走 |
| 楼梯间 | 他已经出了这个家 |
| 被子里 | 就在她旁边，但他装睡 |
| 厨房 | 他还在忙活，拿干活压着事 |

最后一行最好用。 一边切菜一边掉眼泪，比躲进厕所更难写也更有力。

#### 可用细节

| 类 | 内容 |
|---|---|
| 掩护 | 水声 · 抽油烟机 ✓ · 电视 · 他说他去拿个东西 |
| 破绽 | 出来时眼睛 ✓ 是肿的 · 声音哑 · 洗了脸但眼角 ✓ 还红 · 在里面待太久了 |
| 她的处理 | 敲门 · 不敲，在门外坐下 · 什么都不做，等他出来 |
| 出来之后 | 两个人都装作没事 · 她递水／递纸 · 她只是把手放在他背上 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她找不找 | 立马出门找 | 明知道他在哪儿，就是不去 |
| 他知不知道被听见 | 没察觉 | 知道，反而压着声哭 |
| 出来后 | 谁都不提这事 | 她先开了口 |
| 谁躲 | 他躲 | 她躲，这版更少见，也更带劲 |

「她躲起来哭，被他找到」这种情节，语料里很少见。四爱女读者其实很需要「强势方也会崩」的写法，但几乎没人写。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 隔着门听见的那个声音 | 咬着手背不让声音出来 |
| 难点 | 进去还是不进去 | 出去之后要怎么装 |
| 好的处理 | 她在门外坐下来，不说话 | 他洗了脸，但没洗掉 |
| 写崩 | 写成她破门而入 | 写成他哭给她听 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 廊下／柴房／井边／她的马车外 |
| 修仙 | 后山／剑冢／他的洞府最里那间 |
| 星际 | 货舱／观察窗前／逃生舱，他没打算走，但他坐进去了 |

#### 写崩的三种方式

1. 门外那段等待才是这场戏的命。 让她立刻破门而入。
2. 要藏就藏死。 破绽得等出来之后再露。 让他哭得声音很大。
3. 出来之后谁都不提，比当场把话说开更真实。 哭完就和好。

## 四 · 被忽略

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 54.6%

**骨架**｜没人对他做错什么，他就站在那儿，没一个人回头看他。

#### 节拍链

他有一个微小的期待 → 场合发生 → 期待毫无恶意地落空 → 他继续做事 → 回家路上一句话不说

#### 时间轴

这条按次数算，不按时间算。单次落空根本不算事。第一次他自己忍了，第二次他笑一下就过去了，第三次回家路上一个字不说。写的时候前两次必须埋下，不然第三次的沉默没根没底。

#### 为什么这条最难写也最真实

它没有反派、没有冲突、没有事件。它的全部内容是「什么都没发生」。

写法上只有一个着力处：给他一个具体而微小的期待，然后让那个期待落空，且落空得毫无恶意。

| 微小的期待 | 落空的方式 |
|---|---|
| 她会问他今天怎么样 | 她问了别人 |
| 她会注意到他换了发型 | 她看见了，但聊的是别的事 |
| 饭桌上她会问他要不要 | 她给所有人都盛了，跳过了他，他碗里还有 |
| 出门时她会等他 | 她走在前面，没放慢脚步 |

每一条都完全合理。残忍就在这里。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 一桌子人 · 她和朋友聊天 · 她在忙工作 · 家庭聚会 |
| 他的位置 | 在场，但在边上 · 隔一个座位 · 站门口没进来 |
| 他做的事 | 玩手机 ✓（装的）· 给大伙倒水 · 收碗筷 · 一直忙活，忙活的人不用搭话 |
| 她的无心之举 | 介绍别人时漏了他 · 说「我们」时没带上他 |
| 破口 | 回家路上他一声不吭 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她有没有意识到 | 完全没察觉 | 事后才反应过来 |
| 场合 | 就俩人 | 有旁人在，更丢人 |
| 他的反应 | 硬扛着 | 待不住先走了 |
| 后续 | 她发现了，想法补救 | 这事先压着，过很久才翻出来 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她某个瞬间发现他不在座位上了 | 她说「我们」的时候他数了一下人头 |
| 好的处理 | 她想起来的时候不道歉，直接行动 | 他不指责，因为确实没人做错 |
| 写崩 | 写成她故意冷落 | 写成他小肚鸡肠 |

**这条的红线：不能有恶意。** 一旦她是故意的，这条就变成冷暴力。性质完全不同。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 席上没给他留位子／赏赐发了一圈偏没他的／通名时他排最末 |
| 修仙 | 门中大比只点了大弟子／名录上找不到他名字 |
| 星际 | 任务简报里压根没提他这号人 |

古代版有制度加持：位次、名录、称谓，全是可见的排序。 这让「被忽略」有了物理形式。

#### 写崩的三种方式

1. 给她加上恶意。 见上。
2. 让他当场发作。 发作了就变成吵架戏。
3. 写得太长。 这条是钝刀，点到为止，靠积累。

## 五 · 被比较

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 54.6% ＋ 吃醋 37.6%

**骨架**｜有人提了句别人，说那人在某方面比他强。

#### 节拍链

触发物出现 → 他问了一句 → 后悔问了 → 自己去查 → 更努力 → 心结留下

#### 时间轴

那半拍的停顿，从来不在当天发生。真正磨人的是之后，是下沉期，按周计算的那种。他问那一句不过三秒，后悔却翻来覆去一整晚。之后是漫长的沉降：去查那个人，偷偷加练，再也不主动提。比较的伤，总要等到下次再碰到相关的东西，才显出来。

#### 比较的三个来源

| 来源 | 杀伤力 | 说明 |
|---|---|---|
| 外人比 | 低 | 他可以不在乎 |
| 她无意中比 | 高 | 她只是在陈述事实 |
| 他自己比 | 最高 | 没有人说什么，他自己在比 |

第三种最好用。 全程没有人说过一句伤人的话。

#### 可用细节

| 类 | 内容 |
|---|---|
| 比较的维度 | 本事 · 家底 · 认识多久 · 她聊起那人时的口气 · 那人能陪她干点啥 |
| 触发物 | 一张老照片 ✓ · 她手机 ✓ 里没删的旧人 · 别人来一句「你还不如他」· 她随口说「他以前啊……」 |
| 他的反应 | 问了一嘴，问完就后悔 · 啥也没问，转头自己去查 · 更拼命对她好，这个最扎心 |
| 她的迟钝 | 她压根没觉着那句话能伤到人 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 对方是谁 | 前任 | 她的挚友／同僚，更难办 |
| 她的态度 | 她压根没当回事 | 她确实有一瞬间较真了 |
| 他的反应 | 直接说出口 | 憋在心里 |
| 结果 | 她马上发现，把话说清 | 这事成了他多年的疙瘩 |

「她确实有一瞬间比了」这一端更真实，也更需要功力：人是会比的，重要的是比完之后她选了谁。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 难点 | 她怎么开口才不像走过场 | 先问就矮一头 |
| 好的处理 | 她说的每一条，都只有他能对上号 | 他自己想通了大半 |
| 写崩 | 变成她一口气说一堆掏心窝子的话 | 变成他把自己往死里贬 |

具体才行。「我喜欢的是你」是空话。「你煮的粥要放两次盐我才知道你在用心」是理由。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 正君和侧君谁说了算／跟了她多年的旧人／小时候陪她念书的伴读 |
| 修仙 | 以前的道侣／她同门的师兄／双修的人够不够格排第几 |
| 星际 | 她上一个副手／俩人合不合拍的数据 |

女尊设定天生就是把“比”字写在脸上：位次就是排名，排名就是拿来比的。见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。

#### 写崩的三种方式

1. 让对方成为真反派。那是三角恋情节，不是这一条。
2. 让她大段表白。一个具体的细节抵三段情话。
3. 让他一次就释怀。心结要留。

## 六 · 忍到最后一秒

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 54.6% ＋ 哭 63.0%

**骨架**｜他一路都稳住了，偏偏在最稳的那一下翻了车。

#### 节拍链

出事 → 他处理 → 他一直很稳 → 事情结束 → 独处／她出现 → 塌

#### 时间轴

塌的位置是这条的全部技术。塌得太早是脆弱，塌得太晚是麻木。最佳位置是「危险刚过去的那一分钟」。

| 塌的位置 | 效果 |
|---|---|
| 事情进行中 | 显得他坚持不下来，减分 |
| 事情刚结束，独处时 | 标准解 |
| 事情刚结束，她过来时 | 最优解 |
| 很久以后 | 需要额外的触发物 |

「她过来时」最优，因为它把塌的原因归给了她的到场：事情没打垮他，她一到，他就不用撑了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 撑住的表现 | 声音不抖 · 手不抖 · 事情一件件安排明白 · 外人看着跟没事人一样 |
| 撑不住的先兆 | 手开始抖，趁没人注意 · 得扶一下门框 · 说话慢半拍 |
| 塌的形态 | 蹲下去 · 顺着墙往下滑 · 话说到一半卡住 · 什么也没干，就愣着不动 |
| 她的动作 | 不问他怎么了 · 直接抱住 · 或者先啥也不干，坐到他旁边 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 出的什么事 | 外面出乱子 | 他自己家里、身体出问题 |
| 谁在场 | 就他俩 | 旁边还有人，他得硬扛更久 |
| 她的到场 | 赶上了 | 来晚了，他已经自己熬过去了，更难受 |
| 事后 | 他会说两句 | 他一个字都不提 |

「她晚了一步」这个拨法很狠：他自己撑过去了，说明下次他也会自己撑过去。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看见他站得笔直，手在抖 | 撑住的每一分钟 |
| 好的处理 | 她不夸他坚强，她只是在场 | 他塌的时候没有说话 |
| 写崩 | 写成她的英雄救美 | 写成他从头到尾很惨 |

不要夸他坚强。 夸了就等于要求他下次继续坚强。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 办完丧事／打完官司／进了屋才瘫坐下来 |
| 修仙 | 熬过天劫／她到的时候他刚断气 |
| 星际 | 指挥完撤退／门一关，背靠着墙滑下去 |

#### 写崩的三种方式

1. 让他中途崩。那前面撑那么久就全白费了。
2. 让她一路陪着。他得自己扛过绝大部分。
3. 让他事后细盘。塌了就塌了，没什么好解释的。

## 七 · 说了狠话

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 54.6% ＋ 道歉 49.0%

**骨架**｜他说了句自己都不信的话，屋里顿时静下来。

#### 节拍链

积压 → 触发 → 说出口 → 那一秒的空白 → 他想收回 → 收不回 → 后果

#### 时间轴

说出口之后的那三秒是这条的心脏。 那三秒里两个人都没动，都在等对方先反应。

写法：把那三秒里的环境音写出来。冰箱、钟、楼下的车、水龙头没关紧的滴答。声音越琐碎，安静越重。

#### 可用细节

| 类 | 内容 |
|---|---|
| 狠话的类型 | 「你根本不在乎」· 「那你去找她好了」· 「我算什么」· 「你走啊」 |
| 说出口的信号 | 声音突然大了 · 或者声音突然很轻（更狠） |
| 那三秒 | 环境音 · 两个人都没动 · 他的手还举着 |
| 想收回的动作 | 张了张嘴 · 往前迈了半步 · 又停住 |
| 她的反应 | 沉默 · 转身走 · 或者走过去抱住（最难写也最好） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 狠话真假 | 反话，他其实想要她留下 | 真心话，压了很久 |
| 她怎么接 | 走了 | 没走 |
| 他多久道歉 | 当场 | 三天后 |
| 修复 | 完全修复 | 留了痕（更真实） |

「留了痕」是成年人关系的真相。说出去的话可以被原谅，但不会被忘记。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 那三秒 | 她心里在掂量这话有几分真 | 他在琢磨她到底走不走 |
| 好的处理 | 她人没走，但也没马上答应 | 他认错，不找借口 |
| 写崩 | 写她动手／摔门走人 | 写他跪下来求她 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 顶撞了她／当着人说了不该说的／摔了她给的东西 |
| 修仙 | 说要断了契／剑指向她 |
| 星际 | 申请调离／在公开频道说了那句话 |

#### 写崩的三种方式

1. 狠话别放太绝。放出去收不回来，后面就没法写了。
2. 让他当场跪下认错。那三秒的沉默最值钱，别急着打破。
3. 一句话就和好？至少留一章的余波。

## 八 · 冷战

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 54.6%

**骨架**｜两个人住在一起，但谁都不先开口。

#### 节拍链

爆点 → 各自不开口 → 日常动作还在做 → 出现一件必须合作的小事 → 一句功能性的话 → 第二句

#### 时间轴

背景钟照常走，他照常做饭，她照常吃，日子照常过，唯独话停着。反差拖得越久，读者心里那根弦就绷得越紧。别数日子，数话。从零句，到一句「递一下酱油」，再到两句，这中间的距离就是温度回升的刻度。日常对话的密度，才是解冻的进度条。

#### 冷战的物理学

冷战的写法不在情绪在动线：

| 观察点 | 显示什么 |
|---|---|
| 谁先起床 | 谁在躲 |
| 饭是不是还做 | 关系有没有真断 |
| 两份饭是分开吃还是一起吃 | 冷的程度 |
| 谁睡沙发／谁睡里面 | 谁在赌气 |
| 灯谁关的 | 谁最后睡（谁在等） |
| 早上的水杯是不是还倒了两杯 | 习惯有没有断 |

最后一行是冷战戏最好用的一条：手还在做，人不肯说。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 沙发 ✓ · 被子 ✓（多出来那床）· 餐桌 ✓ · 两个水杯 · 玄关 ✓ 的拖鞋摆向 · 灯 ✓ |
| 破冰的契机 | 一件不干不行的小事，比如家里跳闸、他够不着、快递得签收 |
| 谁先开口 | 一般不是道歉，是句顶用的话，比如「盐放哪了」 |
| 和好的信号 | 第一句话之后，又接了一句 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时长 | 一晚 | 一周 |
| 谁在维持 | 他（她想和好） | 她更少见，也更有张力 |
| 破冰方式 | 事件推动 | 有人先低头 |
| 结果 | 和好 | 表面和好，实际有东西变了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 我不该先低头，可我又想先低头 | 她今天又倒了两杯水 |
| 好的处理 | 她光做不说 | 他看在了眼里，但还没想好怎么接 |
| 写崩 | 把她写成理直气壮 | 把他写成阴阳怪气 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 分房／他不去正房请安／她的赏赐照送但没有话 |
| 修仙 | 各自闭关／契约还在但传音不通 |
| 星际 | 排班错开／但他还是给她留了热食 |

#### 写崩的三种方式

1. 冷战里还留早饭、递外套，那才算数，真不管了反而没戏。
2. 俩人憋着不说话，说白了就是都怕伤着对方，互相较着劲。
3. 外人一掺和，那点劲儿就散了，关系也变味了，所以这架只能自己吵。

## 九 · 我是不是不够好

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 54.6%

**骨架**｜他把错全揽到自己身上，别人反倒不好开口了。

#### 节拍链

触发 → 他绕着问 → 没问出结果 → 他开始自我改造 → 突然变懂事 → 她某天发现他不黏了

#### 时间轴

他把自己删得不动声色，慢到她压根没察觉。等到她终于意识到，第一周他不再抢遥控器，第二周报备只剩几行字，第三周连黏人都没了。她越晚发现，他删掉的自己就越多。回头越难，陷得越深，这条的计时器是「她多久才发现」。

#### 为什么这条难处理

「你是不是不喜欢我了」可以被否认。「是不是我不够好」不能，因为否认它等于否认他的感受。

反驳没有用。她的正确应对是改变问题的框架：不回答「你够不够好」，而回答「我要的是什么」。

| 她的回答 | 效果 |
|---|---|
| 「你很好啊」 | 没用，太轻飘飘 |
| 「不是你的问题」 | 更糟，听着像认了你有毛病 |
| 「我最近确实忽略你了」 | 管用，认账就行 |
| 「我要的不是好，我要的是你」 | 最顶，但前面没铺垫说出来就假 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 触发 | 被拿来跟别人比之后 · 撒娇没得到回应之后 · 她连着加了几天班之后 |
| 他的问法 | 不会直说，绕着来：「你今天咋了」「我是不是有点太缠人了」 |
| 他的自我改造 | 不咋撒娇了 · 学着懂事 · 主动讲「你忙你的」，这反而出事 |
| 她的察觉 | 他突然不闹了，乖得不像他 |

「他突然变懂事了」是这个类型里最重的警报。 懂事是弱势方放弃索取的信号。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他问不问 | 问了 | 没问，自己闷头改 |
| 她察不察觉 | 当时就发现 | 过好久才觉出他不再撒娇了 |
| 她的回应 | 嘴上说 | 做出来，推掉饭局，早回一趟家 |
| 结果 | 和好 | 他再也不提了，最糟的收场，不少真夫妻就这么过下去的 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他这周一次都没黏过她 | 我是不是该少要一点 |
| 好的处理 | 她主动让他黏 | 他终于问出口 |
| 写崩 | 写成她一个劲劝他 | 写成他光顾着恨自己 |

「她主动要求他黏」是最漂亮的解法：把索取变成她的需求，他就不用愧疚了。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他开始守规矩守得过分／不再讨赏／请安分毫不差 |
| 修仙 | 他开始拼命修炼／不再来找她 |
| 星际 | 他把私人通讯频率调低了 |

#### 写崩的三种方式

1. 让她长篇安慰。安慰越长，越像在处理麻烦。
2. 让他自我厌弃到底。那是另一种病，不是这条。
3. 别忽略“变懂事”这个信号。这是全条最值得盯的地方。

## 十 · 她也会哭

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：哭 63.0%（女方向罕见）

**骨架**｜强势的一方崩了一回，整篇就崩了这么一次。

#### 为什么必须有这一条

如果她从头到尾都不变，那她就是个工具人，不是活人。而且他那边永远没有转机，那这段关系就成了死设定，哪还算得上关系。

一次就够。一次让整个关系从「照顾与被照顾」变成「互相支撑」。

#### 节拍链

她一直很稳 → 出事 → 她还是很稳 → 独处／他在 → 崩 → 他的反应 → 之后两人都不提

#### 时间轴

同 [六 · 忍到最后一秒](#六--忍到最后一秒)，但门槛更高：她要撑得比他久得多，崩得比他浅得多。

她的崩不需要嚎啕。一滴眼泪、一次呼吸乱掉、一句说到一半的话，就足够。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的破绽 | 手停在半空 · 转过身去 · 一句话说了两遍 · 眼角 ✓ 有一下 |
| 他的反应梯度 | 愣住 → 不知所措 → 走过去 → 抱住 → 什么也没说 |
| 角色反转 | 这回换他来照顾人，笨手笨脚的 |
| 事后 | 她第二天照常 · 他知道那件事发生过 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 起因 | 外面的事：工作、家里、出了事 | 因为他怕自己给不了他要的 |
| 他在不在 | 他撞见 | 她主动让他看见，关系特别铁才敢 |
| 他的处理 | 抱住 | 啥也不干，就坐旁边（更好） |
| 之后 | 提了 | 谁都不提，但俩人都知道不一样了 |

「她主动让他看见」是这条的最高形态：主动示弱是强势方能给出的最大让渡。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她撑不住了，他就在边上 | 头一回见她这样 |
| 内心 | 不能让他看见我这样／我怎么会这样 | 我该咋办，这事我没干过 |
| 好的处理 | 她没解释自己为啥哭 | 他手忙脚乱，但没躲开 |
| 写崩 | 她一下子变娇弱了 | 他借机往上爬 |

「趁机上位」是这条最大的雷。 她崩了不等于关系翻转。第二天她还是她。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 钗环摘了靠在榻边／折子批到一半搁下笔／他进来她连头都没抬 |
| 修仙 | 她那把剑头一回没握住／灵力晃了一下 |
| 星际 | 她在指挥席上愣了三秒／全场就他看见了 |

#### 写崩的三种方式

1. 写超过一次。 一次是深度，两次是人设动摇。
2. 让他趁机翻身。 见上。
3. 让她哭得很厉害。 她的崩要浅，浅才符合她。
