# 委屈与破防

> **分级** `T` ｜ 预警 无 ｜ 亚型 全谱系通用（分级见各条）
> 频次出自[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，统计范围是 2,894 部独立作品。文中的百分比都是编写时实测的。挖掘器扩充后，节拍族会有小幅变动，数字以 13-07 为准（用 `run.py mine` 重跑即可更新）
> 这一族收的是他忍着、憋着、躲起来哭、被忽略、被比较、说狠话、冷战这类场面，她哭的那一回也收在这里。破防要有分量，前面就得一直忍到最后一秒才破。

---

## 哭用多了读者就麻了

哭在这个类型里用得最多，也最容易写滥。

| 反应族 | 作品数 | 占比 |
|---|---:|---:|
| 拥抱 | 2,253 | 77.9% |
| 哭 | 2,243 | 77.5% |
| 委屈 | 2,067 | 71.4% |

写了哭的作品超过六成。同一部里男主要是哭上三次，到第三次读者已经没感觉了。

避免写滥的两个办法：

| 办法 | 做法 |
|---|---|
| 提高门槛 | 前面先把他能忍写足，后面一破才有落差 |
| 换形态 | 换成下表里哭以外的破防形态，不写哭 |

### 破防的七种形态，按烈度排

| 形态 | 表现 | 适合 |
|---|---|---|
| 一 沉默 | 该接话的时候不接 | 最省事，也最耐看 |
| 二 走开 | 起身去阳台／厨房／洗手间 | 得找个地方缓缓 |
| 三 手抖 | 拿东西时手不听使唤 | 身体比嘴先漏底 |
| 四 声音变了 | 说话时嗓子眼堵了一下 | 电话戏专用 |
| 五 红眼眶 | 眼泪硬憋回去 | 比哭出来更扎心 |
| 六 哭 | 正常哭 | 用多了读者就麻了 |
| 七 哭到失控 | 抽噎、说不出整话 | 一部作品用一次就够 |

五和六之间是分水岭。 憋回去的那一下，读者会替他哭。

## 一 · 哭着睡着

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：生病＋睡着 13.9%，做饭＋睡着 14.1%，归家＋睡着 13.2%

**骨架**｜他等她等到撑不住，哭着睡过去了。她进门只看到他在睡，没看到他哭。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 撑到某个具体时刻 |
| 2 | 压垮他的是一件很小的事，算不上大事 |
| 3 | 哭 |
| 4 | 哭到累 |
| 5 | 睡着 |
| 6 | 她回来，看见 |

第 2 拍最要紧。压垮他的必须是小事：微波炉停了、消息没回、灯泡闪了一下。大事会让读者觉得他应该哭，小事才让读者心疼。

#### 时间轴

从哭到睡着要花真实的时间，过程得留下痕迹：

| 记录物 | 显示什么 |
|---|---|
| 抽了几张纸巾，堆在哪里 | 哭了多久 |
| 手机屏幕从亮到暗到再亮 | 他中途看了几次 |
| 身上的姿势（越来越蜷） | 从坐到躺的过程 |
| 睡着的位置不是床 | 他本来是在等 |

最要紧的是最后一行。他睡在沙发上、地上或餐桌边，没睡到床上。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 沙发 ✓ · 被子 ✓（没盖）· 枕头 ✓（抱的是抱枕）· 手机 ✓（还攥在手里）· 餐桌 ✓ |
| 睡姿 | 蜷着 · 脸埋在臂弯 · 一只手搭在桌上 · 身上还穿着外套 ✓ |
| 哭过的痕迹 | 眼角 ✓ 有干痕 · 睫毛 ✓ 粘在一起 · 呼吸还一抽一抽的 · 鼻尖红 |
| 环境 | 灯 ✓ 还亮着 · 电视开着但没声 · 饭菜 ✓ 还在桌上 |
| 她的动作 | 站住 · 不敢出声 · 蹲下来看 · 手伸到一半又停住 |

写一句「呼吸还一抽一抽的」，她没看到的那段就交代了，不必另外叙述。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的处理 | 抱他回房，他没醒 | 她坐床边，等他睁眼 |
| 他醒后 | 装没事，当没哭过 | 直接扑过来 |
| 她说不说破 | 一个字不提 | 第二天开口问了 |
| 谁哭 | 他 | 她少见，铺垫要更足 |

「她坐床边，等他睁眼」比抱他回房好。她坐着等，他醒来那一下她就得面对。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 进入点 | 开门看见沙发上那一团 | 撑不住的那一下 |
| 情绪 | 疼都来不及疼 | 我不想让人看见 |
| 内心难点 | 要不要叫醒他 | 醒来发现她还在 |
| 好的处理 | 她先关电视，再蹲下来 | 他没显摆，也没藏 |
| 写崩 | 她当场崩了，怪自己 | 他等着她来发现 |

「他等着她来发现」最要不得。只要他有一丝表演成分，全条就毁了。 他要真的以为没人会看见。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 趴在桌上睡着了／炭盆早凉了／衣服也没换就躺下 |
| 修仙 | 想打坐却静不下心，靠着墙睡过去／灵力翻腾了一整夜 |
| 星际 | 在舷窗前睡着／终端上还留着没发出去的消息 |
| 末世 | 靠着门睡死过去，手里还攥着刀 |

换到星际，她能看到他写好了又没发出去的那句话。

#### 写崩的三种方式

1. 非得让大事来压垮他。为大事哭，谁看了都觉得理所应当，也就打动不了人。
2. 写成他醒着等她来发现。毛病跟上面一样。
3. 她一进门就喊他名字。那一刻只写安静，别的都不用写，这份安静比写他哭、他闹都重。

后接：[03-撒娇与讨哄 · 狠狠撒娇](03-撒娇与讨哄.md#一--狠狠撒娇) · [06-身体接触](06-身体接触.md)

#### 示例（本库自撰，可直接改写）

> 电视还开着。声音关了，画面一格一格地换，蓝光扫过他的侧脸。
> 他在沙发上蜷着，外套没脱，一只手压在身下，另一只手里还攥着手机，屏幕早黑了。
> 抱枕被他抱在怀里，边角那圈皱得厉害。
> 她把玄关的门轻轻带上，鞋没换。走近了才听见他呼吸的声音，一顿，一顿，像哭到最后忘了怎么停。
> 桌上的菜还盖着保鲜膜。她数了一下，四个盘子，一个都没动过。

## 二 · 憋着不说

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 71.4%

**骨架**｜他难受，她问了一句，他说没事。

#### 节拍链

他不对劲 → 她察觉 → 她问 → 他说没事 → 她再问／不再问 → 结果

#### 时间轴

憋得越久，后面破得越狠。 憋一晚上是撒娇，憋一个月是问题。

按她问了几次来分段写。她第一次问，他说没事。第二次问，他说真的没事。到第三次，她不问了。整段最疼的就落在她不再问的这里。

#### 可用细节

| 类 | 内容 |
|---|---|
| 不对劲的表现 | 话变少 · 玩手机 ✓ 的时间变长 · 睡觉背对着 · 吃得少 · 不撒娇了 |
| 她的察觉方式 | 他今天没蹭她 · 碗里剩了饭 · 他洗澡洗了很久 |
| 他的挡箭牌 | 「没事」「有点累」「工作上的事」 |
| 破口的时机 | 她不再追问之后 · 或者为一件不相干的小事突然炸了 |

「不撒娇了」在这一族里哪儿都能用来报警，前面 [03 卷](03-撒娇与讨哄.md) 也用过。一个平时黏人的人忽然不黏了，就说明出事了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他为什么憋 | 怕她烦 | 觉得说了也白说 |
| 她的应对 | 追着问 | 不问，就守着 |
| 破口方式 | 她逼出来的 | 他自己开口 |
| 内容 | 就那件事 | 说的是另一件，真正那件更沉 |

选「说的是另一件」这一端，依据是人刚开口时往往先拿次要的那件事来试探。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 难点 | 分不清是关心还是逼问 | 怕开口显得自己计较 |
| 好的处理 | 她说「不想说就不说，我陪着你」 | 他讲了，哪怕讲得难听 |
| 写崩 | 把她写得太冷 | 把他写得太作 |

「不想说就不说，我陪着你」好用，她没逼他，人也留在身边。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 站着不敢抬头／她问啥他都说“没事”／夜里她听见他翻来覆去 |
| 修仙 | 灵力乱了硬撑着不吭声／她伸手把脉他往后躲 |
| 星际 | 心率不对他自己把记录删了 |

#### 写崩的三种方式

1. 让他憋得毫无破绽。 破绽要让读者看见，她可以没看见。
2. 让她一问就破。 至少要三次。
3. 憋的内容太小。 憋一个月的事不能是「她忘了买他要的零食」。

#### 示例（本库自撰，可直接改写）

> 「没事。」
> 他说得很快，快到像是准备好的。手机还在手里，屏幕早暗了，他没有点亮。
> 「就是有点累。」
> 她没再问。厨房的水池里堆着碗，这三天都是他洗的，今天没洗。
> 睡觉的时候他背对着她，被子拉到肩膀。
> 她躺了很久，忽然想起来一件事：这三天他一次都没有蹭过她。

## 三 · 躲起来哭

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：哭 77.5%

**骨架**｜他死活不愿在她跟前哭，躲去了别的地方。她最后还是找到了他。

#### 节拍链

憋不住 → 找借口离席 → 挑一个有掩护声的地方 → 哭 → 洗脸 → 出来 → 两人都装作没事

#### 时间轴

他走开不到十分钟，可以当成「去洗手间」，不必理会。过了二十分钟，她会放下手里的活。到半小时还没回来，她就直接起身去找。找到的时间不同，疼的地方也不同。撞见他正哭到一半，最难受。他脸已经洗过、眼睛还红着，又是另一种难受。

#### 藏身处的语义

他挑哪里躲，能看出他跟这个家是什么关系：

| 地点 | 含义 |
|---|---|
| 洗手间 | 最常见。有水声当借口，还有锁 |
| 阳台 | 半公开，他其实没想藏得太严 |
| 车里 | 他自己的地方，而且能开走 |
| 楼梯间 | 他已经出了这个家 |
| 被子里 | 人在她旁边，只是在装睡 |
| 厨房 | 他还在忙活，拿干活压着事 |

表里厨房这一行最好用。边切菜边掉眼泪，比躲进厕所难写，写出来也更有力。

#### 可用细节

| 类 | 内容 |
|---|---|
| 掩护 | 水声 · 抽油烟机 ✓ · 电视 · 他说他去拿个东西 |
| 破绽 | 出来时眼睛 ✓ 是肿的 · 声音哑 · 洗了脸但眼角 ✓ 还红 · 在里面待太久了 |
| 她的处理 | 敲门 · 不敲，在门外坐下 · 什么都不做，等他出来 |
| 出来之后 | 两个人都装作没事 · 她递水／递纸 · 她只是把手放在他背上 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她找不找 | 立马出门找 | 明知道他在哪儿，就是不去 |
| 他知不知道被听见 | 没察觉 | 知道，反而压着声哭 |
| 出来后 | 谁都不提这事 | 她先开了口 |
| 谁躲 | 他躲 | 她躲，这版更少见，也更带劲 |

语料里很少见到「她躲起来哭，被他找到」这种情节。四爱女读者其实很需要「强势方也会崩」的写法，偏偏几乎没人写。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 隔着门听见的那个声音 | 咬着手背不让声音出来 |
| 难点 | 进去还是不进去 | 出去之后要怎么装 |
| 好的处理 | 她在门外坐下来，不说话 | 他洗了脸，但没洗掉 |
| 写崩 | 写成她破门而入 | 写成他哭给她听 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 廊下／柴房／井边／她的马车外 |
| 修仙 | 后山／剑冢／他的洞府最里那间 |
| 星际 | 货舱／观察窗前／逃生舱，他没打算走，但他坐进去了 |

#### 写崩的三种方式

1. 让她立刻破门而入。 门外那段等待别省。
2. 让他哭出很大声。要藏就藏得严严实实，破绽等他出来以后再露。
3. 哭完就和好。他出来后两人谁都不提，比当场把话说开更真实。

## 四 · 被忽略

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 71.4%

**骨架**｜他就在那儿站着，谁都没做错事，也谁都没回头看他一眼。

#### 节拍链

他有个很小的盼头 → 场合到了 → 盼头落空，没人存坏心 → 他接着做事 → 回家路上一句话没说

#### 时间轴

时间按次数算。落空一次根本不算什么。头一回他自己忍了，第二回笑笑就过去，第三回回家路上一个字也不说。前两回必须先埋好，第三回的沉默才有来处。

#### 为什么这条最难写也最真实

这一条没有反派，没有冲突，也没有事件，写的就是「什么都没发生」。

写法是给他一个具体的小盼头，再让它落空，落空得没有一点恶意。

| 微小的期待 | 落空的方式 |
|---|---|
| 她会问他今天怎么样 | 她问了别人 |
| 她会注意到他换了发型 | 她看到了，聊的却是别的 |
| 饭桌上她会问他要不要 | 她给每个人都盛了，偏偏跳过他，他碗里还剩着 |
| 出门时她会等他 | 她走在前面，没放慢脚步 |

哪一条都挑不出错，所以才难受。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 一桌子人 · 她和朋友聊天 · 她在忙工作 · 家庭聚会 |
| 他的位置 | 在场，但在边上 · 隔一个座位 · 站门口没进来 |
| 他做的事 | 玩手机 ✓（装的）· 给大伙倒水 · 收碗筷 · 一直忙活，忙活的人不用搭话 |
| 她的无心之举 | 介绍别人时漏了他 · 说「我们」时没带上他 |
| 破口 | 回家路上他一声不吭 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她有没有意识到 | 完全没察觉 | 事后才反应过来 |
| 场合 | 就俩人 | 有旁人在，更丢人 |
| 他的反应 | 硬扛着 | 待不住先走了 |
| 后续 | 她发现了，想法补救 | 这事先压着，过很久才翻出来 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 某一刻她发现他的座位空了 | 她说「我们」时，他数了数人头 |
| 好的处理 | 她想起来后不道歉，直接去做 | 他不怪谁，本来也没人做错 |
| 写崩 | 写成她故意冷落 | 写成他小肚鸡肠 |

**红线：不能有恶意。** 她只要是故意的，就成了冷暴力，那是完全不同的事。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 席上没给他留位子／赏赐发了一圈偏没他的／通名时他排最末 |
| 修仙 | 门中大比只点了大弟子／名录上找不到他名字 |
| 星际 | 任务简报里压根没提他这号人 |

古代版有制度撑着，位次、名录、称呼都是明摆着的排序，谁被忽略了，一眼就看得出。

#### 写崩的三种方式

1. 给她加上恶意。 见上。
2. 让他当场发火。 一发火就成了吵架戏。
3. 写得太长。 这条是钝刀子。点到就收，靠攒。

## 五 · 被比较

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 71.4% ＋ 吃醋 43.1%

**骨架**｜有人提起另一个人，说那人某方面比他强。

#### 节拍链

引子出现 → 他问了一句 → 问完就后悔 → 自己去查 → 更卖力 → 落下心结

#### 时间轴

时间按周走。他问那一句只要三秒，后悔却翻来覆去一整晚。接下来几周，他去查那个人，偷偷加练，再也不主动提，非得等下回又碰上相关的东西，才露出来。

#### 比较的三个来源

| 来源 | 杀伤力 | 说明 |
|---|---|---|
| 外人比 | 低 | 他可以不在乎 |
| 她无意中比 | 高 | 她只是在陈述事实 |
| 他自己比 | 最高 | 没有人说什么，他自己在比 |

第三种最好用。 从头到尾没人说过一句伤人的话。

#### 可用细节

| 类 | 内容 |
|---|---|
| 比较的维度 | 本事 · 家底 · 认识多久 · 她聊起那人时的口气 · 那人能陪她干点啥 |
| 触发物 | 一张老照片 ✓ · 她手机 ✓ 里没删的旧人 · 别人来一句「你还不如他」· 她随口说「他以前啊……」 |
| 他的反应 | 问了一嘴，问完就后悔 · 啥也没问，转头自己去查 · 更拼命对她好，这个最扎心 |
| 她的迟钝 | 她完全没想到那句话会伤人 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 对方是谁 | 前任 | 她的挚友／同僚，更难办 |
| 她的态度 | 她压根没当回事 | 她确实有一瞬间较真了 |
| 他的反应 | 直接说出口 | 憋在心里 |
| 结果 | 她当下就察觉，把话说开 | 成了他好多年解不开的疙瘩 |

「她确实有一瞬间比了」这一头更真实，也更难写。人都会比较，要看的是比完以后她选了谁。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 难点 | 她怎么说才不像在走过场 | 我先问就矮了一头 |
| 好的处理 | 她说的每一条都只对得上他一个人 | 他自己先想通了大半 |
| 写崩 | 成了她一口气掏一大堆心窝子 | 成了他把自己贬得一文不值 |

得具体。「我喜欢的是你」是句空话，「你煮的粥要放两次盐我才知道你在用心」才算理由。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 正君和侧君谁说了算／跟了她多年的旧人／小时候陪她念书的伴读 |
| 修仙 | 以前的道侣／她同门的师兄／双修的人排第几 |
| 星际 | 她上一个副手／俩人合不合拍的数据 |

女尊设定生来就把“比”写在明面上，位次本身就是排名，排名就是用来比的。见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。

#### 写崩的三种方式

1. 把那个人写成真反派。 那就成了三角恋。
2. 让她大段大段地表白。 一个具体细节顶三段情话。
3. 让他一次就释怀。 心结要留。

## 六 · 忍到最后一秒

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 71.4% ＋ 哭 77.5%

**骨架**｜他一路都稳住了，事情一过去，人才塌下来。

#### 节拍链

出事 → 他处理 → 一直很稳 → 事情过去 → 独处／她出现 → 塌下来

#### 时间轴

要紧的是在事情结束前后哪一刻塌。早了显得脆弱，晚了显得麻木，最好放在「危险刚过去的那一分钟」。

| 塌的位置 | 效果 |
|---|---|
| 事情进行中 | 显得他撑不住，扣分 |
| 事情刚结束，独处时 | 标准解 |
| 事情刚结束，她过来时 | 最好 |
| 很久以后 | 得另外找个引子 |

放在「事情刚结束，她过来时」最好：事情没把他压垮，是她一来，他才不用再撑。

#### 可用细节

| 类 | 内容 |
|---|---|
| 撑住的表现 | 声音不抖 · 手不抖 · 事情一件件安排明白 · 外人看着跟没事人一样 |
| 撑不住的先兆 | 手开始抖，趁没人注意 · 得扶一下门框 · 说话慢半拍 |
| 塌的形态 | 蹲下去 · 顺着墙往下滑 · 话说到一半卡住 · 什么也没干，就愣着不动 |
| 她的动作 | 不问他怎么了 · 直接抱住 · 或者先啥也不干，坐到他旁边 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 出的什么事 | 外面出乱子 | 他自己家里、身体出问题 |
| 谁在场 | 就他俩 | 旁边还有人，他得硬扛更久 |
| 她的到场 | 赶上了 | 晚了一步，他已经自己熬过来，更难受 |
| 事后 | 他会说两句 | 他一个字都不提 |

「来晚了」这一头，他这次自己撑过去了，下次也会一个人撑。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看到他站得笔直，手却在抖 | 撑着的每一分钟 |
| 好的处理 | 她不夸他坚强，只是陪在那儿 | 他塌下来时一句话没说 |
| 写崩 | 写成她的英雄救美 | 写成他从头到尾很惨 |

别夸他坚强。 一夸，就等于要他下回接着坚强。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 办完丧事／打完官司／进了屋才瘫坐下来 |
| 修仙 | 熬过天劫／她到的时候他刚缓过一口气 |
| 星际 | 指挥完撤退／门一关，背靠着墙滑下去 |

#### 写崩的三种方式

1. 让他半路就垮。 前面撑了那么久，全白搭。
2. 让她从头陪到尾。 绝大部分得他自己扛。
3. 让他事后一点点复盘。 塌了就是塌了，用不着解释。

## 七 · 说了狠话

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 71.4% ＋ 道歉 64.3%

**骨架**｜一句他自己都不信的话说出口，屋里一下子静了。

#### 节拍链

攒着 → 被点着 → 说出口 → 空白的那一秒 → 他想收回 → 收不回来 → 后果

#### 时间轴

那三秒，两人都没动，都等着对方先有反应。

写那三秒的环境音：冰箱，钟，楼下的车，没拧紧的水龙头在滴。声音越碎，屋里越显得静。

#### 可用细节

| 类 | 内容 |
|---|---|
| 狠话的类型 | 「你根本不在乎」· 「那你去找她好了」· 「我算什么」· 「你走啊」 |
| 说出口的信号 | 声音突然大了 · 或者声音突然很轻（更狠） |
| 那三秒 | 环境音 · 两个人都没动 · 他的手还举着 |
| 想收回的动作 | 张了张嘴 · 往前迈了半步 · 又停住 |
| 她的反应 | 沉默 · 转身走 · 或者走过去抱住（最难写也最好） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 狠话真假 | 说的是反话，他其实想让她留下 | 是真心话，憋了很久 |
| 她怎么接 | 走了 | 没走 |
| 他多久道歉 | 当场 | 三天后 |
| 修复 | 完全修复 | 留了痕（更真实） |

「留了痕」更真实。说出口的话能被原谅，却忘不掉。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 那三秒 | 她在掂量这话有几分是真的 | 他在想她到底会不会走 |
| 好的处理 | 她没走，也没立刻松口 | 他认错，不找理由 |
| 写崩 | 写她动手／摔门走人 | 写他跪下来求她 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 顶撞了她／当着人说了不该说的／摔了她给的东西 |
| 修仙 | 说要断了契／剑指向她 |
| 星际 | 申请调离／在公开频道说了那句话 |

#### 写崩的三种方式

1. 狠话说得太绝。 说出去收不回，后面就写不下去了。
2. 让他马上跪下认错。 那三秒的安静，别着急打破。
3. 一句话就和好了。 余波起码要留一章。

## 八 · 冷战

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 71.4%

**骨架**｜两人同住一个屋檐下，谁也不先开口。

#### 节拍链

爆发 → 各自闭嘴 → 日常的事照做 → 冒出一件非得两人一起干的小事 → 一句办事的话 → 第二句

#### 时间轴

他照样做饭，她照样吃，日子照样过。就是没话。这样拖得越久，读者心里越紧。别数过了几天，数说了几句：从一句没有，到一句「递一下酱油」，再到两句。

#### 冷战的物理学

写冷战，写动线：

| 观察点 | 显示什么 |
|---|---|
| 谁先起床 | 谁在躲 |
| 饭是不是还做 | 关系有没有真断 |
| 两份饭是分开吃还是一起吃 | 冷的程度 |
| 谁睡沙发／谁睡里面 | 谁在赌气 |
| 灯谁关的 | 谁最后睡（谁在等） |
| 早上的水杯是不是还倒了两杯 | 习惯有没有断 |

最后一行：手还在做，嘴不肯说。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 沙发 ✓ · 被子 ✓（多出来那床）· 餐桌 ✓ · 两个水杯 · 玄关 ✓ 的拖鞋摆向 · 灯 ✓ |
| 破冰的契机 | 非办不可的小事：家里跳闸了，他够不着，快递要签收 |
| 谁先开口 | 通常是一句办事的话，像「盐放哪了」 |
| 和好的信号 | 说完第一句，又跟了一句 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时长 | 一晚 | 一周 |
| 谁在维持 | 他（她想和好） | 她更少见，也更有张力 |
| 破冰方式 | 事件推动 | 有人先低头 |
| 结果 | 和好 | 表面和好，实际有东西变了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 不该是我先低头，可我又想低头 | 她今天还是倒了两杯水 |
| 好的处理 | 她只做不说 | 他都看见了，只是还没想好怎么接 |
| 写崩 | 把她写成理直气壮 | 把他写成阴阳怪气 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 分房／他不去正房请安／她的赏赐照送但没有话 |
| 修仙 | 各自闭关／契约还在但传音不通 |
| 星际 | 排班错开／但他还是给她留了热食 |

#### 写崩的三种方式

1. 写成互相伤害。 冷战是两人都怕伤着对方，所以憋着不开口。
2. 让一方彻底撒手不管。 还惦记着给对方留早饭、递外套，那才叫冷战。
3. 找第三个人来调解。 外人一插手，两人之间那股劲就散了，关系也跟着变味。

## 九 · 我是不是不够好

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 71.4%

**骨架**｜他把错全揽到自己头上，旁人反而没法开口。

#### 节拍链

触发 → 他拐着弯问 → 没问出个结果 → 开始改自己 → 一下子懂事了 → 某天她发觉他不黏人了

#### 时间轴

头一周他不抢遥控器了，第二周报备只剩几行字，第三周连黏人都不黏了，变得太慢，她一点没察觉。她发现得越晚，越难挽回。

#### 为什么这条难处理

「你是不是不喜欢我了」能否认。「是不是我不够好」没法否认，否认它就是在否认他的感受。

跟他争没用。她该回答的是「我要的是什么」，「你够不够好」就别答了。

| 她的回答 | 效果 |
|---|---|
| 「你很好啊」 | 没用，太轻飘飘 |
| 「不是你的问题」 | 更糟，听起来像承认他有毛病 |
| 「我最近确实忽略你了」 | 管用，认账就行 |
| 「我要的不是好，我要的是你」 | 最好，可前面不铺垫，说出来就假 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 触发 | 被拿来跟别人比之后 · 撒娇没得到回应之后 · 她连着加了几天班之后 |
| 他的问法 | 不会直说，绕着来：「你今天咋了」「我是不是有点太缠人了」 |
| 他的自我改造 | 不咋撒娇了 · 学着懂事 · 主动讲「你忙你的」，这反而出事 |
| 她的察觉 | 他突然不闹了，乖得不像他 |

他忽然懂事起来，就得留神了。弱势的一方懂事，说明他不再向她要什么了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他问不问 | 问了 | 没问，自己闷头改 |
| 她察不察觉 | 当时就发现 | 过好久才觉出他不再撒娇了 |
| 她的回应 | 嘴上说 | 做出来，推掉饭局，早回一趟家 |
| 结果 | 和好 | 他再也不提，收场最糟，现实里不少夫妻就这样过下去了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她察觉他这一周一次也没黏过她 | 我是不是该少要一些 |
| 好的处理 | 她主动让他黏 | 他终于问出口 |
| 写崩 | 写成她一个劲劝他 | 写成他光顾着恨自己 |

「她主动让他黏」，索取成了她的需要，他就不必愧疚。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他开始守规矩守得过分／不再讨赏／请安分毫不差 |
| 修仙 | 他开始拼命修炼／不再来找她 |
| 星际 | 他把私人通讯频率调低了 |

#### 写崩的三种方式

1. 让她安慰一大篇。 话越长，越像在应付一桩麻烦。
2. 让他厌弃自己到底。 那是另一种病了。
3. 没把“变懂事”当回事。 这个信号要一直盯着。

## 十 · 她也会哭

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：哭 77.5%（女方向罕见）

**骨架**｜强势的那一方崩了一次，全篇也就这一次。

#### 为什么必须有这一条

她要是从头到尾都不变，就只是个工具人。他那边也永远等不来转机，这段关系就成了一个写死的设定，算不上关系了。

一次足够。有这一次，两人的关系就从「照顾与被照顾」变成了「互相支撑」。

#### 节拍链

她一向稳 → 出事 → 她照样稳 → 独处／他在旁边 → 崩 → 他的反应 → 过后两人都不提

#### 时间轴

和 [六 · 忍到最后一秒](#六--忍到最后一秒) 一样，只是门槛更高：她得比他撑得久得多，崩也崩得浅得多。

她崩用不着嚎啕。一滴眼泪，一下乱了的呼吸，一句没说完的话，足够了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的破绽 | 手停在半空 · 转过身去 · 一句话说了两遍 · 眼角 ✓ 有一下 |
| 他的反应梯度 | 愣住 → 不知所措 → 走过去 → 抱住 → 什么也没说 |
| 角色反转 | 这次换成他照顾她，笨手笨脚 |
| 事后 | 她第二天照常 · 他知道那件事发生过 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 起因 | 外面的事：工作、家里、出了事 | 因为他：她怕自己给不了他要的 |
| 他在不在 | 被他撞见 | 她主动让他看，关系得特别铁才敢这样 |
| 他的处理 | 抱住 | 啥也不干，就坐旁边（更好） |
| 之后 | 提了 | 谁都不提，但俩人都知道不一样了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她撑不住了，他就在边上 | 头一回见她这样 |
| 内心 | 不能让他看到我这副样子／我怎么会这样 | 我该怎么办，从来没遇到过 |
| 好的处理 | 她没解释自己为啥哭 | 他手忙脚乱，但没躲开 |
| 写崩 | 她一下子变娇弱了 | 他借机往上爬 |

「他借机往上爬」最要不得。她崩了，关系也不会翻过来。第二天她照旧是她。

#### 换皮

| 世界 | 等价物 |
|---|---|

#### 写崩的三种方式

1. 写了不止一次。 写到第二次，她的人设就晃了。
2. 让他趁机翻身。 见上。
3. 让她哭得很凶。 她崩得要浅，浅才像她。
