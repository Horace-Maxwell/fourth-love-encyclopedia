## 这一族是这个类型的痛处

前面各卷写的是关系内部。这一卷写关系与世界的摩擦。

GB 遇到的摩擦跟别的类型不一样：它来自不被理解，而非不被祝福。别人很少反对，他们只是看不懂——看不懂她为什么要，也看不懂他为什么肯。

于是就有了这一族最典型的场面：没有人说反对，但空气变了。

## 一 · 被起哄

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：起哄 42.0%（起哄＋请安、起哄＋归家高频同现）

**骨架**｜一桌子人笑着说了一句，没有恶意，但他笑不出来。

#### 节拍链

那句玩笑 → 全桌笑 → 他慢半拍 → 她先看他 → 他自己接或她接 → 话题转走 → 车上谁先提

#### 时间轴

玩笑三秒，他的慢半拍一秒，车上的复盘十分钟。 现场的时间极短，全靠她那一眼的时机（在全桌笑声的第二秒看向他）；真正的处理在回程车上，谁先提起这个话头，隔了几个红绿灯才提，都是分寸的一部分。当晚不提，这事就沉底了，沉底的玩笑最伤。

#### 起哄的三种，杀伤力递增

| 类型 | 说法 | 杀伤 |
|---|---|---|
| 善意 | 「你俩什么时候的事」 | 低 |
| 揶揄 | 「以后你可得听话啊」 | 中——它把关系变成了笑料 |
| 刺 | 「你这日子过得舒服」 | 高——它在说他不劳而获 |

第二档最常见也最难处理。 说的人真的没有恶意，但那句话把他们私下的东西拿出来当了众人的谈资，而且用的是「怕老婆」那套现成的框架。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 聚会 ✓ · 婚礼 · 年夜饭 ✓ · 同事聚餐 |
| 那句话 | 通常是玩笑句式，且带着现成的俗语 |
| 全桌的反应 | 笑了 · 有人接了下一句 · 没人觉得不对 |
| 他 | 跟着笑 · 笑得慢了半拍 · 端起杯子 |
| 她 | 接了话 · 或者没接（都对，但含义不同） |
| 车上 | 谁先提这件事 |

「他笑得慢了半拍」是这条唯一需要写清楚的动作。

#### 她的四种接法

| 接法 | 效果 |
|---|---|
| 顺着玩笑接 | 保住了气氛，但等于认了那个框架 |
| 一句话怼回去 | 痛快，但会把小事变成场面 |
| 平静地纠正 | 「我们不是那样」——最好，也最难说得不尴尬 |
| 不接，转话题 | 安全，但他会觉得被丢下 |

没有完美选项。这就是这条的内容。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 起哄的人 | 亲近的（朋友） | 不熟的（同事家属） |
| 她的处理 | 接 | 不接 |
| 他的处理 | 跟着笑 | 自己回了一句 |
| 事后 | 两人都不提 | 有一个人提了 |

「他自己回了一句」在四爱男读者那里评价最高：不需要她保护，他自己有话说。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听见那句话时先看的是他 | 全桌都笑了，我也得笑 |
| 内心 | 我要不要说点什么 | 别让她替我说 |
| 好的处理 | 她先看他，把选择权给他 | 他自己接了，接得不错 |
| 写崩 | 写成她金句反杀全场 | 写成他忍气吞声还要安慰她 |

「她先看他」是这条最好的一个动作。 一秒钟的对视，把「谁来应对」这件事交给了他。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 席间的打趣／「主君好福气」／同僚调侃他的位份 |
| 修仙 | 同门笑他借了道侣的势／大比上的哄笑 |
| 星际 | 舰上传的段子／他被叫「舰长夫人」 |

#### 写崩的三种方式

1. 写成她一句话反杀全场。 爽，但把这条变成了爽文桥段。
2. 让他毫无反应。 慢半拍那一下必须有。
3. 让起哄的人是坏人。 他们没有恶意。这才是难处。

#### 示例（本库自撰，可直接改写）

> 「你以后可得听话啊。」
> 满桌都笑了。有人接了下一句，笑声又起来一层。
> 他也笑了，慢了半拍。手里的杯子端起来，喝了一口，其实杯子是空的。
> 她把筷子放下。桌上安静了半秒。
> 她先看的是他。
> 他迎上她的视线，很轻地摇了一下头。
> 于是她端起自己那杯，转向另一头：「李总，刚才那个方案——」

## 二 · 议论

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：议论 20.0%

**骨架**｜他们背后被说了。而听见的那个人决定了这场戏怎么走。

#### 节拍链

洗手间或电梯里的半句 → 听见的人站住 → 没进去，走开 → 装作没听见 → 当晚格外沉默 → 说或不说

#### 时间轴

听见只要半句话的时长，消化以天计。 站住、走开、装没事，现场三十秒；之后的沉默期越长，那半句在心里长得越大。说或不说的决定通常在第三天做出：憋过三天还没说的，多半就永远不说了，这条的钟提醒写作者：第三天是最后的说出口窗口。

#### 谁听见，决定一切

| 听见的人 | 走向 |
|---|---|
| 她听见 | 她会处理（对外），但她要不要告诉他 |
| 他听见 | 他多半不会说 |
| 两人一起听见 | 最尴尬也最有戏：都装作没听见 |
| 谁都没听见，但读者听见 | 最冷，且积累得最久 |

「两人一起听见然后都装作没听见」是这条的最佳配置。 一个共同的沉默，比任何一个人的反应都重。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 洗手间隔间 · 电梯 · 茶水间 · 群里被转发的截图 · 楼道 |
| 说法 | 「图什么呢」· 「男人嘛」· 「她也不容易」 |
| 最伤的一种 | 同情她。「她也挺可怜的」比骂他更伤 |
| 他们的反应 | 脚步没停 · 或者停了一下又走了 |
| 事后 | 那天晚上谁都没提 · 但有一个人格外沉默 |

「同情她」是这一族最狠的一刀。它不攻击任何人，却把他们的关系判定成了一场牺牲。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 内容 | 说他 | 说她（同情她） |
| 谁听见 | 一个人 | 两个人 |
| 处理 | 当场怼回去 | 走开 |
| 后果 | 过去了 | 这句话在很久以后被想起 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听见的是「她也挺可怜的」 | 我让她被人可怜了 |
| 内心 | 我不需要被同情 | 我是不是拖累她 |
| 好的处理 | 她告诉他了，并且说这不关他的事 | 他没有因此提出退出 |
| 写崩 | 写成她当场发飙 | 写成他提分手成全她 |

「他提分手成全她」是这个类型最俗也最常见的走法。 它把外部偏见变成了内部危机，且让他的退出显得高尚。用之前想清楚值不值。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 府里下人的闲话／同僚的暗讽／御史的折子 |
| 修仙 | 门内传言／说他是靠她 |
| 星际 | 内部通讯里的段子／人事档案上的批注 |

#### 写崩的三种方式

1. 让议论者是明确的反派。 匿名的、无意的议论更真实。
2. 当场解决。 这类东西解决不了，只能承受。
3. 用他提分手推动情节。 太便宜了。

## 三 · 偏见

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：偏见 27.0%

**骨架**｜有人当面说了。而这次不是玩笑。

#### 节拍链

当面那句「关心」→ 他沉默 → 想解释 → 不解释了 → 她比他先怒 → 很久以后他给出自己的答案

#### 时间轴

当面那句话十秒，他的答案迟到几年。 现场他沉默，她发怒，事件本身当天就结束了；这条的真正终点却在许多年后，某个场合他平静地给出自己的答案（不辩解，只陈述他的生活）。两点之间隔的那几年，就是偏见这种东西的自然消化周期，写短了就假了。

#### 偏见的具体形态

这条要写得有力，靠的是具体。抽象的「世俗眼光」没有杀伤力，具体的句子才有：

| 说法 | 攻击的是 |
|---|---|
| 「一个男的怎么什么都听老婆的」 | 他的性别表现 |
| 「你这样以后怎么在外面立足」 | 他的社会前途 |
| 「她那么强，你受得了？」 | 假定他在忍耐 |
| 「男人还是要有自己的事业」 | 用关心的语气 |
| 「你不觉得委屈？」（问他） | 假定这是牺牲 |
| 「你也该让让他」（对她说） | 要求她收敛 |

最后一行是对她的。 这一族不能只写他被攻击——要求强势方「让一让」，是同一套偏见的另一面。

#### 可用细节

| 类 | 内容 |
|---|---|
| 说话的人 | 长辈 · 老同学 · 领导 · 一个「为你好」的朋友 |
| 语气 | 关心的语气最难反驳 |
| 他的反应 | 第一反应是沉默 · 第二反应是想解释 · 第三反应是不解释了 |
| 她的反应 | 她比他更快生气 |
| 落点 | 他后来说了一句自己的答案 |

「他后来说了一句自己的答案」是这条必须有的收尾。 不是当场，可以是很久以后，但必须有。

#### 他的答案，四个版本

| 版本 | 说法 |
|---|---|
| 辩解型 | 「我们不是你想的那样」——最弱 |
| 反击型 | 「关你什么事」——痛快，但等于承认了框架 |
| 陈述型 | 「我挺好的」——简单，且不解释 |
| 重构型 | 「谁强谁上，这有什么问题」——最好 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 对象 | 针对他 | 针对她（要她收敛） |
| 说话人 | 恶意 | 善意（更难处理） |
| 他的应对 | 当场 | 很久以后 |
| 影响 | 无 | 他真的动摇了一阵 |

「他真的动摇了一阵」值得写。外部评价是会起作用的，写它起作用比写他刀枪不入真实。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 有人对她说「你也该让让他」 | 「你不觉得委屈？」 |
| 内心 | 凭什么是我让 | 我要怎么说才不像在辩解 |
| 好的处理 | 她没有为了别人的眼光收敛 | 他给出了自己的答案，不是她给的 |
| 写崩 | 写成她演讲式反驳 | 写成他需要她来救 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | **方向反转**：偏见变成「他一个男子怎可抛头露面」 |
| 修仙 | 说他修为配不上／靠道侣 |
| 星际 | 说他的基因等级／履历不匹配 |

古代女尊版的换皮改动最小。 制度反过来，偏见跟着反过来——他被要求守规矩、不要多话、不要出头。把现实中女性听过的话原样安在他身上，一句不用改写，这个类型的核心表达就完成了。见 [03-世界观设定/01-女尊世界构建全书](../03-世界观设定/01-女尊世界构建全书.md)。

#### 写崩的三种方式

1. 用抽象的「世俗眼光」。 要具体的句子。
2. 让她替他反驳到底。 他要有自己的答案。
3. 让他完全不受影响。 动摇一阵更真实。

## 四 · 公开

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：公开 33.0%

**骨架**｜他们决定不藏了。而「公开」这件事本身要有一个动作。

#### 节拍链

决定不藏 → 挑一个动作（朋友圈·介绍·牵手进场）→ 半秒安静 → 她继续原话题 → 消息炸开 → 他在自己的场子也做了一次

#### 时间轴

动作一秒，涟漪一周。 牵手进场或一条朋友圈，动作本身瞬间完成；之后按波次计：当场半秒安静是第一波，消息炸开是第二波（当晚），各路私聊求证是第三波（三天内），一周后归于平常。他在自己场子里补做的那一次，是涟漪的回声，隔几天做，刚好。

#### 公开的六种动作，从轻到重

| 动作 | 重量 |
|---|---|
| 不再解释「只是朋友」 | 最轻，被动 |
| 一起出现在一个必须解释的场合 | 中 |
| 她在群里回了一句 | 中 |
| 朋友圈 ✓ 发了一张 | 现代版的标准动作 |
| 她在正式场合介绍他的身份 | 重 |
| 他在自己的地盘介绍她 | **最重，也最少被写** |

最后一行值得专门写。公开这件事在这一类里往往由她来做（她的地位高、她的场合多），而他主动在自己的场子里把她介绍出去，是他为数不多的能主导的场面。

#### 可用细节

| 类 | 内容 |
|---|---|
| 决定的时刻 | 通常不是商量出来的，是某一刻自然做的 |
| 朋友圈 | 发什么 · 谁先发 · 可见范围 · 点赞的顺序 |
| 现场 | 介绍时用的词 · 全场半秒的安静 · 谁先开口打圆场 |
| 他的反应 | 站直了 · 或者他先伸的手 |
| 事后 | 消息炸了 · 有人当天就来问 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁公开的 | 她 | 他 |
| 方式 | 明说 | 一个动作（牵手走进去） |
| 场合 | 熟人圈 | 正式场合 |
| 反应 | 平静 | 出了状况 |
| 之前的状态 | 藏了很久 | 从来没藏过，只是没说 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她说出那个词的时候他抬了下头 | 她当着所有人说了 |
| 内心 | 该说了 | 我要不要先说 |
| 好的处理 | 她说完就继续原来的话题 | 他在自己的场合也做了一次 |
| 写崩 | 写成宣示主权的爽点 | 写成他被动接受安排 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 上族谱／过明路／带他赴宴／给名分 |
| 修仙 | 结契昭告／道侣录／宗门备案 |
| 星际 | 关系登记／权限绑定／公开频道通报 |

古代版的「上族谱」把这条推到顶格：不可撤销、有法律效力、且全族可见。

#### 写崩的三种方式

1. 写成宣示主权。 公开是承认不是占有。
2. 只让她公开。 他也要做一次。
3. 公开之后没有任何反应。 至少要有一个人来问。

## 五 · 他的朋友们

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：聚会 12.0% ＋ 起哄 42.0%

**骨架**｜她第一次进入他的社交圈。而他的朋友们有一套关于他的旧版本。

#### 节拍链

提前打了招呼 → 进场 → 绰号与旧事 → 他另一副样子 → 她融入或格格不入 → 散场 → 他问「他们还行吧」

#### 时间轴

一场局三小时，她的融入以「梗」为进度条。 前一小时她听不懂的旧梗占八成；中段有人给她解说（解说者就是这群人里最先接纳她的）；散场前她接上了一个梗，全桌大笑，接梗那一刻是及格线。他那句「他们还行吧」问在回家路上第五分钟，早了显得紧张，晚了显得不在乎。

#### 这条的价值

他在朋友面前是另一个人，而她第一次看见那个人。

| 她看见的 | 说明 |
|---|---|
| 他说话的音量变了 | 在她面前他更轻 |
| 他会开的玩笑 | 一种她没见过的粗糙 |
| 别人怎么叫他 | 一个绰号 |
| 他被提起的旧事 | 一个她不知道的他 |
| 他喝酒的量 | 在她面前他一直在收着 |

「原来他在别人面前是这样的」是这条的全部内容。 它既是惊喜也可能是不适。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 大排档 · KTV · 球场边 · 他老家的朋友 |
| 他的紧张 | 他一直在看她 · 怕朋友说错话 · 提前打过招呼 |
| 朋友的试探 | 「嫂子」还是直呼其名 · 敬酒时看谁 |
| 旧事 | 有人提起他以前的事（可能是前任、可能是他的落魄期） |
| 她的处理 | 她融不融进去 · 她要不要装得随和 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 朋友的态度 | 接纳 | 保留（觉得她太强） |
| 他的状态 | 放松 | 全程紧张 |
| 她的适应 | 融进去了 | 格格不入，且他看见了 |
| 结果 | 关系更近 | 他之后减少了这类聚会（不是好事） |

「他之后减少了这类聚会」要写出来。 为了关系而放弃自己的社交圈，是一个需要被注意的信号。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看见他在朋友面前的样子 | 我怕他们说错话 |
| 内心 | 这也是他 | 也怕她觉得我掉价 |
| 好的处理 | 她不评价他的朋友 | 他不因为她而抛弃旧交 |
| 写崩 | 写成她降尊纡贵地融入 | 写成他在两边都做人 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他的同窗／旧部／她第一次去他常去的地方 |
| 修仙 | 他的同门／散修朋友 |
| 星际 | 他原来的班组／老战友 |

#### 写崩的三种方式

1. 让她轻松征服全场。 格格不入更有内容。
2. 让朋友们全是配角布景。 至少一个人要有立场。
3. 忽略他的紧张。 他一直在两边看，那是这条的动力。

## 六 · 她的圈子

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：聚会 12.0% ＋ 职场 33.0%

**骨架**｜他被带进她的场合。而在这里，他是「谁谁谁的伴」。

#### 节拍链

他被带进场 → 「这是我先生」→ 名片只递给她 → 他站在她斜后方 → 只有他懂的那件事出现 → 回家路上

#### 时间轴

他的钟按「被忽略的次数」走。 名片绕过他三次、话题绕过他五次，他站在她斜后方数着，不恼；转折点是「只有他懂的那件事」出现的时刻（红酒、设备、一句诗），全场第一次转头看他。这个时刻一场只有一次，写作者要把它放在全场靠后的位置，前面的忽略才有偿还。

#### 与上一条的镜像

| | 他的圈子 | 她的圈子 |
|---|---|---|
| 她的位置 | 客人 | 主人 |
| 他的位置 | 主人 | **附属** |
| 需要适应的人 | 她 | 他 |
| 最难受的一点 | 她插不进话题 | 别人不问他名字 |

「别人不问他名字」是这条的核心细节。 一整晚被介绍为「这是我先生」而没有人问他做什么、叫什么。

这个体验在现实中女性极其熟悉，把它安在他身上，是这个类型最有力的表达。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 商务晚宴 · 行业活动 · 她的同学会 · 颁奖 |
| 他的处理 | 站在她斜后方半步 · 端着一杯没动过的酒 · 帮她拿包 |
| 被忽略的形态 | 名片只递给她 · 话题他插不上 · 有人问她「这是助理？」 |
| 她的动作 | 主动介绍他的职业 · 把话题引到他会的领域 |
| 他的时刻 | 全场有一件事只有他懂 |

「全场有一件事只有他懂」是这条最好的翻盘点，且它不需要她帮忙。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她介不介绍 | 认真介绍他的身份与职业 | 只说「我先生」 |
| 他的状态 | 自在 | 不自在但撑住 |
| 有没有翻盘 | 有（他的领域被用上） | 没有，就这么过去了 |
| 回家路上 | 她道歉 | 他说没事（是真没事还是假的） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现一整晚没人问过他的名字 | 名片都递给她了 |
| 内心 | 我该早点介绍他 | 我站在这儿是什么身份 |
| 好的处理 | 她介绍他的职业不只是身份 | 他没有靠自嘲化解 |
| 写崩 | 写成她全程护着他 | 写成他自卑到提前离场 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 随她赴宴／坐在她身后／无人问他名姓 |
| 修仙 | 她的师门大会／他被称作「那位道侣」 |
| 星际 | 舰队集会／他的名牌上写着她的编号 |

#### 写崩的三种方式

1. 让她全程护着。 他要自己撑一段。
2. 让他用自嘲化解。 自嘲是把伤口当笑话。
3. 省略「没人问名字」这个细节。 那是全条的信息。

## 七 · 当众叫错

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：改口 30.0% ＋ 起哄 42.0%

**骨架**｜私下的那个称呼，在人前脱口而出了。

#### 节拍链

场合正式 → 那个称呼脱口 → 半秒安静 → 他耳朵红了 → 她面不改色接着说 → 会后有人发了个表情 → 两人对视

#### 时间轴

事故半秒，处理三秒，回味一下午。 称呼脱口到全场安静是半秒；她面不改色接下去只用三秒，处理速度就是她的段位。之后的会议他一个字没听进去；散会后那个表情包抵达的时间（十分钟内）说明消息传播的速度，两人对视那一眼，把事故追认成了纪念日。

#### 为什么这条好用

它是一次意外的公开，成本极低但效果极强：一个词，全场安静半秒。

而且它不需要任何人做决定，就是说漏了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 会议室 · 一桌子人 · 电话开着免提 · 微信群发错了 |
| 那个称呼 | 只有他们两个用的那个 |
| 半秒 | 全场的反应 · 谁先笑 · 谁装作没听见 |
| 他 | 耳朵 ✓ 瞬间红 · 立刻改口 · 或者干脆不改 |
| 她 | 面不改色继续说 · 这是最好的处理 |
| 事后 | 有人在群里发了个表情 |

「她面不改色继续说」是这条的最优解。 她不慌。这件事就不算事故。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁叫错 | 他 | 她（更少见，也更有效果） |
| 场合正式度 | 私密场合 | 正式会议 |
| 他的处理 | 改口 | 将错就错 |
| 她的处理 | 装没听见 | 接了一句更过分的 |

「她接了一句更过分的」是喜剧向的最佳处理。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听见的那一秒继续念完了那句话 | 说出口才反应过来 |
| 内心 | 别慌，一慌就成事故了 | 完了 |
| 好的处理 | 她若无其事 | 他红着耳朵把会开完了 |
| 写崩 | 写成她当场调情 | 写成他窘到逃走 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 当堂唤了闺名／忘了称位份／逾矩之称 |
| 修仙 | 大殿上叫了道号之外的名字 |
| 星际 | 公开频道里用了私人称呼 |

古代版最重。称谓在礼制里是硬规矩，叫错就是逾矩，不止于尴尬。 见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。

#### 写崩的三种方式

1. 写成刻意的调情。 意外才有味道。
2. 让全场毫无反应。 半秒的安静必须有。
3. 让他逃走。 撑完那场会比逃走好。

## 八 · 朋友圈的分寸

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.0%

**骨架**｜发不发、发什么、谁在下面评论。三件事就是一整套关系的公示。

#### 节拍链

拍了或没拍 → 发不发 → 可见范围 → 谁点赞谁评论 → 对方的对应动作 → 某天一条消失了

#### 时间轴

发布只要十秒，时间轴上的经营以月计。 单条的钟很短：拍、犹豫、选可见范围、发；长线的钟才是正文，两个人的主页各自像一份公报，谁先出现在谁的照片角落、隔多久升级到正脸、某条突然消失的那天谁先发现。翻旧时间轴的那晚，是这条的隐藏场景。

#### 社交网的语法

| 观察点 | 读作 |
|---|---|
| 谁先发 | 谁更想被看见 |
| 发的是合影还是背影 | 公开程度 |
| 可见范围 | 分组可见 = 半公开 |
| 配文 | 越少越重 |
| 他评论了什么 | 他敢不敢在下面留言 |
| 她点不点赞 | 一个赞就是承认 |
| 置顶 | 最重的一档 |
| 删了 | 出事了 |

「删了」这一栏是这条最好用的爆点。 一条发过的动态消失了，比任何吵架都清楚。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓ · 屏幕 ✓ · 消息 ✓ · 照片 ✓ 的角落露出的东西（同一个杯子、同一条毯子） |
| 泄露 | 他发的风景照里有她的手 · 两人发了同一个地方 |
| 观察者 | 有人截图对比 · 有人在两边都点了赞 |
| 他的克制 | 想发，存了草稿，没发 |
| 她的处理 | 她直接发了，且没分组 |

「他存了草稿没发」与「她直接发了没分组」的对照，是这条最省字的关系说明。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先发 | 她 | 他 |
| 范围 | 全部可见 | 分组（会伤人） |
| 内容 | 合影 | 一个只有对方懂的细节 |
| 后续 | 置顶 | 三天后删了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他发过一条又删了 | 分组可见里有没有我 |
| 好的处理 | 她发的时候没有想太多 | 他没有为此质问 |
| 写崩 | 写成社交平台秀恩爱 | 写成他天天刷她主页 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 题在扇面上的诗／他的字被人认出／一方帕子的绣样 |
| 修仙 | 传音壁上的留言／宗门榜上的名字并列 |
| 星际 | 公开档案的关联栏／通讯录里的置顶 |

#### 写崩的三种方式

1. 写成秀恩爱。 克制的那一方才有戏。
2. 让删除没有后果。 删了要被发现。
3. 忽略分组可见。 那是现代版最狠的一刀。

## 九 · 被拍到

`T` ｜ 无预警 ｜ 现代都市（娱乐圈尤强）｜ 语料频次：社交网 33.0% ＋ 公开 33.0%

**骨架**｜关系被外力公开了，而不是他们自己决定的。

#### 节拍链

照片流出 → 配文与转发 → 四种外部叙事 → 两人商量口径（第一次为此吵）→ 回应或沉默 → 余波

#### 时间轴

外力公开没有预热期，节奏全是被动的。 照片流出到发酵只要几小时；两人商量口径的那一晚是唯一能自主的时间，为此吵的那一架也发生在这一晚（吵的是节奏被抢，不是关系本身）。回应或沉默的决定要在二十四小时内做出，过时舆论会替他们决定。

#### 与「公开」的根本区别

[四 · 公开](#四--公开) 是主动，这一条是被动。而被动公开有一个特殊的伤害：他们失去了对叙事的控制权。

外人不只知道了这件事，还给它配好了故事版本：

| 外部叙事 | 内容 |
|---|---|
| 「她包养他」 | 经济叙事 |
| 「他攀高枝」 | 上位叙事 |
| 「姐弟恋」 | 猎奇叙事 |
| 「她终于恋爱了」 | 把他当成她的附属品 |

每一种都不是真的，但每一种都比真相好传播。

#### 可用细节

| 类 | 内容 |
|---|---|
| 照片 ✓ | 拍到的是最不重要的一个瞬间（他给她拿包） |
| 传播 | 截图 · 转发 · 配文 · 越传越离谱 |
| 他们的处理 | 不回应 · 一起出现 · 发一条 |
| 影响 | 她的工作 · 他的工作（往往他受损更大） |
| 内部 | 两人第一次为「怎么说」吵起来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁受损 | 她 | 他 |
| 回应方式 | 沉默 | 正面回应 |
| 内部反应 | 一致 | 分歧（他想道歉式回应，她不肯） |
| 结果 | 过去了 | 留下了长期标签 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 评论区里那条「她图什么」 | 我成了她的负面新闻 |
| 内心 | 我不解释 | 我要不要退出一阵 |
| 好的处理 | 她把「怎么说」这件事跟他一起决定 | 他没有自作主张地消失 |
| 写崩 | 写成她动用资源压热搜 | 写成他为她好而离开 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 流言传到朝堂／御史参奏／坊间话本编排 |
| 修仙 | 传音壁上的匿名帖／同道议论 |
| 星际 | 内网泄露的影像／舰队八卦频道 |

#### 写崩的三种方式

1. 靠资源压下去。 那是解决问题不是写关系。
2. 让他主动消失成全她。 见 [二 · 议论](#二--议论) 的同一警告。
3. 忽略外部叙事的具体版本。 那四种说法才是杀伤力所在。

## 十 · 她替他挡

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：公开 33.0% ＋ 出面 14.0%

**骨架**｜她站到了他前面。而他要决定接不接受被保护。

#### 节拍链

有人发难 → 她的脚先动了半步 → 先看他一眼 → 他摇头或点头 → 挡或不挡 → 事后他说「下次让我自己来」→ 下一次她真的没动

#### 时间轴

脚动半步只要一瞬，那一眼的确认更短。 发难、她的半步、回头看他、他摇头或点头，全程三秒，但这三秒里完成了一次完整的授权谈判。「下次让我自己来」说在当晚；下一次真的到来隔了几个月，她没动的那次，站在原地的克制比上次的半步更难，时间轴的终点在这里。

#### 这条的两难

保护是好意，但保护同时是一种判断：我认为你自己应付不来。

| 她挡的方式 | 他的感受 |
|---|---|
| 一句话把事情按下去 | 感激 ＋ 一点无力 |
| 私下处理，不让他知道 | 如果被发现，会更难受 |
| 问他「要我出面吗」 | **最好**——把选择权给他 |
| 让他自己处理，在旁边看着 | 需要极强的信任 |

第三行是这条的最优解，也是这一族的通用解法：先问。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 有人当面刁难他 · 工作上被针对 · 家里人说了重话 |
| 她的动作 | 往前半步 · 打断 · 或者只是把手放在他背上 |
| 他的反应 | 松了一口气 · 或者身体先绷了一下 |
| 事后 | 他谢了她 · 但他也说了「下次让我自己来」 |
| 她的调整 | 下一次她真的没动 |

「下一次她真的没动」是这一族最难写也最重的一场。 忍住不保护，比保护难得多。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他要不要 | 需要 | 不需要但她挡了 |
| 她问不问 | 问了 | 直接上 |
| 他的表达 | 感激 | 说了「让我自己来」 |
| 下一次 | 她还是挡了 | 她忍住了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她的脚已经往前迈了半步 | 她又替我说了 |
| 内心 | 我忍不住 | 我知道她是好意 |
| 好的处理 | 她学会了先看他一眼 | 他说出了「让我自己来」 |
| 写崩 | 写成她强势护短的爽点 | 写成他不识好歹 |

「她学会了先看他一眼」与 [一 · 被起哄](#一--被起哄) 的「她先看他」是同一个动作。 这个动作是这一整卷的技术核心：把应对权交回给他。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她当堂发话／一句「他的事我担着」／挡下责罚 |
| 修仙 | 她出手拦下／以自身担保 |
| 星际 | 她动用职权／在记录上签了字 |

#### 写崩的三种方式

1. 写成护短爽点。 那会让他更小。
2. 让他一直感激。 至少有一次他要说「让我自己来」。
3. 忽略她的克制。 忍住不挡的那一次才是这条的顶点。
