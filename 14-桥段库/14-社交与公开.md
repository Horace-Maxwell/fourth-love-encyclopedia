## 这一族是这个类型的痛处

前面各卷写的是关系内部。这一卷写关系与世界的摩擦。

GB这类型的摩擦跟别的类型不一样：身边人压根看不懂，没人跳出来反对，也没人拦着，但也没人真明白——搞不懂她图什么，也想不通他凭什么愿意。

于是就有了这一族最典型的场面：没有人说反对，但空气变了。

## 一 · 被起哄

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：起哄 42.0%（起哄＋请安、起哄＋归家高频同现）

**骨架**｜一桌子人都笑了，没人当回事，可他实在笑不出来。

#### 节拍链

那句玩笑 → 全桌笑 → 他慢半拍 → 她先看他 → 他自己接或她接 → 话题转走 → 车上谁先提

#### 时间轴

玩笑就三秒，他反应慢，等明白过来又得一秒。车上复盘才是重头戏，得聊十分钟。现场那一下其实特别短，全看她抓的时机——全桌人笑到第二秒，她转头看他一眼。真正麻烦的是回程路上，谁先开口提这事，过了几个红绿灯才提，这些全是讲究。要是当晚谁都不提，这事就烂在肚子里了。烂掉的玩笑最伤人。

#### 起哄的三种，杀伤力递增

| 类型 | 说法 | 杀伤 |
|---|---|---|
| 善意 | 「你俩什么时候的事」 | 低 |
| 揶揄 | 「以后你可得听话啊」 | 中——它把关系变成了笑料 |
| 刺 | 「你这日子过得舒服」 | 高——它在说他不劳而获 |

第二档最常见，也最麻烦。说的人真没恶意，但话一出口，等于把人家两口子关起门来的事，拎到大伙儿面前当笑话讲，还顺手套了个「怕老婆」的旧帽子。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 聚会 ✓ · 婚礼 · 年夜饭 ✓ · 同事聚餐 |
| 那句话 | 一般是开玩笑说的，还带句现成的俗话 |
| 全桌的反应 | 笑了 · 有人接了下茬 · 没人觉得不对劲 |
| 他 | 跟着笑 · 笑慢了一拍 · 端起杯子 |
| 她 | 接话了 · 或者没接（都行，但意思不一样） |
| 车上 | 谁先提起这事 |

「他笑得慢了半拍」是这条唯一需要写清楚的动作。

#### 她的四种接法

| 接法 | 效果 |
|---|---|
| 顺着玩笑接 | 气氛没坏，但等于认了那个说法 |
| 一句话怼回去 | 解气，但小事容易闹大 |
| 平静地纠正 | 「我们不是那样」——最好，也最难开口 |
| 不接，转话题 | 安全，但他会觉得你不想理他 |

没有完美选项。这就是这条的内容。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 起哄的人 | 亲近的（朋友） | 不熟的（同事家属） |
| 她的处理 | 接 | 不接 |
| 他的处理 | 跟着笑 | 自己回了一句 |
| 事后 | 两人都不提 | 有一个人提了 |

「他自己回了一句」在四爱男读者那里评价最高：不需要她保护，他自己有话说。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听见那句话，先看他 | 全桌都笑了，我也跟着笑 |
| 内心 | 我该不该接话 | 别让她替我开口 |
| 好的处理 | 她先看他，让他自己选 | 他自己接了，接得挺顺 |
| 写崩 | 写成她甩金句把场子压住 | 写成他憋着委屈还得哄她 |

「她先看他」是这条最好的一个动作。 一秒钟的对视，把「谁来应对」这件事交给了他。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 酒桌上拿他逗乐／「主君好福气」／同僚拿他的位份开涮 |
| 修仙 | 同门笑他靠道侣撑腰／大比时台下起哄 |
| 星际 | 舰上流传的闲话／有人喊他「舰长夫人」 |

#### 写崩的三种方式

1. 写她一句话把全场镇住。爽是爽，但这就变成爽文套路了。
2. 让他一点反应都没有。必须得慢半拍，那个愣神不能少。
3. 把起哄的人写成坏人。其实他们没恶意，难就难在这。

#### 示例（本库自撰，可直接改写）

> 「你以后可得听话啊。」
> 满桌都笑了。有人接了下一句，笑声又起来一层。
> 他也笑了，慢了半拍。手里的杯子端起来，喝了一口，其实杯子是空的。
> 她把筷子放下。桌上安静了半秒。
> 她先看的是他。
> 他迎上她的视线，很轻地摇了一下头。
> 于是她端起自己那杯，转向另一头：「李总，刚才那个方案——」

## 二 · 议论

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：议论 20.0%

**骨架**｜他们背后被人嚼舌头了。可偏偏让听见的那个人，拿定了这出戏怎么唱。

#### 节拍链

洗手间或电梯里的半句 → 听见的人站住 → 没进去，走开 → 装作没听见 → 当晚格外沉默 → 说或不说

#### 时间轴

听见半句话，当时没反应，后面越想越重。站住、走开、装没事，现场就三十秒；但之后沉默越久，那半句在心里越长越大。要不要说，基本第三天定：憋过三天还没开口的，多半就永远咽下去了。这条提醒你：第三天是最后能说出口的窗口。

#### 谁听见，决定一切

| 听见的人 | 走向 |
|---|---|
| 她听见 | 她会自己处理（对外），但要不要告诉他，她得想想 |
| 他听见 | 他多半装不知道 |
| 两人一起听见 | 最尴尬也最有戏：都假装没听见 |
| 谁都没听见，但读者听见 | 最冷，而且攒得最久 |

「两人一起听见然后都装作没听见」是这条的最佳配置。 一个共同的沉默，比任何一个人的反应都重。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 洗手间隔间 · 电梯 · 茶水间 · 群里被转发的截图 · 楼道 |
| 说法 | 「图啥呢」· 「男人就这样」· 「她也不容易」 |
| 最伤的一种 | 同情她。「她也挺可怜的」比骂他更扎心 |
| 他们的反应 | 脚步没停 · 或者顿了一下又走了 |
| 事后 | 那晚谁都没提 · 但有一个人特别沉默 |

「同情她」是这一族最狠的一刀。它不攻击任何人，却把他们的关系判定成了一场牺牲。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 内容 | 说他 | 说她（同情她） |
| 谁听见 | 一个人 | 两个人 |
| 处理 | 当场怼回去 | 走开 |
| 后果 | 过去了 | 这句话在很久以后被想起 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听完就一句「她也挺可怜的」 | 我让她被人可怜了 |
| 内心 | 我不需要人可怜 | 我是不是拖累她了 |
| 好的处理 | 她直接跟他说了，还说这事跟他没关系 | 他没因为这个就说要散 |
| 写崩 | 写成她当场翻脸 | 写成他提分手，说是为她好 |

「他提分手成全她」是这个类型最俗也最常见的走法。 它把外部偏见变成了内部危机，且让他的退出显得高尚。用之前想清楚值不值。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 府里下人的闲话／同僚的暗讽／御史的折子 |
| 修仙 | 门内传言／说他是靠她 |
| 星际 | 内部通讯里的段子／人事档案上的批注 |

#### 写崩的三种方式

1. 让议论者是明确的反派。 匿名的、无意的议论更真实。
2. 当场解决。 这类东西解决不了，只能承受。
3. 用他提分手推动情节。 太便宜了。

## 三 · 偏见

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：偏见 27.0%

**骨架**｜有人当面说了。而这次不是玩笑。

#### 节拍链

当面那句「关心」→ 他沉默 → 想解释 → 不解释了 → 她比他先怒 → 很久以后他给出自己的答案

#### 时间轴

当面那句话就十秒，他当时没接住。她火了，他沉默了，当天这事就算翻篇了。可这条线的真正结尾，是几年后某个场合，他随口把自己的答案说了出来——不辩解，就是陈述自己这些年怎么过的。中间隔的那几年，就是偏见这东西自己烂掉的时间。你写短了，读者一眼就看出来是假的。

#### 偏见的具体形态

这条要写得有力，靠的是具体。抽象的「世俗眼光」没有杀伤力，具体的句子才有：

| 说法 | 攻击的是 |
|---|---|
| 「一个男的怎么什么都听老婆的」 | 他的性别表现 |
| 「你这样以后怎么在外面立足」 | 他的社会前途 |
| 「她那么强，你受得了？」 | 假定他在忍耐 |
| 「男人还是要有自己的事业」 | 用关心的语气 |
| 「你不觉得委屈？」（问他） | 假定这是牺牲 |
| 「你也该让让他」（对她说） | 要求她收敛 |

最后一行是对她的。 这一族不能只写他被攻击——要求强势方「让一让」，是同一套偏见的另一面。

#### 可用细节

| 类 | 内容 |
|---|---|
| 说话的人 | 长辈 · 老同学 · 领导 · 一个「为你好」的朋友 |
| 语气 | 关心的口气最难顶回去 |
| 他的反应 | 先不说话 · 接着想解释 · 最后懒得说了 |
| 她的反应 | 她比他先炸 |
| 落点 | 他后来自己给了个说法 |

「他后来说了一句自己的答案」是这条必须有的收尾。 不是当场，可以是很久以后，但必须有。

#### 他的答案，四个版本

| 版本 | 说法 |
|---|---|
| 辩解型 | 「我们不是你想的那样」——最没劲 |
| 反击型 | 「关你什么事」——解气，但等于认了对方的题 |
| 陈述型 | 「我挺好的」——简单，也不多解释 |
| 重构型 | 「谁行谁上，这不挺正常」——最漂亮 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 对象 | 针对他 | 针对她（要她收敛） |
| 说话人 | 恶意 | 善意（更难处理） |
| 他的应对 | 当场 | 很久以后 |
| 影响 | 无 | 他真的动摇了一阵 |

「他真的动摇了一阵」值得写。外部评价是会起作用的，写它起作用比写他刀枪不入真实。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 有人对她说「你也该让让他」 | 「你不觉得委屈？」 |
| 内心 | 凭什么是我让 | 我要怎么说才不像在辩解 |
| 好的处理 | 她没管别人怎么看，该怎么着还怎么着 | 他给了自己的答案，不是她塞给他的 |
| 写崩 | 写成她当众讲大道理 | 写成他离了她就不行 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | **方向反转**：偏见变成「他一个男子怎可抛头露面」 |
| 修仙 | 说他修为配不上／靠道侣 |
| 星际 | 说他的基因等级／履历不匹配 |

古代女尊文最省事的做法就是换皮。制度翻过来，偏见也跟着翻过来——他得守规矩、少说话、别冒尖。现实里女生听过的那些话，原封不动安到他身上就行，一个字都不用改，这类型的核心表达就出来了。见 [03-世界观设定/01-女尊世界构建全书](../03-世界观设定/01-女尊世界构建全书.md)。

#### 写崩的三种方式

1. 用抽象的「世俗眼光」。 要具体的句子。
2. 让她替他反驳到底。 他要有自己的答案。
3. 让他完全不受影响。 动摇一阵更真实。

## 四 · 公开

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：公开 33.0%

**骨架**｜他们决定不装了。公开这事，得有个具体的动作。

#### 节拍链

决定不藏 → 挑一个动作（朋友圈·介绍·牵手进场）→ 半秒安静 → 她继续原话题 → 消息炸开 → 他在自己的场子也做了一次

#### 时间轴

动作一秒，涟漪一周。牵手进场或发一条朋友圈，动作本身一眨眼就完了；可后面是按波次来的：当场那半秒安静是第一波，消息炸开是第二波（当晚），各路私聊来问是第三波（三天内），一周后也就没人提了。他在自己场子里补做的那一次，是涟漪的回声，隔几天做，刚好。

#### 公开的六种动作，从轻到重

| 动作 | 重量 |
|---|---|
| 不再解释「只是朋友」 | 最轻，被动 |
| 一起出现在一个必须解释的场合 | 中 |
| 她在群里回了一句 | 中 |
| 朋友圈 ✓ 发了一张 | 现代版的标准动作 |
| 她在正式场合介绍他的身份 | 重 |
| 他在自己的地盘介绍她 | **最重，也最少被写** |

最后这一行值得单独拿出来说。公开关系这种事，在这类文里基本都是她来干，毕竟她地位高、场子多、说一句话顶十句。但他主动在自己这边把她介绍出去，这就不一样了，这是他难得能自己说了算的时刻。

#### 可用细节

| 类 | 内容 |
|---|---|
| 决定的时刻 | 一般到那个点自己就定了 |
| 朋友圈 | 发啥 · 谁先发 · 给谁看 · 点赞先后 |
| 现场 | 介绍时咋说的 · 全场静了半秒 · 谁先开口圆场 |
| 他的反应 | 站直了 · 要不他先伸手 |
| 事后 | 消息炸了 · 当天就有人来问 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁公开的 | 她 | 他 |
| 方式 | 直接说 | 用行动（牵着手走进去） |
| 场合 | 熟人面前 | 正式场合 |
| 反应 | 没啥反应 | 出了岔子 |
| 之前的状态 | 瞒了挺久 | 一直没瞒，就是没提 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她说出那个词的时候他抬了下头 | 她当着所有人说了 |
| 内心 | 该说了 | 我要不要先说 |
| 好的处理 | 她说完就接着聊别的 | 他在自己那边也来了一回 |
| 写崩 | 写成她当众立威的爽点 | 写成他认命听安排 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 上族谱／过明路／带他赴宴／给名分 |
| 修仙 | 结契昭告／道侣录／宗门备案 |
| 星际 | 关系登记／权限绑定／公开频道通报 |

古代版的「上族谱」把这条推到顶格：不可撤销、有法律效力、且全族可见。

#### 写崩的三种方式

1. 写成宣示主权。 公开是承认，不是占有。
2. 只让她公开。 他也得来一次。
3. 公开之后没人吭声。 至少得有一个人来问一句。

## 五 · 他的朋友们

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：聚会 12.0% ＋ 起哄 42.0%

**骨架**｜她头一回见他那帮朋友，结果人家嘴里聊的他，跟她认识的根本不是一个人。

#### 节拍链

提前打了招呼 → 进场 → 绰号与旧事 → 他另一副样子 → 她融入或格格不入 → 散场 → 他问「他们还行吧」

#### 时间轴

一场局三个小时，她融没融进去，就看接梗接得怎么样。头一个小时，桌上聊的旧梗她八成听不懂；中间有人开始给她解释——解释的那个人，就是这圈人里第一个愿意接纳她的；快散场的时候，她总算接上一个梗，全桌都笑了，能接上梗，才算及格。他一直到回家路上第五分钟才问那句「他们还行吧」，问早了显得他紧张，问晚了又显得他根本不在乎。

#### 这条的价值

他在朋友面前是另一个人，而她第一次看见那个人。

| 她看见的 | 说明 |
|---|---|
| 他说话的音量变了 | 在她面前会放轻 |
| 他会开的玩笑 | 带点她没见过的野 |
| 别人怎么叫他 | 有个绰号 |
| 他被提起的旧事 | 她不知道的那一面 |
| 他喝酒的量 | 在她面前一直留着量 |

「原来他在别人面前是这样的」是这条的全部内容。 它既是惊喜也可能是不适。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 大排档 · KTV · 球场边 · 他老家的朋友 |
| 他的紧张 | 他老看她 · 怕朋友说漏嘴 · 提前打过招呼 |
| 朋友的试探 | 叫「嫂子」还是直接喊名字 · 敬酒时先看谁 |
| 旧事 | 有人提起他以前的事（可能是前任、可能是他落魄那阵） |
| 她的处理 | 她能不能接上话 · 要不要装得随和点 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 朋友的态度 | 接纳 | 保留（嫌她太强） |
| 他的状态 | 放松 | 一直绷着 |
| 她的适应 | 混熟了 | 融不进去，他还全看在眼里 |
| 结果 | 关系更近 | 他后来不太组这种局了（不是好苗头） |

「他之后减少了这类聚会」要写出来。 为了关系而放弃自己的社交圈，是一个需要被注意的信号。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看见他在朋友面前的样子 | 我怕他们说错话 |
| 内心 | 这也是他 | 也怕她觉得我掉价 |
| 好的处理 | 她不评价他的朋友 | 他不因为她而抛弃旧交 |
| 写崩 | 写成她降尊纡贵地融入 | 写成他在两边都做人 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他的同窗／旧部／她第一次去他常去的地方 |
| 修仙 | 他的同门／散修朋友 |
| 星际 | 他原来的班组／老战友 |

#### 写崩的三种方式

1. 让她轻松赢下全场。 但格格不入的人，戏反而更足。
2. 让朋友全变成背景板。 至少得有一个人站出来唱反调。
3. 别管他紧不紧张。 他一直在两边来回看，这才是这条线的劲头。

## 六 · 她的圈子

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：聚会 12.0% ＋ 职场 33.0%

**骨架**｜他进了她的场子，在这儿，他就是“谁谁谁带的伴儿”。

#### 节拍链

他被带进场 → 「这是我先生」→ 名片只递给她 → 他站在她斜后方 → 只有他懂的那件事出现 → 回家路上

#### 时间轴

他的钟只按「被忽略的次数」走。名片绕过他三次，话题绕过他五次，他站在她斜后方数着，也不恼。真正的转折点，是「只有他懂的那件事」冒出来的那一刻——可能是红酒、设备，或者一句诗。全场第一次有人转头看他。这个时刻，一场里只能有一次，写的时候得把它摁在靠后的位置，前面那些忽略，才算没白写。

#### 与上一条的镜像

| | 他的圈子 | 她的圈子 |
|---|---|---|
| 她的位置 | 客人 | 主人 |
| 他的位置 | 主人 | **附属** |
| 需要适应的人 | 她 | 他 |
| 最难受的一点 | 她插不进话题 | 别人不问他名字 |

「别人不问他名字」是这条的核心细节。 一整晚被介绍为「这是我先生」而没有人问他做什么、叫什么。

这个体验在现实中女性极其熟悉，把它安在他身上，是这个类型最有力的表达。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 商务晚宴 · 行业活动 · 她的同学会 · 颁奖 |
| 他的处理 | 站她斜后方半步 · 端杯酒没喝过 · 帮她拎包 |
| 被忽略的形态 | 名片只递给她 · 他插不上话 · 有人问「这是助理？」 |
| 她的动作 | 主动说他干啥的 · 把话头往他懂的地方带 |
| 他的时刻 | 全场就他一个人懂那事 |

「全场有一件事只有他懂」是这条最好的翻盘点，且它不需要她帮忙。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她介不介绍 | 正经说他是干嘛的 | 就一句「我先生」 |
| 他的状态 | 待着舒服 | 别扭但硬扛 |
| 有没有翻盘 | 有（他那行派上用场） | 没有，这事就翻篇了 |
| 回家路上 | 她先认错 | 他说没事（真没事还是装的） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现一整晚没人问过他的名字 | 名片都递给她了 |
| 内心 | 我该早点介绍他 | 我站在这儿算怎么回事 |
| 好的处理 | 她介绍他时说的是他做的事，不是他挂的头衔 | 他没靠自嘲把这事糊弄过去 |
| 写崩 | 写成她从头到尾护着他 | 写成他觉得自己配不上，先走了 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 随她赴宴／坐在她身后／无人问他名姓 |
| 修仙 | 她的师门大会／他被称作「那位道侣」 |
| 星际 | 舰队集会／他的名牌上写着她的编号 |

#### 写崩的三种方式

1. 让她一路护着。他自己得硬撑一段。
2. 让他拿自嘲混过去。自嘲就是把伤口当段子讲。
3. 别写「没人问名字」那茬。那才是整条的关键。

## 七 · 当众叫错

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：改口 30.0% ＋ 起哄 42.0%

**骨架**｜私下叫的那个称呼，当着人面直接喊出来了。

#### 节拍链

场合正式 → 那个称呼脱口 → 半秒安静 → 他耳朵红了 → 她面不改色接着说 → 会后有人发了个表情 → 两人对视

#### 时间轴

事故半秒，处理三秒，回味一下午。称呼一出口全场安静，那半秒就是她的反应时间；她面不改色接下去，只用三秒，处理速度就是她的段位。之后的会议他一个字没听进去；散会后那个表情包十分钟内就传到了，消息跑得比会还快。两人对视那一眼，事故直接变成了纪念日。

#### 为什么这条好用

它是一次意外的公开，成本极低但效果极强：一个词，全场安静半秒。

而且它不需要任何人做决定，就是说漏了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 会议室 · 一桌子人 · 电话开着免提 · 微信群发错了 |
| 那个称呼 | 只有他俩才叫的那个 |
| 半秒 | 全场啥反应 · 谁先笑 · 谁装没听见 |
| 他 | 耳朵 ✓ 立马红 · 赶紧改口 · 要不就不改 |
| 她 | 脸不红心不跳接着聊 · 这么办最稳 |
| 事后 | 群里有人甩了个表情包 |

「她面不改色继续说」是这条的最优解。 她不慌。这件事就不算事故。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁叫错 | 他 | 她（更少见，也更有效果） |
| 场合正式度 | 私密场合 | 正式会议 |
| 他的处理 | 改口 | 将错就错 |
| 她的处理 | 装没听见 | 接了一句更过分的 |

「她接了一句更过分的」是喜剧向的最佳处理。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听见的那一秒还是把话念完了 | 说出口才反应过来 |
| 内心 | 别慌，一慌就出事了 | 完了 |
| 好的处理 | 她装没事人一样 | 他红着耳朵把会开完了 |
| 写崩 | 写成她当场撩人 | 写成他窘到跑掉 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 当堂唤了闺名／忘了称位份／逾矩之称 |
| 修仙 | 大殿上叫了道号之外的名字 |
| 星际 | 公开频道里用了私人称呼 |

古代版最重。称谓在礼制里是死规矩，叫错就是逾矩，不光是尴尬的事。 见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。

#### 写崩的三种方式

1. 写成刻意的调情。 意外才有味道。
2. 让全场毫无反应。 半秒的安静必须有。
3. 让他逃走。 撑完那场会比逃走好。

## 八 · 朋友圈的分寸

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.0%

**骨架**｜发不发、发什么、谁在底下评论，这三件事就是一段关系的全部底牌。

#### 节拍链

拍了或没拍 → 发不发 → 可见范围 → 谁点赞谁评论 → 对方的对应动作 → 某天一条消失了

#### 时间轴

发布只要十秒，但时间轴上的经营是按月算的。单条的钟很短：拍、犹豫、选可见范围、发；长线的钟才是正文，两个人的主页各自像一份公报，谁先出现在谁的照片角落、隔多久升级到正脸、某条突然消失的那天谁先发现。翻旧时间轴的那晚，才是这条的隐藏场景。

#### 社交网的语法

| 观察点 | 读作 |
|---|---|
| 谁先发 | 谁更想露脸 |
| 发的是合影还是背影 | 公开到啥程度 |
| 可见范围 | 分组可见 = 半公开 |
| 配文 | 字越少事越大 |
| 他评论了什么 | 敢不敢在底下冒头 |
| 她点不点赞 | 点一下就是认了 |
| 置顶 | 最顶格的一档 |
| 删了 | 出事了 |

「删了」这一栏是这条最好用的爆点。 一条发过的动态消失了，比任何吵架都清楚。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓ · 屏幕 ✓ · 消息 ✓ · 照片 ✓ 边角露出的东西（同一个杯子、同一条毯子） |
| 泄露 | 他发的风景照里有她的手 · 两人发了同一个地方 |
| 观察者 | 有人截图对比 · 有人在两边都点了赞 |
| 他的克制 | 想发，存了草稿，没发 |
| 她的处理 | 她直接发了，且没分组 |

「他存了草稿没发」与「她直接发了没分组」的对照，是这条最省字的关系说明。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先发 | 她 | 他 |
| 范围 | 全部可见 | 分组（会伤人） |
| 内容 | 合影 | 一个只有对方懂的细节 |
| 后续 | 置顶 | 三天后删了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她撞见他发完又删了 | 分组可见里有没有我 |
| 好的处理 | 她发的时候没多想 | 他没拿这事来问 |
| 写崩 | 写成在社交平台秀恩爱 | 写成他成天蹲她主页 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 扇面上题的诗／字迹被人认出来／帕子上绣的花样 |
| 修仙 | 传音壁上留的话／宗门榜上名字挨着 |
| 星际 | 公开档案里关联那一栏／通讯录置顶的人 |

#### 写崩的三种方式

1. 写成秀恩爱。 克制的那一方才有戏。
2. 让删除没有后果。 删了要被发现。
3. 忽略分组可见。 那是现代版最狠的一刀。

## 九 · 被拍到

`T` ｜ 无预警 ｜ 现代都市（娱乐圈尤强）｜ 语料频次：社交网 33.0% ＋ 公开 33.0%

**骨架**｜关系是被别人捅出来的，不是自己摊牌的。

#### 节拍链

照片流出 → 配文与转发 → 四种外部叙事 → 两人商量口径（第一次为此吵）→ 回应或沉默 → 余波

#### 时间轴

外力公开没有预热期，节奏全是被动的。照片流出到发酵只要几小时；两人商量口径的那一晚是唯一能自主的时间，为此吵的那一架也发生在这一晚（吵的是节奏被抢，不是关系本身）。回应或沉默的决定要在二十四小时内做出，过时舆论会替他们决定。

#### 与「公开」的根本区别

[四 · 公开](#四--公开) 是主动，这一条是被动。而被动公开有一个特殊的伤害：他们失去了对叙事的控制权。

外人不只知道了这件事，还给它配好了故事版本：

| 外部叙事 | 内容 |
|---|---|
| 「她包养他」 | 经济叙事 |
| 「他攀高枝」 | 上位叙事 |
| 「姐弟恋」 | 猎奇叙事 |
| 「她终于恋爱了」 | 把他当成她的附属品 |

每一种都不是真的，但每一种都比真相好传播。

#### 可用细节

| 类 | 内容 |
|---|---|
| 照片 ✓ | 拍到的偏偏是最没劲的那一下（他顺手帮她拎个包） |
| 传播 | 截图 · 转发 · 配句话 · 越传越邪乎 |
| 他们的处理 | 不吭声 · 一块露面 · 发一条 |
| 影响 | 她那边的工作 · 他那边的工作（吃亏的常是他） |
| 内部 | 俩人头一回因为“这话到底咋说”吵翻 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁受损 | 她 | 他 |
| 回应方式 | 沉默 | 正面回应 |
| 内部反应 | 一致 | 分歧（他想道歉式回应，她不肯） |
| 结果 | 过去了 | 留下了长期标签 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 评论区里那条「她图什么」 | 我成了她的负面新闻 |
| 内心 | 我不解释 | 我要不要退出一阵 |
| 好的处理 | 她把「怎么说」这件事跟他一起商量 | 他没有自作主张地消失 |
| 写崩 | 写成她花钱把热搜压下去 | 写成他为了她好而分手 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 流言传到朝堂／御史参奏／坊间话本编排 |
| 修仙 | 传音壁上的匿名帖／同道议论 |
| 星际 | 内网泄露的影像／舰队八卦频道 |

#### 写崩的三种方式

1. 靠资源硬压下去。那是解决问题，不是写关系。
2. 让他自己走人成全她。见 [二 · 议论](#二--议论) 里那条一样的警告，别犯。
3. 别管外面传的版本具体是啥。那四种说法才是真正扎人的地方。

## 十 · 她替他挡

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：公开 33.0% ＋ 出面 14.0%

**骨架**｜她挡在他前头了。现在轮到他琢磨，这保护他接不接。

#### 节拍链

有人找事 → 她脚先挪了半步 → 先看他一眼 → 他摇头或点头 → 挡或不挡 → 事后他说「下次让我自己来」→ 下一次她真没动

#### 时间轴

脚动半步就是一眨眼的事，那一眼的确认更快。发难、她迈出半步、回头看他、他摇头或点头，整个过程三秒，但就在这三秒里，授权这事儿已经谈完了。「下次让我自己来」是当晚说的；下一次真来的时候隔了好几个月，她没动，站在原地忍着没动，比上次那半步还难熬，时间轴的终点就落在这儿。

#### 这条的两难

保护是好意，但保护同时是一种判断：我认为你自己应付不来。

| 她挡的方式 | 他的感受 |
|---|---|
| 一句话把事情按下去 | 感激，也有点不是滋味 |
| 私下处理，不让他知道 | 要是发现了，心里更堵 |
| 问他「要我出面吗」 | **最好**——让他自己选 |
| 让他自己处理，在旁边看着 | 得特别信得过才行 |

第三行是这条的最优解，也是这一族的通用解法：先问。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 有人当面刁难他 · 工作上被针对 · 家里人说了重话 |
| 她的动作 | 往前半步 · 打断 · 或者只是把手放在他背上 |
| 他的反应 | 松了一口气 · 或者身体先绷了一下 |
| 事后 | 他谢了她 · 但他也说了「下次让我自己来」 |
| 她的调整 | 下一次她真的没动 |

「下一次她真的没动」是这一族最难写也最重的一场。 忍住不保护，比保护难得多。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他要不要 | 需要 | 不需要但她挡了 |
| 她问不问 | 问了 | 直接上 |
| 他的表达 | 感激 | 说了「让我自己来」 |
| 下一次 | 她还是挡了 | 她忍住了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她脚都迈出去了 | 她替我把话说了 |
| 内心 | 我憋不住 | 我知道她为我好 |
| 好的处理 | 她先看了他一眼 | 他说「我自己来」 |
| 写崩 | 写成她护短逞威风 | 写成他不知领情 |

「她学会了先看他一眼」跟 [一 · 被起哄](#一--被起哄) 里「她先看他」是同一个动作。整卷靠的就是这个动作撑起来：把应对权交回给他。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她当堂发话／一句「他的事我担着」／挡下责罚 |
| 修仙 | 她出手拦下／以自身担保 |
| 星际 | 她动用职权／在记录上签了字 |

#### 写崩的三种方式

1. 写成护短爽点。 那会让他更小。
2. 让他一直感激。 至少有一次他要说「让我自己来」。
3. 忽略她的克制。 忍住不挡的那一次才是这条的顶点。
