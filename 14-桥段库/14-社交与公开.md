## 外人看不懂

前面几卷都在关系里头打转，这一卷写它跟外面世界磕碰的地方。

GB 碰上的阻力跟别的类型不一样。身边的人没谁跳出来反对，也没人拦，可就是看不懂，没一个真明白的：想不通她图什么，也想不通他凭什么肯。

所以常见的情形是谁都没说反对，屋里的空气却变了。

## 一 · 被起哄

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：起哄 43.5%（起哄＋请安、起哄＋归家高频同现）

**骨架**｜满桌人都在笑，谁也没当回事，可他笑不出来。

#### 节拍链

那句玩笑 → 全桌笑 → 他慢半拍 → 她先看他 → 他自己接或她接 → 话题转走 → 车上谁先提

#### 时间轴

玩笑本身就三秒，他反应慢，还要再过一秒才回过味来。她转头看他，就在笑声起来的第二秒，满桌都在笑，这一眼很短，全看她卡得准不准。重头戏在回去的车上，能说上十分钟：谁先开口，过了几个红绿灯才开口，都有讲究。当晚要是谁都不提，这件事就烂在肚子里了。

#### 起哄的三种，杀伤力递增

| 类型 | 说法 | 杀伤 |
|---|---|---|
| 善意 | 「你俩什么时候的事」 | 低 |
| 揶揄 | 「以后你可得听话啊」 | 中，拿两人的关系当笑料 |
| 刺 | 「你这日子过得舒服」 | 高，话里是说他不劳而获 |

第二档最常见，也最难收拾：两口子关起门的事被拿到桌面上说，还顺手贴一张「怕老婆」的老标签。说的人不一定有坏心，可话一出口，味道全变了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 聚会 ✓ · 婚礼 · 年夜饭 ✓ · 同事聚餐 |
| 那句话 | 多半是玩笑口吻，再套一句现成的俗话 |
| 全桌的反应 | 笑了 · 有人接了下茬 · 没人觉得不对劲 |
| 他 | 跟着笑 · 笑慢了一拍 · 端起杯子 |
| 她 | 接了话 · 或者没接，两样都行，意思不同 |
| 车上 | 谁先提起这事 |

「笑慢了一拍」要写清楚。

#### 她的四种接法

| 接法 | 效果 |
|---|---|
| 顺着玩笑接 | 气氛保住了，那个说法也就默认了 |
| 一句话怼回去 | 痛快，可小事容易闹成大事 |
| 平静地纠正 | 说「我们不是那样」，效果最好，也最难说出口 |
| 不接，转话题 | 稳妥，可他会以为她不想理他 |

没有完美选项。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 起哄的人 | 亲近的（朋友） | 不熟的（同事家属） |
| 她的处理 | 接 | 不接 |
| 他的处理 | 跟着笑 | 自己回了一句 |
| 事后 | 两人都不提 | 有一个人提了 |

四爱男读者给「自己回了一句」的评价最高：用不着她护着，他自己有话说。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听见那句话，先看他 | 全桌都笑了，我也跟着笑 |
| 内心 | 我该不该接话 | 别让她替我开口 |
| 好的处理 | 她先看他，让他自己选 | 他自己接了，接得挺顺 |
| 写崩 | 写成她甩金句把场子压住 | 写成他憋着委屈还得哄她 |

「她先看他」：对视一秒，「谁来应对」就交到了他手上。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 酒桌上拿他逗乐／「主君好福气」／同僚拿他的位份开涮 |
| 修仙 | 同门笑他靠道侣撑腰／大比时台下起哄 |
| 星际 | 舰上流传的闲话／有人喊他「舰长夫人」 |

#### 写崩的三种方式

1. 写她一句话镇住全场。爽倒是爽，可这就落进爽文套路了。
2. 让他毫无反应。他必须慢半拍，那一下愣神省不得。
3. 把起哄的人写成坏人。他们其实没有恶意，难写就难在这里。

#### 示例（本库自撰，可直接改写）

> 「你以后可得听话啊。」
> 满桌都笑了。有人接了下一句，笑声又起来一层。
> 他也笑了，慢了半拍。手里的杯子端起来，喝了一口，其实杯子是空的。
> 她把筷子放下。桌上安静了半秒。
> 她先看的是他。
> 他迎上她的视线，很轻地摇了一下头。
> 于是她端起自己那杯，转向另一头：「李总，刚才那个方案——」

## 二 · 议论

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：议论 21.0%

**骨架**｜有人在背后嚼他们的舌头，后面怎么走，看是谁听见了。

#### 节拍链

洗手间或电梯里的半句 → 听见的人站住 → 没进去，走开 → 装作没听见 → 当晚格外沉默 → 说或不说

#### 时间轴

当场就三十秒：站住，走开，装作没事。当时不显，过后越想越沉，那半句话在心里放久了会自己长大。第三天是能开口的最后时机，过了三天还没说，多半就一直咽下去了，说不说基本在第三天见分晓。

#### 谁听见，决定一切

| 听见的人 | 走向 |
|---|---|
| 她听见 | 她自己处理，外人看不出来，要不要告诉他，她还得想想 |
| 他听见 | 他多半装不知道 |
| 两人一起听见 | 都装没听见，最尴尬，也最有戏 |
| 谁都没听见，但读者听见 | 最冷，憋得也最久 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 洗手间隔间 · 电梯 · 茶水间 · 群里被转发的截图 · 楼道 |
| 说法 | 「图啥呢」· 「男人就这样」· 「她也不容易」 |
| 最伤的一种 | 同情她，一句「她也挺可怜的」比骂他还扎心 |
| 他们的反应 | 脚步没停 · 或者顿了一下又走了 |
| 事后 | 那晚谁都没提 · 但有一个人特别沉默 |

「同情她」那句话谁也没骂，可他们这段关系在里头成了一场牺牲。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 内容 | 说他 | 说她（同情她） |
| 谁听见 | 一个人 | 两个人 |
| 处理 | 当场怼回去 | 走开 |
| 后果 | 过去了 | 这句话在很久以后被想起 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听完就一句「她也挺可怜的」 | 我让她被人可怜了 |
| 内心 | 我不需要人可怜 | 我是不是拖累她了 |
| 好的处理 | 她直接跟他说了，还说这事跟他没关系 | 他没因为这个就说要散 |
| 写崩 | 写成她当场翻脸 | 写成他提分手，说是为她好 |

他为了成全她提分手，是这个类型里最俗、也最常见的写法。外面的偏见一下变成两人之间的危机，他退出还显得格外高尚。要用，先想清楚值不值。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 府里下人的闲话／同僚的暗讽／御史的折子 |
| 修仙 | 门内传言／说他是靠她 |
| 星际 | 内部通讯里的段子／人事档案上的批注 |

#### 写崩的三种方式

1. 把议论的人写成明摆的反派。匿名、随口的议论更真实。
2. 当场摆平。这种话当场是摆不平的。
3. 拿他提分手推情节。太省事了。

## 三 · 偏见

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：偏见 28.1%

**骨架**｜这回有人当着面说，而且没开玩笑。

#### 节拍链

当面那句「关心」→ 他沉默 → 想解释 → 不解释了 → 她比他先怒 → 很久以后他给出自己的答案

#### 时间轴

当面问的那十秒，她先火了，他没出声，也没接话，当天这页就算翻过去了。过了几年，在某个场合，他随口说出了自己的答案，没辩解，只说这些年是怎么过的。中间这几年要是写短了，读者一眼就看出是假的。

#### 偏见的具体形态

这条要写得有力，得靠具体。抽象的「世俗眼光」伤不了人，一句具体的话才伤得了：

| 说法 | 攻击的是 |
|---|---|
| 「一个男的怎么什么都听老婆的」 | 他的性别表现 |
| 「你这样以后怎么在外面立足」 | 他的社会前途 |
| 「她那么强，你受得了？」 | 假定他在忍耐 |
| 「男人还是要有自己的事业」 | 用关心的语气 |
| 「你不觉得委屈？」（问他） | 假定这是牺牲 |
| 「你也该让让他」（对她说） | 要求她收敛 |

最后一行是冲她说的。这一族别光写他挨攻击，叫强势的一方「让一让」，也是同一套偏见，只是换了一面。

#### 可用细节

| 类 | 内容 |
|---|---|
| 说话的人 | 长辈 · 老同学 · 领导 · 一个「为你好」的朋友 |
| 语气 | 用关心的口气说，最难顶回去 |
| 他的反应 | 先不说话 · 接着想解释 · 最后懒得说了 |
| 她的反应 | 她比他先炸 |
| 落点 | 他后来自己给了个说法 |

「他后来自己给了个说法」不能少，哪怕隔了很久才给。

#### 他的答案，四个版本

| 版本 | 说法 |
|---|---|
| 辩解型 | 「我们不是你想的那样」，最没劲 |
| 反击型 | 「关你什么事」，解气，可也等于接了对方出的题 |
| 陈述型 | 「我挺好的」，简单，不多解释 |
| 重构型 | 「谁行谁上，这不挺正常」，最漂亮 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 对象 | 针对他 | 针对她（要她收敛） |
| 说话人 | 恶意 | 善意（更难处理） |
| 他的应对 | 当场 | 很久以后 |
| 影响 | 无 | 他真的动摇了一阵 |

「他真的动摇了一阵」值得写。外人的话确实会起作用，写出这个作用，比写他刀枪不入更真实。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 有人对她说「你也该让让他」 | 「你不觉得委屈？」 |
| 内心 | 凭什么是我让 | 我要怎么说才不像在辩解 |
| 好的处理 | 她没管别人怎么看，该怎么着还怎么着 | 他给了自己的答案 |
| 写崩 | 写成她当众讲大道理 | 写成他离了她就不行 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | **方向反转**：偏见变成「他一个男子怎可抛头露面」 |
| 修仙 | 说他修为配不上／靠道侣 |
| 星际 | 说他的基因等级／履历不匹配 |

见 [03-世界观设定/01-女尊世界构建全书](../03-世界观设定/01-女尊世界构建全书.md)。女尊文里的「换皮」，是把现实中女生听过的那些话直接搬到男性角色身上，措辞照旧，只把主语换掉，偏见连同制度就一起翻了过来。比如要他守规矩、少说话、别冒尖，主语一换，效果就出来了。

#### 写崩的三种方式

1. 空谈「世俗眼光」。不如写一句具体的。
2. 让她从头到尾替他顶回去。他自己也得拿出个答案。
3. 让他一点都不受影响。动摇一阵反倒更像真的。

## 四 · 公开

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：公开 33.4%

**骨架**｜他们不打算再装了，公开总要落到一个具体动作上。

#### 节拍链

决定不藏 → 挑一个动作：朋友圈·介绍·牵手进场 → 半秒安静 → 她继续原话题 → 消息炸开 → 他在自己的场子也做了一次

#### 时间轴

牵手进场也好，发条朋友圈也好，动作本身一眨眼就过去。第一波是当场那半秒安静，第二波是消息，当晚就炸开，第三波是各路人来问，私聊三天内陆续进来。过了一周就没人再提了。他在自己场子里补的那一次，隔几天再做正合适。

#### 公开的六种动作，从轻到重

| 动作 | 轻重 |
|---|---|
| 不再解释「只是朋友」 | 最轻，被动 |
| 一起出现在一个必须解释的场合 | 中 |
| 她在群里回了一句 | 中 |
| 朋友圈 ✓ 发了一张 | 现代版的标准动作 |
| 她在正式场合介绍他的身份 | 重 |
| 他在自己的地盘介绍她 | **最重，也最少被写** |

她地位高，场子多，说一句顶别人十句，所以这类文里公开关系的事基本都落在她身上。这回换成他主动在自己这边把她介绍出去，意思就不一样了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 决定的时刻 | 多半是到了那一步，自然就定了 |
| 朋友圈 | 发啥 · 谁先发 · 给谁看 · 点赞先后 |
| 现场 | 介绍时咋说的 · 全场静了半秒 · 谁先开口圆场 |
| 他的反应 | 站直了 · 要不他先伸手 |
| 事后 | 消息炸了 · 当天就有人来问 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁公开的 | 她 | 他 |
| 方式 | 直接说 | 用行动，牵着手走进去 |
| 场合 | 熟人面前 | 正式场合 |
| 反应 | 没啥反应 | 出了岔子 |
| 之前的状态 | 瞒了挺久 | 一直没瞒，就是没提 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她说出那个词时他抬了下头 | 她当着所有人说了 |
| 内心 | 该说了 | 我要不要先说 |
| 好的处理 | 她说完就聊别的 | 他在自己那边也来一回 |
| 写崩 | 写成她当众立威的爽点 | 写成他认命听安排 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 上族谱／过明路／带他赴宴／给名分 |
| 修仙 | 结契昭告／道侣录／宗门备案 |
| 星际 | 关系登记／权限绑定／公开频道通报 |

古代的「上族谱」撤不回来，有法律效力，全族都看得见。

#### 写崩的三种方式

1. 写成宣示主权。公开是要认下他。
2. 只让她公开。 他也得来一次。
3. 公开以后谁都没吭声。起码要有一个人来问一句。

## 五 · 他的朋友们

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：聚会 11.7% ＋ 起哄 43.5%

**骨架**｜她第一次见他那帮朋友，他们嘴里的他，跟她认识的那个完全是两个人。

#### 节拍链

提前打了招呼 → 进场 → 绰号与旧事 → 他另一副样子 → 她融入或格格不入 → 散场 → 他问「他们还行吧」

#### 时间轴

这三个小时融没融进去，看的是接梗。头一个小时，桌上的旧梗她八成听不懂。到中段有人开始给她解释，肯解释的那个，就是这圈人里头一个愿意接纳她的。快散场时她总算接上一个梗，全桌都笑了，接上了才算及格。回家路上第五分钟，他才问那句「他们还行吧」。问早了显得他紧张，问晚了又像他根本不在乎。

#### 这条的价值

他在朋友面前换了个人，她这是头一回见到。

| 她看见的 | 说明 |
|---|---|
| 他说话的音量变了 | 在她面前会放轻 |
| 他会开的玩笑 | 带点她没见过的野 |
| 别人怎么叫他 | 有个绰号 |
| 他被提起的旧事 | 她不知道的那一面 |
| 他喝酒的量 | 在她面前一直留着量 |

「原来他在别人面前是这样的」，是惊喜，也可能是不适。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 大排档 · KTV · 球场边 · 他老家的朋友 |
| 他的紧张 | 他老看她 · 怕朋友说漏嘴 · 提前打过招呼 |
| 朋友的试探 | 叫「嫂子」还是直接喊名字 · 敬酒时先看谁 |
| 旧事 | 有人说起他的过去，也许是前任，也许是他落魄的那段 |
| 她的处理 | 她能不能接上话 · 要不要装得随和点 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 朋友的态度 | 接纳 | 保留，嫌她太强 |
| 他的状态 | 放松 | 一直绷着 |
| 她的适应 | 混熟了 | 融不进去，他还全看在眼里 |
| 结果 | 关系更近 | 他后来不太组这种局了，不是好苗头 |

「他后来不太组这种局了」得写出来。为了这段关系丢掉自己的朋友圈子，是个该留意的信号。

| 写崩 | 写成她降尊纡贵地融入 | 写成他在两边都做人 |

1. 让她轻轻松松拿下全场。格格不入的人反倒更有戏。
2. 朋友全写成背景板。起码得有一个人出来唱反调。
3. 不写他紧不紧张。他一直在两边来回看，这个要写出来。

## 六 · 她的圈子

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：聚会 11.7% ＋ 职场 33.9%

**骨架**｜到了她的场子，他就是「谁谁谁带的伴儿」。

#### 节拍链

他被带进场 → 「这是我先生」→ 名片只递给她 → 他站在她斜后方 → 只有他懂的那件事出现 → 回家路上

#### 时间轴

名片三次绕过他，话题五次绕过他，他站在她斜后方一次次数着，也不恼。被晾得够久了，全场才第一次有人转头看他，这样的一下整场只能有一次。转折就在「只有他懂的那件事」冒出来的时候，也许是红酒，也许是设备，也许是一句诗。

#### 与上一条的镜像

| | 他的圈子 | 她的圈子 |
|---|---|---|
| 她的位置 | 客人 | 主人 |
| 他的位置 | 主人 | **附属** |
| 需要适应的人 | 她 | 他 |
| 最难受的一点 | 她插不进话题 | 别人不问他名字 |

一整晚他都被介绍成「这是我先生」，没有一个人问他叫什么、做什么。

现实里的女性对这种滋味太熟了，安到他身上，照样成立。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 商务晚宴 · 行业活动 · 她的同学会 · 颁奖 |
| 他的处理 | 站她斜后方半步 · 端杯酒没喝过 · 帮她拎包 |
| 被忽略的形态 | 名片只递给她 · 他插不上话 · 有人问「这是助理？」 |
| 她的动作 | 主动说他干啥的 · 把话头往他懂的地方带 |
| 他的时刻 | 全场就他一个人懂那事 |

「全场就他一个人懂那事」能把局面翻过来，还用不着她帮。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她介不介绍 | 正经说他是干嘛的 | 就一句「我先生」 |
| 他的状态 | 待着舒服 | 别扭但硬扛 |
| 有没有翻盘 | 有，他那行派上用场 | 没有，这事就翻篇了 |
| 回家路上 | 她先认错 | 他说没事，真没事还是装的 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现一整晚没人问过他的名字 | 名片都递给她了 |
| 内心 | 我该早点介绍他 | 我站在这儿算怎么回事 |
| 好的处理 | 她介绍他时说的是他做的事 | 他没靠自嘲把这事糊弄过去 |
| 写崩 | 写成她从头到尾护着他 | 写成他觉得自己配不上，先走了 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 随她赴宴／坐在她身后／无人问他名姓 |
| 修仙 | 她的师门大会／他被称作「那位道侣」 |
| 星际 | 舰队集会／他的名牌上写着她的编号 |

#### 写崩的三种方式

1. 让她从头护到尾。有一段得他自己硬撑。
2. 让他自嘲两句混过去。自嘲等于拿伤口讲段子。
3. 漏掉「没人问名字」那茬。整件事最要紧的就是这个。

## 七 · 当众叫错

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：改口 30.1% ＋ 起哄 43.5%

**骨架**｜私底下的称呼，当着众人脱口而出。

#### 节拍链

场合正式 → 那个称呼脱口 → 半秒安静 → 他耳朵红了 → 她面不改色接着说 → 会后有人发了个表情 → 两人对视

#### 时间轴

称呼一出口，全场静了半秒，她就靠这半秒反应过来，面不改色往下说，前后不过三秒。后面的话他一个字也没听进去。消息十分钟就传遍了，比会散得还快，一散会，那个表情包已经到了。两人对视一眼，这事就成了往后的笑话，回味了一下午。

#### 为什么这条好用

这是一次意外的公开：一个词，全场静了半秒。

也没有谁拿主意，就是嘴快说漏了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 会议室 · 一桌子人 · 电话开着免提 · 微信群发错了 |
| 那个称呼 | 只有他俩才叫的那个 |
| 半秒 | 全场啥反应 · 谁先笑 · 谁装没听见 |
| 他 | 耳朵 ✓ 立马红 · 赶紧改口 · 要不就不改 |
| 她 | 脸不红心不跳接着聊 · 这么办最稳 |
| 事后 | 群里有人甩了个表情包 |

她不慌，这件事就不算事故。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁叫错 | 他 | 她，更少见，也更有效果 |
| 场合正式度 | 私密场合 | 正式会议 |
| 他的处理 | 改口 | 将错就错 |
| 她的处理 | 装没听见 | 接了一句更过分的 |

喜剧向可以写她「接了一句更过分的」。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听见的那一秒还是把话念完了 | 说出口才反应过来 |
| 内心 | 别慌，一慌就出事 | 完了 |
| 好的处理 | 她装没事人一样 | 他红着耳朵把会开完 |
| 写崩 | 写成她当场撩人 | 写成他窘到跑掉 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 当堂唤了闺名／忘了称位份／逾矩之称 |
| 修仙 | 大殿上叫了道号之外的名字 |
| 星际 | 公开频道里用了私人称呼 |

放在古代分量最重。称谓是礼制里的死规矩，叫错了就算逾矩，远不止尴尬。见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。

#### 写崩的三种方式

1. 写成故意调情。要意外才有味道。
2. 全场一点反应都没有。那半秒安静必须有。
3. 让他跑了。把会撑到散，比跑掉好。

## 八 · 朋友圈的分寸

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.9%

**骨架**｜发什么，什么时候发，谁在底下评论，一段关系全写在这三样里。

#### 节拍链

拍了或没拍 → 发不发 → 可见范围 → 谁点赞谁评论 → 对方的对应动作 → 某天一条消失了

#### 时间轴

时间按月算：谁先出现在谁照片的角落，隔多久才露正脸，哪天有一条突然没了，又是谁先发现的。发一条本身很快，拍，犹豫，选可见范围，发出去，十秒的事。藏在后面的一场，是翻旧时间轴的那个晚上。

#### 社交网的语法

| 观察点 | 读作 |
|---|---|
| 谁先发 | 谁更想露脸 |
| 发的是合影还是背影 | 公开到啥程度 |
| 可见范围 | 分组可见 = 半公开 |
| 配文 | 字越少事越大 |
| 他评论了什么 | 敢不敢在底下冒头 |
| 她点不点赞 | 点一下就是认了 |
| 置顶 | 最顶格的一档 |
| 删了 | 出事了 |

发过的一条动态不见了，不用吵，也知道出事了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓ · 屏幕 ✓ · 消息 ✓ · 照片 ✓ 边角露出的东西，同一个杯子、同一条毯子 |
| 泄露 | 他发的风景照里有她的手 · 两人发了同一个地方 |
| 观察者 | 有人截图对比 · 有人在两边都点了赞 |
| 他的克制 | 想发，存了草稿，没发 |
| 她的处理 | 她直接发了，也没设分组 |

他存着草稿没发，她直接发了也没分组，一比就看出两人的关系。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先发 | 她 | 他 |
| 范围 | 全部可见 | 分组（会伤人） |
| 内容 | 合影 | 一个只有对方懂的细节 |
| 后续 | 置顶 | 三天后删了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她撞见他发完又删了 | 分组可见里有没有我 |
| 好的处理 | 她发的时候没多想 | 他没拿这事来问 |
| 写崩 | 写成在社交平台秀恩爱 | 写成他成天蹲她主页 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 扇面上题的诗被认出来／帕子上绣的花样 |
| 修仙 | 传音壁上留话／宗门榜上名字挨着 |
| 星际 | 公开档案里关联那一栏／通讯录置顶的人 |

#### 写崩的三种方式

1. 写成秀恩爱。忍着不发的那一方才有戏。
2. 删了没后果。删了就该被发现。
3. 不管分组可见。分组可见是会伤人的。

## 九 · 被拍到

`T` ｜ 无预警 ｜ 现代都市（娱乐圈尤强）｜ 语料频次：社交网 33.9% ＋ 公开 33.4%

**骨架**｜关系被人捅了出去。

#### 节拍链

照片流出 → 配文与转发 → 四种外部叙事 → 两人商量口径（第一次为此吵）→ 回应或沉默 → 余波

#### 时间轴

从照片流出到舆论发酵，只有几个小时，两人能自己拿主意的，只有商量口径的那一晚。回应还是沉默，得在二十四小时里定下来，过了时间，舆论就替他们定了。那一晚他们吵，是因为节奏被人抢走了，关系本身没出问题。被外力公开没有预热，节奏从头到尾都在别人手里。

#### 与「公开」的根本区别

[四 · 公开](#四--公开) 是他们自己公开，这一条是被人公开。被动的伤处，是自己的事怎么讲由不得他们。

外人知道了这件事，还顺手给它编好了故事：

| 外部叙事 | 内容 |
|---|---|
| 「她包养他」 | 经济叙事 |
| 「他攀高枝」 | 上位叙事 |
| 「姐弟恋」 | 猎奇叙事 |
| 「她终于恋爱了」 | 把他当成她的附属品 |

四种说法都不对，可都比真相好传。

#### 可用细节

| 类 | 内容 |
|---|---|
| 照片 ✓ | 拍到的偏偏是最没劲的那一下，他顺手帮她拎个包 |
| 传播 | 截图 · 转发 · 配句话 · 越传越邪乎 |
| 他们的处理 | 不吭声 · 一块露面 · 发一条 |
| 影响 | 她那边的工作 · 他那边的工作，吃亏的常是他 |
| 内部 | 俩人头一回因为这话到底咋说吵翻 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁受损 | 她 | 他 |
| 回应方式 | 沉默 | 正面回应 |
| 内部反应 | 一致 | 分歧：他想道歉式回应，她不肯 |
| 结果 | 过去了 | 留下了长期标签 |

| | 四爱女笔下 | 四爱男笔下 |

## 十 · 她替他挡

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：公开 33.4% ＋ 出面 14.5%

**骨架**｜她挡到他前面去了，这回轮到他想：这份保护，要还是不要。

#### 节拍链

有人找事 → 她脚先挪了半步 → 先看他一眼 → 他摇头或点头 → 挡或不挡 → 事后他说「下次让我自己来」→ 下一次她真没动

#### 时间轴

有人发难，她用眼神问，他给了答复，前后不到三秒。她迈出半步，回头看他，他摇头或点头，这一眼问答比她脚下那半步还快。「下次让我自己来」是当晚说的。隔了好几个月，下一次真的来了，她没动，站在原地硬忍着，比上回那半步还难熬。

#### 这条的两难

保护是好意，可保护里也藏着一个判断：我觉得你自己应付不来。

| 她挡的方式 | 他的感受 |
|---|---|
| 一句话把事情按下去 | 感激，也有点不是滋味 |
| 私下处理，不让他知道 | 要是发现了，心里更堵 |
| 问他「要我出面吗」 | **最好**——让他自己选 |
| 让他自己处理，在旁边看着 | 得特别信得过才行 |

第三行那种先问，整族都用得上。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 有人当面刁难他 · 工作上被针对 · 家里人说了重话 |
| 她的动作 | 往前半步 · 打断 · 或者只是把手放在他背上 |
| 他的反应 | 松了一口气 · 或者身体先绷了一下 |
| 事后 | 他谢了她 · 但也说了「下次让我自己来」 |
| 她的调整 | 下一次她真的没动 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他要不要 | 需要 | 不需要但她挡了 |
| 她问不问 | 问了 | 直接上 |
| 他的表达 | 感激 | 说了「让我自己来」 |
| 下一次 | 她还是挡了 | 她忍住了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她脚都迈出去了 | 她替我把话说了 |
| 内心 | 我憋不住 | 我知道她为我好 |
| 好的处理 | 她先看了他一眼 | 他说「我自己来」 |
| 写崩 | 写成她护短逞威风 | 写成他不知领情 |

「她先看了他一眼」，和 [一 · 被起哄](#一--被起哄) 里的「她先看他」是同一个动作。这一卷有两条都用它，把怎么应对交回给他。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她当堂发话／一句「他的事我担着」／挡下责罚 |
| 修仙 | 她出手拦下／以自身担保 |
| 星际 | 她动用职权／在记录上签了字 |

#### 写崩的三种方式

1. 写成护短爽点。他会显得更小。
2. 让他从头感激到尾。起码有一回他得说「让我自己来」。
3. 漏掉她的克制。她忍住没挡的那次要写。
