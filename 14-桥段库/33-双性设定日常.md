## 双性设定的范围和边界

藏书里实测有 432 篇双性（[亚型分布报告 §六](../10-藏书索引-公开/语料统计.md)，按关键词统计，作者标了才算，所以是下限）。它在排雷段也是单词第 2 高频，出现 46 次，只比「虐」的 51 次少（[05-预警与分级实操 §5.2](../06-尺度与写法/05-预警与分级实操.md)）。写的人多，避雷的人也多，预警的位置一点不能动。卷首那行预警不准往后挪，也不准夹在文案中间，原因就在双性的这组数据。

术语卷 pegging 词条的创作提示里说，圈内自己人也批评过这种取舍，可这个设定在语料里照样到处都是（[术语卷词条](../02-术语百科/01-核心身份与权力动态.md)）。pegging 的场面里女方一直在出力，自己没多少快感，这个设定刚好补上了这个缺口，所以才流传开来。严格四爱按身体写实性的规则不承认它（[01-总论 3.2 规则二](../01-总论/01-概念源流与圈史.md)），可那条规则管不到床以外的日子。这十条补的就是这一块，桥段库以前完全没写过。边界归术语卷管，这里只讲一点：设定长在他身上，就要陪着他过日子。

这几个相邻设定别混着用（详细辨析见 [05-易混淆词辨析](../02-术语百科/05-易混淆词辨析.md)）：

| 设定 | 一句话 | 层级 |
|---|---|---|
| 双性 | 两性生理特征并存 | 个体设定（[词条](../02-术语百科/01-核心身份与权力动态.md)） |
| 双儿 | 外观男性、可生育 | 个体设定，耽美种田文源（[词条](../02-术语百科/02-女尊称谓与礼制体系.md)） |
| 女尊男子生子 | 全体男性可育 | 世界观设定（同上卷） |
| 女A男O | 生育由第二性别赋予 | 制度设定（[设计手册](../03-世界观设定/02-GB-ABO设定设计手册.md)） |

边界四条：

| 边界 | 说明 |
|---|---|
| 只写日常 | 只写身体自处、制度接口、关系议题这几类，过程和描写照 [06-尺度与写法](../06-尺度与写法/) 处理，分级最高 `M` |
| 全员成年 | 十条里所有角色都是成年人 |
| tag 前置 | ⚠️双性 写在文案和排雷的最前面，排雷用五行制（[05-预警与分级实操](../06-尺度与写法/05-预警与分级实操.md)） |
| 他自认男性 | 这十条里的「他」都认为自己是男人。平台按主角自己认的性别分频道，认不清的归多元向，不收在这十条里 |

## 一 · 他和他的身体

`T` ｜ ⚠️双性 ｜ 全谱系 ｜ 语料底数：双性 432 篇（卷首口径）

**骨架**｜这具身体他已经跟了二十多年。开场一句话，全书的基调就定下来了。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 冒出来一样东西：体检单、旧病历，或是谁随口开的玩笑 |
| 2 | 回忆：当年家里怎么处理，去看病、搬家，或者当作没事把他养大 |
| 3 | 他懂事的那年，第一次明白这件事要靠自己管 |
| 4 | 交代他如今怎么藏：穿什么、找什么理由、东西放在哪 |
| 5 | 回到眼前，那样东西被处理掉 |
| 6 | 用一句话收尾，向读者交底，未必对谁说出来 |

#### 时间轴

他和身体的这段历史按年算，交代只用一场戏。二十几年塞进一个闪回，压得越紧越像平常日子，铺开来写就成了念病历。

#### 可用细节

| 类 | 内容 |
|---|---|
| 管理系统 | 内衣款式自己挑了好多年 · 洗漱包单独搁 · 病历本藏哪儿心里有数 · 上学那会儿老请长假 |
| 家史两版 | 秘密版：转学、换医生、他妈的一句「别跟人说」 · 平常版：家里根本没当回事，他是上学以后才学会瞒的 |
| 口吻两档 | 羞耻档：想起来全是关门的声音 · 平常档：想起来有饭桌，有笑声 |
| 定调句 | 「习惯了」三个字两种念法：认命，或者真习惯 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 家里怎么养 | 藏着掖着养 | 当普通事养 |
| 他的自我叙述 | 「这摊事得管」 | 「这就是我」 |
| 就医史 | 有医生一直跟着看 | 从没正经看过病 |
| 知道的人 | 就他妈知道 | 谁都不晓得 |

「当平常事养」也有戏可写。家里越当回平常事，到了学校和社会上落差就越大，戏就在那道门槛上。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 进入点 | 读者先知道，她还蒙在鼓里，这点信息差留到后面用 | 用第一人称慢慢讲，像说起一个老熟人 |
| 情绪 | 没有（她还没出场） | 收着写，不卖惨 |
| 好的处理 | 用她的寻常日子衬出他那套管理手法 | 把管理写得顺手，顺手里看得出做了很多年 |
| 写崩 | 让她过早看出破绽 | 一上来就是他三段哭诉的独白 |

#### 写崩的三种方式

1. 开场就来悲情独白。 二十年都过来了，他现在是熟门熟路，情绪留给后面的条目。
2. 把身体当清单写。 设定交代一句就行，一项项摆出来看，人就成了标本。
3. 交代得太晚。 读者照着错的预期投进去的感情，到揭晓时会变成被骗的感觉，这个设定格外经不起。

- 远端：[41-他的身体与年岁](41-他的身体与年岁.md)，身体线换成年岁的版本
- 对照：[十 · 就是身体而已](#十--就是身体而已)，全卷收尾处和这条对上的那一端
- 后接：[二 · 被知道的那天](#二--被知道的那天) · [五 · 他讨厌它的那几年](#五--他讨厌它的那几年)

## 二 · 被知道的那天

`T` ｜ ⚠️双性 ｜ 全谱系 ｜ 设定必需条（拿掉设定即不成立）

**骨架**｜她知道了。她是怎么知道的，决定了两人以后各站在什么位置。

#### 三种知道法

| 方式 | 主动权 | 留给后续的东西 |
|---|---|---|
| 他说 | 在他手里：何时说、怎么说、在哪说，都由他定 | 两人站在一边，她听到的话里有他的信任 |
| 体检／就医 | 在制度手里：检查单先于他的话到了 | 她还得多咽下一层「他原本没打算现在告诉我」 |
| 意外（受伤送医、撞见） | 谁也没有 | 冲击最大，两人都没准备，第一反应全是真的 |

第三种要慎用。它跳过了他的挣扎，这一条的戏也就少了一半。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 躲不过了：同居的日子定下、体检单到手，或者要跑一趟医院 |
| 2 | 他的最后一晚：想好了怎么说，或者根本没想好 |
| 3 | 说出口／被看见的那一刻不要拖，越短越有力 |
| 4 | 她的眼睛先落在哪：他的脸还是单子 |
| 5 | 两人都不出声，停多久由作者定，读者此时正屏着气 |
| 6 | 她开口第一句 |
| 7 | 当晚照常过日子，这一步最容易漏写 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 他说的版本 | 检查单折了又折 · 背好的话一句没用上 · 开口就仨字「有件事」 |
| 体检的版本 | 医生直接打她手机 · 报告单上写的科室名 · 他攥着单子站在诊室外面 |
| 她的第一句话分档 | 「哦」（收下了）· 「疼吗」（先问人）· 「吃饭了没」，把今天拉回正轨 · 追问细节（最悬的一档） |
| 第 7 拍 | 洗碗、遛狗、各洗各的：日子照常过，这就是回答 |

读者凭这一句认识她，作者凭这一句定全书的调子。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 方式 | 他直接说 | 体检／意外 |
| 时间点 | 还没在一起，他给她留了退路 | 已经同居，他输不起了 |
| 她的消化 | 当场就缓过来 | 出门走了一圈才回来 |
| 他等的东西 | 她一句明确的话 | 她什么都不说，像没事一样就好 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她忽然意识到这句话他私下练了多少遍 | 话说出去后的那几秒，心里一片空 |
| 内心 | 先管人，再想事 | 退路他早在心里排好了 |
| 好的处理 | 她的反应没照他排练的走，很平淡 | 他反而有些失落，平静过了头也像不在乎 |
| 写崩 | 她只顾着问奇怪的问题 | 他低声下气地求饶 |

「他有点失望」这一笔不能漏。半辈子盼着的「没关系」，真听到了，心里反倒空了。

#### 写崩的三种方式

1. 让她当场表演大度。 漂亮话是说给读者听的，他要看的是日子怎么接着过。
2. 把坦白写成审判。 他没做错什么，这场戏里根本没有被告。
3. 当晚就进卧室。 拿身体上的接纳来收场最省事，也最假。日常里的接纳，要靠日常来证明。

#### 可串接

前接：[一 · 他和他的身体](#一--他和他的身体)
后接：[六 · 她学着了解](#六--她学着了解) · [三 · 医院这一关](#三--医院这一关)
同族：[15-秘密与坦白 · 坦白的那一夜](15-秘密与坦白.md#六--坦白的那一夜)，通用的骨架写在那里

#### 示例（本库自撰，可直接改写）

> 「有件事。」他说。
> 水壶正响。她关了火，回头。他站在离沙发一步远的地方，手里捏着一张对折又对折的检查单。
> 他准备了很长的版本，带解释，带退路，带一句替她想好的「没关系」。真正说出口的只有四十几个字。
> 她听完，看了他几秒。「哦。」她说，「饭还没好，你先把汤端出去。」
> 他端着汤在餐桌边站了一会儿，才明白这就是她的回答。

## 三 · 医院这一关

`T` ｜ ⚠️双性 ｜ 现代都市（换皮见条内） ｜ 设定必需条

**骨架**｜挂号系统里找不到他这种人，制度一较真，吃苦头的是他们两个。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 有了得去医院的理由：月经乱了、单位要体检、想查能不能生 |
| 2 | 挂哪一科：两人对着挂号页面翻来翻去，定不下来 |
| 3 | 填表：性别一栏两个格子，笔尖停在上面落不下去 |
| 4 | 候诊区：叫号屏念出全名，他起身的那一下 |
| 5 | 诊室：门上贴着「一次只进一位」，她进不进去 |
| 6 | 医生的说法：有好听的，也有难听的，见可用细节 |
| 7 | 出来以后：拿着缴费单走到停车场，两人谁先说话 |

#### 时间轴

医院里的时间按叫号走。等候的四十分钟比诊室里的四分钟长得多，戏也照这个比例分。

#### 可用细节

| 类 | 内容 |
|---|---|
| 制度接口 | 性别栏只能二选一 · 系统按性别不给查某些项目 · 缴费单上写的科室名，他不想让她看见 |
| 医生措辞：钝感版 | 「这情况真不多见啊」（他成了病例）· 当着他面翻书 · 喊同事「你们来看看」 |
| 医生措辞：像样版 | 「平时哪儿不舒服」（他还算病人）· 只说功能，不说稀奇 |
| 她的动作 | 表格上替他勾了勾 · 到诊室门口那步说「我陪他进去」 · 医生要喊同事时她开口拦了 |

这一条写的是流程上的钝感，恶意是另一回事。流程没有脸，有火也找不到人发。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她在不在 | 全程陪着看 | 他自己去的，回家才说 |
| 医生 | 第一次遇到这种情况的年轻医生 | 见惯了的老医生，话很少 |
| 结果 | 没查出问题，定期复查 | 查出毛病要治（接 [八](#八--能不能有孩子)） |
| 他的状态 | 心里有数，流程很熟 | 拖了十年，第一次正经看病 |

写「他一个人去」的话，补一个回家以后的镜头：单子叠好塞在外套内袋，她洗衣服时摸了出来。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 替他打勾那一下 | 叫号屏念出全名那一秒 |
| 内心 | 她第一次亲眼看到制度怎么为难他 | 这些流程，他独自扛了多少年 |
| 好的处理 | 她没吵没闹，过后去填了意见表 | 他在停车场说「其实还好」，说完连自己都信了大半 |
| 写崩 | 当场翻脸，写成维权爽文 | 从头到尾只写他受欺负 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 府医只跟主母说话 · 医案上怎么写 · 抓药伙计多瞧的那一眼 |
| 修仙 | 灵脉图里多出来的一条线 · 医修说话的方式 · 宗门大比前要查的事 |
| 星际 | 基因档案上分的类 · 医疗舱跳出来的「数据不对」 · 舰医不能往外说的事 |

#### 写崩的三种方式

1. 把医生写成恶人。 这一条写的是钝感，改成恶意，就变成打反派了。
2. 让她当场掀桌。 爽是爽了一下，可「流程没有脸」这个真正的问题被她盖住了。
3. 借检查来写身体。 把看病的场面拿来展示身体，就是典型的奇观写法，整条都毁了。

后面接[七 · 他的周期](#七--他的周期)，然后是[八 · 能不能有孩子](#八--能不能有孩子)。

## 四 · 更衣室与澡堂

`T` ｜ ⚠️双性 ｜ 现代都市 ｜ 设定必需条

**骨架**｜在公共场合怎么处理身体，他练了半辈子，这回她在旁边看着。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 来了邀约：公司团建泡温泉、健身房年卡、朋友约着游泳 |
| 2 | 搬出借口库，用他早备好的预案，见可用细节 |
| 3 | 这回预案不管用：领导点了名，或者她也被邀请了 |
| 4 | 做法：错开时间、要单间，或去了不下水 |
| 5 | 有人多问一句，空气停半拍 |
| 6 | 收尾：她在场就由她递台阶，不在场他自己收 |

#### 时间轴

预案要攒好些年，用起来只有几分钟。借口说出口那两秒有多顺，是十几年练出来的，正是这份顺溜让他难受。

#### 可用细节

| 类 | 内容 |
|---|---|
| 借口库 | 「皮肤过敏」「有纹身不方便」「怕水」「那天加班」，轮换着对不同的人用，同一个人只用一次 |
| 错峰技术 | 最早到或最晚走 · 挑带门的淋浴隔间 · 更衣柜选最角落 · 掐着人少的时候进出 |
| 她的台阶 | 「订了家庭池」 · 「他陪我，不去男汤」 · 提前三个月就帮他铺垫「怕水」这个人设 |
| 物件 | 长袖泳衣 · 浴巾怎么系 · 更衣柜钥匙圈在手里攥出的印子 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她在不在 | 在：她可以帮着掩护 | 不在：他独自扛着，回家当笑话讲 |
| 场合强度 | 推得掉的私人小聚 | 推不掉的团建，不去反而更惹眼 |
| 他的心态 | 照流程走，心里很平静 | 临时被逼上场，说辞当场编 |
| 起疑的人 | 没有人察觉 | 有个人多问了一句，之后也没再提 |

「回家讲成笑话」这种写法分量不轻。他把险情当段子讲，她笑完，好半天没出声。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她第一次在旁边看完全程 | 话一说出来，顺得像背过 |
| 内心 | 这一套他得练多少年才行 | 每次都过了关，每次都累 |
| 好的处理 | 她打掩护比他还熟练，事后两人都不提 | 他借别的由头谢她 |
| 写崩 | 她什么都替他扛，像他亲妈 | 写得像特务接头 |

#### 写崩的三种方式

1. 写成悬疑。 千钧一发是掉马戏（身份暴露戏，[15-秘密与坦白 · 掉马](15-秘密与坦白.md#二--掉马)）的写法。这一条写日常，难受也是闷闷的。
2. 真让他被人撞见。 撞见以后要归到别的族，预警等级也变了，不要在这一条里引爆。
3. 她的掩护抢了戏。 她掩护得十全十美，就等于拿走了他的本事。这套流程他熟了半辈子，用不着别人全包。

1. 靠一番话治好。 焦虑没有一次治好的办法，一段话就消掉的恨，说明恨得不真。

3. 写着写着换了对象。 讨厌身体慢慢写成讨厌自己，那是另一种病，要另开一条线来治。

## 六 · 她学着了解

`T` ｜ ⚠️双性 ｜ 全谱系 ｜ 设定必需条

| 拍 | 内容 |
|---|---|
| 1 | 她发觉自己接不上话，有句没听懂，又不敢问 |
| 2 | 背着他查：在搜索框里打了字又删 |
| 3 | 头一回开口问，问法就不对 |
| 4 | 他的反应提醒了她：冷了半拍，或者干脆一句「别研究我」 |
| 5 | 她改了问法，让他来定分寸 |
| 6 | 需要照顾的地方都照顾到，只是不声张 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 功课痕迹 | 忘了开无痕的浏览记录 · 购物车里加了又删的书 · 问学医的朋友时用「我一个朋友」开头 |

| 可以的问法 | 「想让我知道多少」，说多少由他定 · 「这个我该注意什么」，问的是用处，回答就成了照顾 |
| 落地 | 药挪到他顺手那格 · 周期表她记了一份（接 [七](#七--他的周期)）· 挂哪科她提前查好（接 [三](#三--医院这一关)） |

判断问不问：答案该由他管的，问。只为满足好奇的，忍着。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 功课路线 | 当面问他 | 背着他查，查完装作没事 |
| 他的接受度 | 愿意讲，讲着讲着就放松了 | “别研究我”，边界守得很严 |
| 动机被误读 | 没有 | 有一次被当成猎奇，要哄回来 |
| 边界的划法 | 他划线，她守线 | 她有意留白，他一点点往外挪 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 搜索框里那句打了又删的话 | 发现她也记着周期表的那天 |
| 内心 | 想知道，又怕不该问，心里来回拉扯 | 被盯着看的不自在，和被人放在心上的暖意，也在拉扯 |
| 好的处理 | 她问一句：「你想让我知道多少」 | 能说的他一点点往外讲，每次只讲一点 |
| 写崩 | 她问得像审犯人 | 他一问就翻脸，翻上十次，读者先受不了 |

#### 写崩的三种方式

1. 像审讯。 问题一个接一个，他就成了受审的人，想了解他这件事也变了味。
2. 一夜成了专家。 做功课要花时间，也得犯错，没错过的了解靠不住。
3. 当面宣读成果。 做完功课就去跟他汇报，照顾也成了汇报。功课应该落在药盒和日程上。

## 七 · 他的周期

`T` ｜ ⚠️双性 ｜ 全谱系 ｜ 镜像条（对 17 卷第六条）

**骨架**｜这一回换她来掌握分寸，日子反过来，被照顾的是他。

#### 与「她的生理期」互为镜像

[17-同居与身体日常 · 她的生理期](17-同居与身体日常.md#六--她的生理期)那一条里定的规矩，男女对调过来就能用。那一条是他学分寸：别问，照着做，别把人当病人，这一条换她来学。那一条里她总说「我没事」，这一条换他嘴硬。两条对照着写，谁照顾谁、怎么照顾，一来一回就对上了。

| 1 | 前兆：他话少了，她开始留意，药被挪进外套口袋 |

| 她的合适版 | 家里先调暖两度 · 汤在保温壶里，不说 · 日程「恰好」清了 · 下班顺路接他 |
| 暴露风险 | 同事一句「脸色不太对啊」 · 月月固定的「肠胃炎」请假记录 |

这一条和镜像那条差在暴露的风险上：她的周期不必瞒着谁，他的得瞒。

| 轴 | 一端 | 另一端 |

| 他的态度 | 照样扛着，一天不休 | 第一次松口给自己请假，这对他是件大事 |

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她终于懂了他当初为什么不问就去做 | 被人照顾，比疼还叫人别扭 |
| 内心 | 原来往后退比往前进还难 | 这些天他一向是关起门自己过 |
| 好的处理 | 她帮了，没让他知道 | 他受了，没说破 |
| 写崩 | 大张旗鼓守着 | 写成病秧子 |

#### 写崩的三种方式

1. 写成病弱。 周期是正常的生理现象，他平常该做什么照样做。可以写他狼狈，只是别过头。
2. 到处声张。 照顾一嚷嚷就变了味，那几天他最怕的就是被人注意。
3. 写成生理奇观。 疼是主要的，生理细节只是陪衬。两者的笔墨一颠倒，就成了展览。

## 八 · 能不能有孩子

`T` ｜ ⚠️双性 ⚠️生子（议题层，不写孕程） ｜ 全谱系 ｜ 接口条（对 40 卷）

**骨架**｜「能不能」头一次被说出来。这场谈话里，问题本身比答案要紧。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 起因：医院问了句“要孩子吗”、亲戚催促、她随口说笑 |
| 2 | 当场两人都没接，场面冷了一下 |
| 3 | 各自想了几天，谁都没提起 |
| 4 | 由谁先开口，这一选择本身就在塑造人物 |
| 5 | 把三个问题摆开来谈（见可用细节） |
| 6 | 聊不出结果，就说“先这样吧” |

#### 设定分叉

| 设定 | 议题变成什么 |
|---|---|
| 可孕 | 生不生、和谁生、生下来算谁的，都要重新商量 |
| 不可孕／未知 | 要不要查？一查就有答案，有了答案就要面对 |
| 女尊／双儿世界观 | 这个世道早就给能生育的男子定过价，说话时处处带着那层规矩（见[02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)） |

生育机制直接按 [02-GB-ABO设定设计手册 §2.14](../03-世界观设定/02-GB-ABO设定设计手册.md) 写。手册把「怀孕即退场」算作 ABO 长篇最大的结构问题，这里先把基础打牢，后面就不会写崩。

#### 可用细节

| 类 | 内容 |
|---|---|
| 三个问题的拆法 | 能不能：医学上的事，有答案 · 想不想：各自的事，答案可以不同 · 要不要：两人的事，要商量 |
| 谈话的地形 | 深夜的厨房 · 车里并排坐，不用对视，好开口 · 从医院回来的路上 |
| 顺序之争 | 「先查了再说」和「先想好再查」两派，两人各站一边 |
| 词的重量 | 「能」字在他这里向来沉甸甸的，到她嘴里只是随口一问 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 答案 | 能生 | 不能生／懒得查 |
| 更想要的人 | 她 | 他，少见，也更值得写 |
| 触发 | 外部施压（催） | 出于好奇，玩笑里露出真心 |
| 后续 | 放着好几年不理 | 转入 [40-孕产与哺育](40-孕产与哺育.md) |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她忽然发现自己一直默认孩子该由她来生 | 「能」字落下来的时候，他最先想到医院的走廊 |
| 内心 | 旧观念翻了，要重新想清楚自己到底怎么想 | 可能性长在自己身上，选择权却悬在半空 |
| 好的处理 | 她把「想不想」和「要不要」拆开谈 | 他说「我不知道」，没有人因此怪他 |
| 写崩 | 一个人替两个人做了决定 | 写成他一个人把自己赔进去 |

#### 写崩的三种方式

1. 一场戏谈完。 这么大的事一场戏收不住，硬收了读者也不信，这里不能省事。
2. 写成功能。 把能怀孕写成礼物或者用处，他就从人变成了生育工具。这种写崩还裹着甜文的外皮，排雷段拦不下来。
3. 拿孩子验证感情。 用生孩子来证明感情，孩子就成了感情的验资报告，这种写法最容易翻车。

## 九 · 亲密的重新发明

`M` ｜ ⚠️双性 ⚠️亲密接触 ｜ 全谱系 ｜ 结构条（过程走 06 卷）

**骨架**｜设定让默认的剧本作废，两人要自己重新商量。这一条只给框架。

#### 只给结构的意思

这里写「他们怎么商量」，商量一开始就停笔。过程交给 [06-尺度与写法](../06-尺度与写法/)，分级镜头和协商框架那边都有。这一条只写到门口。

圈内讨论过 pegging 的快感缺口（[01-核心身份与权力动态](../02-术语百科/01-核心身份与权力动态.md) 词条创作提示），这里就是对应的戏。设定补上了生理那一层，脚本那一层补不了，还得两个人自己写。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 默认的套路失灵了：到了某一步，两人都不知道该谁先动 |
| 2 | 头一回认真谈：什么能碰、什么不行、什么想试 |
| 3 | 叫法：他那里用什么词来说（见可用细节） |
| 4 | 约好中途喊停的暗号：一个词或一个动作 |
| 5 | 结束后照例聊十分钟，一次不落 |
| 6 | 新套路用顺了，也随时可以改 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 协商的载体 | 关了灯躺着聊 · 玩笑里夹着试探 · 完事之后那句「刚才那个……」 |
| 词汇三档 | 医学用语：稳妥，但生分 · 圈内俗称：现成，可带着别人的眼光 · 自己造的词：只有两人懂，造词那晚就是一场戏 |
| 校准机制 | 说好的「停」字 · 捏两下手 · 先问再碰的清单 |
| 权力语法 | 她主导的方式从「做什么」变成「先问什么」：**问本身就是主导** |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谈的方式 | 认真谈过一次 | 一边试一边改，从没坐下来谈过 |
| 起草人 | 她定框架，他填内容 | 他先起草，她来改 |
| 设定的位置 | 两人之间头等要紧的事 | 众多选项里的一个，可有可无 |
| 同意的粒度 | 一次全定 | 一回说一点 |

写「可有可无」这一端时记着：有设定不等于非用不可，不用的夜晚也算数。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她先开口问的那一下 | 头一回有人问他「你想怎样」，他发觉自己从没想过 |
| 内心 | 开口问比下命令难 | 答不出来的难堪，和被人当回事的震动 |
| 好的处理 | 她搭框架，他填内容 | 他说「不知道」被接住了，下次就带着答案来 |
| 写崩 | 写成一方给的使用说明 | 写成要什么给什么 |

#### 写崩的三种方式

1. 设定只活在床上。 亲密时出现、日常里消失，这样不行。身体不会下班，另外九条写的都是这件事。
2. 写成说明书。 商量是活的对话，画成流程图就死了。流程图 06 卷已经有，用不着叙事来充当。
3. 换汤不换药。 旧的默认换成新的默认，中间一句没谈，重新发明这四个字就成了空话。

## 十 · 就是身体而已

`T` ｜ ⚠️双性 ｜ 全谱系 ｜ 收束条

**骨架**｜设定成了日常的那天平平无奇，连他自己都没察觉。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 平常的一个晚上，不逢什么日子 |
| 2 | 到了从前非得处理点什么的钟点 |
| 3 | 他管了，或没管，都没当回事 |
| 4 | 回过神来：刚才那阵熟悉的别扭没来 |
| 5 | 记不起是从哪天开始这样的 |
| 6 | 没提，或者提了，她说「早看出来了」 |

#### 时间轴

第 5 拍他记不起是哪天变的，因为根本没有这么一天。病历本从夹层挪进抽屉，洗澡开大灯开了多久，借口库多久没添新的，这些变化都没有日期，找不到一个时间点。

#### 可用细节

| 类 | 内容 |
|---|---|
| 从前的触发点 | 她看了他一眼 · 体检短信 · 朋友的一句玩笑 · 换衣服时转过身去 |
| 负证据 | 「怕水」写了三年没用上 · 大灯 · 病历本放哪儿 · 「那里」这词不说了 |
| 台词的减法 | 能直呼名字就直呼，不然就索性不称呼 |
| 她那边 | 什么时候松下来的她心里有数，只是不讲 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 发现者 | 他本人 | 她先察觉，等他自己回过味 |
| 说破 | 不说 | 说了，两人都不当回事 |
| 参照 | 和 [一](#一--他和他的身体) 的开头对上，首尾呼应 | 自成一段 |
| 时点 | 同居好几年以后 | 说不清，总之是某个周二 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看到灯亮着，继续剪她的指甲 | 回过神的那一刻 |
| 内心 | 攒了多年的耐心，这回派上了用场 | 心里一空，又像被填满 |
| 好的处理 | 不庆祝，也不提从前 | 想不起从哪天开始，也就不去想 |
| 写崩 | 颁奖典礼 | 表白宣言 |

#### 写崩的三种方式

1. 开发布会。 「我终于接受自己了」一说出口，这事就不成立了。

2. 写成忘掉了。 共处跟假装看不见是两回事：该处理的照样处理，只是不难受了。

3. 收尾收早了。 前九条铺得不够，这一条就站不住。

#### 示例（本库自撰，可直接改写）

> 周二晚上，他洗完澡出来，头发滴着水，身后浴室的灯还亮着。大灯。
> 她坐在床上剪指甲，抬头看了一眼，没说话。
> 很多年前他洗澡只开镜前那盏小灯，说是省电。她配合着信了很多年。
> 他关灯上床，动作停了半拍，像想起了什么，又想不起来是什么。
> 「怎么了？」
> 「没事。」他说。这回是真的没事。
