## 这一族收什么

双性在藏书里实测 432 篇（[亚型分布报告 §六](../10-藏书索引/亚型分布报告.md)，关键词口径，作者标了才算，是下限），同时是排雷段的单词第 2 高频：46 次，仅次于「虐」的 51 次（[05-预警与分级实操 §5.2](../06-尺度与写法/05-预警与分级实操.md)）。写的人多，排的人也多，所以卷首那行预警不许后置、不许夹在文案中段。

严格四爱按身体写实性规则不认这个设定（[01-总论 3.2 规则二](../01-总论/01-概念源流与圈史.md)）；语料里它照样大量流通，因为它补上了 pegging（女方进入的核心行为，[术语卷词条](../02-术语百科/01-核心身份与权力动态.md)）场景里女方生理快感缺失的技术缺口，这道取舍在圈内自我批评里被点过名（同卷 pegging 词条创作提示）。边界之争归术语卷管，这里只管一件事：设定既然长在他身上，就得跟他一起过日子。此前 L3 层对它零收录，这十条补的是床以外的那部分。

相邻设定不可混用（详辨见 [05-易混淆词辨析](../02-术语百科/05-易混淆词辨析.md)）：

| 设定 | 一句话 | 层级 |
|---|---|---|
| 双性 | 两性生理特征并存 | 个体设定（[词条](../02-术语百科/01-核心身份与权力动态.md)） |
| 双儿 | 外观男性、可生育 | 个体设定，耽美种田文源（[词条](../02-术语百科/02-女尊称谓与礼制体系.md)） |
| 女尊男子生子 | 全体男性可育 | 世界观设定（同上卷） |
| 女A男O | 生育由第二性别赋予 | 制度设定（[设计手册](../03-世界观设定/02-GB-ABO设定设计手册.md)） |

边界四条：

| 边界 | 说明 |
|---|---|
| 只写日常 | 身体自处、制度接口、关系议题；过程与描写全部走 [06-尺度与写法](../06-尺度与写法/)，分级上限 `M` |
| 全员成年 | 十条中的所有角色均为成年人 |
| tag 前置 | ⚠️双性 放在文案与排雷段最前，配合五行制排雷（[05-预警与分级实操](../06-尺度与写法/05-预警与分级实操.md)） |
| 他自认男性 | 十条中的「他」均自认男性；平台按主角自我性别认知分频道，认知存疑的归多元向，不在这十条的射程内 |

## 一 · 他和他的身体

`T` ｜ ⚠️双性 ｜ 全谱系 ｜ 语料底数：双性 432 篇（卷首口径）

**骨架**｜设定交代场：他和这具身体已经过了二十几年，开场的口吻替全书定温度。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 一个触发物出现（体检通知、旧病历、一句玩笑） |
| 2 | 闪回：家里当年怎么处理的（就医、搬家，或当平常事养大） |
| 3 | 他懂事的那一年：第一次明白这件事要管理 |
| 4 | 现在的管理系统亮相（衣着、借口、藏的位置） |
| 5 | 回到当下，触发物被处理掉 |
| 6 | 一句定调的话（对读者交底，未必对任何人说出口） |

#### 时间轴

关系史以年计，交代以一场戏计。二十几年压进一个闪回，压缩比越高越像日常；摊开写，就成了病历陈述。

#### 可用细节

| 类 | 内容 |
|---|---|
| 管理系统 | 自己挑了很多年的内衣款式 · 洗漱包单独放 · 病历本藏的位置 · 学生时代的长期病假条 |
| 家史两版 | 秘密版：转学、换医生、母亲的一句「别跟人说」 · 平常版：家里从没当回事，他到了学校才学会藏 |
| 口吻两档 | 羞耻档：闪回里全是关门声 · 平常档：闪回里有饭桌，有人笑 |
| 定调句 | 「习惯了」三个字，两个读法：认命的，或真的习惯了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 家里怎么养 | 当秘密养 | 当平常事养 |
| 他的自我叙述 | 「这是要管的事」 | 「这就是我」 |
| 就医史 | 有长期随访的医生 | 从没让医生看过 |
| 知道的人 | 只有母亲 | 一个都没有 |

「当平常事养」不等于没戏：家里越平常，学校与社会那一面的落差越大，戏在门槛上。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 进入点 | 她还不知道，读者先知道（信息差留给第二条用） | 第一人称平铺，像介绍一个旧室友 |
| 情绪 | 无（她尚未在场） | 克制，不悲情 |
| 好的处理 | 用她的日常反衬他的管理动作 | 管理写成熟练，熟练里见年头 |
| 写崩 | 让她提前偷看出来 | 开场三段自怜独白 |

#### 写崩的三种方式

1. 开场悲情独白。 二十年都过下来了，他此刻的常态是熟练，情绪要留给后面的条目挣。
2. 身体清单式描写。 交代设定一句就够，逐项展览是把人写成标本。
3. 交代太晚。 读者按错误预期投入的感情，揭晓时会变成被骗感，这个设定尤其赔不起。

后接：[二 · 被知道的那天](#二--被知道的那天) · [五 · 他讨厌它的那几年](#五--他讨厌它的那几年)
远端：[41-他的身体与年岁](41-他的身体与年岁.md)（身体线的年岁版）
对照：[十 · 就是身体而已](#十--就是身体而已)（全卷首尾相合的另一端）

## 二 · 被知道的那天

`T` ｜ ⚠️双性 ｜ 全谱系 ｜ 设定必需条（拿掉设定即不成立）

**骨架**｜她知道了。怎么知道的，决定了两个人后面各站在哪。

#### 三种知道法

| 方式 | 主动权 | 留给后续的东西 |
|---|---|---|
| 他说 | 在他：时机、措辞、地点都是他挑的 | 最平等的起点，她拿到的信息带着他的信任 |
| 体检／就医 | 在制度：单子先于他开口 | 她要多消化一层「他没打算现在告诉我」 |
| 意外（受伤送医、撞见） | 谁都没有 | 最烈，两个人都没排练过，第一反应全是真的 |

第三种慎用：它省掉了他的挣扎，也就省掉了这条一半的分量。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 临界点逼近（同居在即、体检单据、一次就医） |
| 2 | 他的最后一晚：排练措辞，或来不及排练 |
| 3 | 说出口／被看见的那一刻，越短越好 |
| 4 | 她的第一眼：看他的脸，还是看那张单子 |
| 5 | 沉默，长度由作者定，读者在这里屏息 |
| 6 | 她的第一句话 |
| 7 | 当晚剩下的时间照常过完（这一拍最常被漏掉） |

#### 可用细节

| 类 | 内容 |
|---|---|
| 他说的版本 | 对折又对折的检查单 · 排练过的长版本没用上 · 「有件事」三个字开场 |
| 体检的版本 | 医生的电话打到她手机 · 报告单上的科室名 · 他在诊室外攥着单子 |
| 她的第一句话分档 | 「哦」（收下了）· 「疼吗」（先问人）· 「吃饭了没」（把今天还给日常）· 追问细节（最险的一档） |
| 第 7 拍 | 洗碗、遛狗、各自洗漱：日常照常运转，本身就是回答 |

**她的第一句话是全条的秤。** 读者按这一句判断她这个人，作者按这一句定全书的调。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 方式 | 他说 | 体检／意外 |
| 时间点 | 确定关系之前（他给她留退路） | 同居之后（他赌不起了） |
| 她的消化 | 当场消化完 | 出门走了一圈才回来 |
| 他等的东西 | 她的表态 | 她别表态，照常就好 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她意识到这句话他练了多少遍 | 说完之后那几秒的失重 |
| 内心 | 先接住人，再消化事 | 退路清单在脑子里备好了 |
| 好的处理 | 她的反应比他排练过的所有版本都平 | 他发现自己竟有点失望，太平静也像不在乎 |
| 写崩 | 猎奇追问 | 写成跪着请罪 |

「他有点失望」这一笔别漏：盼了半辈子的「没关系」，真听到了反而空。

#### 写崩的三种方式

1. 她当场表演大度。 宣言式的接纳是说给读者听的，把日常过下去才是说给他听的。
2. 把坦白写成审判现场。 他没做错事，这个场面里没有被告席。
3. 当晚就进卧室。 用身体接纳收场是最省事也最假的一版，日常的接纳要用日常证明。

#### 可串接

前接：[一 · 他和他的身体](#一--他和他的身体)
后接：[六 · 她学着了解](#六--她学着了解) · [三 · 医院这一关](#三--医院这一关)
同族：[15-秘密与坦白 · 坦白的那一夜](15-秘密与坦白.md#六--坦白的那一夜)（通用版骨架在那边）

#### 示例（本库自撰，可直接改写）

> 「有件事。」他说。
> 水壶正响。她关了火，回头。他站在离沙发一步远的地方，手里捏着一张对折又对折的检查单。
> 他准备了很长的版本，带解释，带退路，带一句替她想好的「没关系」。真正说出口的只有四十几个字。
> 她听完，看了他几秒。「哦。」她说，「饭还没好，你先把汤端出去。」
> 他端着汤在餐桌边站了一会儿，才明白这就是她的回答。

## 三 · 医院这一关

`T` ｜ ⚠️双性 ｜ 现代都市（换皮见条内） ｜ 设定必需条

**骨架**｜挂号系统里没有他这个选项，制度的钝感要两个人一起扛。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 去医院的理由出现（周期紊乱、体检要求、生育检查） |
| 2 | 挂哪个科：两个人对着挂号页面研究半天 |
| 3 | 表格：性别栏两个格子，笔尖停住 |
| 4 | 候诊区：叫号屏念全名，他起身那一秒 |
| 5 | 诊室：门口贴着「一次只进一位」，她进不进 |
| 6 | 医生的措辞（好坏两版，见可用细节） |
| 7 | 出来之后：缴费单、停车场、两个人说的第一句话 |

#### 时间轴

医院的时间以叫号计。候诊的四十分钟长过诊室里的四分钟，戏也按这个比例分。

#### 可用细节

| 类 | 内容 |
|---|---|
| 制度接口 | 性别栏二选一 · 系统按性别拦掉某些检查项目 · 缴费单上的科室名他捏着不想给人看见 |
| 医生措辞：钝感版 | 「这个情况很少见啊」（他成了病例）· 当着他的面翻书 · 叫同事「来看一下」 |
| 医生措辞：像样版 | 「平时有什么不舒服」（他还是病人）· 只谈功能，不谈稀奇 |
| 她的动作 | 表格上替他把勾打了 · 诊室门口那步「我进去陪他」 · 医生要叫同事时她开口拦了 |

钝感与恶意两回事：这条的对手方是流程，流程没有脸，怒气找不到落点，这份找不到落点就是医院戏独有的质感。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她在不在 | 全程陪诊 | 他一个人去，回家才说 |
| 医生 | 第一次见这种情况的年轻医生 | 见过的老医生，语气平常 |
| 结果 | 常规随访，无事 | 查出要处理的事（接 [八](#八--能不能有孩子)） |
| 他的状态 | 熟练，流程都背下来了 | 第一次正经就诊，拖了十年 |

「他一个人去」这一端配一个回家后的镜头：单子折在外套内袋，她洗衣服时摸到。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 替他打勾那一下笔尖的重量 | 叫号屏念出全名那一秒 |
| 内心 | 她第一次亲眼看制度怎么对他 | 这些流程他一个人走了多少年 |
| 好的处理 | 她不闹，事后去填了意见表 | 他在停车场说「其实还好」，说完自己也信了一半 |
| 写崩 | 当场维权爽文 | 写成全程受辱 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 府医只对主母回话 · 医案上怎么落笔 · 抓药伙计多看的那一眼 |
| 修仙 | 灵脉图谱上多出来的一条 · 医修的措辞 · 宗门大比前的查验 |
| 星际 | 基因档案的分类字段 · 医疗舱弹出的「数据异常」 · 舰医的保密义务 |

#### 写崩的三种方式

1. 医生写成恶役。 制度戏的张力在钝感，换成恶意就成了打反派，降级了。
2. 她当场掀桌。 爽一秒，但把「流程没有脸」这个真问题让渡给了一个假靶子。
3. 借检查写身体。 就诊场面拿来展览身体，是奇观化的标准走法，全条尽毁。

## 四 · 更衣室与澡堂

`T` ｜ ⚠️双性 ｜ 现代都市 ｜ 设定必需条

**骨架**｜公共身体空间是他排练了半辈子的题，这一次她在场。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 邀约出现：公司团建的温泉、健身房年卡、朋友约游泳 |
| 2 | 借口库启动（他的既有预案，见可用细节） |
| 3 | 这次预案失效：领导点名，或她也在受邀名单里 |
| 4 | 执行：错峰、单间，或到场但不下水 |
| 5 | 有人多问一句，空气停半拍 |
| 6 | 收尾：她在场版她递台阶，不在场版他自己收 |

#### 时间轴

预案以年计，执行以分钟计。借口说出口那两秒的流畅度，是十几年练出来的；流畅本身让他难受。

#### 可用细节

| 类 | 内容 |
|---|---|
| 借口库 | 「皮肤过敏」「有纹身不方便」「怕水」「那天加班」，按对象轮换，同一个人不用第二次 |
| 错峰技术 | 最早到或最晚走 · 挑带门的淋浴隔间 · 更衣柜选最角落 · 掐着人流低谷进出 |
| 她的台阶 | 「订了家庭池」 · 「他陪我，不去男汤」 · 提前三个月替他铺垫「怕水」的人设 |
| 物件 | 长袖泳衣 · 浴巾的系法 · 更衣柜钥匙圈攥在手心的印子 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她在不在 | 在：她能造掩护 | 不在：他独自应付，回家讲成笑话 |
| 场合强度 | 可推的私人局 | 难推的团建（推了比去了更显眼） |
| 他的心态 | 例行公事，心跳不加速 | 临场的一次，预案是现编的 |
| 起疑的人 | 没有 | 有一个，多问了一句就没再问 |

「回家讲成笑话」这一端别小看：他把惊险说成段子，她笑完之后半天没说话。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她第一次旁观整套流程跑完 | 借口出口时的那份流畅 |
| 内心 | 这套东西他练了多少年 | 每一次都过关，每一次都在交税 |
| 好的处理 | 掩护做得比他还自然，事后谁都不提 | 他谢她，用的是别的名目 |
| 写崩 | 大包大揽替他挡一切 | 写成惊险谍战 |

#### 写崩的三种方式

1. 悬疑化。 千钧一发是掉马戏（身份暴露戏，[15-秘密与坦白 · 掉马](15-秘密与坦白.md#二--掉马)）的写法；这条是日常，日常的税是钝的。
2. 真让他被撞见。 撞见之后走的族不同，预警等级也不同，别在这条里引爆。
3. 她的掩护抢戏。 掩护做到十成是剥夺：这套流程他熟练了半辈子，轮不到别人代劳十成。

## 五 · 他讨厌它的那几年

`T` ｜ ⚠️双性 ｜ 全谱系 ｜ 长线暗线条

**骨架**｜他恨过这具身体很多年；她改不了身体，她的态度是杠杆。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 最恨的年纪：青春期，身体自作主张的那几年 |
| 2 | 成年后的休战：不看、不碰、不提，相安无事 |
| 3 | 她进入生活，休战协议开始被打扰 |
| 4 | 一次复发：某个诱因让旧账翻上来 |
| 5 | 她的态度第一次称出重量（做的，别是说的） |
| 6 | 共处的开始：恨意降档成偶尔的别扭 |

#### 时间轴

这条以年计，散布全书。第 4 拍的复发可以来多次，每次诱因不同、恢复更快；恢复速度就是这条线的进度条。

#### 可用细节

| 类 | 内容 |
|---|---|
| 遮蔽的层级 | 不照全身镜 → 洗澡只开镜前小灯 → 不让她看 → 「别碰那里」 |
| 复发诱因 | 医院那趟 · 一句无心的玩笑 · 周期紊乱的一周 · 一条猎奇向的新闻 |
| 她的无效动作 | 「有什么好讨厌的」 · 讲道理 · 夸（夸也是一种盯着看） |
| 她的有效动作 | 对他身体的日常反应零变化：手没停过一下，灯照旧关，玩笑照旧开 |

**「零变化」是杠杆的支点：** 他盯着她找反应，找了很多年，一无所获，恨意没了对手。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 强度 | 钝的底噪 | 有急性发作期 |
| 他的表达 | 说出来过一次 | 全在动作里，一个字没说过 |
| 她的杠杆 | 一句话（风险高） | 十年如一日的没反应（慢，稳） |
| 跨度 | 几个月收线 | 贯穿全书的暗线 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他洗澡从不开大灯 | 「讨厌」的内容他一次也没说全过 |
| 内心 | 不追问，把发现存着 | 恨的对象有时是身体，有时是要藏它的自己 |
| 好的处理 | 她的日常纹丝不动 | 某天他自己开了大灯，没通知任何人 |
| 写崩 | 一番话治愈他 | 自怜循环，十章原地踏步 |

#### 写崩的三种方式

1. 演讲解药。 焦虑没有一次性疗法，一段话就治好的恨意，说明恨得不认真。
2. 原地打转。 复发可以多次，但每次要有落差，一样的低谷写三遍是注水。
3. 对象滑移。 讨厌身体写着写着变成讨厌自己，那是另一种病，得另开一条线治。

## 六 · 她学着了解

`T` ｜ ⚠️双性 ｜ 全谱系 ｜ 设定必需条

**骨架**｜她开始做功课；好奇与冒犯之间，隔着一个问法。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 她意识到自己不懂（一次没接住的话头） |
| 2 | 私下查：搜索框里打了又删 |
| 3 | 第一问出口，问法选错了 |
| 4 | 他的反应替她校准（冷了半拍，或直接一句「别研究我」） |
| 5 | 她改了问法，把边界还给他 |
| 6 | 照顾落到实处，不宣布 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 功课痕迹 | 忘了开无痕的浏览记录 · 购物车里加了又删的书 · 问学医的朋友时用「我一个朋友」开头 |
| 冒犯的问法 | 「那你是不是也能……」（他成了标本）· 连问三个（问出了门诊问诊感） |
| 可以的问法 | 「想让我知道多少」（额度他定）· 「这个我该注意什么」（问的是用途，答的是照顾） |
| 落地 | 药挪到他顺手那格 · 周期表她记了一份（接 [七](#七--他的周期)）· 挂哪科她提前查好（接 [三](#三--医院这一关)） |

问法的判据一句话：答案归他管的，问；答案归好奇心管的，忍。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 功课路线 | 问他本人 | 绕开他查，查完装不知道 |
| 他的接受度 | 愿意讲，讲着讲着松了 | 「别研究我」，边界立得很硬 |
| 动机被误读 | 没有 | 有一次被读成猎奇，要修复 |
| 边界的划法 | 他划，她守 | 她主动留白，他慢慢往外让 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 搜索框里那句打了又删的问题 | 发现她也记着周期表的那天 |
| 内心 | 想知道，与该不该问，两股在拧 | 被研究的刺感，与被上心的暖，也在拧 |
| 好的处理 | 问额度：「想让我知道多少」 | 他把额度一点点调大，每次只调一点 |
| 写崩 | 问成审讯 | 一问就恼，恼十次（读者会先累） |

#### 写崩的三种方式

1. 审讯式。 问题连发，他成了答辩人，了解这件事就此变味。
2. 一夜专家。 功课要时间，也要犯错，跳过错误的了解不可信。
3. 成果宣读。 功课做完当面汇报，照顾就变成了考试答卷；功课的正确形态是落在药盒和日程里。

## 七 · 他的周期

`T` ｜ ⚠️双性 ｜ 全谱系 ｜ 镜像条（对 17 卷第六条）

**骨架**｜周期落在他身上，照料方向反了过来，这回轮到她学分寸。

#### 与「她的生理期」互为镜像

[17-同居与身体日常 · 她的生理期](17-同居与身体日常.md#六--她的生理期)的判据在这里原样适用，方向对调：那条里他练的分寸（不问只做、别当病人待），现在轮到她练；那条里她的「我没事」，现在从他嘴里说出来。两条对照着写，照料在这对关系里就闭了环。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 前兆：他话变少，预案启动（药挪进外套口袋） |
| 2 | 照常上班，硬扛；这几天他从小是一个人过的 |
| 3 | 她看出来了（脸色，或她记的那份周期表） |
| 4 | 她的第一版反应过了火：打电话替他请假、当面宣布安排 |
| 5 | 校准：收回到不问只做 |
| 6 | 他发现她也记着日子，愣了一下 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的预案 | 借口存货 · 提前调开的会 · 工位抽屉最里层的药 · 深色裤子的那几天 |
| 她的过火版 | 替他请假 · 「今天别去了」当着他的面定 · 保温杯塞进他包里让同事看见 |
| 她的合适版 | 家里先调暖两度 · 汤在保温壶里，不说 · 日程「恰好」清了 · 下班顺路接他 |
| 暴露风险 | 同事一句「脸色不太对啊」 · 月月固定的「肠胃炎」请假记录 |

暴露风险是这条与镜像条的不对称处：她的周期不用瞒人，他的要。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的态度 | 照常扛，一天不歇 | 第一次允许自己请假（大事件） |
| 她的分寸 | 一次到位 | 先过火再收（更真） |
| 场合 | 都在家 | 工作日，全靠远程动作 |
| 周期本身 | 规律，可预案 | 紊乱（接 [三 · 医院这一关](#三--医院这一关)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她终于懂了当年他为什么不问只做 | 被照顾的不习惯，比疼显眼 |
| 内心 | 原来退后一步比上前一步难 | 这几天向来是关起门自己过的 |
| 好的处理 | 她的照顾全部匿名 | 他收下了，方式是没拆穿 |
| 写崩 | 大张旗鼓的看护 | 病弱化 |

#### 写崩的三种方式

1. 病弱化。 周期是常态生理，他照旧是能干的成年人，狼狈要写得有限度。
2. 声张。 照顾一声张就变成展示，他的这几天最怕的就是被看见。
3. 生理奇观。 疼是内容，生理细节是背景，两者的笔墨比例倒过来就成了展览。

## 八 · 能不能有孩子

`T` ｜ ⚠️双性 ⚠️生子（议题层，不写孕程） ｜ 全谱系 ｜ 接口条（对 40 卷）

**骨架**｜「能不能」第一次被说出口；这场谈话里问题比答案重。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 触发：医院的一句「有生育需求吗」、亲戚的催、她的一句玩笑 |
| 2 | 当场都没接住，话头掉在地上 |
| 3 | 各自想了几天，谁都没提 |
| 4 | 谁先重新开口（这个「谁」本身是人物设计） |
| 5 | 把三个问题拆开谈（见可用细节） |
| 6 | 没有结论的结论：「这次先谈到这里」 |

#### 设定分叉

| 设定 | 议题变成什么 |
|---|---|
| 可孕 | 「用不用这个可能性」，外加默认脚本被掀翻：孩子未必等于她生 |
| 不可孕／未知 | 「要不要去查」：查了就有答案，有答案就得面对 |
| 女尊／双儿世界观 | 制度给可孕男性定过价，谈话多一层制度回声（[02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)） |

生育机制的设计参照 [02-GB-ABO设定设计手册 §2.14](../03-世界观设定/02-GB-ABO设定设计手册.md)：那边把「怀孕即退场」列为 ABO 长篇最大的结构问题，这条接口先替后续打好地基。

#### 可用细节

| 类 | 内容 |
|---|---|
| 三个问题的拆法 | 能不能：医学问题，有答案 · 想不想：各自的问题，答案可以不同 · 要不要：两个人的问题，要谈 |
| 谈话的地形 | 深夜厨房 · 车里（并排不对视，好开口）· 医院回来的路上 |
| 顺序之争 | 「先查了再说」派与「先想好再查」派，两人可以各属一派 |
| 词的重量 | 「能」这个字在他身上向来带着管理成本，在她口中只是个疑问词 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 答案 | 可孕 | 不可孕／不去查 |
| 更想要的人 | 她 | 他（更少见，更值得写） |
| 触发 | 外部压力（催） | 内部好奇（玩笑说漏了真心） |
| 后续 | 就此搁置数年 | 进入 [40-孕产与哺育](40-孕产与哺育.md) |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她惊觉自己默认过「孩子等于我生」 | 「能」字砸下来时他先想到的是医院走廊 |
| 内心 | 默认被掀翻之后，得重新想想想不想 | 可能性长在自己身上，选择权却像悬在半空 |
| 好的处理 | 她把「想不想」和「要不要」分开说 | 他说「我不知道」，而这被允许 |
| 写崩 | 替两个人做了决定 | 写成他单方面的献祭 |

#### 写崩的三种方式

1. 一场谈完。 这个量级的议题一场戏收不了，收了读者也不信。
2. 功能化。 可孕写成礼物或用途，他就从人降成了育具；这种崩法披着甜文的皮，排雷段拦不住它。
3. 验资式。 用生个孩子证明感情，孩子成了感情的审计报告。

## 九 · 亲密的重新发明

`M` ｜ ⚠️双性 ⚠️亲密接触 ｜ 全谱系 ｜ 结构条（过程走 06 卷）

**骨架**｜设定把默认脚本作废了，两个人得自己重新谈一份；本条只给结构。

#### 只给结构的意思

写的对象是「他们怎么商量」，白描到商量为止。任何过程描写走 [06-尺度与写法](../06-尺度与写法/)，那边有分级镜头控制与完整的协商框架；本条停在门口。

pegging 快感缺口的圈内讨论（[01-核心身份与权力动态](../02-术语百科/01-核心身份与权力动态.md) 词条创作提示）在这里有了对应的戏：设定补上了生理层，但补不了脚本层，脚本还得两个人自己写。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 发现默认脚本失效：进行到某一步，谁都不知道下一步该谁动 |
| 2 | 第一次正经谈：什么可以、什么不行、什么想试 |
| 3 | 词汇问题：他的身体用什么词指称（见可用细节） |
| 4 | 立中途校准机制：一个词，或一个动作 |
| 5 | 事后复盘成为习惯，每次十分钟 |
| 6 | 新脚本跑顺，且保留改版权 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 协商的载体 | 深夜关灯后的对话 · 玩笑里夹的试探 · 事后那句「刚才那个……」 |
| 词汇三档 | 医学词：安全但冷 · 圈内俗称：现成，但带着别人的目光 · 自造词：只有两个人懂（造出来的那晚是一场戏） |
| 校准机制 | 约定的「停」字 · 捏两下手 · 先问后碰的区域清单 |
| 权力语法 | 她的主导从「做什么」改写成「先问什么」：**问也是主导的形态** |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谈的方式 | 正式谈过一次 | 试错里长出来，从没开过会 |
| 起草人 | 她定框架他填空 | 他起草她批注 |
| 设定的位置 | 亲密的中心 | 众多选项之一，可用可不用 |
| 同意的粒度 | 一揽子 | 逐次确认 |

「可用可不用」这一端值得多看一眼：设定不等于义务，不用它的那些夜晚同样算数。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 主导的新定义：她先开口问的那一刻 | 第一次有人问「你想怎样」，他发现自己没想过 |
| 内心 | 问出口比下命令难 | 答不上来的羞窘，和被当回事的震动 |
| 好的处理 | 框架她搭，内容他填 | 他的「不知道」被接住，下次他带着答案来 |
| 写崩 | 写成单方面的使用说明 | 写成有求必应 |

#### 写崩的三种方式

1. 只在床上存在。 设定只在亲密场景上线、日常里消失：身体不下班，其余九条全在证明这一点。
2. 写成说明书。 协商是活的对话，写成流程图就死了；流程图那一层 06 卷有，轮不到叙事来当。
3. 换汤不换药。 旧默认换成新默认，中间没有谈；谈被跳过，重新发明四个字就成了空话。

## 十 · 就是身体而已

`T` ｜ ⚠️双性 ｜ 全谱系 ｜ 收束条

**骨架**｜设定褪成日常的那一天，没有仪式，他自己都是后知后觉的。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 一个普通的晚上，没有任何纪念意义 |
| 2 | 某个从前必触发管理动作的时刻到来 |
| 3 | 他做了，或没做，都没多想 |
| 4 | 后知后觉：刚才没有那阵熟悉的紧绷 |
| 5 | 回想不起来是从哪天开始的 |
| 6 | 不说；或说了，她答「早发现了」 |

#### 时间轴

变化的证据全是负的：借口库多久没更新了、洗澡的大灯开了多久了、病历本从夹层挪到抽屉多久了。负证据没有日期，所以第 5 拍注定失败，这个失败就是收束的手感。

#### 可用细节

| 类 | 内容 |
|---|---|
| 从前的触发点 | 她的目光扫过 · 体检通知 · 别人的玩笑话 · 换衣服时的背对 |
| 负证据 | 「怕水」人设三年没用过 · 大灯 · 病历本的位置 · 「那里」这个代词退役了 |
| 台词的减法 | 需要指称时用平常的词，或根本不再需要指称 |
| 她那边 | 她其实记得是哪一段时间松下来的，她不说 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 发现者 | 他自己 | 她先发现，等他自己发现 |
| 说破 | 不说 | 说了，两个人都轻轻带过 |
| 参照 | 与 [一](#一--他和他的身体) 的开场状态对照成环 | 单独成立 |
| 时点 | 同居多年后 | 说不清，反正是个周二 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她注意到灯开着，继续剪指甲 | 后知后觉的那一秒 |
| 内心 | 存了很多年的耐心到账了 | 空了一块，又好像满了 |
| 好的处理 | 不庆祝，不复盘 | 想不起开始的日期，就随它去 |
| 写崩 | 颁奖典礼 | 宣言 |

#### 写崩的三种方式

1. 开发布会。 「我终于接受自己了」说出口的瞬间就不成立了，接受不需要通稿。
2. 写成遗忘。 共处与假装不存在两回事：该管理的照旧管理，只是不疼了。
3. 收得太早。 前面九条的分量没攒够，这条就是空头支票，兑现要有存款。
