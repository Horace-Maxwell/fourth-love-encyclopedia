## 一 · 他的易感期

`T` ｜ 无预警 ｜ 女A男O ｜ 语料频次：易感期 20.7%（易感期＋生病、易感期＋留痕高频同现）

**骨架**｜他管不住自己，第一次在她面前彻底失了态。

#### 节拍链

前兆 → 他提前发「别回来」→ 自我隔离 → 她还是回来了 → 她只是坐着 → 潮退 → 清醒后的那场对话

#### 时间轴

前兆来的第一个小时，他趁自己还没失控，给她发了「别回来」。她第二天还是赶了回来，那时最危险的阶段已经过去。中间这段最难写：她不碰他，也不劝，就坐在三步外，坐了一整夜。潮退以后两人才冷静下来，真正清醒的对话在第三天早上，**这个设定里最要紧的事就是那天早上谈的**：下次还要不要她留下。

#### 为什么这条是 ABO 设定的核心价值

在别的设定里，他顺从是自己**选**的。这个设定里有一段时间，他没得选。

顺从由不得他了，这段关系还算不算数？

| 处理 | 说明 |
|---|---|
| 她趁机 | 关系的性质就变了，很难再写回来 |
| 她不碰，只陪着 | 最能证明这段关系 |
| 她按医嘱处理 | 冷静，但可能显得疏离 |
| 他清醒后的态度 | 要写到这一步 |

他清醒后什么态度必须写：他会不会为自己那副样子羞耻，她又怎么对待这份羞耻。

#### 可用细节

| 类 | 内容 |
|---|---|
| 生理表现 | 体温 · 腺体位置（后颈）· 信息素啥味、多浓 |
| 道具 | 抑制剂 · 阻隔贴 · 药 ✓ · 冰袋 ✓ · 毯子 ✓ |
| 他的挣扎 | 咬着不出声 · 把自己关起来 · 提前发消息 ✓ 让她别回来 |
| 她的处理 | 她还是回来了 |
| 清醒后 | 他不敢看她 · 或者他先开口说了 |

让她别回来的那条消息，是他失控前还能自己做主的最后一件事。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她在不在 | 在 | 她被他支开了 |
| 有没有发生什么 | 没有 | 有（走 [三 · 标记](#三--标记)） |
| 他的羞耻 | 很重 | 他接受了 |
| 之后 | 两人说开了 | 谁都不提 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她收到那条「别回来」的消息 | 我不想让她看见我这样 |
| 内心 | 他现在最需要有人在 | 这不是我 |
| 好的处理 | 她回来了，什么都没做，只是坐着 | 他清醒后自己提起了这件事 |
| 写崩 | 写成她趁机 | 写成他的失控是情趣 |

她什么也没做，就坐着。人管不住自己身体的时候，被尊重比被满足更要紧。

#### 安全与边界

| 线 | 说明 |
|---|---|
| 同意 | 光靠身体反应不算数，这点得在文里写明白 |
| 全员成年 | 凡是有亲密戏的角色，一律都是成年人 |
| 不写可复现细节 | 这条只讲关系怎么搭，具体写法见 [06-尺度与写法](../06-尺度与写法/) |
| 事后处理 | 完事之后得让俩人清醒过来说说话，不能直接跳过去 |

**「生理驱动下的同意是脆弱的」这一点必须在文本里被意识到**，否则 ABO 设定会变成免责工具。

#### 写崩的三种方式

1. 拿易感期把「同意」这关糊弄过去。这么写最烂，偏偏最常见。
2. 把他的失控当调情来写。他那时候是真的没了自己。
3. 醒了以后的事全都略过。醒后那场对话一定要写。

后接：[二 · 她的信息素](#二--她的信息素) · [三 · 标记](#三--标记)

## 二 · 她的信息素

`T` ｜ 无预警 ｜ 女A男O ｜ 语料频次：易感期 20.7%

**骨架**｜在这个设定里，她能用自己的味道让他安静下来，这是别处没有的本事。

#### 节拍链

日常收着 → 一次安抚 → 依赖成形 → 一次用它赢了争吵 → 他说「刚才那个别再用」→ 之后她只在必要时用

#### 时间轴

有一次吵架吵到一半，她用信息素压了下去，三十秒的事，他忽然就没声了。这件事她记了一天，第二天才等到他一句「刚才那个别再用」。从那以后她给自己定了规矩：要用之前先看他一眼，再决定用不用，没必要就不用。那张使用记录越往后越稀。平时她把信息素收着，用一次记一笔，一年也就几回，每回几分钟。

#### 信息素作为权力工具

| 用法 | 效果 | 风险 |
|---|---|---|
| 安抚 | 他立刻平静 | 会变成条件反射 |
| 施压 | 他生理性地服从 | 这是强制，要处理 |
| 标记的气味残留 | 宣示 | 见 [05-占有与吃醋 · 留痕](05-占有与吃醋.md#四--留痕) |
| 收敛不放 | 他会不安 | 最微妙的一种 |

她也能收着不放。他闻不到就焦虑，她一冷着他，他身体先难受。

#### 可用细节

| 类 | 内容 |
|---|---|
| 气味 | 具体是啥味（见 [13-语料挖掘/03-设定元素库](../13-语料挖掘/03-设定元素库.md) 里的信息素气味表） |
| 浓度 | 她平时收着 · 她一进门就放开了 |
| 他的反应 | 肩膀松下来 · 呼吸变沉 · 他自己都没发觉 |
| 依赖 | 他睡不着得抱着她一件衣服 ✓ |
| 边界 | 她拿这个压他一回，这步得想好怎么圆 |

她拿信息素赢一次争吵，是碰红线的场面，值得单写一回，写出后果。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她用不用 | 只在必要时候用 | 天天用，离不开 |
| 他的依赖 | 轻，没啥感觉 | 重到脑子都不清醒 |
| 她有没有滥用 | 没有 | 有过一次，后来她挺后悔 |
| 他知不知道被影响 | 没察觉 | 知道，而且心里不太舒服 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现刚才是用信息素让他闭嘴 | 我咋突然就不气了 |
| 内心 | 这算不算耍赖 | 那不是我自个儿的想法 |
| 好的处理 | 她后来没再拿这招压他 | 他直接说「刚才那招别再使了」 |
| 写崩 | 写成她随便拿来用 | 写成他乐意被管着 |

#### 安全与边界

信息素施压说白了就是**不让对方自己拿主意**。写可以写，但文本里得让人看出你心里有数：这招用了要付代价，而且对方得有本事顶回来。

判断标准和 [05-占有与吃醋 · 独占欲的边界](05-占有与吃醋.md#十--独占欲的边界) 那条一样。

#### 写崩的三种方式

1. 把信息素当万能遥控器用。每用一次，都该有这一次的后果。
2. 写他乐于被生理支配。那他就只剩被摆布了。
3. 没想到「他介意」这一层。他也许知道自己被影响了，而且介意。

## 三 · 标记

`M` ｜ ⚠️亲密接触 ｜ 女A男O ｜ 语料频次：易感期 20.7% ＋ 留痕 46.0%

**骨架**｜临时还是永久，是这个设定里最要命的选择。

#### 节拍链

谁提出 → 清醒时的那次确认 → 做或不做 → 气味变化被外界读到 → 制度后果 → 依赖的新形态 → 各自消化

#### 时间轴

从有人提出到正式确认，中间隔了一个月。提出的那晚不算数，这种事不能当场答复。这一个月里两人各自查资料，各自想后果。确认那天两个人都得清醒，话没几句，日子两人都记着。做完以后的事就由不得自己了：三天之内同事闻出了气味的变化，一周之内制度上的后果全部到齐。

#### 两种标记的不对称

| | 临时标记 | 永久标记 |
|---|---|---|
| 可逆 | 是 | 否（多数设定） |
| 谁受影响更大 | 他 | 他 |
| 意义 | 保护／宣示 | 结合 |
| 现实类比 | 同居 | 结婚 |
| 拒绝的余地 | 有 | 几乎没有 |

**「谁受影响更大」两栏都是他**。ABO 设定在这里天生不对等：她动一下，变的是他的身体。写的时候绕不开这一点。

#### 可用细节

| 类 | 内容 |
|---|---|
| 位置 | 后颈 ✓ 腺体 |
| 之前 | 谁先提的 · 处了多久 · 到底谈没谈 |
| 之后 | 他身上有她的味儿 · 外人一闻就知道 |
| 社会层面 | 标记要不要备案 · 法律认不认 |
| 解除 | 能不能洗掉 · 得搭进去什么 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提出 | 她 | 他（他要一个保证） |
| 时机 | 深思熟虑 | 易感期中（同意问题，见下） |
| 类型 | 临时 | 永久 |
| 之后 | 他安心了 | 他发现自己变得更依赖了 |

他拿到了想要的东西，也发现自己比以前更依赖，搭进去的是一部分独立。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她明白这事回不了头 | 我要她标记我 |
| 内心 | 我动的是他的身子 | 这样她就不会走了 |
| 好的处理 | 她趁他清醒问过一回 | 他说清了为啥非要这个 |
| 写崩 | 把占有欲写得像深情 | 写他靠标记找踏实感 |

他想靠标记换安全感，这一头要小心写。这种心情是真的，可文里得点明，标记解决不了问题。

#### 安全与边界

| 线 | 说明 |
|---|---|
| 同意的时点 | 易感期里点头不算数，大事得等人清醒了再定 |
| 不可逆性 | 要让读者觉出这件事没法回头 |
| 全员成年 | 沾性的情节里，角色都是成年人 |
| 不写可复现细节 | 只写俩人啥关系、后来咋样，具体咋写的看 [06-尺度与写法](../06-尺度与写法/) |

#### 写崩的三种方式

1. 在易感期里直接永久标记，也不问对方愿不愿意。这个设定里这样写的太多，快成套路了。
2. 把不可逆写成浪漫。回不了头，首先是负担。
3. 完全不写社会层面。多数设定里，标记是会带来制度后果的。

## 四 · 他要不要用抑制剂

`T` ｜ 无预警 ｜ 女A男O ｜ 语料频次：易感期 20.7%

**骨架**｜能让他不失控的东西，用还是不用，由他决定。

#### 节拍链

工作要求 → 常规剂量 → 偷偷加量 → 副作用露头 → 她数药盒 → 「在家不用打」→ 新的平衡

#### 时间轴

常规剂量他用了半年，一直没出事。后来一个月比一个月多打一支，连着加了三个月。副作用跟着冒出来，手抖和失眠轮番上门。她数药盒只用了十秒，职业病让她对数字敏感，一眼就看出不对。被发现就是那一下的事。当天晚上，「在家不用打」这五个字就开始算数了。之后用量一个季度一个季度往下降，慢慢稳住。

#### 这条是 ABO 设定里最现实的一条

在这个设定里，抑制剂就像现实中那些让身体去迎合社会要求的手段，会遇到的问题也一样：

| 问题 | 说明 |
|---|---|
| 有没有副作用 | 长期使用伤身 |
| 谁在要求他用 | 工作？社会？她？ |
| 他自己想不想用 | 用了他更自由，也更不像自己 |
| 停用之后 | 反弹 |

还得看是谁要他用。要是她让他用的，事情的性质就全变了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 药 ✓ 盒 ✓ · 注射 · 阻隔贴 · 剂量记录 |
| 他的隐瞒 | 剂量偷偷加了，没跟她说 |
| 副作用 | 犯困 · 反应慢 · 晕过一回 |
| 她的发现 | 见 [15-秘密与坦白 · 他有一件事没说](15-秘密与坦白.md#一--他有一件事没说) |
| 落点 | 她来一句「在家就别打了」 |

有了「在家不用打」，他就有了一个不用压着自己的地方。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁要求 | 工作／社会 | 她（要处理） |
| 他的态度 | 主动用 | 抗拒 |
| 剂量 | 正常 | 超量（隐瞒） |
| 结果 | 停了 | 一直在用 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她数了他的药 ✓ 盒 ✓ | 这样才能正常上班 |
| 好的处理 | 她说「在家不用」 | 他承认自己超量了 |
| 写崩 | 写成她要求他用 | 写成他为她牺牲身体 |

#### 写崩的三种方式

1. 她提要求，他照做，文里却不交代。这是控制。
2. 跳过副作用。 代价得写。
3. 写他独自扛着，不写两人商量。他得有自己的理由。

## 五 · 寿元差

`T` ｜ 无预警 ｜ 修仙 ｜ 语料频次：寿元 11.6%

**骨架**｜她的寿数是八百年，他只有六十年。

#### 节拍链

数字摆上桌 → 三种解法议过 → 选定或搁置 → 他的白发第一次出现 → 旁人误认 → 一个平常的饭桌场面

#### 时间轴

八百年对六十年，数字一摆出来，谁心里都要咯噔一下，可之后反倒没人再提。那一晚两人聊了个通宵，渡他、封存、认了，三条路来回掰扯，最后谁也没拍板，就这么搁下了。日子照常过，搁着搁着就成了默认。第十五年，他冒出第一根白头发，她帮他拔掉，两个人都没出声。从第二十年起，外人开始认错，开口就问「令郎？」饭桌上还是那碗粥，喝粥的工夫一天比一天紧巴。

#### 为什么这是修仙设定最有价值的东西

这个设定让「时间不对等」成了**摆在眼前的事实**，承诺、等待、遗忘这些桥段放进来，分量都会自己加重：

| 普通设定 | 修仙设定 |
|---|---|
| 他等了她三年 | 他等了她三百年 |
| 她忘了三个月前的事 | 她忘了三百年前的事 |
| 「我会一直陪着你」 | 这话在这里兑现不了 |
| 一辈子 | 谁的一辈子 |

#### 三种解法

| 解法 | 代价 |
|---|---|
| 他修上去 | 要资质，要时间，要机缘，最常见 |
| 她降下来 | 她放弃修为，分量极重，还得写清她愿不愿意 |
| 都不解决 | 他老去，她看着。最疼 |

第三种语料里最少，却最值得写。

#### 可用细节

| 类 | 内容 |
|---|---|
| 时间的可见化 | 他白了头 · 他手上有老茧 · 她还是老样子 |
| 旁人 | 别人看他们像母子／师徒 |
| 他的努力 | 他闭关了多少回 · 他吞了多少丹药 |
| 她的准备 | 她一直等那天，先不挑明 |
| 落点 | 一个他老了、她没老的平常日子 |

两个人坐在一起吃饭，其中一个的手在抖。他老了她没老，这样的平常日子，比生离死别还压得人难受。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 差距 | 一倍 | 十倍 |
| 解法 | 他修上去 | 都不解决 |
| 她的态度 | 想尽办法 | 接受了 |
| 结局 | 一起 | 她一个人活下去 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她头一回瞅见他手背上的斑 | 她还是老样子 |
| 内心 | 我该怎么准备这一天 | 我在追一个追不上的人 |
| 好的处理 | 她没说“我会一直陪着你” | 他没因为这事撂挑子 |
| 写崩 | 写成她随便就把他命续上了 | 写成他觉得自己配不上就撤了 |

#### 写崩的三种方式

1. 随手给他续命。这就把设定的价值扔了。
2. 拿「我会一直陪你」来收尾。在这个设定里，这句话是空的。
3. 光写悲伤，不写日常。人是在日常里一天天老的。

## 六 · 她闭关

`T` ｜ 无预警 ｜ 修仙 ｜ 语料频次：闭关 15.7%（闭关＋请安、闭关＋公开高频同现）

**骨架**｜她一闭关就是几年，这几年他一个人熬着。

#### 节拍链

定了闭关 → 交代 → 洞门关上 → 他守着，也过日子 → 里面没了动静的那天 → 出关 → 她的第一眼

#### 时间轴

洞门一关，里外就是两种时间：她在洞里觉不出日子在过，他在外面一年一年地数。第一年他守着。第二年一边守一边过日子，该忙什么忙什么。第三年洞里彻底没了动静，那三个月他就守在洞口，哪儿也没去。他记了整整三年的册子，一页一页都是「今日无事」，拿在手里很沉。她出关推开门，看见的人比她记忆里稳当得多。

#### 与「出差」的根本区别

| | 出差 | 闭关 |
|---|---|---|
| 时长 | 可知 | 不可知 |
| 联系 | 可以 | 完全不能 |
| 意外 | 会通知 | 他不知道里面发生了什么 |
| 他能做的 | 等 | 守 |

里面出了什么事，他不知道。她也许会出关，也许走火入魔，也许就死在里头，他能做的只有守着这扇门。

#### 可用细节

| 类 | 内容 |
|---|---|
| 时间的计量 | 他在洞口划道道 · 换过几回灯油 ✓ · 看山下的树 |
| 他做的事 | 守着 · 布阵 · 把找上门的人打回去 |
| 异动 | 里头有动静了 · 阵法的光颜色不对 |
| 他的煎熬 | 有一回里头彻底没声了 |
| 出关 | 她头一眼瞧见啥 |

她出关，头一个看见的就是他。他在这里守了很久了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时长 | 三个月 | 三十年 |
| 他守不守 | 守着 | 他有自己的事要做 |
| 期间 | 平安 | 出了事 |
| 出关时 | 他在 | 他不在了（最疼） |

另一头是「他不在了」：她进去时他还年轻，出来时人已经没了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 出关时洞外的痕迹 | 今天是第七百天 |
| 好的处理 | 她一出关就先去找他 | 他守着，但日子照常过 |
| 写崩 | 写成一出关啥都摆平了 | 写成他死等，人瘦脱了相 |

他守着，日子也照常过，这么写是健康的。

#### 写崩的三种方式

1. 闭关只当成一段跳过去的时间。洞里洞外都该有戏。
2. 把他写成只是在干熬。他得有自己的日子要过。
3. 丢开「不知道里面怎么样」不写。闭关和出差就差在这里。

## 七 · 渡劫

`T` ｜ 无预警 ｜ 修仙 ｜ 语料频次：双修 7.0% ＋ 闭关 15.7%

**骨架**｜天雷要劈她，他能帮的少得可怜。

#### 节拍链

天象起 → 她入阵他守外 → 一道道数 → 最后一道 → 他守住了位置 → 她过了 → 第一句话是问他

#### 时间轴

天象起来到第一道雷落下，用了半个时辰。之后快慢由天，一道比一道密，一道比一道沉。九道雷，他一道一道数着。**守到第七道，阵光晃了一下，他的脚动了半步又钉回原地，他进去只会害她。** 第九道砸下来，烟尘散开前那几秒，是他这辈子最长的几秒。她睁开眼，第一句问的是他，嗓子哑着。

#### 这条为什么好用

修仙设定里这就是他帮不上忙的时候：她要对付的是天。

他能做的也就这些：

| 他能做的 | 说明 |
|---|---|
| 布阵 | 分担一点 |
| 递丹药 | 在间隙 |
| 挡一道 | 他会死，且她不许 |
| 在场 | 最重要的一件 |
| 事后 | 见 [16-危机与保护 · 她受伤了](16-危机与保护.md#四--她受伤了) |

他能做的，最多就是在场。这和 [01-日常照料 · 守着不睡](01-日常照料.md#六--守着不睡) 是一回事，只是推到了极端。

#### 可用细节

| 类 | 内容 |
|---|---|
| 天象 | 雷云压了几层 · 两道雷隔多久 |
| 他的位置 | 站在阵外 · 她不让进 |
| 他的动作 | 数着雷 · 每打完一道就看她还在不在 |
| 她的状态 | 一道雷下来，人就矮一截 |
| 最后一道 | 他冲进去了 · 也可能没冲 |

他没冲进去的版本更难写：她让他守住阵眼，他就守住了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他能不能帮 | 能帮一点 | 完全帮不上 |
| 他冲不冲 | 冲了 | 守住了自己的位置 |
| 结果 | 她过了 | 她伤得很重 |
| 之后 | 她说了什么 | 她什么都没说 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 第七道之后她看见他还在原地 | 第七道 |
| 内心 | 别过来 | 她说了别过来 |
| 好的处理 | 她过了之后第一句是问他 | 他守住了她交代的位置 |
| 写崩 | 写成他挡雷替死 | 写成他在旁边哭 |

让他替她挡雷送命，这个走向太俗。她的劫得她自己渡。

#### 写崩的三种方式

1. 让他替她挡。 那是她的劫。
2. 把他写得毫无用处。在场就有用。
3. 跳过雷与雷的间隙。每两道雷中间那几秒要写。

## 八 · 通讯延迟

`T` ｜ 无预警 ｜ 星际 ｜ 语料频次：舰船 10.5%

**骨架**｜他说一句话，要过四个钟头才等到她的回音。

#### 节拍链

出航 → 定通讯窗口 → 录制与等待 → 一次情绪错位 → 「等你收到这条的时候」句式成形 → 静默期 → 恢复

#### 时间轴

通讯窗口一天两班，一句话发出去，要四小时后才有回音。往返一拖四小时，对话就成了写信，情绪也总对不上：他正委屈，收到的是她四小时前开的玩笑。到第二周，「等你收到这条的时候」这个说法定了型，之后每条消息都带着时间。最熬人的是三天静默期。三天后恢复通讯，第一条两边几乎同时发出，内容一模一样。

#### 这是星际设定最独一无二的东西

别的设定里，两个人说话都是同步的，这里做不到。

不同步带来的这些，换个设定就没有了：

| 现象 | 说明 |
|---|---|
| 每句话都是对着空气说的 | 说的时候不知道会得到什么 |
| 四小时的反刍 | 他会把自己说的话回想很多遍 |
| 答非所问 | 她回的是四小时前的问题 |
| 情绪错位 | 他难过时她还在为上一条高兴 |
| 无法打断 | 只能听完 |
| 无法安慰 | 等他的安慰到了，她早就过去了 |

他难过时录了一段话，四小时后她才收到，她的回复再走四小时回来。八小时过去，他早缓过来了，收到的却是一段安慰。

#### 可用细节

| 类 | 内容 |
|---|---|
| 通讯记录 | 时间点 · 有没有延迟 · 录了多久 |
| 他的习惯 | 每条都唠很久 · 要么就只说重点 |
| 她的习惯 | 话少 · 但每条都接 |
| 断联 | 跃迁那阵子没信号，啥也收不着 |
| 落点 | 有条他录好了，但没发出去 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 延迟 | 四小时 | 数周 |
| 谁在远处 | 她 | 他 |
| 内容 | 日常 | 一件必须马上说的事 |
| 结果 | 撑住了 | 有一条来得太晚 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看到这条时，他那边已经过了四小时 | 他说完这话，又过了四小时 |
| 好的处理 | 她回的是他此刻正缺的那句话 | 他学会了说「等你看到这条的时候」 |
| 写崩 | 写成了普通异地恋 | 写成了他掐着表干等 |

「等你收到这条的时候」这种说法只在星际版里有，值得反复用。

#### 写崩的三种方式

1. 写成普通异地恋。延迟一定要落到具体的错位上。
2. 漏掉时间戳。每条消息都该标着时间。
3. 通讯想用就能用。那这一条就不存在了。

## 九 · 相对论时间差

`T` ｜ 无预警 ｜ 星际 ｜ 语料频次：舰船 10.5%

**骨架**｜她出海两年回来，他已经老了八岁。

#### 节拍链

出航决定 → 她两年他八年 → 各自过 → 归来对表 → 鬓角 → 她认真听完那六年 → 下一次怎么办

#### 时间轴

出发前，两个人都给对方这段日子留了个念想。她的两年跟着任务走，排得满满的，日子却没什么变化。他的八年跟着日子走，搬了家，换了工作，老了六岁。回来那晚两人对表，两本日历对不上，只能各认各的：他八年，她两年。她认认真真听他讲完那六年，一年接一年，不许他跳过去。过了一个月，两人才敢谈「下一次怎么办」。这道题没有解，两人心里都清楚。

#### 与修仙寿元差的区别

| | 寿元差 | 相对论时间差 |
|---|---|---|
| 差距 | 恒定 | 每次航行累积 |
| 谁老得快 | 他 | 留在原地的那个 |
| 能不能选 | 难 | 可以（不出航） |
| 情绪 | 无奈 | **愧疚**，她的选择造成的 |

她每出航一次，就是自己选了让他多等六年。寿元差那条没有这份愧疚。

#### 可用细节

| 类 | 内容 |
|---|---|
| 计量 | 她船上的钟比地面的钟慢多少 · 两个数一减 |
| 他的变化 | 她走那年他二十八，回来他三十六了 |
| 他的生活 | 那六年他怎么过的，这段非写不可 |
| 她的不变 | 她一点没变，还是老样子 |
| 下一次 | 她还走不走 |

他那六年怎么过的，一定要写。他不能光是在等。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 差距 | 两年比六年 | 两年比二十年 |
| 他的六年 | 他在等 | 他过了自己的六年 |
| 她的选择 | 不再出航 | 还要走 |
| 结局 | 她留下 | 他跟她一起走 |

要是他跟她一起走，时间差就没了，代价是地面上的一切他都得放下。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她回来时他鬓角有白的了 | 这六年我过得挺好 |
| 内心 | 是我让他多过了六年 | 别让她愧疚 |
| 好的处理 | 她问他这六年怎么过的，认真听完 | 他真的过了自己的六年 |
| 写崩 | 写成她自我感动硬扛 | 写成他死等六年没挪窝 |

#### 写崩的三种方式

1. 写他苦守。那六年他得过自己的。
2. 不写她愧疚不愧疚。这一条跟寿元差的区别，就靠这份愧疚。
3. 一趟航行就把事情了结。差距要一次次攒，攒够了才发动。

## 十 · 末世的一份口粮

`T` ｜ 无预警 ｜ 末世 ｜ 语料频次：舰船 10.5% 的邻域（末世设定）

**骨架**｜物资就是命，他却把自己的口粮让给了她。

#### 节拍链

清点 → 分配 → 他说吃过了 → 她发现那份没动 → 生气 → 分了一半 → 他接受了，没再推

#### 时间轴

「我吃过了」这句话从说出口到被拆穿，不超过六小时。她只气了十分钟，接着分一半，前后五分钟：掰开，递过去，看着他吃完。从她改分配制度那天起，物资按天配给，每天清点一次，口粮全部当面分、当面吃，不留转手的空当，谎话撑不过一顿饭。她做的是把「让」从规则里整个拿掉，不给余地，数目一对不上，她一眼就能看出来。

#### 末世设定的唯一机关：让温柔有价

| 日常动作 | 末世里的代价 |
|---|---|
| 做一顿饭 | 吃掉省下的罐头 |
| 留一盏灯 | 烧掉发电机的油 |
| 洗一次头 | 用掉三天的水 |
| 送一样没用的东西 | 白扔东西，图个心里舒坦 |
| 守夜 | 真会出事 |
| 分一半口粮 | 自己少撑几天 |

这一条用不着新桥段，前面二十卷的桥段搬到这里，每一样都有了价钱。

#### 可用细节

| 类 | 内容 |
|---|---|
| 计量 | 还剩几罐 · 还能撑几天 · 水到哪了 |
| 隐瞒 | 他说吃过了 · 她看见他那份没动 |
| 分配 | 谁多谁少 · 谁背地里省着吃 |
| 无用之物 | 他留了件不能吃不能用的东西 |
| 落点 | 俩人争着让对方多吃一口 |

两人争着让对方多吃一口，这场戏得写。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁让 | 他 | 她 |
| 说不说 | 明着让 | 偷偷少吃 |
| 被发现 | 是 | 一直没发现 |
| 结局 | 撑过去了 | 有人撑不住 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他罐头是空的，但没动过 | 我说我吃过了 |
| 好的处理 | 她火了，把自己那份拨给他一半 | 他收下了，没再让 |
| 写崩 | 写成俩人抢着饿肚子的苦情戏 | 写成他把自己饿死还挺光荣 |

他收下了，没再推。到了这个地步，推让就是浪费。

#### 写崩的三种方式

1. 写成互相牺牲的煽情戏。具体写两人争一口吃的场面，反倒更有劲。
2. 不写数量。还剩几罐、还能撑几天，都要写出来。
3. 物资压根不缺。这还算什么末世。

## 十一 · 双修

`M` ｜ ⚠️亲密接触 ｜ 修仙 ｜ 语料频次：双修 7.0%（187 部）

**骨架**｜这门功法要两个人一起练，以后想亲近，谁都不必先找话开口。

#### 节拍链

双修 → 偏见 → 投喂 → 撒娇 → 怔住 → 拥抱

这条链在语料里原样出现过 7 部，顺序可以照搬（[13-语料挖掘/07-桥段分布 §五](../13-语料挖掘/07-桥段分布.md)）。每一拍这样落：

| 拍 | 节拍 | 落在这场戏里 |
|---|---|---|
| 1 | 双修 | 到日子了，两个人面对面坐着练功 |
| 2 | 偏见 | 外人看见了：同门开几句玩笑，长老说句「练得还行」 |
| 3 | 投喂 | 练完功，一碗热粥放旁边，灵力退了心里空，正好垫一口 |
| 4 | 撒娇 | 趁灵力还没散干净，他把平时不敢说的话说了 |
| 5 | 怔住 | 她一口答应，俩人都没反应过来 |
| 6 | 拥抱 | 最后抱在一起，体温能暖到的地方，功法管不着 |

#### 时间轴

双修有固定日子：初一十五，每逢月圆，卡在瓶颈时还要加课。写到第三回，读者自然会拿它跟第一回比，谁先到，蒲团挪近了几寸，话少了多少，都看得出来。

#### 必须合作的身体契约

别的设定里，两人要么先把话说开，要么先冲动一回。这里多出一条路：**功法替两个人把话说了。** 这份约定里有三处，每处都藏着一个反转：

| 哪一处 | 用法 | 反转点 |
|---|---|---|
| 功法借口 | 「按谱来」「就当功课」，谁也不用先承认自己想 | 瓶颈过了借口就不灵了，「还修吗」三个字比表白还难出口 |
| 进度可视化 | 修为涨了多少，就是把亲密摆给人看，涨了同门都知道 | 月考修为涨得漂亮那天，两个人谁都不敢看谁 |
| 窘迫的归属 | 照常理是他窘，修为低的被带着走 | 她讲起来头头是道，一上手先脸红，主导权半路换了人 |

谁更窘，就往谁那边写。她讲图谱讲得头头是道，掌心一贴上，脸却比他先红。这个反转从两边的视角写都能用。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 蒲团两只，一寸一寸挪近 · 功法图谱，翻到那一页停住 · 更漏，算着时间 · 檀香 · 掌心 ✓ 贴住的位置 |
| 进度的量具 | 丹田有没有气感 · 经脉图亮到哪一段 · 师门月考修为涨了多少 |
| 借口的说法 | 「功法要求」「按谱来」「就当功课」，说的时候声音都低半截 |
| 外界 | 同门拿他俩打趣 · 长老一句「进境不错」，俩人同时愣住 |
| 收尾 | 功课散了谁也没走 · 递点吃的 · 谁先憋不住说「下次」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提议 | 她，长辈身份，开口不突兀 | 他憋了好久，拿「为了宗门大比」当由头 |
| 借口的寿命 | 一直管用（功法得长期练） | 用着用着不灵了，瓶颈过了，谁也没提停 |
| 窘迫归属 | 他慌她不慌 | 她先乱了阵脚 |
| 修为差 | 她强他弱，她带他 | 他其实更有天赋，她发现那天脸上挂不住 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己老在盼初一十五 | 掌心贴上来之前的那三秒 |
| 内心 | 是功课，她跟自己说了三遍 | 灵力是她的，心跳是我自己的 |
| 好的处理 | 她先把话撂下：不想修可以说 | 他窘，但他每次都来 |
| 写崩 | 写成她拿功法压人 | 写成他一点不别扭就享用了 |

#### 安全与边界

| 线 | 说明 |
|---|---|
| 同意 | 功法要求归功法要求，本人愿不愿意另外写。「不想修可以说」这句得真能说出口 |
| 权力差 | 有长辈、师父的身份压着，再提双修，谁先开口、怎么开口，写的时候要想清楚 |
| 全员成年 | 沾性的事，角色一律是成年人 |
| 不写可复现细节 | 只写关系怎么走、怎么推，具体场面去 [06-尺度与写法](../06-尺度与写法/) |

#### 写崩的三种方式

1. 把双修写成纯粹的功能交易。没了羞耻感，就只剩一段设定说明，窘迫写出来了，内容才立得住。
2. 借功法绕开同意。这和易感期是同一个雷区，设定不能当免责的挡箭牌。
3. 修为一步登天。一回就涨满，按日子来的设定就白搭了。每回涨一点，多涨几回，才出效果。
