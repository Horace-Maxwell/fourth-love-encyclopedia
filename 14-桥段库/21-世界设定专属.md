## 一 · 他的易感期

`T` ｜ 无预警 ｜ 女A男O ｜ 语料频次：易感期 20.0%（易感期＋生病、易感期＋留痕高频同现）

**骨架**｜他的身体不听他的。而这是他第一次在她面前完全失控。

#### 节拍链

前兆 → 他提前发「别回来」→ 自我隔离 → 她还是回来了 → 她只是坐着 → 潮退 → 清醒后的那场对话

#### 时间轴

**前兆到潮退，七十二小时。** 他的「别回来」发在前兆第一小时，抢在自己失去分寸之前；她赶回来时是第二天。中段的时间最难写也最该写慢：她只是坐在三步外，不碰、不劝，一坐一夜。潮退后的清醒对话发生在第三天早上，两个人都平静，谈的却是这个设定里最重的议题：下次，要不要她在。

#### 为什么这条是 ABO 设定的核心价值

在别的设定里，他的顺从是**选择**。在这里，有一段时间他没有选择。

而这恰恰逼出了这个类型最重要的问题：当顺从不再是选择时，这段关系还成立吗？

| 处理 | 说明 |
|---|---|
| 她趁机 | 关系性质变了，且很难写回来 |
| 她不碰，只陪着 | 最能证明这段关系 |
| 她按医嘱处理 | 冷静，但可能显得疏离 |
| 他清醒后的态度 | 这才是这条的落点 |

**「他清醒后的态度」是必须写的：** 他会不会因为自己那个样子而羞耻，她怎么处理这份羞耻。

#### 可用细节

| 类 | 内容 |
|---|---|
| 生理表现 | 体温 · 腺体的位置（后颈 ✓）· 信息素的浓度与气味 |
| 道具 | 抑制剂 · 阻隔贴 · 药 ✓ · 冰袋 ✓ · 毯子 ✓ |
| 他的挣扎 | 咬着不出声 · 把自己关起来 · 提前发消息 ✓ 让她别回来 |
| 她的处理 | 她还是回来了 |
| 清醒后 | 他不敢看她 · 或者他先开口说了 |

**「提前发消息让她别回来」是这条最好的一个动作：** 在失控之前，他做了最后一件能控制的事。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她在不在 | 在 | 她被他支开了 |
| 有没有发生什么 | 没有 | 有（走 [三 · 标记](#三--标记)） |
| 他的羞耻 | 很重 | 他接受了 |
| 之后 | 两人说开了 | 谁都不提 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她收到那条「别回来」的消息 | 我不想让她看见我这样 |
| 内心 | 他现在最需要有人在 | 这不是我 |
| 好的处理 | 她回来了，且什么都没做，只是坐着 | 他清醒后自己提起了这件事 |
| 写崩 | 写成她趁机 | 写成他的失控是情趣 |

「她什么都没做，只是坐着」是这条的最优解。 在一个身体不由自主的时刻，被尊重比被满足重要。

#### 安全与边界

| 线 | 说明 |
|---|---|
| 同意 | 生理驱动下的同意是脆弱的，文本要处理这一点 |
| 全员成年 | 所有涉性情节中的角色均为成年人 |
| 不写可复现细节 | 本条只写关系结构，具体描写走 [06-尺度与写法](../06-尺度与写法/) |
| 事后处理 | 清醒之后的对话是必需的，不能跳过 |

**「生理驱动下的同意是脆弱的」这一点必须在文本里被意识到**，否则 ABO 设定会变成免责工具。

#### 写崩的三种方式

1. 用易感期免除同意问题。 那是这个设定最常见的滥用。
2. 把失控写成情趣。 对他而言那是失去自我。
3. 跳过清醒之后。 那才是这条的正文。

后接：[二 · 她的信息素](#二--她的信息素) · [三 · 标记](#三--标记)

## 二 · 她的信息素

`T` ｜ 无预警 ｜ 女A男O ｜ 语料频次：易感期 20.0%

**骨架**｜她的味道能让他安静下来。这是这个设定给她的唯一一件专属工具。

#### 节拍链

日常收着 → 一次安抚 → 依赖成形 → 一次用它赢了争吵 → 他说「刚才那个别再用」→ 之后她只在必要时用

#### 时间轴

日常收着，动用一次记一次账。 安抚性的使用一年只有几回，每回几分钟；「用它赢了争吵」的那次只用了三十秒，吵到一半他忽然静了，事后他缓了一天才说出那句「刚才那个别再用」。从那天起她的使用规则改了：必要时才用，用前看他一眼。这条的时间轴是一张使用记录表，越往后越稀疏，稀疏就是尊重。

#### 信息素作为权力工具

| 用法 | 效果 | 风险 |
|---|---|---|
| 安抚 | 他立刻平静 | 会变成条件反射 |
| 施压 | 他生理性地服从 | 这是强制，要处理 |
| 标记的气味残留 | 宣示 | 见 [05-占有与吃醋 · 留痕](05-占有与吃醋.md#四--留痕) |
| 收敛不放 | 他会不安 | 最微妙的一种 |

**「收敛不放」是这条最有意思的用法：** 她可以不释放，而他会因为闻不到而焦虑。冷落被生理化了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 气味 | 具体是什么（见 [13-语料挖掘/03-设定元素库](../13-语料挖掘/03-设定元素库.md) 的信息素气味表） |
| 浓度 | 她刻意收着 · 她一进门就放了 |
| 他的反应 | 肩膀松下来 · 呼吸变深 · 他自己都没意识到 |
| 依赖 | 他睡不着时要她的一件衣服 ✓ |
| 边界 | 她用它来赢一次争吵（这一步要处理） |

**「她用它来赢一次争吵」是这条的红线场面**，且值得专门写一次并给出后果。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她用不用 | 只在必要时 | 日常使用 |
| 他的依赖 | 轻 | 重到影响判断 |
| 她有没有滥用 | 没有 | 有一次，且她后悔了 |
| 他知不知道被影响 | 不知道 | 知道，且他介意 |

「他知道自己被影响，且他介意」是这条最有深度的一版。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己刚才是用信息素让他闭嘴的 | 我刚才为什么突然不生气了 |
| 内心 | 这算不算作弊 | 那不是我自己的判断 |
| 好的处理 | 她之后不再用它解决争执 | 他说出了「刚才那个别再用」 |
| 写崩 | 写成她随意使用 | 写成他享受被支配 |

#### 安全与边界

信息素施压在结构上等同于**削弱对方的自主判断**。写它可以，但文本要能被看出对它有判断：使用要有代价，且对方要能提出异议。

参照 [05-占有与吃醋 · 独占欲的边界](05-占有与吃醋.md#十--独占欲的边界) 的同一判据。

#### 写崩的三种方式

1. 把信息素当成万能遥控器。 用一次要有一次的账。
2. 让他享受被生理支配。 那取消了他的人格。
3. 忽略「他介意」的可能。 那是这条的深层。

## 三 · 标记

`M` ｜ ⚠️亲密接触 ｜ 女A男O ｜ 语料频次：易感期 20.0% ＋ 留痕 47.0%

**骨架**｜临时的还是永久的。这个选择是这个设定里最重的一次决定。

#### 节拍链

谁提出 → 清醒时的那次确认 → 做或不做 → 气味变化被外界读到 → 制度后果 → 依赖的新形态 → 各自消化

#### 时间轴

提出到确认，隔了一个月；确认必须发生在清醒时。 谁先提的那晚没有结论，这种事不许当场答；一个月的冷静期里两个人各自查了资料、各自想了后果。清醒时的那次确认只有几句话，但日期被两个人分别记住了。做了之后的时间属于外界：气味变化三天内被同事读到，制度后果一周内到齐，个人的决定，公共的钟。

#### 两种标记的不对称

| | 临时标记 | 永久标记 |
|---|---|---|
| 可逆 | 是 | 否（多数设定） |
| 谁受影响更大 | 他 | 他 |
| 意义 | 保护／宣示 | 结合 |
| 现实类比 | 同居 | 结婚 |
| 拒绝的余地 | 有 | 几乎没有 |

**「谁受影响更大」两栏都是他**，这是 ABO 设定的结构性不对称，也是这一条必须处理的地方：她的一个动作，改变的是他的身体。

#### 可用细节

| 类 | 内容 |
|---|---|
| 位置 | 后颈 ✓ 腺体 |
| 之前 | 谁提的 · 谈了多久 · 有没有谈 |
| 之后 | 他身上带着她的气味 · 别人闻得出来 |
| 社会层面 | 标记是不是要登记 · 有没有法律效力 |
| 解除 | 能不能解除 · 代价是什么 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提出 | 她 | 他（他要一个保证） |
| 时机 | 深思熟虑 | 易感期中（同意问题，见下） |
| 类型 | 临时 | 永久 |
| 之后 | 他安心了 | 他发现自己变得更依赖了 |

**「他发现自己变得更依赖」是这条最值得写的后果**：得到了想要的东西，代价是失去了一部分独立。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她意识到这是不可逆的 | 我要她标记我 |
| 内心 | 我改变的是他的身体 | 这样她就不会走了 |
| 好的处理 | 她在他清醒时问了一次 | 他说明了他要这个的理由 |
| 写崩 | 写成占有欲的浪漫化 | 写成他用标记求安全感 |

**「他用标记求安全感」这一端要谨慎处理**：它真实，但文本要指出这不是解决办法。

#### 安全与边界

| 线 | 说明 |
|---|---|
| 同意的时点 | 易感期中的同意不可靠，重要决定要在清醒时做 |
| 不可逆性 | 文本要写出这一点的分量 |
| 全员成年 | 涉性情节中的角色均为成年人 |
| 不写可复现细节 | 只写关系结构与后果，具体描写走 [06-尺度与写法](../06-尺度与写法/) |

#### 写崩的三种方式

1. 在易感期中完成永久标记且不处理同意问题。 这是这个设定最常见的滥用。
2. 把不可逆写成浪漫。 不可逆首先是重量。
3. 忽略社会层面。 标记在多数设定里有制度后果。

## 四 · 他要不要用抑制剂

`T` ｜ 无预警 ｜ 女A男O ｜ 语料频次：易感期 20.0%

**骨架**｜一个可以让他不失控的东西。而用不用，是他的自主权问题。

#### 节拍链

工作要求 → 常规剂量 → 偷偷加量 → 副作用露头 → 她数药盒 → 「在家不用打」→ 新的平衡

#### 时间轴

加量是逐月的，被发现是一瞬的。 常规剂量用了半年相安无事；工作压力上来后他偷偷加量，每月多一支，三个月后副作用露头（手抖、失眠）。她数药盒只用了十秒（她对数字的敏感是职业病），「在家不用打」五个字当晚生效。新的平衡按季度巩固：用量回落的曲线，是这条的疗效证明。

#### 这条是 ABO 设定里最现实的一条

抑制剂在这一设定里的位置，类似于现实中任何一种用来让身体符合社会要求的手段。而围绕它的问题也一样：

| 问题 | 说明 |
|---|---|
| 有没有副作用 | 长期使用伤身 |
| 谁在要求他用 | 工作？社会？她？ |
| 他自己想不想用 | 用了他更自由，也更不像自己 |
| 停用之后 | 反弹 |

「谁在要求他用」是这条的核心。 如果是她要求的，性质就完全不同了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 药 ✓ 盒 ✓ · 注射 · 阻隔贴 · 剂量记录 |
| 他的隐瞒 | 他加大了剂量没告诉她 |
| 副作用 | 疲倦 · 迟钝 · 一次晕倒 |
| 她的发现 | 见 [15-秘密与坦白 · 他有一件事没说](15-秘密与坦白.md#一--他有一件事没说) |
| 落点 | 她说「在家不用打」 |

「在家不用打」是这条最好的一句台词。 它给了他一个可以不被抑制的地方。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁要求 | 工作／社会 | 她（要处理） |
| 他的态度 | 主动用 | 抗拒 |
| 剂量 | 正常 | 超量（隐瞒） |
| 结果 | 停了 | 一直在用 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她数了他的药 ✓ 盒 ✓ | 这样才能正常上班 |
| 好的处理 | 她说「在家不用」 | 他承认自己超量了 |
| 写崩 | 写成她要求他用 | 写成他为她牺牲身体 |

#### 写崩的三种方式

1. 让她要求他用且文本不处理。 那是控制。
2. 忽略副作用。 代价是这条的重量。
3. 写成他单方面的牺牲。 他有自己的理由。

## 五 · 寿元差

`T` ｜ 无预警 ｜ 修仙 ｜ 语料频次：寿元 10.0%

**骨架**｜她能活八百年，他能活六十年。这是算术，不是矛盾。

#### 节拍链

数字摆上桌 → 三种解法议过 → 选定或搁置 → 他的白发第一次出现 → 旁人误认 → 一个平常的饭桌场面

#### 时间轴

八百年对六十年，没有比这更大的钟。 数字摆上桌那晚谈了一夜，三种解法（渡他、封存、认了）各议过一轮，然后搁置，搁置本身就是决定：先过日子。他的第一根白发出现在第十五年，她替他拔下来那天两个人都没说话；旁人误认（「令郎？」）从第二十年开始。那个平常的饭桌场面放在最后：粥还是那碗粥，喝粥的时间一天天变得金贵。

#### 为什么这是修仙设定最有价值的东西

它把「时间不对等」变成了**物理事实**，而所有关于承诺、等待、遗忘的桥段在这里都会自动加重：

| 普通设定 | 修仙设定 |
|---|---|
| 他等了她三年 | 他等了她三百年 |
| 她忘了三个月前的事 | 她忘了三百年前的事 |
| 「我会一直陪着你」 | 这句话在这里是数学错误 |
| 一辈子 | 谁的一辈子 |

「谁的一辈子」是这条唯一的问题。

#### 三种解法

| 解法 | 代价 |
|---|---|
| 他修上去 | 需要资质、时间、机缘。最常见 |
| 她降下来 | 她放弃修为。极重，且要处理她的意愿 |
| 都不解决 | 他老去，她看着。最疼 |

第三种在语料里最少，也最值得写。

#### 可用细节

| 类 | 内容 |
|---|---|
| 时间的可见化 | 他的白发 · 他的手 · 她一直没变 |
| 旁人 | 别人以为他们是母子／师徒 |
| 他的努力 | 他闭关的次数 · 他吃的丹药 |
| 她的准备 | 她在为那一天做准备（且不说） |
| 落点 | 一个他老了她没老的日常场面 |

**「一个他老了她没老的日常场面」比任何生离死别都重：** 两个人一起吃饭，一个人的手在抖。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 差距 | 一倍 | 十倍 |
| 解法 | 他修上去 | 都不解决 |
| 她的态度 | 想尽办法 | 接受了 |
| 结局 | 一起 | 她一个人活下去 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她第一次注意到他的手背有斑 | 她还是那个样子 |
| 内心 | 我要为这一天做什么准备 | 我在追一个追不上的人 |
| 好的处理 | 她没有承诺「我会一直」 | 他没有因此放弃当下 |
| 写崩 | 写成她轻易给他续命 | 写成他自卑退出 |

#### 写崩的三种方式

1. 轻易给他续命。 那是把设定的价值扔掉了。
2. 用「我会一直陪你」收场。 放在这种设定里，那句话是空的。
3. 只写悲，不写日常。 老去是在日常里发生的。

## 六 · 她闭关

`T` ｜ 无预警 ｜ 修仙 ｜ 语料频次：闭关 15.0%（闭关＋请安、闭关＋公开高频同现）

**骨架**｜她进去了，出来时是几年后。而这几年他一个人过。

#### 节拍链

定了闭关 → 交代 → 洞门关上 → 他守着，也过日子 → 里面没了动静的那天 → 出关 → 她的第一眼

#### 时间轴

洞门一关，两套时间开始不同速。 里面的她无岁月，外面的他按年过：第一年守着，第二年边守边过日子（该忙的忙），第三年洞里没了动静，那三个月他守在洞口没挪窝。出关那天她推门，看到的是一个比记忆里沉稳的人和一本记满三年的册子：里面一页页全是「今日无事」，无事两个字写了一千遍，就不是无事了。

#### 与「出差」的根本区别

| | 出差 | 闭关 |
|---|---|---|
| 时长 | 可知 | 不可知 |
| 联系 | 可以 | 完全不能 |
| 意外 | 会通知 | 他不知道里面发生了什么 |
| 他能做的 | 等 | 守 |

**「他不知道里面发生了什么」是这条的全部张力：** 她可能出关，可能走火入魔，可能死在里面，而他只能守着一扇门。

#### 可用细节

| 类 | 内容 |
|---|---|
| 时间的计量 | 他在洞口刻痕 · 换了几次灯 ✓ · 山下的树 |
| 他做的事 | 护法 · 布阵 · 打退上门的人 |
| 异动 | 里面传出的声音 · 阵法的光变了颜色 |
| 他的煎熬 | 有一次里面完全没了动静 |
| 出关 | 她第一眼看见的是什么 |

**「她出关第一眼看见的是什么」是这条的落点：** 是他，且他已经在这儿守了很久。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时长 | 三个月 | 三十年 |
| 他守不守 | 守着 | 他有自己的事要做 |
| 期间 | 平安 | 出了事 |
| 出关时 | 他在 | 他不在了（最疼） |

**「他不在了」这一端是修仙设定独有的残酷**：她进去时他还年轻，出来时他已经不在。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 出关时洞外的痕迹 | 今天是第七百天 |
| 好的处理 | 她出关第一件事是找他 | 他守着，但他也过自己的日子 |
| 写崩 | 写成她一出关就解决所有问题 | 写成他枯守到形销骨立 |

「他守着，但他也过自己的日子」是这条最健康的处理。

#### 写崩的三种方式

1. 让闭关只是一个时间跳跃。 里面与外面都要有内容。
2. 写成他枯守。 他要有自己的生活。
3. 忽略「不知道里面怎么样」。 那是这条区别于出差的全部。

## 七 · 渡劫

`T` ｜ 无预警 ｜ 修仙 ｜ 语料频次：双修 6.0% ＋ 闭关 15.0%

**骨架**｜天要劈她。而他能做的极其有限。

#### 节拍链

天象起 → 她入阵他守外 → 一道道数 → 最后一道 → 他守住了位置 → 她过了 → 第一句话是问他

#### 时间轴

**九道雷，一道一拍。** 天象起到第一道落，半个时辰；之后的节奏由天定：一道比一道密、一道比一道沉。他在阵外守着，能做的只有数，数到第七道时阵光晃了一下，他的脚动了半步又钉回去（进去就是害她）。第九道砸下到烟尘散开的那几秒，是他一生最长的几秒。她睁眼第一句问的是他，问的时候嗓子是哑的。

#### 这条为什么好用

它是修仙设定里的**结构性无力时刻**：她面对的是天，他帮不上。

而「帮不上」正是这条的内容：

| 他能做的 | 说明 |
|---|---|
| 布阵 | 分担一点 |
| 递丹药 | 在间隙 |
| 挡一道 | 他会死，且她不许 |
| 在场 | 最重要的一件 |
| 事后 | 见 [16-危机与保护 · 她受伤了](16-危机与保护.md#四--她受伤了) |

**「在场」是他唯一真正能做的事**，而这与 [01-日常照料 · 守着不睡](01-日常照料.md#六--守着不睡) 是同一件事的极端版。

#### 可用细节

| 类 | 内容 |
|---|---|
| 天象 | 雷云的层数 · 每一道之间的间隙 |
| 他的位置 | 阵外 · 她不许他进来 |
| 他的动作 | 数雷 · 每一道之后看她还站不站着 |
| 她的状态 | 一道比一道站得低 |
| 最后一道 | 他冲进去了 · 或者他没有 |

**「他没有冲进去」这一版更难写也更有分量：** 她要他守住阵眼，他守住了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他能不能帮 | 能帮一点 | 完全帮不上 |
| 他冲不冲 | 冲了 | 守住了自己的位置 |
| 结果 | 她过了 | 她伤得很重 |
| 之后 | 她说了什么 | 她什么都没说 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 第七道之后她看见他还在原地 | 第七道 |
| 内心 | 别过来 | 她说了别过来 |
| 好的处理 | 她过了之后第一句是问他 | 他守住了她交代的位置 |
| 写崩 | 写成他挡雷替死 | 写成他在旁边哭 |

**「他挡雷替死」是这条最俗的一个走向**，且它取消了她的主体性——她的劫由她自己渡。

#### 写崩的三种方式

1. 让他替她挡。 那是她的劫。
2. 让他毫无作用。 在场就是作用。
3. 省略间隙。 每两道雷之间的那几秒是全部内容。

## 八 · 通讯延迟

`T` ｜ 无预警 ｜ 星际 ｜ 语料频次：舰船 10.0%

**骨架**｜他说完一句话，要等四小时才知道她怎么答。

#### 节拍链

出航 → 定通讯窗口 → 录制与等待 → 一次情绪错位 → 「等你收到这条的时候」句式成形 → 静默期 → 恢复

#### 时间轴

四小时的往返延迟，把对话切成了信件。 通讯窗口每天两班；一句话出去，答案四小时后到，情绪错位由此而生：他委屈的时候，收到的是她四小时前那句玩笑。「等你收到这条的时候」句式在第二周成形，从此每条消息都自带时间标注。静默期（跃迁遮蔽）三天，是这条的高压段：三天后恢复通讯的第一条，两边几乎同时发出，内容一样。

#### 这是星际设定最独一无二的东西

所有别的设定里，对话是同步的。这里不是。

而不同步造成的东西，别处造不出来：

| 现象 | 说明 |
|---|---|
| 每句话都是对着空气说的 | 说的时候不知道会得到什么 |
| 四小时的反刍 | 他会把自己说的话回想很多遍 |
| 答非所问 | 她的回答对应的是四小时前的问题 |
| 情绪错位 | 他难过时她还在为上一条高兴 |
| 无法打断 | 只能听完 |
| 无法安慰 | 等他的安慰到了，她早就过去了 |

「情绪错位」是这条最好的素材。 他录了一段很难过的话，她收到时已经过了四小时，而她的回复到他那里又是四小时——八小时后他早就好了，却收到了一段安慰。

#### 可用细节

| 类 | 内容 |
|---|---|
| 通讯记录 | 时间戳 · 延迟标注 · 录制时长 |
| 他的习惯 | 每条都录很长 · 或者他学会了只说结论 |
| 她的习惯 | 短 · 但每条都回 |
| 断联 | 跃迁静默期，完全收不到 |
| 落点 | 有一条他录了但没发出去 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 延迟 | 四小时 | 数周 |
| 谁在远处 | 她 | 他 |
| 内容 | 日常 | 一件必须马上说的事 |
| 结果 | 撑住了 | 有一条来得太晚 |

「有一条来得太晚」是这条的最强用法。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她收到的这条是他四小时前的心情 | 说完之后的四小时 |
| 好的处理 | 她回的是他现在需要的，不是四小时前 | 他学会了说「等你收到这条的时候」 |
| 写崩 | 写成普通的异地恋 | 写成他数着秒等 |

**「等你收到这条的时候」这个句式是星际版的专属语法**，值得反复用。

#### 写崩的三种方式

1. 写成普通异地恋。 延迟必须造成具体的错位。
2. 忽略时间戳。 那是这条的度量衡。
3. 让通讯随时可用。 那就没有这一条了。

## 九 · 相对论时间差

`T` ｜ 无预警 ｜ 星际 ｜ 语料频次：舰船 10.0%

**骨架**｜她出航两年，回来时他已经过了八年。

#### 节拍链

出航决定 → 她两年他八年 → 各自过 → 归来对表 → 鬓角 → 她认真听完那六年 → 下一次怎么办

#### 时间轴

她的两年，他的八年，两本日历没法对账，只能互认。 出航前两人各留了一样东西给对方的时间；她的两年按任务走（紧凑、单调），他的八年按人生走（搬了家、换了工作、老了六岁）。归来对表的那晚，她认真听完那六年，一年一年地听，不许他跳。「下一次怎么办」的讨论隔了一个月才敢开：这道题没有好答案，两个人都知道。

#### 与修仙寿元差的区别

| | 寿元差 | 相对论时间差 |
|---|---|---|
| 差距 | 恒定 | 每次航行累积 |
| 谁老得快 | 他 | 留在原地的那个 |
| 能不能选 | 难 | 可以（不出航） |
| 情绪 | 无奈 | **愧疚**（她的选择造成的） |

**「愧疚」是这条独有的：** 她每一次出航，都是主动选择让他多等六年。

#### 可用细节

| 类 | 内容 |
|---|---|
| 计量 | 她的舰载时钟 vs 地面时钟 · 两个数字的差 |
| 他的变化 | 她走时他二十八，回来时他三十六 |
| 他的生活 | 那六年他做了什么（这一段必须写） |
| 她的不变 | 她还是那个样子 |
| 下一次 | 她要不要再出航 |

「那六年他做了什么」是这条必须写的一段。 他不能只是在等。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 差距 | 两年比六年 | 两年比二十年 |
| 他的六年 | 他在等 | 他过了自己的六年 |
| 她的选择 | 不再出航 | 还要走 |
| 结局 | 她留下 | 他跟她一起走 |

**「他跟她一起走」是最好的解法：** 时间差消失了，代价是他放弃了地面上的一切。

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她回来时他鬓角有白的了 | 这六年我过得挺好 |
| 内心 | 是我让他多过了六年 | 别让她愧疚 |
| 好的处理 | 她问他这六年怎么过的，认真听完 | 他真的过了自己的六年 |
| 写崩 | 写成她的英雄主义牺牲 | 写成他苦守六年 |

#### 写崩的三种方式

1. 让他苦守。 他要有自己的六年。
2. 忽略她的愧疚。 那是这条区别于寿元差的核心。
3. 用一次航行解决。 累积才是这条的机关。

## 十 · 末世的一份口粮

`T` ｜ 无预警 ｜ 末世 ｜ 语料频次：舰船 10.0% 的邻域（末世设定）

**骨架**｜在物资即生命的世界里，把自己那份给对方，是最重的一句情话。

清点 → 分配 → 他说吃过了 → 她发现那份没动 → 生气 → 分了一半 → 他接受了，没再推

#### 时间轴

清点每天一次，谎言的寿命只有一顿饭。 物资按天配给，「我吃过了」说出口到被拆穿不超过六小时，她清点时数目对不上（她对数字的敏感在末世也是武器）。生气十分钟，分一半的仪式五分钟：掰开、递过去、看着他吃完。从那天起分配制度改了：所有口粮当面分、当面吃，把「让」的空间制度性地取消，才是真正的让。

| 守夜 | 真的有危险 |
| 分一半口粮 | 少活几天 |

| 隐瞒 | 他说自己吃过了 · 她发现他的那份没动 |
| 分配 | 谁多谁少 · 谁在偷偷少吃 |
| 无用之物 | 他留着的一样不能吃不能用的东西 |
| 落点 | 两个人为了谁多吃一口而争 |

**「为了谁多吃一口而争」是这条最好的一场戏**，且它比任何情话都直接。

#### 变体轴

| 轴 | 一端 | 另一端 |

| 谁让 | 他 | 她 |
| 说不说 | 明着让 | 偷偷少吃 |

| | 四爱女笔下 | 四爱男笔下 |

2. 忽略计量。 数字是末世设定的语法。
3. 让物资不成问题。 那就不是末世了。

| 6 | 拥抱 | 收在体温上，功法管不到的那部分 |

#### 时间轴

双修是课表，情节是周期差。 初一十五、每逢月圆、卡瓶颈时加课；写一次是场面，写第三次就成了制度。第三次和第一次之间的差（谁先到、蒲团挪近了几寸、话少了多少）就是关系的进度条。

#### 必须合作的身体契约

在别的设定里，亲密要么先谈要么先冲动。这里多出第三种入口：**功法替两个人把话说了。** 契约的三个装置各有一个反转点：

| 装置 | 用法 | 反转点 |
|---|---|---|
| 功法借口 | 「按谱来」「就当功课」，谁都不必先承认想 | 瓶颈一过借口失效，「还修吗」三个字比表白难说 |
| 进度可视化 | 修为涨幅是亲密的公开度量，涨了瞒不住同门 | 月考读数好看的那天，两个人都不敢看对方 |
| 窘迫的归属 | 默认他窘：修为低的一方被带着走 | 她理论满分实操脸红，主导权在中途换手 |

「谁更窘」是这条的主调节钮。 她讲图谱头头是道，掌心相抵那一刻却比他先红，这个反转在双向写法里两边都好用。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 蒲团两只（距离一寸寸挪近）· 功法图谱（翻到那一页停住）· 更漏（周期的计时器）· 檀香 · 掌心 ✓ 相抵的位置 |
| 进度的量具 | 丹田气感 · 经脉图上亮起来的那一段 · 师门月考的修为读数 |
| 借口的说法 | 「功法要求」「按谱来」「就当功课」，说的人音量都会低半度 |
| 外界 | 同门的打趣 · 长老一句「进境不错」，两个人同时僵住 |
| 收尾 | 功课散了谁都没起身 · 投喂 · 谁先把「下次」两个字说出口 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提议 | 她（尊长位，名正言顺） | 他（鼓了很久的勇气，说成「为了宗门大比」） |
| 借口的寿命 | 一直有效（功法长期要求） | 中途失效（瓶颈过了，谁都没提停） |
| 窘迫归属 | 他窘她稳 | 她比他先乱 |
| 修为差 | 她高他低，她带他 | 他资质其实更好，她发现那天的表情管理 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己在等初一十五 | 掌心贴上来之前的那三秒 |
| 内心 | 是功课。她把这两个字默念了三遍 | 灵力是她的，心跳是我自己的 |
| 好的处理 | 她先把「不想修可以说」讲在前头 | 他窘，但他每次都到 |
| 写崩 | 写成她拿功法压人 | 写成他毫无障碍地享受 |

#### 安全与边界

| 线 | 说明 |
|---|---|
| 同意 | 功法要求不等于本人同意，两回事分开写；「不想修可以说」得真的可说 |
| 权力差 | 尊长位、师承位叠加双修时，提出方的位置要被文本意识到 |
| 全员成年 | 涉性情节中的角色均为成年人 |
| 不写可复现细节 | 只写关系结构与推进，具体描写走 [06-尺度与写法](../06-尺度与写法/) |

#### 写崩的三种方式

1. 把双修写成纯功能交易。 丢掉羞耻层，这条就只剩设定说明；窘才是正文。
2. 用功法免除同意问题。 与易感期同一条红线：设定不当免责工具。
3. 修为一步登天。 进度条一次拉满，周期装置就废了；涨幅要小，次数要多。
