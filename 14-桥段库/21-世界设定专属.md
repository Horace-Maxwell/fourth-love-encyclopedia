## 一 · 他的易感期

`T` ｜ 无预警 ｜ 女A男O ｜ 语料频次：易感期 20.0%（易感期＋生病、易感期＋留痕高频同现）

**骨架**｜他管不住自己了，头一回在她面前彻底掉链子。

#### 节拍链

前兆 → 他提前发「别回来」→ 自我隔离 → 她还是回来了 → 她只是坐着 → 潮退 → 清醒后的那场对话

#### 时间轴

**设定里最重的事，是第三天早上聊的。** 潮退之后，俩人都冷静了，谈的是下次还要不要她留下。他第二天赶回来时，最危险的阶段已经过去。前兆第一小时，他趁自己还没失控，发了「别回来」那条消息。最难写的是中间那段时间，她没碰他，也没劝，就坐三步外，坐了一整夜。真正清醒的对话发生在潮退之后。

#### 为什么这条是 ABO 设定的核心价值

在别的设定里，他的顺从是**选择**。在这里，有一段时间他没有选择。

而这恰恰逼出了这个类型最重要的问题：当顺从不再是选择时，这段关系还成立吗？

| 处理 | 说明 |
|---|---|
| 她趁机 | 关系性质变了，且很难写回来 |
| 她不碰，只陪着 | 最能证明这段关系 |
| 她按医嘱处理 | 冷静，但可能显得疏离 |
| 他清醒后的态度 | 这才是这条的落点 |

**「他清醒后的态度」是必须写的：** 他会不会因为自己那个样子而羞耻，她怎么处理这份羞耻。

#### 可用细节

| 类 | 内容 |
|---|---|
| 生理表现 | 体温 · 腺体位置（后颈）· 信息素啥味、多浓 |
| 道具 | 抑制剂 · 阻隔贴 · 药 ✓ · 冰袋 ✓ · 毯子 ✓ |
| 他的挣扎 | 咬着不出声 · 把自己关起来 · 提前发消息 ✓ 让她别回来 |
| 她的处理 | 她还是回来了 |
| 清醒后 | 他不敢看她 · 或者他先开口说了 |

**「提前发消息让她别回来」是这条最好的一个动作：** 在失控之前，他做了最后一件能控制的事。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她在不在 | 在 | 她被他支开了 |
| 有没有发生什么 | 没有 | 有（走 [三 · 标记](#三--标记)） |
| 他的羞耻 | 很重 | 他接受了 |
| 之后 | 两人说开了 | 谁都不提 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她收到那条「别回来」的消息 | 我不想让她看见我这样 |
| 内心 | 他现在最需要有人在 | 这不是我 |
| 好的处理 | 她回来了，什么都没做，只是坐着 | 他清醒后自己提起了这件事 |
| 写崩 | 写成她趁机 | 写成他的失控是情趣 |

「她什么都没做，只是坐着」是这条的最优解。 在一个身体不由自主的时刻，被尊重比被满足重要。

#### 安全与边界

| 线 | 说明 |
|---|---|
| 同意 | 光靠身体反应不算数，这点得在文里写明白 |
| 全员成年 | 凡是有亲密戏的角色，一律都是成年人 |
| 不写可复现细节 | 这条只讲关系怎么搭，具体写法见 [06-尺度与写法](../06-尺度与写法/) |
| 事后处理 | 完事之后得让俩人清醒过来说说话，不能直接跳过去 |

**「生理驱动下的同意是脆弱的」这一点必须在文本里被意识到**，否则 ABO 设定会变成免责工具。

#### 写崩的三种方式

1. 用易感期把「同意」这关糊弄过去。这招最烂，也最常用。
2. 把失控写成调情。但对他来说，那是真没了自己。
3. 醒来之后的事全不写。那才是这条该写的东西。

后接：[二 · 她的信息素](#二--她的信息素) · [三 · 标记](#三--标记)

## 二 · 她的信息素

`T` ｜ 无预警 ｜ 女A男O ｜ 语料频次：易感期 20.0%

**骨架**｜她的味道能让他安静下来，这是这个设定里她唯一专属的东西。

#### 节拍链

日常收着 → 一次安抚 → 依赖成形 → 一次用它赢了争吵 → 他说「刚才那个别再用」→ 之后她只在必要时用

#### 时间轴

「压场子三十秒就完事，吵架吵到一半人忽然没声了」——这茬她记了一天，隔天才等来他一句「刚才那个别再用」。打那以后她添了条规矩：动手前先看他一眼，再决定动不动。非必要不动。那张使用记录，时间轴拉长了看，越往后越稀。稀了，就是懂了。日常收着，用一次记一笔账，一年到头几回，每回几分钟。

#### 信息素作为权力工具

| 用法 | 效果 | 风险 |
|---|---|---|
| 安抚 | 他立刻平静 | 会变成条件反射 |
| 施压 | 他生理性地服从 | 这是强制，要处理 |
| 标记的气味残留 | 宣示 | 见 [05-占有与吃醋 · 留痕](05-占有与吃醋.md#四--留痕) |
| 收敛不放 | 他会不安 | 最微妙的一种 |

**「收敛不放」是这条最有意思的用法：** 她可以不释放，而他会因为闻不到而焦虑。冷落被生理化了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 气味 | 具体是啥味（见 [13-语料挖掘/03-设定元素库](../13-语料挖掘/03-设定元素库.md) 里的信息素气味表） |
| 浓度 | 她平时收着 · 她一进门就放开了 |
| 他的反应 | 肩膀松下来 · 呼吸变沉 · 他自己都没发觉 |
| 依赖 | 他睡不着得抱着她一件衣服 ✓ |
| 边界 | 她拿这个压他一回，这步得想好怎么圆 |

**「她用它来赢一次争吵」是这条的红线场面**，且值得专门写一次并给出后果。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她用不用 | 只在必要时候用 | 天天用，离不开 |
| 他的依赖 | 轻，没啥感觉 | 重到脑子都不清醒 |
| 她有没有滥用 | 没有 | 有过一次，后来她挺后悔 |
| 他知不知道被影响 | 没察觉 | 知道，而且心里不太舒服 |

「他知道自己被影响，且他介意」是这条最有深度的一版。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现刚才是用信息素让他闭嘴 | 我咋突然就不气了 |
| 内心 | 这算不算耍赖 | 那不是我自个儿的想法 |
| 好的处理 | 她后来没再拿这招压他 | 他直接说「刚才那招别再使了」 |
| 写崩 | 写成她随便拿来用 | 写成他乐意被管着 |

#### 安全与边界

信息素施压说白了就是**不让对方自己拿主意**。写可以写，但文本里得让人看出你心里有数：这招用了要付代价，而且对方得有本事顶回来。

参照 [05-占有与吃醋 · 独占欲的边界](05-占有与吃醋.md#十--独占欲的边界) 的同一判据。

#### 写崩的三种方式

1. 把信息素当成万能遥控器。用一次要有一次的账。
2. 让他享受被生理支配。那取消了他的人格。
3. 忽略「他介意」的可能。那是这条的深层。

## 三 · 标记

`M` ｜ ⚠️亲密接触 ｜ 女A男O ｜ 语料频次：易感期 20.0% ＋ 留痕 47.0%

**骨架**｜临时还是永久，这是这设定里最要命的选择。

#### 节拍链

谁提出 → 清醒时的那次确认 → 做或不做 → 气味变化被外界读到 → 制度后果 → 依赖的新形态 → 各自消化

#### 时间轴

提出到确认，隔了一个月。确认那天两个人都得是清醒的。谁先提的那晚不算数，这种事不许当场给答复。那一个月里俩人各查各的资料，各想各的后果。清醒时确认那次就几句话，但日子俩人各自都记着。做完之后的事就不归自己管了。三天内气味的变化同事就闻出来了，一周内制度上的后果全到齐。自己做的决定，公共的钟替你记着。

#### 两种标记的不对称

| | 临时标记 | 永久标记 |
|---|---|---|
| 可逆 | 是 | 否（多数设定） |
| 谁受影响更大 | 他 | 他 |
| 意义 | 保护／宣示 | 结合 |
| 现实类比 | 同居 | 结婚 |
| 拒绝的余地 | 有 | 几乎没有 |

**「谁受影响更大」两栏都是他**，这是 ABO 设定里天生就不对等的地方，也是你写的时候绕不过去的坎：她动一下，变的是他的身子。

#### 可用细节

| 类 | 内容 |
|---|---|
| 位置 | 后颈 ✓ 腺体 |
| 之前 | 谁先提的 · 处了多久 · 到底谈没谈 |
| 之后 | 他身上有她的味儿 · 外人一闻就知道 |
| 社会层面 | 标记要不要备案 · 法律认不认 |
| 解除 | 能不能洗掉 · 得搭进去什么 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提出 | 她 | 他（他要一个保证） |
| 时机 | 深思熟虑 | 易感期中（同意问题，见下） |
| 类型 | 临时 | 永久 |
| 之后 | 他安心了 | 他发现自己变得更依赖了 |

**「他发现自己变得更依赖」是这条最值得写的后果**：得到了想要的东西，代价是失去了一部分独立。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她明白这事回不了头 | 我要她标记我 |
| 内心 | 我动的是他的身子 | 这样她就不会走了 |
| 好的处理 | 她趁他清醒问过一回 | 他说清了为啥非要这个 |
| 写崩 | 把占有欲写得像深情 | 写他靠标记找踏实感 |

**「他用标记求安全感」这一端要谨慎处理**：它真实，但文本要指出这不是解决办法。

#### 安全与边界

| 线 | 说明 |
|---|---|
| 同意的时点 | 易感期里点头不算数，大事得等人清醒了再定 |
| 不可逆性 | 写的时候得让读者感觉到这事没法回头 |
| 全员成年 | 沾性的情节里，角色都是成年人 |
| 不写可复现细节 | 只写俩人啥关系、后来咋样，具体咋写的看 [06-尺度与写法](../06-尺度与写法/) |

#### 写崩的三种方式

1. 易感期里直接永久标记，还不问对方愿不愿意——这设定被用烂了，几乎成套路。
2. 把不可逆当成浪漫写。可不可逆首先是个重担，不是糖。
3. 社会层面全当不存在。大多数设定里，标记这件事有制度后果。

## 四 · 他要不要用抑制剂

`T` ｜ 无预警 ｜ 女A男O ｜ 语料频次：易感期 20.0%

**骨架**｜一个能让他不失控的东西，用不用，他说了算。

#### 节拍链

工作要求 → 常规剂量 → 偷偷加量 → 副作用露头 → 她数药盒 → 「在家不用打」→ 新的平衡

#### 时间轴

副作用冒出来那阵子，手抖、失眠轮流找上门。她数药盒，只花了十秒。职业病让她对数字格外敏感，一下就看出了不对劲。之前常规剂量用了半年，一直没事。加量是逐月加上去的，每月多打一支，连打三个月。被发现却是一瞬间的事。「在家不用打」这五个字，当天晚上就生效了。用量降下来的那条曲线，是每个季度慢慢稳住的。这招管用，也是证明。

#### 这条是 ABO 设定里最现实的一条

抑制剂在这个设定里的位置，跟现实中那些让身体去符合社会要求的手段差不多。问题也一样：

| 问题 | 说明 |
|---|---|
| 有没有副作用 | 长期使用伤身 |
| 谁在要求他用 | 工作？社会？她？ |
| 他自己想不想用 | 用了他更自由，也更不像自己 |
| 停用之后 | 反弹 |

「谁在要求他用」是这条的核心。 如果是她要求的，性质就完全不同了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 药 ✓ 盒 ✓ · 注射 · 阻隔贴 · 剂量记录 |
| 他的隐瞒 | 剂量偷偷加了，没跟她说 |
| 副作用 | 犯困 · 反应慢 · 晕过一回 |
| 她的发现 | 见 [15-秘密与坦白 · 他有一件事没说](15-秘密与坦白.md#一--他有一件事没说) |
| 落点 | 她来一句「在家就别打了」 |

「在家不用打」是这条最好的一句台词。 它给了他一个可以不被抑制的地方。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁要求 | 工作／社会 | 她（要处理） |
| 他的态度 | 主动用 | 抗拒 |
| 剂量 | 正常 | 超量（隐瞒） |
| 结果 | 停了 | 一直在用 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她数了他的药 ✓ 盒 ✓ | 这样才能正常上班 |
| 好的处理 | 她说「在家不用」 | 他承认自己超量了 |
| 写崩 | 写成她要求他用 | 写成他为她牺牲身体 |

#### 写崩的三种方式

1. 让她提要求，他照做，但文本不处理。那是控制。
2. 副作用别写。代价才是这条线压秤的地方。
3. 写成他一个人扛，别写两人商量。他得有他自己的理由。

## 五 · 寿元差

`T` ｜ 无预警 ｜ 修仙 ｜ 语料频次：寿元 10.0%

**骨架**｜她能活八百年，他只能活六十年。这是算数，不是矛盾。

#### 节拍链

数字摆上桌 → 三种解法议过 → 选定或搁置 → 他的白发第一次出现 → 旁人误认 → 一个平常的饭桌场面

#### 时间轴

日子过到这个份上，那碗粥还在饭桌上。只是喝粥的工夫，一天比一天紧巴。八百年对六十年，差距摆出来，谁心里都得咯噔一下。可这事反倒没人再提了。那晚聊了一整夜。渡他、封存、认了，三条路翻来覆去地掰扯。最后谁也没拍板，就这么搁下了。日子照过，搁着搁着就成了默认。从第二十年起，外人就开始认错人，张口就是「令郎？」他头一根白头发是第十五年冒出来的。她帮他拔掉那会儿，俩人谁都没吭声。

#### 为什么这是修仙设定最有价值的东西

它把「时间不对等」变成了**物理事实**，而所有关于承诺、等待、遗忘的桥段在这里都会自动加重：

| 普通设定 | 修仙设定 |
|---|---|
| 他等了她三年 | 他等了她三百年 |
| 她忘了三个月前的事 | 她忘了三百年前的事 |
| 「我会一直陪着你」 | 这话搁这儿算不过来账 |
| 一辈子 | 谁的一辈子 |

「谁的一辈子」是这条唯一的问题。

#### 三种解法

| 解法 | 代价 |
|---|---|
| 他修上去 | 需要资质、时间、机缘。最常见 |
| 她降下来 | 她放弃修为。极重，且要处理她的意愿 |
| 都不解决 | 他老去，她看着。最疼 |

第三种在语料里最少，也最值得写。

#### 可用细节

| 类 | 内容 |
|---|---|
| 时间的可见化 | 他白了头 · 他手上有老茧 · 她还是老样子 |
| 旁人 | 别人看他们像母子／师徒 |
| 他的努力 | 他闭关了多少回 · 他吞了多少丹药 |
| 她的准备 | 她一直等那天，先不挑明 |
| 落点 | 一个他老了、她没老的平常日子 |

**「一个他老了她没老的日常场面」比任何生离死别都重：** 两个人一起吃饭，一个人的手在抖。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 差距 | 一倍 | 十倍 |
| 解法 | 他修上去 | 都不解决 |
| 她的态度 | 想尽办法 | 接受了 |
| 结局 | 一起 | 她一个人活下去 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她头一回瞅见他手背上的斑 | 她还是老样子 |
| 内心 | 我该怎么准备这一天 | 我在追一个追不上的人 |
| 好的处理 | 她没说“我会一直陪着你” | 他没因为这事撂挑子 |
| 写崩 | 写成她随便就把他命续上了 | 写成他觉得自己配不上就撤了 |

#### 写崩的三种方式

1. 轻易给他续命。那是把设定的价值扔掉了。
2. 用「我会一直陪你」收场。放在这种设定里，那句话是空的。
3. 只写悲，不写日常。老去是在日常里发生的。

## 六 · 她闭关

`T` ｜ 无预警 ｜ 修仙 ｜ 语料频次：闭关 15.0%（闭关＋请安、闭关＋公开高频同现）

**骨架**｜她进去了，出来是几年后。这几年，是他一个人熬过来的。

#### 节拍链

定了闭关 → 交代 → 洞门关上 → 他守着，也过日子 → 里面没了动静的那天 → 出关 → 她的第一眼

#### 时间轴

她出关推门那天，看见的是个比记忆里稳当多了的人。洞门一关，里面和外面就是两个时间。她在洞里感觉不到日子过。他在外面一年一年数着过。那本册子拿在手里沉甸甸的。他记了整整三年，里面一页页写的都是「今日无事」。可这两个字写了一千遍，就不是无事那么简单了。第一年守着。第二年边守边过日子，该忙啥忙啥。第三年洞里彻底没了动静。那三个月他干脆守在洞口，没挪地方。

#### 与「出差」的根本区别

| | 出差 | 闭关 |
|---|---|---|
| 时长 | 可知 | 不可知 |
| 联系 | 可以 | 完全不能 |
| 意外 | 会通知 | 他不知道里面发生了什么 |
| 他能做的 | 等 | 守 |

**「他不知道里面发生了什么」是这条的全部看点：** 她可能出关，可能走火入魔，可能死在里面，而他只能守着一扇门。

#### 可用细节

| 类 | 内容 |
|---|---|
| 时间的计量 | 他在洞口划道道 · 换过几回灯油 ✓ · 看山下的树 |
| 他做的事 | 守着 · 布阵 · 把找上门的人打回去 |
| 异动 | 里头有动静了 · 阵法的光颜色不对 |
| 他的煎熬 | 有一回里头彻底没声了 |
| 出关 | 她头一眼瞧见啥 |

**「她出关第一眼看见的是什么」是这条的落点：** 是他，且他已经在这儿守了很久。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时长 | 三个月 | 三十年 |
| 他守不守 | 守着 | 他有自己的事要做 |
| 期间 | 平安 | 出了事 |
| 出关时 | 他在 | 他不在了（最疼） |

**「他不在了」这一端是修仙设定独有的残酷**：她进去时他还年轻，出来时他已经不在。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 出关时洞外的痕迹 | 今天是第七百天 |
| 好的处理 | 她一出关就先去找他 | 他守着，但日子照常过 |
| 写崩 | 写成一出关啥都摆平了 | 写成他死等，人瘦脱了相 |

「他守着，但他也过自己的日子」是这条最健康的处理。

#### 写崩的三种方式

1. 他得有自己的日子要过，不能光写一个人在里头熬。
2. 里面和外面都得有戏，闭关不能只是时间上跳过去。
3. 那才是闭关跟出差不一样的唯一地方，别管「不知道里面怎么样」。

## 七 · 渡劫

`T` ｜ 无预警 ｜ 修仙 ｜ 语料频次：双修 6.0% ＋ 闭关 15.0%

**骨架**｜天要劈她。而他能做的极其有限。

#### 节拍链

天象起 → 她入阵他守外 → 一道道数 → 最后一道 → 他守住了位置 → 她过了 → 第一句话是问他

#### 时间轴

**阵外守到第七道时，阵光晃了一下，他的脚动了半步又钉回去——进去就是害她。** 天象起到第一道落，半个时辰。之后的节奏由天定：一道比一道密、一道比一道沉。九道雷，一道一拍，他数着。数到第九道砸下，烟尘散开的那几秒，是他一生最长的几秒。她睁眼第一句问的是他，嗓子是哑的。

#### 这条为什么好用

它是修仙设定里的**结构性无力时刻**：她面对的是天，他帮不上。

而「帮不上」正是这条的内容：

| 他能做的 | 说明 |
|---|---|
| 布阵 | 分担一点 |
| 递丹药 | 在间隙 |
| 挡一道 | 他会死，且她不许 |
| 在场 | 最重要的一件 |
| 事后 | 见 [16-危机与保护 · 她受伤了](16-危机与保护.md#四--她受伤了) |

**「在场」是他唯一真正能做的事**。这事跟 [01-日常照料 · 守着不睡](01-日常照料.md#六--守着不睡) 是同一件事，只是走到了极端版。

#### 可用细节

| 类 | 内容 |
|---|---|
| 天象 | 雷云压了几层 · 两道雷隔多久 |
| 他的位置 | 站在阵外 · 她不让进 |
| 他的动作 | 数着雷 · 每打完一道就看她还在不在 |
| 她的状态 | 一道雷下来，人就矮一截 |
| 最后一道 | 他冲进去了 · 也可能没冲 |

**「他没有冲进去」这一版更难写也更有分量：** 她要他守住阵眼，他守住了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他能不能帮 | 能帮一点 | 完全帮不上 |
| 他冲不冲 | 冲了 | 守住了自己的位置 |
| 结果 | 她过了 | 她伤得很重 |
| 之后 | 她说了什么 | 她什么都没说 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 第七道之后她看见他还在原地 | 第七道 |
| 内心 | 别过来 | 她说了别过来 |
| 好的处理 | 她过了之后第一句是问他 | 他守住了她交代的位置 |
| 写崩 | 写成他挡雷替死 | 写成他在旁边哭 |

**「他挡雷替死」是这条最俗的一个走向**，且它取消了她的主体性——她的劫由她自己渡。

#### 写崩的三种方式

1. 让他替她挡。那是她的劫。
2. 让他毫无作用。在场就是作用。
3. 省略间隙。每两道雷之间的那几秒是全部内容。

## 八 · 通讯延迟

`T` ｜ 无预警 ｜ 星际 ｜ 语料频次：舰船 10.0%

**骨架**｜他说完一句，得等四个钟头，才听见她回话。

#### 节拍链

出航 → 定通讯窗口 → 录制与等待 → 一次情绪错位 → 「等你收到这条的时候」句式成形 → 静默期 → 恢复

#### 时间轴

通讯窗口每天两班。一句话出去，答案四小时后才到。情绪老是错位。四小时的往返延迟，把对话切成了信件。他委屈的时候，收到的是她四小时前那句玩笑。静默期三天。这是这条线最熬人的时候。三天后恢复通讯的第一条，两边几乎同时发出。内容一模一样。「等你收到这条的时候」这个句式第二周就成形了。从此每条消息都自带时间标注。

#### 这是星际设定最独一无二的东西

所有别的设定里，对话是同步的。这里不是。

而不同步造成的东西，别处造不出来：

| 现象 | 说明 |
|---|---|
| 每句话都是对着空气说的 | 说的时候不知道会得到什么 |
| 四小时的反刍 | 他会把自己说的话回想很多遍 |
| 答非所问 | 她回的是四小时前的问题 |
| 情绪错位 | 他难过时她还在为上一条高兴 |
| 无法打断 | 只能听完 |
| 无法安慰 | 等他的安慰到了，她早就过去了 |

「情绪错位」是这条最好的素材。他录了一段很难过的话，她收到时已经过了四小时。她的回复到他那里又是四小时。八小时后他早就好了，却收到了一段安慰。

#### 可用细节

| 类 | 内容 |
|---|---|
| 通讯记录 | 时间点 · 有没有延迟 · 录了多久 |
| 他的习惯 | 每条都唠很久 · 要么就只说重点 |
| 她的习惯 | 话少 · 但每条都接 |
| 断联 | 跃迁那阵子没信号，啥也收不着 |
| 落点 | 有条他录好了，但没发出去 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 延迟 | 四小时 | 数周 |
| 谁在远处 | 她 | 他 |
| 内容 | 日常 | 一件必须马上说的事 |
| 结果 | 撑住了 | 有一条来得太晚 |

「有一条来得太晚」是这条的最强用法。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看到这条时，他那边已经过了四小时 | 他说完这话，又过了四小时 |
| 好的处理 | 她回的是他此刻正缺的那句话，不是四小时前的旧账 | 他学会了说「等你看到这条的时候」 |
| 写崩 | 写成了普通异地恋 | 写成了他掐着表干等 |

**「等你收到这条的时候」这个句式是星际版的专属语法**，值得反复用。

#### 写崩的三种方式

1. 写成普通异地恋。延迟必须造成具体的错位。
2. 忽略时间戳。那是这条的度量衡。
3. 让通讯随时可用。那就没有这一条了。

## 九 · 相对论时间差

`T` ｜ 无预警 ｜ 星际 ｜ 语料频次：舰船 10.0%

**骨架**｜她出海两年，回来时他已经老了八岁。

#### 节拍链

出航决定 → 她两年他八年 → 各自过 → 归来对表 → 鬓角 → 她认真听完那六年 → 下一次怎么办

#### 时间轴

出发前，俩人都给对方的这段时间留了个念想。回来那天晚上对表。她那两年是跟着任务走的。挤得满满当当，日子没变化。他那八年是跟着日子走的。搬了家、换了工作、老了六岁。她认认真真把那六年听完。一年接一年，不让他跳。两本日历对不上。只能互相认账。他的八年，她的两年。隔了一个月，俩人才敢聊「下一次怎么办」。这题没解。谁心里都明白。

#### 与修仙寿元差的区别

| | 寿元差 | 相对论时间差 |
|---|---|---|
| 差距 | 恒定 | 每次航行累积 |
| 谁老得快 | 他 | 留在原地的那个 |
| 能不能选 | 难 | 可以（不出航） |
| 情绪 | 无奈 | **愧疚**，她的选择造成的 |

**「愧疚」是这条独有的：** 她每一次出航，都是主动选择让他多等六年。

#### 可用细节

| 类 | 内容 |
|---|---|
| 计量 | 她船上的钟比地面的钟慢多少 · 两个数一减 |
| 他的变化 | 她走那年他二十八，回来他三十六了 |
| 他的生活 | 那六年他怎么过的，这段非写不可 |
| 她的不变 | 她一点没变，还是老样子 |
| 下一次 | 她还走不走 |

「那六年他做了什么」是这条必须写的一段。 他不能只是在等。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 差距 | 两年比六年 | 两年比二十年 |
| 他的六年 | 他在等 | 他过了自己的六年 |
| 她的选择 | 不再出航 | 还要走 |
| 结局 | 她留下 | 他跟她一起走 |

**「他跟她一起走」是最好的解法：** 时间差消失了，代价是他放弃了地面上的一切。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她回来时他鬓角有白的了 | 这六年我过得挺好 |
| 内心 | 是我让他多过了六年 | 别让她愧疚 |
| 好的处理 | 她问他这六年怎么过的，认真听完 | 他真的过了自己的六年 |
| 写崩 | 写成她自我感动硬扛 | 写成他死等六年没挪窝 |

#### 写崩的三种方式

1. 让他苦守。他得有自己的六年。
2. 别管她愧疚不愧疚。这条跟寿元差不一样，靠的就是这个。
3. 一次航行全解决。这条的关键是攒，攒够了才发动。

## 十 · 末世的一份口粮

`T` ｜ 无预警 ｜ 末世 ｜ 语料频次：舰船 10.0% 的邻域（末世设定）

**骨架**｜在物资就是命的地方，把口粮让给你，比说啥都管用。

#### 节拍链

清点 → 分配 → 他说吃过了 → 她发现那份没动 → 生气 → 分了一半 → 他接受了，没再推

#### 时间轴

她改分配制度那天起，物资按天配给。每天清点一次。所有口粮当面分、当面吃，不留转手的空隙。谎言撑不过一顿饭的工夫。她生气只十分钟。分一半的仪式却要五分钟：掰开、递过去，看着他吃完。「我吃过了」从说出口到被拆穿不超过六小时。她真正做的，是把「让」从规则里整个拿掉。不给余地。她对数字的敏感在末世照样是武器。数目对不上，一眼就看得出。

#### 末世设定的唯一机关：让温柔有价

| 日常动作 | 末世里的代价 |
|---|---|
| 做一顿饭 | 吃掉省下的罐头 |
| 留一盏灯 | 烧掉发电机的油 |
| 洗一次头 | 用掉三天的水 |
| 送一样没用的东西 | 白扔东西，图个心里舒坦 |
| 守夜 | 真会出事 |
| 分一半口粮 | 自己少撑几天 |

这一条不需要新桥段，它是给前面二十卷所有桥段加上价格标签的装置。

#### 可用细节

| 类 | 内容 |
|---|---|
| 计量 | 还剩几罐 · 还能撑几天 · 水到哪了 |
| 隐瞒 | 他说吃过了 · 她看见他那份没动 |
| 分配 | 谁多谁少 · 谁背地里省着吃 |
| 无用之物 | 他留了件不能吃不能用的东西 |
| 落点 | 俩人争着让对方多吃一口 |

**「为了谁多吃一口而争」是这条最好的一场戏**，且它比任何情话都直接。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁让 | 他 | 她 |
| 说不说 | 明着让 | 偷偷少吃 |
| 被发现 | 是 | 一直没发现 |
| 结局 | 撑过去了 | 有人撑不住 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他罐头是空的，但没动过 | 我说我吃过了 |
| 好的处理 | 她火了，把自己那份拨给他一半 | 他收下了，没再让 |
| 写崩 | 写成俩人抢着饿肚子的苦情戏 | 写成他把自己饿死还挺光荣 |

**「他接受了，没有再推」是这条的成熟解法：** 在生存面前，推让本身是一种浪费。

#### 写崩的三种方式

1. 写成互相牺牲的煽情。不如写争一口吃的具体场面，那个更有劲。
2. 忽略计量。数字就是末世设定的语法。
3. 让物资不成问题。那还叫末世吗。

## 十一 · 双修

`M` ｜ ⚠️亲密接触 ｜ 修仙 ｜ 语料频次：双修 6.0%（187 部）

**骨架**｜这功法得俩人一起练，往后想亲近也不用谁先开口找话了。

双修 → 偏见 → 投喂 → 撒娇 → 怔住 → 拥抱

这条链在语料里原样出现 7 部，顺序可照抄（[13-语料挖掘/07-桥段分布 §五](../13-语料挖掘/07-桥段分布.md)）。逐拍落位：

| 拍 | 节拍 | 落在这场戏里 |
|---|---|---|
| 1 | 双修 | 到日子了，两个人面对面坐着练功 |
| 2 | 偏见 | 外人看见了：同门开几句玩笑，长老说句「练得还行」 |
| 3 | 投喂 | 练完功，一碗热粥放旁边，灵力退了心里空，正好垫一口 |
| 4 | 撒娇 | 趁灵力还没散干净，他把平时不敢说的话说了 |
| 5 | 怔住 | 她一口答应，俩人都没反应过来 |
| 6 | 拥抱 | 最后抱在一起，体温能暖到的地方，功法管不着 |

#### 时间轴

双修是课表，情节是周期差。初一十五、每逢月圆、卡瓶颈时加课。写一次是场面，写第三次就成了制度。第三次和第一次之间的差，就是关系的进度条。谁先到、蒲团挪近了几寸、话少了多少，读者全看在眼里。

#### 必须合作的身体契约

别的设定里，俩人要么先谈明白，要么先冲动一把。这个设定里多了一条路：**功法直接把话替俩人说了。** 契约里三个机关，每个都埋了个反转点：

| 装置 | 用法 | 反转点 |
|---|---|---|
| 功法借口 | 「按谱来」「就当功课」，谁都不必先承认想 | 瓶颈一过借口失效，「还修吗」三个字比表白难说 |
| 进度可视化 | 修为涨幅是亲密的公开度量，涨了瞒不住同门 | 月考读数好看的那天，两个人都不敢看对方 |
| 窘迫的归属 | 默认他窘：修为低的一方被带着走 | 她理论满分实操脸红，主导权在中途换手 |

「谁更窘」是这条的主调节钮。她讲图谱头头是道，掌心相抵那一刻却比他先红。这个反转，双向视角里两边都能用。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 蒲团两只，一寸一寸挪近 · 功法图谱，翻到那一页停住 · 更漏，算着时间 · 檀香 · 掌心 ✓ 贴住的位置 |
| 进度的量具 | 丹田有没有气感 · 经脉图亮到哪一段 · 师门月考修为涨了多少 |
| 借口的说法 | 「功法要求」「按谱来」「就当功课」，说的时候声音都低半截 |
| 外界 | 同门拿他俩打趣 · 长老一句「进境不错」，俩人同时愣住 |
| 收尾 | 功课散了谁也没走 · 递点吃的 · 谁先憋不住说「下次」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提议 | 她，长辈身份，开口不突兀 | 他憋了好久，拿「为了宗门大比」当由头 |
| 借口的寿命 | 一直管用（功法得长期练） | 用着用着不灵了，瓶颈过了，谁也没提停 |
| 窘迫归属 | 他慌她不慌 | 她先乱了阵脚 |
| 修为差 | 她强他弱，她带他 | 他其实更有天赋，她发现那天脸上挂不住 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己老在盼初一十五 | 掌心贴上来之前的那三秒 |
| 内心 | 是功课，她跟自己说了三遍 | 灵力是她的，心跳是我自己的 |
| 好的处理 | 她先把话撂下：不想修可以说 | 他窘，但他每次都来 |
| 写崩 | 写成她拿功法压人 | 写成他一点不别扭就享用了 |

#### 安全与边界

| 线 | 说明 |
|---|---|
| 同意 | 功法要求不等于本人愿意，两码事分开写。「不想修可以说」得真能说出口 |
| 权力差 | 长辈、师父这种身份压着，再提双修，谁先开口、怎么开口，文里得心里有数 |
| 全员成年 | 沾性的事，角色一律是成年人 |
| 不写可复现细节 | 只写关系怎么走、怎么推，具体场面去 [06-尺度与写法](../06-尺度与写法/) |

#### 写崩的三种方式

1. 修为一步登天，进度条一次拉满，周期设定就白做了。涨幅小一点，次数多一点，才有效果。
2. 把双修写成纯功能交易，羞耻感一丢，这就剩个设定说明。写得窘迫，才是正经内容。
3. 用功法把同意问题绕过去，这跟易感期是同一个雷区，设定不能拿来当免责牌。
