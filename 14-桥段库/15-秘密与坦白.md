# 秘密与坦白

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**信息不对称就是权力不对称。谁知道得多，谁就在上面。**

---

## 秘密在这一类里的特殊算法

在一段权力不对称的关系里，秘密的分布会放大或抵消这种不对称：

| 谁有秘密 | 效果 |
|---|---|
| 她有，他不知道 | 落差加倍。她占着位置，又握着消息 |
| 他有，她不知道 | 落差没那么大。他手里多了张她没见过的牌 |
| 双方各有 | 最勾人 |
| 都没有 | 关系稳当，就是没火花 |

第二行是这个类型最好用的结构。 弱势方唯一能持有的筹码，往往就是一个她不知道的事。

| 节拍族 | 作品数 | 占比 |
|---|---:|---:|
| 掉马 | 897 | 31.0% |
| 前任 | 897 | 31.0% |
| 旧地 | 463 | 16.0% |
| 坦白 | 174 | 6.0% |
| 隐瞒 | 145 | 5.0% |

「坦白」占6%，「隐瞒」占5%，在全部情境族里垫底。这类情节其实不少见，但大多混在别的场面里，很少单独拎出来写。反过来讲，真把它单独写好，读者一眼就能记住。

## 一 · 他有一件事没说

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：隐瞒 5.0%（低频高价值）

**骨架**｜他手里攥着一件事，她一直不知道。他天天都在琢磨，今天到底说不说。

#### 节拍链

秘密成形 → 每天决定说不说 → 拖延变成新的罪 → 外部逼近 → 三次机会都放过了 → 说或被揭

#### 时间轴

每天一次的「今天说不说」，就是这条的钟摆。秘密本身不动，拖着不说才要命：瞒到第十天，罪名就从「有事没说」变成了「瞒了十天」，刑期跟着天数涨。外面逼得越紧，钟摆晃得越快：三次开口机会各有各的时机，一次比一次好开口，也一次比一次更接近被掀底。

#### 秘密的量级表

选错量级会毁掉整条线。这张表按「被发现之后关系还能不能修复」排：

| 量级 | 内容 | 修复难度 |
|---|---|---|
| 轻 | 他偷偷做了件好事 | 不用改，算加分项 |
| 中 | 他家境／学历／以前干啥的 | 安排一场对话就行 |
| 中重 | 他一开始接近她是有目的的 | 得铺一整条线 |
| 重 | 他连身份都是骗她的 | 基本圆不回来 |
| 过重 | 干过伤害她的事 | 别写，写了这角色就废了 |

中重那一档是这个类型最常用也最合适的：一开始是故意接近，后来动了真心。这样掉马的时候分量够足，又不至于让他没法被原谅。

#### 可用细节

| 类 | 内容 |
|---|---|
| 藏的痕迹 | 一个他从不接的电话 · 一个抽屉 · 某个话题他会绕开 |
| 他的每日决定 | 今天想说 → 时机不对 → 又拖了一天 |
| 越拖越难 | 瞒得越久，越觉得开不了口 |
| 她的察觉 | 她早就觉得有事，就是不知道是什么 |
| 逼近 | 外面出了件事，秘密快兜不住了 |

「隐瞒的时间本身变成了新的罪」，这是这条里最重要的一条规律。到后来他怕的已经不是那件事本身，怕的是「我为什么没早点说」。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他为什么瞒 | 怕失去她 | 为了保护她 |
| 她知不知道有事 | 完全不知道 | 早就知道，在等他自己说 |
| 曝出方式 | 他自己说 | 被别人揭穿 |
| 结果 | 过去了 | 关系变了 |

「她早就知道，在等他自己说」是最好的一版。 它把主动权留给他，也让她的形象立得住。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她还在等，等了挺久 | 今天还是没说出口 |
| 内心 | 我给他点时间 | 明天，明天再说 |
| 好的处理 | 她定了日子，但没戳破 | 他赶在被发现之前自己招了 |
| 写崩 | 写成她啥都知道 | 写成他啥都不干，等着被拆穿 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他的出身／他是细作／他背着旧仇 |
| 修仙 | 他的功法来路／他体内的东西／他的真身 |
| 星际 | 他的档案被改过／他的编号是假的 |

#### 写崩的三种方式

1. 秘密压得太死。压到没法原谅，后面就没法写了。
2. 让他一直没机会主动开口。至少要给他三次机会，而且他每次都放弃。
3. 靠别人揭穿来收场。得他自己说，才够分量。

## 二 · 掉马

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：掉马 31.0%（掉马＋请安、掉马＋和好高频同现）

**骨架**｜遮不住了，但这一刻最值钱的，就是她那一瞬间的反应。

#### 节拍链

触发物到场 → 那一秒 → 她放下手里的东西 → 「还有别的吗」→ 先处理事务 → 她需要的时间 → 交代而非道歉

#### 时间轴

掀开只要一秒，她把时间切成了三段。第一段是那半秒的静，全场都屏着气。第二段是处理正事，一个小时里，她该干嘛干嘛，情绪一点没耽误事。第三段是她自己需要的时间，三天或一周，她直接报了个数，到点再来谈。报时长这个动作本身就是她的风格，连消化情绪都得排个期。

#### 掉马的四种时机

| 时机 | 效果 |
|---|---|
| 关系刚开始 | 伤害小，但也没重量 |
| 关系正好的时候 | 最疼，也最常用 |
| 她刚刚为他做了一件大事之后 | 最狠 |
| 她已经猜到之后 | 转成「她早知道」，见第三条 |

第三行是这条的最强配置： 她刚顶着压力护了他，转头发现他一直在骗她。

#### 她的第一反应，五个版本

这一秒决定这个角色是谁：

| 反应 | 说明 |
|---|---|
| 发怒 | 最直接，但最浅 |
| 平静地问「还有别的吗」 | 冷，且致命 |
| 先处理事务再处理情绪 | 最符合这类角色 |
| 什么都不说，转身走 | 最重 |
| 「我知道」 | 转成第三条 |

「先办事再谈心情」是这个类型的招牌反应。眼下这摊子事还没收尾，她先收拾干净，回头才轮到自己难受。

#### 可用细节

| 类 | 内容 |
|---|---|
| 曝出方式 | 一个电话 · 一个人出现 · 一份文件 · 一句口误 |
| 那一秒 | 环境音 · 她手上的动作停了 · 他知道自己完了 |
| 他的表现 | 不辩解 · 或者说了最不该说的一句「我可以解释」 |
| 她的动作 | 把手里的东西放下，不是摔 |
| 事后 | 她需要多久缓过来 · 这段时间她干了啥 |

「我可以解释」是掉马场最差的一句台词。语料里高频出现，但它把主动权交到对方手里，听起来还像在拖时间。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 曝出方式 | 意外 | 他自己说的 |
| 她的反应 | 爆发 | 平静（更可怕） |
| 严重程度 | 可原谅 | 需要很久 |
| 收场 | 原谅 | 原谅但不复原 |

「原谅但不复原」是成年人关系的真相。 见 [04-委屈与破防 · 说了狠话](04-委屈与破防.md#七--说了狠话) 的同一条。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把手里的东西放下 | 她没有摔，这更糟 |
| 内心 | 先把这件事处理完 | 完了，她连生气都懒得 |
| 好的处理 | 她要一个完整的交代，不要道歉 | 他一次说完，不挤牙膏 |
| 写崩 | 写成她当场原谅 | 写成他跪地哀求 |

「要交代不要道歉」是她这个角色最好的一句要求。 道歉是情绪，交代是事实。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 身份败露／细作／旧主找上门／族谱被翻出来 |
| 修仙 | 真身现形／功法来路暴露／魔气外泄 |
| 星际 | 档案被调出／基因比对／旧编号被识别 |

#### 写崩的三种方式

1. 让她当场原谅。那前面藏的意义就没了。
2. 让他辩解。一次说完，别挤牙膏。
3. 掉马之后没有余震。至少留一章的不对劲。

## 三 · 她早知道

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：掉马 31.0% 的变体

**骨架**｜他鼓足勇气坦白，她说「我知道」。

#### 节拍链

他坦白 → 「我知道」→ 你什么时候知道的 → 为什么不说破 → 你打算瞒到什么时候 → 她说了她在意的那一点

#### 时间轴

两条时间线一对，当场就对不上号了。他这头：秘密藏了八个月，坦白的话在脑海里反复排了两周。她那头：第三周就察觉了，却硬是耐着性子等他开口等了七个月。对上的那一瞬他脑子一片空白，敢情这七个月里，她每天都在给他递台阶。她等了多久，就说明这段关系在她心里还剩下多少信任额度。

#### 这条为什么比掉马更有力

因为它把权力关系写到了极致：她一直掌握着全部信息，而她选择了等。

这既是宠溺也是掌控，两种读法同时成立，这就是它的厚度。

#### 「我知道」之后的三个问题

这三个问题是这条戏的正文：

| 问题 | 谁问 |
|---|---|
| 「你什么时候知道的」 | 他 |
| 「为什么不说破」 | 他 |
| 「你打算瞒到什么时候」 | 她 |

第三个问题是她唯一的怒气所在。 她不在意那件事，她在意他准备瞒多久。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她知道的时点 | 比他以为的早得多，往往在关系开始之前 |
| 她的证据 | 一份她早就调过的资料 · 一个电话 · 她认识那个人 |
| 她为什么等 | 想看他自己说，或者那件事对她不重要 |
| 他的崩溃点 | 不是被识破，是「原来我一直在她眼皮底下演」 |
| 收束 | 她说了她在意的那一点 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 知道多久 | 一段时间 | 从一开始 |
| 她为什么不说 | 等他 | 那件事她不在意 |
| 他的感受 | 释然 | 更难受，他一直在被看着 |
| 关系变化 | 更近 | 他开始怀疑，还有什么她知道而他不知道 |

最后一行是这条的高阶用法： 揭穿之后，不对称反而更明显了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她说「我知道」那一下的语气 | 原来这三年我都在演给她看 |
| 内心 | 我在等他开口 | 她看我演了三年 |
| 好的处理 | 她把为什么等讲明白了 | 他确实难受，而且他说出口了 |
| 写崩 | 把她写成啥都知道的神仙 | 把他写成感恩戴德的样子 |

「她全知全能」是这条最大的陷阱。 要给她一个不知道的点，哪怕很小。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她早查过他的底／案卷一直在她手上 |
| 修仙 | 她的神识早已探过／她认得他的功法出处 |
| 星际 | 她一开始就调过他的真实档案 |

#### 写崩的三种方式

1. 让她全知。留一个她不知道的点。
2. 让他只有感激。「被看了三年」的难受要写。
3. 省略「你打算瞒到什么时候」。那是她的真正情绪。

## 四 · 前任出现

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：前任 31.0%（前任＋失联、前任＋告别高频同现）

**骨架**｜有一个人知道他们不知道的过去。

#### 节拍链

出现（饭局·工作·照片）→ 得体寒暄 → 旧梗飘过 → 他全程正常 → 回家路上安静 → 她主动说了那段 → 界限

#### 时间轴

现场两小时滴水不漏，回程二十分钟见真章。饭局上两人都戴着社交面具，谁也没露馅，时间就这么平平稳稳过去了。上车之后谁都没吭声，从第一个路口一直安静到第五个，她才开口提那段旧事，而且特意挑在快到家的时候才说。讲完正好下车，根本不给话题留过夜的机会。界限当晚就划清楚，不拖到第二天，这才算干净。

#### 谁的前任，写法完全不同

| 谁的 | 主要冲突 | 谁难受 |
|---|---|---|
| 她的前任 | 那个人往往和她「更般配」（同层级） | 他 |
| 他的前任 | 那个人往往见过他的另一面 | 她 |
| 双方都有 | 对照组结构 | 都难受 |

「她的前任和她更般配」是这个类型最扎人的配置。那个人有他缺的东西：同等地位、共同语言，不需要被照顾。

#### 可用细节

| 类 | 内容 |
|---|---|
| 出现方式 | 同一个饭局 · 工作对接 · 老照片 ✓ · 一个共同的朋友 |
| 那个人的态度 | 客客气气，最难搞 · 或者上来就呛，好办 |
| 她的态度 | 跟没事人一样 · 越这样他越心里发毛 |
| 他的观察 | 他俩说话那劲儿 · 一个只有他俩懂的旧梗 |
| 他的反应 | 当场没露馅 · 回家路上一直闷着 |

「得体的前任」比「挑衅的前任」难写十倍，也有效十倍。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 前任的态度 | 得体 | 想复合 |
| 她的态度 | 划清界限 | 保持正常往来（会有戏） |
| 他的反应 | 忍 | 问了 |
| 收场 | 她给了明确的话 | 悬着 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看出他今晚不对劲 | 他俩有个梗我插不上话 |
| 内心 | 那事早翻篇了 | 他俩才像一对 |
| 好的处理 | 她先开口把那事说了 | 他问了，问得还挺自然 |
| 写崩 | 写成她吊着人家 | 写成他审犯人 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她的旧侍／退过的亲事／被她放出府的那个人 |
| 修仙 | 前任道侣／她曾双修过的同门 |
| 星际 | 她的前任副手／档案里的旧配对记录 |

古代女尊版的「旧侍」有一层现代版没有的重量： 那个人可能还住在府里，且有位份。

#### 写崩的三种方式

1. 把前任写成反派。 得体的前任更有力。
2. 让她含糊。 她可以不解释，但不能给错信号。
3. 让他毫不在意。 忍住不问和不在意是两回事。

## 五 · 她的秘密

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：隐瞒 5.0%（女方向少见）

**骨架**｜她也有瞒着的事，多半是怕说了他会瞎操心。

#### 节拍链

她不提 → 痕迹，体检单·阳台电话 → 他发现 → 「你为什么不告诉我」→ 「告诉你有什么用」→ 知情权谈判 → 她说了一件小的

#### 时间轴

她的瞒不是那种天天纠结、睡不着觉的瞒，她瞒得心安理得，这才是最麻烦的地方。时间上是他一直在等：从发现苗头到开口问，他忍了两周，本指望她自己交代，结果没有。那天晚上聊知情权的事，根本聊不完，停一停再继续是常事。她先「说了一件小的」当首付，之后按月慢慢挤牙膏，每次多说一点。这个分期方案就是两个人吵着吵着磨出来的新规矩。

#### 为什么这条少见且值得写

语料里绝大多数秘密都在他那边。原因不难理解：她是掌控者，掌控者被默认没有需要隐藏的东西。

但一个什么都对他坦白的强势方，其实是不真实的。她隐瞒的通常是三类：

| 类型 | 例子 |
|---|---|
| 她的代价 | 她为这段关系付出的东西：推掉的机会、得罪的人 |
| 她的脆弱 | 身体、失眠、一次失败 |
| 她替他挡掉的事 | 他不知道有过这件事 |

第三类最有戏，因为它一旦被发现，他的感受是复杂的：感激 ＋ 被排除在外的难堪。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她隐瞒的方式 | 不说谎，就是不提 |
| 痕迹 | 体检报告 ✓ · 一通她躲到阳台才接的电话 · 她推掉的行程 |
| 他的发现 | 从别人嘴里听到 · 或者看到一张单据 |
| 他的第一反应 | 不是感动，是「你干嘛不跟我说」 |
| 她的理由 | 「跟你说了又能怎样」——这话最扎心 |

「告诉你有什么用」——这句话从她嘴里说出来，最伤人。而且她说的时候通常没恶意，就是单纯觉得说了也白说。可恰恰是这一点，才最戳人。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 隐瞒的内容 | 她的代价 | 她的病 |
| 他怎么知道的 | 第三人 | 他自己发现 |
| 她的理由 | 怕他担心 | 觉得他帮不上 |
| 结果 | 她学会了说 | 她还是没学会 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |

| 内心 | 说了他也帮不上 | 我在这段关系里到底算什么 |
| 好的处理 | 她后来主动说了一件小的 | 他要求的是知情权，不是解决权 |
| 写崩 | 写成她无所不能 | 写成他闹脾气 |

「他要求的是知情权不是解决权」是这条最好的一句台词方向。 他不需要能解决，他需要被告知。

#### 换皮

| 世界 | 等价物 |

2. 让她的隐瞒毫无代价。他得真栽一回跟头，疼了才长记性。
3. 用一次坦白解决全部。她的毛病要是说改就能改，那还叫毛病？

## 六 · 坦白的那一夜

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：坦白 6.0%

**骨架**｜两个人决定把话摊开说。这场啥事都没发生，就光聊。

#### 节拍链

谁提议 → 关灯各坐一头 → 第一件小事试水 → 中间那件 → 停了很久 → 有一件没说 → 天亮「睡吧」

#### 时间轴

从关灯到天亮，六七个小时，节奏是慢慢往上走的。前半夜聊的都是有的没的，算是试探一下。中间那件大事讲完，停了最久，半小时没人吭声，谁也没催谁。后半夜话少了，但每句都顶用。天亮那会儿那句「睡吧」，就是给这一夜盖了个章：说过的都算数，没说出口的，大家心里也明白。这一夜的钟只走一次，但管用很多年。

#### 坦白场的结构

| 拍 | 内容 |
|---|---|
| 1 | 谁提议的，往往是被逼到了墙角 |
| 2 | 环境：关灯／不看对方／各坐一头 |
| 3 | 第一件小事（试水） |
| 4 | 中间那件（真正难说的） |
| 5 | 有一件没说 |
| 6 | 天亮 |

第五拍是这条的价值所在。 一场完全彻底的坦白是假的，总有一件留下了，而读者知道有那一件。

#### 可用细节

| 类 | 内容 |
|---|---|
| 环境 | 关着灯 · 阳台 · 车里 · 这场戏俩人都不看对方 |
| 节奏 | 说几句，歇半天，再开口 |
| 道具 | 烟 · 酒 · 一杯放凉的水 |
| 句式 | 短句 · 话到嘴边又咽回去 · 「算了，跟你说了也没用」结果还是说了 |
| 结束 | 谁先来一句「睡吧」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提议 | 她 | 他 |
| 说了多少 | 大部分 | 只说了最表面的一层 |
| 留下的那件 | 无关紧要 | 最重要的那件 |
| 之后 | 关系更实 | 各自知道对方还留着东西 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听出他跳过了一段 | 那一件我说不出口 |
| 内心 | 他还有没说的 | 她知道我没说完 |
| 好的处理 | 她没有追问那一段 | 他没有假装说完了 |
| 写崩 | 写成审讯 | 一次性倒完所有往事 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 更漏声中的对坐／她屏退左右 |
| 修仙 | 神识相通时无法隐瞒的部分／他仍然藏住了一处 |
| 星际 | 关掉记录仪之后 |

修仙版的「神识相通仍然藏住了一处」多一层：在一个理论上没法隐瞒的设定里，他还是留了一件，隐瞒本身变成了一次主动行为。

#### 写崩的三种方式

1. 写成审讯。她问一句他答一句，那不是坦白。
2. 全部说完。留一件。
3. 靠对话解决所有问题。说完了事情还在。

## 七 · 旧地重游

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：旧地 16.0%

**骨架**｜他带她去了个他从来不说的地方。

#### 节拍链

他说「带你去个地方」→ 路上反常 → 到了 → 「就是这儿」→ 她问了一个小问题 → 站一会儿 → 回程

#### 时间轴

路上的不对劲，比到没到地方更早露出来。出发那会儿他还正常，越靠近话越少，她光看他沉默成什么样，就能猜到还剩多少路。到了地方，站多久他说了算，她不催，也不看表。那个小问题她只问一次，多问一句，他就彻底说不出来了。回去路上话比来时多，说明这趟心里那点东西卸掉了，话多话少，就是这趟管不管用的标尺。

#### 与 [09-分离与重逢 · 旧地](09-分离与重逢.md#十--旧地) 的区别

| | 09 卷的旧地 | 这一条 |
|---|---|---|
| 谁的旧地 | 他们共同的 | 他一个人的 |
| 功能 | 收束全书 | 揭开一层 |
| 情绪 | 回望 | 交付 |

这一条的动作是「带她去」，那是一次主动的交付。

#### 可用细节

| 类 | 内容 |
|---|---|
| 地点 | 老房子 · 他上学那会儿的地方 · 一座坟 ✓ · 他以前打工的店 |
| 路上 | 他一路上没怎么吭声 · 要么就反常地话特别多 |
| 到了 | 他站门口不进去 · 要么就熟门熟路地推门 |
| 他说的话 | 很少。基本就一句「就这儿」 |
| 她的处理 | 不追问 · 要么只问一句特别具体的小事 |

「只问一个很具体的小问题」是她能做的最好的事。「你以前住哪间」比「你当时一定很苦吧」有用一百倍。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提议的 | 他 | 她查到了，提出要去 |
| 他说不说 | 说了一点 | 全程不说 |
| 变化 | 全变了 | 一样没变 |
| 之后 | 他松了 | 他后悔带她来 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他推门的动作很熟 | 带她来这里等于把自己摊开 |
| 好的处理 | 她问了一个具体的小问题 | 他没有解说自己的苦 |
| 写崩 | 写成她的心疼独白 | 写成他的回忆长镜头 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 旧宅／他母亲的坟／他被卖出去的那个院子 |
| 修仙 | 他师门旧址／他筑基的那个山洞 |
| 星际 | 他出生的边境星／已经废弃的居住舱 |

#### 写崩的三种方式

1. 让他讲一段完整的往事。「就是这儿」三个字够了，别多写。
2. 让她大段共情。一个具体问题就行，别铺一堆空话。
3. 写成情节转折。但它也可以什么都不推动，别硬推。

## 八 · 他在她手机里的备注

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.0% ＋ 隐瞒 5.0%

**骨架**｜他看见了她给他存的名字。

#### 节拍链

屏幕亮起 → 他看见那个名字 → 什么都没说 → 对照自己那边存的 → 改或没改 → 很久以后她的备注变了

#### 时间轴

看见她第一眼，就那一下，能回味一礼拜。 他光备注就折腾了两周：先翻自己这边存的什么名，又纠结要不要跟着改，最后要么没动，要么改了。她那边换备注，一年也换不了几回，从全名到小名再到只有他俩懂的暗号，每次换都不吭声，等他发现的时候，早改完好几个月了。翻翻备注史，这段关系怎么变的，全在上面写着。

#### 一个字段承载的全部信息

不需要任何情节，只需要一个字符串。

| 备注 | 读作 |
|---|---|
| 全名 | 距离 |
| 姓 + 一个字 | 工作关系 |
| 名字 | 熟 |
| 一个称呼 | 亲密 |
| 一个字 | 极亲密 |
| 一个表情 | 私人 |
| 「小李（新）」 | **最伤：说明有过一个旧的** |

最后一行是这条的爆点。 括号里的一个字，把整段历史带了出来。

#### 可用细节

| 类 | 内容 |
|---|---|
| 看见的方式 | 她手机屏幕亮了 · 她让他帮着查个号 · 她把手机递过去给他看别的东西 |
| 他的反应 | 瞅见了，也没吭声 |
| 对照 | 他给她存的是啥名 |
| 后续 | 他把自己那边备注改了 · 也可能没动 |
| 很久以后 | 她备注换了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 备注 | 亲密 | 疏远 |
| 他的反应 | 高兴 | 一沉 |
| 说不说 | 说了 | 一直没说 |
| 变化 | 后来改了 | 一直没改（更疼） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |

| 落点 | 她某天想起来自己一直没改 | 括号里那个字 |

| 写崩 | 写成她故意用备注传话 | 写成他因为这个闹别扭 |

1. 写得太长。一个字符串，几句话的事。
2. 让他因此闹。看见了不说才对。
3. 忽略对照。他那边存的是什么，才是这条的另一半。

## 九 · 他一直留着的东西

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：隐瞒 5.0% ＋ 看照片 5.0%

#### 时间轴

盒子里的日期和数量，摆明了就是一条她不在场的时间线。票根按年份排好，纪念品上都写着日期，她翻到的那一刻，等于一口气把他单方面记了三年的日记全看完了。合上放回去，十秒就够，但麻烦的是后劲儿——「从此她开始留意」才是真问题：她后来的每个纪念日都多留了个心眼儿，因为她知道了，他是那种会把东西都存下来的人。

## 十 · 说不出口的那件

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：坦白 6.0%

**骨架**｜关系处得挺好，但有一件事，他这辈子打死都不会提。

#### 节拍链

关系已稳 → 某夜（醉·病·告别）→ 他张了嘴 → 半句 → 换成别的话 → 她听出来了，没追 → 一切照旧

#### 时间轴

张嘴到换话题，只有三秒，那三秒每隔一两年出现一次。
醉的那晚、病的那晚、机场送别的那晚，同一句半途而废的话，多年里露头三四次，每次都停在同一个位置。她从第二次起就听出来了，从没追问。这条没有终点：有些话的时间轴就是永远差三秒，而这三秒两个人都认了。

#### 这条是本卷的收束

前面九条讲的都是秘密如何被揭开。这一条讲永远不被揭开的那一件。

这是关系的正常构造，算不上遗憾。两个人之间有一件永远不会说的事，这件事本身就可以是关系的一部分。

#### 三种处理

| 处理 | 说明 |
|---|---|
| 她知道有那一件，且不问 | 最成熟 |
| 她不知道有那一件 | 最平静，也最脆弱 |
| 他某天差点说了 | 最有戏 |

「他某天差点说了」适合放在全书接近结尾处。一次醉酒，一次生死关头，一次深夜，他张了嘴，然后没说。

#### 可用细节

| 类 | 内容 |
|---|---|
| 那件事的性质 | 不是背叛，多半是丢人或自己都嫌弃的事 |
| 差点说了的时刻 | 喝多那次 ✓ · 大病 · 她受伤 · 有回告别 |
| 他停住的方式 | 说了半截 · 岔开话头 |
| 她的反应 | 她听出来了 · 她没追问 |
| 收尾 | 日子照旧，但读者心里有数了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她知不知道有 | 知道 | 不知道 |
| 最终 | 一直没说 | 很久以后说了 |
| 影响 | 无 | 它一直在轻微地影响他 |
| 读者知不知道 | 知道（更好） | 也不知道 |

「读者知道而她不知道」是这条最有效的配置。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听出他刚才要说别的 | 说了半句，咽回去 |
| 内心 | 他有一件事 | 这一件不能说 |
| 好的处理 | 她不追问，也不装没听见 | 他没说，也不难受 |
| 写崩 | 写成吊胃口 | 写成他扛着苦楚的惨样 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 一桩他做过的事／他曾经的身份／他母亲怎么死的 |
| 修仙 | 他的一段前尘／他曾经动过的念头 |
| 星际 | 他在那场战役里做的选择 |

#### 写崩的三种方式

1. 当悬念钩子用——它不需要被解开。
2. 让他为此痛苦一辈子：可以带着，不必压着。
3. 最后揭开——不揭开，才是这条的意义。
