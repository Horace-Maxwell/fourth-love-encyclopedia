# 秘密与坦白

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**信息不对称就是权力不对称。谁知道得多，谁就在上面。**

---

## 秘密在这一类里的特殊算法

在一段权力不对称的关系里，秘密的分布会放大或抵消这种不对称：

| 谁有秘密 | 效果 |
|---|---|
| 她有，他不知道 | 落差加倍。她既在位置上，又在信息上 |
| 他有，她不知道 | 落差被抵消一部分。**他手里有了一样她没有的东西** |
| 双方各有 | 最有张力 |
| 都没有 | 关系稳定，但没戏 |

第二行是这个类型最好用的结构。 弱势方唯一能持有的筹码，往往就是一个她不知道的事。

| 节拍族 | 作品数 | 占比 |
|---|---:|---:|
| 掉马 | 897 | 31.0% |
| 前任 | 897 | 31.0% |
| 旧地 | 463 | 16.0% |
| 坦白 | 174 | 6.0% |
| 隐瞒 | 145 | 5.0% |

「坦白」6%、「隐瞒」5%，在全部情境族里排在末尾。这类情节并不少，只是多数散在别的场面里，很少单独成场。反过来说，把它单独写好，辨识度极高。

## 一 · 他有一件事没说

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：隐瞒 5.0%（低频高价值）

**骨架**｜他手里有一样她不知道的东西。而他每天都在决定今天要不要说。

#### 节拍链

秘密成形 → 每天决定说不说 → 拖延变成新的罪 → 外部逼近 → 三次机会都放过了 → 说或被揭

#### 时间轴

每天一次的「今天说不说」，就是这条的钟摆。 秘密本身静止，拖延在计息：瞒到第十天，罪名从「有事没说」变成了「瞒了十天」，刑期随时长换档。外部逼近后钟摆加速：三次开口机会各有时刻，一次比一次好开口，也一次比一次接近被揭穿。

#### 秘密的量级表

选错量级会毁掉整条线。这张表按「被发现之后关系还能不能修复」排：

| 量级 | 内容 | 修复难度 |
|---|---|---|
| 轻 | 他偷偷做了件好事 | 无需修复，是甜点 |
| 中 | 他的家世／学历／过去的职业 | 需要一场对话 |
| 中重 | 他接近她最初是有目的的 | 需要整条线 |
| 重 | 他骗了她关于身份的核心事实 | 可能修不回来 |
| 过重 | 涉及伤害她的行为 | 不建议，会毁掉他 |

中重那一档是这个类型最常用也最合适的：有目的地接近，后来是真的。它给了掉马足够的分量，又不至于让他无法被原谅。

#### 可用细节

| 类 | 内容 |
|---|---|
| 藏的痕迹 | 一个他从不接的电话 · 一个抽屉 · 某个话题他会绕开 |
| 他的每日决定 | 今天可以说 → 时机不对 → 又推了一天 |
| 越拖越难 | 隐瞒的时间本身变成了新的罪 |
| 她的察觉 | 她早就知道有事，只是不知道是什么 |
| 逼近 | 一个外部事件让秘密快要自己曝出来 |

「隐瞒的时间本身变成了新的罪」是这条最重要的一条规律。到后来他怕的已经不是那件事本身，怕的是「我为什么没早点说」。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他为什么瞒 | 怕失去她 | 为了保护她 |
| 她知不知道有事 | 完全不知道 | 早就知道，在等他自己说 |
| 曝出方式 | 他自己说 | 被别人揭穿 |
| 结果 | 过去了 | 关系变了 |

「她早就知道，在等他自己说」是最好的一版。 它把主动权留给他，也让她的形象立得住。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她在等，等了很久 | 今天也没说出口 |
| 内心 | 我给他时间 | 明天，明天一定 |
| 好的处理 | 她给期限，但不揭穿 | 他在被揭穿之前自己说了 |
| 写崩 | 写成她全知全能 | 写成他被动到被揭穿 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他的出身／他是细作／他背着旧仇 |
| 修仙 | 他的功法来路／他体内的东西／他的真身 |
| 星际 | 他的档案被改过／他的编号是假的 |

#### 写崩的三种方式

1. 秘密太重。 重到不可原谅，后面就没戏了。
2. 让他一直没有主动说的机会。 要给他至少三次机会且他都放弃了。
3. 靠外部揭穿收场。 他自己说才有分量。

## 二 · 掉马

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：掉马 31.0%（掉马＋请安、掉马＋和好高频同现）

**骨架**｜遮不住了。而这一刻的价值全在**她的第一反应**。

#### 节拍链

触发物到场 → 那一秒 → 她放下手里的东西 → 「还有别的吗」→ 先处理事务 → 她需要的时间 → 交代而非道歉

#### 时间轴

掀开只要一秒，她的处理把时间切成了三段。 第一段是那半秒的静（全场屏息）；第二段是事务处理（一小时内，她的效率不因情绪打折）；第三段是「她需要的时间」，三天或一周，她明确报了时长，到点回来谈。报时长这个动作本身就是她的风格：连消化情绪都有排期。

#### 掉马的四种时机

| 时机 | 效果 |
|---|---|
| 关系刚开始 | 伤害小，但也没重量 |
| 关系正好的时候 | 最疼，也最常用 |
| 她刚刚为他做了一件大事之后 | 最狠 |
| 她已经猜到之后 | 转成「她早知道」，见第三条 |

第三行是这条的最强配置： 她刚顶着压力护了他，转头发现他一直在骗她。

#### 她的第一反应，五个版本

这一秒决定这个角色是谁：

| 反应 | 说明 |
|---|---|
| 发怒 | 最直接，但最浅 |
| 平静地问「还有别的吗」 | 冷，且致命 |
| 先处理事务再处理情绪 | 最符合这类角色 |
| 什么都不说，转身走 | 最重 |
| 「我知道」 | 转成第三条 |

「先处理事务再处理情绪」是这个类型的标志性反应。 眼下这件事还有后续要收拾，她先收拾，然后才轮到她自己。

#### 可用细节

| 类 | 内容 |
|---|---|
| 曝出方式 | 一个电话 · 一个人出现 · 一份文件 · 一句口误 |
| 那一秒 | 环境音 · 她手上的动作停了 · 他知道自己完了 |
| 他的表现 | 不辩解 · 或者说了最不该说的一句「我可以解释」 |
| 她的动作 | 把手里的东西放下（不是摔） |
| 事后 | 她需要多久 · 她在这段时间里做了什么 |

「我可以解释」是掉马场最差的一句台词。 语料里高频，但它把主动权交给了对方，且听起来像在拖延。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 曝出方式 | 意外 | 他自己说的 |
| 她的反应 | 爆发 | 平静（更可怕） |
| 严重程度 | 可原谅 | 需要很久 |
| 收场 | 原谅 | 原谅但不复原 |

「原谅但不复原」是成年人关系的真相。 见 [04-委屈与破防 · 说了狠话](04-委屈与破防.md#七--说了狠话) 的同一条。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把手里的东西放下 | 她没有摔，这更糟 |
| 内心 | 先把这件事处理完 | 完了，她连生气都懒得 |
| 好的处理 | 她要一个完整的交代，不要道歉 | 他一次说完，不挤牙膏 |
| 写崩 | 写成她当场原谅 | 写成他跪地哀求 |

「要交代不要道歉」是她这个角色最好的一句要求。 道歉是情绪，交代是事实。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 身份败露／细作／旧主找上门／族谱被翻出来 |
| 修仙 | 真身现形／功法来路暴露／魔气外泄 |
| 星际 | 档案被调出／基因比对／旧编号被识别 |

#### 写崩的三种方式

1. 让她当场原谅。 那前面藏的意义就没了。
2. 让他辩解。 一次说完，不要挤牙膏。
3. 掉马之后没有余震。 至少留一章的不对劲。

## 三 · 她早知道

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：掉马 31.0% 的变体

**骨架**｜他鼓足勇气坦白，她说「我知道」。

#### 节拍链

他坦白 → 「我知道」→ 你什么时候知道的 → 为什么不说破 → 你打算瞒到什么时候 → 她说了她在意的那一点

#### 时间轴

两条时间线当场对表。 他的线：秘密藏了八个月，坦白排练了两周。她的线：第三周就知道了，等他自己说等了七个月。对表的瞬间他大脑空白，原来这七个月里每一天，她都在给他机会。她「等了多久」的时长，就是她给这段关系的信用额度。

#### 这条为什么比掉马更有力

因为它把权力关系写到了极致：她一直掌握着全部信息，而她选择了等。

这既是宠溺也是掌控，两种读法同时成立，这就是它的厚度。

#### 「我知道」之后的三个问题

这三个问题是这条戏的正文：

| 问题 | 谁问 |
|---|---|
| 「你什么时候知道的」 | 他 |
| 「为什么不说破」 | 他 |
| 「你打算瞒到什么时候」 | 她 |

第三个问题是她唯一的怒气所在。 她不在意那件事，她在意他准备瞒多久。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她知道的时点 | 比他以为的早得多（往往在关系开始之前） |
| 她的证据 | 一份她早就调过的资料 · 一个电话 · 她认识那个人 |
| 她为什么等 | 想看他自己说 · 或者那件事对她不重要 |
| 他的崩溃点 | 不是被识破，是「原来我一直在她眼皮底下演」 |
| 收束 | 她说了她在意的那一点 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 知道多久 | 一段时间 | 从一开始 |
| 她为什么不说 | 等他 | 那件事她不在意 |
| 他的感受 | 释然 | 更难受（他一直在被看着） |
| 关系变化 | 更近 | 他开始怀疑还有什么她知道而他不知道 |

最后一行是这条的高阶用法： 揭穿之后，不对称反而更明显了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她说出「我知道」的语气 | 原来这三年我都在演给她看 |
| 内心 | 我在等他自己说 | 她看着我演了三年 |
| 好的处理 | 她说清楚为什么等 | 他的难受是真的，且他说了 |
| 写崩 | 写成她全知全能的神 | 写成他感激涕零 |

「她全知全能」是这条最大的陷阱。 要给她一个不知道的点，哪怕很小。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她早查过他的底／案卷一直在她手上 |
| 修仙 | 她的神识早已探过／她认得他的功法出处 |
| 星际 | 她一开始就调过他的真实档案 |

#### 写崩的三种方式

1. 让她全知。 留一个她不知道的点。
2. 让他只有感激。 「被看了三年」的难受要写。
3. 省略「你打算瞒到什么时候」。 那是她的真正情绪。

## 四 · 前任出现

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：前任 31.0%（前任＋失联、前任＋告别高频同现）

**骨架**｜有一个人知道他们不知道的过去。

#### 节拍链

出现（饭局·工作·照片）→ 得体寒暄 → 旧梗飘过 → 他全程正常 → 回家路上安静 → 她主动说了那段 → 界限

#### 时间轴

现场两小时滴水不漏，回程二十分钟见真章。 饭局上两人的社交面具都在线，时间平稳流过；上车后的安静从第一个路口持续到第五个，她主动开口讲那段过去的时刻，选在快到家前（讲完正好到家，不给话题过夜的机会）。界限划在当晚，不隔夜，是这条的卫生标准。

#### 谁的前任，写法完全不同

| 谁的 | 主要冲突 | 谁难受 |
|---|---|---|
| 她的前任 | 那个人往往和她「更般配」（同层级） | 他 |
| 他的前任 | 那个人往往见过他的另一面 | 她 |
| 双方都有 | 对照组结构 | 都难受 |

「她的前任和她更般配」是这个类型最扎人的配置。 那个人有他缺的东西：同等地位、共同语言、不需要被照顾。

#### 可用细节

| 类 | 内容 |
|---|---|
| 出现方式 | 同一个饭局 · 工作对接 · 老照片 ✓ · 一个共同的朋友 |
| 那个人的态度 | 得体（最难对付）· 或者挑衅（好对付） |
| 她的态度 | 平常 · 这份平常本身就让他不安 |
| 他的观察 | 他们说话的方式 · 一个只有他们懂的旧梗 |
| 他的反应 | 全程正常 · 回家路上一句话不说 |

「得体的前任」比「挑衅的前任」难写十倍，也有效十倍。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 前任的态度 | 得体 | 想复合 |
| 她的态度 | 划清界限 | 保持正常往来（会有戏） |
| 他的反应 | 忍 | 问了 |
| 收场 | 她给了明确的话 | 悬着 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她注意到他今晚话特别少 | 他们有一个我听不懂的梗 |
| 内心 | 那件事早就过去了 | 他们更像一对 |
| 好的处理 | 她主动说了那段过去 | 他问了，且问得不难看 |
| 写崩 | 写成她暧昧不清 | 写成他查户口 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她的旧侍／退过的亲事／被她放出府的那个人 |
| 修仙 | 前任道侣／她曾双修过的同门 |
| 星际 | 她的前任副手／档案里的旧配对记录 |

古代女尊版的「旧侍」有一层现代版没有的重量： 那个人可能还住在府里，且有位份。

#### 写崩的三种方式

1. 把前任写成反派。 得体的前任更有力。
2. 让她含糊。 她可以不解释，但不能给错信号。
3. 让他毫不在意。 忍住不问和不在意是两回事。

## 五 · 她的秘密

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：隐瞒 5.0%（女方向少见）

**骨架**｜她也有不说的事。而她不说的理由通常是「说了他会担心」。

#### 节拍链

她不提 → 痕迹（体检单·阳台电话）→ 他发现 → 「你为什么不告诉我」→ 「告诉你有什么用」→ 知情权谈判 → 她说了一件小的

#### 时间轴

她的瞒没有「每天挣扎」，她瞒得毫无负担，这才是问题。 时间轴在他那边：从发现痕迹到开口，他等了两周（他在等她自己说，没等到）。知情权谈判当晚谈不完，休会再谈是常态；她「说了一件小的」作为首付，之后按月分期，每期多说一点，这个分期计划就是两人磨出来的新制度。

#### 为什么这条少见且值得写

语料里绝大多数秘密都在他那边。原因不难理解：她是掌控者，掌控者被默认没有需要隐藏的东西。

但一个什么都对他坦白的强势方，其实是不真实的。她隐瞒的通常是三类：

| 类型 | 例子 |
|---|---|
| 她的代价 | 她为这段关系付出的东西（推掉的机会、得罪的人） |
| 她的脆弱 | 身体、失眠、一次失败 |
| 她替他挡掉的事 | 他不知道有过这件事 |

第三类最有戏，因为它一旦被发现，他的感受是复杂的：感激 ＋ 被排除在外的难堪。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她隐瞒的方式 | 不说谎，只是不提 |
| 痕迹 | 体检报告 ✓ · 一通她走到阳台才接的电话 · 她推掉的行程 |
| 他的发现 | 通过第三人 · 或者一张单据 |
| 他的第一反应 | 不是感激，是「你为什么不告诉我」 |
| 她的理由 | 「告诉你有什么用」——这句最伤 |

「告诉你有什么用」是她能说出的最伤人的一句话，而且她说这句时通常没有恶意，她只是在陈述事实。这正是它伤人的原因。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 隐瞒的内容 | 她的代价 | 她的病 |
| 他怎么知道的 | 第三人 | 他自己发现 |
| 她的理由 | 怕他担心 | 觉得他帮不上 |
| 结果 | 她学会了说 | 她还是没学会 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把体检单折起来放进包里 | 那件事我居然是最后一个知道的 |
| 内心 | 说了他也帮不上 | 我在这段关系里到底算什么 |
| 好的处理 | 她后来主动说了一件小的 | 他要求的是知情权，不是解决权 |
| 写崩 | 写成她无所不能 | 写成他闹脾气 |

「他要求的是知情权不是解决权」是这条最好的一句台词方向。 他不需要能解决，他需要被告知。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她替他挡下的弹劾／她付出的代价／她的旧伤 |
| 修仙 | 她替他挡的劫／她的道基有损 |
| 星际 | 她动用的权限／她的体检数据 |

#### 写崩的三种方式

1. 不写她的秘密。 她会变成没有内面的角色。
2. 让她的隐瞒毫无代价。 他要真的受伤一次。
3. 用一次坦白解决全部。 她的习惯不会一次就改。

## 六 · 坦白的那一夜

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：坦白 6.0%

**骨架**｜两个人决定把事情说清楚。这一场没有情节，只有对话。

#### 节拍链

谁提议 → 关灯各坐一头 → 第一件小事试水 → 中间那件 → 停了很久 → 有一件没说 → 天亮「睡吧」

#### 时间轴

从关灯到天亮，六七个小时，节奏是递进的。 前半夜说的都是小事（试水温）；中间那件大的说完，停顿最长，半小时没人说话，谁都没催。后半夜话变少但密度变大。天亮时那句「睡吧」是这一夜的封条：说过的都算数，没说的那件也各自心里有数。这条的钟只走一夜，效力走很多年。

#### 坦白场的结构

| 拍 | 内容 |
|---|---|
| 1 | 谁提议的（往往是被逼到了墙角） |
| 2 | 环境（关灯／不看对方／各坐一头） |
| 3 | 第一件小事（试水） |
| 4 | 中间那件（真正难说的） |
| 5 | 有一件没说 |
| 6 | 天亮 |

第五拍是这条的价值所在。 一场完全彻底的坦白是假的；总有一件留下了，而读者知道有那一件。

#### 可用细节

| 类 | 内容 |
|---|---|
| 环境 | 关着灯 · 阳台 · 车里 · 不看对方是这场戏的前提 |
| 节奏 | 说一段，停很久，再说 |
| 道具 | 烟 · 酒 · 一杯凉了的水 |
| 句式 | 短句 · 说不下去的地方 · 「算了，说了你也……」然后还是说了 |
| 结束 | 谁先说「睡吧」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提议 | 她 | 他 |
| 说了多少 | 大部分 | 只说了最表面的一层 |
| 留下的那件 | 无关紧要 | 最重要的那件 |
| 之后 | 关系更实 | 各自知道对方还留着东西 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听出他跳过了一段 | 那一件我说不出口 |
| 内心 | 他还有没说的 | 她知道我没说完 |
| 好的处理 | 她没有追问那一段 | 他没有假装说完了 |
| 写崩 | 写成审讯 | 写成一次性倾倒全部往事 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 更漏声中的对坐／她屏退左右 |
| 修仙 | 神识相通时无法隐瞒的部分／他仍然藏住了一处 |
| 星际 | 关掉记录仪之后 |

修仙版的「神识相通仍然藏住了一处」多一层：在一个理论上无法隐瞒的设定里，他还是留了一件，隐瞒本身变成了一次主动行为。

#### 写崩的三种方式

1. 写成审讯。 她问一句他答一句，那不是坦白。
2. 全部说完。 留一件。
3. 靠对话解决所有问题。 说完了事情还在。

## 七 · 旧地重游

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：旧地 16.0%

**骨架**｜他带她去了一个他从来不提的地方。

#### 节拍链

他说「带你去个地方」→ 路上反常 → 到了 → 「就是这儿」→ 她问了一个小问题 → 站一会儿 → 回程

#### 时间轴

路上的反常先于目的地抵达。 出发时他还正常，越近话越少，她从他的沉默密度就能画出距离进度条。到了之后站多久由他定，她不看表；那个小问题她只问一个（多问一个，他就说不下去了）。回程的话比来时多，说明这趟卸掉了东西，语量差就是这条的疗效指标。

#### 与 [09-分离与重逢 · 旧地](09-分离与重逢.md#十--旧地) 的区别

| | 09 卷的旧地 | 这一条 |
|---|---|---|
| 谁的旧地 | 他们共同的 | 他一个人的 |
| 功能 | 收束全书 | 揭开一层 |
| 情绪 | 回望 | 交付 |

这一条的动作是「带她去」，那是一次主动的交付。

#### 可用细节

| 类 | 内容 |
|---|---|
| 地点 | 老房子 · 他上学的地方 · 一个墓 ✓ · 他打过工的店 |
| 路上 | 他一路没怎么说话 · 或者他反常地话多 |
| 到了 | 他站在门口没进去 · 或者他很熟练地推门 |
| 他说的话 | 极少。往往只是「就是这儿」 |
| 她的处理 | 不问 · 或者只问一个很具体的小问题 |

「只问一个很具体的小问题」是她能做的最好的事。 「你以前住哪间」比「你当时一定很苦吧」有用一百倍。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提议的 | 他 | 她（她查到了，提出要去） |
| 他说不说 | 说了一点 | 全程不说 |
| 变化 | 全变了 | 一样没变 |
| 之后 | 他松了 | 他后悔带她来 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他推门的动作很熟 | 带她来这里等于把自己摊开 |
| 好的处理 | 她问了一个具体的小问题 | 他没有解说自己的苦 |
| 写崩 | 写成她的心疼独白 | 写成他的回忆长镜头 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 旧宅／他母亲的坟／他被卖出去的那个院子 |
| 修仙 | 他师门旧址／他筑基的那个山洞 |
| 星际 | 他出生的边境星／已经废弃的居住舱 |

#### 写崩的三种方式

1. 让他讲一段完整的往事。 「就是这儿」三个字够了。
2. 让她大段共情。 一个具体问题就好。
3. 写成情节转折。 它可以什么都不推动。

## 八 · 他在她手机里的备注

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.0% ＋ 隐瞒 5.0%

**骨架**｜他看见了她给他存的名字。

#### 节拍链

屏幕亮起 → 他看见那个名字 → 什么都没说 → 对照自己那边存的 → 改或没改 → 很久以后她的备注变了

#### 时间轴

看见只要一眼，回味以周计。 那个名字在他心里挂了两周：对照自己那边的备注、犹豫要不要改、最终没改（或改了）。她的备注变化是年度级事件，从全名到简称到只有两个人懂的代号，每次变更都无公告，被他发现时均已生效数月。备注史就是这段关系的地质层。

#### 一个字段承载的全部信息

不需要任何情节，只需要一个字符串。

| 备注 | 读作 |
|---|---|
| 全名 | 距离 |
| 姓 + 一个字 | 工作关系 |
| 名字 | 熟 |
| 一个称呼 | 亲密 |
| 一个字 | 极亲密 |
| 一个表情 | 私人 |
| 「小李（新）」 | **最伤：说明有过一个旧的** |

最后一行是这条的爆点。 括号里的一个字，把整段历史带了出来。

#### 可用细节

| 类 | 内容 |
|---|---|
| 看见的方式 | 她手机 ✓ 屏幕 ✓ 亮起来 · 她让他帮忙找个号码 · 她递手机给他看别的 |
| 他的反应 | 只是看见了，什么都没说 |
| 对照 | 他给她存的是什么 |
| 后续 | 他改了自己那边的备注 · 或者没改 |
| 很久以后 | 她的备注变了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 备注 | 亲密 | 疏远 |
| 他的反应 | 高兴 | 一沉 |
| 说不说 | 说了 | 一直没说 |
| 变化 | 后来改了 | 一直没改（更疼） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她某天想起来自己一直没改 | 括号里那个字 |
| 好的处理 | 她改的时候不告诉他 | 他看见了，装作没看见 |
| 写崩 | 写成她刻意用备注传情 | 写成他因此闹脾气 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 名册上的记法／请帖上的称呼／她私下叫他的字 |
| 修仙 | 玉简里的标记／道侣录上的记载 |
| 星际 | 通讯录的分组／权限表上的标签 |

#### 写崩的三种方式

1. 写得太长。 一个字符串，几句话。
2. 让他因此闹。 看见了不说才对。
3. 忽略对照。 他那边存的是什么，才是这条的另一半。

## 九 · 他一直留着的东西

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：隐瞒 5.0% ＋ 看照片 5.0%

**骨架**｜她翻到了一样东西。而那样东西说明他一直在等。

#### 节拍链

收拾或搬家 → 翻到盒子 → 日期与数量 → 他出现在门口 → 她合上放回原位 → 从此她开始留意

#### 时间轴

盒子里的日期与数量，是一条她缺席的时间线。 票根按年排、纪念品带日期，她翻到的那一刻，等于一次性读完他单方面记了三年的日志。合上放回原位只用十秒；「从此她开始留意」是这条的长尾：她后来的每个纪念日都多备了一手，因为她知道了他是会存档的人。

#### 与 [07-馈赠与仪式 · 她随手给的东西](07-馈赠与仪式.md#三--她随手给的东西) 的区别

那一条是她给的东西他留着（情感不对称）。
这一条是他自己攒的东西（时间不对称）。

| 留的东西 | 说明什么 |
|---|---|
| 她的照片 ✓（偷拍的） | 他很早就在看她 |
| 一张票根 | 他记得那一天 |
|一份剪报／她的报道 | 他一直在关注 |
| 没送出去的礼物 ✓ | 见 [07 卷第一条](07-馈赠与仪式.md#一--藏了很久的礼物) |
| 一封没发的信 | 最重 |
| 一个日期被圈起来的旧日历 | 最省字 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 发现的场合 | 搬家 · 找东西 · 他住院她替他收拾 |
| 东西的状态 | 保存得极好 · 或者被翻得起了毛边 |
| 时间证据 | 日期 · 泛黄的程度 · 一叠而不是一张 |
| 他的反应 | 抢过去 · 或者不抢 |
| 她的处理 | 放回原处 · 或者拿出来问 |

「一叠而不是一张」是这条最有效的量化手段。 数量就是时间。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 东西 | 一件 | 一整盒 |
| 时间跨度 | 半年 | 十年 |
| 他知不知道被发现 | 不知道 | 知道了 |
| 她的处理 | 放回去 | 问了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 最下面那张的日期 | 她翻到了 |
| 内心 | 他从那么早就开始了 | 别看最下面那张 |
| 好的处理 | 她把盒子按原样合上 | 他没有解释 |
| 写崩 | 写成她感动落泪 | 写成他借此表功 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 一沓没送出的信／她掉的一支簪／她的一张字 |
| 修仙 | 留影石里的一段／她的一缕气息封在瓶里 |
| 星际 | 加密文件夹／一段反复回放的旧录像 |

#### 写崩的三种方式

1. 让他借此表功。 一表功就全废。
2. 让她当场大哭。 合上盒子更好。
3. 东西太多太夸张。 一盒够了，一屋子就变味了。

## 十 · 说不出口的那件

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：坦白 6.0%

**骨架**｜关系已经很好了，但有一件事他这辈子都不打算说。

#### 节拍链

关系已稳 → 某夜（醉·病·告别）→ 他张了嘴 → 半句 → 换成别的话 → 她听出来了，没追 → 一切照旧

#### 时间轴

张嘴到换话题，只有三秒；那三秒每隔一两年出现一次。 醉的那晚、病的那晚、机场送别的那晚，同一句半途而废的话，多年里露头三四次，每次都停在同一个位置。她从第二次起就听出来了，从没追问。这条没有终点：有些话的时间轴就是永远差三秒，而这三秒两个人都认了。

#### 这条是本卷的收束

前面九条讲的都是秘密如何被揭开。这一条讲永远不被揭开的那一件。

这是关系的正常构造，算不上遗憾。两个人之间有一件永远不会说的事，这件事本身可以是关系的一部分。

#### 三种处理

| 处理 | 说明 |
|---|---|
| 她知道有那一件，且不问 | 最成熟 |
| 她不知道有那一件 | 最平静，也最脆弱 |
| 他某天差点说了 | 最有戏 |

「他某天差点说了」适合放在全书接近结尾处：一次醉酒、一次生死关头、一次深夜，他张了嘴，然后没说。

#### 可用细节

| 类 | 内容 |
|---|---|
| 那件事的性质 | 不是背叛，通常是羞耻或自我否定 |
| 差点说了的时刻 | 醉酒 ✓ · 大病 · 她受伤 · 一次告别 |
| 他停住的方式 | 说了半句 · 换成了别的话 |
| 她的反应 | 她听出来了 · 她没有追 |
| 收尾 | 什么都没变，但读者知道那件事在那儿 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她知不知道有 | 知道 | 不知道 |
| 最终 | 一直没说 | 很久以后说了 |
| 影响 | 无 | 它一直在轻微地影响他 |
| 读者知不知道 | 知道（更好） | 也不知道 |

「读者知道而她不知道」是这条最有效的配置。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听出他刚才要说别的 | 说了半句，咽回去 |
| 内心 | 他有一件事 | 这一件不能说 |
| 好的处理 | 她没有追问，也没有假装没听见 | 他没说，且不痛苦 |
| 写崩 | 写成悬念钩子 | 写成他背负重担的苦情 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 一桩他做过的事／他曾经的身份／他母亲怎么死的 |
| 修仙 | 他的一段前尘／他曾经动过的念头 |
| 星际 | 他在那场战役里做的选择 |

#### 写崩的三种方式

1. 当悬念钩子用。 它不需要被解开。
2. 让他为此痛苦一辈子。 可以带着，不必压着。
3. 最后揭开。 不揭开才是这条的意义。
