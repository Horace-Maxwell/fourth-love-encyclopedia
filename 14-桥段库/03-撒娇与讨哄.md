# 撒娇与讨哄

> **分级** `T` ｜ 预警 无 ｜ 亚型 全谱系通用（分级见各条）
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**撒娇是弱势方唯一能主动发起的权力动作**。

---

## 撒娇在这一类里是什么

在别的类型里，撒娇是可爱。这一类里，撒娇是议价。

弱势的一方不能命令、不能强求、不能翻脸。他唯一能主动做的，就是把自己的需求包装成一个她很难拒绝的形状，然后递过去。这是一次谈判，只不过用的是软的货币。

所以判断一段撒娇写得好不好，只看他有没有在冒险。撒娇必然带着被拒绝的可能，那个可能性就是这场戏的张力。没有风险的撒娇是撒泼。

| 反应族 | 作品数 | 占比 |
|---|---:|---:|
| 讨哄 | 1,573 | 54.4% |
| 撒娇 | 1,709 | 59.1% |

这两族的占比在全部反应族里排前列。它是这个类型的日常主食。

## 撒娇的四种档位

写之前先定档。档位错了，人物就崩了。

| 档 | 表现 | 适合谁 | 风险 |
|---|---|---|---|
| 一档 · 挨着 | 不说话，只是靠过来 | 所有类型，尤其冷淡型男主 | 几乎为零 |
| 二档 · 讨要 | 明确要一样东西（抱、亲、陪） | 已确立关系 | 被拒绝 |
| 三档 · 耍赖 | 不讲道理，重复要求 | 亲密度高 | 显得幼稚 |
| 四档 · 装可怜 | 表演脆弱以换取让步 | 有心机的角色 | 被识破，且掉好感 |

一档最难写也最好用。越是平时不撒娇的人，一档的杀伤力越大。

## 一 · 狠狠撒娇

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：撒娇 59.1%，讨哄 54.4%

**骨架**｜委屈攒够了，一次性兑现。她哄了很久才哄好。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 她终于回来／终于发现 |
| 2 | 他第一反应是不理（关键，不能一上来就扑） |
| 3 | 她主动靠近 |
| 4 | 他绷不住了 |
| 5 | 一次性倒出来（这一拍可以长） |
| 6 | 她一件一件接住 |
| 7 | 收在一个很小的动作上 |

第 2 拍是这条的门槛。不理一下再扑，和直接扑，是两个人物。

#### 时间轴

哄的时长就是这条的度量衡。「哄了很久」不能只用四个字带过，要写出三个阶段：

| 阶段 | 她做什么 | 他的状态 |
|---|---|---|
| 前段 | 说好话 | 不接，把脸埋起来 |
| 中段 | 换成动作（抱、拍背、揉头） | 松动，但还在赌气 |
| 后段 | 承诺具体的事 | 开始提条件（说明好了） |

他开始提条件的那一刻，就是哄好了的信号。 比他说「我没生气」可靠得多。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 被子 ✓（蒙头）· 沙发 ✓（背对着）· 枕头 ✓ · 手腕 ✓（被她拉住） |
| 他的抗拒动作 | 转过身去 · 把脸埋进沙发 · 肩膀绷着 · 她碰他就躲一下（但没躲开） |
| 她的推进动作 | 从背后抱 · 手伸到他脸前面 · 掰他肩膀 · 干脆坐在他旁边不说话 |
| 崩的信号 | 呼吸乱了 · 肩膀抖 · 声音闷在布料里 · 突然转过来抓住她 |
| 台词类型 | 他：「你不用管我」（意思是快管我）· 她：不解释，只重复「我在」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的开场 | 立刻扑上来 | 先冷着，被哄开 |
| 内容 | 只为这一件事 | 攒了很久的一堆事一起倒 |
| 她的方式 | 一直说 | 一直不说话，只抱着 |
| 收尾 | 他说没事了 | 他提了个条件（更好） |
| 事后 | 两人都不提 | 他第二天有点不好意思 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 进入点 | 她发现他把脸转开的那一下 | 听见她声音时鼻子先酸了 |
| 内心 | 我该先道歉还是先抱 | 我不能一下就原谅，但我快撑不住了 |
| 好的处理 | 她不辩解为什么晚归，她先处理他 | 他的抗拒是真的，崩溃也是真的 |
| 写崩 | 写成敷衍地哄两句 | 写成得理不饶人 |

四爱女读者的雷区是「她一味认错」，四爱男读者的雷区是「他一味索取」。两边都要有分寸，这场戏才立得住。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他背身跪着不肯起／她亲自去扶／隔着帐子说话 |
| 修仙 | 他闭关不出／她在洞府外坐了一夜／传音他不回 |
| 星际 | 他锁了舱门／她用最高权限开门／他没换密码（这就是答案） |

星际那一版的「他没换密码」是极佳的收法：抗拒是姿态，留门是真心。

#### 写崩的三种方式

1. 让他一被哄就好。 那前面积累的全都白费了。他要慢，要有反复。
2. 让她说太多道理。 讲道理是这条的天敌。她要做的是听着，不是说服。
3. 写成他单方面发泄。 撒娇是双人戏。她的每一个反应都要写。

> 也就一寸。再往里就是扶手了，他没地方去，只好停在那儿，肩膀绷着，脸对着靠垫。
> 「饭我热过了。」她说。
> 他没吭声。

## 二 · 索抱

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 64.3%（全部反应族最高）

**骨架**｜他张开手臂，什么也不说。

#### 节拍链

张手 → 等 → 她过来／不过来 → 抱到 → 不撒手

#### 时间轴

等的那两秒就是全部。 手张开之后到被抱住之前，是这条唯一的悬念，也是唯一的风险。

#### 可用细节

| 类 | 内容 |
|---|---|
| 姿势 | 坐着张手（低姿态）· 站着张手（平等）· 躺着掀开被子（邀请） |
| 她的反应梯度 | 立刻过来 · 先做完手上的事 · 说「等我一下」（他就一直张着） |
| 他的坚持 | 手一直张着不放下，这个细节比任何台词都有效 |
| 抱到之后 | 手扣在她背上 · 下巴搁在她肩上 · 不撒手，她要动他就收紧 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 有没有理由 | 有（受委屈了） | 没有，就是想 |
| 她的反应 | 秒过来 | 让他等 |
| 他要不要说 | 不说，只张手 | 「抱一下」（说出口反而更难） |
| 收尾 | 抱一下就散 | 抱着不动很久 |

「让他等」这一端要小心处理。等一会儿是情趣，等太久是冷落。分寸在于她有没有回应那个张开的手（哪怕只是看一眼）。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她转头看见他张着手在等 | 手张开之后那几秒 |
| 内心 | 手上的事还有三行没写完 | 她要是不过来我就装作在伸懒腰 |
| 好的处理 | 她放下手上的事过去了 | 他没把手放下 |
| 写崩 | 写成她永远秒到 | 写成他必须被满足 |

「装作伸懒腰」这个心理是这条的精髓：他给自己准备了退路，说明他真的在冒险。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 张开双臂／掀起衣袖／她走过去他就跪坐着抱住她的腰 |
| 修仙 | 他的灵识往她那边探了一下又缩回来 |
| 星际 | 在失重舱里他飘过来，抓住她的手腕 |

#### 写崩的三种方式

1. 省略等待。 张手立刻被抱，那是拥抱不是索抱。
2. 让他反复索抱。 一章一次，多了就腻。
3. 配大段心理描写。 这条是纯动作，越少字越好。

#### 示例（本库自撰，可直接改写）

> 他坐在床沿，把两只手张开了。
> 她还在电脑前，屏幕的光把她的侧脸削得很白。
> 「等我一下。」她说，没回头。
> 他没有放下。手就那么举着，肘弯有点酸，他换了个角度，还是举着。
> 他想好了：她要是不过来，就说自己在伸懒腰。
> 光灭了。她走过来，撞进他怀里的时候力气不小，撞得他往后仰了一下。

## 三 · 蹭

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：撒娇 59.1%

**骨架**｜没有语言的请求。一档撒娇的标准形态。

#### 节拍链

找场合（她在忙）→ 伪装成不小心 → 蹭一下停住 → 看她反应 → 没反应再蹭 → 她按住他的头

#### 时间轴

两次蹭之间的间隔就是钟。 第一下和第二下隔多久、第二下比第一下近多少，是他胆量的可视化。她没反应的时间越长，下一次越轻也越近。全场无台词，时间全靠停顿的长短写出来。

#### 蹭的位置学

蹭哪里，意思完全不同。这张表是这条的全部内容：

| 位置 | 意思 | 亲密度 |
|---|---|---|
| 蹭手背 | 试探，可以被忽略 | 低 |
| 蹭手臂 | 我在这儿 | 低 |
| 蹭肩膀 | 我累了 | 中 |
| 蹭脖颈 | 我要你注意我 | 中高 |
| 蹭掌心 | 完全交付 | 高 |
| 用额头顶她 | 撒赖，不讲理 | 高 |

从低往高走一整章，比一上来就到高位有效得多。

#### 可用细节

| 类 | 内容 |
|---|---|
| 触发场合 | 她在忙 · 她在打电话 · 有别人在 · 睡前 |
| 他的伪装 | 装作是不小心 · 装作在找东西 · 装作困了 |
| 她的三种反应 | 不理（他就继续）· 手伸过去（他就得寸进尺）· 按住他的头（这是最好的一种） |
| 频率 | 蹭一下停住，看她；没反应再蹭 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 私下 | 有人在（他会先看一眼四周） |
| 他承不承认 | 不承认，说是不小心 | 直接蹭，坦坦荡荡 |
| 她的回应 | 摸头 | 按住不许动（更有味道） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 手臂上传来的重量 | 蹭第一下之前的犹豫 |
| 好的处理 | 她手上的事没停，但另一只手抬起来了 | 他蹭完之后不看她 |
| 写崩 | 写成她厌烦 | 写成宠物化 |

宠物化是这一族最大的陷阱。 判据：他有没有自己的意志。蹭是他选择的示弱，不是他的本能反应。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 挨着坐／衣角碰衣角／替她研墨时手指擦过 |
| 修仙 | 灵识轻轻碰一下／剑鞘挨着她的 |
| 星际 | 座椅调到最靠近／共享同一条安全索 |

#### 写崩的三种方式

1. 写成动物行为。 见上。
2. 一次蹭到位。 递进才有戏。
3. 她每次都立刻回应。 偶尔没回应，下一次的蹭才有分量。

## 四 · 讨奖励

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：撒娇 59.1%

**骨架**｜他做完了一件事，然后站在那里等。

#### 节拍链

他完成某事 → 汇报（或者不汇报，只是站着）→ 等 → 她给／不给 → 他要的其实不是奖励

#### 时间轴

无。这条的张力来自他要不要开口。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他做的事 | 打扫了家 · 学会了那道菜 · 考试／业绩 · 忍住了没发火 · 自己去医院了 |
| 汇报的方式 | 直接说 · 把成果摆在她能看见的地方 · 假装不经意提起 · 什么都不说，只是等 |
| 他想要的 | 一句夸 · 摸头 · 亲一下 · 她今晚早点回来 |
| 她的给法 | 明确给 · 装没看见（然后在别处补上）· 逗他，让他自己说 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他开不开口 | 直接要 | 等到最后也没说 |
| 她给不给 | 给 | 先不给，逗他 |
| 奖励的性质 | 具体的（亲一下） | 抽象的（她的时间） |
| 落差 | 他要到了 | 她忙忘了（转 [04 卷委屈](04-委屈与破防.md)） |

「等到最后也没说」＋「她忙忘了」这个组合最疼，且不需要任何人做错事。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她注意到他今天一直在她视线里晃 | 排练了三遍怎么开口 |
| 好的处理 | 她主动发现，不让他开口 | 他没得到也不闹 |
| 写崩 | 写成她施舍 | 写成他索取无度 |

「她主动发现，不让他开口」是这条的最优解。让弱势方不必开口，是强势方能给的最高级的体面。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 呈上他抄的经／他打的猎物／等她赏 |
| 修仙 | 突破了一个境界／炼成了一炉丹／等她一句「不错」 |
| 星际 | 模拟考核成绩／等她在终端上看见 |

#### 写崩的三种方式

1. 让奖励太物质。 他要的是被看见，不是东西。
2. 让她夸得太满。 一句就够，多了变哄小孩。
3. 省略他等待的过程。 等待本身才是这条的内容。

## 五 · 装睡

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：就地睡着 52.8%

**骨架**｜他没睡着，但他闭着眼；她知道，她也不说破。

#### 节拍链

他装睡 → 她过来 → 她做了些什么（这是全条内容）→ 他没有动 → 她走了／留下 → 他睁开眼

#### 时间轴

他装睡的时长 ＝ 他忍住不动的时长。呼吸是唯一的破绽。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的破绽 | 呼吸太规律 · 睫毛 ✓ 在抖 · 手指蜷了一下 · 她碰他的时候太配合 |
| 她做的事 | 掖被子 · 看很久 · 亲一下 · 说一句只有睡着的人才能听的话 |
| 关键道具 | 被子 ✓ · 台灯 ✓ · 枕头 ✓ · 她放在床头的东西 |
| 他睁眼的时机 | 她走后 · 她说完那句话之后 · 门关上的一刻 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他为什么装 | 想看她会做什么 | 不想面对刚才那场争执 |
| 她知不知道 | 不知道 | 知道，故意演给他听 |
| 她说了什么 | 什么也没说 | 一句她清醒时说不出口的 |
| 他的处理 | 第二天当作不知道 | 他后来引用了那句话 |

「她知道他在装，故意说给他听」是双向装的最高级用法：两个人都不诚实，但两个人都听懂了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她注意到他睫毛在抖，决定不说破 | 她的呼吸靠近的那一下 |
| 好的处理 | 她把该说的说完，然后走 | 他一直没睁眼 |
| 写崩 | 写成她被骗 | 写成他偷窥式的得意 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 装醉／闭目养神／她以为他睡了才说的话 |
| 修仙 | 装作入定／他的神识其实全程醒着 |
| 星际 | 装作在休眠舱睡着／生命体征他自己调过 |

#### 写崩的三种方式

1. 让他忍不住动。 忍住才有张力。
2. 让她说太多。 一句。最多两句。
3. 第二天马上摊牌。 悬着更好。

## 六 · 闹脾气

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 54.6%

**骨架**｜他在生气，但他生气的方式是让自己更显眼。

#### 节拍链

起因 → 在她视线内制造动静 → 每个动作都瞟她一眼 → 她一句「过来」→ 他绷着脸被拉过去 → 没挣

#### 时间轴

动静按分钟升档。 抽屉关重一点、杯子放响一点、叹气加大音量——每隔几分钟升一级，全部动静都精确控制在她听得见的范围内。她拖得越久他动静越大；那句「过来」出现的时机，就是她给这场戏定的片长。

#### 闹与真气的区别

| | 闹脾气 | 真生气 |
|---|---|---|
| 位置 | 待在她看得见的地方 | 走开 |
| 音量 | 摔东西摔得很轻 | 一点声音都没有 |
| 眼神 | 时不时瞟她 | 不看她 |
| 时长 | 撑不过一小时 | 好几天 |
| 想要的 | 被哄 | 被留下 |

写清楚是哪一种，这场戏才成立。 混着写就变成了不可理喻。

#### 可用细节

| 类 | 内容 |
|---|---|
| 闹的动作 | 碗放得重一点 · 门关得响一点（但没摔）· 走过她面前三次 · 故意不吃饭 |
| 破绽 | 每一次动作都在她视线范围内 |
| 她的应对 | 装没看见（让他闹）· 一句「过来」（最有效）· 直接抱住 |
| 收场 | 他被拉过去的时候还绷着脸，但没挣 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 起因 | 具体的一件事 | 攒了很久，这件是导火索 |
| 她的处理 | 立刻哄 | 晾一会儿再哄 |
| 他的收场 | 自己找台阶下 | 等到她给台阶 |
| 事后 | 两人都笑了 | 他有点羞耻 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 判断 | 她要先分清这是闹还是真气 | 我在闹，我知道我在闹 |
| 好的处理 | 她准确识别，用对的方式回应 | 他保留了收场的体面 |
| 写崩 | 写成她哄不明白 | 写成无理取闹 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 侍立时站得笔直不看她／布菜时故意漏了她那道 |
| 修仙 | 剑气收得比平时重／在她洞府外练剑练到半夜 |
| 星际 | 值班表排得跟她全错开（但还是每天路过） |

#### 写崩的三种方式

1. 让闹变成真吵。 界限一破就是另一条了。
2. 让她完全没察觉。 她可以选择不理，不能没看见。
3. 闹得太久。 一小时是上限。

## 七 · 求表扬

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：撒娇 59.1%

**骨架**｜和「讨奖励」的区别：讨奖励要东西，求表扬只要一句话。

#### 节拍链

做完 → 看她 → 她没反应 → 更明显地看她 → 忍不住说了 → 她给了

#### 时间轴

从做完到开口，中间那段沉默就是全部时长。 他撑了一顿饭还是撑了一晚上，撑的时长就是自尊的厚度。写法上让他撑到一个具体节点——她伸手关灯的前一秒——才憋不住，比撑不满三分钟高级得多。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的暗示梯度 | 站在她旁边 → 把东西放到她手边 → 咳一声 → 「你不觉得今天……」 |
| 她的三种给法 | 认真夸（他会不好意思）· 敷衍夸（他会更闹）· 用行动夸（摸头，最有效） |
| 时间点 | 他等的时长和他的骄傲成反比 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他忍不忍 | 忍住了没说 | 说了 |
| 她的方式 | 语言 | 动作 |
| 落差 | 夸到了 | 她心情不好，没接住 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他一直在旁边转 | 说出口之前的三次深呼吸 |
| 好的处理 | 她准确地夸到了他在意的那一点 | 他说完之后自己也笑了 |
| 写崩 | 写成她随口敷衍 | 写成他讨要 |

「夸到了他在意的那一点」是关键。 夸错地方比不夸更伤，因为它说明她没看懂。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 呈上抄好的字／等她一句「有长进」 |
| 修仙 | 剑法练成了一式／在她面前使了一遍 |
| 星际 | 训练分数发到她终端上 |

#### 写崩的三种方式

1. 让她夸得笼统。 「你真棒」是没有信息的。
2. 让他毫不掩饰地讨。 一点点掩饰才可爱。
3. 省略他的暗示过程。 暗示过程就是这条本身。

## 八 · 装可怜

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：委屈 54.6%

**骨架**｜他放大自己的脆弱，为了换一个具体的让步。四档撒娇，风险最高。

#### 节拍链

他有诉求 → 他知道直说会被拒 → 表演脆弱 → 她心软／她识破 → 结果

#### 时间轴

脆弱是重资产表演，撑不过一个场景。 超时必穿帮：眼眶能红十分钟，红不了一晚上。她识破的时点决定走向——当场戳穿是喜剧，配合到落幕才说「下次直说」是正剧，两种都比演砸了强。

#### 这条为什么危险

装可怜是用感情做筹码。写好了是聪明，写崩了是操控。分界线：

| 可以 | 不可以 |
|---|---|
| 夸大真实存在的委屈 | 编造不存在的伤害 |
| 用来讨一个亲亲 | 用来让她放弃重要的事 |
| 被识破后自己也笑了 | 被识破后加码 |
| 偶尔为之 | 成为惯用手段 |

判据：他有没有把她的愧疚当成资源来经营。 一次是撒娇，三次是操控。

#### 可用细节

| 类 | 内容 |
|---|---|
| 表演的道具 | 手上的小伤（真的，但没那么疼）· 提起旧事 · 一个人待着的姿势 |
| 破绽 | 她一心软他眼神就亮了 · 表演的位置刚好在她视线里 |
| 她的识破 | 不点破，配合一次 · 点破，但还是给了 · 点破，且不给 |
| 他的收场 | 被识破后笑出来（好）· 被识破后恼羞（差） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 委屈的真假 | 真的，只是放大了 | 编的 |
| 她的反应 | 心软 | 一眼看穿 |
| 后续 | 他自己不好意思 | 他尝到甜头，下次加码（危险，要有代价） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 判断 | 她要分清这次是不是真的 | 我在演，但我委屈是真的 |
| 好的处理 | 她给，并且让他知道她知道 | 他适可而止 |
| 写崩 | 写成她永远被骗 | 写成他把这当成工具 |

「她给，并且让他知道她知道」这个处理最漂亮。她把选择权亮出来了，这就从操控变成了共谋。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 跪得比平时久／提起当年的事／不合时宜地咳一声 |
| 修仙 | 显出旧伤／灵力运转时故意滞了一下 |
| 星际 | 体检数据挑着给她看 |

#### 写崩的三种方式

1. 让他持续得逞。 得逞三次以上，人物就从可爱变成了算计。
2. 让她永远看不穿。 她要能看穿，选择给才有分量。
3. 不给代价。 这条必须在某处付出代价，否则文本就是在推荐这种行为。

## 九 · 学别人撒娇

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：撒娇 59.1% 衍生

**骨架**｜他不会撒娇，于是他去学。学得很生硬，效果反而更好。

#### 节拍链

他发现别人这样有用 → 偷偷学 → 生硬地用出来 → 她愣住 → 他窘 → 她笑了 → 她说以后不用学

#### 时间轴

练习期以天计，出手只有一次。 潜伏期里他观察、模仿、对着镜子或对着猫排练；实战窗口只有几秒。生硬感的来源正是这个悬殊的比例——练了一周的动作用出来只有两秒，两秒里全是排练的痕迹。

#### 为什么这条特别好用

它把撒娇这件事本身变成了情节。对冷淡型、高冷型、不会示弱的男主，这是唯一自然的破冰路径。

而且它自带反差：一个不会撒娇的人认真研究怎么撒娇，比会撒娇的人撒娇动人得多。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的学习痕迹 | 手机 ✓ 上搜过的东西 · 观察别的情侣 · 问了朋友 · 对着镜子 ✓ 练 |
| 生硬的表现 | 语气不对 · 时机不对 · 用词像背下来的 · 说完自己先僵住 |
| 她的反应 | 先愣 · 再想笑 · 忍住 · 然后心软 |
| 收尾 | 她说「你不用这样」（意思是你本来就够了） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 学的来源 | 网上 | 身边某个很会撒娇的人（可带醋意） |
| 效果 | 成功 | 失败，但她被逗笑了（同样成功） |
| 她说不说破 | 说破 | 假装没看出来，配合 |
| 后续 | 他放弃了，做回自己 | 他慢慢学会了，但只对她 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看出这句话是学来的 | 说出口那一刻的耳鸣 |
| 好的处理 | 她配合了，事后才说破 | 他窘但没跑 |
| 写崩 | 写成她当场大笑 | 写成他一学就自然 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 看别的侍君怎么讨主君欢心／学得不伦不类 |
| 修仙 | 照着话本学／道侣间的相处他一窍不通 |
| 星际 | 看了三部老片子学怎么表达 |

#### 写崩的三种方式

1. 让他学得很成功。 生硬才是这条的全部魅力。
2. 让她嘲笑。 笑可以，嘲笑不行。
3. 一次就学会。 让他失败两次。

## 十 · 撒娇失败

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：撒娇 59.1% ＋ 委屈 54.6%

**骨架**｜他撒娇了，她没有回应。这是撒娇这一族里唯一必须写的一条。

#### 为什么必须有这一条

前面九条写的都是撒娇成功。如果一部作品里撒娇永远成功，那撒娇就没有风险，没有风险就没有张力，这个动作就退化成了装饰。

必须有一次失败，前面所有的成功才有重量。

#### 节拍链

他撒娇 → 她没反应（她不是在拒绝，只是没留意）→ 他的手停在半空 → 他自己收回来 → 若无其事 → 她后来才发现

#### 时间轴

「手停在半空」那一秒是这条的全部。 前后都可以省略。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她没接住的原因 | 在忙 · 心情不好 · 手机 ✓ 上有别的事 · 单纯没注意到 |
| 他的收回动作 | 把张开的手改成挠头 · 把话头转开 · 站起来说去倒水 |
| 残留的痕迹 | 他那天晚上格外安静 · 第二天他没再撒娇 |
| 她的发现时机 | 当晚 · 几天后 · 或者永远没发现（更疼） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她为什么没接 | 客观原因 | 她那阵子对他不耐烦 |
| 他的处理 | 当场自嘲 | 咽下去，不提 |
| 她发现没 | 发现了，补上 | 一直没发现 |
| 长期影响 | 没有 | 他从此撒娇少了（这个变化要被写出来） |

最后一行是这条的价值所在：行为频率的变化，是最不着痕迹的伤害记录。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她某天忽然想起上周他伸手的样子 | 手停在半空的那一秒 |
| 好的处理 | 她想起来了，且没有大张旗鼓地补偿 | 他没有责怪，但他记住了 |
| 写崩 | 写成她冷血 | 写成他心碎欲绝 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他跪了很久她没叫起／递上去的东西她随手放下了 |
| 修仙 | 传音过去没有回应／他的灵识碰了一下就退回来了 |
| 星际 | 通讯请求她挂断了，随后回了一条「在忙」 |

#### 写崩的三种方式

1. 让她马上意识到并道歉。 立刻补上就没有这条了。
2. 写成她的过错。 她真的在忙。这条的疼在于没有人做错。
3. 让他表现出受伤。 他要装得很好，读者要看穿。
