# 衣装与穿戴

> **分级** 分级见各条，分级上限 `M` ｜ 预警 见各条 ｜ 亚型 全谱系通用
> 频次来源：物件档位来自语料扫描，做法与 [03-世界观设定/05-衣装与器物的权力语法](../03-世界观设定/05-衣装与器物的权力语法.md) 同源。三档只说撞车风险，不说好坏
> 这一族的共同机关：**权力全在动作的方向上。谁的手在动、动的是谁身上的东西，这两问答完，关系就写完了。**

## 这一族跟别族的分界

衣服本身没有权力。一件白衬衫挂在衣柜里什么也不是，穿在他身上、扣子是她系的，才开始有话说。所以这一族的每一条都不写衣服，写**手**。[29-微小仪式拾遗 · 四 · 她带他买衣服](29-微小仪式拾遗.md#四--她带他买衣服) 是这一族的先声，那条写的是「选」，这一族写的是「穿、系、摘、收」。[06-身体接触 · 七 · 系扣子](06-身体接触.md#七--系扣子) 写的是接触本身，这一族写的是接触之后那件东西还留在他身上。| 别族 | 那边写什么 | 这一族写什么 |
|---|---|---|
| 29 · 她带他买衣服 | 挑选的过程，试衣间的轮数 | 挑完之后，穿在身上的日子 |
| 06 · 系扣子 | 指尖与皮肤的距离 | 系完之后那颗扣子归谁管 |
| 35 · 规矩的进阶 | 规则的协商与升级 | 规则落在一件具体的东西上 |

## 一 · 打领带

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：领带 常见档

**骨架**｜他自己打了三次都不对，她说过来。两分钟，她手背蹭到他喉结两回，他一动不敢动。

#### 节拍链

他对着镜子失败若干次 → 她注意到 → 她说过来 → 他站定，微微低头 → 她动手 → 中途有一次停顿 → 勒紧 → 她拍一下他胸口说好了 → 他去照镜子

#### 时间轴

以她的手离开他脖子的次数计。打一条领带要摸三到四次喉结附近，每一次他都得咽一下。第一次他躲了一下，第二次没躲，第三次她停了两秒才继续——那两秒是这场戏的正中心。

#### 高度差的权力语法

| 环节 | 机关 |
|---|---|
| 谁低头 | 他比她高，所以他必须低头才能让她够到。**身高优势在这里反过来变成顺从的姿势** |
| 手的位置 | 领带在喉咙上，那是最不设防的地方，他把它交出去了 |
| 松紧 | 她勒紧的那一下，他的呼吸有半秒空白。她问紧不紧，他说不紧 |
| 收尾 | 她拍一下他胸口，动作像检查货品，两个人都没觉得不对 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的失败 ✓ | 第三次拆开时他有点烦，她在门口看了一会儿才出声 |
| 低头 | 他得比平时低五公分，脖子后面绷着 |
| 停顿 ✓ | 她的手停在结上没动，他等着，也不催 |
| 勒紧 | 「紧不紧？」「不紧。」——其实有点 |
| 镜子 | 他去照，发现打得比自己好，没说出口 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 日常上班 | 他要去见对他不利的人，她打得格外慢 |
| 熟练度 | 他真的不会 | 他会，只是这三个月都让她打 |
| 结尾 | 她拍胸口 | 她揪着领带把他拽下来一点，说了句只有他听得见的话 |
| 后续 | 当天解开 | 那条领带后来只在她在的日子出现 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他低头那一下，后颈的弧度 | 她的手背蹭过来时，他喉咙里那一下 |
| 内心 | 这么大的人，领带都打不好 | 让她弄比自己弄舒服，这话不能说 |
| 好的处理 | 她动作利落，不拖泥带水 | 他没道谢，只是站得更直了 |
| 写崩 | 写成她保姆式照顾 | 写成他撒娇求她打 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她替他系冠缨，下颌抬起来才够得着 |
| 修仙 | 她替他束发穿簪，簪是她的旧物 |
| 星际 | 她替他扣上军装领口的暗扣，那是仪仗规格 |

#### 写崩的三种方式

1. 她一次成功。得有停顿，停顿是戏。
2. 他全程说话。这场戏的分量在他说不出话。
3. 写成她教他打。教学取消了权力，变成培训。

## 二 · 她的衬衫

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：白衬衫 常见档

**骨架**｜他穿她的衬衫，肩膀撑得紧，袖子短一截。她看了一眼说别脱，就这样。

#### 节拍链

他洗完澡没衣服 → 她随手扔一件给他 → 他穿上，明显不合身 → 他要脱 → 她说别脱 → 他站在那儿被看了几秒 → 后续这件衬衫的归属发生变化

#### 时间轴

以「不合身」被提起的次数计。第一次是他自己说，第二次是她说不用改，第三次是别人问起来。三次之后这件衬衫就不再是衣服了。

#### 尺码即证据的权力语法

| 环节 | 机关 |
|---|---|
| 不合身 | 撑紧的肩、短一截的袖，**每一处不合身都在说这件衣服本来是谁的** |
| 谁提出脱 | 他提，说明他知道这不合适；她否决，说明合适不合适她说了算 |
| 被看的几秒 | 她没说好看，只是看着。评价权在她手上，她可以不给 |
| 归属漂移 | 后来这件衬衫在他那儿了，两个人都没提过它是怎么过去的 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 尺寸 ✓ | 袖子到手腕上面两指，他老想往下扯 |
| 她的一眼 | 她从上到下看了一遍，说了句「行」，就没了 |
| 领口 | 她的领口对他来说太紧，第一颗扣不上，他索性敞着 |
| 气味 ✓ | 洗过了，还是不是他惯用的那个味 |
| 外人 | 同事说这件挺特别，他说买错码了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 起因 | 意外没衣服 | 她故意的，早就想看 |
| 尺寸差 | 差一点 | 差很多，穿上像偷来的 |
| 归属 | 还回去 | 留下了，成了他的睡衣 |
| 反向 | 她穿他的 | 她穿他的会松垮，读出来是另一种：那是占有不是标记 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他肩膀把布料撑起来的那道线 | 领口太紧，第一颗扣不上 |
| 内心 | 我的衣服在他身上，这事挺好 | 不合身，但没打算换 |
| 好的处理 | 她只说一个字 | 他没问为什么不让脱 |
| 写崩 | 写成她夸他好看 | 写成他害羞遮挡 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她的外袍披在他身上，尺寸不对，纹样也是女式 |
| 修仙 | 她的法衣认主，他穿上有排斥感，她抬手压下去 |
| ABO | 沾着她信息素的外套，他穿了一整天没换 |

#### 写崩的三种方式

1. 她夸他好看。夸奖是平等关系的语言，这里不能有。
2. 他害羞遮挡。遮挡是拒绝，这条戏要的是接受。
3. 交代衬衫怎么留下的。留白才是归属漂移。

## 三 · 衣帽间的镜子

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：衣帽间 多见档

**骨架**｜她叫他站到全身镜前，从背后给他换上一件，扣子故意扣错一颗，说就这样出去。

#### 节拍链

她把他带进衣帽间 → 让他站到镜前 → 她站在他背后 → 换 → 她故意留一处不整齐 → 他伸手要改 → 她按住 → 他就那样出门

#### 时间轴

以他在镜子里看她的次数计。他看不见她的手，只能在镜子里找她的脸。找一次是确认，找三次是依赖。第三次她终于跟他对上眼，那一刻这场戏成立。

#### 镜子的权力语法

| 环节 | 机关 |
|---|---|
| 站位 | 她在他背后，**他能看见的只有镜子里的她，看不见她的手要做什么** |
| 镜子 | 他被迫看着自己被安排成什么样，逃不掉这个视角 |
| 那颗错扣 | 不是疏忽。留一处不整齐，等于宣布整齐与否她说了算 |
| 他的手被按住 | 他想改，说明他知道错了；她按住，说明这不是错 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 镜中对视 ✓ | 他找了三次才对上，她一直在看他的后颈 |
| 背后的手 | 他感觉到布料被拉平，不知道下一步是哪儿 |
| 错扣 ✓ | 领口歪着，一整天都有人多看他一眼 |
| 按住 | 她的手覆在他手背上，没用力，他就停了 |
| 出门 | 走到玄关他又想去改，她在后面咳了一声 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 家常 | 有正式场合要去，那颗错扣的代价就真了 |
| 他的反应 | 顺从 | 他改了，她没说话，那件衣服此后再没出现过 |
| 错处 | 一颗扣子 | 袖口卷法、领带歪度，越小越狠 |
| 外人 | 无人看见 | 同事提醒他扣错了，他说知道 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 镜子里他找她眼睛的那三次 | 手背被按住时，他停下来的那半秒 |
| 内心 | 他站在那儿的样子，是我摆出来的 | 歪着就歪着，改了她会不高兴 |
| 好的处理 | 她全程不解释为什么 | 他没问为什么 |
| 写崩 | 写成她挑剔他不会穿 | 写成他觉得屈辱 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 铜镜前她替他理衣襟，故意留一角未压平 |
| 修仙 | 水镜映出他的法衣，她指尖一动改了纹路走向 |
| 星际 | 全息镜前她调整他的仪仗配饰，留一处不合规格 |

#### 写崩的三种方式

1. 她解释为什么留那颗扣子。解释就废了。
2. 他觉得屈辱。屈辱是另一条线，这条要的是他接受得心甘情愿。
3. 镜子只当背景。镜子必须被看，被看才有第二个视角。

## 四 · 勒紧腰封

`M` ｜ △调教 ｜ 古代女尊／现代都市 ｜ 语料频次：腰封 偶见档／束腰 偶见档

**骨架**｜以整理仪容为名，她一格一格勒紧。每紧一格他的腰挺一分，呼吸短一分，她数着。

#### 节拍链

场合要求整齐 → 她说过来我看看 → 他站定 → 第一格 → 第二格 → 他吸气的声音变了 → 她问还行吗 → 他说行 → 最后一格 → 她说好了

#### 时间轴

**以格数计。** 三格是整理，五格是别的。她在第四格问一次，第五格不再问。他答「行」的那次比她收的那格重要——那句话之后，剩下的是他同意的。

#### 呼吸的权力语法

| 环节 | 机关 |
|---|---|
| 名义 | 整理仪容。**名义越正当，实际越不是那么回事，两个人心里都清楚** |
| 第四格的问 | 她问了，他有机会说停，他没说。同意在这一格发生 |
| 第五格不问 | 不问是因为上一格已经答过了。**问一次，管后面全部** |
| 呼吸 | 他说话变短，句子被迫切碎，这是最省字的顺从证据 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 手法 ✓ | 她从背后收，膝盖抵着他腰眼借力 |
| 声音 | 搭扣一格一格过去，钝响 |
| 他的答 ✓ | 「还行吗」「行」——两个字，说完之后没再说过整句 |
| 姿态 | 腰一挺，肩就往后打开，他站成了另一个人 |
| 解开 | 当晚她解的时候，他松了一口很长的气，她笑了一下 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 出席正式场合 | 没有场合，纯粹是规矩 |
| 问不问 | 问过一次 | 从来不问，那就是另一种关系了 |
| 时长 | 一晚 | 常态，他每天早上自己系到第三格，第四第五格等她 |
| 解 | 她解 | 她给了他钥匙式的许可：难受了自己松，但要告诉她 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他吸气的声音在第四格变了调 | 她膝盖抵上来那一下，他知道要来了 |
| 内心 | 他挺起来的样子，比松垮着好看太多 | 紧是紧，站得住 |
| 好的处理 | 她问了，且真的等他答 | 他答得干脆，没犹豫 |
| 写崩 | 写成她不管他难不难受 | 写成他忍着不敢说 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 修仙 | 束灵带一寸寸收，灵力流转被压住，他额角出汗 |
| ABO | 抑制项圈调紧一档，信息素被压回去 |
| 星际 | 战术束带按标准勒紧，她亲手校验 |

#### 写崩的三种方式

1. 她一格都不问。问那一次是安全框架落在文本里的样子，删了整条变味。
2. 他忍着不说。忍是被迫，这条要的是他答应。
3. 只写紧不写解。解开那一下才是完整的一轮，没有它就只剩施加。

## 五 · 摘玉冠

`T` ｜ 无预警 ｜ 古代女尊／修仙 ｜ 语料频次：玉冠 偶见档

**骨架**｜她深夜进殿，抬手把他束发的玉冠摘了。青丝散下来，他得仰起脸才看得见她。

#### 节拍链

她进来 → 他起身行礼 → 她走近 → 抬手 → 玉冠离开 → 头发散落 → 他仰脸 → 她把玉冠放在案上 → 那一夜玉冠没回到他头上

#### 时间轴

以玉冠离开头顶到落在案上的那几步计。这几步里他不能动，也不能整理头发。等她把冠放下，规矩才重新开始。

#### 冠的权力语法

| 环节 | 机关 |
|---|---|
| 冠是什么 | 身份、体面、可以见人的样子。**摘冠不是脱衣服，是取消他的社会面** |
| 谁摘 | 冠该由他自己或近侍来摘。她越过这一层，等于宣布这一层不作数 |
| 仰脸 | 头发散了挡视线，他必须抬头。姿势由物件决定，不由命令决定 |
| 放在案上 | 不是扔，是放。她收着，明天还给不给由她 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 声音 ✓ | 玉碰到木案，一声很轻的响，殿里很静 |
| 头发 | 散下来盖住半边脸，他不敢抬手拨 |
| 仰脸 ✓ | 他仰起来，睫毛上有殿里的灯 |
| 她的手 | 摘的时候指腹擦过他鬓角，没停 |
| 第二天 | 冠还在案上。他没去拿，等她递过来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 私下 | 有旁人在，那就是当众降格 |
| 她的态度 | 随手 | 郑重，郑重比随手更压人 |
| 归还 | 第二天还 | 换了一顶，样式是她定的 |
| 反向 | 他自己摘了递上 | 那是请罪，不是被摘，读出来完全两回事 |

#### 双向写法

## 八 · 耳钉

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：耳钉 多见档

| 那半圈 | 正一下用不着转半圈。多出来的那半圈是给他一个人的 |

## 九 · 钥匙挂在她锁骨上

`M` ｜ ⚠️主奴 △调教 ｜ 现代都市／古代女尊 ｜ 语料频次：贞操锁 多见档

**骨架**｜锁扣上了，钥匙穿在链子上挂在她锁骨窝里。他每次抬眼都看得见，看得见也拿不到。

#### 节拍链

协商与同意（必须写） → 扣上 → 钥匙穿链 → 链子挂到她脖子上 → 他看见了 → 日常里反复看见 → 解除的那次由她提

#### 时间轴

以他看见钥匙的次数计。器具本身在身上不产生新信息，产生信息的是那把钥匙每天在她锁骨上晃。一天看见五次就是被提醒五次。

#### 钥匙的位置就是全部的权力语法

| 环节 | 机关 |
|---|---|
| 同意在前 | 这条戏的前提是他答应过。**没有那一段，后面全是别的东西** |
| 器具在他身上 | 但器具不产生戏，它只是把状态固定下来 |
| 钥匙在她身上 | 而且在锁骨这个既显眼又私密的位置。**戏全在这儿** |
| 他能看见 | 看得见拿不到，比藏起来狠得多 |
| 谁提解除 | 她提。他若开口求，那是另一条线，代价不同 |

| 类 | 内容 |
|---|---|
| 位置 ✓ | 链子长度是她量过的，正好落在锁骨窝 |

| 洗澡 | 她进浴室会把链子取下来放在台面上，他站在门口没进去 |

| 轴 | 一端 | 另一端 |
|---|---|---|

## 十 · 铃铛不许响
