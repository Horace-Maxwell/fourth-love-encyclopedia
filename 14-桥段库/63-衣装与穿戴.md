# 衣装与穿戴

> **分级** 分级见各条，分级上限 `M` ｜ 预警 见各条 ｜ 亚型 全谱系通用
> 频次来源：物件的档位来自语料扫描，做法和 [03-世界观设定/05-衣装与器物的权力语法](../03-世界观设定/05-衣装与器物的权力语法.md) 同源。三档只表示撞车风险的高低，不评好坏
> 这一族看两件事：谁的手在动，动的是谁身上的东西。权力全落在动作的方向上。

| 缩写 | 全称 | 含义 |

| RACK | Risk-Aware Consensual Kink | 知晓风险的前提下双方同意 |
| PRICK | Personal Responsibility, Informed Consensual Kink | 个人责任前提下的知情同意 |

三者的共同点：同意必须是知情的、可撤回的、由具备判断能力的成年人做出的。

**虚构与现实的分界**：这一族写的是器物在场景里怎么承载权力，不是现实实践指南。虚构里可以省略协商、省略解除时限、省略身体检查，现实中这三样一样都省不得。涉及呼吸限制、长时间贞操器具、拘束后独处的写法，现实中均属高风险，本族不给任何操作参数。完整判据在 [06-尺度与写法/04-训诫与BDSM专论 § 八](../06-尺度与写法/04-训诫与BDSM专论.md)，那里是唯一来源。

## 这一族跟别族的分界

衣服自己没有权力。一件白衬衫挂在衣柜里什么都不算，穿到他身上、扣子由她来系，才有了话说。所以这一族每一条写的都是**手**，衣服本身不写。[29-微小仪式拾遗 · 四 · 她带他买衣服](29-微小仪式拾遗.md#四--她带他买衣服) 是这一族的先声，那条写「选」，这一族写「穿、系、摘、收」。[06-身体接触 · 七 · 系扣子](06-身体接触.md#七--系扣子) 写接触本身，这一族写接触过后，那件东西还留在他身上。

| 别族 | 那边写什么 | 这一族写什么 |
|---|---|---|
| 29 · 她带他买衣服 | 挑选的过程，试衣间的轮数 | 挑完之后，穿在身上的日子 |
| 06 · 系扣子 | 指尖与皮肤的距离 | 系完之后那颗扣子归谁管 |
| 35 · 规矩的进阶 | 规则的协商与升级 | 规则落在一件具体的东西上 |

## 一 · 打领带

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：领带 常见档

**骨架**｜他自己打了三回都没打对，她说过来。两分钟里，她的手背蹭过他喉结两次，他一动也不敢动。

#### 节拍链

他对着镜子打了几回都没打好 → 她看见了 → 她说过来 → 他站好，稍稍低头 → 她上手 → 中间停了一下 → 勒紧 → 她拍拍他胸口说好了 → 他去照镜子

#### 时间轴

数她的手离开他脖子几次。打一条领带，要在喉结附近碰三到四回，每碰一回他都得咽一下。第一回他躲了一下，第二回没躲，第三回她停了两秒才接着打。这场戏的正中心就是那两秒。

#### 高度差的权力语法

| 环节 | 机关 |
|---|---|
| 谁低头 | 他比她高，得低下头她才够得着。**个子高的那一方，在这里反倒摆出了顺从的姿势** |
| 手的位置 | 领带系在喉咙上，那是最没防备的地方，他把这里交了出去 |
| 松紧 | 她勒紧那一下，他的呼吸空了半秒。她问紧不紧，他说不紧 |
| 收尾 | 她拍拍他胸口，那动作像在验货，两个人都没觉得哪里不对 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的失败 ✓ | 第三次拆开时他有点烦了，她在门口看了一会儿才出声 |
| 低头 | 他得比平常低五公分，后脖子绷着 |
| 停顿 ✓ | 她的手停在结上没动，他等着，也不催 |
| 勒紧 | 「紧不紧？」「不紧。」——其实有点 |
| 镜子 | 他去照镜子，发现比自己打得好，没说出来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 平常上班 | 他要去见对他不利的人，她打得格外慢 |
| 熟练度 | 他真不会 | 他会，只是这三个月都让她来打 |
| 结尾 | 她拍胸口 | 她揪着领带把他往下拽了一点，说了句只有他听得见的话 |
| 后续 | 当天就解了 | 那条领带后来只在她在的日子才戴 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他低头那一下，后颈的弧度 | 她的手背蹭过来时，他喉咙里那一下 |
| 内心 | 这么大的人，领带都打不好 | 让她弄比自己弄舒服，这话不能说 |
| 好的处理 | 她动作利落，不拖泥带水 | 他没道谢，只是站得更直了 |
| 写崩 | 写成她保姆式照顾 | 写成他撒娇求她打 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她替他系冠缨，下颌抬起来才够得着 |
| 修仙 | 她替他束发穿簪，簪是她的旧物 |
| 星际 | 她替他扣上军装领口的暗扣，那是仪仗规格 |

#### 写崩的三种方式

1. 她一次成功。得有停顿，戏就在停顿里。
2. 他全程说话。这场戏有分量，就因为他说不出话。
3. 写成她教他打。一教，权力就没了，成了培训。

## 二 · 她的衬衫

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：白衬衫 常见档

**骨架**｜他穿她的衬衫，肩膀撑得紧绷，袖子短了一截。她看了一眼，说别脱，就这样。

#### 节拍链

他洗完澡没衣服穿 → 她随手扔给他一件 → 他穿上，明显不合身 → 他要脱 → 她说别脱 → 他站在那儿让她看了几秒 → 后来这件衬衫归了谁，悄悄变了

#### 时间轴

数「不合身」被提了几回。头一回是他自己说的，第二回是她说不用改，第三回是别人问起。提过三回，这件衬衫就不再是衣服了。

#### 尺码即证据的权力语法

| 环节 | 机关 |
|---|---|
| 不合身 | 绷紧的肩，短一截的袖子，**每一处不合身都在说这件衣服原本是谁的** |
| 谁提出脱 | 他提，说明他知道这不合适。她不许，说明合不合适由她说了算 |
| 被看的几秒 | 她没说好看，只是看。评价的权力在她手里，她可以不给 |
| 归属漂移 | 后来这件衬衫到了他那里，它是怎么过去的，两个人都没提过 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 尺寸 ✓ | 袖口到手腕上两指，他老想往下拽 |
| 她的一眼 | 她从上到下看了一遍，说了句「行」，就没下文了 |
| 领口 | 她的领口他穿太紧，第一颗扣子扣不上，他干脆敞着 |
| 气味 ✓ | 洗过了，味道还是跟他惯用的不一样 |
| 外人 | 同事说这件挺特别，他说买错尺码了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 起因 | 意外没衣服穿 | 她故意的，早就想看了 |
| 尺寸差 | 差一点 | 差很多，穿上像偷来的 |
| 归属 | 还回去 | 留下了，成了他的睡衣 |
| 反向 | 她穿他的 | 她穿他的会松松垮垮，读出来是另一回事：那是占有，算不上标记 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他的肩膀把布料撑出来的那道线 | 领口太紧，第一颗扣子扣不上 |
| 内心 | 我的衣服在他身上，这事挺好 | 不合身，但没打算换 |
| 好的处理 | 她只说一个字 | 他没问为什么不让脱 |
| 写崩 | 写成她夸他好看 | 写成他害羞遮挡 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她的外袍披在他身上，尺寸不对，纹样也是女式 |
| 修仙 | 她的法衣认主，他穿上有排斥感，她抬手压下去 |
| ABO | 沾着她信息素的外套，他穿了一整天没换 |

#### 写崩的三种方式

1. 她夸他好看。夸奖是平等关系里说的话，这里不能有。
2. 他害羞遮挡。遮挡就是拒绝，这条戏要他接受。
3. 交代衬衫怎么留下的。不说，归属才会悄悄挪走。

## 三 · 衣帽间的镜子

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：衣帽间 多见档

**骨架**｜她让他站到全身镜前，自己在他身后给他换上一件，故意扣错一颗扣子，说就这样出门。

#### 节拍链

她把他领进衣帽间 → 让他站到镜子前 → 她站在他身后 → 换衣服 → 她故意留一处不整齐 → 他伸手想改 → 她按住 → 他就这样出了门

#### 时间轴

数他在镜子里看了她几次。他看不见她的手，只能在镜子里找她的脸。找一回是确认，找三回就是依赖了。第三回她终于和他对上了眼，这场戏到这一刻才立住。

#### 镜子的权力语法

| 环节 | 机关 |
|---|---|
| 站位 | 她在他身后，**他只看得见镜子里的她，看不见她的手要做什么** |
| 镜子 | 他只能看着自己被安排成什么样子，躲不开这个角度 |
| 那颗错扣 | 故意的。留一处不整齐，就是在说整不整齐由她说了算 |
| 他的手被按住 | 他想改，说明他知道扣错了。她按住，说明这不算错 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 镜中对视 ✓ | 他找了三回才对上，她一直看着他的后颈 |
| 背后的手 | 他觉出布料被拉平了，不知道下一下落在哪儿 |
| 错扣 ✓ | 领口歪着，一整天都有人多看他一眼 |
| 按住 | 她的手盖在他手背上，没使劲，他就停了 |
| 出门 | 走到玄关他又想去改，她在身后咳了一声 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 家常 | 要去正式场合，那颗错扣的代价就成真的了 |
| 他的反应 | 顺从 | 他改了，她没吭声，那件衣服后来再没出现过 |
| 错处 | 一颗扣子 | 袖口怎么卷、领带歪多少，越小越狠 |
| 外人 | 没人看见 | 同事提醒他扣错了，他说知道 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 镜子里他找她眼睛的那三回 | 手背被按住时，他停住的那半秒 |
| 内心 | 他站在那儿的样子，是我摆出来的 | 歪着就歪着，改了她会不高兴 |
| 好的处理 | 她全程不解释为什么 | 他没问为什么 |
| 写崩 | 写成她嫌他不会穿 | 写成他觉得屈辱 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 铜镜前她替他理衣襟，故意留一角未压平 |
| 修仙 | 水镜映出他的法衣，她指尖一动改了纹路走向 |
| 星际 | 全息镜前她调整他的仪仗配饰，留一处不合规格 |

#### 写崩的三种方式

1. 她解释为什么留那颗扣子。一解释就废了。
2. 他觉得屈辱。屈辱是另一条线，这条要他心甘情愿地接受。
3. 镜子只当背景。镜子一定要有人看，有人看才有第二个视角。

## 四 · 勒紧腰封

`M` ｜ △调教 ｜ 古代女尊／现代都市 ｜ 语料频次：腰封 偶见档／束腰 偶见档

**骨架**｜她借着整理仪容，一格一格往紧里勒。每紧一格，他的腰就挺直一分，呼吸就短一分，她都数着。

#### 节拍链

场合要求穿戴整齐 → 她说过来我看看 → 他站好 → 第一格 → 第二格 → 他吸气的声音变了 → 她问还行吗 → 他说行 → 最后一格 → 她说好了

#### 时间轴

数格子。三格算整理，五格就是别的了。到第四格她问一次，他答「行」。第五格她没再出声，一直盯着他的呼吸，他随时都可以喊停。

#### 呼吸的权力语法

| 环节 | 机关 |
|---|---|
| 名义 | 整理仪容。**名头越正当，实际就越不是那么回事，两个人心里都明白** |
| 第四格的问 | 她问了，他有机会喊停，他没喊。同意就是在这一格给出的 |
| 第五格不问 | 上一格已经问过，这一格她改成看他的呼吸。问过一次以后，他照样随时可以喊停 |
| 呼吸 | 他说话变短，句子被迫切成碎的，这是用字最少的顺从证据 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 手法 ✓ | 她从背后收紧，膝盖顶着他腰眼借力 |
| 声音 | 搭扣一格格过去，声音发钝 |
| 他的答 ✓ | 「还行吗」「行」——就两个字，说完他再没说过一句整话 |
| 姿态 | 腰一挺，肩膀就往后打开，他站成了另一个人 |
| 解开 | 当晚她给他解开时，他长长松了一口气，她笑了一下 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 去正式场合 | 没有场合，纯粹是规矩 |
| 问不问 | 问过一次 | 从来不问，那就是另一种关系了 |
| 时长 | 一晚 | 成了常态，他每天早上自己系到第三格，第四、第五格等她来 |
| 解 | 她解 | 她给了他钥匙式的许可：难受了可以自己松，但得告诉她 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他吸气的声音到第四格变了调 | 她膝盖顶上来那一下，他知道要来了 |
| 内心 | 他挺起来的样子，比松垮着好看多了 | 紧是紧，站得住 |
| 好的处理 | 她问了，也真的等他回答 | 他答得干脆，没犹豫 |
| 写崩 | 写她不管他难不难受 | 写他忍着不敢说 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 修仙 | 束灵带一寸寸收，灵力流转被压住，他额角出汗 |
| ABO | 抑制项圈调紧一档，信息素被压回去 |
| 星际 | 战术束带按标准勒紧，她亲手校验 |

#### 写崩的三种方式

1. 她一格都不问。问那一次是安全框架落在文本里的样子，删了整条变味。
2. 他忍着不说。忍是被逼的，这条要的是他答应。
3. 只写紧不写解。解开那一下才算走完一轮，少了它就只剩施加。

## 五 · 摘玉冠

`T` ｜ 无预警 ｜ 古代女尊／修仙 ｜ 语料频次：玉冠 偶见档

**骨架**｜她深夜进殿，抬手摘了他束发的玉冠。头发散下来，他得仰起脸才看得到她。

#### 节拍链

她进来 → 他起身行礼 → 她走近 → 抬手 → 玉冠离了头 → 头发散下 → 他仰起脸 → 她把玉冠放到案上 → 那一夜玉冠没再回到他头上

#### 时间轴

从玉冠离开他头顶，到她把冠放上案几，就那么几步。这几步里他不能动，也不能理头发。等她把冠放下，规矩才重新开始。

#### 冠的权力语法

| 环节 | 机关 |
|---|---|
| 冠是什么 | 身份、体面、能见人的样子。**她摘了冠，他这份体面也就没了** |
| 谁摘 | 冠本该他自己摘，或者由近侍摘。她越过这一层，就是说这一层不算数 |
| 仰脸 | 头发散了挡住视线，他只能抬头。姿势是那件东西定的，用不着下令 |
| 放在案上 | 她把冠放在案上收着，明天还不还给他，由她定 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 声音 ✓ | 玉碰在木案上，很轻的一声，殿里很静 |
| 头发 | 散下来遮住半边脸，他不敢抬手去拨 |
| 仰脸 ✓ | 他仰起脸，睫毛上落着殿里的灯光 |
| 她的手 | 摘冠时她指腹擦过他鬓角，没停 |
| 第二天 | 冠还在案上。他没去拿，等她递过来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|

1. 她盯着看。她一盯着，监督的又成了她自己，这条就立不住了。
2. 他崩溃哭喊。这条写他一点一点学会控制，把他击垮就写反了。
3. 没有最后那段无声。他做到了，这场戏才算走完。
