# 家庭与亲属

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**家庭是这段关系遇到的第一个「外部评价系统」，而那套系统的默认值与他们相反。**

## 这一族为什么难

前面十二卷写的都是两个人之间的事，两个人怎么处都行，规矩自己定。这一卷开始有外人掺和进来，而且这人一进来就带着一整套“男该怎么当、女该怎么当”的老剧本。

具体的冲突点，语料里高度集中在这几处：

| 冲突 | 外部预期 | 这段关系的实际 |
|---|---|---|
| 谁养家 | 男方 | 她 |
| 谁做决定 | 男方 | 她 |
| 谁受委屈了 | 假定是她 | 都不是 |
| 谁该改 | 假定是他该「有点男人样」 | 谁都不该 |

不能靠让长辈开明来解决。 一群通情达理的长辈会让这一卷失去全部张力，而且不真实。

## 一 · 他家里人怎么看她

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：见家长 ＋ 偏见 27.0%

**骨架**｜他爸妈对她客气得不像话，这客气本身就是态度。

#### 节拍链

进门 → 过分客气 → 「多担待」那句 → 他一直找事做 → 告辞 → 车上 → 他后来单独回去说了

#### 时间轴

一顿饭吃完，客气劲儿不但没散，反而更浓了。刚进门那会儿还能说是礼貌，两小时后走人还是这个调调，那意思就明摆着了。真正的信号在饭后：他隔了几天又单独跑回去说那次话，隔的天数越少，说明他越急；说多久都行，但他绝不会把话全倒给她。

#### 客气的四层含义

这条不靠冲突，靠过度的礼貌。语料里这类场面的高频写法：

| 表现 | 实际意思 |
|---|---|
| 端上最好的茶 | 你是客人不是家人 |
| 全程称呼职务 | 你的身份先于你的人 |
| 一直问她工作 | 在核算她的价值 |
| 让他去厨房帮忙 | 把他放回原来的位置 |
| 说「他不懂事，你多担待」 | 把他定义成需要被管的人 |

最后一行最伤。 它表面在替她说话，实际把他矮化了，而且是当着他的面。

#### 可用细节

| 类 | 内容 |
|---|---|
| 空间 | 她坐主位还是客位 · 他坐哪 · 谁给谁盛饭 |
| 道具 | 好茶 · 新拆的拖鞋 · 特意买的水果 |
| 他母亲 | 老给她夹菜 · 但眼睛瞅着儿子 |
| 他父亲 | 话不多 · 问了一句房子的事 |
| 他 | 一直没闲着（倒水、拿碗、擦桌），怕一停就得开口 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 家里的态度 | 客气，但心里没松口 | 直接翻脸 |
| 反对的理由 | 嫌她太强 | 嫌她年纪大 / 家世 / 离过婚 |
| 他的立场 | 站她这边 | 两头为难 |
| 她的处理 | 该怎样还怎样 | 故意收着（反而更糟） |

「她刻意收敛」这一端值得写。 为了让长辈接受而假装柔顺，这件事本身就伤害了这段关系，且他会看出来。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看出他闲不住 | 我妈那句「你多担待」 |
| 内心 | 我要不要装一下 | 别说了，别说了 |
| 好的处理 | 她没装，也没较劲 | 他后来单独找父母谈了 |
| 写崩 | 写成她当场翻脸 | 写成他一声不吭忍到底 |

「他后来单独跟父母说了」是这条的必需项。 他不需要当场对抗，但他要说，且要让她知道他说了。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他父兄来探她口风／族里长辈聊位份／聘礼备多厚 |
| 修仙 | 他师门来人了／问俩人合不合适当道侣／根骨配不配 |
| 星际 | 家里查背景／基因匹配报告 |

古代女尊版有一个反转优势：在女尊社会里，他家里人反而会担心他「配不上」她，冲突方向完全不同，值得专门写。

#### 写崩的三种方式

1. 让长辈全部开明。 没有阻力就没有这一卷。
2. 让她当场翻脸。 翻脸痛快，但会让他更难做。
3. 让他全程沉默且事后也不提。 他必须有一次表态。

## 二 · 她家里人怎么看他

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：见家长 ＋ 偏见 27.0%

**骨架**｜她家里人就问了三句话，句句都在夸他。

#### 节拍链

三个问题 → 他答了一件他负责的事 → 她忍住没抢答 → 私下那句「别委屈自己」→ 他听见或没听见 → 回程

#### 时间轴

三个问题之间各隔十分钟，既是审查，也是节奏。不连着问，问一个，吃会儿饭，再问一个，给他喘口气，也看他喘气的样子。「别委屈自己」那句私房话，留在送客的玄关说，全场最后十秒才出口：位置和时机都挑过，专门说给该听见的人听，听没听见，那就是另一回事了。

#### 三个问题

| 问题 | 在称什么 |
|---|---|
| 「小伙子做什么工作的」 | 收入 |
| 「家里几口人」 | 出身 |
| 「以后打算怎么安排」 | 他有没有能力主导（而他不主导） |

第三个最难答。因为诚实的答案是「听她的」，而这个答案在长辈那里是失分的。

#### 他的四种答法

| 答法 | 效果 |
|---|---|
| 「听她的」 | 诚实，但会被读成没主见 |
| 编一套自己的规划 | 撒谎，且她在场 |
| 「我们一起商量」 | 得体的模糊 |
| 说一件具体的、他负责的事 | 最好——用事实代替姿态 |

最后一行是这一族的通用解法：不谈权力分配，谈具体分工。 「家里的事她拿主意，孩子的事我管」比任何辩解都有力。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的动作 | 想替他接话，忍住了 · 或者没忍住 |
| 他的准备 | 这些事他早想过 · 手心 ✓ 冒汗但答得稳 |
| 她父母的观察 | 看他怎么给她盛汤 · 看她怎么支使他 |
| 转折 | 她妈单独问她「他是不是太顺着你了」 |
| 她的回答 | 这话是这条的收尾 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她替不替他答 | 忍住了 | 抢答了（他会失落） |
| 家里的评价 | 满意 | 觉得他不够 |
| 私下那句话 | 「他挺好」 | 「你别太委屈自己」 |
| 他知不知道 | 不知道 | 听见了 |

「她妈说『你别太委屈自己』而他刚好在门外」是这条最狠的一版。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她妈问「他会不会太软」的时候 | 第三个问题 |
| 内心 | 怎么解释他不是软 | 我不能说「听她的」 |
| 好的处理 | 她说的是他做过的具体的事 | 他答了一件他负责的事 |
| 写崩 | 写成她替他包办一切 | 写成他唯唯诺诺 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她母亲问他的家世／能否持家／能不能生养 |
| 修仙 | 她师尊看他的根骨／能否助她修行 |
| 星际 | 她家族评估他的基因与履历 |

古代女尊文里有个点你必须写：女尊社会里，男方家里人对他的打量，跟现实里女方被男方家挑三拣四是一模一样的路子——家世、脾气、能不能生养。你把这个性别对调写明白了，这文的立身之本就有了。

#### 写崩的三种方式

1. 让她全程替他答。 他得自己答一题。
2. 让他背台词似的演。 一件具体的事比说一堆管用。
3. 让长辈立马满意。 留点疑虑反而更像真的。

## 三 · 催

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：催 15.0%

**骨架**｜“什么时候办事”“什么时候要孩子”——这话是问他们俩的，可眼睛一直盯着她。

#### 节拍链

饭桌起头 → 「老大不小」→ 她习惯性要挡 → 他先接了 → 挡过去或挡不过去 → 回家对了一下两人自己的想法

#### 时间轴

每逢过节必催，一年不落。一场也就十分钟：先起个头，再施压，你接招，然后岔开话题。往长了看是按年算的，同一句“老大不小”去年说过，今年还来，明年照样。催婚这事儿吧，外部改变不了，催不会停。能变的只有里头：回家对答案那段对话一年比一年短，因为俩人的答案一年比一年齐。

#### 催的三个方向

| 催什么 | 压力落在谁身上 | GB 特有的扭曲 |
|---|---|---|
| 结婚 | 通常女方扛 | 这里也是她扛（都觉得她该「定下来」） |
| 孩子 | 女方扛 | 但她可能不想要 / 正拼事业 |
| 「让他有点出息」 | 他扛 | 而且这话是当着她面说的 |

第三行是这个类型独有的。 别的类型里没有人会当着女方的面要求男方「有点出息」。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 年夜饭 ✓ · 亲戚聚会 · 电话里 · 她妈突然来家里 |
| 说法 | 「你也老大不小了」· 「趁年轻」· 「别耽误人家」 |
| 他的反应 | 给所有人添茶 · 或者他突然接了话 |
| 她的反应 | 岔开话题 · 或者一句话顶回去 |
| 事后 | 车上的沉默 · 或者两人笑了 |

「他突然接了话」是这条最好的转折：在她习惯性挡在前面的场合，他自己站出来了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁挡 | 她挡 | 他挡 |
| 他们自己的想法 | 一致 | 不一致（更有戏） |
| 催的内容 | 结婚 | 孩子 |
| 结果 | 挡过去了 | 挡不过去，回家要谈 |

「他们自己也不一致」是这条的高阶用法：外部压力揭出了内部分歧。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她刚要张嘴，他先开了口 | 我不能回回让她顶在前头 |
| 内心 | 又来了 | 这回该我了 |
| 好的处理 | 她这回让他挡 | 他挡得难看，可到底挡了 |
| 写崩 | 写成她句句扎心，光图嘴爽 | 写成他怂到底，没一点起色 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 催她纳侍／催子嗣／族中议她无出 |
| 修仙 | 催结契／催双修／宗门要她开枝 |
| 星际 | 生育指标／家族继承压力 |

古代女尊版的「催她纳侍」是这个类型最狠的一个场面：外部要求她多娶，而他必须在场。

#### 写崩的三种方式

1. 写成怼亲戚爽文。 一时痛快，但没有余味。
2. 让他们内部完全一致。 有分歧才有第二场戏。
3. 只写她挡。 至少有一次让他挡。

## 四 · 要不要孩子

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：孩子 24.0%

**骨架**｜这事在这段关系里没有标准答案。

#### 节拍链

他看小孩多看了两眼 → 谁先提 → 那场对话（成本谁付）→ 分工与姓氏 → 决定或推迟 → 外部压力再来

#### 时间轴

这场对话分了几次才谈完。第一次是试探，他多看了两眼小孩，她心里记下了。第二次才正式谈条件，谈了一晚上，谈到后半夜。第三次谈的是分工和孩子跟谁姓，又是另一晚。每次中间隔几周。这种事你谈太快，后面肯定埋雷，慢慢分期谈，才稳。

#### 为什么这条在 GB 里特别

传统脚本里，生育的意愿默认在女方、成本默认由女方承担、决定权在两人但压力在女方。

GB 关系里这几件事全都被打乱了：

| 项 | 传统默认 | 这里的可能 |
|---|---|---|
| 谁更想要 | 女方 | **他更想要**（常见，也好写） |
| 谁承担成本 | 女方（身体和事业） | 还是她 |
| 谁带孩子 | 女方 | 他 |
| 谁的姓 | 男方 | 这一项在女尊设定里最容易闹矛盾 |

「他更想要而她不确定」是这个类型最有特色的一版，而且它把成本问题摊开了：想要的人不承担代价。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他想要的表现 | 看见小孩会多看两眼 · 手机 ✓ 里存了朋友孩子的照片 ✓ · 不说 |
| 她的顾虑 | 事业正忙 · 身体情况 · 她压根没往那想 |
| 那场对话 | 谁先开口 · 什么时候提（一般是在别的事之后） |
| 具体分工 | 谁带娃 · 谁请假 · 孩子跟谁姓 |
| 收束 | 说要 · 说不要 · 说再等等（再等等就是没定） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁想要 | 他 | 她 |
| 分歧 | 有 | 没有（两人都不想，被外部压） |
| 姓氏 | 跟她（女尊设定的常态） | 冲突点 |
| 结局 | 要了 | 不要，且两人都真的接受 |
| 十月这一段 | 现代设定她怀（她的身体第一次接管日程表，产假谈判是 [12-工作与金钱](12-工作与金钱.md)的隐藏关卡，他从副驾驶转正当家） | 女尊／ABO 设定他怀（子嗣制度全套倒置：安胎的是他，走 [21-世界设定专属](21-世界设定专属.md)与 [03-世界观设定](../03-世界观设定/)的生育规则；本卷 [五 · 他带孩子](#五--他带孩子)是它的续章） |

「不要，且两人都真的接受」这一端在语料里少见，值得写。 它需要作者不把生育当成关系的必然终点。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他在看别人家孩子 | 这话我说不出口，一说就像在逼她 |
| 内心 | 这事我该让一步吗 | 这代价不该她扛 |
| 好的处理 | 她认真说了原因，没糊弄过去 | 他直接讲「你不想要就别要」，而且是真心话 |
| 写崩 | 写成她只顾自己 | 写成拿孩子的事压她 |

「这件事的代价不是我付」是他这个角色最值得写的一句内心戏。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 子嗣／随母姓／他能不能生养，直接决定他在家里的位置 |
| 修仙 | 道侣要不要留后／血脉传不传得下去／寿元差让这事更麻烦 |
| 星际 | 生育舱／基因编辑／生娃要排队审批 |
| 女A男O | 生养归 Omega，谁生谁吃亏这事反过来了（走 [03-世界观设定](../03-世界观设定/)） |

女A男O 这设定，是唯一能让男的扛生育这事儿的。就冲这一点，整个故事结构全得反过来写，这也是它最值钱的地方。

#### 写崩的三种方式

1. 用一次意外怀孕跳过讨论。 那是回避不是解决。
2. 让分歧靠一方牺牲收场。 牺牲要有代价，且要被看见。
3. 忽略姓氏问题。 在女尊设定里那是硬冲突。

## 五 · 他带孩子

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：孩子 24.0%

**骨架**｜她上班，他待家里。这搭配在咱这圈里挺正常，放外面就怪了。

#### 节拍链

六点半闹钟 → 送 → 家务循环 → 家长群里唯一的爸爸 → 她回家 → 她数了一遍他做的事 → 一句具体的

#### 时间轴

一天两班倒：他的班从六点半上到她进门。闹钟、早饭、送人、家务、接人、晚饭，他的日程排到一刻钟都不浪费，比上班还紧。她进门就是换班铃；她把他干的活儿挨个数一遍，等于给这张没工资条的排班表签了字。数得越细，签得越实。

#### 可写的三层

| 层 | 内容 |
|---|---|
| 家里 | 他做得好不好、累不累、有没有被看见 |
| 外面 | 幼儿园老师只找妈妈 · 别人问「你爸爸怎么不上班」 |
| 他自己 | 会不会觉得自己在浪费 |

第三层最要紧。全职带孩子的人容易整个人消失在家庭里，跟性别没关系，但写男的这样，读者会觉得新鲜，冲击力也更大。

#### 可用细节

| 类 | 内容 |
|---|---|
| 日常 | 幼儿园 ✓ 接送 · 奶粉 ✓ · 辅食 · 半夜起夜 · 洗不完的衣服 ✓ |
| 他的疲惫 | 白天忙得顾不上吃饭 · 她回来时他已经在打瞌睡 |
| 被忽视 | 家长群里全是妈妈 · 医院表格上「母亲」栏 |
| 她的看见 | 她有一天把他一天干的事数了一遍 |
| 收束 | 她说了句实在话（不是「辛苦了」） |

「不是『辛苦了』而是具体的」是这条的关键。 「今天他咳嗽你半夜起了三次吧」比十句辛苦了有用。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的状态 | 享受 | 硬扛 |
| 外部 | 有人唱反调 | 没人吭声但他自己心里过不去 |
| 她的参与 | 能帮就帮 | 全甩给他（准出事） |
| 转折 | 他打算回去上班 | 他决定接着干，而且是自己选的 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把他今天干的活数了一遍 | 家长群里就我一个男的 |
| 内心 | 我下班就完了，他还没完 | 我是不是在瞎耽误工夫 |
| 好的处理 | 她说的是那件具体的事 | 他认了，说自己有时候也后悔 |
| 写崩 | 写成她觉得该这样 | 写成他啥都不怨的圣人 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 内宅由他掌／教养子女／她在外奔忙 |
| 修仙 | 他守洞府照看幼徒／她出去历练 |
| 星际 | 他留在后方／育儿舱值守 |

#### 写崩的三种方式

1. 写成毫无怨言的圣父。 他要有过后悔的时刻。
2. 让她理所当然。 她要有看见的那一刻。
3. 只写辛苦不写他自己的价值感。 第三层才是这条的深度。

#### 示例（本库自撰，可直接改写）

> 家长群里第一百三十七条消息，全是「收到」。
> 他也发了一个。往上翻，头像清一色是妈妈们，只有他这一个是空白的默认灰。
> 六点半闹钟，七点送，十点买菜，下午三点半接。中间那五个小时他洗了两台机器的衣服。
> 晚上她回来，他已经在沙发上打盹了，孩子的作业摊在茶几上，签好了名。
> 她数了一遍今天的事。数到第九件，停住了。
> 她没有说辛苦了。她说：「他昨天咳嗽，你半夜起了三次吧。」

## 六 · 他的原生家庭

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：旧伤 5.0%（低频高价值）

**骨架**｜他为什么会是这样的人。答案在他很少提的那个家里。

#### 节拍链

一句无意的话漏了缝 → 她记下没问 → 场合撞见（回老家·亲戚）→ 说了一部分 → 她不同情只在场 → 留了一部分

#### 时间轴

信息是一点一点漏出来的，几个月才漏一条。有时候是一句没过脑子的话，有时候是一个莫名其妙的忌讳，有时候是接电话那会儿语气不对。她全记着，但不催，也不问。真撞上那个场面，算集中摊牌，可也只摊一部分，剩下的还得再等几年。这条线是按年算的，急不来，你一急，缝就合上了。

#### 这条是人物地基

一个成年男性愿意进入被主导的位置，这件事需要来处。不是必须，但有了会厚很多。

语料里的高频来处：

| 来处 | 造出的性格 |
|---|---|
| 从小被要求「像个男人」 | 他演腻了，哪天不用装了，整个人都松下来 |
| 家里有一个说了算的女性 | 他吃这一套，待着踏实 |
| 长期被忽视 | 有人明明白白管着他、盯着他，他就走不动道 |
| 父亲缺席或糟糕 | 他死活不想活成那副德行 |
| 家里出过事，他是收拾残局的人 | 他照顾人太顺手了，顺手到没人问他累不累 |

最后一行最好用。 它同时解释了他的能干与他的疲惫。

#### 可用细节

| 类 | 内容 |
|---|---|
| 泄露的方式 | 一句没留神的话 · 他对某类事反应太大 · 他从来不去某个地方 |
| 他的回避 | 「没啥好说的」· 岔开话题那叫一个顺溜 |
| 她的发现 | 不是问出来的，是撞上的 |
| 场合 | 回老家 · 某个节日 ✓ · 一个亲戚冒出来 |
| 说出来之后 | 她第一反应不能是心疼他 |

「她的第一反应不能是同情」是这条的红线。 同情会把他放到需要被拯救的位置，那不是这段关系的性质。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 说不说 | 说了 | 一直瞒着，她自己猜到的 |
| 严重程度 | 小事 | 大事（得小心，看下面） |
| 她的反应 | 没吭声，就握了下他的手 | 她自己把事办了 |
| 之后 | 他松了口气 | 他后悔开了那个口 |

「她去处理了那件事」要小心：替他解决原生家庭问题，容易变成越权。 除非他明确要求。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她撞见他藏着的那块心病 | 话说完之后的冷场 |
| 内心 | 怪不得他平时老那样 | 她会不会觉得我怂 |
| 好的处理 | 她没追着问，也没可怜他，就是待着没走 | 他讲了一半，另一半咽了回去 |
| 写崩 | 写成她来救他 | 写成倒苦水 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 庶出／不受宠／家中排行／被当作联姻筹码养大 |
| 修仙 | 散修出身／被弃／前一世的记忆 |
| 星际 | 边境出身／战争孤儿／基因等级低 |

#### 内容边界

这条会触及童年创伤。写作时的两条线：

| 线 | 说明 |
|---|---|
| 全员成年 | 回忆里的他是未成年，但回忆内容不与任何性内容关联 |
| 不写可复现的伤害细节 | 交代性质与后果即可，不做过程描写 |

具体规则见 [00-编纂规约/03-版权与内容红线](../00-编纂规约/03-版权与内容红线.md)。

#### 写崩的三种方式

1. 用创伤解释他的一切。 人不是由一件事构成的。
2. 让她当救世主。 她可以在场，不能代替他解决。
3. 写成一次性揭底。 分两三次露出来更好。

## 七 · 她的原生家庭

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：旧伤 5.0%

**骨架**｜她的强势不是没来由的，但那来由，多半不怎么体面。

#### 节拍链

她的过度反应被他注意到 → 症状累积 → 他拼出原因 → 「习惯了」三个字 → 她第一次交出一件事 → 他接下了

#### 时间轴

症状先出现，病因最后才浮出来。他最开始注意到的，是她不许别人替她拿主意，对“被安排”这种事反应特别大。这些症状攒了几个月，他自己拼出了背后的原因。等她说出“习惯了”这三个字，又过了很久，她才第一次主动交出某件事。那天才是这条线的真正起点——从那天起，另一套习惯才开始算日子。

#### 为什么必须写

只写他的来处而不写她的，她就成了没有历史的功能角色。

而且这条解决一个具体问题：「她为什么需要掌控」。 一个不需要理由就要掌控一切的人，是设定不是人物。

| 来处 | 造出的性格 |
|---|---|
| 长女，很早开始承担 | 她的掌控是习惯，不是欲望 |
| 家里出过大事，她扛下来的 | 她不敢把事情交给别人 |
| 被否定过一次，此后再没输过 | 她的强硬带着防御 |
| 有一个失败的父亲 | 她不信任依赖 |
| 她赢过，且尝到过赢的代价 | 最有层次的一版 |

「她的掌控是习惯不是欲望」这条设定，天生就带成长线。它等于把人从「喜欢说了算」改成了「没人教过她怎么撒手」，后者是有可能变的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 泄露方式 | 她碰到某类事就反应特别大 · 她从不开口求人 · 她怎么睡 |
| 具体表现 | 她办啥事都留一手 · 她不让别人碰方向盘 · 她的体检单 ✓ |
| 他的发现 | 他先看出的是毛病，过了好久才弄明白根子在哪 |
| 她的说法 | 话少。「习惯了」就完了 |
| 转折 | 她头一回把一件事托给他 |

「她第一次把一件事交给他」是这条的落点，也是这一族里最重的一个动作。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她说不说 | 说了一点 | 一个字都不提 |
| 他怎么知道的 | 她家里告诉他的 | 他自己东拼西凑猜出来的 |
| 她的变化 | 总算肯把一件事交出去 | 始终学不会撒手 |
| 他的作用 | 他接住了 | 他也没接住（这版更真实） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把钥匙 ✓ 递出去的那一下 | 原来她从十六岁就开始扛 |
| 内心 | 交出去会不会出事 | 她不是天生就这样的 |
| 好的处理 | 她交出去之后忍住没检查 | 他把那件事办成了，且没邀功 |
| 写崩 | 写成她的强势是一场误会 | 写成他理解她之后就原谅一切 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 长女承家／早早掌事／母亲的期许／一场变故后她当了家 |
| 修仙 | 她担着宗门／师门被灭她扛下来 |
| 星际 | 她十九岁当上舰长的原因 |

#### 写崩的三种方式

1. 不写。 她就是个工具人。
2. 把她的强势说成是受过伤才这样。 那等于说她本来不行。
3. 觉得理解了就等于治好了她。 理解完事儿才刚开始。

## 八 · 养一只

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：宠物 10.0%

**骨架**｜家里多了一个，两个人那点事全让它给照出来了。

#### 节拍链

谁提的 → 抱回来 → 取名 → 分工成形 → 它黏谁 → 一次闯祸 → 家里的排序定了

#### 时间轴

它的成长就是一本关系账。抱回来那天算起，叫“元年”：取名字那天吵了半小时，谁喂谁遛一周内定了规矩，它第一次拆家是全家第一次联合执法。它跟谁亲的比例每个月都在变，最后黏的往往是白天在家那个，这结果谁都没话说。

#### 宠物是关系的显影剂

它不推动情节，它显示关系：

| 观察点 | 显示什么 |
|---|---|
| 谁想养 | 谁先提出来要个伴儿 |
| 谁负责 | 平时谁在管、谁在喂 |
| 它更黏谁 | 谁在家待得久 |
| 取名字 | 谁说了算 |
| 它生病时谁着急 | 谁最上心 |
| 它做错事谁凶 | 谁在家里说了算 |

最后一行很有意思： 一个从来不凶他的人，会不会凶猫；一个被她管着的人，会不会去管猫。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 猫粮 ✓ · 狗绳 ✓ · 铲屎 ✓ · 它睡谁屋 |
| 日常 | 半夜踩你身上 · 就认她回来才叫 · 他天天记它吃几口 |
| 名字 | 谁起的名 · 有没有背着人叫的小名 |
| 争执 | 让不让上床 · 做不做绝育 · 能不能喂人饭 |
| 他的位置 | 家里排老二（自己老拿这个开涮） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁想养 | 他 | 她 |
| 它黏谁 | 黏他 | 黏她（他会吃醋） |
| 冲突 | 无 | 它撕了她的重要文件 |
| 结局 | 日常 | 它老了／病了（转 [九 · 送走它](#九--送走它)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现它的窝挪到了他那边 | 它今天先蹭的是她 |
| 好的处理 | 她也认真参与，不当甩手掌柜 | 他为了这只跟她争过一次 |
| 写崩 | 写成宠物取代人物戏份 | 写成他和宠物争宠的幼稚 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她的马／他养的鸟／她赏的一只猫 |
| 修仙 | 灵兽／本命兽／它认谁 |
| 星际 | 机械宠物／舰上唯一的活物 |

#### 写崩的三种方式

1. 让宠物抢戏。 它是道具不是角色。
2. 写成人宠争宠。 一次自嘲可以，反复就幼稚。
3. 只写可爱不写分工。 分工才是信息。

## 九 · 送走它

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：宠物 10.0% ＋ 离世 29.0%

**骨架**｜它老了。这是他们头一回一起经历失去。

#### 为什么这条重要

它是一次低成本的预演。真正的生离死别写起来重，而一只宠物的离开可以承载同样的结构，代价小得多。

而且它有一个别的失去没有的特点：决定权在他们手上（治不治、什么时候停），这让它变成了一次共同决策。

#### 节拍链

发现不对 → 检查 → 拖了一阵 → 那个决定 → 最后一天 → 之后家里空的那一块

#### 时间轴

从发现不对劲到做那个决定，中间那段「拖」谁都会这样，这也是这条真正要写的东西。查了又查、吃药、再复查，拖的每一周心里都明白是在拖，但谁都不先开口。最后那天的时间要写足：从早上到傍晚，每个钟头都数着过。等家里空了那一块，按月算，一直空着，直到碗筷收起来那天，才算送完。

#### 可用细节

| 类 | 内容 |
|---|---|
| 迹象 | 它不上沙发 ✓ 了 · 吃得少 · 睡的时间变长 |
| 决定 | 谁先开口 · 谁签字 · 谁抱着 |
| 那天 | 谁在 · 谁哭了 · 谁没哭 |
| 之后 | 猫粮 ✓ 还剩半袋 · 它的窝没扔 · 家里少了一种声音 |
| 很久以后 | 有人送新的，他们说再等等 |

「猫粮还剩半袋」是这条最好用的细节。 剩下来的东西比空掉的位置更疼。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁哭了 | 他 | 她（这版更少见，也更戳人） |
| 谁做决定 | 她 | 他（这回他想自己扛） |
| 之后 | 再养一只 | 好长时间不敢再养 |
| 关系的变化 | 更近了 | 俩人各自缓了一阵 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己也走不动了 | 决定是我做的 |
| 好的处理 | 她让他拿主意，自己陪着 | 他拿了主意，也没怪她 |
| 写崩 | 写成她啥都自己扛 | 写成他垮了，还得她去哄 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她的马老死／他养的鸟 |
| 修仙 | 灵兽寿尽／本命兽断了契 |
| 星际 | 舰上那只被安乐 |

#### 写崩的三种方式

1. 写得太长。 一场戏，不要一章。
2. 让她全程冷静。 她也要有一下。
3. 立刻再养一只收场。 留一段空。

## 十 · 亲人离世

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：离世 29.0%（本族最高）

**骨架**｜有人走了。这段关系里，谁在撑着呢。

#### 节拍链

消息来 → 谁撑着（订票·联系·通知）→ 仪式 → 事毕 → 一个小触发物 → 崩 → 另一个人只是在

#### 时间轴

事务的钟和悲伤的钟不同步。 事务三天办完（订票、联系、仪式），撑着的人全程精确高效；悲伤的钟推迟启动，事毕一两周后被一个小触发物引爆（同 [30-她的世界 · 她哭不出来](30-她的世界.md#七--她哭不出来)的延迟机制）。两块钟的时间差，就是「谁撑着」的代价表。

#### 这条在 GB 里的特殊结构

传统脚本：出事了，男方撑着，女方哭。

这里的可能配置多得多，且每一种都在说明关系：

| 谁的家人 | 谁撑着 | 读作 |
|---|---|---|
| 他的 | 她撑 | 常态。她全包了，他终于能歇着 |
| 他的 | 他撑 | 他不让她碰（有戏） |
| 她的 | 她撑 | 她习惯了，也扛得住 |
| 她的 | 他撑 | **最值的一版**。她头回有人接手 |

第四行是这一族的最高点。 她撑了一辈子，这一次有人替她挡在前面。

#### 可用细节

| 类 | 内容 |
|---|---|
| 事务性的 | 打电话 · 订票 · 联系殡仪 · 通知亲戚 · 这些杂事就是“硬撑”的样子 |
| 她的方式 | 一件件安排，不哭 · 手在抖但字写得很稳 |
| 他的方式 | 他专挑没人干的活干 · 半夜守着 |
| 她的崩点 | 事全办完了 · 一个小东西就能勾出来（一件旧衣、一个没删的号码） |
| 他的动作 | 不问、不劝、就在旁边待着 |

「事情办完之后」是崩点的正确位置，同 [04-委屈与破防 · 忍到最后一秒](04-委屈与破防.md#六--忍到最后一秒)。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁的亲人 | 他的 | 她的 |
| 谁撑 | 她 | 他 |
| 关系深浅 | 亲近 | 疏远（更复杂：不知道该不该难过） |
| 之后 | 关系更紧 | 有一段各自沉默的时间 |

「疏远的亲人去世」是最难写也最真实的一版：没有现成的情绪可用。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 事情全办完的那个晚上 | 她的手在抖但字写得很稳 |
| 内心 | 我不能倒 | 这次我来 |
| 好的处理 | 她后来让自己哭了一回 | 他办了事，但没说“有我在” |
| 写崩 | 写她从头到尾没露过破绽 | 写他一句“有我在”全搞定 |

「有我在」这句在 GB 里要慎用。 它是传统脚本的标志句，用了会让整段关系倒回默认设置。用行动代替它。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 丁忧／扶灵／族中事务／她主丧 |
| 修仙 | 师尊坐化／同门殒落／寿元尽 |
| 星际 | 阵亡通知／没有遗体 |

星际版的「没有遗体」提供了一个别处没有的结构：无法完成的告别。

#### 写崩的三种方式

1. 用「有我在」收场。 见上。
2. 让她全程无懈可击。 她要有一次倒下来。
3. 把葬礼写成情节转折点。 让它就是一件发生的事。
