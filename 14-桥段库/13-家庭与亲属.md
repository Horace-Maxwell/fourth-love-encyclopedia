## 外人进了场

前面十二卷写的都是两个人关起门来的事，怎么处都行，规矩自己定。到这一卷，外人进来了，还随身带着一整套“男该怎么当、女该怎么当”的老剧本。

语料里的冲突，大多扎堆在这几处：

| 冲突 | 外部预期 | 这段关系的实际 |
|---|---|---|
| 谁养家 | 男方 | 她 |
| 谁做决定 | 男方 | 她 |
| 谁受委屈了 | 假定是她 | 都不是 |
| 谁该改 | 假定是他该「有点男人样」 | 谁都不该 |

别指望靠长辈开明来化解。长辈个个通情达理，这一卷就没戏了，也不像真的。

## 一 · 他家里人怎么看她

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：见家长 ＋ 偏见 28.1%

**骨架**｜他爸妈对她客气过了头，客气就是他们的态度。

#### 节拍链

进门 → 过分客气 → 「多担待」那句 → 他一直找事做 → 告辞 → 车上 → 他后来单独回去说了

#### 时间轴

一顿饭吃完，那股客气不但没散，还更重了。进门时客气，还能算礼貌，两小时后告辞还是这个调子，意思就摆在那儿了。他隔几天又一个人回去，把那番话说了，隔得越短，越见得他急。谈多久都行，可谈了什么，他绝不会全倒给她听。要看的信号在饭后。

#### 客气的四层含义

这一条的戏在礼貌过了头。语料里这类场面常见的写法：

| 表现 | 实际意思 |
|---|---|
| 端上最好的茶 | 她是客人，算不上家人 |
| 全程称呼职务 | 她的身份先于她的人 |
| 一直问她工作 | 在掂量她有多少斤两 |
| 让他去厨房帮忙 | 把他放回原来的位置 |
| 说「他不懂事，你多担待」 | 把他定义成需要被管的人 |

最后一行最伤人。 话听着是向着她，其实把他贬低了，还是当着他的面。

#### 可用细节

| 类 | 内容 |
|---|---|
| 空间 | 她坐主位还是客位 · 他坐哪 · 谁给谁盛饭 |
| 道具 | 好茶 · 新拆的拖鞋 · 特意买的水果 |
| 他母亲 | 老给她夹菜 · 但眼睛瞅着儿子 |
| 他父亲 | 话不多 · 问了一句房子的事 |
| 他 | 一直没闲着，倒水、拿碗、擦桌，怕一停就得开口 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 家里的态度 | 客气，但心里没松口 | 直接翻脸 |
| 反对的理由 | 嫌她太强 | 嫌她年纪大 / 家世 / 离过婚 |
| 他的立场 | 站她这边 | 两头为难 |
| 她的处理 | 该怎样还怎样 | 故意收着，反而更糟 |

「故意收着」这一端值得写。她为了让长辈点头装出柔顺的样子，光这一点就伤了两人的关系，他也看得出来。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看出他闲不住 | 我妈那句「你多担待」 |
| 内心 | 我要不要装一下 | 别说了，别说了 |
| 好的处理 | 她没装，也没较劲 | 他后来单独找父母谈了 |
| 写崩 | 写成她当场翻脸 | 写成他一声不吭忍到底 |

「他后来单独找父母谈了」这一笔少不了。他用不着当场顶撞，但话得说，还得让她知道他说过。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他父兄来探她口风／族里长辈聊位份／聘礼备多厚 |
| 修仙 | 他师门来人了／问俩人合不合适当道侣／根骨配不配 |
| 星际 | 家里查背景／基因匹配报告 |

古代女尊版里，他家里人反倒担心他「配不上」她，冲突整个掉了个头，值得单独写。

#### 写崩的三种方式

1. 长辈个个开明。 没了阻力，这一卷也就不用写了。
2. 她当场翻脸。 痛快归痛快，他更难做。
3. 他从头到尾不吭声，过后也不提。 他必须表一回态。

## 二 · 她家里人怎么看他

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：见家长 ＋ 偏见 28.1%

**骨架**｜她家里人就问了三个问题，每一个都在掂量他。

#### 节拍链

三个问题 → 他答了一件他负责的事 → 她忍住没抢答 → 私下那句「别委屈自己」→ 他听见或没听见 → 回程

#### 时间轴

三个问题各隔十分钟，是在审他，也是在掐节奏。不连着问，问一个，吃一会儿饭，再问一个，让他喘口气，也看看他喘气的样子。「别委屈自己」这句体己话留到最后，挑在送客的玄关说，时机卡得正好，就是说给该听见的人听的，至于听没听见，是另一回事。

#### 三个问题

| 问题 | 在称什么 |
|---|---|
| 「小伙子做什么工作的」 | 收入 |
| 「家里几口人」 | 出身 |
| 「以后打算怎么安排」 | 他有没有能力主导（而他不主导） |

第三个最难答。老实回答是「听她的」，可这话在长辈那儿要扣分。

#### 他的四种答法

| 答法 | 效果 |
|---|---|
| 「听她的」 | 诚实，但会被读成没主见 |
| 编一套自己的规划 | 撒谎，且她在场 |
| 「我们一起商量」 | 得体的模糊 |
| 说一件具体的、他负责的事 | 最好，用事实代替姿态 |

这一族通用的办法是绕开谁说了算，直接讲谁管什么。「家里的事她拿主意，孩子的事我管」，比辩解有用。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的动作 | 想替他接话，忍住了 · 或者没忍住 |
| 他的准备 | 这些事他早想过 · 手心 ✓ 冒汗但答得稳 |
| 她父母的观察 | 看他怎么给她盛汤 · 看她怎么支使他 |
| 转折 | 她妈单独问她「他是不是太顺着你了」 |
| 她的回答 | 这话收尾用 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她替不替他答 | 忍住了 | 抢答了，他会失落 |
| 家里的评价 | 满意 | 觉得他不够 |
| 私下那句话 | 「他挺好」 | 「你别太委屈自己」 |
| 他知不知道 | 不知道 | 听见了 |

她妈说「你别太委屈自己」，偏巧他就在门外，这一版最狠。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她妈问「他会不会太软」的时候 | 第三个问题 |
| 内心 | 怎么解释他不软 | 我不能说「听她的」 |
| 好的处理 | 她说的是他做过的事 | 他答了一件他负责的事 |
| 写崩 | 写成她替他包办一切 | 写成他唯唯诺诺 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她母亲问他的家世／能否持家／能不能生养 |
| 修仙 | 她师尊看他的根骨／能否助她修行 |
| 星际 | 她家族评估他的基因与履历 |

女尊文里，她家里人掂量他，家世、脾气、能不能生养，三样一样不少。现实里女方进男方家门被审的那一套，原样搬过来，只是性别对调，被打量的换成了男方。

#### 写崩的三种方式

1. 她全替他答了。 他得亲口答一题。
2. 他像背台词一样演。 说一件具体的事，比讲一大堆管用。
3. 长辈当场就满意了。 留点疑虑反倒更像真的。

## 三 · 催

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：催 15.9%

**骨架**｜「什么时候办事」「什么时候要孩子」，话是问他们两个的，眼睛却一直盯着她。

#### 节拍链

饭桌起头 → 「老大不小」→ 她习惯性要挡 → 他先接了 → 挡过去或挡不过去 → 回家对了一下两人自己的想法

#### 时间轴

逢年过节必催，一年都不落。起个头，加点压，两人接招，再把话岔开，一场也就十分钟。两人的答案一年比一年对得齐，回家对口径的那段话也一年比一年短。外头改不了，催不会停，能变的只有他们自己。去年那句“老大不小”，今年照来，明年也躲不掉。催婚这件事，放长了看是按年过的。

#### 催的三个方向

| 催什么 | 压力落在谁身上 | GB 特有的扭曲 |
|---|---|---|
| 结婚 | 通常女方扛 | 这里也是她扛，都觉得她该「定下来」 |
| 孩子 | 女方扛 | 但她可能不想要 / 正拼事业 |
| 「让他有点出息」 | 他扛 | 而且这话是当着她面说的 |

第三行在别的类型里少见，当着女方的面要男方「有点出息」，这种事不多。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 年夜饭 ✓ · 亲戚聚会 · 电话里 · 她妈突然来家里 |
| 说法 | 「你也老大不小了」· 「趁年轻」· 「别耽误人家」 |
| 他的反应 | 给所有人添茶 · 或者他突然接了话 |
| 她的反应 | 岔开话题 · 或者一句话顶回去 |
| 事后 | 车上的沉默 · 或者两人笑了 |

「他突然接了话」是转折：这种场合向来是她挡在前头，这回他自己站了出来。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁挡 | 她挡 | 他挡 |
| 他们自己的想法 | 一致 | 不一致（更有戏） |
| 催的内容 | 结婚 | 孩子 |
| 结果 | 挡过去了 | 挡不过去，回家要谈 |

「不一致」这一端，外面一催，催出了两人的分歧。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她刚要张嘴，他先开了口 | 我不能回回让她顶在前头 |
| 内心 | 又来了 | 这回该我了 |
| 好的处理 | 她这回让他挡 | 他挡得难看，可到底挡了 |
| 写崩 | 写成她句句扎心，光图嘴爽 | 写成他怂到底，没一点起色 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 催她纳侍／催子嗣／族中议她无出 |
| 修仙 | 催结契／催双修／宗门要她开枝 |
| 星际 | 生育指标／家族继承压力 |

古代女尊版的「催她纳侍」最狠：外头逼她多娶，他还必须在场。

#### 写崩的三种方式

1. 写成怼亲戚的爽文。 痛快一下，过后什么都不剩。
2. 让两人想法完全一样。 有分歧才有第二场。
3. 回回都是她挡。 起码让他挡一回。

## 四 · 要不要孩子

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：孩子 24.8%

**骨架**｜这事放在这段关系里，没有标准答案。

#### 节拍链

他看小孩多看了两眼 → 谁先提 → 那场对话（成本谁付）→ 分工与姓氏 → 决定或推迟 → 外部压力再来

#### 时间轴

第一次见面，他只是多看了小孩两眼，她心里就有数了。隔了几周，第二次坐下来正经谈条件，一谈谈到后半夜。又过一阵，第三次谈分工、谈孩子跟谁姓，照样谈到深夜。分几回谈，中间留出空当，后面才不容易出岔子。一口气谈完，迟早要翻旧账。

#### 为什么这条在 GB 里特别

在传统脚本里，想要孩子的默认是女方，代价默认女方扛，决定是两人一起做，压力却落在女方身上。

到了 GB 关系里，这几样全乱了套：

| 项 | 传统默认 | 这里的可能 |
|---|---|---|
| 谁更想要 | 女方 | **他更想要**（常见，也好写） |
| 谁承担代价 | 女方（身体和事业） | 还是她 |
| 谁带孩子 | 女方 | 他 |
| 谁的姓 | 男方 | 这一项在女尊设定里最容易闹矛盾 |

「他更想要而她不确定」这一版，把代价摆上了桌面：想要的那个人，不用付这个代价。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他想要的表现 | 看见小孩会多看两眼 · 手机 ✓ 里存了朋友孩子的照片 ✓ · 不说 |
| 她的顾虑 | 事业正忙 · 身体情况 · 她压根没往那想 |
| 那场对话 | 谁先开口 · 什么时候提，一般是在别的事之后 |
| 具体分工 | 谁带娃 · 谁请假 · 孩子跟谁姓 |
| 收束 | 说要 · 说不要 · 说再等等，再等等就是没定 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁想要 | 他 | 她 |
| 分歧 | 有 | 没有，两人都不想，被外部压 |
| 姓氏 | 跟她姓，女尊设定的常态 | 冲突点 |
| 结局 | 要了 | 不要，且两人都真的接受 |
| 十月这一段 | 现代设定她怀（产假接 [12-工作与金钱](12-工作与金钱.md)，家里由他当家） | 女尊／ABO 设定他怀（子嗣制度全套倒置：安胎的是他，走 [21-世界设定专属](21-世界设定专属.md)与 [03-世界观设定](../03-世界观设定/)的生育规则。本卷 [五 · 他带孩子](#五--他带孩子)是它的续章） |

「不要，且两人都真的接受」在语料里很少见，可值得写。作者先得不再把生孩子当成关系里非走不可的一步。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他在看别人家孩子 | 这话我说不出口，一说就像在逼她 |
| 内心 | 这事我该让一步吗 | 这代价不该她扛 |
| 好的处理 | 她认真说了原因，没糊弄过去 | 他直接讲「你不想要就别要」，而且是真心话 |
| 写崩 | 写成她只顾自己 | 写成拿孩子的事压她 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 子嗣／随母姓／他能不能生养，直接决定他在家里的位置 |
| 修仙 | 道侣要不要留后／血脉传不传得下去／寿元差让这事更麻烦 |
| 星际 | 生育舱／基因编辑／生娃要排队审批 |
| 女A男O | 生养归 Omega，谁生谁吃亏这事反过来了，见 [03-世界观设定](../03-世界观设定/) |

女A男O的设定里，生孩子由男方来扛。光这一条，整个故事的结构就得倒过来写。

#### 写崩的三种方式

1. 拿一次意外怀孕把商量跳过去。 这是在躲。
2. 分歧靠一方牺牲了事。 牺牲得有代价，也得被看见。
3. 不提姓氏。 放在女尊设定里，这是绕不过去的冲突。

## 五 · 他带孩子

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：孩子 24.8%

**骨架**｜她出门上班，他在家。圈里人看着平常，圈外人看着就怪。

#### 节拍链

六点半闹钟 → 送 → 家务循环 → 家长群里唯一的爸爸 → 她回家 → 她数了一遍他做的事 → 一句具体的

#### 时间轴

六点半闹钟一响，他就开工，一直干到她推门进来：早饭、送人、家务、接人、晚饭，排得比上班还满，一刻钟的空都挤不出。她回家后把他干的事一件件过一遍，数得越细，越说明她看在眼里。

#### 可写的三层

| 层 | 内容 |
|---|---|
| 家里 | 他做得好不好、累不累、有没有被看见 |
| 外面 | 幼儿园老师只找妈妈 · 别人问「你爸爸怎么不上班」 |
| 他自己 | 会不会觉得自己在浪费 |

第三层最要紧。全职带孩子的人，不管男女，都容易被家整个吞掉。写到男的身上，读者觉得新鲜，劲儿也更大。

#### 可用细节

| 类 | 内容 |
|---|---|
| 日常 | 幼儿园 ✓ 接送 · 奶粉 ✓ · 辅食 · 半夜起夜 · 洗不完的衣服 ✓ |
| 他的疲惫 | 白天忙得顾不上吃饭 · 她回来时他已经在打瞌睡 |
| 被忽视 | 家长群里全是妈妈 · 医院表格上「母亲」栏 |
| 她的看见 | 她有一天把他一天干的事数了一遍 |
| 收束 | 她说了句实在话，不是「辛苦了」 |

她说的是具体的事。一句「今天他咳嗽你半夜起了三次吧」，顶十句辛苦了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的状态 | 享受 | 硬扛 |
| 外部 | 有人唱反调 | 没人吭声但他自己心里过不去 |
| 她的参与 | 能帮就帮 | 全甩给他，准出事 |
| 转折 | 他打算回去上班 | 他决定接着干，而且是自己选的 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把他今天干的活数了一遍 | 家长群里就我一个男的 |
| 内心 | 我下班就完了，他还没完 | 我是不是在瞎耽误工夫 |
| 好的处理 | 她说的是那件具体的事 | 他认了，说自己有时候也后悔 |
| 写崩 | 写成她觉得该这样 | 写成他啥都不怨的圣人 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 内宅由他掌／教养子女／她在外奔忙 |
| 修仙 | 他守洞府照看幼徒／她出去历练 |
| 星际 | 他留在后方／育儿舱值守 |

#### 写崩的三种方式

1. 写成一句怨言没有的圣父。 他得有后悔过的时候。
2. 她觉得理所当然。 得有一刻她看见了。
3. 光写累，不写他觉得自己值不值。

#### 示例（本库自撰，可直接改写）

> 家长群里第一百三十七条消息，全是「收到」。
> 他也发了一个。往上翻，头像清一色是妈妈们，只有他这一个是空白的默认灰。
> 六点半闹钟，七点送，十点买菜，下午三点半接。中间那五个小时他洗了两台机器的衣服。
> 晚上她回来，他已经在沙发上打盹了，孩子的作业摊在茶几上，签好了名。
> 她数了一遍今天的事。数到第九件，停住了。
> 她没有说辛苦了。她说：「他昨天咳嗽，你半夜起了三次吧。」

## 六 · 他的原生家庭

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：旧伤 5.1%（低频高价值）

**骨架**｜他怎么成了现在这样，得去他几乎不提的那个家里找。

#### 节拍链

一句无意的话漏了缝 → 她记下没问 → 场合撞见（回老家·亲戚）→ 说了一部分 → 她不同情只在场 → 留了一部分

#### 时间轴

这条线要按年走，急不得。几个月才漏出一点，有时是一句没过脑子的话，有时是接电话时语气不对，有时是个说不出缘由的忌讳。她全记着，不催，也不问，她一急，缝就合上了。真撞上那个场面，算是一次摊开，也只摊开一部分，剩下的还得再等几年。

#### 这条是人物地基

一个成年男人肯待在被主导的位置上，得有个来由。没有也行，有了人物会厚实得多。

语料里的高频来处：

| 来处 | 造出的性格 |
|---|---|
| 从小被要求「像个男人」 | 他演腻了，哪天不用装了，整个人都松下来 |
| 家里有一个说了算的女性 | 他吃这一套，待着踏实 |
| 长期被忽视 | 有人明明白白管着他、盯着他，他就走不动道 |
| 父亲缺席或糟糕 | 他死活不想活成那副德行 |
| 家里出过事，他是收拾残局的人 | 他照顾人太顺手了，顺手到没人问他累不累 |

最后一行最好用。 他为什么能干，为什么累，一并有了交代。

#### 可用细节

| 类 | 内容 |
|---|---|
| 泄露的方式 | 一句没留神的话 · 他对某类事反应太大 · 他从来不去某个地方 |
| 他的回避 | 「没啥好说的」· 岔开话题那叫一个顺溜 |
| 她的发现 | 不是问出来的，是撞上的 |
| 场合 | 回老家 · 某个节日 ✓ · 一个亲戚冒出来 |
| 说出来之后 | 她第一反应不能是心疼他 |

她头一个反应不能是心疼。一同情，他就成了等人来救的那个。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 说不说 | 说了 | 一直瞒着，她自己猜到的 |
| 严重程度 | 小事 | 大事，得小心，看下面 |
| 她的反应 | 没吭声，就握了下他的手 | 她自己把事办了 |
| 之后 | 他松了口气 | 他后悔开了那个口 |

「她自己把事办了」得小心，替他收拾原生家庭的事，很容易管过了界。 除非他明说要她办。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她撞见他藏着的那块心病 | 话说完之后的冷场 |
| 内心 | 怪不得他平时老那样 | 她会不会觉得我怂 |
| 好的处理 | 她没追着问，也没可怜他，就是待着没走 | 他讲了一半，另一半咽了回去 |
| 写崩 | 写成她来救他 | 写成倒苦水 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 庶出／不受宠／家中排行／被当作联姻筹码养大 |
| 修仙 | 散修出身／被弃／前一世的记忆 |
| 星际 | 边境出身／战争孤儿／基因等级低 |

#### 内容边界

这条会碰到童年创伤，写的时候守两条线：

| 线 | 说明 |
|---|---|
| 全员成年 | 回忆里的他是未成年，但回忆内容不与任何性内容关联 |
| 不写可复现的伤害细节 | 交代性质与后果即可，不做过程描写 |

具体规则见 [00-编纂规约/03-版权与内容红线](../00-编纂规约/03-版权与内容红线.md)。

#### 写崩的三种方式

1. 拿创伤解释他的一切。 一件事撑不起一个人。
2. 让她当救世主。 她可以陪着，不能替他把事解决了。
3. 一次把底全揭了。 分两三回露出来更好。

## 七 · 她的原生家庭

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：旧伤 5.1%

**骨架**｜她强势有她的来由，只是那来由多半不怎么体面。

#### 节拍链

她的过度反应被他注意到 → 症状累积 → 他拼出原因 → 「习惯了」三个字 → 她第一次交出一件事 → 他接下了

#### 时间轴

先冒出来的是些零碎的毛病：她不许别人替她拿主意，碰上「被安排」反应特别大。这些毛病攒了几个月，他才自己拼出背后的缘故。接着她说了「习惯了」这三个字。又过了很久，她才头一回主动把一件事交出去。

#### 为什么必须写

只写他的来处，不写她的，她就成了没有过去、只管派用场的角色。

它还回答了「她为什么需要掌控」。掌控欲没个来由，读者不会信。

| 来处 | 造出的性格 |
|---|---|
| 长女，很早开始承担 | 她习惯掌控 |
| 家里出过大事，她扛下来的 | 她不敢把事情交给别人 |
| 被否定过一次，此后再没输过 | 她的强硬带着防御 |
| 有一个失败的父亲 | 她不信任依赖 |
| 她赢过，且尝到过赢的代价 | 最有层次的一版 |

她什么都管，是因为习惯了，这个设定自带成长线。人从「喜欢说了算」换成「没人教过她怎么撒手」，后一种是能变的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 泄露方式 | 她碰到某类事就反应特别大 · 她从不开口求人 · 她怎么睡 |
| 具体表现 | 她办啥事都留一手 · 她不让别人碰方向盘 · 她的体检单 ✓ |
| 他的发现 | 他先看出的是毛病，过了好久才弄明白根子在哪 |
| 她的说法 | 话少。「习惯了」就完了 |
| 转折 | 她头一回把一件事托给他 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她说不说 | 说了一点 | 一个字都不提 |
| 他怎么知道的 | 她家里告诉他的 | 他自己东拼西凑猜出来的 |
| 她的变化 | 总算肯把一件事交出去 | 始终学不会撒手 |
| 他的作用 | 他接住了 | 他也没接住，这版更真实 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把钥匙 ✓ 递出去的那一下 | 原来她从十六岁就开始扛 |
| 内心 | 交出去会不会出事 | 她不是天生就这样的 |
| 好的处理 | 她交出去之后忍住没检查 | 他把那件事办成了，没邀功 |
| 写崩 | 把她的强势写成误会 | 他理解她之后就原谅一切 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 长女承家／早早掌事／母亲的期许／一场变故后她当了家 |
| 修仙 | 她担着宗门／师门被灭她扛下来 |
| 星际 | 她十九岁当上舰长的原因 |

#### 写崩的三种方式

1. 不写。 她就是个工具人。
2. 把她的强势写成受过伤才有的。 等于说她本来不行。
3. 以为理解了就算治好了她。 理解之后，事情才刚开始。

## 八 · 养一只

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：宠物 10.5%

**骨架**｜家里添了一只，两个人之间那点事，全被它照了出来。

#### 节拍链

谁提的 → 抱回来 → 取名 → 分工成形 → 它黏谁 → 一次闯祸 → 家里的排序定了

#### 时间轴

从抱回来那天算，叫「元年」。起名吵了半小时，谁喂谁遛一周内就定了规矩。它头一回拆家，全家头一回一起收拾它。它跟谁更亲，每个月都在变，最后多半黏白天在家的那个，谁也没话说。

#### 宠物是关系的显影剂

它不推动情节，只显示关系：

| 观察点 | 显示什么 |
|---|---|
| 谁想养 | 谁先提出来要个伴儿 |
| 谁负责 | 平时谁在管、谁在喂 |
| 它更黏谁 | 谁在家待得久 |
| 取名字 | 谁说了算 |
| 它生病时谁着急 | 谁最上心 |
| 它做错事谁凶 | 谁在家里说了算 |

最后一行看的是：一个从来不凶他的人，会不会凶猫，一个被她管着的人，会不会去管猫。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 猫粮 ✓ · 狗绳 ✓ · 铲屎 ✓ · 它睡谁屋 |
| 日常 | 半夜踩人身上 · 就认她回来才叫 · 他天天记它吃几口 |
| 名字 | 谁起的名 · 有没有背着人叫的小名 |
| 争执 | 让不让上床 · 做不做绝育 · 能不能喂人饭 |
| 他的位置 | 家里排老二，自己老拿这个开涮 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁想养 | 他 | 她 |
| 它黏谁 | 黏他 | 黏她（他会吃醋） |
| 冲突 | 无 | 它撕了她的重要文件 |
| 结局 | 日常 | 它老了／病了（转 [九 · 送走它](#九--送走它)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现它的窝挪到了他那边 | 它今天先蹭的是她 |
| 好的处理 | 她也认真参与，不甩手不管 | 他为了这只跟她争过一次 |
| 写崩 | 宠物抢了人物戏份 | 他像小孩一样跟宠物争宠 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她的马／他养的鸟／她赏的一只猫 |
| 修仙 | 灵兽／本命兽／它认谁 |
| 星际 | 机械宠物／舰上唯一的活物 |

#### 写崩的三种方式

1. 让宠物抢戏。 它是道具。
2. 写成人宠争宠。 自嘲一回行，老写就幼稚了。
3. 光写可爱，不写分工。 分工里才有东西看。

## 九 · 送走它

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：宠物 10.5% ＋ 离世 29.4%

**骨架**｜它老了，这是他们头一回一起失去什么。

#### 为什么这条重要

送走一只宠物，等于先把同样的路走一遍。真正的生离死别写起来太重，这一回轻得多。

它还有一点跟别的失去不同：治不治、什么时候停，由他们俩说了算，所以这是两个人一起拿的主意。

#### 节拍链

发现不对 → 检查 → 拖了一阵 → 那个决定 → 最后一天 → 之后家里空的那一块

#### 时间轴

从发现不对劲到做那个决定，中间那段「拖」，谁都免不了，要写的就是它。查了又查，吃药，再复查，每拖一周，心里都明白是在拖，可谁都不先开口。最后那一天要写足，从早到傍晚，一个钟头一个钟头地数着过。家里空出的那一块，要按月算，一直空到碗筷收起来那天，才算送完。

#### 可用细节

| 类 | 内容 |
|---|---|
| 迹象 | 它不上沙发 ✓ 了 · 吃得少 · 睡的时间变长 |
| 决定 | 谁先开口 · 谁签字 · 谁抱着 |
| 那天 | 谁在 · 谁哭了 · 谁没哭 |
| 之后 | 猫粮 ✓ 还剩半袋 · 它的窝没扔 · 家里少了一种声音 |
| 很久以后 | 有人送新的，他们说再等等 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁哭了 | 他 | 她，这版更少见，也更戳人 |
| 谁做决定 | 她 | 他这回想自己扛 |
| 之后 | 再养一只 | 好长时间不敢再养 |
| 关系的变化 | 更近了 | 俩人各自缓了一阵 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己也走不动了 | 决定是我做的 |
| 好的处理 | 她让他拿主意，自己陪着 | 他拿了主意，也没怪她 |
| 写崩 | 写成她啥都自己扛 | 写成他垮了，还得她去哄 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她的马老死／他养的鸟 |
| 修仙 | 灵兽寿尽／本命兽断了契 |
| 星际 | 舰上那只被安乐 |

#### 写崩的三种方式

1. 写得太长。 一场戏，不要一章。
2. 她一直冷静。 她也得有那么一下。
3. 马上再养一只了事。 中间得空一段。

## 十 · 亲人离世

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：离世 29.4%（本族最高）

**骨架**｜有人走了，这时候两人里是谁在撑着。

#### 节拍链

消息来 → 谁撑着（订票·联系·通知）→ 仪式 → 事毕 → 一个小触发物 → 崩 → 另一个人只是在

#### 时间轴

订票、联系、仪式都照计划办完，撑着的人三天里没出一点错。等这些都停下来，难过才刚开始，一两周后被某个小东西一下点着，跟 [30-她的世界 · 她哭不出来](30-她的世界.md#七--她哭不出来) 里那种迟来才发作的情形是一回事。

#### 这条在 GB 里的特殊结构

传统脚本里，出了事是男方撑着，女方哭。

这里的路数多得多，每一种都透着两人的关系：

| 谁的家人 | 谁撑着 | 读作 |
|---|---|---|
| 他的 | 她撑 | 常态。她全包了，他终于能歇着 |
| 他的 | 他撑 | 他不让她碰（有戏） |
| 她的 | 她撑 | 她习惯了，也扛得住 |
| 她的 | 他撑 | 她头回有人接手 |

她撑了一辈子，这回总算有人挡在她前头。

#### 可用细节

| 类 | 内容 |
|---|---|
| 事务性的 | 打电话 · 订票 · 联系殡仪 · 通知亲戚 · 这些杂事就是“硬撑”的样子 |
| 她的方式 | 一件件安排，不哭 · 手在抖但字写得很稳 |
| 他的方式 | 他专挑没人干的活干 · 半夜守着 |
| 她的崩点 | 事全办完了 · 一件旧衣、一个没删的号码就能勾出来 |
| 他的动作 | 不问、不劝、就在旁边待着 |

崩就该崩在「事全办完了」的时候，跟 [04-委屈与破防 · 忍到最后一秒](04-委屈与破防.md#六--忍到最后一秒) 一样。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁的亲人 | 他的 | 她的 |
| 谁撑 | 她 | 他 |
| 关系深浅 | 亲近 | 疏远，更复杂：不知道该不该难过 |
| 之后 | 关系更紧 | 有一段各自沉默的时间 |

「疏远」这一版难写，也真，因为没有现成的情绪可套。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 事情全办完的那个晚上 | 她的手在抖但字写得很稳 |
| 内心 | 我不能倒 | 这次我来 |
| 好的处理 | 她后来让自己哭了一回 | 他办了事，但没说“有我在” |
| 写崩 | 写她从头到尾没露过破绽 | 写他一句“有我在”全搞定 |

「有我在」在 GB 里要慎着用。这是传统脚本的招牌台词，一说出口，整段关系就退回老样子了。拿行动顶替这句话。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 丁忧／扶灵／族中事务／她主丧 |
| 修仙 | 师尊坐化／同门殒落／寿元尽 |
| 星际 | 阵亡通知／没有遗体 |

星际版「没有遗体」，告别总也做不完。

#### 写崩的三种方式

1. 用「有我在」收场。 见上。
2. 她从头到尾挑不出毛病。 她得垮一次。
3. 拿葬礼当情节的转折。 它就是一件发生了的事，照实写。
