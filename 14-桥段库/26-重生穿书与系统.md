# 重生穿书与系统

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 重生 · 穿书 · 快穿 · 系统
> 频次数据来自[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，统计基数是 2,894 部独立作品。文里的百分比是编写时实测的，挖掘器扩充后节拍族会有小幅变动，最新数字以 13-07 为准（用 `run.py mine` 重跑更新）
> 这一族写某个人比别人多知道一些事的场面：重生、穿书、系统、快穿、失忆。一个人揣着未来的事活在当下，信息差拉到了最大。

## 这一族在语料里的体量

| 设定族（书级） | 作品数 | 占比 |
|---|---:|---:|
| 穿书／穿越 | 671 | 23.0% |
| 失忆 | 261 | 9.0% |
| 重生 | 228 | 7.9% |
| 系统 | 204 | 7.0% |

**穿书类将近占了全语料的四分之一**。[05-剧情套路/01-经典套路库](../05-剧情套路/01-经典套路库.md) 收了这些书的整体骨架，场景这一层一直空着。这一卷补的就是具体场面：重生的人头一回再见到那个人，是一场实打实的戏，要有实打实的写法。

这四种设定都是有人比别人多知道一些事，各有侧重：

| 设定 | 谁知道未来 | 核心问题 |
|---|---|---|
| 重生 | 她（或他）还记得上一世 | 上一世欠下的 |
| 穿书 | 穿进来的人读过原著 | 照剧情走，还是照人心走 |
| 系统 | 系统派任务 | 被安排好的接近，怎么变成真心 |
| 失忆 | 别人都记得，只有当事人忘了 | 反过来写：全世界都瞒着他一个人 |

## 一 · 重生后的第一面

`T` ｜ 无预警 ｜ 重生 ｜ 语料频次：重生 7.9% ＋ 初见 39.9%

**骨架**｜她记得他是怎么死的，他才刚认识她。

#### 节拍链

重生醒来 → 算日子，离那件事还有多少年 → 去见他 → 见到，活生生的，年轻的 → 忍住 → 用「初识」的规格重新开始

#### 时间轴

**两条时间线叠在一起走**。明面上是刚认识的那一套：第一次见面，第二次约。暗地里是她的倒计时，离上一世出事那天还剩四年三个月。明面上每一场戏，底下都压着这条暗线。

#### 这一面的独门难度

初见该守的那些规矩（见 [11-初遇与确立 · 第一眼](11-初遇与确立.md#一--第一眼)），放到她身上全不管用：

| 初见该有的 | 她的实况 |
|---|---|
| 陌生感 | 他睡觉压着哪只手，她都一清二楚 |
| 分寸感 | 上辈子才叫的称呼，她差点顺嘴喊出来 |
| 慢慢来 | 她恨不得当场抱住他，硬是忍着，指甲都掐进了肉里 |
| 平等的信息 | 他什么样她全知道，她什么样他毫不知情 |

这场戏她只有一件事要做：忍住。上一世的妻子压着一肚子旧情，陪一个不认识自己的人，把「你好，初次见面」重新走一遍。

#### 可用细节

| 类 | 内容 |
|---|---|
| 见面 | 她提前两小时就到了 · 他进门那一刻，她在桌子底下把手攥出了印子 |
| 破绽 | 他爱吃什么、不吃什么、咖啡放几块糖，她每次都“猜”得准到吓人 |
| 他的困惑 | “咱俩以前见过？”她回“你长得像我一个熟人”，这话也不算骗他 |
| 旧情外泄 | 他随口一句话正撞上前世的旧事，她眼眶一下红了，赶紧说是辣的 |
| 暗轴 | 回家后她在日历上圈了一个日子，是四年后的那天 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁重生 | 她 | 他重生，故意在她必经的路上一次次「偶遇」，她只觉得这人的眼神太旧 |
| 上一世 | 圆满，可惜天人永隔 | 有亏欠（转 [二 · 上一世欠他的](#二--上一世欠他的)） |
| 节奏 | 忍着慢慢来 | 没忍住，快到把他吓着，她得给「为什么对我这么好」一个圆得过去的解释 |
| 暗轴事件 | 改写成功 | 只改了一半（以宿命感收尾） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 说出「初次见面」时舌尖发苦 | 刚认识的这个人，莫名让他觉得熟 |
| 内心 | 你不认识我了，太好了，你还活着 | 她看我的眼神，像是认识我好多年 |
| 好的处理 | 她把旧情装进「慢慢来」的壳里，一步都没越 | 他的困惑写够，别让他轻易接受离奇的展开 |
| 写崩 | 写成她一上来就摊牌 | 写成他三句话就信了转世 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她重生回十五岁，他还是隔壁那个没被家里折腾过的少年 |
| 修仙 | 她重修一世，找到他时他还没入魔，这一回她先登门递帖 |
| 星际 | 她是时间线倒回去的实验体，他阵亡档案的编号她倒着都背得出 |

#### 写崩的三种方式

1. 第一面就相认。 要忍住，别急着掀底牌，掀牌另有玩法。
2. 旧情写成全知全能地压人。 他这一世是全新的人，总有新变数打得她措手不及。
3. 丢了暗线。 没有日历上圈的那个日子，重生只是换了个开头。

前接：[11-初遇与确立 · 第一眼](11-初遇与确立.md#一--第一眼)（正常版对照）
后接：[二 · 上一世欠他的](#二--上一世欠他的) · [十 · 知道结局的人](#十--知道结局的人)

#### 示例（本库自撰，可直接改写）

> 「你好，」她说，「初次见面。」
> 这四个字她在楼下练了四十分钟。难的不在说出口，在说的时候别哭。
> 他伸过手来。这只手她太熟了，虎口有道疤——不对，现在还没有。那道疤是三年后的事。
> 「你的咖啡，」服务生问，「加糖吗？」
> 「不加，他胃不好——」她听见自己说到一半，硬生生拐了个弯，「……我猜的。你看着像胃不好的人。」
> 他笑了：「你猜得真准。」
> 准，她想，我拿一辈子换的准。

## 二 · 上一世欠他的

`T` ｜ 无预警 ｜ 重生 ｜ 语料频次：重生 7.9%

**骨架**｜上一世欠了他，这一世加倍待他好，一半出于真心喜欢，一半是在还债。

#### 节拍链

带着愧疚醒来 → 照她的作风列一张偿还清单 → 一项项去做 → 他受宠若惊 → 有一天他觉出这份好里还掺着别的 → 「你是不是在还什么」→ 摊牌，或者接着瞒

#### 时间轴

上一世漏过的生日、错过的演出、没兑现的旅行，她一样样补上。补到清单见底那天，问题来了：还完了，接下来呢。

#### 债的类型

| 上一世的亏欠 | 这一世的补法 | 陷阱 |
|---|---|---|
| 忙到忽略他（最常见） | 这一世推掉一切，按时回家 | 只补时间没用，他要的是她这个人 |
| 没说过那三个字 | 这一世常挂在嘴边 | 说得太多反倒显假，他起了疑 |
| 他为她挡过一次灾 | 这一世提前把那场灾拆掉 | 拆灾会改动时间线，蝴蝶效应反咬回来 |
| 到最后才明白心意 | 这一世从第一天起就对他好 | 无缘无故的好最让人起疑 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 清单 | 写在手账最后一页，缩写只有她看得懂 · 划掉一项时那一笔下得特别重 |
| 他的困惑 | 「我生日你怎么知道」「你怎么知道我想去这」，她的借口快编不下去了 |
| 察觉 | 他发现这些好每一样都正中他没说出口的心愿，像是抄了答案 |
| 那句话 | 「你对我好得……像在赔罪。」他说中了，她端着杯子的手停住了 |

她待他好得像在赔罪，他察觉到不对劲了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 债有多大 | 不当回事 | 上一世他替她死了，这一档的偿还清单只有一项：让他活下来 |
| 摊牌 | 说了实话，他信不信是下一场戏 | 没说，把债一直捂成了单纯的感情 |
| 清单见底 | 还完了才发现早就不是在还债 | 还完那天她慌了：没有清单，她不知道该怎么爱人 |
| 他的态度 | 收下这份好 | 直说「我不要你还，我要你在」 |

她习惯按清单做事，清单划完了，她就不知道怎么爱人了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 划掉清单最后一项那晚的空落 | 他说出「像在赔罪」之后她的脸色 |
| 内心 | 还完了。可我停不下来了。 | 我不要她还，我要她在 |
| 好的处理 | 她最后把清单拿给他看了，没还上的那几项也在 | 他接过清单撕了，说「重写，写往后的」 |
| 写崩 | 写成无尽的内疚循环 | 写成他利用她的愧疚 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 上一世她负了他，另娶高门，这一世聘礼抬进他家那天，他家人还没回过神 |
| 修仙 | 上一世她用他的本命精血续了道基，这一世她把半副道基还给了他 |
| 星际 | 上一世她下令撤退，丢下了他那艘舰，这一世她把旗舰泊位改到他的编队旁边 |

#### 写崩的三种方式

1. 债永远还不清。 清单一定要见底，见底之后她的慌乱才是正文。
2. 他一直被蒙在鼓里。 「像在赔罪」那句一定要响。
3. 愧疚全写成了爱。 撕清单那场要把两样分开。

## 三 · 双重生

`T` ｜ 无预警 ｜ 重生 ｜ 语料频次：重生 7.9%

**骨架**｜两个人都重生了，都当只有自己记得，都在装。

#### 节拍链

各自醒来 → 各自拿主意（都决定瞒着）→ 「初见」（两个影帝同台）→ 互相看出破绽 → 各自试探 → 揭穿那一刻 → 相认

#### 时间轴

**两条线并行地互相猜**：他发现她「猜」得太准，她发现他躲她该躲的劫躲得太熟练。破绽攒到临界点，谁先开口去验证，谁就先暴露了自己，可也先赢了这一局。

#### 破绽对照表

| 她露的 | 他露的 |
|---|---|
| 知道他的忌口（上一世学的） | 提前绕开了那个骗局（上一世栽的） |
| 在他旧伤复发前备好了药 ✓ | 在她项目暴雷前劝她撤了资 |
| 叫错一个只有上一世才有的称呼 | 对一首「还没发行」的歌跟着哼 |

跟着哼还没发行的歌，双重生文常用这种破绽：小、硬、无法解释。

#### 可用细节

| 类 | 内容 |
|---|---|
| 演技 | 两人都把「初识」演得滴水不漏，漏洞只有对方看得出 |
| 试探 | 她故意提起一个上一世的地名，看见他睫毛抖了一下 |
| 揭穿 | 「这首歌下个月才发。」他僵住。她续道：「我也是听你哼才会的。上一世。」 |
| 相认 | 没有抱头痛哭，先是很久的沉默，后来有人笑了：「演了三个月，累不累」 |
| 相认后 | 对答案：各自上一世是哪年、因为什么死的，两份记忆拼成一张全图 |

「对答案」只有双重生才有：两人的上一世并不完全重合，拼的时候才发现对方替自己瞒过一些事。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 记忆 | 同一条时间线 | 两段不同的上一世，拼到一起三观都碎了 |
| 谁先识破 | 她 | 他，这辈子他头一回比她先看明白一件事 |
| 相认时点 | 三个月 | 拖了三年，两人各怀秘密结了婚，婚礼上都在琢磨「对方到底知不知道」 |
| 相认后 | 结成同盟 | 起了分歧：两人想改的事不同，甚至互相拆台 |

两人想改的事可能互斥，她想救的人偏是他上一世的仇人。两份未来打起来了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他睫毛抖了的那一下 | 她嘴里说出「上一世」这三个字 |
| 内心 | 要是他也是……那上一世最后那天，他是故意的 | 她也在。她一直都在。 |
| 好的处理 | 她验证前先想好了「他不是」的退路 | 他揭穿时选的是那首歌，不是更重的事 |
| 写崩 | 写成两人无限装傻 | 写成相认后全知无敌 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 洞房夜却扇时，两人同时说出了上辈子说过的话，扇子掉在了地上 |
| 修仙 | 一起兵解重修，论道时一招一式像练过千百遍，长老看得一头雾水，说这哪像头一回见面 |
| 星际 | 两个时间线被重置过的实验体，数据库里记录编号挨着，谁也没点开过对方那一条 |

#### 写崩的三种方式

1. 一见面就认出对方。 互相猜至少要来三轮。
2. 演技写成了明着演。 破绽要小到只有对方看得出。
3. 相认时抱头痛哭。 先沉默，再对答案，哭留到最后。

## 四 · 剧情开始偏移

`T` ｜ 无预警 ｜ 穿书 ｜ 语料频次：穿书 23.2%

**骨架**｜这本书她看过。可眼前这个男配，根本没照第三章的剧本走。

#### 节拍链

照原著预判 → 头一次小偏，还圆得回来 → 第二次偏，圆不回来了 → 发现剧情彻底失控 → 回头找原因 → 找来找去，原因在她自己身上 → 认了：书没了，人是真的。

#### 时间轴

按「原著章节」来算：第三章他该在宴会上碰见女主，第七章他该黑化。每到一个节点她都掐着点等，剧情却一次比一次偏得远。

#### 偏移的三个阶段

| 阶段 | 现象 | 她的反应 |
|---|---|---|
| 小偏 | 台词差了几个字 | 「记忆误差吧」 |
| 中偏 | 该出现的场合他没出现，因为他在她这里 | 开始翻自己带来的「原著笔记」 |
| 大偏 | 原著里此刻他该恨的人，他正替她挡刀 | 笔记撕了 |

撕掉笔记，就是承认预测不灵了，承认眼前这个人是活的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 笔记 | 她凭记忆默写下来的「剧情大纲」，锁在抽屉最里面（接 [15-秘密与坦白 · 他有一件事没说](15-秘密与坦白.md#一--他有一件事没说)的她版） |
| 掐点 | 原著名场面的日子她都记着，一到那天就绷紧了 |
| 偏移实感 | 他说了一句原著里没有的话，比原著里哪一句都好 |
| 归因 | 风是她扇的：她多看的每一眼都在改他 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他在原著里 | 男配（炮灰） | 反派，她来之前只要躲着他，现在得去改他 |
| 偏移方向 | 变好 | 更糟：她插手太早，黑化提前了，开出一条赎罪线 |
| 笔记 | 撕了 | 被他发现了（转 [七 · 攻略对象不按剧本](#七--攻略对象不按剧本)里的对质） |
| 她的立场 | 由着它偏 | 拼命把剧情往回掰，她怕偏离了结局，后面就全是未知 |

「拼命掰回剧情」这一端有股狠劲：**她明知前面是坑，还是往里跳**。这个错误的选择，比选对了好看得多。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 撕笔记的那一下 | 她总在某几天绷着神经，像在等一场只有她知道的雨 |
| 内心 | 书里没这句，书里也没你这么看我 | 她好像随时准备着替我挡什么 |
| 好的处理 | 她把“原著粉滤镜”一层层摘下来，写足这个过程 | 他的偏移有自己的逻辑，不是为她而偏 |
| 写崩 | 写成她拿剧透当遥控器 | 写成他人设崩了，只为剧情服务 |

他的偏移自有道理。他变好，是因为这一回有人把他当人看。女主光环照没照到他，在这件事上不起作用。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 穿进一卷话本，说书人讲的段子一个个落了空，连说书人自己都犯嘀咕 |
| 修仙 | 穿进一部道门秘史，天机算一回错一回，掌门以为天道出了岔子 |
| 星际 | 穿进一部舰队编年史，书里写的开战日子到了，仗却没打起来 |

#### 写崩的三种方式

1. 剧情永远精准。 得让它偏。
2. 偏移没有原因。 每一次偏移都要能追到她做过的某件事上。
3. 笔记撕得太早。 三个阶段一个都不能少。

## 五 · 原主的影子

`T` ｜ 无预警 ｜ 穿书 ｜ 语料频次：穿书 23.2%

**骨架**｜她以前待他不好。现在他看她，眼神里还有一半落在原来那个她身上。

#### 节拍链

穿过来 → 接下原主的烂摊子（他眼里的戒备）→ 她用自己的方式待他 → 他困惑（「你变了」）→ 得解释为什么「变了」→ 他爱的到底是谁，这个问题冒出来 → 处理

#### 时间轴

头一个月他躲着她的手，第三个月不躲了，第六个月他问出那句：「你到底是谁？」

#### 这条的哲学题（要落成具体的戏）

「他爱上的是这具身体的原主，还是穿来的她」，这个问题别停在内心独白里，要落到三场戏上：

| 戏 | 内容 |
|---|---|
| 旧物戏 | 他收着原主难得对他好那一回给的旧东西，她看见了，吃了一场没有对手的醋 |
| 习惯戏 | 原主爱用的香、挂在嘴边的话，她一样都没有。有一天他说「你现在这样挺好」，这一句就让她落了户 |
| 摊牌戏 | 「你从什么时候开始觉得我不一样的」，他报出的日期正是她穿来那天 |

**他报出穿越那天的日期**，这一招很甜。他没有什么超自然的本事，只是一直看着她，把换了人的那一刻牢牢记住了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 原主遗产 | 一屋子她看不懂的东西 · 一个她圆不上的旧承诺 · 几个等着看她出丑的旧敌 |
| 演砸 | 她模仿原主的签名总差那么一点 · 管家看她的眼神里多了点东西 |
| 戒备消退 | 他从「站三步外回话」，到「递东西时手指敢碰到」 |
| 那句户口 | 「你现在这样挺好」，他不知道这句话对她有多重 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 原主对他 | 很差（她接的是赎罪局） | 很好，她接过一份高分答卷，压力反倒更大 |
| 原主下落 | 人没了 | 还会回来，她占着的是别人的位置和别人的爱人 |
| 摊牌 | 说出穿越的真相 | 只承认「我确实变了」，真相烂在肚子里 |
| 他的选择 | 爱现在这个 | 他分不开，也不肯分：「都是你」 |

「原主还会回来」这一端把甜变成了倒计时：**她越幸福，离归还那天就越近。**

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 那句「你现在这样挺好」 | 他报出日期时她脸上的震动 |
| 内心 | 我是替一个陌生人被爱着，还是真的被爱 | 那天起她眼里有了光。不管她是谁，光是真的 |
| 好的处理 | 她吃原主醋的那场写足，荒唐又真实 | 日期他记得清清楚楚，却从来不追问 |
| 写崩 | 把原主写成纯粹的工具人 | 写成他换了人像换件衣服，一点不难受 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 穿成苛待夫郎的恶主母，全府下人原本替他捏一把汗，后来看她的眼神越来越看不懂 |
| 修仙 | 有夺舍的嫌疑，只有他一个人觉得「夺舍了也比原来那位好」，这念头让他愧疚 |
| 星际 | 意识上传出了错位，生物特征和从前完全一样，他却对她说「你的脑波不一样了」 |

#### 写崩的三种方式

1. 把原主写成纯背景板。 原主留下的东西要一直碍事，隔一阵就冒出来扎一下。
2. 绕开「你是谁」。 至少摊牌那场要正面碰一次，躲不得。
3. 哲学题一直悬着不落地。 三场戏一场都不能少，都要写透。

## 六 · 系统的任务与她的真心

`T` ｜ 无预警 ｜ 系统 ｜ 语料频次：系统 7.0%

**骨架**｜系统提示：攻略目标好感度+10。她一下分不清，刚才那句关心是任务还是真心。

#### 节拍链

绑定系统 → 接下任务（攻略他）→ 照攻略办事 → 好感度上涨 → 有一天她做了件任务以外的事 → 系统没加分，她反而更高兴 → 任务和真心分不清了 → 摊牌，或者反抗系统

#### 时间轴

看好感度数字。+10、+20 一路涨，直到某天她为他做了件系统判「无效」的事，那个 +0 比所有加分都要紧。

#### 「被安排的爱怎么变成真的」三步

| 步 | 现象 |
|---|---|
| 执行 | 每句话都冲着任务说，说完还要瞄一眼面板 |
| 混淆 | 话已经说出去了才想起看面板，先后颠倒了 |
| 反抗 | 系统提醒「这么干耽误任务」，她完全不理 |

「说完才想起看面板」是转折。什么时候看面板，就分出了哪句是任务、哪句是真心。

#### 可用细节

| 类 | 内容 |
|---|---|
| 面板 | 只有她能看见的浮窗 · 好感度进度条 · 任务倒计时 |
| 系统的声音 | 机械提示音偏挑最不该响的时候响：他告白到一半，系统来一句「主线任务完成」 |
| +0 事件 | 他病重，她守了一整夜，面板毫无动静，原来守夜不算任务 |
| 反抗 | 系统说「离远点好做任务」，她干脆把面板调成免打扰 |
| 隐瞒 | 他不知道她看得见面板，她总往空气里瞄，这些他都记着 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 任务目标 | 攻略他 | 更冷的一种：利用他，真心太贵，她付不起 |
| 系统性质 | 工具 | 系统另有算盘，反抗升级成对抗 |
| 他知不知道 | 不知道 | 后来知道了：「所以你哪句是真的」，这个问题交给 [15-秘密与坦白 · 掉马](15-秘密与坦白.md#二--掉马)去处理 |
| 结局 | 任务完成，也是真心 | 为了真心放弃任务奖励（回家的机会） |

「所以你哪句是真的」，系统文一定要正面回答这个问题，答得最好的是：**「看面板之前说的那些。」**

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 那个 +0 | 她第一百次往空气里瞄 |
| 内心 | 加分的话没一句是真的，真话一句都不加分 | 她总盯着一个不存在的地方，像在和谁对账 |
| 好的处理 | 调成免打扰那一下干净利落 | 他早发现了不对劲，决定等她自己说 |
| 写崩 | 写成数值游戏攻略 | 写成他知道后把全部感情一票否决 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 奉懿旨到他身边，是家里派的差事，差事办完那天她把赏赐退了回去 |
| 修仙 | 师门要她和他双修采补，她偏把功法改成两人都得益的路数 |
| 星际 | 芯片直接植进脑子，她做手术摘掉了，代价是军功全被抹掉 |

三个换皮都把「组织安排」写成系统，哪个时代都通。

#### 写崩的三种方式

1. 面板戏压过了人的戏。 数值只在三处露面：开始上涨、+0、免打扰。
2. 系统说没就没了。 反抗要付代价，代价得明码标价。
3. 他知道以后，对这个问题躲躲闪闪。 「哪句是真的」，一定要给个准话。

## 七 · 攻略对象不按剧本

`T` ｜ 无预警 ｜ 穿书 · 系统 ｜ 语料频次：穿书 23.2% ＋ 系统 7.0%

**骨架**｜攻略手册上说他吃温柔小意那一套，他偏不吃，还把她的套路一条条拆了个干净。

#### 节拍链

照攻略出招 → 无效 → 换策略 → 又无效 → 他直球反问一句 → 她乱了 → 扔掉攻略用真人打法 → 管用了，可她已分不清打法和真心

#### 时间轴

照攻略手册的条目一条条试：温柔攻势，败了。欲擒故纵，败了。英雄救美，他自己解决了。败一条划一条，手册划完，正文开场。

#### 他为什么免疫

| 攻略预设 | 他的实况 |
|---|---|
| 「他缺关爱，温柔即可攻陷」 | 他缺的是尊重，温柔里有没有掺假，他一闻就闻出来了 |
| 「制造英雄救美」 | 他自己就能摆平，回头还把她安排的「危机」查了个底朝天 |
| 「欲擒故纵」 | 她三天没理他，他一本正经跑来问「我哪做错了」，把套路问成了事故 |
| 「投其所好」 | 资料上写的爱好是原主瞎编的，一样都对不上 |

他把套路问成了事故。套路最怕认真，一句认真的「为什么」，整本手册就散了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 手册 | 系统面板上的「攻略建议」 · 或者她自己凭记忆默写的原著人设卡 |
| 拆招现场 | 她递上一把「偶遇」时的伞 ✓，他说「你跟了我三条街」 |
| 乱拍 | 他直球一问，她的台词库全空了，冒出一句大实话，好感度猛涨 |
| 复盘 | 面板上写着：有效行为=全部计划外行为 |

「有效行为=全部计划外」，结案陈词由系统替她说了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他免疫的原因 | 生来敏锐 | 他重生了，或者他也是穿来的（接 [三 · 双重生](#三--双重生)，攻略者撞上攻略者） |
| 她的调整 | 放弃套路 | 套路一路升级，输到底才肯放，更好笑也更真 |
| 他的态度 | 拆招，但不点破 | 当面说破：「下次直接说，别绕」 |
| 结局 | 真人打法管用了 | 他早就陷进去了，一直忍着看她表演，最后由他来坦白 |

他早就陷进去了，忍着看她表演，是舍不得戳破。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 台词全用完了，最后冒出来的那句真心话 | 他说「你跟了我三条街」那会儿，她脸上是什么表情 |
| 内心 | 这人怎么不按常理出牌，连接招都不照套路 | 她的招数里带着股认真劲儿，招数本身倒没什么 |
| 好的处理 | 她输得难看，可输得坦荡 | 他接招从不让人下不来台，接完还给人留面子 |
| 写崩 | 写成翻来覆去那几个套路 | 写成他什么都看得穿，像开了天眼 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她照着《驭夫策》行事，他从她枕头底下抽出那本书，翻到折了角的那页，当面念出来 |
| 修仙 | 她用魅心诀下套，他修的恰好是不动心咒，两套功法撞上了 |
| 星际 | 她照心理侧写报告去套近乎，他反手调出她的那份：「咱俩换着看？」 |

「交换着看」：到了星际版，拆招成了一份平等条约。

#### 写崩的三种方式

1. 套路用一次就扔。 至少让主角连输三回。
2. 不交代他为什么免疫。 敏锐也要有来由。
3. 说破以后关系就僵了。 说破之后该有的反应是「下次直接说」。

## 八 · 快穿的每一次告别

`T` ｜ 无预警 ｜ 快穿 ｜ 语料频次：系统 7.0% ＋ 告别 38.9%

**骨架**｜任务完成就得走。每个世界到了最后一刻，她都不敢回头。

#### 节拍链

任务进度 99% → 她开始不说话 → 完成的一瞬间倒计时启动 → 告别，或者来不及告别 → 白光 → 在新世界睁开眼 → 上个世界的余温还在

#### 时间轴

按「世界」来分：每个世界待几个月到几年，结尾都是同一个倒计时。读者和她一样，越甜越慌，早早就难受起来。

#### 快穿告别的三种规格

| 告别 | 场面 |
|---|---|
| 来得及的告别 | 她提前说「我要走了」，对方不信，直到她在他眼前一点点变淡 |
| 来不及的告别 | 任务在拥抱时突然判定完成，白光亮起，她的手还停在他背上没放下 |
| 不告而别 | 趁他睡着时离开，最心软，也最狠 |

#### 这一族与「同一个魂」的钩子

快穿文常见设定：**每个世界的「他」都是同一个灵魂的碎片**。这个钩子决定了告别是什么性质：

| 设定 | 告别的意味 |
|---|---|
| 各世界独立 | 每次离开都是永别，她攒了一身丧气 |
| 同魂碎片 | 告别时说「下个世界见」，可下一个他不记得她，每回都要从头追起 |
| 最后拼合 | 终章所有碎片归位，那个他带着每个世界的记忆看着她：「你欠我十七次告别」 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 倒计时 | 只有她看得见的数字 · 日子过得越好，数字跳得越快，是系统作怪还是她看花了眼，说不清 |
| 带不走 | 什么都带不走，她只能靠记，把每个世界里他的样子都记在脑子里 |
| 余温 | 在新地方睁开眼，手上还留着上个世界牵手的温度，三分钟就散了 |
| 沉默期 | 任务做到 99%，她忽然不说话了，他察觉不对，问：「你要去哪」 |

「越幸福数字走得越快」，是不是错觉都不要紧，写出来就站得住。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 怎么告别 | 来得及 | 三种轮着用，每个世界换一种，疼法不重样 |
| 他 | 独立灵魂 | 同一个魂，最后算总账 |
| 她的策略 | 每个世界都认真去爱 | 从某个世界起不敢再动心，偏偏下个世界的他最难缠 |
| 终局 | 拼合团圆 | 她留在了某一个世界，任务没做完的代价她认下 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 白光亮起，手悬在半空没落下去 | 他刚问出“你要去哪”，她笑得比哭还难看 |
| 内心 | 记住了。这个角度也记住了。 | 她看我的眼神，像在看倒计时 |
| 好的处理 | 她告别的话一次比一次短，疼却一次比一次久 | 最后一章那笔账，留给他自己去算 |
| 写崩 | 虐点像流水线，一套接一套 | 每个世界的他都一个样，毫无分别 |

#### 换皮

[10-换皮对照](10-换皮对照.md) 已经按卷拆好了，星际位面用 21 卷，古代女尊位面用 20 卷，这里不另列换皮表。

#### 写崩的三种方式

1. 每个世界写得一样长一样重。 细写两个，中间的用「第九个世界，秋天」一笔带过。
2. 每次告别都是同一种疼。 三种告别轮着来。
3. 终章算账时轻轻放过。 十七次告别的账一次结清，结够。

## 九 · 失忆后重新认识

`T` ｜ 无预警 ｜ 失忆 ｜ 语料频次：失忆 9.0%

**骨架**｜他醒过来，不认识她了。医生交代别刺激他。她摘下婚戒，说：「你好，我是你的主治联系人。」

#### 节拍链

出事 → 醒来认不出人 → 医生嘱咐不能硬灌记忆 → 她退成「陌生人」→ 从零开始第二次追他 → 记忆碎片闪回 → 恢复，或者没恢复

#### 时间轴

新的感情和旧记忆的恢复同时在走。最好让新感情跑在前面：记忆还没回来，他已经第二次爱上她了。

#### 可用细节

失忆版有几场独有的戏，别的条目借不走：

| 场面 | 戏 |
|---|---|
| 自我介绍 | 她把「初次见面」练了一整晚，比 [一 · 重生后的第一面](#一--重生后的第一面)里的她还难，那一位好歹有一世的准备 |
| 习惯出卖 | 他不记得她，手还记得：递东西自然递到她顺手那一侧 · 睡着后往她那边翻身 |
| 醋 | 他对「探望的陌生美女」动了心思，问护士她有没有对象，护士憋笑憋得内伤 |
| 旧物审讯 | 他翻到合照 ✓：「这男的是我？旁边这是……」她面不改色：「你朋友。」 |
| 回闪 | 某个动作会勾出碎片：她挽头发的手势让他头疼欲裂，眼眶也红了，他不知道为什么 |

他不记得她，手却还记得。陈述性记忆丢了，程序性记忆留着。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁失忆 | 他 | 她。最狠的一版：说「初次见面」的人换成了她，他连夜学会了她工作上的全部活计，只为能待在她身边 |
| 忘的范围 | 全忘 | 只忘了她一个，医学上叫选择性遗忘，其实是专挑最疼的忘 |
| 她的策略 | 从零追起 | 听医生的，远远看着（撑不过三天） |
| 结局 | 记忆回来了，两段感情一起摆上桌 | 没回来，又求了一次婚，同一枚戒指 ✓ 求了两回 |

「只忘了她一个人」这一端，用之前要想清楚：它把「你对他是什么」这个问题推到了生理层面。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 摘婚戒的那一下 | 那个「陌生人」挽头发的手势，让他心口一酸 |
| 内心 | 第二次追他。上回追了三年。 | 我为什么想对她好，才认识六天 |
| 好的处理 | 她不耍手段：他的软肋她都知道，一处都不碰 | 他第二次心动有自己的路，没照着第一次走 |
| 写崩 | 写成她翻出旧照片逼他回忆 | 写成失忆三章就收场 |

他的软肋她全清楚，一处也没碰。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他坠马失忆，她从主君退成「照看他的贵人」，全家陪着她演 |
| 修仙 | 断尘缘的忘情水被人做了手脚，她一剑挑了下药的宗门，回来接着陪他「头回见」 |
| 星际 | 冬眠舱出了故障，存记忆的扇区坏了，数据可以重装，她不肯：「让他自己挑一回。」 |

「数据可重灌，她拒绝」：星际版把这条的伦理难题摆到了明处，是把他恢复过来，还是尊重现在的他。

#### 写崩的三种方式

1. 把失忆当成短暂的波折。 至少给它一整卷的篇幅。
2. 靠旧物轰炸找回记忆。 恢复得从身体和碎片里来。
3. 记忆回来后新感情作废。 两段感情要合到一起，不能互相覆盖。

#### 可串接

后接：[11-初遇与确立](11-初遇与确立.md)。整卷的套路都能复用，失忆后怎么追，就是把初遇那十条再走一遍，这回手里攥着旧档案。

## 十 · 知道结局的人

`T` ｜ 无预警 ｜ 重生 · 穿书 ｜ 语料频次：重生 7.9% ＋ 穿书 23.2%

**骨架**｜她知道他四年后的冬天会死，于是一天天数日子，日历上那个圈一天天近了。

#### 节拍链

带着结局过日子 → 日常越甜，暗线越沉 → 布局改命 → 半路的假警报 → 那一天到了 → 改写成功或失败 → 之后

#### 时间轴

**倒计时走到头时，读者比主角先疼。** 前面[一 · 重生后的第一面](#一--重生后的第一面)埋下的扣子，在这里正好解开。他笑得越没心没肺，日常戏里那股倒计时的劲就越扎人。

#### 已知结局的三种态度

| 态度 | 她的做法 | 风险 |
|---|---|---|
| 硬改 | 提前拆掉要命的事：那辆车、那场病、那个人 | 命运会补回来：这边拆了，那边又冒出来 |
| 备份 | 没把握一定改得了，就先把每天过好 | 「向死而爱」太沉，日子都过成了告别的预演 |
| 摇摆 | 两样都做，还互相打架 | 最真实：想改命的她和认命的她天天吵 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 那个圈 | 他见过日历 ✓ 上的记号，问是什么日子，她说「发薪日」 |
| 布局 | 她提前三年就开始铺路，每一件都装成寻常决定：搬家、换医院、辞掉那份总出差的工作 |
| 假警报 | 提前两年出过一次差不多的苗头，她当场失态，反应大得离谱，他把这事记下了 |
| 那一天 | 从零点起她就不让他离开视线，他被盯得发毛：「今天什么日子？」「……发薪日。」 |
| 之后 | 过了零点，他睡着了，她在床边坐到天亮，把那个圈涂掉，涂了一遍又一遍 |

「发薪日」这个谎她说了两次。第一次是伏笔，第二次读者已经知道是哪一天，这句谎就成了她的宣战。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 改写结果 | 成功了，涂掉那个圈的一段是全书最戳人的地方 | 成了一半：人留下了，代价换了个地方落下（接 [16-危机与保护](16-危机与保护.md)） |
| 他知情否 | 自始至终不知道 | 半路知道了：「所以你这三年的每一天都是……」他说不下去 |
| 结局来源 | 上一世亲身经历 | 从书里看来的，她盼着「书是假的」，盼头和证据来回拉扯 |
| 之后 | 倒计时没了，学着像普通人一样「不知道」 | 新的圈：续集她没看过，头一回碰上未知，她反倒松了口气 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 把那个圈涂掉，涂了很多遍 | 「发薪日」第二次说出口时她的眼神 |
| 内心 | 过了今晚，我就和所有人一样了 | 有件事在她身上压了很多年，压出的印子我看得见 |
| 好的处理 | 布局全藏进日常，一件都不说破 | 知道以后他没怪她瞒着，只是把那三年她做的事数了一遍 |
| 写崩 | 写成她什么都知道 | 写成结局想改就能改 |

「他数了数那三年她做的事」：搬家、换医院、辞职，一件件重新对上，原来全是为了他。这一段是已知结局文的标准泪点，值得写满。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她重生回来，知道他哪天战死，用三年把粮道、将令、连天气都替他改了 |
| 修仙 | 天机阁说他命里有一场死劫，她拿自己的修为往里填，硬是替他把劫挪开了 |
| 星际 | 史书上写他那艘舰会毁在那一仗，她一路升到能改调令的位置，每升一级就多救一回人 |

她往上升，每一级都是为了救他。

#### 写崩的三种方式

1. 倒计时半路泄了劲。 那个圈要压到最后一晚才炸。
2. 改命不用付代价。 这类设定里没有白吃的午餐，拿了多少，早晚要还。
3. 他知道了也不当回事。 那三年她做过的事，他要一件件数出来。
