# 重生穿书与系统

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 重生 · 穿书 · 快穿 · 系统
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**一个人带着未来的知识活在现在。信息不对称被推到了极限。**

## 这一族在语料里的体量

| 设定族（书级） | 作品数 | 占比 |
|---|---:|---:|
| 穿书／穿越 | 671 | 23.0% |
| 失忆 | 261 | 9.0% |
| 重生 | 228 | 8.0% |
| 系统 | 204 | 7.0% |

**穿书类占了全语料的将近四分之一**：[05-剧情套路/01-经典套路库](../05-剧情套路/01-经典套路库.md) 收了它们的书级骨架，但场景层一直是空的。这一卷补的就是：重生的人第一次再见到那个人，是一场具体的戏，得有具体的写法。

这四种设定共享同一个引擎，侧重不同：

| 设定 | 谁知道未来 | 核心债务 |
|---|---|---|
| 重生 | 她（或他）记得上一世 | 上一世欠的 |
| 穿书 | 穿来的人读过原著 | 按剧情走还是按人心走 |
| 系统 | 系统发任务 | 被安排的接近怎么变成真的 |
| 失忆 | 别人都记得，只有当事人不记得 | 反过来：全世界都瞒着他一个人 |

## 一 · 重生后的第一面

`T` ｜ 无预警 ｜ 重生 ｜ 语料频次：重生 8.0% ＋ 初见 38.0%

**骨架**｜她记得他怎么死的。他刚认识她。

#### 节拍链

重生醒来 → 算日子，离那件事还有多少年 → 去见他 → 见到，活生生的，年轻的 → 忍住 → 用「初识」的规格重新开始

#### 时间轴

**两条时间轴叠着走**：明面上是刚认识那套流程，第一次见，第二次约。暗地里是她的倒计时，离上一世出事那天还有四年三个月。每场明面上的戏，底下都压着那根暗轴。

#### 这一面的独门难度

初见的所有规矩（见 [11-初遇与确立 · 第一眼](11-初遇与确立.md#一--第一眼)）对她全部失效：

| 初见该有的 | 她的实况 |
|---|---|
| 陌生感 | 她连他睡觉压哪只手都门儿清 |
| 分寸感 | 她差点顺嘴喊出上辈子才叫的称呼 |
| 慢慢来 | 她恨不得当场把人搂住，硬忍到指甲掐进肉里 |
| 平等的信息 | 他啥样她全知道，她啥样他一点没数 |

忍住，是这场戏唯一的动作。上一世的妻子压着满腔旧情，陪一个不认识自己的人，重新走一遍「你好，初次见面」。

#### 可用细节

| 类 | 内容 |
|---|---|
| 见面 | 她提前两小时到 · 他进门那一刻，她在桌底下把手攥出了印子 |
| 破绽 | 她“猜”中他爱吃什么、不吃什么、咖啡放几块糖，回回都准得吓人 |
| 他的困惑 | “咱俩以前见过？”——她说“你长得像我一个熟人”，也不算骗他 |
| 旧情外泄 | 他随口一句话，正好撞上前世的旧事，她眼眶一下就红了，忙说辣得不行 |
| 暗轴 | 回家后她在日历上圈了个日子，四年后的那天 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁重生 | 她 | 他重生，故意在她必经的路上一次次「偶遇」，她只觉得这人眼神太旧 |
| 上一世 | 圆满但天人永隔 | 有亏欠（转 [二 · 上一世欠他的](#二--上一世欠他的)） |
| 节奏 | 忍住慢慢来 | 忍不住，快得吓到他，她要给「为什么对我这么好」一个能圆的说法 |
| 暗轴事件 | 改写成功 | 只能改一半（宿命感收尾） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「初次见面」说出口，舌尖发苦 | 这个刚认识的人，莫名觉得熟 |
| 内心 | 你不认识我了，太好了，你活着 | 她看我的眼神，像认了我好多年 |
| 好的处理 | 她把旧情藏进「慢慢来」的壳里，一步没跳 | 他的困惑写足，别让他轻易接受超展开 |
| 写崩 | 写成她上来就亮底牌 | 写成他三句话就信了转世 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她重生回十五岁，他还是隔壁没被家里折腾过的少年 |
| 修仙 | 她重修一世，找到他时他还没入魔，这回她先上门递帖 |
| 星际 | 时间线倒回去的实验体，他阵亡的档案编号她倒着都能背出来 |

#### 写崩的三种方式

1. 第一面就相认。 这条的关键就是忍住，别急着掀牌，掀牌有别的玩法。
2. 旧情写成全知碾压。 但他这一世是全新的人，总会有新变数打得她措手不及。
3. 暗轴丢掉。 没了那个圈起来的日子，重生不过是换了个开头。

前接：[11-初遇与确立 · 第一眼](11-初遇与确立.md#一--第一眼)（正常版对照）
后接：[二 · 上一世欠他的](#二--上一世欠他的) · [十 · 知道结局的人](#十--知道结局的人)

#### 示例（本库自撰，可直接改写）

> 「你好，」她说，「初次见面。」
> 这四个字她在楼下练了四十分钟。难的不在说出口，在说的时候别哭。
> 他伸过手来。这只手她太熟了，虎口有道疤——不对，现在还没有。那道疤是三年后的事。
> 「你的咖啡，」服务生问，「加糖吗？」
> 「不加，他胃不好——」她听见自己说到一半，硬生生拐了个弯，「……我猜的。你看着像胃不好的人。」
> 他笑了：「你猜得真准。」
> 准，她想，我拿一辈子换的准。

## 二 · 上一世欠他的

`T` ｜ 无预警 ｜ 重生 ｜ 语料频次：重生 8.0%

**骨架**｜上一世欠他的，这一世加倍对他好，一半是真心喜欢，一半是还债。

#### 节拍链

带着愧疚醒来 → 列偿还清单（按她的风格来）→ 一项项去做 → 他受宠若惊 → 某天他察觉这份好里还有别的东西 → 「你是不是在还什么」→ 摊牌，或者继续瞒

#### 时间轴

**偿还清单就是钟。** 上一世漏掉的生日、错过的演出、没兑现的旅行，她一项项补。补到清单见底的那天，问题来了：还完了，然后呢。

#### 债的类型

| 上一世的亏欠 | 这一世的补法 | 陷阱 |
|---|---|---|
| 忙到忽略他（最常见） | 这一世推掉一切准时回家 | 光补时间没用，他要的是人，不是打卡 |
| 没说过那三个字 | 这一世说得很勤 | 说得太勤反而假，他起疑 |
| 他为她挡过一次灾 | 这一世提前拆掉那个灾 | 拆灾改时间线，蝴蝶效应反噬 |
| 到最后才明白心意 | 这一世第一天就对他好 | 没来由的好最招人疑心 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 清单 | 手账最后一页，只有她看得懂的缩写 · 划掉一项那笔特别用力 |
| 他的困惑 | 「我生日你怎么知道」「你怎么知道我想去这」——她借口快编不下去了 |
| 察觉 | 他发现这些好全踩在他没说过的心愿上，跟抄了答案似的 |
| 那句话 | 「你对我好得……像在赔罪。」他说中了，她端杯子的手顿住 |

「好得像在赔罪」是这条的引爆句：债务式的爱有股味道，被爱的人闻得出来。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 债的重量 | 不当回事 | 他上一世替她死，这一档的偿还清单只有一项：让他活 |
| 摊牌 | 实话说了，他信不信是下一场戏 | 没说，把债捂成了纯粹的情 |
| 清单见底 | 还完才发现早不是在还了 | 还完那天她慌了：没有清单她不知道怎么爱人 |
| 他的态度 | 接受这份好 | 明说「我不要你还，我要你在」 |

「没有清单她不知道怎么爱人」，她的性格底色直接照进设定：连赎罪都要项目化。可项目会结项，感情不会。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 划掉清单最后一项那晚的空 | 「像在赔罪」说出口后她的表情 |
| 内心 | 还完了。可我停不下来了。 | 我不要答案抄写员，我要她 |
| 好的处理 | 她最终把清单给他看了，包括没还上的那几项 | 他收下清单，撕了，说「重写，写往后的」 |
| 写崩 | 写成无限内疚循环 | 写成他利用愧疚 |

「撕了，重写往后的」，他把偿还型关系当场改成了预付型。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 上一世她负他另娶高门，这一世聘礼抬到他家那天，他家还没缓过神来 |
| 修仙 | 上一世拿他的本命精血续了道基，这一世她把半副道基还了回去 |
| 星际 | 上一世她下令撤退，把他那艘舰丢下了，这一世她把旗舰停靠位改到他编队旁边 |

#### 写崩的三种方式

1. 债务永远还不清。清单必须见底，见底之后的慌才是正文。
2. 他全程蒙在鼓里。「像在赔罪」那句必须响。
3. 愧疚全写成爱了。撕清单那场得把这两样切开。

## 三 · 双重生

`T` ｜ 无预警 ｜ 重生 ｜ 语料频次：重生 8.0%

**骨架**｜俩人都重生了，都以为只有自己记得，全在装。

#### 节拍链

各自醒来 → 各自定策（都决定瞒）→ 「初见」（两个影帝同台）→ 互相发现破绽 → 各自试探 → 揭穿的那一刻 → 相认

#### 时间轴

**双线并行的猜疑链**：他发现她「猜」得太准，她发现他躲她该躲的劫躲得太熟。破绽攒到临界点，谁先开口验证，谁先输，也先赢。

#### 破绽对照表

| 她露的 | 他露的 |
|---|---|
| 知道他的忌口（上一世学的） | 提前绕开了那个骗局（上一世栽的） |
| 在他旧伤复发前备好了药 ✓ | 在她项目暴雷前劝她撤了资 |
| 叫错一个只有上一世才有的称呼 | 对一首「还没发行」的歌跟着哼 |

**跟着哼还没发行的歌**是双重生文的经典破绽规格：小、硬、无法解释。

#### 可用细节

| 类 | 内容 |
|---|---|
| 演技 | 两个人把「初识」演得滴水不漏，只有对方看得出漏 |
| 试探 | 她故意提了一个上一世的地名，看他睫毛抖了一下 |
| 揭穿 | 「这首歌下个月才发。」他僵住。她续道：「我也是听你哼才会的。上一世。」 |
| 相认 | 没有拥抱大哭，先是长久的沉默，然后有人笑了：「演了三个月，累不累」 |
| 相认后 | 对答案：各自的上一世死于哪年哪件事——两份记忆拼出全图 |

「对答案」是双重生独有的场面：两个人的上一世不完全重合，拼图时发现对方替自己瞒过的事。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 记忆 | 同一条时间线 | 两条不同的上一世，拼图时三观震碎 |
| 谁先识破 | 她 | 他，他这辈子头一回比她先看明白一件事 |
| 相认时点 | 三个月 | 拖了三年，各自揣着秘密结了婚，婚礼上都在琢磨「对方到底知不知道」 |
| 相认后 | 同盟 | 分歧：两人想改的事不一样，甚至对着干 |

「想改写的事互斥」是这条的高阶冲突：她想救的人恰是他上一世的仇。两份未来打架。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他睫毛抖的那一下 | 「上一世」三个字从她嘴里说出来 |
| 内心 | 要是他也是……那上一世最后那天，他是故意的 | 她也在。她一直都在。 |
| 好的处理 | 她验证前先想好了「他不是」的退路 | 他揭穿时选的是那首歌，不是更重的事 |
| 写崩 | 写成双方无限装傻 | 写成相认后全知无敌 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 洞房夜却扇，两人同时说出上辈子说过的话，扇子掉地上 |
| 修仙 | 一起兵解重修，论道时招招像练过千百遍，长老看得一头雾水，说这哪像头回见面 |
| 星际 | 时间线被重置过的两个实验体，数据库里两人记录挨着号，谁也没点开过对方那条 |

#### 写崩的三种方式

1. 一见面就互相认出。猜疑链至少三轮。
2. 演技写崩成明演。破绽要小到只有对方看得出来。
3. 相认拥抱痛哭。先沉默，再对答案，哭放最后。

## 四 · 剧情开始偏移

`T` ｜ 无预警 ｜ 穿书 ｜ 语料频次：穿书 23.0%

**骨架**｜她看过这本书。可眼前这个男配，压根没按第三章的剧本来。

#### 节拍链

按原著预判 → 第一次小偏，还能圆回来 → 第二次偏，圆不回来了 → 发现剧情彻底失控 → 回头查原因 → 查来查去，问题出在她自己身上 → 认了：书是没了，但人是真的。

#### 时间轴

**以「原著章节」当闹钟用**：第三章他该在宴会上碰见女主，第七章他该黑化。每到一个节点，她就掐着表等，结果剧情一次比一次跑偏。

#### 偏移的三个阶段

| 阶段 | 现象 | 她的反应 |
|---|---|---|
| 小偏 | 台词变了几个字 | 「记忆误差吧」 |
| 中偏 | 他没在该出现的场合出现，因为他在她这儿 | 开始翻自己带来的「原著笔记」 |
| 大偏 | 原著里他此刻该恨的人，他在替她挡刀 | 笔记撕了 |

**撕笔记是这条的仪式动作**：承认预测失效，等于承认眼前人不是纸片、是活的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 笔记 | 她凭记忆默写的「剧情大纲」，锁在抽屉最里层（接 [15-秘密与坦白 · 他有一件事没说](15-秘密与坦白.md#一--他有一件事没说)的她版） |
| 掐点 | 原著名场面的日子她全记着，一到那天就绷着 |
| 偏移实感 | 他说了句原著里没有的话，比原著哪句都强 |
| 归因 | 就是她扇的风：她多看的每眼都在改他 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他在原著里 | 男配（炮灰） | 反派，她来之前只要躲他，现在得改他 |
| 偏移方向 | 变好 | 更糟：她插手太早，黑化提前触发，赎罪线开了 |
| 笔记 | 撕了 | 被他发现了（转 [七 · 攻略对象不按剧本](#七--攻略对象不按剧本)的对质） |
| 她的立场 | 顺着偏 | 拼命掰回剧情，她怕偏出结局，后面全是未知 |

「拼命掰回剧情」这头有股狠劲：**她明知道前面是坑，还是往坑里跳**——这个错选，比选对好看多了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 撕笔记那一下 | 她总在某些日子神经紧绷，像在等一场只有她知道的雨 |
| 内心 | 书里没这句，书里也没你这么看我 | 她好像随时准备着替我挡什么 |
| 好的处理 | 她把“原著粉滤镜”一层层摘下来，写足这个过程 | 他的偏移有自己的逻辑，不是为她而偏 |
| 写崩 | 写成她拿剧透当遥控器 | 写成他人设崩塌服务剧情 |

「他的偏移有自己的逻辑」是这条的尊严线：他变好，是因为这一次有人把他当人，跟女主光环照没照到他无关。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 穿进一卷话本，说书人讲的段子一个个没影，说书人自己都犯嘀咕 |
| 修仙 | 穿进一部道门秘史，天机算一次错一次，掌门觉得天道出了岔子 |
| 星际 | 穿进一部舰队编年史，书里写的打仗日子到了，仗没打起来 |

#### 写崩的三种方式

1. 剧情永远精准。偏移就是这条的题眼。
2. 偏移无因。每次偏移都要能倒查到她的某个动作。
3. 撕笔记太早。三个阶段一个不能省。

## 五 · 原主的影子

`T` ｜ 无预警 ｜ 穿书 ｜ 语料频次：穿书 23.0%

**骨架**｜她以前对他不好。如今他看她的眼神，有一半还落在原来的她身上。

#### 节拍链

穿来 → 接收原主的烂摊子（他眼里的戒备）→ 她按自己的方式待他 → 他困惑（「你变了」）→ 「变了」的解释压力 → 他爱上的是谁的问题浮出 → 处理

#### 时间轴

**他的戒备消退速度就是钟。** 第一个月他躲她的手，第三个月他不躲了，第六个月他问出那句：「你到底是谁？」

#### 这条的哲学题（要落成具体的戏）

「他爱上的是这具身体的原主，还是穿来的她」，别让它停在内心独白，落到三场戏：

| 戏 | 内容 |
|---|---|
| 旧物戏 | 他收着原主给的一样旧东西，原主难得的一次好，她看见，吃了一场没有对手的醋 |
| 习惯戏 | 原主爱用的香、口头禅，她一样都没有。他有天说「你现在这样挺好」，一句话给她落了户 |
| 摊牌戏 | 「你从什么时候开始觉得我不一样的」——他报出的日期，就是她穿来那天 |

**他报出穿越当天的日期**，这招是终极糖。他没什么超自然本事，就是纯粹盯着她看，把换人的那一秒记得死死的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 原主遗产 | 一屋子她看不懂的东西 · 一个她圆不上的旧承诺 · 几个等着看她笑话的旧敌 |
| 演砸 | 她学原主的签名总差一点 · 管家看她的眼神多了点什么 |
| 戒备消退 | 他从「站三步外回话」到「递东西时手指敢碰到」 |
| 那句户口 | 「你现在这样挺好」——他不知道这句话对她意味着什么 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 原主对他 | 很差（她接手赎罪局） | 很好，她接手高分答卷，压力反而更大 |
| 原主下落 | 人没了 | 还会回来，她占的是别人的位子和别人的爱人 |
| 摊牌 | 说了穿越真相 | 只承认「我确实变了」，真相烂在肚里 |
| 他的选择 | 爱现在的 | 他分不开，也拒绝分：「都是你」 |

「原主还会回来」这一端把糖变成了倒计时：**她越幸福，越接近归还日。**

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 那句「你现在这样挺好」 | 报日期时她脸上的震动 |
| 内心 | 我是在替一个陌生人被爱，还是真在被爱 | 那天起她眼里有了光。管她是谁，光是真的 |
| 好的处理 | 她吃原主的醋这场写足，荒诞又真实 | 他连日期都记得清清楚楚，但从来不追问 |
| 写崩 | 把原主写成纯工具人 | 写成他换人跟换衣服似的，一点不难受 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 穿成苛待夫郎的恶主母，全府下人替他捏着汗，慢慢变成看不懂的眼神 |
| 修仙 | 夺舍疑云，他是唯一觉得「夺舍了也比原来那位好」的人，这想法让他愧疚 |
| 星际 | 意识上传错位，他对着生物特征完全一致的她说「你的脑波不一样了」 |

#### 写崩的三种方式

1. 原主写成纯背景板。 原主留下的东西得一直碍事，时不时冒出来扎一下。
2. 「你是谁」这个问题别绕。 至少摊牌那场戏得正面怼一次，不能躲。
3. 哲学题一直悬着没解决。三场戏一场都不能省，全得写透。

## 六 · 系统的任务与她的真心

`T` ｜ 无预警 ｜ 系统 ｜ 语料频次：系统 7.0%

**骨架**｜系统提示：攻略目标好感度+10。她忽然分不清刚才那句关心，是任务，还是真心。

#### 节拍链

绑定系统 → 接任务（攻略他）→ 按攻略行事 → 好感度上涨 → 某天她做了一件任务外的事 → 系统没加分，她却更高兴 → 任务和真心的账算不清了 → 摊牌或反抗系统

#### 时间轴

**好感度数值就是钟**：但这条的戏在数值失灵的地方。+10、+20 一路涨，涨到某天她为他做了件系统判定「无效」的事，那个 +0 比所有加分都重。

#### 「被安排的爱怎么变成真的」三步

| 步 | 现象 |
|---|---|
| 执行 | 每句话都奔着任务去，说完还得瞟一眼面板 |
| 混淆 | 话都说出去了才想起看面板，顺序颠了 |
| 反抗 | 系统提醒「这么干耽误任务」，她压根不当回事 |

**「说完才想起看面板」是转折点**：任务动作与真心动作的分界，就在看面板的时机。

#### 可用细节

| 类 | 内容 |
|---|---|
| 面板 | 只有她能看见的浮窗 · 好感度进度条 · 任务倒计时 |
| 系统的声音 | 机械提示音专挑不该响的时候响：他告白到一半，系统来一句「主线任务完成」 |
| +0 事件 | 他重病她守了一夜，面板一点动静没有——原来守夜不算任务 |
| 反抗 | 系统说「离远点好做任务」，她直接把面板设成了免打扰 |
| 隐瞒 | 他不知道她看得见面板，她老往空气里瞟，他都记在心里了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 任务目标 | 攻略他 | 更冷的：利用他，真心太贵，付不起 |
| 系统性质 | 工具 | 有自己的算盘，反抗升级成对抗 |
| 他知不知道 | 不知道 | 后来知道了：「所以你哪句是真的」——这条问题链交给 [15-秘密与坦白 · 掉马](15-秘密与坦白.md#二--掉马)的规格处理 |
| 结局 | 完成任务且是真心 | 为真心放弃任务奖励（回家的机会） |

「所以你哪句是真的」是系统文必须正面回答的问题，标准答案只有一个：**「看面板之前说的那些。」**

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 那个 +0 | 她瞄向空气的第一百次 |
| 内心 | 加分的没一句真话，真话一句不加分 | 她总在看一个不存在的地方，像在跟谁对账 |
| 好的处理 | 免打扰那一下干脆利落 | 他早就发现了异常，选择等她自己说 |
| 写崩 | 写成数值游戏攻略 | 写成他知道后一票否决全部感情 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 接了懿旨去他身边，家里给派的活，差事办完那天她把赏赐退了 |
| 修仙 | 师门让她跟他双修采补，她偏把功法改成两人都受益的路子 |
| 星际 | 芯片直接种进脑子，她去做手术摘了，代价是军功全抹掉 |

三个换皮同一句话：把「组织安排」写成系统，古今通用。

#### 写崩的三种方式

1. 面板戏别抢人戏。数值就三个地方冒头：起涨、+0、免打扰。
2. 系统别随随便便就没了。反抗得付出代价，得标个价。
3. 他知道了之后，对问题躲躲闪闪。但「哪句是真的」这句，必须给个准话。

## 七 · 攻略对象不按剧本

`T` ｜ 无预警 ｜ 穿书 · 系统 ｜ 语料频次：穿书 23.0% ＋ 系统 7.0%

**骨架**｜攻略手册说他吃温柔小意这套，他不吃，反手把她那些套路一条条全拆了。

#### 节拍链

按攻略出招 → 无效 → 换策略 → 又无效 → 他反问一句直球 → 她乱了 → 弃攻略改真人打法 → 起效了，且她已分不清打法和真心

#### 时间轴

**攻略手册的策略条目就是回合制**：温柔攻势，败。欲擒故纵，败。英雄救美，他自己解决了。每败一条划掉一条，手册划完，戏进入正文。

#### 他为什么免疫

| 攻略预设 | 他的实况 |
|---|---|
| 「他缺关爱，温柔即可攻陷」 | 他缺的不是关爱是尊重，温柔里掺没掺假，他一闻就出来 |
| 「制造英雄救美」 | 他自己能摆平，还反手把她安排的「危机」查了个底朝天 |
| 「欲擒故纵」 | 她三天没理他，他认认真真跑来问「我哪做错了」，把套路问成了事故 |
| 「投其所好」 | 资料上他的爱好是原主瞎编的，全对不上号 |

**「把套路问成事故」的直球**是这条的拆招美学：套路怕认真，一句认真的「为什么」能拆掉整本手册。

#### 可用细节

| 类 | 内容 |
|---|---|
| 手册 | 系统面板上的「攻略建议」 · 或她自己默写的原著人设卡 |
| 拆招现场 | 她递上「偶遇」的伞 ✓，他说「你跟了我三条街」 |
| 乱拍 | 直球问出来那刻她所有台词库清空，说了句大实话，好感度暴涨 |
| 复盘 | 面板显示：有效行为=全部计划外行为 |

「有效行为=全部计划外」，系统替她做了总结陈词。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他免疫的原因 | 天生敏锐 | 他重生／他也穿了（接 [三 · 双重生](#三--双重生)，攻略者撞上攻略者） |
| 她的调整 | 弃套路 | 套路升级，一路输到底才肯弃，更好笑也更真 |
| 他的态度 | 拆招但不点破 | 当面点破：「下次直接说，别绕」 |
| 结局 | 真人打法奏效 | 他早就沦陷了，忍着看她表演，最后这条由他坦白 |

「他早沦陷了忍着看表演」是这条藏的糖底：免疫是假的，舍不得点破是真的。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 台词说完了，最后冒出来的那句真心话 | 她说「你跟了我三条街」那会儿，脸上啥表情 |
| 内心 | 这人咋不按常理出牌，打都不按套路来 | 她那些招数里带着股认真劲儿，招数本身倒没啥 |
| 好的处理 | 她输得难看，但输得敞亮 | 他接招从不让人难堪，接完了还给人留面子 |
| 写崩 | 写成翻来覆去就那几个套路 | 写成他啥都看得透，跟开了天眼似的 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 照着《驭夫策》来，他从她枕头底下抽出那本书，翻到折角那页，直接念 |
| 修仙 | 按魅心诀下套，他练的正好是不动心咒，两套功法撞一块儿了 |
| 星际 | 照心理侧写报告套近乎，他反手把她那份报告调出来：「咱俩换着看？」 |

「交换着看」，星际版把拆招写成了平等条约。

#### 写崩的三种方式

1. 套路用一次就扔。 至少得让主角连输三回。
2. 他凭啥免疫，得交代清楚。 敏锐也得有原因。
3. 戳穿了关系就僵了。 戳穿之后正确的做法是「下次直接说」。

## 八 · 快穿的每一次告别

`T` ｜ 无预警 ｜ 快穿 ｜ 语料频次：系统 7.0% ＋ 告别 37.0%

**骨架**｜任务完成，走人。每个世界的最后一刻，她都没敢回头。

#### 节拍链

任务进度 99% → 她开始沉默 → 完成瞬间倒计时启动 → 告别，或者来不及告别 → 白光 → 新世界睁眼 → 上个世界的余温还在

#### 时间轴

**以「世界」为章节单位的循环钟**：每个世界几个月到几年，结尾都是同一个倒计时。循环本身就是钝刀。读者跟她一样，越甜越慌，早早就开始难受。

#### 快穿告别的三种规格

| 规格 | 场面 |
|---|---|
| 来得及的告别 | 她提前说「我要走了」，对方不信，直到她在他眼前变淡 |
| 来不及的告别 | 任务在拥抱里突然算完成，白光起来时，她手还停在他背后没落下 |
| 不告而别 | 她趁他睡着时走的，最心软也最狠的一种 |

#### 这一族与「同一个魂」的钩子

快穿文的通行设定：**每个世界的「他」是同一个灵魂的碎片**。这个钩子决定告别的性质：

| 设定 | 告别的意味 |
|---|---|
| 各世界独立 | 每次都是真死，她攒了一身丧气 |
| 同魂碎片 | 告别是「下个世界见」，但下个他不记得她——每回都得重新追一遍 |
| 最后拼合 | 终章碎片全归位，那个他带着所有世界的记忆看她：「你欠我十七次告别」 |

「你欠我十七次告别」是快穿文的终极清算句。

#### 可用细节

| 类 | 内容 |
|---|---|
| 倒计时 | 只有她看得见的数字 · 日子越过越好，数字就跳得越快，不知是系统搞鬼还是她看花了眼 |
| 带不走 | 啥也带不走，她就靠记，把他每个世界的样子都记在脑子里 |
| 余温 | 一睁眼到了新地方，手上还留着上个世界牵过的热乎劲儿，三分钟就散了 |
| 沉默期 | 任务做到 99% 她突然不吭声了，他觉出不对劲，问：「你要去哪」 |

「越幸福数字走得越快」，不管是不是错觉，写出来就成立。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 告别规格 | 来得及 | 三种轮着用，每个世界换一种，痛感不重样 |
| 他 | 独立灵魂 | 同魂，最后算总账 |
| 她的策略 | 每个世界都认真爱 | 从某个世界起不敢再动心，下个世界的他偏偏最难缠 |
| 终局 | 拼起来团圆 | 她留在了某个世界，没做完任务的代价她认了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 白光起来，手悬在半空没落下去 | 那句“你要去哪”刚问出口，她笑得比哭还难看 |
| 内心 | 记住了。这个角度也记住了。 | 她看我的眼神，像在看倒计时 |
| 好的处理 | 她告别的话越说越短，可疼一次比一次久 | 最后一章那笔账，留给他，让他自己算 |
| 写崩 | 虐点跟流水线似的，一套一套 | 每个世界的他，都长一个样，没区别 |

#### 换皮

快穿本身就是个换皮机器，这条不用单独列换皮表——它的每个任务世界就是 [10-换皮对照](10-换皮对照.md) 的实弹演习场。古代女尊位面用 20 卷，星际位面用 21 卷，逐卷取用就行。

#### 写崩的三种方式

1. 每个世界等长等重。详写两个，中间的用「第九个世界，秋天」一笔带过。
2. 告别的痛感复制粘贴。三种规格轮换。
3. 终章清算轻轻放过。十七次告别的账，一次结清，结足。

## 九 · 失忆后重新认识

`T` ｜ 无预警 ｜ 失忆 ｜ 语料频次：失忆 9.0%

**骨架**｜他睁开眼，不认识她了。医生说别刺激他。她把婚戒摘下来，说：「你好，我是你的主治联系人。」

#### 节拍链

事故 → 醒来不认人 → 医嘱，不可强行灌输记忆 → 她降级成「陌生人」→ 第二次追妻从零开始 → 记忆碎片回闪 → 恢复或不恢复

#### 时间轴

**两条进度条赛跑**：新感情的进度 vs 旧记忆的恢复进度。最好的写法是让新感情跑赢——记忆恢复之前，他已经第二次爱上她了。

#### 可用细节

失忆版的独门场面，别的条目搬不走：

| 场面 | 戏 |
|---|---|
| 自我介绍 | 她练了一晚上「初次见面」，比 [一 · 重生后的第一面](#一--重生后的第一面)的她还难——那位好歹有一世准备 |
| 习惯出卖 | 他不记得她，手却记得：递东西自动递到她顺手那侧 · 睡着后朝她的方向翻身 |
| 醋 | 他对「探望的陌生美女」起了心思，问护士她有没有对象——护士憋笑憋出内伤 |
| 旧物审讯 | 他翻到合照 ✓：「这男的是我？旁边这是……」她面不改色：「你朋友。」 |
| 回闪 | 某个动作触发碎片：她挽头发的手势让他头痛欲裂，也让他红了眼眶，不知为何 |

**「手记得」是这条的科学抒情**：陈述性记忆没了，程序性记忆还在——爱过的证据存在肌肉里。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁失忆 | 他 | 她。最狠的一版：说「初次见面」的换成她，他连夜把她工作上的活儿全学会了，就为了能挨着她 |
| 忘的范围 | 全忘 | 只忘了她一个人，医学上叫选择性遗忘，说白了就是专挑最疼的忘 |
| 她的策略 | 从零开始追 | 听医生的话远远看着（忍不过三天） |
| 结局 | 记忆回来，两段感情算总账 | 没回来，婚戒重新求了一次，同一枚戒指 ✓ 求了两次 |

「只忘了她一个人」这一端要想好再用：它把「你对他是什么」这个问题问到了生理层面。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 摘婚戒那一下 | 那个「陌生人」挽头发的手势让他心里一酸 |
| 内心 | 第二次追他。上次追了三年。 | 我干嘛想对她好，才认识六天 |
| 好的处理 | 她不用手段：知道他的软肋，但一个都不碰 | 他第二次心动有自己的路子，不是照搬第一次 |
| 写崩 | 写成她翻出旧照硬逼他回忆 | 写成失忆只撑了三章就完事 |

「知道所有软肋一处不用」，她把信息不对称的牌全扣着，打明牌。这是失忆文里她能给出的最高敬意。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 坠马失忆，她从主君降为「照看他的贵人」，全家陪她演戏 |
| 修仙 | 断尘缘的忘情水被人动了手脚，她一剑挑了那下药的宗门，回来接着陪他「头回见」 |
| 星际 | 冬眠舱出毛病，记事的扇区坏了，数据能重装，她不肯：「让他自己挑一回。」 |

「数据可重灌，她拒绝」，星际版把这条的伦理题亮在明面：恢复他，还是尊重现在的他。

#### 写崩的三种方式

1. 失忆就当短期波折。至少给一整卷的长度。
2. 靠旧物轰炸恢复。恢复得从肌肉和碎片里来，不是说教两句就行。
3. 记忆回来后新感情作废。两段感情要合账，不能覆盖。

#### 可串接

前接：[五 · 原主的影子](#五--原主的影子)。同一句“你爱的是谁”，两条路走法完全不同。
后接：[11-初遇与确立](11-初遇与确立.md)。整卷套路复用，失忆后的追法，就是把初遇十条再跑一遍，只不过这次手里攥着旧档。

## 十 · 知道结局的人

`T` ｜ 无预警 ｜ 重生 · 穿书 ｜ 语料频次：重生 8.0% ＋ 穿书 23.0%

**骨架**｜她知道他四年后的冬天会死，于是她一天天数着日子，那个圈一天天收拢。

#### 节拍链

带着结局生活 → 日常越甜，暗线越沉 → 布局改命 → 中途的假警报 → 那一天来了 → 改写成功或失败 → 之后

#### 时间轴

**全书最长的倒计时。** [一 · 重生后的第一面](#一--重生后的第一面)埋的那个圈，走到这儿正好合上。日常戏全带着倒计时滤镜，他笑得越没心没肺，读者越疼。

#### 已知结局的三种态度

| 态度 | 她的做法 | 风险 |
|---|---|---|
| 硬改 | 提前把要命的事拆掉：那辆车、那场病、那个人 | 命运会找补：拆了这头，那头又冒出来 |
| 备份 | 没把握真能改，就先把每天过好 | 「向死而爱」太重，日子全过成了告别预演 |
| 摇摆 | 两头都干，还互相打架 | 最真实：想改命的她跟认命的她天天吵 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 那个圈 | 日历 ✓ 上的记号他见过，问是什么日子，她说「发薪日」 |
| 布局 | 她提前三年就开始铺路，桩桩件件都装成普通决定：搬家、换医院、辞掉那份老出差的工作 |
| 假警报 | 提前两年有过一次差不多的苗头，她当场就绷不住，反应大得离谱——他记住了这回事 |
| 那一天 | 从零点开始她就不让他离开视线，他被看得发毛：「今天什么日子？」「……发薪日。」 |
| 之后 | 零点过了，他睡着，她在床边坐到天亮，把那个圈涂掉——涂了很多遍 |

「发薪日」两次出现是这条的暗号结构：同一个谎，第一次是伏笔，第二次是决战宣言。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 改写结果 | 成了，涂掉那段是全书最戳人的地方 | 半成：人留下了，代价挪了个地方落（接 [16-危机与保护](16-危机与保护.md)） |
| 他知情否 | 从头到尾不知道 | 中途晓得了：「所以你这三年的每一天都是……」他说不出口 |
| 结局来源 | 上一世亲身经历 | 书里看的，她盼着「书是假的」，盼头和证据来回拉扯 |
| 之后 | 倒计时没了，学着像普通人那样「不知道」 | 新的圈：续集她没看过，头一回碰上未知——她反倒松了口气 |

「未知降临她如释重负」是这条的终极出口：知道结局是诅咒，不知道才是普通人的福气。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 涂掉那个圈，涂了很多遍 | 「发薪日」第二次出现时她的眼神 |
| 内心 | 过了今晚，我就跟所有人一样了 | 她身上有件事压了很多年，压痕我看得见 |
| 好的处理 | 布局全藏在日常里，一件都不点破 | 他知情后没怪她瞒着，他数了数那三年她做的事 |
| 写崩 | 写成啥都知道 | 写成结局想改就改 |

「他数了数那三年她做的事」，搬家、换医院、辞职，桩桩重新对焦，原来全是为他。这一段是已知结局文的标准泪点，值得写满。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她重生回来，知道他哪天战死，花了三年，把粮道、将令、天气全给他改了 |
| 修仙 | 天机阁说他有个死劫，她拿自己修为往里填，硬给他把劫挪走了 |
| 星际 | 史书上写他那艘舰要毁在那仗，她一路升到能改调令的位子——升一级，救一回人 |

「升职线全是救人线」，星际版把她的事业心翻译成了情书。

#### 写崩的三种方式

1. 倒计时中途泄压。那个圈的重量得攒到最后一晚才爆。
2. 改命不用付钱。但这类设定里，天底下没有白吃的午餐，拿多少迟早得还。
3. 他知道了也没当回事。可那三年的账，他一件件跟你算。
