# 校园与青涩

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 现代校园（大学及以上）
> 频次数据来自[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，统计基数是 2,894 部独立作品。文里的百分比是编写时实测的，挖掘器扩充后节拍族会有小幅变动，最新数字以 13-07 为准（用 `run.py mine` 重跑更新）
> 本卷全部条目设定在**大学及以上学段**，全部角色均为成年人。
> 这一族收大学校园里的桥段：学姐、招新、图书馆、考前辅导、运动会、食堂、她先毕业、没署名的信、毕业典礼、多年后回学校。校园里的位置差到毕业就到期，从入学第一天起就在倒数。

## 校园 GB 多给了什么

「学姐学弟」算得上姐狗文的半个起源地。这套设定带来三样别处没有的东西：

| 给的 | 说明 |
|---|---|
| 现成的位置差 | 高年级对低年级，天然就是“她在前他在后”，用不着解释 |
| 现成的称呼 | “学姐”离“姐”只差一步，接 [27-年龄差与姐弟](27-年龄差与姐弟.md#二--姐这个字) |
| 一个倒计时 | 她先毕业，这点位置差最多撑两三年，到期就没了 |

三样里倒计时最要紧。职场上下级能共事十年，学姐学弟拿了毕业证就散，所以校园 GB 天生是倒计时叙事。

| 节拍族 | 占比 |
|---|---:|
| 初见 | 38.0% |
| 接送 | 37.0% |
| 教导 | 14.0% |
| 聚会 | 12.0% |

## 一 · 学姐

`G` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：初见 39.9%

**骨架**｜他第一次叫她学姐，后来这两个字一叫好些年，意思换了好几轮。

#### 节拍链

报到、招新或者讲座上，有人介绍「这是 X 学姐」，他就跟着这么叫，她随口应了，称呼从此定下。过了很久，同样两个字意思已经全变了。

#### 时间轴

「学姐」两个字的意思一路在变：先是敬称，后来成了熟人嘴边的习惯，再后来只剩他一个人还这么叫，到毕业多年，他改了口，又改回来。

#### 「学姐」的语义阶梯

| 阶段 | 这两个字的意思 |
|---|---|
| 刚认识 | 全院都喊学姐，他也客客气气跟着喊 |
| 熟了 | 别人都改叫名字，只有他还叫学姐 |
| 更熟 | 她让他直接叫名字，他开不了口 |
| 毕业后 | 终于叫得出名字了，偶尔漏一声学姐，那是在撒娇 |
| 多年后 | 人前叫名字，私下那声学姐是悄悄话 |

她让他叫名字，他叫不出口。称呼一天改不过来，关系就一天停在原地。同样的结构见 [11-初遇与确立 · 改口](11-初遇与确立.md#五--改口)。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 迎新点遮阳棚下，她一把拎起他的行李箱上了台阶，他在原地愣住 |
| 她当时的样子 | 白 T 恤 · 挂着工作牌 · 胳膊晒得发红 · 嗓子都喊哑了 |
| 那一把 | 这事他后来总挂在嘴上：「你当年单手拎我三十寸的箱子」 |
| 称呼 | 全篇盯住这两个字，看它每回在什么时候冒出来 |

她一把拎起他的箱子，**头一面就看出她力气比他大**，这画面抵得上十章铺垫。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 差几届 | 一届 | 三届，她大四他大一，倒计时更短 |
| 初见 | 迎新 | 更早，他高中来参观时就见过她，她不知道，到大学重逢才认出来 |
| 称呼归宿 | 变成私房话 | 他始终没改口，把改口留到某个大场合 |
| 她的印象 | 记住了他 | 她完全没印象（他一个人记了三年，接 [11-初遇与确立 · 他先动心](11-初遇与确立.md#八--他先动心)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 好多年过去，他叫她“学姐”还是当年那个口气 | 她拎箱子那一下，手臂上的线条 |
| 内心 | 迎新那天的事我早不记得了，他倒记得一清二楚 | 这两个字叫顺了口，改不回来了 |
| 好的处理 | 她顺着这个称呼陪他玩，一直不点破 | 他说不清自己为什么改不了口，干脆不解释 |
| 写崩 | 写成她摆学姐架子，处处压着他 | 写成他一见她就脸红，三年都没变 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 书院同门，她入门在先，做了师姐，戒尺也由她拿着 |
| 修仙 | 同门师姐，剑术课由她带他，「师姐」一叫就是三百年 |
| 星际 | 军校学姐，他授衔那天，肩章是她亲手别上的 |

#### 写崩的三种方式

1. 初见写她的脸多惊艳。 惊艳该落在她单手拎箱子那股劲上。
2. 一上来就叫名字。 戏都在叫不出口的那一段。
3. 学姐写成什么都压他一头。 她只比他早两年，别写成神。

## 二 · 社团招新

`G` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：初见 39.9% ＋ 要联系 19.0%

**骨架**｜他在报名表上签了名，动机栏只写「感兴趣」，动机本人站在桌子后头。

#### 节拍链

在摊位前路过 → 看见她，停下 → 装作了解这个社团 → 填表 → 她收表时多看了他一眼 → 第一次活动 → 他成了最勤快的新人

#### 时间轴

填完表到第一次活动中间隔着一周，**这一周他把社团公众号的历史推文全翻完了**。

#### 可用细节

| 类 | 内容 |
|---|---|
| 摊位 | 折叠桌 · 海报是她画的 · 她扯着嗓子喊人，嗓子都哑了 |
| 填表 | 动机栏他咬着笔杆想了半天，写下「感兴趣」 · 字比平时写得端正 |
| 破绽 | 这个社团跟他的专业八竿子打不着 · 室友当场拆穿：「你不是说这玩意儿没劲吗」 |
| 之后 | 每次布置场地都有他 · 搬水搬桌子全是他抢着干 · 她开始记住这个勤快的新人 |
| 她的视角 | 后来她翻到那张报名表，看见动机栏那三个字，笑了好半天 |

多年后她翻到这张报名表，看着那三个字，才知道他当年感兴趣的到底是什么。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 社团类型 | 她当社长，说话最管用 | 她是普通老社员，他绕了一圈才进社 |
| 他的表现 | 勤快到让人注意 | 刻意低调，只挑她看不见的时候干活 |
| 她的察觉 | 她早看明白了 | 一点没察觉，只觉得这届新人挺靠得住 |
| 结局 | 他接了社长，是她毕业前点的头 | 社团只是个开头，后来两人各忙各的 |

「她毕业时把社长的位置点给他」：**她走后空出的位置由他来坐**，相当于校园里的「交出去」（呼应 [07-馈赠与仪式 · 交出去](07-馈赠与仪式.md#六--交出去)）。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 这个新人搬完水一句话也不说 | 报名表递过去她指尖一抖 |
| 内心 | 顺手，而且一直在 | 她没认出我，也行 |
| 好的处理 | 她按本事用他，看穿了也不躲 | 他干活是真卖力 |
| 写崩 | 写成她把他当苦力使 | 写成他卧底追妻 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 诗社文会上他递了行卷，她批了个「可」 |
| 修仙 | 外门招杂役弟子，他报了名，专挑她那座峰 |
| 星际 | 战术小队招新，他第一志愿没填王牌队，填的是她那队 |

#### 写崩的三种方式

1. 动机当场被拆穿。 那张表该压着，压到多年后再翻出来。
2. 他光干活不长进。 社团这条线得让他真学到东西。
3. 她什么都知道。 先让她美上一阵，觉得「这届新人好用」再说。

## 三 · 图书馆

`G` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：教导 14.5% ＋ 睡着 55.9%

**骨架**｜同一张桌子各看各的书，三个月了，谁都没说破。

#### 节拍链

偶然同桌 → 第二次「偶然」→ 默契成了固定座位 → 有了占座的暗号 → 有一方没来的那天 → 说破，或者接着不说破

#### 时间轴

**按自习季来算。** 从期中到期末，一张桌子从陌生人拼着用，变成「我们的位置」，中间可以一句话都没说过。

#### 无声系统

整条可以没有一句台词，话都由物件来说：

| 物件动作 | 意思 |
|---|---|
| 一本书压在对面座位 | 这位置有人了 |
| 一瓶没开的水放在对面 | 今天谢了／别客气 |
| 她的外套 ✓ 搭在他椅背 | 她去倒水了，帮看一下 |
| 一张便签：「三点有课，先走」 | 头一回留话 |
| 便签被夹进对方书里带走了 | 这话他收起来了 |

三个月一句话没说，打破沉默的是一张二十字的便签。

#### 可用细节

| 类 | 内容 |
|---|---|
| 环境 | 翻页声 · 键盘声 · 占座文化 · 闭馆音乐 |
| 睡着 | 他趴在桌上睡着，醒来发现书上盖着她的围巾 ✓（睡着 54%） |
| 破绽 | 他的专业书明明在别的楼层，人却总往她这层跑 |
| 缺席 | 她保研答辩那天没来，他对着空位子怎么也坐不住，晚上那张便签写了又撕 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先占谁的座 | 他蹭她的固定座 | 她是后来的，不知道那是他蹲了很久的位子 |
| 沉默期 | 三个月 | 一整年（极限拉扯） |
| 说破方式 | 便签 | 闭馆时下了场雨，两人共撑一把伞（接 [18-节令与天候 · 下雨](18-节令与天候.md#一--下雨)） |
| 结局 | 说破 | 直到毕业都没说破，毕业十年后在同学会上才对上（转 [十 · 多年后回学校](#十--多年后回学校)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他醒来时书上盖着她的围巾，她装作在看书 | 座位空着的那天，他才发觉这三个月不是习惯 |
| 内心 | 说破就要负责，先这样吧 | 她今天没来。她为什么没来。 |
| 好的处理 | 她的便签只写正事，落款处画个小勾 | 他把每张便签都夹进同一本书 |
| 写崩 | 写成她钓了他三个月 | 写成他偷拍跟踪她 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 藏书楼里同一张书案，她的镇纸总压着对面那卷书 |
| 修仙 | 藏经阁里同一个蒲团，两人的剑在架上越放越近 |
| 星际 | 资料舱的固定终端位，两人登录的时间线严丝合缝 |

「两人的登录记录时间线严丝合缝」：到了星际版，三个月的默契成了一份能调出来的数据。由谁调、在什么场合摆出来，戏就加在这里。

#### 写崩的三种方式

1. 太早说破。 至少要沉默两个月。
2. 塞大段内心独白。 话交给物件去说。
3. 便签写成了情书。 二十个字只写正事，落款画个勾。

## 四 · 考前辅导

`G` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：教导 14.5%

**骨架**｜她给他补了两个礼拜高数，后来才发现他英语说得比她还溜。

#### 节拍链

他眼看要挂科 → 开口求人（比表白还难）→ 定下辅导时间 → 她怎么教（不哄，只纠错）→ 出成绩 → 反过来发现他也有能教她的东西

#### 时间轴

**一路倒数到考试日。** 离考试 21 天、14 天、7 天、前一晚，每一档气氛都不同，前一晚那次辅导拖到楼管来赶人。

#### 与 [11-初遇与确立 · 她教他](11-初遇与确立.md#六--她教他) 的分工

那条写「教」这个动作里的权力关系，这里写只有校园才有的几样：

| 校园特有 | 说明 |
|---|---|
| 开口求助 | 在男生宿舍的风气里，承认「我不会」是道坎，他迈过去了 |
| 成绩摆在那儿 | 教得好坏，分数一出全都看见 |
| 反向科目 | 高数她碾压他，英语口语却是他赢，校园里本事分科目，天然双向 |
| 场地 | 空教室的晚自习，粉笔灰，楼管查楼 |

他也有能教她的科目后，辅导成了双向的，位置差也就变成交换。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 草稿纸用了半本 · 她的字压着他的字批 · 红笔 · 空教室的粉笔 |
| 她的教法 | 「再做一遍」 · 从不夸，做对了直接翻页，翻页就算夸过了 |
| 他的状态 | 装懂，当场被看穿 · 他真弄懂那道题时，她眼睛亮了一下 |
| 反杀现场 | 英语角他一开口，她头一回从他脸上看到「原来你不会」的神情 |
| 结算 | 成绩一出，他跑过半个校园来报分 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 科目 | 她强他弱 | 各有各的擅长（推荐） |
| 教法 | 严 | 平时严，只破过一次例：他真崩溃的那晚，她拉他去吃了宵夜 |
| 结果 | 过了 | 还是挂了，她比他还闷，憋了半天才说「重修我再带你」 |
| 反向辅导 | 有 | 他始终没敢提，一直憋到毕业 |

「挂了她说重修我再教」这个结局别怕用。没考过，关系却进了一步，比顺利通过好写得多。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他真弄懂那道题时，她心里冒出一点说不清的得意 | 憋了三天，他才开口问「学姐能不能教我」 |
| 内心 | 教他比自己刷题累得多，可一到周三还是盼着 | 别装了，她扫一眼就知道你底细 |
| 好的处理 | 她从头到尾一句不夸，翻下一页就算表扬 | 他反过来教她时，不摆架子，也不挑刺 |
| 写崩 | 写成又骂又打的辅导 | 写成他装傻骗她来教 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她教他策论，他的诗赋反倒成了她抄写的范本 |
| 修仙 | 她教他剑法，他记的阵法笔记却被全门弟子传抄 |
| 星际 | 她带他练机甲实操，他做的理论推演帮她纠正了一个错 |

#### 写崩的三种方式

1. 只写她教他。 反过来写就是另一本小说。
2. 把她的严写成刻薄。 她的严是不夸，做对了就翻下一页。
3. 细写考试结果。 读者要的情绪出口，是他跑过半个校园去报分那场戏。

## 五 · 运动会

`G` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：起哄 43.5% ＋ 接送 37.1%

**骨架**｜一年就这一天，四百米决赛，看台上坐着她。

#### 节拍链

报名（被谁怂恿的）→ 训练 → 比赛当天 → 检录处那瓶水 → 发令枪响 → 最后一百米他往看台上找 → 冲线 → 终点

#### 时间轴

照赛程表，上午预赛、下午决赛，中间要等四个小时，比比赛本身长十倍。

#### 为什么运动会是校园 GB 的必写场

平时是他抬头看她，到了看台这儿，方向倒了过来：跑道上的事完全由他说了算，运动会还把这一幕摆到全校面前，效果翻倍。日常里占上风的总是她，这类故事就得留一天给他。[19-玩闹与网络 · 打游戏](19-玩闹与网络.md#三--打游戏)讲的也是这个道理。

#### 可用细节

| 类 | 内容 |
|---|---|
| 赛前 | 检录处她递过来一瓶水，盖子已经拧松了 ✓（拧松瓶盖是把 [29-微小仪式拾遗](29-微小仪式拾遗.md#七--拧瓶盖与够高处) 反过来用） |
| 看台 | 她本来在改论文，枪响以后论文一页也没再翻 |

`G` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：外食 15.1% ＋ 投喂 25.3%

**骨架**｜十二点的食堂，抢座拼桌，还有多打的那份鸡腿。

#### 节拍链

下课铃响，抢饭高峰开始。一个人先去占座，另一个端着两份餐盘挤过来。次数多了就成了固定饭搭子，整个食堂都看惯了他们那一桌。

#### 时间轴

## 七 · 她先毕业

`T` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：告别 38.9%

**骨架**｜她答辩通过那天，他鼓掌鼓得全场最响。掌声停了他才回过神来：倒计时已经走完了。

#### 节拍链

答辩季 → 通过 → 吃散伙饭 → 收拾宿舍 → 校门口送她 → 她走以后的校园 → 两边的节奏开始对不上

#### 时间轴

毕业季的日程是她的，倒计时是他的。 答辩、体检、离校手续，她每划掉一项，他心里就往下沉一格。

#### 这条是校园 GB 的结构性大关

开头说过，校园里的位置差有毕业期限。到期那天，三件事一起来：

| 变化 | 后果 |
|---|---|
| 学姐身份失效 | 她不再是学姐，关系里那点底气没了，两人得重新找平衡，和 [12-工作与金钱 · 他比她强了](12-工作与金钱.md#八--他比她强了) 是一个路数 |
| 空间拆开 | 她去上班或去外地读研，他留在学校，日子从一起过变成各过各的 |
| 关系定性被迫提前 | 校园恋默认“毕业就分”，他们得当面把话说开，重新给关系定个说法 |

**「毕业就分手」这句魔咒，文里要有人明说一次**，室友说或长辈说都可以，然后让两个人用行动推翻它。不提这句，这条等于白写。

#### 可用细节

| 类 | 内容 |
|---|---|
| 答辩日 | 他在楼下等，比她还紧张 · 她出来比了个 OK，他当场蹦了一下 |
| 收拾宿舍 | 四年的东西装了七箱 · 其中一箱她贴的标签写着他的名字，里面全是留给他的 |
| 校门口 | 后备箱关上的一声 · 「到了发消息」 · 车开出去，她从后视镜里看见他还站在原地 |
| 之后 | 一整个学期他都绕开她以前的教学楼走 · 食堂阿姨问起，他说「毕业了」，阿姨给他多打了一个鸡腿 |

「阿姨多打了个鸡腿」：[六 · 食堂](#六--食堂)里那位作证的旁人，到这里谢幕。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 去向 | 同城上班，隔几天见一面 | 去外地或出国（彻底分开 [02-等待与错过 · 时差与异地](02-等待与错过.md#十--时差与异地)） |
| 那句魔咒 | 室友说的 | 她自己先说出口，是给他递台阶，他没接，还把台阶拆了 |
| 他的选择 | 等，同时把自己这两年过好 | 拼命提前毕业或考研，去她的城市 |
| 多年后 | 走通了 | 没走通（转 [22-分手与复合](22-分手与复合.md)，这是校园恋诚实的结局之一） |

她先开口说毕业就分吧，他把台阶拆了。她照老规矩给他留退路，他头一回没接。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 后视镜里，他站在校门口一动不动 | 贴着他名字的那一箱 |
| 内心 | 我先去那个世界，等他两年 | 倒计时走到零，计时器换成了她那座城市的天气 |
| 好的处理 | 她不说「等我安顿好」这种空话，给的是具体日期 | 他没把等待过成干耗 |
| 写崩 | 写成她潇洒地断掉退路 | 写成他在校门口哭瘫 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她考中功名去外地赴任，他留在书院读书。路上要走三个月，家书来回一趟也要两个月，是 [21-世界设定专属 · 通讯延迟](21-世界设定专属.md#八--通讯延迟)的古代版 |
| 修仙 | 她提前出师下山历练，他修为不够，师父不许他出山门 |
| 星际 | 她授衔上舰，他还要两年才毕业。舰队和地面一周只能通一次话 |

#### 写崩的三种方式

1. 把毕业的冲击写轻了。 她一走，两人的日子就全换了样。
2. 魔咒没出现。 「毕业就分」要先摆到台面上，再亲手推翻。
3. 把他的等待写成一连串动作。 要写的是静止。 那两年里他自己也得有成长。

## 八 · 一封没署名的信

`T` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：初见 39.9% ＋ 隐瞒 4.7%

**骨架**｜她收到过一封没署名的信，过了好多年才知道是谁寄的。

#### 节拍链

写信（改了十几稿）→ 把信塞进信箱的那三秒 → 她收到 → 猜不出是谁 → 信被收起来 → 多年后当面对质

#### 时间轴

跨度是整本书：信在开头出现，谜底到结尾才揭。中间隔了多少年，信就压了多少年。

#### 信的物证学

| 细节 | 信息 |
|---|---|
| 手写 | 现在谁还手写啊，能拿笔写字的，多半练过，草稿纸不知道扔哪了 |
| 没署名 | 本就没想让人知道，写完就算了 |
| 措辞 | 通篇没有一个「爱」字，写的都是小事，比如某天她在食堂帮人捡了餐盘 |
| 纸张 | 从中间撕下来的作业纸，穷学生也有穷学生的讲究 |
| 她的处理 | 没扔，夹在一本考研词汇书里，搬了三次家都还在 |

**信里写的全是小事**。大话谁都会写，可记得「她某天帮人捡餐盘」的，只有一直在看她的那个人。

#### 可用细节

| 类 | 内容 |
|---|---|
| 揭开方式 | 多年后他帮她收拾书房翻出来，当场僵住 · 她看他表情就懂了 |
| 对质 | 「这是你写的」不是疑问句 · 他辩解了 0.5 秒，放弃了 |
| 细节回收 | 她说「我猜过三个人，没猜你」 · 他问「那你为什么留着」 · 她答不出来 |
| 第二封 | 还有没有没寄出去的第二封：他书里也夹着一封，是他在她毕业那天写的 |

「那你为什么留着」，她答不上来。信是谁写的揭晓了，她为什么留着信，她自己也是这一刻才明白。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 写信时点 | 大一，还不认识，只能远远看着 | 她毕业前一晚，人快走了，他豁出去写了一封，还是没留名 |
| 她当年 | 根本没往那上面想 | 心里有点数，不敢认真去认 |
| 揭开 | 他自己说漏了嘴 | 她早就对过笔迹，用的是考前辅导那半本草稿纸，装了好多年没出声 |
| 第二封 | 有 | 没有，一封就把力气用光了 |

「她早对过笔迹装作不知道」这个变体，正好能接进 [15-秘密与坦白 · 她早知道](15-秘密与坦白.md#三--她早知道) 的结构：两个人各握着一半谜底，就这么过了好多年。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 问题落到她自己身上，她答不出来 | 信被翻出来的那一刻，他想起二十岁写信的那个晚上 |
| 内心 | 我连这信是谁写的都不知道，搬了三回家还带着 | 她居然留着。她居然留着。 |
| 好的处理 | 她把信又夹回那本书里 | 他把自己那封也拿出来，两人扯平 |
| 写崩 | 写成她设套验笔迹 | 写成他当年一口气写了三十封 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她中举那天的贺帖里，夹着一张没署名的词笺 |
| 修仙 | 一枚不留名的传音玉简，她用神识听了无数遍也认不出是谁，因为他是捏着嗓子念的 |
| 星际 | 一条匿名加密消息，加密手法笨得可爱，用的是教科书第一章的例题 |

「加密方式是教材第一章例题」，等于星际版的半张作业纸。穷学生的仪式感，到哪个世界都一样。

#### 写崩的三种方式

1. 把信写成情书范文。 通篇写小事，不抒情。
2. 当年就揭开。 信要压好多年。
3. 揭开以后写一大段感动。 写她把信夹回那本书就行。

## 九 · 毕业典礼

`T` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：告别 38.9% ＋ 婚仪 38.8%（学位服与拨穗的仪式结构）

**骨架**｜拨穗、合影，学士帽扔上天。有一张照片，镜头外面站着一个人。

#### 节拍链

一早领学位服 → 排队拨穗 → 全班合影 → 自由合影 → 去校园各处打卡 → 抛帽 → 散场

#### 时间轴

**整个流程只有半天，每个环节却都是「最后一次」**：最后一次坐在这个礼堂，最后一次走过这条林荫道。

#### 谁的毕业典礼

| 配置 | 戏眼 |
|---|---|

| 同年毕业 | 两场典礼来回赶，两张穿学位服的合照 ✓ 拿来当全书封面正合适 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 学位服（袖子太长）· 帽穗从右拨到左 · 花束 ✓ · 相机 ✓ |
| 合影政治 | 家长、室友、导师轮流拍，最后那张「随便站站」里，两人挨得最近 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 关系状态 | 已经公开，合影大大方方 | 还没挑明，合影时站位上那点小心思全是戏 |
| 家长 | 见了，毕业典礼顺带见了家长，压力加倍 | 没碰上 |
| 情绪 | 圆满 | 典礼那天两人正在闹别扭，毕业照反倒成了和好的台阶 |
| 那张照片 | 当时拍的 | 过了好几年才看出来，她的毕业照背景里一直有他 |

「毕业照背景里一直有他」这条线算附送的彩蛋，可要等好多年才有人看懂。照片当年就拍下了，和 [八 · 一封没署名的信](#八--一封没署名的信)是同一个套路，先埋下，后面再接上。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 多年后把照片背景放大的那一刻 | 溜进礼堂后排，听见念到她的名字 |
| 内心 | 这张照片我看了十年才看全 | 今天每一个“最后一次”，我都在场 |
| 好的处理 | 她毫无预兆地把帽子扣到他头上 | 他鼓掌鼓到手疼，被人侧目也没停 |
| 写崩 | 写成典礼上当众告白 | 写成他哭湿了学位服 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 放榜和琼林宴，她簪花游街，他挤在人群最前面看 |
| 修仙 | 出师大典，掌门亲手赐剑，全门在山门前摆阵合影 |
| 星际 | 授衔典礼，肩章换上星，礼堂穹顶打开，舰队飞过致敬 |

#### 写崩的三种方式

1. 流程平铺直叙。 半天只写三个「最后一次」。
2. 打卡一圈却不回收前文。 每个点位都要落在前面埋过的场景上。
3. 拿当众告白收尾。 帽子扣他头上，就是全部表态。

## 十 · 多年后回学校

`T` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：旧地 16.9%

**骨架**｜校庆那年顺路回去了一趟，学校哪儿都显得小了。

#### 节拍链

收到校庆请柬或只是路过，动了念头 → 门禁，校门竟然要预约了 → 一处处重走 → 变了的和没变的 → 碰上还认识的人，或者谁也不认识了 → 离开

#### 时间轴

**学校换人换得太快**，四年走一批，过了八年，已经没人记得他们。所以校园版下手更狠，和 [09-分离与重逢 · 旧地](09-分离与重逢.md#十--旧地) 是同一路，只是用「变化清点」来计时，效果更极端。

#### 清点表

| 点位 | 变了 | 没变 |
|---|---|---|
| 迎新台阶 | 加了无障碍坡道 | 第三级台阶还缺着那个角 |
| 图书馆那桌 | 桌椅换新了，占座要扫码 | 窗外那棵树粗了一圈 |
| 食堂 | 阿姨退休了 | 新阿姨打菜的手势一模一样 |
| 操场 | 塑胶换了颜色 | 四百米还是四百米 |
| 社团摊位 | 全是没听说过的新社团 | 招新学妹喊哑的嗓子，跟当年的她一个调子 |

「新学妹喊哑的嗓子和当年的她一个声调」：校园里的人换了一茬，位置还照常转，有人正在变成当年的她。

#### 可用细节

| 类 | 内容 |
|---|---|
| 门禁 | 访客登记写「校友」，学妹看他们像看出土文物 |
| 重走 | 在图书馆那张桌前坐了十分钟，谁都没出声 · 他去食堂窗口点了当年那两样 |
| 遇故人 | 碰上留校任教的同学，对方开口第一句就是「你俩果然」 |
| 离开 | 校门口回头那一眼 · 「下次校庆还来吗」「来」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 距毕业 | 五年 | 二十年（带孩子来，指给孩子看，接 [13-家庭与亲属](13-家庭与亲属.md#五--他带孩子)） |
| 关系线 | 一直在一起 | 分开多年后各自回校，撞上了（[22-分手与复合 · 街上遇见](22-分手与复合.md#五--街上遇见)的校园版，杀伤力加倍） |
| 故人 | 遇到了 | 一个熟人都没遇上，整座校园只剩他俩互相作证 |
| 情绪 | 暖 | 以「都小了一圈」的怅然为主，底子是暖的 |

那四年真的有过，证人只剩身边这一个。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 招新学妹那副嗓子 | 食堂那两样菜的味道，和记忆里差了一点，又说不出差在哪 |
| 内心 | 有人正变成当年的我 | 台阶缺角还在，我们也还在。 |
| 好的处理 | 她在那张桌前坐下，顺手把包放到对面座位上 | 记忆和现实对不上，他不去纠正，就让它对不上 |
| 写崩 | 写成一场怀旧演讲 | 写成走一处哭一处 |

她顺手把包放到对面座位，用的是 [三 · 图书馆](#三--图书馆)的占座暗号，过了十年她还记得。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 重回书院，山长已经换了两任。她当年的策论还刻在廊下，落款被人摸得发亮 |
| 修仙 | 回到山门，当年的杂役弟子已经当上执事，藏经阁那个蒲团换了新的，位置没动 |
| 星际 | 军校开放日，教学舰已经换了三代。模拟舱调出旧档案，两人的记录还存在服务器里 |

「两人的记录还在服务器里」，是星际版的台阶缺角。

#### 写崩的三种方式

1. 清点写成流水账。 五个点位，每处一句变了的、一句没变的。
2. 抒情压过了物件。 占座的包、缺角的台阶，让它们自己说话。
3. 没有换代感。 「谁都不认识我们了」这层怅然得在。
