# 校园与青涩

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 现代校园（大学及以上）
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 本卷全部条目设定在**大学及以上学段**，全部角色均为成年人。
> 这一族的共同机关：**校园里的位置差是有毕业期限的。倒计时从第一天就在走。**

## 校园 GB 的独门结构

「学姐学弟」是半个姐狗文的起源地。这套设定给了三样别处没有的东西：

| 给的 | 说明 |
|---|---|
| 现成的位置差 | 高年级对低年级，天然的「她在前他在后」，不需要任何解释 |
| 现成的称呼 | 「学姐」是「姐」的预科班（接 [27-年龄差与姐弟](27-年龄差与姐弟.md#二--姐这个字)） |
| 一个倒计时 | 她先毕业。位置差有效期两三年，到期自动清零 |

第三样是这一族的心脏。**职场的上下级可以维持十年，学姐学弟撑不过一纸毕业证**：所以校园 GB 天生是限时叙事，每一场戏头顶都挂着日历。

|---|---:|
| 初见 | 38.0% |
| 接送 | 37.0% |

| 聚会 | 12.0% |

## 一 · 学姐

`G` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：初见 38.0%

**骨架**｜他第一次叫她学姐。这两个字他后来叫了很多年，含义换了好几轮。

#### 节拍链

初见的场合（报到·招新·讲座）→ 有人告诉他「这是 X 学姐」→ 他跟着叫了 → 她应得随意 → 这个称呼固定下来 → 很久以后它的含义变了

#### 时间轴

**「学姐」这个词的语义漂移就是时间轴**：从敬称，到熟人间的口头习惯，到只剩他一个人还在叫，到毕业多年后他改口又改回来。

#### 「学姐」的语义阶梯

| 阶段 | 这两个字的意思 |
|---|---|
| 刚认识 | 礼貌性敬称，全院都这么叫 |
| 熟了 | 别人改叫名字了，他没改 |
| 更熟 | 她说「叫名字吧」，他叫不出口 |
| 毕业后 | 他终于能叫名字了，偶尔叫回「学姐」，是撒娇 |
| 多年后 | 人前叫名字，两人独处时那声「学姐」是私房话 |

「她说叫名字吧，他叫不出口」是这条的枢纽：**称呼卡住的地方，就是关系卡住的地方**（同源结构见 [11-初遇与确立 · 改口](11-初遇与确立.md#五--改口)）。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 迎新点的遮阳棚 · 她把他的行李箱一把拎上台阶（他愣在原地） |
| 她当时的样子 | 白 T 恤 · 挂着工作牌 · 晒得手臂发红 · 嗓子喊哑了 |
| 那一把 | 他后来无数次提起「你当年单手拎我三十寸的箱子」 |
| 称呼 | 全篇追踪这两个字的每一次出现 |

「单手拎行李箱」是校园版的初见定格：**第一面就是她比他有力气**，这个画面值十章铺垫。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 差几届 | 一届 | 三届（她研三他大一，倒计时更短） |
| 初见 | 迎新 | 更早（他高中来参观时见过她，她不知道——大学重逢才认出） |
| 称呼归宿 | 变成私房话 | 他一直没改口，改口留给某个大场合 |
| 她的印象 | 记住了他 | 完全没印象（他单方面记了三年，接 [11-初遇与确立 · 他先动心](11-初遇与确立.md#八--他先动心)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 多年后他那声撒娇式的「学姐」 | 拎箱子那一下她手臂上的线条 |
| 内心 | 我都不记得迎新那天了，他记得每个细节 | 这两个字叫顺口了，改不了了 |
| 好的处理 | 她配合这个称呼游戏，从不点破 | 他解释不清为什么改不了口，也不解释了 |
| 写崩 | 写成她刻意学姐威严 | 写成他见面就脸红三年 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 书院同门，她是入门早的师姐，戒尺挂在她那边 |
| 修仙 | 同门师姐，剑术课她带他，一个「师姐」叫了三百年 |
| 星际 | 军校学姐，授衔那天她亲手给他别上肩章 |

#### 写崩的三种方式

1. 初见写成惊艳脸。 惊艳的是那一把拎箱子的力气。
2. 称呼一步到位改成名字。 卡住的过程才是内容。
3. 让学姐身份等于全面碾压。 她只是早两年，不是无所不能。

## 二 · 社团招新

`G` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：初见 38.0% ＋ 要联系 18.0%

**骨架**｜他在报名表上写下名字。动机栏是空的，动机站在桌子后面。

#### 节拍链

摊位前路过 → 停下（因为看见了她）→ 假装了解社团 → 填表 → 她收表时多看了一眼 → 第一次活动 → 他成了最勤的新人

#### 时间轴

**从填表到第一次活动之间的那一周**，他把社团的公众号历史推文翻完了。翻推文这个动作本身就是钟。

#### 可用细节

| 类 | 内容 |
|---|---|
| 摊位 | 折叠桌 · 海报是她画的 · 她在喊话，嗓子已经哑了 |
| 填表 | 动机栏他咬着笔想了很久，写了「感兴趣」 · 字比平时写得认真 |
| 破绽 | 这个社团和他的专业毫无关系 · 室友的原话：「你不是说这玩意儿无聊吗」 |
| 之后 | 布置场地永远有他 · 搬水搬桌子的活他全包了 · 她开始记住这个好用的新人 |
| 她的视角 | 很久以后她翻到那张报名表，动机栏那三个字，笑了很久 |

「她后来翻到报名表」是这条的回收点：动机栏写着感兴趣，感兴趣的是什么，纸上没写的部分多年后自己招了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 社团类型 | 她是社长（权力最直接） | 普通老社员（他曲线入社） |
| 他的表现 | 勤快到显眼 | 刻意低调，只在她看不见的地方干活 |
| 她的察觉 | 早看穿了 | 真没察觉，只觉得这届新人真好用 |
| 结局 | 他接了社长（她毕业时点的名） | 社团只是起点，各自淡出 |

「她毕业时把社长的位置点给他」，**她留下的位置由他接**，这是校园版「交出去」（呼应 [07-馈赠与仪式 · 交出去](07-馈赠与仪式.md#六--交出去)）。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 这个新人搬完水从不邀功 | 报名表递出去时她的指尖 |
| 内心 | 好用。而且总在。 | 她没认出我来，也好 |
| 好的处理 | 她按能力用他，不因为看穿了就疏远 | 他干活是真干，不是表演 |
| 写崩 | 写成她利用劳力 | 写成他卧底追妻 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 诗社文会，他递上的行卷她批了个「可」 |
| 修仙 | 外门招收杂役弟子，他报了她峰上的名 |
| 星际 | 战术小队招新，他把第一志愿从王牌队改成了她的队 |

#### 写崩的三种方式

1. 动机当场戳穿。 那张表要压到多年后再翻出来。
2. 他只干活不成长。 社团线要给他真的长进。
3. 她全知全能。 让她真享受一阵「这届新人好用」的错觉。

## 三 · 图书馆

`G` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：教导 14.0% ＋ 睡着 54.0%

**骨架**｜同一张桌子，各看各的书。三个月，谁都没说破。

#### 节拍链

偶然同桌 → 第二次「偶然」→ 变成默契的固定座位 → 占座的暗号形成 → 一方缺席的那天 → 说破或继续不说破

#### 时间轴

**以自习季为单位。** 期中到期末，一张桌子从陌生人共用变成「我们的位置」，全程可以没有一句对话。

#### 无声系统

这条一句对话都不用，全靠物件说话：

| 物件动作 | 意思 |
|---|---|
| 一本书压在对面座位 | 给对方占的 |
| 一瓶没开的水放在对面 | 今天谢谢／不客气 |
| 她的外套 ✓ 搭在他椅背 | 她去接热水了，东西看着 |
| 一张便签：「三点有课，先走」 | 第一次留下文字 |
| 便签被夹进对方书里带走了 | 文字被收藏了 |

**便签是这条的转折物。** 三个月的沉默系统，被一张二十个字的纸条升级成了通信系统。

#### 可用细节

| 类 | 内容 |
|---|---|
| 环境 | 翻页声 · 键盘声 · 占座文化 · 闭馆音乐 |
| 睡着 | 他趴着睡着了，醒来书上盖着她的围巾 ✓（睡着 54%，图书馆版） |
| 破绽 | 他的专业书和她的完全不同楼层，他却总在她这层 |
| 缺席 | 她保研答辩那天没来，他对着空座位坐立不安，晚上那张便签写了又撕 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先占谁的座 | 他蹭她的固定座 | 她后来的（不知那是他蹲了很久的点） |
| 沉默期 | 三个月 | 一整年（极限拉扯） |
| 说破方式 | 便签 | 闭馆时一场雨，共一把伞（接 [18-节令与天候 · 下雨](18-节令与天候.md#一--下雨)） |
| 结局 | 说破 | 到毕业都没说破，毕业十年后同学会才对上（转 [十 · 多年后回学校](#十--多年后回学校)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 醒来时那条盖在他书上的围巾是她放的，她装作在看书 | 空座位那天他才知道这三个月不是习惯 |
| 内心 | 说破就要负责，先这样吧 | 她今天没来。她为什么没来。 |
| 好的处理 | 她的便签只写事务，落款画了个小勾 | 他把每张便签都夹在同一本书里 |
| 写崩 | 写成她钓鱼三月 | 写成他偷拍监视 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 藏书楼同一张案，她的镇纸永远压着对面那卷 |
| 修仙 | 藏经阁同一格蒲团，他的剑和她的剑在架上越挂越近 |
| 星际 | 资料舱固定终端位，两人的登录记录时间线完全咬合 |

「两人的登录记录时间线严丝合缝」，星际版把三个月的默契变成了一份可以调出来的数据，谁调出来的、什么场合亮出来，是加戏点。

#### 写崩的三种方式

1. 提前说破。 沉默系统至少要运转两个月。
2. 加内心大段独白。 这条的语言就是物件。
3. 便签写成情书。 二十个字，全是事务，勾在落款。

## 四 · 考前辅导

`G` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：教导 14.0%

**骨架**｜她给他补高数。两周后发现，他的英语比她好得多。

#### 节拍链

他挂科边缘 → 开口求助（比表白还难）→ 固定辅导时间 → 她的教法（不哄，只纠正）→ 成绩出来 → 反向发现：他也有能教她的

#### 时间轴

**倒计时向考试日收敛。** 距离考试 21 天、14 天、7 天、前夜——每一档的气氛不同，前夜那次辅导到楼管赶人。

#### 与 [11-初遇与确立 · 她教他](11-初遇与确立.md#六--她教他) 的分工

那一条写「教」这个动作的权力结构，这一条写校园特有的部分：

| 校园特有 | 说明 |
|---|---|
| 求助的开口成本 | 承认「我不会」对男生宿舍文化来说是个坎，他跨过来了 |
| 成绩是硬结算 | 教得好不好，分数当众揭榜 |
| 反向科目 | 她高数碾压，英语口语被他反杀——**校园里能力是分科目的**，天然双向 |
| 场地 | 空教室的晚自习，粉笔灰，楼管查楼 |

「反向科目」是这条的钥匙：**辅导关系一旦双向，位置差就变成了交换**，这正是这段关系最好的预演。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 草稿纸用了半本 · 她的字压着他的字批 · 红笔 · 空教室的粉笔 |
| 她的教法 | 「再做一遍」 · 不夸，做对了就翻下一页（翻页就是表扬） |
| 他的状态 | 装懂被当场识破 · 真懂那题时她眼里那下亮 |
| 反杀现场 | 英语角他张口，她第一次在他脸上看到「原来你不会」的表情 |
| 结算 | 成绩出来他冲过半个校园来报分 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 科目 | 她强他弱 | 各有领地（推荐） |
| 教法 | 严 | 严里夹一次破例（他真崩溃那晚她请了顿宵夜） |
| 结果 | 过了 | 还是挂了（她比他还沉默，然后说「重修我再教」） |
| 反向辅导 | 有 | 他没敢提出来，憋到毕业 |

「挂了她说重修我再教」这一端别怕用：**结果失败但关系升级**，比顺利通过好写得多。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他真懂那题时她莫名的成就感 | 开口说「学姐能不能教我」用了三天 |
| 内心 | 教他比自己刷题累十倍，但我在等每周三 | 别装懂，她一眼就看出来 |
| 好的处理 | 她的翻页式表扬贯穿全程 | 他反向教她时没有报复性地严 |
| 写崩 | 写成打骂式辅导 | 写成他装弱骗辅导 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她教他策论，他的诗赋反过来是她抄的范本 |
| 修仙 | 她教剑，他的阵法笔记全门弟子传抄 |
| 星际 | 她带他机甲实操，他的理论推演替她纠了一个错 |

#### 写崩的三种方式

1. 全程单向。 反向科目是这条的下半场。
2. 她的严写成刻薄。 严的判据是翻页，不是挖苦。
3. 考试结果一笔带过。 冲过半个校园报分那一段是情绪出口。

## 五 · 运动会

`G` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：起哄 42.0% ＋ 接送 37.0%

**骨架**｜四百米决赛。这是全年唯一一天，看台上的人是她。

#### 节拍链

报名（谁怂恿的）→ 训练期 → 比赛日 → 检录处的那瓶水 → 枪响 → 最后一百米他找看台 → 冲线 → 终点处

#### 时间轴

**赛程表是钟**：上午预赛、下午决赛，中间那四个小时的等待比比赛长十倍。

#### 为什么运动会是校园 GB 的必写场

日常里位置在她那边。**跑道是全校园唯一一块他的绝对主场**：她坐在看台上，视线方向反过来了。这个类型需要给他这样一天（同一原理见 [19-玩闹与网络 · 打游戏](19-玩闹与网络.md#三--打游戏)），而运动会把它放大到全校围观的规格。

#### 可用细节

| 类 | 内容 |
|---|---|
| 赛前 | 检录处她递来一瓶拧松了盖的水 ✓（拧松这个细节反着用了 [29-微小仪式拾遗](29-微小仪式拾遗.md#七--拧瓶盖与够高处)） |
| 看台 | 她本来在改论文，枪响后论文再没翻过页 |
| 最后一百米 | 他明明该看终点，偏头找了一眼看台——这0.3秒的偏头是全场文眼 |
| 冲线后 | 他弯腰喘，喘完第一眼还是看台 · 广播念成绩，她跟着全班一起喊了他名字 |
| 之后 | 名次牌他没要，要了她拍的那张糊照 ✓ |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 成绩 | 拿了名次 | 摔了（她从看台下来的速度比救护站快） |
| 她的位置 | 看台 | 终点线计时员（近到能听见他喘） |

## 七 · 她先毕业

`T` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：告别 37.0%

**骨架**｜她答辩通过那天，他鼓了全场最响的掌。掌声停了他才想起来：倒计时归零了。

#### 节拍链

答辩季 → 通过 → 散伙饭季 → 收拾宿舍 → 校门口那一送 → 她走后的校园 → 两地节奏开始错位

#### 时间轴

毕业季的日程表面向她，倒计时面向他。 答辩、体检、离校手续，每一项她划掉一格，他心里沉一格。

#### 这条是校园 GB 的结构性大关

开卷就说过：校园的位置差有毕业期限。到期这天，三件事同时发生：

| 变化 | 后果 |
|---|---|
| 学姐身份失效 | 位置差的制度来源没了，关系要换地基（预演了 [12-工作与金钱 · 他比她强了](12-工作与金钱.md#八--他比她强了)的结构） |
| 空间拆开 | 她进职场或外地读研，他还在校园——生活节奏从同频变异步 |
| 关系定性被迫提前 | 「毕业就分」是校园恋的默认结局，他们要当面推翻这个默认 |

**「毕业就分手」这句魔咒要在文里被明确说出来一次**：由室友说、由长辈说都行——然后被两个人用行动否掉。不提它，等于绕开了这条的主考题。

#### 可用细节

| 类 | 内容 |
|---|---|
| 答辩日 | 他在楼下等，比她还紧张 · 她出来比了个 OK，他原地跳了一下 |
| 收拾宿舍 | 四年的东西装了七箱 · 有一箱她贴的标签是他的名字（都是要留给他的） |
| 校门口 | 车后备箱关上的那声 · 「到了发消息」 · 车开出去她从后视镜看他站在原地 |
| 之后 | 他绕开她以前的教学楼走了一学期 · 食堂阿姨问起，他说「毕业了」，阿姨多打了个鸡腿 |

「阿姨多打了个鸡腿」，[六 · 食堂](#六--食堂)的公证人在这里完成她的谢幕。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 去向 | 同城工作（半分离） | 外地／出国（全套接 [02-等待与错过 · 时差与异地](02-等待与错过.md#十--时差与异地)） |
| 那句魔咒 | 室友说的 | 她自己先说的（她给他递台阶，他没接，把台阶拆了） |
| 他的选择 | 等，且把自己的两年过好 | 拼命提前毕业／考研去她的城市 |
| 多年后 | 走通了 | 没走通（转 [22-分手与复合](22-分手与复合.md)，校园恋的诚实结局之一） |

「她先说毕业就分吧，他把台阶拆了」是这条最有性格的一版：她按惯例给退路，他第一次拒绝了她的安排。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 后视镜里他站在校门口没动 | 贴着他名字的那一箱 |
| 内心 | 我先走进的那个世界，等他两年 | 倒计时到零，计时器换成了她的城市天气 |
| 好的处理 | 她不说「等我安顿好」这种空话，她给了具体日期 | 他没有把等待过成停滞 |
| 写崩 | 写成她潇洒断后路 | 写成他哭瘫校门口 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她科考中式赴任，他还在书院；驿路三千里，家书接 [21-世界设定专属 · 通讯延迟](21-世界设定专属.md#八--通讯延迟)的古代版 |
| 修仙 | 她提前出师下山历练，他修为未到不能出山门 |
| 星际 | 她授衔登舰，他还剩两年学制；舰队通讯窗口一周一次 |

#### 写崩的三种方式

1. 淡化毕业的结构冲击。 这是地基更换，不是一次远行。
2. 魔咒不出场。 「毕业就分」必须被说出来再被推翻。
3. 他的等待写成静止。 他那两年要有自己的成长线。

## 八 · 一封没署名的信

`T` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：初见 38.0% ＋ 隐瞒 5.0%

**骨架**｜她收到过一封没署名的信。很多年后才知道是谁写的。

#### 节拍链

信写成（改了十几稿）→ 投递（塞进信箱那三秒）→ 她收到 → 猜不出是谁 → 信被收起来 → 多年后对质

#### 时间轴

**这条横跨全书**：信在开头出现，谜底在结尾揭开。中间隔多少年，信就压多少年。

#### 信的物证学

| 细节 | 信息 |
|---|---|
| 手写 | 电子时代还手写，说明练过（练字的草稿哪去了） |
| 没署名 | 不求回应，只求说出 |
| 措辞 | 通篇没有一个「爱」字，写的全是小事：某天她在食堂帮人捡了餐盘 |
| 纸张 | 从中间裁开的作业纸——穷学生的仪式感 |
| 她的处理 | 没扔。夹进了一本考研词汇书，搬了三次家都在 |

**信里写的全是小事**，这是它的指纹：写大话的信可以是任何人写的，记得「她某天帮人捡餐盘」的只能是一直在看她的那一个。

#### 可用细节

| 类 | 内容 |
|---|---|
| 揭开方式 | 多年后他帮她收拾书房翻到，当场僵住 · 她看他表情就懂了 |
| 对质 | 「这是你写的」不是疑问句 · 他辩解了 0.5 秒就放弃了 |
| 细节回收 | 她说「我猜过三个人，没猜你」 · 他问「那你为什么留着」 · 她答不上来 |
| 第二封 | 有没有第二封没寄出的（他书里也夹着一封，写于她毕业那天） |

「那你为什么留着」＋她答不上来——信的谜底揭开了，留信的谜底她自己也是刚刚才懂。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 写信时点 | 大一（认识之前，纯远望） | 她毕业前夜（快失去时的孤注一掷，但还是没署名） |
| 她当年 | 完全没头绪 | 隐约猜到过，不敢确认 |
| 揭开 | 他自己露馅 | 她其实早对过笔迹（考前辅导那半本草稿纸），装了很多年不知道 |
| 第二封 | 有 | 没有，那一封就是全部勇气 |

「她早对过笔迹装作不知道」把这条接进了 [15-秘密与坦白 · 她早知道](15-秘密与坦白.md#三--她早知道)的结构：两个人各藏了半个谜底过了很多年。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「为什么留着」这个问题问到她自己头上 | 信被翻出来那刻，二十岁的自己当场归位 |
| 内心 | 我留着一封不知道谁写的信，搬了三次家 | 她居然留着。她居然留着。 |
| 好的处理 | 她把信重新夹回那本书 | 他把自己那封也拿了出来，扯平 |
| 写崩 | 写成她钓鱼验笔迹 | 写成他当年连写三十封 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 一阕无落款的词笺，混在她及第那日的贺帖里 |
| 修仙 | 一枚匿名的传音玉简，她灵识扫过千百遍认不出声音（他变了声念的） |
| 星际 | 一条匿名加密信息，加密方式土得可爱，是教材第一章的例题 |

「加密方式是教材第一章例题」，星际版的作业纸裁半：穷学生的仪式感，各个世界通用。

#### 写崩的三种方式

1. 信写成情书范文。 全篇小事，零抒情，才是指纹。
2. 当年就揭开。 这封信的利息按年计。
3. 揭开后大肆感动。 「重新夹回去」比任何反应都好。

`T` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：告别 37.0% ＋ 婚仪 38.8%（学位服与拨穗的仪式结构）

## 十 · 多年后回学校

`T` ｜ 无预警 ｜ 现代校园 ｜ 语料频次：旧地 16.0%

**骨架**｜校庆、还是路过，两个人回了一次学校。所有的地方都小了一圈。

#### 节拍链

起意（校庆请柬或纯路过）→ 门禁（校门居然要预约了）→ 逐点重走 → 变了的和没变的 → 遇到还认识的人（或谁都不认识了）→ 离开

#### 时间轴

**用「变化清点」计时**，与 [09-分离与重逢 · 旧地](09-分离与重逢.md#十--旧地)同一技法，校园版的清点表更狠，因为校园换代最快：四年一批人，八年就没人认识他们了。

#### 清点表

| 点位 | 变了 | 没变 |
|---|---|---|
| 迎新台阶 | 加了无障碍坡道 | 台阶第三级还是缺个角 |
| 图书馆那桌 | 换了新桌椅，占座要扫码了 | 窗外那棵树，粗了一圈 |
| 食堂 | 阿姨退休了 | 新阿姨打菜的手势一模一样 |
| 操场 | 塑胶换了颜色 | 四百米还是四百米 |
| 社团摊位 | 全是没听过的新社团 | 招新学妹喊哑的嗓子，和当年的她一个声调 |

「新学妹喊哑的嗓子和当年的她一个声调」，校园的人换了，位置还在运转，有人正在成为当年的她。

#### 可用细节

| 类 | 内容 |
|---|---|
| 门禁 | 访客登记写「校友」，学妹看他们的眼神像看出土文物 |
| 重走 | 在图书馆那桌坐了十分钟，谁都没说话 · 他去食堂窗口点了当年那两样 |
| 遇故人 | 遇到留校任教的同学，对方第一句：「你俩果然」 |
| 离开 | 校门口回头那一眼 · 「下次校庆还来吗」「来」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 距毕业 | 五年 | 二十年（带着孩子来，指给孩子看，接 [13-家庭与亲属](13-家庭与亲属.md#五--他带孩子)） |
| 关系线 | 一直在一起 | 分开多年后各自回校撞上（[22-分手与复合 · 街上遇见](22-分手与复合.md#五--街上遇见)的校园版，杀伤力翻倍） |
| 故人 | 遇到了 | 一个都没遇到，整座校园只剩他们互为证人 |
| 情绪 | 暖 | 「都小了一圈」的怅然为主，暖垫底 |

「整座校园只剩他们互为证人」是这条的终极形态：能证明那四年存在过的，只剩身边这个人。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 招新学妹那把嗓子 | 食堂那两样菜的味道，和记忆里差了一点，说不出差在哪 |
| 内心 | 有人正在变成当年的我 | 台阶缺角还在。我们也还在。 |
| 好的处理 | 她在那张桌前坐下时，顺手把包放在了对面座位上 | 他没有纠正记忆与现实的差，让它差着 |
| 写崩 | 写成怀旧演讲 | 写成逐点哭一遍 |

「顺手把包放在对面座位上」，[三 · 图书馆](#三--图书馆)的占座暗号，肌肉记忆跨越十年自动运行。全条不需要更多抒情了。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 重访书院，山长换了两任；她当年的策论刻在廊下，落款被摸得发亮 |
| 修仙 | 回山门，当年的杂役弟子已是执事；藏经阁那格蒲团换了新的，位置没挪 |
| 星际 | 军校开放日，教学舰换了三代；模拟舱调出旧档案，两人的记录还在服务器里 |

「两人的记录还在服务器里」，星际版的台阶缺角。

#### 写崩的三种方式

1. 清点表写成流水账。 五个点位，每个一句变一句没变。
2. 抒情盖过物件。 占座的包、缺角的台阶，让它们自己说。
3. 忽略换代感。 「谁都不认识我们了」是这条的底色，暖要从这底色里透出来。
