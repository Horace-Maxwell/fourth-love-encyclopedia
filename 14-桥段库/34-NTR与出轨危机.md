## 一 · 第三个人的影子

`T` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：吃醋 43.1% ＋ 社交网 33.9%（悬置期无独立族）

**骨架**｜确证之前那一段。一条消息、一个名字、一阵香味，每一件都能被自己说服过去。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 第一件小事：回消息慢了十分钟，理由是现成的 |
| 2 | 第二件：一个名字在他嘴里出现了第二次，位置比上次靠前 |
| 3 | 自我说服。每件小事配一个解释，解释都站得住 |
| 4 | 第三件是物质的：一件不属于这个家的东西，或者一阵不属于他的味道 |
| 5 | 开始留意，同时不承认自己在留意（这一拍最长） |
| 6 | 一次能查证的机会摆在面前，没查，或者查了一半停手 |
| 7 | 悬置结束：撞见、坦白、或者什么都没发生 |

第 7 拍三条出口，选哪条决定后面九条走哪几条。悬置期的长度就是这一段全部的戏，事一旦坐实，剩下的只有清算。

#### 可用细节

| 类 | 内容 |
|---|---|
| 信号物 | 手机 ✓（1.2×） · 微信 ✓（1.4×） · 改了的备注 · 一件不属于这个家的东西 · 洗衣篮里的味道 |
| 时间刻度 | 回消息的延迟从三分钟变成四十分钟 · 加班固定在每周同一天 · 洗澡时手机带进浴室 |
| 自我说服 | 她替他想好的理由比他自己想的还周全 · 他把她的反常记在了自己头上 |
| 没查的动作 | 屏幕亮着，人走开了 · 密码知道，输了两位数删掉 · 相册翻到某一页退出去 |
| 台词类型 | 「今天怎么这么晚」——问的是事实，听的是语气 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁在悬置 | 她（习惯查证的人，这次不想查） | 他（没有查的位置，只能等） |
| 信号密度 | 三件，隔得很远 | 一周五件，挤成一堆 |
| 出口 | 事是真的 | 事是假的（转 [九 · 误会型](#九--误会型)） |
| 谁先说破 | 当事人自己 | 第三人（[43-第三人与群像 · 她的下属看见了](43-第三人与群像.md#七--她的下属看见了)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她替他把每件小事都圆过去了，圆得太熟练 | 她外套上那个味道，他闻了两次 |
| 内心 | 查了就是不信他，不查就得自己扛着 | 问出口就先输一半 |
| 好的处理 | 她照常安排，安排里多了一项她自己都没察觉的核对 | 他没问，只把她的外套挂到了通风的地方 |
| 写崩 | 写成她一开始就笃定 | 写成他哭着质问 |

#### 写崩的三种方式

1. 信号一次给足。 三件小事挤在同一页，悬置就不成立了；小事之间要隔开日子。
2. 让读者比角色早知道太多。 这一段的痛感来自当事人自己的犹豫，读者手里的证据一超量，戏就变成等着看笑话。
3. 用巧合替代自我说服。 每件小事都要有一个当事人真心接受的解释；解释站不住，人就成了瞎子。

后接：[二 · 他看见了](#二--他看见了) · [三 · 她看见了](#三--她看见了) · [九 · 误会型](#九--误会型)

## 二 · 他看见了

`T` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：误会 35.1%（目击拍）＋ 隐瞒 4.7%

**骨架**｜男受目击版。看见与装作没看见之间隔着一个晚上，那一晚是他的全部戏。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 目击。画面完整，不需要推理 |
| 2 | 第一反应是躲开，不是上前 |
| 3 | 回家。他先到，饭做上了 |
| 4 | 她回来。他照常接包、照常添汤 |
| 5 | 夜里他一遍遍回放，把画面里的人重新摆位置 |
| 6 | 天亮前他做了决定：说，还是收着 |
| 7 | 收着的那一版：第二天他的温柔高了半度，她察觉到了 |

他在本类型里常年是被照顾的一方，没有质问的资格感，所以第 2 拍的躲开是本能，第 5 拍的自我审判排在对她的追问之前。

#### 目击之后的两条路

| | 说破 | 收着 |
|---|---|---|
| 当晚 | 一句话出口，房子静下来 | 照常吃饭，他多添了一次汤 |
| 成本 | 她必须当场给答案 | 他一个人扛，扛的每一天都在计息 |
| 风险 | 问早了，误会型的账要退（[九 · 误会型](#九--误会型)） | 拖久了，读者的耐心先于他崩 |
| 后面接 | [四 · 对峙桌](#四--对峙桌) | [七 · 原谅的价格](#七--原谅的价格) · [八 · 不原谅](#八--不原谅) |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓ · 玄关 ✓（2.0×） · 做到一半的饭 · 他给她留的那盏灯 · 洗到一半的碗 |
| 目击现场 | 站在原地把口袋里的手攥紧 · 走回去的路绕了远 · 外套挂了两次才挂正 |
| 夜里 | 他数她的呼吸 · 背对着她睁着眼 · 手机屏幕一亮他就闭眼 |
| 第二天 | 比平时早起十分钟 · 给她挤好牙膏 · 没问她昨天几点回的 |
| 台词类型 | 他说的话全是家常，一句问句都没有 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 目击的清晰度 | 完整，不需要推理 | 半截（转 [九 · 误会型](#九--误会型)） |
| 他的处理 | 当晚说破 | 收着，收成一条长线 |
| 资格感 | 有，他知道自己可以问 | 没有，他先审判自己（接 [04-委屈与破防 · 我是不是不够好](04-委屈与破防.md#九--我是不是不够好)） |
| 她知不知道他看见了 | 不知道 | 知道，且在等他开口（更难写，也更疼） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他今天温柔得反常，她想不出原因 | 玄关那盏灯他还是开了 |
| 内心 | 他没问，她松了口气，松完就慌 | 我先把饭做完 |
| 好的处理 | 她察觉到那半度，先没作声 | 他做的每件事都和昨天一样，只有一件不一样：他没问她累不累 |
| 写崩 | 写成她演技拙劣当场露馅 | 写成他当街哭喊 |

#### 写崩的三种方式

1. 让他立刻爆发。 男受的第一反应通常是缩回去；爆发要留到 [四 · 对峙桌](#四--对峙桌)，且要有人推他一把。
2. 把隐忍写成美德。 收着是一种止损算法，代价要写出来：他多扛一天，账面就多一天利息。
3. 只给读者看画面。 那一晚的重量在他脑内的重新摆位上，画面本身两句话就够。

#### 示例（本库自撰，可直接改写）

> 他先到家。菜是早上就想好的，两个人的量。
> 米下锅的时候他把手机反扣在灶台上。屏幕亮了两次，他没看。

## 三 · 她看见了

`T` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：误会 35.1%（目击拍）＋ 吃醋 43.1%

**骨架**｜女攻目击版。同一个画面，五种女主给五种反应；她的处理方式暴露她全部性格。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 目击。她没有愣住，两秒之内完成取证 |
| 2 | 她走开，或者她走上前（这一步分岔） |
| 3 | 回家路上顺序已经排好：先问什么、后办什么 |
| 4 | 到家。她照常，照常得可怕 |
| 5 | 她动用了一次资源：调一次记录、问一个人、打一个电话 |
| 6 | 事实到手。她坐了一会儿 |
| 7 | 处理方式定下，动手之前她给自己留了退路，或者没留 |

#### 五种女主的处理方式

原型名从 [04-人设原型/01-女主原型谱](../04-人设原型/01-女主原型谱.md) 取。

| 原型 | 处理方式 | 暴露的东西 |
|---|---|---|
| 能力型女 Alpha | 当天查清，第三天摊牌，议程比工作会议还整齐 | 她怕的不是失去，是失控 |
| 清冷寡言型 | 一句不问，把他的东西从共用抽屉挪出去 | 她的判决不设听证 |
| 温柔主导型 | 先问他累不累，问完才问那个人是谁 | 温柔是刀鞘，不是刀 |
| 女帝／权力顶端型 | 先处置第三者，再回来处置他 | 关系与权力共用同一套流程 |
| 疯批女攻 | 笑着照常过了两周，第十五天动手 | 她的时间表读者看不懂，动笔前先给她备一条底线 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓ · 一张拍下来没发给任何人的照片（2.0×） · 车里没熄的火 · 当晚没脱的外套 |
| 她的取证 | 记住时间与地点 · 核对他上周报过的行程 · 该问的人只问一句 |
| 她的照常 | 照样问他今天怎么样 · 照样先给他盛饭 · 照常里没有一处破绽 |
| 真的破绽 | 洗手洗了很久 · 手机反扣在桌上 · 第一次没纠正他的坐姿 |
| 台词类型 | 短问句，一次一个，问完就等 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 上不上前 | 上前，当场短兵相接 | 不上前，她要完整的证据链 |
| 动不动用资源 | 动用，快且脏 | 忍住不用（转 [05-占有与吃醋 · 独占欲的边界](05-占有与吃醋.md#十--独占欲的边界)） |
| 第三者的处置 | 她先找第三者 | 只处理他，第三者与她无关（这一端更可怕） |
| 给不给自己退路 | 留了，她已经在想之后怎么活 | 没留（接 [八 · 不原谅](#八--不原谅)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 两秒取完证，第三秒才觉得疼 | 她今晚照常，照常得他后背发凉 |
| 内心 | 先把事办完，疼可以排到后面 | 她没问，那就是已经知道了 |
| 好的处理 | 动用资源之前她停了一次，那几秒写清楚 | 他看见她洗手洗了很久，什么都明白了 |
| 写崩 | 写成她当场撕打第三者 | 写成他毫无察觉，一路装到摊牌 |

#### 写崩的三种方式

1. 让她当场失态。 失态可以有，但要挑地方；她的性格决定失态发生在无人处，不在停车场。
2. 处理方式通用化。 换一个女主也能照搬的反应等于人设作废，对着上表按原型挑。
3. 把资源写成万能钥匙。 一个电话查清一切，取证就没有重量了；资源要有代价，包括她欠下的人情。

## 四 · 对峙桌

`T` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：吵架 15.7% ＋ 坦白 6.5%

**骨架**｜摊牌那一场。证据摆上桌，三个人的位置怎么排，决定这是审判还是清算。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 场地选定：家里的餐桌，还是外面 |
| 2 | 落座。谁在主位，谁背对门，第三者坐哪 |
| 3 | 证据上桌：一张照片、一条记录、一件东西 |
| 4 | 第一轮走事实。语气还平 |
| 5 | 第二轮走动机。这一轮才见血 |
| 6 | 有人离席。离席的是谁，等于宣布这一场谁输了 |
| 7 | 收场：一条当场定下的规矩，或者一句谁也没接的话 |

#### 三方位置调度

修罗场的权力戏版本在 [05-剧情套路/02-名场面结构库](../05-剧情套路/02-名场面结构库.md)，这里是它的日常版：同一张餐桌，靠座位排班分胜负。

| 配置 | 位置 | 效果 |
|---|---|---|
| 两人对坐，第三者不在场 | 她在主位，他在侧位 | 审判庭。他的每句话都像供词 |
| 两人并坐，证据在对面 | 同侧落座，照片摊在桌心 | 共同面对一件事，最容易走向重建 |
| 三人同桌 | 第三者被叫来了 | 三个人里必有一个是被展示的物品，动笔前先想清楚是谁 |
| 第三者在场但不说话 | 她只跟他说话 | 狠的一种：第三者被当成家具 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 摊在桌心的照片（2.0×） · 一杯没人动的水 · 桌上的钥匙 · 谁的手机在桌面上，谁就在被检查 · 锅里还热着的那顿饭 |
| 动作 | 她把证据推过去，不说话 · 他的手在桌下 · 有人把椅子往后挪了两寸 |
| 语言 | 事实轮用短句 · 动机轮开始出现「什么时候开始的」这种不可回答的问题 |
| 离席 | 谁先站起来 · 站起来的人有没有把椅子推回去（推回去的还想回来） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 主持人 | 她（常态） | 他（他把她叫到桌前，这一端极少写） |
| 第三者 | 不在场 | 在场，且比谁都冷静 |
| 证据 | 硬的：记录、影像 | 软的：一个说不清的细节，全场靠语气打 |
| 收场 | 定下一条规矩 | 没有结论，各自去睡（第二天再开一场） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把证据推过去时手是稳的 | 他看着那张照片，先想的是她拿了多久 |
| 内心 | 我要的是事实，不是道歉 | 她一直知道，一直没说 |
| 好的处理 | 她只问三个问题，问完就等 | 他答的每句都是完整事实，包括对自己不利的那部分 |
| 写崩 | 写成她连珠炮式审问 | 写成他当场跪下来求 |

#### 写崩的三种方式

1. 一场戏走完全程。 事实、动机、判决挤在一顿饭里，后面六条就没得写了；对峙桌只解决事实。
2. 第三者当场认输退场。 认输省事，省下来的正是这一场的重量。
3. 用一句真相反转收场。 反转要么按 [九 · 误会型](#九--误会型) 的排布提前埋好，要么不用。

## 五 · 他被抢

`T` ｜ ⚠️NTR·逆NTR ｜ 全谱系 ｜ 语料频次：NTR/逆NTR 142 篇 2.5%（文案标签统计实测，四向混计）

**骨架**｜逆NTR 主线。别的女攻来夺，他的态度是唯一的悬念。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 另一个女攻出现，带着一条与他无关的动机线（她本来是来谈事的） |
| 2 | 她给出的恰好是他缺的：一句正面评价、一个位置、一次被认真问过意见 |
| 3 | 他没有拒绝，也没有回应。他只是回家晚了半小时 |
| 4 | 她察觉到的不是第三者，是他身上多出来的东西 |
| 5 | 两个女攻同框一次。全场没有一句争夺的话，规矩全在细节里 |

| 7 | 他的选择，以及他做选择时用的理由 |

第 7 拍的理由比结果重要：理由与两边开的条件都无关，他才是人。

#### 他的意志在哪几拍出场

逆NTR 的雷区在 05-01 已经标死：他若全程没有选择权，会被读成物品。场面层的落法是给他三次出声的机会，最迟不晚于第 3 拍。

| 拍 | 他的动作 | 漏掉会怎样 |
|---|---|---|
| 3 | 回家晚半小时是他自己的决定 | 越界成了被动发生的事故 |
| 6 | 他拒绝在别人排好的时间里做选择 | 他成了被两个人分配的东西 |
| 7 | 他给出理由，理由与两边的条件无关 | 结局读起来像拍卖落槌 |

| 类 | 内容 |
|---|---|
| 道具 | 第三者递的名片 · 她给他的一次机会（一份工作、一次进修、一场演出） · 没换的门锁 · 停在同一条路上的两辆车 |
| 同框细节 | 谁先叫他的名字 · 谁替他拉椅子 · 谁在他面前提起对方时用了敬称 |
| 他多出来的东西 | 他开始有自己的日程 · 说话前会停顿一下 · 第一次拒绝了一件小事 |
| 她的察觉 | 他不再等她的意见 · 她第一次不知道他在忙什么 · 他的手机不再随手递给她 |
| 台词类型 | 第三者的话里全是问句，她的话里全是安排 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 第三者的路数 | 给的是位置与尊重 | 给的是纵容与放任 |
| 他的动摇 | 从未动摇（戏在她的恐惧上） | 真的动摇过（更重，也更容易被读成他渣） |
| 结局 | 他留下 | 他走（BE，须前置） |
| 她的应对 | 加倍地管（越管推得越远） | 第一次问他想要什么（管用，且难写） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他身上多了一样她没给过的东西 | 那个人问他意见，问完等他答完 |
| 内心 | 我给的是最好的，为什么不够 | 被认真问一次意见，比什么都难扛 |
| 好的处理 | 她没去找第三者，她回来问他 | 他留下的理由与两边开的条件都无关 |
| 写崩 | 写成她与第三者比价 | 写成他全程被动，等着结果 |

#### 写崩的三种方式

1. 两个女攻拍卖他。 双方轮流加码，他站在中间不出声，逆NTR 就写成了物权转移。
2. 第三者靠使坏得分。 下药、造谣、拆信一出场，她就不再是对手，只是障碍。
3. 靠第三者自行退场收尾。 良心发现主动让路，这一场就白打了；她要败在他的选择上。

## 七 · 原谅的价格

`T` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：和好 36.1% ＋ 前任 32.1%

**骨架**｜留下不等于翻篇。原谅之后的日常怎么继续，价目单一项项付。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 决定留下。这个决定很短，短到不像大事 |
| 2 | 第一顿饭。两个人都在演正常，演得都不好 |
| 3 | 第一个具体障碍：一个词、一个地点、一个时间段成了雷 |
| 4 | 一条新规矩落地：报备、密码、某个不再去的地方 |
| 5 | 一次复发。深夜翻旧账，翻完道歉，道歉也不管用 |
| 6 | 三个月后的一件小事，两个人发现自己已经不再核对 |
| 7 | 新常态成立。有一样东西永久地不一样了，两个人都知道是哪一样 |

#### 价目单

| 项 | 具体形态 | 有效期 |
|---|---|---|
| 收不回的东西 | 一件礼物送不出去了 · 一个称呼不再用 · 一家店不再去 | 永久 |
| 改掉的规矩 | 报备制 · 密码共享 · 每周固定的一晚 | 半年到一年，然后自然废止或者转正 |
| 让出去的位置 | 某件事上失去了不被过问的权利 | 到信任重建为止 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 新密码 · 手机放桌面的新习惯 · 那家不再去的店 · 一件他没扔的旧物 · 冰箱上多出来的日程 |
| 复发的形态 | 深夜翻旧账 · 一个相似的香水味 · 群里一个同名的人发言 |
| 两个人的演技 | 她笑得比平时准时 · 他把「今天见了谁」写成汇报 · 报备报得像交作业 |
| 不再核对的那天 | 她没问，也没想起来要问 |
| 台词类型 | 「先这样」「暂时」——限期的词，两个人都不说「以后」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁原谅谁 | 她原谅他 | 他原谅她（少写，且更难服人） |
| 原谅的成色 | 真翻篇，要写出转折那一天 | 留下来但不原谅（[八 · 不原谅](#八--不原谅) 的孪生版） |
| 规矩的来源 | 被绿方开的条件 | 出轨方自己提的（更重） |
| 结束方式 | 规矩自然废止 | 规矩留到最后一章还在 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把报备表停掉的那一天 | 他每天发的定位，发到自己都忘了为什么发 |
| 内心 | 我原谅了，可我还在数日子 | 我得让她随时能查到我 |
| 好的处理 | 她说停就停，不解释，也不回头翻 | 他不辩解一个字，只把每件事做到可查 |
| 写崩 | 写成她一句话原谅 | 写成他靠一顿哭戏过关 |

#### 写崩的三种方式

1. 一顿饭完成原谅。 决定可以短，日常必须长；价目单至少要在三场戏里逐项付掉。
2. 把规矩写成惩罚。 报备制是止损工具，写成刑具就改姓了，走 [35-规矩的进阶 · 协商桌](35-规矩的进阶.md#二--协商桌) 的框架。
3. 复发只写一次。 一次复发是事件，反复才是真相；至少写两次，第二次的强度要更低。

## 八 · 不原谅

`T` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：分手 8.4% ＋ 冷战 19.0%

**骨架**｜走向 22 卷之前的最后一场。把离开写成决定，不写成崩溃。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 决定在事前就下了。这一场只是执行 |
| 2 | 事务先办完：账、钥匙、共同的东西 |
| 3 | 最后一顿饭，或者没有最后一顿饭 |
| 4 | 对方察觉执行已经开始，开始挽留 |
| 5 | 挽留的每一句都被接住，接得很客气 |
| 6 | 走的那一下：门、电梯、车。不回头，也不加速 |
| 7 | 之后的第一件事，是一件具体的事务 |

#### 决定与崩溃的分界

| 观察点 | 决定 | 崩溃 |
|---|---|---|
| 时间 | 事前已下，这一场执行 | 当场生成，随情绪摆动 |
| 语速 | 慢，句子完整 | 快，句子断 |
| 事务 | 办完了才走 | 走了以后还挂着 |
| 挽留的效果 | 被接住，不被撼动 | 每一句都能动摇一下 |
| 之后 | 有下一件事 | 只剩空白 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 鞋柜上的钥匙 · 共同账户的最后一笔 · 没带走的那一件 · 删了没删干净的相册 |
| 她走的样子 | 椅子推回原位 · 走之前关了他习惯开的那盏灯 · 车在楼下停了四十秒 |
| 他走的样子 | 把冰箱里的菜做完了 · 留了一张写家电怎么用的便条 · 把她的东西归了位 |
| 被留下的人 | 站在原地，第一反应是收拾（收拾是最诚实的动作） |
| 台词类型 | 事务句：钥匙在哪、东西什么时候取、账已经清了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 走的是谁 | 她走 | 他走（他的退出权见 [22-分手与复合](22-分手与复合.md) 卷首） |
| 说不说明理由 | 说了，只说一遍 | 不说（更冷，也更容易被读成赌气） |
| 事务量 | 全部办完 | 只办一件，留一个钩子 |
| 之后 | 断干净（[22-分手与复合 · 没有复合](22-分手与复合.md#十--没有复合)） | 留一条缝（[22-分手与复合 · 谁先低头](22-分手与复合.md#八--谁先低头)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 最后一笔账转完，备注栏她填的是日期 | 他把家电说明写完才走 |
| 内心 | 疼是疼的，排在事务后面 | 我不能留一个烂摊子给她 |
| 好的处理 | 理由她说了一遍，之后不再重复 | 他没有一句怨话，怨全在那张便条的字迹里 |
| 写崩 | 写成她甩下一句绝杀台词 | 写成他歇斯底里 |

#### 写崩的三种方式

1. 把离开写成惩罚。 离开是止损，写成「让对方后悔」就矮了一截，还给复合埋了一条廉价的路。
2. 让挽留有效。 这一场的挽留必须全部失败；有效的挽留属于 [七 · 原谅的价格](#七--原谅的价格)。
3. 收在崩溃的画面上。 收在事务上刀才进得深：转账、便条、推回原位的椅子。

> 她把椅子推回桌下，去阳台收了自己的两件衣服。他站在客厅门口，同一句话说了三次，每次换一个说法。她都听完了，听完点头。
> 「钥匙在鞋柜上。」她说。
> 电梯来得很快。门要合上时她伸手挡了一下。她没打算回去。是他跟出来了，她怕夹着他。
> 车里她坐了四十秒才发动。四点半有个会，她没请假。

## 九 · 误会型

`T` ｜ ⚠️NTR（伪NTR／误会流，tag 照标）｜ 全谱系 ｜ 语料频次：误会 35.1% ＋ 隐瞒 4.7%

**骨架**｜全场是误会。读者先于角色知道，还是后于角色知道，两种排法两种文。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 一个真实的可疑事实，经得起复查，不是巧合 |
| 2 | 当事人不解释的理由。这一拍决定误会能撑多久 |
| 3 | 误会成立，痛感按 NTR 的规格收 |
| 4 | 中途一次险些解开的机会，被一件小事错过 |
| 5 | 真相的第一块碎片，由物件或第三人带来 |
| 6 | 解开。被误会方的第一句话决定这一场值不值 |
| 7 | 退款：事实撤销，痛感留着，中间说过的狠话不撤销 |

#### 两种排法

| | 读者先知道 | 读者后知道 |
|---|---|---|
| 读者的位置 | 全程看着当事人受冤 | 与当事人同步受骗 |
| 情绪 | 钝痛，每场同框都在等解开 | 惊雷，解开时读者与角色一起松 |
| 风险 | 拖久了读者急躁，转头骂角色蠢 | 解开若不严丝合缝，读者觉得被耍 |
| 长度上限 | 短，越短越好 | 可以长，线索要提前埋 |
| 配套 | 第三方视角的一两句提示 | 不给任何越界的视角 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 可疑事实 | 一笔转账 · 一次同行 · 一个孩子 · 一间房的租约 · 一张合照（照片 2.0×） |
| 不解释的理由 | 替人守秘 · 说了会伤到第三方 · 以为对方不会信 · 说清这件要先承认另一件更难说的 |
| 错过的机会 | 话说到一半来了电话 · 递到手里的东西被人拿走 · 一句问句用了陈述的语气 |
| 真相载体 | 一张收据 · 一个称呼 · 一个不在场的人随口的一句话 |
| 台词类型 | 解开那一刻的第一句：问对方这段日子怎么过的，而不是自辩 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 误会的方向 | 他被误会 | 她被误会（她连解释的习惯都没有） |
| 不解释的成色 | 有硬理由 | 只有骨气（掉价，慎用） |
| 退款范围 | 全退，事实全假 | 半退：确实有一段没说（[28-误会与信任 · 看见的那一半](28-误会与信任.md#一--看见的那一半) 的半灰版） |
| 解开之后 | 直接进重建 | 先算「为什么不问我」这笔新账 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 解开之后她第一句问的是他这一个月怎么过的 | 他不解释的那一刻，理由在他心里成立得很完整 |
| 内心 | 我查了，我信了我查到的 | 说出来要牵出另一个人 |
| 好的处理 | 她道歉，道歉用的是事实句 | 他不居功，也不说「我早说过」 |
| 写崩 | 写成她揪着不放三章 | 写成他为了骨气硬扛到底 |

#### 写崩的三种方式

1. 藏 tag。 伪NTR 照样按 NTR 标，读者按方向避雷；真相能退款，预警不能。
2. 用巧合堆误会。 每一层都要有人的选择在里面，堆巧合等于让读者赌气。
3. 解开即痊愈。 狠话不跟着事实一起撤销，那几句要在 [十 · 信任的重建](#十--信任的重建) 里单独还。

后接：[十 · 信任的重建](#十--信任的重建)

## 十 · 信任的重建

`M` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：和好 36.1% ＋ 同居 21.1%

**骨架**｜危机之后亲密怎么回来。身体比话诚实，也比话慢。

过程与尺度不在这里排，走 [06-尺度与写法](../06-尺度与写法/) 与 [36-亲密的完整结构](36-亲密的完整结构.md)；这里只给恢复的刻度。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 第一次同床。什么都没发生，两个人都醒着 |
| 2 | 一次日常接触失败：她伸手，他躲了半寸，两个人都装作没有 |
| 3 | 谈一次。谈的是具体动作，不是感情 |
| 4 | 重新约定：可以做的、暂时不做的、要先问一声的 |
| 5 | 第一次成功的接触。短，且发生在白天 |
| 6 | 一次退回。进度不是单调递增，退回要写 |
| 7 | 某个平常的晚上，动作自己回来了，没有人宣布 |

#### 恢复的刻度

| 阶段 | 可观察的动作 | 时间感 |
|---|---|---|
| 零 | 同床，背对背，中间空一条 | 第一周 |
| 一 | 白天的手 · 递东西时碰到的指尖 | 两三周 |
| 二 | 睡着之后的靠近（醒着做不到的，睡着做得到） | 一个月上下 |
| 三 | 主动的一次，且由被绿方主动 | 不定，可能永远停在二 |
| 四 | 动作自己回来了 | 没有日期 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 床中线 · 他的枕头挪回来的那天 · 两条毛巾又挂到一起 · 她重新用回那瓶搁置的沐浴露 |
| 失败的形态 | 躲了半寸 · 手放上去又拿开 · 灯的开关按了一半 |
| 谈话的语言 | 只说动作不说感情 · 用「先」和「暂时」 · 谁都不许说「随便你」 |
| 回来的信号 | 他睡着之后翻身找她 · 她伸手之前不再先看他的表情 |
| 台词类型 | 陈述句报进度：今天可以、今天不行、明天再说 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先主动 | 被绿方（重，且真） | 出轨方（容易被读成赎罪，慎用） |
| 恢复速度 | 三个月 | 一年以上，或者停在阶段二 |
| 有没有退回 | 有（常态） | 没有（会假） |
| 落点 | 身体先回来，话后回来 | 话回来了，身体一直没回（BE 侧的一种，须前置） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她伸手之前先看了一眼他的肩膀 | 睡着之后他翻身，手落回原来的位置 |
| 内心 | 我不想让他觉得这是考试 | 我怕的不是她碰我，是我自己躲 |
| 好的处理 | 「暂时不做」的那几项她自己也守着 | 他先说出躲的那半寸，说得像在陈述天气 |
| 写崩 | 写成一场情热抹平一切 | 写成他从此对亲密关闭 |

#### 写崩的三种方式

1. 用一次亲密收尾。 危机的账不在身体里结，身体只是刻度表。
2. 进度单调递增。 每一场都比上一场近，读起来像打卡；退回那一拍是可信度的来源。
3. 把谈话写成表白。 重建期的谈话只谈动作与时限，抽象的承诺到这个阶段没有购买力。
