## 一 · 第三个人的影子

`T` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：吃醋 43.1% ＋ 社交网 33.9%（悬置期无独立族）

**骨架**｜最难熬的是还没确定的那段日子。一条消息、一个名字、一股香味，哪样都能拿来哄自己。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 第一件小事：消息晚回了十分钟，理由张口就来 |
| 2 | 第二件：他嘴里冒出同一个名字两次，第二次比第一次顺口 |
| 3 | 自己说服自己，每件小事都找个解释，解释都还像样 |
| 4 | 第三件是实在的：家里多出一样不该有的东西，或者身上沾了不该有的气味 |
| 5 | 心里在意了，嘴上不承认，这段最熬人 |
| 6 | 明明查得清，偏偏不查，或者查到一半放下 |
| 7 | 悬着的心落了地：撞见了、说开了，或者什么事都没有 |

第 7 拍有三个出口，选了哪个，后面九条就跟着走哪条路。悬着的日子拖多久，这段戏就有多长。事情一旦坐实，后面就全是清算。

#### 可用细节

| 类 | 内容 |
|---|---|
| 信号物 | 手机 ✓（1.2×） · 微信 ✓（1.4×） · 改了的备注 · 一件不属于这个家的东西 · 洗衣篮里的味道 |
| 时间刻度 | 回消息从三分钟拖到四十分钟 · 加班固定在每周同一天 · 洗澡时手机带进浴室 |
| 自我说服 | 她替他想的理由比他自己编的还周到 · 他把她的反常归到自己身上 |
| 没查的动作 | 屏幕亮着，人走开了 · 密码知道，输了两位数删掉 · 相册翻到某一页退出去 |
| 台词类型 | 「今天怎么这么晚」——嘴上问事实，耳朵听语气 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁在悬置 | 她一向习惯查证，这回不想查 | 他没有资格去查，只能等 |
| 信号密度 | 三件，间隔很远 | 一周五件，扎堆出现 |
| 出口 | 事是真的 | 事是假的（转 [九 · 误会型](#九--误会型)） |
| 谁先说破 | 当事人自己 | 第三人（[43-第三人与群像 · 她的下属看见了](43-第三人与群像.md#七--她的下属看见了)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 每件小事她都替他圆了过去，圆得太顺 | 她外套上的那股味道，他闻了两次 |
| 内心 | 一查就是不信他，不查就只能自己扛 | 一开口问，他就先低了一头 |
| 好的处理 | 她照常安排，里面多了一项连她自己都没察觉的核对 | 他没问，只是把她的外套挪到通风的地方 |
| 写崩 | 写她一开始就认定了 | 写他哭着质问 |

#### 写崩的三种方式

1. 信号一次给齐。 三件小事挤在一页上，悬着的感觉就没了，小事之间要隔开几天。
2. 让读者比角色先知道太多。 这一段疼就疼在当事人自己的犹豫上。读者手里的证据一多过头，戏就成了等着看笑话。
3. 拿巧合代替自我说服。 每件小事都得有一个当事人真心信的解释，解释立不住，人就像瞎了一样。

## 二 · 他看见了

`T` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：误会 35.1%（目击拍）＋ 隐瞒 4.7%

**骨架**｜男受视角。那晚他全看见了，一整夜却装得若无其事。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 亲眼看到了，画面摆在眼前，用不着猜 |
| 2 | 第一反应是躲，不是冲上去 |
| 3 | 回家。他先到，饭已经做上了 |
| 4 | 她到家，他照旧接过包，照旧添汤 |
| 5 | 夜里他睡不着，把看见的画面又过了一遍 |
| 6 | 天亮前他定了：说，还是不说 |
| 7 | 不说的版本：第二天他多了点温柔，她察觉到了 |

这类男主向来是受欺负的一方，没底气去质问谁。所以第 2 拍他躲开是本能，第 5 拍他先怪的是自己，根本想不到去追问她。

#### 目击之后的两条路

| | 说破 | 收着 |
|---|---|---|
| 当晚 | 话一出口，屋里没了声音 | 饭照常吃，他还多盛了碗汤 |
| 代价 | 她得当场给个答案 | 他独自扛着，每多扛一天就多受一天 |
| 风险 | 问得太早，万一是误会还得收回来（[九 · 误会型](#九--误会型)） | 拖得太久，他还没崩，读者先没了耐心 |
| 后面接 | [四 · 对峙桌](#四--对峙桌) | [七 · 原谅的价格](#七--原谅的价格) · [八 · 不原谅](#八--不原谅) |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓ · 玄关 ✓（2.0×） · 饭做到一半 · 他给她留的那盏灯 · 碗洗到一半 |
| 目击现场 | 站在原地，兜里的手攥紧 · 回去的路绕了远 · 外套挂了两次才挂正 |
| 夜里 | 他数她的呼吸 · 背对着她睁着眼 · 手机屏幕一亮他就闭眼 |
| 第二天 | 比平时早起十分钟 · 给她挤好牙膏 · 没问她昨天几点回的 |
| 台词类型 | 他说的全是家常话，一个问句也没有 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 目击的清晰度 | 看得一清二楚，没什么可猜 | 只看见了尾巴（转 [九 · 误会型](#九--误会型)） |
| 他的处理 | 当晚就说破 | 忍着不说，忍成一条暗线 |
| 资格感 | 有，他觉得自己有资格问 | 没有，他先认定自己不配（接 [04-委屈与破防 · 我是不是不够好](04-委屈与破防.md#九--我是不是不够好)） |
| 她知不知道他看见了 | 不知道 | 知道，而且在等他开口，更难写，也更疼 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他今天温柔得反常，她懒得多想 | 玄关那盏灯他照样开着 |
| 内心 | 他没问，她松了口气，随即又悬起来 | 我先把饭做完 |
| 好的处理 | 她觉出那半度的温差，暂时没出声 | 他做的每件事都和昨天一样，只有一件不同：没问她累不累 |
| 写崩 | 写她演得太差，当场露馅 | 写他在街上放声大哭 |

#### 写崩的三种方式

1. 让他马上爆发。 男受头一个反应多半是往回缩。爆发留到 [四 · 对峙桌](#四--对峙桌)，还要有人推他一把才炸得起来。
2. 把隐忍写成美德。 忍着其实是在止损，代价却必须写明白。他每多扛一天就多付一天，读者要看得见他在扛。
3. 只把画面给读者看。 要写的是那一晚在他脑子里一遍遍重摆，画面本身两句话就行，别解释。

后接：[四 · 对峙桌](#四--对峙桌) · [七 · 原谅的价格](#七--原谅的价格)
对照：[三 · 她看见了](#三--她看见了)（镜像写法） · [15-秘密与坦白 · 他有一件事没说](15-秘密与坦白.md#一--他有一件事没说)

#### 示例（本库自撰，可直接改写）

> 他先到家。菜是早上就想好的，两个人的量。
> 米下锅的时候他把手机反扣在灶台上。屏幕亮了两次，他没看。
> 她七点四十进门，说今天累。他接过包，挂好，又挂了一次。
> 饭桌上她讲了件公司的事，讲到一半自己笑了。他也笑，笑完把汤给她添上。
> 夜里他背对着她躺着。那个画面他重放了很多遍，每一遍都试着把人重新摆一次：她站左边，那个人站右边；她先走，还是那个人先走。摆到第几遍他不记得了。
> 天亮前他起来热了牛奶，端回床边坐下。他决定了：今天不说。

## 三 · 她看见了

`T` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：误会 35.1%（目击拍）＋ 吃醋 43.1%

**骨架**｜一样的场面，五种女主五种接法，怎么接，人设就全露了。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 撞见了，她没慌，两秒之内把证据收好 |
| 2 | 她转身走，或者径直上前，按情况分两路 |
| 3 | 回去的路上心里已经排好：先问什么、再办什么 |
| 4 | 到家后她照常过日子，照常到让人心里发毛 |
| 5 | 她用掉一次人情：查一回记录、托人问一句、打一个电话 |
| 6 | 查清楚了，她坐着发了一阵呆 |
| 7 | 拿定主意，动手之前她给自己留了退路，或者索性没留 |

#### 五种女主的处理方式

原型的名字取自 [04-人设原型/01-女主原型谱](../04-人设原型/01-女主原型谱.md)。

| 原型 | 处理方式 | 暴露的东西 |
|---|---|---|
| 能力型女 Alpha | 当天查明，第三天摊牌，安排得比开会还清楚 | 她怕自己说话不作数 |
| 清冷寡言型 | 什么也不问，把他的东西从共用抽屉里拿走 | 她下了判决，却不给他申辩的机会 |
| 温柔主导型 | 先问他累不累，然后才问那人是谁 | 她的温柔下面藏着刀 |
| 女帝／权力顶端型 | 先处置第三者，再回头处置他 | 感情和权力照同一套规矩办 |
| 疯批女攻 | 笑着照常过了两个礼拜，第十五天出手 | 她的时间表谁也看不懂，动笔前先替她定一条底线 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓ · 一张拍了但没发给任何人的照片（2.0×） · 车里没熄的火 · 当晚没脱的外套 |
| 她的取证 | 记住时间跟地点 · 拿他上周报的行程对一对 · 该问的人只问一句 |
| 她的照常 | 照样问他今天怎么样 · 照样先给他盛饭 · 照常里没有一处露馅 |
| 真的破绽 | 洗手洗了很久 · 手机反扣在桌上 · 头一回没纠正他坐姿 |
| 台词类型 | 短问句，一次只问一个，问完就等着 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 上不上前 | 上前，当场处理 | 不上前，她要拿到确凿的证据 |
| 动不动用资源 | 动用，下手快且狠 | 忍住不用（转 [05-占有与吃醋 · 独占欲的边界](05-占有与吃醋.md#十--独占欲的边界)） |
| 第三者的处置 | 她先跟第三者算账 | 只处置他，第三者她懒得理，这一种更吓人 |
| 给不给自己退路 | 留了，她已经在打算往后的日子 | 没留（接 [八 · 不原谅](#八--不原谅)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 两秒钟取好证，到第三秒才觉出疼 | 她今晚一切照常，照常到他背后发凉 |
| 内心 | 先把事情办完，疼可以往后放 | 她不问，说明她已经知道了 |
| 好的处理 | 动用资源之前她停了一下，那几秒要写清楚 | 他见她洗手洗了很久，一下全明白了 |
| 写崩 | 写她当场跟第三者撕打 | 写他什么都没察觉，一直装到摊牌 |

#### 写崩的三种方式

1. 让她当场失态。 可以失态，但得挑地方。照她的性子，只会在没人的地方崩溃，不会在停车场就撑不住。
2. 处理得太大众。 换一个女主也照样能用的反应，等于这个人设白立了。照着上表按原型去挑。
3. 把资源写成万能钥匙。 一通电话就什么都查清了，取证就没意思了。动用资源要付出代价，人情也是代价。

## 四 · 对峙桌

`T` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：吵架 15.7% ＋ 坦白 6.5%

**骨架**｜摊牌的那场戏，证据全摆上桌。三个人各坐在哪，决定了这是审问还是清算。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 选地方：家里的饭桌，或者外面找个地方 |
| 2 | 落座：谁坐主位，谁背对着门，第三个人坐在哪 |
| 3 | 东西放上桌：一张照片、一条记录、一样实物 |
| 4 | 先对事实。口气还稳着 |
| 5 | 再问动机。到这儿才撕开 |
| 6 | 有人起身离开。谁走，就等于谁认了输 |
| 7 | 收尾：当场立下一条规矩，或者丢下一句没人接的话 |

#### 三方位置调度

修罗场里权力戏的写法见 [05-剧情套路/02-名场面结构库](../05-剧情套路/02-名场面结构库.md)。这里写日常的版本：还是那张桌子，座位怎么排，输赢就怎么定。

| 配置 | 位置 | 效果 |
|---|---|---|
| 两人对坐，第三者不在场 | 她坐主位，他坐侧位 | 像审判庭，他每句话都像在招供 |
| 两人并坐，证据在对面 | 坐在同一边，照片摊在桌子中间 | 两人一起面对这件事，最容易走到重建 |
| 三人同桌 | 第三者被叫了过来 | 三人里总有一个被当成展品，下笔前先想好是谁 |
| 第三者在场但不说话 | 她只对他说话 | 狠的写法：第三者被当成一件家具 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 摊在桌心的照片（2.0×） · 一杯没人动的水 · 桌上的钥匙 · 谁的手机在桌面上，谁就在被检查 · 锅里还热着的那顿饭 |
| 动作 | 她把证据推过去，不说话 · 他的手在桌下 · 有人把椅子往后挪了两寸 |
| 语言 | 讲事实时用短句 · 谈到动机，就有人问出「什么时候开始的」这类答不上的话 |
| 离席 | 谁先起身 · 起身的人有没有把椅子推回原处，推回去的人还想回来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 主持人 | 她（常态） | 他把她叫到桌前，这一种基本不写 |
| 第三者 | 不在场 | 在场，还比谁都镇定 |
| 证据 | 硬证据：记录、影像 | 软证据：一个讲不清的细节，整场全凭语气撑着 |
| 收场 | 立了一条规矩 | 没有结论，分开睡，第二天接着谈 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把证据推过去，手很稳 | 他盯着那张照片，先想的是她攥着它多久了 |
| 内心 | 我想要真相，用不着对不起 | 她早就知道，一直没出声 |
| 好的处理 | 她只问三个问题，问完就不说话，等着 | 他每句都答得完整，对自己不利的也照实说 |
| 写崩 | 写她像机关枪一样审他 | 写他当场下跪求饶 |

#### 写崩的三种方式

1. 一场戏把全程走完。 事实、动机、判决都塞进一顿饭，后面六条就没东西可写了。对峙桌只处理事实。
2. 让第三者当场认输离开。 认输是省事，这场戏也跟着轻了。
3. 靠一句真相来反转收场。 要反转，就照 [九 · 误会型](#九--误会型) 的排法早早埋好，不然就别用。

## 五 · 他被抢

`T` ｜ ⚠️NTR·逆NTR ｜ 全谱系 ｜ 语料频次：NTR/逆NTR 142 篇 2.5%（文案标签统计实测，四向混计）

**骨架**｜逆NTR 主线。有别的女攻来抢他，看点只有一个：他到底是什么态度。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 另一个女攻出现了，她原本只是来谈正事，和男主一点也不沾边 |
| 2 | 可她随手给出的，恰好是他缺的：一句夸奖、一个位置、一次认真问他的意见 |
| 3 | 他没接，也没躲，只是那天晚回家半小时 |
| 4 | 她没感觉到有情敌，只觉得他身上多了点什么 |
| 5 | 两个女攻见了一面，谁都没说要争，规矩全在动作里 |
| 6 | 有人要他表态。第三者逼和她逼，写法不同 |
| 7 | 他选了谁，又用什么理由说服了自己 |

第 7 拍里理由比结果要紧。他给的理由不沾两边开出的条件，这样他才是个人。

#### 他的意志在哪几拍出场

逆NTR 的雷区，05-01 那版已经标死：他要是全程没得选，读者就当他是个物件。落到场面上，给他三次开口的机会，在下表第 3、6、7 拍，第一次最晚在第 3 拍。

| 拍 | 他的动作 | 漏掉会怎样 |
|---|---|---|
| 3 | 晚回家半小时，是他自己的选择 | 越界写成被动发生的事 |
| 6 | 别人定好时间让他选，他不选 | 他成了两个人分配的东西 |
| 7 | 他说出理由，和两边的条件都不相干 | 结局读起来像拍卖落槌 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 别人递来的名片 · 她给过他一次机会，一份工作、一次进修、一场演出 · 一直没换的门锁 · 停在同一条路上的两辆车 |
| 同框细节 | 谁先喊他名字 · 谁帮他拉椅子 · 谁在他面前提起对方时用了敬称 |
| 他多出来的东西 | 他开始有自己的安排 · 说话前会顿一下 · 第一次为件小事说了不 |
| 她的察觉 | 他不再等她点头 · 她头一回不知道他在忙啥 · 他的手机不再随手递给她 |
| 台词类型 | 第三者一开口是问句，她一开口是安排 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 第三者的路数 | 给人名分和面子 | 惯着、由着、不拦着 |
| 他的动摇 | 始终没松口，戏全在她的害怕上 | 真的动过心，分量更重，也更容易被骂渣 |
| 结局 | 他留下 | 他走了，BE，要早早埋线 |
| 她的应对 | 管得更严，越严他离得越远 | 第一次问他想要什么，有用，但不好写 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他身上多出一样她从没给过的东西 | 那个人问他的意见，问完还等他说完 |
| 内心 | 我给他的都是最好的，为什么还不够 | 有人认真问他一句，他最扛不住这个 |
| 好的处理 | 她没去找别人，回来问他 | 他留下来，不是因为哪边给得多 |
| 写崩 | 写她跟别人比谁给得多 | 写他从头到尾不动，只等结果 |

#### 写崩的三种方式

1. 让两个女攻拍卖他。 两边轮番加价，他夹在中间一声不吭，逆NTR 就成了物权转移。
2. 让第三者靠使坏得分。 下药、造谣、拆信一用上，她就成了障碍，算不上对手。
3. 让第三者自己退出来收尾。 她良心发现主动让开，这一仗就白打了。她得输在他的选择上。

## 七 · 原谅的价格

`T` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：和好 36.1% ＋ 前任 32.1%

**骨架**｜原谅了，事情也没就此过去。日子照常过，欠下的一样一样还。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 决定留下，决定得很快，快得不像大事 |
| 2 | 第一顿饭，两人都在装没事，都装得不像 |
| 3 | 头一道具体的坎：某个词、某个地方、某段时间碰不得了 |
| 4 | 立下一条新规矩：报备、密码、一个再也不去的地方 |
| 5 | 复发一次：半夜翻起旧账，翻完道歉，道歉也不管用 |
| 6 | 三个月后因为一件小事，两人发现自己已经懒得核对了 |
| 7 | 新常态立住了。有一样东西彻底变了，两人都清楚是哪一样 |

#### 价目单

| 项 | 具体形态 | 有效期 |
|---|---|---|
| 收不回的东西 | 一件礼物送不出去了 · 一个称呼不再用 · 一家店不再去 | 永久 |
| 改掉的规矩 | 报备制 · 密码共享 · 每周固定的一晚 | 半年到一年，之后自然作废，或者转成长期 |
| 让出去的位置 | 在某件事上不再有不被过问的权利 | 一直到信任重建 |
| 留给重建的时间 | 至少写满三个月的日常 | 接 [十 · 信任的重建](#十--信任的重建) |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 新密码 · 手机放桌面的新习惯 · 那家不再去的店 · 一件他没扔的旧物 · 冰箱上多出来的日程 |
| 复发的形态 | 深夜翻旧账 · 一个相似的香水味 · 群里一个同名的人发言 |
| 两个人的演技 | 她笑得比平时准时 · 他把「今天见了谁」写成汇报 · 报备报得像交作业 |
| 不再核对的那天 | 她没有问，也压根没想起要问 |
| 台词类型 | 「先这样」「暂时」——都是带期限的词，两人谁也不说「以后」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁原谅谁 | 她原谅他 | 他原谅她，更难让人信服 |
| 原谅的成色 | 真的翻过去了，要写出转折的那一天 | 人留下，心里没原谅（[八 · 不原谅](#八--不原谅) 的孪生版） |
| 规矩的来源 | 被绿一方提的条件 | 出轨一方自己提出（更重） |
| 结束方式 | 规矩自然作废 | 到最后一章规矩还在 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她停掉报备表的那一天 | 他天天发定位，发到后来自己都忘了为什么发 |
| 内心 | 我原谅了，可还在一天天数日子 | 我要让她随时都能找到我 |
| 好的处理 | 她说停就停，不作解释，也不再翻旧账 | 他不辩白，只把每件事都做到经得起查 |
| 写崩 | 写她一句话就原谅了 | 写他哭一场就蒙混过关 |

#### 写崩的三种方式

1. 一顿饭就原谅完了。 决定可以快，日常得长，价目单至少要在三场戏里一项项付清。
2. 把规矩写成惩罚。 报备制是用来止损的，写成刑具就是另一出戏了，要按 [35-规矩的进阶 · 协商桌](35-规矩的进阶.md#二--协商桌) 的框架写。
3. 复发只写一回。 起码写两回，第二回要比第一回轻。

## 八 · 不原谅

`T` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：分手 8.4% ＋ 冷战 19.0%

**骨架**｜分手前的最后一场。走是她自己选的，没人逼。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 主意早就拿定了，这一场只是走流程 |
| 2 | 先了结正事：账目、钥匙、共用的东西 |
| 3 | 吃最后一顿饭，也可能这顿也免了 |
| 4 | 对方发觉人是真要走了，开始挽留 |
| 5 | 挽留的话句句都接住，接得客客气气 |
| 6 | 离开那一下：门、电梯、车，不回头也不加快 |
| 7 | 走后做的头一件事，是一件具体的小事 |

#### 决定与崩溃的分界

| 观察点 | 决定 | 崩溃 |
|---|---|---|
| 时间 | 早定好了，此刻照着办 | 临时才变，全凭心情 |
| 语速 | 慢，每句都说完整 | 快，话也说不顺 |
| 事务 | 事情办完才走 | 人走了，事还悬着 |
| 挽留的效果 | 接得住，劝不动 | 说一句，晃一下 |
| 之后 | 还有别的事要忙 | 脑子里一片空白 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 鞋柜上的钥匙 · 共同账户最后那笔钱 · 没带走的那件衣服 · 删了又没删干净的相册 |
| 她走的样子 | 椅子推回原位 · 走之前把他常开的那盏灯关了 · 车在楼下停了四十秒 |
| 他走的样子 | 把冰箱里的菜全做了 · 留了张便条写家电怎么用 · 把她的东西都放回原位 |
| 被留下的人 | 站在原地，头一个反应是收拾东西，这是最实在的反应 |
| 台词类型 | 事务句：钥匙在哪、东西什么时候取、账已经清了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 走的是谁 | 她走 | 他走（关于他的退出权，见 [22-分手与复合](22-分手与复合.md) 卷首） |
| 说不说明理由 | 说，只说一次 | 不说，更冷，也更容易被看成赌气 |
| 事务量 | 全都办妥 | 只办一件，留下一个钩子 |
| 之后 | 断得干干净净（[22-分手与复合 · 没有复合](22-分手与复合.md#十--没有复合)） | 留下一道缝（[22-分手与复合 · 谁先低头](22-分手与复合.md#八--谁先低头)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 转完最后一笔账，她在备注栏填了日期 | 他写完家电的用法才离开 |
| 内心 | 疼归疼，先把手上的事办完 | 我不能给她留下烂摊子 |
| 好的处理 | 她把理由说了一次，往后不再提 | 他一句怨言都没说，怨气全在便条的字迹里 |
| 写崩 | 写她丢下一句绝杀台词 | 写他歇斯底里 |

#### 写崩的三种方式

1. 把离开写成惩罚。 离开是为了止损，写成「让对方后悔」就低了一截，还替复合铺了一条廉价的路。
2. 让挽留起作用。 这一场里的挽留一定要全部落空，管用的挽留归 [七 · 原谅的价格](#七--原谅的价格)。
3. 停在崩溃的画面上。 停在事务上，刀才扎得深：转账、便条、推回原处的椅子。

## 九 · 误会型

`T` ｜ ⚠️NTR（伪NTR／误会流，tag 照标）｜ 全谱系 ｜ 语料频次：误会 35.1% ＋ 隐瞒 4.7%

**骨架**｜从头到尾是一场误会。读者比角色先知道还是后知道，是两种写法，写出两种文。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 事情是真的，查得到，也没有赶巧的成分 |
| 2 | 当事人为什么不解释，这一拍决定了误会能拖多久 |
| 3 | 误会坐实了，该多疼写多疼，照 NTR 的规格写 |
| 4 | 中途差点解开，却被一件小事岔开了 |
| 5 | 真相冒头：某样东西或某个旁人递来了第一块拼图 |
| 6 | 解开：被冤枉的人开口说的第一句，决定这场戏值不值 |
| 7 | 退款：事没了，疼还在，之前撂下的狠话也还算数 |

#### 两种排法

| | 读者先知道 | 读者后知道 |
|---|---|---|
| 读者的位置 | 从头看着当事人蒙冤 | 和当事人一起被蒙在鼓里 |
| 情绪 | 憋闷，每回同框都盼着说开 | 爆开，真相揭晓时读者和角色一起松一口气 |
| 风险 | 拖久了读者会烦，转头骂角色蠢 | 真相对不上的话，读者会觉得被耍 |
| 长度上限 | 要短，越短越好 | 可以长，但线头要早埋 |
| 配套 | 用第三方视角带上一两句 | 越界的视角一点都不给 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 可疑事实 | 一笔转账 · 一次同行 · 一个孩子 · 一间房的租约 · 一张合照（照片 2.0×） |
| 不解释的理由 | 替人瞒着 · 说了怕伤到别人 · 觉得对方不会信 · 要讲清这个，得先招另一件更说不出口的 |
| 错过的机会 | 话说到一半来了电话 · 递到手边的东西被人拿走 · 明明想问，却用陈述句带过去了 |
| 真相载体 | 一张收据 · 一个称呼 · 一个不在场的人随口说的话 |
| 台词类型 | 揭开那一刻的第一句：先问对方这些日子怎么过来的，不急着辩解 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 误会的方向 | 他被误会 | 她被误会，连解释都懒得开口 |
| 不解释的成色 | 有硬理由 | 就是犟，掉价，慎用 |
| 退款范围 | 全退，事实全是假的 | 半退：确实有一段瞒着没说（[28-误会与信任 · 看见的那一半](28-误会与信任.md#一--看见的那一半) 的半灰版） |
| 解开之后 | 直接进入重建 | 先要过「为什么不问我」这道坎 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 误会解开，她第一句问的是他这一个月怎么熬过来的 | 他不解释的那一刻，心里那套道理已经自圆其说 |
| 内心 | 我查过，查到的我就信 | 一说就得把另一个人牵扯进来 |
| 好的处理 | 她认错，认错时摆出事实 | 他不邀功，也不说一句“我早跟你说了” |
| 写崩 | 写她抓着这事不放，闹上三章 | 写他死要面子，硬扛到底 |

#### 写崩的三种方式

1. 藏起 tag。 伪NTR 也照 NTR 标，读者靠方向避雷。
2. 靠巧合堆出误会。 每一层里都要有某个人自己的选择，全凭巧合堆，读者只会觉得被耍了。
3. 一解开就痊愈。 真相出来了，狠话也不能当没说过，那几句要在 [十 · 信任的重建](#十--信任的重建) 里另外还。

后接：[十 · 信任的重建](#十--信任的重建)

## 十 · 信任的重建

`M` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：和好 36.1% ＋ 同居 21.1%

**骨架**｜危机过后，亲密怎么回来。身体比嘴诚实，也比嘴慢。

过程和尺度的安排见 [06-尺度与写法](../06-尺度与写法/) 和 [36-亲密的完整结构](36-亲密的完整结构.md)，这里不讲。这一条只写恢复到哪一步怎么定。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 第一次躺在一起，什么都没做，两个人都没睡着 |
| 2 | 想碰没碰成：她伸出手，他躲开半寸，两人都没出声 |
| 3 | 认真谈了一回，谈手放在哪、怎么放，感情一句没谈 |
| 4 | 重新约定：能做的、暂时不做的、要先问一句再做的 |
| 5 | 第一次碰成了，时间很短，还是在白天 |
| 6 | 又退了回去。进度不会一路向前，后退也要写 |
| 7 | 某天晚上，谁都没提，手自己伸了过去 |

#### 恢复的刻度

| 阶段 | 可观察的动作 | 时间感 |
|---|---|---|
| 零 | 睡一张床，背对背，中间空一道 | 第一周 |
| 一 | 白天的手 · 递东西时碰到的指尖 | 两三周 |
| 二 | 睡着后的靠近，醒着做不到，睡着了能做到 | 一个月左右 |
| 三 | 主动一次，而且是被绿方主动 | 说不准，可能一直停在二 |
| 四 | 动作自己回来了 | 没有日期 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 床中线 · 他的枕头挪回来的那天 · 两条毛巾又挂到一起 · 她重新用回那瓶搁置的沐浴露 |
| 失败的形态 | 躲了半寸 · 手放上去又拿开 · 灯的开关按了一半 |
| 谈话的语言 | 只说动作不说感情 · 用「先」和「暂时」 · 谁都不许说「随便你」 |
| 回来的信号 | 他睡着之后翻身找她 · 她伸手之前不再先看他的表情 |
| 台词类型 | 陈述句报进度：今天可以、今天不行、明天再说 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先主动 | 被绿的一方，戏重，也真 | 出轨的一方，容易被看作赎罪，要慎用 |
| 恢复速度 | 三个月 | 一年以上，或者停在第二阶段 |
| 有没有退回 | 有，常见 | 没有，会显得假 |
| 落点 | 人先回来，话慢慢跟上 | 话回来了，人始终没回来，这种偏 BE，要早做铺垫 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她伸手前先看了眼他的肩膀 | 他睡着后翻了个身，手落回老地方 |
| 内心 | 我不想让他觉得这是在考他 | 她碰我我不怕，我怕的是自己躲 |
| 好的处理 | 「暂时不做」的那几项，她自己也遵守 | 他先把躲开的那半寸说出来，口气像在说今天阴天 |
| 写崩 | 写一场情热就把一切都盖过去 | 写他从此再不碰亲密的事 |

#### 写崩的三种方式

1. 拿一次亲密来收尾。 危机不该由身体来清算，身体只管记下来。
2. 进度跳着走。 只能一步一步来。 可要是每一场都比上一场更进一步，读起来就像打卡，关键时候退一步，读者才会信。
3. 把谈话写成表白。 重建期间说话只讲具体的动作和期限，这时候空口许诺没人会信。
