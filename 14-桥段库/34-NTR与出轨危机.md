## 一 · 第三个人的影子

`T` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：吃醋 43.1% ＋ 社交网 33.9%（悬置期无独立族）

**骨架**｜确证之前那一段最难熬。一条消息、一个名字、一阵香味，每样都能自己骗自己过去。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 第一件小事：回消息慢了十分钟，理由顺手就有 |
| 2 | 第二件：一个名字从他嘴里蹦出来两次，这次比上次顺溜 |
| 3 | 自己劝自己。每件小事都配个说法，说法还都挺像回事 |
| 4 | 第三件是实打实的：家里多了样不该有的东西，或者身上沾了股不该有的味儿 |
| 5 | 开始上心，嘴上还不认（这段最磨人） |
| 6 | 明明能查清楚，偏不查，或者查一半扔了 |
| 7 | 悬着的那口气落了：撞见了、说开了、或者啥也没发生 |

第 7 拍给了三条出口，你选哪条，后面九条就跟着定哪条。悬置期撑多长，这段戏就有多长。事一旦坐实了，后面全是算账，没别的可写。

#### 可用细节

| 类 | 内容 |
|---|---|
| 信号物 | 手机 ✓（1.2×） · 微信 ✓（1.4×） · 改了的备注 · 一件不属于这个家的东西 · 洗衣篮里的味道 |
| 时间刻度 | 回消息从三分钟拖到四十分钟 · 加班固定在每周同一天 · 洗澡时手机带进浴室 |
| 自我说服 | 她替他想好的理由比他自己想的还周全 · 他把她的反常记在了自己头上 |
| 没查的动作 | 屏幕亮着，人走开了 · 密码知道，输了两位数删掉 · 相册翻到某一页退出去 |
| 台词类型 | 「今天怎么这么晚」——问的是事实，听的是语气 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁在悬置 | 她（习惯查证的人，这次不想查） | 他（没有查的位置，只能等） |
| 信号密度 | 三件，隔得很远 | 一周五件，挤成一堆 |
| 出口 | 事是真的 | 事是假的（转 [九 · 误会型](#九--误会型)） |
| 谁先说破 | 当事人自己 | 第三人（[43-第三人与群像 · 她的下属看见了](43-第三人与群像.md#七--她的下属看见了)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她替他把每件小事都圆过去了，圆得太顺手 | 她外套上那个味儿，他闻了两回 |
| 内心 | 查了就是不信他，不查就得自己扛着 | 问出口就先矮一头 |
| 好的处理 | 她照常安排，安排里多了一项她自己都没留神的核对 | 他没问，只把她的外套挪到了通风的地儿 |
| 写崩 | 写成她一开始就认准了 | 写成他哭着质问 |

#### 写崩的三种方式

1. 信号一次给足。 三件小事挤在同一页，悬置就不成立了；小事之间要隔开日子。
2. 让读者比角色早知道太多。 这一段的痛感来自当事人自己的犹豫，读者手里的证据一超量，戏就变成等着看笑话。
3. 用巧合替代自我说服。 每件小事都要有一个当事人真心接受的解释；解释站不住，人就成了瞎子。

后接：[二 · 他看见了](#二--他看见了) · [三 · 她看见了](#三--她看见了) · [九 · 误会型](#九--误会型)

## 二 · 他看见了

`T` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：误会 35.1%（目击拍）＋ 隐瞒 4.7%

**骨架**｜男受视角。撞见那晚他全看见了，但装了一整夜没吭声。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 亲眼看见。画面就在眼前，不用猜 |
| 2 | 第一反应是躲，不是冲上去 |
| 3 | 回家。他先到，饭已经做上了 |
| 4 | 她回来。他照常接包、照常添汤 |
| 5 | 夜里他翻来覆去，把看到的画面重新摆了一遍 |
| 6 | 天亮前他定了：说，还是不说 |
| 7 | 不说那版：第二天他温柔了点，她感觉到了 |

他在这个类型里一直是挨欺负的那个，哪来的底气质问别人。所以第 2 拍他躲开是本能反应，第 5 拍他先怪自己，压根轮不到去追问她。

#### 目击之后的两条路

| | 说破 | 收着 |
|---|---|---|
| 当晚 | 一句话出口，屋里静了 | 照常吃饭，他多添了碗汤 |
| 成本 | 她必须当场给答案 | 他一个人扛，扛一天算一天利息 |
| 风险 | 问早了，误会那笔账得退（[九 · 误会型](#九--误会型)） | 拖久了，读者先没耐心，他还没崩 |
| 后面接 | [四 · 对峙桌](#四--对峙桌) | [七 · 原谅的价格](#七--原谅的价格) · [八 · 不原谅](#八--不原谅) |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓ · 玄关 ✓（2.0×） · 饭做到一半 · 他给她留的那盏灯 · 碗洗到一半 |
| 目击现场 | 站在原地，兜里的手攥紧 · 回去的路绕了远 · 外套挂了两次才挂正 |
| 夜里 | 他数她的呼吸 · 背对着她睁着眼 · 手机屏幕一亮他就闭眼 |
| 第二天 | 比平时早起十分钟 · 给她挤好牙膏 · 没问她昨天几点回的 |
| 台词类型 | 他说的话全是家常，一句问句都没有 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 目击的清晰度 | 看得清清楚楚，不用猜 | 只看了个尾巴（转 [九 · 误会型](#九--误会型)） |
| 他的处理 | 当天晚上就挑明 | 憋着，憋成一条暗线 |
| 资格感 | 有，他觉得自己问得着 | 没有，他先觉得自己不配（接 [04-委屈与破防 · 我是不是不够好](04-委屈与破防.md#九--我是不是不够好)） |
| 她知不知道他看见了 | 不知道 | 知道，而且就等他开口（更难写，也更扎心） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他今天温柔得不对劲，她懒得琢磨 | 玄关那盏灯他还是开了 |
| 内心 | 他没问，她松口气，松完又提起来 | 我先把饭做完 |
| 好的处理 | 她感觉到那半度温差，先没吭声 | 他干的每件事都跟昨天一样，就一件不一样：他没问她累不累 |
| 写崩 | 写成她演技太差当场穿帮 | 写成他当街嚎啕大哭 |

#### 写崩的三种方式

1. 让他立刻爆发。男受的第一反应通常是缩回去；爆发要留到 [四 · 对峙桌](#四--对峙桌)，而且得有人推他一把才炸得出来。
2. 把隐忍写成美德。收着其实是止损，但代价必须写明白：他多扛一天，账上就多记一天利息，读者得看见这笔账。
3. 只给读者看画面。那一晚的事在他脑子里反复重新摆位，画面本身两句话就够，别解释。

前接：[一 · 第三个人的影子](#一--第三个人的影子) · [28-误会与信任 · 看见的那一半](28-误会与信任.md#一--看见的那一半)（同一个动作，那边写的是误会）
后接：[四 · 对峙桌](#四--对峙桌) · [七 · 原谅的价格](#七--原谅的价格)
对照：[三 · 她看见了](#三--她看见了)（镜像写法） · [15-秘密与坦白 · 他有一件事没说](15-秘密与坦白.md#一--他有一件事没说)

#### 示例（本库自撰，可直接改写）

> 他先到家。菜是早上就想好的，两个人的量。
> 米下锅的时候他把手机反扣在灶台上。屏幕亮了两次，他没看。
> 她七点四十进门，说今天累。他接过包，挂好，又挂了一次。
> 饭桌上她讲了件公司的事，讲到一半自己笑了。他也笑，笑完把汤给她添上。
> 夜里他背对着她躺着。那个画面他重放了很多遍，每一遍都试着把人重新摆一次：她站左边，那个人站右边；她先走，还是那个人先走。摆到第几遍他不记得了。
> 天亮前他起来热了牛奶，端回床边坐下。他决定了：今天不说。

## 三 · 她看见了

`T` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：误会 35.1%（目击拍）＋ 吃醋 43.1%

**骨架**｜女攻视角。同一幕戏，五个女主五种反应；她怎么接，人设就全露了。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 撞见了。她没慌，两秒内就把证据收好了 |
| 2 | 她走人，或者直接上前（这一步看情况分岔） |
| 3 | 回去路上心里已经排好：先问啥、再办啥 |
| 4 | 到家。她照常过日子，照常得让人发毛 |
| 5 | 她花了一次人情：翻一次记录、找个人问、打个电话 |
| 6 | 事查清楚了。她坐着发了会儿呆 |
| 7 | 主意定了，动手前她给自己留了后路，或者干脆没留 |

#### 五种女主的处理方式

原型名从 [04-人设原型/01-女主原型谱](../04-人设原型/01-女主原型谱.md) 取。

| 原型 | 处理方式 | 暴露的东西 |
|---|---|---|
| 能力型女 Alpha | 当天查清，第三天摊牌，安排得比开会还明白 | 她怕的不是失去，是说了不算 |
| 清冷寡言型 | 一句不问，把他的东西从共用抽屉拿走 | 她判了，但不给你申诉的机会 |
| 温柔主导型 | 先问他累不累，问完才问那人是谁 | 温柔是刀鞘，不是刀 |
| 女帝／权力顶端型 | 先收拾第三者，再回来收拾他 | 感情和权力走的是同一套规矩 |
| 疯批女攻 | 笑着照常过了两周，第十五天动手 | 她的时间表没人看得懂，动笔前先给她定条底线 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓ · 一张拍了但没发给任何人的照片（2.0×） · 车里没熄的火 · 当晚没脱的外套 |
| 她的取证 | 记住时间跟地点 · 拿他上周报的行程对一对 · 该问的人只问一句 |
| 她的照常 | 照样问他今天怎么样 · 照样先给他盛饭 · 照常里没有一处露馅 |
| 真的破绽 | 洗手洗了很久 · 手机反扣在桌上 · 头一回没纠正他坐姿 |
| 台词类型 | 短问句，一次一个，问完就等 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 上不上前 | 上前，当场就干 | 不上前，她要的是板上钉钉的证据 |
| 动不动用资源 | 用，又快又狠 | 忍着不用（转 [05-占有与吃醋 · 独占欲的边界](05-占有与吃醋.md#十--独占欲的边界)） |
| 第三者的处置 | 她先找第三者算账 | 只收拾他，第三者她懒得管（这一端更吓人） |
| 给不给自己退路 | 留了，她已经在盘算以后的日子 | 没留（接 [八 · 不原谅](#八--不原谅)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 两秒取完证，第三秒才觉得疼 | 她今晚照常，照常得他后背发凉 |
| 内心 | 先把事办完，疼可以排到后面 | 她没问，那就是已经知道了 |
| 好的处理 | 动用资源之前她停了一次，那几秒写清楚 | 他看见她洗手洗了很久，什么都明白了 |
| 写崩 | 写成她当场撕打第三者 | 写成他毫无察觉，一路装到摊牌 |

#### 写崩的三种方式

1. 让她当场失态。 失态可以有，但要挑地方；她的性格决定了她只会在没人的时候崩，不会在停车场就绷不住。
2. 处理方式太通用。 换个女主也能直接套的反应，等于这个人设白立了，对着上表按原型挑。
3. 把资源写成万能钥匙。 一个电话啥都能查清，那取证还有啥分量？资源得付代价，人情也算。

## 四 · 对峙桌

`T` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：吵架 15.7% ＋ 坦白 6.5%

**骨架**｜摊牌那场戏。证据全甩桌上了，三个人谁坐哪儿，直接决定这是审人还是算账。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 定地方：家里那张饭桌，还是外头找个地儿 |
| 2 | 坐下。谁坐主位，谁背对门，第三个人坐哪儿 |
| 3 | 东西摆桌上：一张照片、一条记录、一件实物 |
| 4 | 先对事实。口气还稳着 |
| 5 | 再问动机。到这儿才撕开 |
| 6 | 有人起身走人。走的是谁，等于认了谁输 |
| 7 | 收尾：要么当场立条规矩，要么撂下一句没人接的话 |

#### 三方位置调度

修罗场的权力戏版本在 [05-剧情套路/02-名场面结构库](../05-剧情套路/02-名场面结构库.md)，这里讲的是日常版：还是那张桌子，谁坐哪儿，谁就赢。

| 配置 | 位置 | 效果 |
|---|---|---|
| 两人对坐，第三者不在场 | 她在主位，他在侧位 | 审判庭。他的每句话都像供词 |
| 两人并坐，证据在对面 | 同侧落座，照片摊在桌心 | 共同面对一件事，最容易走向重建 |
| 三人同桌 | 第三者被叫来了 | 三个人里必有一个是被展示的物品，动笔前先想清楚是谁 |
| 第三者在场但不说话 | 她只跟他说话 | 狠的一种：第三者被当成家具 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 摊在桌心的照片（2.0×） · 一杯没人动的水 · 桌上的钥匙 · 谁的手机在桌面上，谁就在被检查 · 锅里还热着的那顿饭 |
| 动作 | 她把证据推过去，不说话 · 他的手在桌下 · 有人把椅子往后挪了两寸 |
| 语言 | 说事的时候用短句 · 聊到动机了，开始有人问「什么时候开始的」这种答不上来的话 |
| 离席 | 谁先站起来 · 站起来的人有没有把椅子推回去（推回去的还想回来） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 主持人 | 她（常态） | 他（他把她叫到桌前，这头基本不写） |
| 第三者 | 不在场 | 在场，而且比谁都稳 |
| 证据 | 硬的：记录、影像 | 软的：一个说不清的细节，全场靠口气撑 |
| 收场 | 定下一条规矩 | 没结论，各睡各的（第二天再开一场） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把证据推过去，手没抖 | 他看着那张照片，先琢磨她攥了多久 |
| 内心 | 我要的是真相，不是对不起 | 她早知道了，一直没吭声 |
| 好的处理 | 她就问三个问题，问完就闭嘴等 | 他每句都答全了，连对自己不利的也没瞒 |
| 写崩 | 写成她机关枪一样审人 | 写成他当场跪下求饶 |

#### 写崩的三种方式

1. 一场戏走完全程。事实、动机、判决全塞进一顿饭里，后面六条就没得写了；对峙桌只解决事实。
2. 第三者当场认输退场。认输省事，省下来的正是这一场的重量。
3. 用一句真相反转收场。反转要么按 [九 · 误会型](#九--误会型) 的排布提前埋好，要么不用。

## 五 · 他被抢

`T` ｜ ⚠️NTR·逆NTR ｜ 全谱系 ｜ 语料频次：NTR/逆NTR 142 篇 2.5%（文案标签统计实测，四向混计）

**骨架**｜逆NTR主线。别的女攻来抢他，他到底啥态度，这才是唯一的看点。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 另一个女攻冒出来，她本来只是来谈正事的，跟男主没半点关系 |
| 2 | 但她随手给的，正好是他缺的：夸了他一句、给了他个位置、认真问了他意见 |
| 3 | 他没接话，也没躲开。就是那天回家晚了半小时 |
| 4 | 她没觉得来了个情敌，她是觉得他身上多了点东西 |
| 5 | 两个女攻碰了一面。谁都没说争抢的话，但规矩都在举动里 |
| 6 | 有人逼他表态。是第三者逼，还是她逼，写法不一样 |
| 7 | 他选了谁，以及他拿什么理由说服自己 |

第 7 拍的理由比结果重要：理由与两边开的条件都无关，他才是人。

#### 他的意志在哪几拍出场

逆NTR的雷区在05-01已经标死了：他要是全程没得选，读者直接当他是个物件。场面那边怎么落？给他三次开口的机会，最晚别拖过第3拍。

| 拍 | 他的动作 | 漏掉会怎样 |
|---|---|---|
| 3 | 晚回家半小时，是他自己选的 | 越界变成被动出的事 |
| 6 | 别人定好时间让他挑，他不挑 | 他成了被两个人分的东西 |
| 7 | 他讲理由，理由跟两边条件都不沾 | 结局读着像拍卖一锤定音 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 别人递来的名片 · 她给过他一次机会（一份工作、一次进修、一场演出） · 一直没换的门锁 · 停在同一条路上的两辆车 |
| 同框细节 | 谁先喊他名字 · 谁帮他拉椅子 · 谁在他面前提起对方时用了敬称 |
| 他多出来的东西 | 他开始有自己的安排 · 说话前会顿一下 · 第一次为件小事说了不 |
| 她的察觉 | 他不再等她点头 · 她头一回不知道他在忙啥 · 他的手机不再随手递给她 |
| 台词类型 | 第三者开口就是问句，她开口就是安排 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 第三者的路数 | 给人名分和面子 | 惯着、由着、不拦着 |
| 他的动摇 | 一直没松过口（戏全在她怕上） | 真动过心（更重，也更容易被骂渣） |
| 结局 | 他留下来 | 他走了（BE，得提前埋线） |
| 她的应对 | 管得更紧（越紧人越远） | 头一回问他想要啥（管用，但难写） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他身上多了一样她没给过的东西 | 那人问他意见，问完还等他答完 |
| 内心 | 我给的是最好的，怎么还不够 | 有人认真问他一句，比啥都扛不住 |
| 好的处理 | 她没去找别人，她回来问他 | 他留下，不是因为哪边给得多 |
| 写崩 | 写成她跟别人比谁给得多 | 写成他全程没动静，光等结果 |

#### 写崩的三种方式

1. 两个女攻拍卖他。 双方轮流加码，他站在中间不出声，逆NTR 就写成了物权转移。
2. 第三者靠使坏得分。 下药、造谣、拆信一出场，她就不再是对手，只是障碍。
3. 靠第三者自行退场收尾。 良心发现主动让路，这一场就白打了；她要败在他的选择上。

## 七 · 原谅的价格

`T` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：和好 36.1% ＋ 前任 32.1%

**骨架**｜原谅了不代表这事就过去了。日子还得过，账还得一笔笔算。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 决定留下。这个决定很短，短到不像大事 |
| 2 | 第一顿饭。两个人都在装正常，装得都不像 |
| 3 | 第一个具体的坎：一个词、一个地方、一段时间成了雷 |
| 4 | 一条新规矩定了：报备、密码、某个再也不去的地方 |
| 5 | 一次复发。半夜翻旧账，翻完道歉，道歉也没用 |
| 6 | 三个月后的一件小事，两个人发现自己已经懒得去对 |
| 7 | 新常态成了。有一样东西彻底变了，两个人都知道是哪样 |

#### 价目单

| 项 | 具体形态 | 有效期 |
|---|---|---|
| 收不回的东西 | 一件礼物送不出去了 · 一个称呼不再用 · 一家店不再去 | 永久 |
| 改掉的规矩 | 报备制 · 密码共享 · 每周固定的一晚 | 半年到一年，然后自然废止或者转正 |
| 让出去的位置 | 某件事上失去了不被过问的权利 | 到信任重建为止 |
| 留给重建的时间 | 至少三个月的日常，要写满 | 接 [十 · 信任的重建](#十--信任的重建) |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 新密码 · 手机放桌面的新习惯 · 那家不再去的店 · 一件他没扔的旧物 · 冰箱上多出来的日程 |
| 复发的形态 | 深夜翻旧账 · 一个相似的香水味 · 群里一个同名的人发言 |
| 两个人的演技 | 她笑得比平时准时 · 他把「今天见了谁」写成汇报 · 报备报得像交作业 |
| 不再核对的那天 | 她没问，也没想起来要问 |
| 台词类型 | 「先这样」「暂时」——限期的词，两个人都不说「以后」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁原谅谁 | 她原谅他 | 他原谅她（少写，且更难服人） |
| 原谅的成色 | 真翻篇，要写出转折那一天 | 留下来但不原谅（[八 · 不原谅](#八--不原谅) 的孪生版） |
| 规矩的来源 | 被绿方开的条件 | 出轨方自己提的（更重） |
| 结束方式 | 规矩自然废止 | 规矩留到最后一章还在 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把报备表停掉那天 | 他每天发定位，发到后来自己都忘了为啥发 |
| 内心 | 我原谅了，可日子还在数 | 我得让她随时找得到我 |
| 好的处理 | 她说停就停，不解释，也不回头翻旧账 | 他不辩解，只把每件事做到查得到 |
| 写崩 | 写成她一句话就原谅 | 写成他哭一场就混过去 |

#### 写崩的三种方式

1. 一顿饭完成原谅。 决定可以短，日常必须长；价目单至少要在三场戏里逐项付掉。
2. 把规矩写成惩罚。 报备制是止损工具，写成刑具就改姓了，走 [35-规矩的进阶 · 协商桌](35-规矩的进阶.md#二--协商桌) 的框架。
3. 复发只写一次。 一次复发是事件，反复才是真相；至少写两次，第二次的强度要更低。

## 八 · 不原谅

`T` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：分手 8.4% ＋ 冷战 19.0%

**骨架**｜22卷之前最后一场，离开是她自己选的，不是被逼的。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 决定早就做了，这场就是走个过场 |
| 2 | 先把正事清了：账、钥匙、共用的东西 |
| 3 | 吃最后一顿饭，也可能连这顿都省了 |
| 4 | 对方发现你真要走了，开始留你 |
| 5 | 留你的话，每句都接住了，接得客客气气 |
| 6 | 走那一下：门、电梯、车。不回头，也不加快 |
| 7 | 之后干的第一件事，是件具体的小事 |

#### 决定与崩溃的分界

| 观察点 | 决定 | 崩溃 |
|---|---|---|
| 时间 | 早就定好了，这会儿就是照办 | 临到头才变，全看心情 |
| 语速 | 慢，话都说全 | 快，话都说不利索 |
| 事务 | 办完事才挪窝 | 人走了，事还吊着 |
| 挽留的效果 | 接得住，劝不动 | 说一句，晃一下 |
| 之后 | 还有别的事要忙 | 脑子里空空的 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 鞋柜上的钥匙 · 共同账户最后那笔钱 · 没带走的那件衣服 · 删了又没删干净的相册 |
| 她走的样子 | 椅子推回原位 · 走之前把他常开的那盏灯关了 · 车在楼下停了四十秒 |
| 他走的样子 | 把冰箱里的菜全做了 · 留了张便条写家电怎么用 · 把她的东西都放回原位 |
| 被留下的人 | 站在原地，第一反应是收拾（收拾是最实在的反应） |
| 台词类型 | 事务句：钥匙在哪、东西什么时候取、账已经清了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 走的是谁 | 她走 | 他走（他的退出权见 [22-分手与复合](22-分手与复合.md) 卷首） |
| 说不说明理由 | 说了，只说一遍 | 不说（更冷，也更容易被读成赌气） |
| 事务量 | 全部办完 | 只办一件，留一个钩子 |
| 之后 | 断干净（[22-分手与复合 · 没有复合](22-分手与复合.md#十--没有复合)） | 留一条缝（[22-分手与复合 · 谁先低头](22-分手与复合.md#八--谁先低头)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 最后一笔账转完，备注栏她填的是日期 | 他把家电说明写完才走 |
| 内心 | 疼是疼的，但先把手头事办完 | 我不能留一个烂摊子给她 |
| 好的处理 | 理由她说了一遍，之后不再提 | 他没说一句怨话，怨全在那张便条的字迹里 |
| 写崩 | 写成她甩下一句绝杀台词 | 写成他歇斯底里 |

#### 写崩的三种方式

1. 把离开写成惩罚。离开是止损，写成「让对方后悔」就矮了一截，还给复合埋了一条廉价的路。
2. 让挽留有效。 这一场的挽留必须全部失败；有效的挽留属于 [七 · 原谅的价格](#七--原谅的价格)。
3. 收在崩溃的画面上。 收在事务上刀才进得深：转账、便条、推回原位的椅子。

## 九 · 误会型

`T` ｜ ⚠️NTR（伪NTR／误会流，tag 照标）｜ 全谱系 ｜ 语料频次：误会 35.1% ＋ 隐瞒 4.7%

**骨架**｜全场都是误会。读者比角色早知道，还是比角色晚知道，两种写法两种文。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 一件真事，查得到，不是赶巧碰上的 |
| 2 | 当事人为啥不解释。这一拍决定误会能拖多久 |
| 3 | 误会坐实，该多疼就多疼，按 NTR 的规格来 |
| 4 | 中间差点就解开了，结果被件小事岔过去 |
| 5 | 真相露头，东西或旁人递过来的第一块拼图 |
| 6 | 解开。被冤枉的人开口第一句，决定这场戏值不值 |
| 7 | 退款：事没了，疼还在，之前撂的狠话不算数 |

#### 两种排法

| | 读者先知道 | 读者后知道 |
|---|---|---|
| 读者的位置 | 全程看着当事人受冤 | 跟当事人一块儿被骗 |
| 情绪 | 憋得慌，每次同框都盼着说开 | 炸开，真相揭的时候读者跟角色一起松口气 |
| 风险 | 拖久了读者烦，回头骂角色傻 | 真相要是对不上，读者觉得被溜了 |
| 长度上限 | 短，越短越好 | 能长，但线头得提前埋 |
| 配套 | 第三方视角带一两句 | 一点越界的视角都不给 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 可疑事实 | 一笔转账 · 一次同行 · 一个孩子 · 一间房的租约 · 一张合照（照片 2.0×） |
| 不解释的理由 | 替人瞒着 · 说了怕伤到别人 · 觉得对方不会信 · 要讲清这个，得先招另一件更说不出口的 |
| 错过的机会 | 话说到一半来了电话 · 递到手边的东西被人拿走 · 明明想问，却用陈述句带过去了 |
| 真相载体 | 一张收据 · 一个称呼 · 一个不在场的人随口说的话 |
| 台词类型 | 揭开那一刻的第一句：问对方这段日子怎么过的，而不是急着辩解 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 误会的方向 | 他被误会 | 她被误会（她连解释都懒得解释） |
| 不解释的成色 | 有硬理由 | 就是犟（掉价，慎用） |
| 退款范围 | 全退，事实全假 | 半退：确实有一段没说（[28-误会与信任 · 看见的那一半](28-误会与信任.md#一--看见的那一半) 的半灰版） |
| 解开之后 | 直接进重建 | 先算「为什么不问我」这笔新账 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她解开绳子，头一句问他这一个月怎么熬的 | 他不解释，那一刻他心里那套理已经圆上了 |
| 内心 | 我查过了，查到的我信 | 说了就得把另一个人也扯出来 |
| 好的处理 | 她认错，认错就摆事实 | 他不抢功，也不来一句“我早跟你说了” |
| 写崩 | 写成她揪着这事没完没了，闹三章 | 写成他死要面子，硬撑到底 |

#### 写崩的三种方式

1. 藏 tag。 伪NTR 照样按 NTR 标，读者按方向避雷；真相能退款，预警不能。
2. 用巧合堆误会。 每一层都得有人自己的选择在里头，光靠巧合堆，读者只会觉得你在耍他们。
3. 解开即痊愈。 狠话不能跟着真相一起当没说过，那几句得在 [十 · 信任的重建](#十--信任的重建) 里单独还。

## 十 · 信任的重建

`M` ｜ ⚠️NTR ⚠️出轨 ｜ 全谱系 ｜ 语料频次：和好 36.1% ＋ 同居 21.1%

**骨架**｜危机过后，亲密怎么恢复。身体比嘴老实，也比嘴慢。

过程跟尺度怎么排，不在这篇里讲，去翻 [06-尺度与写法](../06-尺度与写法/) 和 [36-亲密的完整结构](36-亲密的完整结构.md)。这里只告诉你恢复的刻度怎么定。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 头一回躺一块儿。啥也没干，俩人谁也没睡着 |
| 2 | 想碰一下没碰成：她伸手，他躲了半寸，谁都没吭声 |
| 3 | 摊开来聊了一次。聊的是手放哪儿、怎么放，不是感情 |
| 4 | 重新说好：能做的、先不做的、得问一声再做的 |
| 5 | 头一回碰成了。很短，还是大白天 |
| 6 | 又缩回去了。进度不是一直往前走的，退一步也得写 |
| 7 | 有天晚上，谁也没提，手自己就伸过去了 |

#### 恢复的刻度

| 阶段 | 可观察的动作 | 时间感 |
|---|---|---|
| 零 | 同床，背对背，中间空一条 | 第一周 |
| 一 | 白天的手 · 递东西时碰到的指尖 | 两三周 |
| 二 | 睡着之后的靠近（醒着做不到的，睡着做得到） | 一个月上下 |
| 三 | 主动的一次，且由被绿方主动 | 不定，可能永远停在二 |
| 四 | 动作自己回来了 | 没有日期 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 床中线 · 他的枕头挪回来的那天 · 两条毛巾又挂到一起 · 她重新用回那瓶搁置的沐浴露 |
| 失败的形态 | 躲了半寸 · 手放上去又拿开 · 灯的开关按了一半 |
| 谈话的语言 | 只说动作不说感情 · 用「先」和「暂时」 · 谁都不许说「随便你」 |
| 回来的信号 | 他睡着之后翻身找她 · 她伸手之前不再先看他的表情 |
| 台词类型 | 陈述句报进度：今天可以、今天不行、明天再说 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先主动 | 被绿那方（戏重，而且是真的） | 出轨那方（容易被看成赎罪，慎用） |
| 恢复速度 | 三个月 | 一年往上，或者卡在第二阶段 |
| 有没有退回 | 有（常见） | 没有（会显得假） |
| 落点 | 人先回来，话慢慢跟上 | 话回来了，人一直没回来（偏 BE 的一种，得提前铺垫） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她伸手之前先看了一眼他的肩膀 | 睡着之后他翻身，手落回原来的位置 |
| 内心 | 我不想让他觉得这是考试 | 我怕的不是她碰我，是我自己躲 |
| 好的处理 | 「暂时不做」的那几项她自己也守着 | 他先说出躲的那半寸，说得像在说今天阴天 |
| 写崩 | 写成一场情热把啥都盖过去了 | 写成他从此再也不碰亲密事 |

#### 写崩的三种方式

1. 用一次亲密收尾。 危机这笔账，身体不负责清算，它只负责记录。
2. 进度别跳，一步步来。 每一场都比上一场更进一步，不然读起来像打卡；关键时候退一步，读者才信。
3. 把谈话写成表白。 重建期的对话，只说具体动作和期限，空头承诺到这时候没人买账。
