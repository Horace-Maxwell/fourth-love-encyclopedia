## 换皮的判据

大部分「换皮失败」都是同一个错误。道具换了。机关没换。

每条桥段都有一个机关，也就是它靠什么产生情绪。换皮时道具可以全换，机关必须原样保留。

| 桥段 | 道具 | 机关 |
|---|---|---|
| 等门与热菜 | 微波炉、保鲜膜 | 可重复的物质动作把时间显影 |
| 玄关的灯 | 灯 | 一个不说话的持续在场 |
| 数到三 | 数字 | 不说出后果的空白 |
| 她随手给的东西 | 一支笔 | 同一物在两人心里的重量差 |
| 重逢的第一眼 | 机场出口 | 找错两次之后的那一下认出 |

判据只有一句：换完之后，那个机关还在不在。

古代版把微波炉换成灶上的砂锅，「反复加热」这个动作还在，戏就还在。换成「她一直没回来，他很难过」呢？道具没了，机关也没了。那叫删戏。

## 十一个世界的换皮清单

### 古代女尊

这一档最省事。它自带一整套可见的等级语汇，成本最低，收益最高。

| 现代靠什么表达 | 古代用什么 | 优势 |
|---|---|---|
| 称呼的亲疏 | 称谓与位次 | 制度化，旁人也能读懂 |
| 心意 | 信物（玉佩、络子、帕子） | 物理可见、可佩戴、可被夺回 |
| 时间流逝 | 更漏、灯烛、香计时 | 天然的计时器 |
| 亲密动作 | 挽发、正冠、系带 | 礼制含义，代整即代认 |
| 公开承认 | 赐座、唤封号、列入名录 | 一个词等于一道令 |
| 责罚 | 家规、府规、跪与叫起 | 有制度支撑，冲突来源更丰富 |

这里有个陷阱。古代女尊的制度让很多行为「合法」，因而越界会变得不易察觉。禁足、责罚、人身依附在制度上说得通，正因为说得通，文本更需要自己有判断。见 [08-规训日常版 · 规矩的边界](08-规训日常版.md#十--规矩的边界)。

相关规则见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md) 与 [03-世界观设定](../03-世界观设定/)。

### 修仙

修仙胜在尺度。等一晚可以写成守一百年。

| 现代的量级 | 修仙的量级 | 能写出的东西 |
|---|---|---|
| 等一晚 | 守一百年 | 等待的极限形态 |
| 藏了半年的礼物 | 炼了三百年的法器 | 准备期拉到不可思议 |
| 她忘了三个月前的事 | 她忘了三百年前的事 | 记忆不对称的极端 |
| 异地三个月 | 洞中一日世上千年 | 时间差成为物理事实 |
| 旧地重游 | 百年后禁制还在 | 没有人来撤过 |

寿元差是修仙版独有的资源。两个人的时间不等速。「他记了三百年她早忘了」在这里是事实，谈不上薄情。

其余对照：

| 现代 | 修仙 |
|---|---|
| 手机 · 消息 | 传音玉简 · 传讯符 |
| 门锁 · 钥匙 | 禁制 · 洞府权限 |
| 药 · 体温计 | 丹药 · 探脉 · 灵力查探 |
| 结婚 · 戒指 | 结契 · 本命契印 |
| 生病 | 走火入魔 · 心魔 · 渡劫 |
| 出差 | 闭关 · 历练 |

### 星际

星际胜在延迟。通讯要等，两个人的时间还会错开。

| 装置 | 能写出的东西 |
|---|---|
| 光速延迟 | 对话不可能同步。他说完要等四小时才知道回答，这四小时他会把自己的话反复回想 |
| 跃迁静默 | 强制失联，且不是任何人的错 |
| 相对论时差 | 她过了两年，他过了八年 |
| 权限系统 | 「他没换密码」= 抗拒是姿态，留门是真心 |
| 生命体征遥测 | 身体状态可被远程读取，隐瞒变得困难 |
| 低重力 / 失重 | 「她抱不动他」这个物理难题被解决了 |

其余对照：

| 现代 | 星际 |
|---|---|
| 玄关的灯 | 舱门权限一直开着 · 泊位灯 |
| 做饭 | 合成食物调参数 · 真食材配额 |
| 手机 | 终端 · 通讯频道 |
| 家 | 舱室 · 泊位 |
| 生日 | 地球历的某一天，舰上没人过 |
| 送站 | 登舰口 · 跃迁前最后的通讯窗口 |

### 末世

末世胜在稀缺。资源不够，每个日常动作都要付代价。

| 现代 | 末世 | 代价 |
|---|---|---|
| 做一顿饭 | 用掉了省下来的罐头 | 这顿饭是从生存里省出来的 |
| 留一盏灯 | 烧掉了发电机的燃料 | 等待有了成本 |
| 送礼 | 一样不能吃不能用的东西 | 纯粹的浪费，因而纯粹 |
| 洗头 | 用掉三天的水 | 亲密变成奢侈 |
| 守夜 | 真的有危险 | 守着不睡不是情话，是职责 |

末世版的通用效果：把所有温柔都变成有价的。比起现代版，它只多这一样。但这一样极强。

### 武侠

落差来自武功与江湖地位：武功一场打斗就能定，江湖地位靠传闻与战绩累积，比武功耐久。恩义是江湖唯一成文的法律，一次救命之恩可以合法换来一生的人身依附。

| 桥段 | 武侠等价物 |
|---|---|
| 等门与热菜 | 灶上煨了三回的那壶酒 · 客栈留的一盏灯与一副碗筷 |
| 玄关的灯 | 后门的门闩一直没落 |
| 消息已读不回 | 信鸽回来了，脚环是空的 |
| 查手机 | 翻他的书信匣 · 摸他袖中那张字条 |
| 擦药与倒吸气 | 上金疮药 · 推宫过血。武侠版天然高频，受伤是常态 |
| 半夜发烧 | 毒发 · 内伤反噬 · 走岔了气 |
| 数到三 | 三招之内 · 一炷香为限 |
| 没收 | 收了他的剑。兵器即身份，收剑重于收手机 |
| 罚站 | 面壁 · 扎马步到天亮 |
| 藏了很久的礼物 | 打了三年的一柄剑 · 攒了十年的一味药引 |
| 见家长 | 拜山门 · 引他见师父 |
| 她给钱，他不要 | 她替他垫了镖银 · 她把他的卖身契买了回来 |

失效的桥段与改法：

| 桥段 | 失效原因 | 改法 |
|---|---|---|
| 困在电梯 · 停电的晚上 | 江湖遍地荒庙空屋，强制独处不稀缺 | 换成地形。只容两人的天险，把随从、身份、江湖规矩一并取消 |
| 他受伤了 · 她受伤了 | 受伤是日常，非常事件的地位没了 | 量级提到「这一次治不好」。武力差被受伤抹平，用一次是转折，用三次读者就不信 |
| 时差与异地 | 江湖没有精确时钟 | 换成约期与误期：说好清明前到，人清明后才到 |
| 她给钱，他不要 | 没有镖银月钱田产的江湖里，金钱一族悬空 | 先立一条经济线，它同时是女主资本权的现成来源 |

### 西幻

落差来源杂：血统爵位、魔力等级、神权、种族差都能与制度绑在一起。契约是最硬的一格，它把「不能离开」写成一条带反噬的魔法规则。

| 桥段 | 西幻等价物 |
|---|---|
| 戒指 | 誓约印记 · 刻在骨上的契纹 |
| 领证那天 | 立誓 · 神前宣誓 · 血契签订 |
| 门锁 · 钥匙 | 塔的准入符文 · 领主印章 |
| 手机 · 消息 | 传讯水晶 · 信使鸟 · 一次性卷轴 |
| 玄关的灯 | 塔顶那盏灯从没熄过 |
| 半夜发烧 | 魔力反噬 · 诅咒发作 · 圣痕灼烧 |
| 药 · 体温计 | 治疗术 · 药剂 · 圣光诊断 |
| 没收 | 收回佩剑与纹章 |
| 立规矩 | 誓约条款，违反自带反噬 |
| 见家长 | 家族引荐礼 · 教会的资格审查 |
| 上族谱 | 纹章上添一格 · 记入谱系卷 |
| 出差前夜 | 远征前夜 · 讨伐令下达那天 |

失效的桥段与改法：

| 桥段 | 失效原因 | 改法 |
|---|---|---|
| 他删了那个人 · 朋友圈的分寸 | 没有现代社交形态 | 找可见的物理动作：他把她的信物从自己纹章上取下来 |
| 立规矩 · 数到三 | 誓约自带强制力，「她盯着他守规矩」这层戏被契约吃掉 | 誓约留一条只有她能开的宽免口子。宽免权比强制权有戏 |
| 她是我上司 · 他失业了 | 只有魔法没有社会时，职务一族无处落脚 | 先写出税、农民、教会与王权之争，再让他被撤去骑士团职位 |
| 寿元差 | 与修仙同构，不必再换一次皮 | 西幻的加值在跨种族：通婚禁令与法律地位差是修仙没有的 |

### 民国

新旧秩序并存，同一个决定被族规与报纸两套标准分别评判。她可以既是当家人又是留洋归来者，两套身份在一个人身上打架。资本、私人武装、政治庇护三样在这里都合法。

| 桥段 | 民国等价物 |
|---|---|
| 消息已读不回 | 电报没有回音 · 信投出租界就断了 |
| 每天的电话 | 每晚的长途，接线员在中间听着 |
| 玄关的灯 | 门房不落锁 · 廊下那盏电灯给他留着 |
| 公开 | 在报上登一则启事 |
| 议论 | 小报花边 · 茶楼里的说法 |
| 见家长 | 族老开祠堂问话 |
| 上族谱 | 入谱排字辈 |
| 领证那天 | 换庚帖与登报结婚启事，新旧两样可以同时办 |
| 家法 · 罚站 | 祠堂跪家法。旧宗法现成，不必自造 |
| 她给钱，他不要 | 月钱与私房 · 她把厂里的股子划到他名下 |
| 出差前夜 | 上船前夜 · 北上那班火车 |
| 藏了很久的礼物 | 托洋行订了两年才到的一样东西 |

失效的桥段与改法：

| 桥段 | 失效原因 | 改法 |
|---|---|---|
| 她改了规矩 | 旧秩序有几百年惯性，不会被一句「都什么年代了」说服 | 改规矩得走利益、暴力、时间三条路之一，且要付价 |
| 困在电梯 · 停电的晚上 | 电梯电灯汽车都存在，但都是稀缺物 | 桥段保留，同时写清谁配用。设施本身即阶级 |
| 一年过去了 | 脱开时局的一年，在民国等于架空 | 把通胀、战事、政权更迭挂上去，时间才有重量 |
| 掉马 · 他有一件事没说 | 私人信息靠人际网络流通，不靠设备 | 走漏改由旧仆、同乡、报馆记者三条线之一；租界一条街之隔换一套规矩，是现成的信息落差 |

### 娱乐圈

落差全部与可见性挂钩：咖位是可计算的等级，合同是可违反的规则，资源分配权决定他接得到什么本子。舆论这一格的执行者是不在场的大众，任何一方都控制不了。

| 桥段 | 娱乐圈等价物 |
|---|---|
| 玄关的灯 | 保姆车停在楼下没走 · 她没撤掉他那个通告 |
| 消息已读不回 | 消息要过经纪人转 · 他的号不在自己手里 |
| 公开 | 官宣 · 工作室声明 |
| 当众宣示 | 红毯上她替他理领口，且有镜头 |
| 被拍到 | 狗仔跟拍。这个皮把「被看」变成物理事件 |
| 朋友圈的分寸 | 微博的分寸：点赞算不算，几点发算不算 |
| 议论 | 热搜 · 词条 · 控评 |
| 没收 | 撤番 · 抽资源 · 换角 |
| 立规矩 | 合同条款与人设手册 |
| 她是我上司 | 她是投资人 · 制片 · 经纪公司老板 |
| 见家长 | 见公司高层 · 见她背后的资方 |
| 合照 | 官方物料，与他手机里那张没发出去的 |

失效的桥段与改法：

| 桥段 | 失效原因 | 改法 |
|---|---|---|
| 掉马 · 他有一件事没说 | 人设是被制度化的角色扮演，他在人前本就不是自己，落差被摊薄 | 掉马对象从她换成粉丝与公众；对她那一版改写成「他连在她面前也在营业」 |
| 哭着睡着 · 躲起来哭 | 私密空间在这里是稀缺资源 | 先造出一间没有镜头的房间，这间房本身就是礼物 |
| 她替他挡 | 想虐就爆黑料、想甜就全网祝福的舆论，机关在作者手上 | 舆论要有自己的惯性：她挡下来的那一次要留后账 |
| 被起哄 · 偏见 | 咖位差写成纯粹的羞辱时戏就断了 | 圈里人都是精算师，他被压番之后要有还手或筹划 |

### 电竞

落差来源是首发权、指挥位与复盘的解释权。战队把「他行不行」直接换算成上不上场，而数据公开，她的判断随时可被全网复核。

| 桥段 | 电竞等价物 |
|---|---|
| 等门与热菜 | 训练室凌晨那份还热着的宵夜 |
| 玄关的灯 | 训练室的灯给他留着 |
| 消息已读不回 | 队内语音里他不开麦 |
| 罚站 | 加练 · 一个人留下打到天亮 |
| 没收 | 拿掉首发 · 换位置 · 报停赛 |
| 立规矩 | 队规 · 作息表 · 合同里那条注册权 |
| 数到三 | 一个赛季的观察期 |
| 她是我上司 | 她是教练 · 队长 · 俱乐部老板 |
| 他要证明自己 | 复盘数据。他行不行有一份可打印的答案 |
| 出差前夜 | 飞赛区前夜 · 封闭集训前一晚 |
| 被拍到 | 麦没关 · 赛后采访 · 观众席镜头扫过 |
| 时差与异地 | 他转会去了别的赛区 |

失效的桥段与改法：

| 桥段 | 失效原因 | 改法 |
|---|---|---|
| 打游戏 | 游戏在这里是工作，玩闹的机关没了 | 玩闹往非竞技处找：一局不排名的、他教她玩别的、赛季结束那晚打通宵单机 |
| 时间站在他那边 · 她的年龄焦虑 | 选手职业寿命二十四五岁到顶，年龄压力压在年下那一边 | 整条翻面，焦虑的是他、安慰的是她。这是电竞相对其他皮的加值 |
| 她给钱，他不要 | 转会费、违约金、注册权归属都是公开数字，钱在这里没有私密性 | 金钱一族改写成签字权：她签或不签那份转会同意书 |
| 网上的另一个他 | 网遊 GB 在游戏世界内，电竞 GB 在现实赛场，两者的马甲不通用 | 电竞版的马甲是小号与直播间人格，压在现实身份之上，见 [02-术语百科/04-尺度预警与社群黑话](../02-术语百科/04-尺度预警与社群黑话.md) |

### 无限流

能力必须被反复证明：副本里活下来靠真本事，她的强不需要制度背书。代价是感情线笔墨被副本挤占。

| 桥段 | 无限流等价物 |
|---|---|
| 玄关的灯 | 安全屋的灯她留着 · 墙上她的记号还在 |
| 等门与热菜 | 结算间里那份省下来的补给 |
| 数到三 | 副本规则写死的倒计时 |
| 立规矩 | 副本规则。规矩不由她定，她只是先读懂了 |
| 没收 | 收走他的道具 · 不带他进这一场 |
| 半夜发烧 | 副本后遗症 · 精神值跌破线 |
| 擦药与倒吸气 | 结算后疗伤，药剂按积分计价 |
| 藏了很久的礼物 | 攒了几十场积分换来的、对通关毫无用处的一样东西 |
| 她的秘密 | 这个副本她进过几次 |
| 时差与异地 | 两个人被分进不同副本 |
| 重逢的第一眼 | 结算大厅里他还站着 |
| 失忆后重新认识 | 副本清洗记忆，只有她记得上一轮 |

失效的桥段与改法：

| 桥段 | 失效原因 | 改法 |
|---|---|---|
| 01、17、18 三卷的日常族 | 副本占满时间，日常没有场地 | 全部塞进休整期。日常在这里是稀缺品，一顿饭的分量顶别的世界十顿 |
| 她早知道 · 知道结局的人 | 预知若永不失效，机关空转 | 配一次失灵。她的优势是七分钟，不是一百年 |
| 见家长 · 上族谱 · 领证那天 | 社会制度在副本里不存在 | 只能落在主世界回归段，或改写成幸存者之间的私约 |
| 他为什么不走 | 这个皮替作者回答了：他走不出去 | 省下的这一笔要还回去。强制关系的落差不该恒定，靠自愿动作补差 |

### 非人 / 异种

落差来自身体与时间尺度的不对等。寿命差这一格的特殊处在于落差不来自强弱，来自她见过太多次这种事。契约与初拥把从属关系写成生理事实。

| 桥段 | 非人 / 异种等价物 |
|---|---|
| 戒指 | 血契 · 初拥 · 一片鳞 · 真名 |
| 留痕 | 咬痕即契约，生理与社会含义各占一半 |
| 后颈 | 咬点 · 逆鳞 · 心口的契印 |
| 半夜发烧 | 饥饿发作 · 兽性上头 · 化形不稳 |
| 药 · 体温计 | 她的血 · 安抚仪式 |
| 玄关的灯 | 她给的那道结界口子一直没合 |
| 洗澡之后 | 露出本体。信任暴露的最高一级 |
| 她随手给的东西 | 一片鳞、一根羽、一滴血。对她随手，对他是命 |
| 藏了很久的礼物 | 一样她活了八百年才攒齐的东西 |
| 见家长 | 见族群 · 见她的旧同类 |
| 她的秘密 | 她送走过七个 |
| 一年过去了 | 他老了一岁，她没有 |

失效的桥段与改法：

| 桥段 | 失效原因 | 改法 |
|---|---|---|
| 他比她强了 | 物种能力差是硬的，翻不过来 | 给她一条不能违反的禁忌（不能伤他、不能被看见本体、不能背血契）。绝对力量变成有约束的力量，博弈才回来 |
| 他的易感期一族 | 饥饿与发作和易感期同构，同样带「生理即免责」的陷阱 | 发作可以解释行为，不能取消道歉。整套解法走 [03-世界观设定/02-GB-ABO设定设计手册](../03-世界观设定/02-GB-ABO设定设计手册.md) |
| 差几岁这件事 | 数字差在这里没有意义 | 换成「她送走过几个」。寿命差必须有人在意，否则它只是一个数字 |
| 全部日常族 | 非人只当标签用时，作息、饮食、社交、价值观照搬现代人，这层皮等于没换 | 先定她的时间感、道德感、身体感各偏差多少，日常桥段从那三处长出来 |

以上七节的设定依据见 [03-世界观设定/03-其他世界背景设定](../03-世界观设定/03-其他世界背景设定.md) 对应各节；电竞与无限流在该篇未单列背景，权力落差按 [03-世界观设定/04-非女尊设定下的权力来源设计](../03-世界观设定/04-非女尊设定下的权力来源设计.md) 的职务权、专业能力、信息差三格推演，`【一家之言】`。

### 女A男O（ABO）

这不算一个独立世界。它叠加在任意世界上，是一层生理设定，改变的是某些桥段的正当性来源。

| 桥段 | 普通设定 | 女A男O |
|---|---|---|
| 闻到别人的味道 | 疑神疑鬼 | 生理事实，且他有权不安 |
| 后颈 | 亲密动作 | 腺体，生理要害 |
| 留痕 | 情感标记 | 标记，有明确的生理与社会含义 |
| 半夜发烧 | 生病 | 易感期 · 标记不稳 |
| 戒指 | 承诺 | 永久标记 |

具体规则走 [03-世界观设定](../03-世界观设定/)，本卷不重复。

### 三条改造经验

| 经验 | 说明 |
|---|---|
| 古代版缺通讯，就用**物理距离** | 「已读不回」改成「信送出去没有回音」，且信是可以摸到的，反而更强 |
| 古代版缺私密，就用**礼制** | 现代靠关起门来才有的亲密，古代靠打破规矩来实现，越礼本身就是内容 |
| 星际／修仙缺日常，就**制造稀缺** | 一次真食材、一次通讯窗口、一次出关，稀缺让日常重新有重量 |

## 一个反例

举个例子。「见家长」这条在古代女尊里不能直接搬。

现代版的冲突来自「他靠你养」这类质问，前提是现代社会默认男性该养家。女尊社会里没有这个前提。照搬必然失效。

正确的改造是换掉冲突来源：

| 现代版的质问 | 古代女尊版的等价冲突 |
|---|---|
| 「他一个大男人靠你养？」 | 「他家世配不上你的门第」 |
| 「你怎么什么都听她的？」 | 「他规矩太差，不像正君该有的样子」 |
| 「你委不委屈？」（问她） | 「你要为他推掉那门更好的亲事？」 |

换皮要找的是那个世界里的同位冲突，不是把台词翻译一遍。
