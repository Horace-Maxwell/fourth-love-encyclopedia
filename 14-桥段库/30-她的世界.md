# 她的世界

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**她不是「强」这一个字。这一卷写她的背面——失败、上司、闺蜜、醉、素颜、少女时代——每一条都是防止她变成纸板立牌的支撑柱。**

---

## 为什么要单独给她一卷

对全库做过一次对称性审计：他的委屈有一卷（04），他的撒娇有一卷（03），他的受伤、他的朋友、他的自尊心，处处有专门条目。她呢？她在大多数条目里是「解决方案」，出面、兜底、拍板、哄好。解决方案没有内心，只有功能。

写崩的女主几乎都崩在这里：全书她只输出不消耗，强得没有来路也没有成本。语料的数据戳破了这个立牌：

| 节拍族 | 命中 | 占比 |
|---|---:|---:|
| 醉酒 | 928 部 | 32.1% |
| 闺蜜在场 | 328 部 | 11.3% |
| 卸妆素颜 | 233 部 | 8.1% |
| 受挫 | 231 部 | 8.0% |

**近三分之一的作品写过醉酒场面**：喝醉是语料里她卸甲的第一大通道。这一卷十条，就是十条卸甲通道：她在哪里可以不当解决方案。

写作总则一句话：她的强是皮肤不是骨骼。骨骼是这一卷的十样东西。

## 一 · 她的失败

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：受挫 8.0%

**骨架**｜项目黄了。三年的那个。她开完最后的收尾会，平静地回家，平静地吃饭，平静地洗碗，把一只碗洗了四分钟。

#### 节拍链

失败落定 → 对外的体面收尾 → 回家 → 过度平静期 → 破绽（那只洗了四分钟的碗）→ 他的接近方式 → 她的出口 → 第二天照常上班

#### 时间轴

她的失败没有当天的崩溃，只有延迟的渗漏。当天她是全公司最镇定的人；渗漏从第三天开始：睡眠变浅、洗碗变长、对无关小事的耐心变短。他读的就是这些延迟数据。

#### 她处理失败的方式（与他完全相反）

| | 他的失败 | 她的失败 |
|---|---|---|
| 第一反应 | 找她说 | 谁都不说 |
| 需要的 | 安慰 | 空间——但不是无人的空间，是**有人在但不问的空间** |
| 复盘 | 情绪先行 | 复盘文档她自己写，写完加密 |
| 出口 | 说出来就好一半 | 做点什么才能好：她的哀悼方式是行动（把失败项目的资料整理归档，装订成册——**给死掉的项目办葬礼**） |

**「有人在但不问」是他的考题**：坐在同一个房间各干各的，递水果不递话，这门手艺全库只有这一条教。

#### 可用细节

| 类 | 内容 |
|---|---|
| 体面收尾 | 收尾会上她还在给团队兜底：「责任在我，简历里别写这段，写我名字，背书我来」 |
| 渗漏 | 那只碗 ✓ · 半夜他醒来发现客厅灯 ✓ 亮着，她在看那个项目的旧文件——不是不甘，是告别 |
| 他做对的 | 没说「没关系」没说「下次会好」——他说的是：「饿不饿。我下面。」深夜那碗面 ✓ 什么都没解决，什么都解决了 |
| 葬礼 | 归档那晚她让他帮忙打孔装订；装订完她拍了拍册子，说了句「行了」——**「行了」是她的悼词** |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 失败量级 | 项目黄了 | 事业级塌方（公司没了——她的重建期以年计，接 [16-危机与保护 · 一起扛](16-危机与保护.md#十--一起扛)) |
| 渗漏出口 | 洗碗四分钟 | 迁怒了一次（对他，为一件小事——她道歉道得比失败本身更艰难） |
| 他的应对 | 满分（在但不问） | 犯过错（追问「到底怎么了」把她问关机了——他从这次学会的） |
| 葬礼形式 | 装订归档 | 她带他去吃了顿好的：「庆祝。」「庆祝什么？」「庆祝敢做。」——**失败的重新定价** |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「行了」两个字的收音 | 那只洗了四分钟的碗 |
| 内心 | 输了。输得起。输得起这三个字要练很多年。 | 她不需要我说什么，她需要我在——「在」是个动词 |
| 好的处理 | 她的痛感全程行为化，复盘加密件不给读者看全文 | 他的那碗面火候写足：他也紧张，怕水开的声音太响 |
| 写崩 | 写成她秒满血 | 写成他强行开导 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她主理的新政被驳回；退朝后她绕远路走了半城，他在府门口等，手里拎着她爱的那家酒——没温，她喜欢冷的 |
| 修仙 | 冲击金丹失败，道基受损；闭关疗伤前她只带了一样东西：他写的字帖——「看着不心浮」 |
| 星际 | 她主导的航线申请被否；否决函下来那晚他把模拟舱借了两小时——「输给评审会，别输给自己的手感」 |

#### 写崩的三种方式

1. 当天崩溃大哭。 她的失败走延迟渗漏，不走现场爆破。
2. 他一碗鸡汤救全场。 那碗面的全部功效是「在」，不是「治」。
3. 失败无成本满血复活。 「行了」之后她还是会在某个深夜再看一眼那本册子。

## 二 · 她也有上司

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：职场 21.0%

**骨架**｜在家一言九鼎的人，周一早上九点，站在另一间办公室里听训。他撞见过一次，世界观当场重组。

#### 节拍链

她的权力假象期（他以为她是食物链顶端）→ 撞见现场（她被上级驳回／训话）→ 他的震动 → 她的坦然 → 关于「位置」的一课 → 他看她的目光多了一层东西

#### 时间轴

**以他的认知更新为轴。** 撞见之前，她是无所不能的抽象强者；撞见之后，她是「每天也在挨压、然后把压力在进家门前卸掉」的具体的人。具体的人才能被爱到骨头缝里。

#### 撞见现场的写法

| 要素 | 处理 |
|---|---|
| 场景 | 他来送文件／接她下班，隔着玻璃会议室看见：她站着，对面坐着的人在说什么，她在记 |
| 她的姿态 | 不卑不亢地挨训——**挨训也有段位**：她记要点、认错误、不辩解不该辩的、只争该争的那一条 |
| 他的位置 | 站在工位区，进退不得，手里的咖啡 ✓ 慢慢凉掉 |
| 对视 | 她出会议室看见他，愣了半秒，然后如常走过来：「等久了？」——不解释，不遮掩，也不表演坚强 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的上司 | 不写成恶人——写成她的十年后：同样的强，多十年的伤；两人互相尊重互相为难，这才是职场 |
| 车上 | 回程她说了实话：「刚才那单，是我错了。」——**她在他面前承认业务错误，比在他面前哭还罕见** |
| 他的震动 | 他原以为她的强是天赋，那天起知道是日结的：每天挣，每天花，每天清零 |
| 卸压仪式 | 进家门前她在车里坐三分钟——他后来知道了这三分钟，从此到楼下不催她 |

「车里的三分钟」是这条的核心意象：**家门是她的国境线，三分钟是海关**：工作的那个她不入境。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 上级形态 | 上司 | 甲方／董事会／监管（她的食物链往上还有好几层，层层写实） |
| 他的反应 | 认知更新 | 心疼到想冲进去理论（被她一个眼神按住——事后她说「谢谢你想冲，谢谢你没冲」） |
| 她的态度 | 坦然 | 那天确实狼狈（被越级追责，不公平的那种——她在车里坐了不止三分钟，他把车开去了海边） |
| 长线 | —— | 多年后她成了别人的上司；她训人的方式里有当年那位的影子，也有刻意改掉的部分 |

「谢谢你想冲，谢谢你没冲」，两个谢谢之间是她对他全部的要求：情绪同盟，行动克制。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「是我错了」在车里说出口 | 隔着玻璃那幕的每一秒 |
| 内心 | 他看见了。也好。 | 她站在那里挨训的样子，比她赢的任何一次都让我想娶她 |
| 好的处理 | 她的挨训写出段位，狼狈也狼狈得专业 | 他的心疼不转化为对她上司的敌意——他分得清体系和人 |
| 写崩 | 写成她在职场也无敌 | 写成他替她出头大闹 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她在朝上被御史参、被上位者敲打；他从家仆嘴里拼出朝堂全图，从此她下朝晚了，他的灯 ✓ 一定亮着 |
| 修仙 | 她头上有掌门、有太上长老、有宗规；执法堂领戒尺那次他在门外站了一个时辰——进不去，也不走 |
| 星际 | 她的军衔之上还有七级；晋升答辩被压那晚，他把她的勋章 ✓ 全部擦了一遍，摆回原位，一个字没说 |

「把勋章擦一遍摆回去」，他的表态方式：你的战功我都记得，评审团不算数。

#### 写崩的三种方式

1. 她的职场全知全胜。 无上司的强是玄幻，不是人物。
2. 上司写成纯反派。 她的十年后版本才有信息量。
3. 他撞见后待遇降级。 目光里多的那层是敬意加心疼，不是滤镜碎裂。

## 三 · 她的闺蜜

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：闺蜜 11.3%

**骨架**｜有一个人，认识她比他早十年，存着她所有的黑历史，并且第一次见他就把丑话说在了前头。

#### 节拍链

闺蜜的存在被提及 → 见面（面试局）→ 丑话与考察 → 通过或留察 → 闺蜜成为关系的第三只眼 → 某次危机中闺蜜的立场 → 三人格局稳定

#### 时间轴

**闺蜜的信任进度独立于她的**，且更慢：她三个月就认定了他，闺蜜用了一年半。最后一票投下来的时机，往往在某次她受挫、闺蜜看到他的处理之后。

#### 闺蜜的职能清单

| 职能 | 场面 |
|---|---|
| 史官 | 她的少女时代、旧伤、前任编年史，全在闺蜜脑子里——他想考古只能走这条道，而史官有职业操守：「她的事，她自己说」 |
| 面试官 | 第一次见面的三个问题，问得他后背发汗；末了闺蜜对她说的是：「行，眼睛干净。」 |
| 泄压阀 | 她不对他说的那部分（怕他担心的、关于他的），说给闺蜜——**闺蜜是她唯一的全量备份** |
| 敌我识别 | 谁在背后嚼舌根，闺蜜的情报网比她的快（接 [28-误会与信任 · 好心办坏事的人](28-误会与信任.md#七--好心办坏事的人)：好心设局的多半也是她） |
| 战时同盟 | 两人吵架，闺蜜骂她：「你那个毛病又犯了」——**能骂她的人才是真闺蜜**，无脑站队的是塑料 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 面试局 | 火锅店（闺蜜选的，观察一个人怎么对待服务员和怎么涮毛肚）· 三个问题的最后一个：「她加班到三点的时候，你在干嘛？」 |
| 黑历史 | 闺蜜手机 ✓ 里她大学时期的照片 ✓——他见过一张，笑了一周，被她没收了观看权 |
| 暗号 | 两人有一套完整的眼神语和缩写黑话，他在场时启用——他听不懂，但听得懂「在说我」 |
| 立场 | 那次冷战闺蜜给他打了电话：「我只说一次。她昨天哭了。挂了。」——十一个字，泄露了机密也守住了立场 |

「她昨天哭了。挂了。」是闺蜜文学的标准弹道：**背叛式忠诚**：出卖她的强撑，成全她的关系。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 闺蜜对他 | 一年半后转正 | 永远留察（「我认可你，不代表我不备案」——闺蜜的世界观如此，尊重） |
| 闺蜜自身 | 已婚顾问型 | 单身贵族型（她们的双人夜话是她唯一说「废话」的地方） |
| 危机立场 | 站她但骂她 | 有一次站了他（她要为事业放弃纪念日第三次，闺蜜说「这次你错」——闺蜜的公正是她信任的地基） |
| 他与闺蜜 | 相敬如宾 | 结成地下同盟（她的生日、她的体检 ✓、她的低气压预报，两人共享情报——被她发现后假装生气，实际红了眼眶） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「你那个毛病又犯了」被骂中的沉默 | 十一个字的那通电话 |
| 内心 | 她认识全部版本的我，包括废弃版本 | 面试没通过没关系，我有的是时间刷成绩 |
| 好的处理 | 闺蜜有自己的人生线，不是她的功能件 | 他对闺蜜的敬意真诚：这人替他守了十年他没赶上的她 |
| 写崩 | 写成闺蜜工具人 | 写成闺蜜与他暧昧（这是另一个类型，与本库无关） |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 手帕交／同科进士；面试局设在诗会，考较的是他的字——「字如其人，这人藏不住坏」 |
| 修仙 | 同门师姐妹；面试局是一场切磋，考的不是他的修为，是他护不护得住要害——他护住了，护的是她的旧伤位置：「你怎么知道她旧伤在左肩？」「她冷天会揉。」当场转正 |
| 星际 | 军校同期；面试局在靶场，成绩单不重要，重要的是他打完看谁——「打得一般。看她的次数及格了。」 |

修仙版「她冷天会揉左肩」是全条最好的一颗糖：面试考的从来是观察量，资质只算入场券。

#### 写崩的三种方式

1. 闺蜜只在需要时出现。 史官有自己的编年史。
2. 面试一顿饭通过。 一年半的留察期是闺蜜的尊严。
3. 「能骂她」写丢。 只会站队的闺蜜是背景音。

## 四 · 她喝醉

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：醉酒 32.1%

**骨架**｜她的酒量是商场传说，从没人见她醉过。所以当她真的醉了，他手足无措得像接到一件绝版易碎品。

#### 节拍链

喝的理由（庆功·饯别·闺蜜局·或没有理由）→ 超量 → 醉态启动 → 他接手 → 醉态的完整展演 → 抵家安置 → 第二天的记忆管理

#### 时间轴

**醉是她唯一的合法失控。** 语料里 32.1% 的作品写过醉酒场面，这个类型三分之一的书都懂：她这样的人物，清醒时的每句话都过审，只有酒精能绕过审查制度。醉后台词是她的真话解禁版。

#### 她的醉态谱系（选型用）

| 型 | 表现 | 泄露的 |
|---|---|---|
| 安静型 | 不闹，就是盯着他看，看很久，看笑了 | 平时不许自己这样看 |
| 指挥型 | 醉了还在部署工作，对着他布置明年战略，逻辑严密用词标准——就是对象错了 | 她的操作系统没有关机键，只有换屏 |
| 幼态型 | 数他的睫毛 · 要求再讲一遍他们怎么认识的 · 讲到一半睡着 | 她也想当被照顾的那个，一年就这一晚 |
| 诚实型 | 「我跟你说个秘密」——秘密是「我很怕你哪天觉得我无聊」 | 强者的恐惧清单，平时锁保险柜 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 接手 | 闺蜜来电：「来收人。她说了，只让你来。」——醉了还在做访问控制 |
| 路上 | 背她上楼（接 [06-身体接触 · 被抱起来](06-身体接触.md#八--被抱起来)的反向轴），她在他背上批准了一个并购案 |

## 五 · 卸妆

## 七 · 她哭不出来

`T` ｜ ⚠️亲人离世（变体轴一端） ｜ 全谱系 ｜ 语料频次：哭（反应族）77.5%，本条写的是它的缺席

**骨架**｜该哭的场合，她哭不出来。葬礼上、重逢时、感动处，别人泪如雨下，她站在那里，干着眼眶，怀疑自己坏掉了。

#### 节拍链

催泪场合 → 全场落泪她干着 → 自我怀疑（「我是不是没心」）→ 他的观察 → 眼泪的替代出口被他发现 → 某个毫无道理的时刻，泪崩 → 崩后的她与他

#### 时间轴

**她的眼泪有延迟摆放机制**：现场不出，延迟数日，然后被一个八竿子打不着的触发器引爆：葬礼上没哭的人，两周后因为一支修不好的旧钢笔 ✓ 哭到蹲下。**眼泪从不缺席，只是错位。**

#### 哭不出来的机制（写作用，不作医学陈述）

| 层 | 内容 |
|---|---|
| 装机史 | 「罚站都不哭」的小孩（见 [六 · 她的少女时代](#六--她的少女时代)）——哭在她的系统里被编译成「输」 |
| 岗位要求 | 二十年的谈判桌训练：情绪外露=筹码泄露 |
| 替代出口 | 她的悲伤走别的端口：暴力洗碗、深夜整理旧物、超长距离的走路——**行为是她的哭法** |
| 错位引爆 | 防御系统只设防「该哭的场合」；不设防的小物件（钢笔、旧歌、一碗做得和记忆里一样的汤）从侧门进来 |

| 类 | 内容 |
|---|---|
| 干眼眶现场 | 她在葬礼上是最稳的那个：安排车辆、应对亲戚、扶住哭到腿软的长辈——全场没人发现主事的人一滴泪都没有，除了他 |
| 自我怀疑 | 深夜她问过他一次：「我是不是有问题。」——问得平静，平静本身就是问题的一部分 |
| 引爆现场 | 那支钢笔是逝者送她的成人礼；修笔铺说「零件停产了」——她在铺子门口蹲下去的那一下，两周的账一次结清 |
| 他的接法 | 不劝不拍不说「哭出来就好了」——蹲下来，用身体挡住路人视线，等——**他把街角变成了一个临时的私人房间** |

「用身体挡出一个房间」是这条的名画面：她的崩溃要的是遮蔽，安慰派不上用场。

## 八 · 她的追星角落

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.0%

## 九 · 她羡慕他的松弛

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：受挫 8.0% ＋ 夜深 37.5%

**骨架**｜他午睡说睡就睡，快乐说来就来，一支雪糕能高兴一下午。她盯着他看，像在看一种自己失传已久的技术。

#### 节拍链

日常对照（他的松弛与她的紧绷同框）→ 她的观察 → 某天她说出那句话（「你怎么做到的」）→ 他愣住（从没觉得这是技术）→ 教学尝试 → 失败的滑稽与成功的一小步

#### 时间轴

**这条的进度以「她的一小步」计**，极慢且反复：学会周末上午不看手机 ✓（坚持了两周，破功，再来）、学会吃饭时只吃饭、学会「什么都不干」着躺十分钟——第十分钟她开始心率不齐，这是全条最疼也最好笑的一笔。

#### 两种操作系统的对照表

| 场景 | 他 | 她 |
|---|---|---|
| 排队 | 观察前面小孩的帽子，自得其乐 | 已在心里重构这家店的动线效率 |
| 假期第一天 | 睡到自然醒，幸福感满格 | 九点自动醒，躺着列了明天的清单，充满负罪感 |
| 计划外下雨 | 「正好，看雨。」 | 立刻计算全天日程的连锁调整 |
| 一支雪糕 ✓ | 一下午的快乐 | 「这个糖分」——说完看见他的表情，把后半句咽了 |

**她的紧绷是功勋，不是毛病**：她的一切都是这套系统挣来的。所以这条不写「她该改」，写她想给自己放个假，而他是唯一的度假地。

#### 可用细节

| 类 | 内容 |
|---|---|
| 那句话 | 「你怎么做到的？」问得认真到他以为在谈业务 |
| 他的教学 | 「教不了……你饿了会教别人饿吗？」——**松弛对他是体质不是技术**，这个答案让她更羡慕了 |
| 笨拙练习 | 「什么都不干十分钟」挑战：她第三分钟伸手够手机被他按住，第七分钟开始用脚打拍子，第十分钟宣布「这比开董事会累」 |
| 传染 | 教不会，但会传染：和他在一起的第几年起，她排队时也开始看小孩的帽子了——**松弛不是学会的，是待在松弛的人身边泡会的** |

| 她的羡慕 | 明说 | 不说（只是看他的目光越来越长——他被看毛了：「我脸上有字？」「有。写着『会活』。」） |

| 长线 | 传染成功一小块 | 她的松弛只在他在场时启动——他不在，系统回滚；这个依赖她知道，且不打算修复 |

「碎过一回就改握法了」，他的松弛有来历时，这条从生活散文升格为两种幸存者的相认。

「没什么好看，就是好看」，古代版他的一句话，是松弛的最好定义：**无目的性**。她的世界里第一次有东西不需要理由。

#### 写崩的三种方式

1. 把她写成该被治疗的病人。 紧绷是功勋，松弛是度假——不是对错。
2. 他的松弛写成懒。 松弛是在场能力，懒是缺席——两码事。
3. 教学成功。 教不会，只能传染。十年泡出一小块，就是全部战果。

## 十 · 她的体检报告

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：生病 39.0%（她侧用法）

#### 写崩的三种方式

1. 箭头升级成绝症。 这条的题材是「拖」与「怕失控」，不是生死戏——生死戏在 [16-危机与保护](16-危机与保护.md)，分开写。
2. 他的管理写成控制。 策反秘书可以，替她做医疗决定不可以——诊室里做决定的永远是她。
3. 「没锁的抽屉」说破。 暗道一见光就塌。
