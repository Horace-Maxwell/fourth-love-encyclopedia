## 为什么要单独给她一卷

把全库翻了一遍，发现一件事：他的委屈有单独一卷（04），撒娇也有一卷（03），受伤、朋友、自尊心，样样有专门的条目。轮到她，多数条目里她只是来“解决问题”的：出面、兜底、拍板、哄好。

写崩的女主，差不多都是一整本书只往外给、自己从不耗损，强得没来由，也不用付出什么。语料里的数据把这块立牌戳破了：

| 节拍族 | 命中 | 占比 |
|---|---:|---:|
| 醉酒 | 928 部 | 32.1% |
| 闺蜜在场 | 328 部 | 11.3% |
| 卸妆素颜 | 233 部 | 8.1% |
| 受挫 | 231 部 | 8.0% |

**近三分之一的作品写过醉酒场面**，在表里排第一，不过这个数没分是谁喝醉。这一卷十条写的都是她在哪里可以不当解决方案。

## 一 · 她的失败

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：受挫 8.0%

**骨架**｜她干了三年的项目黄了。最后一个会开完，她回家，吃饭，洗碗，一只碗洗了四分钟。

#### 节拍链

失败成了定局 → 在外头把场面圆过去 → 回家 → 装没事的那几天 → 露了馅，一只碗洗了四分钟 → 他怎么靠过来 → 她怎么脱身 → 第二天照常上班

#### 时间轴

他留意的是她那些慢半拍才冒出来的信号。刚出事时，她反倒是全公司最稳的那个，过了几天才漏出来。第三天起，她睡不踏实，碗越洗越久，碰上鸡毛蒜皮的事越来越没耐心。

#### 她处理失败的方式（与他完全相反）

| | 他的失败 | 她的失败 |
|---|---|---|
| 第一反应 | 找她说 | 谁都不说 |
| 需要的 | 安慰 | 空间——**有人在但不问** |
| 复盘 | 情绪先行 | 复盘文档她自己动手写，写完就加密 |
| 出口 | 说出来就好一半 | 得动手做点什么才好得了：她把黄掉项目的资料整理归档，装订成册，**给死掉的项目办葬礼** |

他得学会人在、嘴不问：两个人待在一个屋里各忙各的，他只递水果，不递话。

#### 可用细节

| 类 | 内容 |
|---|---|
| 体面收尾 | 到了收尾会，她还在替团队兜着：「责任在我，简历里别写这段，写我名字，背书我来」 |
| 渗漏 | 那只碗 ✓ · 他半夜醒来，客厅灯 ✓ 还亮着，她在翻那个项目的旧文件，是在跟它告别 |
| 他做对的 | 他没说「没关系」，也没说「下次会好」，只说了句：「饿不饿。我下面。」深夜那碗面 ✓ 什么都没解决，什么都解决了 |
| 葬礼 | 归档那晚，她叫他帮着打孔装订，订好后她拍拍册子，说了声「行了」，**「行了」是她的悼词** |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 失败量级 | 项目黄了 | 整个事业塌了（公司没了，她好几年才缓过来，接 [16-危机与保护 · 一起扛](16-危机与保护.md#十--一起扛)) |
| 渗漏出口 | 洗碗四分钟 | 她为一件小事冲他发了回火，道歉比扛失败本身还费劲 |
| 他的应对 | 满分（在但不问） | 他也犯过错：追着问「到底怎么了」，把她问得关了机，他是从那回学会的 |
| 葬礼形式 | 装订归档 | 她拉他出去吃了顿好的：「庆祝。」「庆祝什么？」「庆祝敢做。」 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「行了」两个字收尾 | 那只洗了四分钟的碗 |
| 内心 | 输了。输得起。可“输得起”这三个字，得练多少年才说得出口。 | 她不用我说什么，我人在就行。 |
| 好的处理 | 她疼都疼在动作上，复盘那段空着，让读者自己猜 | 他煮那碗面的火候写足：他心里也慌，怕水开的声音太响露了馅 |
| 写崩 | 写成她转头就没事了 | 写成他硬劝，跟讲道理似的 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她主持的新政被驳了，退朝后她绕远路走了半座城，他在府门口等着，手里提着她爱喝的那家酒，没温，她爱喝冷的 |
| 修仙 | 她冲金丹没冲过，道基受了损，闭关疗伤前只带了一样东西：他写的字帖，「看着不心浮」 |
| 星际 | 她牵头的航线申请没批，否决函到的那晚，他借来模拟舱两小时：「输给评审会，别输给自己的手感」 |

#### 写崩的三种方式

1. 当天就崩溃大哭。她的失败是一点点渗出来的。
2. 让他一碗鸡汤救了全场。那碗面只是「陪着」，算不上「治好」。
3. 失败了没代价，转眼满血复活。她嘴上说了「行了」，半夜还是会翻出那本册子再看一眼。

## 二 · 她也有上司

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：职场 33.9%

**骨架**｜她在家说一不二，周一早上九点却站在别人办公室里挨训。他撞见过一回，当场三观碎了一地。

#### 节拍链

一开始他以为她站在食物链顶端。后来撞见了现场：她被上级驳回、训话。他愣在那儿，她倒无所谓。这一课讲的是「位置」。从那以后，他看她的眼神多了一层东西。

#### 时间轴

转折只有一天，就是他撞见的那天。在那之前，她在他眼里强得无所不能。那之后，她成了一个具体的人，「每天也在挨压、然后把压力在进家门前卸掉」的那种具体。

#### 撞见现场的写法

| 要素 | 处理 |
|---|---|
| 场景 | 他来送文件／接她下班，隔着会议室的玻璃看见她站着，对面坐着的人在训她，她在记 |
| 她的姿态 | 挨训挨得不卑不亢，**挨训也有段位**：要点记下，错就认，不该辩的不辩，只争该争的那一条 |
| 他的位置 | 他站在工位区，进退两难，手里那杯咖啡 ✓ 一点点凉了 |
| 对视 | 她出了会议室看见他，愣了半秒，随后没事人似的走过来：「等久了？」她不解释，不遮掩，也不装坚强 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的上司 | 别写成恶人，写成十年后的她：一样强，多了十年的伤，两人互相敬着，也互相较劲，写实的职场就是这样 |
| 车上 | 回去的路上她说了实话：「刚才那单，是我错了。」**她当着他的面认错，比当着他的面哭还少见** |
| 他的震动 | 他一直以为她生来就强，那天才知道是攒出来的：每天挣一点，每天花出去，每天归零 |
| 卸压仪式 | 进家门前她会在车里坐三分钟。他后来懂了这三分钟，从此车到楼下也不催她 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 上级形态 | 上司 | 甲方／董事会／监管，她上面还有人，一层压着一层，往写实里写 |
| 他的反应 | 认知更新 | 他心疼得想冲进去理论，被她一个眼神按住了。事后她说「谢谢你想冲，谢谢你没冲」 |
| 她的态度 | 坦然 | 那天她确实狼狈：被越级追责，明摆着是欺负人。她在车里坐了好久，他把车开到了海边 |
| 长线 | —— | 多年后她也成了别人的上司，训人的路数里有当年那位的影子，也有她特意改掉的地方 |

她要他站在她这边，可别替她动手。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 在车里说出口的「是我错了」 | 隔着玻璃那一幕的每一秒 |
| 内心 | 他看见了。也好。 | 她站在那里挨训的样子，比她赢的任何一次都让我想娶她 |
| 好的处理 | 她挨训挨得有水平，狼狈是狼狈，份儿没丢 | 他心疼归心疼，没冲她上司发火，他分得清这事该谁担 |
| 写崩 | 写成她在职场也横着走 | 写成他冲上去替她出头大闹一场 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她在朝上被御史参、被上头敲打，他从下人的话里一点点拼出朝堂上的全貌，往后她下朝一晚，他那盏灯 ✓ 准亮着 |
| 修仙 | 她上头有掌门，有太上长老，还有宗规。她去执法堂领戒尺那回，他在门外站了一个时辰，进不去，也不肯走 |
| 星际 | 她的军衔往上还有七级，晋升答辩被压下来的那晚，他把她的勋章 ✓ 一枚枚擦亮，放回原处，一声没吭 |

#### 写崩的三种方式

1. 她职场上全知全胜。没有上司的强是玄幻。
2. 把上司写成纯反派。写成十年后的她，才有东西可看。
3. 撞见以后她在他眼里掉价。他目光里多的那层是敬意加心疼。

## 三 · 她的闺蜜

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：闺蜜 11.3%

**骨架**｜闺蜜认识她比他早了十年，她的黑历史全攥在闺蜜手里。头一回见面，闺蜜就把丑话说在了前头。

#### 节拍链

闺蜜被提起 → 见面（面试局）→ 丑话说在前头，边处边看 → 过关，或者留校察看 → 闺蜜成了这段关系的监督员 → 出事那天闺蜜站哪边 → 三个人就这样处下去

#### 时间轴

闺蜜往往要亲眼看到他在她受挫后怎么做，才投下最后一票。她三个月就认定了他，闺蜜花了一年半。**闺蜜的信任进度是另一条线**，走得更慢。

#### 闺蜜的职能清单

| 职能 | 场面 |
|---|---|
| 史官 | 她小时候是什么样，从前受过什么伤，交过几个男朋友，闺蜜都记着。他想打听只能去问闺蜜，可闺蜜有规矩：「她的事，她自己说」 |
| 面试官 | 头回见面就抛出三个问题，把他问得直冒汗，最后闺蜜对她说：「行，这人眼神干净。」 |
| 泄压阀 | 有些话她不敢跟他说，怕他操心，偏偏又跟他有关，这些全倒给了闺蜜，**闺蜜是她唯一的树洞，什么都替她存着** |
| 敌我识别 | 谁在背后嚼她舌根，闺蜜比她本人还先知道（接 [28-误会与信任 · 好心办坏事的人](28-误会与信任.md#七--好心办坏事的人)：好心帮倒忙的，多半也是她） |
| 战时同盟 | 他俩吵架，闺蜜骂的是她：「你这老毛病又犯了吧」。**能当面骂她的才是真闺蜜**，只站队不吭声的是塑料姐妹 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 面试局 | 地方是闺蜜挑的火锅店，看一个人怎么对服务员、怎么涮毛肚 · 三个问题里最后一个是：「她加班到三点的时候，你在干嘛？」 |
| 黑历史 | 闺蜜手机 ✓ 里存着她大学时的照片 ✓，他看过一张，笑了一个星期，被她收回了看照片的资格 |
| 暗号 | 她俩有一整套眼神和缩写黑话，专挑他在场时用。他听不懂内容，但听得出「在说我」 |
| 立场 | 冷战那回，闺蜜给他打了个电话：「我只说一次。她昨天哭了。挂了。」十二个字，机密是泄了，立场也守住了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 闺蜜对他 | 一年半后转正 | 一直留校察看，「我认可你，不代表我不备案」，闺蜜看人就是这样，得尊重 |
| 闺蜜自身 | 已婚顾问型 | 单身贵族型，她俩深夜的闲聊，是她唯一肯说「废话」的地方 |
| 危机立场 | 站她但骂她 | 有一回站到了他那边：她要为了事业第三次放掉纪念日，闺蜜说「这次你错」 |
| 他与闺蜜 | 相敬如宾 | 两人结成地下同盟，她的生日、她的体检 ✓、她什么时候要心情低落，情报互通。被她发现后，她假装生气，其实红了眼眶 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 挨了「你那个毛病又犯了」那句骂之后的沉默 | 十二个字的那通电话 |
| 内心 | 她见过我所有样子，连最烂的那版都算 | 面试没过就没过，我时间多，慢慢刷分呗 |
| 好的处理 | 闺蜜有她自己的日子，没整天围着她转 | 他打心底敬重闺蜜：他没能陪着她的那十年，是这个人替他守着 |
| 写崩 | 把闺蜜写成工具人 | 把闺蜜写成跟他暧昧，那属于另一类，这里不管 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 手帕交／同科进士。面试局摆在诗会上，考的是他的字：「字如其人，这人藏不住坏」 |
| 修仙 | 同门师姐妹。面试局是一场切磋，看他护不护得住要害。他护住了，护的是她旧伤的位置：「你怎么知道她旧伤在左肩？」「她冷天会揉。」当场转正 |
| 星际 | 军校同期，面试局设在靶场。成绩单无所谓，要看的是他打完看谁：「打得一般。看她的次数及格了。」 |

#### 写崩的三种方式

1. 闺蜜只在用得着时露面。闺蜜得有自己的日子。
2. 一顿饭就过了面试。闺蜜要看他一年半。
3. 「能骂她」写丢了。闺蜜得能当面骂她。

## 四 · 她喝醉

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：醉酒 32.1%

**骨架**｜她的酒量在圈里出了名，没人见她醉过。真醉的那天，他当场懵了，像捧着一件限量版古董，手都不知道往哪放。

#### 节拍链

为什么喝：庆功、饯别、闺蜜局，或者根本没理由 → 喝过了量 → 醉态上来 → 他接手 → 醉态从头到尾摆一遍 → 到家安顿好 → 第二天两人怎么对付这段记忆

#### 时间轴

从喝过量到送回家安顿好，是一个晚上，戏一直延到第二天怎么对付那段记忆。语料里 32.1% 的作品写过醉酒场面。她这样的人，清醒时每句话都先在心里过一遍审，只有酒能绕过去，醉后说的全是她平时不敢说的真话。

#### 她的醉态谱系（选型用）

| 型 | 表现 | 泄露的 |
|---|---|---|
| 安静型 | 不闹，只盯着他看，看了很久，看着看着笑了 | 平时她不许自己这么看 |
| 指挥型 | 醉了还在安排工作，对着他布置明年的战略，逻辑严密，用词规范，只是找错了对象 | 她醉了也停不下来 |
| 幼态型 | 数他的睫毛 · 非要他再讲一遍两人怎么认识的 · 讲到一半睡着了 | 她也想当被照顾的那一个，一年只有这一晚 |
| 诚实型 | 「我跟你说个秘密」，秘密是「我很怕你哪天觉得我无聊」 | 强的人也有怕的事，平时锁在保险柜里 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 接手 | 闺蜜打来电话：「来收人。她说了，只让你来。」醉成这样，她还在管谁能靠近 |
| 路上 | 他背她上楼（接 [06-身体接触 · 被抱起来](06-身体接触.md#八--被抱起来)的反向轴），她趴在他背上批了一个并购案 |
| 安置 | 他学着给她卸妆（笨手笨脚，接 [五 · 卸妆](#五--卸妆)）· 蜂蜜水 ✓ 放在床头，吸管折好了角度 |
| 记忆管理 | 第二天她跟没事人一样，他也配合着演「你昨晚很乖什么都没说」，**两人都知道对方在演，这场双向假装是温度最高的默契** |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|

| 修仙 | 道心稳的人不轻易掉泪，师门觉得脸上有光。让她破防的是他重伤痊愈后做的一顿家常饭，味道像极了她做凡人时她娘做的，一口下去眼泪就自己掉了，连她都吓了一跳 |
| 星际 | 军人条例里没有哭这一条。让她崩的是一场退役战舰拆解直播，拆的是她开过的那艘。他想关掉，她说「开着」，从头看到尾，满脸是泪，背挺得笔直 |

#### 写崩的三种方式

1. 写成没眼泪的怪事。她会哭，只是哭错了时候。
2. 他把「哭出来」当任务。他只管挡视线。
3. 拿大事当引爆点。越小越不相干，越可信。

## 八 · 她的追星角落

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.9%

**骨架**｜书房里上锁的第三个抽屉，拉开来没有一份合同，全是演唱会周边。她追了二十年的乐队，下个月来办告别巡演。

#### 节拍链

秘密角落被发现（或她自己打开）→ 她的追星史铺开 → 决定去演唱会 → 抢票 → 现场 → 他见到了第四种她 → 这个角落不再藏着

#### 时间轴

**追星史跟她的人生史是并着走的**。高三省早饭钱买的磁带，大学翻墙出去看的第一场live，工作后有了钱却没了时间的那十年。乐队哪年巡演，她那年在干什么，一一对得上。

#### 追星的她（第四种她）

|---|---|
| 公司 | 一种 |
| 家里 | 第二种 |

| 演唱会现场 | **第四种：跟着唱到破音，荧光棒 ✓ 挥得有板有眼，唱到副歌眼睛亮得像十七岁** |

在现场，他最多分一成心思给台上，另外九成都在看她。「我追的星在我旁边追星」，想到这句，他在人堆里笑出了声。

## 九 · 她羡慕他的松弛

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：受挫 8.0% ＋ 夜深 37.5%

**骨架**｜他午睡一躺就着，高兴起来说来就来，一根雪糕能乐一下午。她看着他，像在看一门自己早忘光了的手艺。

#### 节拍链

她平时绷得像拉满的弓弦，他那份松垮她暗中看了很久。终于忍不住开口的那天，他正吊儿郎当地歪在椅子上，她问：「你怎么做到的」。他愣了，从没觉得自己这么过日子算什么本事。后来他试着教她，教得鸡飞狗跳，她总算学会了一点。

#### 时间轴

周末上午不碰手机 ✓，撑了两周破了功，从头再来。吃饭就只吃饭。躺着「啥也不干」十分钟，到第十分钟她慌得不行。进度得按「她的一小步」来算，慢得磨人，还总是反复。

#### 两种操作系统的对照表

| 场景 | 他 | 她 |
|---|---|---|
| 排队 | 盯着前面小孩的帽子，自己乐呵 | 心里把这家店的路线重新排了一遍 |
| 假期第一天 | 睡到自然醒，美得很 | 九点就醒，躺着想明天的事，越想越慌 |
| 计划外下雨 | 「正好，看雨。」 | 马上盘算今天所有安排怎么改 |
| 一支雪糕 ✓ | 能高兴一下午 | 「这糖分……」话到嘴边，看他一眼，咽回去了 |

她绷着是有来由的，现在的地位、底气，全是靠这股狠劲拼出来的。所以这条别写「她该改改」，写她终于想歇口气了，只敢在他这儿躺平。

#### 可用细节

| 类 | 内容 |
|---|---|
| 那句话 | 「你怎么做到的？」她问得太认真，他差点以为是在谈项目 |
| 他的教学 | 「教不了……你饿了会教别人饿吗？」**他生来就这样，没练过**，她听完更羡慕了 |
| 笨拙练习 | 「啥也不干十分钟」挑战：第三分钟她伸手去够手机，被他按住，第七分钟脚开始打拍子，第十分钟她宣布「这比开董事会还累」 |
| 传染 | 教不会，但能传染：跟他在一起的第几年起，她排队时也开始看小孩的帽子了，**松弛学不来，只能在松弛的人身边待久了沾上** |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的羡慕 | 明说 | 不说，只是看他的时候越看越久，把他看得发毛：「我脸上有字？」「有。写着『会活』。」 |
| 他的松弛来源 | 天生 | 也是挣来的，背后有事：大病过一场／家里塌过一回。「攥太紧的都碎过，我碎过一回就改握法了」 |
| 反向 | —— | 他也羡慕她绷得住：「你那种想要就去拿的狠劲，我学不会」。**互相羡慕对方活法**，两头都写才完整 |
| 长线 | 传染成功一小块 | 她只有在他面前才松得下来，他一不在，又缩回去了。她自己清楚，也不打算改 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 十分钟后心跳乱掉 | 「会活」两个字 |
| 内心 | 我赢过那么多人，栽在一根雪糕上 | 她看我的眼神，像在看什么稀奇东西 |
| 好的处理 | 她羡慕是羡慕，可不觉得自己比他差，两条路各有各的仗 | 他不说「你别想了」，只是陪着 |
| 写崩 | 写成有钱人自我检讨 | 写成劝人别努力的鸡汤 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她批折子批到半夜，他在院子里看星星，一看就是一个时辰。她问「星星有啥好看的」，他说「没啥好看，就是好看」，她把这句话琢磨了一夜 |
| 修仙 | 她练快剑，他修随缘。同一片云，她看出的是剑招的走势，他看出的是「像只猫」，路子不同，倒也坐得到一块 |
| 星际 | 她的作息精确到秒，他的日程只有三个字「醒、吃、乐」。跃迁晚了四小时，全舰乱成一锅粥，他睡得正香，她盯着他的睡脸，默默关掉了「延误应急预案」那份文档 |

古代版里那句「没啥好看，就是好看」，讲的是松弛本来就不图什么。

#### 写崩的三种方式

1. 把她写成一个该治的病人。绷着和松着，没有谁对谁错。
2. 把他的松弛写成懒。他松下来的时候，人是在的。
3. 写成教会了。教不会，只能传染，泡十年也就染上一小块。

## 十 · 她的体检报告

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：生病 49.4%（她侧用法）

**骨架**｜体检报告出来，三个箭头。她扫一眼就塞进抽屉，接着开会。他把它从抽屉里翻出来，一项一项查到半夜。

#### 节拍链

体检拖了两年，是他押着去的 → 报告出来 → 她三秒钟就处理完 → 他深夜查资料 → 谈判（复查之战）→ 复查 → 结果 → 两人签下过日子的条约

#### 时间轴

体检一拖就是两年：预约拖，拿报告拖，复查也拖，「等我忙完这阵」那一阵永远忙不完。他在日历上画了个圈，「等我忙完」就成了一个跑不掉的日子。

#### 全库病役分工的倒转

语料里 49.4% 的作品写了生病照顾，绝大多数是他病、她照顾。这条反过来写，要难得多：

| | 他生病 | 她生病（或指标异常） |
|---|---|---|
| 承认 | 会说难受 | 「没事」（她说没事就是有事，接 [01-日常照料 · 半夜发烧](01-日常照料.md#三--半夜发烧)) |
| 就医 | 她押着去，当天就去了 | 他押着去，来回磨了三回 |
| 照顾接受度 | 全盘接受 | 跟他讨价还价：「粥可以，别熬夜陪着」，被驳回了 |
| 深层 | 病了就是病了 | **她怕的是失控**：她把报告塞进抽屉，心里在乎，只是觉得不看就还没发生 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 三个箭头 | 甲状腺结节（复查级）· 某项血值偏高 · 睡眠严重不足带出来的几项，**写实但不写重**：都是压力大的人常见的异常，这里不写绝症戏 |
| 他的研究 | 浏览器 ✓ 的记录里全是医学词条 · 笔记 ✓ 记了三页，标出两个要问医生的问题 |
| 复查之战 | 「下月吧」「明天。九点。挂好了。」「我明天有——」「改了。你秘书批的。」**他把她的秘书拉到了自己这边**，一战成名 |
| 条约 | 复查没事以后签的生活条约：十二点前睡（做到六成）· 咖啡 ✓ 限两杯，她耍赖换大杯，又被补了一条堵上 · 年检不再拖，他直接跟体检中心签了每年自动预约 |

2. 把他管她写成控制她。拉拢秘书可以，替她拿医疗主意不行。在诊室里拍板的永远是她。
3. 把「没锁的抽屉」说破了。暗道见了光就塌。
