# 她的世界

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**她不是「强」这一个字。这一卷写她的背面——失败、上司、闺蜜、醉、素颜、少女时代——每一条都是防止她变成纸板立牌的支撑柱。**

## 为什么要单独给她一卷

全库翻完一遍，发现个事儿：他的委屈单独一卷（04），撒娇单独一卷（03），受伤、朋友、自尊心，全都有专门条目。她呢？大部分条目里她就是来“解决问题”的——出面、兜底、拍板、哄好。可解决问题的人，不需要有内心，只需要有用。

写崩的女主几乎都崩在同一个地方：全书她只输出不消耗，强得没有来路，也没有成本。语料的数据直接戳破了这个立牌：

| 节拍族 | 命中 | 占比 |
|---|---:|---:|
| 醉酒 | 928 部 | 32.1% |
| 闺蜜在场 | 328 部 | 11.3% |
| 卸妆素颜 | 233 部 | 8.1% |
| 受挫 | 231 部 | 8.0% |

**近三分之一的作品写过醉酒场面**：喝醉是语料里她卸甲的第一大通道。这一卷十条，就是十条卸甲通道：她在哪里可以不当解决方案。

写作总则一句话：她的强是皮肤不是骨骼。骨骼是这一卷的十样东西。

## 一 · 她的失败

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：受挫 8.0%

**骨架**｜项目黄了，干了三年的那个。她开完最后的会，回家，吃饭，洗碗，一只碗洗了四分钟。

#### 节拍链

失败落定 → 对外把场面圆过去 → 回家 → 假装没事的那几天 → 露馅，那只碗洗了四分钟 → 他怎么靠过来的 → 她怎么逃出去的 → 第二天照常上班

#### 时间轴

她的失败是过了几天才漏出来的。那天她反而是全公司最稳的一个。漏是从第三天开始的，睡不踏实，碗越洗越久，对鸡毛蒜皮的事越来越没耐心。他看的就是这些慢半拍的信号。

#### 她处理失败的方式（与他完全相反）

| | 他的失败 | 她的失败 |
|---|---|---|
| 第一反应 | 找她说 | 谁都不说 |
| 需要的 | 安慰 | 空间——**有人在但不问** |
| 复盘 | 情绪先行 | 复盘文档她自己写，写完加密 |
| 出口 | 说出来就好一半 | 做点什么才能好：她把失败项目的资料整理归档，装订成册，**给死掉的项目办葬礼** |

**「有人在但不问」是他的考题**——坐在同一个房间各干各的，递水果不递话，这门手艺全库仅有这一条教。

#### 可用细节

| 类 | 内容 |
|---|---|
| 体面收尾 | 收尾会上她还在给团队兜底：「责任在我，简历里别写这段，写我名字，背书我来」 |
| 渗漏 | 那只碗 ✓ · 半夜他醒来发现客厅灯 ✓ 亮着，她在看那个项目的旧文件——她在告别 |
| 他做对的 | 没说「没关系」没说「下次会好」——他说的是：「饿不饿。我下面。」深夜那碗面 ✓ 什么都没解决，什么都解决了 |
| 葬礼 | 归档那晚她让他帮忙打孔装订，装订完她拍了拍册子，说了句「行了」——**「行了」是她的悼词** |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 失败量级 | 项目黄了 | 事业级塌方（公司没了，她缓了好几年，接 [16-危机与保护 · 一起扛](16-危机与保护.md#十--一起扛)) |
| 渗漏出口 | 洗碗四分钟 | 迁怒了一次，对他，为一件小事，她道歉比失败本身还费劲 |
| 他的应对 | 满分（在但不问） | 犯过错，追问「到底怎么了」把她问关机了，他打那回学的 |
| 葬礼形式 | 装订归档 | 她带他去吃了顿好的：「庆祝。」「庆祝什么？」「庆祝敢做。」——**失败的重新定价** |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「行了」两个字收尾 | 那只洗了四分钟的碗 |
| 内心 | 输了。输得起。可“输得起”这三个字，得练多少年才说得出口。 | 她不用我说什么，我人在就行——“在”不是站着，是陪着。 |
| 好的处理 | 她的疼全在动作里，复盘那段留白，读者自己猜 | 他那碗面火候写透了：他也慌，怕水沸声太响露馅 |
| 写崩 | 写成她转头就没事了 | 写成他硬劝，跟讲道理似的 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她主理的新政被驳回，退朝后她绕远路走了半城，他在府门口等，手里拎着她爱的那家酒——没温，她喜欢冷的 |
| 修仙 | 冲击金丹失败，道基受损，闭关疗伤前她只带了一样东西：他写的字帖——「看着不心浮」 |
| 星际 | 她主导的航线申请被否，否决函下来那晚他把模拟舱借了两小时——「输给评审会，别输给自己的手感」 |

#### 写崩的三种方式

1. 当天崩溃大哭。她的失败是慢慢渗出来的，不是当场炸开的。
2. 他一碗鸡汤救全场。那碗面的作用说白了就是「陪着」，不是「治好」。
3. 失败无成本满血复活。嘴上说「行了」，可半夜她还是会翻出那本册子再看一眼。

## 二 · 她也有上司

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：职场 21.0%

**骨架**｜在家说一不二的主儿，周一早上九点站别人办公室挨训，他撞见过一回，当场三观碎了一地。

#### 节拍链

她的权力假象期，他以为她站食物链顶端。结果撞见现场，她被上级驳回、训话。他愣住，她无所谓。这一课讲的是「位置」。他看她的眼神，多了一层东西。

#### 时间轴

**以他的认知更新为轴。** 撞见之前，她是无所不能的抽象强者。撞见之后，她是「每天也在挨压、然后把压力在进家门前卸掉」的具体的人。具体的人才能被爱到骨头缝里。

#### 撞见现场的写法

| 要素 | 处理 |
|---|---|
| 场景 | 他来送文件／接她下班，隔着玻璃会议室看见：她站着，对面坐着的人在说她，她在记 |
| 她的姿态 | 不卑不亢地挨训——**挨训也有段位**：她记要点、认错、不该辩的不辩、只争该争的那一条 |
| 他的位置 | 站在工位区，进退不得，手里的咖啡 ✓ 慢慢凉掉 |
| 对视 | 她出会议室看见他，愣了半秒，然后像没事人一样走过来：「等久了？」——不解释，不遮掩，也不装坚强 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的上司 | 不写成恶人——写成她的十年后：一样的强，多十年的伤，两人互相敬着也互相较劲，这才是职场 |
| 车上 | 回程她说了实话：「刚才那单，是我错了。」——**她在他面前认错，比在他面前哭还少见** |
| 他的震动 | 他原以为她的强是天生的，那天起知道是攒出来的：每天挣，每天花，每天清零 |
| 卸压仪式 | 进家门前她在车里坐三分钟——他后来懂了这三分钟，从此到楼下不催她 |

「车里的三分钟」是这条的核心意象：**家门是她的国境线，三分钟是海关**：工作的那个她不入境。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 上级形态 | 上司 | 甲方／董事会／监管，她上头还有人，一层压一层，写实点就对了 |
| 他的反应 | 认知更新 | 心疼到想冲进去理论，被她一个眼神按住——事后她说「谢谢你想冲，谢谢你没冲」 |
| 她的态度 | 坦然 | 那天确实狼狈，被越级追责，摆明了欺负人——她在车里坐了好一阵，他把车开去了海边 |
| 长线 | —— | 多年后她当了别人的上司，她训人的方式里有当年那位的影子，也有自己刻意改掉的地方 |

「谢谢你想冲，谢谢你没冲」，两个谢谢之间是她对他全部的要求：情绪同盟，行动克制。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「是我错了」在车里说出口 | 隔着玻璃那幕的每一秒 |
| 内心 | 他看见了。也好。 | 她站在那里挨训的样子，比她赢的任何一次都让我想娶她 |
| 好的处理 | 她挨训也挨得有水平，狼狈归狼狈，不丢份儿 | 他心疼归心疼，不冲她上司发火——他分得清谁该担责 |
| 写崩 | 写成她在职场也横着走 | 写成他冲上去替她出头大闹一场 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她在朝上挨御史参、被上头敲打，他从下人嘴里拼出朝堂全貌，往后她下朝晚了，他那盏灯 ✓ 准亮着 |
| 修仙 | 她上头有掌门、有太上长老、有宗规，执法堂领戒尺那回，他在门外杵了一个时辰，进不去，也不走 |
| 星际 | 她军衔上头还有七级，晋升答辩被压那晚，他把她的勋章 ✓ 挨个擦亮，放回原处，一个字没吭 |

「把勋章擦一遍摆回去」，他的表态方式：你的战功我都记得，评审团不算数。

#### 写崩的三种方式

1. 她的职场全知全胜。无上司的强是玄幻，不是人物。
2. 上司写成纯反派。她的十年后版本才有信息量。
3. 他撞见后待遇降级。目光里多的那层是敬意加心疼，不是滤镜碎裂。

## 三 · 她的闺蜜

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：闺蜜 11.3%

**骨架**｜他认识她比她早十年，手里攥着她全部黑历史，头回见面就把丑话摆到了台面上。

#### 节拍链

闺蜜被提到 → 见面（面试局）→ 丑话说前头，边处边看 → 过关或留校察看 → 闺蜜成了这段关系的监督员 → 出事那天闺蜜站哪边 → 三个人就这么处下去了

#### 时间轴

**闺蜜的信任进度是另一条线**，而且更慢。她三个月就认定了他，闺蜜用了一年半。最后一票投下来，往往是在她受了挫、闺蜜亲眼看到他怎么处理之后。

#### 闺蜜的职能清单

| 职能 | 场面 |
|---|---|
| 史官 | 她小时候什么样、以前受过什么伤、交过几个男朋友，闺蜜全记着——他想打听只能找她，可闺蜜有规矩：「她的事，她自己说」 |
| 面试官 | 头回见面就问三个问题，问得他直冒汗，末了闺蜜跟她说的是：「行，这人眼神干净。」 |
| 泄压阀 | 她不敢跟他说的那些话，怕他操心、又跟他有关的，全倒给闺蜜——**闺蜜就是她唯一的树洞，啥都存着** |
| 敌我识别 | 谁在背后说她闲话，闺蜜的消息比她还灵通（接 [28-误会与信任 · 好心办坏事的人](28-误会与信任.md#七--好心办坏事的人)：好心帮倒忙的也多半是她） |
| 战时同盟 | 两人吵架，闺蜜骂她：「你这老毛病又犯了吧」——**能当面骂她的才是真闺蜜**，光站队不吭声的是塑料姐妹 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 面试局 | 火锅店，闺蜜选的，观察一个人怎么对待服务员和怎么涮毛肚 · 三个问题的最后一个：「她加班到三点的时候，你在干嘛？」 |
| 黑历史 | 闺蜜手机 ✓ 里她大学时期的照片 ✓——他见过一张，笑了一周，被她没收了观看权 |
| 暗号 | 两人有一套完整的眼神语和缩写黑话，他在场时启用——他听不懂，但听得懂「在说我」 |
| 立场 | 那次冷战闺蜜给他打了电话：「我只说一次。她昨天哭了。挂了。」——十一个字，泄露了机密也守住了立场 |

「她昨天哭了。挂了。」是闺蜜文学的标准弹道：**背叛式忠诚**：出卖她的强撑，成全她的关系。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 闺蜜对他 | 一年半后转正 | 永远留察，「我认可你，不代表我不备案」——闺蜜的世界观如此，尊重 |
| 闺蜜自身 | 已婚顾问型 | 单身贵族型，她们的双人夜话是她唯一说「废话」的地方 |
| 危机立场 | 站她但骂她 | 有一次站了他，她要为事业放弃纪念日第三次，闺蜜说「这次你错」——闺蜜的公正是她信任的地基 |
| 他与闺蜜 | 相敬如宾 | 结成地下同盟，她的生日、她的体检 ✓、她的低气压预报，两人共享情报——被她发现后假装生气，实际红了眼眶 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「你那个毛病又犯了」被骂中的沉默 | 十一个字的那通电话 |
| 内心 | 她见过我所有样子，连最烂的那版都算 | 面试没过就没过，我时间多，慢慢刷分呗 |
| 好的处理 | 闺蜜有自己的日子要过，不是围着她转的摆设 | 他对闺蜜是真心敬重：这人替他守了十年他没能陪着的她 |
| 写崩 | 把闺蜜写成工具人 | 把闺蜜写成跟他暧昧，那是另一类，不归这儿管 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 手帕交／同科进士。面试局设在诗会，考较的是他的字——「字如其人，这人藏不住坏」 |
| 修仙 | 同门师姐妹，面试局是一场切磋，考的是他护不护得住要害——他护住了，护的是她的旧伤位置：「你怎么知道她旧伤在左肩？」「她冷天会揉。」当场转正 |
| 星际 | 军校同期，面试局在靶场，成绩单不重要，重要的是他打完看谁——「打得一般。看她的次数及格了。」 |

修仙版「她冷天会揉左肩」是全条最好的一颗糖：面试考的从来是观察量，资质只算入场券。

#### 写崩的三种方式

1. 闺蜜只在需要时出现。史官有自己的编年史。
2. 面试一顿饭通过。一年半的留察期是闺蜜的尊严。
3. 「能骂她」写丢。只会站队的闺蜜是背景音。

## 四 · 她喝醉

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：醉酒 32.1%

**骨架**｜她酒量在圈里是出了名的，谁都没见她醉过。结果真醉那天，他直接懵了，像捧了件限量版古董，手都不知道往哪儿搁。

#### 节拍链

喝的理由：庆功、饯别、闺蜜局，或者干脆没有理由→ 超量 → 醉态启动 → 他接手 → 醉态的完整展演 → 抵家安置 → 第二天的记忆管理

#### 时间轴

**醉是她唯一能合法发疯的时候。** 语料里 32.1% 的作品写过醉酒场面，这个类型三分之一的书都懂：她这样的人物，清醒时每句话都像过审，只有酒精能绕开那道审查。醉后说的话，全是她平时不敢说的真话。

#### 她的醉态谱系（选型用）

| 型 | 表现 | 泄露的 |
|---|---|---|
| 安静型 | 不闹，就是盯着他看，看很久，看笑了 | 平时不许自己这样看 |
| 指挥型 | 醉了还在部署工作，对着他布置明年战略，逻辑严密用词标准——就是对象错了 | 她的操作系统没有关机键，只有换屏 |
| 幼态型 | 数他的睫毛 · 要求再讲一遍他们怎么认识的 · 讲到一半睡着 | 她也想当被照顾的那个，一年就这一晚 |
| 诚实型 | 「我跟你说个秘密」——秘密是「我很怕你哪天觉得我无聊」 | 强者的恐惧清单，平时锁保险柜 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 接手 | 闺蜜来电：「来收人。她说了，只让你来。」——醉了还在做访问控制 |

## 五 · 卸妆

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：卸妆 8.1%

**骨架**｜口红是上战场的装备，眉毛是防线，粉底是护盾。晚上十一点，她在浴室镜子前一层层卸掉这些。他见过一回，之后一直觉得那像降旗。

#### 节拍链

#### 时间轴

妆的厚度跟当天要打的仗成正比。见董事会的妆最重，周末在家基本素颜。他后来学会了从早上那几笔看出当天战况——口红越红，会越难开。**妆就是她的战报栏**，这本事他练了两年。

「素颜是限量发行」，全公司见过她素颜的人数：零。他的独家授权是在某个加班的深夜自然发生的。她洗完脸出来，愣了一下，然后没回浴室补。**没补，就是授权。**

3. 带妆睡那天追问战报。 虚掩的门是他的满分卷，推门是零分。

## 七 · 她哭不出来

`T` ｜ ⚠️亲人离世（变体轴一端） ｜ 全谱系 ｜ 语料频次：哭（反应族）77.5%，本条写的是它的缺席

**骨架**｜该哭的时候她一滴泪都掉不出来。葬礼上，重逢时，感动处，别人哭成一片，她站那儿眼睛干干的，怀疑自己是不是有毛病。

#### 节拍链

催泪场合 → 全场落泪，她干坐着 → 自我怀疑，心想「我是不是没心」→ 他注意到了 → 他发现她眼泪的替代出口 → 某个毫无道理的时刻，泪崩 → 崩完之后的她和他

#### 时间轴

**她的眼泪有延迟到账功能**：当场不哭，过几天才炸。葬礼上愣是没掉泪的人，两周后因为一支修不好的旧钢笔，蹲地上哭得站不起来。✓ **眼泪从不缺席，只是总挑错时候。**

#### 哭不出来的机制（写作用，不作医学陈述）

| 层 | 内容 |
|---|---|
| 装机史 | 「罚站都不哭」的小孩（见 [六 · 她的少女时代](#六--她的少女时代)）——她哭不出来，那感觉被系统当成「输」给吞了 |
| 岗位要求 | 二十年谈判桌练出来的：脸上露一点情绪，就等于把底牌交出去 |
| 替代出口 | 她的难过走别的道：使劲刷碗、半夜翻旧东西、闷头走很远的路——**她就是这么哭的** |
| 错位引爆 | 她防着那些该哭的场面，可钢笔、旧歌、一碗味道跟记忆里一模一样的汤，从旁边溜进来，一下就破防 |

## 九 · 她羡慕他的松弛

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：受挫 8.0% ＋ 夜深 37.5%

**骨架**｜他午睡倒头就着，开心说来就来，一根雪糕能乐一下午。她瞅着他，像瞅一门早忘干净了的手艺。

#### 节拍链

日常对照：他吊儿郎当，她绷得跟弓弦似的 → 她偷摸观察 → 某天她憋不住问了一句：「你怎么做到的」→ 他愣住，压根没觉得这算个本事 → 试着教她 → 教得鸡飞狗跳，但好歹学成了一点

#### 时间轴

**这条的进度以「她的一小步」计**，慢得磨人，还老反复。周末上午不碰手机 ✓，撑了两周，破功，重来。吃饭就专心吃。躺着「啥也不干」十分钟，到第十分钟她心慌得不行。这条最疼，也最逗。

#### 两种操作系统的对照表

| 场景 | 他 | 她 |
|---|---|---|
| 排队 | 盯着前面小孩的帽子，自己乐呵 | 心里把这家店的路线重新排了一遍 |
| 假期第一天 | 睡到自然醒，美得很 | 九点就醒，躺着想明天的事，越想越慌 |
| 计划外下雨 | 「正好，看雨。」 | 马上盘算今天所有安排怎么改 |
| 一支雪糕 ✓ | 能高兴一下午 | 「这糖分……」话到嘴边，看他一眼，咽回去了 |

**她的紧绷是功勋，不是毛病**：她现在的地位、底气，全是靠这股狠劲拼出来的。所以这条别写「她该改改」，写她终于想歇口气了，而他是她唯一敢躺平的窝。

1. 箭头升级成绝症。 这条的题材是「拖」与「怕失控」，不是生死戏。生死戏在 [16-危机与保护](16-危机与保护.md)，分开写。
2. 他的管理写成控制。 策反秘书可以，替她做医疗决定不行。诊室里做决定的永远是她。
3. 「没锁的抽屉」说破。 暗道一见光就塌。
