# 桥段库 · 日常戏怎么搭

> **分级** `G` ｜ 预警 无 ｜ 亚型 全谱系通用（逐条另标，分级见各条）
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）

## 这一卷补的是什么

先看一个具体场面：

> 弟弟给姐姐做了饭。姐姐晚上本来要回来吃，临时加班。弟弟把菜热了很多遍，一直没等到，最后哭着睡着了。姐姐下班回家看见了，弟弟狠狠撒娇，姐姐哄了很久才好。

这场戏在本类型里几乎人人写过。可本库建到第十三卷，没有任何一卷收得下它。不是漏。中间缺着一层，前面几卷都够不着：

| 层 | 数量 | 是什么 | 在哪一卷 |
|---|---:|---|---|
| L1 套路 | 35 | 书级骨架：重生复仇、契约婚姻 | [05-01 经典套路库](../05-剧情套路/01-经典套路库.md) |
| L2 名场面 | 16 | 权力戏模板：下马威、跪与不跪、修罗场 | [05-02 名场面结构库](../05-剧情套路/02-名场面结构库.md) |
| **L3 桥段** | **444** | **日常微剧情：等门热菜、哭着睡着** | **就是这里，44 个族文件** |
| L4 语言 | 1,900+ | 命令句、称谓、气口 | [13-02 权力语言库](../13-语料挖掘/02-权力语言库.md) |

L2 那 16 个场面全是权力对峙，骨架是「空间调度 → 信息差 → 动作链」。日常戏套不进去。它的发动机换了一个：时间流逝。「热了很多遍」就是把这段时间画出来给读者看。

L3 是写手每天真正在填的那一层。

## 把上面那场戏拆开

| 拍 | 内容 | 节拍族 | 起什么作用 |
|---|---|---|---|
| 1 触发 | 弟弟做了饭 | 做饭 | 立起期待，且是**他单方面付出的** |
| 2 阻碍 | 姐姐临时加班 | 加班 | 期待落空，且**不是任何人的错**（关键） |
| 3 累积 | 菜热了很多遍 | 反复 | **时间可视化**。这一拍是全场的心脏 |
| 4 崩点 | 哭着睡着 | 哭 ＋ 睡着 | 情绪到顶，且他**没等到人就先撑不住了** |
| 5 反转 | 姐姐回家发现 | 归家 | 视角交接：从他等，变成她看见 |
| 6 收束 | 狠狠撒娇，哄很久 | 撒娇 ＋ 讨哄 | 把委屈兑换成亲密，**不是解决问题，是转换货币** |

第 3 拍是这场戏成立的唯一理由。删掉它试试。剩下「他等她，她晚归，他哭了」，一句话就说完了，没有戏。加上它，读者跟着微波炉转了三轮，时间被物质化了。

这条规律推得开：日常戏的强度不取决于事件大小，取决于有没有一个可重复的物质动作把时间显影出来。热菜、看表、走到门口再走回来、把手机屏幕点亮又熄掉，都是同一个机关。

拆完之后它在本卷的位置：

| 拍 | 收在哪一条 |
|---|---|
| 1–3 | [02-等待与错过 · 等门与热菜](02-等待与错过.md#一--等门与热菜) |
| 4 | [04-委屈与破防 · 哭着睡着](04-委屈与破防.md#一--哭着睡着) |
| 5–6 | [03-撒娇与讨哄 · 狠狠撒娇](03-撒娇与讨哄.md#一--狠狠撒娇) |

一场戏跨三条是常态。所以每条都带「可串接」一栏。就是为了拼。

### 每条长什么样

| 栏目 | 用来干什么 |
|---|---|
| 一句话骨架 | 判断这条对不对路 |
| 节拍链 | 照抄的骨架 |

| 可用细节 | 道具／动作／感官／台词类型。带 ✓ 是语料实测高频 |
| 变体轴 | 一条顶四条用。拨一下就是另一场戏 |

| 常见写崩 | 三条。本库招牌 |
| 可串接 | 前接、后接哪几条 |
| 语料频次 | 这一族在 2,706 部含桥段作品里的占比 |
| 示例 | 27 条最高频或最难写的有。本库自撰，可直接改写 |

### 关于「双向写法」

本库同时服务四爱女与四爱男。同一场戏，两边关心的东西不一样：

| | 四爱女视角 | 四爱男视角 |
|---|---|---|
| 注意力落在 | 我发现了什么、我决定怎么处理 | 我怎么等的、我等到了什么 |
| 情绪来源 | 心疼混着一点被需要的满足 | 委屈混着一点不敢说的期待 |
| 最容易写崩 | 写成居高临下的施舍 | 写成一味索取的巨婴 |
| 收尾的权力 | 在我手上，但不能表现得像施舍 | 不在我手上，但可以主动兑换 |

两栏都写，是因为一场戏从哪边写，选的细节完全不同。她视角要写「玄关的灯还亮着」，他视角要写「第三次把汤端下来」。

### 关于「✓」

「可用细节」里带 ✓ 的，是在 2,706 部含桥段作品里实测过的高频物件，并且算过**提升度**（这场戏里的出现率 ÷ 一般桥段里的出现率）。

举例：门、车、手机在每一场戏里都高频，它们是背景不是特征。真正属于某场戏的是——

| 场景 | 特征物件（提升度） |
|---|---|
| 发烧生病 | 退烧 1.9× · 输液 1.9× · 体温计 1.7× |
| 下厨备饭 | 油烟 1.4× · 围裙 1.2× |
| 开门到家 | 玄关 2.0× |
| 备礼送礼 | 包装 1.6× |
| 卸妆素颜 | 冰袋 2.1× |
| 守着不睡 | 冰袋 1.8× |
| 联系不上 | 电话 1.4× · 手机 1.3× |

没带 ✓ 的只是语料里少见，照样能用。用了辨识度反而高，代价是读者的熟悉感低一点。

## 选目是怎么定的

选目由语料的数字定下来，编者只做归并与排序。分四步走：

**第一步，共现窗口。** 全语料按 2,500 字窗口找节拍共现（≥3 个不同情境族落在同一窗口），按组合频次排序。高频组合直接立条——完整组合榜见 [13-语料挖掘/07-桥段分布 § 四](../13-语料挖掘/07-桥段分布.md)。

**第二步，族级频次。** 有些场面不与别的场面共现，但单族出现率极高（婚仪 38.8%、误会 35.1%、醉酒 32.1%、歌舞 25.7%），这些成卷收（23 婚嫁、28 误会与信任、30 她的世界、29 微小仪式拾遗）。

**第三步，缺口清扫。** 对着挖掘结果做了五路排查：挖出的族是否都有归处、套路库的书级设定（重生 8%、穿书 23%）在场景层有没有对应的戏、经典场面的性别倒置版是否收全（领舞、剥虾、壁咚倒置）、人生节点是否有制度性遗漏（分手、婚嫁、校园）、她那一侧的戏份是否与他对称（30 卷由此而来）。

**第四步 · 链级校核。** 把 [13-语料挖掘/07-桥段分布 § 五](../13-语料挖掘/07-桥段分布.md) 的 30 条有序节拍链逐链拼装：每一拍都要有一条桥段接得上，整条链拼得出来，这条链才算被库覆盖。拼不出的那一拍，就是下一轮的立条依据。本轮补的双修（[21-世界设定专属](21-世界设定专属.md)）、旧伤（[41-他的身体与年岁](41-他的身体与年岁.md)）都是这么来的。

低频的也收。「反复加热」只有 3.4% 的作品写过，而它恰恰是这一族里效率最高的机关：几乎没人在用，时间可视化的效果又最直接。「困电梯」只有 0.3%，可它是「停电」的强化版，结构通用。频次低只说明竞争小，跟该不该写是两码事。

## 这一卷的边界

| 不做 | 为什么 |
|---|---|
| 不搬原文 | 全卷零藏书原句。节拍是抽象结构，道具是单词，示例是本库自撰 |
| 不判甜虐 | 同一串节拍两种收法都成立，机器判不了，所以做成「变体轴」交给你拨 |
| 不做长桥段 | 窗口 2,500 字，跨章的长线戏被切成两段。要长线去 [05-01 套路库](../05-剧情套路/01-经典套路库.md) |
| 不写重度实践的过程 | 08 卷是日常低烈度责罚。重度实践的符号与协商层（项圈、安全词、事后照护）入 [35-规矩的进阶](35-规矩的进阶.md)，结构层入 [36-亲密的完整结构](36-亲密的完整结构.md)（`E` 级，只写结构与技法，成段描写零收录）；过程写法仍走 [06-尺度与写法](../06-尺度与写法/) 并带安全框架 |
| 校园卷全员成年 | [24-校园与青涩](24-校园与青涩.md) 全部设定在大学及以上学段；[27-年龄差与姐弟](27-年龄差与姐弟.md) 的「姐弟」均为非血缘 |
| 不替代原作 | 桥段是公共层，谁都可以写「等门与热菜」；但每一部具体作品的文字与情节编排是作者的。用本卷搭自己的戏，不照着别人的书洗稿；喜欢的作品去正版渠道支持（[红线 · 第二节](../00-编纂规约/03-版权与内容红线.md)） |
