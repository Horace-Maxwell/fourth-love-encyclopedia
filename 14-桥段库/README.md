# 桥段库 · 日常戏怎么搭

> **分级** `G` ｜ 预警 无 ｜ 亚型 全谱系通用（逐条另标，分级见各条）
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一卷的性质：机器给结构与频次，写法由人补。翻开就能直接取用。

---

## 这一卷补的是什么

先看一个具体场面：

> 弟弟给姐姐做了饭。姐姐晚上本来要回来吃，临时加班。弟弟把菜热了很多遍，一直没等到，最后哭着睡着了。姐姐下班回家看见了，弟弟狠狠撒娇，姐姐哄了很久才好。

这场戏，写这个类型的人基本都碰过。但咱这库建到第十三卷了，没有一卷能把它收进去。中间缺着一层，前面几卷都够不着那个边儿。

| 层 | 数量 | 是什么 | 在哪一卷 |
|---|---:|---|---|
| L1 套路 | 35 | 书级骨架：重生复仇、契约婚姻 | [05-01 经典套路库](../05-剧情套路/01-经典套路库.md) |
| L2 名场面 | 16 | 权力戏模板：下马威、跪与不跪、修罗场 | [05-02 名场面结构库](../05-剧情套路/02-名场面结构库.md) |
| **L3 桥段** | **614** | **日常小剧情：等门热菜、哭着睡着** | **就是这里，61 个族文件** |
| L4 语言 | 1,900+ | 命令句、称谓、气口 | [13-02 权力语言库](../13-语料挖掘/02-权力语言库.md) |

L2 那 16 个场面全是权力对峙，骨架是「空间调度 → 信息差 → 动作链」。日常戏套不进去。它的发动机换了一个：时间流逝。「热了很多遍」就是把这段时间画出来给读者看。

L3 是写手每天真正在填的那一层。

## 把上面那场戏拆开

| 拍 | 内容 | 节拍族 | 起什么作用 |
|---|---|---|---|
| 1 触发 | 弟弟做了饭 | 做饭 | 让人有个盼头，而且**是他一个人忙活的** |
| 2 阻碍 | 姐姐临时加班 | 加班 | 盼头落空，还**怪不到任何人头上**（关键） |
| 3 累积 | 菜热了很多遍 | 反复 | **能看出时间过了多久**。这一拍是全场最要命的 |
| 4 崩点 | 哭着睡着 | 哭 ＋ 睡着 | 情绪顶满了，而且他**没等到人，先撑不住了** |
| 5 反转 | 姐姐回家发现 | 归家 | 换人看：从他傻等，变成她撞见 |
| 6 收束 | 狠狠撒娇，哄很久 | 撒娇 ＋ 讨哄 | 拿委屈换亲热，**把难受变成黏糊的由头** |

第 3 拍是这场戏能不能立住的命根子。你把它删了试试，剩下「他等她，她晚归，他哭了」，一句话就说完了，没戏。加上它，读者跟着微波炉转了三圈，时间一下子有了重量。

这条规律基本成立：日常戏写得好不好，不看你写的事大不大，看你有没有一个能反复出现的具体动作，把时间“显”出来。热菜、看表、走到门口又折回来、把手机屏幕按亮再按灭，都是同一个套路。

拆完之后它在本卷的位置：

| 拍 | 收在哪一条 |
|---|---|
| 1–3 | [02-等待与错过 · 等门与热菜](02-等待与错过.md#一--等门与热菜) |
| 4 | [04-委屈与破防 · 哭着睡着](04-委屈与破防.md#一--哭着睡着) |
| 5–6 | [03-撒娇与讨哄 · 狠狠撒娇](03-撒娇与讨哄.md#一--狠狠撒娇) |

一场戏跨三条是常态。所以每条都带「可串接」一栏。就是为了拼。

### 每条长什么样

| 栏目 | 用来干什么 |
|---|---|
| 一句话骨架 | 看一眼就知道这条能不能用 |
| 节拍链 | 照着排场次就行 |
| 时间轴 | 情绪靠什么顶起来。日常戏全看这个 |
| 可用细节 | 道具／动作／感官／台词类型。带 ✓ 是实测里常出现的 |
| 变体轴 | 一条能当四条使。换个角度就是另一场戏 |
| 双向写法 | 四爱女笔下 / 四爱男笔下，两边都写 |
| 换皮 | 现代 → 古代女尊 / 修仙 / 星际，换套衣服就行 |
| 常见写崩 | 三条。这库的招牌 |
| 可串接 | 前面接哪条、后面接哪条 |
| 语料频次 | 这一族在 2,706 部含桥段作品里占多少 |
| 示例 | 27 条，挑最高频或最难写的。本库自己写的，拿去改就能用 |

### 关于「双向写法」

本库同时服务四爱女与四爱男。同一场戏，两边关心的东西不一样：

| | 四爱女视角 | 四爱男视角 |
|---|---|---|
| 注意力落在 | 我发现了什么、我打算怎么办 | 我怎么等的、最后等来啥 |
| 情绪来源 | 心疼，也有点被需要的踏实 | 委屈，还藏着点不敢说的盼头 |
| 最容易写崩 | 写成高高在上的赏赐 | 写成只会伸手要的巨婴 |
| 收尾的权力 | 在我手里，但不能显得像赏 | 不在我手里，但能自己开口换 |

两栏都写，是因为同一场戏从谁那边写，挑的细节完全不是一回事。她那边得写「玄关的灯还亮着」，他那边就得写「第三次把汤端下来」。

### 关于「✓」

「可用细节」里打 ✓ 的，是在 2,706 部带这桥段的作品里真试出来高频出现的物件，还算了**提升度**（这场戏里出现得有多勤 ÷ 一般桥段里出现得有多勤）。

举例：门、车、手机在每一场戏里都高频，它们是背景不是特征。真正属于某场戏的是——

| 场景 | 特征物件（提升度） |
|---|---|
| 发烧生病 | 退烧药 1.9× · 输液 1.9× · 体温计 1.7× |
| 下厨备饭 | 油烟 1.4× · 围裙 1.2× |
| 开门到家 | 玄关 2.0× |
| 备礼送礼 | 包装 1.6× |
| 卸妆素颜 | 冰袋 2.1× |
| 守着不睡 | 冰袋 1.8× |
| 联系不上 | 电话 1.4× · 手机 1.3× |

没带 ✓ 的只是语料里少见，照样能用。用了辨识度反而高，代价是读者的熟悉感低一点。

## 选目是怎么定的

选目由语料的数字定下来，编者只做归并与排序。分四步走：

**第一步，共现窗口。** 全语料按 2,500 字窗口找节拍共现（≥3 个不同情境族落在同一窗口），按组合频次排序。高频组合直接立条——完整组合榜见 [13-语料挖掘/07-桥段分布 § 四](../13-语料挖掘/07-桥段分布.md)。

**第二步，看单族频次。** 有的场面不跟别的场面搭着出现，但自己一个族类就反复刷脸（婚仪 38.8%、误会 35.1%、醉酒 32.1%、歌舞 25.7%），这几类直接单独收卷（23 婚嫁、28 误会与信任、30 她的世界、29 微小仪式拾遗）。

**第三步，缺口清扫。** 挖完之后，得再查五遍：挖出来的这些族，是不是每个都有地方安放？套路库里的书级设定（重生 8%、穿书 23%）在具体场景里，有没有对应的戏？经典场面反过来写的那种，比如领舞、剥虾、壁咚，性别一换，收全了没有？人生节点上，有没有因为制度卡着就漏掉的，比如分手、婚嫁、校园？最后，她那边的戏份，是不是跟他这边一样多——30 卷就是这么算出来的。

**第四步 · 链级校核。** 把 [13-语料挖掘/07-桥段分布 § 五](../13-语料挖掘/07-桥段分布.md) 里那 30 条有序节拍链，一条一条拿来拼装：每一拍都得有对应的桥段能接上，整条链能拼完整，才算这条链被咱们的库覆盖了。要是有哪一拍拼不上，那这一拍就是下一轮要立条的依据。这轮补的双修（[21-世界设定专属](21-世界设定专属.md)）、旧伤（[41-他的身体与年岁](41-他的身体与年岁.md)），都是这么补出来的。

低频的也收。「反复加热」只有 3.4% 的作品写过，但它恰恰是这堆设定里最好用的机关：几乎没人写，时间可视化的效果又最直白。「困电梯」只有 0.3%，可它是「停电」的升级版，套路通用。写得少只说明竞争小，跟值不值得写是两码事。

## 这一卷的边界

| 不做 | 为什么 |
|---|---|
| 不搬原文 | 全卷没有一句原书原话。节拍是骨架，道具是零件，示例都是我们自己写的 |
| 不判甜虐 | 同一串节拍，两种收法都说得通，机器分不了，所以做成「变体轴」让你自己拨 |
| 不做长桥段 | 单节窗口 2,500 字，跨章的长线戏会被切成两段。要长线去 [05-01 套路库](../05-剧情套路/01-经典套路库.md) |
| 不写重度实践的过程 | 08 卷只写日常低烈度责罚。重度实践的符号和协商层（项圈、安全词、事后照护）放 [35-规矩的进阶](35-规矩的进阶.md)，结构层放 [36-亲密的完整结构](36-亲密的完整结构.md)（`E` 级，只写结构和技法，不收录成段描写）；过程怎么写还是走 [06-尺度与写法](../06-尺度与写法/) 并带安全框架 |
| 校园卷全员成年 | [24-校园与青涩](24-校园与青涩.md) 的设定全在大学及以上；[27-年龄差与姐弟](27-年龄差与姐弟.md) 里的「姐弟」都没有血缘关系 |
| 不替代原作 | 桥段是公共的，谁都能写「等门与热菜」；但每部具体作品的文字和情节编排是作者的。用本卷搭自己的戏，别照着别人的书洗稿；喜欢的作品去正版渠道支持（[红线 · 第二节](../00-编纂规约/03-版权与内容红线.md)） |
