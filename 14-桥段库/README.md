## 从一场戏说起

先看一个具体场面：

> 弟弟给姐姐做了饭。姐姐晚上本来要回来吃，临时加班。弟弟把菜热了很多遍，一直没等到，最后哭着睡着了。姐姐下班回家看见了，弟弟狠狠撒娇，姐姐哄了很久才好。

写这个类型的人，基本都写过这场戏。可这个库建到第十三卷，还没有哪一卷收得下它。中间少了一层。

| 层 | 数量 | 是什么 | 在哪一卷 |
|---|---:|---|---|
| L1 套路 | 35 | 书级骨架：重生复仇、契约婚姻 | [05-01 经典套路库](../05-剧情套路/01-经典套路库.md) |
| L2 名场面 | 16 | 权力戏模板：下马威、跪与不跪、修罗场 | [05-02 名场面结构库](../05-剧情套路/02-名场面结构库.md) |
| **L3 桥段** | **624** | **日常小剧情：等门热菜、哭着睡着** | **就是这里，62 个族文件** |
| L4 语言 | 1,900+ | 命令句、称谓、气口 | [13-02 权力语言库](../13-语料挖掘/02-权力语言库.md) |

L2 的 16 个场面都是权力对峙，按「空间调度 → 信息差 → 动作链」搭。日常戏装不进这个架子。它靠时间往前走。「热了很多遍」写的就是这段时间，读者看得见。

L3 是写手每天在填的那一层。

## 把上面那场戏拆开

| 拍 | 内容 | 节拍族 | 起什么作用 |
|---|---|---|---|
| 1 触发 | 弟弟做了饭 | 做饭 | 盼头有了，活儿是他一个人张罗的 |
| 2 阻碍 | 姐姐临时加班 | 加班 | 盼头落了空，又没法怪谁 |
| 3 累积 | 菜热了很多遍 | 反复 | 等了多久，看得出来 |
| 4 崩点 | 哭着睡着 | 哭 ＋ 睡着 | 情绪到了顶，人还没等回来，他先撑不住 |
| 5 反转 | 姐姐回家发现 | 归家 | 换了人看：先是他傻等，再是她撞见 |
| 6 收束 | 狠狠撒娇，哄很久 | 撒娇 ＋ 讨哄 | 委屈拿去换亲热，难受成了黏糊的由头 |

第 3 拍删不得。可以写微波炉「叮」的那一声，响了一遍又一遍，读者自己就知道过了多久。没了这一拍，故事就只剩一句「他等她，她晚归，他哭了」。

日常戏写不写得活，看的是有没有一个具体动作能反复出现，把时间「显」出来，事件大小倒在其次。热菜、看表、走到门口又折回来、把手机屏幕按亮又按灭，都是这样的动作。同一个动作用上几回，日常感差不多就有了。

|---|---|
| 1–3 | [02-等待与错过 · 等门与热菜](02-等待与错过.md#一--等门与热菜) |

### 每条长什么样

| 栏目 | 用来干什么 |
|---|---|
| 一句话骨架 | 扫一眼就知道这条用不用得上 |
| 节拍链 | 照着排场次就行 |
| 时间轴 | 情绪靠什么顶起来。日常戏全看这个 |
| 可用细节 | 道具／动作／感官／台词类型，带 ✓ 的在实测里出现得多 |
| 变体轴 | 换个角度就是另一场戏，一条能当四条用 |
| 双向写法 | 四爱女笔下、四爱男笔下，两边各写一遍 |
| 换皮 | 现代 → 古代女尊 / 修仙 / 星际，换身衣服就成 |
| 常见写崩 | 三条。这库的招牌 |
| 可串接 | 前面接哪条、后面接哪条 |
| 语料频次 | 这一族在 2,706 部含桥段作品里占多少 |
| 示例 | 27 条，挑最高频或最难写的。本库自己写的，拿去改就能用 |

### 关于「双向写法」

这个库写给四爱女，也写给四爱男。同一场戏，两边在意的东西不同：

| | 四爱女视角 | 四爱男视角 |
|---|---|---|
| 注意力落在 | 我看见了什么、接下来怎么办 | 我是怎么等的、最后等来了什么 |
| 情绪来源 | 心疼，外加一点被需要的踏实 | 委屈，底下压着点不敢说出口的盼头 |
| 最容易写崩 | 写成居高临下的赏赐 | 写成只会伸手要的巨婴 |
| 收尾的权力 | 在我手里，只是不能让人觉得是赏 | 不在我手里，可我能自己开口去换 |

同一场戏，站在谁那边写，挑出来的细节完全不同，所以两栏都要写。她那边得写「玄关的灯还亮着」，他那边就得写「第三次把汤端下来」。

### 关于「✓」

✓ 标的「可用细节」，是含桥段的 2,706 部作品里真正高频出现的物件。**提升度**也一起算好了：这件东西在这场戏里的出现频率，除以它在一般桥段里的频率，就看出它有多突出。

比如门、车、手机，哪场戏里都常见，算不上特征。各场戏自己的特征物件是这些：

| 场景 | 特征物件（提升度） |
|---|---|
| 发烧生病 | 退烧 1.9× · 输液 1.9× · 体温计 1.7× |
| 下厨备饭 | 油烟 1.4× · 围裙 1.2× |
| 开门到家 | 玄关 2.0× |
| 备礼送礼 | 包装 1.6× |
| 卸妆素颜 | 冰袋 2.1× |
| 守着不睡 | 冰袋 1.8× |
| 联系不上 | 电话 1.4× · 手机 1.3× |

没带 ✓ 的，只说明语料里少见，一样能用。用上了辨识度还更高，只是读者没那么熟悉。

## 选目是怎么定的

收哪些条目，是语料的数字定的，编者只管归并和排序。一共四步：

**第一步，共现窗口。** 全语料切成 2,500 字的窗口找节拍共现，一个窗口里落进 ≥3 个不同情境族就算一次，按组合频次排。排在前头的直接立条，完整组合榜在 [13-语料挖掘/07-桥段分布 § 四](../13-语料挖掘/07-桥段分布.md)。

**第二步，看单族频次。** 有些场面不跟别的场面一起出现，单看自己这一族就常常露面：婚仪 38.8%、误会 35.1%、醉酒 32.1%、歌舞 25.7%。这几类各自单独成卷，分别收进 23 婚嫁、28 误会与信任、30 她的世界、29 微小仪式拾遗。

**第三步，缺口清扫。** 挖完之后，还要再查五遍。挖出来的族是不是都有地方放？套路库里的书级设定（重生 8%、穿书 23%）落到具体场景，有没有对应的戏？经典场面反着写的，比如领舞、剥虾、壁咚，性别一换，收全了没有？人生节点里，有没有因为制度卡着而漏掉的，比如分手、婚嫁、校园？最后，她那边的戏是不是跟他这边一样多？30 卷就是这么算出来的。

**第四步 · 链级校核。**
把 [13-语料挖掘/07-桥段分布 § 五](../13-语料挖掘/07-桥段分布.md) 的 30 条有序节拍链逐条拿来，用库里的桥段去拼。
每一拍都接得上、整条链拼得完整，这条链才算被咱们的库覆盖了。
哪一拍接不上，下一轮就照着这一拍立新条。
双修（[21-世界设定专属](21-世界设定专属.md)）、旧伤（[41-他的身体与年岁](41-他的身体与年岁.md)）就是这样补进来的。

「困电梯」是「停电」的升级版，只有 0.3% 的作品写过，套路大家却都熟。「反复加热」有 3.4% 涉及，可它反而最好用，几乎没人碰，时间过了多久也写得最直白。写得少只说明写的人少，跟值不值得写是两码事。

## 这一卷的边界

| 不做 | 为什么 |
|---|---|
| 不搬原文 | 全卷一句原书的话都没有。节拍是骨架，道具是零件，示例全是我们自己写的 |
| 不判甜虐 | 一串节拍往甜收、往虐收都说得通，机器分不出来，就做成「变体轴」，交给写的人自己拨 |
| 不做长桥段 | 一个窗口只有 2,500 字，跨章的长线戏会被切成两半。要长线戏，去 [05-01 套路库](../05-剧情套路/01-经典套路库.md) |
| 不写重度实践的过程 | 08 卷只写日常低烈度责罚。重度实践的符号和协商层，比如项圈、安全词、事后照护，放 [35-规矩的进阶](35-规矩的进阶.md)，结构层放 [36-亲密的完整结构](36-亲密的完整结构.md)，`E` 级只写结构和技法，不收录成段描写。过程怎么写还是走 [06-尺度与写法](../06-尺度与写法/) 并带安全框架 |
| 校园卷全员成年 | [24-校园与青涩](24-校园与青涩.md) 的设定全在大学及以上，[27-年龄差与姐弟](27-年龄差与姐弟.md) 里的「姐弟」都没有血缘关系 |
| 不替代原作 | 桥段是大家的，谁都能写「等门与热菜」，可每部作品的文字和情节编排归它的作者。拿本卷搭自己的戏，别照着别人的书洗稿。喜欢哪部作品，就去正版渠道支持（[红线 · 第二节](../00-编纂规约/03-版权与内容红线.md)） |
