## 分离戏写惯性

前面八卷写的都是人在跟前的事，这一卷写人不在。

他不在以后，平时没人留意的东西都冒了出来：多倒的那杯水，做好了没人吃的饭，床那头空出来的一块，照习惯留着的那盏灯。一个人走了，他留下的痕迹才看得清。

所以这一族有个通用的写法：

| 步 | 做什么 |
|---|---|
| 1 | 把某个日常动作写足（前面几章） |
| 2 | 分离 |
| 3 | 留在原地的人仍然做那个动作 |
| 4 | 他／她意识到自己在对空气做这件事 |

第 3 步最要紧。 想念不用写，写惯性。

|---|---:|---:|

## 一 · 出差前夜

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送等候 37.1%

**骨架**｜行李箱摊在地上，两人谁也没碰。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 收拾行李 |
| 2 | 他往里塞她不知道的东西 |
| 3 | 有一件事想说，没说 |
| 4 | 睡前 |
| 5 | 有一个人先睡着了，通常不是要走的那个 |
| 6 | 早上 |

#### 时间轴

行李箱的开合次数就是时间轴。 拉链拉上又打开三次，因为每次都想起还要带一样。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 行李箱 · 充电器（谁的）· 外套 · 药，他偷偷塞给她的 · 保温杯 |
| 他塞进去的 | 感冒药 · 她爱吃的那牌子 · 一张纸条 · 他自己的一件衣服 |
| 想说没说的 | 「早点回来」（说了显得黏人）·「我陪你去」（他知道不行） |
| 睡前 | 谁先躺下 · 有没有多聊几句 · 明明该睡了却聊到半夜 |
| 早上 | 闹钟还没响，她已经醒了 |

「他自己的一件衣服」到了千里之外，就替他陪在那儿。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁走 | 她（更常见） | 他 |
| 时长 | 三天 | 半年 |
| 气氛 | 平常 | 前一天刚吵完架 |
| 那句话 | 说了 | 到机场才说 · 或者一直没说 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现箱子里多了东西 | 塞进去时那一下犹豫 |
| 内心 | 我要不要说别送了 | 我能不能说句「早点回来」 |
| 好的处理 | 她收拾时把那件衣服留下了 | 他没说，但他塞了 |
| 写崩 | 写成她公事公办 | 写成他难舍难分 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 收拾行李／他在包袱里塞了平安符／她出征前夜 |
| 修仙 | 她要闭关／出门历练／他给的护身符 |
| 星际 | 出发前夜／他录了段话存进她终端 |

#### 写崩的三种方式

1. 让两人促膝长谈。 话说尽了，后面的想念就落了空。
2. 漏了他塞东西。 塞的那一下最要紧。
3. 写成生离死别。 三天而已。

## 二 · 送到门口

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送等候 37.1%

**骨架**｜他一路送，送到没法再送。

#### 节拍链

他送 → 一路找理由多送一段 → 她说「回去吧」→ 他停下 → 没有立刻转身 → 楼道的声控灯灭了

#### 时间轴

她上楼，声控灯跟着她的脚步一层层亮起来，又一层层灭下去。最后一层灭掉之前，他一直站在原地没动。三百米的路，说一句「顺便买个水」就多绕二百米，再找一句，就送到楼下了。

#### 送的层级

| 送到哪 | 读作 |
|---|---|
| 门口 | 常规 |
| 楼下 | 多送了一段 |
| 路口 | 他找不到停下的理由了 |
| 车站／机场 | 全程 |
| 他站在原地看她走 | 最要紧 |

「他站在原地看她走」这一拍少不了。要写的是他停下来以后。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的拖延 | 帮她拎东西（不重）· 替她按电梯 · 没话找话 |
| 停下的理由 | 她说「回去吧」· 或者他自己停 |
| 停下之后 | 他没马上走 · 站到看不见为止 · 她没回头（也可能回了） |
| 环境 | 电梯门一关 · 她的车拐弯 · 楼道灯灭了 |

「楼道的声控灯灭了」适合收尾：他站得太久，灯当这儿没人了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 送多远 | 门口 | 一路送到机场 |
| 她回不回头 | 回头，挥手 | 没回头，一回头就走不成了 |
| 他的停 | 她喊停才停 | 自己停下来 |
| 事后 | 他马上回家 | 他在楼下杵了半天 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她要不要回头 | 她转过弯的那一下 |
| 内心 | 回头就走不了了 | 再看一眼 |
| 好的处理 | 她没回头，但放慢了脚步 | 他站到灯灭 |
| 写崩 | 写成她洒脱转身 | 写成他追出去 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 送到府门／送到城外／十里长亭 |
| 修仙 | 送到山门／看她御剑远去成一个点 |
| 星际 | 送到闸口／看舰体离港 |

#### 写崩的三种方式

1. 让他追出去。 停下才是这条。
2. 让她大方地道别。 脚步放慢一点就行。
3. 省略停下之后。

## 三 · 她不在的第一天

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送等候 37.1% ＋ 联系不上 23.2%

**骨架**｜该干的他照常干完了，抬起头才发现，没有人回来。

#### 节拍链

照常做饭 → 盛出两碗才想起 → 到了她平常回来的点 → 他看了一眼门 → 没收那副碗 → 她来电话，他说「都挺好的」

#### 时间轴

几点做饭，她平常几点进门，几点互道晚安，他全按原来的钟点过，每到一个点就愣一下。电话里那句「都挺好的」，四个字他练了半小时。

#### 惯性清单

不写想念，写惯性。

| 惯性动作 | 发现的方式 |
|---|---|
| 做了两个人的饭 | 盛出来才想起 |
| 倒了两杯水 | 另一杯放了一晚上 |
| 留了玄关 ✓ 的灯 | 睡前才关 |
| 睡在自己那一侧 | 床太空 |
| 听见楼道有脚步声 | 站起来才反应过来 |
| 想说一句话 | 转头才想起没人 |
| 买菜买了两份 | 结账时才发现 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 餐桌 ✓ · 碗 ✓（多摆的那副）· 被子 ✓ · 沙发 ✓ · 门 ✓ |
| 时间 | 到了她平时到家的点 · 他瞅了一眼门 |
| 处理方式 | 他没去收那副多摆的碗 · 要么收了，收得飞快 |
| 晚上 | 他睡她那边 · 要么硬睡自己那边 |

「他睡在她那一侧」和「他坚持睡自己那侧」写出来是两种完全不一样的人，两种都对。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的处理 | 照常过 | 干脆把家里彻底打扫了一遍，用忙碌压住 |
| 通话 | 当晚就打了 | 忍住没打 |
| 第几天开始适应 | 第二天 | 一直没适应 |
| 反向 | 他在家 | 她在外地，同样在做惯性动作，两边对切 |

「对切」是两边各写一半：两个人照着习惯做同一件事，谁也不知道对方也在做。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她在酒店里给两个人倒了水 | 盛出两碗饭 |
| 内心 | 我居然习惯了 | 到点了 |
| 好的处理 | 两边都没说想你 | 他没收那副碗 |
| 写崩 | 写成她一头扎进工作里 | 写成他坐不住 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 还是摆了两副碗筷／马厩空了，他还是去添了草料 |
| 修仙 | 还是煮了两份灵茶／守着个没人住的洞府 |
| 星际 | 舱里温度、氧气，还是按两个人调的 |

#### 写崩的三种方式

1. 直接写他想她。 只写惯性，想念一个字不提。
2. 让他哭。 这条要干。
3. 只写他这一头。 两边对切着写才完整。

#### 示例（本库自撰，可直接改写）

> 两个碗，两双筷子，摆得整整齐齐。
> 他盛完饭才想起来，站在桌边看了一会儿，没有把多余的那一副收走。
> 七点十分，楼道里有脚步声。他站起来，走了两步，才反应过来那是隔壁。
> 手机响了。他看着屏幕，等它响到第三声才接。
> 「吃了。」他说，眼睛落在那碗没动过的饭上，「都挺好的，你别惦记。」
> 电话那头有雨声。他问：「你那边下雨了？」

## 四 · 陪床

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：发烧生病 49.4% ＋ 守着不睡 7.2%

**骨架**｜有人住院，一个躺着，一个在旁边陪床。

#### 节拍链

住进来 → 第二天带来家里的杯子 → 输液瓶换了几次 → 第五天他开始赶她回家 → 「我不」→ 出院那天谁都不知说什么

#### 时间轴

病房里外头来的动静，只有护士进来换瓶。他按输液瓶算时间，一瓶差不多四十分钟。到第五天他开始赶她走，可一天比一天赶得没劲。出院那天两个人反倒不知道怎么办了，回到家还得重新适应。

#### 与「半夜发烧」的区别

[01-日常照料 · 半夜发烧](01-日常照料.md#三--半夜发烧)只有一夜。陪床要陪很多天，写法完全两样：别写着急，写日子怎么在一个陌生地方重新过起来。

| 观察点 | 内容 |
|---|---|
| 第几天 | 陪床戏按天数往前推 |
| 陪床的人怎么睡 | 折叠椅、沙发、直接趴床边 |
| 日常怎么重建 | 保温桶、洗漱用品、她带来的枕头 ✓ |
| 谁在照顾谁 | 到第五天，躺着的人开始心疼陪的人 |

最后一行是个转折：躺着的人开始心疼陪床的人。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 输液 ✓ · 医院 ✓ · 保温杯 ✓ · 毛巾 ✓ · 药 ✓ · 病房的窗 · 折叠椅 |
| 时间的记录 | 输液瓶换了几次 · 窗外从白到黑到白 · 他胡子长出来了／她三天没洗头 |
| 重建日常 | 从家里带来的杯子 · 电视调到熟悉的台 · 手机 ✓ 充电线 ✓ 缠在床栏上 |
| 转折的信号 | 「你回家睡一晚」「我不」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁住院 | 他 | 她，陪床的是他，戏更少见 |
| 病情 | 小手术 | 拖很久 |
| 陪的人 | 就她一个 | 有人来换班，她也不走 |
| 结局 | 出院 | 出院那天俩人谁都不知该说啥 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她学会了看输液速度 | 醒来第一眼看她在不在椅子上 |
| 好的处理 | 她把家里的杯子带来了 | 他开始赶她回家睡 |
| 写崩 | 写成她啥都不要了光守着 | 写成他病恹恹等人疼 |

「她把家里的杯子带来了」：到了这儿，她也照样过日子。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 侍疾／她亲手煎药／她住进偏房守着 |
| 修仙 | 他疗伤闭关，她守在洞外／天天渡灵力给他 |
| 星际 | 医疗舱外放把椅子坐着等／她把办公用的东西都搬来了 |

「她把办公用的东西都搬来了」跟「把家里的杯子带来」是一回事：把自己的日子挪到这儿来。

#### 写崩的三种方式

1. 写她什么都不要了。 把工作搬过来比辞职更真，也更戳人。
2. 让病人一直虚着。 到了第五天，他就开始管她了。
3. 跳过重新过日子的那部分。 这条线跟急救戏差就差在这儿。

## 五 · 每天的电话

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：联系不上 23.2%

**骨架**｜天天通电话，净说些没营养的话，谁也不肯先挂。

#### 节拍链

谁先打 → 说些没营养的 → 沉默但不挂 → 电快没了还不挂 → 「那我挂了」→「嗯」→「……你挂」

#### 时间轴

内容再空，通话时长也做不了假。第一周每天二十分钟，到第三周涨到四十分钟，还舍不得挂。充电线够不着床的那晚，电量一格格往下掉，最不是滋味。要紧的在挂断之前：从说出「那我挂了」到真挂断，平均还能拖六分钟。

#### 通话的形状

| 观察点 | 显示什么 |
|---|---|
| 谁先打 | 谁在等 |
| 打了多久 | 关系温度 |
| 说了什么 | 通常没营养，这是好的 |
| 谁先说挂 | 权力，或者体贴 |
| 挂之前那句 | 最要紧 |
| 有没有沉默的部分 | 沉默还不挂，最亲密 |

「沉默还不挂」：电话开着，两个人各忙各的，谁也不说话。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓ · 充电 ✓，电快没了还不挂 · 耳机 ✓ · 视频 ✓ |
| 背景音 | 她那边的雨 · 他这边的抽油烟机 ✓ · 电视 |
| 内容 | 今天吃了什么 · 一件很小的事讲了三分钟 |
| 挂之前 | 「那我挂了」「嗯」「……你挂」 |
| 时长记录 | 通话记录上的分钟数，一天比一天短／长 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先打 | 他 | 她少见，但他更乐意 |
| 内容 | 话多 | 没话 |
| 频率 | 天天打 | 越打越少（得留神） |
| 视频还是语音 | 视频 | 只语音，他怕她看见自己 |

「只语音」这头可以埋一条线：他不想让她看见的，就是这一章藏着的事。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他每次都提前十分钟等着 | 电话接通前那两声嘟 |
| 好的处理 | 她净说些有的没的 | 他不问她啥时候回来 |
| 写崩 | 写成她在做工作汇报 | 写成他在盯梢 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 家书／每月一封／他数着日子等驿站 |
| 修仙 | 传音玉简／每日一道 |
| 星际 | 定时通讯窗口／延迟四小时的单向留言 |

星际版是单向留言，他说完得等四小时才知道她怎么回，所以每句话说出去都像对着空气。

#### 写崩的三种方式

1. 让通话说正事。 这一条要的就是废话。
2. 不写怎么挂的电话。 挂之前那几个来回最要紧。
3. 不写打得勤还是少。 越打越少，就是出事了。

## 六 · 提前回来

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：开门到家 46.2%

**骨架**｜她比说好的早一天回来，事先也没讲。

#### 节拍链

她提前订了票 → 忍住没说 → 到家 → 他不在／他在 → 那一刻

#### 时间轴

她提前一天订了票，忍了二十四小时没说，每回打电话都差点说漏嘴。门一开，接下来就看他怎么反应，最要紧的是他愣住的那两秒。

#### 两种走向

| 他在不在 | 走向 |
|---|---|
| 他在，且正在做那些惯性动作 | 甜。她看见了自己不在时的家 |
| 他在，但状态很差 | 揪心。她看见了他一个人时的样子 |
| 他不在 | 她在家里等，角色对调 |
| 他不在，且家里很空 | 最疼的一版 |

「家里很空」说的是他一个人在家时不开火、不开灯，外卖盒堆着。原来那些日常，都是做给她的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的隐瞒 | 憋了三天没说 · 差点说漏嘴 · 改签了机票没跟他讲 |
| 进门 | 钥匙 ✓ 拧动的声音 · 她故意轻手轻脚 |
| 她看见的 | 桌上摆着两副碗筷 ✓ · 沙发 ✓ 上的毯子 · 垃圾桶里的外卖盒 |
| 他的反应 | 愣住 · 手里的东西掉地上 · 站那儿不敢动 |
| 第一个动作 | 谁先迈步走过去 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提前 | 她 | 他（他去了她那边） |
| 隐瞒程度 | 完全没说 | 他其实猜到了，一直在算日子 |
| 他的状态 | 好 | 不好 |
| 反应 | 扑过来 | 站着没动，然后眼睛红了 |

比起「扑过来」，「站着没动，然后眼睛红了」更戳人。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 开门后看见的那个家 | 听见钥匙声的那一秒 |
| 内心 | 原来他一个人是这么过的 | 是不是听岔了 |
| 好的处理 | 她先放下行李，再走过去 | 他没马上动 |
| 写崩 | 写成惊喜派对那种闹腾 | 写成他绷不住大哭 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 提前班师／她连夜赶回／不让人通报 |
| 修仙 | 提前出关／她的气息忽然出现在山门 |
| 星际 | 提前跃迁／她没申报行程 |

#### 写崩的三种方式

1. 写成生日惊喜。 这一条好在私密。
2. 让他毫无防备就狂喜。 那一愣得留着。
3. 省略她看见的家。

## 七 · 重逢的第一眼

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送等候 37.1%

**骨架**｜隔着人群认出对方的那一秒。

#### 节拍链

在人群里找 → 找错两次 → 先认出走路的姿势 → 身体先动 → 走过去那段路 → 第一句话很平常

#### 时间轴

在人群里找了几十秒，认错两回，心一回比一回跳得快。认出来的那一秒，身体比脑子先动。走过去那段路只有十几米，走的人觉得像走了一辈子。

#### 一秒里的三个阶段

| 阶段 | 内容 |
|---|---|
| 没看见 | 在人群里找，找错了两次 |
| 看见了 | 认出的那一下，身体先动 |
| 走过去 | 戏全在这段路有多长 |

「找错了两次」不能少。一下就看见了，就没有那一秒了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 找的动作 | 踮脚 · 手机 ✓ 举起来又放下 · 数出来的人 |
| 认出的信号 | 先认出走路的样子／背影／某件衣服 ✓ |
| 身体的反应 | 呼吸停一下 · 往前迈了一步才想起挥手 |
| 走过去的这段 | 谁走得快 · 最后几步是不是跑的 · 中间隔着啥 |
| 到面前 | 说的第一句话，一般没啥特别的 |

第一句话多半很平常，「你瘦了」「路上堵吗」。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时长 | 三天 | 三年 |
| 场合 | 私下 | 大庭广众，不能抱 |
| 第一个动作 | 抱 | 只敢握手腕 ✓ |
| 第一句话 | 随口说的 | 张不开嘴 |
| 变化 | 谁都没变 | 有一个人变了，这条更难写 |

分开久了，总有人会变。重逢难，难在得重新认识。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 在人群里认出他的那一下 | 她还没看见我，我先看见她了 |
| 内心 | 他好像瘦了 | 我要不要现在挥手 |
| 好的处理 | 她的第一句话很平常 | 他先看见的，但他等她找到 |
| 写崩 | 写成慢镜头奔跑拥抱 | 写成他痛哭失声 |

「他等她找到」：他早看见她了，没喊，就等她自己把他找出来。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 城门／码头／她的车驾进城他在人群里 |
| 修仙 | 山门／她御剑落下的那一刻 |
| 星际 | 闸口／舷窗外她的舰体进港 |

#### 写崩的三种方式

1. 写成慢镜头。 这一段的节奏总被人群打断。
2. 第一句话太重。 越平常越好。
3. 把找错的两次省了。 那两次就是铺垫。

## 八 · 回家之后

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：开门到家 46.2%

**骨架**｜重逢的热乎劲一过，接着就得重新磨合着过日子。

#### 节拍链

人回来后，说话客气了些，碰到对方时会犹豫一下，睡觉躺错了位置。磨了几天，某个私人仪式又自己回来了。

#### 时间轴

头几天没什么动静，直到某个私人仪式自己回来：睡前那杯水，出门前拍一下肩。它回来那天，磨合期就算过去了，谁也没宣布。第一天说话还客客气气，第二天碰到对方还要犹豫半拍，第三天睡觉各回各的位置，第四五天，仪式自己回来了。走到哪一步，全看这些小动作，磨合期三到五天。

#### 为什么要写这一条

重逢了，事情还没完。分开的这段日子里，人都会变，各自添了新习惯，聊着聊着总有几秒接不上，那种生分说不清道不明。

多数作品写到重逢就收笔了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 生分的迹象 | 说话见外了 · 碰她的时候顿了一下 · 睡觉躺错了地方 |
| 新习惯 | 他这半年多了个毛病 · 她嘴里多了句新口头禅 |
| 磨合 | 头一顿饭做多了／做少了 · 洗澡谁先谁后乱了套 |
| 恢复的信号 | 那个只有俩人知道的仪式，又自己冒出来了（见 [07 卷第十条](07-馈赠与仪式.md#十--一个只属于他们的仪式)） |
| 时长 | 三天 · 一周 |

那个只有两个人知道的仪式又冒出来了，谁都不用说「我们和好了」。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 生分程度 | 一晚就过去了 | 一周 |
| 谁先察觉 | 她 | 他 |
| 处理 | 直接说出来 | 各自等它过去 |
| 结果 | 完全恢复 | 有一点东西永久地变了（更真实） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她愣了一下，才想起他杯子搁哪儿了 | 她睡觉的姿势跟以前不一样了 |
| 好的处理 | 她直接说了句：「还不太习惯」 | 他没装成啥事没有 |
| 写崩 | 写成俩人立马黏糊得不行 | 写成他整天瞎琢磨怕这怕那 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 回家头几天，礼数全忘了，他拿不准要不要跪 |
| 修仙 | 一出关才发现，闭关几十年，外头早换了几代人 |
| 星际 | 时间对不上，她飞了两年回来，他这边已过八年 |

修仙和星际版里，同一段分离，两个人过的时间并不一样长，重逢后对不上也就说得通。

#### 写崩的三种方式

1. 跳过这一段。 很多作品都省了，这里别省。
2. 把生分写成误会。 时间一长，自然就会这样。
3. 让什么都马上复原。 留一点没恢复的。

#### 可串接

前接：[七 · 重逢的第一眼](#七--重逢的第一眼)

## 九 · 走的是他

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送等候 37.1%

**骨架**｜平常出差、远行的是她，这一条反过来。

#### 节拍链

他拿到机会 → 她第一反应是安排 → 忍住不问「非去不可吗」→ 清单推过去 → 送走 → 她开始数日子

#### 时间轴

送走他那一刻，倒数就开始了。日子照常过，只是每晚的电话都按他那边的时差掐着打，日历上的记号一页页画到他回来那天。航班号她背得滚瓜烂熟，嘴上却说「记不清了」。

#### 为什么要单独写

这一族默认是她走他留，因为有事业、有正事、被外面点名要的是她。他走的那一版很少见，考的是她受不受得了什么都不知道、什么也管不着的日子。

#### 他为什么会走

| 原因 | 性质 |
|---|---|
| 他自己的事业 | 最健康，也最少被写 |
| 家里出事 | 被迫 |
| 他要去证明什么 | 与关系直接相关 |
| 他需要离开一阵 | 关系出了问题 |

第一种在语料里少见，值得专门写。在这一类里，他有自己的事要去做，这本身就很难得。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的反应 | 先忙着张罗订票、塞钱、找人帮忙 · 回头才顾上舍不得 |
| 她的克制 | 憋着没问那句「非去不可吗」 |
| 她一个人时 | 她照旧忙活的样子（对照 [三 · 她不在的第一天](#三--她不在的第一天)） |
| 他那边 | 他在那边顺不顺，她总是最后才听说 |

「她第一反应是安排」：她表达感情，就是动手把问题解决掉。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她支不支持 | 全力支持 | 心里不情愿但没说 |
| 他去做的事 | 成功了 | 失败了，狼狈地回来 |
| 联系 | 频繁 | 他报喜不报忧 |
| 结局 | 回来 | 她过去了 |

「她过去了」这种结局在这一类里很少见，也很有力：这回是她为他挪了地方。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己开始掰着指头算日子 | 我得让她知道，我不光会躲在她后头 |
| 内心 | 我是不是该拦一下 | 我不能让她替我操心 |
| 好的处理 | 她没拦，但能铺的路全铺好了 | 他搞砸了，也老老实实说了 |
| 写崩 | 写成她装大方、假放手 | 写成他一赌气就玩消失 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他回本家／他要去考功名／他去从军（罕见但极有戏） |
| 修仙 | 他要自己去历练／不靠她的资源 |
| 星际 | 他申请了独立任务 |

「他去从军」放在古代女尊设定里极有戏：那个世界里男人不该上战场，他偏去了。

#### 写崩的三种方式

1. 让他走只为赌气。 他得有自己要干的事。
2. 让她对他那边的事了如指掌。 她得不知情。
3. 让他一定成功。 灰头土脸地回来也算一种结局，还更真实。

## 十 · 旧地

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送等候 37.1% 衍生

**骨架**｜多年以后，其中一个人又回去了一趟。

#### 节拍链

很久以后 → 一个人去 → 站一会儿 → 找变了的 → 找到一样没变的 → 什么也没做就走了

#### 时间轴

那棵树、那级台阶都还在，店已经换了招牌。人在原地站了十分钟，眼睛在找哪里变了，记忆在找哪里没变，然后什么也没做就走了。

#### 用法

这一条适合放在结尾，或者时间跳过一大段之后。前面所有的日常，都收进了这一个地方。

| 地点 | 唤起 |
|---|---|
| 那间出租屋 | 最初的日常 |
| 那个路口 | 送别 |
| 那家店 | 一次很小的事 |
| 那张沙发 ✓ | 哭着睡着的那次 |
| 那个玄关 ✓ | 留灯的那些夜 |

前提是这些地方前文写到过。没铺垫过的旧地，读者不会有感觉。

#### 可用细节

| 类 | 内容 |
|---|---|
| 变化 | 店换了招牌 · 那面墙重新刷过 · 沙发换了 · 玄关的灯改成感应的了 |
| 没变的 | 一样很小的东西：门框上的划痕、墙角的一块瓷砖 |
| 谁去的 | 一个人去 · 两个人一起去 · 一个人去，另一个在等 |
| 做了什么 | 什么也没做 · 站了一会儿 · 拍了张照片 ✓ |

「门框上的划痕」（量身高留下的）回收起来很顺手。见 [06-身体接触 · 量身高](06-身体接触.md#六--量身高)。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 结局 | 两人还在一起 | 已经不在一起了 |
| 谁去 | 他 | 她 |
| 变化 | 全变了 | 一样东西没变 |
| 情绪 | 暖 | 空 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现那道划痕还在 | 沙发换了，位置没换 |
| 好的处理 | 她什么都没说，拍了张照 | 他站了一会儿就走了 |
| 写崩 | 写成大段回忆闪回 | 写成他睹物思人的独白 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 旧宅／她当年住过的那间／院里的那棵树长高了 |
| 修仙 | 洞府／百年后再来，禁制还在 |
| 星际 | 那个泊位／那颗星球的那片海 |

修仙版里，过了百年禁制还在，可见这些年没人来撤过。

#### 写崩的三种方式

1. 写成回忆闪回。 只写眼前看到的，回忆留给读者自己补。
2. 让什么都变了。 得留一样没变的。
3. 用在没铺垫过的地方。 旧地要靠前文先铺好。
