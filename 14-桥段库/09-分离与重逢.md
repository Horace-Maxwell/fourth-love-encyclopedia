## 分离为什么是日常戏的放大器

前面八卷写的都是在场时的事。这一卷写不在场。

一个人走了之后，他留下的痕迹才显形。 平时看不见的东西，在缺席时全部浮出来：那一侧的床、多倒的一杯水、习惯性留的灯、准备好又没人吃的饭。

所以这一族的写法有一个通用配方：

| 步 | 做什么 |
|---|---|
| 1 | 把某个日常动作写足（前面几章） |
| 2 | 分离 |
| 3 | 留在原地的人仍然做那个动作 |
| 4 | 他／她意识到自己在对空气做这件事 |

第 3 步是全族的核心。 不写想念，写惯性。

| 节拍族 | 作品数 | 占比 |
|---|---:|---:|
| 接送等候 | 920 | 31.8% |
| 联系不上 | 571 | 19.7% |

## 一 · 出差前夜

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送等候 31.8%

**骨架**｜行李箱敞开在地上，两个人都在做别的事。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 收拾行李 |
| 2 | 他往里塞东西（她不知道的东西） |
| 3 | 有一件事想说，没说 |
| 4 | 睡前 |
| 5 | 有一个人先睡着了（通常不是要走的那个） |
| 6 | 早上 |

#### 时间轴

行李箱的开合次数就是时间轴。 拉链拉上又打开三次，因为每次都想起还要带一样。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 行李箱 · 充电 ✓ 器（谁的）· 外套 ✓ · 药 ✓（他给她塞的）· 保温杯 ✓ |
| 他塞进去的 | 感冒药 · 她爱吃的那个牌子 · 一张纸条 · 他自己的一件衣服 |
| 想说没说的 | 「早点回来」（说了显得黏）· 「我陪你去」（他知道不行） |
| 睡前 | 谁先躺下 · 有没有多聊一会儿 · 明明该早睡却聊到很晚 |
| 早上 | 闹钟 ✓ 响之前她已经醒了 |

「他自己的一件衣服」是这条最好用的一个道具：它会在千里之外替他在场。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁走 | 她（更常见） | 他 |
| 时长 | 三天 | 半年 |
| 气氛 | 平常 | 前一天刚吵完架 |
| 那句话 | 说了 | 到机场才说 · 或者一直没说 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现箱子里多了东西 | 塞进去时的那一下犹豫 |
| 内心 | 我要不要说别送了 | 我能不能说一句「早点回来」 |
| 好的处理 | 她收拾时把那件衣服留下了 | 他没说，但他塞了 |
| 写崩 | 写成她公事公办 | 写成他难舍难分 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 打点行装／他在包袱里塞了平安符／她出征前夜 |
| 修仙 | 她要闭关／出远门历练／他给的护身符 |
| 星际 | 出航前夜／他把自己的一段录音塞进她的终端 |

#### 写崩的三种方式

1. 让两人促膝长谈。 说尽了，后面的思念就空了。
2. 省略他塞东西。 那是全条唯一的动作。
3. 写成生离死别。 三天而已。

## 二 · 送到门口

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送等候 31.8%

**骨架**｜他一直送，送到不能再送。

#### 节拍链

他送 → 一路找理由多送一段 → 她说「回去吧」→ 他停下 → 没有立刻转身 → 楼道的声控灯灭了

#### 时间轴

路程是固定的，他把它走出了弹性。 三百米的路，绕一句「顺便买个水」就多二百米，再绕一句就到了楼下。真正的钟是声控灯：她上楼，灯一层层亮又一层层灭，最后一层灭掉之前，他都站在原地。

#### 送的层级

| 送到哪 | 读作 |
|---|---|
| 门口 | 常规 |
| 楼下 | 多送了一段 |
| 路口 | 他找不到停下的理由了 |
| 车站／机场 | 全程 |
| 他站在原地看她走 | 全条的落点 |

「他站在原地看她走」这一拍是必须的。 送的价值不在送，在停下之后。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的拖延 | 帮她拎东西（其实不重）· 替她按电梯 · 说一句无关的话 |
| 停下的理由 | 她说「回去吧」· 或者他自己停 |
| 停下之后 | 他没有立刻转身 · 他站到看不见为止 · 她没有回头（或者回头了） |
| 环境 | 电梯门合上的那一下 · 她的车拐弯 · 楼道的声控灯灭了 |

「楼道的声控灯灭了」是极好的收尾：他站得太久，灯以为没人。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 送多远 | 门口 | 他一路送到了机场 |
| 她回不回头 | 回头，挥手 | 没回头（她知道回头会走不了） |
| 他的停 | 她让他停 | 他自己停 |
| 事后 | 他立刻回家 | 他在楼下站了很久 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她要不要回头 | 她转过弯的那一下 |
| 内心 | 回头就走不了了 | 再看一眼 |
| 好的处理 | 她没回头，但她放慢了脚步 | 他站到灯灭 |
| 写崩 | 写成她洒脱转身 | 写成他追出去 |

「她放慢了脚步」是最好的处理：不回头是克制，放慢是心软，两个都做到了。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 送到府门／送到城外／十里长亭 |
| 修仙 | 送到山门／看她御剑远去成一个点 |
| 星际 | 送到闸口／看舰体离港 |

#### 写崩的三种方式

1. 让他追出去。 停下才是这条。
2. 让她大方地告别。 放慢脚步就够了。
3. 省略停下之后。 那是全条的内容。

## 三 · 她不在的第一天

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送等候 31.8% ＋ 联系不上 19.7%

**骨架**｜他照常做了所有的事，做完才发现没有人回来。

#### 节拍链

照常做饭 → 盛出两碗才想起 → 到了她平常回来的点 → 他看了一眼门 → 没收那副碗 → 她来电话，他说「都挺好的」

#### 时间轴

日常的钟照常走，走到每个共用节点就空一格。 做饭的点、她平常进门的点、睡前互道晚安的点，他全按原时刻表执行，每到一个节点空一拍。那通电话是全天唯一的补给，「都挺好的」四个字他练了半小时。

#### 惯性清单

这条的全部内容就是这张表。不写想念，写惯性。

| 惯性动作 | 发现的方式 |
|---|---|
| 做了两个人的饭 | 盛出来才想起 |
| 倒了两杯水 | 另一杯放在桌上一晚上 |
| 留了玄关 ✓ 的灯 | 睡前才关 |
| 睡在自己那一侧 | 床太空 |
| 听见楼道有脚步声 | 站起来了才反应过来 |
| 想说一句话 | 转过头才想起没人 |
| 买菜买了两份 | 结账时才发现 |

「站起来了才反应过来」是最好的一条。 身体先于意识。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 餐桌 ✓ · 碗 ✓（多摆的那一副）· 被子 ✓ · 沙发 ✓ · 门 ✓ |
| 时间 | 到了她平常回来的点 · 他看了一眼门 |
| 处理方式 | 他没有收起多摆的那副碗 · 或者他收了，收得很快 |
| 晚上 | 他睡在她那一侧 · 或者坚持睡自己那侧 |

「他睡在她那一侧」和「他坚持睡自己那侧」是两种完全不同的人物，都对。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的处理 | 照常过 | 干脆把家里彻底打扫了一遍（用忙碌压住） |
| 通话 | 当晚就打了 | 忍住没打 |
| 第几天开始适应 | 第二天 | 一直没适应 |
| 反向 | 他在家 | 她在外地，同样在做惯性动作（对切） |

「对切」是这条最好的结构： 两地各写一半，两个人做着同一件惯性动作，谁都不知道对方也在做。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她在酒店里给两个人的杯子倒了水 | 盛出两碗饭 |
| 内心 | 我居然习惯了 | 到点了 |
| 好的处理 | 两边都没有说想你 | 他没有收那副碗 |
| 写崩 | 写成她全然投入工作 | 写成他坐立不安 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 照常摆了两副碗筷／她的马厩空着他还是去添了草料 |
| 修仙 | 照常煮了两份灵茶／守着空洞府 |
| 星际 | 舱内环境还是按两个人的参数设着 |

#### 写崩的三种方式

1. 直接写他想她。 全条只写惯性，不写想念。
2. 让他哭。 这条要干。
3. 只写他这一边。 对切结构才是完整的。

#### 示例（本库自撰，可直接改写）

> 两个碗，两双筷子，摆得整整齐齐。
> 他盛完饭才想起来，站在桌边看了一会儿，没有把多余的那一副收走。
> 七点十分，楼道里有脚步声。他站起来，走了两步，才反应过来那是隔壁。
> 手机响了。他看着屏幕，等它响到第三声才接。
> 「吃了。」他说，眼睛落在那碗没动过的饭上，「都挺好的，你别惦记。」
> 电话那头有雨声。他问：「你那边下雨了？」

## 四 · 陪床

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：发烧生病 45.7% ＋ 守着不睡 6.4%

**骨架**｜住院。一个人躺着，一个人在旁边住下来。

#### 节拍链

住进来 → 第二天带来家里的杯子 → 输液瓶换了几次 → 第五天他开始赶她回家 → 「我不」→ 出院那天谁都不知说什么

#### 时间轴

以输液瓶为钟。 一瓶四十分钟，换瓶时护士进来是仅有的外部事件；第五天他开始赶她回家，赶人的力度一天比一天弱。出院那天钟停了，两个人反而不知道怎么办，医院的时间结构没了，得重新回到家的时间结构里。

#### 与「半夜发烧」的区别

[01-日常照料 · 半夜发烧](01-日常照料.md#三--半夜发烧) 是一夜的事。陪床是很多天，所以它的写法完全不同：不写焦急，写日常在异地重建。

| 观察点 | 内容 |
|---|---|
| 第几天 | 陪床戏靠天数推进 |
| 陪床的人怎么睡 | 折叠椅、沙发、直接趴床边 |
| 日常怎么重建 | 保温桶、洗漱用品、她带来的枕头 ✓ |
| 谁在照顾谁 | 到第五天，躺着的人开始担心陪的人 |

最后一行是这条的转折。 病人开始心疼陪床的，这个反转比任何深情台词都有效。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 输液 ✓ · 医院 ✓ · 保温杯 ✓ · 毛巾 ✓ · 药 ✓ · 病房的窗 · 折叠椅 |
| 时间的记录 | 输液瓶换了几次 · 窗外从白到黑到白 · 她胡子长出来了／她三天没洗头 |
| 重建日常 | 从家里带来的杯子 · 电视调到熟悉的台 · 手机 ✓ 充电线 ✓ 缠在床栏上 |
| 转折的信号 | 「你回家睡一晚」「我不」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁住院 | 他 | 她（陪床的是他，戏更少见） |
| 病情 | 小手术 | 长期 |
| 陪的人 | 她一个人 | 有人换班，但她不肯走 |
| 结局 | 出院 | 出院那天两人都不知道说什么好 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她学会了看输液速度 | 醒来第一眼看她在不在椅子上 |
| 好的处理 | 她把家里的杯子带来了 | 他开始赶她回家睡 |
| 写崩 | 写成她放弃一切守候 | 写成他病弱美人 |

「她把家里的杯子带来了」是这条最好的一个动作：她不是在等他好，她是在这里过日子。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 侍疾／她亲自煎药／她在偏房住下 |
| 修仙 | 疗伤闭关她在洞外守着／每日渡一次灵力 |
| 星际 | 医疗舱外的观察椅／她把办公终端搬了过来 |

「她把办公终端搬了过来」和「把家里的杯子带来」是同一个动作：把自己的生活挪过来。

#### 写崩的三种方式

1. 写成她抛下一切。 她把工作搬过来比她辞职更真实也更有力。
2. 让病人一直虚弱。 第五天他要开始管她。
3. 省略日常重建。 那是这条区别于急救戏的全部。

## 五 · 每天的电话

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：联系不上 19.7%

**骨架**｜通话本身没有内容。有内容的是通话的形状。

#### 节拍链

谁先打 → 说些没营养的 → 沉默但不挂 → 电快没了还不挂 → 「那我挂了」→「嗯」→「……你挂」

#### 时间轴

通话时长在说真话。 内容没营养，时长有营养：第一周每天二十分钟，第三周四十分钟还挂不断，「那我挂了」到真挂断之间平均隔六分钟，这六分钟才是电话的正文。电量条是倒计时，充电线够不着床的那晚最疼。

#### 通话的形状

| 观察点 | 显示什么 |
|---|---|
| 谁先打 | 谁在等 |
| 打了多久 | 关系温度 |
| 说了什么 | 通常是没营养的（这是好的） |
| 谁先说挂 | 权力，或者体贴 |
| 挂之前那句 | 全条的落点 |
| 有没有沉默的部分 | 沉默还不挂，是最亲密的形态 |

「沉默还不挂」是这条最好的写法。 两个人各做各的事，电话开着，谁都不说话。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓ · 充电 ✓（电快没了还不挂）· 耳机 ✓ · 视频 ✓ |
| 背景音 | 她那边的雨 · 他这边的抽油烟机 ✓ · 电视 |
| 内容 | 今天吃了什么 · 一件很小的事讲了三分钟 |
| 挂之前 | 「那我挂了」「嗯」「……你挂」 |
| 时长记录 | 通话记录上的分钟数，一天比一天短／长 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先打 | 他 | 她（更少见，也更让他高兴） |
| 内容 | 很多话 | 沉默 |
| 频率 | 每天 | 越来越少（这是警报） |
| 视频还是语音 | 视频 | 只语音（他不想让她看见自己的样子） |

「只语音」这一端可以承载一条暗线：他不想被看见的东西，正是这一章的秘密。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他每次都是提前十分钟就在等 | 电话接通前那两声等待音 |
| 好的处理 | 她说的都是废话 | 他不问她什么时候回来 |
| 写崩 | 写成她公事汇报 | 写成他查岗 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 家书／每月一封／他数着日子等驿站 |
| 修仙 | 传音玉简／每日一道 |
| 星际 | 定时通讯窗口／延迟四小时的单向留言 |

星际版的单向留言最动人：他说完要等四小时才知道她怎么答，所以他说的每句话都是对着空气说的。

#### 写崩的三种方式

1. 让通话有实质内容。 废话才是亲密。
2. 省略挂电话的过程。 那是全条的高点。
3. 不写频率变化。 频率就是关系曲线。

## 六 · 提前回来

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：开门到家 42.5%

**骨架**｜她比说好的早回来一天，且没说。

#### 节拍链

她提前订了票 → 忍住没说 → 到家 → 他不在／他在 → 那一刻

#### 时间轴

惊喜有一个精确的引爆时刻，前面全是引线。她提前一天订票，忍了二十四小时没说，每次通话都差点说漏，这段忍是前戏。开门那一秒引爆；之后的时间归他的反应，愣住那两秒，比后面所有拥抱都值钱。

#### 两种走向

| 他在不在 | 走向 |
|---|---|
| 他在，且正在做那些惯性动作 | 甜。她看见了自己不在时的家 |
| 他在，但状态很差 | 揪心。她看见了他一个人时的样子 |
| 他不在 | 她在家里等，角色对调 |
| 他不在，且家里很空 | 最疼的一版 |

「家里很空」是指他一个人时没有开火、没有开灯、外卖盒堆着。 这说明那些日常是为她做的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的隐瞒 | 忍了三天没说 · 差点说漏 · 改了机票没告诉他 |
| 进门 | 钥匙 ✓ 转动的声音 · 她故意放轻 |
| 她看见的 | 桌上摆着两副碗 ✓ · 沙发 ✓ 上的毯子 · 垃圾桶里的外卖盒 |
| 他的反应 | 愣住 · 手里的东西掉了 · 站在原地不敢动 |
| 第一个动作 | 谁先走过去 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提前 | 她 | 他（他去了她那边） |
| 隐瞒程度 | 完全没说 | 他其实猜到了（他一直在算日子） |
| 他的状态 | 好 | 不好 |
| 反应 | 扑过来 | 站着没动，然后眼睛红了 |

「站着没动，然后眼睛红了」比「扑过来」更有分量。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 开门后看见的那个家 | 听见钥匙声的那一秒 |
| 内心 | 原来他一个人是这样过的 | 是不是听错了 |
| 好的处理 | 她先把行李放下，再走过去 | 他没有立刻动 |
| 写崩 | 写成惊喜派对式的欢庆 | 写成他失控大哭 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 提前班师／她连夜赶回／不让人通报 |
| 修仙 | 提前出关／她的气息忽然出现在山门 |
| 星际 | 提前跃迁／她没申报行程 |

#### 写崩的三种方式

1. 写成生日惊喜。 这条的力度来自私密。
2. 让他毫无准备地狂喜。 那一愣要留。
3. 省略她看见的家。 那才是这条的信息。

## 七 · 重逢的第一眼

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送等候 31.8%

**骨架**｜看见的那一秒。这条只有一秒，但它是这一族的顶点。

#### 节拍链

在人群里找 → 找错两次 → 认出（先认出走路的姿势）→ 身体先动 → 走过去那段路 → 第一句话很平常

#### 时间轴

只有一秒，前后各拉一条长焦。 前面是人群里搜索的几十秒（找错两次，心跳一次比一次快）；认出的那一秒身体先于意识动了；之后是走过去的那段路，十几米，走的人觉得走了很久。三段速度不同，中间那一秒最短也最重。

#### 一秒里的三个阶段

| 阶段 | 内容 |
|---|---|
| 没看见 | 在人群里找，找错了两次 |
| 看见了 | 认出的那一下，身体先动 |
| 走过去 | 这段路的长度就是全部的张力 |

「找错了两次」是必须的。 直接看见就没有那一秒了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 找的动作 | 踮脚 · 手机 ✓ 举起来又放下 · 数出口出来的人 |
| 认出的信号 | 先认出的是走路的姿势／背影／某件衣服 ✓ |
| 身体的反应 | 呼吸停一下 · 往前迈了一步才想起要挥手 |
| 走过去的这段 | 谁走得快 · 最后几步是跑的吗 · 中间隔着什么 |
| 到面前 | 说的第一句话（通常很平常） |

「说的第一句话通常很平常」是这条最好的收尾。 「你瘦了」「路上堵吗」比任何深情台词都真。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时长 | 三天 | 三年 |
| 场合 | 私下 | 人很多（不能抱） |
| 第一个动作 | 抱 | 只是握住手腕 ✓ |
| 第一句话 | 很平常 | 说不出话 |
| 变化 | 都没变 | 有一方变了（这条更难写） |

「有一方变了」是长分离的必然。重逢难在重新认识，不在激动。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 在人群里认出他的那一下 | 她还没看见我，我先看见她了 |
| 内心 | 他好像瘦了 | 我要不要现在挥手 |
| 好的处理 | 她的第一句话很平常 | 他先看见的，但他等她找到 |
| 写崩 | 写成慢镜头奔跑拥抱 | 写成他痛哭失声 |

「他等她找到」是最好的一个细节。 他早就看见她了，但他没有喊，他要让她自己找到他。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 城门／码头／她的车驾进城他在人群里 |
| 修仙 | 山门／她御剑落下的那一刻 |
| 星际 | 闸口／舷窗外她的舰体进港 |

#### 写崩的三种方式

1. 写成慢镜头。 这条的节奏是被人群打断的。
2. 第一句话太重。 越平常越好。
3. 省略找错的两次。 那两次是这条的全部铺垫。

## 八 · 回家之后

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：开门到家 42.5%

**骨架**｜重逢的高点过去了，接下来是重新磨合。

#### 节拍链

回来 → 说话客气了一点 → 碰到对方时有一下犹豫 → 睡觉位置错了 → 磨合几天 → 某个私人仪式自然地又出现

#### 时间轴

磨合期三到五天，进度看小动作。 第一天说话带客气，第二天碰到对方还有半拍犹豫，第三天睡觉位置各归各位，第四五天某个私人仪式（睡前那杯水、出门前的那下拍肩）自己回来了，仪式回归的那天，磨合期结束，谁都没宣布。

#### 为什么要写这一条

因为重逢不是结束。分开的时间会留下痕迹：各自形成的新习惯、说不上来的生分、一句话要多想两秒才接得上。

大部分作品写到重逢就收了。写这一段的，才是真的在写关系。

#### 可用细节

| 类 | 内容 |
|---|---|
| 生分的迹象 | 说话客气了一点 · 碰到对方时有一下犹豫 · 睡觉的位置错了 |
| 新习惯 | 他这半年学会了一件事 · 她带回来一个新的口头禅 |
| 磨合 | 第一顿饭做多了／做少了 · 洗澡的顺序乱了 |
| 恢复的信号 | 某个私人仪式自然地又出现了（见 [07 卷第十条](07-馈赠与仪式.md#十--一个只属于他们的仪式)） |
| 时长 | 三天 · 一周 |

「私人仪式自然地又出现」是最好的恢复信号。 不需要任何人说「我们和好了」。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 生分程度 | 一晚就过去了 | 一周 |
| 谁先察觉 | 她 | 他 |
| 处理 | 直接说出来 | 各自等它过去 |
| 结果 | 完全恢复 | 有一点东西永久地变了（更真实） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己要想一下才知道他的杯子放哪 | 她的睡姿变了 |
| 好的处理 | 她说出来了：「有点不习惯」 | 他没有假装一切如常 |
| 写崩 | 写成两人立刻如胶似漆 | 写成他患得患失 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 归家后的头几日／规矩生疏了／他不知道该不该跪 |
| 修仙 | 出关后／寿元差让这段时间对两人的长度不同 |
| 星际 | 相对论时间差／她过了两年，他过了八年 |

修仙与星际共享一个别处没有的资源：分离的时长对两个人是不相等的。 这让重逢后的不同步有了物理依据。

#### 写崩的三种方式

1. 跳过这一段。 这是这一族最常被省略也最有价值的一条。
2. 把生分写成误会。 它不是误会，它是时间的正常结果。
3. 让一切立刻恢复。 留一点没恢复的。

## 九 · 走的是他

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送等候 31.8%

**骨架**｜通常是她出差、她远行。这条反过来。

#### 节拍链

他拿到机会 → 她第一反应是安排 → 忍住不问「非去不可吗」→ 清单推过去 → 送走 → 她开始数日子

#### 时间轴

她的钟从送走那天开始倒数。 明面上她照常运转，暗地里日历有记号；每天的电话她掐着他那边的时差打，她这辈子没为任何人换算过时区。他回来的日期她口头说「记不清了」，实际精确到航班号。

#### 为什么要单独写

这一族默认的配置是她走他留，因为她是那个有事业、有职责、被外界征召的人。他走的那一版罕见，且它测试的是完全不同的东西：她能不能承受不掌握情况。

#### 他为什么会走

| 原因 | 性质 |
|---|---|
| 他自己的事业 | 最健康，也最少被写 |
| 家里出事 | 被迫 |
| 他要去证明什么 | 与关系直接相关 |
| 他需要离开一阵 | 关系出了问题 |

第一种在语料里几乎看不到，值得专门写。他有自己的事要去做，这件事本身在这一类里就是稀缺的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的反应 | 第一反应是安排（订票、给钱、托关系）· 然后才是舍不得 |
| 她的克制 | 忍住不问「非去不可吗」 |
| 她一个人时 | 她做惯性动作的样子（对照 [三 · 她不在的第一天](#三--她不在的第一天)） |
| 他那边 | 他在那边过得好不好，她是最后一个知道的 |

「第一反应是安排」是这条最准的一笔：她表达感情的方式就是解决问题。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她支不支持 | 全力支持 | 心里不情愿但没说 |
| 他去做的事 | 成功了 | 失败了，狼狈地回来 |
| 联系 | 频繁 | 他报喜不报忧 |
| 结局 | 回来 | 她过去了 |

「她过去了」这个结局在这一类里很少见，也很有力。强势方为对方改变位置，比宠溺一百次更重。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己在数日子 | 我要证明我不是只能待在她身后 |
| 内心 | 我是不是该拦 | 我不能让她担心 |
| 好的处理 | 她没拦，且她把能安排的都安排了 | 他失败了也说了 |
| 写崩 | 写成她大度放行的表演 | 写成他离家出走式的赌气 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他回本家／他要去考功名／他去从军（罕见但极有戏） |
| 修仙 | 他要自己去历练／不靠她的资源 |
| 星际 | 他申请了独立任务 |

「他去从军」在古代女尊设定里是最有张力的一版：在一个男性不该上战场的世界里，他去了。

#### 写崩的三种方式

1. 让他去的目的只是赌气。 他要有自己的事。
2. 让她全程掌控他那边的情况。 不知情才是这条的内容。
3. 让他必然成功。 狼狈地回来也是一种结局，且更真实。

## 十 · 旧地

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送等候 31.8% 衍生

**骨架**｜很久以后，其中一个人又去了那个地方。

#### 节拍链

很久以后 → 一个人去 → 站一会儿 → 找变了的 → 找到一样没变的 → 什么也没做就走了

#### 时间轴

两条时间轴在同一个地点交汇。 站在原地的十分钟里，当年的时间和现在的时间重叠着走：找变了的（店换了招牌）用眼睛，找没变的（那棵树、那级台阶）用记忆。什么也没做就走了，因为要做的事，当年已经做完了。

#### 用法

这条是全卷的收束件，用在结尾或者时间跳跃之后。它的机制是把前面所有的日常压缩进一个空间里。

| 地点 | 唤起 |
|---|---|
| 那间出租屋 | 最初的日常 |
| 那个路口 | 送别 |
| 那家店 | 一次很小的事 |
| 那张沙发 ✓ | 哭着睡着的那次 |
| 那个玄关 ✓ | 留灯的那些夜 |

前提是这些地方在前文出现过。 没铺过的旧地是没有重量的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 变化 | 店换了招牌 · 那面墙重新刷过 · 沙发换了 · 玄关的灯改成感应的了 |
| 没变的 | 一样很小的东西（门框上的划痕、墙角的一块瓷砖） |
| 谁去的 | 一个人去 · 两个人一起去 · 一个人去，另一个在等 |
| 做了什么 | 什么也没做 · 站了一会儿 · 拍了张照片 ✓ |

「门框上的划痕」（量身高留下的）是最好用的一个回收点。 见 [06-身体接触 · 量身高](06-身体接触.md#六--量身高)。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 结局 | 两人还在一起 | 已经不在一起了 |
| 谁去 | 他 | 她 |
| 变化 | 全变了 | 一样东西没变 |
| 情绪 | 暖 | 空 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现那道划痕还在 | 沙发换了，位置没换 |
| 好的处理 | 她什么都没说，拍了张照 | 他站了一会儿就走了 |
| 写崩 | 写成大段回忆闪回 | 写成他睹物思人的独白 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 旧宅／她当年住过的那间／院里的那棵树长高了 |
| 修仙 | 洞府／百年后再来，禁制还在 |
| 星际 | 那个泊位／那颗星球的那片海 |

修仙版最有力：百年后禁制还在，说明没有人来撤过。

#### 写崩的三种方式

1. 写成回忆闪回。 只写现在看见的，回忆交给读者。
2. 让一切都变了。 留一样没变的。
3. 在没铺垫的地方用它。 旧地的重量全部来自前文。
