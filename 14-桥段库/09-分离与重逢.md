## 分离为什么是日常戏的放大器

前面八卷写的都是在场时的事。这一卷写不在场。

一个人走了之后，他留下的东西才显出来。平时谁也不会注意的那些，等人不在了，全冒出来了：床那边空出来的一块、多倒的那杯水、习惯性留着的那盏灯、做好了没人吃的饭。

所以这一族的写法有一个通用配方：

| 步 | 做什么 |
|---|---|
| 1 | 把某个日常动作写足（前面几章） |
| 2 | 分离 |
| 3 | 留在原地的人仍然做那个动作 |
| 4 | 他／她意识到自己在对空气做这件事 |

第 3 步是全族的核心。 不写想念，写惯性。

|---|---:|---:|
| 接送等候 | 920 | 31.8% |
| 联系不上 | 571 | 19.7% |

## 一 · 出差前夜

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送等候 31.8%

**骨架**｜行李箱摊在地上，谁都没去管它。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 收拾行李 |
| 2 | 他往里塞东西（她不知道的东西） |
| 3 | 有一件事想说，没说 |
| 4 | 睡前 |
| 5 | 有一个人先睡着了（通常不是要走的那个） |
| 6 | 早上 |

#### 时间轴

行李箱的开合次数就是时间轴。 拉链拉上又打开三次，因为每次都想起还要带一样。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 行李箱 · 充电器（谁的）· 外套 · 药（他偷偷塞给她的）· 保温杯 |
| 他塞进去的 | 感冒药 · 她爱吃的那牌子 · 一张纸条 · 他自己的一件衣服 |
| 想说没说的 | 「早点回来」（说了显得黏人）·「我陪你去」（他知道不行） |
| 睡前 | 谁先躺下 · 有没有多聊几句 · 明明该睡了却聊到半夜 |
| 早上 | 闹钟还没响，她已经醒了 |

「他自己的一件衣服」是这条最好用的一个道具：它会在千里之外替他在场。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁走 | 她（更常见） | 他 |
| 时长 | 三天 | 半年 |
| 气氛 | 平常 | 前一天刚吵完架 |
| 那句话 | 说了 | 到机场才说 · 或者一直没说 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现箱子里多了东西 | 塞进去时的那一下犹豫 |
| 内心 | 我要不要说别送了 | 我能不能说一句「早点回来」 |
| 好的处理 | 她收拾时把那件衣服留下了 | 他没说，但他塞了 |
| 写崩 | 写成她公事公办 | 写成他难舍难分 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 收拾行李／他在包袱里塞了平安符／她出征前夜 |
| 修仙 | 她要闭关／出门历练／他给的护身符 |
| 星际 | 出发前夜／他录了段话存进她终端 |

#### 写崩的三种方式

1. 让两人促膝长谈。 说尽了，后面的思念就空了。
2. 省略他塞东西。 那是全条唯一的动作。
3. 写成生离死别。 三天而已。

## 二 · 送到门口

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送等候 31.8%

**骨架**｜他一直送，送到不能再送。

#### 节拍链

他送 → 一路找理由多送一段 → 她说「回去吧」→ 他停下 → 没有立刻转身 → 楼道的声控灯灭了

#### 时间轴

路程是固定的，他硬是把它走活了。三百米的路，加一句「顺便买个水」就多绕二百米，再绕一句，就到楼下了。真正的钟是声控灯：她上楼，灯一层层亮又一层层灭，最后一层灭掉之前，他一直站在原地。

#### 送的层级

| 送到哪 | 读作 |
|---|---|
| 门口 | 常规 |
| 楼下 | 多送了一段 |
| 路口 | 他找不到停下的理由了 |
| 车站／机场 | 全程 |
| 他站在原地看她走 | 全条的落点 |

「他站在原地看她走」这一拍是必须的。 送的价值不在送，在停下之后。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的拖延 | 帮她拎东西（其实不重）· 替她按电梯 · 没话找话 |
| 停下的理由 | 她说「回去吧」· 或者他自己停 |
| 停下之后 | 他没马上走 · 站到看不见为止 · 她没回头（或者回了） |
| 环境 | 电梯门一关 · 她的车拐弯 · 楼道灯灭了 |

「楼道的声控灯灭了」是极好的收尾：他站得太久，灯以为没人。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 送多远 | 门口 | 一路送到机场 |
| 她回不回头 | 回头，挥手 | 没回头（一回头就走不成了） |
| 他的停 | 她喊停才停 | 自己停下来 |
| 事后 | 他马上回家 | 他在楼下杵了半天 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她要不要回头 | 她转过弯的那一下 |
| 内心 | 回头就走不了了 | 再看一眼 |
| 好的处理 | 她没回头，但她放慢了脚步 | 他站到灯灭 |
| 写崩 | 写成她洒脱转身 | 写成他追出去 |

「她放慢了脚步」是最好的处理：不回头是克制，放慢是心软，两个都做到了。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 送到府门／送到城外／十里长亭 |
| 修仙 | 送到山门／看她御剑远去成一个点 |
| 星际 | 送到闸口／看舰体离港 |

#### 写崩的三种方式

1. 让他追出去。 停下才是这条。
2. 让她大方地告别。 放慢脚步就够了。
3. 省略停下之后。 那是全条的内容。

## 三 · 她不在的第一天

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送等候 31.8% ＋ 联系不上 19.7%

**骨架**｜他照常把该干的都干完了，一抬头才发现，没人回来。

#### 节拍链

照常做饭 → 盛出两碗才想起 → 到了她平常回来的点 → 他看了一眼门 → 没收那副碗 → 她来电话，他说「都挺好的」

#### 时间轴

日常的钟照常走，走到俩人共用的那些节点就空一格。做饭的点、她平常进门的点、睡前互道晚安的点，他全按原时刻表执行，每到一个节点就愣一下。那通电话是全天唯一的补给，「都挺好的」四个字他练了半小时。

#### 惯性清单

这条的全部内容就是这张表。不写想念，写惯性。

| 惯性动作 | 发现的方式 |
|---|---|
| 做了两个人的饭 | 盛出来才想起 |
| 倒了两杯水 | 另一杯放在桌上一晚上 |
| 留了玄关 ✓ 的灯 | 睡前才关 |
| 睡在自己那一侧 | 床太空 |
| 听见楼道有脚步声 | 站起来了才反应过来 |
| 想说一句话 | 转过头才想起没人 |
| 买菜买了两份 | 结账时才发现 |

「站起来了才反应过来」是最好的一条。 身体先于意识。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 餐桌 ✓ · 碗 ✓（多摆的那一副）· 被子 ✓ · 沙发 ✓ · 门 ✓ |
| 时间 | 到了她平时到家的点 · 他瞅了一眼门 |
| 处理方式 | 他没去收那副多摆的碗 · 要么收了，收得飞快 |
| 晚上 | 他睡她那边 · 要么硬睡自己那边 |

「他睡在她那一侧」和「他坚持睡自己那侧」是两种完全不同的人物，都对。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的处理 | 照常过 | 干脆把家里彻底打扫了一遍（用忙碌压住） |
| 通话 | 当晚就打了 | 忍住没打 |
| 第几天开始适应 | 第二天 | 一直没适应 |
| 反向 | 他在家 | 她在外地，同样在做惯性动作（对切） |

「对切」是这条最好的结构： 两地各写一半，两个人做着同一件惯性动作，谁都不知道对方也在做。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她在酒店里给两个人倒了水 | 盛出两碗饭 |
| 内心 | 我居然习惯了 | 到点了 |
| 好的处理 | 两边都没说想你 | 他没接那副碗 |
| 写崩 | 写成她一头扎进工作里 | 写成他坐不住 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 还是摆了两副碗筷／马厩空了，他还是去添了草料 |
| 修仙 | 还是煮了两份灵茶／守着个没人住的洞府 |
| 星际 | 舱里温度、氧气，还是按两个人调的 |

#### 写崩的三种方式

1. 直接写他想她。 全条只写惯性，不写想念。
2. 让他哭。 这条要干。
3. 只写他这一边。 对切结构才是完整的。

#### 示例（本库自撰，可直接改写）

> 两个碗，两双筷子，摆得整整齐齐。
> 他盛完饭才想起来，站在桌边看了一会儿，没有把多余的那一副收走。
> 七点十分，楼道里有脚步声。他站起来，走了两步，才反应过来那是隔壁。
> 手机响了。他看着屏幕，等它响到第三声才接。
> 「吃了。」他说，眼睛落在那碗没动过的饭上，「都挺好的，你别惦记。」
> 电话那头有雨声。他问：「你那边下雨了？」

## 四 · 陪床

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：发烧生病 45.7% ＋ 守着不睡 6.4%

**骨架**｜住院。一个人躺着，旁边有个人陪床。

#### 节拍链

住进来 → 第二天带来家里的杯子 → 输液瓶换了几次 → 第五天他开始赶她回家 → 「我不」→ 出院那天谁都不知说什么

#### 时间轴

以输液瓶当钟用。一瓶大概四十分钟，护士进来换瓶是唯一的外部动静；第五天他开始赶她走，赶人的劲儿一天比一天小。出院那天钟停了，两个人反而不知道咋办，医院的时间框架没了，得重新适应家里的时间。

#### 与「半夜发烧」的区别

[01-日常照料 · 半夜发烧](01-日常照料.md#三--半夜发烧) 是一夜的事。陪床是很多天，所以写法完全不一样：别写着急，写日常怎么在陌生地方重新搭起来。

| 观察点 | 内容 |
|---|---|
| 第几天 | 陪床戏靠天数往前推 |
| 陪床的人怎么睡 | 折叠椅、沙发、直接趴床边 |
| 日常怎么重建 | 保温桶、洗漱用品、她带来的枕头 ✓ |
| 谁在照顾谁 | 到第五天，躺着的人开始心疼陪的人 |

最后一行是这条的转折。 病人开始心疼陪床的，这个反转比任何深情台词都有效。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 输液 ✓ · 医院 ✓ · 保温杯 ✓ · 毛巾 ✓ · 药 ✓ · 病房的窗 · 折叠椅 |
| 时间的记录 | 输液瓶换了几次 · 窗外从白到黑到白 · 她胡子长出来了／她三天没洗头 |
| 重建日常 | 从家里带来的杯子 · 电视调到熟悉的台 · 手机 ✓ 充电线 ✓ 缠在床栏上 |
| 转折的信号 | 「你回家睡一晚」「我不」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁住院 | 他 | 她（陪床的是他，戏更少见） |
| 病情 | 小手术 | 拖很久 |
| 陪的人 | 就她一个 | 有人来换班，她也不走 |
| 结局 | 出院 | 出院那天俩人谁都不知该说啥 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她学会了看输液速度 | 醒来第一眼看她在不在椅子上 |
| 好的处理 | 她把家里的杯子带来了 | 他开始赶她回家睡 |
| 写崩 | 写成她啥都不要了光守着 | 写成他病恹恹等人疼 |

「她把家里的杯子带来了」是这条最好的一个动作：她不是在等他好，她是在这里过日子。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 侍疾／她亲手煎药／她住进偏房守着 |
| 修仙 | 她疗伤闭关，自己守在洞外／天天渡灵力给她 |
| 星际 | 医疗舱外放把椅子坐着等／她把办公用的东西都搬来了 |

「她把办公终端搬了过来」和「把家里的杯子带来」是同一个动作：把自己的生活挪过来。

#### 写崩的三种方式

1. 写成她抛下一切。 她把工作搬过来，比辞职更真实，也更戳人。
2. 让病人一直虚弱。 到第五天，他开始管她了。
3. 日常重建的部分别写。 这条线和急救戏的区别，全在这。

## 五 · 每天的电话

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：联系不上 19.7%

**骨架**｜通话内容不重要，重要的是通话的形状。

#### 节拍链

谁先打 → 说些没营养的 → 沉默但不挂 → 电快没了还不挂 → 「那我挂了」→「嗯」→「……你挂」

#### 时间轴

通话时长骗不了人。内容聊得再水，时长是实打实的：第一周每天二十分钟，到第三周就四十分钟还舍不得挂。「那我挂了」说完到真挂断，中间平均拖六分钟，这六分钟才是电话的正题。电量条就是倒计时，充电线够不着床的那晚，心里最难受。

#### 通话的形状

| 观察点 | 显示什么 |
|---|---|
| 谁先打 | 谁在等 |
| 打了多久 | 关系温度 |
| 说了什么 | 通常是没营养的（这是好的） |
| 谁先说挂 | 权力，或者体贴 |
| 挂之前那句 | 全条的落点 |
| 有没有沉默的部分 | 沉默还不挂，是最亲密的形态 |

「沉默还不挂」是这条最好的写法。 两个人各做各的事，电话开着，谁都不说话。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓ · 充电 ✓（电快没了还不挂）· 耳机 ✓ · 视频 ✓ |
| 背景音 | 她那边的雨 · 他这边的抽油烟机 ✓ · 电视 |
| 内容 | 今天吃了什么 · 一件很小的事讲了三分钟 |
| 挂之前 | 「那我挂了」「嗯」「……你挂」 |
| 时长记录 | 通话记录上的分钟数，一天比一天短／长 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先打 | 他 | 她（少见，但他更乐意） |
| 内容 | 话多 | 没话 |
| 频率 | 天天打 | 越打越少（得留神） |
| 视频还是语音 | 视频 | 只语音（他怕她看见自己） |

「只语音」这一端可以承载一条暗线：他不想被看见的东西，正是这一章的秘密。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他每次都提前十分钟等着 | 电话接通前那两声嘟 |
| 好的处理 | 她净说些有的没的 | 他不问她啥时候回来 |
| 写崩 | 写成她在做工作汇报 | 写成他在盯梢 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 家书／每月一封／他数着日子等驿站 |
| 修仙 | 传音玉简／每日一道 |
| 星际 | 定时通讯窗口／延迟四小时的单向留言 |

星际版的单向留言最动人：他说完要等四小时才知道她怎么答，所以他说的每句话都是对着空气说的。

#### 写崩的三种方式

1. 让通话有实质内容。 废话才是亲密。
2. 省略挂电话的过程。 那是全条的高点。
3. 不写频率变化。 频率就是关系曲线。

## 六 · 提前回来

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：开门到家 42.5%

**骨架**｜她比说好的早回来一天，且没说。

#### 节拍链

她提前订了票 → 忍住没说 → 到家 → 他不在／他在 → 那一刻

#### 时间轴

惊喜有一个精确的引爆时刻，前面全是引线。她提前一天订票，忍了二十四小时没说，每次通话都差点说漏，这段忍是前戏。开门那一秒引爆；之后的时间归他的反应，愣住那两秒，比后面所有拥抱都值钱。

#### 两种走向

| 他在不在 | 走向 |
|---|---|
| 他在，且正在做那些惯性动作 | 甜。她看见了自己不在时的家 |
| 他在，但状态很差 | 揪心。她看见了他一个人时的样子 |
| 他不在 | 她在家里等，角色对调 |
| 他不在，且家里很空 | 最疼的一版 |

「家里很空」是指他一个人时没有开火、没有开灯、外卖盒堆着。 这说明那些日常是为她做的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的隐瞒 | 憋了三天没说 · 差点说漏嘴 · 改签了机票没跟他讲 |
| 进门 | 钥匙 ✓ 拧动的声音 · 她故意轻手轻脚 |
| 她看见的 | 桌上摆着两副碗筷 ✓ · 沙发 ✓ 上的毯子 · 垃圾桶里的外卖盒 |
| 他的反应 | 愣住 · 手里的东西掉地上 · 站那儿不敢动 |
| 第一个动作 | 谁先迈步走过去 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提前 | 她 | 他（他去了她那边） |
| 隐瞒程度 | 完全没说 | 他其实猜到了（他一直在算日子） |
| 他的状态 | 好 | 不好 |
| 反应 | 扑过来 | 站着没动，然后眼睛红了 |

「站着没动，然后眼睛红了」比「扑过来」更有分量。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 开门后看见的那个家 | 听见钥匙声的那一秒 |
| 内心 | 原来他一个人是这么过的 | 是不是听岔了 |
| 好的处理 | 她先放下行李，再走过去 | 他没马上动 |
| 写崩 | 写成惊喜派对那种闹腾 | 写成他绷不住大哭 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 提前班师／她连夜赶回／不让人通报 |
| 修仙 | 提前出关／她的气息忽然出现在山门 |
| 星际 | 提前跃迁／她没申报行程 |

#### 写崩的三种方式

1. 写成生日惊喜。 这条的力度来自私密。
2. 让他毫无准备地狂喜。 那一愣要留。
3. 省略她看见的家。 那才是这条的信息。

## 七 · 重逢的第一眼

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送等候 31.8%

**骨架**｜看见的那一秒，就这一秒，是他们全族最顶的时候。

#### 节拍链

在人群里找 → 找错两次 → 认出（先认出走路的姿势）→ 身体先动 → 走过去那段路 → 第一句话很平常

#### 时间轴

只有一秒，前后各拉一条长焦。前面是人群里找人的那几十秒（认错两回，心跳一次比一次快）；认出来的那一秒，身体比脑子先动；然后是走过去的那段路，十几米，走的人觉得跟走了一辈子似的。三段速度不一样，中间那一秒最短，也最压秤。

#### 一秒里的三个阶段

| 阶段 | 内容 |
|---|---|
| 没看见 | 在人群里找，找错了两次 |
| 看见了 | 认出的那一下，身体先动 |
| 走过去 | 这段路的长度就是全部的张力 |

「找错了两次」是必须的。 直接看见就没有那一秒了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 找的动作 | 踮脚 · 手机 ✓ 举起来又放下 · 数出来的人 |
| 认出的信号 | 先认出走路的样子／背影／某件衣服 ✓ |
| 身体的反应 | 呼吸停一下 · 往前迈了一步才想起挥手 |
| 走过去的这段 | 谁走得快 · 最后几步是不是跑的 · 中间隔着啥 |
| 到面前 | 说的第一句话（一般没啥特别的） |

「说的第一句话通常很平常」是这条最好的收尾。 「你瘦了」「路上堵吗」比任何深情台词都真。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时长 | 三天 | 三年 |
| 场合 | 私下 | 大庭广众（不能抱） |
| 第一个动作 | 抱 | 只敢握手腕 ✓ |
| 第一句话 | 随口说的 | 张不开嘴 |
| 变化 | 谁都没变 | 有一个人变了（这条更难写） |

「有一方变了」是长分离的必然。重逢难在重新认识，不在激动。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 在人群里认出他的那一下 | 她还没看见我，我先看见她了 |
| 内心 | 他好像瘦了 | 我要不要现在挥手 |
| 好的处理 | 她的第一句话很平常 | 他先看见的，但他等她找到 |
| 写崩 | 写成慢镜头奔跑拥抱 | 写成他痛哭失声 |

「他等她找到」是最好的一个细节。 他早就看见她了，但他没有喊，他要让她自己找到他。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 城门／码头／她的车驾进城他在人群里 |
| 修仙 | 山门／她御剑落下的那一刻 |
| 星际 | 闸口／舷窗外她的舰体进港 |

#### 写崩的三种方式

1. 写成慢镜头。 这条的节奏是被人群打断的。
2. 第一句话太重。 越平常越好。
3. 省略找错的两次。 那两次是这条的全部铺垫。

#### 可串接

前接：[02-等待与错过 · 站台与机场](02-等待与错过.md#七--站台与机场)

## 八 · 回家之后

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：开门到家 42.5%

**骨架**｜重逢那阵热乎劲儿过了，接下来就是重新磨日子。

#### 节拍链

回来 → 说话客气了一点 → 碰到对方时有一下犹豫 → 睡觉位置错了 → 磨合几天 → 某个私人仪式自然地又出现

#### 时间轴

磨合期三到五天，进度看小动作。第一天说话还带着客气，第二天碰到对方还有半拍犹豫，第三天睡觉位置各归各位，第四五天某个私人仪式（睡前那杯水、出门前的那下拍肩）自己回来了，仪式回归的那天，磨合期就结束了，谁也没宣布。

#### 为什么要写这一条

因为重逢不是终点。分开那几年，人都会变。各自有了新习惯，聊天时总有几秒接不上话，那种生分，说不清道不明。

大部分作品写到重逢就收了。写这一段的，才是真的在写关系。

#### 可用细节

| 类 | 内容 |
|---|---|
| 生分的迹象 | 说话见外了 · 碰她的时候顿了一下 · 睡觉躺错了地方 |
| 新习惯 | 他这半年多了个毛病 · 她嘴里多了句新口头禅 |
| 磨合 | 头一顿饭做多了／做少了 · 洗澡谁先谁后乱了套 |
| 恢复的信号 | 那个只有俩人知道的仪式，又自己冒出来了（见 [07 卷第十条](07-馈赠与仪式.md#十--一个只属于他们的仪式)） |
| 时长 | 三天 · 一周 |

「私人仪式自然地又出现」是最好的恢复信号。 不需要任何人说「我们和好了」。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 生分程度 | 一晚就过去了 | 一周 |
| 谁先察觉 | 她 | 他 |
| 处理 | 直接说出来 | 各自等它过去 |
| 结果 | 完全恢复 | 有一点东西永久地变了（更真实） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她愣了一下，才想起他杯子搁哪儿了 | 她睡觉的姿势跟以前不一样了 |
| 好的处理 | 她直接说了句：「还不太习惯」 | 他没装成啥事没有 |
| 写崩 | 写成俩人立马黏糊得不行 | 写成他整天瞎琢磨怕这怕那 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 回家头几天／礼数全忘了／他拿不准要不要跪 |
| 修仙 | 一出关才发现／一个闭关几十年，外头早换了几代人 |
| 星际 | 时间对不上／她飞了两年回来，他这边已经过了八年 |

修仙与星际共享一个别处没有的资源：分离的时长对两个人是不相等的。 这让重逢后的不同步有了物理依据。

#### 写崩的三种方式

1. 跳过这一段。 这是这一族最常被省略也最有价值的一条。
2. 把生分写成误会。 它不是误会，它是时间的正常结果。
3. 让一切立刻恢复。 留一点没恢复的。

## 九 · 走的是他

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送等候 31.8%

**骨架**｜通常是她出差、她远行。这条反过来。

#### 节拍链

他拿到机会 → 她第一反应是安排 → 忍住不问「非去不可吗」→ 清单推过去 → 送走 → 她开始数日子

#### 时间轴

她的钟从送走那天开始倒数。 表面上她照常过日子，背地里日历上画着记号；每天打电话都掐着他那边的时差，她这辈子没为谁倒过时区。他哪天回来，她嘴上说「记不清了」，其实连航班号都背得出来。

#### 为什么要单独写

这一族默认的配置是她走他留，因为她才是那个有事业、有正事、被外面点名要的人。他走的那一版很少见，而且它试的根本不是同一件事——试的是她扛不扛得住什么都不知道、什么也管不着的日子。

#### 他为什么会走

| 原因 | 性质 |
|---|---|
| 他自己的事业 | 最健康，也最少被写 |
| 家里出事 | 被迫 |
| 他要去证明什么 | 与关系直接相关 |
| 他需要离开一阵 | 关系出了问题 |

第一种在语料里几乎看不到，值得专门写。他有自己的事要去做，这件事本身在这一类里就是稀缺的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的反应 | 先忙着张罗（订票、塞钱、找人帮忙）· 回头才顾上舍不得 |
| 她的克制 | 憋着没问那句「非去不可吗」 |
| 她一个人时 | 她照旧忙活的样子（对照 [三 · 她不在的第一天](#三--她不在的第一天)） |
| 他那边 | 他在那边顺不顺，她总是最后才听说 |

「第一反应是安排」是这条最准的一笔：她表达感情的方式就是解决问题。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她支不支持 | 全力支持 | 心里不情愿但没说 |
| 他去做的事 | 成功了 | 失败了，狼狈地回来 |
| 联系 | 频繁 | 他报喜不报忧 |
| 结局 | 回来 | 她过去了 |

「她过去了」这个结局在这一类里很少见，也很有力。强势方为对方改变位置，比宠溺一百次更重。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己开始掰着指头算日子 | 我得让她知道，我不光会躲在她后头 |
| 内心 | 我是不是该拦一下 | 我不能让她替我操心 |
| 好的处理 | 她没拦，但能铺的路全铺好了 | 他搞砸了，也老老实实说了 |
| 写崩 | 写成她装大方、假放手 | 写成他一赌气就玩消失 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他回本家／他要去考功名／他去从军（罕见但极有戏） |
| 修仙 | 他要自己去历练／不靠她的资源 |
| 星际 | 他申请了独立任务 |

「他去从军」在古代女尊设定里是最有张力的一版：在一个男性不该上战场的世界里，他去了。

#### 写崩的三种方式

1. 让他去的目的只是赌气。 他要有自己的事。
2. 让她全程掌控他那边的情况。 不知情才是这条的内容。
3. 让他必然成功。 狼狈地回来也是一种结局，且更真实。

## 十 · 旧地

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送等候 31.8% 衍生

**骨架**｜多年以后，有个人又回了趟那儿。

#### 节拍链

很久以后 → 一个人去 → 站一会儿 → 找变了的 → 找到一样没变的 → 什么也没做就走了

#### 时间轴

两条时间线，撞在了同一个地方。你在原地站十分钟，十年前的时间跟现在的时间叠在一起往前走。眼睛找变了的，比如店换了招牌；记忆找没变的，比如那棵树、那级台阶。然后什么也没干就走了，因为该干的事，当年已经干完了。

#### 用法

这条是全卷的收束件，用在结尾或者时间跳跃之后。它的机制是把前面所有的日常压缩进一个空间里。

| 地点 | 唤起 |
|---|---|
| 那间出租屋 | 最初的日常 |
| 那个路口 | 送别 |
| 那家店 | 一次很小的事 |
| 那张沙发 ✓ | 哭着睡着的那次 |
| 那个玄关 ✓ | 留灯的那些夜 |

前提是这些地方在前文出现过。 没铺过的旧地是没有重量的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 变化 | 店换了招牌 · 那面墙重新刷过 · 沙发换了 · 玄关的灯改成感应的了 |
| 没变的 | 一样很小的东西（门框上的划痕、墙角的一块瓷砖） |
| 谁去的 | 一个人去 · 两个人一起去 · 一个人去，另一个在等 |
| 做了什么 | 什么也没做 · 站了一会儿 · 拍了张照片 ✓ |

「门框上的划痕」（量身高留下的）是最好用的一个回收点。 见 [06-身体接触 · 量身高](06-身体接触.md#六--量身高)。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 结局 | 两人还在一起 | 已经不在一起了 |
| 谁去 | 他 | 她 |
| 变化 | 全变了 | 一样东西没变 |
| 情绪 | 暖 | 空 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现那道划痕还在 | 沙发换了，位置没换 |
| 好的处理 | 她什么都没说，拍了张照 | 他站了一会儿就走了 |
| 写崩 | 写成大段回忆闪回 | 写成他睹物思人的独白 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 旧宅／她当年住过的那间／院里的那棵树长高了 |
| 修仙 | 洞府／百年后再来，禁制还在 |
| 星际 | 那个泊位／那颗星球的那片海 |

修仙版最有力：百年后禁制还在，说明没有人来撤过。

#### 写崩的三种方式

1. 写成回忆闪回。只写现在看见的，回忆交给读者。
2. 让一切都变了。留一样没变的。
3. 在没铺垫的地方用它。旧地的重量全部来自前文。
