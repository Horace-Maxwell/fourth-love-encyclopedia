## 一 · 第一次过夜

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：同居 21.1% ＋ 洗漱 37.6%

**骨架**｜他留下了，一晚上就忙一件事，东西该放哪。

#### 节拍链

留下的决定 → 洗漱的顺序 → 穿什么睡 → 睡哪 → 熄灯 → 谁先睡着

#### 时间轴

那天晚上从洗漱到关灯，用了整整两个小时，每一步都慢。光睡衣就折腾了十分钟：他身上那件尺码明显不对，她翻出一件特大号T恤，也不知道哪儿来的，他也没问。洗漱时两个人互相让，让了五分钟。睡哪儿又商量了十分钟。关了灯才是最难熬的，两个人都没睡着，谁翻个身都听得清清楚楚。天亮以后，两个人都嘴硬，说自己睡得挺好。

#### 五个必须决定的小事

这条靠这五个决定：

| 事 | 决定权在谁 |
|---|---|
| 谁先洗澡 | 房子是她的，通常她来定 |
| 他穿什么 | 她的旧 T 恤／新买的／他自己带了 |
| 睡哪 | 床／沙发 ✓／她让开半边 |
| 灯谁关 | 谁离门近谁关 |
| 谁先睡着 | 多半是她，他翻来覆去 |

「他自己带了」这个选项值得单拿出来写。他带着换洗的东西来，可见早想过要留下。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 新拆封的牙刷 · 浴巾 ✓ · 她洗发水的味儿 · 吹风机 ✓ · 多出来的一个杯子 |
| 他的拘谨 | 洗完澡不知道站哪儿 · 头发没吹干 · 手机 ✓ 充电线 ✓ 忘带 |
| 她的自然 | 她该干嘛干嘛 · 顺手扔给他一条毛巾 ✓ |
| 那一刻 | 灯关了之后那三十秒 |
| 早上 | 谁先醒 · 早饭 · 他碗洗不洗 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 有没有发生什么 | 没有 | 有 |
| 睡哪 | 分开 | 一起 |
| 他的状态 | 紧张 | 自在得让她意外 |
| 第二天 | 他很早走了 | 他留下做了早饭 |

「什么都没发生」的写法反而好写，也经得起反复读。笔墨就花在关灯后的那三十秒上。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她翻三个抽屉给他找睡衣 | 洗完澡站在客厅中间 |
| 内心 | 我这没男人用的东西 | 我睡哪啊 |
| 好的处理 | 她直接说「睡这儿」，不解释 | 他问了句「我睡沙发？」 |
| 写崩 | 写成她早就计划好的 | 写成他处处算计 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 留宿／歇在偏房还是正房／她让人铺了床 |
| 修仙 | 他在她洞府外结庐／她开了阵法让他进来 |
| 星际 | 他的舱位权限被加进了她的舱 |

#### 写崩的三种方式

1. 直接写亲密。读者等的是关灯后的那三十秒，这段不能省。
2. 略过「东西放哪」。五个小决定都得写。
3. 写成她早有安排。这事自然发生才有味，写成安排好的最容易砸。

#### 示例（本库自撰，可直接改写）

> 他洗完澡出来，头发滴着水，站在客厅正中间。
> 她从卧室扔了条毛巾过来，砸在他脸上。
> 「睡这儿。」她指了指里屋，「沙发太短，你腿放不下。」
> 他「哦」了一声，没动。
> 她翻了三个抽屉才找出一件宽松的旧 T 恤——她这儿从来没有过男人的东西。
> 灯关掉之后有三十秒，两个人都没说话。
> 然后她说：「你头发没吹干。」

## 二 · 搬进来

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：同居 21.1%（同居＋归家、同居＋节日高频同现）

**骨架**｜他搬进来了，带多少东西、放在哪儿，两个人一样一样商量。

#### 节拍链

谁提的 → 打包 → 他带来的东西 → 那件难看的 → 她挪出半个柜子 → 混放成形 → 快递地址改了

#### 时间轴

纸箱当天就能拆完，可这还不算。头一周，他的东西还堆在「他那块地儿」，第二周开始往外漫，第三周她把柜子腾出半格，到第四周，牙刷、充电线、拖鞋已经混着用了。搬家一天搬得完，东西混到一块儿得一个月。快递地址改过来的那天，才算真住到一起。

#### 搬家的三个阶段

| 阶段 | 表现 | 关系 |
|---|---|---|
| 一 | 他有一把牙刷在这儿 | 客人 |
| 二 | 他有一个抽屉 | 常客 |
| 三 | 他的东西没有专属位置，混在她的东西里 | 住在一起 |

**到第三阶段才算真同居**，可从二到三的那一步，常常被略过不写。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他带来的 | 少得让她意外 · 或者多得得收拾 |
| 冲突点 | 他那旧沙发要不要 · 他妈给的一套碗 · 一件她觉得丑的东西 |
| 她的让步 | 那件丑的，她留下了 |
| 空间重排 | 她腾出半个衣柜 · 她的东西头一回被人挪动 |
| 落点 | 她把自己东西挪开的那一下 |

「她把自己东西挪开的那一下」得写。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提的 | 她 | 他（他会先试探） |
| 住谁的房子 | 她的 | 他的（罕见，值得写） |
| 他带的东西 | 很少 | 很多 |
| 冲突 | 无 | 一件东西的去留 |

住他房子的写法少见，效果却好：她住进的是他的地盘，屋里谁占哪个位置，全得重新排一遍。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她腾柜子时手顿了一下 | 我带的东西是不是太多了 |
| 内心 | 这屋子我一人住了六年 | 这不是我的家 |
| 好的处理 | 她主动说「你东西放这儿就行」 | 他没把自己缩成一小团 |
| 写崩 | 写成她理所当然地让地方 | 写成他觉得自己是外人 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 抬进府／住哪个院／他的箱笼有几担 |
| 修仙 | 入洞府／她给他一间静室／他的法器摆在何处 |
| 星际 | 舱位合并／权限重新分配 |

#### 写崩的三种方式

1. 一步到位。三个阶段要分得清，让人一眼看得出来。
2. 让她二话不说就腾出地方。她住了六年的屋子，说让就让，不可能没感觉。
3. 把那件难看的东西处理掉。留下它，才算真的接纳。

## 三 · 家务的分配

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：同居 21.1% ＋ 做饭 48.4%

**骨架**｜谁干啥，就是这个家的规矩，不光是家务怎么分的事。

#### 节拍链

分工自然成形 → 隐形劳动浮现 → 一次爆发或一次说开 → 她坚持做一件 → 各自领域确认 → 成为长期制度

#### 时间轴

规矩是一个月一个月慢慢定下来的。头两个月，谁顺手谁干。到第三个月，那些「没人做过但一直有人做」的事才冒出来：买米、交费、张罗过年过节。吵起来只要一晚上，两个人就在那晚谈开，谈了两个小时。之后定下的分工能一直用好几年，靠的是每个季度小吵一回，顺手调一调。

#### 三种分配模型

| 模型 | 说法 | 隐患 |
|---|---|---|
| 他全包 | 「他喜欢做」 | 容易滑成保姆 |
| 按能力分 | 「他会做饭她会修东西」 | 最健康 |
| 按时间分 | 「谁在家谁做」 | 最现实 |
| 请人 | 「都忙」 | 回避了问题 |

「他全包」在语料里很常见，也最得想办法补救。办法是给她留一件事：她做不好，可偏要自己做。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的领域 | 厨房（灶 ✓、油烟 ✓、砂锅 ✓）· 洗衣 · 收纳 |
| 她的领域 | 修东西 · 换灯泡 · 交涉（物业、快递、维修） |
| 摩擦点 | 他嫌她乱放东西 · 她嫌他收得太整齐找不到 |
| 她坚持做的那件 | 做得不好，但她要做 |
| 隐形劳动 | 谁记得该买什么 · 谁记得交费 · 这一项通常没人算 |

记着家里啥时候该买米、水电费哪天交、谁的生日快到了，这些都不算在家务里，偏偏最耗人。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 分配 | 他多 | 平均 |
| 她的参与 | 完全不管 | 坚持做一件 |
| 摩擦 | 无 | 一次爆发 |
| 隐形劳动 | 他承担 | 她承担 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现家里从来不缺吃的 | 她今天问我洗衣液搁哪儿了 |
| 内心 | 这些事我压根没管过 | 我做这些不是因为我欠她的 |
| 好的处理 | 她开始学着记事儿 | 他把自己那点委屈说出口了 |
| 写崩 | 写成她啥活都不碰 | 写成他闷头干、一句怨言没有 |

「他把自己那点委屈说出口了」这一步不能少。一句怨言都没有的人，读者不会信。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 内宅由他掌／对牌与钥匙 ✓ 在谁手上／她管外他管内 |
| 修仙 | 洞府洒扫／灵植照料／她修行他打理 |
| 星际 | 舱内维护值班表 |

古代版里，「对牌与钥匙」在谁手上，谁就管着这个家，活儿用不着自己动手干。

#### 写崩的三种方式

1. 让他一句怨言没有。至少不平一回。
2. 忽略隐形劳动。 这个要写。
3. 让她啥都不管。给她一件做不好还坚持做的事，这角色就活了。

## 四 · 洗澡之后

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：洗漱 37.6%（洗漱＋睡着、洗漱＋留痕高频同现）

**骨架**｜水声停后那几分钟，家里最松快。

#### 节拍链

水声停 → 吹风机响 → 湿发与雾气 → 最松弛的时段 → 一段没防备的对话 → 收在睡前

#### 时间轴

水声停了到吹风机响起来，中间大概有五分钟，家里这时候最放松：热气还没散，头发湿着，拖鞋随便趿着。不少没防备的话，就是在吹风机一阵一阵响的空当里说出来的。风停了，漏出一句，风又响了，正好盖过去，谁也不用接话。这场戏的节奏不用看表，数吹风机开关了几回就行。开三回停三回，就够说完一段平时打死也说不出口的话。

#### 为什么这条高频

洗漱占 37.6%，在情境族里排进前二十。它本身就占齐了三样：时间明确，地方私密，两个人都卸了装备。

#### 可用细节

| 类 | 内容 |
|---|---|
| 声音 | 水声停了 · 吹风机 ✓ 响 · 关掉之后耳朵里嗡嗡的安静 |
| 道具 | 浴巾 ✓ · 头发还滴着水 · 水汽 · 镜子 ✓ · 拖鞋踩出的湿印子 |
| 谁给谁 | 吹头发（见 [01 卷第八条](01-日常照料.md#八--洗头与吹头发)）· 递睡衣 · 涂药 ✓ |
| 状态差 | 她洗完放松，他洗完紧绷，因为他在别人家 |
| 对话 | 这时候说话，最容易掏心窝子 |

这会儿说话最没防备。要写一场坦白、一句实话或者一个请求，放在这时候最顺。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁洗完 | 他 | 她 |
| 状态 | 放松 | 有事没说 |
| 发生什么 | 一段对话 | 什么都没有 |
| 收尾 | 睡觉 | 一个动作 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他头发还在滴水 | 她洗完出来的样儿 |
| 好的处理 | 她顺手把毛巾丢过去 | 他自己去把头发吹了 |
| 写崩 | 写成擦边戏 | 写成他偷看 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 沐浴后／散着发／他捧巾伺候／她自己挽发 |
| 修仙 | 以灵力烘干／他替她束发 |
| 星际 | 舰上限水／共用一次配额 |

#### 写崩的三种方式

1. 写成擦边。这场戏要的是松弛。
2. 不写声音。水声停、吹风机停，这两下就是整场戏的节拍。
3. 往里塞对话。这段空当是留给读者自己去想的，塞进话去反倒堵住了。

## 五 · 他喝多了

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：醉酒 32.1%（醉酒＋归家、醉酒＋留痕高频同现）

**骨架**｜他喝多了，把平时不说的话说了出来。

#### 节拍链

电话来或被送回 → 进门 → 她处理（灌水·浴室·守着）→ 他说了那句 → 睡去 → 第二天记不记得 → 她提不提

#### 时间轴

从进门算起，前后九十分钟。头半小时是灌水、擦脸、扒外套，他乖得像件大行李。到第六十分钟上下，真话冒了出来，夹在一堆胡话里，挑出来就剩「那句」。第二天醒来，他记不记得，装不装不记得，她提还是不提，这三件事在早饭桌上十分钟就定了，谁也没说破。

#### 醉酒为什么好用

清醒时他不会说的话、不会做的事，喝醉了都能说能做。**第二天还可以不认账。**

有了「可以不认」，两个人都留着退路。

#### 醉的三个层次

| 层 | 表现 | 能用来做什么 |
|---|---|---|
| 微醺 | 话多了、笑点低 | 他会说平时不说的实话 |
| 醉 | 走不稳、黏人 | 他会做平时不做的动作 |
| 断片 | 完全失控 | 他会说出那件事，且第二天不记得 |

**第三层要小心用。** 断了片说出来的事，第二天很难收拾。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 一身酒气 ✓ · 醒酒汤 ✓ · 他外套 ✓ 甩在门口 · 鞋也没脱 |
| 她的处理 | 扶 · 喂水 · 拖进浴室 · 半夜爬起来看他吐没吐 |
| 他的表现 | 话特别多 · 或者一声不吭光攥着她 |
| 他说的话 | 一句平时打死也不会说的 |
| 第二天 | 他装不装傻 · 她提不提这茬 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁醉 | 他 | 她（少见，且极有戏） |
| 醉的原因 | 应酬 | 心里有事 |
| 他说了什么 | 撒娇的话 | 一句实话 |
| 第二天 | 真不记得 | 记得，装不记得 |

「她喝醉」这一版值得单独写。她卸下防备是什么样子，多半是他头一个看到。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他拽着她袖子不撒手那一下 | 第二天醒来脑子发空 |
| 内心 | 他说的是不是真心话 | 我昨晚到底说了啥 |
| 好的处理 | 她记下了，但第二天没提 | 他没借着酒劲装疯 |
| 写崩 | 写成借着酒劲占便宜 | 写成他酒后撒泼 |

不能借酒装疯。醉了也得认账。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 宴上被灌／她命人抬回／醒酒汤 |
| 修仙 | 灵酒／他修为压不住酒气 |
| 星际 | 舰上的合成酒／他违规喝了 |

#### 写崩的三种方式

1. 靠醉酒推进亲密。借醉就是躲责任。
2. 让他撒酒疯。醉要可爱或者可怜，别难看。
3. 第二天整个略掉。他到底记不记得，这个要写。

## 六 · 她的生理期

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：生理期 10.8%

**骨架**｜她疼得说不出话。可这事赌的，就是他还记不记得。

#### 节拍链

她硬撑，他看出来了，不问，只管做：屋里调暖，药备好，日程往后挪。她不想被当病人，最后还是受了。后来她才知道，日子他一直记着。

#### 时间轴

那天晚上本来有安排，她撑到下午，实在扛不住了。他什么也没说，把暖贴和热水放好。他手机里有个提醒，她不知道，已经记了大半年。下午三点，他悄悄把日程往后推了。后来她翻到那条日历，盯着看了十秒，一句话没说。她是一个小时一个小时撑着，他是一个月一个月备着。

#### 为什么这条在 GB 里特殊

生理期由不得她。她凡事都要攥在自己手里，这几天却只能老实待着，让人照顾。

他怎么照顾她，就看得出他平时多上心：

| 他做的 | 说明 |
|---|---|
| 递红糖水 | 最基础，也最敷衍 |
| 提前买好了她用的那个牌子 | 他记得 |
| 把暖宝宝提前热好 | 他知道她的时间 |
| 什么都不说地把工作日程往后推了 | 他管到了她的事业 |
| 不提这件事，只是把家里调暖了两度 | 最好 |

最后一行写得最好，它没拿她当病人看。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的状态 | 脸色差 · 话少 · 蜷着 · 不肯说自己难受 |
| 他的准备 | 家里常备的那一格 · 他记的日子 |
| 她的抗拒 | 「我没事」· 她烦别人拿她当病人 |
| 分寸 | 他不问，光做 |
| 落点 | 她后来才发现他一直记着 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的态度 | 你照顾就照顾吧 | 别把我当病人 |
| 他的做法 | 明着来 | 偷偷做 |
| 她知不知道他记着 | 没察觉 | 后来翻到了 |
| 场合 | 家里 | 单位（她得端着） |

她在单位得端着，今天在硬撑，全公司只有他知道。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现家里的暖气早就开了 | 她今天第三次揉腰 |
| 内心 | 我不想被人看扁 | 别问，问了她又要硬撑 |
| 好的处理 | 她领了这份好，没多说什么 | 他不吭声，该干嘛干嘛 |
| 写崩 | 把她写成娇滴滴的 | 把他写成咋咋呼呼的 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他备下姜汤／换了软垫／替她告了假 |
| 修仙 | 她修为不稳／他守着闭关 |
| 星际 | 抑制剂／他偷偷改了她的体检数据 |
| 女A男O | 反着来：**他发情／他易感**，详见 [21 卷](21-世界设定专属.md) |

女A男O 反过来写，换的只是谁在受罪。身体不由自己的变成了他，照顾的那几个动作一个不少，只是倒了过来。

#### 写崩的三种方式

1. 把她写得娇弱。她疼，可她不弱。
2. 大惊小怪。 不问只做才对。
3. 只写一杯红糖水。这是最敷衍的写法。

## 七 · 第一次

`M` ｜ ⚠️亲密接触 ｜ 全谱系 ｜ 语料频次：留痕 46.0% ＋ 洗漱 37.6%

**骨架**｜这条只写结构和关系的变化，不写具体过程。

#### 节拍链

之前的默契累积 → 发生（过程不在本条）→ 第二天早上 → 两个人都醒着装睡 → 第一句话很平常 → 物件悄悄换了位置

#### 时间轴

前面早有铺垫：眼神多停几秒，告别一次比一次拖得长，默契是一周一周攒起来的。中间那段不写，只写前后。第二天早上要一分钟一分钟地写。两个人都醒了，装睡装了二十分钟，谁先装作「醒」过来，第一句话有多平常，都在这二十分钟里。越平常越好。一周之内，牙刷、枕头、某件衣服悄悄挪了地方，也换了主人。

#### 本条的边界

场景具体怎么写，去看 [06-尺度与写法/03-情欲场景结构](../06-尺度与写法/03-情欲场景结构.md)，分级镜头怎么控制，那一卷都讲到了。

这里只看一件事：这场戏前后，关系变了什么。

#### 前后对照表

| 项 | 之前 | 之后 |
|---|---|---|
| 谁发起 | 试探 | 已确立 |
| 称呼 | 可能还没改 | 通常这之后改 |
| 空间 | 他的东西在客房 | 挪进主卧 |
| 第二天早上 | — | 要写的是这个 |

#### 第二天早上，四种写法

| 写法 | 关系含义 |
|---|---|
| 她先醒，看了他一会儿 | 她想确认这事真发生了 |
| 他先醒，不敢动 | 他拿不准自己该不该留下 |
| 两个人都醒着装睡 | 最好 |
| 她已经去上班了，留了字条 | 她打算这么处理 |

「两个人都醒着装睡」，因为谁都不想先开口，给刚才的事下个定义。

#### 可用细节

| 类 | 内容 |
|---|---|
| 之后的物件 | 多出来的一支牙刷 · 被挪动的枕头 ✓ · 他的衬衫 ✓ 在椅背上 |
| 身体的痕迹 | 见 [05-占有与吃醋 · 留痕](05-占有与吃醋.md#四--留痕) |
| 第一句话 | 越平常越好（「几点了」） |
| 变化的信号 | 他洗漱时用了她的杯子，没问一声 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先醒 | 她 | 他 |
| 说不说破 | 都装睡到闹钟响 | 她先开了口 |
| 之后几天 | 自然过渡 | 尴尬了两天才顺 |
| 物证 | 牙刷进了杯架 | 他的衬衫上了她的衣架 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她先醒，看了他一会儿 | 他醒着，不敢动 |
| 内心 | 就这样吧，挺好 | 我现在起来算不算逃 |
| 好的处理 | 她开口先问「几点了」 | 他没问「我们算什么」 |
| 写崩 | 写成她大清早盘算得失 | 写成他翻来覆去瞎琢磨一整章 |

#### 安全与边界

| 线 | 说明 |
|---|---|
| 全员成年 | 所有涉及亲密情节的角色都得是成年人 |
| 知情同意 | 双方都愿意，中途想停随时能停 |
| 不写可复现细节 | 本卷只聊关系怎么搭，不写具体过程 |
| 分级 | 真写到具体镜头，按 [06-尺度与写法](../06-尺度与写法/) 的分级来控 |

#### 换皮

换个世界，结构照搬，过程在哪儿都不写：

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 合卺次日早上请安迟了半刻，全府都心里有数。她说了句「往后他辰时起」，从此就成了规矩 |

#### 写崩的三种方式

1. 让这场戏把关系里的问题一口气写完。到了现实里，那些矛盾一个也没解决。
2. 把第二天早上略过去。那个早上得写。
3. 让两人谁说了算在这场戏里颠倒过来。床上谁压谁，和过日子谁拿主意，是两回事。

## 八 · 之后的日常

`M` ｜ ⚠️亲密接触 ｜ 全谱系 ｜ 语料频次：留痕 46.0%

**骨架**｜次数多了，亲密成了两个人说别的话的一种办法。

#### 节拍链

从事件变成语言 → 频率成形 → 一次被拒 → 他分辨（是累还是不想）→ 说开 → 频率变化被当体温计读

#### 时间轴

要看的是频率。过了刚开始那段，节奏自己就有了：忙的时候少，和好以后多，心里有事就乱。有一回被拒，他用了三天才弄清「是累还是不想」，先看，再试，最后干脆直接问。说开以后，这事就一直往下过，没有个头。

#### 从事件到语言

| 阶段 | 性质 |
|---|---|
| 第一次 | 事件。要专门写 |
| 前几次 | 还是事件 |
| 之后 | 语言。用来说别的事 |

之后用来说别的事：

| 用法 | 说的是什么 |
|---|---|
| 累了一天，只是抱着睡 | 陪着你 |
| 吵完架之后 | 和好 |
| 她主动 | 她今天心情不好 |
| 他被拒绝 | 她真的很累（他得看得出来） |
| 中途停下来说了句正事 | 这俩人已经过成日子了 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 频率的变化 | 忙起来之后 · 吵架之后 · 光这个变，就有戏 |
| 分辨的能力 | 他分不分得清「今天不行」和「不想」 |
| 被拒绝时 | 他啥反应，这人啥样就露出来了 |
| 日常化的标志 | 正聊着，有人接了个工作电话 |

分得清的人，和把每次拒绝都当成信号的人，写出来是两种角色。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 主动方 | 她为主 | 双向 |
| 被拒绝时 | 他接受 | 他不安 |
| 频率变化 | 稳定 | 明显下降（是信号，要处理） |
| 沟通 | 说得出口 | 都不说 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她说「今天太累了」之后他啥反应 | 她俩礼拜没主动找他了 |
| 好的处理 | 她明说就是累，没别的意思 | 他开口问了，问得挺自然 |
| 写崩 | 写她拿亲热当赏钱或罚钱 | 写他记着次数，伸手要账 |

别拿亲密当奖赏或惩罚。这么一写，关系就成了交易，再要写回来很难。

#### 安全与边界

同第七条：全员成年、知情同意、随时能喊停，不写具体过程。谁说了停就得马上停，这一点在文里得让读者看得见。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 侍寝排在哪天，全府上下都有数。她索性把排班废了，想见就见，府里人说这比改祖制还稀罕 |
| 修仙 | 双修从必修的功课成了家常便饭，两人修为涨得快还是慢，同门拿来开玩笑，他俩从不接茬 |
| 星际 | 舱里的温度、灯光，两人的偏好慢慢合成了一套。系统摸清了两人的作息，某天弹出一条「已生成双人模式」 |

#### 写崩的三种方式

1. 用亲密做奖惩。 见上。
2. 让他把每次被拒都当成出了大事。能分清楚，说明他是个大人。
3. 不管频率的变化。频率一变，就是有事。

## 九 · 两个人的作息

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：同居 21.1% ＋ 夜深 37.5%

**骨架**｜她十一点睡，他两点睡，光这一件事就能磨上一辈子。

#### 节拍链

差异暴露 → 蹑手蹑脚期 → 妥协的物证（耳机·震动闹钟）→ 一次爆发 → 谈 → 分房或磨合 → 新常态

#### 时间轴

前后折腾了半年，最后的办法很简单：他十二点先上床，等她睡熟了再起来。为了这个，前几个月家里鸡飞狗跳。头一个月他进卧室都蹑手蹑脚，关门练到没声音。从第二个月起，耳机、震动闹钟、遮光帘，一个月添一样。第四个月的一个周二凌晨，她第三次被吵醒，当场炸了。当晚两人谈开，第二天试着分房，撑了一个礼拜，两个人都睡不踏实，还是不行。绕了这么大一圈，全是为了十一点到凌晨两点这三个小时。

#### 作息差是同居的第一大摩擦

比家务常见，比钱的事琐碎，还分不出对错。

| 差异 | 后果 |
|---|---|
| 睡觉时间 | 一个被吵醒，一个不敢动 |
| 起床时间 | 早起的那个每天蹑手蹑脚 |
| 吃饭时间 | 一个等一个 |
| 加班规律 | 见 [02-等待与错过](02-等待与错过.md) |
| 周末怎么过 | 一个要出门，一个要睡觉 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 妥协的痕迹 | 他买了降噪耳机 ✓ · 她把闹钟 ✓ 调成震动 · 客厅的小夜灯 |
| 磨合失败的痕迹 | 有人开始睡沙发 ✓ · 有人开始在客厅待到很晚 |
| 隐忍 | 一个人躺着装睡，等另一个人进来 |
| 崩点 | 某天有人说了「你能不能……」 |
| 解决 | 分房睡是因为作息合不来，感情没出问题 · 这点得写明 |

分房睡和关系出问题是两码事，值得单独写清楚。语料里常把这两件事混在一起。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁迁就谁 | 他迁就她 | 各自保留 |
| 结果 | 磨合成了 | 分房，且两人都很好 |
| 摩擦 | 小 | 爆发过一次 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她半夜醒来，发现他还没睡 | 她翻身的时候，我就不敢动 |
| 好的处理 | 她提出分房睡，也把原因讲清楚了 | 他没把这事当成她不爱他 |
| 写崩 | 写成她不懂事 | 写成他硬扛了一年没吭声 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她要早朝／他守夜／各院分住是常态 |
| 修仙 | 她闭关他不闭／打坐时间错开 |
| 星际 | 值班表／三班倒 |

古代女尊里分房本来就是定例，所以「同寝」反倒成了特殊待遇。现代版没有这个便利。

#### 写崩的三种方式

1. 把分房写成感情危机。它可能就是作息不合。
2. 让一方一直迁就。怨气会越攒越多。
3. 不写让步留下的东西。降噪耳机、震动闹钟，都是这段关系的证据。

| 各自的保留 | 她死活不扔的 · 他舍不得丢的 |
| 融合的部分 | 一件俩人都忘了谁买的玩意 |
| 外人视角 | 来个人就说「你们家待着真舒服」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 融合程度 | 高（分不清谁的） | 各自分明 |
| 时间 | 一年 | 十年 |
| 用途 | 甜的收尾 | 分手后的对照，同一段描写全部反过来 |

最后一行的用法：分开以后，把同一份清单原样再写一遍，每一项都空了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她忽然想不起沙发是打哪儿来的 | 这儿是我住得最久的一个地儿 |
| 好的处理 | 她发觉有件小事跟以前不一样了 | 他说不清这屋哪儿算他的，可处处都是 |
| 写崩 | 把温馨小家写成物件清单 | 写成了他终于有家的那种煽情戏 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 院子里的树长高了／他添的那几样东西一直没动过 |
| 修仙 | 洞府里多了几件凡间的东西／她开始留一盏灯不灭 |
| 星际 | 舱里多了些地球来的物件／私人物品配额全用完了 |

#### 写崩的三种方式

1. 写成清单堆砌。 挑三样。
2. 大段抒情。 物件自己会说。
3. 只拿来写甜。反过来用一回，劲更大。
