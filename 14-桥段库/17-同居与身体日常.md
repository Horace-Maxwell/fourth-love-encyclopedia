## 一 · 第一次过夜

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：同居 20.0% ＋ 洗漱 37.0%

**骨架**｜他留下来了，一晚上就忙一件事，东西该放哪。

#### 节拍链

留下的决定 → 洗漱的顺序 → 穿什么睡 → 睡哪 → 熄灯 → 谁先睡着

#### 时间轴

那晚从洗漱到熄灯，整整两个小时像被拖成了慢镜头。睡衣折腾了十分钟，他穿的那件尺码明显不对，她翻出一件特大号T恤，也不知从哪儿来的，他也没多问。洗漱时互相让了五分钟，睡哪儿又商量了半天，又耗掉十分钟。灯一灭，真正的煎熬才刚开始，俩人都醒着，连翻身都听得一清二楚。谁先睡着谁就输了，可最后谁也没赢——天亮时，两人都硬撑着说自己睡得挺好。

#### 五个必须决定的小事

这条不靠情节，靠这五个决定：

| 事 | 决定权在谁 |
|---|---|
| 谁先洗澡 | 一般她说了算，房子是她的 |
| 他穿什么 | 她的旧 T 恤／新买的／他自己带了 |
| 睡哪 | 床／沙发 ✓／她让开半边 |
| 灯谁关 | 谁离门近谁关 |
| 谁先睡着 | 多半是她，他翻来覆去 |

「他自己带了」这个选项值得单独用。 他带了换洗的东西过来，说明他早就想过会留下。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 新拆封的牙刷 · 浴巾 ✓ · 她洗发水的味儿 · 吹风机 ✓ · 多出来的一个杯子 |
| 他的拘谨 | 洗完澡不知道站哪儿 · 头发没吹干 · 手机 ✓ 充电线 ✓ 忘带 |
| 她的自然 | 她该干嘛干嘛 · 顺手扔给他一条毛巾 ✓ |
| 那一刻 | 灯关了之后那三十秒 |
| 早上 | 谁先醒 · 早饭 · 他碗洗不洗 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 有没有发生什么 | 没有 | 有 |
| 睡哪 | 分开 | 一起 |
| 他的状态 | 紧张 | 自在得让她意外 |
| 第二天 | 他很早走了 | 他留下做了早饭 |

「什么都没发生」这一版更好写也更耐读。 张力全在那三十秒里。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她翻三个抽屉给他找睡衣 | 洗完澡站在客厅中间 |
| 内心 | 我这没男人用的东西 | 我睡哪啊 |
| 好的处理 | 她直接说「睡这儿」，不解释 | 他问了句「我睡沙发？」 |
| 写崩 | 写成她早就计划好的 | 写成他处处算计 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 留宿／歇在偏房还是正房／她让人铺了床 |
| 修仙 | 他在她洞府外结庐／她开了阵法让他进来 |
| 星际 | 他的舱位权限被加进了她的舱 |

#### 写崩的三种方式

1. 别铺垫，读者要的就是那三十秒，直接进入亲密。
2. 别啰嗦，五个小决定就是全部内容，把「东西放哪」这种细节省掉。
3. 这招最容易翻车，写成她的刻意安排，自然发生才有味道。

#### 示例（本库自撰，可直接改写）

> 他洗完澡出来，头发滴着水，站在客厅正中间。
> 她从卧室扔了条毛巾过来，砸在他脸上。
> 「睡这儿。」她指了指里屋，「沙发太短，你腿放不下。」
> 他「哦」了一声，没动。
> 她翻了三个抽屉才找出一件宽松的旧 T 恤——她这儿从来没有过男人的东西。
> 灯关掉之后有三十秒，两个人都没说话。
> 然后她说：「你头发没吹干。」

## 二 · 搬进来

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：同居 20.0%（同居＋归家、同居＋节日高频同现）

**骨架**｜他的东西搬进来了，放多少、搁哪儿，都是商量着来的。

#### 节拍链

谁提的 → 打包 → 他带来的东西 → 那件难看的 → 她挪出半个柜子 → 混放成形 → 快递地址改了

#### 时间轴

纸箱当天拆完不算数。他东西头一周还堆在「他那块地儿」，第二周开始往外漫，第三周她柜子腾出半格，第四周牙刷、充电线、拖鞋全混着用了。搬家当天能搬完，但磁场要磨合一个月。快递地址改过来那天，才算真住一块儿了——「收货人」那俩字，比钥匙还管用。

#### 搬家的三个阶段

| 阶段 | 表现 | 关系 |
|---|---|---|
| 一 | 他有一把牙刷在这儿 | 客人 |
| 二 | 他有一个抽屉 | 常客 |
| 三 | 他的东西没有专属位置，混在她的东西里 | 住在一起 |

**第三阶段才是真的同居**，而从二到三的那一步往往没有被写出来。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他带来的 | 少得让她意外 · 或者多得得收拾 |
| 冲突点 | 他那旧沙发要不要 · 他妈给的一套碗 · 一件她觉得丑的东西 |
| 她的让步 | 那件丑的，她留下了 |
| 空间重排 | 她腾出半个衣柜 · 她的东西头一回被人挪动 |
| 落点 | 她把自己东西挪开的那一下 |

「她把自己的东西挪开」是这条的核心动作。她让出的是习惯，不只是空间。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提的 | 她 | 他（他会先试探） |
| 住谁的房子 | 她的 | 他的（罕见，值得写） |
| 他带的东西 | 很少 | 很多 |
| 冲突 | 无 | 一件东西的去留 |

**「住他的房子」这一版少见且有效：** 她进入他的领地，全部的位置关系被重新洗一遍。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她腾柜子时手顿了一下 | 我带的东西是不是太多了 |
| 内心 | 这屋子我一人住了六年 | 这不是我的家 |
| 好的处理 | 她主动说「你东西放这儿就行」 | 他没把自己缩成一小团 |
| 写崩 | 写成她理所当然地让地方 | 写成他觉得自己是外人 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 抬进府／住哪个院／他的箱笼有几担 |
| 修仙 | 入洞府／她给他一间静室／他的法器摆在何处 |
| 星际 | 舱位合并／权限重新分配 |

#### 写崩的三种方式

1. 住了六年的屋子，说让就让，不可能没感觉，那就让她痛痛快快把地方腾出来。
2. 三个阶段得让人一眼就看明白，一步到位。
3. 别去管那件难看的东西，留着它，才算真接纳。

## 三 · 家务的分配

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：同居 20.0% ＋ 做饭 49.0%

**骨架**｜谁干啥，是这段关系里明码标价的规矩，不光是活儿咋分的事。

#### 节拍链

分工自然成形 → 隐形劳动浮现 → 一次爆发或一次说开 → 她坚持做一件 → 各自领域确认 → 成为长期制度

#### 时间轴

谈判发生在那晚，持续了两个小时。前两个月分工自然沉降，谁顺手谁就做了。到第三个月，「没人做过但一直有人做」的事才浮出来，比如买米、缴费、安排年节。之后的制度能稳定运行好几年，靠的是每季度吵一次小架来微调，这属于正常损耗。制度的成形按月算，爆发只需要一晚。

#### 三种分配模型

| 模型 | 说法 | 隐患 |
|---|---|---|
| 他全包 | 「他喜欢做」 | 容易滑成保姆 |
| 按能力分 | 「他会做饭她会修东西」 | 最健康 |
| 按时间分 | 「谁在家谁做」 | 最现实 |
| 请人 | 「都忙」 | 回避了问题 |

「他全包」是语料里的高频配置，也是最需要处理的一个。 处理方法：让她做一件她做得不好但坚持要做的事。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的领域 | 厨房（灶 ✓、油烟 ✓、砂锅 ✓）· 洗衣 · 收纳 |
| 她的领域 | 修东西 · 换灯泡 · 交涉（物业、快递、维修） |
| 摩擦点 | 他嫌她乱放东西 · 她嫌他收得太整齐找不到 |
| 她坚持做的那件 | 做得不好，但她要做 |
| 隐形劳动 | 谁记得该买什么 · 谁记得交费 · 这一项通常没人算 |

「隐形劳动」这个点，是这条里最值得写的东西。你想想，记着家里啥时候没米了、水电费哪天交、谁生日快到了——这些不算家务活，可它们最磨人。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 分配 | 他多 | 平均 |
| 她的参与 | 完全不管 | 坚持做一件 |
| 摩擦 | 无 | 一次爆发 |
| 隐形劳动 | 他承担 | 她承担 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现家里从来不缺吃的 | 她今天问我洗衣液搁哪儿了 |
| 内心 | 这些事我压根没管过 | 我做这些不是因为我欠她的 |
| 好的处理 | 她开始学着记事儿 | 他把自己那点委屈说出口了 |
| 写崩 | 写成她啥活都不碰 | 写成他闷头干、一句怨言没有 |

「他说出了自己的不平」是这条必须有的一场。 全程无怨言的家务承担者，是设定不是人物。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 内宅由他掌／对牌与钥匙 ✓ 在谁手上／她管外他管内 |
| 修仙 | 洞府洒扫／灵植照料／她修行他打理 |
| 星际 | 舱内维护值班表 |

**古代版的「对牌与钥匙」是这条换皮的顶格**：管家管的是权，不是活。

#### 写崩的三种方式

1. 让他毫无怨言。至少一次不平。
2. 忽略隐形劳动。这条的深层是这个。
3. 让她完全不参与。一件做不好但坚持的事，能救这个角色。

## 四 · 洗澡之后

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：洗漱 37.0%（洗漱＋睡着、洗漱＋留痕高频同现）

**骨架**｜水声停了。那几分钟，这家里头最松快。

#### 节拍链

水声停 → 吹风机响 → 湿发与雾气 → 最松弛的时段 → 一段没防备的对话 → 收在睡前

#### 时间轴

水声停了，吹风机响起来，中间隔了大概五分钟。这五分钟里的家是最放松的：热气没散，头发还是湿的，拖鞋随便趿着。很多没防备的话，就是趁吹风机断断续续的时候说出来的。风一停，话就漏出一句，风再响，话题正好被盖过去，谁也不用接。这段戏的节奏不用掐表，数吹风机开关就行——开三次关三次，够塞进一段平时打死都说不出口的话。

#### 为什么这条高频

洗漱 37% 在情境族里排第五。原因是它天然满足三件事：时间明确、空间私密、双方都卸了装备。

#### 可用细节

| 类 | 内容 |
|---|---|
| 声音 | 水声停了 · 吹风机 ✓ 响 · 关掉之后耳朵里嗡嗡的安静 |
| 道具 | 浴巾 ✓ · 头发还滴着水 · 水汽 · 镜子 ✓ · 拖鞋踩出的湿印子 |
| 谁给谁 | 吹头发（见 [01 卷第八条](01-日常照料.md#八--洗头与吹头发)）· 递睡衣 · 涂药 ✓ |
| 状态差 | 她洗完是放松，他洗完是紧绷，因为他在别人家 |
| 对话 | 这时候说话，最容易掏心窝子 |

**「这个时段的对话最没有防备」是这条的功能：** 需要一场坦白、一句实话、一个请求，放在这里最自然。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁洗完 | 他 | 她 |
| 状态 | 放松 | 有事没说 |
| 发生什么 | 一段对话 | 什么都没有 |
| 收尾 | 睡觉 | 一个动作 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他头发还在滴水 | 她洗完出来的样儿 |
| 好的处理 | 她顺手把毛巾丢过去 | 他自己去把头发吹了 |
| 写崩 | 写成擦边戏 | 写成他偷看 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 沐浴后／散着发／他捧巾伺候／她自己挽发 |
| 修仙 | 以灵力烘干／他替她束发 |
| 星际 | 舰上限水／共用一次配额 |

#### 写崩的三种方式

1. 写成擦边。 这条要的是松弛感，不是露多少肉。
2. 忽略声音。 水声停了，吹风机停了，这两个点就是这条的节奏。
3. 别放对话进去。 这个空档，是留给读者自己脑补的，塞了话反而堵。

## 五 · 他喝多了

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：醉酒 31.0%（醉酒＋归家、醉酒＋留痕高频同现）

**骨架**｜他喝多了。喝醉，是这个题材里最合理的卸防方式。

#### 节拍链

电话来或被送回 → 进门 → 她处理（灌水·浴室·守着）→ 他说了那句 → 睡去 → 第二天记不记得 → 她提不提

#### 时间轴

第二天睁眼，账从昨晚开始算：记不记得、装不装不记得、她提还是不提。三个决定在早饭桌上十分钟内全做完，谁也没捅破。九十分钟的流程从进门算起，灌水、擦脸、扒外套，前半小时他配合得跟个大行李似的。真话在第六十分钟左右冒了头，夹在胡话里，滤干净后只剩「那句」。

#### 醉酒为什么好用

清醒时他不会说的话、不会做的动作，醉了都可以。**而且第二天可以不认。**

这个「可以不认」是关键：它让双方都保留了退路。

#### 醉的三个层次

| 层 | 表现 | 能用来做什么 |
|---|---|---|
| 微醺 | 话多了、笑点低 | 他会说平时不说的实话 |
| 醉 | 走不稳、黏人 | 他会做平时不做的动作 |
| 断片 | 完全失控 | 他会说出那件事，且第二天不记得 |

**第三层要慎用。** 断片状态下的坦白会让第二天的处理变得很复杂。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 一身酒气 ✓ · 醒酒汤 ✓ · 他外套 ✓ 甩在门口 · 鞋也没脱 |
| 她的处理 | 扶 · 喂水 · 拖进浴室 · 半夜爬起来看他吐没吐 |
| 他的表现 | 话特别多 · 或者一声不吭光攥着她 |
| 他说的话 | 一句平时打死也不会说的 |
| 第二天 | 他装不装傻 · 她提不提这茬 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁醉 | 他 | 她（少见，且极有戏） |
| 醉的原因 | 应酬 | 心里有事 |
| 他说了什么 | 撒娇的话 | 一句实话 |
| 第二天 | 真不记得 | 记得，装不记得 |

「她喝醉」这一版值得专门写。 她卸下防备的样子，他大概率是第一个见到的人。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他拽着她袖子不撒手那一下 | 第二天醒来脑子发空 |
| 内心 | 他说的是不是真心话 | 我昨晚到底说了啥 |
| 好的处理 | 她记下了，但第二天没提 | 他没借着酒劲装疯 |
| 写崩 | 写成借着酒劲占便宜 | 写成他酒后撒泼 |

「借醉装疯」是这条的红线。 醉是卸防不是免责。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 宴上被灌／她命人抬回／醒酒汤 |
| 修仙 | 灵酒／他修为压不住酒气 |
| 星际 | 舰上的合成酒／他违规喝了 |

#### 写崩的三种方式

1. 用醉酒推进亲密。借醉是逃避责任。
2. 让他撒酒疯。醉要可爱或可怜，不要难堪。
3. 第二天完全跳过。记不记得那一格才是重点。

## 六 · 她的生理期

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：生理期 10.0%

**骨架**｜她疼得说不出话。可他要赌的，就是他还记不记得。

#### 节拍链

她硬撑，他看出来了。不问，只做。调暖、备药、日程后移。她不想被当病人，最后还是接受了。后来她发现，日子他一直记着。

#### 时间轴

她撑到下午，实在扛不住的时候，晚上本来有安排。他一句话不说，把暖贴和热水放好，手机里那个她不知道的提醒，已经记了大半年。下午三点，他悄悄把日程往后挪了。她后来翻到那个日历条目，盯着看了十秒，什么都没说。那十秒比任何台词都重。他的准备按月算，她的硬撑按小时算。

#### 为什么这条在 GB 里特殊

生理期是她掌控不了的事。一个凡事都要抓在手里的人，这种时候只能老实待着，让别人照顾。

而照顾她的方式，暴露了他平时有多留意：

| 他做的 | 说明 |
|---|---|
| 递红糖水 | 最基础，也最敷衍 |
| 提前买好了她用的那个牌子 | 他记得 |
| 把暖宝宝提前热好 | 他知道她的时间 |
| 什么都不说地把工作日程往后推了 | 他管到了她的事业 |
| 不提这件事，只是把家里调暖了两度 | 最好 |

最后一行最好，因为它不把她当病人。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的状态 | 脸色差 · 话少 · 蜷着 · 不肯说自己难受 |
| 他的准备 | 家里常备的那一格 · 他记的日子 |
| 她的抗拒 | 「我没事」· 她烦别人拿她当病人 |
| 分寸 | 他不问，光做 |
| 落点 | 她后来才发现他一直记着 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的态度 | 你照顾就照顾吧 | 别把我当病人 |
| 他的做法 | 明着来 | 偷偷做 |
| 她知不知道他记着 | 没察觉 | 后来翻到了 |
| 场合 | 家里 | 单位（她得端着） |

**「工作场合她要撑住」这一版最有力：** 全公司只有他知道她今天在硬撑。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现家里的暖气早就开了 | 她今天第三次揉腰 |
| 内心 | 我不想被人看扁 | 别问，问了她又要硬撑 |
| 好的处理 | 她领了这份好，没多说什么 | 他不吭声，该干嘛干嘛 |
| 写崩 | 把她写成娇滴滴的 | 把他写成咋咋呼呼的 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他备下姜汤／换了软垫／替她告了假 |
| 修仙 | 她修为不稳／他守着闭关 |
| 星际 | 抑制剂／他偷偷改了她的体检数据 |
| 女A男O | 反着来：**他发情／他易感**，详见 [21 卷](21-世界设定专属.md) |

**女A男O 的方向反转只换承受者，不换动作：** 生理上的不可控转到了他身上，照护的那几个动作原样保留，方向反过来。

#### 写崩的三种方式

1. 把她写成娇弱。 她疼但她不弱。
2. 大惊小怪。 不问只做才对。
3. 只写红糖水。 那是最敷衍的一档。

## 七 · 第一次

`M` ｜ ⚠️亲密接触 ｜ 全谱系 ｜ 语料频次：留痕 47.0% ＋ 洗漱 37.0%

**骨架**｜这条只写结构和关系的变化，不写具体过程。

#### 节拍链

之前的默契累积 → 发生（过程不在本条）→ 第二天早上 → 两个人都醒着装睡 → 第一句话很平常 → 物件悄悄换了位置

#### 时间轴

中间那段，时间轴不写，只记两头。一周之内，牙刷、枕头、某件衣服，物件静悄悄换了位置，主人也换了。谁先“醒”的表演、第一句话有多平常，第二天早上按分钟算：两个人都醒了但装睡那二十分钟，全在里头。越平常越加分。眼神多停几秒、告别越拖越长，默契按周累积，早就在铺垫了。

#### 本条的边界

具体的场景写法走 [06-尺度与写法/03-情欲场景结构](../06-尺度与写法/03-情欲场景结构.md)，那一卷把分级镜头怎么控制讲全了。

这里只处理一件事：这场戏前后，关系变了什么。

#### 前后对照表

| 项 | 之前 | 之后 |
|---|---|---|
| 谁发起 | 试探 | 已确立 |
| 称呼 | 可能还没改 | 通常这之后改 |
| 空间 | 他的东西在客房 | 挪进主卧 |
| 第二天早上 | — | 这才是这条真正要写的 |

#### 第二天早上，四种写法

| 写法 | 关系含义 |
|---|---|
| 她先醒，看了他一会儿 | 她想确认这事真发生了 |
| 他先醒，不敢动 | 他拿不准自己该不该留下 |
| 两个人都醒着装睡 | 最好 |
| 她已经去上班了，留了字条 | 她打算这么处理 |

「两人都醒着装睡」是这条最好的一版。 谁都不想先开口定义刚才发生的事。

#### 可用细节

| 类 | 内容 |
|---|---|
| 之后的物件 | 多出来的一支牙刷 · 被挪动的枕头 ✓ · 他的衬衫 ✓ 在椅背上 |
| 身体的痕迹 | 见 [05-占有与吃醋 · 留痕](05-占有与吃醋.md#四--留痕) |
| 第一句话 | 越平常越好（「几点了」） |
| 变化的信号 | 他洗漱时用了她的杯子，没问一声 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先醒 | 她 | 他 |
| 说不说破 | 都装睡到闹钟响 | 她先开了口 |
| 之后几天 | 自然过渡 | 尴尬了两天才顺 |
| 物证 | 牙刷进了杯架 | 他的衬衫上了她的衣架 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她先醒，看了他一会儿 | 他醒着，不敢动 |
| 内心 | 就这样吧，挺好 | 我现在起来算不算逃 |
| 好的处理 | 她开口先问「几点了」 | 他没问「我们算什么」 |
| 写崩 | 写成她大清早盘算得失 | 写成他翻来覆去瞎琢磨一整章 |

#### 安全与边界

| 线 | 说明 |
|---|---|
| 全员成年 | 所有涉及亲密情节的角色都得是成年人 |
| 知情同意 | 双方都愿意，中途想停随时能停 |
| 不写可复现细节 | 本卷只聊关系怎么搭，不写具体过程 |
| 分级 | 真写到具体镜头，按 [06-尺度与写法](../06-尺度与写法/) 的分级来控 |

#### 换皮

结构等价物照迁，过程在任何世界都不写：

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 合卺第二天早上，请安迟了半刻，全府都心里有数。她一句「往后他辰时起」，新规矩就这么定了 |
| 修仙 | 双修头一回之后灵气串了，第二天上课谁都能看出来。俩人谁也不吭声，装没事人 |
| 星际 | 门禁记录合成了一条，第二天吃早饭，他盯着那行记录瞅了半天没说话 |

#### 写崩的三种方式

1. 这一场戏把关系里的问题都写完了。但真到现实里，那些矛盾一个都没解决。
2. 第二天早上别写。那才是这条线的正文。
3. 让权力关系在这一场里掉个儿。床上谁压谁，跟关系里谁说了算，是两码事。

## 八 · 之后的日常

`M` ｜ ⚠️亲密接触 ｜ 全谱系 ｜ 语料频次：留痕 47.0%

**骨架**｜亲密变成日常以后，就不再是事，而是话。

#### 节拍链

从事件变成语言 → 频率成形 → 一次被拒 → 他分辨（是累还是不想）→ 说开 → 频率变化被当体温计读

#### 时间轴

**日历不再按日期走，而是按频率走。** 成形期之后，节奏自己长了出来。忙季它降，和好后它升，有心事它乱——频率变化像体温计，标记着两个人的状态。被拒那次，是表盘上的一次异常跳动。他花了三天才分清「是累还是不想」，先观察，再试探，最后干脆直接问。说开之后，这条时间轴就没有终点，成了往后所有日子的背景音。

#### 从事件到语言

| 阶段 | 性质 |
|---|---|
| 第一次 | 事件。要专门写 |
| 前几次 | 还是事件 |
| 之后 | 语言。用来说别的事 |

**「用来说别的事」是这条的全部内容：**

| 用法 | 说的是什么 |
|---|---|
| 累了一天，只是抱着睡 | 陪着你 |
| 吵完架之后 | 和好 |
| 她主动 | 她今天心情不好 |
| 他被拒绝 | 她真的很累（他得看得出来） |
| 中途停下来说了句正事 | 这俩人已经过成日子了 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 频率的变化 | 忙起来之后 · 吵架之后 · 光这个变，就有戏 |
| 分辨的能力 | 他分不分得清「今天不行」和「不想」 |
| 被拒绝时 | 他啥反应，这人啥样就露出来了 |
| 日常化的标志 | 正聊着，有人接了个工作电话 |

「他能不能分清」是这条最重要的一条。能分清的人，和那种把每次拒绝都读成信号的人，完全是两种角色。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 主动方 | 她为主 | 双向 |
| 被拒绝时 | 他接受 | 他不安 |
| 频率变化 | 稳定 | 明显下降（是信号，要处理） |
| 沟通 | 说得出口 | 都不说 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她说「今天太累了」之后他啥反应 | 她俩礼拜没主动找他了 |
| 好的处理 | 她明说就是累，没别的意思 | 他开口问了，问得挺自然 |
| 写崩 | 写她拿亲热当赏钱或罚钱 | 写他记着次数，伸手要账 |

「用亲密作为奖惩」是这条的红线。 它会把关系变成交易，且很难写回来。

#### 安全与边界

同第七条：全员成年、知情同意、随时能喊停，不写具体过程。谁说了停就得马上停，这一点在文里得让读者看得见。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 侍寝的日子全府上下都心里有数，她干脆废了排班，想见就见，府里人说这比改祖制还新鲜 |
| 修仙 | 双修从必修课变成家常便饭，修为涨得快慢成了同门开玩笑的由头，俩人从来不接话 |
| 星际 | 舱里温度、灯光这些偏好悄悄合到一块儿，系统学会俩人作息，某天弹出一条「已生成双人模式」 |

#### 写崩的三种方式

1. 用亲密做奖惩。见上。
2. 让他把每次拒绝都读成危机。分辨能力就是这个角色的成熟度。
3. 忽略频率变化。那是关系的体温计。

## 九 · 两个人的作息

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：同居 20.0% ＋ 夜深 37.0%

**骨架**｜她十一点睡，他两点睡。就这点事，能磨一辈子。

#### 节拍链

差异暴露 → 蹑手蹑脚期 → 妥协的物证（耳机·震动闹钟）→ 一次爆发 → 谈 → 分房或磨合 → 新常态

#### 时间轴

半年下来，折腾了无数个来回，最后定下的办法倒简单：他十二点先上床，陪她睡熟了再起来。可这法子是拿前几个月的鸡飞狗跳换的。头一个月，他进屋都蹑手蹑脚，关门练到没声。第二个月起，添耳机、震动闹钟、遮光帘，一个月添一样。到第四个月某个周二凌晨，她第三次被吵醒，当场炸了。当晚聊完，第二天试着分房睡，撑了一礼拜，不行，俩人都睡不踏实。绕了这么一大圈，就为了十一点到凌晨两点那三个小时。

#### 作息差是同居的第一大摩擦

比家务更常见，比金钱更琐碎，且没有对错。

| 差异 | 后果 |
|---|---|
| 睡觉时间 | 一个被吵醒，一个不敢动 |
| 起床时间 | 早起的那个每天蹑手蹑脚 |
| 吃饭时间 | 一个等一个 |
| 加班规律 | 见 [02-等待与错过](02-等待与错过.md) |
| 周末怎么过 | 一个要出门，一个要睡觉 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 妥协的痕迹 | 他买了降噪耳机 ✓ · 她把闹钟 ✓ 调成震动 · 客厅的小夜灯 |
| 磨合失败的痕迹 | 有人开始睡沙发 ✓ · 有人开始在客厅待到很晚 |
| 隐忍 | 一个人躺着装睡，等另一个人进来 |
| 崩点 | 某天有人说了「你能不能……」 |
| 解决 | 分房睡，不是感情出问题，是作息合不来 · 这点得写明 |

「分房睡不等于关系出问题」值得单独写清楚。 语料里这两件事常被混为一谈。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁迁就谁 | 他迁就她 | 各自保留 |
| 结果 | 磨合成了 | 分房，且两人都很好 |
| 摩擦 | 小 | 爆发过一次 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她半夜醒来，发现他还没睡 | 她翻身的时候，我就不敢动 |
| 好的处理 | 她提出分房睡，也把原因讲清楚了 | 他没把这事当成她不爱他 |
| 写崩 | 写成她不懂事 | 写成他硬扛了一年没吭声 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她要早朝／他守夜／各院分住是常态 |
| 修仙 | 她闭关他不闭／打坐时间错开 |
| 星际 | 值班表／三班倒 |

**古代女尊版有一个现代版没有的优势：分房本来就是制度**，所以「同寝」反而成了特殊待遇。

#### 写崩的三种方式

1. 把分房写成关系危机。其实它可能只是作息问题。
2. 让一方永远迁就。怨气会越积越深。
3. 忽略妥协的物证。降噪耳机、震动闹钟，这些就是关系的证据。

## 十 · 家的形状

<!-- gb-nonscene -->
`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：同居 20.0% ＋ 归家 46.0%

**骨架**｜住了一年，这屋子就染上了他俩的味儿。

#### 这条是全卷的收束

| 一个只有他们懂的东西放在客厅 | 外人看不懂，他俩明白 |
| 有一样东西一直没扔 | 见 [15-秘密与坦白 · 他一直留着的东西](15-秘密与坦白.md#九--他一直留着的东西) |

**「冰箱里有两种牛奶」是最省字的一条：** 两个人住在一起，但没有人被抹掉。

#### 可用细节

| 类 | 内容 |
|---|---|
| 时间的痕迹 | 用旧了的东西 · 换过的东西 · 修过的东西 |
| 各自的保留 | 她死活不扔的 · 他舍不得丢的 |
| 融合的部分 | 一件俩人都忘了谁买的玩意 |
| 外人视角 | 来个人就说「你们家待着真舒服」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 融合程度 | 高（分不清谁的） | 各自分明 |
| 时间 | 一年 | 十年 |
| 用途 | 甜的收尾 | 分手后的对照，同一段描写全部反过来 |

**最后一行是这条最狠的用法：** 分开之后，同一份清单原样再写一遍，每一项都变成了空的。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她忽然想不起沙发是打哪儿来的 | 这儿是我住得最久的一个地儿 |
| 好的处理 | 她发觉有件小事跟以前不一样了 | 他说不清这屋哪儿算他的，可处处都是 |
| 写崩 | 把温馨小家写成物件清单 | 写成了他终于有家的那种煽情戏 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 院子里的树长高了／他添的那几样东西一直没动过 |
| 修仙 | 洞府里多了几件凡间的东西／她开始留一盏灯不灭 |
| 星际 | 舱里多了些地球来的物件／私人物品配额全用完了 |

#### 写崩的三种方式

1. 写成清单堆砌。 挑三样。
2. 大段抒情。 物件自己会说。
3. 只用在甜的场合。 反过来用一次，威力翻倍。
