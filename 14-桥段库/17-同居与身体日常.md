## 一 · 第一次过夜

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：同居 20.0% ＋ 洗漱 37.0%

**骨架**｜他留下了。而这一晚全部的内容是「东西放哪」。

#### 节拍链

留下的决定 → 洗漱的顺序 → 穿什么睡 → 睡哪 → 熄灯 → 谁先睡着

#### 时间轴

从「要不留下」到熄灯，两个小时被拉成了慢动作。 洗漱顺序的谦让五分钟、睡衣问题十分钟（他的尺码没有，她翻出一件超大T恤，来历不明，他没问）、睡哪的谈判又十分钟。熄灯后的钟最慢：两个人都醒着，都听得见对方翻身，谁先睡着谁输，都输了，天亮时两个人都说自己睡得很好。

#### 五个必须决定的小事

这条不靠情节，靠这五个决定：

| 事 | 决定权在谁 |
|---|---|
| 谁先洗澡 | 通常她（她的房子） |
| 他穿什么 | 她的旧 T 恤／新买的／他自己带了 |
| 睡哪 | 床／沙发 ✓／她让开了半边 |
| 灯谁关 | 离门近的那个 |
| 谁先睡着 | 通常是她（他睡不着） |

「他自己带了」这个选项值得单独用。 他带了换洗的东西过来，说明他早就想过会留下。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 新拆封的牙刷 · 浴巾 ✓ · 她的洗发水味道 · 吹风机 ✓ · 多出来的一个杯子 |
| 他的拘谨 | 洗完澡不知道往哪站 · 头发没吹干 · 手机 ✓ 充电线 ✓ 忘带 |
| 她的自然 | 她照常做自己的事 · 顺手扔给他一条毛巾 ✓ |
| 那一刻 | 灯关掉之后的三十秒 |
| 早上 | 谁先醒 · 早饭 · 他要不要洗碗 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 有没有发生什么 | 没有 | 有 |
| 睡哪 | 分开 | 一起 |
| 他的状态 | 紧张 | 自在得让她意外 |
| 第二天 | 他很早走了 | 他留下做了早饭 |

「什么都没发生」这一版更好写也更耐读。 张力全在那三十秒里。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她给他找睡衣时翻了三个抽屉 | 洗完澡站在客厅中间 |
| 内心 | 我这儿没有男人的东西 | 我该睡哪 |
| 好的处理 | 她直接说「睡这儿」，不解释 | 他问了一句「我睡沙发？」 |
| 写崩 | 写成她刻意安排 | 写成他步步为营 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 留宿／歇在偏房还是正房／她让人铺了床 |
| 修仙 | 他在她洞府外结庐／她开了阵法让他进来 |
| 星际 | 他的舱位权限被加进了她的舱 |

#### 写崩的三种方式

1. 直接进入亲密。 这条卖的是那三十秒。
2. 省略「东西放哪」。 五个小决定就是全部内容。
3. 写成她的刻意安排。 自然发生才有味道。

#### 示例（本库自撰，可直接改写）

> 他洗完澡出来，头发滴着水，站在客厅正中间。
> 她从卧室扔了条毛巾过来，砸在他脸上。
> 「睡这儿。」她指了指里屋，「沙发太短，你腿放不下。」
> 他「哦」了一声，没动。
> 她翻了三个抽屉才找出一件宽松的旧 T 恤——她这儿从来没有过男人的东西。
> 灯关掉之后有三十秒，两个人都没说话。
> 然后她说：「你头发没吹干。」

## 二 · 搬进来

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：同居 20.0%（同居＋归家、同居＋节日高频同现）

**骨架**｜他的东西进了这个家。而进多少、放哪，是一场无声的谈判。

#### 节拍链

谁提的 → 打包 → 他带来的东西 → 那件难看的 → 她挪出半个柜子 → 混放成形 → 快递地址改了

#### 时间轴

搬入一天完成，磁场重排用一个月。 纸箱当天拆完是假象，他的东西第一周聚在「他的角落」，第二周开始扩散，第三周她的柜子挪出半格，第四周牙刷、充电线、拖鞋完成混编。快递地址改过来的那天是法律意义上的竣工日：系统里的「收货人」二字，比钥匙还硬。

#### 搬家的三个阶段

| 阶段 | 表现 | 关系 |
|---|---|---|
| 一 | 他有一把牙刷在这儿 | 客人 |
| 二 | 他有一个抽屉 | 常客 |
| 三 | 他的东西没有专属位置，混在她的东西里 | 住在一起 |

**第三阶段才是真的同居**，而从二到三的那一步往往没有被写出来。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他带来的 | 少得让她意外 · 或者多得需要清理 |
| 冲突点 | 他的旧沙发 ✓ 要不要 · 他母亲给的一套碗 ✓ · 一件她觉得难看的东西 |
| 她的让步 | 她留下了那件难看的 |
| 空间重排 | 她挪出了半个衣柜 · 她的东西第一次被移动 |
| 落点 | 她把自己的东西挪开的那一下 |

「她把自己的东西挪开」是这条的核心动作。她让出的是习惯，不只是空间。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提的 | 她 | 他（他会先试探） |
| 住谁的房子 | 她的 | 他的（罕见，值得写） |
| 他带的东西 | 很少 | 很多 |
| 冲突 | 无 | 一件东西的去留 |

**「住他的房子」这一版少见且有效：** 她进入他的领地，全部的位置关系被重新洗一遍。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把柜子腾出一半时手停了一下 | 我带的东西是不是太多了 |
| 内心 | 这是我一个人住了六年的地方 | 这不是我的家 |
| 好的处理 | 她主动说了「你的东西可以放这儿」 | 他没有把自己缩到最小 |
| 写崩 | 写成她理所当然地施舍空间 | 写成他寄人篱下 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 抬进府／住哪个院／他的箱笼有几担 |
| 修仙 | 入洞府／她给他一间静室／他的法器摆在何处 |
| 星际 | 舱位合并／权限重新分配 |

#### 写崩的三种方式

1. 一步到位。 三个阶段要能看出来。
2. 让她轻松让出全部空间。 她住了六年的地方，让出来是有感觉的。
3. 忽略那件难看的东西。 留下它才是接纳。

## 三 · 家务的分配

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：同居 20.0% ＋ 做饭 49.0%

**骨架**｜谁做什么，是这段关系的经济制度，不止是分工问题。

#### 节拍链

分工自然成形 → 隐形劳动浮现 → 一次爆发或一次说开 → 她坚持做一件 → 各自领域确认 → 成为长期制度

#### 时间轴

制度的成形以月计，爆发只要一晚。 前两个月分工自然沉降（谁顺手谁做）；隐形劳动的账单在第三个月浮出，记着买米、盯着缴费、安排年节，这些「没人做过但一直有人做」的事被摊上桌面那晚，谈判两小时。之后的制度稳定运行以年计，微调靠季度性的小争执，这是正常损耗。

#### 三种分配模型

| 模型 | 说法 | 隐患 |
|---|---|---|
| 他全包 | 「他喜欢做」 | 容易滑成保姆 |
| 按能力分 | 「他会做饭她会修东西」 | 最健康 |
| 按时间分 | 「谁在家谁做」 | 最现实 |
| 请人 | 「都忙」 | 回避了问题 |

「他全包」是语料里的高频配置，也是最需要处理的一个。 处理方法：让她做一件她做得不好但坚持要做的事。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的领域 | 厨房（灶 ✓、油烟 ✓、砂锅 ✓）· 洗衣 · 收纳 |
| 她的领域 | 修东西 · 换灯泡 · 交涉（物业、快递、维修） |
| 摩擦点 | 他嫌她乱放东西 · 她嫌他收得太整齐找不到 |
| 她坚持做的那件 | 做得不好，但她要做 |
| 隐形劳动 | 谁记得该买什么 · 谁记得交费 · 这一项通常没人算 |

「隐形劳动」是这条最值得写的一层。 记着家里缺什么、什么时候该交费、谁的生日快到了——这些不算家务，但它们最累人。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 分配 | 他多 | 平均 |
| 她的参与 | 完全不管 | 坚持做一件 |
| 摩擦 | 无 | 一次爆发 |
| 隐形劳动 | 他承担 | 她承担 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现家里的米从来没断过 | 她今天问我洗衣液放哪 |
| 内心 | 这些事我从来没操心过 | 我做这些不是因为我该做 |
| 好的处理 | 她开始记一件事 | 他说出了自己的不平 |
| 写崩 | 写成她十指不沾阳春水 | 写成他任劳任怨 |

「他说出了自己的不平」是这条必须有的一场。 全程无怨言的家务承担者，是设定不是人物。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 内宅由他掌／对牌与钥匙 ✓ 在谁手上／她管外他管内 |
| 修仙 | 洞府洒扫／灵植照料／她修行他打理 |
| 星际 | 舱内维护值班表 |

**古代版的「对牌与钥匙」是这条换皮的顶格**：管家管的是权，不是活。

#### 写崩的三种方式

1. 让他毫无怨言。 至少一次不平。
2. 忽略隐形劳动。 那是这条的深层。
3. 让她完全不参与。 一件做不好但坚持的事，能救这个角色。

## 四 · 洗澡之后

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：洗漱 37.0%（洗漱＋睡着、洗漱＋留痕高频同现）

**骨架**｜水声停了。接下来那几分钟是这个家最松弛的时段。

#### 节拍链

水声停 → 吹风机响 → 湿发与雾气 → 最松弛的时段 → 一段没防备的对话 → 收在睡前

#### 时间轴

水声停到吹风机响，中间有五分钟真空。 这五分钟里的家最软：热气、湿发、没穿好的拖鞋。没防备的对话就发生在吹风机的间歇里，风声一停，话就漏出来一句，风声再起，话题被合法地掐断。这条的钟以「吹风机的开关次数」计拍，三次开关能装下一段平时说不出口的话。

#### 为什么这条高频

洗漱 37% 在情境族里排第五。原因是它天然满足三件事：时间明确、空间私密、双方都卸了装备。

#### 可用细节

| 类 | 内容 |
|---|---|
| 声音 | 水声停 · 吹风机 ✓ 响 · 停机之后的耳鸣式安静 |
| 道具 | 浴巾 ✓ · 湿的头发 · 雾气 · 镜子 ✓ · 拖鞋的湿脚印 |
| 谁给谁 | 吹头发（见 [01 卷第八条](01-日常照料.md#八--洗头与吹头发)）· 递睡衣 · 涂药 ✓ |
| 状态差 | 她洗完是放松，他洗完是紧张（他在别人家） |
| 对话 | 这个时段的对话最没有防备 |

**「这个时段的对话最没有防备」是这条的功能：** 需要一场坦白、一句实话、一个请求，放在这里最自然。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁洗完 | 他 | 她 |
| 状态 | 放松 | 有事没说 |
| 发生什么 | 一段对话 | 什么都没有 |
| 收尾 | 睡觉 | 一个动作 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他的头发还在滴水 | 她洗完出来的样子 |
| 好的处理 | 她顺手把毛巾扔过去 | 他自己去把头发吹了 |
| 写崩 | 写成擦边描写 | 写成他偷看 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 沐浴后／散着发／他捧巾伺候／她自己挽发 |
| 修仙 | 以灵力烘干／他替她束发 |
| 星际 | 舰上限水／共用一次配额 |

#### 写崩的三种方式

1. 写成擦边。 这条要的是松弛不是暴露。
2. 忽略声音。 水声停与吹风机停是这条的两个节点。
3. 不放对话进去。 这个时段是最好的对话容器。

## 五 · 他喝多了

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：醉酒 31.0%（醉酒＋归家、醉酒＋留痕高频同现）

**骨架**｜他喝醉了。而醉是这个类型最合理的卸防装置。

#### 节拍链

电话来或被送回 → 进门 → 她处理（灌水·浴室·守着）→ 他说了那句 → 睡去 → 第二天记不记得 → 她提不提

#### 时间轴

从进门到睡去九十分钟，真话出现在第六十分钟前后。 前半程是流程（灌水、擦脸、扒外套），他配合得像件大行李；中段进入胡话区，胡话过滤完剩一句真的，就是「那句」。第二天的钟从他睁眼开始：记不记得、装不装记得、她提不提，三个决定在早饭桌上十分钟内各自做完，谁都没说破。

#### 醉酒为什么好用

清醒时他不会说的话、不会做的动作，醉了都可以。**而且第二天可以不认。**

这个「可以不认」是关键：它让双方都保留了退路。

#### 醉的三个层次

| 层 | 表现 | 能用来做什么 |
|---|---|---|
| 微醺 | 话多了、笑点低 | 他会说平时不说的实话 |
| 醉 | 走不稳、黏人 | 他会做平时不做的动作 |
| 断片 | 完全失控 | 他会说出那件事，且第二天不记得 |

**第三层要慎用。** 断片状态下的坦白会让第二天的处理变得很复杂。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 一身酒气 ✓ · 醒酒汤 ✓ · 他的外套 ✓ 掉在门口 · 鞋没脱 |
| 她的处理 | 扶 · 灌水 · 把他弄进浴室 · 半夜起来看他有没有吐 |
| 他的表现 | 一直在说话 · 或者一句话不说只是抓着她 |
| 他说的话 | 一句平时绝不会说的 |
| 第二天 | 他记不记得 · 她提不提 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁醉 | 他 | 她（少见，且极有戏） |
| 醉的原因 | 应酬 | 心里有事 |
| 他说了什么 | 撒娇的话 | 一句实话 |
| 第二天 | 真不记得 | 记得，装不记得 |

「她喝醉」这一版值得专门写。 她卸下防备的样子，他大概率是第一个见到的人。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他抓着她袖口不放的那一下 | 第二天醒来的空白 |
| 内心 | 他说的是真心话吗 | 我昨天说了什么 |
| 好的处理 | 她记住了，但第二天不提 | 他没有借醉装疯 |
| 写崩 | 写成醉酒趁机 | 写成他撒酒疯 |

「借醉装疯」是这条的红线。 醉是卸防不是免责。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 宴上被灌／她命人抬回／醒酒汤 |
| 修仙 | 灵酒／他修为压不住酒气 |
| 星际 | 舰上的合成酒／他违规喝了 |

#### 写崩的三种方式

1. 用醉酒推进亲密。 借醉是逃避责任。
2. 让他撒酒疯。 醉要可爱或可怜，不要难堪。
3. 第二天完全跳过。 记不记得那一格才是重点。

## 六 · 她的生理期

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：生理期 10.0%

**骨架**｜她疼得说不出话。而他要做的事，考验的是他记不记得。

#### 节拍链

她硬撑 → 他看出来了 → 不问只做（调暖·备药·日程后移）→ 她拒绝被当病人 → 接受了 → 她后来发现他一直记着日子

#### 时间轴

她的硬撑以小时计，他的准备以月计。 当天的时间线：她撑到下午实在熬不住、他下午三点把暖贴和热水放到位（不说话）、晚上日程被他悄悄后移。长时间线藏在后面：他记日子记了大半年，手机里有个她不知道的提醒，被她发现那天，她盯着那个日历条目看了十秒，什么都没说，那十秒比任何台词都长。

#### 为什么这条在 GB 里特殊

生理期是一个**她无法掌控的状况**。对一个凡事都在掌控中的角色来说，这是少数几个她必须被照顾的时刻。

而照顾她的方式，暴露了他平时有多留意：

| 他做的 | 说明 |
|---|---|
| 递红糖水 | 最基础，也最敷衍 |
| 提前买好了她用的那个牌子 | 他记得 |
| 把暖宝宝提前热好 | 他知道她的时间 |
| 什么都不说地把工作日程往后推了 | 他管到了她的事业 |
| 不提这件事，只是把家里调暖了两度 | 最好 |

最后一行最好，因为它不把她当病人。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的状态 | 脸色 · 话少 · 蜷着 · 拒绝承认自己不舒服 |
| 他的准备 | 家里常备的那一格 · 他记的日子 |
| 她的抗拒 | 「我没事」· 她不喜欢被当成虚弱 |
| 分寸 | 他不问，只做 |
| 落点 | 她后来发现他一直记着 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的态度 | 接受照顾 | 拒绝被当病人 |
| 他的做法 | 明着照顾 | 不动声色 |
| 她知不知道他记着 | 不知道 | 后来发现了 |
| 场合 | 家里 | 工作场合（她要撑住） |

**「工作场合她要撑住」这一版最有力：** 全公司只有他知道她今天在硬撑。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现家里的暖气早就开了 | 她今天第三次揉腰 |
| 内心 | 我不想被当成弱的 | 别问，问了她就要逞强 |
| 好的处理 | 她接受了，且没有解释 | 他不问只做 |
| 写崩 | 写成她娇弱化 | 写成他大惊小怪 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他备下姜汤／换了软垫／告了她的假 |
| 修仙 | 她的修为受影响／他护法 |
| 星际 | 抑制剂／她的生理数据被他调过 |
| 女A男O | 方向反转：**易感期／发情期在他身上**（见 [21 卷](21-世界设定专属.md)） |

**女A男O 的方向反转只换承受者，不换动作：** 生理上的不可控转到了他身上，照护的那几个动作原样保留，方向反过来。

#### 写崩的三种方式

1. 把她写成娇弱。 她疼但她不弱。
2. 大惊小怪。 不问只做才对。
3. 只写红糖水。 那是最敷衍的一档。

## 七 · 第一次

`M` ｜ ⚠️亲密接触 ｜ 全谱系 ｜ 语料频次：留痕 47.0% ＋ 洗漱 37.0%

**骨架**｜本条只写结构与关系变化，不写过程。

#### 节拍链

之前的默契累积 → 发生（过程不在本条）→ 第二天早上 → 两个人都醒着装睡 → 第一句话很平常 → 物件悄悄换了位置

#### 时间轴

本条只写前后，不写中间。时间轴也一样。 之前的默契累积以周计（眼神的停留变长、告别越来越拖）；第二天早上的钟以分钟计：两个人都醒着装睡的那二十分钟、谁先「醒」的表演、第一句话的平常度（越平常越高分）。物件换位置发生在一周内，牙刷、枕头、某件衣服，静悄悄完成的产权变更。

#### 本条的边界

具体的场景写法走 [06-尺度与写法/03-情欲场景结构](../06-尺度与写法/03-情欲场景结构.md)，那一卷有完整的分级镜头控制。

这里只处理一件事：这场戏前后，关系变了什么。

#### 前后对照表

| 项 | 之前 | 之后 |
|---|---|---|
| 谁发起 | 试探 | 已确立 |
| 称呼 | 可能还没改 | 通常这之后改 |
| 空间 | 他的东西在客房 | 挪进主卧 |
| 第二天早上 | — | 这才是这条真正要写的 |

#### 第二天早上，四种写法

| 写法 | 关系含义 |
|---|---|
| 她先醒，看了他一会儿 | 她在确认这件事发生了 |
| 他先醒，不敢动 | 他在确认自己该不该还在这儿 |
| 两个人都醒着装睡 | 最好 |
| 她已经去上班了，留了字条 | 她的处理方式 |

「两人都醒着装睡」是这条最好的一版。 谁都不想先开口定义刚才发生的事。

#### 可用细节

| 类 | 内容 |
|---|---|
| 之后的物件 | 多出来的一支牙刷 · 被挪动的枕头 ✓ · 他的衬衫 ✓ 在椅背上 |
| 身体的痕迹 | 见 [05-占有与吃醋 · 留痕](05-占有与吃醋.md#四--留痕) |
| 第一句话 | 越平常越好（「几点了」） |
| 变化的信号 | 他洗漱时用了她的杯子，没有问 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先醒 | 她 | 他 |
| 说不说破 | 都装睡到闹钟响 | 她先开了口 |
| 之后几天 | 自然过渡 | 尴尬了两天才顺 |
| 物证 | 牙刷进了杯架 | 他的衬衫上了她的衣架 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她先醒，看了他一会儿 | 他醒着，不敢动 |
| 内心 | 就这样吧，挺好 | 我现在起来算不算逃 |
| 好的处理 | 她的第一句是「几点了」 | 他没有问「我们算什么」 |
| 写崩 | 写成她清晨审视利弊 | 写成他患得患失一整章 |

#### 安全与边界

| 线 | 说明 |
|---|---|
| 全员成年 | 所有涉性情节中的角色均为成年人 |
| 知情同意 | 双方自愿，且过程中可随时停止 |
| 不写可复现细节 | 本卷只讨论关系结构，不做过程描写 |
| 分级 | 涉及具体描写的部分走 [06-尺度与写法](../06-尺度与写法/) 的分级镜头控制 |

#### 换皮

结构等价物照迁，过程在任何世界都不写：

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 合卺之后的第二天早上：请安的时辰他迟了半刻，满府心照不宣，她一句「往后他辰时起」把新规矩定了 |

1. 用这一场解决所有关系问题。 它改变不了任何已有的矛盾。

3. 让权力关系在这一场里翻转。 床上的配置与关系配置是两回事。

## 八 · 之后的日常

`M` ｜ ⚠️亲密接触 ｜ 全谱系 ｜ 语料频次：留痕 47.0%

**骨架**｜亲密变成了日常之后，它就不再是事件，而成了一种语言。

#### 节拍链

从事件变成语言 → 频率成形 → 一次被拒 → 他分辨（是累还是不想）→ 说开 → 频率变化被当体温计读

#### 时间轴

**频率本身成了日历。** 成形期后它有了自己的节律；被拒的那一次是钟面上的异常读数，他分辨「是累还是不想」用了三天（观察、试探、最后直接问）。说开之后频率变化被当体温计读：忙季它降、和好后它升、有心事它乱。这条的时间轴没有终点，它就是两个人往后所有日子的背景钟。

#### 从事件到语言

| 阶段 | 性质 |
|---|---|
| 第一次 | 事件。要专门写 |
| 前几次 | 还是事件 |
| 之后 | 语言。用来说别的事 |

**「用来说别的事」是这条的全部内容：**

| 用法 | 说的是什么 |
|---|---|
| 累了一天，只是抱着睡 | 陪伴 |
| 吵完架之后 | 和好 |
| 她主动 | 她今天心情不好 |
| 他被拒绝 | 她真的很累（他要能分辨） |
| 中途停下来说了句正事 | 这段关系已经很日常了 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 频率的变化 | 忙起来之后 · 吵架之后 · 这个变化本身是信息 |
| 分辨的能力 | 他能不能分清「今天不行」和「不想」 |
| 被拒绝时 | 他的反应决定了他这个人 |
| 日常化的标志 | 中途有人接了个工作电话 |

「他能不能分清」是这条最重要的一条。 一个能分清的人，和一个把每次拒绝都读成信号的人，是两种角色。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 主动方 | 她为主 | 双向 |
| 被拒绝时 | 他接受 | 他不安 |
| 频率变化 | 稳定 | 明显下降（是信号，要处理） |
| 沟通 | 说得出口 | 都不说 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她说「今天太累了」之后他的反应 | 她已经两周没有主动了 |
| 好的处理 | 她说清楚是累不是别的 | 他问了，且问得平常 |
| 写崩 | 写成她用亲密作为奖惩 | 写成他计数与索取 |

「用亲密作为奖惩」是这条的红线。 它会把关系变成交易，且很难写回来。

#### 安全与边界

同第七条：全员成年、知情同意、可随时停止、不写可复现细节。任何一方表示停止时立刻停止，这一点在文本里要能看出来。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 侍寝的频率在府里是半公开的历书；她废了排期那套，改成「想见就见」，此举在府中引起的震动不亚于改祖制 |
| 修仙 | 双修从功课变成了日常；进境快慢成了同门打趣的话头，两人从不接茬 |
| 星际 | 舱室环境参数（温度、灯光的偏好合并）是这条的星际形态：系统默默学习了两个人的共同作息，某天推送「已生成双人模式」 |

#### 写崩的三种方式

1. 用亲密做奖惩。 见上。
2. 让他把每次拒绝都读成危机。 分辨能力是这个角色的成熟度。
3. 忽略频率变化。 那是关系的体温计。

## 九 · 两个人的作息

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：同居 20.0% ＋ 夜深 37.0%

**骨架**｜她十一点睡，他两点睡。这件小事会磨很久。

#### 节拍链

差异暴露 → 蹑手蹑脚期 → 妥协的物证（耳机·震动闹钟）→ 一次爆发 → 谈 → 分房或磨合 → 新常态

#### 时间轴

十一点与两点之间的三小时，磨了半年。 蹑手蹑脚期一个月（他练出了无声关门的手艺）；物证期两个月（耳机、震动闹钟、遮光帘按月添置）；爆发在第四个月的某个周二凌晨（她被吵醒第三次）；谈判一晚，试分房一周，失败，都睡不好；最终磨出的新常态：他十二点上床陪到她睡着，再起来。半年的磨合，磨出的是这个绕远的解。

#### 作息差是同居的第一大摩擦

比家务更常见，比金钱更琐碎，且没有对错。

| 差异 | 后果 |
|---|---|
| 睡觉时间 | 一个被吵醒，一个不敢动 |
| 起床时间 | 早起的那个每天蹑手蹑脚 |
| 吃饭时间 | 一个等一个 |
| 加班规律 | 见 [02-等待与错过](02-等待与错过.md) |
| 周末怎么过 | 一个要出门，一个要睡觉 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 妥协的痕迹 | 他买了降噪耳机 ✓ · 她把闹钟 ✓ 调成震动 · 客厅的小夜灯 |
| 磨合失败的痕迹 | 有人开始睡沙发 ✓ · 有人开始在客厅待到很晚 |
| 隐忍 | 一个人躺着装睡等另一个人进来 |
| 崩点 | 某天有人说了「你能不能……」 |
| 解决 | 分房睡（不是关系问题，是作息问题）· 这一点要写清楚 |

「分房睡不等于关系出问题」值得单独写清楚。 语料里这两件事常被混为一谈。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁迁就谁 | 他迁就她 | 各自保留 |
| 结果 | 磨合成了 | 分房，且两人都很好 |
| 摩擦 | 小 | 爆发过一次 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她半夜醒来发现他还没睡 | 她翻身的时候我就不敢动 |
| 好的处理 | 她提出了分房，且说明了理由 | 他没有把这件事读成不爱 |
| 写崩 | 写成她不体谅 | 写成他默默忍受一年 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她要早朝／他守夜／各院分住是常态 |
| 修仙 | 她闭关他不闭／打坐时间错开 |
| 星际 | 值班表／三班倒 |

**古代女尊版有一个现代版没有的优势：分房本来就是制度**，所以「同寝」反而成了特殊待遇。

#### 写崩的三种方式

1. 把分房写成关系危机。 它可以只是作息问题。
2. 让一方永远迁就。 会积成怨。
3. 忽略妥协的物证。 降噪耳机、震动闹钟就是关系的证据。

## 十 · 家的形状

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：同居 20.0% ＋ 归家 46.0%

**骨架**｜住了一年之后，这个家变成了他们两个人的样子。

#### 这条是全卷的收束

不是一场戏。这是一个可以在全书任意处插入的状态描写。

它的写法是列举变化：

| 变了什么 | 说明 |
|---|---|
| 冰箱里有两种牛奶 ✓ | 各自的口味都被保留 |
| 遥控器旁边多了一副老花镜 | 时间过去了 |
| 沙发 ✓ 塌陷的两个位置 | 各自的领地固定了 |
| 玄关 ✓ 的鞋摆成了固定的顺序 | 习惯成形 |
| 墙上多了一张照片 ✓ | 见 [07-馈赠与仪式 · 合照](07-馈赠与仪式.md#五--合照) |
| 一个只有他们懂的东西放在客厅 | 私人史 |
| 有一样东西一直没扔 | 见 [15-秘密与坦白 · 他一直留着的东西](15-秘密与坦白.md#九--他一直留着的东西) |

**「冰箱里有两种牛奶」是最省字的一条：** 两个人住在一起，但没有人被抹掉。

#### 可用细节

| 类 | 内容 |
|---|---|
| 时间的痕迹 | 磨损 · 换过的东西 · 修过的东西 |
| 各自的保留 | 一样她坚持不换的 · 一样他坚持留着的 |
| 融合的部分 | 一件说不清是谁买的东西 |
| 外人视角 | 有客人来，说「你们家挺舒服的」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 融合程度 | 高（分不清谁的） | 各自分明 |
| 时间 | 一年 | 十年 |
| 用途 | 甜的收尾 | 分手后的对照（同一段描写，全部反过来） |

**最后一行是这条最狠的用法：** 分开之后，同一份清单原样再写一遍，每一项都变成了空的。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己已经不记得沙发是谁买的 | 这是我住过最久的地方 |
| 好的处理 | 她注意到一件小事变了 | 他说不出这个家哪里是他的，但哪里都是 |
| 写崩 | 写成温馨小家的清单堆砌 | 写成他终于有了归属的煽情 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 院子里的树长高了／他添置的那几样一直没动 |
| 修仙 | 洞府里多了凡俗的物件／她开始留一盏灯 |
| 星际 | 舱内多了地球的东西／私人物品配额用满了 |

#### 写崩的三种方式

1. 写成清单堆砌。 挑三样。
2. 大段抒情。 物件自己会说。
3. 只用在甜的场合。 反过来用一次，威力翻倍。
