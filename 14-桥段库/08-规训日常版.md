## 安全框架（本卷统一说明，先读这一节）

本卷说的是**日常小打小闹**的那些规矩和罚法：罚站、没收、禁足、写检讨、数到三。这跟 [06-尺度与写法](../06-尺度与写法/) 里聊的训诫／BDSM 是两码事，但底线上头是一套，所以该讲的框架在这儿也得讲全。

### 三条社群共识

| 缩写 | 全称 | 含义 |
|---|---|---|
| SSC | Safe, Sane, Consensual | 安全、理智、双方同意 |
| RACK | Risk-Aware Consensual Kink | 知晓风险的前提下双方同意 |
| PRICK | Personal Responsibility, Informed Consensual Kink | 个人责任前提下的知情同意 |

三者是社群在不同年代提出的框架，共同点是**同意必须是知情的、可撤回的、由具备判断能力的成年人做出的**。

### 虚构与现实的分界

小说里的规矩和责罚，说白了就是个**幻想工具**——用来写关系里的拉扯感，整个世界攥在作者手里，出事也能兜住。**别拿它当现实操作手册。** 现实里真要搞权力交换那套，得提前说好底线、定好安全词、随时能喊停，双方都得清楚自己冒多大险。

本卷不提供任何可复现的实施细节，只讨论叙事结构。

### 本卷的三条硬边界

| 边界 | 说明 |
|---|---|
| 全员成年 | 凡是沾规矩和责罚的角色，都得是成年人 |
| 不写伤害 | 这卷里责罚不弄伤人。要写伤的去 [06-尺度与写法](../06-尺度与写法/) |
| 规矩要有来源 | 单方面定规矩叫拿捏人，两边一起认的才算关系 |

第三条是本卷与控制叙事的分水岭。 判据见 [十 · 规矩的边界](#十--规矩的边界)。

## 一 · 数到三

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 12.3%（挖掘器中对应「数数」族）

**骨架**｜最短的规训。三个数字，没威胁。

#### 为什么有效

它不说后果。「一」「二」之间的空白由对方自己填，而对方填进去的东西永远比任何具体威胁更有效。

这也是它的写作要点：不要写出后果是什么。 一旦写出来，紧张感就被兑现掉了。

#### 节拍链

她开始数 → 他知道要发生什么 → 「二」 → 他在「二」和「三」之间做出选择 → 通常不会数到三

#### 时间轴

全条最多就十秒，真正的戏全压在“二”和“三”之间。“一”就是开个头，“二”念完她故意停一下，那一下的安静比前面俩数加起来都扎人。一年到头“三”基本用不上，真数到三了，那意思就变了，就不是这条戏了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的语气 | 平平的。关键是不嚷 |
| 数的速度 | 慢。每个数中间都空一拍 |
| 他的反应 | 数到一还在赌 · 数到二身体已经先动了 |
| 从没数到三 | 这个设定本身就说明了他俩的关系 |
| 例外 | 有一次真数到了三，那一章得单写 |

「有一次真的数到了三」值得作为整条线的转折：规矩第一次被执行，关系才真正被测试。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 数到几 | 二 | 三（很少见，数到三肯定还有后话） |
| 场合 | 私下 | 有旁人在（他会更来劲） |
| 他的态度 | 马上听话 | 故意拖到「二点五」（就是撒娇） |
| 起因 | 他真惹事了 | 一件屁大点的事，俩人都明白是在闹着玩 |

最后一行的「两个人都知道这是游戏」，是这条从控制变成情趣的开关。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 她其实也不知道数到三要怎么办 | 数到二的时候，脑子已经空了 |
| 好的处理 | 她语气很平，听不出情绪 | 他照做了，但笑着照做的 |
| 写崩 | 写成了真吓人 | 写成了被吓住 |

「他是笑着服从的」是这一族全部条目的通用判据。有笑就是情趣。没笑，就要重新检查这段关系。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 数三声／唤他的全名／她放下茶盏的那一声 |
| 修仙 | 一道灵力压下来／她的剑出鞘半寸 |
| 星际 | 倒计时／她开口报的编号 |

#### 写崩的三种方式

1. 写出后果是什么。 空白比内容有力。
2. 让她提高音量。 平静才可怕。
3. 每次都数。 用多了就成了口头禅。

#### 示例（本库自撰，可直接改写）

> 「一。」
> 她靠在书房门框上说的，语气很平，没有提高音量。
> 键盘上的手停了。没有离开。
> 「二。」
> 停顿比上一个数字长了一些。她没有往前走，也没有看表，就站在那儿。
> 屏幕的光在他脸上跳了一下。他保存，关机，起身。
> 她从来没有数到过三。这件事两个人都知道，谁也没提过。

## 二 · 罚站

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 12.3%

**骨架**｜让他站着。剩下的全是时间和地方。

#### 节拍链

定时长 → 他站过去 → 换重心、偷看时间、听她在做什么 → 她一直在看表（没让他知道）→ 她来叫

#### 时间轴

时长就是刑期，也是唯一的内容。十五分钟的站，前五分钟他在赌气，中五分钟在放空，后五分钟在竖着耳朵听她的动静。她那边的钟也同步走：她定的十五分钟，她自己盯着表一秒没少数，两块表对着走，这条的暗结构就在这。

#### 位置的语义

| 站在哪 | 读作 |
|---|---|
| 墙角 | 最正式，最像惩罚 |
| 她视线里 | 她要看着 |
| 她视线外 | 更难受（他不知道她什么时候来） |
| 门口 | 半驱逐 |
| 她身边 | 几乎不算罚了 |

「她视线外」这一版最有效，因为惩罚的内容从「站着」变成了「等」，而等的强度不由她控制。

#### 可用细节

| 类 | 内容 |
|---|---|
| 时长 | 她说了多久 · 实际多久 · 他有没有偷偷动 |
| 他的小动作 | 换重心 · 手不知道放哪 · 偷看时间 · 听她在做什么 |
| 环境 | 她在隔壁的声音 · 空调 · 墙上的一道印子他数了很多遍 |
| 结束的方式 | 她来叫 · 时间到他自己走出来 · 她忘了（这条要单独写） |

「她忘了」是这条最疼的一版，且不需要任何恶意。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 起因 | 他确实办砸了事 | 她正烦着（这一头得让他付出点代价） |
| 时长 | 十分钟 | 她压根没想起来 |
| 他的态度 | 认罚 | 委屈归委屈，人还杵那儿 |
| 结束 | 她过来，揉了揉他脑袋 | 她过来，先甩一句「知道自己错哪儿了不」 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 罚多久合适，她其实一直在看表 | 她在干什么，她还记不记得我 |
| 好的处理 | 她一直在数时间，只是没让他知道 | 他站满了，一秒没少 |
| 写崩 | 写成真正的羞辱 | 写成毫无感觉 |

「她一直在看表」是这条的救命细节。惩罚有边界。她在控制，不在发泄。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 廊下候着／跪在阶前／她不叫起就不能起 |
| 修仙 | 阵中静立／面壁 |
| 星际 | 舱外待命／被移出通讯频道 |

古代版的「不叫起就不能起」在制度上是合法的，因此戏剧张力来源不同：罚他的是规矩不是她，她只是没有免。

#### 写崩的三种方式

1. 罚得太久。超过一小时就从情趣变成了折磨。
2. 让她真的忘了且不处理。忘了可以写，但后果必须有。
3. 写成他毫无反应地服从。那些小动作才是这条的内容。

## 三 · 没收

`G` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 12.3%

**骨架**｜她拿了他一样东西。拿走了啥，比拿走本身要紧。

#### 节拍链

她摊手 → 他迟疑 → 先做完手上那件事 → 自己交出来 → 她说明期限 → 到点归还

#### 时间轴

期限从她说出口那刻起就压在两个人头顶上。
「三天」，第一天他故意装得满不在乎，第二天开始绕着那个抽屉走，第三天到点前半小时就在客厅来回晃。
她一分钟不早、一分钟不晚地还，守时是这套规矩的信用。

#### 没收物的分级

| 物 | 力度 | 说明 |
|---|---|---|
| 手机 ✓ | 轻 | 最常见，也最像玩笑 |
| 游戏机 / 他正在看的书 | 轻 | 断掉他的注意力 |
| 车 ✓ 钥匙 ✓ | 中 | 断掉他的行动力 |
| 他的工作证 / 门禁 | 重 | 已经越界，见第十条 |
| 她自己送他的东西 | 特殊 | 收回赠予，最疼 |

最后一行最有力，也最危险。收回自己送的东西，等于撤回一次承认。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的动作 | 直接从他手里抽走 · 摊手等他自己交 · 后者更有力 |
| 他的交法 | 立刻交 · 迟疑一下 · 交之前先把手头那事弄完 |
| 保管方式 | 放他眼皮底下（更难受）· 收进抽屉 |
| 归还 | 到点就还 · 他来要 · 她主动还并说清楚为啥 |

「摊手等他自己交」比「抢过来」有力得多：让他自己交出来，是让他参与执行。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 收什么 | 玩物 | 必需品（危险，见第十条） |
| 时长 | 一晚 | 没说期限 |
| 他的反应 | 认了 | 半夜偷偷去拿（然后被抓） |
| 归还 | 到点还 | 她忘了还，他也没提 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 收多久合适 | 她把它放哪儿了 |
| 好的处理 | 她说了为啥收、收多久 | 他交了，没多问一句 |
| 写崩 | 写成想收就收 | 写成藏起来自己用 |

「说明原因和期限」是本卷所有责罚条目的通用要求。 没有期限的剥夺是控制，不是规矩。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 收了他的印／收了他的马／不许他出府 |
| 修仙 | 封了他的法器／禁了他的灵力三日 |
| 星际 | 冻结权限／收回舰载终端 |

#### 写崩的三种方式

1. 没收必需品且不还。 见第十条的判据。
2. 不说期限。 没完没了地扣着东西，这越界了。
3. 写成她随时可以拿走任何东西。 那是房东收租，不是处对象。

## 四 · 写检讨

`G` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 12.3%

**骨架**｜让他把这事写下来，写的过程比写了啥更重要。

#### 节拍链

她要求 → 他前半段敷衍 → 写着写着真想了 → 中间划掉一段 → 交上去 → 她收进抽屉

#### 时间轴

写多久，态度就写在纸上。十分钟交上来，那叫糊弄；两小时交上来，那是真写了点东西进去。中间划掉的那几行，就是她犹豫、改主意的地方。她收检讨的时候，先看纸面上划痕多不多，比看内容还快，一眼就知道这两小时她到底在干嘛。

#### 为什么好用

十条责罚里，就这条得他自己开口。站着、跪着、东西被收走，都是别人拿他怎么样；写检讨不一样，得自己把话捋顺了，那就非得真琢磨一遍不可。

而且它会产生一份物证。 那份检讨可以被保留、被翻出来、被在很久以后重读。

#### 可用细节

| 类 | 内容 |
|---|---|
| 形式 | 手写 · 限字数 · 她要检查 · 写得不行得重来 |
| 他的写法 | 前面糊弄，后面写着写着认真了 · 也有反着来的 |
| 破绽 | 后面的字越来越乱 · 中间涂掉一段 · 纸角压出了印 |
| 她的批改 | 她真改了 · 或者压根没看，就让他写 |
| 保留 | 她收进抽屉里，过了很久他翻出来还在 |

「她把它收着」是这条最好的收尾。 它把一次责罚变成了一份纪念。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的态度 | 敷衍 | 认真到写了三页 |
| 她看不看 | 认真看还批注 | 收起来没看 |
| 内容 | 就事论事 | 写着写着跑偏了（表白、控诉） |
| 后续 | 撕了 | 她留着 |

「写着写着写成了别的」是最好的拨法：被要求交代的场合，往往是他唯一敢说真话的场合。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 她要的不是他认错，是他真往心里去 | 写到第二页就不知道自己写啥了 |
| 好的处理 | 她真看了，还接了他写别的话茬 | 他写了实话 |
| 写崩 | 写成她开批斗会 | 写成他变着法儿道歉 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 抄家规／罚抄经／写请罪折子 |
| 修仙 | 抄门规／将过错刻在石上 |
| 星际 | 提交事故报告／录一段口述 |

古代版的「抄家规」多出一层：抄的是别人定下的规矩，抄一百遍就成了自己的。这个规训机制值得单独写。

#### 写崩的三种方式

1. 让她当法官。批注的语气决定这条是亲密还是审判。
2. 让他写得很漂亮。潦草、划掉、跑题，才是真的。
3. 写完就撕。留着，以后用。

## 五 · 禁足

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 12.3%

**骨架**｜不许他出门。这条比整卷其他规矩都狠。

#### 节拍链

起因 → 她说了期限与原因 → 他其实可以出去 → 他没有 → 出现必须出门的那次 → 她怎么处理

#### 时间轴

期限定的是几天，但真正考的是他每天路过门口那一下。门没锁，他一天能经过玄关八百回，每一回没走出去，都等于重新答应了一次。等到真得出门那天，肯定是被事情逼到头了：规矩和现实撞上，她当场改规矩，怎么改的，比关着他不让出门还关键。

#### 先说边界

限制人身自由是这一族里最接近越界的一条。可写，但必须满足三个条件：

| 条件 | 说明 |
|---|---|
| 有期限 | 一晚、一周，明确 |
| 有原因 | 且原因与安全相关最好（他上次出去出了事） |
| 可协商 | 他有真的必须出去的事，她会同意 |

缺任何一条，这就成了控制，不再是桥段。见 [十 · 规矩的边界](#十--规矩的边界)。

#### 可用细节

| 类 | 内容 |
|---|---|
| 执行方式 | 嘴上说好（他自觉就行）· 她拿了钥匙 ✓（已经偏重） |
| 他的遵守 | 他本来能出门，但他没去 |
| 时间的过法 | 他在家干啥 · 阳台蹲了半天 · 窗 ✓ 边 |
| 破例 | 他非得出门那回，她咋办的 |

「他其实可以出去，但他没有」是这条唯一安全的写法。 自愿遵守是关系，物理限制是囚禁。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 执行 | 嘴上说说 | 真动手（不建议，且得想清楚） |
| 时长 | 一晚上 | 一礼拜 |
| 他的态度 | 认了 | 不乐意，但照做 |
| 破例 | 她开口说算了 | 他自己坏了规矩，还主动交代 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 我是不是管太多了 | 我能走，咋还不走 |
| 好的处理 | 她早早就松了口，给了台阶 | 他守规矩，是因为自己想守 |
| 写崩 | 写成了关起来不让出门 | 写成了他啥都听别人的，自己不动脑子 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 不许出院／门房得了话／她的令牌在她手上 |
| 修仙 | 禁制／不许出洞府三日 |
| 星际 | 舱室权限限制 |

古代版有一个必须注意的问题：古代女尊的制度环境使禁足合法，这会让越界变得不易察觉。 写古代版时，越是制度允许，越要让文本本身对它有判断。

#### 写崩的三种方式

1. 物理囚禁且文本不反思。 这是本卷的红线。
2. 无期限。 见上。
3. 让他完全失去出去的意愿。 那是心理控制的表现，不是亲密。

前接：[05-占有与吃醋](05-占有与吃醋.md)

## 六 · 立规矩

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 12.3%

**骨架**｜第一条规矩是怎么来的。

#### 节拍链

一次具体的事故 → 谁提出 → 定第一条 → 她给自己也定一条 → 记在哪 → 后来第二条怎么加的

#### 时间轴

从出事到定规矩，中间得隔几天。当天别急着谈，气头上说出来的全是狠话，不是规矩。等过两天，俩人都缓过来了，谁先开口、话怎么说、她自己给自己也加一条那个动作，都得慢慢磨。立规矩这事儿，越不急，定下来的东西才真算数。

#### 规矩的三种来源

| 来源 | 性质 | 读感 |
|---|---|---|
| 她单方面宣布 | 权力 | 最直接，也最容易滑向控制 |
| 从一次具体的事故里长出来 | 协商 | 最扎实 |
| 他自己提出来的 | 请求 | 最有味道 |

第三种在这一类里最少被写，也最有价值。他主动要求一条规矩，是因为规矩能给他确定性。

#### 可用细节

| 类 | 内容 |
|---|---|
| 第一条规矩通常是 | 出门说一声 · 饭得吃 · 有事直说 · 别自己扛 |
| 注意 | 上面每条其实都是护着他 |
| 立的场合 | 吵完一架之后 · 他受了伤之后 · 睡前随口提一嘴 |
| 记录 | 写没写下来 · 记在哪儿 |
| 增补 | 第二条、第三条是怎么加上去的 |

「每一条其实都是保护他的」——这一族最核心的洞察就在这儿。
真正好的规矩，不是拿绳子捆人。被管着的那一方，心里踏实，不是觉得被卡脖子。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提的 | 她 | 他 |
| 规矩指向 | 约束他的行为 | 保护他的利益 |
| 数量 | 就一条 | 一整套（越多越要小心） |
| 双向性 | 只约束他 | 她也有要遵守的（最好） |

「她也有要遵守的」是这一族里分量最重的一个拨法。 单向规矩是管理，双向规矩是关系。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 我干嘛要管他 | 有条规矩我反倒安心 |
| 好的处理 | 她给自己也立了条规矩 | 他直接说了他想要哪条 |
| 写崩 | 写成当众宣布家规 | 写成他求着别人管他 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 家规／府规／她亲口定的一条 |
| 修仙 | 道侣契约的条款／双修的约定 |
| 星际 | 编入个人协议 |

古代女尊有现成的制度语汇（家规、府规、门规），但也因此更需要区分：沿用的旧规矩和他们两个人定的新规矩，性质完全不同。 见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。

#### 写崩的三种方式

1. 一次定十条。 一条。规矩要一条条长出来。
2. 只约束他。 双向才成立。
3. 不写规矩的来源。 来源就是这条的全部内容。

前接：[16-危机与保护 · 吵到最难看的时候](16-危机与保护.md#六--吵到最难看的时候)（大吵之后的制度化收尾是立规矩的常见起点）

## 七 · 求情

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 12.3%

**骨架**｜他求她这回算了。怎么求的，她松不松口，各占一半。

#### 节拍链

罚已定 → 他求（或不求）→ 她别开眼 → 「不行」说了两遍 → 减刑／照执行 → 给了理由

#### 时间轴

求情的窗口期很短。罚已经定了，到开始动手之间就几分钟，过了这个村就没这个店，执行到一半再喊停，没人理你，这条规矩双方心里都门儿清。她那句「不行」，第一遍是表态，第二遍声音就软了半度——这两遍中间隔的那几秒，就是这整场戏最要命的地方。

#### 求情的四种方式

| 方式 | 效果 |
|---|---|
| 讲道理 | 最没用 |
| 撒娇 | 有用，但她会说「这次不行」 |
| 认真道歉 | 通常能减刑 |
| 什么都不说，就看着她 | 最有效 |

最后一种最有效，也最难写。 它把决定权完全交给她，同时施加了最大的压力。

#### 她的四种回应

| 回应 | 读作 |
|---|---|
| 直接免了 | 规矩不重要，他重要（但会让规矩贬值） |
| 减刑 | 最常见 |
| 不准，但给了理由 | 最好的一种 |
| 不准，且不解释 | 最冷，需要后续处理 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的动作 | 拽她袖子 ✓ · 挡她前头 · 蹲下来看她 · 一直盯着 |
| 她的动作 | 别开眼（说明快撑不住了）· 停多久 |
| 破绽 | 她说了两遍「不行」（第二遍是跟自己说的） |
| 收尾 | 她松了一半 · 或者她来句「下次」 |

「她的『不行』说了两遍」是这条最好的一个细节。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他求不求 | 求 | 不求，直接认罚（更有骨气，也更让她心软） |
| 她准不准 | 准 | 不准 |
| 有没有旁人 | 私下 | 有人在（他不会求） |
| 后续 | 罚照执行 | 她自己提前叫停了 |

「不求，直接认罚」在四爱男读者那里评价最高。 顺从不等于讨饶。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 我要是免了，规矩就没了 | 我不求，我认 |
| 好的处理 | 她不准，但她说了为什么 | 他接受了，且没有怨 |
| 写崩 | 写成她铁石心肠 | 写成他哭闹求饶 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 跪下求／旁人替他求／她说「谁替他求，一起罚」 |
| 修仙 | 传音求／同门代为说情 |
| 星际 | 在公开频道申请复议 |

#### 写崩的三种方式

1. 让她每次都心软。 规矩就废了。
2. 让他跪地上哭。 那是另一种感觉，而且会把他这个人写坏。
3. 让她不准，还不给说法。 至少给个理由。

#### 可串接

前接：[二 · 罚站](#二--罚站) · [三 · 没收](#三--没收)
后接：[九 · 罚完之后](#九--罚完之后)

## 八 · 他自己认罚

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 12.3%

**骨架**｜她还没开口，他已经站过去了。

#### 为什么这条是本卷的高点

它说明规矩已经内化了：执行的人换成了他自己。

而且它把主动权交回给了他。一个自己走去墙角的人，履的是约，受的算不上罚。

#### 节拍链

他做了错事 → 她还没反应 → 他自己去了 → 她愣住 → 她的处理

#### 时间轴

他比她先动，就快那么一步，但这一步就是整条时间线的差距。从出事到他站过去，前后不到一分钟，她脸上表情都还没换过来。剩下的时间全是她的：愣三秒，走十步，开口前还犹豫了一下，全是慢动作，因为他这一步等于把主动权递回给了她。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的动作 | 自己站过去 · 把手机 ✓ 放桌上推给她 · 自己开始写 |
| 她的反应 | 愣住 · 想笑 · 心里软了一下 |
| 她的三种处理 | 照罚（认了他这份自觉）· 免了（怕他多想）· 陪他站（最好） |
| 事后 | 他问「我这样是不是有点过了」 |

「陪他站」是这条最好的处理。 她走过去和他并排站着，规矩还在，但执行方式变了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他为什么自己去 | 真的知道错了 | 想抢在她生气之前 |
| 她的处理 | 照罚 | 陪站 |
| 他的心态 | 踏实 | 忐忑（怕她不接受这个自罚） |

「怕她不接受」这个心理很值钱：自罚也是一次示好，示好就有被拒绝的风险。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她进屋看见他已经站在那儿 | 走过去的那几步 |
| 好的处理 | 她没吭声，过去站他边上 | 他没提这茬 |
| 写崩 | 写她夸个没完 | 写他装样子罚自己 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 自己跪在阶前／自己去领罚／递上写好的请罪折 |
| 修仙 | 自入思过崖 |
| 星际 | 自己提交了违规报告 |

#### 写崩的三种方式

1. 让她夸你。 一夸，自罚就成了演戏。
2. 让他回回都自罚。 罚成习惯了，这招就废了。
3. 免罚但不说为啥。 免了就得给个说法，不然规矩就散了。

## 九 · 罚完之后

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 12.3% ＋ 讨哄 54.4%

**骨架**｜惩罚完了那十分钟，比挨罚那会儿还难熬。

#### 为什么必须写

在权力交换的故事里，这一段有专门的说法。作用是让两个人从“办事”状态切回“过日子”状态：确认对方没事、确认关系没伤着、确认刚才那事儿俩人都认。

跳过这一段，前面所有的责罚都会显得冷。 这是整族里最不能省的一条。

#### 节拍链

结束 → 她过来 → 身体接触 → 确认 → 回到日常

#### 时间轴

规定动作结束后的十分钟，才是自由发挥。惩罚有时长，修复没有：她什么时候过来——立刻来是心疼，晚五分钟来是给彼此台阶——先碰哪儿后碰哪儿，那句确认的话挑在第几分钟说，全看两个人当时的状态。十分钟内把气氛拉回日常，就算安全落地。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的第一个动作 | 摸头 · 拉他手 ✓ · 直接抱住 · 递水 |
| 确认的话 | 「腿麻不麻」（不提错，只问身体）· 「过来」 |
| 他的反应 | 绷了好久的肩膀松下来 · 突然抱得很紧 · 一声不吭 |
| 回到日常的信号 | 她随口说了句别的（今晚吃啥） |
| 有些作品会有的 | 回头聊：为啥罚、他咋想、下回咋办 |

「她说了一件完全无关的事」是最好的收束。 惩罚结束的标志是恢复日常，原谅不算。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的方式 | 直接抱 | 先谈，再抱 |
| 他的反应 | 立刻缓过来 | 需要很久 |
| 有没有复盘 | 有 | 没有，直接翻篇 |
| 谁先说话 | 她 | 他（「我知道错哪了」） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 我刚才是不是太过了 | 她还是过来了 |
| 好的处理 | 她先顾他的伤，再顾别的事 | 他抱得很紧，但没掉眼泪 |
| 写崩 | 写成她拍拍屁股就走 | 写成他马上撒娇要哄 |

「她若无其事离开」是这一族里最严重的写崩。 罚完不管，会让整段关系显得是单向的支配。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 叫起／亲自扶／赐座／让他坐到身边 |
| 修仙 | 撤了禁制／渡一道灵力 |
| 星际 | 恢复权限／把他调回原岗位 |

古代版的重心全在「亲自扶」这一个动作上：罚是制度，扶是人。

#### 写崩的三种方式

1. 这一段可以直接跳过。全族上下就这一条不能省。
2. 亲密关系要立刻升级。收束不是给甜头。
3. 让她光讲道理，别提身体。先问她腿麻不麻，再聊别的。

## 十 · 规矩的边界

<!-- gb-nonscene -->
`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 本条是本卷的判据，不列为桥段

**骨架**｜什么时候规矩变成了控制。

#### 判据表

| 维度 | 是规矩 | 是控制 |
|---|---|---|
| 来源 | 两个人商量出来的 | 一个人硬塞给你的 |
| 期限 | 说好多久就多久 | 没个头 |
| 可协商 | 能通融、能改 | 说一不二 |
| 范围 | 就事论事 | 管你交朋友、花多少钱、出门干啥 |
| 目的 | 想让日子过得稳 | 想让对方听自己的 |
| 收束 | 罚完还能好好过 | 罚完就翻篇了 |
| 他的状态 | 会笑、会求情、会顶嘴 | 不敢、不会、没有了 |

最后一行是最可靠的单一判据。 一个还会顶嘴的人是在关系里，一个不再顶嘴的人已经不在了。

#### 写作上怎么用

素材库不回避控制叙事，但要区分它、标注它。

| 可以写 | 要求 |
|---|---|
| 越界的规矩 | 文本要能被看出对它有判断 |
| 支配欲失控 | 后面要有代价，或者清醒的反抗 |
| 他真的不敢顶嘴了 | 这个变化要被某个人看见 |

让越界毫无后果地被奖赏，才是真正的问题。 写一个越界的角色不是问题，把越界当成深情来展示才是。

#### 与 06 卷的分层

| | 本卷 | [06-尺度与写法](../06-尺度与写法/) |
|---|---|---|
| 烈度 | 日常小打小闹 | 训诫／BDSM 专论 |
| 内容 | 罚站、没收、写检讨 | 正经的权力交换玩法 |
| 身体伤害 | 没有 | 按那卷的规矩来 |
| 安全框架 | 这页开头说了 | 那卷讲得更细 |

两卷共享同一套底线：SSC、RACK、PRICK，全员成年，虚构与现实分开。

#### 再说一次虚构与现实

本卷聊的全是**怎么写故事**。小说里的规矩和责罚，是作者说了算的幻想设定，跟现实里怎么处关系是两码事。现实里真要搞权力交换那套，得事先说好、有安全词、随时能喊停，双方都得清楚自己在冒什么险。**这卷不是教你在现实里怎么玩的。**

如果在现实关系中感到自己的行动自由、社交联系或经济自主受到限制，那不是这里讨论的任何一种东西。

#### 可串接

本条不独立成场，是本卷全部条目的判据附注。
