## 安全框架（本卷统一说明，先读这一节）

本卷收录的是**日常低烈度**的规矩与责罚：罚站、没收、禁足、写检讨、数到三。它与 [06-尺度与写法](../06-尺度与写法/) 的训诫／BDSM 专论是两层东西，但两层共享同一套底线，所以框架在这里也要写全。

### 三条社群共识

| 缩写 | 全称 | 含义 |
|---|---|---|
| SSC | Safe, Sane, Consensual | 安全、理智、双方同意 |
| RACK | Risk-Aware Consensual Kink | 知晓风险的前提下双方同意 |
| PRICK | Personal Responsibility, Informed Consensual Kink | 个人责任前提下的知情同意 |

三者是社群在不同年代提出的框架，共同点是**同意必须是知情的、可撤回的、由具备判断能力的成年人做出的**。

### 虚构与现实的分界

小说里的规矩与责罚是**幻想装置**：它服务于关系张力的表达，运行在一个由作者控制的、后果可控的世界里。**它不是现实指南。** 现实中的任何权力交换关系都需要事前协商、安全词、可随时中止的机制，以及双方对风险的真实认知。

本卷不提供任何可复现的实施细节，只讨论叙事结构。

### 本卷的三条硬边界

| 边界 | 说明 |
|---|---|
| 全员成年 | 所有涉及规矩与责罚的角色均为成年人 |
| 不写伤害 | 本卷的责罚不造成身体伤害。带伤的走 [06-尺度与写法](../06-尺度与写法/) |
| 规矩要有来源 | 凭空立规矩是控制，双方形成的规矩才是关系 |

第三条是本卷与控制叙事的分水岭。 判据见 [十 · 规矩的边界](#十--规矩的边界)。

## 一 · 数到三

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 12.3%（挖掘器中对应「数数」族）

**骨架**｜最短的规训。三个数字，没有威胁内容。

#### 为什么有效

它不说后果。「一」「二」之间的空白由对方自己填，而对方填进去的东西永远比任何具体威胁更有效。

这也是它的写作要点：不要写出后果是什么。 一旦写出来，紧张感就被兑现掉了。

#### 节拍链

她开始数 → 他知道要发生什么 → 「二」 → 他在「二」和「三」之间做出选择 → 通常不会数到三

#### 时间轴

全条的时长封顶十秒，重量全压在「二」与「三」之间。 「一」是程序启动，「二」之后的停顿她刻意拉长，那一秒的静默比两个数字加起来都响。数到三的情况一年不超过一次，数到了，就是另一条戏了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的语气 | 平的。不提高音量是关键 |
| 数的速度 | 慢。每个数字之间的停顿长于必要 |
| 他的反应 | 在「一」时还在赌 · 在「二」时身体先动了 |
| 从没数到三 | 这个设定本身就是关系的说明 |
| 例外 | 有一次真的数到了三，那一章要单独写 |

「有一次真的数到了三」值得作为整条线的转折：规矩第一次被执行，关系才真正被测试。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 数到几 | 二 | 三（罕见，且要有后续） |
| 场合 | 私下 | 有人在（他会更快） |
| 他的态度 | 立刻服从 | 故意拖到「二点五」（撒娇的一种） |
| 起因 | 他真的做错了 | 一件很小的事，两个人都知道这是游戏 |

最后一行的「两个人都知道这是游戏」，是这条从控制变成情趣的开关。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 她其实也不知道数到三要怎么办 | 在「二」的时候脑子是空的 |
| 好的处理 | 她的语气平静，没有情绪 | 他服从了，但他是笑着服从的 |
| 写崩 | 写成真正的威慑 | 写成恐惧反应 |

「他是笑着服从的」是这一族全部条目的通用判据。有笑就是情趣。没笑，就要重新检查这段关系。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 数三声／唤他的全名／她放下茶盏的那一声 |
| 修仙 | 一道灵力压下来／她的剑出鞘半寸 |
| 星际 | 倒计时／她开口报的编号 |

#### 写崩的三种方式

1. 写出后果是什么。 空白比内容有力。
2. 让她提高音量。 平静才可怕。
3. 每次都数。 用多了就成了口头禅。

#### 示例（本库自撰，可直接改写）

> 「一。」
> 她靠在书房门框上说的，语气很平，没有提高音量。
> 键盘上的手停了。没有离开。
> 「二。」
> 停顿比上一个数字长了一些。她没有往前走，也没有看表，就站在那儿。
> 屏幕的光在他脸上跳了一下。他保存，关机，起身。
> 她从来没有数到过三。这件事两个人都知道，谁也没提过。

## 二 · 罚站

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 12.3%

**骨架**｜让他站着。全部的内容是时间和位置。

#### 节拍链

定时长 → 他站过去 → 换重心、偷看时间、听她在做什么 → 她一直在看表（没让他知道）→ 她来叫

#### 时间轴

时长是刑期，也是唯一的内容。 十五分钟的站，前五分钟他在赌气，中五分钟在放空，后五分钟在竖着耳朵听她的动静。她那边的钟同步走：她定的十五分钟，她自己盯着表一秒没少数，两块表对着走，是这条的暗结构。

#### 位置的语义

| 站在哪 | 读作 |
|---|---|
| 墙角 | 最正式，最像惩罚 |
| 她视线里 | 她要看着 |
| 她视线外 | 更难受（他不知道她什么时候来） |
| 门口 | 半驱逐 |
| 她身边 | 几乎不算罚了 |

「她视线外」这一版最有效，因为惩罚的内容从「站着」变成了「等」，而等的强度不由她控制。

#### 可用细节

| 类 | 内容 |
|---|---|
| 时长 | 她说了多久 · 实际多久 · 他有没有偷偷动 |
| 他的小动作 | 换重心 · 手不知道放哪 · 偷看时间 · 听她在做什么 |
| 环境 | 她在隔壁的声音 · 空调 · 墙上的一道印子他数了很多遍 |
| 结束的方式 | 她来叫 · 时间到他自己走出来 · 她忘了（这条要单独写） |

「她忘了」是这条最疼的一版，且不需要任何恶意。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 起因 | 他确实做错了 | 她心情不好（这一端要有代价） |
| 时长 | 十分钟 | 她忘了 |
| 他的态度 | 认罚 | 委屈但站着 |
| 结束 | 她来了，摸摸头 | 她来了，先问「知道错哪了吗」 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 罚多久合适，她其实一直在看表 | 她在干什么，她还记不记得我 |
| 好的处理 | 她一直在数时间，只是没让他知道 | 他站满了，一秒没少 |
| 写崩 | 写成真正的羞辱 | 写成毫无感觉 |

「她一直在看表」是这条的救命细节。惩罚有边界。她在控制，不在发泄。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 廊下候着／跪在阶前／她不叫起就不能起 |
| 修仙 | 阵中静立／面壁 |
| 星际 | 舱外待命／被移出通讯频道 |

古代版的「不叫起就不能起」在制度上是合法的，因此戏剧张力来源不同：罚他的是规矩不是她，她只是没有免。

#### 写崩的三种方式

1. 罚得太久。 超过一小时就从情趣变成了折磨。
2. 让她真的忘了且不处理。 忘了可以写，但后果必须有。
3. 写成他毫无反应地服从。 那些小动作才是这条的内容。

## 三 · 没收

`G` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 12.3%

**骨架**｜她拿走了他的某样东西。拿走什么，比拿走这件事重要。

#### 节拍链

她摊手 → 他迟疑 → 先做完手上那件事 → 自己交出来 → 她说明期限 → 到点归还

#### 时间轴

期限从她说出口那刻起挂在两个人头上。 「三天」，第一天他故意表现得毫不在乎，第二天开始绕着那个抽屉走，第三天到点前半小时就在客厅晃。她一分钟不早、一分钟不晚地还，守时是这套规矩的信用。

#### 没收物的分级

| 物 | 力度 | 说明 |
|---|---|---|
| 手机 ✓ | 轻 | 最常见，也最像玩笑 |
| 游戏机 / 他正在看的书 | 轻 | 断掉他的注意力 |
| 车 ✓ 钥匙 ✓ | 中 | 断掉他的行动力 |
| 他的工作证 / 门禁 | 重 | 已经越界，见第十条 |
| 她自己送他的东西 | 特殊 | 收回赠予，最疼 |

最后一行最有力，也最危险。收回自己送的东西，等于撤回一次承认。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的动作 | 直接从他手里抽走 · 摊手等他自己交 · 后者更有力 |
| 他的交法 | 立刻交 · 迟疑一下 · 交之前先做完手上那件事 |
| 保管方式 | 放在他看得见的地方（更难受）· 收进抽屉 |
| 归还 | 时间到就还 · 他来要 · 她主动还并说明理由 |

「摊手等他自己交」比「抢过来」有力得多：让他自己交出来，是让他参与执行。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 收什么 | 玩物 | 必需品（危险，见第十条） |
| 时长 | 一晚 | 没说期限 |
| 他的反应 | 认了 | 半夜偷偷去拿（然后被抓） |
| 归还 | 到点还 | 她忘了还，他也没提 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 收多久合适 | 她把它放在哪儿了 |
| 好的处理 | 她说明了原因和期限 | 他交了，没有讨价还价 |
| 写崩 | 写成随意剥夺 | 写成偷偷藏起备用机 |

「说明原因和期限」是本卷所有责罚条目的通用要求。 没有期限的剥夺是控制，不是规矩。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 收了他的印／收了他的马／不许他出府 |
| 修仙 | 封了他的法器／禁了他的灵力三日 |
| 星际 | 冻结权限／收回舰载终端 |

#### 写崩的三种方式

1. 没收必需品且不还。 见第十条的判据。
2. 不说期限。 无期限的剥夺越界。
3. 写成她随时可以拿走任何东西。 那是财产关系不是亲密关系。

## 四 · 写检讨

`G` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 12.3%

**骨架**｜让他把事情写下来。写的过程比写的内容重要。

#### 节拍链

她要求 → 他前半段敷衍 → 写着写着真想了 → 中间划掉一段 → 交上去 → 她收进抽屉

#### 时间轴

写的时长出卖态度。 十分钟交卷的是敷衍，两小时交卷的写进去了真东西，中途那段划掉的，就是转折发生的时刻。她收检讨时扫一眼页面上的划痕密度，比读内容更快判断出这两小时怎么过的。

#### 为什么好用

十条责罚里只有这一条要求他表述。站着、跪着、被没收，都是被动的；写检讨要他自己组织语言，于是他必须真的想一遍。

而且它会产生一份物证。 那份检讨可以被保留、被翻出来、被在很久以后重读。

#### 可用细节

| 类 | 内容 |
|---|---|
| 形式 | 手写 · 字数要求 · 她要看 · 不合格要重写 |
| 他的写法 | 前半段敷衍，后半段写着写着真的想了 · 或者反过来 |
| 破绽 | 字迹后半变潦草 · 中间划掉了一段 · 边角有折痕 |
| 她的批改 | 她真的批了 · 或者她根本没看，只是要他写 |
| 保留 | 她把它收进抽屉，很久以后他发现还在 |

「她把它收着」是这条最好的收尾。 它把一次责罚变成了一份纪念。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的态度 | 敷衍 | 认真到写了三页 |
| 她看不看 | 认真看并批注 | 收起来没看 |
| 内容 | 就事论事 | 写着写着写成了别的（表白、控诉） |
| 后续 | 撕了 | 她留着 |

「写着写着写成了别的」是最好的拨法：被要求交代的场合，往往是他唯一敢说真话的场合。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 她想要的不是道歉，是他真的想过 | 写到第二页时不知道在写什么了 |
| 好的处理 | 她认真读了，且回应了他写的别的部分 | 他写了真话 |
| 写崩 | 写成她审判 | 写成他花式认错 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 抄家规／罚抄经／写请罪折子 |
| 修仙 | 抄门规／将过错刻在石上 |
| 星际 | 提交事故报告／录一段口述 |

古代版的「抄家规」多出一层：抄的是别人定下的规矩，抄一百遍就成了自己的。这个规训机制值得单独写。

#### 写崩的三种方式

1. 让她当法官。 批注的语气决定这条是亲密还是审判。
2. 让他写得很漂亮。 潦草、划掉、跑题，才是真的。
3. 写完就撕。 留着，以后用。

## 五 · 禁足

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 12.3%

**骨架**｜不许他出门。这条的危险度高于本卷其余各条。

#### 节拍链

起因 → 她说了期限与原因 → 他其实可以出去 → 他没有 → 出现必须出门的那次 → 她怎么处理

#### 时间轴

期限定了几天，考验的却是每一个「可以出去」的时刻。 门没锁，他每天路过玄关无数次，每一次不出去都是重新签一遍同意。必须出门的那次是期限内的突发事件：规矩撞上现实，她当场修法，修法的过程比禁足本身重要。

#### 先说边界

限制人身自由是这一族里最接近越界的一条。可写，但必须满足三个条件：

| 条件 | 说明 |
|---|---|
| 有期限 | 一晚、一周，明确 |
| 有原因 | 且原因与安全相关最好（他上次出去出了事） |
| 可协商 | 他有真的必须出去的事，她会同意 |

缺任何一条，这就成了控制，不再是桥段。见 [十 · 规矩的边界](#十--规矩的边界)。

#### 可用细节

| 类 | 内容 |
|---|---|
| 执行方式 | 口头约定（他自己遵守，最好）· 她收了钥匙 ✓（已经偏重） |
| 他的遵守 | 他其实可以出去，但他没有 |
| 时间的过法 | 他在家做了什么 · 阳台待了很久 · 窗 ✓ 边 |
| 破例 | 他必须出去的那次，她怎么处理 |

「他其实可以出去，但他没有」是这条唯一安全的写法。 自愿遵守是关系，物理限制是囚禁。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 执行 | 口头约定 | 物理限制（不建议，且必须有反思） |
| 时长 | 一晚 | 一周 |
| 他的态度 | 认了 | 抗议但遵守 |
| 破例 | 她主动免了 | 他自己破了例，然后主动说 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 我是不是管太宽了 | 我可以走，我为什么不走 |
| 好的处理 | 她提前给了破例的口子 | 他遵守是因为他愿意 |
| 写崩 | 写成软禁 | 写成他失去自主判断 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 不许出院／门房得了话／她的令牌在她手上 |
| 修仙 | 禁制／不许出洞府三日 |
| 星际 | 舱室权限限制 |

古代版有一个必须注意的问题：古代女尊的制度环境使禁足合法，这会让越界变得不易察觉。 写古代版时，越是制度允许，越要让文本本身对它有判断。

#### 写崩的三种方式

1. 物理囚禁且文本不反思。 这是本卷的红线。
2. 无期限。 见上。
3. 让他完全失去出去的意愿。 那是心理控制的表现，不是亲密。

#### 可串接

前接：[05-占有与吃醋](05-占有与吃醋.md)
后接：[十 · 规矩的边界](#十--规矩的边界)

## 六 · 立规矩

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 12.3%

**骨架**｜第一条规矩是怎么来的。

#### 节拍链

一次具体的事故 → 谁提出 → 定第一条 → 她给自己也定一条 → 记在哪 → 后来第二条怎么加的

#### 时间轴

从事故到成文，隔一次冷静期。 当天不立规矩，气头上立的是惩罚不是制度。隔了两天，两个人都平静了，谁先提起，条文怎么措辞，她给自己也加一条的那一笔，都要慢慢来。立法过程的节奏越慢，规矩越像规矩。

#### 规矩的三种来源

| 来源 | 性质 | 读感 |
|---|---|---|
| 她单方面宣布 | 权力 | 最直接，也最容易滑向控制 |
| 从一次具体的事故里长出来 | 协商 | 最扎实 |
| 他自己提出来的 | 请求 | 最有味道 |

第三种在这一类里最少被写，也最有价值。他主动要求一条规矩，是因为规矩能给他确定性。

#### 可用细节

| 类 | 内容 |
|---|---|
| 第一条规矩通常是 | 出门要说一声 · 不许不吃饭 · 有事直接讲 · 不许自己扛 |
| 注意 | 上面每一条其实都是保护他的 |
| 立的场合 | 一次冲突之后 · 一次他受伤之后 · 睡前随口 |
| 记录 | 有没有写下来 · 记在哪 |
| 增补 | 第二条、第三条是怎么加的 |

「每一条其实都是保护他的」是这一族的关键洞察。 好的规矩系统里，被约束的一方获得的是安全感而不是限制。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提的 | 她 | 他 |
| 规矩指向 | 约束他的行为 | 保护他的利益 |
| 数量 | 就一条 | 一整套（越多越要小心） |
| 双向性 | 只约束他 | 她也有要遵守的（最好） |

「她也有要遵守的」是这一族里分量最重的一个拨法。 单向规矩是管理，双向规矩是关系。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 我凭什么给他定规矩 | 有规矩我反而踏实 |
| 好的处理 | 她给自己也定了一条 | 他提出了他要的那条 |
| 写崩 | 写成家规颁布 | 写成他求约束 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 家规／府规／她亲口定的一条 |
| 修仙 | 道侣契约的条款／双修的约定 |
| 星际 | 编入个人协议 |

古代女尊有现成的制度语汇（家规、府规、门规），但也因此更需要区分：沿用的旧规矩和他们两个人定的新规矩，性质完全不同。 见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。

#### 写崩的三种方式

1. 一次定十条。 一条。规矩要一条条长出来。
2. 只约束他。 双向才成立。
3. 不写规矩的来源。 来源就是这条的全部内容。

前接：[16-危机与保护 · 吵到最难看的时候](16-危机与保护.md#六--吵到最难看的时候)（大吵之后的制度化收尾是立规矩的常见起点）
后接：本卷全部条目（规矩是它们的前提）

## 七 · 求情

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 12.3%

**骨架**｜他求她免了这次。求的方式，和她准不准，各是一半内容。

#### 节拍链

罚已定 → 他求（或不求）→ 她别开眼 → 「不行」说了两遍 → 减刑／照执行 → 给了理由

#### 时间轴

求情的窗口期很短。 罚已定到开始执行之间只有几分钟，过时不候，执行中途求情不受理，这是双方都懂的程序。她的「不行」说第一遍是立场，说第二遍时声音软了半度：两遍之间隔的那几秒，就是这条的全部戏眼。

#### 求情的四种方式

| 方式 | 效果 |
|---|---|
| 讲道理 | 最没用 |
| 撒娇 | 有用，但她会说「这次不行」 |
| 认真道歉 | 通常能减刑 |
| 什么都不说，就看着她 | 最有效 |

最后一种最有效，也最难写。 它把决定权完全交给她，同时施加了最大的压力。

#### 她的四种回应

| 回应 | 读作 |
|---|---|
| 直接免了 | 规矩不重要，他重要（但会让规矩贬值） |
| 减刑 | 最常见 |
| 不准，但给了理由 | 最好的一种 |
| 不准，且不解释 | 最冷，需要后续处理 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的动作 | 拽她的袖子 ✓ · 挡在她面前 · 蹲下来平视 · 一直看着她 |
| 她的动作 | 别开眼（说明快撑不住了）· 停顿的时长 |
| 破绽 | 她的「不行」说了两遍（第二遍是说给自己听的） |
| 收尾 | 她减了一半 · 或者她说「下次」 |

「她的『不行』说了两遍」是这条最好的一个细节。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他求不求 | 求 | 不求，直接认罚（更有骨气，也更让她心软） |
| 她准不准 | 准 | 不准 |
| 有没有旁人 | 私下 | 有人在（他不会求） |
| 后续 | 罚照执行 | 她自己提前叫停了 |

「不求，直接认罚」在四爱男读者那里评价最高。 顺从不等于讨饶。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 我要是免了，规矩就没了 | 我不求，我认 |
| 好的处理 | 她不准，但她说了为什么 | 他接受了，且没有怨 |
| 写崩 | 写成她铁石心肠 | 写成他哭闹求饶 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 跪下求／旁人替他求／她说「谁替他求，一起罚」 |
| 修仙 | 传音求／同门代为说情 |
| 星际 | 在公开频道申请复议 |

#### 写崩的三种方式

1. 让她每次都心软。 规矩会贬值。
2. 让他跪地哭求。 那是另一种质感，且会损伤他的人物。
3. 让她不准且不解释。 至少给一个理由。

#### 可串接

前接：[二 · 罚站](#二--罚站) · [三 · 没收](#三--没收)
后接：[九 · 罚完之后](#九--罚完之后)

## 八 · 他自己认罚

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 12.3%

**骨架**｜她还没说什么，他已经站到那儿去了。

#### 为什么这条是本卷的高点

它说明规矩已经内化了：执行的人换成了他自己。

而且它把主动权交回给了他。一个自己走去墙角的人，履的是约，受的算不上罚。

#### 节拍链

他做了错事 → 她还没反应 → 他自己去了 → 她愣住 → 她的处理

#### 时间轴

他比她的反应快了一步，这「一步」就是全条的时间差。 事故发生到他站过去，中间不超过一分钟，她连表情都还没换完。之后的时间归她：她愣住三秒、走过去十步、开口前又斟酌了一下，全程慢镜头，因为主动权被他这一步交还给了她。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的动作 | 自己站过去 · 把手机 ✓ 放在桌上推给她 · 自己开始写 |
| 她的反应 | 愣住 · 想笑 · 心里那一下软 |
| 她的三种处理 | 照罚（承认他的自觉）· 免了（可能会让他不安）· 陪他站（最好） |
| 事后 | 他问「这样算不算过了」 |

「陪他站」是这条最好的处理。 她走过去和他并排站着，规矩还在，但执行方式变了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他为什么自己去 | 真的知道错了 | 想抢在她生气之前 |
| 她的处理 | 照罚 | 陪站 |
| 他的心态 | 踏实 | 忐忑（怕她不接受这个自罚） |

「怕她不接受」这个心理很值钱：自罚也是一次示好，示好就有被拒绝的风险。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她进屋看见他已经站在那儿 | 走过去的那几步 |
| 好的处理 | 她什么也没说，走过去站在旁边 | 他没有邀功 |
| 写崩 | 写成她大加赞赏 | 写成他表演式自罚 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 自己跪在阶前／自己去领罚／递上写好的请罪折 |
| 修仙 | 自入思过崖 |
| 星际 | 自己提交了违规报告 |

#### 写崩的三种方式

1. 让她大加赞赏。 赞赏会让自罚变成表演。
2. 让他每次都自罚。 变成条件反射就不对了。
3. 免了且不说明。 免了要给理由，否则规矩会松。

## 九 · 罚完之后

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 12.3% ＋ 讨哄 54.4%

**骨架**｜惩罚结束之后的那十分钟，比惩罚本身重要。

#### 为什么必须写

在权力交换的叙事里，这一段有专门的名字。它的功能是把关系从执行模式切回日常模式：确认双方都还好、确认关系没有受损、确认刚才发生的事在双方的共识之内。

跳过这一段，前面所有的责罚都会显得冷。 这是整族里最不能省的一条。

#### 节拍链

结束 → 她过来 → 身体接触 → 确认 → 回到日常

#### 时间轴

规定动作结束后的十分钟，才是自由发挥。 惩罚有时长，修复没有：她过来的时机（立刻来是心疼，晚五分钟来是给彼此台阶）、接触的顺序（先碰肩再揉头）、那句确认的话挑在第几分钟说，全由两个人现场拿捏。十分钟内完成回到日常的软着陆。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的第一个动作 | 摸头 · 拉他手 ✓ · 直接抱住 · 递水 |
| 确认的话 | 「腿麻不麻」（不谈错误，只谈身体）· 「过来」 |
| 他的反应 | 绷了很久的肩膀塌下来 · 突然抱得很紧 · 什么都不说 |
| 回到日常的信号 | 她说了一件完全无关的事（今晚吃什么） |
| 有些作品会有的 | 复盘：为什么罚、他怎么想的、下次怎么办 |

「她说了一件完全无关的事」是最好的收束。 惩罚结束的标志是恢复日常，原谅不算。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的方式 | 直接抱 | 先谈，再抱 |
| 他的反应 | 立刻缓过来 | 需要很久 |
| 有没有复盘 | 有 | 没有，直接翻篇 |
| 谁先说话 | 她 | 他（「我知道错哪了」） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 我刚才是不是过了 | 她还是过来了 |
| 好的处理 | 她先处理他的身体，再处理事情 | 他抱得很紧，但他没哭 |
| 写崩 | 写成她若无其事离开 | 写成他立刻撒娇邀宠 |

「她若无其事离开」是这一族里最严重的写崩。 罚完不管，会让整段关系显得是单向的支配。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 叫起／亲自扶／赐座／让他坐到身边 |
| 修仙 | 撤了禁制／渡一道灵力 |
| 星际 | 恢复权限／把他调回原岗位 |

古代版的重心全在「亲自扶」这一个动作上：罚是制度，扶是人。

#### 写崩的三种方式

1. 跳过这一段。 整族里唯一不能省的一条。
2. 写成立刻的亲密升级。 收束不是奖励。
3. 让她只谈道理不谈身体。 先问腿麻不麻，再谈别的。

## 十 · 规矩的边界

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 本条是本卷的判据，不列为桥段

**骨架**｜什么时候规矩变成了控制。

#### 判据表

| 维度 | 是规矩 | 是控制 |
|---|---|---|
| 来源 | 双方形成 | 单方强加 |
| 期限 | 明确 | 无限期 |
| 可协商 | 有例外机制 | 不容置疑 |
| 范围 | 具体行为 | 人身自由、社交、经济 |
| 目的 | 关系的稳定 | 一方的支配 |
| 收束 | 罚完有恢复 | 罚完就结束 |
| 他的状态 | 会笑、会求情、会顶嘴 | 不敢、不会、没有了 |

最后一行是最可靠的单一判据。 一个还会顶嘴的人是在关系里，一个不再顶嘴的人已经不在了。

#### 写作上怎么用

素材库不回避控制叙事，但要区分它、标注它。

| 可以写 | 要求 |
|---|---|
| 越界的规矩 | 文本要能被看出对它有判断 |
| 支配欲失控 | 后面要有代价，或者清醒的反抗 |
| 他真的不敢顶嘴了 | 这个变化要被某个人看见 |

让越界毫无后果地被奖赏，才是真正的问题。 写一个越界的角色不是问题，把越界当成深情来展示才是。

#### 与 06 卷的分层

| | 本卷 | [06-尺度与写法](../06-尺度与写法/) |
|---|---|---|
| 烈度 | 日常低烈度 | 训诫／BDSM 专论 |
| 内容 | 罚站、没收、写检讨 | 完整的权力交换实践 |
| 身体伤害 | 无 | 按那一卷的框架处理 |
| 安全框架 | 本页开头已列 | 该卷有更完整的说明 |

两卷共享同一套底线：SSC、RACK、PRICK，全员成年，虚构与现实分开。

#### 再说一次虚构与现实

本卷讨论的全部是**叙事技法**。小说里的规矩与责罚是幻想装置，运行在作者控制的世界里。现实中的权力交换关系需要事前协商、安全词、可随时中止的机制，以及双方对风险的真实认知。**本卷不是现实实践指南。**

如果在现实关系中感到自己的行动自由、社交联系或经济自主受到限制，那不是这里讨论的任何一种东西。

#### 可串接

本条不独立成场，是本卷全部条目的判据附注。
