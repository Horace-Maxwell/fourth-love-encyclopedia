## 安全框架（本卷统一说明，先读这一节）

罚站、没收、禁足、写检讨、数到三——这类**日常小打小闹**的规矩和罚法，跟 [06-尺度与写法](../06-尺度与写法/) 里聊的训诫／BDSM 不是一回事。可底线上头，两边共用一套，所以该讲的框架，这一卷也得讲全。

### 三条社群共识

| 缩写 | 全称 | 含义 |
|---|---|---|
| SSC | Safe, Sane, Consensual | 安全、理智、双方同意 |
| RACK | Risk-Aware Consensual Kink | 知晓风险的前提下双方同意 |
| PRICK | Personal Responsibility, Informed Consensual Kink | 个人责任前提下的知情同意 |

这三个框架是社群在不同年代提出来的，共同的一点是：**同意必须是知情的、可撤回的，而且得由具备判断能力的成年人来做。**

### 虚构与现实的分界

小说里的规矩和责罚，说白了就是个**幻想工具**——用来写关系里的拉扯感，整个世界攥在作者手里，出事也能兜住。**别拿它当现实操作手册。** 现实里真要搞权力交换那套，得提前说好底线、定好安全词、随时能喊停，双方都得清楚自己冒多大险。

本卷不提供任何可复现的实施细节，只讨论叙事结构。

### 本卷的三条硬边界

| 边界 | 说明 |
|---|---|
| 全员成年 | 沾规矩和责罚的角色都得是成年人 |
| 不写伤害 | 这卷里责罚不弄伤人。写伤的去 [06-尺度与写法](../06-尺度与写法/) |
| 规矩要有来源 | 单方面定规矩叫拿捏人，两边一起认的才算关系 |

本卷和控制叙事就在第三条上分开。怎么判断，见 [十 · 规矩的边界](#十--规矩的边界)。

## 一 · 数到三

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 15.0%（挖掘器中对应「数数」族）

**骨架**｜她只数「一」「二」，数到三会怎样，不说。

#### 为什么有效

后果她不说。「一」「二」中间那段空白留给他自己去填，他自己想出来的，往往比说出口的后果更吓人。

所以别把后果写出来。 一写出来，就不紧张了。

#### 节拍链

她开始数 → 他知道要发生什么 → 「二」 → 他在「二」和「三」之间做出选择 → 通常不会数到三

#### 时间轴

从头到尾最多十秒，要紧的是「二」和「三」中间那一下。真数到三，事情就变了味，所以“三”一年到头也用不上几回。她念完“二”故意停住，那阵安静比前两个数加起来还扎人。“一”只管起个头。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的语气 | 平平的，要紧的是不嚷 |
| 数的速度 | 慢。每个数中间都空一拍 |
| 他的反应 | 数到一还在赌 · 数到二身体已经先动了 |
| 从没数到三 | 光这一点，就看得出他俩是什么关系 |
| 例外 | 有一次真数到了三，那一章得单写 |

「有一次真数到了三」能当整条线的转折：规矩头一回真的执行，这段关系才算真正经受考验。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 数到几 | 二 | 三，很少见，数到三肯定还有后话 |
| 场合 | 私下 | 有旁人在，他会更来劲 |
| 他的态度 | 马上听话 | 故意拖到「二点五」，就是撒娇 |
| 起因 | 他真惹事了 | 一件屁大点的事，俩人都明白是在闹着玩 |

最后一行写的「俩人都明白是在闹着玩」，有这一层，就算情趣，不算控制。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 她其实也不知道数到三要怎么办 | 数到二的时候，脑子已经空了 |
| 好的处理 | 她语气很平，听不出情绪 | 他照做了，但笑着照做的 |
| 写崩 | 写成了真吓人 | 写成了被吓住 |

这一族每一条，都可以拿「他照做了，但笑着照做的」来对一对：他笑着，就是情趣。他没笑，这段关系就得重新看看。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 数三声／唤他的全名／她放下茶盏的那一声 |
| 修仙 | 一道灵力压下来／她的剑出鞘半寸 |
| 星际 | 倒计时／她开口报的编号 |

#### 写崩的三种方式

1. 把后果写出来。 留白比写满更有力。
2. 让她提高音量。 平静才可怕。
3. 回回都数。 数多了就成了口头禅。

#### 示例（本库自撰，可直接改写）

> 「一。」
> 她靠在书房门框上说的，语气很平，没有提高音量。
> 键盘上的手停了。没有离开。
> 「二。」
> 停顿比上一个数字长了一些。她没有往前走，也没有看表，就站在那儿。
> 屏幕的光在他脸上跳了一下。他保存，关机，起身。
> 她从来没有数到过三。这件事两个人都知道，谁也没提过。

## 二 · 罚站

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 15.0%

**骨架**｜叫他站着。剩下要写的只有多久、在哪。

#### 节拍链

定时长 → 他站过去 → 换重心、偷看时间、听她在做什么 → 她一直在看表（没让他知道）→ 她来叫

#### 时间轴

十五分钟是她定的，也是她自己数的，她盯着表，一秒都没少。他那边也在数，两块表一起走。头五分钟他在赌气，中间五分钟发呆，最后五分钟竖着耳朵听她那边有什么动静。

#### 位置的语义

| 站在哪 | 读作 |
|---|---|
| 墙角 | 最正式，最像惩罚 |
| 她视线里 | 她要看着 |
| 她视线外 | 更难受，他不知道她什么时候来 |
| 门口 | 半驱逐 |
| 她身边 | 几乎不算罚了 |

「她视线外」这一版最管用。罚的东西从「站着」换成了「等」，等得多难熬，不由她控制。

#### 可用细节

| 类 | 内容 |
|---|---|
| 时长 | 她说了多久 · 实际多久 · 他有没有偷偷动 |
| 他的小动作 | 换重心 · 手不知道放哪 · 偷看时间 · 听她在做什么 |
| 环境 | 她在隔壁的声音 · 空调 · 墙上的一道印子他数了很多遍 |
| 结束的方式 | 她来叫 · 时间到他自己走出来 · 她忘了，这条要单独写 |

「她忘了」这一版，用不着一点恶意。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 起因 | 他确实办砸了事 | 她正烦着，这一头得让他付出点代价 |
| 时长 | 十分钟 | 她压根没想起来 |
| 他的态度 | 认罚 | 委屈归委屈，人还杵那儿 |
| 结束 | 她过来，揉了揉他脑袋 | 她过来，先甩一句「知道自己错哪儿了不」 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 罚多久合适，她其实一直在看表 | 她在干什么，她还记不记得我 |
| 好的处理 | 她一直在数时间，只是没让他知道 | 他站满了，一秒没少 |
| 写崩 | 写成真正的羞辱 | 写成毫无感觉 |

「她一直在看表」：罚有个限度，她没拿他撒气。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 廊下候着／跪在阶前／她不叫起就不能起 |
| 修仙 | 阵中静立／面壁 |
| 星际 | 舱外待命／被移出通讯频道 |

古代版里「不叫起就不能起」是制度允许的。罚他的是规矩，她只是没开口免掉。

#### 写崩的三种方式

1. 罚太久。 过了一小时，情趣就成了折磨。
2. 让她真忘了，事后也不管。 忘可以写，后果一定得有。
3. 写他服从得毫无反应。 他的小动作要写出来。

## 三 · 没收

`G` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 15.0%

**骨架**｜她收走他一样东西，收的是什么比收本身要紧。

#### 节拍链

她摊手 → 他迟疑 → 先做完手上那件事 → 自己交出来 → 她说明期限 → 到点归还

#### 时间轴

她把期限一说出口，两个人心里就都压着这件事。
「三天」：第一天他故意装得满不在乎，第二天开始绕着那个抽屉走，第三天还没到点，提前半小时就在客厅里来回晃。
她到点就还，一分钟不早，一分钟不晚。说到做到，规矩才作数。

#### 没收物的分级

| 物 | 力度 | 说明 |
|---|---|---|
| 手机 ✓ | 轻 | 最常见，也最像玩笑 |
| 游戏机 / 他正在看的书 | 轻 | 断掉他的注意力 |
| 车 ✓ 钥匙 ✓ | 中 | 断掉他的行动力 |
| 他的工作证 / 门禁 | 重 | 越界了，见第十条 |
| 她自己送他的东西 | 特殊 | 收回赠予，最疼 |

最后一行最有力，也最危险。把自己送的东西拿回来，等于撤回了一次承认。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的动作 | 直接从他手里抽走 · 摊手等他自己交 · 后者更有力 |
| 他的交法 | 立刻交 · 迟疑一下 · 交之前先把手头那事弄完 |
| 保管方式 | 放他眼皮底下，他更难受 · 收进抽屉 |
| 归还 | 到点就还 · 他来要 · 她主动还并说清楚为啥 |

「摊手等他自己交」比从他手里直接抽走有力得多。东西由他亲手交出来，他也就参与了这次执行。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 收什么 | 玩物 | 必需品（危险，见第十条） |
| 时长 | 一晚 | 没说期限 |
| 他的反应 | 认了 | 半夜偷偷去拿（然后被抓） |
| 归还 | 到点还 | 她忘了还，他也没提 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 收多久合适 | 她把它放哪儿了 |
| 好的处理 | 她说了为啥收、收多久 | 他交了，没多问一句 |
| 写崩 | 写成想收就收 | 写成藏起来自己用 |

本卷每一条责罚都要「说明原因和期限」。拿走东西却不说期限，那就是控制。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 收了他的印／收了他的马／不许他出府 |
| 修仙 | 封了他的法器／禁了他的灵力三日 |
| 星际 | 冻结权限／收回舰载终端 |

#### 写崩的三种方式

1. 收走必需品又不还。 判据看第十条。
2. 不说期限。 东西一直扣着，就越界了。
3. 写成她什么东西都能随时拿走。 那就成了控制，见第十条。

## 四 · 写检讨

`G` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 15.0%

**骨架**｜叫他把这件事写下来，怎么写的比写了什么要紧。

#### 节拍链

她要求 → 他前半段敷衍 → 写着写着真想了 → 中间划掉一段 → 交上去 → 她收进抽屉

#### 时间轴

她收到检讨，先看几点交的，再数纸上划了几道，最后才看写了什么。十分钟就交上来的，纸面干干净净，一看就是糊弄，没花心思。两小时才交的，中间几行划掉的痕迹，是他犹豫、改主意时留下的，是真往里写了东西。态度怎么样都摆在纸面上，比读内容看得还快。

#### 为什么好用

罚站、罚跪、东西被收走，都是别人对他做什么。写检讨得他自己把话理顺，不真琢磨一遍写不出来。

写下来的检讨还能留着，过了很久也能翻出来看。

#### 可用细节

| 类 | 内容 |
|---|---|
| 形式 | 手写 · 限字数 · 她要检查 · 写得不行得重来 |
| 他的写法 | 前面糊弄，后面写着写着认真了 · 也有反着来的 |
| 破绽 | 后面的字越来越乱 · 中间涂掉一段 · 纸角压出了印 |
| 她的批改 | 她真改了 · 或者压根没看，就让他写 |
| 保留 | 她收进抽屉里，过了很久他翻出来还在 |

她把检讨收进抽屉，这次责罚也就成了一样纪念。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的态度 | 敷衍 | 认真到写了三页 |
| 她看不看 | 认真看还批注 | 收起来没看 |
| 内容 | 就事论事 | 写着写着跑偏了（表白、控诉） |
| 后续 | 撕了 | 她留着 |

「写着写着跑偏了」这头说明，叫他写检讨，他反倒常常敢写真话。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 她要他真往心里去 | 写到第二页就不知道自己写啥了 |
| 好的处理 | 她真看了，还接了他写别的话茬 | 他写了实话 |
| 写崩 | 写成她开批斗会 | 写成他变着法儿道歉 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 抄家规／罚抄经／写请罪折子 |
| 修仙 | 抄门规／将过错刻在石上 |
| 星际 | 提交事故报告／录一段口述 |

古代版的「抄家规」，抄的是别人定的规矩，抄上一百遍，也就成了他自己的。

#### 写崩的三种方式

1. 让她当法官。 她批注用什么语气，决定了这是亲密还是审判。
2. 让他写得很漂亮。 潦草、划掉、跑题，才像真的。
3. 写完就撕。 留着，以后用。

## 五 · 禁足

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 15.0%

**骨架**｜不许他出门。

#### 节拍链

起因 → 她说了期限与原因 → 他其实可以出去 → 他没有 → 出现必须出门的那次 → 她怎么处理

#### 时间轴

期限说的是几天，真正考验他的是每天路过门口的那一下。门没锁，他一天在玄关走过八百回，每一回没出去，都是又答应了一次。到了非出门不可的那天，一定是事情把他逼到头了。规矩撞上现实，她当场改规矩，怎么改，比关着他不让出门更要紧。

#### 先说边界

这一族里，限制人身自由离越界最近。能写，但得满足三个条件：

| 条件 | 说明 |
|---|---|
| 有期限 | 一晚、一周，明确 |
| 有原因 | 原因最好跟安全有关，比如他上次出去出了事 |
| 可协商 | 他有真的必须出去的事，她会同意 |

少一条，就成了控制，算不上桥段了。见 [十 · 规矩的边界](#十--规矩的边界)。

#### 可用细节

| 类 | 内容 |
|---|---|
| 执行方式 | 嘴上说好，他自觉就行 · 她拿了钥匙 ✓（已经偏重） |
| 他的遵守 | 他本来能出门，但他没去 |
| 时间的过法 | 他在家干啥 · 阳台蹲了半天 · 窗 ✓ 边 |
| 破例 | 他非得出门那回，她咋办的 |

这条安全的写法只有一种：「他其实可以出去，但他没有」。门一锁，就成了囚禁。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 执行 | 嘴上说说 | 真动手，且得想清楚 |
| 时长 | 一晚上 | 一礼拜 |
| 他的态度 | 认了 | 不乐意，但照做 |
| 破例 | 她开口说算了 | 他自己坏了规矩，还主动交代 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 我是不是管太多了 | 我能走，咋还不走 |
| 好的处理 | 她早早就松了口，给了台阶 | 他守规矩，是因为自己想守 |
| 写崩 | 写成了关起来不让出门 | 写成了他啥都听别人的，自己不动脑子 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 不许出院／门房得了话／她的令牌在她手上 |
| 修仙 | 禁制／不许出洞府三日 |
| 星际 | 舱室权限限制 |

古代版要特别当心：女尊制度下禁足是合法的，越没越界就很难看出来。所以制度越允许，文里越得自己表明态度。

#### 写崩的三种方式

1. 把人关起来，文里却不反思。 这是本卷的红线。
2. 无期限。 见上。
3. 让他连出门的念头都没了。 那是心理控制。

后接：[十 · 规矩的边界](#十--规矩的边界)

## 六 · 立规矩

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 15.0%

**骨架**｜写第一条规矩怎么来。

#### 节拍链

一次具体的事故 → 谁提出 → 定第一条 → 她给自己也定一条 → 记在哪 → 后来第二条怎么加的

#### 时间轴

别当天就谈，过两天再说。气头上说出来的都是狠话，定不成规矩。等两个人都缓过来，谁先开口、往哪边说、她给自己加的那一条，都得慢慢磨出来。立规矩越不急，定下来的越作数。从出事到立规矩，中间那几天一定要留。

#### 规矩的三种来源

| 来源 | 性质 | 读着像 |
|---|---|---|
| 她单方面宣布 | 权力 | 最直接，也最容易滑向控制 |
| 从一次具体的事故里长出来 | 协商 | 最扎实 |
| 他自己提出来的 | 请求 | 最有味道 |

第三种少见，值得写。他自己开口要一条规矩，是因为有了规矩，他心里才有底。

#### 可用细节

| 类 | 内容 |
|---|---|
| 第一条规矩通常是 | 出门说一声 · 饭得吃 · 有事直说 · 别自己扛 |
| 注意 | 上面每条其实都是护着他 |
| 立的场合 | 吵完一架之后 · 他受了伤之后 · 睡前随口提一嘴 |
| 记录 | 写没写下来 · 记在哪儿 |
| 增补 | 第二条、第三条怎么加上去的 |

上面这几条，说到底都在护着他。
所以被管的那个人反倒心里踏实。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提的 | 她 | 他 |
| 规矩指向 | 约束他的行为 | 保护他的利益 |
| 数量 | 就一条 | 一整套（越多越要小心） |
| 双向性 | 只约束他 | 她也有要遵守的（最好） |

「她也有要遵守的」：她给自己也定上一条，规矩就不光是用来管他的了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 我干嘛要管他 | 有条规矩我反倒安心 |
| 好的处理 | 她给自己也立了条规矩 | 他直接说了他想要哪条 |
| 写崩 | 写成当众宣布家规 | 写成他求着别人管他 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 家规／府规／她亲口定的一条 |
| 修仙 | 道侣契约的条款／双修的约定 |
| 星际 | 编入个人协议 |

古代女尊制度里本来就有家规、府规、门规这些现成的叫法，可它们跟这两个人自己定的规矩完全是两码事。现成的词越好用，越容易把两者混成一回事。见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。

#### 写崩的三种方式

1. 一次定十条。 先一条，规矩得一条条长出来。
2. 只约束他。 双向才成立。
3. 不写规矩从哪来。 这一条要写的就是来源。

#### 可串接

前接：[16-危机与保护 · 吵到最难看的时候](16-危机与保护.md#六--吵到最难看的时候)。大吵一架之后定下规矩来收场，规矩常常就是这么开始的。
后接：本卷全部条目，它们都以规矩为前提。

## 七 · 求情

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 15.0%

**骨架**｜他求她这回就算了：他怎么求，她松不松口。

#### 节拍链

罚已定 → 他求（或不求）→ 她别开眼 → 「不行」说了两遍 → 减刑／照执行 → 给了理由

#### 时间轴

从定下罚到真开始，只有几分钟，能求情的就这一小会儿，错过就没了。罚到一半再求已经晚了，这一点两个人心里都清楚。她那句「不行」，第一遍是表态，第二遍声音就软了半度。要紧的是两遍中间隔的那几秒。

#### 求情的四种方式

| 方式 | 效果 |
|---|---|
| 讲道理 | 最没用 |
| 撒娇 | 有用，但她会说「这次不行」 |
| 认真道歉 | 通常能减刑 |
| 什么都不说，就看着她 | 最有效 |

最后一种最管用，也最难写。他把主意全交给她拿，又给了她最大的压力。

#### 她的四种回应

| 回应 | 读作 |
|---|---|
| 直接免了 | 他比规矩重要，可这样规矩就不作数了 |
| 减刑 | 最常见 |
| 不准，但给了理由 | 最好的一种 |
| 不准，且不解释 | 最冷，后面得补上 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的动作 | 拽她袖子 ✓ · 挡她前头 · 蹲下来看她 · 一直盯着 |
| 她的动作 | 别开眼，快撑不住了 · 停顿越来越长 |
| 破绽 | 她说了两遍「不行」，第二遍是跟自己说的 |
| 收尾 | 她松了一半 · 或者她来句「下次」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他求不求 | 求 | 不求，直接认罚，更有骨气，也更让她心软 |
| 她准不准 | 准 | 不准 |
| 有没有旁人 | 私下 | 有人在（他不会求） |
| 后续 | 罚照执行 | 她自己提前叫停了 |

四爱男读者对「不求，直接认罚」评价最高：顺从不等于讨饶。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 我要是免了，规矩就没了 | 我不求，我认 |
| 好的处理 | 她不准，但说了为什么 | 他接受了，没有怨 |
| 写崩 | 写成她铁石心肠 | 写成他哭闹求饶 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 跪下求／旁人替他求／她说「谁替他求，一起罚」 |
| 修仙 | 传音求／同门代为说情 |
| 星际 | 在公开频道申请复议 |

#### 写崩的三种方式

1. 她回回都心软，规矩就成了摆设。
2. 让他跪在地上哭。那是另一种味道了，还会把他这个人写坏。
3. 她不准，也不给说法。理由至少得给一个。

#### 可串接

前接：[二 · 罚站](#二--罚站) · [三 · 没收](#三--没收)
后接：[九 · 罚完之后](#九--罚完之后)

## 八 · 他自己认罚

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 15.0%

**骨架**｜她话还没说，他自己先站过去了。

#### 为什么这条是本卷的高点

规矩已经长进他心里了，动手执行的人换成了他自己。

主动权也回到了他手上。他自己走到墙角，是在守他们的约定。

#### 节拍链

他做了错事 → 她还没反应 → 他自己去了 → 她愣住 → 她的处理

#### 时间轴

她愣了三秒，又走了十步，开口之前还犹豫了一下，每一步都慢了下来。前后不到一分钟，他先站到了她身边，脸上的表情都没来得及换。等她回过神，节奏已经全在她手里。他只早动了一步，可这一步等于把主动权交回到她手上。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的动作 | 自己站过去 · 把手机 ✓ 放桌上推给她 · 自己开始写 |
| 她的反应 | 愣住 · 想笑 · 心里软了一下 |
| 她的三种处理 | 照罚，认了他这份自觉 · 免了（怕他多想）· 陪他站（最好） |
| 事后 | 他问「我这样是不是有点过了」 |

「陪他站」：她走过去，和他并排站着。规矩照旧，执行的方式换了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他为什么自己去 | 真的知道错了 | 想抢在她生气之前 |
| 她的处理 | 照罚 | 陪站 |
| 他的心态 | 踏实 | 忐忑，怕她不接受这个自罚 |

「怕她不接受这个自罚」这份心思能写。自己罚自己也是在示好，示好就可能被拒绝。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她进屋看见他已经站在那儿 | 走过去的那几步 |
| 好的处理 | 她没吭声，过去站他边上 | 他没提这茬 |
| 写崩 | 写她夸个没完 | 写他装样子罚自己 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 自己跪在阶前／自己去领罚／递上写好的请罪折 |
| 修仙 | 自入思过崖 |
| 星际 | 自己提交了违规报告 |

#### 写崩的三种方式

1. 让她夸他。 她一夸，自罚就成了表演。
2. 让他每回都自己认罚。 一成习惯，这一招就不灵了。
3. 免了罚却不说为什么。 免可以，得有个说法，规矩才不散。

## 九 · 罚完之后

`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 语料频次：日常责罚 15.0% ＋ 讨哄 68.5%

**骨架**｜罚完之后那十分钟，比挨罚的时候还难熬。

#### 为什么必须写

权力交换的故事里，这一段总有它的位置。两个人从「办事」切回「过日子」，就靠这一段：确认刚才的事两个人都认，确认对方没事，确认关系没受伤。

这一段一跳过，前面的责罚就全显得冷冰冰的。

#### 节拍链

结束 → 她过来 → 身体接触 → 确认 → 回到日常

#### 时间轴

十分钟内能把气氛拉回日常，就算稳稳落了地。她什么时候过来有讲究：马上过来是心疼，晚五分钟是给两个人都留个台阶。确认的那句话放在第几分钟说，先碰哪里后碰哪里，都看两个人当时的状态。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的第一个动作 | 摸头 · 拉他手 ✓ · 直接抱住 · 递水 |
| 确认的话 | 「腿麻不麻」，不提错，只问身体 · 「过来」 |
| 他的反应 | 绷了好久的肩膀松下来 · 突然抱得很紧 · 一声不吭 |
| 回到日常的信号 | 她随口说了句别的，比如今晚吃啥 |
| 有些作品会有的 | 回头聊：为啥罚、他咋想、下回咋办 |

「她随口说了句别的」：日子照常过起来，罚才算结束，光原谅还不算。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的方式 | 直接抱 | 先谈，再抱 |
| 他的反应 | 立刻缓过来 | 需要很久 |
| 有没有复盘 | 有 | 没有，直接翻篇 |
| 谁先说话 | 她 | 他（「我知道错哪了」） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 内心 | 我刚才是不是太过了 | 她还是过来了 |
| 好的处理 | 她先顾他的伤，再顾别的事 | 他抱得很紧，但没掉眼泪 |
| 写崩 | 写成她拍拍屁股就走 | 写成他马上撒娇要哄 |

「她拍拍屁股就走」最要不得。罚完就不管了，整段关系看着就成了她单方面支配他。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 叫起／亲自扶／赐座／让他坐到身边 |
| 修仙 | 撤了禁制／渡一道灵力 |
| 星际 | 恢复权限／把他调回原岗位 |

古代版要写「亲自扶」：罚是制度，扶他的是她这个人。

#### 写崩的三种方式

1. 觉得这段可以直接跳过。 整族里就这一条省不得。
2. 马上让亲密升级。 收尾用不着给甜头。
3. 让她只讲道理，不碰他。 先问他腿麻不麻，别的后面再说。

## 十 · 规矩的边界

<!-- gb-nonscene -->
`T` ｜ ⚠️训诫 ｜ 全谱系 ｜ 本条是本卷的判据，不列为桥段

**骨架**｜规矩到哪一步就成了控制。

#### 判据表

| 维度 | 是规矩 | 是控制 |
|---|---|---|
| 来源 | 两个人商量出来的 | 一个人硬塞的 |
| 期限 | 说好多久就多久 | 没个头 |
| 可协商 | 能通融、能改 | 说一不二 |
| 范围 | 就事论事 | 管他交朋友、花多少钱、出门干啥 |
| 目的 | 想让日子过得稳 | 想让对方听自己的 |
| 收束 | 罚完还能好好过 | 罚完就翻篇了 |
| 他的状态 | 会笑、会求情、会顶嘴 | 不敢、不会、没有了 |

只看一行的话，最后一行最靠得住。还会顶嘴的人还在这段关系里，不再顶嘴的人已经不在了。

#### 写作上怎么用

素材库不躲着控制叙事，但要把它分出来、标出来。

| 可以写 | 要求 |
|---|---|
| 越界的规矩 | 文本要能被看出对它有判断 |
| 支配欲失控 | 后面要有代价，或者清醒的反抗 |
| 他真的不敢顶嘴了 | 这个变化要被某个人看见 |

越界不但没付代价，反倒被奖赏，问题出在这里。越界可以写，别写成深情。

#### 与 06 卷的分层

| | 本卷 | [06-尺度与写法](../06-尺度与写法/) |
|---|---|---|
| 烈度 | 日常小打小闹 | 训诫／BDSM 专论 |
| 内容 | 罚站、没收、写检讨 | 正经的权力交换玩法 |
| 身体伤害 | 没有 | 按那卷的规矩来 |
| 安全框架 | 这页开头说了 | 那卷讲得更细 |

两卷共享同一套底线：SSC、RACK、PRICK，全员成年，虚构与现实分开。

#### 再说一次虚构与现实

小说里的规矩和责罚，是写故事的人定下来的，属于幻想设定，跟现实中人和人怎么相处是两码事。现实里要碰权力交换那套，安全词得有，事先说好，随时能喊停，各自冒多大险也得心里有数。**这卷不是教你在现实里怎么玩的。** 本卷通篇聊的是**怎么写故事**。

如果在现实关系里觉得自己的行动自由、社交联系或者经济自主受了限制，那这不算这里讨论的任何一种东西。

#### 可串接

这一条不单独成场，是给本卷所有条目附的判断标准。
