## 这一族的用法

前面各卷的桥段都需要一个起因。这一卷不需要：下雨就是下雨，过年就是过年。

它们的价值在于：

| 功能 | 说明 |
|---|---|
| 制造独处 | 下雨天俩人都走不了 |
| 制造义务 | 过年不回去说不过去 |
| 制造对照 | 想想去年这时候在干嘛 |
| 制造仪式 | 年年都干的那件事 |
| 制造截止 | 换季、年底、生日前头 |

「去年这个时候」是这一族最有效的一句话。 节令自带年度循环，而循环就是最省力的时间刻度。

## 一 · 下雨

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：雨雪（雨雪＋归家、雨雪＋接送高频同现）

**骨架**｜一把伞，俩人在一块儿，本来不用走这段路的。

#### 节拍链

突然下雨 → 谁有伞 → 打法（偏向谁）→ 一路 → 湿了半边肩 → 到家擦头发烧水 → 有人感冒了

#### 时间轴

一段路走多久，伞歪多少，就是全程唯一的信号。出门的时候伞还在正中间，走一半偏了十五度，到楼下的时候打伞那人半边肩膀全湿了。伞越歪越厉害，谁也没吭声。感冒是这条线的延时引信：三天后才发作，发作的时候俩人都清楚是哪天埋下的。

#### 伞的调度学

这条的全部内容是**伞怎么打**：

| 打法 | 读作 |
|---|---|
| 她撑，他淋湿一边肩 | 他在让 |
| 他撑，她淋湿一边肩 | 他没顾好（可以是失误，也可以是他没经验） |
| 他撑，且伞明显偏向她 | 传统脚本，用了要处理 |
| 她把伞塞给他，自己跑 | 最有她的样子 |
| 只有一把，她说「你拿着」 | 她在下命令，且是为他好 |
| 两把伞，但走得很近 | 最含蓄 |

「她把伞塞给他自己跑」是这条最好用的一版。 它同时完成了照顾与拒绝被照顾。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 伞 ✓ · 湿掉的半边肩 · 头发滴水 · 鞋进水 · 便利店门口 |
| 场景 | 突然下雨 · 没带伞 · 等雨停 · 淋着跑回去 |
| 之后 | 谁给谁擦头发 · 谁去烧热水 ✓ · 感冒 ✓（转 [01 卷](01-日常照料.md)） |
| 声音 | 雨打在伞面上 · 说话要提高音量 · 或者干脆不说 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁撑伞 | 她 | 他 |
| 有没有伞 | 有一把 | 都没有 |
| 结果 | 到了 | 躲在一个地方等雨停 |
| 之后 | 无事 | 有人感冒了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他那半边肩全湿了 | 她的伞一直偏向我这边 |
| 好的处理 | 她把伞正过来，什么也没说 | 他自己往外挪了半步 |
| 写崩 | 写成撑伞定情的老套镜头 | 写成他默默淋湿的牺牲感 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 一把油纸伞／她的车驾／他跟在车边淋着 |
| 修仙 | 灵力挡雨／她随手一个结界罩住两人 |
| 星际 | 酸雨／防护罩配额只够一个人 |

星际版的「防护罩只够一个人」把这条推到了极端：问题从谁体贴谁，变成了谁活。

#### 写崩的三种方式

1. 写成定情镜头。 这条太常见，越平常越好。
2. 让他默默淋湿。 牺牲感会让她显得没看见。
3. 省略之后。 擦头发、烧水、感冒，才是这条的下半场。

## 二 · 降温

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：冷热 25.0%（冷热＋生病、冷热＋做饭高频同现）

**骨架**｜天冷了，谁记得给你加衣服，比说啥都好使。

#### 节拍链

降温预报 → 谁记得谁 → 外套围巾直接给 → 手的温度 → 空调温度之争 → 一件衣服轮流穿

#### 时间轴

降温是一夜之间的事，头天预报刚出来，晚上就有人把厚外套挂到门口最顺手的地方，第二天早上对方出门才看见。空调温度这事，两个人能争一整个冬天，一个要26，一个要24，谁都不让谁。最后谁也没赢，解决办法是换了一床加厚的被子。

#### 冷的三种用法

| 用法 | 说明 |
|---|---|
| 制造照料 | 加衣、热饮、暖气 |
| 制造靠近 | 冷是最正当的贴近理由 |
| 制造对照 | 他冷她不冷（体质差）· 她冷他不冷 |

**第三种最少被写。** 两个人对温度的感受不同，这件小事可以磨很久：她开空调他觉得冷，他开暖气她觉得闷。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 外套 ✓ · 围巾 ✓ · 暖气片 ✓ · 空调 ✓ 遥控器 · 热水袋 · 手套 ✓ |
| 加衣的动作 | 她把外套扔给他 · 他把围巾往她脖子上绕 · 谁替谁拉拉链 |
| 手的温度 | 谁的手凉 · 谁把谁的手塞进自己口袋 ✓ |
| 摩擦 | 为空调开几度吵一架 |
| 落点 | 一件衣服，两人换着穿 |

「一件衣服两个人轮流穿」是这条最省字的亲密证明。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁怕冷 | 她 | 他 |
| 谁记得 | 他记得她 | 她记得他 |
| 方式 | 明说 | 默默做了 |
| 摩擦 | 无 | 温度之争成了长期梗 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她出门时手里多了一条围巾 | 她今天穿得太少 |
| 好的处理 | 她穿了，也没说不用 | 他不念叨「你怎么穿这么少」，直接递过去 |
| 写崩 | 把她写成啥都不会的小孩 | 写成他围着人唠叨个没完 |

「不说，直接给」是这一族的通用手法。 一句「你怎么穿这么少」会把关心变成指责。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 手炉／斗篷／他备好的姜茶／炭盆添了几回 |
| 修仙 | 灵力驱寒／她随手渡一缕暖 |
| 星际 | 舱温设定／恒温服的配额 |

#### 写崩的三种方式

1. 只写加衣服。 温差一出来，戏就来了。
2. 直接甩一句「你怎么穿这么少」。 别铺垫，给就完了。
3. 手凉不凉别写。 那才是最有用的触觉细节。

## 三 · 过年

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：节日 33.0%（节日＋做饭＋归家为高频三元组合）

**骨架**｜过年就是一年一次的被迫交底：去谁家、算你什么人、怎么跟人介绍你。

#### 节拍链

定去谁家 → 路上 → 进门与红包 → 席间那句催 → 他去了厨房 → 她跟过去站了一会儿 → 除夕夜的十分钟

#### 时间轴

七天假期，真正要紧的就除夕夜那十分钟。前面全是走流程：路上花半天，进门的头一小时最难熬，催婚的话准在第二轮敬酒时冒出来，一点没跑。守岁到零点前后，一屋子人各刷各的手机，他俩趁机溜到阳台，那十分钟，是七天里唯一能喘口气的时候。

#### 过年的四个考题

| 考题 | 难点 |
|---|---|
| 去谁家 | 两边都得去，还是先紧着一头 |
| 什么身份 | 见 [11-初遇与确立 · 没有表白](11-初遇与确立.md#十--没有表白)：没名分咋整 |
| 红包给谁 | 谁给老人、谁给孩子、钱谁掏 |
| 坐哪 | 座位排的就是地位 |

「红包钱谁出」是最现实也最少被写的一题。 他掏还是她掏，掏了之后长辈的反应，都是信息。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 年夜饭 ✓ · 红包 · 春联 · 行李箱 · 带回去的礼物 ✓ |
| 场面 | 一桌子人 · 谁挨着谁坐 · 谁去厨房 |
| 那句话 | 「明年该轮到你了吧」（催，见 [13 卷](13-家庭与亲属.md#三--催)） |
| 他的位置 | 他去厨房了，桌上没他坐的地儿 |
| 除夕夜 | 两人单独待十分钟 |

「他去厨房了，因为在桌上没有他的位置」是这条最准的一笔。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 去哪家 | 她家 | 他家 |
| 身份 | 已经定了 | 还没有名分 |
| 气氛 | 融洽 | 尴尬 |
| 两人独处 | 有 | 全程被围着 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他一晚上都在厨房 | 桌上没有我的位置 |
| 内心 | 我该把他叫出来 | 在这儿反而自在 |
| 好的处理 | 她去厨房陪他站了一会儿 | 他没有委屈 |
| 写崩 | 写成她大战全家 | 写成他被欺负的年 |

「她去厨房陪他站一会儿」比「她把他拉回桌上」好。 后者是纠正，前者是加入。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 除夕家宴／祭祖时他站哪／族中排位 |
| 修仙 | 宗门年节／他是不是在名录上 |
| 星际 | 地球历春节／舰上只有他们两个在过 |

**星际版的「舰上只有他们两个在过」是最温柔的一版：** 没有外人，节日回到了它本来的样子。

#### 写崩的三种方式

1. 写成大战全家的爽文。 过年的难处在于没人是坏人。
2. 别写「坐哪」。 坐哪就是你在家排老几，这最省字。
3. 全程只写尴尬。 除夕夜那十分钟要留。

## 四 · 节日的分寸

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：节日 33.0%

**骨架**｜情人节、七夕、纪念日——过不过、怎么过，说白了就是看谁更在意谁。

#### 节拍链

日子临近 → 谁记得 → 试探「今天几号」→ 都偷偷准备了或一方忘了 → 撞车或落空 → 私人日子的确立

#### 时间轴

倒计时从一周前开始，两条准备线互相保密。 「今天几号」的试探出现在倒数第三天，问的人装随意，答的人装没懂；当天的撞车（都订了餐厅）或落空（一方真忘了）在晚上七点揭晓。这条的长线是「私人日子」的确立：过着过着，公历节日让位给了只有他们知道的纪念日。

#### 节日的不对称

| 情况 | 说明 |
|---|---|
| 他在意，她不在意 | 常见。他记着日子，她压根没当回事 |
| 她在意，他不在意 | 写得少，但一写就出效果 |
| 都不在意 | 这俩人处得踏实，但得让读者看出来他俩是商量好的 |
| 都在意但都不说 | 最有戏：俩人都偷偷备好了，谁都不吭声 |

**「都偷偷准备了」是这条最好的一版**，且它可以做成一次小小的喜剧。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的准备 | 提前订好位子 · 藏了东西（见 [07 卷第一条](07-馈赠与仪式.md#一--藏了很久的礼物)）· 请了假 |
| 她的状态 | 当天要开会 · 或者她也请了假，没吭声 |
| 试探 | 「今天几号来着」 |
| 撞车 | 两人订了同一家餐厅 · 买了对方已经有的东西 |
| 落点 | 一个只有他俩才懂的日子，比啥节日都顶用 |

**「一个只有他们两个才懂的日子」是这条的终点：** 公共节日是给外人看的，私人纪念日才是关系本身。见 [07-馈赠与仪式 · 一个只属于他们的仪式](07-馈赠与仪式.md#十--一个只属于他们的仪式)。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁记得 | 他 | 两个人都记得 |
| 过不过 | 认真过 | 说好了不过 |
| 意外 | 无 | 撞车／错过（转 [02 卷第八条](02-等待与错过.md#八--错过的纪念日)） |
| 私人日子 | 有 | 还没有 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他今天请了假 | 她今天一句都没提 |
| 好的处理 | 她也准备了，而且比他更早 | 他没因为她没提就蔫一整天 |
| 写崩 | 写成她砸钱搞大场面 | 写成他干等着她想起自己 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 上元／七夕／她的生辰／他们初见那日 |
| 修仙 | 结契日／她突破的那天／百年之期 |
| 星际 | 地球历的某天／他们第一次同航的日子 |

#### 写崩的三种方式

1. 当成惊喜派对来写。见 [07-馈赠与仪式 · 生日](07-馈赠与仪式.md#四--生日) 里那条警告，一个道理。
2. 只写公共节日。这条真正要写的是私人日子，别跑偏。
3. 让不在意的那方显得冷。不在意节日，不等于不在意人，这俩是两码事。

## 五 · 一起出门

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：旅行 35.0%（旅行＋约会、旅行＋请安高频同现）

**骨架**｜旅行就是七十二小时的压缩测试，两个人怎么处，全暴露了。

#### 节拍链

定攻略 → 出发 → 分工暴露 → 迷路或岔子 → 妥协（留半天不安排）→ 一张两人都嫌丑的合照 → 回程

#### 时间轴

七十二小时连轴转，一天一个样。头一天就能看出谁管路线谁管饭；第二天底线全暴露，累到啥程度开始甩脸子；第三天妥协方案就出来了，下午不排行程。回程那俩小时就是验收报告：还能聊几句的，算过了；各刷各手机的，回去等着谈吧。

#### 旅行暴露什么

| 环节 | 暴露 |
|---|---|
| 谁做攻略 | 平时怎么管着你 |
| 谁背包 | 谁力气大谁干活 |
| 迷路时谁着急 | 遇事扛不扛得住 |
| 吃什么 | 谁肯先低头 |
| 拍照谁拍谁 | 见 [07-馈赠与仪式 · 合照](07-馈赠与仪式.md#五--合照) |
| 累了怎么办 | 谁先开口歇 |
| 出了岔子 | 吵架还是想法子 |

「出了岔子」是这条真正的考题。 顺利的旅行没有内容，出岔子之后的十分钟才有。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 行李箱 · 攻略（她列的表格）· 导航 · 车票 · 一张两人都嫌丑的合照 ✓ |
| 她的方式 | 全程有计划 · 每个环节都订好了 |
| 他的方式 | 想随便走走 |
| 摩擦 | 计划派 vs 随性派，这组最常吵也最真 |
| 妥协 | 她留出半天不安排 |
| 目的地机关 | 游乐园（过山车上谁先叫）· 摩天轮（两人关一起＋到顶倒计时）· 烟花（同一秒抬头）· 海边（离开日常的失序许可）· 夜市（边走边吃的投喂链）· 露营（停电条的自愿版：主动上交现代性一晚）· 温泉（浴衣与卸妆的双重卸甲） |

「她留出半天不安排」是这条最好的一个让步。她没放弃计划，只是给计划留了一个空格。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁安排 | 她全包 | 他偷偷做了一份 |
| 摩擦 | 无 | 因为行程吵了一次 |
| 岔子 | 无 | 丢东西／误车／下雨 |
| 收获 | 玩得开心 | 发现了对方的一面 |
| 性质 | 普通出游 | 蜜月（接 [23-婚嫁](23-婚嫁.md)：同一场旅行加了仪式滤镜，行李里多了两本证，酒店前台那声称呼谁也没纠正） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他也偷偷做了份攻略，没敢拿出来 | 她的表格细到每分每秒 |
| 内心 | 我是不是排得太满了 | 说想随便走走，他会不会觉得没劲 |
| 好的处理 | 她把他写的那项也加进去了 | 他说了他真正想去的地方 |
| 写崩 | 写成她从头指挥到尾 | 写成他一步不离跟着走 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 同行赴任／游历／她带他回乡 |
| 修仙 | 同去秘境／历练／她带他上山 |
| 星际 | 跨星系航行／一次休假 |

#### 写崩的三种方式

1. 写成风景游记。 人比景重要。
2. 全程顺利。 岔子才是内容。
3. 让他全程跟随。 他要说出一个自己想去的地方。

## 六 · 出了岔子

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：旅行 35.0% ＋ 危险 18.0%

**骨架**｜东西丢了，车误了，订错了。这十分钟，就看咱俩扛不扛得住。

#### 节拍链

出事（票·证件·订错）→ 半秒懵 → 她掏手机处理或先笑出来 → 分头 → 解决或报废 → 很难吃的一顿饭

#### 时间轴

从出事到解决，就十分钟。半秒发懵，三秒搞清楚是啥事，一分钟内分头行动，她打电话他跑窗口，十分钟内必须见分晓。搞不定就当场转B计划，改签、补办、认栽都行。那顿饭很难吃，但两小时后吃，既是庆功也是复盘。难吃这事，多年后还能拿来当梗。

#### 反应的四种，等级递增

| 反应 | 关系质地 |
|---|---|
| 互相埋怨 | 最差 |
| 一个人扛下来解决 | 常态，但另一个人会没位置 |
| 分头处理 | 好 |
| 先笑出来，再处理 | 最好 |

「先笑出来」是最难写也最能说明问题的一档。 一段成熟的关系在意外面前的第一反应是荒诞感，不是焦虑。

#### 可用细节

| 类 | 内容 |
|---|---|
| 岔子的类型 | 证件丢了 · 航班取消 · 订错了日期 · 语言不通 · 钱包被偷 |
| 她的第一反应 | 拿出手机 ✓ 开始处理 |
| 他的第一反应 | 先看她的脸色 |
| 转折 | 有件事只有他能办（转 [16 卷第九条](16-危机与保护.md#九--他能做到的那件事)） |
| 收尾 | 事办完了，俩人一块吃了顿特难吃的饭 |

**「解决之后吃了很难吃的一顿饭」比「圆满解决」好**：狼狈本身就是共同记忆。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁的错 | 她 | 他 |
| 谁解决 | 她 | 他 |
| 有没有埋怨 | 没有 | 有一句，之后后悔了 |
| 结果 | 解决了 | 没解决，行程报废 |

**「她的错」这一版值得写。** 一个凡事都对的人偶尔犯错，且要面对自己的失误。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 是她订错的 | 她愣住的那一秒 |
| 内心 | 这次是我的问题 | 别说，什么都别说 |
| 好的处理 | 她直接认了，不找补 | 他说了「没事，正好」 |
| 写崩 | 写成她永远没错 | 写成他借机数落 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 走错了路／驿站客满／盘缠被偷 |
| 修仙 | 传送阵出错／秘境提前关闭 |
| 星际 | 航线关闭／跃迁失败／补给不够 |

#### 写崩的三种方式

1. 让她永远不出错。她要是出一次错，人物立马就活了。
2. 靠一方英雄式解决。不如分头处理，各管一摊。
3. 圆满收场。最难吃的那顿饭，才是这条线的落点。

后接：[16-危机与保护 · 一起扛](16-危机与保护.md#十--一起扛)

## 七 · 换季

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：冷热 25.0%

**骨架**｜收拾换季衣服的时候，突然就看见时间了。

#### 节拍链

翻箱倒柜 → 「这个还要吗」循环 → 翻出旧物 → 忽然安静 → 一件谁都没提就放回去了 → 收尾

#### 时间轴

一下午的整理，翻到那件旧物的时候，手就停了。前面一个小时都是流水线操作——要、不要、捐——结果那件东西一出来，两个人谁也没说话，围着它各自愣了好几分钟。最后谁也没提，又给放回去了。收拾完衣柜，换季是完成了，但有些东西，是又续了一年。

#### 换季的功能：清点

这条不必另设时间标记，收拾衣柜本身就是清点这一年：

| 翻出来的 | 说明 |
|---|---|
| 去年买的还没穿过的 | 这一年过得多快 |
| 他的衣服在她柜子里占了多少 | 关系的进展 |
| 一件旧的舍不得扔 | 见 [15-秘密与坦白 · 他一直留着的东西](15-秘密与坦白.md#九--他一直留着的东西) |
| 一件不是他也不是她的 | 前任／来客／一个待解释的东西 |
| 尺码不合了 | 身体变了 |

「一件不是他也不是她的」可以直接引爆一场戏。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场景 | 俩人一块儿收拾 · 要不就他自个儿收拾 |
| 对话 | 「这个还要吗」——这话问了好几遍了 |
| 分歧 | 他非扔，她拦着 · 要不就反过来 |
| 味道 | 樟脑球 · 洗衣粉 · 箱子底下压久了的味儿 |
| 落点 | 有件东西谁也没吭声，又放回去了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁收拾 | 他 | 一起 |
| 翻出什么 | 旧照片 ✓ | 一件不该在这儿的东西 |
| 扔不扔 | 扔了一批 | 什么都没扔 |
| 情绪 | 日常 | 忽然安静下来 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他衣服多到柜子快塞不下 | 她去年就说要扔这件 |
| 好的处理 | 她没扔，把那件旧的放回去了 | 他看见那件不认识的，没问是谁的 |
| 写崩 | 写成她对着旧衣服掉眼泪 | 写成他借这事翻旧账吵一架 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 换季裁衣／箱笼清点／旧年的料子 |
| 修仙 | 整理储物袋／百年前的旧物 |
| 星际 | 私人物品配额清理／舱位重新分配 |

#### 写崩的三种方式

1. 写成怀旧散文。挑两件东西就够。
2. 别管「这个还要吗」。那句来回问的话，就是这条的节奏。
3. 拿它揭开大秘密。小东西带出大情绪。

## 八 · 年底

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：节日 33.0% ＋ 加班 25.0%

**骨架**｜她忙到脚不沾地的那阵子，他基本见不着她人影。

#### 节拍链

冲刺开始 → 连续晚归 → 他忍着 → 某天说了一句 → 她抽了半小时回家吃饭 → 忙完的第一个周末 → 下一个周期

#### 时间轴

一个月的冲刺期，见面时间一周比一周少。第一周还能一起吃个晚饭，第二周就只剩早饭了，到了第三周，就靠睡前那半小时，俩人时间还经常错开。他那句话憋了三周，第三周周末才说出来；她后来抽空补了顿饭，就三十分钟，但手机从头到尾扣在桌上没碰过——时间不够，态度来凑。等忙完那个周末，她整天都拿来陪他，算是补偿。然后下一轮忙活又开始了。

#### 年底的双重压力

| 压力 | 落在谁身上 |
|---|---|
| 工作冲刺 | 她 |
| 应酬 | 她 |
| 一个人过的晚上 | 他 |
| 各种「你们什么时候……」 | 两个人 |

**这一族的所有等待类桥段在年底会同时发作**，见 [02-等待与错过](02-等待与错过.md)。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的状态 | 连着两周没在十点前回来 · 睡不够 · 体检报告 ✓ 拖着没看 |
| 他的状态 | 做好的饭 ✓ 一次次热（转 [02 卷第一条](02-等待与错过.md#一--等门与热菜)） |
| 他做的事 | 把她的日程理了一份 · 到点提醒她吃药 ✓ |
| 冲突 | 他忍了两周，某天实在没忍住，开了口 |
| 收束 | 忙完之后的第一个周末 |

「忙完之后的第一个周末」是这条必须写的一场。 补偿的硬通货是时间，礼物抵不了账。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的态度 | 完全支持 | 忍了很久 |
| 她的察觉 | 察觉了 | 忙到没察觉 |
| 冲突 | 有 | 无（但有代价） |
| 之后 | 补上了 | 又进入下一个周期 |

「又进入下一个周期」是最真实的收尾。 年底过了还有年中，这不是一次性的问题。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她翻到他整理的那份日程表 | 这是这周第四次一个人吃饭 |
| 内心 | 我已经两周没跟他说过一句完整的话 | 忍到过完这阵 |
| 好的处理 | 她在最忙的时候抽了半小时回家吃饭 | 他说了那句，说得不难看 |
| 写崩 | 写成她事业与感情二选一 | 写成他埋怨她工作 |

「抽了半小时回家吃饭」比「推掉工作」好一百倍。 前者是安排，后者是牺牲。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 年关政务／她连日不归／他在府中等 |
| 修仙 | 宗门大典／她主持事务／闭关期临近 |
| 星际 | 年度考核／舰队调防 |

#### 写崩的三种方式

1. 写成事业与感情二选一。 那是伪命题。
2. 用推掉工作解决。 抽半小时更真实。
3. 忙完就圆满。 下一个周期还会来。

## 九 · 一年过去了

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：节日 33.0%

**骨架**｜同一天，又来了一遍。而对照本身就是全部。

#### 节拍链

同一个日子 → 同一家店同一桌 → 细节对照（谁做饭·坐哪·称呼）→ 一样没变的 → 说破或都没提

#### 时间轴

两个时间点，中间隔整整一年。写法就是左右两栏对着写：去年这桌他紧张得点错菜，今年他熟门熟路加了她爱的那道；去年称呼还生疏，今年老板娘都认识他们了。变化一项项列，一样没变的那项（比如坐的位置）放最后，说破不说破，都算收尾。

#### 年度对照表

这条的写法是**把去年那一场原样再写一遍，只改动细节**：

| 项 | 去年 | 今年 |
|---|---|---|
| 谁做的饭 | 他 | 还是他，但她洗碗了 |
| 坐哪 | 各坐一头 | 挨着 |
| 说了什么 | 客气 | 没说话，但都自在 |
| 谁先睡 | 他等她 | 两个人一起 |
| 那件事 | 他没敢提 | 提了 |

**改动越小越好。** 一年的变化如果需要大幅改写才能看出来，那说明关系变得太快，不真实。

#### 可用细节

| 类 | 内容 |
|---|---|
| 锚点 | 还是那家馆子 · 还是那个座 · 还是那道菜 |
| 物证 | 去年的照片 ✓ 跟今年摆一起看 · 同一件衣裳 ✓ |
| 变化 | 叫法不一样了 · 做某个动作顺不顺 · 东西挪了地方 |
| 没变的 | 至少留一样，从头到尾没动过 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 方向 | 变好了 | 变淡了（同样的写法，反过来） |
| 时间跨度 | 一年 | 十年 |
| 谁在对照 | 她 | 他 |
| 说不说破 | 说了「去年这时候……」 | 谁都没提 |

**「变淡了」这一版威力极大**，且它用的是完全相同的技法。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他今年没提前订位（反正也不用订了） | 去年这时候我还喊她全名 |
| 好的处理 | 她没把话说破 | 他啥都记得 |
| 写崩 | 写成倒叙回忆 | 写成他年终汇报 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 又一年上元／同一处灯／她的位次变了 |
| 修仙 | 百年一度／同一个日子他的修为变了 |
| 星际 | 同一条航线／舷窗外同一片星域 |

#### 写崩的三种方式

1. 大段回忆。 用对照，不用回忆。
2. 变化太大。 越小越好。
3. 只用在变好的场合。 反着用一次。

## 十 · 春夏秋冬

<!-- gb-nonscene -->
`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：冷热 25.0% ＋ 节日 33.0%

**骨架**｜这条不是单个桥段，是能撑起整本书的框架：按春夏秋冬给关系分段写。

#### 四季的情绪配置

这是一张可以直接用的分章表：

| 季 | 适合放什么 | 为什么 |
|---|---|---|
| 春 | 初遇、试探、第一次约 | 万物刚醒，天气也舒服，不用硬找事 |
| 夏 | 冲突、爆发、最热烈的部分 | 热得人烦躁，衣服也穿得少 |
| 秋 | 稳定期、日常、隐忧浮现 | 一边收成，一边叶子开始掉 |
| 冬 | 危机、分离、或者最暖的部分 | 冷的时候想抱团，也容易出事 |

春夏秋冬四章的结构，是这个类型最省力的长篇骨架。

#### 每一季的专属物件

| 季 | 物件 |
|---|---|
| 春 | 薄外套 ✓ · 雨 ✓ · 换季的衣柜 |
| 夏 | 空调 ✓ · 冰镇的东西 · 汗 · 蝉 · 台风 |
| 秋 | 长袖 · 第一次降温 ✓ · 落叶 · 中秋 ✓ |
| 冬 | 暖气 ✓ · 围巾 ✓ · 雪 ✓ · 手炉 · 过年 ✓ |

#### 用法

| 用法 | 说明 |
|---|---|
| 分章 | 一季一部分 |
| 循环 | 两轮四季，同一个季节对照写 |
| 单季 | 全书发生在一个夏天（强度最高） |
| 逆序 | 从冬写到春（复苏结构） |

「全书发生在一个夏天」是短篇最好用的结构。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 跨度 | 一年 | 十年（每年只写一天） |
| 结构 | 顺序 | 对照（去年今年交替） |
| 收尾的季节 | 春（新生） | 冬（沉淀） |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 二十四节气／农时／科考和朝会一年一轮 |
| 修仙 | 百年算一季／灵气涨落／宗门大比隔几年办一次 |
| 星际 | 没四季（得自己定）：赶路分几段、跃迁要等多久、补给撑几天 |

**星际版没有天然季节，这既是难点也是机会：** 自己造一套周期，那套周期本身就是世界观。

#### 写崩的三种方式

1. 每一季都写景。 挑物件，不写风景。
2. 季节与情绪不匹配。 夏天写离别不是不行，但要有理由。
3. 四季平均用力。 挑一季重点写。
