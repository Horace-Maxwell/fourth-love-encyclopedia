## 一 · 下雨

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：雨雪＋归家、雨雪＋接送高频同现

**骨架**｜两个人挤在一把伞下，走一段本来不用走的路。

#### 节拍链

突然下雨 → 谁有伞 → 打法（偏向谁）→ 一路 → 湿了半边肩 → 到家擦头发烧水 → 有人感冒了

#### 时间轴

伞歪了一路。出门时还在正中，走到一半偏了十五度，到楼下，打伞那人半边肩膀全湿了。谁也没吭声。三天后有人感冒了，两个人都清楚是哪天落下的。整段路上，伞越歪越厉害，是唯一的信号。

#### 伞的调度学

这条写**伞怎么打**：

| 打法 | 读作 |
|---|---|
| 她撑，他淋湿一边肩 | 他在让 |
| 他撑，她淋湿一边肩 | 他没顾好，可能是失误，也可能是没经验 |
| 他撑，且伞明显偏向她 | 传统脚本，用了要处理 |
| 她把伞塞给他，自己跑 | 最有她的样子 |
| 只有一把，她说「你拿着」 | 她在下命令，且是为他好 |
| 两把伞，但走得很近 | 最含蓄 |

「她把伞塞给他，自己跑」，她照顾了他，也不让他照顾自己。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 伞 ✓ · 湿掉的半边肩 · 头发滴水 · 鞋进水 · 便利店门口 |
| 场景 | 突然下雨 · 没带伞 · 等雨停 · 淋着跑回去 |
| 之后 | 谁给谁擦头发 · 谁去烧热水 ✓ · 感冒 ✓（转 [01 卷](01-日常照料.md)） |
| 声音 | 雨打在伞面上 · 说话要提高音量 · 或者干脆不说 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁撑伞 | 她 | 他 |
| 有没有伞 | 有一把 | 都没有 |
| 结果 | 到了 | 躲在一个地方等雨停 |
| 之后 | 无事 | 有人感冒了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他那半边肩全湿了 | 她的伞一直偏向我这边 |
| 好的处理 | 她把伞正过来，什么也没说 | 他自己往外挪了半步 |
| 写崩 | 写成撑伞定情的老套镜头 | 写成他默默淋湿的牺牲感 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 一把油纸伞／她的车驾／他跟在车边淋着 |
| 修仙 | 灵力挡雨／她随手一个结界罩住两人 |
| 星际 | 酸雨／防护罩配额只够一个人 |

星际版是「防护罩只够一个人」，谁体贴谁变成了谁活下来。

#### 写崩的三种方式

1. 写成定情镜头。打伞太常见了，写得越平常越好。
2. 让他默默淋湿。牺牲感一出来，她就像没看见。
3. 略掉回家以后。擦头发、烧水、感冒，都要写。

## 二 · 降温

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：冷热 25.4%，冷热＋生病、冷热＋做饭高频同现

**骨架**｜一降温，就看谁记着给谁加衣服。

#### 节拍链

降温预报 → 谁记得谁 → 外套围巾直接给 → 手的温度 → 空调温度之争 → 一件衣服轮流穿

#### 时间轴

降温就一夜的事。头天晚上预报一出，门口最顺手的地方就挂上了厚外套，对方第二天早上出门才看见。空调温度两个人能吵一个冬天，一个非要26，一个非要24，谁也不让。最后换了床加厚的被子，这事才过去。

#### 冷的三种用法

| 用法 | 说明 |
|---|---|
| 制造照料 | 加衣、热饮、暖气 |
| 制造靠近 | 冷是最正当的贴近理由 |
| 制造对照 | 他冷她不冷（体质差）· 她冷他不冷 |

**第三种写的人最少。** 两个人怕冷怕热不一样，这点小事能磨好久：她开空调，他嫌冷，他开暖气，她嫌闷。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 外套 ✓ · 围巾 ✓ · 暖气片 ✓ · 空调 ✓ 遥控器 · 热水袋 · 手套 ✓ |
| 加衣的动作 | 她把外套扔给他 · 他把围巾绕到她脖子上 · 谁替谁拉拉链 |
| 手的温度 | 谁的手凉 · 谁把谁的手塞进自己口袋 ✓ |
| 摩擦 | 为空调开几度吵一架 |
| 落点 | 一件衣服，两人换着穿 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁怕冷 | 她 | 他 |
| 谁记得 | 他记得她 | 她记得他 |
| 方式 | 明说 | 默默做了 |
| 摩擦 | 无 | 温度之争成了长期梗 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她出门时手里多了一条围巾 | 她今天穿得太少 |
| 好的处理 | 她穿了，也没说不用 | 他不念叨「你怎么穿这么少」，直接递过去 |
| 写崩 | 把她写成啥都不会的小孩 | 写成他围着人唠叨个没完 |

这一族通常的写法是不说话，直接给。问一句「你怎么穿这么少」，关心就成了数落。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 手炉／斗篷／他备好的姜茶／炭盆添了几回 |
| 修仙 | 灵力驱寒／她随手渡一缕暖 |
| 星际 | 舱温设定／恒温服的配额 |

#### 写崩的三种方式

1. 光写加衣服。冷热一有差别，戏就来了。
2. 只念叨「你怎么穿这么少」，衣服却不递过去。不用铺垫，直接给。
3. 不写手凉不凉。手凉不凉得写。

## 三 · 过年

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：节日 33.3%（节日＋做饭＋归家为高频三元组合）

**骨架**｜过年每年逼人交一次底：去谁家，算什么人，怎么跟人介绍。

#### 节拍链

定去谁家 → 路上 → 进门与红包 → 席间那句催 → 他去了厨房 → 她跟过去站了一会儿 → 除夕夜的十分钟

#### 时间轴

七天假，要紧的就是除夕夜那十分钟，前面都是走过场。路上花掉半天，进门头一个钟头最难熬，第二轮敬酒时准有人催婚，一回不落。守岁守到零点前后，一屋子人各自刷手机，他俩趁机溜到阳台上。七天里能喘口气的，就这十分钟。

#### 过年的四个考题

| 考题 | 难点 |
|---|---|
| 去谁家 | 两边都得去，还是先紧着一头 |
| 什么身份 | 见 [11-初遇与确立 · 没有表白](11-初遇与确立.md#十--没有表白)：没名分咋整 |
| 红包给谁 | 谁给老人、谁给孩子、钱谁掏 |
| 坐哪 | 座位排的就是地位 |

「钱谁掏」最现实，写的人却最少。他掏还是她掏，掏完长辈什么脸色，都能看出东西来。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 年夜饭 ✓ · 红包 · 春联 · 行李箱 · 带回去的礼物 ✓ |
| 场面 | 一桌子人 · 谁挨着谁坐 · 谁去厨房 |
| 那句话 | 「明年该轮到你了吧」（催，见 [13 卷](13-家庭与亲属.md#三--催)） |
| 他的位置 | 他去厨房了，桌上没他坐的地儿 |
| 除夕夜 | 两人单独待十分钟 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 去哪家 | 她家 | 他家 |
| 身份 | 已经定了 | 还没有名分 |
| 气氛 | 融洽 | 尴尬 |
| 两人独处 | 有 | 全程被围着 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他一晚上都在厨房 | 桌上没有我的位置 |
| 内心 | 我该把他叫出来 | 在这儿反而自在 |
| 好的处理 | 她去厨房陪他站了一会儿 | 他没有委屈 |
| 写崩 | 写成她大战全家 | 写成他被欺负的年 |

「她去厨房陪他站了一会儿」，比把他拉回桌上好。拉他回去，等于说他做得不对。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 除夕家宴／祭祖时他站哪／族中排位 |
| 修仙 | 宗门年节／他是不是在名录上 |
| 星际 | 地球历春节／舰上只有他们两个在过 |

星际版「舰上只有他们两个在过」，没一个外人。

#### 写崩的三种方式

1. 写成大战全家的爽文。过年难就难在谁都不是坏人。
2. 漏掉「坐哪」。坐哪，就是他在家排第几。
3. 从头到尾只写尴尬。除夕夜那十分钟得留着。

## 四 · 节日的分寸

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：节日 33.3%

**骨架**｜情人节、七夕、纪念日，过不过、怎么过，看得出谁更在意谁。

#### 节拍链

日子临近 → 谁记得 → 试探「今天几号」→ 都偷偷准备了或一方忘了 → 撞车或落空 → 私人日子的确立

#### 时间轴

提前一周，两个人的心思就各自藏着了。还剩三天时，有人随口问了句「今天几号」，另一个也随口应了，像没听出来。到底撞车还是落空，晚上七点才知道：撞车是两边都订了餐厅，落空是有一边根本没想起来。日子久了，公历节日越来越不当回事，记得牢的是只有他们俩懂的纪念日，这条线最后落到「私人日子」上。

#### 节日的不对称

| 情况 | 说明 |
|---|---|
| 他在意，她不在意 | 常见。他记着日子，她压根没当回事 |
| 她在意，他不在意 | 写得少，但一写就出效果 |
| 都不在意 | 这俩人处得踏实，但得让读者看出来他俩是商量好的 |
| 都在意但都不说 | 最有戏：俩人都偷偷备好了，谁都不吭声 |

「都偷偷准备了」能写成一出小喜剧。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的准备 | 提前订好位子 · 藏了东西（见 [07 卷第一条](07-馈赠与仪式.md#一--藏了很久的礼物)）· 请了假 |
| 她的状态 | 当天要开会 · 或者她也请了假，没吭声 |
| 试探 | 「今天几号来着」 |
| 撞车 | 两人订了同一家餐厅 · 买了对方已经有的东西 |
| 落点 | 一个只有他俩才懂的日子，比啥节日都顶用 |

对他们来说，自己的纪念日比公共节日要紧。这条线最后落到「一个只有他们两个才懂的日子」，见 [07-馈赠与仪式 · 一个只属于他们的仪式](07-馈赠与仪式.md#十--一个只属于他们的仪式)。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁记得 | 他 | 两个人都记得 |
| 过不过 | 认真过 | 说好了不过 |
| 意外 | 无 | 撞车／错过（转 [02 卷第八条](02-等待与错过.md#八--错过的纪念日)） |
| 私人日子 | 有 | 还没有 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他今天请了假 | 她今天一句都没提 |
| 好的处理 | 她也准备了，而且比他更早 | 他没因为她没提就蔫一整天 |
| 写崩 | 写成她砸钱搞大场面 | 写成他干等着她想起自己 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 上元／七夕／她的生辰／他们初见那日 |
| 修仙 | 结契日／她突破的那天／百年之期 |
| 星际 | 地球历的某天／他们第一次同航的日子 |

#### 写崩的三种方式

1. 写成惊喜派对。道理和 [07-馈赠与仪式 · 生日](07-馈赠与仪式.md#四--生日) 里那条警告一样。
2. 只写公共节日。这一条要写的是私人的日子，别写偏了。
3. 把不在意的那个写得冷淡。不在意节日和不在意人是两码事。

## 五 · 一起出门

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：旅行 35.7%（旅行＋约会、旅行＋请安高频同现）

**骨架**｜出门七十二小时，两个人怎么相处，全露出来了。

#### 节拍链

定攻略 → 出发 → 分工暴露 → 迷路或岔子 → 妥协（留半天不安排）→ 一张两人都嫌丑的合照 → 回程

#### 时间轴

七十二小时连着转，一天一个样。第一天就看得出谁管路线、谁管吃饭。第二天累到什么份上开始甩脸子，底线全露了。第三天想出了折中的办法：下午不排行程。回程那两个小时，要是各刷各的手机，回去就等着谈吧。还能聊上几句的，就算过关了。

#### 旅行暴露什么

| 环节 | 暴露 |
|---|---|
| 谁做攻略 | 平时怎么管着对方 |
| 谁背包 | 谁力气大谁干活 |
| 迷路时谁着急 | 遇事扛不扛得住 |
| 吃什么 | 谁肯先低头 |
| 拍照谁拍谁 | 见 [07-馈赠与仪式 · 合照](07-馈赠与仪式.md#五--合照) |
| 累了怎么办 | 谁先开口歇 |
| 出了岔子 | 吵架还是想法子 |

顺顺利利的旅行没什么可写，出了岔子那十分钟才有。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 行李箱 · 攻略（她列的表格）· 导航 · 车票 · 一张两人都嫌丑的合照 ✓ |
| 她的方式 | 全程有计划 · 每个环节都订好了 |
| 他的方式 | 想随便走走 |
| 摩擦 | 计划派 vs 随性派，这组最常吵也最真 |
| 妥协 | 她留出半天不安排 |
| 去哪儿玩 | 游乐园过山车上谁先叫 · 摩天轮两人关一起＋到顶倒计时 · 烟花（同一秒抬头）· 海边（平时不干的事可以干）· 夜市（边走边吃，互相喂）· 露营（一晚上不碰手机）· 温泉（浴衣，不化妆） |

「她留出半天不安排」算她让了一步。计划她还照做，只是里面留了块空白。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁安排 | 她全包 | 他偷偷做了一份 |
| 摩擦 | 无 | 因为行程吵了一次 |
| 岔子 | 无 | 丢东西／误车／下雨 |
| 收获 | 玩得开心 | 发现了对方的一面 |
| 性质 | 普通出游 | 蜜月（接 [23-婚嫁](23-婚嫁.md)：一样的旅行多了层仪式感，行李里多了两本证，酒店前台怎么称呼他们，谁也没纠正） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他也偷偷做了份攻略，没敢拿出来 | 她的表格细到每分每秒 |
| 内心 | 我是不是排得太满了 | 说想随便走走，她会不会觉得没劲 |
| 好的处理 | 她把他写的那项也加进去了 | 他说了他真正想去的地方 |
| 写崩 | 写成她从头指挥到尾 | 写成他一步不离跟着走 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 同行赴任／游历／她带他回乡 |
| 修仙 | 同去秘境／历练／她带他上山 |
| 星际 | 跨星系航行／一次休假 |

#### 写崩的三种方式

1. 写成风景游记。 人比景重要。
2. 全程顺利。 岔子才是内容。
3. 让他从头跟到尾。他得说出一个自己想去的地方。

## 六 · 出了岔子

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：旅行 35.7% ＋ 危险 18.1%

**骨架**｜丢了东西，误了车，订错了，出事那十分钟看得出两个人扛不扛得住。

#### 节拍链

出事（票·证件·订错）→ 半秒懵 → 她掏手机处理或先笑出来 → 分头 → 解决或报废 → 很难吃的一顿饭

#### 时间轴

先懵半秒，三秒弄清怎么回事，一分钟内分头去办，她打电话，他跑窗口，从出事到解决一共十分钟。搞不定就马上换B计划，改签、补办、认栽，哪种都算收了场。那顿饭难吃得让人记到现在，可两小时后重新坐下来吃，味道全变了，成了庆功宴加复盘会。多年以后，这点难吃还能翻出来当笑话。

#### 反应的四种，等级递增

| 反应 | 关系怎么样 |
|---|---|
| 互相埋怨 | 最差 |
| 一个人扛下来解决 | 常态，但另一个人会没位置 |
| 分头处理 | 好 |
| 先笑出来，再处理 | 最好 |

「先笑出来」最难写，也最能看出两个人处到了哪一步。关系成熟了，碰上意外，头一个反应是觉得荒唐。

#### 可用细节

| 类 | 内容 |
|---|---|
| 岔子的类型 | 证件丢了 · 航班取消 · 订错了日期 · 语言不通 · 钱包被偷 |
| 她的第一反应 | 拿出手机 ✓ 开始处理 |
| 他的第一反应 | 先看她的脸色 |
| 转折 | 有件事只有他能办（转 [16 卷第九条](16-危机与保护.md#九--他能做到的那件事)） |
| 收尾 | 事办完了，俩人一块吃了顿特难吃的饭 |

解决完再吃一顿很难吃的饭，比圆满收场好。狼狈也是两人共有的回忆。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁的错 | 她 | 他 |
| 谁解决 | 她 | 他 |
| 有没有埋怨 | 没有 | 有一句，之后后悔了 |
| 结果 | 解决了 | 没解决，行程报废 |

**「她的错」这一版值得写。** 一向什么都对的人难得错一回，还得自己认下来。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 是她订错的 | 她愣住的那一秒 |
| 内心 | 这次是我的问题 | 别说，什么都别说 |
| 好的处理 | 她直接认了，不找补 | 他说了「没事，正好」 |
| 写崩 | 写成她永远没错 | 写成他借机数落 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 走错了路／驿站客满／盘缠被偷 |
| 修仙 | 传送阵出错／秘境提前关闭 |
| 星际 | 航线关闭／跃迁失败／补给不够 |

#### 写崩的三种方式

1. 让她从不出错。让她错一回，人就活了。
2. 靠一个人逞英雄解决。分头去办、各管一摊更好。
3. 收得太圆满。那顿最难吃的饭要写。

## 七 · 换季

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：冷热 25.4%

**骨架**｜换季收衣服，翻出了旧东西。

#### 节拍链

翻箱倒柜 → 「这个还要吗」循环 → 翻出旧物 → 忽然安静 → 一件谁都没提就放回去了 → 收尾

#### 时间轴

头一个小时还像在流水线上，要的一堆，不要的一堆，捐的一堆，到后半段，手上越来越慢。翻出那件旧东西时，两个人围着它站了好几分钟，谁都没开口。后来也没人提，它又回到了柜子里。关上衣柜门，两个人还是没说话。换季的活儿是收了尾，有些东西又跟着留了一年。

#### 换季的功能：清点

用不着另外交代时间，收拾一遍衣柜，这一年就清点了一遍：

| 翻出来的 | 说明 |
|---|---|
| 去年买的还没穿过的 | 这一年过得多快 |
| 他的衣服在她柜子里占了多少 | 关系的进展 |
| 一件旧的舍不得扔 | 见 [15-秘密与坦白 · 他一直留着的东西](15-秘密与坦白.md#九--他一直留着的东西) |
| 一件不是他也不是她的 | 前任／来客／一个待解释的东西 |
| 尺码不合了 | 身体变了 |

翻出「一件不是他也不是她的」，一场戏马上就能起来。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场景 | 俩人一块儿收拾 · 要不就他自个儿收拾 |
| 对话 | 「这个还要吗」——这话问了好几遍了 |
| 分歧 | 他非扔，她拦着 · 要不就反过来 |
| 味道 | 樟脑球 · 洗衣粉 · 箱子底下压久了的味儿 |
| 落点 | 有件东西谁也没吭声，又放回去了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁收拾 | 他 | 一起 |
| 翻出什么 | 旧照片 ✓ | 一件不该在这儿的东西 |
| 扔不扔 | 扔了一批 | 什么都没扔 |
| 情绪 | 日常 | 忽然安静下来 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他衣服多到柜子快塞不下 | 她去年就说要扔这件 |
| 好的处理 | 她没扔，把那件旧的放回去了 | 他看见那件不认识的，没问是谁的 |
| 写崩 | 写成她对着旧衣服掉眼泪 | 写成他借这事翻旧账吵一架 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 换季裁衣／箱笼清点／旧年的料子 |
| 修仙 | 整理储物袋／百年前的旧物 |
| 星际 | 私人物品配额清理／舱位重新分配 |

#### 写崩的三种方式

1. 写成怀旧散文。挑两件东西写就行。
2. 不写「这个还要吗」。来回问的这一句，就是整场的节拍。
3. 拿它揭大秘密。用小东西带出大情绪。

## 八 · 年底

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：节日 33.3% ＋ 加班 25.4%

**骨架**｜她忙得脚不沾地的那阵子，他基本见不着她。

#### 节拍链

冲刺开始 → 连续晚归 → 他忍着 → 某天说了一句 → 她抽了半小时回家吃饭 → 忙完的第一个周末 → 下一个周期

#### 时间轴

冲刺期一个月，两人见面一周比一周少。第一周还能一起吃晚饭，第二周只剩早饭，到第三周，就剩睡前那半小时，还常常对不上。他那句话忍了两周，到第三周周末才说出口。她后来抽空回来补了顿饭，只有三十分钟，手机一直扣在桌上没碰。时间给不够，就拿态度补。忙完那个周末，她一整天都陪着他，算是补偿。然后下一轮又忙起来了。

#### 年底的双重压力

| 压力 | 落在谁身上 |
|---|---|
| 工作冲刺 | 她 |
| 应酬 | 她 |
| 一个人过的晚上 | 他 |
| 各种「你们什么时候……」 | 两个人 |

**这一族所有等待类的桥段，到年底会一起发作**，见 [02-等待与错过](02-等待与错过.md)。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的状态 | 连着两周没在十点前回来 · 睡不够 · 体检报告 ✓ 拖着没看 |
| 他的状态 | 做好的饭 ✓ 一次次热（转 [02 卷第一条](02-等待与错过.md#一--等门与热菜)） |
| 他做的事 | 把她的日程理了一份 · 到点提醒她吃药 ✓ |
| 冲突 | 他忍了两周，某天实在没忍住，开了口 |
| 收束 | 忙完之后的第一个周末 |

「忙完之后的第一个周末」必须写。要补就拿时间补，送东西补不了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的态度 | 完全支持 | 忍了很久 |
| 她的察觉 | 察觉了 | 忙到没察觉 |
| 冲突 | 有 | 无（但有代价） |
| 之后 | 补上了 | 又进入下一个周期 |

「又进入下一个周期」这样收尾最真实。年底过去还有年中，这事不会只来一次。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她翻到他整理的那份日程表 | 这是这周第四次一个人吃饭 |
| 内心 | 我已经两周没跟他说过一句完整的话 | 忍到过完这阵 |
| 好的处理 | 她在最忙的时候抽了半小时回家吃饭 | 他说了那句，说得不难看 |
| 写崩 | 写成她事业与感情二选一 | 写成他埋怨她工作 |

她抽半小时回家吃顿饭就行，用不着把工作推掉。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 年关政务／她连日不归／他在府中等 |
| 修仙 | 宗门大典／她主持事务／闭关期临近 |
| 星际 | 年度考核／舰队调防 |

#### 写崩的三种方式

1. 写成事业感情二选一，这本就是假问题。
2. 靠推掉工作来解决。抽出半小时更真实。
3. 一忙完就圆满了。下一轮还会来。

## 九 · 一年过去了

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：节日 33.3%

**骨架**｜同一天，又来了一遍。

#### 节拍链

同一个日子 → 同一家店同一桌 → 细节对照谁做饭、坐哪、称呼 → 一样没变的 → 说破或都没提

#### 时间轴

去年那顿他紧张得点错了菜，今年他熟门熟路，还加了她爱吃的那道。两次中间隔了整整一年。变了的一项项列出来，左右两栏对着写，一样没变的放在最后，比如还是那家店那张桌。去年称呼还生分，今年老板娘都认得他们了。说破也好，不说破也好，都能收尾。

#### 年度对照表

这条的写法是**把去年那一场原样再写一遍，只改动细节**：

| 项 | 去年 | 今年 |
|---|---|---|
| 谁做的饭 | 他 | 还是他，但她洗碗了 |
| 坐哪 | 各坐一头 | 挨着 |
| 说了什么 | 客气 | 没说话，但都自在 |
| 谁先睡 | 他等她 | 两个人一起 |
| 那件事 | 他没敢提 | 提了 |

**改动越小越好。** 一年的变化如果需要大幅改写才能看出来，那说明关系变得太快，不真实。

#### 可用细节

| 类 | 内容 |
|---|---|
| 锚点 | 还是那家馆子 · 还是那个座 · 还是那道菜 |
| 物证 | 去年的照片 ✓ 跟今年摆一起看 · 同一件衣裳 ✓ |
| 变化 | 叫法不一样了 · 做某个动作顺不顺 · 东西挪了地方 |
| 没变的 | 至少留一样，从头到尾没动过 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 方向 | 变好了 | 变淡了，同样的写法反过来 |
| 时间跨度 | 一年 | 十年 |
| 谁在对照 | 她 | 他 |
| 说不说破 | 说了「去年这时候……」 | 谁都没提 |

「变淡了」那一版照样这么写，只是往反方向走。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他今年没提前订位，反正也不用订了 | 去年这时候我还喊她全名 |
| 好的处理 | 她没把话说破 | 他啥都记得 |
| 写崩 | 写成倒叙回忆 | 写成他年终汇报 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 又一年上元／同一处灯／她的位次变了 |
| 修仙 | 百年一度／同一个日子他的修为变了 |
| 星际 | 同一条航线／舷窗外同一片星域 |

#### 写崩的三种方式

1. 大段回忆。 用对照，不用回忆。
2. 变化太大。 越小越好。
3. 只写变好的。也反过来用一回。

## 十 · 春夏秋冬

<!-- gb-nonscene -->
`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：冷热 25.4% ＋ 节日 33.3%

**骨架**｜拿春夏秋冬给整本书的感情线分段。

#### 四季的情绪配置

下面这张分章表拿来就能用：

| 季 | 适合放什么 | 为什么 |
|---|---|---|
| 春 | 初遇、试探、第一次约 | 万物刚醒，天气也舒服，不用硬找事 |
| 夏 | 冲突、爆发、最热烈的部分 | 热得人烦躁，衣服也穿得少 |
| 秋 | 稳定期、日常、隐忧浮现 | 一边收成，一边叶子开始掉 |
| 冬 | 危机、分离、或者最暖的部分 | 冷的时候想抱团，也容易出事 |

按春夏秋冬分四章，写长篇能省不少力气。

#### 每一季的专属物件

| 季 | 物件 |
|---|---|
| 春 | 薄外套 ✓ · 雨 ✓ · 换季的衣柜 |
| 夏 | 空调 ✓ · 冰镇的东西 · 汗 · 蝉 · 台风 |
| 秋 | 长袖 · 第一次降温 ✓ · 落叶 · 中秋 ✓ |
| 冬 | 暖气 ✓ · 围巾 ✓ · 雪 ✓ · 手炉 · 过年 ✓ |

#### 用法

| 用法 | 说明 |
|---|---|
| 分章 | 一季一部分 |
| 循环 | 两轮四季，同一个季节对照写 |
| 单季 | 全书发生在一个夏天（强度最高） |
| 逆序 | 从冬写到春（复苏结构） |

「全书发生在一个夏天」适合写短篇。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 跨度 | 一年 | 十年（每年只写一天） |
| 结构 | 顺序 | 对照（去年今年交替） |
| 收尾的季节 | 春（新生） | 冬（沉淀） |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 二十四节气／农时／科考和朝会一年一轮 |
| 修仙 | 百年算一季／灵气涨落／宗门大比隔几年办一次 |
| 星际 | 没四季（得自己定）：赶路分几段、跃迁要等多久、补给撑几天 |

星际版没有现成的四季，周期得自己定。

#### 写崩的三种方式

1. 每一季都写景。挑物件写，风景省掉。
2. 季节和情绪对不上。夏天也能写离别，只是要有个理由。
3. 四季写得一样重。挑一季重点写。
