> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 现代都市为主
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**玩是唯一一个可以合法暂停权力关系的场合，而暂停之后怎么恢复，才是内容。**

## 为什么这一族值得单开

前面十八卷写的都是实打实的东西。这一卷写的是**不实打实的东西**。可一段关系里要是全是实打实，人会累垮的。

玩闹的功能：

| 功能 | 说明 |
|---|---|
| 减压阀 | 前面积累的紧张需要一个出口 |
| 平权区 | 打游戏时她可能输给他 |
| 试探场 | 用玩笑说真话 |
| 私人语言 | 只有他们懂的梗 |

「打游戏时她可能输给他」是这一族最重要的一句。一个能合法赢她的场合，对他这个角色来说是刚需。

## 一 · 第一条消息

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.0%

**骨架**｜加上之后，谁先发，发什么，隔了多久。

#### 节拍链

加上了 → 草稿删改 → 借口成立 → 发出 → 等回复的六小时 → 她回了，或她主动发来一条

#### 时间轴

从发出去到对方回，隔了六个小时。前四十分钟他盯着输入框，打了删，删了打，后六个小时手机扣在桌上，隔十分钟就翻过来看一眼。他哪知道她其中五个半小时在开会，只觉得那六小时就是一场漫长的审判。她其实只晚了六小时回，草稿从加上到发出去，改了四十分钟。

#### 三个数字就是全部

| 数字 | 说明 |
|---|---|
| 隔了多久 | 三天是常见的煎熬期 |
| 删改了几遍 | 他的版本数 |
| 最后剩几个字 | 通常极短 |

「删改了十七遍最后发出去四个字」是这条最有效的一句。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的草稿 | 「在吗」→「今天谢谢你」→ 删掉 →「[表情]」 |
| 借口 | 找个由头联系她，比如还东西、问事、发文件 |
| 她的回复 | 秒回 · 隔了六小时 · 一个字 |
| 他的解读 | 那六个钟头他每分钟都在琢磨 |
| 转折 | 她先发来了一条 |

「她主动发来一条」在他那里的重量，是他发十条的十倍。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先发 | 他 | 她 |
| 借口 | 有 | 没有 |
| 她的回复速度 | 秒回 | 很久 |
| 之后 | 聊起来了 | 断了，很久以后才续上 |
| 认识顺序 | 先见人后加号（本条默认） | 先网后面（网恋线：聊了半年才奔现，见面那天是 [11-初遇与确立 · 第一眼](11-初遇与确立.md#一--第一眼)的延迟版——声音和头像先入为主，真人对不对得上号是开局考题，认出对方的方式最好不是脸，是说话的节奏） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她随手回的那一句 | 输入框里的第十七版 |
| 内心 | 这人怎么这么客气 | 会不会打扰她 |
| 好的处理 | 她回得短，但好歹回了 | 他发完就把手机扣桌上 |
| 写崩 | 写成她故意不理人 | 写成他翻来覆去想三章 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 第一封信／写了三张废了两张／托人捎的一句话 |
| 修仙 | 第一道传音／他犹豫了三天才发 |
| 星际 | 第一条私人频道通讯 |

#### 写崩的三种方式

1. 让他纠结太久。 一场戏，不要一章。
2. 让她故意晾着。 她只是在忙。
3. 省略草稿。 那十七版就是全部内容。

## 二 · 聊天记录

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.0%

**骨架**｜聊天记录从头翻到尾，就是两个人关系的全部。

#### 节拍链

日常累积 → 长度差与速度差 → 一条撤回 → 她往上翻 → 翻到最早 → 这次多回了两句

#### 时间轴

聊天窗口自带时间戳，往上翻多少，就等于往过去走了多远。她那天晚上往上翻，从今天翻到上个月花了十分钟，翻到最早那条用了半小时。越早的消息他说话越客气，敬语什么时候开始消失的，时间戳记得一清二楚。翻完回到输入框，这次她多回了两句：考古改变了当下的语速。

#### 可读的六项

| 项 | 读作 |
|---|---|
| 消息长度差 | 他的长她的短，这是常态 |
| 回复速度差 | 谁在等谁 |
| 谁发起话题 | 主动方 |
| 表情包的用法 | 他用得多，拿来缓冲 |
| 语音还是文字 | 语音更亲密 |
| 撤回了什么 | 最有戏的一项 |

**「他撤回了一条」是这条最好用的爆点：** 撤回本身就是内容，而她看见了「撤回了一条消息」。

#### 可用细节

| 类 | 内容 |
|---|---|
| 界面细节 | 「对方正在输入」闪一下又没了 · 已读不回（见 [02 卷第三条](02-等待与错过.md#三--消息已读不回)） |
| 时间戳 | 凌晨两点发的那条 |
| 长度对照 | 他打了一大段，她回了个「嗯」 |
| 他的自我审查 | 字打完了又全删掉，最后发了个「好」 |
| 翻旧记录 | 她没事往上翻，翻到好几个月前 |

**「她往上翻」是这条的抒情用法**，且它不需要任何回忆描写——记录本身就是回忆。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁翻记录 | 她 | 他 |
| 撤回 | 有 | 无 |
| 长度差 | 明显 | 后来变均衡了（关系的进展） |
| 用途 | 甜 | 分手后再翻（同样的技法） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她往上翻，发现自己以前都只回一个字 | 「对方正在输入」出现了又消失 |
| 好的处理 | 她注意到了，这次多回了两句 | 他没有为「嗯」多想 |
| 写崩 | 大段聊天记录直接贴 | 他分析每一个标点 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 一叠书信／字数与频率／她的回信越来越长 |
| 修仙 | 传音玉简的存留／神识里的痕迹 |
| 星际 | 通讯日志／延迟造成的错位对话 |

#### 写崩的三种方式

1. 大段贴聊天记录。 挑三条。
2. 让他过度解读标点。 一次可以，反复就病态。
3. 忽略撤回。 那是最省字的一刀。

## 三 · 打游戏

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：游戏 21.0%（游戏＋上药、游戏＋做饭高频同现）

**骨架**｜她在这世上未必比他强，可这事对他们俩来说，都够呛。

#### 节拍链

组队 → 他换了个人（开始指挥）→ 她听他的 → 输赢 → 她不服再来 → 现实身份回来的那一刻

#### 时间轴

她盯着他看了三秒：刚才那个人呢？摘下耳机那秒，现实身份就回来了。可进了语音他完全变个人——话少、判断快、敢直接喊她ID，让她「别送」。一局二十分钟，加载完那一秒，身份就换了。输赢一局一算，她一句"再来"，三局起步。他放下麦就变回平时那副样子。

#### 这条为什么必须有

他需要一个能赢的场合。不为翻身，只为证明这段关系不是单向的服从。

而她需要一个能输的场合。一个从来没输过的人，是不完整的。

#### 四种配置

| 配置 | 效果 |
|---|---|
| 他强她弱 | 他带她（见 [11 卷第六条](11-初遇与确立.md#六--她教他) 反着来）· 最顺手 |
| 她强他弱 | 跟平常一样，没啥戏 |
| 势均力敌 | 有较劲的感觉，能写很久 |
| 她故意输 | 他会看出来，心里还不爽 |

「她故意输」这一端要处理。 被让着赢，比输更伤人。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场景 | 开黑 ✓ · 双人游戏 · 排位 ✓ · 她被队友骂 · 他护着 |
| 他的状态 | 在这儿他话变多，语气也不一样 · 她头回听他这么说话 |
| 她的状态 | 玩得太当真，输了就拉脸 |
| 摩擦 | 她菜还不服 · 他不敢明说 |
| 落点 | 她输了，撂一句「再来一把」 |

「她第一次听见他这样说话」是这条最有价值的观察。 游戏里的他是另一个人。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁强 | 他 | 她 |
| 她输了 | 服气 | 不服，非要再来 |
| 他的处理 | 认真赢 | 放水（会被发现） |
| 有没有赌注 | 无 | 有（见 [四 · 打赌](#四--打赌)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他打游戏时指挥得有模有样 | 这局她听我的 |
| 内心 | 原来他也会这么说话 | 在这儿我说了算 |
| 好的处理 | 她真按他说的来了 | 他没让着她 |
| 写崩 | 把她写得样样都行 | 把他写成拿游戏耍威风 |

这条的最优解是「她真的听他的了」。在一个他更懂的领域里，她服从了，且这不需要任何解释。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 下棋／投壶／射覆／他棋艺胜她 |
| 修仙 | 论道／某一门他更精通／炼器 |
| 星际 | 模拟战／某类机型他更熟 |

**古代版的「下棋」不必另找理由让她退位**：棋盘上没有身份。

#### 写崩的三种方式

1. 让她在所有领域都强。她要有输的地方。
2. 让他放水。认真赢才是尊重。
3. 忽略他在游戏里的另一副样子。那是这条的观察点。

## 四 · 打赌

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：游戏 21.0%

**骨架**｜赌注是什么，比谁赢更重要。

#### 节拍链

起赌约 → 定赌注 → 认真程度超预期 → 分胜负 → 他说不出要什么 → 「你慢慢想，我记着」→ 兑现那天

#### 时间轴

赌注是当场定的，赌局只用了十分钟，可他赢下之后，却迟迟没开口要什么。她也不催他，只留下一句「你慢慢想，我记着」，那笔赌债便悬在了两人之间。之后几个月，她隔三差五拿这事逗他：「想好没」。等到兑现那天，他要的东西小得让她愣住——吊了三个月，就为这个？就为这个。

#### 赌注的分级

| 赌注 | 关系含义 |
|---|---|
| 一顿饭 | 无 |
| 洗一周碗 | 家务的调剂 |
| 「答应我一件事」 | 空头支票，最有戏 |
| 「叫我一声……」 | 称呼，见 [11 卷第五条](11-初遇与确立.md#五--改口) |
| 「今晚听我的」 | 权力临时换手 |
| 一个问题的真话 | 最狠 |

**「今晚听我的」就是这一族和 [08-规训日常版](08-规训日常版.md) 的分水岭**：说白了，就是一次你情我愿、说好什么时候结束、拿游戏当幌子的权力倒转。

#### 可用细节

| 类 | 内容 |
|---|---|
| 提议 | 谁先提的赌约 · 对方有没有跟着加注 |
| 过程 | 本来闹着玩，越玩越当真 |
| 结果 | 谁赢了 · 有没有赖账 |
| 兑现 | 怎么兑现，才是这段的重头戏 |
| 落差 | 他赢了，却不知道想要啥 |

「他赢了，但不知道该要什么」是这条最好的一版。 长期不索取的人，突然有了索取的权利，会愣住。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁赢 | 他 | 她 |
| 赌注 | 小 | 「答应我一件事」 |
| 兑现 | 立刻 | 他一直没用那个权利 |
| 耍赖 | 无 | 有，谁耍赖也是信息 |

**「他一直没用那个权利」可以埋很久**，直到某一章他终于用了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他赢了，却半天说不出想要啥 | 我能要点啥 |
| 内心 | 他压根没往那想过 | 想要的那个，张不开嘴 |
| 好的处理 | 她说「不急，你慢慢想，我记着」 | 他最后开口，要的只是一件小事 |
| 写崩 | 写成她说话不算话 | 写成他张嘴就要一大堆 |

「他最后要的是一件小事」比要一件大事动人得多。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 赌一局棋／她许他一诺／可用一次的令牌 |
| 修仙 | 论道输了应一件事／一枚可召她的符 |
| 星际 | 一次优先权／她给他一个权限 |

**「一个可以用一次的东西」是这条最好的物化形式**：令牌、符、权限，握在他手里，看得见。

#### 写崩的三种方式

1. 让她赖账。 一次都不行。
2. 让他要一件大事。 小事更重。
3. 立刻兑现。 存着更有戏。

## 五 · 捉弄

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：捉弄 20.0%，捉弄＋吃醋、捉弄＋洗漱高频同现

**骨架**｜她逗他，逗着逗着就过了。

#### 节拍链

起意 → 演 → 他配合或信了 → 他眼神变了 → 她立刻收手 → 道歉 → 「刚才那个别再来了」

#### 时间轴

安全时间掐得刚刚好，也就两三分钟，超过这个限度玩笑就变味了。她反应极快，半秒就能收手、道歉，演到对方眼神变了的那个瞬间，立刻停。界限就永远定住了，从「刚才那个别再来了」这句话一出口开始。这条线划下来之后，后面再怎么闹都不会出事。

#### 那条线在哪

| 判据 | 是逗 | 是欺负 |
|---|---|---|
| 他有没有笑 | 有 | 没有 |
| 有没有旁人 | 私下 | 当众 |
| 触及的是什么 | 小事，不往心里去 | 他最在乎的那点事 |
| 能不能反击 | 能 | 不能 |
| 她会不会停 | 他一皱眉就停 | 接着来 |

「他一皱眉就停」是唯一可靠的判据。

#### 捉弄的清单

| 做什么 | 分量 |
|---|---|
| 藏他的东西 | 轻 |
| 假装忘了他的生日 | 中 |
| 学他说话 | 中 |
| 当着人叫他的小名 | 中高 |
| 假装要走 | 高，且危险 |
| 假装不认识他 | 高，且要谨慎 |

「假装要走」这一档要小心。 对一个本来就没有安全感的角色，这个玩笑会真的伤到。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的方式 | 面不改色 · 装得跟真的一样 |
| 他的识破 | 他其实早看出来了 · 但没拆穿 |
| 反击 | 他也会反过来逗她（重点） |
| 分寸 | 她到某个点就停了 |
| 落点 | 他后来才说「你刚才真把我唬住了」 |

「他也会捉弄回去」是这条最重要的一栏。 单向的捉弄是权力展示，双向的才是玩。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁捉弄谁 | 她 | 他（少见，且很好玩） |
| 场合 | 私下 | 有人在 |
| 他的反应 | 配合 | 真的被吓到 |
| 收场 | 都笑了 | 她道歉了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看他眼神不对，马上停了 | 有一瞬间我差点当真 |
| 好的处理 | 她认真道了歉，不是敷衍 | 他撂了句「刚才那样别再有了」 |
| 写崩 | 写成她没完没了地折腾 | 写成他啥都忍，没一点底线 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 逗他／故意冷落一日／假意要纳新人 |
| 修仙 | 藏起他的法器／假装认不出他 |
| 星际 | 改他的权限／假装调走他 |

**「假意要纳新人」在古代女尊里是极危险的玩笑**，因为那在制度上是可以真的发生的。

#### 写崩的三种方式

1. 单向捉弄。他要能还手。
2. 触及他真正在意的。那不是玩笑。
3. 让她不收手。收手的那一下才是这条的品格。

## 六 · 只有他们懂的梗

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：捉弄 20.0% ＋ 社交网 33.0%

**骨架**｜一句话旁人听着摸不着头脑，俩人一对眼就笑了。

#### 节拍链

一次事故成了梗 → 反复使用 → 当众用，全场只有两人笑 → 「没什么」→ 某天没接上 → 收尾处再现

#### 时间轴

**梗的生命周期以年计。** 诞生于某次事故，十秒钟的意外。成形于反复引用，头一个月高频。成熟于当众使用，全场只有两人笑。沉淀为日常缩写。「某天没接上」是梗的中年危机，隔了太久，一方忘了。收尾处的再现是它的返场，多年后一个词砸下来，两个人还是同时笑了。

#### 私人语言的构造

| 来源 | 例 |
|---|---|
| 一次失败 | 他做糊的那顿饭 |
| 一个口误 | 她说错的一个词 |
| 一个共同的糗事 | 出岔子的那次旅行 |
| 一个外号 | 只有他们这样叫某个人 |
| 一个数字 | 那天的房号、车牌 |

私人梗的价值在于它不可转让。 别人听见了也进不去。

#### 三个用法

| 用法 | 说明 |
|---|---|
| 建立亲密 | 当众用一次，全场只有两个人在笑 |
| 计量疏远 | 某天她没接上那个梗 |
| 收尾 | 结局处它再出现一次 |

「某天她没接上那个梗」是这招最狠的地方。跟 [07-馈赠与仪式 · 一个只属于他们的仪式](07-馈赠与仪式.md#十--一个只属于他们的仪式) 里那个“打破仪式”的套路是一个道理。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 一桌子人 · 会议上 · 微信群 ✓ |
| 表现 | 两个人同时笑 · 别人问「什么意思」 · 他们说「没什么」 |
| 排他性 | 一句「没什么」，外人就进不来了 |
| 频率 | 用多了招人烦，一本书顶多来三次 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先用 | 她 | 他 |
| 场合 | 私下 | 当众 |
| 别人的反应 | 追问 | 没注意 |
| 后来 | 一直在用 | 有一天没人再提了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她说完那句，全桌只有他笑了 | 她还记得 |
| 好的处理 | 她对别人说「没什么」 | 他没有向别人解释 |
| 写崩 | 写成刻意秀默契 | 写成他反复提醒她那个梗 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 一句典故／她给他起的字／只有两人知道的旧事 |
| 修仙 | 一个手势／神识里的一个符号 |
| 星际 | 一段代码／一个坐标 |

#### 写崩的三种方式

1. 用太多次。 三次。
2. 跟读者解释这个梗多好笑。 不如让读者也进不去。
3. 只用在甜的场合。 真正要紧的是没接上的那次。

后接：[七 · 一起看片](#七--一起看片)

## 七 · 一起看片

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.0% ＋ 睡着 54.0%

**骨架**｜沙发上一坐，手机亮着，谁也没心思看。

#### 节拍链

选片 → 开场 → 谁先没在看 → 靠过来或睡着 → 剧情引出一个话题 → 字幕滚完没人动

#### 时间轴

注意力撑不过二十分钟，片长却有两小时。字幕滚完，屏幕蓝光还亮着，没人伸手去按暂停，谁都不想先开口结束这个晚上。前二十分钟还认真在看，之后有人翻手机，有人打量起旁边的人。第七十分钟前后，有人睡着了，靠过来的重量一点点压上来。

#### 这条的功能：容器

它本身没有内容，但它是**最好的对话容器与时间容器**：

| 需要什么 | 放这里 |
|---|---|
| 一场随意的对话 | 看片时最自然 |
| 一次靠近 | 靠肩、盖毯子 |
| 一次睡着 | 见 [06-身体接触 · 靠肩](06-身体接触.md#四--靠肩) |
| 一个话题的引子 | 剧情带出来的 |
| 时间流逝 | 一部片子的功夫 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 沙发 ✓ · 毯子 ✓ · 遥控器归谁 · 零食 · 灯 ✓ 关不关 |
| 选片 | 谁挑的 · 她挑的他没兴趣，但也没吭声 |
| 中途 | 有人看睡了 · 有人去倒水 · 停了好几回 |
| 讨论 | 剧里一件事，聊到了俩人自己 |
| 结束 | 片尾字幕走完，谁也没动弹 |

「因为剧情里的一件事聊到了自己」是这条最有效的用法。 借别人的故事说自己的事。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁选片 | 她 | 他 |
| 看没看进去 | 看了 | 都没在看 |
| 睡着 | 他 | 她（她太累了） |
| 引出的话题 | 无 | 一件他们一直没谈的事 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他半小时没换姿势，原来睡着了 | 她选的这个我看不下去，但我不说 |
| 好的处理 | 她把片子暂停了 | 他后来说了他想看的那个 |
| 写崩 | 写成她全程主导选片 | 写成他一味迁就 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 一起听戏／看话本／她念他听 |
| 修仙 | 观星／看留影石里的旧事 |
| 星际 | 舷窗外的星图／舰上的旧影像资料 |

#### 写崩的三种方式

1. 详细复述片子内容。 片子只是容器。
2. 让他全程迁就。 他要说一次自己想看的。
3. 忽略「都没在看」。 那才是这条的实情。

## 八 · 网上的另一个他

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.0%

**骨架**｜她发现了他的另一个账号。

#### 节拍链

算法推荐 → 认出细节 → 她往下翻 → 三年前那条 → 关掉或继续 → 说不说破 → 他删没删号

#### 时间轴

她把三年的另一个他按时间倒序摊开，一条条铺在眼前。最早那条，发在他们认识之前，认出他只需要一个杯子，或者一只手，那么短。往下翻的那两个小时里，她纠结了三天，要不要说破。算法一秒给出的结果，她翻了一整晚才看完。他到底删没删号，这条没写死。删了，两条线并成一条。没删，是给自己留了间屋子。两种结局，都说得通。

#### 这条的三种走向

| 账号里是什么 | 走向 |
|---|---|
| 他的爱好／作品 | 甜。她发现了他没露过的一面 |
| 关于她的记录 | 甜里带惊。他写了不少跟她有关的 |
| 他的抱怨 | 疼。他在网上说了当面不敢说的话 |
| 一段旧关系 | 转 [15-秘密与坦白 · 前任出现](15-秘密与坦白.md#四--前任出现) |

**第三种最有价值。** 匿名账号是他唯一可以不扮演的地方，而她闯进去了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 发现方式 | 刷推荐刷到 · 朋友转发 · 一个眼熟的词 |
| 认出的证据 | 一张照片 ✓ 的边角 · 一句口头禅 · 一个只有她知道的细节 |
| 她的处理 | 划走 · 或者往下翻了很久 |
| 内容 | 三年前的一条 · 隔了这么久，这条才显出分量 |
| 之后 | 点破还是装没看见 |

「往下翻了很久」这个动作就是这条的全部张力。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 内容 | 无害 | 关于她的抱怨 |
| 她的处理 | 不说破 | 说了 |
| 他知不知道被发现 | 不知道 | 知道，且删号了 |
| 结果 | 她更懂他了 | 他失去了唯一的出口 |

「他失去了唯一的出口」是这条最疼的收尾。 被理解的代价是没有了藏身处。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 三年前那一条 | 她可能看见了 |
| 内心 | 这些他从来没跟我说过 | 那是我唯一说真话的地方 |
| 好的处理 | 她没挑明，但悄悄改了做法 | 他没删号 |
| 写崩 | 写成她盯梢查岗 | 写成他网上网下两个人 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他的私人手札／写了没寄的信／他题在墙上的字 |
| 修仙 | 他的心魔／神识深处的一处 |
| 星际 | 加密日志／私人航行记录 |

#### 写崩的三种方式

1. 写成查岗。 她是无意发现的。
2. 让内容太重。 一句抱怨够了。
3. 当场对质。 不说破更有力。

## 九 · 拍照

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：看照片 5.0%

**骨架**｜手机相册就是这段关系的底账。

#### 节拍链

他偷拍成习惯 → 数量差 → 她第一次举起手机拍他 → 他愣住 → 设成屏保或收进相册 → 某天翻相册

#### 时间轴

那天晚上俩人把相册摊开，时间线一对，居然拼成了一条完整的。她手机里存了他三十张，他手机里存了她九百张，这个比例僵了整整两年。头一回是她主动举起手机拍他，快门响了一下，他愣了三秒。后来那三十张慢慢往上加，涨得慢，但再也没停过。翻盘只用了一秒，数量差却是按年攒出来的。

#### 相册的构成学

| 统计项 | 读作 |
|---|---|
| 她的照片有多少张 | 他拍的 |
| 他的照片有多少张 | 她拍的，通常少得多 |
| 合影有多少张 | 关系公开到啥程度 |
| 有没有偷拍 | 见 [15-秘密与坦白 · 他一直留着的东西](15-秘密与坦白.md#九--他一直留着的东西) |
| 最早的一张 | 啥时候开始的 |
| 谁在谁的手机屏保上 | 最直接的一项 |

「他拍她的三百张，她拍他的六张」是这条最有效的数据对照。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他拍的 | 她没看镜头的时候 · 她工作时 · 她睡着 ✓ |
| 她拍的 | 少，但每张都有由头 |
| 她的第一次拍他 | 打这儿起就不一样了 |
| 删照片 | 出了事，头一件事就是删 |
| 洗出来的那张 | 见 [07-馈赠与仪式 · 合照](07-馈赠与仪式.md#五--合照) |

「她第一次拍他」这个动作可以撑起一整场戏。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 数量差 | 悬殊 | 后来变均衡 |
| 她拍的 | 没有 | 有一张，且她设成了屏保 |
| 偷拍 | 有 | 无 |
| 用途 | 甜 | 分手后删照片，同一张清单反过来 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她翻自己相册，发现他只有六张 | 她今天拍我了 |
| 好的处理 | 她开始拍他 | 他没提过这茬 |
| 写崩 | 写成她突然开窍猛补拍 | 写成他挨个数照片 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 画像／她画的他／他描的她 |
| 修仙 | 留影石／她存了几段 |
| 星际 | 影像记录／私人存储配额分给了谁 |

#### 写崩的三种方式

1. 忽略数量差。 那是这条的地基。
2. 让她突然大量补拍。 一张就够。
3. 写成秀恩爱。 私密性是这条的价值。

## 十 · 无聊的下午

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：睡着 54.0% ＋ 社交网 33.0%

**骨架**｜什么都没发生。可「什么都没发生」才是这题材里最难写、也最该写的一场。

#### 节拍链

各做各的 → 脚搭上来 → 三句废话 → 光移过地板 → 有人睡着 → 「吃什么」→ 起身

#### 时间轴

光从茶几挪到沙发脚，冰水杯壁上的水珠从密到干，有人呼吸着呼吸着就睡着了。三个小时，屋里唯一的钟是地板上的光斑，没别的事发生，时间就靠这些物理动静来显影。「吃什么」是这段里唯一的台词兼闹钟，它一响，下午就结束了。谁也不觉得白过，但谁也说不上这三小时干了啥。

#### 为什么最难写

因为它没有钩子、没有冲突、没有推进。它唯一的功能是证明这两个人在一起不需要事件。

而一部作品如果通篇都是事件，读者不会相信他们真的过日子。

#### 怎么写「什么都没发生」

| 手法 | 说明 |
|---|---|
| 用平行动作 | 两个人各做各的，在同一个房间 |
| 用无意义对话 | 三句话，全是废话 |
| 用长时间的沉默 | 且沉默是舒服的 |
| 用一个微小的物理接触 | 脚碰到脚，没有人挪开 |
| 用天气 | 光从这边移到那边 |
| 用时间跳跃 | 「等她抬头的时候，太阳已经转过去了」 |

最后一行是这条最省字的技法。

#### 可用细节

| 类 | 内容 |
|---|---|
| 各自在做的 | 她看文件 · 他打游戏 ✓ · 声音互相成了背景 |
| 位置 | 沙发 ✓ 两头 · 或者他的脚搁她腿上 |
| 光 | 从窗户挪过地板 |
| 声音 | 空调 ✓ · 楼下车响 · 他偶尔笑一声 |
| 对话 | 「几点了」「不知道」「哦」 |
| 结束 | 有人问「吃啥」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 有没有接触 | 没有 | 脚碰着脚 |
| 对话 | 三句 | 零句 |
| 时长 | 一小时 | 一整个下午 |
| 用途 | 关系稳定的证明 | 冷战期，同样的场景，读感完全相反 |

**最后一行值得记：** 同一段文字，两人关系不同，读起来天差地别。同一个「什么都没发生的下午」，写法几乎不用动，只改一两个细节，味道就全变了。她关了门，他去了另一个房间——冷战时写出来是钝刀子割肉，好的时候写出来是岁月静好。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她抬头时太阳已经转过去了 | 她的脚一直没挪开 |
| 好的处理 | 她没觉得非得说点什么 | 他没硬找话聊 |
| 写崩 | 变成她一个人在心里嘀咕个没完 | 变成他光顾着看她脸色 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 一个午后／她批文他研墨／蝉声 |
| 修仙 | 同坐一处打坐／百年如一日 |
| 星际 | 长途航行的空白期／舷窗外什么都没有 |

**星际版的「长途航行空白期」是这条最纯粹的形态**：几个月里什么都不会发生，只有两个人。

#### 示例（本库自撰，可直接改写）

> 她在看文件，他在打游戏，耳机只戴了一只。
> 他的脚搭在她腿上，谁都没挪开。
> 「几点了。」
> 「不知道。」
> 「哦。」
> 光从地板这头移到了那头，中间经过一只拖鞋，把它的影子拉得很长。
> 等她抬头的时候，太阳已经转过去了，屋子里暗了一层，谁都没起来开灯。

#### 写崩的三种方式

1. 加内心独白。越空越好。
2. 用它推剧情。它的价值就是推不动剧情。
3. 一本书里不写这一场。那会让所有的甜都显得像表演。
