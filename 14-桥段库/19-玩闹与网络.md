## 玩闹管什么

前面十八卷写的都是正经事，这一卷写玩闹。一段关系要是只有正经事，人会累垮。

玩闹的功能：

| 功能 | 说明 |
|---|---|
| 减压阀 | 前面积累的紧张需要一个出口 |
| 平权区 | 打游戏时她可能输给他 |
| 试探场 | 用玩笑说真话 |
| 私人语言 | 只有他们懂的梗 |

他能光明正大赢她一回的机会不多，打游戏算一个。

## 一 · 第一条消息

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.9%

**骨架**｜加上了，谁先开口，说什么，隔了多久。

#### 节拍链

加上了 → 草稿删改 → 借口成立 → 发出 → 等回复的六小时 → 她回了，或她主动发来一条

#### 时间轴

草稿从加上到发出去改了四十分钟，这四十分钟他一直盯着输入框，打了删，删了打。发出去以后，隔了六个小时她才回。这六个小时手机扣在桌上，他隔十分钟就翻过来看一眼。他哪知道，这中间她有五个半小时在开会。

#### 三个数字就是全部

| 数字 | 说明 |
|---|---|
| 隔了多久 | 三天是常见的煎熬期 |
| 删改了几遍 | 他的版本数 |
| 最后剩几个字 | 通常极短 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的草稿 | 「在吗」→「今天谢谢你」→ 删掉 →「[表情]」 |
| 借口 | 找个由头联系她，比如还东西、问事、发文件 |
| 她的回复 | 秒回 · 隔了六小时 · 一个字 |
| 他的解读 | 那六个钟头他每分钟都在琢磨 |
| 转折 | 她先发来了一条 |

她主动发一条过来，比他发十条都管用。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先发 | 他 | 她 |
| 借口 | 有 | 没有 |
| 她的回复速度 | 秒回 | 很久 |
| 之后 | 聊起来了 | 断了，很久以后才续上 |
| 认识顺序 | 先见人后加号（本条默认） | 先网后面（网恋线：聊了半年才奔现，见面那天是 [11-初遇与确立 · 第一眼](11-初遇与确立.md#一--第一眼)的延迟版——声音和头像先入为主，开局先看真人对不对得上号，认出对方最好靠说话的节奏） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她随手回的那一句 | 输入框里的第十七版 |
| 内心 | 这人怎么这么客气 | 会不会打扰她 |
| 好的处理 | 她回得短，但好歹回了 | 他发完就把手机扣桌上 |
| 写崩 | 写成她故意不理人 | 写成他翻来覆去想三章 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 第一封信／写了三张废了两张／托人捎的一句话 |
| 修仙 | 第一道传音／他犹豫了三天才发 |
| 星际 | 第一条私人频道通讯 |

#### 写崩的三种方式

1. 让他纠结太久。写一场，别写一章。
2. 让她故意晾着。 她只是在忙。
3. 略掉草稿。这场戏写的就是那十七版。

## 二 · 聊天记录

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.9%

**骨架**｜她把聊天记录从头翻到尾，两个人是怎么一点点熟起来的，都在里头。

#### 节拍链

日常累积 → 长度差与速度差 → 一条撤回 → 她往上翻 → 翻到最早 → 这次多回了两句

#### 时间轴

时间看聊天窗口上的时间戳就行。那天晚上她往上翻，从今天翻到上个月用了十分钟，翻到最早那条用了半小时。越往前，他说话越客气，敬语是哪天开始不见的，时间戳上一清二楚。翻完回到输入框，她这回多回了两句。

#### 可读的六项

| 项 | 读作 |
|---|---|
| 消息长度差 | 他的长她的短，这是常态 |
| 回复速度差 | 谁在等谁 |
| 谁发起话题 | 主动方 |
| 表情包的用法 | 他用得多，拿来缓冲 |
| 语音还是文字 | 语音更亲密 |
| 撤回了什么 | 最有戏的一项 |

他撤回了一条，她看到了那行「撤回了一条消息」。

#### 可用细节

| 类 | 内容 |
|---|---|
| 界面细节 | 「对方正在输入」闪一下又没了 · 已读不回（见 [02 卷第三条](02-等待与错过.md#三--消息已读不回)） |
| 时间戳 | 凌晨两点发的那条 |
| 长度对照 | 他打了一大段，她回了个「嗯」 |
| 他的自我审查 | 字打完了又全删掉，最后发了个「好」 |
| 翻旧记录 | 她没事往上翻，翻到好几个月前 |

写她往上翻记录，不用另写回忆。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁翻记录 | 她 | 他 |
| 撤回 | 有 | 无 |
| 长度差 | 明显 | 后来变均衡了（关系的进展） |
| 用途 | 甜 | 分手后再翻（同样的技法） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她往上翻，发现自己以前都只回一个字 | 「对方正在输入」出现了又消失 |
| 好的处理 | 她注意到了，这次多回了两句 | 他没有为「嗯」多想 |
| 写崩 | 大段聊天记录直接贴 | 他分析每一个标点 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 一叠书信／字数与频率／她的回信越来越长 |
| 修仙 | 传音玉简的存留／神识里的痕迹 |
| 星际 | 通讯日志／延迟造成的错位对话 |

#### 写崩的三种方式

1. 大段贴聊天记录。 挑三条。
2. 让他揪着标点琢磨。一次可以，回回如此就是病。
3. 不写撤回。撤回是最省字的一刀。

## 三 · 打游戏

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：游戏 21.7%（游戏＋上药、游戏＋做饭高频同现）

**骨架**｜她在这世上未必比他强，可这事对他们俩来说，都够呛。

#### 节拍链

组队 → 他换了个人（开始指挥）→ 她听他的 → 输赢 → 她不服再来 → 现实身份回来的那一刻

#### 时间轴

加载完的那一秒，身份就换了。一进语音，他像换了个人：话少，判断快，敢直接喊她ID，叫她「别送」。一局二十分钟，输赢一局一算，她一句"再来"，起码三局。他放下麦，又变回平时的样子。摘下耳机那一秒，现实里的身份回来了，她盯着他看了三秒：刚才那个人呢？

#### 这条为什么必须有

他得有个能赢的地方，这段关系才不至于全是他听她的。他并不想翻身。

而她需要一个能输的场合。

#### 四种配置

| 配置 | 效果 |
|---|---|
| 他强她弱 | 他带她（见 [11 卷第六条](11-初遇与确立.md#六--她教他) 反着来）· 最顺手 |
| 她强他弱 | 跟平常一样，没啥戏 |
| 势均力敌 | 有较劲的感觉，能写很久 |
| 她故意输 | 他会看出来，心里还不爽 |

「她故意输」写了就得接着处理。被让着赢，比输了更伤人。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场景 | 开黑 ✓ · 双人游戏 · 排位 ✓ · 她被队友骂 · 他护着 |
| 他的状态 | 在这儿他话变多，语气也不一样 · 她头回听他这么说话 |
| 她的状态 | 玩得太当真，输了就拉脸 |
| 摩擦 | 她菜还不服 · 他不敢明说 |
| 落点 | 她输了，撂一句「再来一把」 |

她头一回听他这么说话，在游戏里他像换了个人。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁强 | 他 | 她 |
| 她输了 | 服气 | 不服，非要再来 |
| 他的处理 | 认真赢 | 放水（会被发现） |
| 有没有赌注 | 无 | 有（见 [四 · 打赌](#四--打赌)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他打游戏时指挥得有模有样 | 这局她听我的 |
| 内心 | 原来他也会这么说话 | 在这儿我说了算 |
| 好的处理 | 她真按他说的来了 | 他没让着她 |
| 写崩 | 把她写得样样都行 | 把他写成拿游戏耍威风 |

碰上他更在行的事，她就真照他说的做，也不用多解释。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 下棋／投壶／射覆／他棋艺胜她 |
| 修仙 | 论道／某一门他更精通／炼器 |
| 星际 | 模拟战／某类机型他更熟 |

古代版用「下棋」，不用另找理由让她让出位置，棋盘上不讲身份。

#### 写崩的三种方式

1. 让她样样都强。她总得有输的地方。
2. 让他放水。 他得认真赢。
3. 不写他在游戏里的另一副样子。她头回听他这么说话，这得写出来。

## 四 · 打赌

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：游戏 21.7%

**骨架**｜赌的是什么，比输赢要紧。

#### 节拍链

起赌约 → 定赌注 → 认真程度超预期 → 分胜负 → 他说不出要什么 → 「你慢慢想，我记着」→ 兑现那天

#### 时间轴

赌注当场定，一局十分钟就赌完了。他赢了，却迟迟没说要什么。她也不催，只撂下一句「你慢慢想，我记着」。之后几个月，她时不时拿这事逗他：「想好没」。到兑现那天，他要的东西小得让她一愣。吊了三个月，就为这个？就为这个。

#### 赌注的分级

| 赌注 | 关系含义 |
|---|---|
| 一顿饭 | 无 |
| 洗一周碗 | 家务的调剂 |
| 「答应我一件事」 | 空头支票，最有戏 |
| 「叫我一声……」 | 称呼，见 [11 卷第五条](11-初遇与确立.md#五--改口) |
| 「今晚听我的」 | 权力临时换手 |
| 一个问题的真话 | 最狠 |

**这一族和 [08-规训日常版](08-规训日常版.md) 就从「今晚听我的」分开**：这里是两个人你情我愿，说好什么时候结束，借着游戏把谁说了算倒过来一次。

#### 可用细节

| 类 | 内容 |
|---|---|
| 提议 | 谁先提的赌约 · 对方有没有跟着加注 |
| 过程 | 本来闹着玩，越玩越当真 |
| 结果 | 谁赢了 · 有没有赖账 |
| 兑现 | 怎么兑现，才是这段的重头戏 |
| 落差 | 他赢了，却不知道想要啥 |

他赢了，却不知道要什么。一个很久没开口要过东西的人，突然可以要了，反倒愣住。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁赢 | 他 | 她 |
| 赌注 | 小 | 「答应我一件事」 |
| 兑现 | 立刻 | 他一直没用那个权利 |
| 耍赖 | 无 | 有，谁耍赖也是信息 |

**「他一直没用那个权利」能埋很久**，埋到某一章他终于用了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他赢了，却半天说不出想要啥 | 我能要点啥 |
| 内心 | 他压根没往那想过 | 想要的那个，张不开嘴 |
| 好的处理 | 她说「不急，你慢慢想，我记着」 | 他最后开口，要的只是一件小事 |
| 写崩 | 写成她说话不算话 | 写成他张嘴就要一大堆 |

「他最后要的是一件小事」，比他要件大事动人多了。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 赌一局棋／她许他一诺／可用一次的令牌 |
| 修仙 | 论道输了应一件事／一枚可召她的符 |
| 星际 | 一次优先权／她给他一个权限 |

令牌、符、权限，都是能用一次的东西，攥在他手里，看得见。

#### 写崩的三种方式

1. 让她赖账。 一次都不行。
2. 让他要件大事。要件小事更动人。
3. 立刻兑现。 存着更有戏。

## 五 · 捉弄

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：捉弄 21.3%，捉弄＋吃醋、捉弄＋洗漱高频同现

**骨架**｜她逗他，逗过了头。

#### 节拍链

起意 → 演 → 他配合或信了 → 他眼神变了 → 她立刻收手 → 道歉 → 「刚才那个别再来了」

#### 时间轴

玩笑能开的时间也就两三分钟，过了就变味。她反应快，演到他眼神一变，马上停，半秒内收手、道歉。他说了句「刚才那个别再来了」，界线就划下了，往后再怎么闹也出不了事。

#### 那条线在哪

| 判据 | 是逗 | 是欺负 |
|---|---|---|
| 他有没有笑 | 有 | 没有 |
| 有没有旁人 | 私下 | 当众 |
| 触及的是什么 | 小事，不往心里去 | 他最在乎的那点事 |
| 能不能反击 | 能 | 不能 |
| 她会不会停 | 他一皱眉就停 | 接着来 |

这里面能让人放心的是「他一皱眉就停」。

#### 捉弄的清单

| 做什么 | 分量 |
|---|---|
| 藏他的东西 | 轻 |
| 假装忘了他的生日 | 中 |
| 学他说话 | 中 |
| 当着人叫他的小名 | 中高 |
| 假装要走 | 高，且危险 |
| 假装不认识他 | 高，且要谨慎 |

「假装要走」这种玩笑得小心开。角色要是本来就没安全感，这一下会真伤到人。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的方式 | 面不改色 · 装得跟真的一样 |
| 他的识破 | 他其实早看出来了 · 但没拆穿 |
| 反击 | 他也会反过来逗她（重点） |
| 分寸 | 她到某个点就停了 |
| 落点 | 他后来才说「你刚才真把我唬住了」 |

他也会反过来逗她，要不然就成了她一个人拿捏他。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁捉弄谁 | 她 | 他（少见，且很好玩） |
| 场合 | 私下 | 有人在 |
| 他的反应 | 配合 | 真的被吓到 |
| 收场 | 都笑了 | 她道歉了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看他眼神不对，马上停了 | 有一瞬间我差点当真 |
| 好的处理 | 她认真道了歉 | 他撂了句「刚才那样别再有了」 |
| 写崩 | 写成她没完没了地折腾 | 写成他啥都忍，没一点底线 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 逗他／故意冷落一日／假意要纳新人 |
| 修仙 | 藏起他的法器／假装认不出他 |
| 星际 | 改他的权限／假装调走他 |

**在古代女尊里，「假意要纳新人」这个玩笑非常危险**，按那里的规矩，这事是真能发生的。

#### 写崩的三种方式

1. 单向捉弄。 他要能还手。
2. 碰到他真在意的事。那就不算玩笑了。
3. 让她一直不收手。他眼神一不对，她就得停。

## 六 · 只有他们懂的梗

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：捉弄 21.3% ＋ 社交网 33.9%

**骨架**｜一句话别人听得莫名其妙，他俩对视一眼就笑了。

#### 节拍链

一次事故成了梗 → 反复使用 → 当众用，全场只有两人笑 → 「没什么」→ 某天没接上 → 收尾处再现

#### 时间轴

这得按年算。梗出自某次十秒钟的意外，头一个月翻来覆去地用，后来当着人用，满屋子只有他俩在笑，再后来缩成了平常说话的一部分。隔得太久，某天有一方忘了，没接上。到收尾，它又出现一次：多年以后一个词砸下来，两个人还是一起笑了。

#### 私人语言的构造

| 来源 | 例 |
|---|---|
| 一次失败 | 他做糊的那顿饭 |
| 一个口误 | 她说错的一个词 |
| 一个共同的糗事 | 出岔子的那次旅行 |
| 一个外号 | 只有他们这样叫某个人 |
| 一个数字 | 那天的房号、车牌 |

别人听见了也进不去。

#### 三个用法

| 用法 | 说明 |
|---|---|
| 建立亲密 | 当众用一次，全场只有两个人在笑 |
| 计量疏远 | 某天她没接上那个梗 |
| 收尾 | 结局处它再出现一次 |

某天她没接上那个梗，道理和 [07-馈赠与仪式 · 一个只属于他们的仪式](07-馈赠与仪式.md#十--一个只属于他们的仪式) 里“打破仪式”的写法一样。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 一桌子人 · 会议上 · 微信群 ✓ |
| 表现 | 两个人同时笑 · 别人问「什么意思」 · 他们说「没什么」 |
| 排他性 | 一句「没什么」，外人就进不来了 |
| 频率 | 用多了招人烦，一本书顶多来三次 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先用 | 她 | 他 |
| 场合 | 私下 | 当众 |
| 别人的反应 | 追问 | 没注意 |
| 后来 | 一直在用 | 有一天没人再提了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她说完那句，全桌只有他笑了 | 她还记得 |
| 好的处理 | 她对别人说「没什么」 | 他没有向别人解释 |
| 写崩 | 写成刻意秀默契 | 写成他反复提醒她那个梗 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 一句典故／她给他起的字／只有两人知道的旧事 |
| 修仙 | 一个手势／神识里的一个符号 |
| 星际 | 一段代码／一个坐标 |

#### 写崩的三种方式

1. 用太多次。 三次。
2. 跟读者解释这个梗有多好笑。干脆让读者也进不去。
3. 只拿来写甜。要紧的是没接上的那一回。

## 七 · 一起看片

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.9% ＋ 睡着 55.9%

**骨架**｜沙发上坐着，电视亮着，两个人都没心思看。

#### 节拍链

选片 → 开场 → 谁先没在看 → 靠过来或睡着 → 剧情引出一个话题 → 字幕滚完没人动

#### 时间轴

片子两个小时，注意力撑不过二十分钟。前二十分钟还在认真看，之后有人翻手机，有人打量起旁边的人。第七十分钟上下，有人睡着了，身子靠过来，重量一点点压上来。片尾字幕走完，屏幕的蓝光还亮着，谁也没伸手去关，谁都不想先开口结束这个晚上。

#### 这条的功能：容器

片子本身没啥好写，它是给下面这些事当由头的：

| 需要什么 | 放这里 |
|---|---|
| 一场随意的对话 | 看片时最自然 |
| 一次靠近 | 靠肩、盖毯子 |
| 一次睡着 | 见 [06-身体接触 · 靠肩](06-身体接触.md#四--靠肩) |
| 一个话题的引子 | 剧情带出来的 |
| 时间流逝 | 一部片子的功夫 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 沙发 ✓ · 毯子 ✓ · 遥控器归谁 · 零食 · 灯 ✓ 关不关 |
| 选片 | 谁挑的 · 她挑的他没兴趣，但也没吭声 |
| 中途 | 有人看睡了 · 有人去倒水 · 停了好几回 |
| 讨论 | 剧里一件事，聊到了俩人自己 |
| 结束 | 片尾字幕走完，谁也没动弹 |

借别人的故事说自己的事。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁选片 | 她 | 他 |
| 看没看进去 | 看了 | 都没在看 |
| 睡着 | 他 | 她（她太累了） |
| 引出的话题 | 无 | 一件他们一直没谈的事 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他半小时没换姿势，原来睡着了 | 她选的这个我看不下去，但我不说 |
| 好的处理 | 她把片子暂停了 | 他后来说了他想看的那个 |
| 写崩 | 写成她全程主导选片 | 写成他一味迁就 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 一起听戏／看话本／她念他听 |
| 修仙 | 观星／看留影石里的旧事 |
| 星际 | 舷窗外的星图／舰上的旧影像资料 |

#### 写崩的三种方式

1. 细细复述片子内容。片子只是个由头。
2. 让他一直迁就。他得说一回自己想看的。
3. 漏掉「都没在看」。其实两个人谁都没在看。

## 八 · 网上的另一个他

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.9%

**骨架**｜她撞见了他的另一个账号。

#### 节拍链

算法推荐 → 认出细节 → 她往下翻 → 三年前那条 → 关掉或继续 → 说不说破 → 他删没删号

#### 时间轴

她把另一个他三年来发的东西倒着摊开，一条条看。最早那条，发在他们认识之前。认出是他，只要一个杯子或者一只手，一眼的事。她往下翻了两个小时，算法一秒钟推给她的东西，她一整晚才看完。要不要说破，她又纠结了三天。他删没删号，两种结局都说得通：删了，两条线并成一条，没删，是给自己留了间屋子。

#### 这条的三种走向

| 账号里是什么 | 走向 |
|---|---|
| 他的爱好／作品 | 甜。她发现了他没露过的一面 |
| 关于她的记录 | 甜里带惊。他写了不少跟她有关的 |
| 他的抱怨 | 疼。他在网上说了当面不敢说的话 |
| 一段旧关系 | 转 [15-秘密与坦白 · 前任出现](15-秘密与坦白.md#四--前任出现) |

第三种里，匿名账号是他难得不用装的地方，她闯了进去。

#### 可用细节

| 类 | 内容 |
|---|---|
| 发现方式 | 刷推荐刷到 · 朋友转发 · 一个眼熟的词 |
| 认出的证据 | 一张照片 ✓ 的边角 · 一句口头禅 · 一个只有她知道的细节 |
| 她的处理 | 划走 · 或者往下翻了很久 |
| 内容 | 三年前的一条 · 隔了这么久，这条才显出分量 |
| 之后 | 点破还是装没看见 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 内容 | 无害 | 关于她的抱怨 |
| 她的处理 | 不说破 | 说了 |
| 他知不知道被发现 | 不知道 | 知道，且删号了 |
| 结果 | 她更懂他了 | 他失去了唯一的出口 |

她看懂他了，他也没处可躲了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 三年前那一条 | 她可能看见了 |
| 内心 | 这些他从来没跟我说过 | 那是我唯一说真话的地方 |
| 好的处理 | 她没挑明，但悄悄改了做法 | 他没删号 |
| 写崩 | 写成她盯梢查岗 | 写成他网上网下两个人 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他的私人手札／写了没寄的信／他题在墙上的字 |
| 修仙 | 他的心魔／神识深处的一处 |
| 星际 | 加密日志／私人航行记录 |

#### 写崩的三种方式

1. 写成查岗。 她是无意发现的。
2. 让内容太重。 一句抱怨够了。
3. 当场对质。 不说破更有力。

前接：[二 · 聊天记录](#二--聊天记录)
后接：[15-秘密与坦白 · 他有一件事没说](15-秘密与坦白.md#一--他有一件事没说)

## 九 · 拍照

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：看照片 4.9%

**骨架**｜他手机里有她多少张，她手机里有他多少张。

#### 节拍链

他偷拍成习惯 → 数量差 → 她第一次举起手机拍他 → 他愣住 → 设成屏保或收进相册 → 某天翻相册

#### 时间轴

那天晚上两人把相册摊开，一对时间线，竟然拼出了完整的一条。她手机里有他三十张，他手机里有她九百张，这个比例一僵就是两年。头一回是她主动举起手机拍他，咔嚓一声，他愣了三秒。后来那三十张慢慢往上涨，涨得慢，可再没停过。

#### 相册的构成学

| 统计项 | 读作 |
|---|---|
| 她的照片有多少张 | 他拍的 |
| 他的照片有多少张 | 她拍的，通常少得多 |
| 合影有多少张 | 关系公开到啥程度 |
| 有没有偷拍 | 见 [15-秘密与坦白 · 他一直留着的东西](15-秘密与坦白.md#九--他一直留着的东西) |
| 最早的一张 | 啥时候开始的 |
| 谁在谁的手机屏保上 | 最直接的一项 |

他拍她三百张，她拍他六张，摆出这样一组数字就行。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他拍的 | 她没看镜头的时候 · 她工作时 · 她睡着 ✓ |
| 她拍的 | 少，但每张都有由头 |
| 她的第一次拍他 | 打这儿起就不一样了 |
| 删照片 | 出了事，头一件事就是删 |
| 洗出来的那张 | 见 [07-馈赠与仪式 · 合照](07-馈赠与仪式.md#五--合照) |

「她第一次拍他」，光这一个动作就能撑起一场戏。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 数量差 | 悬殊 | 后来变均衡 |
| 她拍的 | 没有 | 有一张，且她设成了屏保 |
| 偷拍 | 有 | 无 |
| 用途 | 甜 | 分手后删照片，同一张清单反过来 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她翻自己相册，发现他只有六张 | 她今天拍我了 |
| 好的处理 | 她开始拍他 | 他没提过这茬 |
| 写崩 | 写成她突然开窍猛补拍 | 写成他挨个数照片 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 画像／她画的他／他描的她 |
| 修仙 | 留影石／她存了几段 |
| 星际 | 影像记录／私人存储配额分给了谁 |

#### 写崩的三种方式

1. 不写数量差。他拍得多、她拍得少，这点要写出来。
2. 让她突然补拍一大堆。有一张就行。
3. 写成秀恩爱。 这事是私密的。

## 十 · 无聊的下午

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：睡着 55.9% ＋ 社交网 33.9%

**骨架**｜什么都没发生的一场。不好写，可一本书里不能没有。

#### 节拍链

各做各的 → 脚搭上来 → 三句废话 → 光移过地板 → 有人睡着 → 「吃什么」→ 起身

#### 时间轴

光从茶几挪到沙发脚，冰水杯上的水珠从密密一层到干透，有人呼吸慢慢沉下去，睡着了。三个小时里没发生别的事。有人问出「吃什么」，这个下午就过完了。谁都不觉得白过，可谁也说不出这三个小时干了什么。

#### 为什么最难写

因为它没有钩子，没有冲突，剧情也不往前走。读者从这里看到，两个人待在一起，用不着发生什么。

一部作品要是从头到尾都在出事，读者就不信这两人真在过日子。

#### 怎么写「什么都没发生」

| 手法 | 说明 |
|---|---|
| 用平行动作 | 两个人各做各的，在同一个房间 |
| 用无意义对话 | 三句话，全是废话 |
| 用长时间的沉默 | 且沉默是舒服的 |
| 用一个微小的物理接触 | 脚碰到脚，没有人挪开 |
| 用天气 | 光从这边移到那边 |
| 用时间跳跃 | 「等她抬头的时候，太阳已经转过去了」 |

最后一行最省字。

#### 可用细节

| 类 | 内容 |
|---|---|
| 各自在做的 | 她看文件 · 他打游戏 ✓ · 声音互相成了背景 |
| 位置 | 沙发 ✓ 两头 · 或者他的脚搁她腿上 |
| 光 | 从窗户挪过地板 |
| 声音 | 空调 ✓ · 楼下车响 · 他偶尔笑一声 |
| 对话 | 「几点了」「不知道」「哦」 |
| 结束 | 有人问「吃啥」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 有没有接触 | 没有 | 脚碰着脚 |
| 对话 | 三句 | 零句 |
| 时长 | 一小时 | 一整个下午 |
| 用途 | 关系稳定的证明 | 冷战期，同样的场景，读感完全相反 |

一样的文字，放进不同的关系里，读着天差地别。同一个「什么都没发生的下午」，写法几乎不动，改一两个细节，味道就全变了。比如她关了门，他去了另一个房间：冷战时读着像钝刀子割肉，关系好的时候读着是岁月静好。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她抬头时太阳已经转过去了 | 她的脚一直没挪开 |
| 好的处理 | 她没觉得非得说点什么 | 他没硬找话聊 |
| 写崩 | 变成她一个人在心里嘀咕个没完 | 变成他光顾着看她脸色 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 一个午后／她批文他研墨／蝉声 |
| 修仙 | 同坐一处打坐／百年如一日 |
| 星际 | 长途航行的空白期／舷窗外什么都没有 |

星际版的「长途航行空白期」，一连几个月什么事都没有，只有他们两个。

#### 示例（本库自撰，可直接改写）

> 她在看文件，他在打游戏，耳机只戴了一只。
> 他的脚搭在她腿上，谁都没挪开。
> 「几点了。」
> 「不知道。」
> 「哦。」
> 光从地板这头移到了那头，中间经过一只拖鞋，把它的影子拉得很长。
> 等她抬头的时候，太阳已经转过去了，屋子里暗了一层，谁都没起来开灯。

#### 写崩的三种方式

1. 加内心独白。 越空越好。
2. 拿它推剧情。这场戏推不动剧情。
3. 整本书里没有这一场。少了它，所有的甜都容易像在演。
