# 馈赠与仪式

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次出自[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，按 2,894 部独立作品统计。文中的百分比是编写时实测的，挖掘器扩充后节拍族会有小幅变动，数字以 13-07 当前的为准（`run.py mine` 重跑更新）
> 送礼、生日、合照、交出去、戒指、见家长、一起买东西、私人仪式，这些场面都归这一族。礼一送出去，这段关系就有了物证。

## 送礼的方向不对称

| | 她送他 | 他送她 |
|---|---|---|
| 性质 | 赏赐 · 给口饭吃 · 盖章 | 表白 · 献宝 · 证明自己有用 |
| 常见物 | 贵的 · 带身份的 · 她挑的 | 便宜的 · 亲手做的 · 攒钱买的 |
| 拒绝的可能 | 他基本没法说不 | 她可以不要 |
| 他／她收到时 | 他得琢磨「我配不配」 | 她得琢磨「他花了多少」 |
| 最疼的写法 | 她随手丢的东西他当命根子 | 他攒了仨月的钱她压根没看价签 |

最后一行最好用。

| 节拍族 | 作品数 | 占比 | 特征物件（提升度） |
|---|---:|---:|---|
| 备礼送礼 | 857 | 29.6% | 包装 1.6× |

「包装 1.6×」是这一族唯一过线的特征物件。这一族写包装比写礼物本身管用，准备的过程都留在包装上。

## 一 · 藏了很久的礼物

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 29.6%，做饭＋赠礼 5.4%

**骨架**｜他准备了很久，一直没找着合适的时候拿出来。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 他决定送（起因很小） |
| 2 | 准备攒钱、学手艺、到处找 |
| 3 | 藏起来 |
| 4 | 找时机，一次次错过 |
| 5 | 藏太久，快过期／不合时宜了 |
| 6 | 送出去，或者被发现，或者一直没送 |

第 5 拍要写。东西藏太久，藏本身就成了新情节。

#### 时间轴

藏的时长 ＝ 他的犹豫。写法：

| 记录物 | 显示什么 |
|---|---|
| 藏的位置换过三次 | 他怕被人翻出来 |
| 包装 ✓ 边角磨白了 | 他没事就拿出来摸 |
| 收据上的日期 | 她后来才瞧见 |
| 尺码不对了 / 过了保质期 | 搁太久，早变样了 |

包装边角都磨白了。他没拆过，摸倒摸了很多回。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 包装 ✓（1.6×）· 礼盒 ✓（1.6×）· 丝带 ✓ · 收据 · 藏哪儿了：柜子顶层、行李箱夹层、他自己的书里 |
| 准备痕迹 | 这几个月他省吃俭用 · 手上的伤（做手工弄的）· 偷偷问过她朋友 |
| 错过的时机 | 她加班 · 她心情不好 · 旁边有人 · 他自己临阵缩了 |
| 被发现的方式 | 她找东西翻出来 · 搬家时看到 · 他自己终于拿出来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 送没送出去 | 送了 | 一直没送，她很久以后才发现 |
| 礼物价值 | 便宜但花了心思 | 贵到不像他会买的，她会心疼 |
| 她的反应 | 收下 | 先问「多少钱」，这句会伤人 |
| 时机 | 总算等到合适的当口 | 在不该开口的时候憋不住说了 |

「在不该开口的时候憋不住说了」比「总算等到合适的当口」好。准备了很久的东西，往往是一时没忍住才送出去的。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看见包装磨白的边角 | 每一次拿出来又放回去 |
| 内心 | 他到底藏了多久 | 今天行不行，今天算不算好日子 |
| 好的处理 | 她不问价格，她问「什么时候买的」 | 他没说自己攒了多久 |
| 写崩 | 写成她当场落泪 | 写成他委屈地强调自己多辛苦 |

问「什么时候买的」，比问「多少钱」强得多。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 亲手打的首饰／攒了三年的银子／绣了半年的活计 |
| 修仙 | 炼了百年的法器／拿命从险境采来的灵材 |
| 星际 | 用配额换的／从地球带上来的旧东西 |

修仙版炼一件法器就要好多年，藏的时间能拉到最长。

#### 写崩的三种方式

1. 礼物太贵。 一贵就成了比谁有钱，他那份心意反倒没人看见。
2. 让他自己说“我为你做了多少多少”。 他一诉苦，读者马上就不心疼他了。
3. 让她当场哭。 她忍得越狠，读者越替她难受。

#### 可串接

前接：[02-等待与错过 · 错过的纪念日](02-等待与错过.md#八--错过的纪念日)
后接：[三 · 她随手给的东西](#三--她随手给的东西)

#### 示例（本库自撰，可直接改写）

> 盒子在柜子最上层，压在换季的被子底下。
> 换过三个地方。一开始在抽屉，后来觉得她会拉抽屉；挪到床底，又怕扫地时被看见。
> 边角那圈丝带已经不太挺了，是被手指来回捋的。他把它拿出来的时候，先在袖子上蹭了蹭灰。
> 里面的东西他自己都没再看过。日期是三月十七号。今天九月了。

## 二 · 送错的礼物

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 29.6%

**骨架**｜他送了，可送错了。送错比送对更好看。

#### 节拍链

他送出 → 她拆开 → 那零点五秒的停顿 → 她说喜欢 → 他听出来了 → 她留着或去换

#### 时间轴

那零点五秒的停顿之后，余波能拖一周。她要是留着，他每回看见都会想起来。她要是去换，换的那天他陪着，两个人谁也不提为什么换。

#### 送错的四种方式

| 错法 | 说明 | 疼的点 |
|---|---|---|
| 尺寸错 | 他不知道她穿多大 | 说明他压根没上心 |
| 品味错 | 他挑了自己觉得好的 | 说明他还按自己那套来 |
| 过时了 | 她三个月前想要，现在不想要了 | 时间差 |
| 撞了 | 别人已经送过一样的 | 最难堪 |

「撞了」最好用，还能直接接到 [05-占有与吃醋](05-占有与吃醋.md)。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他发现错了的瞬间 | 她拆开时那零点五秒的停顿 |
| 她的补救 | 立马说喜欢，他听得出来 · 要不就老实说「我换一个尺码」 |
| 他的反应 | 想拿回来 · 说「我去换」· 一声不吭 |
| 后来 | 她一直戴着那个不合适的 · 或者她真去换了，两种都行 |

「她一直戴着那个不合适的」好还是「她去换了」好，要看人物。一直戴着是心疼他，去换是尊重他花的钱。两种都能写，选哪种得说得出道理。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她说不说破 | 假装喜欢 | 直说 |
| 他知不知道她在假装 | 不知道 | 知道，更难受 |
| 结局 | 她留着 | 她去换了，且告诉他了 |
| 后续 | 他从此更用心地观察她 | 他从此不敢送了（更疼） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 拆开那一下心里咯噔 | 她停顿的那零点五秒 |
| 好的处理 | 她实话实说，但话说得软 | 他没有马上认错 |
| 写崩 | 写她装都装不像 | 写他破罐子破摔 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 送的样式她早不戴了／料子不合她的品级 |
| 修仙 | 法器属性与她的功法相冲 |
| 星际 | 规格不兼容她的装备 |

#### 写崩的三种方式

1. 错得无关痛痒。 要错就真错，错到他自己也明白。
2. 让她大方得毫无波澜。 那零点五秒一定要有。
3. 他从此不送了，文里却不交代。 这个变化得让她看见。

后接：[04-委屈与破防 · 我是不是不够好](04-委屈与破防.md#九--我是不是不够好)

## 三 · 她随手给的东西

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 29.6%

**骨架**｜她随手丢给他的东西，他当宝贝收了三年。

#### 节拍链

她顺手给 → 他单独收着 → 三年过去 → 她翻他抽屉看见 → 「这个是哪来的」→ 他说「捡的」

#### 时间轴

撑起这段的是两边的时间差。在他那儿是三年，单独收着，搬了三次家都带着。在她那儿只有一秒，顺手一递，转身就忘了。直到她问出「这个是哪来的」，两边的时间才第一次对上。

#### 为什么这条是这一族的核心

同一样东西，在两个人心里差了一百倍的分量。

她是真顺手，他也是真珍惜。

#### 可用细节

| 类 | 内容 |
|---|---|
| 物品 | 她喝剩的半瓶水 · 她用过的笔 · 她随手买的挂件 · 她那件旧外套 ✓ |
| 他的收藏方式 | 单独搁着 · 不用 · 用了也小心怕弄坏 · 换手机时先把那条消息转走 ✓ |
| 她的记忆 | 她压根不记得给过 |
| 揭开的时机 | 她帮他搬东西时看见 · 她问「这哪来的」 |
| 实测特征物 | 相册 ✓（提升度 9.0×）· 照片 ✓（2.0×），在「看照片」场景实测，9.0× 是整张表里最高的。揭开这件事要是走翻相册这条路，道具本身就有戏（来源：[13-07 §道具提升度](../13-语料挖掘/07-桥段分布.md)） |

她一问「这个是哪来的」，这事就藏不住了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她记不记得 | 隐约记得 | 完全不记得 |
| 他说不说 | 说了 | 说「捡的」 |
| 她的反应 | 心里一沉 | 她也开始琢磨自己平时都给了人家啥 |
| 物品状态 | 保存得很好 | 用坏了但没扔 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她认出那是自己的东西 | 她问起来的那一刻 |
| 内心 | 我什么时候给的 | 别问，别问 |
| 好的处理 | 她不追问，但她记住了 | 他说「捡的」，然后转身 |
| 写崩 | 写成她感动到哭 | 写成他哀怨地控诉 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她赏的一方帕子／她用旧的一支笔／她随手系的络子 |
| 修仙 | 她剑上掉的一缕穗子／她随手给的一枚符 |
| 星际 | 她换下的旧徽章／她留的一段旧录音 |

#### 写崩的三种方式

1. 让她马上补偿他。 一补就俗了。
2. 让他和盘托出。 说「捡的」两个字就行。
3. 写成他卑微。 珍惜和卑微是两码事，看他有没有借这个向她要什么。

#### 示例（本库自撰，可直接改写）

> 抽屉最里层有个盒子，鞋盒那么大，压在几本旧书下面。
> 她打开了。里面只有一支笔。
> 笔杆上的漆掉了一小块，笔帽有个磕痕。三年前她用过的那支，写不出水之后随手扔在桌上。
> 她把盒子合上，放回原处，位置摆得和刚才一样。
> 「文件我找到了。」她说。
> 那天之后，她开始留意自己顺手给了他什么。

## 四 · 生日

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 29.6%

**骨架**｜她记不记得他的生日，比怎么过更要紧。

#### 节拍链

他说「不用过」→ 她记得 → 不办大的 → 点蜡烛 → 他闭眼太久 → 睁眼时看的是她

#### 时间轴

一场其实很短，蜡烛从点上到吹灭，最多十分钟。可以连写三年：去年他还说「不用过」，今年提前一周就不对劲了，明年说不定会自己开口说愿望。

#### 生日能测出什么

| 观察点 | 测出 |
|---|---|
| 谁的生日被过得更隆重 | 谁在这段关系里更重 |
| 他记不记得她的 | 及格线 |
| 她记不记得他的 | 真考验 |
| 蛋糕 ✓ 上写谁的名字 | 谁说了算 |
| 有没有别人在 | 关系敢不敢见光 |
| 他许的愿 | 整条线的收尾 |

最该写「他许的愿」，他不会说出口。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 蛋糕 ✓ · 蜡烛 ✓ · 礼盒 ✓ · 花束 ✓ · 照片 ✓ · 那顶纸帽子 |
| 他的生日 | 他不提 · 她忘了／她记得 · 他说「不用过」（这句要留） |
| 许愿的细节 | 他闭眼太久 · 她在旁边等 · 他睁眼时看的是她 |
| 收尾 | 蜡烛吹灭后的那几秒黑 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁的生日 | 她的 | 他的（更有戏） |
| 他提不提 | 提前露点口风 | 一个字不说 |
| 她记不记得 | 记得，早备好了 | 忘了，当天才补 |
| 愿望 | 他讲出来了 | 他没讲，读者心里有数 |

会说「不用过」的人，往往从来没人认真给他过过生日。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他从来没被好好过过生日 | 蜡烛点上的那一刻 |
| 好的处理 | 她不办大的，她只是记得 | 他许的愿跟自己无关 |
| 写崩 | 写成盛大的惊喜派对 | 写成他自怜身世 |

「她不办大的，她只是记得」好过大张旗鼓的惊喜。排场是摆给外人看的，记得是留给他的。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 生辰／长寿面／她赐的生辰礼 |
| 修仙 | 他的凡人生辰早已没人记得，除了她 |
| 星际 | 地球历的日期，舰上没人过 |

修仙和星际的世界里没人记这个日子，只有她记着。

#### 写崩的三种方式

1. 搞成惊喜派对。 人一多就像在演戏。
2. 让他把愿望说出来。 让读者猜到就行。
3. 漏掉「不用过」这句。 这句话后面压着他整段过去。

## 五 · 合照

`G` ｜ 无预警 ｜ 现代／星际 ｜ 语料频次：备礼送礼 29.6%

**骨架**｜第一张合照一发出去，多少句话都比不上。

#### 节拍链

有人提议 → 拍 → 他不敢靠太近，或悄悄拉近半寸 → 他没看镜头 → 设成锁屏 → 换掉 → 又设回来

#### 时间轴

按快门只要 1/125 秒。有人来了他就把锁屏换掉，人一走再设回来，来回换了三轮，每换一次、每设一次，都是在表态。

#### 照片的语义

| 观察点 | 读作 |
|---|---|
| 谁提出拍的 | 谁更想留个念想 |
| 拍的时候两人的距离 | 俩人走到哪一步了 |
| 他有没有看镜头 | 他眼里是她还是走流程 |
| 照片放在哪 | 手机 ✓ 锁屏／相册 ✓ 最底下／打印出来 |
| 发不发出去 | 让多少人看见 |
| 三年后再看这张 | 这三年攒下的分量够不够 |

最该写的是「他有没有看镜头」。这类照片里，他常常在看她。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 照片 ✓ · 相册 ✓ · 手机 ✓ · 屏幕 ✓ · 打印出来那张的折痕 |
| 拍照的场合 | 随手 · 特意 · 别人帮拍 · 自拍时手不够长 |
| 他的姿态 | 不敢靠太近 · 手不知道放哪 · 或者他悄悄拉近了半寸 |
| 后续 | 他把它设成锁屏，又换掉，又设回来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提议 | 她 | 他（他会找借口） |
| 他敢不敢公开 | 设成锁屏 | 只放在相册最深处 |
| 数量 | 只有一张 | 他存了很多张她的，两人的只有一张 |
| 后续 | 越拍越多 | 这张一直是唯一的一张 |

「他存了很多张她的，两人的只有一张」这头好写。张数差多少，他一个人看她和两人互相认定就差多少。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她翻他手机，看他相册里存了啥 | 拍照时手搁哪儿 |
| 好的处理 | 她拿那张图当了锁屏 | 他想要一张，没敢开口 |
| 写崩 | 写成她逼他公开 | 写成他偷拍上瘾 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 画像／她请人画的双人图／他自己描的一张 |
| 修仙 | 留影石／神识里的一段记忆 |
| 星际 | 全息影像／一段被他反复回放的舱内录像 |

古代版里「他自己描的一张」画得并不像，可他描了很多遍。

#### 写崩的三种方式

1. 写成秀恩爱。 这条写私下的。
2. 省略他的手放在哪。
3. 拍太多张。 第一张难得，就因为只有这一张。

## 六 · 交出去

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 29.6%

**骨架**｜他把族里分量最重的信物交到她手上，让她明白这件事他做得了主。

#### 节拍链

他决定 → 推过去 → 「你拿着」（不解释）→ 她愣住 → 她怎么接 → 她也给了他一样

#### 时间轴

他想了三个月才拿定主意，交出去只花了三秒。说「你拿着」这三个字之前，他盘算了整整一季：值不值，她会不会嫌太沉，怎么说才不显得太郑重。交的时候越是轻描淡写，前面那三个月就越重。

#### 交出去的东西

按轻重排：

| 物 | 交出的是 |
|---|---|
| 家门钥匙 ✓ | 空间 |
| 手机 ✓ 密码 | 隐私 |
| 工资卡 / 存折 | 经济自主 |
| 他的日程 | 时间 |
| 他的旧物（唯一一件） | 过去 |
| 一个只有他知道的秘密 | 底牌 |

交出去只是开个头，重头戏在她怎么接。

| 她的接法 | 读作 |
|---|---|
| 收下并使用 | 她当成事实 |
| 收下但从不用 | 她收心意，不收权力 |
| 退回去 | 她觉得他不用交这个 |
| 收下，然后交出对等的一样 | 最好的一种 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 交出的动作 | 放桌上推过去 · 塞她包里 · 直接把密码说了 |
| 他的措辞 | 「你拿着」（不解释）· 或者啰嗦一堆，说明他紧张 |
| 她的反应 | 愣住 · 问「为啥」· 啥也没问就收了 |
| 后续 | 他后不后悔 · 她到底用没用 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他交的东西 | 走个形式 | 来真的（工资卡、密码） |
| 她的处理 | 收下 | 退回去，把话说清楚 |
| 是不是被要求的 | 他自己乐意 | 她开口要的，性质完全两码事 |
| 后续 | 关系更近了 | 他回头又想拿回来，这条更真实 |

写「她开口要的」这一头要当心。她逼他交出自主权，是控制，他自己交给她，是信任。动作一样，看谁先伸的手，意思就完全相反。可以对照 [05-占有与吃醋 · 独占欲的边界](05-占有与吃醋.md#十--独占欲的边界)。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 东西被推过来的那一下 | 说出口之前想了多久 |
| 内心 | 我该不该收 | 她收了就说明她认了 |
| 好的处理 | 她收下，也回了他一样 | 他没提附加条件 |
| 写崩 | 写成她收得理所当然 | 写成他把自己整个搭进去 |

「她也给了他一样」：两个人本来不对等，这一回换得对等了。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 卖身契／他的印鉴／族谱上的名字／他把身契交到她手上 |
| 修仙 | 本命法器／魂灯／识海权限 |
| 星际 | 最高权限授权／生命体征绑定到她的终端 |

古代版的「身契」分量最重，也最要当心，一不留神就写成人身依附。要写明是他自己选的，她也得给出明确的回应。

#### 写崩的三种方式

1. 写成人身依附。 把自主权交给她，跟连人格都丢掉是两回事。
2. 让她要求他交。 见上。
3. 交完就没了下文。 她怎么处置，要接着写。

前接：[三 · 她随手给的东西](#三--她随手给的东西)
后接：[08-规训日常版](08-规训日常版.md) · [七 · 戒指](#七--戒指)

## 七 · 戒指

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 29.6%

**骨架**｜就写谁给谁戴、戴在哪只手上。

#### 节拍链

拿出来 → 手抖 → 戴不进去 → 推到底 → 转一下让它正 → 谁都没说话

#### 时间轴

从拿出来到戴正，前后不到一分钟，要拆成六拍慢慢放。掏、抖、对不准、推、转正、沉默，每拍中间都可以停一停。这一分钟别写快了。

#### 戴法的语义表

| 谁给谁 | 哪只手 | 读作 |
|---|---|---|
| 她给他戴 | 左手无名指 | 明摆着告诉别人 |
| 她给他戴 | 右手 | 留着，或者设定里另有说法 |
| 他给她戴 | 左手无名指 | 求她，得她抬一下手 |
| 他自己戴上 | — | 自己说了算 |
| 两人互相戴 | — | 谁也没压过谁 |
| 她把自己的给他 | 尺寸不合，他戴小指 | 最戳人的一版 |

「尺寸不合，他戴小指」：「这不是为你准备的，但我给你了」和「我收下了，用我的办法」，两句话都在这一个动作里。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 戒指 ✓ · 礼盒 ✓ · 丝带 ✓ · 尺寸（他量过她手指 ✓）· 内圈刻字 |
| 戴的动作 | 手抖 · 戴不进去 · 推到底 · 转正 |
| 他的手 | 手指 ✓ 有茧／有伤，戒指一衬，手显得更粗 |
| 后续 | 洗手时摘下来放老地方 · 或者一直戴着不摘 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁给谁 | 她给他 | 他给她 |
| 场合 | 正式 | 特随便（厨房里、车上） |
| 他戴不戴出门 | 戴 | 上班摘下来，这细节得有说法 |
| 有没有承诺 | 说了 | 一个字没提 |

随便的场合常常比正式场合更打动人。洗着碗被套上一枚戒指，比跪地求婚更像过日子。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他手指比想的粗 | 她捏他手那一下 |
| 好的处理 | 她没吭声，直接戴上 | 他没问啥意思 |
| 写崩 | 写成了钻戒几克拉 | 写成了他哭得不行 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 玉扳指／她的一枚私印／束发的簪／腰间的玉牌 |
| 修仙 | 本命契印／她的一缕剑气烙在他腕上 |
| 星际 | 权限环／她的识别码写进他的腕带 |
| 女A男O | 标记（见 [03-世界观设定](../03-世界观设定/)） |

#### 写崩的三种方式

1. 只写戒指这个物件。 材质、价钱都无所谓。
2. 配一大段誓言。 话都在动作里了。
3. 不写怎么戴上去。 手抖、卡住、推到底，三下就写完了。

前接：[六 · 交出去](#六--交出去)

## 八 · 见家长

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 29.6%

**骨架**｜这段关系头一回让外人审，审的尺子对他不利。

#### 节拍链

他提前准备 → 席间那句质问 → 桌上安静半秒 → 她挡回去／他自己答 → 车里的沉默

#### 时间轴

要紧的就三个瞬间：落座时那一眼，质问出口的那半秒，临走时谁送到门口。饭桌上剩下的两小时都是陪衬。真正见分晓的是回去车上那段沉默：谁先憋不住开口、头一句说什么，比饭桌上所有的话都戳人。

#### 这条在这一类里的特殊性

传统言情里见家长，查的是男方挣多少、有没有前途。到了这个类型，问的东西换了：

| 常见质问 | 指向 |
|---|---|
| 「他一个大男人，靠你养？」 | 他挣钱不行 |
| 「你怎么什么都听她的？」 | 觉得他没主见 |
| 「你委不委屈啊？」（问她） | 觉得她亏了 |
| 「他家里怎么想？」 | 家里给的压力 |

难就难在，他们关系里最好的那部分，在外人眼里恰恰最不对劲。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 家宴 · 她爸妈来家里 · 他那边亲戚 · 同学聚会 |
| 他的准备 | 提前练了怎么接话 · 买了东西 ✓ · 换了身不像自己的衣服 ✓ |
| 那句话出口时 | 桌上静了半秒 · 看谁先开口 |
| 她的护 | 一句话顶回去 · 或者她也懵了，第一次更真实 |
| 事后 | 车里 ✓ 谁都没说话 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁家 | 她家 | 他家，他家更可能不理解 |
| 她的反应 | 当场挡 | 当时没反应过来，事后才想明白 |
| 他的反应 | 忍 | 自己回答了（且答得很好） |
| 结局 | 被接受 | 没被接受，两人自己扛 |

「自己回答了（且答得很好）」这头，他想让人承认，他护得住这段关系。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她反应过来自己慢了半拍 | 那句话砸下来，他先愣住 |
| 好的处理 | 她过后专门为那半拍道歉 | 他说“我不委屈”，语气很稳 |
| 写崩 | 写成她当场掀桌子 | 写成他憋一宿不敢吭声 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 认亲／宗族议事／他的父兄来问她的意思 |
| 修仙 | 拜见师门／宗门长老质疑他的资质配不配 |
| 星际 | 家族审查／匹配度报告不达标 |

现代版没有这个条件，冲突全靠关系本身撑着。古代女尊版不同，制度站在角色这边，这种关系在那个社会是常态，冲突就得从别处找，门第、家族利益都可以，写出来层次反倒更多。

#### 写崩的三种方式

1. 让她当场发火。 火一发完，事情反倒说不清了。
2. 让他从头到尾一声不出。 至少要有一回是他自己开口。
3. 让所有人马上就懂。 这个类型本来就不被理解，写出这点才有人看。

后接：[04-委屈与破防 · 忍到最后一秒](04-委屈与破防.md#六--忍到最后一秒)

## 九 · 一起买东西

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 29.6%

**骨架**｜逛超市，两个人推着购物车从头逛到尾。

#### 节拍链

推车 → 他往里放的全是她的 → 他自己那样拿起又放下 → 她把它拿回来放进车 → 结账

#### 时间轴

四十分钟，从生鲜区走到收银台，车里的东西换了好几轮。他给她拿的一样样放进去，他给自己挑的，拿起来又放下，她看见了，再拿回来放进车里。走到收银台时，车里那几样他自己的，都是他放下过、又被她放回来的。结账时看一眼车里就明白了。

#### 购物车社会学

| 观察点 | 读作 |
|---|---|
| 谁推车 | 谁在主导 |
| 他往车里放什么 | 他记得她要什么 |
| 她放回去的是什么 | 她的边界，太贵的、他给自己买的 |
| 结账谁付 | 经济关系 |
| 谁提袋子 | 体力分工 |
| 有没有买他自己的东西 | 他有没有把自己算进这个家 |

最后一条最好用。满满一车，全是她的和家里的，没有一样是他自己想要的。写到这儿，可以直接接 [04-委屈与破防](04-委屈与破防.md)。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 购物车 · 保鲜膜 ✓ · 牛奶 ✓ · 鸡蛋 ✓ · 他偷偷放进去又拿出来的那样 |
| 他的行为 | 记得她爱用的牌子 · 自己那份专挑便宜的 · 盯着价签看半天 |
| 她的行为 | 把他放回去的东西又拿回来 · 直接扫码付了 |
| 小摩擦 | 这东西买不买 · 到底听谁的 |

写「把他放回去的东西又拿回来」，一句台词都用不着。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁付钱 | 她 | 他坚持要付（他的钱不多） |
| 他买不买自己的 | 买 | 一样都没买 |
| 气氛 | 日常琐碎 | 刚吵完架，全程不说话但还是一起去了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 车里没一样东西是他的 | 拿起来又放下的那一下 |
| 好的处理 | 她不说破，直接拿回来搁车里 | 他没解释为啥放回去 |
| 写崩 | 写成她阔气包场 | 写成他抠门硬省还煽情 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 逛集市／她替他买下他多看了两眼的那样 |
| 修仙 | 坊市／灵石的分配 |
| 星际 | 配额分配／补给单上的项目 |

#### 写崩的三种方式

1. 写成购物清单。 挑三样，别全堆上。
2. 让她花钱眼都不眨。 这段好看在细节上。
3. 不写他放回去那一下。 这一下最要紧。

## 十 · 一个只属于他们的仪式

<!-- gb-nonscene -->
`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 29.6% 衍生

**骨架**｜只有他们两个懂的一件小事，能撑起一整本书。

#### 什么是私人仪式

一件小事，反复发生，意思只有他们两个知道。

| 例子 | 起源 |
|---|---|
| 出门前她拍两下他的背 | 第一次随手，后来成了习惯 |
| 他永远把她的杯子放在右手边 | 她左撇子，他反着放 |
| 每次吵完架她煮同一样东西 | 第一次和好时煮的 |
| 他数她回来的脚步声 | 等门那段时间留下的 |
| 她走之前会把他的头发拨一下 | 没有原因 |

私人仪式可以被打破。

#### 三个用法

| 用法 | 做法 |
|---|---|
| 建立 | 第一次发生时不点破，让它自然重复 |
| 计量 | 中途某次没做，读者立刻知道出事了 |
| 收束 | 结尾时它再次出现，什么都不用说 |

中间那个用法最有力：「今天她出门前没有拍他的背。」就这一句，前面一整章的铺垫都派上了用场。

#### 可用细节

| 类 | 内容 |
|---|---|
| 起源 | 必须是偶然的，不能是约定的 |
| 重复 | 至少写三次读者才会记住 |
| 变形 | 分开时他自己做了一遍 |
| 打破 | 一次缺席 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她想起自己从哪天开始干的 | 她今天没干 |
| 好的处理 | 她自己也讲不明白 | 他停了两秒才走 |
| 写崩 | 写成像事先说好的暗号 | 写成他死磕着数日子 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她出门前替他理一下衣领／每月初一的那盏灯 |
| 修仙 | 她每次闭关前留一道印记 |
| 星际 | 每次跃迁前的同一句话 |

#### 写崩的三种方式

1. 事先说好了约定。 说好的叫暗号，自己慢慢长出来的才叫仪式。
2. 只用一次。 至少用三次。
3. 一断就马上解释。 让读者自己看出来。

#### 可串接

这一条不单独成一场，它从头到尾贯穿全书，本卷哪一条都能挂上它。
