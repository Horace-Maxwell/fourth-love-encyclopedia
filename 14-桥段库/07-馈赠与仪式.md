# 馈赠与仪式

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**送礼是把关系变成物证。**

## 送礼的方向不对称

| | 她送他 | 他送她 |
|---|---|---|
| 性质 | 赏赐 · 给口饭吃 · 盖章 | 表白 · 献宝 · 证明自己有用 |
| 常见物 | 贵的 · 带身份的 · 她挑的 | 便宜的 · 亲手做的 · 攒钱买的 |
| 拒绝的可能 | 他基本没法说不 | 她可以不要 |
| 他／她收到时 | 他得琢磨「我配不配」 | 她得琢磨「他花了多少」 |
| 最疼的写法 | 她随手丢的东西他当命根子 | 他攒了仨月的钱她压根没看价签 |

最后一行是这一族最好用的一栏。 送礼的不对称，就是这个类型的关系不对称的物质形式。

| 节拍族 | 作品数 | 占比 | 特征物件（提升度） |
|---|---:|---:|---|
| 备礼送礼 | 718 | 24.8% | 包装 2.2× · 礼盒 1.6× · 蛋糕 1.5× · 丝带 1.2× · 花束 1.2× |

「包装 2.2×」是全库第二高的提升度。这一族的物质核心是包装，不是礼物本身。包装记录了准备的过程。

## 一 · 藏了很久的礼物

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 24.8%，做饭＋赠礼 4.6%

**骨架**｜他准备了挺久，就是一直没碰上合适的茬口。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 他决定送（起因很小） |
| 2 | 准备攒钱、学手艺、到处找 |
| 3 | 藏起来 |
| 4 | 找时机，一次次错过 |
| 5 | 藏太久，快过期／不合时宜了 |
| 6 | 送出去，或者被发现，或者一直没送 |

第 5 拍是这条区别于普通送礼戏的地方。 藏太久本身会变成新的情节。

#### 时间轴

藏的时长 ＝ 他的犹豫。写法：

| 记录物 | 显示什么 |
|---|---|
| 藏的位置换过三次 | 他怕被人翻出来 |
| 包装 ✓ 边角磨白了 | 他没事就拿出来摸 |
| 收据上的日期 | 她后来才瞧见 |
| 尺码不对了 / 过了保质期 | 搁太久，早变样了 |

「包装边角磨白」是这条最好的细节。 他没拆过，但他摸过很多次。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 包装 ✓（2.2×）· 礼盒 ✓（1.6×）· 丝带 ✓ · 收据 · 藏哪儿了：柜子顶层、行李箱夹层、他自己的书里 |
| 准备痕迹 | 这几个月他省吃俭用 · 手上的伤（做手工弄的）· 偷偷问过她朋友 |
| 错过的时机 | 她加班 · 她心情不好 · 旁边有人 · 他自己临阵缩了 |
| 被发现的方式 | 她找东西翻出来 · 搬家时看到 · 他自己终于拿出来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 送没送出去 | 送了 | 一直没送，她很久以后才发现 |
| 礼物价值 | 便宜但花了心思 | 贵到不像他会买的，她会心疼 |
| 她的反应 | 收下 | 先问「多少钱」，这句会伤人 |
| 时机 | 总算等到合适的当口 | 在不该开口的时候憋不住说了 |

「在完全不合适的时候脱口而出」比「找到完美时机」好：准备了很久的东西往往是失控着送出去的。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看见包装磨白的边角 | 每一次拿出来又放回去 |
| 内心 | 他到底藏了多久 | 今天行不行，今天算不算好日子 |
| 好的处理 | 她不问价格，她问「什么时候买的」 | 他没说自己攒了多久 |
| 写崩 | 写成她当场落泪 | 写成他委屈地强调自己多辛苦 |

「什么时候买的」比「多少钱」好一万倍。 前者问的是时间，后者问的是钱。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 亲手打的首饰／攒了三年的银子／绣了半年的活计 |
| 修仙 | 炼了百年的法器／拿命从险境采来的灵材 |
| 星际 | 用配额换的／从地球带上来的旧东西 |

修仙版有天然优势：炼制周期以年计，藏的时长可以拉到极限。

#### 写崩的三种方式

1. 礼物送得太贵。一贵，整段就变成拼财力了，他那点心意反而没人看了。
2. 让他自己说“我为你做了多少多少”。他一开口诉苦，读者立马就不心疼了。
3. 让她当场哭出来。她越忍着，读者越替她难受。

#### 可串接

前接：[02-等待与错过 · 错过的纪念日](02-等待与错过.md#八--错过的纪念日)
后接：[三 · 她随手给的东西](#三--她随手给的东西)

#### 示例（本库自撰，可直接改写）

> 盒子在柜子最上层，压在换季的被子底下。
> 换过三个地方。一开始在抽屉，后来觉得她会拉抽屉；挪到床底，又怕扫地时被看见。
> 边角那圈丝带已经不太挺了，是被手指来回捋的。他把它拿出来的时候，先在袖子上蹭了蹭灰。
> 里面的东西他自己都没再看过。日期是三月十七号。今天九月了。

## 二 · 送错的礼物

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 24.8%

**骨架**｜他送了，但送错了，这条比送对的更有看头。

#### 节拍链

他送出 → 她拆开 → 那零点五秒的停顿 → 她说喜欢 → 他听出来了 → 她留着或去换

#### 时间轴

那条她一直留着的，送错的，他每次看见都会想起来。换的那天他陪着去，两个人都不提为什么。或者去换，换之前先拆开，拆开瞬间那半秒是全条的心脏，之后的时间属于处理。从零点五秒的停顿开始，一周的余震。错的余震比对的余温长。

#### 送错的四种方式

| 错法 | 说明 | 疼的点 |
|---|---|---|
| 尺寸错 | 他不知道她穿多大 | 说明他压根没上心 |
| 品味错 | 他挑了自己觉得好的 | 说明他还按自己那套来 |
| 过时了 | 她三个月前想要，现在不想要了 | 时间差 |
| 撞了 | 别人已经送过一样的 | 最难堪 |

「撞了」最好用，且可以直接接 [05-占有与吃醋](05-占有与吃醋.md)。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他发现错了的瞬间 | 她拆开时那零点五秒的停顿 |
| 她的补救 | 立马说喜欢，他听得出来 · 要不就老实说「我换一个尺码」 |
| 他的反应 | 想拿回来 · 说「我去换」· 一声不吭 |
| 后来 | 她一直戴着那个不合适的 · 或者她真去换了，两种都行 |

「她一直戴着那个不合适的」和「她去换了」哪个更好，得看人物。前者是心疼他，后者是尊重他的钱。两种都能写，但得选得有道理。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她说不说破 | 假装喜欢 | 直说 |
| 他知不知道她在假装 | 不知道 | 知道，更难受 |
| 结局 | 她留着 | 她去换了，且告诉他了 |
| 后续 | 他从此更用心地观察她 | 他从此不敢送了（更疼） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 拆开那一下心里咯噔 | 她停顿的那零点五秒 |
| 好的处理 | 她实话实说，但话说得软 | 他没有马上认错 |
| 写崩 | 写她装都装不像 | 写他破罐子破摔 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 送的样式她早不戴了／料子不合她的品级 |
| 修仙 | 法器属性与她的功法相冲 |
| 星际 | 规格不兼容她的装备 |

#### 写崩的三种方式

1. 让错误无关紧要。要真的错，错得他自己也知道。
2. 让她大方到毫无波澜。那零点五秒必须有。
3. 让他从此不送了，但文本不处理。这个变化要被她看见。

## 三 · 她随手给的东西

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 24.8%

**骨架**｜她随手丢的那东西，他当宝贝一样攒了三年。

#### 节拍链

她顺手给 → 他单独收着 → 三年过去 → 她翻他抽屉看见 → 「这个是哪来的」→ 他说「捡的」

#### 时间轴

这条全靠时差撑起来。他那边三年，单独收着，搬家三次都带着。她这边一秒，顺手一递，转头就忘。两个人的钟走速不一样。「这个是哪来的」一问出口，两条时间线才头一回对上。

#### 为什么这条是这一族的核心

它把不对称写到了极致：同一件物品，在两个人心里的重量差了一百倍。

而且它不需要任何人做错事。她真的只是顺手，他真的很珍惜。

#### 可用细节

| 类 | 内容 |
|---|---|
| 物品 | 她喝剩的半瓶水 · 她用过的笔 · 她随手买的挂件 · 她那件旧外套 ✓ |
| 他的收藏方式 | 单独搁着 · 不用 · 用了也小心怕弄坏 · 换手机时先把那条消息转走 ✓ |
| 她的记忆 | 她压根不记得给过 |
| 揭开的时机 | 她帮他搬东西时看见 · 她问「这哪来的」 |
| 实测特征物 | 相册 ✓（提升度 9.0×）· 照片 ✓（2.0×），「看照片」场景实测，9.0× 是整张表里最高的——揭开戏要是走翻相册这条路，道具自己就带戏（来源：[13-07 §道具提升度](../13-语料挖掘/07-桥段分布.md)） |

「这个是哪来的」这句话是这条的引爆器。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她记不记得 | 隐约记得 | 完全不记得 |
| 他说不说 | 说了 | 说「捡的」 |
| 她的反应 | 心里一沉 | 她也开始琢磨自己平时都给了人家啥 |
| 物品状态 | 保存得很好 | 用坏了但没扔 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她认出那是自己的东西 | 她问起来的那一刻 |
| 内心 | 我什么时候给的 | 别问，别问 |
| 好的处理 | 她不追问，但她记住了 | 他说「捡的」，然后转身 |
| 写崩 | 写成她感动到哭 | 写成他哀怨地控诉 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她赏的一方帕子／她用旧的一支笔／她随手系的络子 |
| 修仙 | 她剑上掉的一缕穗子／她随手给的一枚符 |
| 星际 | 她换下的旧徽章／她留的一段旧录音 |

#### 写崩的三种方式

1. 让她马上补偿。补偿会把这条庸俗化。
2. 让他说出全部。「捡的」两个字就够。
3. 写成他卑微。珍惜不等于卑微。判据：他有没有因此要求什么。

#### 示例（本库自撰，可直接改写）

> 抽屉最里层有个盒子，鞋盒那么大，压在几本旧书下面。
> 她打开了。里面只有一支笔。
> 笔杆上的漆掉了一小块，笔帽有个磕痕。三年前她用过的那支，写不出水之后随手扔在桌上。
> 她把盒子合上，放回原处，位置摆得和刚才一样。
> 「文件我找到了。」她说。
> 那天之后，她开始留意自己顺手给了他什么。

## 四 · 生日

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 24.8%

**骨架**｜生日在这类文里就是个时间刻度，不是拿来庆祝的。

#### 节拍链

他说「不用过」→ 她记得 → 不办大的 → 点蜡烛 → 他闭眼太久 → 睁眼时看的是她

#### 时间轴

老式挂钟一年一格，生日戏却短得像蜡烛点上到吹灭，撑死十分钟。三年压进一根蜡烛里，去年他还说「不用过」，今年提前一周就不对劲，明年大概会自己开口报愿望。纵向拉得长，单场戏短得很，写生日就得这么干。

#### 生日能测出什么

| 观察点 | 测出 |
|---|---|
| 谁的生日被过得更隆重 | 谁在这段关系里更重 |
| 他记不记得她的 | 及格线 |
| 她记不记得他的 | 真考验 |
| 蛋糕 ✓ 上写谁的名字 | 谁说了算 |
| 有没有别人在 | 关系敢不敢见光 |
| 他许的愿 | 整条线的收尾 |

「他许的愿」是这条唯一必须写的。 而且他不会说出来。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 蛋糕 ✓（1.5×）· 蜡烛 ✓ · 礼盒 ✓ · 花束 ✓ · 照片 ✓ · 那顶纸帽子 |
| 他的生日 | 他不提 · 她忘了／她记得 · 他说「不用过」（这句要留） |
| 许愿的细节 | 他闭眼太久 · 她在旁边等 · 他睁眼时看的是她 |
| 收尾 | 蜡烛吹灭后的那几秒黑 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁的生日 | 她的 | 他的（更有戏） |
| 他提不提 | 提前露点口风 | 一个字不说 |
| 她记不记得 | 记得，早备好了 | 忘了，当天才补 |
| 愿望 | 他讲出来了 | 他没讲，读者心里有数 |

「他说『不用过』」是这个类型里最需要被拆穿的一句话。 说这句的人，往往从来没有被认真过过生日。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他从来没被好好过过生日 | 蜡烛点上的那一刻 |
| 好的处理 | 她不办大的，她只是记得 | 他许的愿跟自己无关 |
| 写崩 | 写成盛大的惊喜派对 | 写成他自怜身世 |

「不办大的，只是记得」在这个类型里的评价远高于盛大惊喜。排场是给外人看的，记得是给他的。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 生辰／长寿面／她赐的生辰礼 |
| 修仙 | 他的凡人生辰早已没人记得，除了她 |
| 星际 | 地球历的日期，舰上没人过 |

修仙与星际版共享同一个最强设定：在一个不记录这个日期的世界里，只有她记得。

#### 写崩的三种方式

1. 办成惊喜派对。人越多，越像表演。
2. 让他说出愿望。读者猜到就够了。
3. 忽略「不用过」这句。那句话背后有整段前史。

## 五 · 合照

`G` ｜ 无预警 ｜ 现代／星际 ｜ 语料频次：备礼送礼 24.8%

**骨架**｜第一张合照发出来，比说多少句都好使。

#### 节拍链

有人提议 → 拍 → 他不敢靠太近，或悄悄拉近半寸 → 他没看镜头 → 设成锁屏 → 换掉 → 又设回来

#### 时间轴

有人来了，锁屏换掉，人走了，再设回来。快门一按，1/125秒的事，但照片设成锁屏，能用很久。每次换、每次设，都是一次表态。这照片的寿命，比相册里其他东西都长。拍照就那么一下，锁屏却换了三轮。

#### 照片的语义

| 观察点 | 读作 |
|---|---|
| 谁提出拍的 | 谁更想留个念想 |
| 拍的时候两人的距离 | 俩人走到哪一步了 |
| 他有没有看镜头 | 他眼里是她还是走流程 |
| 照片放在哪 | 手机 ✓ 锁屏／相册 ✓ 最底下／打印出来 |
| 发不发出去 | 让多少人看见 |
| 三年后再看这张 | 时间够不够沉 |

「他有没有看镜头」是这条唯一需要写的细节。 很多这类照片里，他在看她。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 照片 ✓ · 相册 ✓ · 手机 ✓ · 屏幕 ✓ · 打印出来那张的折痕 |
| 拍照的场合 | 随手 · 特意 · 别人帮拍 · 自拍时手不够长 |
| 他的姿态 | 不敢靠太近 · 手不知道放哪 · 或者他悄悄拉近了半寸 |
| 后续 | 他把它设成锁屏，又换掉，又设回来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提议 | 她 | 他（他会找借口） |
| 他敢不敢公开 | 设成锁屏 | 只放在相册最深处 |
| 数量 | 只有一张 | 他存了很多张她的，两人的只有一张 |
| 后续 | 越拍越多 | 这张一直是唯一的一张 |

「他存了很多张她的，两人的只有一张」是极好的设定：单方面凝视与双方确认，数量差就是关系差。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她翻他手机，看他相册里存了啥 | 拍照时手搁哪儿 |
| 好的处理 | 她拿那张图当了锁屏 | 他想要一张，没敢开口 |
| 写崩 | 写成她逼他公开 | 写成他偷拍上瘾 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 画像／她请人画的双人图／他自己描的一张 |
| 修仙 | 留影石／神识里的一段记忆 |
| 星际 | 全息影像／一段被他反复回放的舱内录像 |

古代版的「他自己描的一张」最动人：画得不像，但他画了很多遍。

#### 写崩的三种方式

1. 写成秀恩爱。这条的重量在私密，不在公开。
2. 省略他的手放在哪。那是全条的信息。
3. 拍得太多。第一张的价值来自唯一。

## 六 · 交出去

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 24.8%

**骨架**｜他把族里最重的一件信物交到她手里，让她知道这事他说了算。

#### 节拍链

他决定 → 推过去 → 「你拿着」（不解释）→ 她愣住 → 她怎么接 → 她也给了他一样

#### 时间轴

决定用了三个月，交出去就三秒钟。「你拿着」这三个字说出口之前，他整整盘算了一个季度：值不值、她会不会嫌沉、怎么说才不显得太隆重。交出去的时候越轻描淡写，前头那三个月就越压秤。反差越大，这条越成立。

#### 交出去的东西

按重量排：

| 物 | 交出的是 |
|---|---|
| 家门钥匙 ✓ | 空间 |
| 手机 ✓ 密码 | 隐私 |
| 工资卡 / 存折 | 经济自主 |
| 他的日程 | 时间 |
| 他的旧物（唯一一件） | 过去 |
| 一个只有他知道的秘密 | 底牌 |

这条的重头在她怎么接，交出去只是开场。

| 她的接法 | 读作 |
|---|---|
| 收下并使用 | 她当成事实 |
| 收下但从不用 | 她收心意，不收权力 |
| 退回去 | 她觉得他不用交这个 |
| 收下，然后交出对等的一样 | 最好的一种 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 交出的动作 | 放桌上推过去 · 塞她包里 · 直接把密码说了 |
| 他的措辞 | 「你拿着」（不解释）· 或者啰嗦一堆，说明他紧张 |
| 她的反应 | 愣住 · 问「为啥」· 啥也没问就收了 |
| 后续 | 他后不后悔 · 她到底用没用 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他交的东西 | 走个形式 | 来真的（工资卡、密码） |
| 她的处理 | 收下 | 退回去，把话说清楚 |
| 是不是被要求的 | 他自己乐意 | 她开口要的，性质完全两码事 |
| 后续 | 关系更近了 | 他回头又想拿回来，这条更真实 |

「她提出的」这头得留神：你逼着对方把自主权交出来，那是控制，人家自己主动交给你，那是信任。同一个动作，谁先伸手，性质就全反了。具体可以翻翻 [05-占有与吃醋 · 独占欲的边界](05-占有与吃醋.md#十--独占欲的边界)。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 东西被推过来的那一下 | 说出口之前想了多久 |
| 内心 | 我该不该收 | 她收了就说明她认了 |
| 好的处理 | 她收下，也回了他一样 | 他没提附加条件 |
| 写崩 | 写成她收得理所当然 | 写成他把自己整个搭进去 |

「她也给了他一样」是这个类型里最好的收法。不对称的关系里，一次对等的交换，比十次宠溺更有分量。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 卖身契／他的印鉴／族谱上的名字／他把身契交到她手上 |
| 修仙 | 本命法器／魂灯／识海权限 |
| 星际 | 最高权限授权／生命体征绑定到她的终端 |

古代版的「身契」在语义上最重，也最需要小心：它容易滑向人身依附。写的时候要让这是他的选择，而且她得有明确的回应。

#### 写崩的三种方式

1. 写成人身依附。交出自主权和放弃人格是两回事。
2. 让她要求他交。见上。
3. 交完就没下文。她怎么处置，才是这条的下半场。

## 七 · 戒指

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 24.8%

**骨架**｜谁给谁戴、戴哪只手，就这点事。

#### 节拍链

拿出来 → 手抖 → 戴不进去 → 推到底 → 转一下让它正 → 谁都没说话

#### 时间轴

从拿出来到戴正，全程不到一分钟，拆成六拍慢放。掏、抖、对不准、推、转正、沉默——每拍之间可以停顿，停顿里塞的是这段关系的全部前史。这一分钟是全书时间密度最高的一分钟，别赶。

#### 戴法的语义表

| 谁给谁 | 哪只手 | 读作 |
|---|---|---|
| 她给他戴 | 左手无名指 | 明摆着告诉别人 |
| 她给他戴 | 右手 | 留着，或者设定里另有说法 |
| 他给她戴 | 左手无名指 | 求她，得她抬一下手 |
| 他自己戴上 | — | 自己说了算 |
| 两人互相戴 | — | 谁也没压过谁 |
| 她把自己的给他 | 尺寸不合，他戴小指 | 最戳人的一版 |

「尺寸不合，戴在小指」是这条最好用的写法。它把「这不是为你准备的，但我给你了」和「我收下了，用我的办法」压在同一个动作里。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 戒指 ✓ · 礼盒 ✓ · 丝带 ✓ · 尺寸（他量过她手指 ✓）· 内圈刻字 |
| 戴的动作 | 手抖 · 戴不进去 · 推到底 · 转正 |
| 他的手 | 手指 ✓ 有茧／有伤，戒指一衬，手显得更粗 |
| 后续 | 洗手时摘下来放老地方 · 或者一直戴着不摘 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁给谁 | 她给他 | 他给她 |
| 场合 | 正式 | 特随便（厨房里、车上） |
| 他戴不戴出门 | 戴 | 上班摘下来，这细节得有说法 |
| 有没有承诺 | 说了 | 一个字没提 |

「极随意的场合」往往比正式场合动人：在洗碗的时候被套上一枚戒指，比跪地求婚更像生活。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他手指比想的粗 | 她捏他手那一下 |
| 好的处理 | 她没吭声，直接戴上 | 他没问啥意思 |
| 写崩 | 写成了钻戒几克拉 | 写成了他哭得不行 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 玉扳指／她的一枚私印／束发的簪／腰间的玉牌 |
| 修仙 | 本命契印／她的一缕剑气烙在他腕上 |
| 星际 | 权限环／她的识别码写进他的腕带 |
| 女A男O | 标记（见 [03-世界观设定](../03-世界观设定/)） |

#### 写崩的三种方式

1. 写成物件本身。什么材质、值多少钱，根本不重要。
2. 配上大段誓言。动作本身就把话说完了。
3. 不写怎么戴上去的。手抖、卡住、推到底，这三下就完了。

## 八 · 见家长

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 24.8%

**骨架**｜关系第一次被外人查了，查的标准向来对他不友好。

#### 节拍链

他提前准备 → 席间那句质问 → 桌上安静半秒 → 她挡回去／他自己答 → 车里的沉默

#### 时间轴

真正要紧的其实就三个瞬间，落座那一眼，质问出口那半秒，还有临走时谁送到门口。饭桌上其余两小时，全是凑数。车里那段沉默才见真章，谁先憋不住开口，第一句说什么，比席间所有话都更戳人。收尾那刻谁站在门口目送，反倒比道别本身更有分量。

#### 这条在这一类里的特殊性

传统言情里，见家长审查的是男方的经济与前途。这个类型里，问题变了：

| 常见质问 | 指向 |
|---|---|
| 「他一个大男人，靠你养？」 | 他挣钱不行 |
| 「你怎么什么都听她的？」 | 觉得他没主见 |
| 「你委不委屈啊？」（问她） | 觉得她亏了 |
| 「他家里怎么想？」 | 家里给的压力 |

这一族的核心冲突是：他们关系里最好的部分，正是外人眼里最不对劲的部分。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 家宴 · 她爸妈来家里 · 他那边亲戚 · 同学聚会 |
| 他的准备 | 提前练了怎么接话 · 买了东西 ✓ · 换了身不像自己的衣服 ✓ |
| 那句话出口时 | 桌上静了半秒 · 看谁先开口 |
| 她的护 | 一句话顶回去 · 或者她也懵了，第一次更真实 |
| 事后 | 车里 ✓ 谁都没说话 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁家 | 她家 | 他家，他家更可能不理解 |
| 她的反应 | 当场挡 | 当时没反应过来，事后才想明白 |
| 他的反应 | 忍 | 自己回答了（且答得很好） |
| 结局 | 被接受 | 没被接受，两人自己扛 |

「他自己回答了，且答得很好」是这条最好的一版：他不需要被保护，他需要被承认有能力保护这段关系。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她反应过来自己慢了半拍 | 那句话砸下来，他先愣住 |
| 好的处理 | 她过后专门为那半拍道歉 | 他说“我不委屈”，语气很稳 |
| 写崩 | 写成她当场掀桌子 | 写成他憋一宿不敢吭声 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 认亲／宗族议事／他的父兄来问她的意思 |
| 修仙 | 拜见师门／宗门长老质疑他的资质配不配 |
| 星际 | 家族审查／匹配度报告不达标 |

现代版没这条件，冲突只能靠关系本身硬撑。古代女尊版就不一样了，制度站在角色这边，关系在那个社会里是常态，所以冲突得从别处挖，门第、家族利益都行，这么写层次反而更丰富。

#### 写崩的三种方式

1. 这类型写得明白，才能让人看懂，毕竟它天生就不被理解。
2. 让她当场炸了，火发完了，事儿反倒说不清了。
3. 让他从头到尾不吭声，可至少有一次，是他自己主动开口。

## 九 · 一起买东西

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 24.8%

**骨架**｜逛超市。这条就是俩人推着购物车从头走到尾。

#### 节拍链

推车 → 他往里放的全是她的 → 他自己那样拿起又放下 → 她把它拿回来放进车 → 结账

#### 时间轴

四十分钟，从生鲜区走到收银台，购物车里的东西换了好几轮。他替她拿的，她看见了又放回去，他为自己挑的，也被她放回去。走到收银台的时候，车里剩下的那些，他原本放下过，又放回去了。购物车就是进度条，一条动线走到底，谁欠谁、谁占谁，到最后一目了然。结账的时候，车里的比例已经说明了一切。

#### 购物车社会学

| 观察点 | 读作 |
|---|---|
| 谁推车 | 谁在主导 |
| 他往车里放什么 | 他记得她要什么 |
| 她放回去的是什么 | 她的边界，太贵的、他给自己买的 |
| 结账谁付 | 经济关系 |
| 谁提袋子 | 体力分工 |
| 有没有买他自己的东西 | 他有没有把自己算进这个家 |

最后一条最实用。那一车东西，全是她的和家里的，没一样是他自己想要的。这个细节直接接 [04-委屈与破防](04-委屈与破防.md) 就行。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 购物车 · 保鲜膜 ✓ · 牛奶 ✓ · 鸡蛋 ✓ · 他偷偷放进去又拿出来的那样 |
| 他的行为 | 记得她爱用的牌子 · 自己那份专挑便宜的 · 盯着价签看半天 |
| 她的行为 | 把他放回去的东西又拿回来 · 直接扫码付了 |
| 小摩擦 | 这东西买不买 · 到底听谁的 |

「她把他放回去的东西又拿回来」是这条的最优解，且一句台词都不需要。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁付钱 | 她 | 他坚持要付（他的钱不多） |
| 他买不买自己的 | 买 | 一样都没买 |
| 气氛 | 日常琐碎 | 刚吵完架，全程不说话但还是一起去了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 车里没一样东西是他的 | 拿起来又放下的那一下 |
| 好的处理 | 她不说破，直接拿回来搁车里 | 他没解释为啥放回去 |
| 写崩 | 写成她阔气包场 | 写成他抠门硬省还煽情 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 逛集市／她替他买下他多看了两眼的那样 |
| 修仙 | 坊市／灵石的分配 |
| 星际 | 配额分配／补给单上的项目 |

#### 写崩的三种方式

1. 写成购物清单。 挑三样，别堆一堆。
2. 让她花钱不眨眼。 这条卖的是细节，不是摆阔。
3. 别写他放回去那下。 那才是关键。

## 十 · 一个只属于他们的仪式

<!-- gb-nonscene -->
`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 24.8% 衍生

**骨架**｜这不是一个桥段，而是能撑起整本书的设定。

#### 什么是私人仪式

一件重复发生的、只有他们两个知道含义的小事。

| 例子 | 起源 |
|---|---|
| 出门前她拍两下他的背 | 第一次随手，后来成了习惯 |
| 他永远把她的杯子放在右手边 | 她左撇子，他反着放 |
| 每次吵完架她煮同一样东西 | 第一次和好时煮的 |
| 他数她回来的脚步声 | 等门那段时间留下的 |
| 她走之前会把他的头发拨一下 | 没有原因 |

私人仪式的价值在于它可以被打破。 建立它用一章，打破它用一句话。

#### 三个用法

| 用法 | 做法 |
|---|---|
| 建立 | 第一次发生时不点破，让它自然重复 |
| 计量 | 中途某次没做，读者立刻知道出事了 |
| 收束 | 结尾时它再次出现，什么都不用说 |

中间那个用法最有力：「今天她出门前没有拍他的背。」一句话，一整章的铺垫全部兑现。

#### 可用细节

| 类 | 内容 |
|---|---|
| 起源 | 必须是偶然的，不能是约定的 |
| 重复 | 至少写三次读者才会记住 |
| 变形 | 分开时他自己做了一遍 |
| 打破 | 一次缺席 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她想起自己从哪天开始干的 | 她今天没干 |
| 好的处理 | 她自己也讲不明白 | 他停了两秒才走 |
| 写崩 | 写成像事先说好的暗号 | 写成他死磕着数日子 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她出门前替他理一下衣领／每月初一的那盏灯 |
| 修仙 | 她每次闭关前留一道印记 |
| 星际 | 每次跃迁前的同一句话 |

#### 写崩的三种方式

1. 得有个明确的约定。 约定的是暗号，自然长出来的才叫仪式。
2. 只用一次。 至少用三次。
3. 破了马上解释。 让读者自己看出来。
