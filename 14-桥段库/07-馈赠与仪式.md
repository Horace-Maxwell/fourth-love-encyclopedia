# 馈赠与仪式

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**送礼是把关系变成物证。**

## 送礼的方向不对称

| | 她送他 | 他送她 |
|---|---|---|
| 性质 | 赏赐 · 供给 · 标记 | 表白 · 献 · 证明自己有用 |
| 常见物 | 贵的 · 有身份含义的 · 她挑的 | 便宜的 · 亲手做的 · 攒钱买的 |
| 拒绝的可能 | 他几乎不能拒绝 | 她可以不收 |
| 他／她收到时 | 他要考虑「我配不配」 | 她要考虑「他花了多少」 |
| 最疼的写法 | 她随手送的东西他当宝贝 | 他攒了三个月的钱她根本没在意价格 |

最后一行是这一族最好用的一栏。 送礼的不对称，就是这个类型的关系不对称的物质形式。

| 节拍族 | 作品数 | 占比 | 特征物件（提升度） |
|---|---:|---:|---|
| 备礼送礼 | 718 | 24.8% | 包装 2.2× · 礼盒 1.6× · 蛋糕 1.5× · 丝带 1.2× · 花束 1.2× |

「包装 2.2×」是全库第二高的提升度。这一族的物质核心是包装，不是礼物本身。包装记录了准备的过程。

## 一 · 藏了很久的礼物

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 24.8%，做饭＋赠礼 4.6%

**骨架**｜他准备了很久，一直没找到合适的时机。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 他决定送（起因很小） |
| 2 | 准备（攒钱／学手艺／到处找） |
| 3 | 藏起来 |
| 4 | 找时机，一次次错过 |
| 5 | 藏太久，快过期／不合时宜了 |
| 6 | 送出去，或者被发现，或者一直没送 |

第 5 拍是这条区别于普通送礼戏的地方。 藏太久本身会变成新的情节。

#### 时间轴

藏的时长 ＝ 他的犹豫。写法：

| 记录物 | 显示什么 |
|---|---|
| 藏的位置换过三次 | 他一直在担心被发现 |
| 包装 ✓ 边角磨白了 | 他反复拿出来看 |
| 收据上的日期 | 她后来看见了 |
| 尺码不对了 / 过了保质期 | 藏得太久 |

「包装边角磨白」是这条最好的细节。 他没拆过，但他摸过很多次。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 包装 ✓（2.2×）· 礼盒 ✓（1.6×）· 丝带 ✓ · 收据 · 藏的位置（柜子上层、行李箱夹层、他自己的书里） |
| 准备痕迹 | 他这几个月很省 · 他手上的伤（手工）· 他偷偷问过她朋友 |
| 错过的时机 | 她加班 · 她心情不好 · 有别人在 · 他自己临阵退了 |
| 被发现的方式 | 她找东西时看见 · 搬家时 · 他自己终于拿出来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 送没送出去 | 送了 | 一直没送（她很久以后才发现） |
| 礼物价值 | 便宜但花了心思 | 贵到不合他的身份（她会心疼） |
| 她的反应 | 收下 | 先问「多少钱」（这句会伤人） |
| 时机 | 终于等到了好时机 | 在一个完全不合适的时候脱口而出 |

「在完全不合适的时候脱口而出」比「找到完美时机」好：准备了很久的东西往往是失控着送出去的。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看见包装磨白的边角 | 每一次拿出来又放回去 |
| 内心 | 他到底藏了多久 | 今天行不行，今天算不算好日子 |
| 好的处理 | 她不问价格，她问「什么时候买的」 | 他没说自己攒了多久 |
| 写崩 | 写成她当场落泪 | 写成他委屈地强调自己多辛苦 |

「什么时候买的」比「多少钱」好一万倍。 前者问的是时间，后者问的是钱。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 亲手打的一件首饰／攒了三年的银子／绣了半年的东西 |
| 修仙 | 炼了百年的一件法器／采了三次险境的灵材 |
| 星际 | 用配额换的／从地球带上来的一件旧物 |

修仙版有天然优势：炼制周期以年计，藏的时长可以拉到极限。

#### 写崩的三种方式

1. 让礼物太贵重。 贵重把这条变成物质叙事，且会削弱他的位置。
2. 让他强调自己的付出。 他一说，读者就不心疼了。
3. 让她当场大哭。 她的反应越轻，读者的反应越重。

#### 可串接

前接：[02-等待与错过 · 错过的纪念日](02-等待与错过.md#八--错过的纪念日)
后接：[三 · 她随手给的东西](#三--她随手给的东西)

#### 示例（本库自撰，可直接改写）

> 盒子在柜子最上层，压在换季的被子底下。
> 换过三个地方。一开始在抽屉，后来觉得她会拉抽屉；挪到床底，又怕扫地时被看见。
> 边角那圈丝带已经不太挺了，是被手指来回捋的。他把它拿出来的时候，先在袖子上蹭了蹭灰。
> 里面的东西他自己都没再看过。日期是三月十七号。今天九月了。

## 二 · 送错的礼物

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 24.8%

**骨架**｜他送了，但送错了。这条比送对更有内容。

#### 节拍链

他送出 → 她拆开 → 那零点五秒的停顿 → 她说喜欢 → 他听出来了 → 她留着或去换

#### 时间轴

零点五秒的停顿，一周的余震。 拆开瞬间那半秒是全条的心脏，之后的时间属于处理：她留着（他每次看见都想起送错）或去换（换的那天他陪着去，两个人都不提为什么）。错的余震比对的余温长。

#### 送错的四种方式

| 错法 | 说明 | 疼的点 |
|---|---|---|
| 尺寸错 | 他不知道她的号 | 说明他没那么了解她 |
| 品味错 | 他挑了自己觉得好的 | 说明他还在按自己的标准 |
| 过时了 | 她三个月前想要，现在不想要了 | 时间差 |
| 撞了 | 别人已经送过一样的 | 最难堪 |

「撞了」最好用，且可以直接接 [05-占有与吃醋](05-占有与吃醋.md)。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他发现错了的瞬间 | 她拆开时那零点五秒的停顿 |
| 她的补救 | 立刻说喜欢（他听得出来）· 或者诚实地说「我换一个尺码」 |
| 他的反应 | 想收回来 · 说「我去换」· 一句话不说 |
| 后来 | 她一直戴着那个不合适的 · 或者她真的去换了（两种都对） |

「她一直戴着那个不合适的」和「她去换了」哪个更好，取决于人物：前者是心疼他，后者是尊重他的钱。 都可以写，但要选得有理由。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她说不说破 | 假装喜欢 | 直说 |
| 他知不知道她在假装 | 不知道 | 知道，更难受 |
| 结局 | 她留着 | 她去换了，且告诉他了 |
| 后续 | 他从此更用心地观察她 | 他从此不敢送了（更疼） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 拆开那一下的心里咯噔 | 她停顿的那零点五秒 |
| 好的处理 | 她诚实但温和地处理 | 他没有立刻道歉 |
| 写崩 | 写成她演技拙劣 | 写成他自暴自弃 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 送的样式她早不戴了／料子不合她的品级 |
| 修仙 | 法器属性与她的功法相冲 |
| 星际 | 规格不兼容她的装备 |

#### 写崩的三种方式

1. 让错误无关紧要。 要真的错，错得他自己也知道。
2. 让她大方到毫无波澜。 那零点五秒必须有。
3. 让他从此不送了而文本不处理。 这个变化要被她看见。

## 三 · 她随手给的东西

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 24.8%

**骨架**｜她顺手给的一样东西，他当宝贝收了三年。

#### 节拍链

她顺手给 → 他单独收着 → 三年过去 → 她翻他抽屉看见 → 「这个是哪来的」→ 他说「捡的」

#### 时间轴

两个人的钟不同速。 她那边一秒（顺手一递，转头就忘）；他那边三年（单独收、搬家三次都带着）。这条的全部力量来自时差——「这个是哪来的」问出口时，两条时间线才第一次对表。

#### 为什么这条是这一族的核心

它把不对称写到了极致：同一件物品，在两个人心里的重量差了一百倍。

而且它不需要任何人做错事。她真的只是顺手，他真的很珍惜。

#### 可用细节

| 类 | 内容 |
|---|---|
| 物品 | 她剩下的半瓶水 · 她用过的笔 · 她随手买的一个挂件 · 她的旧外套 ✓ |
| 他的收藏方式 | 单独放着 · 不用 · 用了也不敢用坏 · 换手机时先转移这条消息 ✓ |
| 她的记忆 | 完全不记得给过 |
| 揭开的时机 | 她搬他东西时看见 · 她问「这个是哪来的」 |
| 实测特征物 | 相册 ✓（提升度 9.0×）· 照片 ✓（2.0×），「看照片」场景实测，9.0× 为提升度全表最高——揭开戏若走翻相册的路，道具自带辨识度（来源：[13-07 §道具提升度](../13-语料挖掘/07-桥段分布.md)） |

「这个是哪来的」这句话是这条的引爆器。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她记不记得 | 隐约记得 | 完全不记得 |
| 他说不说 | 说了 | 说「捡的」 |
| 她的反应 | 心里一沉 | 她也从此开始留意自己给了什么 |
| 物品状态 | 保存得很好 | 用坏了但没扔 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她认出那是自己的东西 | 她问起来的那一刻 |
| 内心 | 我什么时候给的 | 别问，别问 |
| 好的处理 | 她不追问，但她记住了 | 他说「捡的」，然后转身 |
| 写崩 | 写成她感动到哭 | 写成他哀怨地控诉 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她赏下的一方帕子／她用旧的一支笔／她随手系上的络子 |
| 修仙 | 她剑上掉下的一缕穗子／她随手给的一枚符 |
| 星际 | 她换下来的旧徽章／她的一段旧录音 |

#### 写崩的三种方式

1. 让她马上补偿。 补偿会把这条庸俗化。
2. 让他说出全部。 「捡的」两个字就够。
3. 写成他卑微。 珍惜不等于卑微。判据：他有没有因此要求什么。

#### 示例（本库自撰，可直接改写）

> 抽屉最里层有个盒子，鞋盒那么大，压在几本旧书下面。
> 她打开了。里面只有一支笔。
> 笔杆上的漆掉了一小块，笔帽有个磕痕。三年前她用过的那支，写不出水之后随手扔在桌上。
> 她把盒子合上，放回原处，位置摆得和刚才一样。
> 「文件我找到了。」她说。
> 那天之后，她开始留意自己顺手给了他什么。

## 四 · 生日

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 24.8%

**骨架**｜生日在这一类里的用法是校准，不是庆祝。

#### 节拍链

他说「不用过」→ 她记得 → 不办大的 → 点蜡烛 → 他闭眼太久 → 睁眼时看的是她

#### 时间轴

一年一格的校准器。 单场很短：蜡烛点上到吹灭不过十分钟。纵向很长：去年他说「不用过」，今年他提前一周开始状态异常，明年他会主动报愿望。生日的写法是把三年叠在一根蜡烛上。

#### 生日能测出什么

| 观察点 | 测出 |
|---|---|
| 谁的生日被过得更隆重 | 关系的重心 |
| 他记不记得她的 | 基线 |
| 她记不记得他的 | 真正的考题 |
| 蛋糕 ✓ 上写谁的名字 | 谁在主持 |
| 有没有别人在 | 关系的公开程度 |
| 他许的愿 | 全条的落点 |

「他许的愿」是这条唯一必须写的。 而且他不会说出来。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 蛋糕 ✓（1.5×）· 蜡烛 ✓ · 礼盒 ✓ · 花束 ✓ · 照片 ✓ · 那顶纸帽子 |
| 他的生日 | 他不提 · 她忘了／她记得 · 他说「不用过」（这句要留） |
| 许愿的细节 | 他闭眼太久 · 她在旁边等 · 他睁眼时看的是她 |
| 收尾 | 蜡烛吹灭后的那几秒黑 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁的生日 | 她的 | 他的（更有戏） |
| 他提不提 | 提前暗示 | 一个字不说 |
| 她记不记得 | 记得，且早有准备 | 忘了，当天补救 |
| 愿望 | 他说了出来 | 他没说，读者知道 |

「他说『不用过』」是这个类型里最需要被拆穿的一句话。 说这句的人，往往从来没有被认真过过生日。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他从来没被好好过过生日 | 蜡烛点上的那一刻 |
| 好的处理 | 她不办大的，她只是记得 | 他许的愿跟自己无关 |
| 写崩 | 写成盛大的惊喜派对 | 写成他自怜身世 |

「不办大的，只是记得」在这个类型里的评价远高于盛大惊喜。排场是给外人看的，记得是给他的。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 生辰／长寿面／她赐的生辰礼 |
| 修仙 | 他的凡人生辰（早已没人记得，除了她） |
| 星际 | 地球历的日期，舰上没人过 |

修仙与星际版共享同一个最强设定：在一个不记录这个日期的世界里，只有她记得。

#### 写崩的三种方式

1. 办成惊喜派对。 人越多，越像表演。
2. 让他说出愿望。 读者猜到就够了。
3. 忽略「不用过」这句。 那句话背后有整段前史。

## 五 · 合照

`G` ｜ 无预警 ｜ 现代／星际 ｜ 语料频次：备礼送礼 24.8%

**骨架**｜第一张两个人的合照，比任何口头承诺都实在。

#### 节拍链

有人提议 → 拍 → 他不敢靠太近，或悄悄拉近半寸 → 他没看镜头 → 设成锁屏 → 换掉 → 又设回来

#### 时间轴

快门 1/125 秒，锁屏换了三轮。 拍的过程极短，照片的服役期极长：设成锁屏、来人时换掉、走了又设回来。换与设的每一轮都是一次立场声明，这条的钟走在相册之外。

#### 照片的语义

| 观察点 | 读作 |
|---|---|
| 谁提出拍的 | 谁更想留下证据 |
| 拍的时候两人的距离 | 关系阶段 |
| 他有没有看镜头 | 他在看她还是在配合 |
| 照片放在哪 | 手机 ✓ 锁屏／相册 ✓ 深处／打印出来 |
| 发不发出去 | 公开程度 |
| 三年后再看这张 | 时间的重量 |

「他有没有看镜头」是这条唯一需要写的细节。 很多这类照片里，他在看她。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 照片 ✓ · 相册 ✓ · 手机 ✓ · 屏幕 ✓ · 打印出来那张的折痕 |
| 拍照的场合 | 随手 · 特意 · 别人帮拍 · 自拍时手不够长 |
| 他的姿态 | 不敢靠太近 · 手不知道放哪 · 或者他悄悄拉近了半寸 |
| 后续 | 他把它设成锁屏，又换掉，又设回来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提议 | 她 | 他（他会找借口） |
| 他敢不敢公开 | 设成锁屏 | 只放在相册最深处 |
| 数量 | 只有一张 | 他存了很多张她的，两人的只有一张 |
| 后续 | 越拍越多 | 这张一直是唯一的一张 |

「他存了很多张她的，两人的只有一张」是极好的设定：单方面凝视与双方确认，数量差就是关系差。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她翻他手机时看见相册的构成 | 拍照时手放在哪 |
| 好的处理 | 她把那张设成了自己的锁屏 | 他没敢说他想要一张 |
| 写崩 | 写成她要求公开 | 写成他偷拍成癖 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 画像／她请人画的双人图／他自己描的一张 |
| 修仙 | 留影石／神识里的一段记忆 |
| 星际 | 全息影像／一段被他反复回放的舱内录像 |

古代版的「他自己描的一张」最动人：画得不像，但他画了很多遍。

#### 写崩的三种方式

1. 写成秀恩爱。 这条的重量在私密而非公开。
2. 省略他的手放在哪。 那是全条的信息。
3. 拍得太多。 第一张的价值来自唯一。

## 六 · 交出去

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 24.8%

**骨架**｜他把某样代表自己自主权的东西交给她。这是这一族里最重的一条。

#### 节拍链

他决定 → 推过去 → 「你拿着」（不解释）→ 她愣住 → 她怎么接 → 她也给了他一样

#### 时间轴

决定用了三个月，交付只用三秒。 「你拿着」三个字之前，他盘算了整整一个季度：值不值、她会不会觉得重、怎么说才不隆重。交付瞬间越轻描淡写，前面那三个月越有分量——比例反差就是这条的结构。

#### 交出去的东西

按重量排：

| 物 | 交出的是 |
|---|---|
| 家门钥匙 ✓ | 空间 |
| 手机 ✓ 密码 | 隐私 |
| 工资卡 / 存折 | 经济自主 |
| 他的日程 | 时间 |
| 他的旧物（唯一一件） | 过去 |
| 一个只有他知道的秘密 | 底牌 |

这条的重头在她怎么接，交出去只是开场。

| 她的接法 | 读作 |
|---|---|
| 收下并使用 | 她把它当成事实 |
| 收下但从不用 | 她收的是心意不是权力 |
| 退回去 | 她认为他不需要交这个 |
| 收下，然后交出对等的一样 | 最好的一种 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 交出的动作 | 放在桌上推过去 · 塞进她包里 · 直接说出密码 |
| 他的措辞 | 「你拿着」（不解释）· 或者一长串解释（说明他紧张） |
| 她的反应 | 愣住 · 问「为什么」· 什么都没问就收了 |
| 后续 | 他有没有后悔 · 她有没有真的用 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他交的东西 | 象征性的 | 实质性的（工资卡、密码） |
| 她的处理 | 收下 | 退回并说明理由 |
| 是不是被要求的 | 他主动 | 她提出的（性质完全不同） |
| 后续 | 关系加深 | 他后来想拿回来（这条更真实） |

「她提出的」这一端要小心：要求对方交出自主权是控制，主动交出是信任。 同一个动作，方向决定性质。参见 [05-占有与吃醋 · 独占欲的边界](05-占有与吃醋.md#十--独占欲的边界)。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 东西被推过来的那一下 | 说出口之前想了多久 |
| 内心 | 我该不该收 | 她收了就说明她认了 |
| 好的处理 | 她收下，然后也给了他一样 | 他没有附加任何条件 |
| 写崩 | 写成她理所当然地收 | 写成他献祭式的交付 |

「她也给了他一样」是这个类型里最好的收法。 不对称的关系里，一次对等的交换比十次宠溺更有分量。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 卖身契／他的印鉴／族谱上的名字／他把身契交到她手上 |
| 修仙 | 本命法器／魂灯／识海权限 |
| 星际 | 最高权限授权／他的生命体征绑定到她的终端 |

古代版的「身契」在语义上最重，也最需要小心：它容易滑向人身依附。 写的时候要让它是他的选择，且她要有明确的回应。

#### 写崩的三种方式

1. 写成人身依附。 交出自主权和放弃人格是两回事。
2. 让她要求他交。 见上。
3. 交完就没下文。 她怎么处置，才是这条的下半场。

## 七 · 戒指

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 24.8%

**骨架**｜谁给谁戴，戴在哪只手，这两件事就是全部内容。

#### 节拍链

拿出来 → 手抖 → 戴不进去 → 推到底 → 转一下让它正 → 谁都没说话

#### 时间轴

从拿出来到戴正，全程不到一分钟，拆成六拍慢放。 掏、抖、对不准、推、转正、沉默——每拍之间可以停顿，停顿里塞的是这段关系的全部前史。这一分钟是全书时间密度最高的一分钟，别赶。

#### 戴法的语义表

| 谁给谁 | 哪只手 | 读作 |
|---|---|---|
| 她给他戴 | 左手无名指 | 标准宣示 |
| 她给他戴 | 右手 | 保留 · 或者设定里的另一种含义 |
| 他给她戴 | 左手无名指 | 请求，需要她抬手配合 |
| 他自己戴上 | — | 单方面 |
| 两人互相戴 | — | 对等 |
| 她把自己的给他 | 尺寸不合，他戴在小指 | 最好的一版 |

「尺寸不合，戴在小指」是这条最好用的写法：它把「这不是为你准备的，但我给你了」和「我收下了，用我的办法」压在同一个动作里。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 戒指 ✓ · 礼盒 ✓ · 丝带 ✓ · 尺寸（他量过她的手指 ✓）· 内圈刻的字 |
| 戴的动作 | 手抖 · 戴不进去 · 推到底 · 转了一下让它正 |
| 他的手 | 手指 ✓ 上有茧／有伤，戒指衬得手更粗 |
| 后续 | 他洗手时会摘下来放在固定位置 · 或者从不摘 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁给谁 | 她给他 | 他给她 |
| 场合 | 正式 | 极随意（在厨房、在车上） |
| 他戴不戴出门 | 戴 | 上班摘下来（这个细节要有理由） |
| 有没有承诺 | 说了 | 什么都没说 |

「极随意的场合」往往比正式场合动人：在洗碗的时候被套上一枚戒指，比跪地求婚更像生活。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他的手指比想象中粗 | 她的手指捏着他手的那一下 |
| 好的处理 | 她一句话没说，直接戴上 | 他没问这是什么意思 |
| 写崩 | 写成钻戒克拉数 | 写成他喜极而泣 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 玉扳指／她的一枚私印／束发的簪／腰间的玉牌 |
| 修仙 | 本命契印／她的一缕剑气烙在他腕上 |
| 星际 | 权限环／她的识别码写进他的腕带 |
| 女A男O | 标记（走 [03-世界观设定](../03-世界观设定/)） |

#### 写崩的三种方式

1. 写成物质规格。 材质与价格是最不重要的。
2. 配长篇誓言。 动作自带全部信息。
3. 省略戴的过程。 手抖、戴不进去、推到底，这三下就是全部。

前接：[六 · 交出去](#六--交出去)

## 八 · 见家长

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 24.8%

**骨架**｜关系第一次接受外部审查。而审查的标准通常对他不利。

#### 节拍链

他提前准备 → 席间那句质问 → 桌上安静半秒 → 她挡回去／他自己答 → 车里的沉默

#### 时间轴

席间两小时，其实只有三个时刻。落座时的目光扫描、那句质问出口的半秒、离席时谁送到门口——其余时间都是缓冲垫。车里的沉默是延长赛：谁先开口、开口第一句是什么，比饭桌上任何一句都重。

#### 这条在这一类里的特殊性

传统言情里，见家长审查的是男方的经济与前途。这个类型里，问题变了：

| 常见质问 | 指向 |
|---|---|
| 「他一个大男人，靠你养？」 | 他的经济地位 |
| 「你怎么什么都听她的？」 | 他的顺从被当成缺陷 |
| 「你委不委屈啊？」（问她） | 假定她吃亏了 |
| 「他家里怎么想？」 | 外部压力 |

这一族的核心冲突是：他们关系里最好的部分，正是外人眼里最不对劲的部分。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 家宴 · 她父母来家里 · 他家里的亲戚 · 同学聚会 |
| 他的准备 | 提前练习了怎么回答 · 买了礼物 ✓ · 换了不像自己的衣服 ✓ |
| 那句话出口时 | 桌上安静了半秒 · 谁先开口 |
| 她的护 | 一句话挡回去 · 或者她也愣住了（更真实的第一次） |
| 事后 | 车 ✓ 里的沉默 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁家 | 她家 | 他家（他家更可能不理解） |
| 她的反应 | 当场挡 | 当时没反应过来，事后才想明白 |
| 他的反应 | 忍 | 自己回答了（且答得很好） |
| 结局 | 被接受 | 没被接受，两人自己扛 |

「他自己回答了，且答得很好」是这条最好的一版：他不需要被保护，他需要被承认有能力保护这段关系。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她意识到自己刚才慢了半拍 | 那句话落地时他的第一反应 |
| 好的处理 | 她事后道歉，为的是慢了半拍 | 他说「我不委屈」，且说得平静 |
| 写崩 | 写成她当场翻桌 | 写成他忍气吞声一整晚 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 认亲／宗族议事／他的父兄来问她的意思 |
| 修仙 | 拜见师门／宗门长老质疑他的资质配不配 |
| 星际 | 家族审查／匹配度报告不达标 |

古代女尊版有一个现代版没有的资源：制度是站在他们这边的。 女尊社会里这段关系是正常的，冲突要来自别处（门第、家族利益），这反而让写作更有层次。

#### 写崩的三种方式

1. 让她大发雷霆。 情绪爆发会掩盖问题本身。
2. 让他全程沉默。 至少要有一次他自己开口。
3. 让所有人立刻理解。 不被理解是这个类型的现实处境，写出来才有价值。

## 九 · 一起买东西

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 24.8%

**骨架**｜逛超市。这条的全部内容是两个人的购物车。

#### 节拍链

推车 → 他往里放的全是她的 → 他自己那样拿起又放下 → 她把它拿回来放进车 → 结账

#### 时间轴

一条动线走到底，购物车是进度条。 从生鲜区到收银台四十分钟，车里的东西比例在变：他放进来的全是她的，他自己那几样拿起又放下，被她拿回来重新放进去。结账时购物车的构成，就是这段关系的资产负债表。

#### 购物车社会学

| 观察点 | 读作 |
|---|---|
| 谁推车 | 谁在主导 |
| 他往车里放什么 | 他记得她要什么 |
| 她放回去的是什么 | 她的边界（太贵的、他给自己买的） |
| 结账谁付 | 经济关系 |
| 谁提袋子 | 体力分工 |
| 有没有买他自己的东西 | 他有没有把自己算进这个家 |

最后一行是最好用的一条。 一整车东西全是她的和家里的，没有一样是他自己想要的，这个细节可以直接接 [04-委屈与破防](04-委屈与破防.md)。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 购物车 · 保鲜膜 ✓ · 牛奶 ✓ · 鸡蛋 ✓ · 他偷偷放进去又拿出来的那样 |
| 他的行为 | 记得她的牌子 · 挑最便宜的自己那份 · 看价格标签的时间 |
| 她的行为 | 把他放回去的东西又拿回来 · 直接扫码付掉 |
| 小摩擦 | 买不买这个 · 谁的口味说了算 |

「她把他放回去的东西又拿回来」是这条的最优解，且一句台词都不需要。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁付钱 | 她 | 他坚持要付（他的钱不多） |
| 他买不买自己的 | 买 | 一样都没买 |
| 气氛 | 日常琐碎 | 刚吵完架，全程不说话但还是一起去了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 车里没有一样是他的 | 拿起来又放下的那一下 |
| 好的处理 | 她不说破，直接拿回来放进车 | 他没有解释为什么放回去 |
| 写崩 | 写成她大手笔包场 | 写成他一味节省地感人 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 逛集市／她替他买下他多看了两眼的那样 |
| 修仙 | 坊市／灵石的分配 |
| 星际 | 配额分配／补给单上的项目 |

#### 写崩的三种方式

1. 写成购物清单。 挑三样，不要罗列。
2. 让她豪掷千金。 这条卖的是细致不是阔气。
3. 省略他放回去的动作。 那是全条的核心。

## 十 · 一个只属于他们的仪式

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：备礼送礼 24.8% 衍生

**骨架**｜这条不是一场戏。它是一个可以贯穿全书的装置。

#### 什么是私人仪式

一件重复发生的、只有他们两个知道含义的小事。

| 例子 | 起源 |
|---|---|
| 出门前她拍两下他的背 | 第一次是随手，后来成了习惯 |
| 他永远把她的杯子放在右手边 | 因为她左撇子的相反 |
| 每次吵完架她煮同一样东西 | 第一次和好时煮的 |
| 他数她回来的脚步声 | 从等门那段时间留下的 |
| 她走之前会把他的头发拨一下 | 没有原因 |

私人仪式的价值在于它可以被打破。 建立它用一章，打破它用一句话。

#### 三个用法

| 用法 | 做法 |
|---|---|
| 建立 | 第一次发生时不点破，让它自然重复 |
| 计量 | 中途某次没做，读者立刻知道出事了 |
| 收束 | 结尾时它再次出现，什么都不用说 |

中间那个用法最有力：「今天她出门前没有拍他的背。」一句话，一整章的铺垫全部兑现。

#### 可用细节

| 类 | 内容 |
|---|---|
| 起源 | 必须是偶然的，不能是约定的 |
| 重复 | 至少写三次读者才会记住 |
| 变形 | 分开时他自己做了一遍 |
| 打破 | 一次缺席 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她意识到自己什么时候开始做这件事的 | 她今天没做 |
| 好的处理 | 她自己也说不清为什么 | 他等了两秒才走 |
| 写崩 | 写成刻意约定的暗号 | 写成他执念式的计数 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她出门前替他理一下衣领／每月初一的那盏灯 |
| 修仙 | 她每次闭关前留一道印记 |
| 星际 | 每次跃迁前的同一句话 |

#### 写崩的三种方式

1. 让它有明确的约定。 约定的是暗号，自然形成的才是仪式。
2. 只出现一次。 至少三次。
3. 打破之后立刻解释。 让读者自己发现。

#### 可串接
