# 分手与复合

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来自 [13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数是 2,894 部独立作品。文中的百分比是编写时实测的，挖掘器扩充以后节拍族会有小幅变动，当前的权威数字以 13-07 为准（用 `run.py mine` 重跑更新）。
> 这一族从分手写到复合：说出口的那天，真话和场面话，第一周，还东西，偶遇，深夜电话，谁先低头，重新在一起，也写没复合的和离婚的。两人权力不对等，他手里能自己单方面定的，只有走不走这一件。

## 分手在这一类里有什么不一样

传统言情的分手是两边较劲。这里不一样。

很多事她说了算，只有一件她怎么都没辙：**他要走，她拦不住。** 下命令不管用，给多少好处也不管用，拿身份压人就更不行。他第一次用上自己说了算的权力，就是「他提分手」，这件事落到她身上，比落在别的关系里要命得多。

她最无奈的大概在这儿：**她说出口的话都像决定。** 「我们分开吧」从她嘴里出来，听着像下通知，没有商量的意思。她得花很大力气，才能让这话听着没那么像开会，多数时候还是做不到。

| 节拍族 | 占比 |
|---|---:|
| 分手 | 8.4% |
| 和好 | 35.0% |
| 前任 | 31.0% |
| 醉酒 | 31.0% |

主流文里，几乎没人正面去写「破」。语料里写复合（和好）的占 36.1%，写分开的只有 8.4%，「和好」比「分手」多得多。破镜重圆是这个类型里排在前头的套路，见 [05-01 经典套路库](../05-剧情套路/01-经典套路库.md)。

## 一 · 说出口的那天

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：分手 8.4%

**骨架**｜那两个字到底还是说出来了。说的人很平静，听的人也没当回事。

#### 节拍链

积累，彼此心里都清楚不对劲 → 一个不大的引子 → 那句话出口 → 几秒安静 → 没人挽留 → 事务性交代几句，东西、钥匙 → 门关上

#### 时间轴

几个月一路往下滑，最后收在十分钟里。**从那句话出口到门关上，可能只有十分钟。** 真正的分手往往很短，写的时候重心要放在前面的滑坡上，那句话本身反倒要写轻。

#### 谁提的，是两场完全不同的戏

| | 他提 | 她提 |
|---|---|---|
| 这句话的性质 | 他手里唯一能自己说了算的事 | 又是她一个人拿主意 |
| 说出口的难度 | 憋了挺久才敢开口 | 难在别说得像下通知 |
| 对方的第一反应 | 她愣住了。头一回觉得拦不住他 | 他问「是不是我哪儿做得不对」 |
| 最疼的点 | 她这才发现手里没牌可打 | 他到末了还在怪自己 |

「是我哪里不好」这句必须写。他被甩以后头一个反应是怀疑自己，处在他那个位置的人，本能就是先怪自己。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 家里 · 车 ✓ 里（门锁了）· 一家吃过很多次的店 |
| 引子 | 一件很小的事：又放鸽子 · 一句话口气不对 · 一个没接的电话 ✓ |
| 那几秒 | 冰箱嗡嗡响 · 楼下车声 · 谁都没动 |
| 事务性收尾 | 「东西我明天来拿」· 钥匙 ✓ 放哪儿 · 谁先站起来 |
| 平静 | 两个人都没哭。哭是后来一个人的事 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提 | 他 | 她 |
| 理由 | 说了真的 | 说了个体面的 |
| 现场 | 平静 | 有一方失态，另一方反而冷静下来 |
| 收尾 | 干净 | 拖着，谁都没搬走 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现这事她管不了 | 这句话我练了三个月 |
| 内心 | 我什么都能搞定，就这个不行 | 她居然没拦我 |
| 好的处理 | 她没讲条件，就说了声「好」 | 他说完也没等她留他 |
| 写崩 | 写成她冷着脸放人走 | 写成他赌气试她反应 |

「赌气试探」不能碰。拿分手逼对方表态，就是把分手当了筹码。真提才算数。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他求去／递还身契／自请下堂／她放他出府 |
| 修仙 | 断契／他退还本命信物／道不同 |
| 星际 | 解除关系登记／他申请调离她的舰 |

古代版里他「自请下堂」，丢掉的除了这段关系，还有身份、住处和生计。

#### 写崩的三种方式

1. 写成大吵到顶点那一刻。真分手多半在吵到没力气的那天。
2. 让一方当场跪下求。这一手最容易写砸。挽留放到后面几段，当场一跪，戏就写贱了。
3. 理由含含糊糊。读者可以不知道，当事人心里必须有数。

## 二 · 真话与场面话

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：分手 8.4%

**骨架**｜分手的理由有两个：嘴上说的，和真正的。

#### 节拍链

说出口的理由（体面）→ 对方接受了 → 各自回去 → 真理由在独处时浮出来 → 有没有人后来知道

#### 时间轴

真正的理由往往分开几周以后才冒出来。当时说不出口，是自己也还没想明白，算不上不诚实。

#### 常见的两层对照

| 说出口的 | 真的 |
|---|---|
| 「性格不合」 | 他受不了永远当被安排的那个 |
| 「我配不上你」 | 他撑不住外界那些话了 |
| 「我想一个人过一阵」 | 她的世界太大，他找不到自己的位置 |
| 「我太忙了，耽误你」 | 她不敢承认自己需要人 |
| 「就是累了」 | 有一件具体的事，谁都没提 |

最后一行最常见。嘴上说「就是累了」，背后有一件具体的事，那件事往往小得说不出口。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场面话的特征 | 圆、周到、挑不出错，像事先背过 |
| 真话的藏处 | 一句没说完的半截 · 提到某件事时的停顿 |
| 后来的揭开 | 第三人转述 · 醉后（醉酒 31%）· 复合前的那次谈 |
| 对方的反应 | 「原来是这个」——比当时听到的任何理由都难受 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 真话何时揭开 | 几周后 | 复合的时候才说 |
| 谁先说破 | 提分手的人 | 被分的人自己想明白了 |
| 真理由的性质 | 关系内的 | 关系外的（家里、身体、旧事） |
| 揭开之后 | 释然 | 更难受，当时说了就不用分了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她回头一想，他那句话顿了一下 | 真话到了嘴边，又咽回去 |
| 内心 | 他给的理由站不住脚 | 其实就是在怨她 |
| 好的处理 | 她没揪着场面话吵，去挖底下的实话 | 他后来还是把真话说了 |
| 写崩 | 写成她审犯人一样逼问 | 写成他死活不开口的闷葫芦 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 嘴上说想家，真话全在没寄出去的信里 |
| 修仙 | 拿道心不稳当幌子，其实是过不了寿元差这一关 |
| 星际 | 申请表上写“个人发展”，附件里一个字没填 |

#### 写崩的三种方式

1. 场面话写得太假。好的场面话，真到说的人自己都能信三分。
2. 揭开得太快。 隔几周再揭开。
3. 真话只是一句空泛的埋怨。它得落在一件具体的事上。

## 三 · 分开后的第一周

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：分手 8.4% ＋ 归家 46.2%

**骨架**｜关系结束了，习惯没有。

#### 节拍链

第一天（麻木，甚至轻松）→ 第二三天（习惯开始扑空）→ 撑着 → 一件小事破防 → 各自熬过第一周

#### 时间轴

**第一周的情绪是起伏的。** 头一两天常是假的轻松，到第三四天，习惯开始一个一个扑空，破防多半在第五六天，被一件很小的事引爆。

#### 习惯扑空清单

写法和 [09-分离与重逢 · 她不在的第一天](09-分离与重逢.md#三--她不在的第一天) 一样，只是这回没有归期：

| 扑空的习惯 | 疼在哪 |
|---|---|
| 做了两个人的饭 ✓ | 盛出来才想起，不会再有第二双筷子了 |
| 到点看门口 | 玄关 ✓ 的灯不知道该不该留 |
| 想转发一条消息 ✓ | 输入框开了又关 |
| 睡自己那半边 | 另一半空着，没人抢被子 ✓ 了 |
| 买菜拿了他不吃的葱 | 现在可以买了，反而难受 |

看最后一行：**自由回来的那一刻最疼。** 他不喜欢的事终于可以做了，做起来一点也不好受。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 那副没收走的碗 ✓ · 他留下的充电线 ✓ · 她那瓶还剩一半的东西 |
| 破防引爆物 | 一首歌 · 外卖软件的常点推荐 · 快递送来分手前买的东西 |
| 撑着的方式 | 她加班 · 他接了很多活 · 都把日程填满 |
| 别人 | 谁都没告诉 · 或者只告诉了一个人 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁更狼狈 | 他 | 她且她不许自己狼狈 |
| 告不告诉别人 | 瞒着 | 闺蜜或兄弟知道了 |
| 破防的引子 | 一件遗留物 | 一个日期 |
| 第一周结束 | 缓过来一点 | 更沉了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她第五天在超市拿起那把葱 | 输入框开了又关的那条 |
| 内心 | 我早该习惯一个人 | 她那边是不是已经没事了 |
| 好的处理 | 她的崩溃很短，且没人看见 | 他没有发出去那条消息 |
| 写崩 | 写成她无痛切割 | 写成他天天买醉 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他那院子她再没进去过，回廊也绕开走 |
| 修仙 | 洞府禁制还留着他的名，她一直没抹掉 |
| 星际 | 舱位权限到期自动收回，系统弹确认，她盯着那键按不下去 |

星际版里连分手都要「系统弹确认」，她的手就停在那个按钮上。

#### 写崩的三种方式

1. 第一天就写崩溃。头一天看着轻松，难受其实才开头。
2. 两边用一样的力气写。一边写透，另一边留白。
3. 拿酗酒堕落来演痛苦。习惯一次次扑空，比失态狠得多。

## 四 · 还东西

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：分手 8.4% ＋ 赠礼 29.6%

**骨架**｜一个纸箱，装着两年。

#### 节拍链

两人发消息约时间，客气得像陌生人。收拾起来比想的多花了不少工夫。交接那几分钟里，有一样东西说不清该归谁。门关上以后，箱子要怎么处理。

#### 时间轴

每拿起一样就要想一回：是他的，是我的，还是两个人的。最难办的是两个人的。

#### 三类东西

| 类 | 处理 | 戏在哪 |
|---|---|---|
| 明确是对方的 | 装箱 | 无 |
| 对方送的 | 还不还，两难 | 还了是绝情，不还是没断干净 |
| 说不清的 | 那只一起买的锅 ✓ · 那只猫 | 这一类要多写 |

宠物归谁，能单独写成一场戏，接 [13-家庭与亲属 · 养一只](13-家庭与亲属.md#八--养一只)。它认两个人，却只能跟一个走。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 纸箱 · 胶带声 · 钥匙 ✓（最后才放下）· 一件他故意没拿的 |
| 交接 | 约在楼下不上去 · 或者上去了，站玄关 ✓ 没进门 |
| 措辞 | 「都在这了」· 「那我走了」· 全程没超过十句 |
| 故意遗漏 | 有一样东西两人都没提，留着它，就还连着一根线 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 方式 | 当面 | 快递（更冷，也更干净） |
| 送的东西 | 还了 | 都留着，两边都是 |
| 那根线 | 留了 | 没留，真的清了 |
| 情绪 | 全程平静 | 有一样东西让一方停了几秒 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她随手给过的东西，被原样还了回来 | 钥匙搁下那一下的动静 |
| 内心 | 他连这都留着呢 | 别去数箱子里缺了啥 |
| 好的处理 | 她收了箱子，没当场打开看 | 他留了一样东西，也没吭声 |
| 写崩 | 写成了算账分家产 | 写成了他闹脾气撒泼 |

「她随手给过的东西被还回来了」，和 [07-馈赠与仪式 · 她随手给的东西](07-馈赠与仪式.md#三--她随手给的东西) 写的是同一件东西，只是分了前后两段。收下那时是演戏，还回去又是另一出戏。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 退还聘物／信物锁匣里送回／名帖划掉 |
| 修仙 | 解契要两个人一起到场，修仙界独有的狠处：散伙也得成双 |
| 星际 | 权限一项项删，每删一回都跳个确认框 |

#### 写崩的三种方式

1. 每样东西配一段回忆。挑一样写，其余用「装了半箱」带过。
2. 交接时把话说尽。这场戏的规矩是不超过十句。
3. 漏掉说不清归谁的那一类。锅和猫才是正戏。

## 五 · 街上遇见

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：前任 32.1% ＋ 初见 39.9%

**骨架**｜分开后第一次碰上，三秒钟里有四条路可走。

#### 节拍链

看见（谁先看见谁）→ 躲不躲 → 打不打招呼 → 那三十秒的寒暄 → 走开 → 各自走出五十米之后的样子

#### 时间轴

三十秒的寒暄，写三行就够了。**这场戏的正文在走开之后**，各自走出五十米以后的那一段，才是该下力气的地方。

#### 四种走法

| 走法 | 含义 |
|---|---|
| 一方看见，躲了 | 还没缓过来 |
| 都看见了，点头走过 | 体面，但都在硬撑 |
| 站住说了三十秒 | 「最近好吗」「挺好的」，没一句真的 |
| 一方身边有新的人 | 转 [六 · 共同朋友的场合](#六--共同朋友的场合) 的对照结构 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 地点 | 超市（最日常最扎心）· 地铁 ✓ 对面 · 那家常去的店 ✓ 门口 |
| 变化 | 他换了发型 ✓ · 她瘦了 · 有一样没变，还拎着那个包 |
| 寒暄内容 | 天气、工作、「你气色不错」——全是客套话 |
| 走开之后 | 她在下一个路口站了一会儿 · 他把刚买的东西拎反了方向 |

「把东西拎反了方向」这种失灵的动作，比心理描写准。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 距离分手 | 一个月 | 三年 |
| 谁先开口 | 她 | 他，他以前不敢先说话，现在敢了，这本身就是事 |
| 身边 | 都一个人 | 有一方不是 |
| 之后 | 就这样了 | 当晚有一方翻了旧照片 ✓ |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他先开口了，以前他不敢 | 她的包还是那个 |
| 内心 | 他过得好，我该替他高兴 | 三十秒，别超时 |
| 好的处理 | 她说了句实在话：「你这样挺好」 | 他一个字都没提过去 |
| 写崩 | 写成她吃醋发火 | 写成他当街失态 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 街上远远瞧见一眼／他跟着新主家的马车过去／庙会人堆里 |
| 修仙 | 坊市碰见／隔了百年在路上撞上，他头发白了，她模样没变，寿元差 |
| 星际 | 中转站错身／两边舰队一起出任务，点名时听见他名字 |

#### 写崩的三种方式

1. 当街摊开旧事。街上只寒暄，旧事留给别的场合。
2. 靠偶遇推着复合。偶遇只证明没放下，复合要走别的路。
3. 跳过走开以后。那五十米要写。

## 七 · 深夜那通电话

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：醉酒 32.1% ＋ 失联 23.2%

#### 时间轴

## 八 · 谁先低头

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：和好 36.1%

**骨架**｜有人先开口了。分了手再先开口，比吵完架先服软难得多。

#### 节拍链

决定（想了很多天）→ 找一个由头 → 第一次接触（极轻）→ 对方的回应 → 试探往来几轮 → 见面

#### 时间轴

第一条消息发出去，到真见上面，中间要小心地来回好几轮，一轮比一轮隔得短。

#### 由头的等级

| 由头 | 含义 |
|---|---|
| 「你落了个东西在我这」 | 最安全，可进可退 |
| 节日的群发式祝福 | 试水温 |

| 回应的温度 | 秒回还是隔天 · 句尾有没有那个语气词 |
| 双方的克制 | 都不提那件事 · 都在等对方先提 |
| 见面 | 约在老地方还是新地方，选址就是态度 |

| 节奏 | 几天 | 几个月 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她直接站楼下等了 | 那条消息他磨了一小时才回 |

| 写崩 | 写成她下命令把人叫回来 | 写成他故意吊着人玩 |

| 世界 | 等价物 |

1. 一条消息就复合了。中间那几轮拉扯，少不了。
2. 先低头的人从头怂到尾。低头是在给台阶。
3. 借口一个接一个地找。借口用一回就够，第二句就该说人话了。

## 九 · 重新在一起

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：和好 36.1%

**骨架**｜复合以后，两人等于从头再处一回。

#### 节拍链

那次见面 → 把当时的真话说完（接 [二 · 真话与场面话](#二--真话与场面话)）→ 问题摆上桌 → 各自让了一步 → 重新开始 → 有些东西回不来，有些东西是新的

#### 时间轴

复合那天，是第二段关系的头一天。写到「在一起了」就停笔，最难的那部分就扔给读者去想了。

#### 新旧对照表

破镜重圆的「圆」不是原样：

| 项 | 从前 | 现在 |
|---|---|---|
| 那个分手的原因 | 没人提 | 摆上桌谈过了 |
| 她的安排 | 直接定 | 先问一句 |
| 他的委屈 | 攒着 | 当天说 |
| 那件旧物 | 在箱底 | 摆回了原位，但两个人都知道它进过箱子 |

最后一行，东西能放回原位，但进过箱子这件事抹不掉。这次是谈出来的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 那次谈 | 没在家，约在外面见 · 聊了挺久 · 中间有阵子谁都没吭声 |
| 让步 | 一人退一步，说具体的，她改个毛病，他应下一件事 |
| 搬回来 | 东西比上回少 · 有的他扔了，她也没问 |
| 周围人 | 知道的反应不一样 · 有人替他们踏实，有人替他们悬着心 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谈的深度 | 把话说开了 | 说一半留一半，后面还得炸，写长线用 |
| 变化 | 真改了 | 头三个月改了，后来老毛病又犯，得想办法 |
| 周围 | 都支持 | 有人明着反对 |
| 那道疤 | 成了招牌 | 成了随时能翻的旧账，写崩前兆 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她做安排前停了半秒，先问了他 | 他发现那样东西被摆回了原位 |
| 内心 | 这半秒的停顿就是我让的那步 | 这次我有说话的份 |
| 好的处理 | 她的改变小而具体，且撑过了三个月 | 他把「当天说」真的做到了 |
| 写崩 | 写成一切如初 | 写成他拿旧事当护身符 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 重新下聘，聘礼单子和上次一字不差，就多添了一行 |
| 修仙 | 重新结契，这次契文是俩人一块儿写的 |
| 星际 | 重新绑权限，这回是两边互相授权 |

「契文两个人一起拟」「双向授权」，三个换皮说的是同一件事：第二次的仪式里，他有了起草权。

#### 写崩的三种方式

1. 复合那天就写成大团圆。那天只是第二段故事的开头。
2. 把分手的原因糊弄过去。没解决的问题，迟早原样找回来。
3. 以为一切都和以前一样。总有些东西回不来，也该有些新长出来的。

## 十 · 没有复合

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：分手 8.4%（BE 向，语料罕见）

**骨架**｜也有一种结局：两个人没回到一起，也不算输。

#### 节拍链

时间过去 → 各自的生活成形 → 一次平静的重逢 → 说了当年没说的话 → 道别 → 各自走，都没有回头

#### 时间轴

**这条要隔得够久才成立。** 隔一年太短，情绪还在。过了五年，再说什么都只是交代，没了试探的意思。

#### 为什么这条要写

大家写惯了权力关系怎么建立，很少写它怎么体面地收场。语料库里「和好」占到 36.1%，「分手」只有8.4%，差不多默认了破镜就得重圆。可前面那些戏要立住，收场先得写得体面。有的故事就该以分开结尾，爱过，也改不了不合适。

#### 可用细节

| 类 | 内容 |
|---|---|
| 重逢 | 好几年没见，俩人都挺稳当 · 就喝了杯咖啡的工夫 |
| 交代 | 「那年那事儿，其实吧……」——憋了多年的话总算说出口 |
| 现在 | 日子都还凑合 · 一个结了婚 · 要不都单着，也不是在等谁 |
| 道别 | 「那我走了」跟当年那声一样，意思全变了 |
| 留下的 | 他跟她学的那些还在用 · 她为他改的毛病没再改回去 |

两个人分开了，他跟她学的那些，现在还用着。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 有没有重逢 | 有那杯咖啡 | 没有，只是各自知道对方的消息 |
| 情绪 | 释然 | 平静底下压着一点什么，且不再翻开 |
| 现在的关系 | 成了很淡的朋友 | 不联系，不憎恨 |
| 叙事位置 | 全书结局 | 前任线的收束（主线另有其人） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |

| 落点 | 她发现自己有个习惯是他留下的 | 他现在敢先开口了，是她教的 |
| 内心 | 那几年没白过，就是结束了 | 谢和对不起，都不必再说了 |
| 好的处理 | 她没说「祝你幸福」这种话 | 他讲的是件实实在在的小事 |
| 写崩 | 写成她一个人苦等 | 写成他彻底垮了 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 多年后他随家人赴宴，跟她隔桌见了礼，礼数挑不出错 |
| 修仙 | 百年后论道大会坐一桌，行的还是同门礼 |
| 星际 | 联合任务里公事公办，配合还是那么顺手，这点顺手就是剩下的全部 |

#### 写崩的三种方式

1. 结尾埋复合钩子。这条写的就是不回去。
2. 写分开把一个人毁了。两个人各自都过得还行，才对得起那段关系。
3. 说真话时旧情又烧起来。说完就走，还走得动，才算结束。

## 十一 · 离婚这一场

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：分手 8.4% ＋ 婚仪 38.8% 的交集（语料罕见，正面写的更少）

**骨架**｜领了证也能离。恋爱分手说完那句话就结束了，这里说完那句话，才开始办手续。

#### 与前十条的结构差

| | 恋爱分手（前十条） | 离婚 |
|---|---|---|
| 生效方式 | 嘴上说完就算 | 嘴上说完只算申请，要等章盖下来 |
| 时长 | 十分钟 | 三十一天起步 |
| 参与方 | 两个人 | 两个人加窗口、填表、冷静期 |
| 财产 | 一个纸箱 | 一张财产表，一行一行签字 |
| 撤回成本 | 一句话 | 冷静期里第二趟不去，申请就自动作废，退路是制度事先留好的 |
| 结束的凭证 | 门关上的声响 | 一本新证 |

前十条都把「说出口」写轻，把前后写重。这一条说出口同样最轻，只是后面压着一整套流程。

#### 节拍链

那句话刚说完 → 发现这事没完（查流程那晚）→ 财产一项项对 → 交材料 → 等三十天冷静期 → 再去一趟 → 拿号排队 → 新证到手 → 在门口站了一会儿

#### 时间轴

情绪和手续对不上，有两种错法。
一种是情绪先走完了：人早就散了，手续还没办完，两人反倒客客气气的，像在替别人办离婚，配合得比结婚那会儿还默契。
另一种是手续先办完了：章盖了，证也领了，情绪还没跟上，人站在民政局大厅里，捏着新证，不知道接下来该干什么。
冷静期那三十天，会把这种错位放大：住不住一起，说不说话，猫谁来喂，每天都要重新定一回。

#### 可用细节

| 类 | 内容 |
|---|---|

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 错位方向 | 人已经炸了，流程还没动 | 流程走完了，人还没缓过来 |
| 冷静期 | 各住各的 | 还住一块，房子一时半会儿卖不掉 |
| 财产表 | 聊得挺客气 | 卡在一行上，偏偏是最不值钱的那行 |
| 二次到场 | 俩人都来了 | 有一方没来，白跑一趟，然后呢 |

「有一方没来」这一头，两种收法都说得通：可能是回心转意，也可能只是假没请下来。另一方站在大厅里等号，不知道是哪一种。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 财产表拉到最后一行，合计栏是空的 | 排队号上的字母和当年不一样 |
| 内心 | 流程是我提的，走到一半我在盼它出错 | 冷静期原来是给我数日子用的 |
| 好的处理 | 她把那行谁都不要的划给了自己 | 他没有迟到，签字的笔画比平时慢 |
| 写崩 | 写成她高效办离婚秀强势 | 写成他当场下跪挽回 |

| 修仙 | 解契得俩人一块儿去契坛，灵识印记一层层褪，褪到最后一层俩人都下不去手 |

#### 写崩的三种方式

1. 只把流程当背景。排队号和财产表就是正文，跳过它们，这一条就写回前十条去了。
2. 拿手续的荒诞来搞笑。那口气可以有，可两个人毕竟是在一起拆一个家。
3. 把冷静期写成复合倒计时。它首先是悬着的三十天，两种结局都得真有可能。
