# 分手与复合

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**在一段权力不对称的关系里，退出权是他手里唯一一件单方面的东西。**

---

## 分手在这一类里的特殊结构

传统言情的分手是双方博弈。这里不是。

她掌握着关系里几乎所有的决定权，唯独一件事她做不了主：**他要走，她留不住。** 命令留不住人，资源留不住人，位置更留不住。所以「他提分手」在这一类里的分量，比在任何别的类型里都重——那是他第一次动用只属于他的权力。

反过来，她提分手也有她的难处：**她说出口的话都像决定。** 一句「我们分开吧」从她嘴里出来，听起来不像商量，像通知。她要花额外的力气让这句话不带公事腔，而她往往做不到。

| 节拍族 | 占比 |
|---|---:|
| 分手 | 8.4% |
| 和好 | 35.0% |
| 前任 | 31.0% |
| 醉酒 | 31.0% |

「和好」35% 对「分手」8.4%——语料里写复合的远多于写分开的。破镜重圆是这个类型的头部套路（见 [05-01 经典套路库](../05-剧情套路/01-经典套路库.md)），但那道「破」本身几乎没人正面写。这一族把它补上。

## 一 · 说出口的那天

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：分手 8.4%

**骨架**｜那两个字说出口了。而说的人和听的人，都比想象中平静。

#### 节拍链

积累（各自都知道有问题）→ 一个不大的引子 → 那句话出口 → 几秒安静 → 没有人挽留 → 事务性的几句（东西、钥匙）→ 门关上

#### 时间轴

真正的分手往往很短。**从那句话出口到门关上，可能只有十分钟**，而这十分钟前面是几个月的滑坡。写法上把重心放在滑坡上，那句话本身反而要轻。

#### 谁提的，是两场完全不同的戏

| | 他提 | 她提 |
|---|---|---|
| 这句话的性质 | 他唯一的单方面权力 | 又一个由她做的决定 |
| 说出口的难度 | 攒了很久的勇气 | 难在让它不像通知 |
| 对方的第一反应 | 她愣住。她第一次拦不住一件事 | 他问「是我哪里不好」 |
| 最疼的点 | 她发现自己没有筹码 | 他到最后还在找自己的错 |

「是我哪里不好」这句要写。他被分手的第一反应是找自己的问题，不是愤怒。这是这个位置上的人的本能，也是这场戏最难受的地方。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 家里 · 车 ✓ 里（封闭，谁都下不去）· 一家吃过很多次的店 |
| 引子 | 一件很小的事：又一次爽约 · 一句口气不对的话 · 一个没接的电话 ✓ |
| 那几秒 | 冰箱的嗡声 · 楼下的车 · 谁都没动 |
| 事务性收尾 | 「东西我明天来拿」· 钥匙 ✓ 放在哪 · 谁先站起来 |
| 平静 | 两个人都没哭。哭是后来一个人的事 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提 | 他 | 她 |
| 理由 | 说了真的 | 说了个体面的 |
| 现场 | 平静 | 有一方失态（另一方反而冷静下来） |
| 收尾 | 干净 | 拖着，谁都没搬走 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现这件事不在她的权限里 | 这句话我练了三个月 |
| 内心 | 我可以解决一切，除了这个 | 她居然没有拦 |
| 好的处理 | 她没有谈条件，她说「好」 | 他说完没有等她挽留 |
| 写崩 | 写成她冷酷放行 | 写成他赌气试探 |

「赌气试探」是这条的红线：用分手逼对方表态，是把最重的一张牌打成筹码。真提才算数。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他求去／递还身契／自请下堂／她放他出府 |
| 修仙 | 断契／他退还本命信物／道不同 |
| 星际 | 解除关系登记／他申请调离她的舰 |

古代版的「自请下堂」自带制度重量：他放弃的不只是关系，是身份、住所和生计，这让这个决定的成本看得见。

#### 写崩的三种方式

1. 写成大吵一架的顶点。 真正的分手多半发生在吵不动了之后。
2. 让一方当场下跪挽留。 挽留放到后面几条去，当场留人只会让这场戏廉价。
3. 理由含糊。 读者可以不被告知，当事人自己必须清楚。

## 二 · 真话与场面话

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：分手 8.4%

**骨架**｜分手理由有两层：说出口的那个，和真的那个。

#### 节拍链

说出口的理由（体面）→ 对方接受了 → 各自回去 → 真理由在独处时浮出来 → 有没有人后来知道

#### 时间轴

真理由浮出水面往往在分开几周之后。当时说不出，无关诚实，当时自己也没想明白。

#### 常见的两层对照

| 说出口的 | 真的 |
|---|---|
| 「性格不合」 | 他受不了永远当被安排的那个 |
| 「我配不上你」 | 他撑不住外界那些话了 |
| 「我想一个人过一阵」 | 她的世界太大，他找不到自己的位置 |
| 「我太忙了，耽误你」 | 她不敢承认自己需要人 |
| 「就是累了」 | 有一件具体的事，谁都没提 |

最后一行最常见：分手理由是抽象的，分手原因是具体的。 那件具体的事往往小得说不出口。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场面话的特征 | 圆、周到、挑不出错，像准备过 |
| 真话的藏处 | 一句没说完的半截 · 提到某件事时的停顿 |
| 后来的揭开 | 第三人转述 · 醉后（醉酒 31%）· 复合前的那次谈 |
| 对方的反应 | 「原来是这个」——比当时听到的任何理由都难受 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 真话何时揭开 | 几周后 | 复合的时候才说 |
| 谁先说破 | 提分手的人 | 被分的人自己想明白了 |
| 真理由的性质 | 关系内的 | 关系外的（家里、身体、旧事） |
| 揭开之后 | 释然 | 更难受（当时说了就不用分了） |

「当时说了就不用分了」是这条最疼的落点。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她复盘时发现他那句话里的停顿 | 真话到嘴边换成了场面话 |
| 内心 | 他说的那个理由不成立 | 说真的那个，就是在怪她 |
| 好的处理 | 她没有拿着场面话去辩，她去找真的 | 他后来把真话补上了 |
| 写崩 | 写成她逼问审讯 | 写成他打死不说的哑谜 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 呈上去的理由是「思乡」，真的理由在没寄出的信里 |
| 修仙 | 说是道心不稳，真的是寿元那笔账 |
| 星际 | 申请书上写「个人发展」，附件里什么都没写 |

#### 写崩的三种方式

1. 让场面话太假。 好的场面话应该真到连自己都能信三分。
2. 揭开得太快。 隔的时间就是这条的重量。
3. 真话是一句抽象的怨。 必须落到一件具体的事上。

## 三 · 分开后的第一周

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：分手 8.4% ＋ 归家 46.0%

**骨架**｜关系结束了，习惯没有。

#### 节拍链

第一天（麻木，甚至轻松）→ 第二三天（习惯开始扑空）→ 撑着 → 一件小事破防 → 各自熬过第一周

#### 时间轴

**第一周的情绪不是线性的。** 头一两天常常是假性的轻松，第三四天习惯开始一个个扑空，破防往往在第五六天由一件极小的事引爆。

#### 习惯扑空清单

与 [09-分离与重逢 · 她不在的第一天](09-分离与重逢.md#三--她不在的第一天) 同一个技法，但这次没有归期：

| 扑空的习惯 | 疼在哪 |
|---|---|
| 做了两个人的饭 ✓ | 盛出来才想起，且不会再有第二副碗了 |
| 到点看门口 | 玄关 ✓ 的灯不知道该不该留 |
| 想转发一条消息 ✓ | 输入框开了又关 |
| 睡自己那半边 | 另一半空着，没人抢被子 ✓ 了 |
| 买菜拿了他不吃的葱 | 现在可以买了，反而难受 |

最后一行是这条的独门细节：**自由回来的那一刻最疼。** 终于可以做他不喜欢的事了，而这件事一点也不好。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 那副没收走的碗 ✓ · 他留下的充电 ✓ 线 · 她那瓶还剩一半的东西 |
| 破防引爆物 | 一首歌 · 外卖软件的常点推荐 · 快递送来分手前买的东西 |
| 撑着的方式 | 她加班 · 他接了很多活 · 都把日程填满 |
| 别人 | 谁都没告诉 · 或者只告诉了一个人 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁更狼狈 | 他 | 她（且她不许自己狼狈） |
| 告不告诉别人 | 瞒着 | 闺蜜或兄弟知道了 |
| 破防的引子 | 一件遗留物 | 一个日期 |
| 第一周结束 | 缓过来一点 | 更沉了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她第五天在超市拿起那把葱 | 输入框开了又关的那条 |
| 内心 | 我早该习惯一个人 | 她那边是不是已经没事了 |
| 好的处理 | 她的崩溃很短，且没人看见 | 他没有发出去那条消息 |
| 写崩 | 写成她无痛切割 | 写成他天天买醉 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他的院子空了，她绕开那条回廊走 |
| 修仙 | 洞府的禁制还留着他的权限，她没撤 |
| 星际 | 舱位权限到期自动回收，系统弹了一条确认，她按了很久 |

星际版的「系统弹确认」把这条推到了极致：**连分手都有一个进度条**，而她的手停在按钮上。

#### 写崩的三种方式

1. 让第一天就崩溃。 假性轻松才是真实的第一步。
2. 两个人平均用力。 挑一边写深。另一边留白。
3. 用酗酒堕落表现痛苦。 扑空的习惯比失态有力得多。

## 四 · 还东西

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：分手 8.4% ＋ 赠礼 29.0%

**骨架**｜一个纸箱，装着两年。

#### 节拍链

约时间（消息措辞客气得陌生）→ 收拾（比想象中久）→ 交接那几分钟 → 有一样东西的归属说不清 → 门关上 → 箱子怎么处理

#### 时间轴

收拾的过程就是回忆的强制重放。每拿起一样就要判断一次：归他，归我，还是归两个人。第三类最难办。

#### 三类东西

| 类 | 处理 | 戏在哪 |
|---|---|---|
| 明确是对方的 | 装箱 | 无 |
| 对方送的 | 还不还，两难 | 还了是绝情，不还是没断干净 |
| 说不清的 | 那只一起买的锅 ✓ · 那只猫 | 这一类是这条的正文 |

宠物的归属可以单独撑一场戏（接 [13-家庭与亲属 · 养一只](13-家庭与亲属.md#八--养一只)）：它两边都认，而它只能去一边。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 纸箱 · 胶带的声音 · 钥匙 ✓（最后放下的那样）· 一件他故意没拿的 |
| 交接 | 约在楼下不上去 · 或者上去了，站在玄关 ✓ 没进门 |
| 措辞 | 「都在这了」· 「那我走了」· 全程没超过十句 |
| 故意遗漏 | 有一样东西谁都没提。留下它等于留了一根线 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 方式 | 当面 | 快递（更冷，也更干净） |
| 送的东西 | 还了 | 都留着（两边都是） |
| 那根线 | 留了 | 没留，真的清了 |
| 情绪 | 全程平静 | 有一样东西让一方停了几秒 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 箱底那样她随手给过的东西被还回来了 | 钥匙放下的那一声 |
| 内心 | 他连这个都留着过 | 别数箱子里少了什么 |
| 好的处理 | 她收下箱子没有当场翻 | 他留下了一样，且不说 |
| 写崩 | 写成清点财产 | 写成他崩溃耍赖 |

「她随手给过的东西被还回来了」与 [07-馈赠与仪式 · 她随手给的东西](07-馈赠与仪式.md#三--她随手给的东西) 是同一件物品的两个时态：收藏它是一场戏，归还它是另一场。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 退还聘物／信物封在匣里送回／名帖销了 |
| 修仙 | 解契要两人都到场，这是修仙版独有的残忍：断都要一起断 |
| 星际 | 权限逐项移除，每一项都弹一次确认 |

#### 写崩的三种方式

1. 逐样东西写回忆。 挑一样，其余用「装了半箱」带过。
2. 交接时把话说透。 这场戏的规矩是十句以内。
3. 忽略说不清的那一类。 锅和猫才是正文。

## 五 · 街上遇见

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：前任 31.0% ＋ 初见 38.0%

**骨架**｜分开之后第一次撞见。三秒钟，四种走法。

#### 节拍链

看见（谁先看见谁）→ 躲不躲 → 打不打招呼 → 那三十秒的寒暄 → 走开 → 各自走出五十米之后的样子

#### 时间轴

**这场戏的正文在走开之后。** 寒暄三十秒写三行就够，各自走出五十米之后那一段，才是要用力的地方。

#### 四种走法

| 走法 | 含义 |
|---|---|
| 一方看见，躲了 | 没好利索 |
| 都看见了，点头走过 | 体面，且都在硬撑体面 |
| 站住说了三十秒 | 「最近好吗」「挺好的」全程没有一句真话 |
| 一方身边有新的人 | 转 [六 · 共同朋友的场合](#六--共同朋友的场合) 的对照结构 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 地点 | 超市（最日常最疼）· 地铁 ✓ 对面 · 那家常去的店 ✓ 门口 |
| 变化 | 他换了发型 ✓ · 她瘦了 · 有一样没变（还拎着那个包） |
| 寒暄内容 | 天气、工作、「你气色不错」——全是壳 |
| 走开之后 | 她在下一个路口站了一会儿 · 他把刚买的东西拎反了方向 |

「把东西拎反了方向」这类失灵动作，比任何心理描写都准。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 距离分手 | 一个月 | 三年 |
| 谁先开口 | 她 | 他（他从前不敢先开口，现在敢了——这个变化本身是信息） |
| 身边 | 都一个人 | 有一方不是 |
| 之后 | 就这样了 | 当晚有一方翻了旧照片 ✓ |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他先开口了，从前他不敢 | 她的包还是那个 |
| 内心 | 他过得好，我该高兴 | 三十秒，别超时 |
| 好的处理 | 她说了句真的：「你这样挺好」 | 他没有提过去，一个字都没有 |
| 写崩 | 写成她妒火中烧 | 写成他当街失态 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 街市遥遥一见／他随新主家的车驾过去／庙会人群里 |
| 修仙 | 坊市相遇／百年后道左相逢，他鬓角白了她没变（接寿元差） |
| 星际 | 中转站擦肩／不同舰队的联合任务点名时听到名字 |

#### 写崩的三种方式

1. 当街说开旧事。 街上只有壳。芯要留给别的场合。
2. 让偶遇推动复合。 偶遇只负责证明没放下，复合另有路。
3. 省略走开之后。 那五十米才是这条。

## 六 · 共同朋友的场合

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：前任 31.0% ＋ 聚会 12.0%

**骨架**｜婚礼、聚会、老友的局。两个人都收到了请帖，谁都没理由不去。

#### 节拍链

请帖到（都知道对方会去）→ 去不去的挣扎 → 都去了 → 被安排的座位 → 全场的小心翼翼 → 一个必须同框的环节 → 散场

#### 时间轴

#### 可用细节

| 全场 | 朋友们都知道，都装不知道 · 有人喝多了差点提 |
| 同框环节 | 合影时被喊到一起 · 游戏环节抽到 · 敬酒敬到同一桌 |

| 散场 | 一个先走 · 另一个看着门口 |

| 场合 | 婚礼（婚仪 38.8%，最大化对照） | 小聚 |

| 谁先走 | 他 | 她（她从不早退，这次早退了） |
| 之后 | 无 | 有人发来消息：「今天……算了，没事」 |

2. 当众和好。 场合只负责把火拨旺，不负责烧。
3. 让一方缺席。 都到场，戏才成立。

## 七 · 深夜那通电话

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：醉酒 31.0% ＋ 失联 23.0%

**骨架**｜凌晨一点，屏幕上是那个没改备注的名字。

#### 节拍链

铃声（看清来电人）→ 接不接的三秒 → 接了 → 对面是醉的 → 听 → 说不说自己的 → 挂断之后

#### 时间轴

通话时长就是刻度。对面说了二十分钟，这边总共说了不到十句。 听比说难写。也比说重要。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手机 ✓ 屏幕 ✓ 在黑暗里亮起 · 备注名没改 · 通话计时在走 |
| 对面 | 背景音（酒局散了的街边）· 说话颠三倒四 · 说到一半没声了 |
| 这边 | 坐起来 · 没开灯 · 「你在哪，我叫车送你」 |
| 内容 | 醉话里混着一句真的 · 第二天对面不记得 |
| 挂断后 | 这边到天亮没睡 · 叫的车到了，订单截图存了下来 |

「叫的车到了，订单截图存了下来」，她处理完了，然后留了一个谁都不知道的纪念。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁打给谁 | 他打来（醉） | 她打来（她从不失控，这次拨了又挂） |
| 接没接 | 接了 | 没接，第二天看见未接 ✓ 心里那一沉 |
| 说了什么 | 醉话里一句真的 | 只是听着对方呼吸，谁都没说话 |
| 后续 | 装作没发生 | 这通电话成了复合的第一块砖 |

「她拨了又挂」是她这个角色能做出的最大失态，一秒钟就够。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 那句混在醉话里的真话 | 早上看见通话记录：四十七分钟 |
| 内心 | 他清醒的时候永远不会说这些 | 我说了什么 |
| 好的处理 | 她先安排人安全，再消化那句话 | 他没有装死，他发了一句「昨晚抱歉」 |
| 写崩 | 写成她连夜赶去 | 写成他惯性买醉夜夜拨号 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 深夜递进府的一封字迹歪斜的信 |
| 修仙 | 醉后灵识失控，传音符自己飞了出去 |
| 星际 | 深夜频道请求，接通后只有酒馆的噪音和呼吸 |

#### 写崩的三种方式

1. 电话里把话说清。 醉话只能漏一句真的，多了就假。
2. 连夜奔赴。 隔着线才是这条的分寸。
3. 第二天双方摊牌。 装作没发生，让那句话在两个人心里各自长。

## 八 · 谁先低头

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：和好 35.0%

**骨架**｜有人先动了。而这次先动的成本，比吵架后和好高一个数量级。

#### 节拍链

决定（想了很多天）→ 找一个由头 → 第一次接触（极轻）→ 对方的回应 → 试探往来几轮 → 见面

#### 时间轴

从第一条消息到见面，**中间隔着几轮小心翼翼的往来**。每一轮的间隔在缩短，这个缩短就是进度条。

#### 由头的等级

| 由头 | 含义 |
|---|---|
| 「你落了个东西在我这」 | 最安全，可进可退 |
| 节日的群发式祝福 | 试水温 |
| 「路过那家店，想起你爱吃的」 | 已经不装了 |
| 「有空吗，想跟你说件事」 | 摊牌 |
| 直接出现在楼下 | 她的做法。她一旦决定就不迂回 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 第一条消息 | 措辞改了很多遍（接 [19-玩闹与网络 · 第一条消息](19-玩闹与网络.md#一--第一条消息)，同一个人又回到了删改草稿的日子） |
| 回应的温度 | 秒回还是隔天 · 句尾有没有那个语气词 |
| 双方的克制 | 都不提那件事 · 都在等对方先提 |
| 见面 | 约在老地方还是新地方（选址就是态度） |

「同一个人又回到了删改草稿的日子」，关系确立前的那套小心翼翼原样回来了，而这次两个人都认得它。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先动 | 他 | 她 |
| 由头 | 找了个体面的 | 不找了，直说 |
| 对方 | 等这一天很久了 | 真的犹豫 |
| 节奏 | 几天 | 几个月 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她直接站在了楼下 | 那条消息他看了一小时才回 |
| 内心 | 迂回不是我的做法 | 回快了显得我一直在等。我确实一直在等 |
| 好的处理 | 她开口第一句是那件当时没说的真话 | 他回了，且没有装淡定 |
| 写崩 | 写成她命令式召回 | 写成他欲擒故纵 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她的车驾停在他家巷口／一份没有署名的年礼 |
| 修仙 | 他的传讯符权限重新亮了，是她那边开的 |
| 星际 | 他收到一条航线共享，起点是她的坐标 |

「传讯符权限重新亮了」：不说话，先把门打开。这是强势方低头的标准姿势——**她不道歉，她先恢复通道。**

#### 写崩的三种方式

1. 一条消息直接复合。 中间那几轮往来是必须的。
2. 让先低头的一方全程卑微。 低头是勇气不是投降。
3. 由头戏做太足。 由头只用一次，第二句就该往真处走。

## 九 · 重新在一起

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：和好 35.0%

**骨架**｜复合不是回到从前。是两个人重新谈了一份新的。

#### 节拍链

那次见面 → 把当时的真话说完（接 [二 · 真话与场面话](#二--真话与场面话)）→ 问题摆上桌 → 各自让了一步 → 重新开始 → 有些东西回不来，有些东西是新的

#### 时间轴

复合那天是第二段关系的第一天，不是终点。写到「在一起了」就收，等于把最难的部分留给了读者想象。

#### 新旧对照表

破镜重圆的「圆」不是原样：

| 项 | 从前 | 现在 |
|---|---|---|
| 那个分手的原因 | 没人提 | 摆上桌谈过了 |
| 她的安排 | 直接定 | 先问一句 |
| 他的委屈 | 攒着 | 当天说 |
| 那件旧物 | 在箱底 | 摆回了原位，但两个人都知道它进过箱子 |

最后一行是这条的意象：东西可以摆回去，进过箱子这件事消不掉。那算防伪标记，算不上伤痕——它证明这次是谈出来的，不是糊回去的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 那次谈 | 不在家里，在一个中性的地方 · 谈了很久 · 有一段两个人都没说话 |
| 让步 | 各一条，具体的（她改掉一个习惯，他答应一件事） |
| 搬回来 | 东西比上次少 · 有些他扔了，她没问 |
| 周围人 | 知道的人反应不一 · 有人替他们松口气，有人捏把汗 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谈的深度 | 谈透了 | 谈了一半（会二次爆发，写长线用） |
| 变化 | 真变了 | 头三个月变了，后来往回滑（要处理） |
| 周围 | 祝福 | 有人明确反对 |
| 那道疤 | 成了防伪标记 | 成了随时能翻的旧账（写崩前兆） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她做安排前停了半秒，先问了他 | 他发现那样东西被摆回了原位 |
| 内心 | 这半秒的停顿就是我让的那步 | 这次我有说话的份 |
| 好的处理 | 她的改变小而具体，且撑过了三个月 | 他把「当天说」真的做到了 |
| 写崩 | 写成一切如初 | 写成他拿旧事当护身符 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 重新下聘，聘礼单子和上次一字不差多添了一行 |
| 修仙 | 重新结契，这次的契文两个人一起拟的 |
| 星际 | 重新绑定权限，这次是双向授权 |

「契文两个人一起拟」「双向授权」，三个换皮说的是同一件事：第二次的仪式里，他有了起草权。

#### 写崩的三种方式

1. 复合当天写成大团圆终点。 那是第二段的第一天。
2. 让分手的原因蒸发。 没谈过的问题会原样回来。
3. 让一切复原。 要有回不来的，也要有新的。

## 十 · 没有复合

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：分手 8.4%（BE 向，语料罕见）

**骨架**｜也有一种结局：他们没有回去。而这不是失败。

#### 节拍链

时间过去 → 各自的生活成形 → 一次平静的重逢 → 说了当年没说的话 → 道别 → 各自走，都没有回头

#### 时间轴

**这条要隔得够久才成立。** 一年太短，情绪还在；五年之后，说什么都不再是试探，只是交代。

#### 为什么这条要写

「和好」35% 对「分手」8.4%，语料几乎默认破镜必重圆。但有一类故事的诚实结局是分开：不合适就是不合适，爱过也不改这一点。这个类型写惯了权力关系的建立，很少写它体面地结束——能把结束写体面，前面的所有戏才更可信。

#### 可用细节

| 类 | 内容 |
|---|---|
| 重逢 | 多年后，都平静了 · 一杯咖啡的时长 |
| 交代 | 「当年那件事，其实是……」——真话终于说完了 |
| 现在 | 各自过得不坏 · 有一方成了家 · 或者都没有，但也不是为了谁 |
| 道别 | 「那我走了」和当年那句一样，含义完全不同 |
| 留下的 | 他从她身上学会的东西还在用 · 她因他改掉的习惯没改回去 |

「他从她身上学会的东西还在用」是这条的落点：关系没了，关系造成的那部分人还在。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 有没有重逢 | 有那杯咖啡 | 没有，只是各自知道对方的消息 |
| 情绪 | 释然 | 平静底下压着一点什么，且不再翻开 |
| 现在的关系 | 成了很淡的朋友 | 不联系，不憎恨 |
| 叙事位置 | 全书结局 | 前任线的收束（主线另有其人） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己有个习惯是他留下的 | 他现在敢先开口了，这是她教的 |
| 内心 | 那几年不是错的，只是完了 | 谢谢，和抱歉，都过时了 |
| 好的处理 | 她没有说「祝你幸福」这种话 | 他说的是一件具体的小事 |
| 写崩 | 写成她独身守望 | 写成他一蹶不振 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 多年后他随家人赴宴，与她隔席见礼，礼数周全 |
| 修仙 | 百年后论道大会同席，执的是同门之礼 |
| 星际 | 联合任务里公事公办，配合得依然默契，这默契就是全部遗产 |

「配合得依然默契」，星际版把这条说透了：**默契比关系活得久。**

#### 写崩的三种方式

1. 结尾埋复合钩子。 这条的价值就是不回去。
2. 让分开毁掉一个人。 各自过得不坏，才是对那段关系的敬意。
3. 交代真话时旧情复燃。 说完就走，走得动，才叫结束。

## 十一 · 离婚这一场

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：分手 8.4% ＋ 婚仪 38.8% 的交集（语料罕见，正面写的更少）

**骨架**｜领过证的分手。那句话说完，恋爱分手已经结束的地方，这里才刚开始走流程。

#### 与前十条的结构差

| | 恋爱分手（前十条） | 离婚 |
|---|---|---|
| 生效方式 | 说出口就生效 | 说出口只算申请，生效要等章 |
| 时长 | 十分钟 | 三十一天起步 |
| 参与方 | 两个人 | 两个人＋窗口、表格、冷静期 |
| 财产 | 一个纸箱 | 一张财产表，逐行签字 |
| 撤回成本 | 一句话 | 冷静期内不去二次到场，申请自动作废：制度替人备好了台阶 |
| 结束的凭证 | 门关上的声音 | 一本新证 |

前十条的核心技术是把「说出口」写轻、把前后写重；这一条反过来：**说出口最轻，流程最重。** 分手靠勇气，离婚靠出勤。

#### 节拍链

那句话出口 → 发现说完不算完（查流程那晚）→ 财产表逐行谈 → 递交申请 → 冷静期三十天 → 二次到场 → 排队号 → 新证到手 → 门口那一站

#### 时间轴

情绪与手续不同步，错位有两个方向。 情绪先到：人早就散了，手续还在走，两个人像在替别人办事，配合得出奇地好。手续先到：章都盖了，情绪没跟上，拿着新证站在大厅里，不知道下一步该往哪边走。冷静期那三十天是错位的放大器：住不住在一起、说不说话、谁去喂那只猫，每一天都要重新决定一次。

#### 可用细节

| 类 | 内容 |
|---|---|

| 财产表 | 表格把八年折成行 · 「这台冰箱写你还是写我」谈得比当年买它还认真 · 有一行谁都不要 · 有一行谁都想要（猫） |

| 窗口 | 工作人员例行问「都考虑好了吗」，两个人同时说「嗯」，同时没看对方 |
| 那一站 | 出了大厅，一个说「吃个饭吗」· 最后一顿，点的还是老三样 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 错位方向 | 情绪先到，手续在走 | 手续走完，情绪没跟上 |
| 冷静期 | 分居各过 | 同一屋檐（房子一时半会儿处理不了） |
| 财产表 | 谈得体面 | 卡在一行上（往往是最不值钱的那行） |
| 二次到场 | 都到了 | 有一方没来，申请作废，然后呢 |

「有一方没来」这一端两种收法都成立：没来是回心转意，或者只是没请下假。哪一种，另一方站在大厅里等号的时候不知道。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 财产表拉到最后一行，合计栏是空的 | 排队号上的字母和当年不一样 |
| 内心 | 流程是我提的，走到一半我在盼它出错 | 冷静期原来是给我数日子用的 |
| 好的处理 | 她把那行谁都不要的划给了自己 | 他没有迟到，签字的笔画比平时慢 |
| 写崩 | 写成她高效办离婚秀强势 | 写成他当场下跪挽回 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 和离书一式两份，按了手印还要过官府销名帖；他搬出府那天，管家按旧例来问「行李走正门还是侧门」 |
| 修仙 | 解契要两人同至契坛，灵识印记一层层退，退到最后一层两个人都停了手 |
| 星际 | 系统冷静期三十个标准日，每天弹一次「是否撤回」，两边都看着那个弹窗数到了第三十天 |

#### 写崩的三种方式

1. 把流程写成背景。 排队号和财产表就是正文，跳过它们等于把这条写回了前十条。
2. 用手续的荒诞感搞喜剧。 可以有那口气，但底色是两个人在合作拆一个家。
3. 冷静期写成复合倒计时。 它首先是三十天的悬置，两种结局都得真的可能。
