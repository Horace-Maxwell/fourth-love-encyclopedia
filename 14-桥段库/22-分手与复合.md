# 分手与复合

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**在一段权力不对称的关系里，退出权是他手里唯一一件单方面的东西。**

---

## 分手在这一类里的特殊结构

传统言情的分手是双方博弈。这里不是。

她说了算的事不少，但有一件她始终没办法：**他要走，她拦不住。** 命令没用，给再多好处也没用，更别说拿身份压人。所以「他提分手」这事儿，在她这儿比在别的关系里都致命。那是他头一回用上自己说了算的权力。

反过来，她提分手也有她的难处：**她说出口的话都像决定。** 一句「我们分开吧」从她嘴里出来，听着不像商量，像下通知。她得费老大劲才能让这句话听着没那么像开会，可多数时候，她就是做不到。

| 节拍族 | 占比 |
|---|---:|
| 分手 | 8.4% |
| 和好 | 35.0% |
| 前任 | 31.0% |
| 醉酒 | 31.0% |

「和好」35% 对「分手」8.4%，语料里写复合的远多于写分开的。破镜重圆是这个类型的头部套路，见 [05-01 经典套路库](../05-剧情套路/01-经典套路库.md)。但那道「破」本身几乎没人正面写。这一族把它补上。

## 一 · 说出口的那天

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：分手 8.4%

**骨架**｜那两个字终究还是说出口了。说的人平静，听的人也没当回事。

#### 节拍链

积累，彼此心里都清楚不对劲 → 一个不大的引子 → 那句话出口 → 几秒安静 → 没人挽留 → 事务性交代几句，东西、钥匙 → 门关上

#### 时间轴

真正的分手往往很短。**从那句话出口到门关上，可能只有十分钟**，而这十分钟前面是几个月的滑坡。写法上把重心放在滑坡上，那句话本身反而要轻。

#### 谁提的，是两场完全不同的戏

| | 他提 | 她提 |
|---|---|---|
| 这句话的性质 | 他手里唯一能自己说了算的事 | 又是她一个人拿主意 |
| 说出口的难度 | 憋了挺久才敢开口 | 难在别说得像下通知 |
| 对方的第一反应 | 她愣住了。头一回觉得拦不住他 | 他问「是不是我哪儿做得不对」 |
| 最疼的点 | 她这才发现手里没牌可打 | 他到末了还在怪自己 |

「是我哪里不好」这句必须写。他被甩了，第一反应是怀疑自己，不是发火。坐他那个位置的人，本能就是先怪自己。这场戏最让人难受的，也就是这一下。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 家里 · 车 ✓ 里（门锁了）· 一家吃过很多次的店 |
| 引子 | 一件很小的事：又放鸽子 · 一句话口气不对 · 一个没接的电话 ✓ |
| 那几秒 | 冰箱嗡嗡响 · 楼下车声 · 谁都没动 |
| 事务性收尾 | 「东西我明天来拿」· 钥匙 ✓ 放哪儿 · 谁先站起来 |
| 平静 | 两个人都没哭。哭是后来一个人的事 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提 | 他 | 她 |
| 理由 | 说了真的 | 说了个体面的 |
| 现场 | 平静 | 有一方失态，另一方反而冷静下来 |
| 收尾 | 干净 | 拖着，谁都没搬走 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现这事她管不了 | 这句话我练了三个月 |
| 内心 | 我什么都能搞定，就这个不行 | 她居然没拦我 |
| 好的处理 | 她没讲条件，就说了声「好」 | 他说完也没等她留他 |
| 写崩 | 写成她冷着脸放人走 | 写成他赌气试她反应 |

「赌气试探」是这条的红线：用分手逼对方表态，是把最重的一张牌打成筹码。真提才算数。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他求去／递还身契／自请下堂／她放他出府 |
| 修仙 | 断契／他退还本命信物／道不同 |
| 星际 | 解除关系登记／他申请调离她的舰 |

古代版的「自请下堂」自带制度重量。他放弃的不只是关系，是身份、住所和生计，这个决定的成本看得见。

#### 写崩的三种方式

1. 写成大吵一架的顶点。真正分手，多半是吵到没力气那天。
2. 让一方当场下跪挽留。这招最容易翻车。留人放后面几段写，当场跪只会把戏写贱了。
3. 理由可以含糊。读者可以不知道，但当事人心里必须有数。

## 二 · 真话与场面话

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：分手 8.4%

**骨架**｜分手理由有两层，说出来的那个，和真的那个。

#### 节拍链

说出口的理由（体面）→ 对方接受了 → 各自回去 → 真理由在独处时浮出来 → 有没有人后来知道

#### 时间轴

真理由浮出水面往往在分开几周之后。当时说不出，无关诚实，当时自己也没想明白。

#### 常见的两层对照

| 说出口的 | 真的 |
|---|---|
| 「性格不合」 | 他受不了永远当被安排的那个 |
| 「我配不上你」 | 他撑不住外界那些话了 |
| 「我想一个人过一阵」 | 她的世界太大，他找不到自己的位置 |
| 「我太忙了，耽误你」 | 她不敢承认自己需要人 |
| 「就是累了」 | 有一件具体的事，谁都没提 |

最后一行最常见：分手理由是抽象的，分手原因是具体的。 那件具体的事往往小得说不出口。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场面话的特征 | 圆、周到、挑不出错，像事先背过 |
| 真话的藏处 | 一句没说完的半截 · 提到某件事时的停顿 |
| 后来的揭开 | 第三人转述 · 醉后（醉酒 31%）· 复合前的那次谈 |
| 对方的反应 | 「原来是这个」——比当时听到的任何理由都难受 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 真话何时揭开 | 几周后 | 复合的时候才说 |
| 谁先说破 | 提分手的人 | 被分的人自己想明白了 |
| 真理由的性质 | 关系内的 | 关系外的（家里、身体、旧事） |
| 揭开之后 | 释然 | 更难受，当时说了就不用分了 |

「当时说了就不用分了」是这条最疼的落点。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她回头一想，他那句话顿了一下 | 真话到了嘴边，又咽回去 |
| 内心 | 他给的理由站不住脚 | 说白了，就是在怨她 |
| 好的处理 | 她没揪着场面话吵，去挖底下的实话 | 他后来还是把真话说了 |
| 写崩 | 写成她审犯人一样逼问 | 写成他死活不开口的闷葫芦 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 嘴上说想家，真话全在没寄出去的信里 |
| 修仙 | 拿道心不稳当幌子，其实是算不过寿元那笔账 |
| 星际 | 申请表上写“个人发展”，附件里一个字没填 |

#### 写崩的三种方式

1. 场面话太假。 好的场面话，真到连自己都能信三分。
2. 揭开得太快。 隔的时间，就是这条的重量。
3. 真话是一句抽象的怨。 得落到一件具体的事上。

## 三 · 分开后的第一周

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：分手 8.4% ＋ 归家 46.0%

**骨架**｜关系结束了，习惯没有。

#### 节拍链

第一天（麻木，甚至轻松）→ 第二三天（习惯开始扑空）→ 撑着 → 一件小事破防 → 各自熬过第一周

#### 时间轴

**第一周的情绪不是线性的。** 头一两天常常是假性的轻松，第三四天习惯开始一个个扑空，破防往往在第五六天由一件极小的事引爆。

#### 习惯扑空清单

与 [09-分离与重逢 · 她不在的第一天](09-分离与重逢.md#三--她不在的第一天) 同一个技法，但这次没有归期：

| 扑空的习惯 | 疼在哪 |
|---|---|
| 做了两个人的饭 ✓ | 盛出来才想起，不会再有第二双筷子了 |
| 到点看门口 | 玄关 ✓ 的灯不知道该不该留 |
| 想转发一条消息 ✓ | 输入框开了又关 |
| 睡自己那半边 | 另一半空着，没人抢被子 ✓ 了 |
| 买菜拿了他不吃的葱 | 现在可以买了，反而难受 |

最后一行是这条的独门细节：**自由回来的那一刻最疼。** 终于可以做他不喜欢的事了，而这件事一点也不好。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 那副没收走的碗 ✓ · 他留下的充电线 ✓ · 她那瓶还剩一半的东西 |
| 破防引爆物 | 一首歌 · 外卖软件的常点推荐 · 快递送来分手前买的东西 |
| 撑着的方式 | 她加班 · 他接了很多活 · 都把日程填满 |
| 别人 | 谁都没告诉 · 或者只告诉了一个人 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁更狼狈 | 他 | 她且她不许自己狼狈 |
| 告不告诉别人 | 瞒着 | 闺蜜或兄弟知道了 |
| 破防的引子 | 一件遗留物 | 一个日期 |
| 第一周结束 | 缓过来一点 | 更沉了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她第五天在超市拿起那把葱 | 输入框开了又关的那条 |
| 内心 | 我早该习惯一个人 | 她那边是不是已经没事了 |
| 好的处理 | 她的崩溃很短，且没人看见 | 他没有发出去那条消息 |
| 写崩 | 写成她无痛切割 | 写成他天天买醉 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他那院子她再没进去过，回廊也绕开走 |
| 修仙 | 洞府禁制还留着他的名，她一直没抹掉 |
| 星际 | 舱位权限到期自动收回，系统弹确认，她盯着那键按不下去 |

星际版的「系统弹确认」把这条推到了极致：**连分手都有一个进度条**，而她的手停在按钮上。

#### 写崩的三种方式

1. 别让第一天就崩盘。看着轻松，其实才是真开始。
2. 别俩人平均使劲。一边写透，另一边留白。
3. 用酗酒堕落演痛苦？扑空的习惯比失态狠多了。

## 四 · 还东西

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：分手 8.4% ＋ 赠礼 29.0%

**骨架**｜一个纸箱，装着两年。

#### 节拍链

约时间，消息里客气得跟陌生人似的。然后收拾，比预想的多花了不少时间。交接那几分钟，有一样东西归谁说不清楚。门一关，箱子怎么处理。

#### 时间轴

收拾的过程，就是回忆被强制重放。每拿起一样东西，都得判断一次：归他，归我，还是归两个人。第三类最难办。

#### 三类东西

| 类 | 处理 | 戏在哪 |
|---|---|---|
| 明确是对方的 | 装箱 | 无 |
| 对方送的 | 还不还，两难 | 还了是绝情，不还是没断干净 |
| 说不清的 | 那只一起买的锅 ✓ · 那只猫 | 这一类是这条的正文 |

宠物的归属可以单独撑一场戏，接 [13-家庭与亲属 · 养一只](13-家庭与亲属.md#八--养一只)。它两边都认，可它只能去一边。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 纸箱 · 胶带声 · 钥匙 ✓（最后才放下）· 一件他故意没拿的 |
| 交接 | 约在楼下不上去 · 或者上去了，站玄关 ✓ 没进门 |
| 措辞 | 「都在这了」· 「那我走了」· 全程没超过十句 |
| 故意遗漏 | 有样东西谁都没提。留着它，等于留了根线 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 方式 | 当面 | 快递（更冷，也更干净） |
| 送的东西 | 还了 | 都留着，两边都是 |
| 那根线 | 留了 | 没留，真的清了 |
| 情绪 | 全程平静 | 有一样东西让一方停了几秒 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她随手给过的东西，被原样还了回来 | 钥匙搁下那一下的动静 |
| 内心 | 他连这都留着呢 | 别去数箱子里缺了啥 |
| 好的处理 | 她收了箱子，没当场打开看 | 他留了一样东西，也没吭声 |
| 写崩 | 写成了算账分家产 | 写成了他闹脾气撒泼 |

「她随手给过的东西被还回来了」跟 [07-馈赠与仪式 · 她随手给的东西](07-馈赠与仪式.md#三--她随手给的东西) 其实是同一件东西，分两个阶段写。收下的时候是演戏，还回去的时候又是另一出戏。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 退还聘物／信物锁匣里送回／名帖划掉 |
| 修仙 | 解契得俩人一块儿来，这是修仙界才有的狠：散伙也得成双 |
| 星际 | 权限一项项删，每删一回都跳个确认框 |

#### 写崩的三种方式

1. 逐样东西写回忆。挑一样，其余用「装了半箱」带过。
2. 交接时把话说透。这场戏的规矩是十句以内。
3. 忽略说不清的那一类。锅和猫才是正文。

## 五 · 街上遇见

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：前任 31.0% ＋ 初见 38.0%

**骨架**｜分开后头一回撞上。三秒，四条路可选。

#### 节拍链

看见（谁先看见谁）→ 躲不躲 → 打不打招呼 → 那三十秒的寒暄 → 走开 → 各自走出五十米之后的样子

#### 时间轴

**这场戏的正文在走开之后。** 寒暄三十秒写三行就够，各自走出五十米之后那一段，才是要用力的地方。

#### 四种走法

| 走法 | 含义 |
|---|---|
| 一方看见，躲了 | 还没缓过来 |
| 都看见了，点头走过 | 体面，但都在硬撑 |
| 站住说了三十秒 | 「最近好吗」「挺好的」，没一句真的 |
| 一方身边有新的人 | 转 [六 · 共同朋友的场合](#六--共同朋友的场合) 的对照结构 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 地点 | 超市（最日常最扎心）· 地铁 ✓ 对面 · 那家常去的店 ✓ 门口 |
| 变化 | 他换了发型 ✓ · 她瘦了 · 有一样没变，还拎着那个包 |
| 寒暄内容 | 天气、工作、「你气色不错」——全是客套话 |
| 走开之后 | 她在下一个路口站了一会儿 · 他把刚买的东西拎反了方向 |

「把东西拎反了方向」这类失灵动作，比任何心理描写都准。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 距离分手 | 一个月 | 三年 |
| 谁先开口 | 她 | 他，他以前不敢先说话，现在敢了，这本身就是事 |
| 身边 | 都一个人 | 有一方不是 |
| 之后 | 就这样了 | 当晚有一方翻了旧照片 ✓ |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他先开口了，以前他不敢 | 她的包还是那个 |
| 内心 | 他过得好，我该替他高兴 | 三十秒，别超时 |
| 好的处理 | 她说了句实在话：「你这样挺好」 | 他一个字都没提过去 |
| 写崩 | 写成她吃醋发火 | 写成他当街失态 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 街上远远瞧见一眼／他跟着新主家的马车过去／庙会人堆里 |
| 修仙 | 坊市碰见／隔了百年在路上撞上，他头发白了，她模样没变，寿元差 |
| 星际 | 中转站错身／两边舰队一起出任务，点名时听见他名字 |

#### 写崩的三种方式

1. 当街说开旧事。 街上只有壳。芯要留给别的场合。
2. 让偶遇推动复合。 偶遇只负责证明没放下，复合另有路。
3. 省略走开之后。 那五十米才是这条。

## 六 · 共同朋友的场合

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：前任 31.0% ＋ 聚会 12.0%

**骨架**｜婚礼、聚会、老朋友的局。两个人各自都收到了请帖，谁也躲不掉。

## 七 · 深夜那通电话

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：醉酒 31.0% ＋ 失联 23.0%

**骨架**｜凌晨一点，屏幕上还是那个没改备注的名字。

#### 节拍链

铃声（看清来电人）→ 接不接的三秒 → 接了 → 对面是醉的 → 听 → 说不说自己的 → 挂断之后

#### 时间轴

通话时长就是刻度。对面说了二十分钟，这边总共说了不到十句。 听比说难写。也比说重要。

#### 可用细节

| 类 | 内容 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁打给谁 | 他喝多了打来 | 她从来不掉链子，这回拨了又挂 |

1. 电话里把话说清。醉话只能漏一句真的，多了就假。
2. 连夜奔赴。隔着线才是这条的分寸。

## 八 · 谁先低头

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：和好 35.0%

**骨架**｜有人先动手了。这回的代价，可比吵完架再和好贵多了。

#### 节拍链

决定（想了很多天）→ 找一个由头 → 第一次接触（极轻）→ 对方的回应 → 试探往来几轮 → 见面

#### 时间轴

从第一条消息到见面，中间隔着几轮小心翼翼的往来。每一轮的间隔都在缩短，这个缩短就是进度条。

#### 由头的等级

| 由头 | 含义 |
|---|---|
| 「你落了个东西在我这」 | 最安全，可进可退 |
| 节日的群发式祝福 | 试水温 |
| 「路过那家店，想起你爱吃的」 | 已经不装了 |
| 「有空吗，想跟你说件事」 | 摊牌 |
| 直接出现在楼下 | 她决定就不迂回 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 第一条消息 | 措辞改了很多遍（接 [19-玩闹与网络 · 第一条消息](19-玩闹与网络.md#一--第一条消息)，同一个人又回到删改草稿的日子） |
| 回应的温度 | 秒回还是隔天 · 句尾有没有那个语气词 |
| 双方的克制 | 都不提那件事 · 都在等对方先提 |
| 见面 | 约在老地方还是新地方，选址就是态度 |

「同一个人又回到了删改草稿的日子」，关系确立前的那套小心翼翼原样回来了，而这次两个人都认得它。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先动 | 他 | 她 |
| 由头 | 找了个体面的 | 不找了，直说 |
| 对方 | 等这一天很久了 | 真的犹豫 |
| 节奏 | 几天 | 几个月 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她直接站楼下等了 | 那条消息他磨了一小时才回 |
| 内心 | 绕弯子不是我的风格 | 回太快显得我老等着。我确实一直在等 |
| 好的处理 | 她开口先提那件当时没说的真话 | 他回了，也没装没事人 |
| 写崩 | 写成她下命令把人叫回来 | 写成他故意吊着人玩 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她车驾停在他家巷口／一份没署名的年礼 |
| 修仙 | 他传讯符又能用了，是她那边给开的 |
| 星际 | 她发来一条航线共享，起点就定在她那儿 |

#### 写崩的三种方式

1. 一条消息直接复合。中间那几轮来回拉扯，省不了。
2. 先低头的那个人，别让他从头怂到尾。低头是给台阶，不是认输。
3. 找借口这事，别没完没了。借口用一次就够了，第二句就得说人话。

## 九 · 重新在一起

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：和好 35.0%

**骨架**｜复合不是回到过去，是俩人重新处了一回。

#### 节拍链

那次见面 → 把当时的真话说完（接 [二 · 真话与场面话](#二--真话与场面话)）→ 问题摆上桌 → 各自让了一步 → 重新开始 → 有些东西回不来，有些东西是新的

#### 时间轴

复合那天是第二段关系的第一天，不是终点。写到「在一起了」就收，等于把最难的部分留给了读者想象。

#### 新旧对照表

破镜重圆的「圆」不是原样：

| 项 | 从前 | 现在 |
|---|---|---|
| 那个分手的原因 | 没人提 | 摆上桌谈过了 |
| 她的安排 | 直接定 | 先问一句 |
| 他的委屈 | 攒着 | 当天说 |
| 那件旧物 | 在箱底 | 摆回了原位，但两个人都知道它进过箱子 |

最后一行是这条的核心意象：东西能放回原位，但进过箱子这件事抹不掉。那算防伪标记，算不上伤疤。它证明这次是谈出来的，不是糊弄回去的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 那次谈 | 没在家，约在外面见 · 聊了挺久 · 中间有阵子谁都没吭声 |
| 让步 | 一人退一步，说具体的，她改个毛病，他应下一件事 |
| 搬回来 | 东西比上回少 · 有的他扔了，她也没问 |
| 周围人 | 知道的反应不一样 · 有人替他们踏实，有人替他们悬着心 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谈的深度 | 把话说开了 | 说一半留一半，后面还得炸，写长线用 |
| 变化 | 真改了 | 头三个月改了，后来老毛病又犯，得想办法 |
| 周围 | 都支持 | 有人明着反对 |
| 那道疤 | 成了招牌 | 成了随时能翻的旧账，写崩前兆 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她做安排前停了半秒，先问了他 | 他发现那样东西被摆回了原位 |
| 内心 | 这半秒的停顿就是我让的那步 | 这次我有说话的份 |
| 好的处理 | 她的改变小而具体，且撑过了三个月 | 他把「当天说」真的做到了 |
| 写崩 | 写成一切如初 | 写成他拿旧事当护身符 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 重新下聘，聘礼单子和上次一字不差，就多添了一行 |
| 修仙 | 重新结契，这次契文是俩人一块儿写的 |
| 星际 | 重新绑权限，这回是两边互相授权 |

「契文两个人一起拟」「双向授权」，三个换皮说的是同一件事：第二次的仪式里，他有了起草权。

#### 写崩的三种方式

1. 复合当天就写大团圆，那才是第二段故事的第一天。
2. 分手的原因别糊弄过去。没解决的问题，迟早原样找上门。
3. 别想着一切照旧。总要有点回不来的，也得有点新长出来的。

## 十 · 没有复合

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：分手 8.4%（BE 向，语料罕见）

**骨架**｜还有一种结局：他们没回去，但也不算输。

#### 节拍链

时间过去 → 各自的生活成形 → 一次平静的重逢 → 说了当年没说的话 → 道别 → 各自走，都没有回头

#### 时间轴

**这条要隔得够久才成立。** 一年太短，情绪还在。五年之后，说什么都不再是试探，只是交代。

#### 为什么这条要写

「和好」能占到35%，「分手」只有8.4%，语料库差不多默认了破镜就得重圆。但有些故事，诚实的结局就是分开。不合适就是不合适，爱过也改变不了这个事实。这类故事平时写惯了权力关系的建立，很少去写它体面地收场。但能把收场写体面了，前面那些戏才立得住。

#### 可用细节

| 类 | 内容 |
|---|---|
| 重逢 | 好几年没见，俩人都挺稳当 · 就喝了杯咖啡的工夫 |
| 交代 | 「那年那事儿，其实吧……」——憋了多年的话总算说出口 |
| 现在 | 日子都还凑合 · 一个结了婚 · 要不都单着，也不是在等谁 |
| 道别 | 「那我走了」跟当年那声一样，意思全变了 |
| 留下的 | 他跟她学的那些还在用 · 她为他改的毛病没再改回去 |

「他从她身上学会的东西还在用」是这条的落点：关系没了，关系造成的那部分人还在。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 有没有重逢 | 有那杯咖啡 | 没有，只是各自知道对方的消息 |
| 情绪 | 释然 | 平静底下压着一点什么，且不再翻开 |
| 现在的关系 | 成了很淡的朋友 | 不联系，不憎恨 |
| 叙事位置 | 全书结局 | 前任线的收束（主线另有其人） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己有个习惯是他留下的 | 他现在敢先开口了，是她教的 |
| 内心 | 那几年没白过，就是结束了 | 谢和对不起，都不必再说了 |
| 好的处理 | 她没说「祝你幸福」这种话 | 他讲的是件实实在在的小事 |
| 写崩 | 写成她一个人苦等 | 写成他彻底垮了 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 多年后他随家人赴宴，跟她隔桌见了礼，礼数挑不出错 |
| 修仙 | 百年后论道大会坐一桌，行的还是同门礼 |
| 星际 | 联合任务里公事公办，配合还是那么顺手，这点顺手就是剩下的全部 |

「配合得依然默契」，星际版把这条说透了：**默契比关系活得久。**

#### 写崩的三种方式

1. 结尾埋复合钩子。这条的价值就是不回去。
2. 让分开毁掉一个人。各自过得不坏，才是对那段关系的敬意。
3. 交代真话时旧情复燃。说完就走，走得动，才叫结束。

## 十一 · 离婚这一场

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：分手 8.4% ＋ 婚仪 38.8% 的交集（语料罕见，正面写的更少）

**骨架**｜领证了还能离。那句话说完，恋爱分手已经结束的地方，这儿才刚开始办手续。

#### 与前十条的结构差

| | 恋爱分手（前十条） | 离婚 |
|---|---|---|
| 生效方式 | 嘴上说完就算 | 嘴上说完只算申请，要等章盖下来 |
| 时长 | 十分钟 | 三十一天起步 |
| 参与方 | 两个人 | 两个人加窗口、填表、冷静期 |
| 财产 | 一个纸箱 | 一张财产表，一行一行签字 |
| 撤回成本 | 一句话 | 冷静期里不去第二趟，申请自己作废，制度替人留好退路 |
| 结束的凭证 | 门关上的声响 | 一本新证 |

前十条的核心技术，是把「说出口」写轻，把前后写重。这一条反过来：说出口最轻，流程最重。分手靠勇气，离婚靠出勤。

#### 节拍链

那句话刚说完 → 发现这事没完（查流程那晚）→ 财产一项项对 → 交材料 → 等三十天冷静期 → 再去一趟 → 拿号排队 → 新证到手 → 在门口站了一会儿

#### 时间轴

情绪和手续对不上，有两种错法。
一种是情绪先没了：人早散了，手续还没走完，俩人反倒客客气气，像在帮别人办离婚，配合得比结婚时还默契。
另一种是手续先办完了：章盖了，证领了，情绪却还没到位，站在民政局大厅里，手里捏着新证，愣是不知道下一步该干嘛。
冷静期那三十天，就是专门放大这种错位的：住不住一块、说不说话、猫归谁喂，每天都得重新定一次。

#### 可用细节

| 类 | 内容 |
|---|---|
| 流程道具 | 排队号（A 区领证 B 区离证，叫号声来回响）· 户口本 · 两张两寸照，背景色跟当年不一样了 · 离婚协议打印店装订的那份 |
| 财产表 | 表格把八年折成几行 · 「这台冰箱写你还是写我」谈得比当年买它还较真 · 有一行谁都不想要 · 有一行谁都想要（猫） |
| 冷静期 | 各自数着的三十天 · 谁都没提「要不算了」，谁都等着对方先开口 · 第二十九天那条消息没发出去 ✓ |
| 窗口 | 工作人员照例问「都想好了吗」，两个人同时说「嗯」，同时没看对方 |
| 那一站 | 出了大厅，一个说「吃个饭吗」· 最后一顿，点的还是老三样 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 错位方向 | 人已经炸了，流程还没动 | 流程走完了，人还没缓过来 |
| 冷静期 | 各住各的 | 还住一块，房子一时半会儿卖不掉 |
| 财产表 | 聊得挺客气 | 卡在一行上，偏偏是最不值钱的那行 |
| 二次到场 | 俩人都来了 | 有一方没来，白跑一趟，然后呢 |

「有一方没来」这一端两种收法都成立：没来是回心转意，或者只是没请下假。哪一种，另一方站在大厅里等号的时候不知道。

#### 写崩的三种方式

1. 把流程写成背景。排队号和财产表就是正文，跳过它们等于把这条写回了前十条。
2. 用手续的荒诞感搞喜剧。可以有那口气，但底色是两个人在合作拆一个家。
3. 冷静期写成复合倒计时。它首先是三十天的悬置，两种结局都得真的可能。
