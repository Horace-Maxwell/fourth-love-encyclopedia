# 危机与保护

> **分级** 分级见各条，分级上限 `T` ｜ 预警 ⚠️暴力（低烈度，见各条）｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**保护是这个类型最容易滑回传统脚本的地方，也是最能证明它不同的地方。**

## 这一族的核心难题

危机场面是所有言情的标配，但在 GB 里它有一个特殊的陷阱：危险一来，很多作者会下意识地让男方挡在前面。

那一下就把前面几十章建立的东西全还回去了。

而正确的做法不是反过来（永远让她挡），那照样是把“护着”当成“说了算”的证据。这一族真正的规矩就一句话：谁扛得住谁上，完事之后还得有人收拾烂摊子。

| 配置 | 说明 | 常见度 |
|---|---|---|
| 她挡 | 符合设定 | 高 |
| 他挡 | 他有他的能力 | 中，且要处理 |
| 各挡各的 | 两个人都在做自己能做的 | 最好，最少写 |
| 谁都没挡住 | 最真实 | 低 |

| 节拍族 | 作品数 | 占比 |
|---|---:|---:|
| 受伤 | 1,505 | 52.0% |
| 和好 | 1,013 | 35.0% |
| 被欺负 | 723 | 25.0% |
| 危险 | 521 | 18.0% |
| 吵架 | 434 | 15.0% |
| 出面 | 405 | 14.0% |

「受伤」52% 是全库排名第二的情境族。这一族是这个类型的高频区。

## 一 · 他被为难

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：被欺负 25.0%（被欺负＋受伤、被欺负＋留痕高频同现）

**骨架**｜有人在单位里故意给他难堪，可这回她没在。

#### 节拍链

排挤或抢功 → 「你不是有关系吗」→ 他没提她的名字 → 自己处理（专业或事后）→ 没跟她说 → 她从别处知道

#### 时间轴

为难持续了几周，她知道时已经结束了。 排挤是慢刀子：会议不叫他、功劳被摘，以周计地累积；他自己处理也以周计（收集记录、正面摊牌或用作品说话）。她从别处知道的那天，事情已经收场，她拿到的是一份「事后报告」，这个时间差就是他要的：他要的是处理完再让她知道。

#### 「她不在」是这条的前提

如果她在，这条就该接 [14-社交与公开 · 她替他挡](14-社交与公开.md#十--她替他挡)。她不在，他就得自己扛下来，这条才有用。

#### 他的四种处理

| 处理 | 说明 | 读者观感 |
|---|---|---|
| 忍 | 啥也没干 | 读者憋得慌，除非后面有招 |
| 硬顶 | 当场翻脸 | 爽是爽，但得写清楚代价 |
| 用专业赢 | 拿本事把对方摁回去 | 最漂亮 |
| 事后处理 | 当时不动，过后再收拾 | 最有嚼头 |

「用专业赢」是这一族的最优解：他不需要靠她，也不需要靠体力，他靠的是自己那一份本事。

#### 可用细节

| 类 | 内容 |
|---|---|
| 刁难的形态 | 开会不叫他 · 功劳算自己的 · 当众揭他老底 · 派他干杂活 |
| 提到她 | 「你不是有关系吗」——这话就是这一挂的招牌 |
| 他的反应 | 没提她名字 |
| 事后 | 也没跟她说 |
| 她的发现 | 听别人讲的 · 或者压根不知道 |

「他没有提她的名字」是这条的核心动作。 手里有一张牌但不打，这就是他的分寸。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他说不说 | 告诉她了 | 一直没说 |
| 她知不知道 | 从别人处知道 | 完全不知道 |
| 他的处理 | 自己解决了 | 没解决 |
| 她的后续 | 她去处理了 | 她忍住了 |

「她忍住了」比「她去处理了」难写，也更有分量。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她是听别人说的这事 | 「你不是有关系吗」 |
| 内心 | 他咋不跟我说一声 | 一提她名字，我就真成那种人了 |
| 好的处理 | 她问了，但没急着管 | 他自己摆平了，事后也没提 |
| 写崩 | 写成她直接杀过去算账 | 写成他光忍着不吭声 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 同僚排挤／被指派苦差／有人当面提他的位份 |
| 修仙 | 同门欺压／资源被克扣／说他靠道侣 |
| 星际 | 被排除在任务外／有人查他的档案 |

#### 写崩的三种方式

1. 让她杀过去解决。 那这条就没发生过。
2. 让他从头忍到尾。 至少要有一次反击。
3. 让他打出她这张牌。 那是这条的红线。

## 二 · 她知道了

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：被欺负 25.0% ＋ 出面 14.0%

**骨架**｜她是从别人嘴里听说他受了委屈的，可她第一句问的是：“他咋不跟我说呢？”

#### 节拍链

别人说漏 → 她当天没提 → 想了一晚 → 「今天有人跟我说了件事」→ 「小事」→ 「以后可以跟我说」→ 下一次他说了

#### 时间轴

从知道到开口，她憋了一整晚没提。当天就问，那口气肯定是审犯人；想了一宿，把「你为什么不告诉我」换成了「今天有人跟我说了件事」。这一晚的缓冲，是她有修养，也是她会写。「下一次他说了」隔了俩月，制度性变化的生效期就是这么长，写短了就假了。

#### 这条的双重伤害

| 伤 | 内容 |
|---|---|
| 一 | 他受了委屈 |
| 二 | 他没告诉她 |

第二重比第一重更让她难受，而这一点她通常不会直接说。

#### 她的四种反应

| 反应 | 效果 |
|---|---|
| 立刻去处理 | 会让他觉得自己更没用 |
| 质问他为什么不说 | 变成了他的错 |
| 什么都不说，暗中处理 | 被发现会更糟 |
| 问他「要我做什么吗」 | 最好 |

第四种是这一族的通用解法，与 [14 卷第十条](14-社交与公开.md#十--她替他挡) 同源：先问。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的得知 | 同事说漏嘴 · 翻到一份文件 · 她自己瞧出来了 |
| 她的克制 | 当天没吱声 · 憋了一宿 |
| 她的开口 | 「今儿有人跟我念叨了个事」 |
| 他的反应 | 「没事」——这俩字就是他的壳 |
| 落点 | 她没问「你咋不早说」，就一句「往后你也能跟我说」 |

「以后可以跟我说」比「你怎么不告诉我」好一百倍。 前者是邀请，后者是指责。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的反应 | 出手 | 忍住 |
| 他的态度 | 说了 | 坚持说是小事 |
| 结果 | 他之后开始说了 | 他还是不说 |
| 长期 | 关系更实 | 他习惯性地屏蔽她 |

「他习惯性地屏蔽她」是最坏也最真实的走向，可以接 [04-委屈与破防 · 我是不是不够好](04-委屈与破防.md#九--我是不是不够好)。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听完没当场翻脸 | 「小事」 |
| 内心 | 他不说，是怕我闹吧 | 说了她肯定插手，那我还算啥 |
| 好的处理 | 她说「下次记得跟我说」 | 他说了句「下回再说」 |
| 写崩 | 写成她撒泼发脾气 | 写成他死犟不回头 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 下人回报／她从别处听说他挨了排揎 |
| 修仙 | 她神识扫过发现他有暗伤 |
| 星际 | 她调记录时看见了 |

#### 写崩的三种方式

1. 让她当场爆发。 忍一晚上更有力。
2. 用「你怎么不告诉我」开场。 那是指责。
3. 立刻解决。 她要先问。

## 三 · 他受伤了

`T` ｜ ⚠️暴力（低烈度）｜ 全谱系 ｜ 语料频次：受伤 52.0%（受伤＋上药＋生病为最高频三元组合）

**骨架**｜他带伤回来，她是先问咋弄的，还是先处理伤口。

#### 节拍链

带伤回来 → 换手拿东西露了馅 → 她的顺序（先处理或先问）→ 上药 → 怎么弄的 → 不是实话 → 她提了她的条件

#### 时间轴

处理伤十分钟，处理谎一整晚。上药很快：清创、消毒、包扎，她手稳得像练过；“怎么弄的”是包扎完才问的，顺序是她的规矩（先修人，再审案）。他第一版说法当场就被拆穿了，真话磨了半小时才挤出来；她条件是在睡前提的，一句话，从那天起就定了。

#### 顺序就是性格

| 顺序 | 说明 |
|---|---|
| 先问怎么弄的 | 她得先摸清底细。合她性子，但会让他先绷着不敢松劲 |
| 先处理伤 | 手比嘴快。更贴心，可她心里犯嘀咕 |
| 一边处理一边问 | 最常见，也最自然 |
| 什么都不问 | 最狠——她心里其实早就有数了 |

「什么都不问」这一版最好用，尤其当伤是为她受的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 伤的形态 | 淤青 ✓ · 破皮 · 缝针 · 手上的 · 衣服能盖住的地方 |
| 他的隐瞒 | 穿长袖遮 · 用没伤的那只手干活 · 说是不小心撞的 |
| 破绽 | 有个动作顿了一下 · 拿东西换了只手 · 洗澡洗得特别久 |
| 她的发现 | 撞见了 · 或者她心里早就有数 |
| 处理 | 见 [01-日常照料 · 擦药与倒吸气](01-日常照料.md#七--擦药与倒吸气) |

#### 伤是怎么来的，四种

| 来源 | 关系含义 |
|---|---|
| 意外 | 无 |
| 工作 | 他的世界她进不去的那部分 |
| 为她打的架 | 最常见，也最需要处理 |
| 别人对他的伤害 | 转 [一 · 他被为难](#一--他被为难) |

「为她打的架」要小心。 这是最容易滑回传统脚本的一处：他用暴力保护她，等于用体力换回了男性位置。

处理方法：让那场架没赢，或者让她明确说这不是她要的。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 伤的来源 | 意外 | 为她 |
| 他说不说 | 说了 | 编了个理由 |
| 她的反应 | 心疼 | 生气（气他不惜身） |
| 后续 | 她处理了对方 | 她要求他答应下次不这样 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他换了只手拿杯子 | 别让她看见 |
| 内心 | 又是为我 | 我不想让她觉得我打不过 |
| 好的处理 | 她生气，但她先处理伤 | 他没有拿伤来邀功 |
| 写崩 | 写成她被英雄救美感动 | 写成他靠受伤换关注 |

#### 内容边界

本条涉及低烈度暴力（打架、擦伤）。写作时：

| 线 | 说明 |
|---|---|
| 不写可复现的伤害手法 | 只写后果，不写过程细节 |
| 不把暴力浪漫化 | 「为她打架」得有代价，不能光给甜头 |
| 严重伤害另走 | 重伤／医疗情节见 [09-分离与重逢 · 陪床](09-分离与重逢.md#四--陪床) |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他替她挡了一刀；药才上到一半她问「谁下的手」，问完当晚就点了兵 |
| 修仙 | 护山那仗他伤了经脉还硬撑着装没事；她一搭脉脸就沉了，罚他闭关养着，自己搬去洞府外间守着 |
| 星际 | 训练舱数据骗不了人：冲击伤记录她第二天照例一翻就看见了。他瞒了一宿，等于白瞒一份日志 |

#### 写崩的三种方式

1. 让打架成为他的高光。 那是把传统脚本请回来了。
2. 让她因此更爱他。 她可以心疼，不能因此改变对他的评价。
3. 伤得太重。 重伤会把日常戏变成生死戏。

## 四 · 她受伤了

`T` ｜ ⚠️暴力（低烈度）｜ 全谱系 ｜ 语料频次：受伤 52.0%（女方向少见）

**骨架**｜这次是她。他头一回碰上这种场面。

#### 节拍链

电话打来 → 他赶到 → 「你是家属吗」→ 签字 → 一件件处理 → 她醒来先问工作 → 「都处理了」→ 他事后才开始抖

#### 时间轴

他的钟在事发时停了，事后才恢复走动。从接电话到医院那四十分钟，他完全断片——连自己怎么打的车都想不起来。签字、缴费、联系她助理，三小时忙得像个机器人，一点情绪都没有。她醒了，他看起来没事，但抖是延后到的：当晚在医院走廊，就他一个人，手突然不听使唤了。前面撑住、后面崩掉，这个时间差，就是这条的写法。

#### 为什么这条必须写

她一直是处理问题的那个人。她受伤，意味着系统里唯一的处理者失效了，而他要顶上去。

这是这一族里最有价值的一条，也是最少被写的。

#### 他要做的四件事

| 事 | 难点 |
|---|---|
| 现场处置 | 他可能不会 |
| 通知谁 | 她的工作怎么办、家里怎么说 |
| 决策 | 她昏着，医生问他 |
| 陪着 | 见 [09-分离与重逢 · 陪床](09-分离与重逢.md#四--陪床) |

第三件最重。 一个从来不做决定的人，突然要替她做决定。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的状态 | 手抖着签字 · 电话里声音倒挺稳（他自己都没想到） |
| 他的能力 | 她的事他其实全知道：血型、过敏啥的 ✓、她公司找谁管用 |
| 她醒来后 | 先问工作的事 · 他说「都办妥了」 |
| 她的反应 | 愣住 · 没料到他真能接住 |
| 转折 | 她头一回觉得，不用什么都自己顶 |

「他其实知道她所有的事」是这条的高光。 那些他默默记下的细节，在这一刻全部变成了能力。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 严重程度 | 小伤 | 需要手术 |
| 他的表现 | 慌但顶住了 | 完全乱了（也真实） |
| 她的反应 | 感激 | 不习惯 |
| 之后 | 她开始交出去一些事 | 她很快恢复原样 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她醒来发现事都办妥了 | 医生问「你是家属吗」 |
| 内心 | 原来没我也行 | 现在只剩我了 |
| 好的处理 | 她说了谢谢，而且是真心实意的 | 他事办完了才开始发抖 |
| 写崩 | 写成她一下子变成小媳妇样 | 写成他一晚上就变强了 |

「他做完之后才开始抖」是这条最好的收尾。 撑住是当下的，垮是事后的。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她重伤／他主持府中事务／有人趁机发难 |
| 修仙 | 她受了内伤闭关／他守着洞府对付上门的 |
| 星际 | 她进医疗舱／他临时接管指挥 |

#### 写崩的三种方式

1. 让她瞬间变柔弱。她受伤了，性格没变。
2. 让他一夜成长。他的能力本来就在，只是没用过。
3. 别忽略「他知道她所有的事」。那是全条的地基。

## 五 · 一场架

`T` ｜ ⚠️暴力（低烈度）｜ 全谱系 ｜ 语料频次：吵架 15.0% ＋ 危险 18.0%

**骨架**｜真打起来了。这一架谁动了手，谁干了啥，以后都记着呢。

#### 节拍链

起因 → 动手（很快）→ 结束 → 挂彩与手续 → 她赶到 → 先处理事 → 再说这件事不对 → 代价结算

#### 时间轴

**动手十秒，代价按周还。** 架打得快，快得没过程：起因、出手、结束，前后不到一分钟。但后面每段都比它长——处理伤口半小时，走手续两小时，她赶过来先办事再谈事，又搭进去一晚上。代价按周算：处分、赔偿、熟人圈里那些议论。十秒对几周，这比例摆出来，她自己那句「这件事不对」都不用多解释。

#### 三种配置

| 配置 | 说明 | 处理要点 |
|---|---|---|
| 他动手 | 最常见 | 要有代价，且她的态度要明确 |
| 她动手 | 少见，且很有效 | 她可能比他更利落 |
| 两人一起 | 最少写 | 配合本身就是关系的证明 |

「她比他更利落」这一版值得写。 在一个不假定女性会打架的默认里，她一记干脆的处理，比他挥十拳更有效。

#### 可用细节

| 类 | 内容 |
|---|---|
| 起因 | 有人先动手 · 有人嘴欠 · 护犊子 |
| 过程 | 短。真打起来很快 |
| 结果 | 谁见血了 · 有没有闹到警局／族里／舰上 |
| 事后 | 做笔录 · 赔钱 · 道歉 · 挨处分 |
| 关系 | 她怎么看这事 |

「事后」比「过程」重要得多。 打完之后的手续、代价、评价，才是这条的内容。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁动手 | 他 | 她 |
| 赢没赢 | 赢了 | 没赢（更好） |
| 她的态度 | 支持 | 明确说这不是解决办法 |
| 代价 | 无 | 处分／赔偿／她替他收拾 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她赶到时架已经打完了 | 打完之后手在抖 |
| 内心 | 他为什么要动手 | 我知道不该，但我控制不住 |
| 好的处理 | 她先把事办了，再跟他说这样不对 | 他认了，说自己刚才没忍住 |
| 写崩 | 写成她觉得他打架特带劲 | 写成他打架特别帅 |

「她为他的暴力骄傲」是这条的红线。 暴力可以发生，不能被奖赏。

#### 内容边界

同 [三 · 他受伤了](#三--他受伤了)：不写可复现的伤害手法，暴力要有后果，严重情节另走 [06-尺度与写法](../06-尺度与写法/)。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 街头有人骂她，他动了手；被带到堂上时指节还渗着血。她来得很快，先保人领出来，出了衙门才说「这事不对」 |
| 修仙 | 同门笑她双修耽误修行，他拔了剑；比斗有门规兜底，罚抄戒律三百遍。她没求情，只把伤药搁在戒律堂门口 |
| 星际 | 军营斗殴上了军法记录，关三天禁闭。她按程序去探视，隔着观察窗就一句：「出来把手养好。账我记下了，走程序清。」 |

#### 写崩的三种方式

1. 把打架写成高光时刻。 见上。
2. 过程写太长。 真架很短。
3. 没有事后。 手续与代价才是这条的价值。

## 六 · 吵到最难看的时候

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：吵架 15.0%

**骨架**｜这次不是吵架。两个人把心里话全倒出来了，句句扎心。

#### 节拍链

小事起头 → 三个回合变成别的 → 音量一大一轻 → 双方说了真话 → 一句之后没人再说 → 摔门或坐下 → 各自那一夜

#### 时间轴

三个回合的升级只用十分钟，那句话之后时间冻结。从小事到翻旧账到人身，每回合三分钟，音量一路走高；最难听那句出口后，屋里静了整整一分钟，这一分钟里谁都可以收手，谁都没收。之后的那一夜两个人各自睁眼到天亮，同一屋檐下两只失眠钟并行，这画面比吵架本身狠。

#### 与 [04-委屈与破防 · 说了狠话](04-委屈与破防.md#七--说了狠话) 的区别

那一条是他说了一句反话（他其实想要她留下）。
这一条是双方都说了真话，且真话正好是对方最怕听见的。

| 他说的真话 | 她说的真话 |
|---|---|
| 「你根本没把我当回事」 | 「我没时间哄你」 |
| 「我在这个家里算什么」 | 「这些年是谁在撑」 |
| 「你从来不问我怎么想」 | 「你想要什么，你说过吗」 |

注意这些话都是成立的，这才是它们伤人的原因。

#### 可用细节

| 类 | 内容 |
|---|---|
| 升级过程 | 从一件小事开始 · 三个来回就变了样 |
| 音量 | 一个越喊越大，一个越说越没声 |
| 停下的方式 | 一句话说完没人接话 · 或者有人摔门 ✓ 出去 |
| 那之后 | 屋里那摊东西搁了好几天没人收拾 |
| 谁先动 | 一般先动的是平时做饭那个（得吃饭啊） |

「一个越来越大，一个越来越轻」是这条最准的声音设计。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先失控 | 他 | 她 |
| 说的是不是实话 | 是 | 是气话 |
| 收场 | 有人走了 | 都留在原地 |
| 修复 | 当晚 | 几天后 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己说话跟上班似的 | 她说得没错，这才最堵得慌 |
| 内心 | 我不能输 | 我吵都没资格吵 |
| 好的处理 | 她后来认了，说那句是自己过了 | 他没摔门，反而坐下了 |
| 写崩 | 写成她单方面压着打 | 写成他撒泼打滚 |

「她发现自己在用工作时的语气」是这条最刺人的一笔。 把上司的语气带回家，是她最容易犯的错。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 当着下人吵／他跪下了但话没软／她摔了茶盏 |
| 修仙 | 灵压外泄／她的剑意惊动了整座山 |
| 星际 | 舱内警报因为声浪响了 |

#### 写崩的三种方式

1. 让她单方面碾压。 她口才好，但这场架不该赢。
2. 用摔门收场。 坐下来更难，也更好。
3. 当晚就和好。 至少留一夜。

## 七 · 和好的第一步

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：和好 35.0%（和好＋受伤、和好＋掉马高频同现）

**骨架**｜没有人道歉。但有人做了一件事。

#### 节拍链

僵持 → 有人做了一件小事（盛饭·递水·掖被）→ 功能性的第一句 → 第二句 → 日常恢复 → 那件事沉底或谈开

#### 时间轴

僵持是按天算的，破冰只要几秒钟。第三天晚饭，有人多盛了一碗饭推过去，五秒的动作，四天的僵局就这么没了。当晚恢复功能性对话（就一句），第二天正常聊了几句，第三天能开玩笑了。解冻是一层一层来的，每层隔一天。但引发矛盾那件事有没有说开，才决定这次是彻底化了，还是只是暂时冻上了。

#### 和好的语法：动作先于语言

这个类型的和好几乎从不靠一句「对不起」。原因是权力不对称让道歉变得别扭——她道歉像施舍，他道歉像认输。

于是和好靠动作：

| 动作 | 谁做 | 意思 |
|---|---|---|
| 做了饭 ✓ | 他 | 日子照常过 |
| 把他那份也盛了 | 她 | 你还在这个家 |
| 递了一杯水 | 任一方 | 先别吵了 |
| 半夜把被子 ✓ 给他掖上 | 她 | 知道你没睡着 |
| 早上照常倒了两杯水 | 任一方 | 习惯没断 |
| 剪指甲 | 见 [01 卷第九条](01-日常照料.md#九--剪指甲) | 找个借口挨近点 |

「照常倒了两杯水」是最省字的和好信号。

#### 可用细节

| 类 | 内容 |
|---|---|
| 时间 | 第二天早上 · 或者当晚三点 |
| 第一个动作 | 通常很小，做的人还装得挺自然 |
| 第一句话 | 就是句正事（「盐在哪」） |
| 第二句话 | 这句才是真和好了 |
| 那件事 | 一般不再提，要么等很久以后才说 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先动 | 她 | 他 |
| 有没有道歉 | 有 | 没有 |
| 那件事 | 谈开了 | 绕过去了（会复发） |
| 修复程度 | 完全 | 表面 |

「绕过去了」要标出来。 绕过去的事会在下一次吵架时原样回来。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 桌上多了一副碗筷 ✓ | 她把我的那份也盛了 |
| 内心 | 我不会说对不起，但我可以这么做 | 她盛了，那就是翻篇了 |
| 好的处理 | 她做了事，也没多解释 | 他接下了这事 |
| 写崩 | 写成一堆和好的话 | 写成他等着人去哄 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她叫他起来／赏了一样东西／让他坐到身边 |
| 修仙 | 她撤了禁制／传音过来一句无关的话 |
| 星际 | 权限恢复了／她把班排回了一起 |

#### 写崩的三种方式

1. 靠一场长对话和好。 动作先于语言。
2. 让道歉解决一切。 这个类型里道歉最难说得自然。
3. 每次都完全修复。 有几次要留残余。

## 八 · 她第一次求人

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：出面 14.0% 的反向

**骨架**｜她开口问他要了样东西，这事儿她以前从来没干过。

#### 节拍链

她想了很久 → 开口（极短）→ 他愣住 → 立刻答应，没问 → 事成或未成 → 她说了谢或没说 → 关系多了一个通道

#### 时间轴

开口就一句话，她为这一句憋了整整一个星期。她不是没试过别的办法，能走的路全走了一遍，走不通了，才轮到「求」这个选项。她挑了个普通晚饭后的时间开口，语气装得跟聊闲天似的。他答应得倒快，一秒都没犹豫。可事成之后，她那声「谢」反而拖了好几天才说出口，比求还难。这两下对比一出来，她这人什么性子，读者心里就有数了。

#### 为什么这条是这一族的顶点

她不求人。这是她的性格，也是她的困境——从不求人的人，也从不给别人帮她的机会。

所以她开口的那一刻，给出去的是一个位置，不是一个请求。

#### 她求的四种，重量递增

| 求什么 | 重量 |
|---|---|
| 一件小事（帮我拿一下） | 轻，日常 |
| 陪我去一个地方 | 中 |
| 帮我处理一件我处理不了的事 | 重 |
| 别走 | 最重 |

「别走」两个字是这个角色能说出的最重的话，且它通常出现在全书的后段。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的准备 | 她琢磨了半天怎么张嘴 · 也可能一张嘴就出来了 |
| 开口的方式 | 话很短 · 不解释 · 也不给理由 |
| 她的姿态 | 没低头 · 这不是服软，是托付 |
| 他的反应 | 一愣 · 接着就应了 · 连什么事都没问 |
| 事后 | 她道了声谢 · 或者一声没吭 |

「他甚至没问是什么事」是这条最好的一个反应。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她求什么 | 具体的事 | 「别走」 |
| 她的状态 | 冷静 | 熬不住了 |
| 他能不能做到 | 能 | 不能（更有戏） |
| 之后 | 她开始更多地求助 | 这是唯一一次 |

「他做不到」这一端是最难写的： 她终于开口了，而他帮不上。这一版的余味最长。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 开口之前那几秒 | 她在跟我说「你帮我」 |
| 内心 | 我从来不求人 | 她终于用得上我了 |
| 好的处理 | 她说得简短，也不解释 | 他先答应下来，再想怎么办 |
| 写崩 | 写成她低头认输 | 写成他得意起来 |

「她低头认输」和「他扬眉吐气」是这条的双雷。 这不是权力翻转，这是信任。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她开口托他一件事／把印信交给他 |
| 修仙 | 她请他护法／把本命交托 |
| 星际 | 她把指挥权临时交给他 |

#### 写崩的三种方式

1. 写成权力翻转。 求助不等于交出位置。
2. 让她说很多。 越短越重。
3. 让他趁机提条件。 那会毁掉这一刻。

#### 示例（本库自撰，可直接改写）

> 她站在门口，外套还没脱。
> 「你帮我一下。」
> 他从沙发上起来，手里的东西放下了：「什么事。」
> 「明天上午，你替我去一趟。」她说的就这么多，没有解释是什么事，也没有说为什么是他。
> 他没有问。
> 「行。」他说，「几点。」
> 她报了个时间，然后站在那儿没动。他这才发现她还没换鞋。

## 九 · 他能做到的那件事

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：出面 14.0% ＋ 危险 18.0%

**骨架**｜全场就他能干这事，而且靠的不是力气。

#### 节拍链

危机卡住 → 他知道自己能 → 没宣告就去做了 → 成了 → 她后来才知道 → 下一件也交给了他

#### 时间轴

危机那几天，他一声不吭地在干活。别人急得团团转的七十二小时里，他消失了好几个半天，谁也没注意，她也没注意。事情办成了，消息传回来，没人知道是他干的；她花了一周才查出来。几个月后，下一件事又落到他头上——信任这东西，不靠嘴上说，就看下一次任务给谁。

#### 这条是这一族的答案

前面八条都在处理「谁保护谁」的难题。这一条给出解法：不要比谁能挡，要给他一件只有他能做的事。

而且这件事不能是体力型的，否则又回到了传统脚本。

| 他能做的 | 为什么只有他 |
|---|---|
| 他认识那个关键的人 | 他的圈子她没有 |
| 他懂那门技术 | 他的专业 |
| 他能安抚某个人 | 他的耐心 |
| 他记得一个所有人都忘了的细节 | 他一直在留意 |
| 他敢做一件她的身份不允许她做的事 | 位置的互补 |
| 他能等 | 她做不到的那件事 |

最后两行最好。它们写的是位置互补，不是能力比较。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 出了事 · 要谈条件 · 她搞不定的一件私事 |
| 他的出场 | 没声张 · 他直接去办了 |
| 她的反应 | 她过后才晓得是他干的 |
| 旁人的反应 | 有人对他刮目相看 |
| 落点 | 她没夸他，她下回有事还找他 |

「她把下一件事也交给了他」比任何夸奖都重。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她知不知道 | 当场知道 | 过了很久才反应过来 |
| 他说不说 | 憋着不说 | 说了（也行） |
| 难度 | 顺手的事 | 他真搭进去了不少 |
| 之后 | 她从此就赖上他了 | 用完就完，没下文了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现这事是他干的 | 这事我能干 |
| 内心 | 我压根没想过他还有这手 | 总算轮到我了 |
| 好的处理 | 她把下件事也丢给他 | 他干完也不吭声 |
| 写崩 | 写成他忽然变超人 | 写成他等着别人夸 |

「他突然开挂」是这条最大的陷阱。 他的能力要在前文有过铺垫，哪怕只是一句。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他说动了那个人／她不懂的他懂／他替她跑腿 |
| 修仙 | 他这功法正好压她一头／他认得那阵 |
| 星际 | 那片星域他熟／那台机器他能修 |

#### 写崩的三种方式

1. 让他的能力凭空出现。 前文要有伏笔。
2. 让他做的是体力活。 那会回到传统脚本。
3. 让他等着被夸。 做完不提才对。

## 十 · 一起扛

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：危险 18.0% ＋ 和好 35.0%

**骨架**｜这回谁也不用护着谁。各干各的，事也办成了。

#### 节拍链

事发 → 不用商量，各自去做 → 中途对视一眼 → 有人熬不住另一个顶上 → 结束 → 并排坐着，不说话

#### 时间轴

两条线同时走，一个倒计时压着。出事之后没人开会分活儿，俩人一对眼神，各走各路，一个管家里，一个管外面，进度全靠晚上碰头对表，每天十分钟，说的全是正事。中间有一个人撑不住歇了半天，另一个直接顶上，没断档。等全办完了，俩人并排坐着谁也没说话，那二十分钟，是全书里俩人唯一一段谁都不用干活的空当。

#### 这条是全卷的收束

前九条都在处理保护的方向问题。这一条取消了这个问题：分工，而不是保护。

| 分工的形态 | 说明 |
|---|---|
| 她对外，他对内 | 最常见 |
| 她决策，他执行 | 符合原设定 |
| 他挡在前面，她在后面调度 | 少见，但成立 |
| 各管一半，中途换手 | 最好 |

「中途换手」是这条的最高形态。她熬不住的那一段他顶上，他熬不住的那一段她顶回来。

#### 可用细节

| 类 | 内容 |
|---|---|
| 事件 | 家里出事 · 摊上麻烦 · 一件事非得俩人一起干才行 |
| 分工 | 不用多说，各干各的 |
| 中间 | 有一回俩人正好同时抬头看对方 |
| 疲惫 | 谁先撑不住 · 另一个怎么接手 |
| 结束 | 俩人坐在一块儿，谁也没吭声 |

「不需要商量，各自去做了」是这条最好的一句描写。 默契比配合更能说明关系。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 结果 | 办成了 | 没办成，但一起挺住了 |
| 分工 | 明确 | 中途换过 |
| 之后 | 关系更实 | 两人都累到不想说话 |
| 谁先熬不住 | 她 | 他 |

「没办成，但一起挺住了」这一端更值得写。结果不重要，一起才重要。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她回头一看，那摊事他已经收拾利索了 | 这摊事我来 |
| 内心 | 不用多说，他全明白 | 她那头我不掺和 |
| 好的处理 | 她没去查他干得咋样 | 他没等她发话就上手了 |
| 写崩 | 写成了她指哪他打哪 | 写成了他急着显摆自己 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她在外头跑事，他在家看摊子／族里出了事，俩人各管一摊 |
| 修仙 | 她顶在前头，他守阵眼／一起扛过这劫，双修渡过去 |
| 星际 | 她发令，他开船／船被打坏了，俩人分头去修 |

#### 写崩的三种方式

1. 写成她指挥他执行。 那还是单向。
2. 让分工需要长篇商量。 默契更好。
3. 结尾大段总结感情。 坐在一起不说话就够了。
