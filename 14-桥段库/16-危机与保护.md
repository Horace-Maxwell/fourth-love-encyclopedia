# 危机与保护

> **分级** 分级见各条，分级上限 `T` ｜ 预警 ⚠️暴力（低烈度，见各条）｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**保护是这个类型最容易滑回传统脚本的地方，也是最能证明它不同的地方。**

---

## 这一族的核心难题

危机场面是所有言情的标配，但在 GB 里它有一个特殊的陷阱：危险一来，很多作者会下意识地让男方挡在前面。

那一下就把前面几十章建立的东西全还回去了。

而正确的做法不是反过来（永远让她挡），那同样是把保护当成了权力的证明。这一族的真正答案是：谁有能力谁上，且事后要处理。

| 配置 | 说明 | 常见度 |
|---|---|---|
| 她挡 | 符合设定 | 高 |
| 他挡 | 他有他的能力 | 中，且要处理 |
| 各挡各的 | 两个人都在做自己能做的 | 最好，最少写 |
| 谁都没挡住 | 最真实 | 低 |

| 节拍族 | 作品数 | 占比 |
|---|---:|---:|
| 受伤 | 1,505 | 52.0% |
| 和好 | 1,013 | 35.0% |
| 被欺负 | 723 | 25.0% |
| 危险 | 521 | 18.0% |
| 吵架 | 434 | 15.0% |
| 出面 | 405 | 14.0% |

「受伤」52% 是全库排名第二的情境族。这一族是这个类型的高频区。

## 一 · 他被为难

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：被欺负 25.0%（被欺负＋受伤、被欺负＋留痕高频同现）

**骨架**｜有人在职场／场合里刁难他。而这次她不在。

#### 节拍链

排挤或抢功 → 「你不是有关系吗」→ 他没提她的名字 → 自己处理（专业或事后）→ 没跟她说 → 她从别处知道

#### 时间轴

为难持续了几周，她知道时已经结束了。 排挤是慢刀子：会议不叫他、功劳被摘，以周计地累积；他自己处理也以周计（收集记录、正面摊牌或用作品说话）。她从别处知道的那天，事情已经收场，她拿到的是一份「事后报告」，这个时间差就是他要的：他要的是处理完再让她知道。

#### 「她不在」是这条的前提

如果她在，这条就变成了 [14-社交与公开 · 她替他挡](14-社交与公开.md#十--她替他挡)。她不在，他必须自己处理，这才是这条的价值。

#### 他的四种处理

| 处理 | 说明 | 读者观感 |
|---|---|---|
| 忍 | 什么都没做 | 会让读者憋屈，除非有后手 |
| 硬顶 | 当场翻脸 | 痛快，但代价要写 |
| 用专业赢 | 用能力把对方压回去 | 最好 |
| 事后处理 | 当场不动，事后一击 | 最有层次 |

「用专业赢」是这一族的最优解：他不需要靠她，也不需要靠体力，他靠的是自己那一份本事。

#### 可用细节

| 类 | 内容 |
|---|---|
| 刁难的形态 | 把他排除在会议外 · 抢他的功劳 · 当众提他的私事 · 派他做没意义的活 |
| 提到她 | 「你不是有关系吗」——这句是这一族的标志句 |
| 他的反应 | 没有提她的名字 |
| 事后 | 他没跟她说 |
| 她的发现 | 从别人那里 · 或者一直没发现 |

「他没有提她的名字」是这条的核心动作。 手里有一张牌但不打，这就是他的分寸。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他说不说 | 告诉她了 | 一直没说 |
| 她知不知道 | 从别人处知道 | 完全不知道 |
| 他的处理 | 自己解决了 | 没解决 |
| 她的后续 | 她去处理了 | 她忍住了 |

「她忍住了」比「她去处理了」难写，也更有分量。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她从别人嘴里听说这件事 | 「你不是有关系吗」 |
| 内心 | 他为什么不告诉我 | 一提她的名字，我就真成那种人了 |
| 好的处理 | 她问了，但没有立刻插手 | 他自己解决了，且事后也没邀功 |
| 写崩 | 写成她杀过去报复 | 写成他一味隐忍 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 同僚排挤／被指派苦差／有人当面提他的位份 |
| 修仙 | 同门欺压／资源被克扣／说他靠道侣 |
| 星际 | 被排除在任务外／有人查他的档案 |

#### 写崩的三种方式

1. 让她杀过去解决。 那这条就没发生过。
2. 让他从头忍到尾。 至少要有一次反击。
3. 让他打出她这张牌。 那是这条的红线。

## 二 · 她知道了

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：被欺负 25.0% ＋ 出面 14.0%

**骨架**｜她从别人那里知道了他受的委屈。而她的第一个问题是「他为什么不告诉我」。

#### 节拍链

别人说漏 → 她当天没提 → 想了一晚 → 「今天有人跟我说了件事」→ 「小事」→ 「以后可以跟我说」→ 下一次他说了

#### 时间轴

从知道到开口，她给自己留了一晚上。 当天不提，气头上的问法一定是审问；想了一晚，把「你为什么不告诉我」改写成「今天有人跟我说了件事」。这一晚的缓冲是她的修养，也是技术。「下一次他说了」隔了两个月，制度性变化的生效期就是这么长，写短了就假了。

#### 这条的双重伤害

| 伤 | 内容 |
|---|---|
| 一 | 他受了委屈 |
| 二 | 他没告诉她 |

第二重比第一重更让她难受，而这一点她通常不会直接说。

#### 她的四种反应

| 反应 | 效果 |
|---|---|
| 立刻去处理 | 会让他觉得自己更没用 |
| 质问他为什么不说 | 变成了他的错 |
| 什么都不说，暗中处理 | 被发现会更糟 |
| 问他「要我做什么吗」 | 最好 |

第四种是这一族的通用解法，与 [14 卷第十条](14-社交与公开.md#十--她替他挡) 同源：先问。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的得知 | 一个同事说漏 · 一份文件 · 她自己看出来了 |
| 她的克制 | 她当天没提 · 想了一晚上 |
| 她的开口 | 「今天有人跟我说了一件事」 |
| 他的反应 | 「小事」——这两个字是他的防线 |
| 落点 | 她说的不是「你怎么不告诉我」，而是「以后可以跟我说」 |

「以后可以跟我说」比「你怎么不告诉我」好一百倍。 前者是邀请，后者是指责。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的反应 | 出手 | 忍住 |
| 他的态度 | 说了 | 坚持说是小事 |
| 结果 | 他之后开始说了 | 他还是不说 |
| 长期 | 关系更实 | 他习惯性地屏蔽她 |

「他习惯性地屏蔽她」是这条最坏也最真实的走向，可以接 [04-委屈与破防 · 我是不是不够好](04-委屈与破防.md#九--我是不是不够好)。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听完之后没有当场发作 | 「小事」 |
| 内心 | 他不告诉我，是不是觉得我会小题大做 | 说了她就要出手，那我算什么 |
| 好的处理 | 她说「以后可以跟我说」 | 他说了下一次 |
| 写崩 | 写成她的怒火表演 | 写成他固执到底 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 下人回报／她从别处听说他挨了排揎 |
| 修仙 | 她神识扫过发现他有暗伤 |
| 星际 | 她调记录时看见了 |

#### 写崩的三种方式

1. 让她当场爆发。 忍一晚上更有力。
2. 用「你怎么不告诉我」开场。 那是指责。
3. 立刻解决。 她要先问。

## 三 · 他受伤了

`T` ｜ ⚠️暴力（低烈度）｜ 全谱系 ｜ 语料频次：受伤 52.0%（受伤＋上药＋生病为最高频三元组合）

**骨架**｜他带着伤回来。而她要先问「怎么弄的」还是先处理伤。

#### 节拍链

带伤回来 → 换手拿东西露了馅 → 她的顺序（先处理或先问）→ 上药 → 怎么弄的 → 不是实话 → 她提了她的条件

#### 时间轴

处理伤十分钟，处理谎一整晚。 上药的流程很快：清创、消毒、包扎，她手稳得像做过培训；「怎么弄的」问在包扎完之后，顺序是她的原则（先修人，再审案）。他的第一版说法当场被识破，真话在半小时后才挤出来；她的条件提在睡前，一句话，从此生效。

#### 顺序就是性格

| 顺序 | 说明 |
|---|---|
| 先问怎么弄的 | 她要先掌握情况。符合她，但会让他先撑住不能松 |
| 先处理伤 | 她的手先动。更暖，但她心里在问 |
| 一边处理一边问 | 最常见 |
| 什么都不问 | 最重——她已经猜到了 |

「什么都不问」这一版最好用，尤其当伤是为她受的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 伤的形态 | 淤青 ✓ · 破了皮 · 缝了几针 · 手上的 · 遮得住的位置 |
| 他的隐瞒 | 换了长袖 · 用没受伤那只手做事 · 说是自己撞的 |
| 破绽 | 一个动作卡了一下 · 拿东西换了手 · 洗澡时间变长 |
| 她的发现 | 撞见 · 或者她一直知道 |
| 处理 | 见 [01-日常照料 · 擦药与倒吸气](01-日常照料.md#七--擦药与倒吸气) |

#### 伤是怎么来的，四种

| 来源 | 关系含义 |
|---|---|
| 意外 | 无 |
| 工作 | 他的世界她进不去的那部分 |
| 为她打的架 | 最常见，也最需要处理 |
| 别人对他的伤害 | 转 [一 · 他被为难](#一--他被为难) |

「为她打的架」要小心。 这是最容易滑回传统脚本的一处：他用暴力保护她，等于用体力换回了男性位置。

处理方法：让那场架没赢，或者让她明确说这不是她要的。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 伤的来源 | 意外 | 为她 |
| 他说不说 | 说了 | 编了个理由 |
| 她的反应 | 心疼 | 生气（气他不惜身） |
| 后续 | 她处理了对方 | 她要求他答应下次不这样 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他换了只手拿杯子 | 别让她看见 |
| 内心 | 又是为我 | 我不想让她觉得我打不过 |
| 好的处理 | 她生气，但她先处理伤 | 他没有拿伤来邀功 |
| 写崩 | 写成她被英雄救美感动 | 写成他靠受伤换关注 |

#### 内容边界

本条涉及低烈度暴力（打架、擦伤）。写作时：

| 线 | 说明 |
|---|---|
| 不写可复现的伤害手法 | 交代后果，不做过程细节 |
| 不把暴力浪漫化 | 「为她打架」要有代价，不能只有奖励 |
| 严重伤害另走 | 重伤／医疗情节见 [09-分离与重逢 · 陪床](09-分离与重逢.md#四--陪床) |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他替她挡了行刺的一道；金疮药上到一半她问「谁的刀」，问完当夜点了兵 |
| 修仙 | 护山一战他伤了经脉还瞒着行功掩饰；她一搭脉就沉了脸，罚他闭关静养，自己搬进洞府外间守着 |
| 星际 | 训练舱数据造不了假：冲击伤记录她第二天例行调阅就看到了。他瞒了一晚，等于多瞒了一份日志 |

#### 写崩的三种方式

1. 让打架成为他的高光。 那是把传统脚本请回来了。
2. 让她因此更爱他。 她可以心疼，不能因此改变对他的评价。
3. 伤得太重。 重伤会把日常戏变成生死戏。

## 四 · 她受伤了

`T` ｜ ⚠️暴力（低烈度）｜ 全谱系 ｜ 语料频次：受伤 52.0%（女方向少见）

**骨架**｜这次是她。而他要面对一个他从没面对过的场面。

#### 节拍链

电话打来 → 他赶到 → 「你是家属吗」→ 签字 → 一件件处理 → 她醒来先问工作 → 「都处理了」→ 他事后才开始抖

#### 时间轴

他的钟在事发时停了，事后才恢复走动。 从接电话到医院的四十分钟他没有记忆（怎么打的车都想不起来）；签字、缴费、联系她助理，三小时高效运转，全程无情绪。她醒来后一切如常；他的抖是延迟到账的：当晚在医院走廊，独自一人时，手才开始不听使唤。前紧后崩的时间差，就是这条的写法。

#### 为什么这条必须写

她一直是处理问题的那个人。她受伤，意味着系统里唯一的处理者失效了，而他要顶上去。

这是这一族里最有价值的一条，也是最少被写的。

#### 他要做的四件事

| 事 | 难点 |
|---|---|
| 现场处置 | 他可能不会 |
| 通知谁 | 她的工作怎么办、家里怎么说 |
| 决策 | 她昏着，医生问他 |
| 陪着 | 见 [09-分离与重逢 · 陪床](09-分离与重逢.md#四--陪床) |

第三件最重。 一个从来不做决定的人，突然要替她做决定。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他的状态 | 手抖着签字 · 声音在电话里很稳（他自己都意外） |
| 他的能力 | 他其实知道她所有的事：血型、过敏源 ✓、她公司谁能联系 |
| 她醒来后 | 第一件事是问工作 · 他说「都处理了」 |
| 她的反应 | 愣住 · 她没想到他能处理 |
| 转折 | 她第一次意识到可以不用自己扛 |

「他其实知道她所有的事」是这条的高光。 那些他默默记下的细节，在这一刻全部变成了能力。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 严重程度 | 小伤 | 需要手术 |
| 他的表现 | 慌但顶住了 | 完全乱了（也真实） |
| 她的反应 | 感激 | 不习惯 |
| 之后 | 她开始交出去一些事 | 她很快恢复原样 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她醒来发现事情都办好了 | 医生问「你是家属吗」 |
| 内心 | 原来我可以不在场 | 现在只有我 |
| 好的处理 | 她说了谢谢，且是认真的 | 他做完之后才开始抖 |
| 写崩 | 写成她瞬间变小鸟依人 | 写成他一夜之间强大了 |

「他做完之后才开始抖」是这条最好的收尾。 撑住是当下的，垮是事后的。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她重伤／他主持府中事务／有人趁机发难 |
| 修仙 | 她受了内伤闭关／他守着洞府对付上门的 |
| 星际 | 她进医疗舱／他临时接管指挥 |

#### 写崩的三种方式

1. 让她瞬间变柔弱。 她受伤了，性格没变。
2. 让他一夜成长。 他的能力本来就在，只是没用过。
3. 忽略「他知道她所有的事」。 那是全条的地基。

## 五 · 一场架

`T` ｜ ⚠️暴力（低烈度）｜ 全谱系 ｜ 语料频次：吵架 15.0% ＋ 危险 18.0%

**骨架**｜真的动手了。而这场架里谁做了什么，会被记很久。

#### 节拍链

起因 → 动手（很快）→ 结束 → 挂彩与手续 → 她赶到 → 先处理事 → 再说这件事不对 → 代价结算

#### 时间轴

**动手十秒，代价按周偿还。** 架本身快得没有过程：起因、出手、结束，前后不到一分钟；之后的每一段都比它长，处理挂彩半小时、走手续两小时、她赶到后先办事再谈话又一晚。代价结算以周计（处分、赔偿、旧识圈的议论）。十秒对几周，这个比例本身就是她那句「这件事不对」的论据。

#### 三种配置

| 配置 | 说明 | 处理要点 |
|---|---|---|
| 他动手 | 最常见 | 要有代价，且她的态度要明确 |
| 她动手 | 少见，且很有效 | 她可能比他更利落 |
| 两人一起 | 最少写 | 配合本身就是关系的证明 |

「她比他更利落」这一版值得写。 在一个不假定女性会打架的默认里，她一记干脆的处理，比他挥十拳更有效。

#### 可用细节

| 类 | 内容 |
|---|---|
| 起因 | 有人动手在先 · 有人说了不该说的 · 护人 |
| 过程 | 短。真架很快 |
| 结果 | 谁挂彩 · 有没有闹到警局／族里／舰上 |
| 事后 | 笔录 · 赔钱 · 道歉 · 处分 |
| 关系 | 她怎么评价这件事 |

「事后」比「过程」重要得多。 打完之后的手续、代价、评价，才是这条的内容。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁动手 | 他 | 她 |
| 赢没赢 | 赢了 | 没赢（更好） |
| 她的态度 | 支持 | 明确说这不是解决办法 |
| 代价 | 无 | 处分／赔偿／她替他收拾 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她赶到时架已经打完了 | 打完之后手在抖 |
| 内心 | 他为什么要动手 | 我知道不该，但我控制不住 |
| 好的处理 | 她先处理事，再说这件事不对 | 他承认自己失控了 |
| 写崩 | 写成她为他的暴力骄傲 | 写成他打架很帅 |

「她为他的暴力骄傲」是这条的红线。 暴力可以发生，不能被奖赏。

#### 内容边界

同 [三 · 他受伤了](#三--他受伤了)：不写可复现的伤害手法，暴力要有后果，严重情节另走 [06-尺度与写法](../06-尺度与写法/)。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 街头有人辱她，他动了手；被带到堂上时指节还渗着血。她来得很快，先具保领人，出了衙门才说「这事不对」 |
| 修仙 | 同门讥她双修误道，他拔了剑；比斗有门规兜底，罚抄戒律三百遍。她没求情，只把伤药放在了戒律堂门口 |
| 星际 | 军营斗殴上军法记录，禁闭三日。她按程序探视，隔着观察窗一句话：「出来把手养好。账我记下了，走程序清。」 |

#### 写崩的三种方式

1. 把打架写成高光时刻。 见上。
2. 过程写太长。 真架很短。
3. 没有事后。 手续与代价才是这条的价值。

## 六 · 吵到最难看的时候

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：吵架 15.0%

**骨架**｜这次不是拌嘴。两个人都说了实话，而实话最难听。

#### 节拍链

小事起头 → 三个回合变成别的 → 音量一大一轻 → 双方说了真话 → 一句之后没人再说 → 摔门或坐下 → 各自那一夜

#### 时间轴

三个回合的升级只用十分钟，那句话之后时间冻结。 从小事到翻旧账到人身，每回合三分钟，音量一路走高；最难听那句出口后，屋里静了整整一分钟，这一分钟里谁都可以收手，谁都没收。之后的那一夜两个人各自睁眼到天亮，同一屋檐下两只失眠钟并行，这画面比吵架本身狠。

#### 与 [04-委屈与破防 · 说了狠话](04-委屈与破防.md#七--说了狠话) 的区别

那一条是他说了一句反话（他其实想要她留下）。
这一条是双方都说了真话，且真话正好是对方最怕听见的。

| 他说的真话 | 她说的真话 |
|---|---|
| 「你根本没把我当回事」 | 「我没时间哄你」 |
| 「我在这个家里算什么」 | 「这些年是谁在撑」 |
| 「你从来不问我怎么想」 | 「你想要什么，你说过吗」 |

注意这些话都是成立的，这才是它们伤人的原因。

#### 可用细节

| 类 | 内容 |
|---|---|
| 升级过程 | 从一件小事开始 · 三个回合内变成了别的事 |
| 音量 | 一个越来越大，一个越来越轻 |
| 停下的方式 | 一句话之后没人再说 · 或者有人摔门 ✓ 出去 |
| 那之后 | 屋里的东西保持原状很久 |
| 谁先动 | 通常是做家务的那个人先动（因为要吃饭） |

「一个越来越大，一个越来越轻」是这条最准的声音设计。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先失控 | 他 | 她 |
| 说的是不是实话 | 是 | 是气话 |
| 收场 | 有人走了 | 都留在原地 |
| 修复 | 当晚 | 几天后 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己在用工作时的语气 | 她说的是对的，这才最难受 |
| 内心 | 我不能输 | 我没有立场吵 |
| 好的处理 | 她后来承认自己说的那句过分了 | 他没有摔门走，他坐下了 |
| 写崩 | 写成她单方面碾压 | 写成他歇斯底里 |

「她发现自己在用工作时的语气」是这条最刺人的一笔。 把上司的语气带回家，是她最容易犯的错。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 当着下人吵／他跪下了但话没软／她摔了茶盏 |
| 修仙 | 灵压外泄／她的剑意惊动了整座山 |
| 星际 | 舱内警报因为声浪响了 |

#### 写崩的三种方式

1. 让她单方面碾压。 她口才好，但这场架不该赢。
2. 用摔门收场。 坐下来更难，也更好。
3. 当晚就和好。 至少留一夜。

## 七 · 和好的第一步

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：和好 35.0%（和好＋受伤、和好＋掉马高频同现）

**骨架**｜没有人道歉。但有人做了一件事。

#### 节拍链

僵持 → 有人做了一件小事（盛饭·递水·掖被）→ 功能性的第一句 → 第二句 → 日常恢复 → 那件事沉底或谈开

#### 时间轴

僵持以天计，破冰只要一个动作的时长。 第三天晚饭，有人多盛了一碗饭推过去，五秒钟的动作结束四天的僵局。功能性对话恢复在当晚（一句），正常对话恢复在次日（几句），玩笑恢复在第三天，解冻是分层的，每层隔一天。那件引发一切的事谈没谈开，决定这次冰冻是化了还是只是入了库。

#### 和好的语法：动作先于语言

这个类型的和好几乎从不靠一句「对不起」。原因是权力不对称让道歉变得别扭——她道歉像施舍，他道歉像认输。

于是和好靠动作：

| 动作 | 谁做 | 意思 |
|---|---|---|
| 做了饭 ✓ | 他 | 日常恢复 |
| 把他那份也盛了 | 她 | 你还在这个家里 |
| 递了一杯水 | 任一方 | 停战 |
| 半夜把被子 ✓ 给他掖上 | 她 | 我知道你没睡 |
| 早上照常倒了两杯水 | 任一方 | 习惯没断 |
| 剪指甲 | 见 [01 卷第九条](01-日常照料.md#九--剪指甲) | 需要靠近的理由 |

「照常倒了两杯水」是最省字的和好信号。

#### 可用细节

| 类 | 内容 |
|---|---|
| 时间 | 第二天早上 · 或者当晚三点 |
| 第一个动作 | 通常极小，且做的人假装是顺手 |
| 第一句话 | 功能性的（「盐在哪」） |
| 第二句话 | 这一句才是真的和好 |
| 那件事 | 通常不再被提起，或者很久以后才提 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先动 | 她 | 他 |
| 有没有道歉 | 有 | 没有 |
| 那件事 | 谈开了 | 绕过去了（会复发） |
| 修复程度 | 完全 | 表面 |

「绕过去了」要标出来。 绕过去的事会在下一次吵架时原样回来。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 桌上多了一副碗筷 ✓ | 她把我的那份也盛了 |
| 内心 | 我不会说对不起，但我可以做这个 | 她盛了，那就是过去了 |
| 好的处理 | 她做了动作，且没有解释 | 他接下了那个动作 |
| 写崩 | 写成大段和解对话 | 写成他等着被哄 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她叫他起来／赏了一样东西／让他坐到身边 |
| 修仙 | 她撤了禁制／传音过来一句无关的话 |
| 星际 | 权限恢复了／她把班排回了一起 |

#### 写崩的三种方式

1. 靠一场长对话和好。 动作先于语言。
2. 让道歉解决一切。 这个类型里道歉最难说得自然。
3. 每次都完全修复。 有几次要留残余。

## 八 · 她第一次求人

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：出面 14.0% 的反向

**骨架**｜她开口向他要一样东西。而这件事她从来没做过。

#### 节拍链

她想了很久 → 开口（极短）→ 他愣住 → 立刻答应，没问 → 事成或未成 → 她说了谢或没说 → 关系多了一个通道

#### 时间轴

开口只有一句话的时长，酝酿用了一个星期。 她把所有别的路都走了一遍（这是她的程序正义），全部走不通，才轮到「求」这个选项；开口选在一个普通的晚饭后，语气刻意平常。他答应用了一秒。事成之后她的「谢」拖了几天才说出口，那声谢比求还难，两个时长对比着写，她这个人就立住了。

#### 为什么这条是这一族的顶点

她不求人。这是她的性格，也是她的困境——从不求人的人，也从不给别人帮她的机会。

所以她开口的那一刻，给出去的是一个位置，不是一个请求。

#### 她求的四种，重量递增

| 求什么 | 重量 |
|---|---|
| 一件小事（帮我拿一下） | 轻，日常 |
| 陪我去一个地方 | 中 |
| 帮我处理一件我处理不了的事 | 重 |
| 别走 | 最重 |

「别走」两个字是这个角色能说出的最重的话，且它通常出现在全书的后段。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她的准备 | 她想了很久怎么开口 · 或者是脱口而出的 |
| 开口的方式 | 极短 · 不解释 · 不给理由 |
| 她的姿态 | 没有低头 · 这不是示弱，是委托 |
| 他的反应 | 愣住 · 然后立刻答应 · 甚至没问是什么事 |
| 事后 | 她说了谢谢 · 或者她什么都没说 |

「他甚至没问是什么事」是这条最好的一个反应。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她求什么 | 具体的事 | 「别走」 |
| 她的状态 | 冷静 | 熬不住了 |
| 他能不能做到 | 能 | 不能（更有戏） |
| 之后 | 她开始更多地求助 | 这是唯一一次 |

「他做不到」这一端是最难写的： 她终于开口了，而他帮不上。这一版的余味最长。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 开口之前那几秒 | 她在跟我说「你帮我」 |
| 内心 | 我从来不求人 | 她终于用得上我了 |
| 好的处理 | 她说得简短，且没有解释 | 他答应之后才开始想怎么办 |
| 写崩 | 写成她低头认输 | 写成他扬眉吐气 |

「她低头认输」和「他扬眉吐气」是这条的双雷。 这不是权力翻转，这是信任。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她开口托他一件事／把印信交给他 |
| 修仙 | 她请他护法／把本命交托 |
| 星际 | 她把指挥权临时交给他 |

#### 写崩的三种方式

1. 写成权力翻转。 求助不等于交出位置。
2. 让她说很多。 越短越重。
3. 让他趁机提条件。 那会毁掉这一刻。

#### 示例（本库自撰，可直接改写）

> 她站在门口，外套还没脱。
> 「你帮我一下。」
> 他从沙发上起来，手里的东西放下了：「什么事。」
> 「明天上午，你替我去一趟。」她说的就这么多，没有解释是什么事，也没有说为什么是他。
> 他没有问。
> 「行。」他说，「几点。」
> 她报了个时间，然后站在那儿没动。他这才发现她还没换鞋。

## 九 · 他能做到的那件事

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：出面 14.0% ＋ 危险 18.0%

**骨架**｜有一件事全场只有他能做。而这件事跟力气无关。

#### 节拍链

危机卡住 → 他知道自己能 → 没宣告就去做了 → 成了 → 她后来才知道 → 下一件也交给了他

#### 时间轴

危机卡住的那几天，他一声不响地在动。 别人急得团团转的七十二小时里，他消失了几个半天，没人注意，包括她。事成的消息传回来时，没人知道是他；她倒查出来用了一周。「下一件也交给了他」发生在几个月后，信任的续约不靠表态，靠下一次任务落到谁头上。

#### 这条是这一族的答案

前面八条都在处理「谁保护谁」的难题。这一条给出解法：不要比谁能挡，要给他一件只有他能做的事。

而且这件事不能是体力型的，否则又回到了传统脚本。

| 他能做的 | 为什么只有他 |
|---|---|
| 他认识那个关键的人 | 他的圈子她没有 |
| 他懂那门技术 | 他的专业 |
| 他能安抚某个人 | 他的耐心 |
| 他记得一个所有人都忘了的细节 | 他一直在留意 |
| 他敢做一件她的身份不允许她做的事 | 位置的互补 |
| 他能等 | 她做不到的那件事 |

最后两行最好。它们写的是位置互补，不是能力比较。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 一次危机 · 一次谈判 · 一件她处理不了的私事 |
| 他的出场 | 没有宣告 · 他只是去做了 |
| 她的反应 | 她后来才知道是他做的 |
| 旁人的反应 | 有人重新认识了他 |
| 落点 | 她没有夸他，她把下一件事也交给了他 |

「她把下一件事也交给了他」比任何夸奖都重。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她知不知道 | 当场知道 | 很久以后才知道 |
| 他说不说 | 不说 | 说了（也可以） |
| 难度 | 举手之劳 | 他付出了代价 |
| 之后 | 她开始依赖他这一块 | 一次性的 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现这件事是他办的 | 这件事我能办 |
| 内心 | 我从来不知道他还有这个 | 终于轮到我了 |
| 好的处理 | 她把下一件也交给他 | 他做完了不提 |
| 写崩 | 写成他突然开挂 | 写成他等着被认可 |

「他突然开挂」是这条最大的陷阱。 他的能力要在前文有过铺垫，哪怕只是一句。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他去说服了那个人／他懂她不懂的那一门／他替她跑了一趟 |
| 修仙 | 他的功法正好克制／他认得那个阵 |
| 星际 | 他熟悉那片星域／他能修那台机器 |

#### 写崩的三种方式

1. 让他的能力凭空出现。 前文要有伏笔。
2. 让他做的是体力活。 那会回到传统脚本。
3. 让他等着被夸。 做完不提才对。

## 十 · 一起扛

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：危险 18.0% ＋ 和好 35.0%

**骨架**｜这次不是谁保护谁。两个人各做各的，事情办成了。

#### 节拍链

事发 → 不用商量，各自去做 → 中途对视一眼 → 有人熬不住另一个顶上 → 结束 → 并排坐着，不说话

#### 时间轴

并行的两条行动线，同一个倒计时。 事发后没有分工会议，两人对视一眼各自出门，一个对内一个对外，进度靠深夜碰头对表（每晚十分钟，说的全是干货）。中途有人熬不住的那半天，另一个顶上，无缝。结束后并排坐着不说话的那二十分钟，是全书唯一一段两个人共享的、什么都不用做的时间。

#### 这条是全卷的收束

前九条都在处理保护的方向问题。这一条取消了这个问题：分工，而不是保护。

| 分工的形态 | 说明 |
|---|---|
| 她对外，他对内 | 最常见 |
| 她决策，他执行 | 符合原设定 |
| 他挡在前面，她在后面调度 | 少见，但成立 |
| 各管一半，中途换手 | 最好 |

「中途换手」是这条的最高形态。她熬不住的那一段他顶上，他熬不住的那一段她顶回来。

#### 可用细节

| 类 | 内容 |
|---|---|
| 事件 | 家里出事 · 一场危机 · 一个必须两个人才能完成的事 |
| 分工 | 不需要商量，各自去做了 |
| 中间 | 有一个时刻他们同时看向对方 |
| 疲惫 | 谁先熬不住 · 另一个人怎么接 |
| 结束 | 两个人坐在同一个地方，谁都没说话 |

「不需要商量，各自去做了」是这条最好的一句描写。 默契比配合更能说明关系。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 结果 | 办成了 | 没办成，但一起挺住了 |
| 分工 | 明确 | 中途换过 |
| 之后 | 关系更实 | 两人都累到不想说话 |
| 谁先熬不住 | 她 | 他 |

「没办成，但一起挺住了」这一端更值得写。结果不重要，一起才重要。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她回头发现那一块他已经处理完了 | 这一块交给我 |
| 内心 | 不用交代他就知道 | 她那边我不插手 |
| 好的处理 | 她没有检查他做得对不对 | 他没有等她安排 |
| 写崩 | 写成她指挥他执行 | 写成他抢着表现 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她在外周旋他在内稳住／族中变故两人分头处置 |
| 修仙 | 她挡正面他护阵眼／双修共渡一劫 |
| 星际 | 她指挥他驾驶／舰体受损两人分头抢修 |

#### 写崩的三种方式

1. 写成她指挥他执行。 那还是单向。
2. 让分工需要长篇商量。 默契更好。
3. 结尾大段总结感情。 坐在一起不说话就够了。
