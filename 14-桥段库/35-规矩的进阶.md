### 三条社群共识

| 缩写 | 全称 | 含义 |
|---|---|---|
| SSC | Safe, Sane, Consensual | 安全、理智、双方同意 |

三者是社群在不同年代提出的框架，共同点是**同意必须是知情的、可撤回的、由具备判断能力的成年人做出的**。

### 虚构与现实的分界

小说里的权力交换是**幻想装置**：它服务于关系张力，运行在作者控制的、后果可控的世界里。**它不是现实指南。** 现实中的实践需要事前协商、安全词、可随时中止的机制与对风险的真实认知；本卷写的协商与安全词是叙事结构，不是操作教程。全员成年，无一例外。规矩与控制的判据表见 [08-规训日常版 · 规矩的边界](08-规训日常版.md#十--规矩的边界)。

## 一 · 项圈的日常等价物

`T` ｜ ⚠️主奴（符号层） ｜ 全谱系 ｜ 标签基数：`主奴` 59 篇、`调教` 164 篇（10-藏书索引/文案标签统计）

**骨架**｜collar在日常里的叫法，手链、表、围巾、工牌。戴上是一个身份，摘了是另一个身份。

#### 为什么要化名

项圈这东西，在大多数世界里根本没法戴出门。说白了，化名要解决的就是一件事：归属感得让人看见，但只让那两个人看见。外人看着就是块表，他自己心里清楚戴的是什么。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 挑东西。她逛了半天，就一个要求：普通到谁都不会多看一眼 |
| 2 | 送出去。她亲手给他戴上，扣搭扣的是她，这动作跟花出去的钱一样要紧 |
| 3 | 说好。什么时候能摘，洗澡、体检、过安检，摘了放哪儿 |
| 4 | 处久了。他开始不自觉地摸它，充电、上弦、换表带，成了俩人每天一起做的事 |
| 5 | 有人问。「新表？」他回「她给的」，没说错，也没说全 |
| 6 | 摘下来那次。吵架时他当面摘了，或者她直接收回去 |
| 7 | 再戴回去。谁先提的、怎么又戴上的，跟第 2 拍对着写 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 等价物谱系 | 手链最贴身，离项圈最近 · 机械表每天得上弦，跟日课似的 · 围巾她亲手围，就那几个月能戴 · 工牌绳她把他原来那根换掉了 · 尾戒 |
| 授予动作 | 她绕到他身后扣搭扣 · 试松紧时问「勒不勒」· 收走包装盒，这事就算定了 |
| 日课 | 每晚摘下放进同一个盘子 · 出差忘带那次，俩人谁都没睡踏实 |
| 摘下的语义 | 自己摘＝闹脾气 · 被收回＝降了 · 换新＝接着处 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 可见度 | 明戴，答得坦荡 | 暗戴，衣领底下 |
| 谁提出 | 她给的 | 他自己开口要的，分量更重 |
| 摘下史 | 从来没摘过 | 摘过一回，俩人都记着那天 |
| 物的来历 | 新买的 | 她戴旧了的那件，传下来的，最重 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 扣搭扣时他绷直的后颈 | 金属贴上皮肤那一秒的凉 |
| 内心 | 他会不会觉得我太过了 | 别人问起时那点偷偷的得意 |
| 好的处理 | 她把什么时候能摘先讲明白 | 他摘下来时比戴上去还小心 |
| 写崩 | 写成显摆贵重礼物 | 写成脖子上拴链子自怨自艾 |

#### 写崩的三种方式

1. 写成送礼。 没有授予、约定、日课这三件，它就退回成 07 卷的礼物条目。
2. 让旁人识破。 这玩意儿全靠只有两个人能对上暗号，第三个人一看穿，戏就没了。
3. 只写戴不写摘。 可以摘，摘过，又戴回来，那才是心甘情愿。焊死的叫枷锁。

## 二 · 协商桌

`T` ｜ ⚠️训诫（协商层） ｜ 全谱系 ｜ 写法出处：`negotiation`（事前协商），06-04 §八共同底盘第①件

**骨架**｜第一次把话说明白的那晚，怎么谈的，比谈成啥更重要。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 借口。直说太难，谁都得找个台阶：一篇转发的帖子、一部剧、一句「有个问题」 |
| 2 | 冷场。开了头之后的三十秒，谁都没接话 |
| 3 | 报价。先报小的试试水，「以后我说停就停」，大的压在后头 |
| 4 | 红线。先谈不要什么，不要什么，比要什么实在 |
| 5 | 讨价。她要的和他能给的对不上的那几条，摆出来 |
| 6 | 搁置。谈不拢的记下来，注明三个月后再谈。能搁置，说明谈的是真事 |
| 7 | 生效。没有签字，只有那晚之后第一次有人说「按说好的来」 |

#### 时间轴

**一晚谈不完是正常刻度。** 第一晚只够立红线，细则散在之后几周的饭桌和车里，一次补一条。一次谈全的协商是台词汇报，分期的协商才是关系在生长。

#### 可用细节

| 类 | 内容 |
|---|---|
| 跳板道具 | 转发的帖子（「你看这人写的」）· 匿名论坛截图 · 半杯酒（壮胆，不能多）· 关了灯再开口 |
| 谈的姿势 | 不面对面，并排坐 · 各自盯着桌面 · 他把杯子转了很多圈 |
| 红线的说法 | 「这个不行」不解释也成立 · 解释过的红线，原话得记住 |
| 记录 | 备忘录 · 手账最后一页 · 什么都没记，但都记得 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁发起 | 她怕吓着他 | 他攒了很久的勇气 |
| 载体 | 文字，先发长消息 | 当面，更难，更重 |
| 细到什么程度 | 只立三条 | 细到称谓与时段 |
| 结果 | 一次谈成 | 第一轮谈崩，隔周重开，崩过的那版更扎实 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他说「这个不行」时她心里松了一下 | 开口提第一个要求前，那口憋着的气 |
| 内心 | 原来他真琢磨过，不是顺着我说 | 说少了怕亏，说多了又怕她瞧不上 |
| 好的处理 | 她把自己那条线也亮出来 | 他头一个要求小得让人鼻子发酸 |
| 写崩 | 写成她拿着表挨个问 | 写成他啥都点头的认怂书 |

#### 写崩的三种方式

1. 一晚谈完所有。 商量是细水长流的事，一次全谈妥，那不成签合同了？
2. 只有她在问。 光一个人问，那是面试。他也得有要求，哪怕就一条，也算双向奔赴。
3. 谈完当场就全做了。 谈归谈，做归做，中间那段时间的拉扯，才是后面十场戏的命根子。

## 三 · 安全词

`T` ｜ ⚠️训诫（叫停机制） ｜ 全谱系 ｜ 写法出处：`safeword`（安全词），06-04 §八共同底盘第②件

**骨架**｜选出来那天它只是个词，真被人用了一回，才算数。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 选词。标准：平时打死不会说，喊出来不许笑场，然后两个人笑了半小时 |
| 2 | 分档。红黄绿三档，红＝马上停，黄＝缓一缓，绿＝接着来，记进两个人的词库 |
| 3 | 挂着不用。几个月过去，它像灭火器一样落灰 |
| 4 | 被用的那次。用在一个特别小的场合，小到她愣半秒才反应过来 |
| 5 | 马上停。她停得比任何承诺都快，这半秒里的事决定后面所有事 |
| 6 | 停下之后。先递水，先给毯子，先问「现在要啥」，最后才轮到为什么 |
| 7 | 复盘与回归。词回到日常，从此他真的敢用了 |

#### 时间轴

从选词到首次使用隔得越久，那一停就越重。首次用之前，这个词的效力只是理论值。用过之后，每一场戏都换了地基。他知道门一直开着，才敢往里走。

#### 可用细节

| 类 | 内容 |
|---|---|
| 词的选型 | 水果跟菜名（群里老规矩）· 某个地名 · 他小时候养的狗叫啥（一喊她就难受） |
| 说不出话时 | 约好手势：拍两下 · 手里攥的东西松开（掉了就停） |
| 立停动作 | 手上事全停 · 灯打开 · 先递水和毯子，再问话 |
| 事后 | 那词当晚不提 · 第二天她问「昨天那条，是改，还是删」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁用的 | 他 | 她，安全词两边都能用，她也能喊停 |
| 用在哪 | 办事的时候 | 平时过日子，家宴上他小声说了那词，她立马拉他走人 |
| 用了之后 | 规矩直接作废 | 改一改，接着用 |
| 词的走向 | 只在办事时用 | 混进日常，成了俩人专用的暗号 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 听到那个词，手先停，脑子后到 | 说出口前，他咽了三次 |
| 内心 | 他终于用了，说明他终于信了 | 用了怕扫兴，不用撑不住 |
| 好的处理 | 停完不追问原因，只处理当下 | 他后来主动解释那晚为什么喊停 |
| 写崩 | 写成她被冒犯 | 写成拿叫停当撒娇 |

#### 写崩的三种方式

1. 她犹豫了一秒。安全词这东西，说好了就是无条件生效，她这一秒没接上，整套规矩就白定了。
2. 全篇没人喊过。光挂着不用，那叫道具，真喊出来一次，才叫规矩。至少得安排一回真触发。
3. 别跟求饶混一块儿写。求饶可以不理，见 08 卷求情条。但安全词不行。这条线得让读者看清楚。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 说好的一个字 · 摔杯子就算数 · 枕下玉扣搁桌上就是停 |
| 修仙 | 传音玉符捏碎就停 · 一道说好的灵力波纹 |
| 星际 | 紧急频道按个码 · 手环敲两下 |

#### 示例（本库自撰，可直接改写）

> 「杨梅。」
> 声音不大。她正要说的话停在喉咙里，半秒，手先松开了。
> 灯打开。水递过去。毯子搭上他肩膀的时候，她还什么都没问。
> 「不问为什么。」她说，「先说现在要什么。」
> 他捏着杯子，过了一会儿说：「就坐一会儿。」
> 那晚这个词没有再出现。隔了一天她才问：昨天那条，是改，还是删。

## 四 · 事后照护

`T` ｜ ⚠️训诫（场后） ｜ 全谱系 ｜ AO3 `Aftercare` 90,099 篇，全圈通用词汇（06-04 §7.3 实测）

**骨架**｜戏散场之后，水、毯子、聊两句，把状态找回来。这是维护，不算奖励。

#### 与 08 卷「罚完之后」的分界

[08-规训日常版 · 罚完之后](08-规训日常版.md#九--罚完之后) 写低烈度责罚后的十分钟，靠她临场发挥。这条写**成套的例行程序**：有清单、有顺序、有存货，像消防演习一样被两个人排练过。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 收尾信号。一句固定的话或一个动作，告诉大家戏演完了 |
| 2 | 先管身体。水、糖、毯子、体温，顺序提前排好 |
| 3 | 安静待一会儿。几分钟不说话，让他自己慢慢缓过来 |
| 4 | 称呼换回来。从戏里的叫法换回名字，看谁先开口 |
| 5 | 聊三句：现在感觉咋样 · 刚才哪段最舒服 · 下次哪里得调 |
| 6 | 她也得被照顾。给她也倒杯水，她的手其实也在抖，这步最少人写 |
| 7 | 回到日常。各干各的，话题落到晚上吃什么 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 存货 | 床头柜那个抽屉：巧克力 · 电解质水 · 薄毯 · 暖贴 |
| 复位的话 | 先喊名字 · 「回来了？」· 他答非所问也不掰扯 |
| 双向的证据 | 她喝水的手 · 那句「我刚才也紧张」说出来有多难 |
| 清单迭代 | 第 N 版清单上划掉的东西，他其实不爱巧克力，改成温豆浆 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 建制程度 | 即兴 | 清单钉在抽屉内侧 |
| 方向 | 她照护他 | 互相，她那份由他执行 |
| 他要的类型 | 要说话 | 要安静，问出他要哪种，本身是一场戏 |
| 时长 | 十分钟 | 后劲长的场次留整晚 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他身子暖回来，她攥着的手才松开 | 毯子一压下来，心里那点空就填上了 |
| 内心 | 她老怕漏了哪一步，翻来覆去数 | 散场了还有人要，这事他没想到 |
| 好的处理 | 她连自己那杯水都算进安排里 | 有一回他倒先递了水过来 |
| 写崩 | 写成哄孩子 | 写成白吃白喝还嫌不够 |

#### 写崩的三种方式

1. 用亲密升级替代照护。 06-04 幻想装置清单第⑧条点了名：拿宠爱占这个位置，照护就永远缺席。
2. 每次流程一模一样。 清单要迭代，划掉的项目比新增的更能证明她在看他。
3. 只照护他。 她也从场里出来，她那杯水没人递，写了这一笔，关系才是双人的。

`T` ｜ ⚠️训诫 △虐心 ｜ 全谱系 ｜ AO3 `Subdrop` 5,363 篇，中文圈几乎空白（06-04 §7.3、§7.5）

**骨架**｜subdrop，就是高强度场景结束后几小时到几天情绪崩了，两场戏中间他一个人扛着，她发现时已经晚了。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 事办完了，人也哄好了，大家都觉得这页翻过去了 |
| 2 | 第二天下午他开始不对劲：饭点不饿，消息回得慢半拍 |
| 3 | 自己心里犯嘀咕：我咋会想要那个，她是不是觉得我挺没劲 |
| 4 | 装。照常上班、照常说晚安，演得挺像，隔着屏幕她看不出来 |

| 7 | 补救加预防。这回靠抱，下回靠规矩：场后四十八小时得打个卡 |

#### 时间轴

塌陷是有延迟的，这条戏全靠这个延迟。当天夜里是安全的，落差在第二十四到七十二小时之间到货。她的发现必须晚，晚到他已经独自撑过了最深那段，她的愧疚才有分量，预案才立得起来。

#### 可用细节

| 类 | 内容 |
|---|---|
| 可见信号 | 回复变短 · 取消了健身 · 冰箱里她备的菜没动 · 澡洗了很久 |
| 他的内语 | 那不是我 · 她现在怎么看我 · 下次她还会要我吗 |
| 她的发现渠道 | 消息长度曲线 · 他没发的那条日常照片 · 说不出理由的直觉 |
| 预案工具 | 场后 48 小时各发一次一到十分自评 · 只在低落时用的暗号 · 提前写好的信，封皮注明「难受的时候拆」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 延迟 | 一天 | 三天，拖得越久事越大 |
| 谁先说破 | 她发现 | 他自己按预案发了求救，成长后的版本 |
| 她那侧 | 她没事 | 她也不好受，俩人隔着两地各自崩，最扎心的一版 |
| 之后 | 立了预案 | 只收拾了这次，下回还得犯，埋个长线 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 那句「我没事」越说越短 | 天黑了也懒得开灯的那个傍晚 |
| 内心 | 照顾我一样没落下，怎么还是不对 | 这委屈讲出来，倒像在怨她 |
| 好的处理 | 她来了不急着问，先挨着坐下 | 他把打好的那个「三」发了出去 |
| 写崩 | 写成她做错了事挨批 | 写成耍性子等人哄 |

#### 写崩的三种方式

1. 写成闹别扭。低落是身体的事，不是冲着她来的。写成赌气，这条就废了。
2. 当天就被发现。拖延是骨架，没了拖延，「独自经历」这个核心就没了。
3. 一次大哄了结。这条的收尾靠的是预案，不是抱一下。抱一下只能了结眼前这一回，预案管的是往后每一回。

#### 示例（本库自撰，可直接改写）

> 周三下午，他在茶水间对着微波炉站了两分钟，忘了自己热的是什么。
> 手机上她问晚上吃什么。他回了个「都行」。
> 前天晚上一切都好，好到他睡前还在笑。
> 摔下来是从今天早上开始的，没有原因，像退潮，露出一片他自己都不认识的滩涂。
> 晚上八点，门响。她进来没开灯，摸黑在他旁边坐下，隔了一会儿说：「打个分。」
> 「三。」他说。
> 「嗯。」她说，「三就三，我在这儿。」

`T` ｜ 无预警 ｜ 全谱系 ｜ AO3 `Praise Kink` 173,436 篇，为 `Femdom`（33,088）的 5.2 倍（数据注于 [04-人设原型/01-女主原型谱](../04-人设原型/01-女主原型谱.md) §八）

#### 为什么难写一个量级

责罚本身自带一套流程：犯规、执行、收尾。但夸奖没有流程，只有节奏。写砸了也不是一回事。罚写过头是失控，夸写太多是通胀。贬值是慢慢来的，作者往往根本感觉不到。

#### 节拍链

|---|---|

| 3 | 他开始围着那句话做事，自己没察觉 |
| 4 | 通胀警报：她随口夸多了，他的耳朵开始不灵了 |
| 5 | 她建节律：随口、专注、公开分成三档，专注档限量 |
| 6 | 不夸的那天。他交上来一件明显该夸的事，她只说了「嗯」 |
| 7 | 他问出那句「今天怎么了」。夸奖这事第一次被挑明，两个人聊了它 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 三档夸法 | 随口手上忙着别的事带一句 · 专注，停下来，看着他说整句 · 公开，当着第三人的面，一年也就几回 |
| 夸的对象 | 夸他做的事、做的选择（「你先问了我，这点很好」），别老夸长相和天生的东西，人靠这个长成什么样 |
| 载体 | 就那两个字 · 顺手揉一下头发 · 消息里单独发一行「很好」 |
| 通胀信号 | 他听到夸不再抬头 · 她一天说了七回「不错」，自己都没数过 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 公开度 | 只有他俩知道 | 当着人随口一句，他能记一个月 |
| 他的耐受 | 听不得夸，会躲，夸他像拿灯晃他 | 明着要夸（接 brat 那条） |
| 撤温 | 罚他，有由头 | 不是故意的，她就是累了，这个更难受，他能自己琢磨三天 |

| | 四爱女笔下 | 四爱男笔下 |

| 内心 | 夸少了亏他，夸多了这话就没劲了 | 为一句话较劲，丢不丢人，丢人，但想要 |
| 好的处理 | 她夸人心里有数，他察觉不到那本账 | 他学着夸回去，笨拙但句句都对着她做的事 |
| 写崩 | 写成敷衍的彩虹屁 | 写成夸两句就飘了 |

#### 写崩的三种方式

1. 高频滥发。 夸奖这东西，发多了就不值钱。整篇都是「真棒」，等于钱印多了变废纸。第 4 拍防的就是这个。
2. 只夸天赋。 「你真聪明」夸不到点子上，行为不会变。得夸他具体做了啥选择，人物才跟着长。
3. 撤温写成冷暴力。 撤温得有原因、有期限、有解除动作，三样缺一样，她就从主导变成施冷的那一方了。具体见 06-04 §7.2③。

## 九 · 边缘的零尺度版

| 线的三型 | 时间线（门禁、倒计时）· 动作线（到手腕为止）· 称谓线，那个字不许叫出口 |
| 计量工具 | 一首歌的长度 · 电梯从 18 楼到 1 楼 · 红灯读秒 · 呼吸的次数 |
| 停的写法 | 停在动作的上升沿，不写下降沿 · 转场去洗手池、阳台、冰箱 |
| 账本 | 两个人都在记次数，谁都不承认在记 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁握着线 | 她说了算 | 两个人商量着来（接协商桌） |
| 出口 | 定好了日子，这根线有到期那天 | 一直吊着，危险：读者会跑，总得有个了断 |
| 破防方 | 他先撑不住 | 她先规矩她定的，结果她先犯，这版最好看 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 停下来的那一下，她自己心跳成什么样 | 线里头最后一毫米是热是凉 |
| 内心 | 线是我定的，凭什么受罪的也是我 | 她到底有没有数到我数的那个数 |
| 好的处理 | 她把线往回挪了一寸，罚自己没守住 | 他喊停那一回，她看他的眼神不一样了 |
| 写崩 | 写成钓鱼一样吊着人 | 写成比谁能忍的苦修比赛 |

#### 写崩的三种方式

1. 过线。 过线一次这条就结束了，后续归 06 卷，零尺度版的命根是那条线完好。
2. 不计量。 读者感受不到「更近了」，边缘就退化成普通暧昧，数字是这条的血。
3. 无限悬置。 只逼近，从来不真到，四十章之后读者就不等了，到期日要在文里存在，哪怕只有两个人知道。

## 十 · 契约的签订与到期

`T` ｜ ⚠️主奴（契约符号层，无过程描写） ｜ 全谱系 ｜ 套路对应：[05-剧情套路/01 · 契约关系](../05-剧情套路/01-经典套路库.md)

**骨架**｜白纸黑字。签订是仪式，履行是日常，到期是审判。

#### 先立一条

关系契约在现实里没有法律效力，它的全部效力来自双方认领。这一点要写进故事里，让角色知道这张纸随时能撕，他们还是选择签，这个动作才有分量。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 起意。口头规矩攒到第九条，版本记混了，有人提议写成白纸黑字 |
| 2 | 起草。谁动笔、照着什么改、改到第几稿 |
| 3 | 逐条谈。每一条背后都出过事，条文就是伤疤的大名 |
| 4 | 她加的那条。管她自己的：撤温不过夜、罚前必须问原因 |
| 5 | 终止条款。「任一方可随时终止」写在最末，字最小，分量最重 |
| 6 | 签。日期、两个名字、一式两份，各自收进抽屉 |
| 7 | 履行期。纸进抽屉，条款进身体，半年没人再翻 |
| 8 | 到期日。谁先想起的，续签时改的那几笔，就是这半年的账本 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 条款类型 | 称谓条 · 时间条，几点之后归她管 · 物品条，那条手链的地位 · 例外条，生病奔丧全部暂停 · 终止条 |
| 签署道具 | 那支笔（此后专用）· 打印店老板多看的那一眼 · 骑缝的两个指印，玩笑着按的，按完都没笑 |
| 履历痕迹 | 空白处的铅笔批注 · 某条被划掉又描回来 · 复印件的折角 |
| 到期处理 | 原样续签 · 改三条再签 · 不续，关系升级成不需要纸的版本，或者结束 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 文本形态 | 手机备忘录互相传 | 打印装订，郑重这事看人，拿它逗乐就亏了 |
| 期限 | 先试三个月 | 正经处一年 |
| 到期走向 | 接着续 | 不续了，换戒指，约定换一种形式 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 写终止条款时她停笔最久 | 签名前他把全文又读了一遍，第 4 条读了两遍 |
| 内心 | 白纸黑字会不会吓着他 | 有纸押着，反而睡得着了 |
| 好的处理 | 终止条款是她主动写的 | 到期那天是他先提的续签 |
| 写崩 | 写成霸总的卖身合同 | 写成他含泪画押 |

#### 写崩的三种方式

1. 写成法律文书。它的效力在情感层，文本得心里有数，写成能上法庭的合同，越界又失真。
2. 没有终止条款。不可退出的契约，按 [08-规训日常版 · 规矩的边界](08-规训日常版.md#十--规矩的边界) 的判据，已经是控制。
3. 签完即忘。到期日才是正文，不写到期，契约只是道具，写了到期，契约就成了日历。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 婚书外另立的私约 · 妆匣底下压的字据 · 对牌掰成两半 |
| 修仙 | 道侣契上添的条款 · 心口的契印，日子一到自己就淡，想续得再画一回 |
| 星际 | 两边都签的加密协议 · 一到日子就弹窗问「续不续」 |

## 十一 · 规矩失效期

`T` ｜ ⚠️训诫 △虐心 ｜ 全谱系 ｜ 场景关联：[01-日常照料](01-日常照料.md)（病）· [13-家庭与亲属](13-家庭与亲属.md)（丧）

**骨架**｜他生病、回老家奔丧、又赶上大考，那几天规矩全停了。停摆让俩人看清了规矩底下压着的是啥。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 事发。烧到三十九度、外婆打电话来、进考前封闭月 |
| 2 | 她放话：「这段时间没规矩。」这话一说出口，本身就是立规矩 |
| 3 | 他反倒慌了。规矩撤掉的头一晚，他十一点半还醒着，不知道几点该睡 |
| 4 | 他偷偷照旧。没人管他，他还是十一点关灯，药也按她定的点吃 |
| 5 | 她看在眼里，没吭声。那几条他自己守着的，她心里记了数 |
| 6 | 底子露出来。守灵夜他攥着她的手说「明天几点叫我」，规矩没了，托付还在 |
| 7 | 恢复那天。他先开口问「什么时候恢复」，恢复得有个仪式，哪怕只是她重新替他把手链扣上 |

#### 时间轴

失效期多长，事情说了算；什么时候恢复，他说了算。病，一周；丧，四十九天；考，一季。她就守一条：宁可他晚点开口，也不主动提前。他先提，规矩才算他立的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 宣布方式 | 一句话 · 把契约收进更深的抽屉 · 那几天她只发「吃了吗」「睡吧」 |
| 他自发维持的 | 熄灯时间 · 吃药点 · 那声固定的「我到了」，安全汇报最后不做了 |
| 她的暗账 | 哪几条他守了、哪几条真放了，两张名单她都记着，一个字没提 |
| 恢复仪式 | 重新扣上手链 · 契约放回浅抽屉 · 她又说回那句熟悉的口头禅 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 事由 | 病（身体撑不住了） | 丧，心撑不住了，停得更久也更轻 |
| 他的反应 | 照旧，规矩早成了习惯 | 真全放下，也行：说明规矩本来就紧，恢复时得松一松 |
| 恢复 | 他先开口要 | 她试着给，他接住了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 说「没有规矩」那句时他眼里闪过的慌 | 空荡的十一点，手在台灯开关上停了停 |
| 内心 | 规矩一停，我手里还剩啥能给她 | 原来不是怕她管，是怕没人管 |
| 好的处理 | 她从头到尾没查过，就是天天陪着 | 丧期第七天他说：手链帮我戴回去吧 |
| 写崩 | 写成停罚期照样扣钱 | 写成他松口气似的撒欢 |

#### 写崩的三种方式

1. 暂停期照罚。大考前一天还罚站，规矩就成了她的需要，失效期是规矩的体检，也是她的。
2. 他毫无失重。骨架抽走连一晚失眠都没有，说明规矩从未进入他，前面的铺垫全数塌方。
3. 悄悄恢复。哪天恢复的都说不清，等于告诉读者规矩可有可无。恢复日要有日期、有动作、有一句话。
