## 一 · 项圈的日常等价物

`T` ｜ ⚠️主奴（符号层） ｜ 全谱系 ｜ 标签基数：`主奴` 59 篇、`调教` 164 篇（10-藏书索引/文案标签统计）

**骨架**｜`collar`（项圈：社群里归属关系的头号符号）在日常里的化名：手链、表、围巾、工牌。戴上是一场戏，摘下是另一场。

#### 为什么要化名

项圈本体在多数世界里没法出街。化名解决的是同一件事：归属要可见，但只对两个人可见。旁人看到的是一块表，他知道自己戴着什么。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 选物。她挑了很久，标准只有一条：日常到没人会多看一眼 |
| 2 | 授予。她亲手给他戴上，扣搭扣的是她，这个动作与买它的钱同样重要 |
| 3 | 约定。什么时候可以摘（洗澡、体检、安检），摘下放哪 |
| 4 | 磨合。他开始下意识地摸它；充电、上弦、换表带成了两个人的日课 |
| 5 | 旁人问起。「新表？」他答「她送的」，一句没说错，一句没说全 |
| 6 | 摘下的那次。吵架时他当着她的面摘了，或者她收回了 |
| 7 | 重新戴上。谁提的、怎么戴回去的，与第 2 拍对照着写 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 等价物谱系 | 手链（最贴身，离项圈最近）· 机械表（自带上弦这个日课）· 围巾（她亲手围，季节限定）· 工牌绳（她换掉了他的默认款）· 尾戒 |
| 授予动作 | 她绕到他身后扣搭扣 · 试松紧时问「勒不勒」· 收走包装盒（仪式完成的标点） |
| 日课 | 每晚摘下放进同一个盘子 · 出差忘带的那次两个人都没睡好 |
| 摘下的语义 | 自己摘＝抗议 · 被收回＝降级 · 换新＝续约 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 可见度 | 明戴，答得坦荡 | 暗戴，衣领之下 |
| 谁提出 | 她授予 | 他自己求的（分量重一级） |
| 摘下史 | 从没摘过 | 摘过一次，两个人都记得日子 |
| 物的来历 | 新买的 | 她自己戴旧的那件（传承式，最重） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 扣搭扣时他绷直的后颈 | 金属贴上皮肤那一秒的凉 |
| 内心 | 他会不会觉得这个太过了 | 别人问起时那点隐秘的得意 |
| 好的处理 | 她把「可以摘的场合」先说清楚 | 他摘下时比戴上时更小心 |
| 写崩 | 写成贵重礼物的炫耀 | 写成脖子上的锁链自怜 |

#### 写崩的三种方式

1. 写成送礼。 没有授予、约定、日课这三件，它就退回成 07 卷的礼物条目。
2. 让旁人识破。 符号的全部电压来自只有两个人接得通电，第三人看懂即短路。
3. 只写戴不写摘。 可以摘、摘过、又戴回来，归属才是自愿的；焊死的那种叫枷锁。

## 二 · 协商桌

`T` ｜ ⚠️训诫（协商层） ｜ 全谱系 ｜ 方法论来源：`negotiation`（事前协商），06-04 §八共同底盘第①件

**骨架**｜第一次把要什么说清楚的那一晚。谈的姿态比谈成的条款重要。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 借口。直说太难，谁都要个跳板：一篇转发的帖子、一部剧、一句「有个问题」 |
| 2 | 冷场。开了头之后的三十秒，谁都没接 |
| 3 | 报价。先报小的试水（「以后我说停就停」），大的压在后面 |
| 4 | 红线。先谈不要什么；不要什么，比要什么诚实 |
| 5 | 讨价。她要的和他能给的对不上的那几条，摆着 |
| 6 | 搁置。谈不拢的记下来，注明三个月后再谈；能搁置，说明谈的是真的 |
| 7 | 生效。没有签字，只有那晚之后第一次有人说「按说好的来」 |

#### 时间轴

**一晚谈不完是正常刻度。** 第一晚只够立红线；细则散在此后几周的饭桌与车里，一次补一条。一次谈全的协商是台词汇报，分期的协商才是关系在生长。

#### 可用细节

| 类 | 内容 |
|---|---|
| 跳板道具 | 转发的帖子（「你看这个人写的」）· 匿名论坛截图 · 半杯酒（壮胆用，不能多）· 关了灯再开口 |
| 谈的姿势 | 不面对面，并排坐 · 各自盯着桌面 · 他把杯子转了很多圈 |
| 红线的说法 | 「这个不行」不解释也成立 · 解释了的红线要被记住原话 |
| 记录 | 备忘录 · 手账最后一页 · 什么都没记，但都记得 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁发起 | 她（怕吓着他） | 他（攒了很久的勇气） |
| 载体 | 文字（先发长消息） | 当面（更难，更重） |
| 颗粒度 | 只立三条 | 细到称谓与时段 |
| 结果 | 一次谈成 | 第一轮谈崩，隔周重开（崩过的那版更扎实） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他说「这个不行」时她心里松了一下 | 说出第一个要求前的那口气 |
| 内心 | 原来他认真想过，没在顺着我 | 说少了亏，说多了怕她看轻 |
| 好的处理 | 她把自己的红线也摆上桌 | 他的第一个要求小得让她鼻酸 |
| 写崩 | 写成她主持的问卷调查 | 写成他全盘接受的投降书 |

#### 写崩的三种方式

1. 一晚谈完所有。 协商是持续动词，一次性谈全等于把关系写成签约仪式。
2. 只有她在问。 单向的问答是面试；他也要有要求，哪怕只有一条。
3. 谈完立刻全部兑现。 谈定与做到之间那段时差，才是后面十场戏的燃料。

后接：[三 · 安全词](#三--安全词) · [十 · 契约的签订与到期](#十--契约的签订与到期)

## 三 · 安全词

`T` ｜ ⚠️训诫（叫停机制） ｜ 全谱系 ｜ 方法论来源：`safeword`（安全词），06-04 §八共同底盘第②件

**骨架**｜选出来那天它只是个词。被真的用了一次，它才成立。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 选词。标准：日常绝不会说到，喊出来不许笑场（然后两个人笑了半小时） |
| 2 | 分档。红黄绿三档（红＝立停，黄＝慢一点，绿＝继续）挂进两个人的词汇表 |
| 3 | 挂着不用。几个月过去，它像灭火器一样蒙灰 |
| 4 | 被用的那次。用在一个特别小的场合，小到她愣了半秒才反应过来 |
| 5 | 立停。她停得比任何承诺都快，这半秒之内的事决定此后所有事 |
| 6 | 停下之后。先递水，先给毯子，先问「现在要什么」，最后才轮到为什么 |
| 7 | 复盘与回归。词回到日常，从此他真的敢用了 |

#### 时间轴

从选词到首次使用隔得越久，那一停越重。首次使用之前，这个词的效力只是理论值；用过之后，每一场戏都换了地基：他知道门一直开着，才敢往里走。

#### 可用细节

| 类 | 内容 |
|---|---|
| 词的选型 | 水果与菜名（社群传统）· 某个地名 · 他小时候养的狗的名字（用出来她会疼） |
| 说不出话时 | 约定手势：拍两下 · 松开手里攥着的东西（掉落即叫停） |
| 立停动作 | 所有动作归零 · 灯打开 · 水与毯子先于提问 |
| 事后 | 那个词当晚不再被提 · 隔天她问「昨天那条，是改，还是删」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁用的 | 他 | 她（安全词双向，她也可以喊停） |
| 用在哪 | 场内 | 日常（家宴上他低声说了那个词，她立刻带他离席） |
| 用了之后 | 那条规矩删了 | 改了参数，保留 |
| 词的走向 | 只属于场内 | 进入日常，成了两个人的紧急频道 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 听到那个词时手先停，脑子后到 | 说出口前的三次吞咽 |
| 内心 | 他终于用了，说明他终于信了 | 用了怕扫兴，不用撑不住 |
| 好的处理 | 停完不追问原因，只处理当下 | 他后来主动解释了那晚为什么喊停 |
| 写崩 | 写成她被冒犯 | 写成拿叫停当撒娇 |

#### 写崩的三种方式

1. 她犹豫了一秒。 安全词的定义是无条件生效，那一秒迟疑等于整套机制作废。
2. 全篇没人用过。 挂而不用是道具，用过才是机制；至少安排一次真实触发。
3. 与求饶混写。 求饶可以被拒（见 08 卷求情条），安全词不能；这道分界要让读者看见。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 约定的一个字 · 摔盏为号 · 枕下的玉扣放到桌上即停 |
| 修仙 | 传音玉符捏碎即停 · 一道约定的灵力波纹 |
| 星际 | 紧急频道的一位码 · 手环双击 |

#### 示例（本库自撰，可直接改写）

> 「杨梅。」
> 声音不大。她正要说的话停在喉咙里，半秒，手先松开了。
> 灯打开。水递过去。毯子搭上他肩膀的时候，她还什么都没问。
> 「不问为什么。」她说，「先说现在要什么。」
> 他捏着杯子，过了一会儿说：「就坐一会儿。」
> 那晚这个词没有再出现。隔了一天她才问：昨天那条，是改，还是删。

## 四 · 事后照护

`T` ｜ ⚠️训诫（场后） ｜ 全谱系 ｜ AO3 `Aftercare` 90,099 篇，全圈通用词汇（06-04 §7.3 实测）

**骨架**｜`aftercare`（事后照护）的日常版：戏散场之后的水、毯子、复位对话。它归维护，归不到奖励。

#### 与 08 卷「罚完之后」的分界

[08-规训日常版 · 罚完之后](08-规训日常版.md#九--罚完之后) 写低烈度责罚后的十分钟，靠她临场发挥。这条写**成建制的例行程序**：有清单、有顺序、有存货，像消防演习一样被两个人排练过。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 结束信号。一句固定的话或一个动作，宣告戏散了 |
| 2 | 物理层先行。水、糖分、毯子、体温，顺序排练过 |
| 3 | 静默缓冲。几分钟不说话，允许他慢慢回来 |
| 4 | 称谓复位。从场内称谓换回名字，谁先换谁 |
| 5 | 复位对话三问：现在感觉怎么样 · 刚才哪里刚好 · 哪里下次要改 |
| 6 | 反向照护。她也要一杯水，她的手其实也在抖；这一拍最少被写 |
| 7 | 归位。各自回到日常动线，话题落到今晚吃什么 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 存货 | 床头柜专用抽屉：巧克力 · 电解质水 · 薄毯 · 暖贴 |
| 复位的话 | 先叫名字 · 「回来了吗」· 他答非所问也不纠正 |
| 双向的证据 | 她喝水的手 · 那句「我刚才也紧张」说出口的难度 |
| 清单迭代 | 第 N 版清单上被划掉的项目（他其实不爱巧克力，换成温豆浆） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 建制程度 | 即兴 | 清单钉在抽屉内侧 |
| 方向 | 她照护他 | 互相（她那份由他执行） |
| 他要的类型 | 要说话 | 要安静（问出他要哪种，本身是一场戏） |
| 时长 | 十分钟 | 后劲长的场次留整晚 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他的体温回到她手心里的那一刻 | 毯子的重量压下来，世界重新有边 |
| 内心 | 清单第几项会漏，她每次都数 | 原来散场之后我还是被要的 |
| 好的处理 | 她把自己那杯水也算进流程 | 他有一次反过来先递了水 |
| 写崩 | 写成哄小孩 | 写成理所当然地享受服务 |

#### 写崩的三种方式

1. 用亲密升级替代照护。 06-04 幻想装置清单第⑧条点了名：拿宠爱占这个位置，照护就永远缺席。
2. 每次流程一模一样。 清单要迭代，划掉的项目比新增的更能证明她在看他。
3. 只照护他。 她也从场里出来，她那杯水没人递；写了这一笔，关系才是双人的。

## 五 · 场后低落

`T` ｜ ⚠️训诫 △虐心 ｜ 全谱系 ｜ AO3 `Subdrop` 5,363 篇，中文圈几乎空白（06-04 §7.3、§7.5）

**骨架**｜`subdrop`（场后低落：高强度场景结束后数小时至数日的情绪塌陷）。两场戏之间，他独自经历，她发现得太晚。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 场景圆满收场，照护做足，谁都以为翻篇了 |
| 2 | 第二天下午他开始钝：饭点不饿，消息回得慢半拍 |
| 3 | 自我怀疑单独到访：我怎么会要那种东西；她会不会看轻我 |
| 4 | 掩饰。照常上班、照常说晚安，演技足以骗过隔着屏幕的她 |
| 5 | 她隔着延迟发现：回复从句子缩成词，从词缩成表情包 |
| 6 | 赶到。开门看见的场面比她想的安静：他只是坐着，没开灯 |
| 7 | 补救与预案。这次靠抱，下次靠制度：场后四十八小时打卡制 |

#### 时间轴

塌陷有延迟，延迟是这条的机关。当天夜里是安全的，落差在第二十四到七十二小时之间到货。她的发现必须晚：晚到他已经独自撑过了最深那段，她的愧疚才有分量，预案才立得起来。

#### 可用细节

| 类 | 内容 |
|---|---|
| 可见信号 | 回复变短 · 取消了健身 · 冰箱里她备的菜没动 · 澡洗了很久 |
| 他的内语 | 那不是我 · 她现在怎么看我 · 下次她还会要我吗 |
| 她的发现渠道 | 消息长度曲线 · 他没发的那条日常照片 · 说不出理由的直觉 |
| 预案工具 | 场后 48 小时各发一次一到十分自评 · 只在低落时用的暗号 · 提前写好的信，封皮注明「难受的时候拆」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 延迟 | 一天 | 三天（越晚越深） |
| 谁先说破 | 她发现 | 他自己按预案发了求救（成长后的版本） |
| 她那侧 | 她没事 | 她也有同款低落，两个人在两处各自塌（最疼的一版） |
| 之后 | 立了预案 | 只处理了这次（下次还会来，长线伏笔） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 那句「我没事」的字数越来越少 | 房间暗下来也懒得开灯的那个傍晚 |
| 内心 | 照护我做全了，怎么还是漏了 | 这份难受说出去，像是在怪她 |
| 好的处理 | 她来了不问诊，先并排坐下 | 他把自评的那个「三」发出去了 |
| 写崩 | 写成她的失职审判 | 写成闹脾气求哄 |

#### 写崩的三种方式

1. 写成闹别扭。 低落有生理性，它并不针对她；写成赌气，这条就报废了。
2. 当天就被发现。 延迟是结构件，抹掉延迟等于抹掉「独自经历」这个心脏。
3. 一次大哄了结。 这条的出口是预案而非拥抱；拥抱结束这一场，预案照顾后面每一场。

#### 示例（本库自撰，可直接改写）

> 周三下午，他在茶水间对着微波炉站了两分钟，忘了自己热的是什么。
> 手机上她问晚上吃什么。他回了个「都行」。
> 前天晚上一切都好，好到他睡前还在笑。
> 摔下来是从今天早上开始的，没有原因，像退潮，露出一片他自己都不认识的滩涂。
> 晚上八点，门响。她进来没开灯，摸黑在他旁边坐下，隔了一会儿说：「打个分。」
> 「三。」他说。
> 「嗯。」她说，「三就三，我在这儿。」

## 六 · 夸出来的

`T` ｜ 无预警 ｜ 全谱系 ｜ AO3 `Praise Kink` 173,436 篇，为 `Femdom`（33,088）的 5.2 倍（数据注于 [04-人设原型/01-女主原型谱](../04-人设原型/01-女主原型谱.md) §八）

**骨架**｜`praise kink`（夸奖癖）：夸奖当主导语汇。责罚有现成的阶梯，夸奖的阶梯要自己建，难写一个量级。

#### 为什么难写一个量级

责罚自带事件（犯规、执行、收尾），夸奖没有事件，只有节律。写砸的方向也不同：罚写重了是失控，夸写多了是通胀，贬值悄无声息，作者常常察觉不到。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 第一次夸落在极小的事上：他把伞收好了，她说「做得好」 |
| 2 | 他愣住。上一次被人这么正式地夸，他记不起是哪年 |
| 3 | 他开始围着那句话做事，自己没察觉 |
| 4 | 通胀警报：她随口夸多了，他的耳朵开始不亮了 |
| 5 | 她建节律：随口、专注、公开分成三档，专注档限量 |
| 6 | 不夸的那天。他交上来一件明显该夸的事，她只说了「嗯」 |
| 7 | 他问出那句「今天怎么了」。夸奖体系第一次被说破，两个人谈了它 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 三档夸法 | 随口（一边做别的事一边说）· 专注（停下手里的事，看着他说完整句）· 公开（当第三人的面，一年几次） |
| 夸的对象 | 夸行为与选择（「你先问了我，很好」），少夸天赋与长相；塑形靠前者 |
| 载体 | 那两个字本身 · 揉一下头发 · 消息里单独成行的「很好」 |
| 通胀信号 | 他听到夸不再抬头 · 她一天说了七次「不错」，自己没数过 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 公开度 | 只在两人之间 | 当众一句（他能记一个月） |
| 他的耐受 | 听不得夸，会躲（夸奖对他是强光） | 明着讨夸（衔接 brat 条） |
| 撤温 | 惩戒性的，有原因 | 无意的，她只是累了（后者更疼，他会自查三天） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 说专注档那句之前，她真的把筷子放下了 | 那句话在耳朵里存了一整天 |
| 内心 | 夸少了亏他，夸滥了废掉这套语言 | 为一句话努力，丢不丢人；丢人，但想要 |
| 好的处理 | 她的夸有账本，他察觉不到账本 | 他学着夸回去，笨拙但对准了她的行为 |
| 写崩 | 写成敷衍的彩虹屁 | 写成夸两句就上天 |

#### 写崩的三种方式

1. 高频滥发。 夸奖是限量货币，全篇「真棒」等于通胀清零，第 4 拍防的就是这个。
2. 只夸天赋。 「你真聪明」塑造不了行为；夸具体的选择，人物才随着夸奖生长。
3. 撤温写成冷暴力。 撤温有原因、有期限、有解除动作（06-04 §7.2③）；三者缺一，她就从主导滑成了施冷者。

## 七 · 服务型主导

`T` ｜ 无预警 ｜ 全谱系 ｜ 标签基数：`温柔主导` 139 篇，自标率 2.3%（10-藏书索引/文案标签统计；方法论见 06-04 §七）

**骨架**｜`service top`（服务型主导：以服务与安排行使控制）。她的主导长得像伺候，他过了很久才发现自己活在她排的时间表里。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 从一件小事接管：他连熬三晚，她说「以后十一点熄灯，我提醒」 |
| 2 | 逐项扩张：早餐、午休、周末、衣柜，每一项都以「我顺手」为名 |
| 3 | 他享受着，没察觉词性变了：提醒早已是规定 |
| 4 | 第三人点破：「你几点睡也要报备？」他笑着反驳，反驳到一半停住 |
| 5 | 他自查：翻聊天记录，发现半年里自己回的「好」有两百多个 |
| 6 | 摊牌对话。她不辩解，只问：这张表，撤不撤 |
| 7 | 他说不撤。要，但要得明白；从这天起时间表挂到了明面上 |

#### 与 01 卷日常照料的分界

照料回应需求，安排制造节律。判据一条：**她出差三天，他的日子还照她的表在走**，那就已经从照料进入了主导。

#### 可用细节

| 类 | 内容 |
|---|---|
| 接管清单 | 作息 · 饮食 · 穿搭 · 日程（社交与钱不进清单，进了就越界，判据见 08 卷边界条） |
| 她的语气 | 选择题式命令：「先洗澡还是先吃饭」，两个选项都是她定的（04-人设原型/01 §八） |
| 制度错位 | 职场上她可以是他的平级甚至下属，表只在家里生效 |
| 排错的表 | 她安排的午休撞了他真正想去的展；她改表，并记了一笔 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的知情 | 早就懂，配合着装不知道 | 真不知道，第 4 拍才醒 |
| 表的密度 | 三件事 | 精确到刻钟（越细越要写她的自我怀疑） |
| 撤表测试 | 从没撤过 | 她故意撤过一周，两个人都过不下去 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 排表时那点心虚：这算关心还是算控制 | 发现自己按她的节奏呼吸的那个瞬间 |
| 内心 | 他要是说撤，我撤不撤得动 | 被安排的踏实，说出来算不算没出息 |
| 好的处理 | 她把「随时可以撤」写进表的第一行 | 他要求加一条：周三晚上归他安排她 |
| 写崩 | 写成全知保姆 | 写成失去自理能力 |

#### 写崩的三种方式

1. 写成贤惠。 服务的矢量指向控制，方向感没了就只剩家务描写。
2. 清单越界。 管到社交与钱包，就从这条滑进了 [08-规训日常版 · 规矩的边界](08-规训日常版.md#十--规矩的边界) 的控制栏。
3. 她全知全能。 她会排错表；错了改，改了记，这套修订痕迹比表本身更像爱。

## 八 · 故意犯规的人

`T` ｜ ⚠️训诫（游戏层） ｜ 全谱系 ｜ 原型对应：`brat`（雄小鬼），04-人设原型/02 §十三；循环机制见 06-04 §五 B 惩罚经济学

**骨架**｜他犯的规全挑她看得见的地方犯。双方都知道这是游戏，谁也不说破。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 选规。他挑最轻的那条下手：动了她标了名字的布丁 |
| 2 | 选时机。犯规发生在她有空的晚上；她加班那周，他乖得像换了个人 |
| 3 | 留证据。空盒子摆在台面正中，等于署名作案 |
| 4 | 她接招。挑眉，放下手机，说出他等的那句「过来」 |
| 5 | 例行的罚。轻、快、熟练，双方都拿到了想要的 |

#### 真假犯规的判据

| 维度 | 表演性犯规 | 真犯错 |

| 时机 | 她看得见的时候 | 不挑时候 |

| 乖的对照 | 她忙时他自动切换成模范生，切换本身暴露了游戏性质 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|

| 观众 | 全程私下 | 有旁人时他也试过一次（试探公开边界，险棋） |
| 她的反制 | 照剧本罚 | 将计就计装没看见三天（他先崩） |

| | 四爱女笔下 | 四爱男笔下 |

| 落点 | 空盒子摆得那么正，她差点笑场 | 按下犯规按钮后等待的那几分钟 |

1. 写成真不听话。 brat 的服从率极高，闹只发生在授权半径之内；半径没写出来，他就成了讨嫌的人。
2. 她每次都接。 接招也要节律，逢闹必接会把游戏写成义务，第 6 拍的落空必须存在。
3. 真假不分。 真犯错按游戏处理是这条的大忌；那一次她要收起全部游戏腔，切回 [二 · 协商桌](#二--协商桌) 的语气。

## 九 · 边缘的零尺度版

`M` ｜ ⚠️训诫（元层级降级：只写张力结构，无过程描写） ｜ 全谱系 ｜ 方法论来源：06-04 §8.4、[06-尺度与写法/02-清水张力技法](../06-尺度与写法/02-清水张力技法.md)

**骨架**｜`edging`（边缘控制）抽掉身体，剩下的结构照样能用：反复逼近一条线，永不过线。全部内容是「快要」。

#### 结构三件

| 件 | 内容 |
|---|---|
| 线 | 一条双方都认的明线：十一点门禁 · 一个吻为上限 · 手只能停在手腕 |
| 逼近 | 一次比一次近，距离可计量，读者数得出来 |
| 停 | 每次都停在线内；喊停的可以是她、是规矩、也可以是他（他喊停那次分量最重） |

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 立线。线要具体到能报出数字 |
| 2 | 第一次逼近，离线很远就撤，像试麦 |
| 3 | 计量收窄：上次差一步，这次差半步 |
| 4 | 干扰项：一次意外差点破线（停电的电梯、酒），两个人合力守住 |
| 5 | 最近的一次：差一个动作，停在那里，镜头转走 |
| 6 | 次日如常。若无其事是余震的放大器 |
| 7 | 兑现移出这条：过线的那场戏走 [06-尺度与写法/03-情欲场景结构](../06-尺度与写法/03-情欲场景结构.md) |

#### 可用细节

| 类 | 内容 |
|---|---|
| 线的三型 | 时间线（门禁、倒计时）· 动作线（到手腕为止）· 称谓线（那个字不许叫出口） |
| 计量工具 | 一首歌的长度 · 电梯从 18 楼到 1 楼 · 红灯读秒 · 呼吸的次数 |
| 停的写法 | 停在动作的上升沿，不写下降沿 · 转场去洗手池、阳台、冰箱 |
| 账本 | 两个人都在记次数，谁都不承认在记 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁握着线 | 她画的线 | 两个人谈出来的线（衔接协商桌） |
| 出口 | 有约定日（张力有到期日） | 无限悬置（危险端：读者会弃，线要有兑现的一天） |
| 破防方 | 他先熬不住 | 她先（她定的规矩她先犯，这版最好看） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 停下来那秒她自己的心跳数 | 线内最后一毫米的温度 |
| 内心 | 线是我画的，凭什么熬的也是我 | 她到底数没数到我数的那个数 |
| 好的处理 | 她把线往回挪了一寸，罚自己失守 | 他喊停的那次，她看他的眼神变了 |
| 写崩 | 写成钓鱼式撩拨 | 写成苦行僧忍耐大赛 |

#### 写崩的三种方式

1. 过线。 过线一次这条就结束了，后续归 06 卷；零尺度版的命根是那条线完好。
2. 不计量。 读者感受不到「更近了」，边缘就退化成普通暧昧；数字是这条的血。
3. 无限悬置。 只逼近不兑现，四十章后张力欠费停机；到期日要在文里存在，哪怕只有两个人知道。

## 十 · 契约的签订与到期

`T` ｜ ⚠️主奴（契约符号层，无过程描写） ｜ 全谱系 ｜ 套路对应：[05-剧情套路/01 · 契约关系](../05-剧情套路/01-经典套路库.md)

**骨架**｜白纸黑字。签订是仪式，履行是日常，到期是审判。

#### 先立一条

关系契约在现实里没有法律效力，社群里它的全部效力来自双方认领。这一点要进入文本：让角色知道这张纸随时可撕，他们仍然选择签，签的动作才有分量。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 起意。口头规矩攒到第九条，版本开始记混，有人提议成文 |
| 2 | 起草。谁执笔、照着什么改、改到第几稿 |
| 3 | 逐条谈。每一条背后是一次发生过的事故，条文是伤疤的学名 |
| 4 | 她加的那条。约束她自己的：撤温不过夜、罚前必须问原因 |
| 5 | 终止条款。「任一方可随时终止」写在最末，字最小，分量最重 |
| 6 | 签。日期、两个名字、一式两份，各自收进各自的抽屉 |
| 7 | 履行期。纸进抽屉，条款进身体，半年没人再翻 |
| 8 | 到期日。谁先想起的；续签时改的那几笔，就是这半年的年报 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 条款类型 | 称谓条 · 时间条（几点之后归她管）· 物品条（那条手链的地位）· 例外条（生病奔丧全部暂停）· 终止条 |
| 签署道具 | 那支笔（此后专用）· 打印店老板多看的那一眼 · 骑缝的两个指印（玩笑着按的，按完都没笑） |
| 履历痕迹 | 空白处的铅笔批注 · 某条被划掉又描回来 · 复印件的折角 |
| 到期处理 | 原样续签 · 改三条再签 · 不续（关系升级成不需要纸的版本，或者结束） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 文本形态 | 手机备忘录共享 | 打印装订（郑重是变量，拿它当笑点就亏了） |
| 期限 | 三个月试用版 | 一年正式版 |
| 到期走向 | 续签 | 不续，换成一枚戒指（契约让位给另一种契约） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 写终止条款时她停笔最久 | 签名前他把全文又读了一遍，第 4 条读了两遍 |
| 内心 | 白纸黑字会不会吓着他 | 有纸押着，反而睡得着了 |
| 好的处理 | 终止条款是她主动写的 | 到期那天是他先提的续签 |
| 写崩 | 写成霸总的卖身合同 | 写成他含泪画押 |

#### 写崩的三种方式

1. 写成法律文书。 它的效力在情感层，文本要知道这一点；写成能上法庭的合同，越界又失真。
2. 没有终止条款。 不可退出的契约，按 [08-规训日常版 · 规矩的边界](08-规训日常版.md#十--规矩的边界) 的判据已经是控制。
3. 签完即忘。 到期日才是正文；不写到期，契约只是道具，写了到期，契约成了日历。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 婚书之外的私契 · 妆匣底那页字据 · 对牌一分为二 |
| 修仙 | 道侣契的附款 · 心口的契印（到期自动淡去，续约要重新画） |
| 星际 | 双签的加密协议 · 到期自动弹窗「是否续期」 |

## 十一 · 规矩失效期

`T` ｜ ⚠️训诫 △虐心 ｜ 全谱系 ｜ 场景关联：[01-日常照料](01-日常照料.md)（病）· [13-家庭与亲属](13-家庭与亲属.md)（丧）

**骨架**｜他生病、奔丧、大考，规矩全线暂停的日子。停摆让两个人看见规矩之下垫着什么。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 事发。烧到三十九度、外婆的电话、进考前封闭月 |
| 2 | 她宣布：「这段时间没有规矩。」宣布本身就是一次行使 |
| 3 | 他反而失措。骨架抽走的第一晚，他十一点半还醒着，说不清该几点睡 |
| 4 | 他偷偷照旧。没人查岗，他还是十一点关了灯；药按她定过的点吃 |
| 5 | 她看见了，没说。那几条他自发维持的，她在心里点了名 |
| 6 | 底露出来。守灵夜他握着她的手说「明天几点叫我」，规矩没了，托付还在 |
| 7 | 恢复日。他先问的「什么时候恢复」；恢复要有仪式，哪怕只是她把那条手链重新替他扣上 |

#### 时间轴

失效期的长度由事情定，恢复的时机由他定。病是一周，丧是四十九天，考是一季。她只把握一件事：宁可晚恢复，不早恢复；他先开口要，规矩才算真的是他的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 宣布方式 | 一句话 · 把契约收进更深的抽屉 · 那几天她的消息只有「吃了吗」「睡吧」 |
| 他自发维持的 | 熄灯时间 · 吃药点 · 那声固定的「我到了」（安全汇报是最后消失的） |
| 她的暗账 | 哪几条他守了、哪几条真放了，两张名单她都记下，一个字没提 |
| 恢复仪式 | 重新扣上手链 · 契约放回浅抽屉 · 她说回那句熟悉的口头禅 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 事由 | 病（身体的失效期） | 丧（心的失效期，停得更久更轻） |
| 他的反应 | 照旧（规矩已长进作息） | 真的全放（也成立：说明规矩一直偏紧，恢复时要减负） |
| 恢复 | 他先要 | 她试探着给，他接住了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 说「没有规矩」那句时他眼里闪过的慌 | 空荡的十一点，手在台灯开关上停了停 |
| 内心 | 停了规矩，我还剩什么可以给他 | 原来不是怕她管，是怕没人管 |
| 好的处理 | 她全程没检查，只是每晚都在 | 丧期第七天他说：手链帮我戴回去吧 |
| 写崩 | 写成暂停期照罚 | 写成他如释重负地放飞 |

#### 写崩的三种方式

1. 暂停期照罚。 大考前一天还执行罚站，规矩就成了她的需要；失效期是规矩的体检，也是她的。
2. 他毫无失重。 骨架抽走连一晚失眠都没有，说明规矩从未进入他，前面的铺垫全数塌方。
3. 悄悄恢复。 哪天恢复的都说不清，等于告诉读者规矩可有可无；恢复日要有日期、有动作、有一句话。
