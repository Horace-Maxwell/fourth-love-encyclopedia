# 第三人与群像

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**镜头不在两人身上。** 第三人的眼睛量出这段关系在世界里的尺寸，第三人的嘴替世界给它定名。

## 这一族补哪条空档

[04-人设原型/04-配角功能位设计](../04-人设原型/04-配角功能位设计.md) 立了 13 个功能位，桥段库此前各卷的条目却几乎全是二人场：功能位有定义、有设计卡，在日常微剧情这一层没有一条戏真正让它们上镜。这一族逐条挂靠功能位，把「位置」落成「一场戏」。

镜头交给第三人之后，日常戏的发动机跟着换：

| | 二人场 | 借第三人的场 |
|---|---|---|
| 情绪来源 | 内心戏 | 观察误差（第三人看错的那部分） |
| 关系显影 | 时间流逝的物质动作 | 旁人的反应与转述 |
| 一场戏的产出 | 谁先低头 | 谁被看见了什么 |

语料侧的底数（13-07 实测）：

| 节拍族 | 作品数 | 占比 |
|---|---:|---:|
| 起哄 | 1,259 | 43.5% |
| 孩子 | 719 | 24.8% |
| 议论 | 609 | 21.0% |
| 聚会 | 338 | 11.7% |
| 闺蜜在场 | 328 | 11.3% |
| 旁人看 | 197 | 6.8% |

「旁人看」6.8%，在上表垫底：写第三人在场的多，肯把整场镜头交出去的少。频次低只等于竞争小。

「双向写法」在这一族多一层：除了她笔下他笔下，还要选**借谁的眼睛**。同一场戏，借审视者的眼睛出刀，借无知者的眼睛出糖。各条的表格围绕这个选择填。

## 一 · 嬷嬷位开口

`T` ｜ 无预警 ｜ 古代女尊／架空王朝（现代对应见变体轴）｜ 语料频次：请安 26.6%、立规矩 19.5%（13-07 实测）

**骨架**｜制度有一句难听的话要说，借她的嘴说。一位主角不便说，另一位不能驳。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 事由很小（一次迟了的请安、一件放错位置的东西） |
| 2 | 嬷嬷开讲，从小事一路讲到「男子的本分」，制度的原话由她念出 |
| 3 | 他听着，视线越过嬷嬷的肩去找她 |
| 4 | 她不在场；或在场，没接话 |
| 5 | 嬷嬷讲完，行礼退下，全程挑不出一个字的错 |
| 6 | 独处时他转述这段话，删掉了最难听的那句 |
| 7 | 她的处理：留着规矩换掉说法，或什么都不做 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 晨昏定省的廊下 · 分例发放 · 进门第一课 · 有客在的前厅 |
| 她的话术 | 「不是老奴多嘴」开场 · 收尾必称「府里的规矩」（先声明权力是借来的）· 主动加码，主人没要求的她替主人要求了 |
| 他的反应 | 全程只应一个字 · 找她的视线落空 · 转述时删句 |
| 现代对应 | 执行秘书替她回绝了他的来电 · HR 按章发的那份通知 · 助理提醒他「开会时间别发消息」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她知不知道 | 事后才知道 | 她默许的（冷一档） |
| 嬷嬷忠于什么 | 忠于她 | 忠于规矩本身，她也管不动 |
| 他的消化 | 转述时删句护她 | 一字不落复述给她听，把球踢回去 |
| 世界 | 古代府邸 | 现代公司（秘书位、HR） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借嬷嬷的：主人破例的那一瞬，落在执行者眼里 | 借他自己的：听训时数她用了几次「规矩」 |
| 落点 | 听完转述，她发现了被删掉的那句 | 视线越过肩去找她，没找到 |
| 好的处理 | 她不骂嬷嬷，她改规矩 | 删句的动作出于护，出不了怕 |
| 写崩 | 写成恶仆欺主 | 写成他被吓破了胆 |

#### 写崩的三种方式

1. 把嬷嬷写成恶意 NPC。 她每句都合规，吓人的地方在合规；写成恶仆，主角平白得了道德便宜，功能位塌掉。
2. 让她当场发作。 当场驳嬷嬷等于当众废规矩，那归 [20-女尊制度场景 · 她改了规矩](20-女尊制度场景.md#七--她改了规矩)；这条的分寸在事后。
3. 嬷嬷只出场一次。 执行者靠日常反复在场立住，只来一次的是传话筒。

#### 可串接

前接：[20-女尊制度场景 · 晨昏定省](20-女尊制度场景.md#一--晨昏定省)
功能位：[04-配角功能位设计 · 五、中层执行者](../04-人设原型/04-配角功能位设计.md#五中层执行者嬷嬷位)（她说主角不便说的话）
后接：[08-规训日常版](08-规训日常版.md)（同一套规矩由她亲口说时的样子）
对照：[20-女尊制度场景 · 家法](20-女尊制度场景.md#六--家法)

## 二 · 竞争者上门

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：吃醋 43.1%（13-07 实测）

**骨架**｜另一个女攻当面向他表达兴趣。他的应对方式，就是这段关系的成色检验。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 场合给了机会：她不在场，或在场但隔着一段距离 |
| 2 | 搭讪不低级，条件摆得开，是一份体面的邀请 |
| 3 | 他听完了，礼貌是他的教养，没有打断 |
| 4 | 拒绝：不辩解、不炫耀，一句话说明归属 |
| 5 | 竞争者认输不认错：撤了，但不觉得自己看走了眼 |
| 6 | 他讲不讲：回去以后提不提这件事 |
| 7 | 她的反应，先问出口的那个问题 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 竞争者的开场 | 递名片 · 「她不懂珍惜你」（攻击关系，不攻击人）· 条件真的好：更有钱、更闲、更温柔 |
| 他的应对分层 | 听完 → 名片还回去 → 一句话 → 不给第二回合 |
| 那句话的版本 | 「我有人了」最简 · 「她懂我」最短 · 报出她的名字最重（宣示归属，方向反着来） |
| 她的反应 | 先问「你怎么回的」而非「她是谁」（问句的选择就是安全感的读数） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她在不在场 | 不在，他独自应对 | 在，隔着人群看完全程，没出手 |
| 竞争者的强度 | 条件确实更好 | 条件平平，但恰好懂他的领域 |
| 他讲不讲 | 主动讲了 | 没讲，她从别人那里听到 |
| 后续 | 一次即止 | 同圈同事，长期在场，不改口 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借竞争者的：她看中的他，和我看见的他差在哪 | 借他自己的：拒绝不需要斟酌，答案是现成的 |
| 落点 | 「你怎么回的」问出口，才发现自己在意 | 名片还回去的那一下没有犹豫 |
| 好的处理 | 她全程没出手，把这一局整个交给他 | 他拒得平静，事后不表功、不邀赏 |
| 写崩 | 写成她杀出来宣示主权 | 写成他炫耀自己抢手 |

#### 写崩的三种方式

1. 竞争者写成小丑。 条件不行，他的拒绝就不值钱；对照够强，拒绝才有分量。
2. 让她出手抢人。 镜头一转回她，这条就退回 [05-占有与吃醋](05-占有与吃醋.md) 了；这一族的机关是她不动。
3. 拒绝靠贬低对方完成。 他要说的只有归属；一踩人，他的教养和这段关系一起掉价。

#### 可串接

前接：[05-占有与吃醋 · 那个人是谁](05-占有与吃醋.md#一--那个人是谁)
功能位：[04-配角功能位设计 · 二、阻碍位](../04-人设原型/04-配角功能位设计.md#二阻碍位)（立场合理、全程不改口）· [04-配角功能位设计 · 四、对照组位](../04-人设原型/04-配角功能位设计.md#四对照组位)（更好的选项被当面拒绝）
后接：[05-占有与吃醋 · 当众宣示](05-占有与吃醋.md#八--当众宣示)

## 三 · 镜像位的婚礼

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：婚仪 38.8%（13-07 实测）

**骨架**｜去参加另一对四爱的婚礼。整场他们都在别人身上看自己。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 请柬到，新人是圈内认识的另一对 |
| 2 | 路上话很少，两个人想到了同一件事，都没说 |
| 3 | 仪式的走位跟惯例反着：她先上台等他，戒指是她给他戴 |
| 4 | 他偷看她的反应，她也在偷看他，互相抓到 |
| 5 | 旁桌的议论飘过来一句，给这类婚事称了回重 |
| 6 | 敬酒到他们这桌，新人与他们对视，四个人都懂 |
| 7 | 回程，谁先开口；开口说的却不是婚礼 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 请柬 ✓（1.2×）· 喜糖 ✓（1.6×）· 座位卡 · 手捧花的去向 |
| 反着来的环节 | 致辞的顺序 · 交换戒指谁先伸手 · 抛花球他去接 · 挡酒的方向 |
| 各自的小动作 | 她数流程，像在预习 · 他把喜糖收进兜里，捏了一路 |
| 旁桌那句 | 「男方家里也同意了？」（一句话就是一杆秤） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 镜像方向 | 前向：对方先走到了 | 后向：对方是刚确认关系的小年轻，看他们像看当年 |
| 两人的阶段 | 还没谈到婚嫁，这场是引信 | 已订婚，这场是预演 |
| 那对的成色 | 真好，照出向往 | 席间起了一句口角，照出恐惧 |
| 收束 | 回程说开了 | 谁也没提，当晚喜糖被摆在了桌上 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借她自己的：整场看的是对面那个新郎，找他的影子 | 借他自己的：整场看的是新娘牵人的手势，认出了她 |
| 落点 | 发现自己在给流程记笔记 | 兜里的喜糖被捏软了 |
| 好的处理 | 她不问他想不想要，她开始留意他的反应 | 他不催，只是把请柬留了下来 |
| 写崩 | 写成她当场借机逼婚 | 写成他自卑：这种日子轮不到我们 |

#### 写崩的三种方式

1. 镜像那对是纸片人。 他们要真实到有自己的裂缝；全程只为主角服务的婚礼是布景。
2. 当场表白或求婚。 引信当场引爆，镜像就白搭了；这条的产出是回程车里那句没头没尾的话。
3. 议论写成满场敌意。 旁桌只需要一句；句句带刺，就滑进 [14-社交与公开](14-社交与公开.md) 的另一条戏了。

#### 可串接

前接：[44-圈层与同好](44-圈层与同好.md)（新人从同好圈里来，同轮在写）
功能位：[04-配角功能位设计 · 一、镜像位](../04-人设原型/04-配角功能位设计.md#一镜像位)（镜像的效力全在亲眼看见，转述无效）
后接：[23-婚嫁 · 求婚](23-婚嫁.md#一--求婚)（引信引燃）· [23-婚嫁 · 当天](23-婚嫁.md#七--当天)（轮到他们）

## 四 · 对照组同框

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：聚会 11.7%（13-07 实测）

**骨架**｜一桌两对：一对传统夫妻，一对他们。谁都没提差别，差别自己长出来。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 组局：老同学夫妇约饭，四人一桌 |
| 2 | 落座就分了工：对面他点菜她看手机；这边她拿菜单，报忌口的是他 |
| 3 | 第一轮对照：倒茶、剥虾、接电话，同一件事两边做法相反 |
| 4 | 对面先觉出来，那位丈夫抛出一句玩笑 |
| 5 | 羡慕藏不住：对面妻子的目光在「他给她剥虾」上多停了一秒 |
| 6 | 话题擦过雷区「你们家谁管钱」，两对各答各的，答案反着 |
| 7 | 散场分头走，两对各自在车里聊起对方 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 对照的物件 | 菜单（谁接）· 买单（谁的手机 ✓ 先出来）· 车钥匙（谁开车）· 虾壳堆在谁那侧 |
| 对面妻子的三次注视 | 他递水时 · 他记得她忌口时 · 买单她伸手他没拦时 |
| 对面丈夫的玩笑 | 「兄弟你这么惯着，以后管不住啊」（一个「管」字漏出他的语法） |
| 车里的复盘 | 对面那对的沉默比这边的长 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 对面的成色 | 恩爱的传统夫妻，对照才公平 | 面和心不和，这边成了照妖镜 |
| 先觉察的人 | 对面妻子 | 对面丈夫，他的不适说不出口 |
| 雷区话题 | 谁管钱 | 要不要孩子、谁带 |
| 收束 | 互留好印象 | 对面当晚吵了一架，起头是一句「人家……」 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借对面丈夫的：他看不懂的地方，就是差别所在 | 借对面妻子的：她多看的每一眼都在称重 |
| 落点 | 「管不住」那句她没接，他自己接了：「不用管。」 | 对面妻子问他「你不介意吗」，他隔了半秒才明白介意什么 |
| 好的处理 | 不让这边赢：对面也有这边没有的东西 | 他的自然是本色，没有一分表演给对面看 |
| 写崩 | 写成传统夫妻被打脸 | 写成他向对面开讲座 |

#### 写崩的三种方式

1. 把对面写成反面教材。 对照要公平，对面也得有真感情；一边倒的对照是宣传画。
2. 有人把差别说破。 这条的机关是无声，谁说破谁输；说破版走 [14-社交与公开 · 被起哄](14-社交与公开.md#一--被起哄)。
3. 四个人全程发言。 群像戏要留一个只看不说的人；人人抢话，就没有镜头了。

#### 可串接

前接：[29-微小仪式拾遗 · 剥虾](29-微小仪式拾遗.md#八--剥虾)（对照的最小单元）
功能位：[04-配角功能位设计 · 四、对照组位](../04-人设原型/04-配角功能位设计.md#四对照组位)（同一套情境施于两对，规则的性质自己显影）
后接：[13-家庭与亲属 · 要不要孩子](13-家庭与亲属.md#四--要不要孩子)（雷区话题的正篇）

## 五 · 解说员

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：闺蜜在场 11.3%、议论 21.0%（13-07 实测）

**骨架**｜一个知情人向一个不知情者解释他们俩。解释得越用力，错得越具体。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 新人进场（新同事、远房亲戚、刚回国的旧友），撞见一幕反常：她开会，他在楼下等 |
| 2 | 新人发问，问题自带框架：「她男朋友怕她？」 |
| 3 | 解说员开讲，三分对七分错，错的方向全是解说员自己的世界观 |
| 4 | 现场验证：正主出现，行为跟解说对不上 |
| 5 | 新人二次发问，问题变了，框架松了 |
| 6 | 解说员收尾：「反正他们过得挺好。」 |
| 7 | 正主始终没发现这场解说发生过；或她听见了一段，没纠正 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 错法清单 | 时间线错（以为她追的他）· 因果错（以为他图钱）· 分工错（以为家里她做饭）· 唯一说对的：「他俩谁也离不开谁」 |
| 新人的问题 | 第一问身份 · 第二问「图什么」 · 第三回合不问了 |
| 验证场面 | 解说到「她说一不二」，楼下正好看见她替他撑伞拎包 |
| 解说员的身份 | 闺蜜错得最少 · 同事错得最典型 · 邻居阿姨错得最善良 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 与他们的距离 | 近（闺蜜：错在细节） | 远（邻居：错在框架） |
| 错误的性质 | 笑点：无伤大雅的想当然 | 刀点：错处恰是他们最疼的那处，如「反正他们不会要孩子」 |
| 正主知不知道 | 全程不知道 | 她听到一段，没纠正 |
| 新人的去向 | 被说服 | 没被说服，自己观察出了第三个版本 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借新人的：不带成见的第一眼，比熟人的准 | 借解说员的：错误清单数出世界对他的全部想象 |
| 落点 | 她听到的那段解说里，唯一说对的那句 | 「图什么」被人替他答了三个版本，没有一个对 |
| 好的处理 | 她不纠正，错误版本护住了真实版本 | 他知道这些版本存在，一个也不认领 |
| 写崩 | 写成她现身打脸辟谣 | 写成他偷听后受伤自闭 |

#### 写崩的三种方式

1. 解说员全说对。 全对就成了作者的播音腔；错误率才是信息，错的方向就是世界观的读数。
2. 解说员带立场。 一替谁辩护，解说就成了宣传，新人和读者一起打折。
3. 信息倾倒。 一口气讲完两人十年是设定说明书；拆成三次，每次讲一半、错一半。

#### 写崩的三种方式

1. 写成她的个人秀。 碾压可以有，接纳的钥匙却是守规矩；一场碾压换不来固定名单。
2. 兄弟们写成起哄背景板。 至少一个人要有自己的顾虑与转变；全员工具人的接纳不值钱。
3. 让他全程护驾。 他一挡，审视就够不到她，接纳也就无从发生。

2. 让她动用权力灭火。 一查一封，日常戏就成了职场惊悚；她的分寸是不动。
3. 跳过撞见者的心理。 第一个人的犹豫（说不说、跟谁说）是整条链的种子，直接跳到满城风雨，链就断了。

> 门合上了。负二到十七楼，小周的手心出了一层汗。
> 下午她只告诉了拼午饭的同事一个人，外加三遍「别说出去」。
> 第二天，茶水间有人反过来凑近她：「听说了没，李总在停车场给人跪下了！」
> 「是系鞋带，」她脱口纠正，说完才反应过来自己成了信源。

| 轴 | 一端 | 另一端 |
|---|---|---|

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|

| 落点 | 她听见转译版「我妈是队长」的那一秒 | 孩子跟同学吵架护的是他：「我爸做的饭比你爸买的好吃」 |
| 好的处理 | 不借孩子的嘴发宣言，孩子只管陈述事实 | 他答问题时不自嘲；一自嘲，孩子就学会了羞耻 |
| 写崩 | 孩子说出成人议题的台词 | 写成孩子被歧视的苦情戏 |

#### 写崩的三种方式

1. 孩子当传声筒。 五岁的嘴说三十岁的话，一句就穿帮；孩子的台词只能用孩子的语料：吃的、玩的、谁大谁小。
2. 困惑写成创伤。 孩子的困惑是事实核对，答得好当天就消化；写成身份危机，是把大人的焦虑披了件小孩外套。
3. 家里从不接招。 问题要被认真回答；被糊弄过去的问题会在孩子那里发霉。

| 3 | 闺蜜的镜头（解说员）：低声给桌上新来的表妹讲这对的历史，讲错一处 |
| 4 | 他兄弟的镜头（对照组位）：看着看着想起自己家，低头给妻子发了条消息 |
| 5 | 孩子的镜头：谁的杯子空了归爸爸添，瓶盖归妈妈开 |
| 6 | 新婚小夫妻的镜头（镜像位）：在这对身上看十年后的自己 |
| 7 | 共识事件：她替他挡了那杯酒；人人看见，没人说破，各自入账 |
| 8 | 收束镜头拉远：桌下那两只手，谁也没看见，只有读者看见 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 视点纪律 | 一人一镜头一细节，两个人不许观察同一件事 |
| 各镜头的专属物 | 阿姨看分工 · 长辈看筷子 · 闺蜜看眼色 · 兄弟看自己 · 孩子看杯子 · 新人看未来 |
| 双轨声部 | 桌面上的话题热闹，每个人心里的读数安静 |
| 散席的残局 | 谁的碗空谁的碗满 · 她父亲那杯没动的酒空了 · 打包的袋子拎在谁手里 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 年夜饭，人齐 | 寿宴、满月酒：有外圈客人，视差更大 |
| 视点数 | 四个，紧凑 | 七个，全功能位到齐，需要篇幅撑 |
| 共识事件 | 她替他挡酒 | 他一句话替她收了长辈的话头 |
| 收束镜头 | 桌下的手 | 散席后的空桌残局 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 开场给最挑剔的那双（她父亲），压轴给孩子 | 开场给最亲的那双（兄弟、阿姨），压轴给她家长辈 |
| 落点 | 挑剔的眼睛数完七筷子，停了 | 散席时她父亲那杯酒空了，喝掉它的人是她 |
| 好的处理 | 主角全场零内心戏，形象全由观察拼出 | 每换一个视点，两人的形象被修正一次 |
| 写崩 | 写成众人轮流夸的表彰会 | 写成两人当众撒糖的直播 |

#### 写崩的三种方式

1. 人人发言，无人观察。 群像的镜头是眼睛；满桌金句，等于没有镜头。
2. 视点轮转但读数相同。 七双眼睛看出同一个结论，就白轮了；视差才是产出。
3. 给主角开内心戏。 这条的纪律是两位主角内心全程静音；一开口，整场群像散架。

#### 示例（本库自撰，可直接改写）

> 张姨端最后一道菜上桌，心里有了数：单子是先生开的，钱是太太转的。
> 老爷子那边数到第七筷，把面前那杯酒往女婿跟前推了半寸。
> 「外公，爸爸不能喝酒，」小满举着可乐罐喊，「妈妈说的。」
> 桌子另一头，表妹小声问：「姐夫家一直这样？」「十年了，」闺蜜替她答，「头两年我也这么问。」
> 那杯酒最后是她喝的。没人说什么，只有小满把可乐罐跟她的杯子碰了一下。
