# 第三人与群像

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测。节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的镜头不对着他们两个，十条都交给第三个人。第三个人怎么看、怎么称呼，外头就怎么认这段关系。

## 和配角功能位的对应

[04-人设原型/04-配角功能位设计](../04-人设原型/04-配角功能位设计.md) 里定了13个功能位，桥段库前面几卷的条目却几乎都是两个人之间的戏。功能位有定义，有设计卡，到了日常小剧情里，一场戏也没让它们出来过。这一族每条都挂到功能位上，把「位置」写成「一场戏」。

镜头给了第三个人，日常戏从哪儿来也跟着变了：

| | 二人场 | 借第三人的场 |
|---|---|---|
| 情绪来源 | 心里那点事 | 别人看岔的那块 |
| 关系显影 | 日子一天天过，人做出点啥 | 旁人怎么看、怎么传 |
| 一场戏的结果 | 谁先服软 | 谁露了哪手让人瞧见 |

语料侧的底数（13-07 实测）：

| 节拍族 | 作品数 | 占比 |
|---|---:|---:|
| 起哄 | 1,259 | 43.5% |
| 孩子 | 719 | 24.8% |
| 议论 | 609 | 21.0% |
| 聚会 | 338 | 11.7% |
| 闺蜜在场 | 328 | 11.3% |
| 旁人看 | 197 | 6.8% |

「旁人看」占 6.8%，上表里排最末。写第三人在场的多，肯把整场镜头交出去的少。频次低，只说明这条路上人少。

后面每条的表格怎么填，要先定借谁的眼睛看。同一场戏换个人看，看出来的完全两样：知道内情的看着扎心，不知道的当成撒糖。所以这一族的「双向写法」多了一步，除了定她写他还是他写她，还要选**借谁的眼睛看**。

## 一 · 嬷嬷位开口

`T` ｜ 无预警 ｜ 古代女尊／架空王朝（现代对应见变体轴）｜ 语料频次：请安 26.6%、立规矩 19.5%（13-07 实测）

**骨架**｜难听的规矩话，制度得借她的嘴说出来，主角不方便开口，另一个也接不了。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 起因很小：请安来晚了一回，一件东西放错了地方 |
| 2 | 嬷嬷开口，从小事一路说到「男子的本分」，规矩原话由她来念 |
| 3 | 他听着，目光越过嬷嬷的肩膀去找她 |
| 4 | 她不在场，或在场，没接话 |
| 5 | 嬷嬷说完，行个礼退下，从头到尾一个字都挑不出错 |
| 6 | 只剩两人时他转述这番话，最难听那句咽了回去 |
| 7 | 她怎么做：规矩不动，换个说法，或者干脆全都不动 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 晨昏定省的廊下 · 分例发放 · 进门第一课 · 有客在的前厅 |
| 她的话术 | 「不是老奴多嘴」开场 · 收尾必称「府里的规矩」，先声明权力是借来的 · 主动加码，主人没要求的她替主人要求了 |
| 他的反应 | 全程只应一个字 · 找她的视线落空 · 转述时删句 |
| 现代对应 | 执行秘书替他挡了那通电话 · HR 按章发的那份通知 · 助理提醒他「开会时间别发消息」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她知不知道 | 过后才知道 | 心里有数，装作不知道 |
| 嬷嬷忠于什么 | 忠于她这个人 | 忠于规矩本身，她也管不动 |
| 他的消化 | 转述时删掉几句，护着她 | 原话一字不落说给她听，把球踢回给她 |
| 世界 | 古代府邸 | 现代公司（秘书位、HR） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借嬷嬷的：主人破例的那一下，被执行规矩的人撞见 | 借他自己的：挨训时数着她说了几遍「规矩」 |
| 落点 | 听完转述，她发觉少了那一句 | 他的目光越过肩膀去找她，没找到 |
| 好的处理 | 她不骂嬷嬷，去改规矩 | 他删掉那句，是在护着她 |
| 写崩 | 写成恶仆欺主 | 写成他吓破了胆 |

#### 写崩的三种方式

1. 把嬷嬷写成坏心眼的NPC。 她每句话都挑不出错，吓人就吓在这里。写成恶仆，主角白得一块道德高地，这个功能位也就废了。
2. 让她当场发作。 当场驳嬷嬷就是当众拆台，那归[20-女尊制度场景·她改了规矩](20-女尊制度场景.md#七--她改了规矩)写。这里要的是事后再算。
3. 嬷嬷只露一次面。 天天都在的人才立得住规矩，只来一趟的只是传话的。

前接：[20-女尊制度场景 · 晨昏定省](20-女尊制度场景.md#一--晨昏定省)
功能位：[04-配角功能位设计 · 五、中层执行者](../04-人设原型/04-配角功能位设计.md#五中层执行者嬷嬷位)。主角不好说的话，借她的嘴说。
后接：[08-规训日常版](08-规训日常版.md)。同一套规矩，换成她亲口来说。
对照：[20-女尊制度场景 · 家法](20-女尊制度场景.md#六--家法)

## 二 · 竞争者上门

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：吃醋 43.1%（13-07 实测）

**骨架**｜另一个女攻直接来撩他，他怎么应对，就能看出这段关系稳不稳。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 场合给了机会：她不在，或者在场但离得有点远 |
| 2 | 搭讪不掉价，条件讲得清清楚楚，是个体面的邀请 |
| 3 | 他听完了，没有打断，这是教养 |
| 4 | 拒绝时不辩解，不炫耀，一句讲明自己归谁 |
| 5 | 竞争者认输不认错：人撤了，可不觉得自己看错了人 |
| 6 | 他说不说：回去后提不提这件事 |
| 7 | 她的反应，看她先问的是哪一句 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 竞争者的开场 | 递名片 · 「她不懂珍惜你」，挑拨关系但不贬低你 · 条件确实好：更有钱、更闲、更温柔 |
| 他的应对分层 | 听完 → 名片还回去 → 说一句 → 不接第二茬 |
| 那句话的版本 | 「我有人了」最省事 · 「她懂我」最戳心 · 直接报她名字最狠，宣告主权，反着来 |
| 她的反应 | 先问「你怎么回的」，没问「她是谁」，先问哪句就露出她在意什么 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她在不在场 | 不在，他一个人应付 | 在，远远看完全程，没插手 |
| 竞争者的强度 | 条件确实更好 | 条件一般，但正好懂他那行 |
| 他讲不讲 | 自己说了 | 没说，她从旁人那儿听来的 |
| 后续 | 只那一回 | 同圈子的同事，天天见面，也没改口 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借竞争者的：她看上的这个他，和我看到的他差在哪儿 | 借他自己的：拒绝用不着想，话就在嘴边 |
| 落点 | 「你怎么回的」一出口，她才发觉自己上心了 | 还名片的那一下，他手很稳 |
| 好的处理 | 她始终没插手，这一局整个交给他 | 他拒绝得很平静，过后不炫耀，也不讨赏 |
| 写崩 | 写成她冲出来抢人，跟人宣战 | 写成他到处显摆自己有人追 |

#### 写崩的三种方式

1. 把竞争者写成小丑。 对方条件差，他拒绝也就不稀奇了。对方够强，这一拒才有分量。
2. 让她出手抢人。 镜头一回到她身上，就退回 [05-占有与吃醋](05-占有与吃醋.md) 那一卷了。这里要她按兵不动。
3. 靠贬低对方来拒绝。 他只需要说清自己归谁。一踩人，他的教养跟这段关系一起掉价。

#### 可串接

前接：[05-占有与吃醋 · 那个人是谁](05-占有与吃醋.md#一--那个人是谁)
功能位：[04-配角功能位设计 · 二、阻碍位](../04-人设原型/04-配角功能位设计.md#二阻碍位)立场合理，全程不改口· [04-配角功能位设计 · 四、对照组位](../04-人设原型/04-配角功能位设计.md#四对照组位)，更好的选项被当面拒绝
后接：[05-占有与吃醋 · 当众宣示](05-占有与吃醋.md#八--当众宣示)

## 三 · 镜像位的婚礼

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：婚仪 38.8%（13-07 实测）

**骨架**｜两人去参加另一对四爱的婚礼，从头到尾都在别人身上找自己的影子。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 收到请柬，新人是圈里认识的那一对 |
| 2 | 路上没怎么说话，两人想到的是同一件事，谁也没说破 |
| 3 | 仪式顺序和寻常的反过来：她先上台等他，戒指也由她给他戴 |
| 4 | 他偷看她，她也偷看他，目光撞上了 |
| 5 | 邻桌有人小声嘀咕了一句，这场婚事因此显得有了分量 |
| 6 | 敬酒敬到他们这桌，新人看着他们，四个人都心照不宣 |
| 7 | 回程总得有个人先开口，可说出来的话和婚礼一点不沾边 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 请柬 ✓（1.2×）· 喜糖 ✓（1.6×）· 座位卡 · 手捧花最后给了谁 |
| 反着来的环节 | 谁先上台说话 · 戒指谁先伸手 · 他跑去接捧花 · 酒往哪边挡 |
| 各自的小动作 | 她心里过流程，像背课文 · 他把喜糖塞兜里，一路捏着没撒手 |
| 旁桌那句 | 「男方家也点头了？」这一句就是杆秤 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 镜像方向 | 前向：人家已经走完这一步 | 后向：人家刚在一起，看着像当年的自己 |
| 两人的阶段 | 还没谈到结婚，这场是个引子 | 已经订婚，这场是提前演练 |
| 那对过得怎样 | 真感情，让人羡慕 | 饭桌上拌了两句嘴，让人心里发凉 |
| 收束 | 回去路上把话说开了 | 谁都没提，晚上那盒喜糖搁在桌上没人动 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借她的：一整场盯着那个新郎，看他像谁 | 借他的：一整场看新娘牵手的动作，从里面认出了她 |
| 落点 | 发现自己在记流程笔记 | 兜里的喜糖被捏软了 |
| 好的处理 | 她不问他愿不愿意，改成留意他的反应 | 他不催，只把请柬收了起来 |
| 写崩 | 写成她当场逼婚 | 写成他自卑：这种日子轮不到我们 |

#### 写崩的三种方式

1. 镜像那对写成纸片人。 他们得真到有自己的裂缝。一场婚礼从头到尾只为主角服务，就成了布景。
2. 当场表白或者求婚。 引信当场就炸，镜像就白铺了。这里要写的是回程车上那句没头没尾的话。
3. 把议论写成满场敌意。 邻桌只要一句。句句带刺，就滑进 [14-社交与公开](14-社交与公开.md) 的另一场戏。

#### 可串接

前接：[44-圈层与同好](44-圈层与同好.md)，新人是从同好圈里来的。
功能位：[04-配角功能位设计 · 一、镜像位](../04-人设原型/04-配角功能位设计.md#一镜像位)，镜像要亲眼看见才起作用，听人转述不算。
后接：[23-婚嫁 · 求婚](23-婚嫁.md#一--求婚)（引信引燃）· [23-婚嫁 · 当天](23-婚嫁.md#七--当天)（轮到他们）

## 四 · 对照组同框

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：聚会 11.7%（13-07 实测）

**骨架**｜一桌两对，一对老派夫妻，一对他们。谁也没点破，差别自己就浮上来了。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 组局：老同学两口子约饭，四个人坐一桌 |
| 2 | 一坐下就看出差别：对面他点菜她刷手机，这边她拿菜单，说忌口的是他 |
| 3 | 头一轮对比：倒茶、剥虾、接电话，同一件事两边做法正好相反 |
| 4 | 对面先反应过来，那男的开了句玩笑 |
| 5 | 羡慕藏不住：对面媳妇儿看他给她剥虾，眼神多停了一秒 |
| 6 | 话头蹭到雷区“你们家谁管钱”，两家各答各的，答案正好拧着 |
| 7 | 散场各走各的，两对在自家车里聊起对方 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 对照的物件 | 菜单（谁接）· 买单，谁的手机先掏出来 ✓ · 车钥匙（谁开）· 虾壳堆谁那边 |
| 对面妻子的三次注视 | 他递水时 · 他记得她不吃啥时 · 买单她伸手他没拦时 |
| 对面丈夫的玩笑 | 「兄弟你这么惯着，以后管不住啊」，一个「管」字露了他的底 |
| 车里的复盘 | 对面那对没说话的时间，比咱俩这边长 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 对面过得怎样 | 恩爱的传统夫妻，对照才公平 | 面和心不和，这边成了照妖镜 |
| 先觉察的人 | 对面妻子 | 对面丈夫，他的别扭说不出口 |
| 雷区话题 | 谁管钱 | 要不要孩子、谁带 |
| 收束 | 互留好印象 | 对面当晚吵了一架，起头是一句「人家……」 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借对面丈夫的：他看不懂的地方，就是差别所在 | 借对面妻子的：她多看的每一眼都在掂量 |
| 落点 | 「管不住」那句她没接，他自己接了：「不用管。」 | 对面妻子问他「你不介意吗」，他隔了半秒才明白介意什么 |
| 好的处理 | 不让这边赢：对面也有这边没有的东西 | 他的自然是本色，没有一分表演给对面看 |
| 写崩 | 写成传统夫妻被打脸 | 写成他向对面开讲座 |

#### 写崩的三种方式

1. 把对面写成反面教材。 对照要公平，对面也得有真感情，一边倒的对照是宣传画。
2. 有人把差别说破。 这条要的是无声，谁说破谁输。说破版走 [14-社交与公开 · 被起哄](14-社交与公开.md#一--被起哄)。
3. 四个人全程发言。 群像戏要留一个只看不说的人。人人抢话，就没有镜头了。

#### 可串接

前接：[29-微小仪式拾遗 · 剥虾](29-微小仪式拾遗.md#八--剥虾)，拿这个当最小对照单元看。
功能位：[04-配角功能位设计 · 四、对照组位](../04-人设原型/04-配角功能位设计.md#四对照组位)，同一件事，让两对人都做一遍，规则自己就露出来了。
后接：[13-家庭与亲属 · 要不要孩子](13-家庭与亲属.md#四--要不要孩子)，雷区话题正式开聊。

## 五 · 解说员

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：闺蜜在场 11.3%、议论 21.0%（13-07 实测）

**骨架**｜知情的人给不知情的人解释他们俩的关系，越卖力讲得越离谱。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 新来的人进场，新同事、远房亲戚、刚回国的老朋友，撞见反常的一幕：她在开会，他在楼下等 |
| 2 | 新人一开口，问题里就带着预设：「她男朋友怕她？」 |
| 3 | 解说员开讲，三分对七分错，错的地方全按解说员自己的世界观来 |
| 4 | 当场对证：本人出现了，做的跟讲的对不上 |
| 5 | 新人再问，问题换了，预设松动了 |
| 6 | 解说员收尾：「反正他们过得挺好。」 |
| 7 | 本人一直不知道有过这场解说，或者她听到了一段，没去纠正 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 错法清单 | 时间线错（以为她追的他）· 因果错（以为他图钱）· 分工错，以为家里她做饭 · 唯一说对的：「他俩谁也离不开谁」 |
| 新人的问题 | 上来先问身份 · 再问「图什么」 · 第三回干脆不问了 |
| 验证场面 | 正说到「她说一不二」，楼下恰好撞见她给他撑伞拎包 |
| 解说员的身份 | 闺蜜错得最少 · 同事错得最典型 · 邻居阿姨错得最善良 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 与他们的距离 | 近（闺蜜：错在细节） | 远（邻居：错在框架） |
| 错误的性质 | 笑点：想当然，无伤大雅 | 刀点：错的偏偏是他们最疼的地方，比如「反正他们不会要孩子」 |
| 正主知不知道 | 全程不知道 | 她听到一段，没纠正 |
| 新人的去向 | 被说服 | 没被说服，自己观察出了第三个版本 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借新人的：第一次看，没成见，反而比熟人准 | 借解说员的：错处一条条数下来，倒拼全了别人眼里的他 |
| 落点 | 她听到的那段解说里，只有一句是对的 | 别人替他回答「图什么」，答了三个版本，一个都不沾边 |
| 好的处理 | 她不去纠正，错的版本反而把真的那个护住了 | 那些说法他都知道，一个也不认 |
| 写崩 | 写成她当场揭穿、打脸辟谣 | 写成他偷听了，心里难受，自己躲起来 |

#### 写崩的三种方式

1. 解说员句句都对。 全对就成了作者在念稿，解说员错在哪，就看得出这是个什么样的人。
2. 解说员有立场。 一替谁说话，解说就变成宣传，新人和读者都要打个折扣去听。
3. 一股脑倒信息。 一口气讲完两人的十年，就成了设定说明书。拆成三次讲，每次讲一半，错一半。

#### 可串接

前接：[30-她的世界 · 她的闺蜜](30-她的世界.md#三--她的闺蜜)。她是错得最少的解说员，照样会带偏。
功能位：[04-配角功能位设计 · 七、解说员](../04-人设原型/04-配角功能位设计.md#七解说员管家型)。没有立场才当得了解说员，说法要有固定的套路。
后接：[14-社交与公开 · 议论](14-社交与公开.md#二--议论)。解说一失控就成了议论。还有[26-重生穿书与系统 · 失忆后重新认识](26-重生穿书与系统.md#九--失忆后重新认识)，这里最用得上解说员的本事。

## 六 · 兄弟局

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：聚会 11.7%、游戏 21.7%（13-07 实测）

**骨架**｜她走进他那个只有男人的圈子，球场、健身房、开黑局。先被人从头到脚打量一遍，才被拉进来，每种玩法都有自己的规矩。

|---|---|

| 2 | 一进场就是试探：没人跟她搭话，人人都在打量她，传球先绕过她 |
| 3 | 头一次掂量她，故意出个难题：一个球，一组重量，一局排位 |
| 4 | 她做到了，或者没做到。两样都行，往下走法不同 |
| 5 | 某一刻称呼变了：「嫂子」改成直呼名字，或者反过来 |
| 6 | 有人背地里跟他说了句话，兄弟间的认可向来不当面说 |

| 类 | 内容 |
|---|---|
| 空间的规矩 | 球场：传不传她球 · 健身房：帮不帮她加片 · 开黑局：语音里谁先跟她搭话 |

| 接纳的信号 | 递水时把她算进去 · 下次组局群里拉上她 · 有人当面骂他，当外人面不骂人 |
| 她的处理 | 不装内行 · 输了认 · 赢了也不端着，端着才是看不起人 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的水平 | 真强，碾压全场 | 纯新手，肯下功夫学 |
| 空间 | 球场、健身房 | 开黑局：隔着语音，没人盯着她看 |
| 兄弟们的顾虑 | 怕她玩得不痛快 | 怕在她面前露怯，她官太大 |
| 收束 | 以后固定叫她 | 只去了那一次，后来他在局里常提起她 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借兄弟里最横的那个：他最不服人，他服了才算数 | 借他自己的：两边都看着，怕兄弟没面子，也怕她寒心 |
| 落点 | 有人当她面骂他，她笑了，知道这是认她了 | 群里弹出「下周还带弟妹吗」那一秒 |
| 好的处理 | 她守这里的规矩，不摆公司那套架子 | 他不替她出头，让她自己闯进去 |
| 写崩 | 写成她一路碾压，兄弟全服 | 写成兄弟全不懂事，就为了抬她 |

#### 写崩的三种方式

1. 写成她一个人的秀。 可以碾压，可被接纳靠的是守规矩，赢一场换不来以后的固定名额。
2. 把兄弟们写成起哄的背景板。 起码得有一个人有自己的顾虑，也有转变。一群工具人接纳她，不值钱。
3. 让他一路护着。 他一挡，别人的打量碰不到她，也就谈不上接纳。

## 七 · 她的下属看见了

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：上下级 17.5%、议论 21.0%（13-07 实测）

**骨架**｜女上司蹲下来给他系鞋带，被下属撞见了。不到两天，公司里传出了七个版本。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 撞见：在电梯口或者停车场，她蹲下去，就两秒钟 |
| 2 | 撞见的人头一个反应是退回去装没看见，手机都没敢举 |
| 3 | 头一回只讲给一个人听，还叮嘱了三遍「别说出去」 |
| 4 | 版本分裂：小白脸 → 倒贴 → 其实是她老公 → 老公又怎样，蹲下的是她 |
| 5 | 传闻碰上她本人：茶水间一下子静得太快，她端着杯子走出来 |
| 6 | 她怎么处理：不澄清，不追查，第二天一切照常 |
| 7 | 传闻怎么消停：一周后有了新瓜，或者她带他出席年会，一锤定音 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 画面要素 | 她蹲着 · 他伸手想拦，被一把拍开 · 系完她抬头说了句啥，没人听清，这空当就是流言的苗床 |
| 发酵介质 | 茶水间 · 工作群小号 · 午饭拼桌 · 屏幕上晃一眼的消息 ✓ |
| 版本规律 | 每传一版都更圆乎，也更邪乎 |
| 她的读数 | 下属看她的眼神变了，是更不怕她了，还是更怕了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 撞见者 | 她的心腹，嘴严实 | 刚来的实习生，啥都往外说 |
| 传闻方向 | 说他：吃软饭 | 说她：「她居然会蹲下」，大家惊的是她肯弯腰 |
| 她的处理 | 不搭理 | 年会带他露面，明着认人 |
| 他知不知道 | 始终不知道 | 知道了，先是乐，后来难受，难受的是她被人嚼舌根 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借撞见者的：她蹲下去的那两秒，下属对她的看法当场变了 | 借他自己的：伸手拦，被拍开，随她去 |
| 落点 | 茶水间静下来那一秒，她全听懂了 | 他后来才知道，那两秒在公司里够传多少闲话 |
| 好的处理 | 她不管别人怎么传，自己该干嘛干嘛 | 他不觉得被看见是丢脸 |
| 写崩 | 写成她摆架子查谁嘴碎 | 写成他从此躲着她走 |

#### 写崩的三种方式

1. 传闻只有一个版本。 传着会变样才叫发酵，一个传一个原样复述是通知，算不上传闻。
2. 让她拿权力去压。 一查一封口，日常戏就成了职场惊悚片，她有分寸，就是按着不动。
3. 跳过撞见者的心思。 头一个人犹豫说不说、跟谁说，后面的一串都从这里长出来。直接跳到满城风雨，这一串就接不上了。

#### 示例（本库自撰，可直接改写）

> 电梯到负二层，门开了一半，小周看见的是：李总蹲在车边，正给那个男人系鞋带。
> 男人伸手来拦，被她拍开了。她系得不快，系完抬头说了句什么，男人就笑。
> 门合上了。负二到十七楼，小周的手心出了一层汗。
> 下午她只告诉了拼午饭的同事一个人，外加三遍「别说出去」。
> 第二天，茶水间有人反过来凑近她：「听说了没，李总在停车场给人跪下了！」
> 「是系鞋带，」她脱口纠正，说完才反应过来自己成了信源。

| 世界 | 现代两家 | 古代女尊，整个反过来：他家怕高攀不上 |

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借他母亲的：一直盯着看，其实是怕儿子受委屈 | 借她父亲的：闷着头下棋，让了三个子 |

1. 四位长辈看法一模一样。 四个人看出四样来才有戏，看法都一样，就跟只写了一位没区别。
2. 把长辈写成制度的传声筒。 反对也好接受也好，都得有私人的来由，比如自己婚姻的影子。只会讲大道理的长辈就是块标语牌。

## 九 · 孩子看父母

`T` ｜ 无预警 ｜ 全谱系（婚后有子设定）｜ 语料频次：孩子 24.8%（13-07 实测）

**骨架**｜孩子觉得妈妈说了算是天经地义。出门转了一圈，回到家又被掰了回来。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 先摆出孩子眼里的常识：签字找妈妈，破了洞找爸爸，两样都想要的先找爸爸，再让爸爸去找妈妈 |
| 2 | 外头的样板进来了：同学说「我家我爸说了算」，课本插图里系围裙的是妈妈 |
| 3 | 孩子的疑问很小，只是在核对事实：「你家的爸爸不做饭吗？」 |
| 4 | 问题带回家，饭桌上问出来，时机总是最准 |
| 5 | 父母来答：谁接，怎么接。他答的和她答的不一样 |
| 6 | 孩子想明白了，第二天用自己的话讲给同学听，讲得比父母原话还顺 |
| 7 | 最后一拍：孩子作文或画里的这个家 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 孩子的账本 | 开家长会的是妈妈 · 编辫子的是爸爸 · 打雷时三个人挤一张床的位次 |
| 那个问题 | 「为什么咱们家跟别人家是反的？」孩子说的「反」没有褒贬，只是说顺序 |
| 两个版本的答案 | 他背对着灶台答：「谁的事谁说了算，家里的事妈妈懂得多。」她放下筷子答：「你爸做饭好吃，我挣钱多，各干各的强项。」 |
| 转译版 | 「我妈是队长，我爸是管家，我是队员」，官职是孩子自己封的 |
| 画里的证据 | 全家福里妈妈画得最大 · 爸爸手里有锅铲 · 三个人手牵手的次序 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 孩子的年纪 | 学龄前，问题最直 | 小学高年级，开始护短，为这事跟同学吵了一架 |
| 模板来源 | 同学 | 课本、动画片：没人可吵，只能回家问 |
| 谁接的问题 | 他接，背对着答 | 她接，放下筷子正面答 |
| 尾拍 | 作文被老师当堂念了 | 什么也没写，照旧过，常识用不着表态 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借孩子的：在孩子那里妈妈一直是「靠谱」，谈不上「强势」 | 借孩子的：爸爸的围裙就跟别人爸爸的公文包一样平常 |
| 落点 | 她听见转译版「我妈是队长」的那一秒 | 孩子跟同学吵架护的是他：「我爸做的饭比你爸买的好吃」 |
| 好的处理 | 别借孩子的嘴喊口号，孩子只讲事实 | 他答的时候不自嘲，他一自嘲，孩子就学会了羞耻 |
| 写崩 | 孩子说出大人话 | 写成孩子被歧视的苦情戏 |

#### 写崩的三种方式

1. 让孩子当传声筒。 五岁的孩子说三十岁的话，一句就露馅。孩子的台词只能用孩子的话：吃的、玩的、谁大谁小。
2. 把疑问写成创伤。 孩子只是在核对事实，答得好当天就过去了。写成身份危机，等于给大人的焦虑套了件小孩的外衣。
3. 家里一直不接这个话。 问题得认真答，糊弄过去的问题会在孩子心里发霉。

## 十 · 一桌人的那顿饭

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：聚会 11.7%、旁人看 6.8%（13-07 实测）

**骨架**｜一顿家宴，镜头从桌上每个人身上挨个扫过。两个主角从头到尾没有内心戏，全由别人把他们拼出来。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 帮厨阿姨的镜头（嬷嬷位）：单子是先生开的，钱是太太转的，谁当家她心里清楚 |
| 2 | 她父亲的镜头（阻碍位）：数着他给女儿夹了几回菜，数到第七回就不数了 |
| 3 | 闺蜜的镜头（解说员）：小声给桌上新来的表妹讲这两人的旧事，故意讲错一处 |
| 4 | 他兄弟的镜头（对照组位）：看着看着想到自己家，低头给老婆发了条消息 |
| 5 | 孩子的镜头：谁杯子空了由爸爸添，瓶盖由妈妈开 |
| 6 | 新婚小夫妻的镜头（镜像位）：从这两人身上看十年后的自己 |
| 7 | 共识事件：她替他挡了那杯酒，人人都看见了，没人说破，各记在心里 |
| 8 | 收尾镜头拉远：桌子底下那两只手，桌上没人看见，只有读者看见 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 视点纪律 | 一个镜头只跟一个人，别让两个人同时盯着同一件事 |
| 各镜头的专属物 | 阿姨看分工 · 长辈看筷子 · 闺蜜看眼色 · 兄弟看自己 · 孩子看杯子 · 新人看未来 |
| 双轨声部 | 桌面上聊得热闹，心里各想各的 |
| 散席的残局 | 谁的碗空谁的碗满 · 她爸那杯酒没动就撤了 · 打包袋最后谁拎走 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 年夜饭，人齐 | 寿宴、满月酒：有外圈客人，看的人更多 |
| 视点数 | 四个，挤一桌 | 七个，该来的都来了，得花笔墨铺 |
| 共识事件 | 她替他挡酒 | 他接过长辈的话，帮她打圆场 |
| 收束镜头 | 桌下的手 | 散席后，桌上剩残羹剩酒 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 从最看不上他的她爸看起，收在孩子身上 | 从最亲的兄弟、阿姨看起，收在她家长辈那里 |
| 落点 | 挑刺的人数到第七筷子，不数了 | 散席时她爸那杯酒空了，是她喝的 |
| 好的处理 | 主角从头到尾不写心里话，全靠别人的眼神拼出这个人 | 每换一个视角，两人的样子就重描一遍 |
| 写崩 | 写成一群人排着队夸她 | 写成俩人当众秀恩爱给人看 |

#### 写崩的三种方式

1. 人人抢着说话，没人在看。 群像戏的镜头就是一双双眼睛，满桌都是金句，等于没有镜头。
2. 视点换来换去，看到的全一样。 七双眼睛得出同一个结论，换视点也就没意义了。
3. 给主角写内心戏。 这里的规矩是两个主角从头到尾不出心声，一开口，整场群像就散了。

#### 示例（本库自撰，可直接改写）

> 张姨端最后一道菜上桌，心里有了数：单子是先生开的，钱是太太转的。
> 老爷子那边数到第七筷，把面前那杯酒往女婿跟前推了半寸。
> 「外公，爸爸不能喝酒，」小满举着可乐罐喊，「妈妈说的。」
> 桌子另一头，表妹小声问：「姐夫家一直这样？」「十年了，」闺蜜替她答，「头两年我也这么问。」
> 那杯酒最后是她喝的。没人说什么，只有小满把可乐罐跟她的杯子碰了一下。
