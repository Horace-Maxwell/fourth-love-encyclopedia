# 第三人与群像

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**镜头不在两人身上。** 第三人的眼睛量出这段关系在世界里的尺寸，第三人的嘴替世界给它定名。

## 这一族补哪条空档

[04-人设原型/04-配角功能位设计](../04-人设原型/04-配角功能位设计.md) 里立了13个功能位，但桥段库前面几卷的条目基本全是两个人之间的戏。功能位有定义、有设计卡，可日常微剧情这一层，没有一条戏真让它们上场。这一族逐条挂到功能位上，把「位置」变成「一场戏」。

镜头交给第三人之后，日常戏的发动机跟着换：

| | 二人场 | 借第三人的场 |
|---|---|---|
| 情绪来源 | 心里那点事 | 别人看岔的那块 |
| 关系显影 | 日子一天天过，人做出点啥 | 旁人怎么看、怎么传 |
| 一场戏的产出 | 谁先服软 | 谁露了哪手让人瞧见 |

语料侧的底数（13-07 实测）：

| 节拍族 | 作品数 | 占比 |
|---|---:|---:|
| 起哄 | 1,259 | 43.5% |
| 孩子 | 719 | 24.8% |
| 议论 | 609 | 21.0% |
| 聚会 | 338 | 11.7% |
| 闺蜜在场 | 328 | 11.3% |
| 旁人看 | 197 | 6.8% |

「旁人看」6.8%，在上表垫底：写第三人在场的多，肯把整场镜头交出去的少。频次低只等于竞争小。

「双向写法」在这一族里多一步：不光要定她写他、他写她，还得选**借谁的眼睛看**。同一场戏，借看得懂的人的眼睛，就是刀；借看不懂的人的眼睛，就是糖。后面每一条的表格，都围着这个选择来填。

## 一 · 嬷嬷位开口

`T` ｜ 无预警 ｜ 古代女尊／架空王朝（现代对应见变体轴）｜ 语料频次：请安 26.6%、立规矩 19.5%（13-07 实测）

**骨架**｜制度得借她的嘴说句难听话，主角不方便开口，另一个也没法接。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 事由很小，一次请安来晚了、一件东西搁错了地方 |
| 2 | 嬷嬷开讲，从小事一路扯到「男子的本分」，规矩的原话由她念出来 |
| 3 | 他听着，眼神越过嬷嬷的肩去找她 |
| 4 | 她不在场，或在场，没接话 |
| 5 | 嬷嬷讲完，行礼退下，全程挑不出一个字的毛病 |
| 6 | 独处时他转述这段话，把最难听的那句咽了回去 |
| 7 | 她的做法：规矩留着，说法换掉，或干脆什么都不动 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 晨昏定省的廊下 · 分例发放 · 进门第一课 · 有客在的前厅 |
| 她的话术 | 「不是老奴多嘴」开场 · 收尾必称「府里的规矩」，先声明权力是借来的 · 主动加码，主人没要求的她替主人要求了 |
| 他的反应 | 全程只应一个字 · 找她的视线落空 · 转述时删句 |
| 现代对应 | 执行秘书替他挡了那通电话 · HR 按章发的那份通知 · 助理提醒他「开会时间别发消息」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她知不知道 | 事后才知道 | 她心里有数，但装不知道 |
| 嬷嬷忠于什么 | 忠于她这个人 | 忠于规矩本身，她也管不动 |
| 他的消化 | 转述时删几句，护着她 | 原话全说给她听，把球踢回去 |
| 世界 | 古代府邸 | 现代公司（秘书位、HR） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借嬷嬷的：主人破例那一瞬，让执行者撞见了 | 借他自己的：听训时数她说了几遍「规矩」 |
| 落点 | 听完转述，她发现那句被删了 | 视线越过肩去找她，没找着 |
| 好的处理 | 她不骂嬷嬷，她改规矩 | 删句是为了护，不是怕 |
| 写崩 | 写成恶仆欺主 | 写成他吓破了胆 |

#### 写崩的三种方式

1. 把嬷嬷写成恶意NPC。她每句话都挑不出错，吓人的地方就在这。写成恶仆，主角白捡一个道德高地，这个位子就废了。
2. 让她当场发作。当场驳嬷嬷等于当众拆台，那是[20-女尊制度场景·她改了规矩](20-女尊制度场景.md#七--她改了规矩)的事。这条讲究的是秋后算账。
3. 嬷嬷只出场一次。天天在场的人才能立住规矩，只来一趟的那是传话的。

#### 可串接

前接：[20-女尊制度场景 · 晨昏定省](20-女尊制度场景.md#一--晨昏定省)
功能位：[04-配角功能位设计 · 五、中层执行者](../04-人设原型/04-配角功能位设计.md#五中层执行者嬷嬷位)。主角不方便讲的话，借她的嘴说出来。
后接：[08-规训日常版](08-规训日常版.md)。同一套规矩，她亲口说出来的样子。
对照：[20-女尊制度场景 · 家法](20-女尊制度场景.md#六--家法)

## 二 · 竞争者上门

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：吃醋 43.1%（13-07 实测）

**骨架**｜另一个女攻直接来撩他，他能不能应付，这段关系成色立马见分晓。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 场合给了机会：她不在场，或者在场但隔着一段距离 |
| 2 | 搭讪不丢人，条件摆得明明白白，是一份体面的邀请 |
| 3 | 他听完了，没打断，礼貌是教养 |
| 4 | 拒绝：不辩解、不炫耀，一句话说清归属 |
| 5 | 竞争者认输不认错：撤了，但不觉得自己看走眼 |
| 6 | 他讲不讲：回去以后提不提这事 |
| 7 | 她的反应，先问出口的那个问题 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 竞争者的开场 | 递名片 · 「她不懂珍惜你」，挑拨关系但不贬低你 · 条件确实好：更有钱、更闲、更温柔 |
| 他的应对分层 | 听完 → 名片还回去 → 说一句 → 不接第二茬 |
| 那句话的版本 | 「我有人了」最省事 · 「她懂我」最戳心 · 直接报她名字最狠，宣告主权，反着来 |
| 她的反应 | 先问「你怎么回的」而不是「她是谁」，问哪个就暴露她心里在意啥 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她在不在场 | 不在，他独自应对 | 在，远远看着全程，没插手 |
| 竞争者的强度 | 条件确实更好 | 条件一般，但正好懂他那行 |
| 他讲不讲 | 自己说了 | 没说，她从旁人那儿听来的 |
| 后续 | 就那一回 | 同圈子的同事，天天见，也没改口 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借竞争者的：她看中的他，跟我看见的他差在哪 | 借他自己的：拒绝不用想，答案就在嘴边 |
| 落点 | 「你怎么回的」问出口，才发觉自己上心了 | 名片还回去那一下，手没抖 |
| 好的处理 | 她从头到尾没插手，这一局全交给他 | 他拒得平平静静，事后不显摆、不讨赏 |
| 写崩 | 写成她冲出来抢人，跟人宣战 | 写成他到处显摆自己有人追 |

#### 写崩的三种方式

1. 竞争者写成小丑。条件不行，他的拒绝就不值钱。对照够强，拒绝才有分量。
2. 让她出手抢人。镜头一转回她，这条就退回 [05-占有与吃醋](05-占有与吃醋.md) 了。这一族的机关是她不动。
3. 拒绝靠贬低对方完成。他要说的只有归属。一踩人，他的教养和这段关系一起掉价。

#### 可串接

前接：[05-占有与吃醋 · 那个人是谁](05-占有与吃醋.md#一--那个人是谁)
功能位：[04-配角功能位设计 · 二、阻碍位](../04-人设原型/04-配角功能位设计.md#二阻碍位)立场合理，全程不改口· [04-配角功能位设计 · 四、对照组位](../04-人设原型/04-配角功能位设计.md#四对照组位)，更好的选项被当面拒绝
后接：[05-占有与吃醋 · 当众宣示](05-占有与吃醋.md#八--当众宣示)

## 三 · 镜像位的婚礼

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：婚仪 38.8%（13-07 实测）

**骨架**｜去参加另一对四爱的婚礼，整场他俩都在别人身上找自己的影子。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 请柬到了，一看新人，是圈里认识的那一对 |
| 2 | 路上话不多，俩人心里都想起同一件事，谁也没挑明 |
| 3 | 仪式顺序跟平常反着来：她先上台等他，戒指也是她给他戴 |
| 4 | 他偷瞄她，她也偷瞄他，正好撞上 |
| 5 | 旁边桌有人嘀咕了一句，这话让这婚事显得有点分量 |
| 6 | 敬酒轮到他们这桌，新人看着他们，四个人心里都明白 |
| 7 | 回去路上，总得有个人先开口，可张嘴说的，跟婚礼半点不沾 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 请柬 ✓（1.2×）· 喜糖 ✓（1.6×）· 座位卡 · 手捧花最后给了谁 |
| 反着来的环节 | 谁先上台说话 · 戒指谁先伸手 · 他跑去接捧花 · 酒往哪边挡 |
| 各自的小动作 | 她心里过流程，像背课文 · 他把喜糖塞兜里，一路捏着没撒手 |
| 旁桌那句 | 「男方家也点头了？」一句话就是杆秤 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 镜像方向 | 前向：对方已经走完了 | 后向：对方刚在一起，看他们像看当年的自己 |
| 两人的阶段 | 还没谈到结婚，这场是个引子 | 已经订婚，这场是提前演练 |
| 那对的成色 | 真感情，让人羡慕 | 饭桌上拌了两句嘴，让人心里发凉 |
| 收束 | 回去路上把话说开了 | 谁都没提，晚上那盒喜糖搁在桌上没人动 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借她自己的：整场盯的是对面那个新郎，找他像谁 | 借他自己的：整场看的是新娘牵手的动作，认出了她 |
| 落点 | 发现自己在记流程笔记 | 兜里的喜糖被捏软了 |
| 好的处理 | 她不问他愿不愿意，她开始看他的反应 | 他不催，只是把请柬留了下来 |
| 写崩 | 写成她当场逼婚 | 写成他自卑：这种日子轮不到我们 |

#### 写崩的三种方式

1. 镜像那对是纸片人。他们得真实到有自己的裂缝。全程只为主角服务的婚礼是布景。
2. 当场表白或求婚。引信当场引爆，镜像就白搭了。这条的产出是回程车里那句没头没尾的话。
3. 议论写成满场敌意。旁桌只需要一句。句句带刺，就滑进 [14-社交与公开](14-社交与公开.md) 的另一条戏了。

#### 可串接

前接：[44-圈层与同好](44-圈层与同好.md)，新人从同好圈里来，同轮在写。
功能位：[04-配角功能位设计 · 一、镜像位](../04-人设原型/04-配角功能位设计.md#一镜像位)，镜像的效力全在亲眼看见，转述无效。
后接：[23-婚嫁 · 求婚](23-婚嫁.md#一--求婚)（引信引燃）· [23-婚嫁 · 当天](23-婚嫁.md#七--当天)（轮到他们）

## 四 · 对照组同框

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：聚会 11.7%（13-07 实测）

**骨架**｜一桌两对，一对老派夫妻，一对他们。谁也没点破，差别自己就浮上来了。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 组局：老同学两口子约饭，四个人坐一桌 |
| 2 | 一坐下就看出差别：对面他点菜她刷手机，这边她拿菜单，说忌口的是他 |
| 3 | 头一轮对比：倒茶、剥虾、接电话，同一件事两边做法正好相反 |
| 4 | 对面先反应过来，那男的开了句玩笑 |
| 5 | 羡慕藏不住：对面媳妇儿看他给她剥虾，眼神多停了一秒 |
| 6 | 话头蹭到雷区“你们家谁管钱”，两家各答各的，答案正好拧着 |
| 7 | 散场各走各的，两对在自家车里聊起对方 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 对照的物件 | 菜单（谁接）· 买单，谁的手机先掏出来 ✓ · 车钥匙（谁开）· 虾壳堆谁那边 |
| 对面妻子的三次注视 | 他递水时 · 他记得她不吃啥时 · 买单她伸手他没拦时 |
| 对面丈夫的玩笑 | 「兄弟你这么惯着，以后管不住啊」，一个「管」字露了他的底 |
| 车里的复盘 | 对面那对没说话的时间，比咱俩这边长 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 对面的成色 | 恩爱的传统夫妻，对照才公平 | 面和心不和，这边成了照妖镜 |
| 先觉察的人 | 对面妻子 | 对面丈夫，他的别扭说不出口 |
| 雷区话题 | 谁管钱 | 要不要孩子、谁带 |
| 收束 | 互留好印象 | 对面当晚吵了一架，起头是一句「人家……」 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借对面丈夫的：他看不懂的地方，就是差别所在 | 借对面妻子的：她多看的每一眼都在掂量 |
| 落点 | 「管不住」那句她没接，他自己接了：「不用管。」 | 对面妻子问他「你不介意吗」，他隔了半秒才明白介意什么 |
| 好的处理 | 不让这边赢：对面也有这边没有的东西 | 他的自然是本色，没有一分表演给对面看 |
| 写崩 | 写成传统夫妻被打脸 | 写成他向对面开讲座 |

#### 写崩的三种方式

1. 把对面写成反面教材。 对照要公平，对面也得有真感情，一边倒的对照是宣传画。
2. 有人把差别说破。 这条的机关是无声，谁说破谁输。说破版走 [14-社交与公开 · 被起哄](14-社交与公开.md#一--被起哄)。
3. 四个人全程发言。 群像戏要留一个只看不说的人。人人抢话，就没有镜头了。

#### 可串接

前接：[29-微小仪式拾遗 · 剥虾](29-微小仪式拾遗.md#八--剥虾)，拿这个当最小对照单元看。
功能位：[04-配角功能位设计 · 四、对照组位](../04-人设原型/04-配角功能位设计.md#四对照组位)，同一件事，让两对人都做一遍，规则自己就露出来了。
后接：[13-家庭与亲属 · 要不要孩子](13-家庭与亲属.md#四--要不要孩子)，雷区话题正式开聊。

## 五 · 解说员

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：闺蜜在场 11.3%、议论 21.0%（13-07 实测）

**骨架**｜知情的人跟不知情的人解释他俩的关系，越使劲，越离谱。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 新人进场，新同事、远房亲戚、刚回国的旧友，撞见一幕反常：她开会，他在楼下等 |
| 2 | 新人发问，问题自带框架：「她男朋友怕她？」 |
| 3 | 解说员开讲，三分对七分错，错的方向全是解说员自己的世界观 |
| 4 | 现场验证：正主出现，行为跟解说对不上 |
| 5 | 新人二次发问，问题变了，框架松了 |
| 6 | 解说员收尾：「反正他们过得挺好。」 |
| 7 | 正主始终没发现这场解说发生过，或她听见了一段，没纠正 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 错法清单 | 时间线错（以为她追的他）· 因果错（以为他图钱）· 分工错，以为家里她做饭 · 唯一说对的：「他俩谁也离不开谁」 |
| 新人的问题 | 上来先问身份 · 再问「图什么」 · 第三回干脆不问了 |
| 验证场面 | 正说到「她说一不二」，楼下恰好撞见她给他撑伞拎包 |
| 解说员的身份 | 闺蜜错得最少 · 同事错得最典型 · 邻居阿姨错得最善良 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 与他们的距离 | 近（闺蜜：错在细节） | 远（邻居：错在框架） |
| 错误的性质 | 笑点：无伤大雅的想当然 | 刀点：错处恰是他们最疼的那处，如「反正他们不会要孩子」 |
| 正主知不知道 | 全程不知道 | 她听到一段，没纠正 |
| 新人的去向 | 被说服 | 没被说服，自己观察出了第三个版本 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 借新人的：头一回看，没偏见，比熟人看得准 | 借解说员的：把错处一条条数出来，反倒凑全了别人眼里的他 |
| 落点 | 她听到那段解说，里头只有一句说对了 | 别人替他答「图什么」，答了三版，没一版挨着边 |
| 好的处理 | 她不纠正，错的版本反倒护住了真的那个 | 他知道那些说法，一个也不认 |
| 写崩 | 写成她当场揭穿、打脸辟谣 | 写成他偷听了，心里难受，自己躲起来 |

#### 写崩的三种方式

1. 解说员全说对。全对就成了作者的播音腔，错误率才是信息，错的方向就是世界观的读数。
2. 解说员带立场。一替谁辩护，解说就成了宣传，新人和读者一起打折。
3. 信息倾倒。一口气讲完两人十年是设定说明书，拆成三次，每次讲一半、错一半。

前接：[30-她的世界 · 她的闺蜜](30-她的世界.md#三--她的闺蜜)。这位解说员错得最少，但照样带偏。
功能位：[04-配角功能位设计 · 七、解说员](../04-人设原型/04-配角功能位设计.md#七解说员管家型)。没立场才配当解说，但交付的话术得固定套路。

| | 四爱女笔下 | 四爱男笔下 |

2. 让她动用权力灭火。一查一封，日常戏就成了职场惊悚，她的分寸是不动。
3. 跳过撞见者的心理。第一个人的犹豫，说不说、跟谁说，是整条链的种子。直接跳到满城风雨，链就断了。

> 门合上了。负二到十七楼，小周的手心出了一层汗。

> 第二天，茶水间有人反过来凑近她：「听说了没，李总在停车场给人跪下了！」

1. 孩子当传声筒。五岁的嘴说三十岁的话，一句就穿帮。孩子的台词只能用孩子的语料：吃的、玩的、谁大谁小。

3. 家里从不接招。问题要被认真回答，被糊弄过去的问题会在孩子那里发霉。

| 轴 | 一端 | 另一端 |
|---|---|---|

| 共识事件 | 她替他挡酒 | 他接过长辈的话，帮她打圆场 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 借谁的眼睛 | 开场让最看不上她的她爸来看，最后落到孩子身上 | 开场让最亲的兄弟、阿姨来看，最后落到她家长辈那儿 |
| 落点 | 挑刺的人数到第七筷子，不数了 | 散席时她爸那杯酒空了，是她喝的 |
| 好的处理 | 主角全程不写心里话，全靠别人眼神拼出这个人 | 每换个视角，俩人的样子就被重新描一遍 |
| 写崩 | 写成一群人排着队夸她 | 写成俩人当众秀恩爱给人看 |

#### 写崩的三种方式

1. 人人都抢着说话，没人真正在看。群像戏的镜头是眼睛。满桌金句，等于没镜头。
2. 视点换来换去，读数全一样。七双眼睛看出同一个结论，那还换什么？视差才是产出。
3. 给主角开内心戏。但这条的规矩是两位主角内心全程静音。一开口，整场群像就散架了。

#### 示例（本库自撰，可直接改写）

> 张姨端最后一道菜上桌，心里有了数：单子是先生开的，钱是太太转的。
> 老爷子那边数到第七筷，把面前那杯酒往女婿跟前推了半寸。
> 「外公，爸爸不能喝酒，」小满举着可乐罐喊，「妈妈说的。」
> 桌子另一头，表妹小声问：「姐夫家一直这样？」「十年了，」闺蜜替她答，「头两年我也这么问。」
> 那杯酒最后是她喝的。没人说什么，只有小满把可乐罐跟她的杯子碰了一下。
