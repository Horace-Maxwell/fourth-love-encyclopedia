# 等待与错过

> **分级** `T` ｜ 预警 无 ｜ 亚型 现代都市为主，古代／星际可换皮（分级见各条）
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**时间流逝**。没有人做错什么，情绪是时间自己堆起来的。

---

## 这一族为什么好用

等待类桥段的成本极低，效果极高。没有冲突、没有反派、没有误会，只需要一个人在原地，和一个不断走动的钟。

它好使，靠的是**等的人和被等的人信息对不上**：这边人把日子一天天熬进去了，那边人压根不知道。读者两边都看得见，所以替这边的人憋得慌。这个写法不用把谁写成坏人，甜文虐文都能用，也是最不容易写成一滩狗血的招。

| 节拍族 | 作品数 | 占比 |
|---|---:|---:|
| 等人不归 | 1,257 | 43.4% |
| 开门到家 | 1,229 | 42.5% |
| 夜深未睡 | 989 | 34.2% |
| 接送等候 | 920 | 31.8% |
| 临时缺席 | 602 | 20.8% |
| 联系不上 | 571 | 19.7% |
| 反复加热／重做 | 83 | 2.9% |

最后一行值得单独看。「反复加热」只有 2.9% 的作品写过，但它是这一族里效率最高的机关。见第一条。

## 一 · 等门与热菜

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：做饭＋归家 14.3%，做饭＋睡着 12.0%，反复 2.9%

**骨架**｜饭热了三回，人还没回来，他先撑不住睡了。

#### 节拍链

| 拍 | 内容 | 节拍族 | 作用 |
|---|---|---|---|
| 1 触发 | 他做了饭，摆好了等 | 做饭 | 让人盼着，而且是他单方面在付出 |
| 2 阻碍 | 她临时加班／应酬走不开 | 加班 | 盼头落空，但谁也没错 |
| 3 累积 | 菜热了一遍又一遍 | 反复 | 时间看得见。全场最戳心 |
| 4 崩点 | 等到哭着睡着 | 哭 ＋ 睡着 | 他没等到人，先撑不住了 |
| 5 反转 | 她回家，看见 | 归家 | 换成她的视角 |
| 6 收束 | 撒娇，哄很久 | 撒娇 ＋ 讨哄 | 委屈变成亲热 |

#### 时间轴

这场戏的劲不靠事件，靠的是那个能反复做的动作。你把第 3 拍删了试试，剩下的就是「他等她，她晚归，他哭了」，一句话的事；加上它，读者跟着微波炉转了整整三圈。

可用的显影动作，按显影效率排：

| 动作 | 一次循环显示多久 | 备注 |
|---|---|---|
| 端下来再热一遍 | 20–30 分钟 | 最顶。油凝了、菜色暗了、汤也收干了，肉眼看得见 |
| 走到玄关又走回来 | 5–10 分钟 | 连空间一起写进去，画面感强 |
| 点亮手机看时间又熄掉 | 1–2 分钟 | 信息密，写焦躁正好 |
| 把凉了的菜倒掉重做 | 40 分钟起 | 用一回就行，再来一次就假了 |
| 数楼下的车灯 | 不定 | 古代／没手机的时候拿这个顶替 |

一场戏用一到两种。不要全用。全用了就从「他在等」变成「作者在演示他在等」。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 保鲜膜 ✓ · 微波炉 ✓ · 砂锅 ✓ · 灶 ✓ · 油烟 ✓ · 围裙 ✓ · 玄关的灯 ✓ · 拖鞋的摆向 · 保温桶 · 手机屏幕的时间 ✓ |
| 物理变化 | 汤面上凝的油 · 米饭结的壳 · 青菜从翠转黄 · 蒸汽从有到无 · 碗沿的温度 |
| 动作 | 端下来、盖回去、擦一遍桌子、把筷子摆正、又摆一次 |
| 感官 | 抽油烟机停掉之后的安静 · 冰箱压缩机的嗡声 · 楼道有脚步声但走过去了 |
| 台词类型 | 发出去没回的消息（越写越短：「什么时候回」→「饭好了」→「嗯」）· 不说的话 |

「✓」为语料实测高频。围裙 1.4×、灶 1.4×、油烟 1.4×、砂锅 1.3× 是「下厨」场的特征物件；玄关 1.9× 是「归家」场的。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 甜↔虐 | 她赶在最后一刻回来了，饭还热着 | 她凌晨才回，他已经睡了，饭没动过 |
| 她知不知道 | 她一路都惦记着，堵在路上急 | 她压根忘了今天有饭 |
| 他说不说 | 他说「没事，我不饿」 | 他一句不提，第二天照做 |
| 谁先低头 | 她先道歉 | 他先撒个娇，把这事翻篇 |
| 是不是第一次 | 头一回，所以他还敢盼着 | 都好几回了，所以他这回没做饭 |

最后一行的「他这次没做饭」是全条最狠的一个拨法。不需要任何人说重话。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 视角进入点 | 从推开门那一刻开始写 | 从饭做好那一刻开始写 |
| 注意力落在 | 玄关的灯还亮着、桌上盖着保鲜膜、他缩在沙发一角 | 第三次端下来时汤面结了油 |
| 情绪 | 心疼里混着一点被需要的暖 | 委屈里混着不敢说的期待 |
| 内心难点 | 我该叫醒他还是让他睡 | 我要不要发第四条消息 |
| 收尾的权力 | 在她手上，但不能演成施舍 | 不在他手上，但可以主动兑换 |

同一场戏从哪边写，选的细节完全不同。她视角写玄关的灯，他视角写第三次端下来。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 酒菜还温着、灶里添了三回炭、廊下灯笼续了油、更漏 |
| 修仙 | 保温阵法重启好几回、灵食放凉了、传讯玉简没回音 |
| 星际 | 恒温舱来回保温、终端上消息没读、舷窗外巡航过了三班 |
| 末世 | 省着吃的罐头、柴烧了三回、天黑前就得收工 |

换皮的判据是有没有保住「反复」这一拍。换了世界没换掉显影动作，戏就还在。

#### 写崩的三种方式

1. 让她的缺席变成过错。一旦写成「她答应了却不当回事」，戏就从等待变成了失约，情绪从委屈变成了指责，甜虐结构塌成狗血。她要真的走不开。
2. 让他把委屈说出口。「我等了你三个小时」这句一出口，第 3 拍的所有积累都被兑现掉了。他不说。读者替他说，才有余味。
3. 跳过物质变化直接写情绪。「他越等越难过」是概述不是戏。汤面凝了油才是戏。

前接：[07-馈赠与仪式 · 藏了很久的礼物](07-馈赠与仪式.md)（饭是为纪念日做的，加倍）
后接：[04-委屈与破防 · 哭着睡着](04-委屈与破防.md) → [03-撒娇与讨哄 · 狠狠撒娇](03-撒娇与讨哄.md)
对照：[01-日常照料 · 学着做饭](01-日常照料.md)（讲他为什么会做这顿饭）

#### 示例（本库自撰，可直接改写）

> 汤第三次端下来的时候，表面那层油已经凝了，结成一片薄薄的白，用勺子一碰就裂开。
> 他把勺子放回去。没有再搅。
> 微波炉的转盘还在空转，嗡的一声停了，屋子里就只剩下冰箱的声音。
> 手机亮了一下，是推送。他把它扣在桌上，又翻过来，屏幕上还是十点四十一。
> 玄关的灯他没关。拖鞋摆得很正，朝着门口，一直朝着门口。

## 二 · 临时加班

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：临时缺席 20.8%

**骨架**｜她本来想走，一个电话把她定住了。留下倒简单，难的是开口跟他说。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 她已经在收拾东西，外套都拿了 |
| 2 | 电话／消息进来，走不了 |
| 3 | 她盯着手机，想怎么说 |
| 4 | 发出去的话删了又改，改了又删，最后就剩五个字 |
| 5 | 他回得很快，而且很乖 |
| 6 | 那个「很乖」比抱怨更让她难受 |

#### 时间轴

这条的时间不在他那边，在她那边。她删改消息的过程就是时间。越删越短，越短越心虚。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手里那件外套 · 电话 ✓ · 未接 ✓ · 微信 ✓ · 会议室百叶窗 · 凉透的咖啡 |
| 动作 | 外套搭回椅背、站着讲完电话没坐回去、字打了又删 |
| 台词类型 | 她：「今天回不去了」（原来写的是三行）· 他：「好」「你注意休息」（回得太快） |
| 反差点 | 他回得越快，话越短 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她告不告诉 | 直接说了 | 说一半，把原因咽回去了 |
| 他信不信 | 他信 | 他信，但心里清楚还有事瞒着 |
| 谁的电话 | 工作上的 | 前任／家里／不能接的人（转成 [05 卷吃醋](05-占有与吃醋.md)） |
| 频次 | 头一回 | 这个月第四回了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 核心难点 | 我该不该为他放鸽子 | 我该不该让他看出我生气 |
| 最容易写崩 | 写成事业和感情非得二选一 | 写成冷着脸不说话 |
| 好的处理 | 她没去成，但记着这事，回头补上 | 他不甩脸子，但也不装没事人 |

四爱女读者对「为了他放弃工作」这个解法普遍反感。她可以晚归，不该被要求辞职。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 宫里留宿／军务走不开／衙门有案子，没法递话 |
| 修仙 | 闭关让人叫醒／宗门催得急／传讯符让禁制挡了 |
| 星际 | 跃迁就这一班船／消息来回得等半天 |

#### 写崩的三种方式

1. 加班当借口，写一次两次行，别老用。写多了读者直接猜出轨，这故事就歪了。
2. 让她内疚，一句“对不起”够了。写她翻来覆去自责个没完，这是把她写怂了。
3. 他回“没事”回得飞快，看着是乖，但读者得看见他回完就把手机扣桌上，那才是真有事。

前接：[12-工作与金钱 · 加班到深夜的办公室](12-工作与金钱.md#九--加班到深夜的办公室)（同一个晚上的她那一侧）
后接：[一 · 等门与热菜](#一--等门与热菜) · [三 · 消息已读不回](#三--消息已读不回)

## 三 · 消息已读不回

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：联系不上 19.7%

**骨架**｜消息已读不回，他脑子里一会儿往最坏处想，一会儿又往最好处想。

#### 节拍链

触发（发出第一条）→ 已读 → 等 → 再发 → 不敢再发 → 删掉草稿 → 她的电话突然打来

#### 时间轴

发送时间戳就是时间轴，不用另写。 21:04、21:09、21:26、22:38——四个时间点，四种心境，一个字都不用解释。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 电话 ✓（1.6×）· 充电 ✓（1.5×）· 手机 ✓ · 未接 ✓ · 微信 ✓ · 输入框里的草稿 |
| 状态细节 | 电量从 40% 掉到 12% 还不去充 · 网络切了一遍以为是自己的问题 · 把消息撤回 |
| 动作 | 退出聊天界面再进去、下拉刷新、点开她的头像看很久 |
| 台词类型 | 越发越短，最后一条是标点或表情 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 真相 | 她手机没电／在开会 | 她看见了，故意晾着 |
| 他的反应 | 自己找台阶下 | 越想越慌，脑补到分手 |
| 解开的方式 | 她打个电话说清楚 | 她直接堵到门口来 |
| 谁先服软 | 她先认错 | 他抢着说没事 |

「故意晾着」这一端要小心：晾人是权力操作，写得不好会滑成冷暴力。如果要用，必须给她一个能站住的理由，且事后有明确的收束。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 情绪 | 看见十七条未读时心里咯噔一下 | 每条消息发出去后那十分钟的等 |
| 好的处理 | 她不多解释，直接拿行动补 | 他不追问，但那份难受他自己收着 |
| 写崩 | 写成她觉得就该这样 | 写成他一条接一条追问你在哪 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 信寄出去没回音／驿站断了／她身边那个侍卫跑来带句话 |
| 修仙 | 传讯玉简亮了又灭／神识探不着／被结界挡在外面 |
| 星际 | 消息延迟／跃迁时没信号／舰上不让私下联系 |

古代版有一个现代版没有的优势：**信件的物理性**。他可以摸那封没送出去的信，可以看见墨迹干了。

#### 写崩的三种方式

1. 让他连发二十条。 一次就够了。真正难受的是不敢发第二条。
2. 把误会拖过一章。 这条的保质期很短，隔章解开就变成了折磨读者。
3. 让她的理由太完美。 完美理由会把他的难受变成无理取闹。理由要成立。但不必无懈可击。

## 四 · 楼下等到睡着

`T` ｜ 无预警 ｜ 现代／校园 ｜ 语料频次：接送＋睡着 5.8%，接送＋等待 4.9%

**骨架**｜他去接她，到太早了，在车里／楼下等到睡着了；她出来看见的就是这样。

#### 节拍链

到得太早 → 等 → 天色变化 → 睡着 → 她出来 → 她没有立刻叫醒他

#### 时间轴

天色。这条的时间不用钟表，用光。从「还亮着」到「路灯亮了」到「路灯下有虫子」。三段就够。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 车 ✓ · 副驾上的外套 · 保温杯 ✓ · 校门口 · 后座 · 安全带没解 · 手机 ✓ |
| 姿势 | 头歪向车窗 · 手还搭在方向盘上 · 怀里抱着给她带的东西 |
| 环境 | 玻璃上一层薄雾 · 路灯亮的那一下 · 有人经过看了一眼 |
| 她的动作 | 站在车外看了一会儿才敲窗 · 先把外套盖上再叫 · 干脆不叫，自己上车坐着 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁在等 | 他等她（主流） | 她等他（也行，就是少见） |
| 她的反应 | 叫醒他 | 不叫，坐进副驾陪着 |
| 他醒后 | 装没睡着 | 直接认了，顺带撒娇 |
| 为什么早到 | 怕迟到 | 提前一小时就走，也没吭声 |

「她等他」这一端在语料里明显偏少，写好了辨识度高。四爱女读者对「她也会为他做这种事」的需求是真实存在的。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 看点 | 隔着车窗看他睡着的那几秒 | 醒来时她已经在旁边坐着了 |
| 心理 | 他到底等了多久（她去看仪表盘的时间） | 装睡还是睁眼 |
| 收尾 | 她开车，让他继续睡 | 他坚持要开，被按回副驾 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 车驾在宫门外候着／守在廊下／马拴了一整天 |
| 修仙 | 御剑停在山门外／守在阵眼旁打坐睡过去 |
| 星际 | 泊在轨道站等她换班／驾驶舱里睡着，导航还开着 |

#### 写崩的三种方式

1. 写成他很可怜。 他不是可怜，他是心甘情愿。这两种感觉差远了。
2. 让她感动得当场落泪。 这条的力度配不上眼泪。她安静地看几秒就够了。
3. 交代他等了多久。 别写「等了两小时」，写仪表盘上的到达时间，让她自己算。

## 五 · 玄关的灯

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：归家 42.5%，夜深＋归家 6.9%

**骨架**｜她回来得晚，玄关灯还亮着，那是他憋着没说的所有话。

#### 节拍链

她开门 → 灯亮着 → 屋里没声音 → 她看见他睡在能看见门的地方 → 她关灯／不关

#### 时间轴

这条基本没有时间线，就是一幅定格的画面。放在这个分类里，是因为所有写“等”的桥段，最后都能拿它收尾。前面不管你用哪种写法来磨时间，最后都可以落在这盏灯上。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 玄关 ✓（1.9×，回家那场戏最管用的东西）· 灯 ✓ · 拖鞋 · 钥匙 ✓ · 沙发 ✓ · 被子 ✓ · 门 ✓ |
| 位置学 | 他躺那儿能不能瞅见门，这条就讲这个 |
| 变化 | 拖鞋搁的方向 · 沙发上多出来的毯子 · 门口的外卖袋（他一口没动） |
| 声音 | 她插钥匙时故意轻手轻脚 · 换鞋都没敢坐一下 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 灯是给谁的 | 他专门留的 | 他忘了关就睡了（她以为是专门留的） |
| 她怎么做 | 把他抱回屋 | 把灯关了，坐他旁边 |
| 他醒不醒 | 醒了，开口就是「你回来了」 | 没醒，第二天也不提 |
| 是不是第一次 | 她头一回留意这盏灯 | 灯亮了三年，她今天才瞅见 |

最后一行可以承载整章的重量：同一盏灯，看见的那一刻才成为情节。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她忽然发觉这灯已经亮了一整夜 | 他天天出门前琢磨几点回来，好把灯留着 |
| 好的处理 | 她没吭声，第二天买了个感应灯（他没要） | 他说「我怕你摸黑」，不说「我在等你」 |
| 写崩 | 让她当场掉眼泪 | 让他自己跑去表功 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 廊下的灯笼／门房没落锁／窗纸上的一点亮 |
| 修仙 | 洞府外的引路灯／留着的一缕神识／没收的传送阵 |
| 星际 | 舱门权限一直开着／泊位灯／恒温没关 |

#### 写崩的三种方式

1. 让他自己把话挑明。「我一直给你留着灯」——这句一出口，灯就不再是灯，成了台词。
2. 别给灯来三段特写加抒情。一句话带过，读者自己会停在那儿。
3. 别让她第一眼就看明白。她没看懂更好，看懂那一下，留给后面某一章再揭。

#### 示例（本库自撰，可直接改写）

> 门开的时候，那盏灯正亮着。
> 她换鞋，抬头，看见拖鞋摆得很正，朝着门口。
> 客厅没开灯。沙发那头有个人蜷着，电视是暗的，屏幕上映出她自己的影子。
> 她伸手去按开关，按到一半停住了。
> 灯是他留的。她忽然想不起来这盏灯从哪一天开始，就一直这样亮着了。

## 六 · 提前回家

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：归家 42.5%

**骨架**｜她提前回来了，撞见他一个人待着。

#### 节拍链

她提早到家 → 没出声 → 看见他在做什么（这一拍是全条的内容）→ 他发现 → 反应

#### 时间轴

这条靠的是信息差。收进这一族是因为它跟「等待」正好反过来——等待写的是他不知道她在做什么，这条写的是她看见了他不知道被看见的样子。

#### 撞见什么

撞见了什么，就定了整场戏的情绪。按情绪分：

| 撞见 | 情绪 | 后续走向 |
|---|---|---|
| 他在学做她爱吃的菜，失败了满地狼藉 | 甜 | [01-日常照料 · 学着做饭](01-日常照料.md) |
| 他在对着镜子练习怎么开口 | 甜带酸 | 表白线 |
| 他在偷偷吃药／捂着伤 | 揪心 | [01-日常照料 · 装病与真病](01-日常照料.md) |
| 他在打电话，语气不像平时 | 悬 | [05-占有与吃醋](05-占有与吃醋.md) |
| 他在收拾行李 | 冷 | [09-分离与重逢](09-分离与重逢.md) |
| 他什么也没做，就是坐着 | 空 | 最难写，也最有余味 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 钥匙 ✓（她故意没使）· 门 ✓ · 玄关 ✓ · 手机 ✓ · 他没听见的缘由（耳机 ✓／水声／油烟机 ✓） |
| 她的动作 | 站门口没换鞋 · 手还搁门把上 · 打算退出去重新敲一遍 |
| 他的动作 | 听见动静那一顿 · 手忙脚乱往兜里塞 · 要么索性不收了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她说不说破 | 当场说破 | 退回门外重新开门，装作没看见 |
| 他知不知道被看见 | 不知道 | 知道，但两人都不提 |
| 撞见的性质 | 温柔的 | 难堪的 |

「退回门外重新开门」是这条最讲究的一个拨法。她把他的体面还给他了，而且他知道她还了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 张力 | 说破还是不说破 | 被看见的那一秒有多想找地缝 |
| 好的处理 | 她护住他的面子 | 他后来主动提，说明他懂了 |
| 写崩 | 写成抓包／审问 | 写成他矫情 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 提早回府／掀帘子那一瞬／隔着屏风听见 |
| 修仙 | 提前出关／神识扫过洞府 |
| 星际 | 提前结束任务／权限进舱 |

#### 写崩的三种方式

1. 把撞见写成误会的引信。 那是狗血线，不是这一条。
2. 让她躲起来偷看很久。 一眼就够。看久了性质就变了。
3. 撞见的东西太重。 这条的容器只装得下一件小事。大事要单独开场。

## 七 · 站台与机场

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送 31.8%

**骨架**｜送人跟被送，同一个地方，去的时候和回来的时候，完全是两码事。

#### 节拍链

去程：到得太早 → 无话找话 → 广播响 → 该走了 → 最后一句
回程：提前到 → 盯着出口 → 人潮 → 看见 → 那一步

#### 时间轴

**广播和显示屏替你计时**，不用另写。去程用倒计时，回程用航班状态。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 站台 ✓ · 地铁 ✓ · 车窗 ✓ · 行李箱轮子响 · 检票口那道线 · 他偷偷塞她包里的东西 |
| 去程动作 | 帮她理领子（第三回）· 话说到一半被广播盖过去 · 隔着闸机摆手 |
| 回程动作 | 举着牌子（上面不是她名字）· 一个一个数出来的人 · 眼睛都不敢眨 |
| 感官 | 广播嗡嗡的回声 · 箱子轮子卡在地砖缝里的动静 · 出站口灌进来的风 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁送谁 | 他送她（她出差） | 她送他 |
| 最后一句 | 说出口了 | 没说，或者说了别的 |
| 回程 | 她看见他在等 | 他没来，她自己回的 |
| 时长 | 三天 | 三年 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 去程 | 她回头几次，故事就推进几步 | 他话到嘴边又咽回去，怕她真走 |
| 回程 | 她远远瞅见他，脚下不自觉快了 | 他早到两钟头，这事打死不认 |
| 写崩 | 写着写着成了天人永隔 | 写着写着成了死缠烂打 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 十里长亭／城门口／渡口／折柳 |
| 修仙 | 山门／传送阵／御剑起飞那一下 |
| 星际 | 登舰口／跃迁前的最后通讯窗口 |

古代版自带一套成熟的仪式语汇（长亭、折柳、饯行酒），换皮成本最低。

#### 写崩的三种方式

1. 让两人在站台上把话全说完。 说完了，回程那场戏就没了，别这么干。
2. 写成慢镜头。 站台戏不能顺顺当当聊下去，得被打断：广播响了、人挤过来、该检票了。
3. 回程一眼就看见。 让她先没看见，再看见，中间那两秒才是关键。

## 八 · 错过的纪念日

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：做饭＋赠礼 4.6%，赠礼 24.8%

**骨架**｜他准备了很久，她忘了。

#### 节拍链

他提前准备 → 她当天没提 → 他等 → 等到不能再等 → 他自己收起来 → 她想起来（或者没有）

#### 时间轴

准备期越长，这一刀捅得越深。「上个月就订好了」和「今早才买的」，疼法完全不一样。把准备期搁在前面写，读者会跟着替他掐日子。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 包装 ✓（2.2×，送礼场面最扎眼的物件）· 礼盒 ✓（1.6×）· 蛋糕 ✓（1.5×）· 丝带 ✓ · 花束 ✓ · 藏东西的地方 |
| 准备痕迹 | 攒了三个月的钱 · 学了两周的手艺 · 提前问过她朋友 |
| 收起来的动作 | 把蛋糕塞冰箱最里头 · 丝带解下来 · 礼盒放回柜子顶层 |
| 她想起来时 | 时间点（当晚／第二天／一周后）决定这条线是甜还是刀 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她为什么忘 | 忙昏头了 | 她压根没把这日子当回事 |
| 他说不说 | 第二天跟没事人似的拿出来 | 往后一个字没再提 |
| 谁的纪念日 | 俩人正式在一起那天 | 他自己认定的那天（更上心） |
| 补救 | 她当晚赶回来了 | 她第二年记了一整年 |

「他单方面认定的日子」这一端最扎人：她没有错，因为她不知道那天有什么。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 发现的方式 | 她在冰箱最里层翻出那个盒子 | 他决定不拆开的那一刻 |
| 情绪 | 过了一阵才觉出分量 | 收起来时很平静（比哭还沉） |
| 好的处理 | 她不当场道歉，记在心里，往后做到 | 他不让她看见，但东西留在了那儿 |
| 写崩 | 写成她挨骂 | 写成他赌气 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 生辰／成亲那天／她说过要一起看的花开那天 |
| 修仙 | 结契那天／她随口说的“等我出关” |
| 星际 | 舰上纪念日／地球上的某一天（就他一个人还记得） |

#### 写崩的三种方式

1. 让她当场崩溃道歉。她一哭，读者就不盯着他看了，注意力全在她身上。
2. 礼物得往贵了写。但一贵，味儿就变了，成物质了。手工的、便宜的、偷偷准备了好久的，才最扎心。
3. 当天就翻篇。隔一阵子再翻出来，才够劲儿。

## 九 · 找不到人

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：联系不上 19.7%

**骨架**｜他不见了。她从“没事吧”到“出事了”，就四十分钟。

#### 节拍链

联系不上 → 合理化 → 开始找 → 找过的地方越来越具体 → 找到 → 她的第一反应

#### 时间轴

她合理化的速度就是她的紧张程度。 前十分钟「可能在洗澡」，二十分钟「可能手机没电」，四十分钟她已经在楼下了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 电话 ✓ · 未接 ✓ · 充电 ✓ · 他落家里的手机 · 他常去的地方的名单 |
| 找的顺序 | 她按自己猜的地方挨个找，找哪儿先找哪儿，能看出她多懂他 |
| 找到时 | 他在哪儿 · 他在干嘛 · 他是不是等着她来找 |
| 她的第一反应 | 骂／抱／一声不吭 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他为什么消失 | 意外（手机没电、加班、堵路上） | 他躲起来了 |
| 他想不想被找到 | 想 | 不想，但她还是找到了 |
| 她的反应 | 先发火 | 先抱住，一句话都说不出 |
| 找到的地点 | 平常的地方 | 一个她没想到、但想到之后全懂了的地方 |

最后一行是这条的最高级用法：地点即人物。他躲在哪里，说明了他是谁。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 张力 | 她越找越快，心里也越来越慌 | 他听着手机在口袋里震，没接 |
| 好的处理 | 她找到人，先看他没事，再算账 | 他不说为啥躲，但人没走远 |
| 写崩 | 写成她满城找人，光顾着跑 | 写成他拿消失来拿捏她 |

「用消失惩罚对方」这招搁现实里就是操控，PUA味儿太冲了。真要写这个，文里必须得有个态度，得让读者看出来这不对，别整得跟高级调情似的。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 人没回府／派人满城找／他躲旧宅里／在她不知道的坟前 |
| 修仙 | 神识探不到／传讯符烧了／他把灵识关了 |
| 星际 | 定位没了／他关了生命体征信标 |

#### 写崩的三种方式

1. 把找人写成节奏冒险。 重点是她要去哪儿，不是她跑了几条街。
2. 让他真出事。 那是另一种故事了，日常戏会被挤得没影。
3. 找到就赶紧和好。 中间那段谁也不说话，才是这段戏唯一值钱的地方。

## 十 · 时差与异地

`G` ｜ 无预警 ｜ 现代／星际 ｜ 语料频次：联系不上 19.7%（含异地场景）

**骨架**｜两个人时间总错开，处对象处成了值班。

#### 节拍链

约定通话时间 → 他调闹钟／她推掉会 → 有一次没对上 → 后来越来越难对上 → 两人都不提这件事

#### 时间轴

这条的时间轴是唯一一条按周和按月走的。 别的桥段以小时计，这条要写「第三周开始，通话从每天变成隔天」。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 两个时区的时钟 · 手机 ✓ · 视频 ✓ · 充电 ✓ · 他那边的天气 · 没寄出的东西 |
| 时差的物质表现 | 她的早饭是他的宵夜 · 他挂电话时那边在下雨 · 背景音里的陌生语言 |
| 累积的动作 | 记住时差不用算了 · 学会看他那边的天气预报 · 攒了很多要说的事，通话时只说了三件 |
| 台词类型 | 「你睡吧」（说了很多次）· 「没什么事，就是想说一声」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时长 | 三个月 | 没个头 |
| 谁在等 | 他等她回来 | 俩人都等对方先松口 |
| 结局 | 一个人过去了 | 扛住了，可都跟以前不一样了 |
| 通话质量 | 一聊就是半天 | 话越来越少，越来越见外 |

「越来越客气」是异地戏最准的伤害指标，比吵架准。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己开始为通话做准备（像开会） | 他调了三个闹钟，都是为了她那边的时间 |
| 好的处理 | 她不说「我很忙」，她说她那边现在几点 | 他不催，但他把没说的话记下来了 |
| 写崩 | 写成她冷淡了 | 写成他患得患失 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她在边关／他在京中，家书走一个月，写的时候是春天，收到已是夏天 |
| 修仙 | 洞中一日世上千年／她闭关三年，他等了三年 |
| 星际 | 光速延迟／跃迁后差了十七个月／她的一句话他四小时后才听见 |

星际版有一个别处没有的写法：对话不可能同步。他说完话要等四小时才知道她怎么答，这四小时里他会把自己说的话反复回想。

#### 写崩的三种方式

1. 让时差只是背景板。 时差必须造成具体的错过，否则它只是设定。
2. 写成流水账通话记录。 挑三次写：第一次、开始变短的那次、最后一次。
3. 用误会推进。 异地戏的敌人是时间不是误会。加了误会就变成了别的类型。
