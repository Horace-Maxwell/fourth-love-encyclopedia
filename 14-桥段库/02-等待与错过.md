# 等待与错过

> **分级** `T` ｜ 预警 无 ｜ 亚型 现代都市为主，古代／星际可换皮（分级见各条）
> 频次出自[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，统计的是 2,894 部独立作品。文中的百分比是编写时测的，挖掘器扩充以后节拍族会有小幅变动，最新数字看 13-07（用 `run.py mine` 重跑更新）。
> 等门、加班、已读不回、接送、留灯、纪念日、找人、异地，这些场面都归这一族。谁也没做错事，情绪全是时间一点点攒出来的。

## 等待戏的写法和频次

等待戏好写，也好使。用不着冲突、反派、误会，只要有个人在原地等着。

**等的人和被等的人信息对不上**，读者却两头都看得见，所以替等着的那个人憋屈：那边的人一点不知情，这边的人已经一天天熬过去了。这种写法甜文虐文都能用，最不容易写成狗血，也不必安排谁当坏人。

| 节拍族 | 作品数 | 占比 |
|---|---:|---:|
| 等人不归 | 1,436 | 49.6% |
| 开门到家 | 1,336 | 46.2% |
| 夜深未睡 | 1,085 | 37.5% |
| 接送等候 | 1,074 | 37.1% |
| 临时缺席 | 734 | 25.4% |
| 联系不上 | 671 | 23.2% |
| 反复加热／重做 | 97 | 3.4% |

表里最后一行要单独说一下。写过「反复加热」的作品只有 3.4%，可写了的效果最好，具体见第一条。

## 一 · 等门与热菜

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：做饭＋归家 17.7%，做饭＋睡着 14.1%，反复 3.4%

**骨架**｜饭热到第三回，她还没回来，他先熬不住睡着了。

#### 节拍链

| 拍 | 内容 | 节拍族 | 作用 |
|---|---|---|---|
| 1 触发 | 他做好饭摆上桌，开始等 | 做饭 | 有了盼头，付出的只有他一个 |
| 2 阻碍 | 她临时加班或有应酬，走不开 | 加班 | 盼头落空，可谁都没错 |
| 3 累积 | 菜一遍遍回锅 | 反复 | 时间看得见了，整场最戳人 |
| 4 崩点 | 等着等着哭睡过去 | 哭 ＋ 睡着 | 人没等来，他自己先垮了 |
| 5 反转 | 她到家，看见了 | 归家 | 镜头转到她那边 |
| 6 收束 | 撒娇，哄了好半天 | 撒娇 ＋ 讨哄 | 委屈化成了亲热 |

#### 时间轴

整场的时间都压在第 3 拍那个可以重复的动作上。把它删了，就只剩「他等她，她晚归，他哭了」，一句话就讲完。有了它，读者是陪着微波炉转满三圈的。

能写出时间的动作，越靠前越好用：

| 动作 | 一次循环显示多久 | 备注 |
|---|---|---|
| 端下来再热一遍 | 20–30 分钟 | 最好用。油凝住、菜色发暗、汤收干，眼睛就看得出来 |
| 走到玄关又走回来 | 5–10 分钟 | 屋里的空间也跟着写进来了，有画面 |
| 点亮手机看时间又熄掉 | 1–2 分钟 | 信息密，适合写焦躁 |
| 把凉了的菜倒掉重做 | 40 分钟起 | 用一次就行，第二次就假了 |
| 数楼下的车灯 | 不定 | 古代或者没手机的设定里用它来替 |

一场戏挑一两种，别全用。全用上，「他在等」就成了「作者在演示他在等」。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 保鲜膜 ✓ · 微波炉 ✓ · 砂锅 ✓ · 灶 ✓ · 油烟 ✓ · 围裙 ✓ · 玄关的灯 ✓ · 拖鞋的摆向 · 保温桶 · 手机屏幕的时间 ✓ |
| 物理变化 | 汤面上凝了油 · 米饭结了壳 · 青菜从翠转黄 · 蒸汽从有到无 · 碗沿的温度 |
| 动作 | 端下来、盖回去、擦一遍桌子、把筷子摆正、又摆一次 |
| 感官 | 抽油烟机停掉之后的安静 · 冰箱压缩机的嗡声 · 楼道有脚步声但走过去了 |
| 台词类型 | 发出去没人回的消息，一条比一条短：「什么时候回」→「饭好了」→「嗯」· 没说出口的话 |

打「✓」的是语料实测高频。围裙 1.2×、油烟 1.4× 是「下厨」场的标志物件，玄关 2.0× 属于「归家」场。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 甜↔虐 | 她踩着最后一刻进门，饭还是热的 | 她凌晨才到家，他睡了，饭一口没动 |
| 她知不知道 | 她一路惦记，堵在路上干着急 | 她完全忘了今天有这顿饭 |
| 他说不说 | 他回一句「没事，我不饿」 | 他什么都不说，第二天照样做 |
| 谁先低头 | 她先开口道歉 | 他先撒个娇，这事就过去了 |
| 是不是第一次 | 头一回，他还敢盼 | 已经好几回了，他这回没做饭 |

最后一行的「他这回没做饭」，谁都不必说一句重话。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 视角进入点 | 推开门那一刻写起 | 饭做好那一刻写起 |
| 注意力落在 | 玄关灯还开着，桌上的菜盖着保鲜膜，他缩在沙发角上 | 第三回端下来，汤面已经结了层油 |
| 情绪 | 心疼，又有点被需要的暖意 | 委屈，还夹着不敢说出口的盼头 |
| 内心难点 | 叫醒他，还是让他接着睡 | 第四条消息发不发 |
| 收尾的权力 | 由她决定，但别演成施舍 | 轮不到他决定，不过他能主动去兑换 |

同一场戏，站在哪一边写，挑的细节就完全两样：她那边写玄关的灯，他那边写第三回端下来。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 酒菜还温着、灶里添了三回炭、廊下灯笼续了油、更漏 |
| 修仙 | 保温阵法重启好几回、灵食放凉了、传讯玉简没回音 |
| 星际 | 恒温舱来回保温、终端上消息没读、舷窗外巡航过了三班 |
| 末世 | 省着吃的罐头、柴烧了三回、天黑前就得收工 |

换皮成不成，看「反复」这一拍还在不在。世界换了，这个动作留着，戏就没丢。

#### 写崩的三种方式

1. 把她的缺席写成她的错。 只要写成「她答应了却不当回事」，等待就成了失约，委屈就成了指责，甜虐的架子垮下来变成狗血。她得是真走不开。
2. 让他把委屈说出来。 他一说「我等了你三个小时」，第 3 拍攒下的东西就全泄了。他不开口，读者会在心里替他说，后劲才留得住。
3. 不写东西的变化，直接写情绪。 「他越等越难过」是概括，要写汤面凝的油。

#### 可串接

前接：[07-馈赠与仪式 · 藏了很久的礼物](07-馈赠与仪式.md)，这顿饭是为纪念日做的，加倍
后接：[04-委屈与破防 · 哭着睡着](04-委屈与破防.md) → [03-撒娇与讨哄 · 狠狠撒娇](03-撒娇与讨哄.md)
对照：[01-日常照料 · 学着做饭](01-日常照料.md)，交代他为什么会做这顿饭。

#### 示例（本库自撰，可直接改写）

> 汤第三次端下来的时候，表面那层油已经凝了，结成一片薄薄的白，用勺子一碰就裂开。
> 他把勺子放回去。没有再搅。
> 微波炉的转盘还在空转，嗡的一声停了，屋子里就只剩下冰箱的声音。
> 手机亮了一下，是推送。他把它扣在桌上，又翻过来，屏幕上还是十点四十一。
> 玄关的灯他没关。拖鞋摆得很正，朝着门口，一直朝着门口。

## 二 · 临时加班

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：临时缺席 25.4%

**骨架**｜她正要走，一个电话把她留住了。留下来不难，难在怎么跟他开口。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 她都在收东西了，外套也拿在手上 |
| 2 | 电话／消息进来，走不了 |
| 3 | 她盯着手机，想怎么说 |
| 4 | 要发的话改了删、删了改，到最后只剩五个字 |
| 5 | 他回得很快，而且很乖 |
| 6 | 他回得「很乖」，她比听抱怨还难受 |

#### 时间轴

这条的时间算在她那头，看她删改消息：越删越短，越短越心虚。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 手里那件外套 · 电话 ✓ · 未接 ✓ · 微信 ✓ · 会议室百叶窗 · 凉透的咖啡 |
| 动作 | 外套搭回椅背、站着讲完电话没坐回去、字打了又删 |
| 台词类型 | 她：「今天回不去了」· 他：「好」「你注意休息」（回得太快） |
| 反差点 | 他回得越快，话越短 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她告不告诉 | 照直说了 | 只说一半，原因咽了回去 |
| 他信不信 | 信了 | 信了，可心里知道还有事瞒着他 |
| 谁的电话 | 工作上的 | 前任／家里／不能接的人（见 [05 卷吃醋](05-占有与吃醋.md)） |
| 频次 | 头一回 | 这个月第四回了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 核心难点 | 该不该为了他放鸽子 | 该不该让对方看出我在生气 |
| 最容易写崩 | 写成事业和感情只能留一样 | 写成他板着脸一句话不说 |
| 好的处理 | 她没去成，心里记着，过后补回来 | 他不给脸色看，也不装作什么都没发生 |

「为了他放弃工作」这种解法，四爱女读者普遍反感。她可以晚回家，但不该被要求辞职。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 宫里留宿／军务走不开／衙门有案子，没法递话 |
| 修仙 | 闭关让人叫醒／宗门催得急／传讯符让禁制挡了 |
| 星际 | 跃迁就这一班船／消息来回得等半天 |

#### 写崩的三种方式

1. 加班这个借口反复用。 一两次没问题，次次都是加班，读者就不信了，会直接往出轨上猜，故事也就跑偏了。
2. 让她没完没了地自责。 这样会把她写怂，内疚的话一句“对不起”足够。
3. 只写他飞快回了个“没事”。 这样只显得乖。要让读者看到他回完就把手机扣在桌上，才知道他心里有事。

#### 可串接

前接：[12-工作与金钱 · 加班到深夜的办公室](12-工作与金钱.md#九--加班到深夜的办公室)，写的是同一晚她那边的情形
后接：[一 · 等门与热菜](#一--等门与热菜) · [三 · 消息已读不回](#三--消息已读不回)
互斥：别跟 [六 · 提前回家](#六--提前回家) 排进同一章，两边的节奏会抵掉。

## 三 · 消息已读不回

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：联系不上 23.2%

**骨架**｜消息显示已读，却没回，他一会儿往最坏处想，一会儿又往最好处想。

#### 节拍链

发出第一条（触发）→ 显示已读 → 等 → 再发一条 → 不敢再发 → 把草稿删了 → 她忽然打来电话

#### 时间轴

消息的发送时间就是时间轴，用不着另写。 21:04、21:09、21:26、22:38——四个时刻，四种心情，一个字都不必解释。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 电话 ✓（1.4×）· 充电 ✓ · 手机 ✓ · 未接 ✓ · 微信 ✓ · 输入框里的草稿 |
| 状态细节 | 电量从 40% 掉到 12% 还不去充 · 网络切了一遍，以为是自己这边的问题 · 把消息撤回 |
| 动作 | 退出聊天界面再进去、下拉刷新、点开她的头像看很久 |
| 台词类型 | 一条比一条短，最后只发个标点或表情 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 真相 | 她手机没电／在开会 | 她看见了，故意晾着 |
| 他的反应 | 给自己找个台阶 | 越想越怕，都想到分手了 |
| 解开的方式 | 她一个电话打来讲明白 | 她干脆找上门来 |
| 谁先服软 | 她先认错 | 他抢着说没事 |

「故意晾着」这一头要慎用。晾人就是在拿捏人，写不好会变成冷暴力。真要用，必须给她一个站得住的理由，事后还要明明白白地收住。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 情绪 | 一看十七条未读，她心里一沉 | 每发出一条，就干等那十分钟 |
| 好的处理 | 她不多解释，用行动补回来 | 他不追问，难受自己咽下去 |
| 写崩 | 写成她觉得理所当然 | 写成他一条接一条地问人在哪 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 信寄出去没回音／驿站断了／她身边那个侍卫跑来带句话 |
| 修仙 | 传讯玉简亮了又灭／神识探不着／被结界挡在外面 |
| 星际 | 消息延迟／跃迁时没信号／舰上不让私下联系 |

古代版比现代版多一样好处：信是拿在手里的东西。他能摸到那封没寄出去的信，看得见墨迹已经干了。

#### 写崩的三种方式

1. 让他一口气发二十条。 发一条就够。最难受的是第二条不敢发。
2. 让误会拖过一章。 这种误会撑不久，隔一章才解开，就成了折磨读者。
3. 给她的理由太完美。 理由一完美，他的难受就成了无理取闹。理由要说得通，用不着无懈可击。

后接：[05-占有与吃醋 · 那个人是谁](05-占有与吃醋.md) · [04-委屈与破防 · 憋着不说](04-委屈与破防.md)

## 四 · 楼下等到睡着

`T` ｜ 无预警 ｜ 现代／校园 ｜ 语料频次：接送＋睡着 8.4%，接送＋等待 6.8%

**骨架**｜他去接她，来得太早，在车里等睡着了。她出来，看到的就是这个样子。

#### 节拍链

来早了 → 等 → 天色变了 → 睡着 → 她出来 → 她没马上叫醒他

#### 时间轴

「还亮着」「路灯亮了」「路灯下有虫子」，写这三段足够。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 车 ✓ · 副驾上的外套 · 保温杯 ✓ · 校门口 · 后座 · 安全带没解 · 手机 ✓ |
| 姿势 | 头歪向车窗 · 手还搭在方向盘上 · 怀里抱着给她带的东西 |
| 环境 | 玻璃上一层薄雾 · 路灯亮的那一下 · 有人经过看了一眼 |
| 她的动作 | 站在车外看了一会儿才敲窗 · 先把外套盖上再叫 · 干脆不叫，自己上车坐着 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁在等 | 他等她（主流） | 她等他（少见） |
| 她的反应 | 叫醒他 | 不叫，坐进副驾陪着 |
| 他醒后 | 装没睡着 | 直接认了，顺带撒娇 |
| 为什么早到 | 怕迟到 | 提前一个钟头就出门，一声没说 |

「她等他」这一头在语料里明显少，写好了很有辨识度。四爱女读者需要看到「她也会为他做这种事」的情节。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 看点 | 隔着车窗看他睡的那几秒 | 一睁眼，她已经坐在旁边 |
| 心理 | 他等了多久？她瞄一眼仪表盘 | 接着装睡，还是睁眼 |
| 收尾 | 她来开，让他接着睡 | 他非要自己开，被按回副驾 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 车驾在宫门外候着／守在廊下／马拴了一整天 |
| 修仙 | 御剑停在山门外／守在阵眼旁打坐睡过去 |
| 星际 | 泊在轨道站等她换班／驾驶舱里睡着，导航还开着 |

#### 写崩的三种方式

1. 把他写得很可怜。 他是自己愿意等的，可怜和情愿差得很远。
2. 让她感动到当场掉泪。 这场戏的分量撑不起眼泪，她静静看他几秒就好。
3. 直接交代他等了多久。 不写「等了两小时」，写仪表盘上显示的到达时间，让她自己算。

后接：[06-身体接触 · 膝枕](06-身体接触.md) · [03-撒娇与讨哄 · 装睡](03-撒娇与讨哄.md)

## 五 · 玄关的灯

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：归家 46.2%，夜深＋归家 9.9%

**骨架**｜她很晚才到家，玄关的灯开着，他就睡在看得见门的位置。

#### 节拍链

她开门 → 灯开着 → 屋里静悄悄 → 她发现他睡在看得见门的位置 → 她关灯，或者不关

#### 时间轴

没有时间轴。这一条差不多就是一张定格画面，全靠她开门、看见灯亮着往下走。不管前面用什么办法拖时间，几乎所有「等」的桥段都能拿这盏灯收尾。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 玄关 ✓（2.0×，回家那场戏最管用）· 灯 ✓ · 拖鞋 · 钥匙 ✓ · 沙发 ✓ · 被子 ✓ · 门 ✓ |
| 他躺哪儿 | 要写的就一点：他躺的地方看不看得见门 |
| 变化 | 拖鞋搁的方向 · 沙发上多出来的毯子 · 门口的外卖袋（他一口没动） |
| 声音 | 她插钥匙时故意轻手轻脚 · 换鞋都没敢坐一下 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 灯是给谁的 | 他特意留的 | 他忘了关就睡着了，她当成是特意留的 |
| 她怎么做 | 把他抱回屋 | 把灯关了，坐他旁边 |
| 他醒不醒 | 醒了，头一句就是「你回来了」 | 没醒，第二天也没提起 |
| 是不是第一次 | 她第一次注意到这盏灯 | 灯亮了三年，她今天才看见 |

最后一行能撑起一整章：那盏灯亮了三年，她到今天才看见。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她突然意识到这灯亮了一整夜 | 他每天出门前都要盘算几点回来，好把灯留上 |
| 好的处理 | 她什么都没说，第二天买回一个感应灯，他没要 | 他只说「我怕你摸黑」，「我在等你」不说 |
| 写崩 | 让她当场哭出来 | 让他自己去邀功 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 廊下的灯笼／门房没落锁／窗纸上的一点亮 |
| 修仙 | 洞府外的引路灯／留着的一缕神识／没收的传送阵 |
| 星际 | 舱门权限一直开着／泊位灯／恒温没关 |

#### 写崩的三种方式

1. 让他自己说破。 他一说「我一直给你留着灯」——灯就成了一句台词，没了灯本来的样子。
2. 给灯写三段特写，再抒一通情。 一句带过，读者自己会停在那儿。
3. 让她一眼就看懂。 她没看懂反而好，看懂的那一刻留到后面哪一章再揭开。

#### 示例（本库自撰，可直接改写）

> 门开的时候，那盏灯正亮着。
> 她换鞋，抬头，看见拖鞋摆得很正，朝着门口。
> 客厅没开灯。沙发那头有个人蜷着，电视是暗的，屏幕上映出她自己的影子。
> 她伸手去按开关，按到一半停住了。
> 灯是他留的。她忽然想不起来这盏灯从哪一天开始，就一直这样亮着了。

## 六 · 提前回家

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：归家 46.2%

**骨架**｜她早回了家，撞上他一个人待着的样子。

#### 节拍链

她提前到家 → 没出声 → 看到他在干什么，整条的内容都在这一拍 → 他发现了 → 反应

#### 时间轴

2. 让她躲着偷看半天。 看一眼足够，看久了就变味了。

## 七 · 站台与机场

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：接送 37.1%

**骨架**｜同一个地方，送人和被人送不一样，走的时候和回来的时候也完全是两回事。

#### 节拍链

去程：来早了 → 没话找话 → 广播响起 → 到点要走 → 最后一句
回程：早早到了 → 盯住出口 → 人一波波出来 → 看见了 → 那一步

#### 时间轴

时间交给广播和显示屏报，不必另写。去程看倒计时，回程看航班状态。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 站台 ✓ · 地铁 ✓ · 车窗 ✓ · 行李箱轮子响 · 检票口那道线 · 他偷偷塞她包里的东西 |

| 回程动作 | 举着牌子，上面不是她名字 · 一个一个数出来的人 · 眼睛都不敢眨 |
| 感官 | 广播嗡嗡的回声 · 箱子轮子卡在地砖缝里的动静 · 出站口灌进来的风 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁送谁 | 他送她（她出差） | 她送他 |
| 最后一句 | 说出口了 | 没说，或者说了别的 |
| 回程 | 她看见他在等 | 他没来，她自己回的 |
| 时长 | 三天 | 三年 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 去程 | 她每回一次头，故事就往前走一步 | 话到嘴边他又咽了回去，怕她真的走 |
| 回程 | 隔老远看见他，她脚步自己就快了 | 他提前两个钟头就到了，死也不承认 |
| 写崩 | 写着写着成了天人永隔 | 写着写着成了死缠烂打 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 十里长亭／城门口／渡口／折柳 |
| 修仙 | 山门／传送阵／御剑起飞那一下 |
| 星际 | 登舰口／跃迁前的最后通讯窗口 |

#### 写崩的三种方式

1. 让两个人在站台上把话说尽。 话都说完，回程那场就没戏可写了。
2. 拍成慢镜头。 站台上的话不能一路顺顺当当说下去，要被打断：广播响了，人挤过来，该检票了。
3. 回程一眼就看到人。 让她先找不着，再看见，戏都在中间那两秒。

## 八 · 错过的纪念日

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：做饭＋赠礼 5.4%，赠礼 29.6%

**骨架**｜他准备了很久，她忘了。

#### 节拍链

他早早备好 → 那天她没提 → 他等 → 等到等不下去 → 他自己收起来 → 她想起来了（或者没有）

#### 时间轴

准备得越久，后面这一下越疼。「上个月就订好了」和「今早才买的」，疼的程度差得远。准备的日子放在前面写，读者会跟着他一起数天数。

#### 可用细节

| 类 | 内容 |

| 道具 | 包装 ✓（1.6×，送礼场面最扎眼）· 礼盒 ✓（1.6×）· 蛋糕 ✓（1.5×）· 丝带 ✓ · 花束 ✓ · 藏东西的地方 |

| 她想起来时 | 当晚、第二天、一周后，哪个时间点想起来，决定这条线是甜还是刀 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她为什么忘 | 忙晕了 | 她从没把这个日子放在心上 |
| 他说不说 | 第二天像没事一样拿出来 | 以后再也没提过一个字 |
| 谁的纪念日 | 两人正式在一起的那天 | 他自己认定的那天，他更在意 |
| 补救 | 她当晚赶回来了 | 她第二年一直记着 |

| | 四爱女笔下 | 四爱男笔下 |

| 情绪 | 过一阵才回过味 | 收起来时很平静，没掉泪 |
| 好的处理 | 她没当场道歉，记下了，以后做到 | 他不让她看到，东西却还留在原处 |
| 写崩 | 写成她挨骂 | 写成他赌气 |

#### 写崩的三种方式

1. 让她当场崩溃、拼命道歉。 她一哭，读者的眼睛就从他身上挪到她身上了。
2. 把礼物往贵里写。 礼物一贵，味道就变成物质了。手工做的、不值钱的、偷偷备了很久的，才最扎心。
3. 当天就让事情过去。 过一阵再被翻出来，劲儿才足。

## 九 · 找不到人

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：联系不上 23.2%

**骨架**｜他不见了。她从“没事吧”到“出事了”，只隔四十分钟。

#### 节拍链

联系不上 → 给自己找理由 → 开始找 → 找的地方越来越具体 → 找到 → 她的第一反应

#### 时间轴

她找理由安慰自己的速度，就是她紧张的程度。头十分钟想的是「可能在洗澡」，到二十分钟成了「可能手机没电」，四十分钟时她人已经到楼下了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 电话 ✓ · 未接 ✓ · 充电 ✓ · 他落家里的手机 · 他常去的地方的名单 |
| 找的顺序 | 她照自己猜的地方一处处找，先去哪后去哪，看得出她有多了解他 |
| 找到时 | 他在哪儿 · 他在干嘛 · 他是不是等着她来找 |
| 她的第一反应 | 骂／抱／一声不吭 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他为什么消失 | 意外：手机没电、加班、堵路上 | 他躲起来了 |
| 他想不想被找到 | 想 | 不想，但她还是找到了 |
| 她的反应 | 先发火 | 先抱住他，话都说不出来 |
| 找到的地点 | 平时会去的地方 | 她没想到的地方，可一想到就全明白了 |

看最后一行，他躲到哪儿，就看出他是谁。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 张力 | 她越找越急，心也越来越慌 | 手机在兜里震，他听着，没接 |
| 好的处理 | 找到人先确认他没事，再跟他算账 | 他不讲为什么躲，可也没走远 |
| 写崩 | 写成她满城跑，只剩下跑 | 写成他用消失拿捏她 |

「用消失惩罚对方」放在现实里就是操控，PUA 的味道很重。真写这个，文里必须有立场，让读者看得出这样不对，别写得像高级调情。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 人没回府／派人满城找／他躲旧宅里／在她不知道的坟前 |
| 修仙 | 神识探不到／传讯符烧了／他把灵识关了 |
| 星际 | 定位没了／他关了生命体征信标 |

#### 写崩的三种方式

1. 把找人写成赶节奏的冒险。 要写她会往哪儿找。
2. 让他真出了事。 那就成了另一个故事，日常这场戏会被挤没。
3. 一找到就马上和好。 中间谁都不说话那段，别省。

## 十 · 时差与异地

`G` ｜ 无预警 ｜ 现代／星际 ｜ 语料频次：联系不上 23.2%（含异地场景）

**骨架**｜两人的时间老是错开，谈恋爱谈得像轮班。

#### 节拍链

约好通话时间 → 他定闹钟／她推会 → 有一回没对上 → 之后越来越难对上 → 谁都不提这事

#### 时间轴

这一条的时间按周、按月走。别的桥段按小时算，这里要写「第三周开始，通话从每天变成隔天」。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 两个时区的时钟 · 手机 ✓ · 视频 ✓ · 充电 ✓ · 他那边的天气 · 没寄出的东西 |
| 时差的物质表现 | 她的早饭是他的宵夜 · 他挂电话时那边在下雨 · 背景音里的陌生语言 |
| 累积的动作 | 记住时差不用算了 · 学会看他那边的天气预报 · 攒了很多要说的事，通话时只说了三件 |
| 台词类型 | 「你睡吧」（说了很多次）· 「没什么事，就是想说一声」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时长 | 三个月 | 没个头 |
| 谁在等 | 他等她回来 | 俩人都等对方先松口 |
| 结局 | 一方搬过去了 | 撑下来了，可两人都变了 |
| 通话质量 | 一聊就是半天 | 话越来越少，越来越见外 |

说话越来越客气，比吵一架还说明问题。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发觉自己通话前要先准备，跟开会一样 | 他定了三个闹钟，全按她那边的时间 |
| 好的处理 | 她不讲「我很忙」，只告诉他她那边现在几点 | 他不催，没说出口的话都记了下来 |
| 写崩 | 写成她冷淡了 | 写成他患得患失 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她守边关，他留京城，一封家书走一个月，落笔是春天，到手已入夏 |
| 修仙 | 洞中一日世上千年／她闭关三年，他等了三年 |
| 星际 | 光速延迟／跃迁后差十七个月／她一句话，他四小时后才听见 |

星际版里两人说话没法同步。他说完一句，要四小时后才知道她怎么回，这四小时里他会把自己那句话翻来覆去地想。

#### 写崩的三种方式

1. 时差只当背景板。 时差必须让两人具体错过点什么，否则只是一条设定。
2. 把通话写成流水账。 只挑三次：第一次，开始变短的那次，最后一次。
3. 靠误会推剧情。 异地戏是拿时间磨人的，误会一加进来，就成了另一种类型。
