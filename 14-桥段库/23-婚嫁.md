> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来自 [13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数是 2,894 部独立作品。文中的百分比是编写时实测的，挖掘器扩充以后节拍族会有小幅变动，当前的权威数字以 13-07 为准（用 `run.py mine` 重跑更新）。
> 这一族把婚嫁从求婚到纪念日一步步写下来：两家谈判，领证，办不办婚礼，试装，前夜，当天，敬茶改口，第一顿早饭。每一步都有老规矩，这对人得一样一样重新谈。

## 婚嫁为什么绕不开

恋爱可以关起门来两个人自己定，婚嫁不行。孩子跟谁姓，新房写谁的名字，彩礼怎么谈，求婚谁先开口，这四件事都有老规矩，默认的都是“男方该怎样、女方该怎样”，这对人的情况，一条也套不上。

在这些作品里，「婚仪」族出现的比例有 **38.8%**，排在所有情境族前列。别的题材一笔带过的环节，到这里都成了绕不开的场面，要么一个个改设定，要么一个个破防。写到婚嫁，这一关就躲不过去。

| 节拍族 | 占比 |
|---|---:|
| 婚仪 | 38.8% |
| 戒指 | 36.0% |
| 节日 | 33.0% |

## 一 · 求婚

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：戒指 38.2% ＋ 婚仪 38.8%

**骨架**｜总得有个人先提，可在这段关系里，谁开口都别扭。

#### 节拍链

念头（谁先动的）→ 准备与拖延 → 时机一次次错过 → 说出口往往不在计划的场合 → 对方的反应 → 那枚戒指的下落

#### 时间轴

准备好的人一回回错过时机，最后多半在没准备的场合说出口：厨房里，堵车的路上，吵完一架谁都不出声的时候。

#### 谁求，各有各的难

| | 她求 | 他求 |
|---|---|---|
| 顺理成章吗 | 像她会干的事，可她明白这事不能当成派活儿 | 是他这辈子头一回这么主动 |
| 难点 | 把「定了」说成「求你」 | 攒够「我够格开这口」的底气 |
| 常见形态 | 一句话，不带情绪，直说 | 心里过了几十遍，张嘴还是颤 |
| 对方的反应 | 他先愣住，接着眼圈红了 | 她先愣住，然后笑了：「你总算开口了」 |

「你终于说了」这五个字，背后要有事撑着：她等他开口等了很久，一直忍着没替他说。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 戒指 ✓（藏了很久，接 [07-馈赠与仪式 · 藏了很久的礼物](07-馈赠与仪式.md#一--藏了很久的礼物)）· 单膝跪还是不跪，放进这段关系里得重新掂量 |
| 场合 | 计划好的没用上 · 真发生在一个平常时刻 |
| 台词 | 她版：「结婚吧。跟我。」 · 他版：练过的全忘了，只剩「嫁给我好不好」 |
| 意外 | 两个人同一阵子都在准备，撞了 |

「单膝跪不跪」值得单独拿出来说。传统求婚里跪是标准动作，放进这段关系，意思就变了：他跪，是照老剧本走，她跪，是她让了一大步。两种跪法都说得通，选哪一种，本身就是表态。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁求 | 她 | 他 |
| 场合 | 准备过的 | 脱口而出的 |
| 应答 | 当场答 | 「让我想想」，要接得住这个「想想」 |
| 戒指 | 有 | 没有，后补那场是加戏 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把「我决定了」咽回去，改口成「你愿意吗」 | 开口前手心全是汗 |
| 内心 | 这是我唯一不能替他答的题 | 说完这句，退路就没了 |
| 好的处理 | 她求婚也给他留了拒绝的余地 | 他求婚没靠酒壮胆 |
| 写崩 | 写成下命令 | 写成当众逼婚 |

这个类型里，公开求婚尤其危险。不管谁向谁求，当众开口都等于借舆论施压。私下问，才算真的在问。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她派媒人上门提亲（走规矩），或他自己开口求娶，不守规矩，也更当真 |
| 修仙 | 求着结道侣契／她把自己本命法器分他一半，认他当半个主人 |
| 星际 | 去登记永久关系，页面弹出来得两个人各按一下确认才算数 |

星际版好在两人要各按一次确认，制度逼着这件事只能双向。

#### 写崩的三种方式

1. 求婚当高潮，写完就收。求完婚，后面还有九条能写。
2. 她的求婚写成了安排。那五个字必须是问句。
3. 他借着酒劲求婚。清醒时开口才算数。

## 二 · 两家坐下来谈

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：婚仪 38.8% ＋ 见家长

**骨架**｜彩礼、房子、酒席，看着是在谈钱，底下是两家过日子的规矩合不上。

#### 节拍链

定了要办 → 约两家见面 → 席间逐项过彩礼、房、酒席、户口 → 某一项卡住 → 各自回去消化 → 二次谈或私下解

#### 时间轴

每过一项算一拍，哪一项卡住，哪一项就是这场的主戏。

#### 卡点清单

每一项的传统默认，都跟这两人拧着：

| 项 | 传统默认 | 这里的实况 | 卡在哪 |
|---|---|---|---|
| 彩礼 | 男方出 | 他家拿不出她家看得上的数 | 她说不要，两边都没面子 |
| 房 | 男方备 | 房是她的，早买好了 | 他家非要添点钱，说不然脸上挂不住 |
| 酒席 | 男方主场 | 她家排场大 | 谁先摆、摆几桌，争半天 |
| 迎亲 | 男迎女 | 谁去接谁 | 这一项经常谈崩 |

两边父母都要写得有道理。他们都不坏，各过各的日子，各守各的理。两个当事人夹在中间，只能自己再编出第三套。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场面 | 圆桌 · 茶换了三遍 · 两位母亲客气得刀光剑影 |
| 他 | 全程被谈论，很少被询问 · 他爸说「我们家条件就这样」时他的手 |
| 她 | 一句「这些我来出」让全场安静，且不是好的安静 |
| 解法 | 散场后两个当事人在楼下对了一遍真实方案：明面一套，实际一套 |

现实里最常见的办法就是「明面一套，实际一套」：两边父母各有一个能拿出去说的版本，日子实际怎么过，两人自己定。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 卡点 | 钱 | 面子（更难解） |
| 谈崩没 | 没崩 | 崩过一次，缓了半个月 |
| 谁打圆场 | 她 | 他第一次在两家人面前拿了主意 |
| 结局 | 谈成 | 简办，两边都让 |

那是他第一次当着两家人拿主意，一屋子长辈中间，他替两个人开了口。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她那句「我来出」说完，屋里安静了 | 全程被当第三人称聊 |
| 内心 | 我这么解决问题，在这桌上全不对 | 该我说话了 |
| 好的处理 | 她学着把方案说成是长辈的主意 | 他开口那次，条理清楚，也没带情绪 |
| 写崩 | 写成她拍桌子，全场不敢吭声 | 写成他全程没存在感 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 议聘：聘礼单一样样对／嫁妆薄了，他以后在妻家抬不起头 |
| 修仙 | 两派说亲：灵石当聘礼／面子不能丢／长老们吵成一团 |
| 星际 | 两家律师坐下来谈财产分割，两个当事人坐旁边听 |

古代女尊版里，嫁妆的压力落在他家：他进门以后腰杆硬不硬，全看家里陪送了多少。这和现实里的彩礼焦虑正好倒过来，写透了，比光换性别设定值钱得多。

#### 写崩的三种方式

1. 把哪一边的父母写成反派。两边都有理，才难办。
2. 拿她的钱一下把事摆平。钱只摆得平钱那部分。
3. 他从头到尾不说话。至少让他开一次口，而且那次开口得真管用。

## 三 · 领证那天

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：戒指 38.2%

**骨架**｜九块钱，半个钟头，一个上午就把一辈子的事办完了。

#### 节拍链

到了约好的日子，取号，填表，窗口照例问几句，拍照，两个红本拿到手，出门在台阶上一站，忽然不知道该干什么了。

#### 时间轴

**筹备想了半年，办下来只用了二十六分钟**，手续快得荒唐。

#### 可用细节

| 类 | 内容 |
|---|---|
| 流程 | 取号机 · 表格上「双方」两个字 · 工作人员见多了，脸上没啥表情 |
| 细节 | 拍照时工作人员说「往中间靠一靠」，两个人同时挪了一下 |
| 那两个本 | 谁拿着 · 塞进谁的包 · 路上偷偷翻开看了三次 |
| 出门之后 | 台阶上站了一会儿 · 「现在干嘛？」「……吃面去？」 |
| 落差 | 人生大事办完的那顿饭，是路边一碗面 |

**这一族里只有这个环节没有传统剧本压着**，调子由「办完终身大事去吃了碗面」这一条定下。行政流程不管谁强谁弱，走完了，两人反倒最放松，最像他们本来的样子。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时点 | 婚礼前 | 不办婚礼，就搞这个（接 [四](#四--办不办婚礼)） |
| 保密 | 两家都清楚 | 先斩后奏，后果得写 |
| 情绪 | 心里有点小动静 | 有个人在窗口前眼眶红了，旁边的人见多了 |
| 那顿饭 | 路边吃碗面 | 回家他来做（接 [01-日常照料](01-日常照料.md#一--学着做饭)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 签完字手一直抖，她平时手稳得很 | 红本照片里他笑得牙都露多了 |
| 内心 | 二十六分钟，我谈个合同都不止这点时间 | 从今天起表格上「配偶」那栏总算有内容了 |
| 好的处理 | 她顺手把本子递给他拿着 | 他路上翻了三次，每次都假装找东西 |
| 写崩 | 写成搞大排场补偿她 | 写成他高兴得哭到失态 |

证件这类东西一向归她管，这两个本子，她交给他拿了。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 没有直接对应的——正经婚书得走六礼，见 [七 · 当天](#七--当天)，最像的是私下换庚帖 |
| 修仙 | 道侣名录上登记，掌籍长老盖个印，前后一炷香的工夫 |
| 星际 | 终端上两人做生物认证，系统响一声「绑定完成」，俩人就盯着那行字发愣 |

#### 写崩的三种方式

1. 把领证写得很隆重。它的味道恰恰在不隆重。
2. 出门以后那段空白写得满满的。一句「现在干嘛」，比抱一下准得多。
3. 跳过窗口前那些琐事。办事的细节越平淡，感情越有地方使劲。

## 四 · 办不办婚礼

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：婚仪 38.8%

**骨架**｜证已经领了，婚礼要办给谁看，两人想的不一样。

#### 节拍链

有人提起 → 发现想法不同 → 各自的理由摆出来 → 背后的真实顾虑露出来 → 折中或一方让 → 定案

#### 时间轴

这件事会来回谈好几轮，**一轮比一轮更靠近真实的理由**：先说「麻烦」，再提「花钱」，最后才说到真正怕的那件事。

#### 表面理由与真实顾虑

| 谁 | 说出口的 | 真的 |
|---|---|---|
| 不想办的一方 | 「俗、累、浪费钱」 | 怕那套流程：迎亲、改口、闹，哪个环节都是把两人架在老规矩上给人围观 |
| 想办的一方 | 「就一辈子一次」 | 想要一个让所有人都瞧见的定心丸，接着 [11-初遇与确立 · 没有表白](11-初遇与确立.md#十--没有表白)那茬儿，想找补回来 |

**常见的是她不想办、他想办**：她怕那套流程，他想让名分被人看见。两个人的真实理由都挖出来了，折中的办法才谈得拢。

#### 可用细节

| 类 | 内容 |
|---|---|
| 折中方案 | 只请两桌至亲 · 旅行结婚 · 只拍照不办席 · 办，但流程自己定 |
| 谈判细节 | 他列了一张「能省的环节」清单 · 她看到「堵门游戏：删」时笑了 |
| 定案 | 留下的每一样都有说法 |

他列的那张「能省的环节」清单很管用：把婚礼拆开一项项谈，他俩就是这样对付老一套的。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 分歧方向 | 她不想他想 | 他不想她想，少见，他的理由要给足 |
| 结局 | 简办 | 不办，多年后补了一场只有两个人的 |
| 压力源 | 内部分歧 | 父母要面子（接 [二](#二--两家坐下来谈)） |
| 情绪 | 商量 | 吵了一架才见真话 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看明白了，他要的是让人正眼瞧一回 | 她担心啥，他一条条都看出来了 |
| 内心 | 这回我陪他撑一回场面 | 我想开口要的那点东西，想想真没劲 |
| 好的处理 | 她肯接这活儿，但说好了俩人一起定流程 | 他把自己那点真实想法讲出来了 |
| 写崩 | 写成了她冷着脸把仪式推了 | 写成了他跑去找父母闹，拿家里压人 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 简礼还是全礼／她位高，全礼会让他家没面子，简礼又显得不重视 |
| 修仙 | 昭告三界还是只告本门／道侣礼办得多大，摆明了两人在修真界的地位 |
| 星际 | 舰上小办还是回母星大办／要不要开通讯直播 |

#### 写崩的三种方式

1. 只谈到表面理由为止。「俗」和「一辈子一次」都不是真话。
2. 一方把另一方硬压服。折中方案得两边都出了血。
3. 把想办仪式的心愿写成虚荣。他想要被人看见的承认，这个要求正当。

## 五 · 试装

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：婚仪 38.8% ＋ 置装 6.8%

**骨架**｜婚纱店里，店员每句话都在告诉他俩，这一行默认谁是主角。

#### 节拍链

进店 → 店员对着「新郎」推销的话术全部落空 → 各自试装 → 帘子拉开的那一眼 → 定装 → 帐单谁付（店员又猜错了）

#### 时间轴

每换一套算一拍，最要紧的是帘子拉开的那一下。

#### 行业默认与现场实况

| 店员的默认 | 现场 |
|---|---|
| 新娘做主选婚纱 | 她十分钟选完，跟开会似的 |
| 新郎随便挑一套 | 他试了七套，比她还上心 |
| 「新郎在外面等就好」 | 帘子一拉，他先回头问她「这套行不行」 |
| 「先生您看新娘多美」 | 她看他那愣神的样子，店员那套夸词根本用不上 |

「他试了七套她十分钟选完」：**谁更在意外表，两人对调了**，这是现成的反差。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 婚纱 ✓ · 西装的肩线 · 皮尺 · 试衣间 ✓ 的帘子 · 一墙的镜子 ✓ |
| 帘子拉开 | 两次拉开写两种：她出来他站起来了，他出来她放下了手机 ✓ |
| 店员 | 从话术错乱到看懂气氛改口，这个配角有小弧光 |
| 定装 | 她那套挑的是他多看了一眼的 · 他那套是她定的 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁更挑 | 他 | 她把选婚纱当项目管理，他看不下去了接手 |
| 穿什么 | 常规婚纱西装 | 她想穿西装，那后面的事都要写：家里怎么反应，当天全场怎么看 |
| 气氛 | 轻松 | 试到某一套忽然安静，两个人同时意识到这事是真的 |
| 结账 | 她付 | 他早偷偷付了定金 |
| 延长线 | 试装日（本条正题） | 拍摄日（婚纱照：摄影师照惯例喊「新郎手放新娘腰上」，是照做还是当场改动作，拍一组照片就表一次态。成片里他们自己最喜欢的，往往是抓拍的那张） |

**婚礼上穿什么，全场都盯着**。她换上西装，态度就穿在了身上。读者要看的就是这个，阻力在这儿，爽点也在这儿。「她想穿西装」这一点别浪费了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 帘子一拉，他站起来那一下 | 镜子里的自己，还有身后她的表情 |
| 内心 | 原来他比我更在意这场婚礼 | 这套贵了点，可她看着挺喜欢 |
| 好的处理 | 她挑得认真，全是为他 | 他老实说试了七套：怕站她身边配不上 |
| 写崩 | 写成她从头到尾没上心 | 写成他扭扭捏捏，死活不肯试 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 量体裁喜服／他的嫁衣按规矩该素净，她偏让人绣最艳的 |
| 修仙 | 炼一件婚服法衣／俩人把灵力往同一匹料子上染 |
| 星际 | 全息试衣定礼服，系统按老模板给错了款，俩人一块儿调参数 |

古代女尊版里，「嫁衣」穿在他身上：**嫁衣规制、盖头、红妆整套挪到他那边**，哪一项都是现成的戏。

1. 只写她试衣服。他那七套才是反差的重头。
2. 把店员当成不出声的背景。这个配角说错话又改口，是白送的喜剧。
3. 试装从头笑到尾。中间要有一下忽然安静下来。

## 六 · 婚礼前夜

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：婚仪 38.8% ＋ 夜深 37.5%

**骨架**｜老规矩说今晚要分开睡，结果两个人都没睡着。

#### 节拍链

被各自家人领走（习俗）→ 各自的夜 → 忍不住的消息往来 → 一通压低声音的电话 → 有人翻墙／溜出来（或没有）→ 天亮

#### 时间轴

**手机上的时间从 23:00 走到 04:30**，一路倒数，明天这个钟点已经在仪式当中了。

#### 两边的夜

| 她那边 | 他那边 |
|---|---|
| 母亲坐在床边说了很多，最后说「他挺好」 | 兄弟们闹完散了，屋里忽然空下来 |
| 她第一次听母亲讲自己当年 | 他对着挂起来的礼服发呆 |
| 表面镇定，凌晨在阳台站了一会儿 | 给她发：「睡了吗」秒回：「没」 |

母亲那句「他挺好」，是长辈拖到前一晚才给的认可。

#### 可用细节

| 类 | 内容 |
|---|---|
| 消息 ✓ | 有一搭没一搭 · 「明天别紧张」「你才紧张」 · 都在等对方先说睡 |
| 电话 | 压着声音打的 · 内容全是废话 · 挂断前停了几秒 |
| 溜出来 | 楼下见了十分钟，什么也没干，就是看看 · 被家人抓包，笑着轰回去 |
| 各自 | 她检查了三遍流程表 · 他把誓词又背了一遍，背串了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 守不守习俗 | 分开睡 | 根本没分，习俗第一项就被砍了 |
| 情绪 | 期待 | 有一方忽然慌了，另一方在电话里接住 |
| 溜出来 | 溜了 | 没溜，隔着消息道晚安 |
| 长辈 | 前夜和解 | 前夜还有一场没谈完的（接 [二](#二--两家坐下来谈)） |

「有一方忽然慌了」这一头要写得公道，慌的也可以是她。
平时拿惯了主意的人，一件事明天就要定死，前一晚忽然心虚，再正常不过。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她妈那句「他挺好」 | 空屋子里挂着的那身礼服 |
| 内心 | 我从不失眠，今晚例外 | 明天走到她旁边的路只有二十米，我练了三年 |
| 好的处理 | 她把慌说给他听了，电话里 | 他说「你要是明天想跑，跑之前叫上我」 |
| 写崩 | 写成她冷静如常 | 写成他借酒壮胆 |

他给的定心丸，就是那句「你要是想跑，跑之前叫上我」。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他在家最后一晚，母兄叮嘱半天，她隔墙扔来个果子，上头系着字条 |
| 修仙 | 都说要闭关静心，神识却在结界边上撞见，谁也没先走 |
| 星际 | 两艘舰并排飞，私人频道开了一宿，大半宿就剩呼吸声 |

#### 写崩的三种方式

1. 把前夜写成回忆大合集。回忆一段就够了，重点是今晚怎么睡不着。
2. 两边写得一样多。挑一边做主场，另一边靠几条消息带出来就行。
3. 把溜出来写成大戏。就十分钟，看一眼就回去，别弄得像私奔。

## 七 · 当天

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：婚仪 38.8%

**骨架**｜每个环节老规矩都给了现成答案，他们一项一项全改成自己的。

#### 节拍链

清晨各自梳妆 → 迎亲（谁迎谁）→ 堵门（堵谁）→ 仪式 → 誓词 → 交换戒指 → 敬酒 → 送客 → 洞房门关上，终于只剩两个人

#### 时间轴

一切按流程表来。**从早上六点到晚上十点，每个环节都卡着点走**，到最后一拍之前，两人一刻也没单独待过。

#### 逐环节的改写

| 环节 | 传统版 | 他们的版本 |
|---|---|---|
| 迎亲 | 男迎女 | 她去迎他，他家那边炸了锅又觉得新鲜 · 或互不迎，中场汇合 |
| 堵门 | 堵新郎 | 他的兄弟堵她，题目全是「他不吃什么」，她全对 |
| 入场 | 父亲挽女儿交给新郎 | 谁挽谁进场，这个画面怎么摆，提前吵了三轮 |
| 誓词 | 模板 | 自己写的，都很短，都有一句只有对方听得懂 |
| 敬酒 | 新郎挡酒 | 她挡他的酒，全场起哄，他耳朵红到脖子 |

堵门题全答对，这段好写：她隔着门喊答案，一道没错，门里门外都在笑。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 流程表 · 誓词小抄，他手心全是汗，纸都洇了 · 戒指 ✓ 枕 · 请柬 ✓ · 喜糖 ✓ |
| 走神瞬间 | 仪式到一半，俩人一对眼，差点笑场，想起昨晚那句「想跑叫上我」 |
| 长辈 | 他妈哭了 · 她爸跟他碰了杯，啥也没说 |
| 最后一拍 | 门一关，俩人往床沿一瘫，礼服都没脱，她问：「饿不饿，我点外卖」 |

拿「叫外卖」收尾，正好和 [三 · 领证那天](#三--领证那天) 的「吃面」前后对上。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 规模 | 就两桌至亲 | 全套大办 |
| 事故 | 没有 | 出了点小岔子，戒指一时找不着，反倒成了全场最松快的一刻 |
| 情绪峰值 | 誓词 | 一个没写进流程的瞬间 |
| 结尾 | 点外卖 | 他下厨，礼服袖子一挽，这人物就立住了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 挡酒时全场的哄笑，和他通红的耳朵 | 她一路走过来的那二十米 |
| 内心 | 这些流程真吵，可他在发光 | 别哭。忍住。没忍住 |
| 好的处理 | 她的誓词短而具体，落在一件小事上 | 他的誓词最后一句只有她听懂了 |
| 写崩 | 写成她全程掌控如主持 | 写成他从头哭到尾 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 六礼全反过来：她上门迎亲，他盖盖头出门，他娘替他压钗。拜堂、却扇、喝交杯酒 |
| 修仙 | 道侣礼：两人共握一把剑发誓，双修阵一亮，满山冒灵光，师门在底下起哄，跟村里办喜事一样 |
| 星际 | 在舰桥办仪式，舰长当证婚人，俩人生物信号在主屏上合成一条线，全舰人跟着喊好 |

古代女尊文里，「却扇礼」这一套挺有意思，值得单独拿出来讲。**扇子一掀，人脸才露**，这个亮相原本是留给扇子后面那位新娘的，现在换成他坐在那里，脸被扇子挡着。

#### 写崩的三种方式

1. 把整套流程记成流水账。挑三个环节写足，其余一句话带过。
2. 把事故写成灾难。婚礼上出岔子，该用来让全场松下来。
3. 一剩两个人就马上转场。「饿不饿」那一拍得留着，删了整场白忙。

## 八 · 敬茶与改口

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：婚仪 38.8% ＋ 改口 30.1%

**骨架**｜端一杯茶，喊一声「妈」。改这一声口，比婚礼上念誓词费劲多了。

#### 节拍链

摆茶 → 他先敬她父母 → 那声称呼卡了一下 → 出口 → 红包 → 换她敬他父母 → 他母亲的那句话 → 礼成

#### 时间轴

两杯茶，几分钟的事。要写的就是那两声称呼，别的都是流程。

#### 两声改口的不对称

| | 他叫她父母 | 她叫他父母 |
|---|---|---|
| 难点 | 她父亲那关：他攒了很久的底气 | 她不习惯对任何人执小辈礼 |
| 卡壳的样子 | 声音比排练时小了一半 | 语气差点带上谈判腔，自己收住了 |
| 对方回应 | 她父亲「哎」了一声，别过头去 | 他母亲拉着她的手说了句掏心窝的 |
| 那句掏心窝的 | — | 「他从小没让我省过心，往后麻烦你了」：把儿子托付给她，这话原本是托付女儿时说的，现在方向反了 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 茶盘 · 跪垫，跪不跪提前说好 · 红包厚薄不一样，两家暗地里较劲的余波 |
| 微表情 | 她爸接茶时手抖了一下 · 他妈抬手抹眼角，用的是拇指 |
| 卡壳 | 那声「妈」出口前咽了一下，全场都听见那个停顿 |
| 之后 | 长辈马上切换成唠家常模式，紧张劲儿一下就没了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 跪不跪 | 跪 | 鞠躬，这事之前闹过一次，没谈拢 |
| 谁更紧张 | 他 | 她（难得见她发怵） |
| 长辈反应 | 顺当 | 有位长辈从头到尾没露笑脸，往后日子有的磨 |
| 红包 | 照常 | 里头除了钱还夹了件旧东西，他妈留给儿媳妇的镯子，最后给了她，这岔子怎么圆 |

「传家镯子」好写：**婆婆把留给儿媳的传家物给了她**。东西按老规矩往下传，接的人却不照老规矩来，收下还是转手送人，一个动作就定了整篇的调子。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他母亲那句托付 | 她父亲的那声「哎」 |
| 内心 | 人家把一个大活人交到我手里了 | 这关熬过去，往后就没更难的了 |
| 好的处理 | 她收了镯子，回头就套他手腕上 | 他第二声喊出来，嗓子已经稳了 |
| 写崩 | 写成她谁都不用行礼 | 写成他跪在那儿没完没了磕头 |

她收下镯子，回头套到他手腕上，传错位的东西归到了对的人身上。

| 古代女尊 | 庙见礼：他跟着她拜她家祖宗，名字写进她族谱。见 [20-女尊制度场景 · 他上了族谱](20-女尊制度场景.md#八--他上了族谱) |

## 十 · 纪念日的演变

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：节日 33.3% ＋ 婚仪 38.8%

#### 节拍链

第一年（隆重）→ 第三年（差点忘，补救）→ 第五年不再办，但都记得→ 第十年一句「今天几年了」→ 每一年的落点

#### 时间轴

**按年来写**，和 [18-节令与天候 · 一年过去了](18-节令与天候.md#九--一年过去了) 那个对照是一个路数：同一个日子反复写几遍，每次只改最不起眼的小地方。

#### 演变表

| 年份 | 过法 | 那天的一句话 |
|---|---|---|
| 第一年 | 订了餐厅，俩人都紧张，跟补办第一次约会似的 | 「明年还来这家」 |
| 第三年 | 一方出差没赶上，视频里补了一顿（接 [02-等待与错过 · 错过的纪念日](02-等待与错过.md#八--错过的纪念日)） | 「回来补」 |
| 第五年 | 没订餐厅。他炒了几个菜，她拎了瓶酒 | 「比那家好吃」 |
| 第十年 | 早上出门她说了句「十年了」，晚上桌上多摆了两个菜 | 什么都没说 |

从「说很多」到「什么都没说」，话一年比一年少，是因为熟了。这条要把递减写成升温。

#### 可用细节

| 类 | 内容 |
|---|---|
| 锚点物 | 每年在同一位置拍一张 ✓，十张排开就是全书年表 · 那瓶「等十年开」的酒 |
| 差点忘的那年 | 谁忘了 · 对方怎么不动声色地提醒 · 补救的样子 |
| 递减的仪式 | 礼物从贵重到实用到没有，「没有」那年反而最稳 |
| 增加的东西 | 话少了，菜多了 · 第十年桌上那两个菜正是第一年餐厅点过的 |

「第十年的两个菜是第一年餐厅的」：减到最后，又回到起点，刚好合上。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 跨度 | 写到五年 | 写到几十年（接 [21-世界设定专属 · 寿元差](21-世界设定专属.md#五--寿元差)，年轮会走完） |
| 中间 | 顺 | 有一年是分居中过的（接 [22-分手与复合](22-分手与复合.md)），那年谁都没提，但都记得 |
| 递减 | 自然 | 有一方先慌了：「我们是不是淡了」，另一方拿那两个菜作答 |
| 结尾用法 | 全书终章 | 中段拿来跳时间 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 第十年那句随口说的「十年了」 | 桌上那两个菜，她一眼认出来 |
| 内心 | 不办了，不是忘了 | 她还记得那家店点过啥 |
| 好的处理 | 她纪念的方式越来越小，越来越准 | 他每年那张照片 ✓ 拍在同一个地方 |
| 写崩 | 写成一年年算旧账 | 写成年年大操大办没区别 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 每年那天她推了应酬回府吃饭，第十年告了假，满朝都愣了 |
| 修仙 | 百年小聚一回，千年那次回了结契的山头，守山的徒弟换了好几茬 |
| 星际 | 每年按“地球日”过一天，舰上日历跟地球差得越来越多，他们也不管，就认自己那套 |

他们只认自己那套日子。

#### 写崩的三种方式

1. 每年写得一样长。越往后越要写短，短到一句。
2. 把递减写成危机。「我们是不是淡了」这句，得让那两个菜给否掉。
3. 只写甜的年份。中间夹一个坏年头，年轮才像真的。
