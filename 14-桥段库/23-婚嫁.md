# 婚嫁

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**婚嫁是传统性别脚本密度最高的一套流程，这对关系走到这里，每一个环节都要重新谈。**

---

## 为什么婚嫁是这个类型的决赛圈

恋爱可以只关起门来过，婚嫁不行。求婚该谁开口、彩礼怎么谈、新房写谁的名、孩子跟谁姓——**每一个习俗都内置了「男方如何、女方如何」的默认答案**，而这对关系跟每一个默认答案都拧着。

于是别的类型里走个过场的环节，在这里全是戏：要么逐项改写，要么逐项破防。实测「婚仪」族出现在 **38.8%** 的作品窗口里，在全部情境族里排进前列。写到最后，几乎没有作品绕得开这一关。

| 节拍族 | 占比 |
|---|---:|
| 婚仪 | 38.8% |
| 戒指 | 36.0% |
| 节日 | 33.0% |

## 一 · 求婚

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：戒指 36.0% ＋ 婚仪 38.8%

**骨架**｜这件事总得有人开口。而在这段关系里，谁开口都不顺理成章。

#### 节拍链

念头（谁先动的）→ 准备与拖延 → 时机一次次错过 → 说出口（往往不在计划的场合）→ 对方的反应 → 那枚戒指的下落

#### 时间轴

求婚的钟是**拖延**。准备好的人一次次错过时机，最后说出口的场合往往毫无准备——在厨房、在堵车的路上、在吵完一架的沉默里。

#### 谁求，各有各的难

| | 她求 | 他求 |
|---|---|---|
| 顺理成章吗 | 像她的作风，但她清楚这不能像布置任务 | 是他这辈子最大的一次主动 |
| 难点 | 把「决定」说成「请求」 | 攒够「我配开这个口」的底气 |
| 常见形态 | 一句话，平静，直接 | 排练了几十遍，说出来还是抖 |
| 对方的反应 | 他先愣，再红眼眶 | 她先愣，然后笑了：「你终于说了」 |

「你终于说了」这五个字要背后有货：她等他开这个口等了很久，且忍住了没替他说。 忍住不替他做这件事，是她给他留的最后一块主场。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 戒指 ✓（藏了多久，接 [07-馈赠与仪式 · 藏了很久的礼物](07-馈赠与仪式.md#一--藏了很久的礼物)）· 单膝还是不跪（这个动作在这段关系里要重新想） |
| 场合 | 计划好的没用上 · 真发生在一个平常时刻 |
| 台词 | 她版：「结婚吧。跟我。」 · 他版：练过的全忘了，只剩「嫁给我好不好」 |
| 意外 | 两个人同一阵子都在准备，撞了 |

「单膝跪不跪」值得专门写一笔：跪是传统求婚的规定动作，但在这段关系里它另有含义——他跪，是沿用旧脚本；她跪，是全场最重的一次让渡。 两种都成立，选哪种就是在表态。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁求 | 她 | 他 |
| 场合 | 准备过的 | 脱口而出的 |
| 应答 | 当场答 | 「让我想想」（要接得住这个「想想」） |
| 戒指 | 有 | 没有，后补（后补那场是加戏） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把「我决定了」咽回去，改口成「你愿意吗」 | 开口前手心全是汗 |
| 内心 | 这是我唯一不能替他答的题 | 说完这句，退路就没了 |
| 好的处理 | 她求婚也给他留了拒绝的空间 | 他求婚没有借酒 |
| 写崩 | 写成下达通知 | 写成大型公开逼婚 |

公开求婚在本类型里尤其危险：当众开口等于借舆论施压，无论谁对谁。私下问，才算真问。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她遣媒登门（制度内），或他越过媒妁自己开口（制度外，更重） |
| 修仙 | 求结道侣契／她把本命法器的认主权分他一半 |
| 星际 | 申请永久关系登记，申请页要两个人各按一次确认 |

「各按一次确认」是星际版的好处：制度强制了这件事必须双向。

#### 写崩的三种方式

1. 把求婚当剧情高潮收尾。 求婚是这一族的门，后面九条才是房子。
2. 她求婚写成安排。 那五个字必须是问句。
3. 他求婚靠醉。 清醒着开口才算数。

## 二 · 两家坐下来谈

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：婚仪 38.8% ＋ 见家长

**骨架**｜彩礼、房子、酒席。桌上谈的是钱，桌下谈的是两套性别脚本的正面相撞。

#### 节拍链

定了要办 → 约两家见面 → 席间逐项过（彩礼·房·酒席·户口）→ 某一项卡住 → 各自回去消化 → 二次谈或私下解

#### 时间轴

这条按**议程项**走。每过一项是一拍，卡住的那一项就是本场的主戏。

#### 卡点清单

每一项的传统默认都跟这对关系拧着：

| 项 | 传统默认 | 这里的实况 | 卡在哪 |
|---|---|---|---|
| 彩礼 | 男方出 | 他家拿不出她家看得上的数 | 她说不要，两边都没面子 |
| 房 | 男方备 | 房是她的，早买好了 | 他家坚持要「添一间房的钱」保面子 |
| 酒席 | 男方主场 | 她家门面大 | 谁家先摆、摆几桌 |
| 迎亲 | 男迎女 | 谁去接谁 | 这一项经常谈崩 |

这条的正确写法是让双方父母都有理。他们都不是恶人，各自执行着各自那套脚本；两个当事人要在夹缝里给出第三套。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场面 | 圆桌 · 茶换了三遍 · 两位母亲客气得刀光剑影 |
| 他 | 全程被谈论，很少被询问 · 他爸把「我们家条件就这样」说出口时他的手 |
| 她 | 一句「这些我来出」让全场安静，且不是好的安静 |
| 解法 | 散场后两个当事人在楼下把真实方案对了一遍：明面一套，实际一套 |

「明面一套，实际一套」是现实里最常见的解：给两边父母各留一个说得出去的版本，实际怎么过他们自己定。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 卡点 | 钱 | 面子（更难解） |
| 谈崩没 | 没崩 | 崩过一次，缓了半个月 |
| 谁打圆场 | 她 | 他（他第一次在两家人面前拿了主意） |
| 结局 | 谈成 | 简办，两边都让 |

「他第一次在两家人面前拿主意」是这条的高光位：在一屋子长辈中间，他替两个人说了话。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她那句「我来出」落地后的安静 | 全程被当第三人称谈论 |
| 内心 | 我解决问题的方式在这张桌上全是错的 | 该我说话了 |
| 好的处理 | 她学着把方案包装成长辈的功劳 | 他开口那次条理清楚，不带情绪 |
| 写崩 | 写成她拍桌全场闭嘴 | 写成他全程隐形 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 议聘：聘礼单逐行过／他家嫁妆的厚薄关乎他日后腰杆 |
| 修仙 | 两宗议亲：灵石聘礼／门派颜面／长老团各执一词 |
| 星际 | 两个家族的律师谈判财产协议，两个当事人坐在旁听席 |

古代女尊版方向整个反过来：**嫁妆压力在他家**。他家陪送厚薄决定他进门后的底气，这是把现实彩礼焦虑做了镜像，值得整场展开。

#### 写崩的三种方式

1. 把某一方父母写成反派。 都有理，才是难。
2. 用她的钱一键平推。 钱能平的只有钱的部分。
3. 他全程沉默。 至少给他一次发言，且让那次发言起了作用。

## 三 · 领证那天

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：戒指 36.0%

**骨架**｜九块钱，半小时，一个上午就办完的终身大事。

#### 节拍链

约的日子到了 → 排号 → 填表 → 窗口几个例行问题 → 拍照 → 拿到那两个红本 → 出门站在台阶上，忽然不知道干什么

#### 时间轴

行政流程快得荒谬。**筹备想了半年，办理只花了二十六分钟**：这个落差就是本条的戏眼。

#### 可用细节

| 类 | 内容 |
|---|---|
| 流程 | 取号机 · 表格上「双方」两个字 · 工作人员例行公事的平静 |
| 细节 | 拍照时工作人员说「往中间靠一靠」，两个人同时挪了一下 |
| 那两个本 | 谁拿着 · 塞进谁的包 · 路上偷偷翻开看了三次 |
| 出门之后 | 台阶上站了一会儿 · 「现在干嘛？」「……吃面去？」 |
| 落差 | 人生大事办完的那顿饭，是路边一碗面 |

「办完终身大事去吃了碗面」是这条的定调：**这一族里唯一没有传统脚本压场的环节**，因为流程是行政的，行政不问谁强谁弱。所以它反而最松弛、最像他们自己。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时点 | 婚礼前 | 不办婚礼，只有这个（接 [四](#四--办不办婚礼)） |
| 保密 | 两家都知道 | 先斩后奏（后果要写） |
| 情绪 | 平静里冒泡 | 有一方在窗口前红了眼眶（工作人员见怪不怪） |
| 那顿饭 | 路边面 | 回家他做（接 [01-日常照料](01-日常照料.md#一--学着做饭)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 签完字发现手一直有点抖，她的手从不抖 | 红本上的照片里他笑得太开 |
| 内心 | 二十六分钟，我谈一个合同都不止这个时长 | 从今天起表格上「配偶」那栏有的写了 |
| 好的处理 | 她把本子给他拿着 | 他路上翻了三次，每次都装作找东西 |
| 写崩 | 写成豪华仪式感补偿 | 写成他喜极失态 |

「她把本子给他拿着」一个动作顶三段话：证件类的东西向来归她管，这两本她给了他。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 无直接对应——婚书要过六礼，见 [七 · 当天](#七--当天)；最接近的是私底下换庚帖 |
| 修仙 | 道侣名录登记，掌籍长老盖印，前后一炷香 |
| 星际 | 终端上双人生物认证，系统提示音「绑定完成」，两个人对着那行字看了很久 |

#### 写崩的三种方式

1. 把领证写隆重。 它的全部味道就是不隆重。
2. 省略出门后那段空白。 「现在干嘛」这句台词比任何拥抱都准。
3. 跳过窗口小事。 行政细节的平淡是抒情的底色。

## 四 · 办不办婚礼

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：婚仪 38.8%

**骨架**｜证已经领了。婚礼是办给谁看的，两个人意见不一样。

#### 节拍链

有人提起 → 发现想法不同 → 各自的理由摆出来 → 背后的真实顾虑露出来 → 折中或一方让 → 定案

#### 时间轴

这场讨论会反复几轮，**每一轮都比上一轮更接近真实理由**：从「麻烦」谈到「花钱」，最后谈到真正怕的那件事。

#### 表面理由与真实顾虑

| 谁 | 说出口的 | 真的 |
|---|---|---|
| 不想办的一方 | 「俗、累、浪费钱」 | 怕那套流程：迎亲、改口、闹——每个环节都会把两人摆到传统位置上示众 |
| 想办的一方 | 「就一辈子一次」 | 想要一个被所有人看见的确认（往往是他，接 [11-初遇与确立 · 没有表白](11-初遇与确立.md#十--没有表白)的补偿心理） |

**常见配置是她不想办、他想办**：她怕的是流程，他要的是名分可见。把两个真实理由都挖出来，折中方案才有落点。

#### 可用细节

| 类 | 内容 |
|---|---|
| 折中方案 | 只请两桌至亲 · 旅行婚礼 · 只拍照不办席 · 办，但流程自己定 |
| 谈判细节 | 他列了一张「可以砍掉的环节」清单 · 她看到「堵门游戏：删」时笑了 |
| 定案 | 保留的环节每一项都有理由 |

「可以砍掉的环节清单」是这条最实用的道具：**把婚礼拆成模块逐项谈判**，正是这对关系处理传统脚本的标准姿势。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 分歧方向 | 她不想他想 | 他不想她想（少见，他的理由要给足） |
| 结局 | 简办 | 不办，多年后补了一场只有两个人的 |
| 压力源 | 内部分歧 | 父母要面子（接 [二](#二--两家坐下来谈)） |
| 情绪 | 商量 | 吵了一架才见真话 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他要的不是排场，是「站在人前被承认一次」 | 她怕的环节列出来，他一项项看懂了 |
| 内心 | 我可以为他站一次台 | 我要的那个东西，说出来真小气 |
| 好的处理 | 她答应办，条件是流程共写 | 他把真实理由说出口了 |
| 写崩 | 写成她冷酷拒绝仪式 | 写成他闹到父母那里施压 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 简礼还是全礼／她位高，全礼会把他家衬得难堪，简礼又像轻慢 |
| 修仙 | 昭告三界还是只告本门／道侣礼的规格即地位声明 |
| 星际 | 舰上小仪式还是回母星大办／通讯直播开不开 |

#### 写崩的三种方式

1. 停在表面理由。 「俗」和「一辈子一次」都不是真话。
2. 一方碾压式说服。 折中方案必须两边都出了血。
3. 把想办仪式的心愿写成虚荣。 他要的是可见的承认，这个需求是正当的。

## 五 · 试装

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：婚仪 38.8% ＋ 置装 6.8%

**骨架**｜婚纱店里，店员的每一句话都在暴露这个行业的默认设置。

#### 节拍链

进店 → 店员对着「新郎」推销的话术全部落空 → 各自试装 → 帘子拉开的那一眼 → 定装 → 帐单谁付（店员又猜错了）

#### 时间轴

按**试的套数**走。每换一套是一拍，帘子拉开是每一拍的重音。

#### 行业默认与现场实况

| 店员的默认 | 现场 |
|---|---|
| 新娘做主选婚纱 | 她十分钟选完，效率像开会 |
| 新郎随便挑一套 | 他试了七套，比她认真得多 |
| 「新郎在外面等就好」 | 帘子拉开，他先转过来问她「这套呢」 |
| 「先生您看新娘多美」 | 她看着他愣住的那种「美」，店员话术里没有这一款 |

「他试了七套她十分钟选完」，**在意外表的程度对调**，一个现成的反差。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 婚纱 ✓ · 西装的肩线 · 皮尺 · 试衣间 ✓ 的帘子 · 一墙的镜子 ✓ |
| 帘子拉开 | 两次拉开写两种：她出来他站起来了；他出来她放下了手机 ✓ |
| 店员 | 从话术错乱到看懂气氛改口，这个配角有小弧光 |
| 定装 | 她那套挑的是他多看了一眼的 · 他那套是她定的 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁更挑 | 他 | 她（她把选婚纱当项目管理，他看不下去了接手） |
| 穿什么 | 常规婚纱西装 | 她想穿西装（这一选择的后续要写：家里的反应、当天的全场目光） |
| 气氛 | 轻松 | 试到某一套忽然安静（两个人同时意识到这事是真的） |
| 结账 | 她付 | 他早偷偷付了定金 |
| 延长线 | 试装日（本条正题） | 拍摄日（婚纱照：摄影师按惯例喊「新郎手放新娘腰上」，照做还是当场重新设计动作，一组照片就是一次立场表态；成片里他们自己最喜欢的，往往是抓拍的那张） |

「她想穿西装」这一端别浪费：**着装是婚礼上最显眼的性别符号**，她若换装，等于把这段关系的样子直接穿在了身上——阻力和爽点都在这里。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 帘子拉开他站起来那一下 | 镜子里的自己，和身后她的表情 |
| 内心 | 原来他比我在意这场婚礼 | 这套太贵了，但她好像喜欢 |
| 好的处理 | 她认真选了，为他 | 他坦白试了七套的理由：想配得上站她旁边 |
| 写崩 | 写成她全程敷衍 | 写成他扭捏推辞 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 量体裁喜服／他的嫁衣绣样按例该素净，她吩咐照最艳的来 |
| 修仙 | 炼制婚服法衣／两人灵力共染一匹料 |
| 星际 | 定制礼服的全息试衣，系统按传统模板给错了款，两人对着改参数 |

古代女尊版的「嫁衣」在他身上：**嫁衣规制、盖头、红妆全套移到他那边**，每一项都是现成的戏。

#### 写崩的三种方式

1. 只写她试装。 他那七套才是反差主菜。
2. 店员当无声背景。 这个配角的错乱与改口是免费的喜剧。
3. 试装一路笑到底。 中间要有那一下忽然的安静。

## 六 · 婚礼前夜

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：婚仪 38.8% ＋ 夜深 37.0%

**骨架**｜按习俗今晚要分开睡。两个人都睡不着。

#### 节拍链

被各自家人领走（习俗）→ 各自的夜 → 忍不住的消息往来 → 一通压低声音的电话 → 有人翻墙／溜出来（或没有）→ 天亮

#### 时间轴

倒计时。**手机上的时间从 23:00 走到 04:30**，明天此刻已经在仪式中间了。

#### 两边的夜

| 她那边 | 他那边 |
|---|---|
| 母亲坐在床边说了很多，最后说「他挺好」 | 兄弟们闹完散了，屋里忽然空下来 |
| 她第一次听母亲讲自己当年 | 他对着挂起来的礼服发呆 |
| 表面镇定，凌晨在阳台站了一会儿 | 给她发：「睡了吗」秒回：「没」 |

「母亲那句『他挺好』」是这条藏的一把钥匙：**长辈的认可拖到前夜才给**，此前所有的保留在这一晚清账。

#### 可用细节

| 类 | 内容 |
|---|---|
| 消息 ✓ | 有一搭没一搭 · 「明天别紧张」「你才紧张」 · 都在等对方先说睡 |
| 电话 | 压着声音打的 · 内容全是废话 · 挂断前停了几秒 |
| 溜出来 | 楼下见了十分钟，什么也没干，就是看看 · 被家人抓包，笑着轰回去 |
| 各自 | 她检查了三遍流程表 · 他把誓词又背了一遍，背串了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 守不守习俗 | 分开睡 | 根本没分（习俗第一项就被砍了） |
| 情绪 | 期待 | 有一方忽然慌了，另一方在电话里接住 |
| 溜出来 | 溜了 | 没溜，隔着消息道晚安 |
| 长辈 | 前夜和解 | 前夜还有一场没谈完的（接 [二](#二--两家坐下来谈)） |

「有一方忽然慌了」这一端要写公道：慌的可以是她。 决定做惯了的人，在一个不可撤销的决定前夜慌一下，非常真实。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她妈那句「他挺好」 | 空屋子里挂着的那身礼服 |
| 内心 | 我从不失眠，今晚例外 | 明天走到她旁边的路只有二十米，我练了三年 |
| 好的处理 | 她把慌说给他听了，电话里 | 他说「你要是明天想跑，跑之前叫上我」 |
| 写崩 | 写成她冷静如常 | 写成他借酒壮胆 |

「你要是想跑，跑之前叫上我」，他版本的定心丸：不堵门，同逃。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他在家中最后一夜，母兄嘱咐；她隔墙掷来一枚系着字条的果子 |
| 修仙 | 各自闭关静心，神识却在结界边碰上了，都没走 |
| 星际 | 两艘舰并航，私人频道开了一夜，多数时间只有呼吸声 |

#### 写崩的三种方式

1. 前夜写成回忆总集。 回忆一段就够，主体是今晚的失眠。
2. 两边平均用力。 挑一边为主场，另一边用消息透出来。
3. 溜出来演成大戏。 十分钟，看看就回。

## 七 · 当天

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：婚仪 38.8%

**骨架**｜每个仪式环节都自带一个传统答案。他们一项项给出了自己的。

#### 节拍链

清晨各自梳妆 → 迎亲（谁迎谁）→ 堵门（堵谁）→ 仪式 → 誓词 → 交换戒指 → 敬酒 → 送客 → 洞房门关上，终于只剩两个人

#### 时间轴

流程表就是钟。**从早六点到晚十点，每个环节踩点进行**，两个人真正独处的时间为零，直到最后一拍。

#### 逐环节的改写

| 环节 | 传统版 | 他们的版本 |
|---|---|---|
| 迎亲 | 男迎女 | 她去迎他（他家那边炸了锅又觉得新鲜）· 或互不迎，中场汇合 |
| 堵门 | 堵新郎 | 他的兄弟堵她，题目全是「他不吃什么」，她全对 |
| 入场 | 父亲挽女儿交给新郎 | 谁挽谁进场，这个画面怎么摆，提前吵了三轮 |
| 誓词 | 模板 | 自己写的，都很短，都有一句只有对方听得懂 |
| 敬酒 | 新郎挡酒 | 她挡他的酒，全场起哄，他耳朵红到脖子 |

「堵门题全对」是最好写的一小场：她对着门后喊答案，一题不错，门里门外都在笑。 考题即关系存档。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 流程表 · 誓词的小抄（他手心的汗把纸洇了）· 戒指 ✓ 枕 · 请柬 ✓ · 喜糖 ✓ |
| 走神瞬间 | 仪式中途四目相对，同时想笑（因为想起前夜那句「想跑叫上我」） |
| 长辈 | 他母亲哭了 · 她父亲跟他碰了一杯，什么都没说 |
| 最后一拍 | 门关上，两个人瘫在床沿，礼服都没脱，她说：「饿不饿，我叫外卖」 |

「叫外卖」收尾与 [三 · 领证那天](#三--领证那天) 的「吃面」呼应：这一族的抒情都落在最平常的一口吃的上。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 规模 | 两桌至亲 | 全套大办 |
| 事故 | 无 | 有一件小事故（戒指一时找不到），反而成了全场最放松的一刻 |
| 情绪峰值 | 誓词 | 一个没排进流程的瞬间 |
| 结尾 | 外卖 | 他下厨（礼服袖子挽起来那一下，全书立住） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 挡酒时全场的哄笑，和他通红的耳朵 | 她一路走过来的那二十米 |
| 内心 | 这些流程真吵，可他在发光 | 别哭。忍住。没忍住 |
| 好的处理 | 她的誓词短而具体，落在一件小事上 | 他的誓词最后一句只有她听懂了 |
| 写崩 | 写成她全程掌控如主持 | 写成他从头哭到尾 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 全套六礼倒置：她亲迎，他蒙盖头出门，他母亲替他压钗；拜堂、却扇、合卺 |
| 修仙 | 道侣礼：共执一剑立誓／双修阵起时满山灵光，观礼的师门起哄声不输凡俗 |
| 星际 | 舰桥仪式，舰长证婚；两人的生物信号在主屏上并成一条线，全舰欢呼 |

古代女尊版的「却扇」值得单写：**行却扇礼时移开扇子看到他那张脸**，这个环节天生就是为盖头下的人准备的高光，现在坐在扇子后面的是他。

#### 写崩的三种方式

1. 流水账过全流程。 挑三个环节写足，其余一句带过。
2. 事故写成灾难。 婚礼事故的正确用法是让全场松下来。
3. 只剩两人后立刻转场。 「饿不饿」那一拍是全天的落点，删了整场白忙。

## 八 · 敬茶与改口

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：婚仪 38.8% ＋ 改口 30.0%

**骨架**｜一杯茶，一声「妈」。这声改口比婚礼上任何誓词都难出口。

#### 节拍链

摆茶 → 他先敬她父母 → 那声称呼卡了一下 → 出口 → 红包 → 换她敬他父母 → 他母亲的那句话 → 礼成

#### 时间轴

两杯茶，几分钟。**全场的重量压在两声称呼上**，其余都是流程。

#### 两声改口的不对称

| | 他叫她父母 | 她叫他父母 |
|---|---|---|
| 难点 | 她父亲那关：他攒了很久的底气 | 她不习惯对任何人执小辈礼 |
| 卡壳的样子 | 声音比排练时小了一半 | 语气差点带上谈判腔，自己收住了 |
| 对方回应 | 她父亲「哎」了一声，别过头去 | 他母亲拉着她的手说了句掏心窝的 |
| 那句掏心窝的 | — | 「他从小没让我省过心，往后麻烦你了」——把儿子托付给她，这句是传统里托付女儿的话，方向换了 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 茶盘 · 跪垫（跪不跪，提前谈过）· 红包的厚度差（两家暗暗较劲的余波） |
| 微表情 | 她父亲接茶时手抖了一下 · 他母亲抬手抹眼角，用的是拇指 |
| 卡壳 | 那声「妈」出口前吞咽了一下，全场都听见了那个停顿 |
| 之后 | 长辈立刻转入唠家常模式，紧张感一秒蒸发 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 跪不跪 | 跪 | 鞠躬（这项提前谈崩过一次） |
| 谁更紧张 | 他 | 她（罕见的她怯场） |
| 长辈反应 | 顺利 | 有一位始终没给好脸，成为婚后长线 |
| 红包 | 常规 | 里面除了钱还有一样旧物（他母亲留给「儿媳」的镯子给了她，这个错位怎么处理） |

「传家镯子」这一端是好题目：**婆婆把给儿媳的传家物给她**，物件按旧脚本传递，收的人不在旧脚本里——收还是改赠，一个动作定调。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他母亲那句托付 | 她父亲的那声「哎」 |
| 内心 | 我被托付了一个人 | 这一关过了，这辈子最难的一关 |
| 好的处理 | 她收了镯子，转手戴在了他腕上 | 他叫第二声时声音正常了 |
| 写崩 | 写成她豁免一切礼节 | 写成他磕头如捣蒜 |

「镯子转手戴在他腕上」：把错位的传家物归到正确的人身上，一个动作改写了整个仪式的方向。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 庙见礼：他随她拜她家宗祠，名字录入她族（接 [20-女尊制度场景 · 他上了族谱](20-女尊制度场景.md#八--他上了族谱)） |
| 修仙 | 拜师门长辈，改称「师伯师叔」，辈分表当场重排 |
| 星际 | 家族数据库权限互授，称谓字段正式变更 |

#### 写崩的三种方式

1. 改口一带而过。 那个吞咽的停顿是全场的心脏。
2. 长辈全员慈祥。 留一位没松口的，婚后才有戏。
3. 红包只是红包。 让它装点别的东西。

## 九 · 婚后第一顿早饭

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：做饭 47.0% ＋ 婚仪 38.8%

**骨架**｜什么都没变。粥还是那个粥。而有个词从今天起可以用了。

#### 节拍链

醒来（比平时晚）→ 厨房有声音 → 一切如常的早饭 → 谁先用了那个新称呼 → 愣一下，笑 → 照旧收拾出门

#### 时间轴

| | 四爱女笔下 | 四爱男笔下 |

## 十 · 纪念日的演变

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：节日 33.0% ＋ 婚仪 38.8%

**骨架**｜第一年、第五年、第十年，同一个日子过法不同。过法的变迁就是婚姻的年轮。

#### 节拍链

第一年（隆重）→ 第三年（差点忘，补救）→ 第五年（不再办，但都记得）→ 第十年（一句「今天几年了」）→ 每一年的落点

#### 时间轴

**这条的钟以年为单位**，与 [18-节令与天候 · 一年过去了](18-节令与天候.md#九--一年过去了) 的对照技法同源：同一日子重写多次，改的细节越小越好。

#### 演变表

| 年份 | 过法 | 那天的一句话 |
|---|---|---|
| 第一年 | 订了餐厅，都紧张，像补办初次约会 | 「明年还来这家」 |
| 第三年 | 一方出差错过，视频 ✓ 里补过（接 [02-等待与错过 · 错过的纪念日](02-等待与错过.md#八--错过的纪念日)） | 「回来补」 |
| 第五年 | 没订餐厅。他做了菜，她带了酒 | 「比那家好吃」 |
| 第十年 | 早上出门她说了句「十年了」，晚上桌上多了两个菜 | 什么都没说 |

从「说很多」到「什么都没说」，这个递减是熟，不是淡。这条要把递减写成升温。

#### 可用细节

| 类 | 内容 |
|---|---|
| 锚点物 | 每年在同一位置拍一张 ✓（十张排开就是全书年表）· 那瓶「等十年开」的酒 |
| 差点忘的那年 | 谁忘了 · 对方怎么不动声色地提醒 · 补救的样子 |
| 递减的仪式 | 礼物从贵重到实用到没有，「没有」那年反而最稳 |
| 增加的东西 | 话少了，菜多了 · 第十年桌上那两个菜正是第一年餐厅点过的 |

「第十年的两个菜是第一年餐厅的」，递减到头，绕回起点，正好合上。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 跨度 | 写到五年 | 写到几十年（接 [21-世界设定专属 · 寿元差](21-世界设定专属.md#五--寿元差)，年轮会走完） |
| 中间 | 顺 | 有一年是分居中过的（接 [22-分手与复合](22-分手与复合.md)），那年谁都没提，但都记得 |
| 递减 | 自然 | 有一方先慌了：「我们是不是淡了」——另一方用那两个菜回答 |
| 结尾用法 | 全书终章 | 中段的时间跳跃装置 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 第十年那句轻描淡写的「十年了」 | 桌上那两个菜，她认出来了 |
| 内心 | 不办了，不是忘了 | 她记得那家餐厅点过什么 |
| 好的处理 | 她的纪念方式越来越小，越来越准 | 他每年那张照片 ✓ 拍在同一个位置 |
| 写崩 | 写成逐年盘点感情账 | 写成年年隆重毫无变化 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 每年那日她推了所有帖子在府里用饭；第十年那日她告了假——满朝皆惊 |
| 修仙 | 百年一小祭，千年那次两人回了当年结契的山头，山头已换了三代弟子 |
| 星际 | 每年校准一次「地球日」过这一天；舰历与地球历的偏差越攒越大，他们只认自己那套 |

「他们只认自己那套历法」：把私人纪念日过成了私有时间体系，这是星际版独有的浪漫。

#### 写崩的三种方式

1. 每年写一样长。 后面的年份要越写越短，短到一句。
2. 把递减写成危机。 「我们是不是淡了」要被那两个菜否掉。
3. 只写甜年。 中间放一个坏年份，年轮才是真的。
