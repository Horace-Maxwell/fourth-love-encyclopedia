## 安全框架（先读这一节）

这一族写的是古代女尊设定里的制度层，框架要在动笔前写全。婚仪、七出、男德、验身、位阶、籍、扶正、封诰——其中一半直接性转自现实历史上的人身依附制度。

### 三条社群共识

| 缩写 | 全称 | 含义 |
|---|---|---|
| SSC | Safe, Sane, Consensual | 安全、理智、双方同意 |
| RACK | Risk-Aware Consensual Kink | 知晓风险的前提下双方同意 |
| PRICK | Personal Responsibility, Informed Consensual Kink | 个人责任前提下的知情同意 |

这三样说法，是不同年代的读者自己琢磨出来的。意思归到一处：同意这件事，得是头脑清醒的成年人做的，清楚自己在干什么，而且随时能反悔。

### 虚构与现实的分界

**古代那套人身依附规矩，是拿来玩梗的，不是拿来当真的。** 良贱、验身、家法、七出、籍没，历史上真压得人喘不过气。小说里把这套东西翻过来用，让读者换个角度看看它长什么样。但世界是作者说了算，后果也是作者说了算。它不是现实操作手册。

这一族不提供任何可复现的实施细节，只讨论叙事结构。

### 三条硬边界

| 边界 | 说明 |
|---|---|
| 全员成年 | 所有涉及婚配、依附与责罚的角色都是成年人 |
| 不写过程 | 验身、家法、责罚只写结果，过程不写。具体写法看 [06-尺度与写法/04-训诫与BDSM专论](../06-尺度与写法/04-训诫与BDSM专论.md) |
| 制度要被使用 | 设定里写了的制度，正文里既没人用，也没人违反，就是白写（怎么查死设定见 [02-术语百科 5.5](../02-术语百科/02-女尊称谓与礼制体系.md)） |

关于家法完整框架和越界判定的内容，在 [08-规训日常版 · 安全框架](08-规训日常版.md) 和 [20-女尊制度场景 · 家法](20-女尊制度场景.md#六--家法) 里。带 ⚠️训诫 的三条，分别是 [四 · 守身这回事](#四--守身这回事)、[五 · 通房与外室](#五--通房与外室)、[七 · 扶正](#七--扶正)。

## 一 · 大婚

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：婚礼仪式＋请安＋选侍 24 部 / 0.9%（[13-07 §四情境组合](../13-语料挖掘/07-桥段分布.md) 榜首）

**骨架**｜女娶男嫁，三天办完。头一天她把他娶进门，第二天他头一回请安，第三天妾室按位次排定。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 议亲先定规格：是娶（三书六礼全套）还是纳（仪注低一等），这一步一定，后面所有名分都定了（[纳夫／娶夫](../02-术语百科/02-女尊称谓与礼制体系.md) 词条） |
| 2 | 下聘。聘礼由她家出，和现实正好反过来，他家备嫁妆，妆册一式两份 |
| 3 | 迎娶那天她亲自去接，他上轿，门槛、火盆、喜秤的性转版一样样过 |
| 4 | 拜堂的先后：先告祖，再拜她的母父，最后交拜 |
| 5 | 入夜前的那半刻：她挑起帕子，他抬头，头一回在自己家里看她 |
| 6 | 第二天五更，头一次晨昏定省：奉茶，改口，被领着见府里的人（这一拍接 [20-女尊制度场景 · 晨昏定省](20-女尊制度场景.md#一--晨昏定省) 的第一天） |
| 7 | 第三天媵侍见礼，位次当场排定，妆册和人册一起入库 |
| 8 | 三天礼成，第四天起照日常的钟点过 |

#### 时间轴

**三天，一天一个说了算。** 第一天听礼官的，什么时辰做什么，一点都差不得。第二天听她爹娘的，茶烫不烫，说几句话，赏什么，全看长辈的心情。第三天看位次，媵侍谁站前谁站后，一旦排定，往后几十年都不会变。他自己能支配的时间只有两段：坐在轿子里的那一个时辰，和第三天晚上两人单独待的那一会儿。

#### 三日各写什么

| 日 | 制度动作 | 要写的 |
|---|---|---|
| 第一日 | 聘、迎、拜 | 她亲自去接，去不去，差的是整整一个台阶 |
| 第二日 | 奉茶、改口、请安 | 婆公肯不肯接那杯茶，接了才算改了口 |
| 第三日 | 媵侍见礼、排位次 | 他站在哪儿，全府上下往后就照那个位置看他 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 文书 | 聘书 · 妆册一式两份，男方家留底 · 婚书上两个名字谁写在前 |
| 器物 | 喜秤 · 火盆 · 那盏改口茶凉了要换一盏，换过一次的人都记得 · 他袖子里攥着的礼单 |
| 礼节 | 拜的次序 · 他跪的次数 · 谁扶他起来 |
| 媵 | 陪嫁过来的同族兄弟或舅甥（[媵](../02-术语百科/02-女尊称谓与礼制体系.md) 词条），他们排在哪里，牵着他的体面 |
| 破绽 | 三天里他几乎没吃东西 · 第二天嗓子哑了，茶太烫，话又一句不能少 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 规格 | 娶（全礼） | 纳，仪注减半，名分也一起减半 |
| 她去不去亲迎 | 亲自去 | 派人代迎，规矩上挑不出错，可明摆着是在打脸 |
| 媵 | 有，贵族出嫁都带 | 没有，他出身寒门，第三天没人可排，这一天格外难熬 |
| 三日办得怎样 | 礼数挑不出错 | 出过一处小错，是谁替他兜住的，那人就是他往后能靠的人 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 亲迎那天她掀轿帘的手 | 跨火盆那一步，他迈得比礼官教的还高 |
| 内心 | 三天里真由她说了算的，只有这一回 | 每一步都是排好的，只有掀帘那一眼是多出来的 |
| 好的处理 | 她在礼官没留意的地方，多做了一件小事 | 礼数一点没错，错的那一点别人看不出来 |
| 写崩 | 婚仪写成流水账 | 当夜写成重头戏 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 领证、婚礼、回门三件事（[23-婚嫁](23-婚嫁.md) 整卷） |
| 修仙 | 结契大典、拜山门、道侣录留名 |
| 星际 | 登记、舰上典礼、权限交割三段 |

#### 写崩的三种方式

1. 三日压成一日。 三天各有一个说了算的人，砍掉两天，剩下的只是表面功夫。
2. 礼数写全了，人却不见了。 礼单可以查书，他吃了几口饭查不到，作者该下笔的是后面这个。
3. 媵侍当摆设。 第三天排下的位次，后文要用上，不然那一天就白写了。

## 二 · 和离与休夫

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：无独立节拍族（词条见 [02-术语百科 · 和离／休夫](../02-术语百科/02-女尊称谓与礼制体系.md)）

**骨架**｜和离也好，休夫也好，都在同一张桌上写。和离书一人一份，休书只有一份。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 事到临头，不办不行。或者她非保他不可，或者她非丢开他不可，再不然就是他自己待不下去了 |
| 2 | 先翻规矩：要休，得占七出里的一条，不孝父母、无子、偷人、善妒、恶疾、多嘴、偷盗，和离只要两边都点头 |
| 3 | 有人翻出三不去：替公婆守过孝的，从穷日子一起熬过来的，娘家已经没人的，占一条就休不了 |
| 4 | 谁执笔，谁在旁边看着，族里长辈、中人、官媒都算 |
| 5 | 落笔那一下各不相同：和离书一人一份，休书只在她手里一张，另一张进衙门存档 |
| 6 | 嫁妆怎么算，原样带走，对半分，还是一分不给 |
| 7 | 从哪道门出去，正门和侧门差的是往后一辈子的脸面 |
| 8 | 往后怎么称呼：她在外面怎么提起他，他在外面怎么提起她 |

#### 时间轴

事情逼到眼前只要一天，走完却要一个月。查名目花半天，三不去的核对要请族里最年长的那位来说，一说就是一整天。文书改了三遍，改的都是名目那一行，真落笔用不了半炷香。清点妆奁花两天，一件件对着册子。最后是出门那一步，这一步走完，前头那一个月才算了结。

#### 两种落笔法

| | 她放手（和离） | 他求去（下堂） |
|---|---|---|
| 名目 | 两边都点头，不用扯理由 | 得替他编个像样的说法，多半落在他自己身上 |
| 文书 | 一式两份 | 他求的是休书，只有一份，丢脸的是他 |
| 妆奁 | 原样还回去，算是给足了面子 | 他常常什么都不要，好让那张文书看上去是她占理 |
| 停在哪 | 她按住笔的那一下 | 他把编好的理由推过去，说“照这个写” |
| 后事 | 他还能再嫁 | 名声坏在名目那一行，再嫁就难了 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 文书 | 和离书的写法，各无怨怼、各自婚嫁 · 休书里写的那一条七出 · 官府盖的骑缝印 |
| 三不去 | 他替婆公守过孝的那一年，这条最常被拿来救人 |
| 在场的人 | 族老 · 中人 · 官媒 · 一个没忍住哭出来的下人 |
| 妆奁 | 册子上样样对得上，只有一样对不上，那一样是他自己添进去的 |
| 门 | 正门 · 侧门 · 他从哪道门走出去，第二天全城就都知道了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提的 | 她 | 他几乎提不了，所以得借七出绕个弯 |
| 名目的真假 | 真的 | 编的，编个名目是给对方台阶，也是把错揽到自己身上 |
| 妆奁 | 原样还回去 | 他一样都不拿 |
| 结局 | 各自再嫁 | 过了几年来了一封信（走 [22-分手与复合](22-分手与复合.md) 的古代接口） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 名目那一行她改了三遍 | 说「照这个写」四个字时的语速 |
| 内心 | 写真的伤他的名声，写假的伤她自己的 | 名目落在我身上，她才干净 |
| 好的处理 | 和离与休夫分开写清楚，不混着用 | 求去的理由具体到官媒能记下来 |
| 写崩 | 休书被当成吵架的道具甩出来 | 潇洒一转身，妆奁不算，门也不问 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 协议离婚和诉讼离婚的区别（[22-分手与复合 · 离婚这一场](22-分手与复合.md#十一--离婚这一场)） |

| 星际 | 关系解绑要打申请 · 权限先收谁的 |

#### 写崩的三种方式

1. 和离与休夫混用。 一个两愿，一个单方，混用就等于制度没写。
2. 七出只念不用。 条款列出来了，情节却不靠它，那就是死设定。
3. 妆奁不算。 清点财产这一段，靠感情糊弄不过去。

## 三 · 男德课

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：无独立节拍族（词条见 [02-术语百科 · 男德／男戒／男红](../02-术语百科/02-女尊称谓与礼制体系.md)）

**骨架**｜《男戒》那一套他守了十几年，熟到不用过脑子。她头一回看出这一点的那天怎么应对，往后就分出了三种写法。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 婚前那套规矩是怎么教的：三从，没出嫁听娘的，嫁了听媳妇的，媳妇没了听闺女的，四德，媳妇的德、媳妇的话、媳妇的样、媳妇干的活 |
| 2 | 平日里想都不用想就做了：她起身他也起身，她坐着他就在旁边站着，眼睛只敢落在她脚尖往上三寸那块地方 |
| 3 | 她头一回看出来，他这样是背熟的，她原当是脾气好 |
| 4 | 她试着让他破一回例：坐下，抬头，先动筷子 |
| 5 | 他要么做不到，要么做到了，却一整夜没合眼 |
| 6 | 她心里拿定主意：接着用，挑着用，还是全都扔掉 |
| 7 | 全扔掉的麻烦：规矩一没了他反倒慌，得有人给他另立一套 |
| 8 | 过了好些年，他偶尔还会退那半步，两个人谁都不提 |

#### 时间轴

试着破一条，当场就能见效。可要真改掉一条，至少得半年，改到再也不犯，得三年。中间来回反复是常事，她一出门，老毛病就回来了。这一套他学了十几年，改也得按年来算。

#### 三种态度，三种人

| 她的态度 | 她是谁 | 他的处境 |
|---|---|---|
| 照旧沿用 | 靠这套规矩上位的人，她信这一套 | 稳妥，可一辈子也就是个做得好的人 |
| 挑着用 | 场面上的礼数留着，私下不讲这一套 | 最常见，分寸在哪里也最难说清 |
| 整套拆了 | 她要的是能和她说上话的人 | 先懵，再慢慢缓过来，懵的那一段最好看 |

#### 可用细节

## 四 · 守身这回事

`M` ｜ ⚠️训诫 ｜ 古代女尊 ｜ 语料频次：无独立节拍族（词条见 [02-术语百科 · 守身如玉](../02-术语百科/02-女尊称谓与礼制体系.md)）

**骨架**｜把贞洁那一套整个搬到男人身上：婚前要守，婚后要验，丢了就是名节毁了。她信不信这一套，决定了这场戏是在压人还是在拆台。

#### 安全框架（承卷首）

| 项 | 说明 |
|---|---|
| 共识框架 | SSC · RACK · PRICK，全文见卷首 |
| 虚构与现实 | 验身、名节这类事，是故事里编出来的设定，别当成现实里的规矩 |
| 不写过程 | 只交代有这回事、带来什么后果，不写任何能照着学的细节 |
| 全员成年 | 出场角色全是成年人 |

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 规矩比人先到：成亲前身子得干净，这是谈婚论嫁的硬杠杠 |
| 2 | 查不查要看形式，婚前要凭证，婚后要堵住别人的嘴。过程不写，只写有没有这回事 |
| 3 | 有人拿这件事挤兑他，酒桌上一句话，下人嚼的一句舌根 |
| 4 | 话传到她耳朵里，中间隔了一天，那是下人在掂量该不该报 |
| 5 | 她的处理就三种：信，查，装作没看见 |
| 6 | 她怎么处置，所有人都看在眼里，府里人看他的眼光马上就变了 |
| 7 | 事后他自己过不去：被议论的是身子，抬不起头的是整个人 |

#### 时间轴

她听到那句闲话，已经隔了一天。话从席上起，三十息工夫就传遍了，要洗掉却得好些年。处置得快，三天内能定调，慢一点，一个月后就成了定论。最久的是他自己那一关，闲话早散干净了，他还放不下。

#### 可用细节

| 类 | 内容 |
|---|---|
| 凭证 | 议亲时男方家写的那张纸 · 保人是谁 · 那张纸收在妆奁的哪一层 |
| 闲话的形状 | 半句话 · 一个眼神 · 一句“听说”，说的人自己也没底 |
| 她的三档 | 信，当场把话顶回去 · 查了，就等于认了这套规矩 · 不查最难，不查也得给出个说法 |
| 他的处境 | 名节这种事自证不了，越解释越像真的 |
| 收尾的物件 | 那张凭证最后怎么处置：烧掉，还给他，还是照旧收着 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他守没守 | 守了，清清白白，照样有人说闲话 | 没守，有过前事，这话才真戳到心上 |
| 她信不信这套 | 信，她是在规矩里长大的，写实，但不容易讨人喜欢 | 不信，后果她得自己扛，族里会记着 |
| 处置 | 公开 | 私下，快，可堵不住别人的嘴 |
| 收尾 | 那张凭证烧了 | 那张纸还在，只是再没人提 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 听完闲话，她开口问的第一句是什么 | 他明白自己怎么都说不清的那一下 |
| 内心 | 查不查，都等于认下了这条规矩 | 干不干净，全凭别人一张嘴 |
| 好的处理 | 收拾传话的人，不冲着他的身子去 | 他不急着洗清，也不装大度 |
| 写崩 | 检验写成走过场 | 失贞写成他人品有亏 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 他从前的事被人翻出来嚼舌根（[15-秘密与坦白 · 前任出现](15-秘密与坦白.md#四--前任出现)） |
| 修仙 | 元阳和道基那一套说法 · 同门在背后嘀咕 |
| 星际 | 婚配档案里存着旧记录 · 谁有权翻出来看 |

#### 写崩的三种方式

1. 把检验写成场面。 写出有这套制度就行，怎么执行不用写。把过程写细了，就越过了卷首那条线。
2. 让她也信这套，却不让她付出代价。 信有信的代价，不信也有不信的，两边都得还。
3. 用一句「我信你」收尾。 光说信堵不住别人的嘴，得处置传话的人。

## 六 · 招赘与入赘

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：无独立节拍族（词条见 [02-术语百科 · 一妻多夫／平夫制／走婚](../02-术语百科/02-女尊称谓与礼制体系.md)）

| 2 | 女户立得起来，全靠她当户主，后面所有的事都从这一条来 |

| 5 | 他原来那家算账：少了一个干活的人，多了一门亲戚，两边心里各有盘算 |
| 6 | 头一回有人用新的姓名叫他，他愣了一拍才答应 |
| 7 | 孩子随母姓，写进族谱那天，他在一旁看着 |
| 8 | 多年以后，他的本名只在三个地方还看得到：旧档案里，他娘嘴里，或者某件老物件上 |

| 走婚版 | 来不来全由她 · 门口留个记号 · 他不问下回 |
| 收尾物 | 一件刻着旧名的东西，他没扔掉，也没拿出来过 |

| 轴 | 一端 | 另一端 |
|---|---|---|
| 形态 | 招赘，他把自己交了出去 | 走婚，谁也不交，各留一半 |

| 他的接受度 | 认了，而且认得干脆 | 始终没认，半辈子都在两个名字之间过 |

| | 四爱女笔下 | 四爱男笔下 |

| 内心 | 他算是我户上的人了，这一行比婚书还管用 | 往后我归谁管，纸上写得一清二楚 |
| 好的处理 | 户籍后面还要用上，别开头交代完就丢开 | 改名的别扭放在签名那一下停顿里 |
| 写崩 | 改姓弄成了求婚现场 | 招赘和走婚搅成一锅粥 |

| 世界 | 等价物 |

## 七 · 扶正

`M` ｜ ⚠️训诫 ｜ 古代女尊 ｜ 语料频次：位份 16.5%（[02-术语百科 · 良籍／扶正／俾男](../02-术语百科/02-女尊称谓与礼制体系.md) 的场面化）

**骨架**｜正夫的位子空着，够格的人身上都压着一个籍。先改籍，后扶正，落印的时候他还站在门外。

#### 安全框架（承卷首）

虚构世界里，「良贱之别」如何运作、如何被钻空子，才是这故事真正要碰的东西。历史上那套人身依附确实存在，但具体怎么操作，不写，能照着搬的，也不碰。故事里所有角色，都是成年人。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 正夫位空了出来：人没了，和离了，或者被休了（接 [二](#二--和离与休夫)） |
| 2 | 排资格：媵最够格，良籍臣室差一档，抬举的通房再往后，贱籍垫底 |
| 3 | 卡在籍上。良贱不通婚，贱籍要先脱籍：赎身，销贱，入良册，这道手续最耗时日 |
| 4 | 族议。嫡庶分明的世家一律不准，管得不严的准，但礼数要降一格 |
| 5 | 写好文书，盖印。印砸在纸上那一声响，这件事才算落了地 |
| 6 | 礼数降格的几处：办个宴就算，不告祖，不走正门 |
| 7 | 他从侧门进来，一路走到正堂站定 |
| 8 | 称呼当天全改，府里人改口快慢，就看出人心往哪倒 |

#### 时间轴

族里开了三次会，文书起草了好几天，最后盖章只是一眨眼的事。可章盖完了称呼还得改，下人三天改完，族里三年都改不干净。赎身销贱要跑官府，快则半年，慢则三年，中间要人担保，要花钱，还得她亲自出面。她一出面，族里就记下一笔。

#### 籍这一关

| 出身 | 能不能扶正 | 要先做什么 |
|---|---|---|
| 官宦养男 | 可 | 无 |
| 平民良籍（登记臣书） | 可 | 无 |
| 通房抬举 | 可 | 先入册给名分 |
| 赤贫卖身 | 须先改籍 | 赎身、销贱籍、入良册 |
| 戏子、伎男 | 须先改籍，且族议几乎必阻 | 同上，另加一场公议 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 文书 | 良册 · 臣书 · 扶正的那一纸 · 骑缝印 |
| 钱 | 赎身要多少两银子，写出个数，比写“不菲”管用 · 钱是谁出的 · 这笔钱往后会被人翻出来说 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的出身 | 良籍（顺当，戏在族议上） | 贱籍，戏在改籍那一段 |
| 族议 | 过了 | 没过，她另找出路（改宗规，走 [20-女尊制度场景 · 她改了规矩](20-女尊制度场景.md#七--她改了规矩)） |
| 仪注 | 降一等，合规矩，往后总有人拿这事说他 | 她非要全礼，代价落到他身上，全府都知道那是破了例 |
| 他的反应 | 平静地受了 | 他自己请求降等，不想她为此欠下人情 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 印按下去，她的手没抖 | 侧门的门槛比正门矮，他记下了 |
| 内心 | 名分我给得起，出身我给不了 | 名分有了，出身还差一截 |
| 好的处理 | 改籍和扶正分开写，中间隔上一段 | 降了等的地方，他自己一处一处地数 |
| 写崩 | 一张文书当场解决所有事 | 写一大段感恩戴德的独白 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 从同居到领证 · 试用转正 · 先给名分还是先落户口（[38-制度里的两个人](38-制度里的两个人.md)） |
| 修仙 | 记名弟子转亲传 · 道侣录上挪位子 · 血契重签 |
| 星际 | 临时权限转成正式编制 · 档案里那条「原编制」怎么也删不掉 |

#### 写崩的三种方式

1. 跳过籍这一关。 名分她给得了，出身她给不了。跳过这一关，这条就只剩一场仪式。
2. 仪注减等不写。 不告祖，不走正门，把这几处省掉的写出来，读者才看得见制度。
3. 落印之后皆大欢喜。 改口的快慢要写，印落下了，人心未必跟着改。

## 八 · 一家子的称谓

`G` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：请安 26.6%，称谓在请安场里每日兑现

**骨架**｜孩子头一回开口叫人，把家里的辈分挨个喊了一遍。轮到自己时，也把那一辈报得齐齐全全。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 孩子刚学说话，府里先教哪个称呼，先教叫谁，谁的位分就高 |
| 2 | 正夫叫「爹爹／阿爹／父亲大人」，位分低的叫「小爹／叔爹／庶父」（[小爹](../02-术语百科/02-女尊称谓与礼制体系.md) 词条） |
| 3 | 孩子叫错过一回 |
| 4 | 当场是谁纠正的，口气有多重，被叫错的那个人脸上挂不挂得住 |
| 5 | 他自己对不同的人换不同的称呼：对她，对长辈，对外客，对下人，四种叫法 |
| 6 | 有一回外客在场，孩子当众叫错了，大人怎么把场面圆回来 |
| 7 | 孩子长大了，称呼早就定死，有一个称呼，他一辈子没听孩子改过口 |

#### 时间轴

**孩子两岁到五岁，是称呼定型的窗口期。** 这几年教什么就叫什么，叫错也都集中在这三年，往后就很少出错了。成年以后再改口，基本只在关系变动的时候，比如 [七 · 扶正](#七--扶正) 之后全府一起改口。

#### 一家子怎么叫

| 关系 | 称呼 | 备注 |
|---|---|---|
| 子女→母 | 母亲 · 娘 | 语序倒置的总原则见 [母父](../02-术语百科/02-女尊称谓与礼制体系.md) 词条 |
| 子女→正夫 | 爹爹 · 阿爹 · 父亲大人 | 皇室叫「父后」，和「君后」是同一个人的两种叫法 |
| 子女→低位配偶 | 小爹 · 叔爹 · 庶父 | 用错了，就等于当众划了位阶 |
| 他→她 | 妻主 · 主子，看世界设定有多硬来选 | 「妻主」出现得越少越有力（[妻主](../02-术语百科/02-女尊称谓与礼制体系.md) 词条里的语感提示） |
| 他→自称 | 在下／臣身／侍身／奴家 | 四级往下降，一开口就听得出他在哪一档 |
| 并称 | 母父 · 妻夫 · 娘爹 · 婆公 · 奶爷 | 男先女后的语序全部倒过来 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 教的现场 | 谁抱着孩子教 · 教的第一个称呼是哪个 · 有人在旁边听着，一声不吭 |
| 叫错 | 把「小爹」叫成「爹爹」，位分低的那个先红了脸 · 反过来叫错，正夫不作声，这比发作更难写，也更好看 |
| 纠正 | 她来纠正 · 被叫错的那位自己纠正，他的分寸就在这一句里 |
| 自称的切换 | 他在她面前用哪一档，在外客面前又用哪一档，换过去的那半秒 |
| 一辈子没改的那一声 | 孩子成年以后还是那样叫，为什么，谁都不提 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 叫错的方向 | 往高里叫，位分低的人听着受用，又有点慌 | 往低里叫，正夫被降了一格，满座静了一息 |
| 教的人 | 她 | 乳母或长辈，教出来的称呼带着教的人的立场 |
| 他的自称 | 全程守规矩 | 私下自称「我」，单这一个字就越了规矩 |
| 收场 | 一句话带过去 | 这一次叫错，成了后面某件事的引子 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 孩子叫错之后，她先看的是谁 | 「爹爹」两个字落到别人身上的那一下 |
| 内心 | 一个称呼就把人钉在了位置上 | 我是什么位置，让一个三岁的孩子念了出来 |
| 好的处理 | 嘴上轻轻纠正，位份上一点不让 | 他自己纠正，比谁都快 |
| 写崩 | 称谓混用露了馅，写着写着把「父后」写成「母后」 | 把叫错当成无关紧要的小插曲 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 孩子在外人面前怎么叫他 · 他在她同事面前怎么介绍自己（[38-制度里的两个人 · 家长会谁去](38-制度里的两个人.md#三--家长会谁去)） |
| 修仙 | 师叔和师尊差着辈分 · 弟子怎么称呼他，要看她在门里排第几 |
| 星际 | 档案里填的那一栏关系 · 系统播报时念出来的那个称呼 |

#### 写崩的三种方式

1. 称谓表只在设定页齐整。 天天要用的东西放在附录里，正文一开口就露了馅。
2. 一套称谓混着两派用。 君系和夫系各成一套，一部书里只能选一派。
3. 叫错不留后果。 位阶要靠称呼落到实处，叫错一次却没人在意，位阶就等于不存在。

## 九 · 她的仕途

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：告别 38.9%（外放与赴任）＋ 位份 16.5%

**骨架**｜放榜，授官，外放。她的名字往上走一格，他的品级就跟着动一格。官眷是别人给他的身份，他这辈子只有这一个。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 她下场应考。规矩摆在那里，女子能考，男子不准考（见[男德](../02-术语百科/02-女尊称谓与礼制体系.md)词条） |
| 2 | 放榜那天他在哪儿：在家等着，在榜下挤着看，还是被人支开了 |
| 3 | 授官和封诰。朝廷给官员配偶的封赏落到他头上：冠服，品级，诰命的那道旨 |
| 4 | 外放的消息一来，全府收拾行装，交接事务 |
| 5 | 任上官眷之间的来往：同僚家的夫郎们，座次怎么排，谁家官大谁先开口 |
| 6 | 她在任上出了事（弹劾、亏空、下狱），官眷要连坐，那条律文写得明明白白 |
| 7 | 升官或贬官，他的品级跟着变，冠服换一回，称呼也换一回 |
| 8 | 她告老还乡那一年，那道诰命仍挂在他屋里 |

#### 时间轴

每外放一回，他就收拾一回行李，到第三回，闭着眼都知道哪只箱子装着书。她三年一考，满三年就换地方。中间总有一段要分两地，他先留下，她先走，或者他后头跟去，那一阵走 [09-分离与重逢](09-分离与重逢.md)。

#### 官眷这个身份

| 项 | 内容 |

| 可见形式 | 诰命那张纸 · 冠服 · 坐在哪儿 · 出门是什么排场 |
| 好处 | 他第一次在府门外头有了正经名分 |
| 代价 | 她的官位一动他就跟着动，她下了大牢，他也跑不了 |
| 最难写的一格 | 在官眷席上他得替她撑住面子，又不敢压过她一头 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 放榜 | 榜下挤满了人 · 报喜的跑错了门 · 他给多少赏钱，给多了是显摆，给少了是失礼 |

| 轴 | 一端 | 另一端 |

| 外放 | 一起去 | 他留下来（[20-女尊制度场景 · 她要出征](20-女尊制度场景.md#九--她要出征) 的文官版） |

## 十 · 制度的缝

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：位份 16.5% ＋ 请安 26.6%（收束条，不引新族）

**骨架**｜碰上一件事，规矩里翻不出说法：没条款，没先例，也没人管。两个人就自己给它定了一条规矩。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 冒出一件具体的小事，比如他想在她书房摆张自己的桌子，他名下能不能有处产业，他能不能替她出面见个人 |
| 2 | 按老规矩，先去问执事这事怎么办 |
| 3 | 执事翻了旧档回来，说没见过这种事 |
| 4 | 没翻到，两头就都悬着：没说不许，也没说能 |
| 5 | 摆在面前两条路：当没这回事，省心，他自己也会把话咽回去，要么自己定个规矩 |
| 6 | 规矩由谁定、落在哪儿：口头说定、写进家书，还是干脆入家规 |
| 7 | 第一次按这条规矩办事。等真有人拿它说事，它才算立住 |
| 8 | 过了些年，有人把这条当老例搬出来用，那时它早已不只是两个人之间的事 |

#### 时间轴

两人商量只用了一个晚上，落到纸上更短。问和查都在同一天，查出无此例只花了半天。立下的这一条，要等多少年后有人援引才见分晓。第一次被援引，隔一年到数年，等第三个人也拿它来用，它才真进了制度。要是一直没人援引，它就只是他们俩之间的一句话，这也是一种结局。

#### 与 20 卷第十条的分别

| | [20 · 制度之外的那一刻](20-女尊制度场景.md#十--制度之外的那一刻) | 这一条 |
|---|---|---|
| 缺口的性质 | 一时没人管 | 根本没有这条规矩，典章翻遍也找不到 |
| 时长 | 几分钟，随时能收 | 一件事，能留上几十年 |
| 收法 | 两人立刻退回原样 | 两人给自己立了条规矩 |
| 与制度的关系 | 绕开它 | 给它添一笔 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 那件小事 | 挑得越小越好，像一张桌子、一把钥匙、一天由自己说了算 |
| 查的过程 | 执事翻的那几本 · 翻到第三本时的语气 · 「回主子，查无此例」 |
| 立条的形态 | 口头最轻，也最容易反悔 · 写进家书 · 入家规分量最重，往后谁也绕不开 |
| 第一次援引 | 谁先提的 · 提的时候他在不在场 |
| 收尾 | 多年以后，有人把这条当老规矩搬出来，念它的人并不知道它的来历 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提出立条 | 她 | 他。由他来提代价更大，开口提这件事本身就越了界 |
| 形态 | 口头 | 入家规（接 [20-女尊制度场景 · 她改了规矩](20-女尊制度场景.md#七--她改了规矩)：那一条是改旧条文，这一条是补一个新格子） |
| 影响面 | 只管他们俩 | 管到后来人身上，有人因此沾光，也有人被它卡住 |
| 结局 | 有人援引，进了制度 | 始终没人用，只在他们俩之间作数 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 停在“查无此例”这一句，不往下写 | 这么小的事还得开口去问，他没想到 |
| 内心 | 没人管，没人拦，也没人替她兜着 | 头一回连书里都找不到答案 |
| 好的处理 | 立下的那条规矩写成条款的样子，别写成情话 | 他提的事小到旁人根本记不住 |
| 写崩 | 补上的那条后来再没出现 | 借着这一条，把整套规矩一路掀翻 |

#### 写崩的三种方式

1. 补的那一条只露一次面。 新条至少要被人引用一回才作数，否则写了等于没写。
2. 拿这一条去推翻整套制度。 这里只补一条，换掉整部典章是另一个故事。
3. 那件事挑得太大。 事情越大，越容易碰上现成的条文，只有小事才可能真的无例可查。
