## 安全框架（先读这一节）

这一族写的是古代女尊设定里的制度层：婚仪、七出、男德、验身、位阶、籍、扶正、封诰。其中一半直接性转自现实历史上的人身依附制度，所以框架要在动笔前写全。

### 三条社群共识

| 缩写 | 全称 | 含义 |
|---|---|---|
| SSC | Safe, Sane, Consensual | 安全、理智、双方同意 |
| RACK | Risk-Aware Consensual Kink | 知晓风险的前提下双方同意 |
| PRICK | Personal Responsibility, Informed Consensual Kink | 个人责任前提下的知情同意 |

三者是社群在不同年代提出的框架，共同点是同意必须是知情的、可撤回的、由具备判断能力的成年人做出的。

### 虚构与现实的分界

**古代人身依附制度是幻想装置，不是现实模板。** 良贱之别、验身、家法、七出、籍没，在历史上都真实压迫过人；小说把这套逻辑性转过来，让读者换个方向看见它的形状，运行在一个由作者控制、后果可控的世界里。它不是现实指南。

这一族不提供任何可复现的实施细节，只讨论叙事结构。

### 三条硬边界

| 边界 | 说明 |
|---|---|
| 全员成年 | 所有涉及婚配、依附与责罚的角色均为成年人 |
| 不写过程 | 验身、家法、责罚只写其存在与后果；过程描写走 [06-尺度与写法/04-训诫与BDSM专论](../06-尺度与写法/04-训诫与BDSM专论.md) |
| 制度要被使用 | 写进设定的制度若在正文里既不被使用也不被违反，它就是装饰（死设定检验法见 [02-术语百科 5.5](../02-术语百科/02-女尊称谓与礼制体系.md)） |

带 ⚠️训诫 的三条是 [四 · 守身这回事](#四--守身这回事)、[五 · 通房与外室](#五--通房与外室)、[七 · 扶正](#七--扶正)。家法本身的完整框架与越界判据在 [08-规训日常版 · 安全框架](08-规训日常版.md) 与 [20-女尊制度场景 · 家法](20-女尊制度场景.md#六--家法)。

## 一 · 大婚

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：婚礼仪式＋请安＋选侍 24 部 / 0.9%（[13-07 §四情境组合](../13-语料挖掘/07-桥段分布.md) 榜首）

**骨架**｜女娶男嫁的三日全流程。第一日她把他接回来，第二日他第一次请安，第三日媵侍并入位次。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 议亲先定规格：娶（三书六礼全套）还是纳（仪注低一等），这一步定死后面所有名分（[纳夫／娶夫](../02-术语百科/02-女尊称谓与礼制体系.md) 词条） |
| 2 | 下聘。聘礼由她这边出，方向与现实相反；他家备嫁妆，妆册一式两份 |
| 3 | 迎娶那日她亲去接，他上轿；门槛、火盆、喜秤的性转版逐样过一遍 |
| 4 | 拜堂的次序：先告祖，再拜她的母父，最后交拜 |
| 5 | 当夜之前那半刻：她挑帕，他抬头，第一次在自己家里看她 |
| 6 | 次日五更，第一次晨昏定省：奉茶、改口、领见府中人（这一拍接 [20-女尊制度场景 · 晨昏定省](20-女尊制度场景.md#一--晨昏定省) 的第一天） |
| 7 | 第三日媵侍见礼，位次当场排定，妆册与人册一并入库 |
| 8 | 三日礼成，第四日起走日常的钟 |

#### 时间轴

**三日，每一日归一个人管。** 第一日归礼官，流程分秒不由人；第二日归她的母父，茶烫不烫、话说几句、赏什么，全在长辈手里；第三日归位次，媵侍站的先后一旦排定，此后数十年不轻易动。他自己的时间只有两段：轿子里的一个时辰，和第三日夜里独处的一刻。

#### 三日各写什么

| 日 | 制度动作 | 落点 |
|---|---|---|
| 第一日 | 聘、迎、拜 | 她亲自去接（去与不去差一整个位阶） |
| 第二日 | 奉茶、改口、请安 | 婆公受不受那盏茶，受了改口才作数 |
| 第三日 | 媵侍见礼、排位次 | 他站的位置从此是全府读他的第一行字 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 文书 | 聘书 · 妆册（一式两份，男家留底）· 婚书上两个名字谁在前 |
| 器物 | 喜秤 · 火盆 · 那盏改口茶（凉了要重换，重换过一次的人都记得）· 他袖里攥着的礼单 |
| 礼节 | 拜的次序 · 他跪的次数 · 谁扶他起来 |
| 媵 | 陪嫁的同族兄弟或舅甥（[媵](../02-术语百科/02-女尊称谓与礼制体系.md) 词条），他们的位次连着他的体面 |
| 破绽 | 三日里他吃了几口东西 · 第二日的嗓子（茶太烫，话又不能少） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 规格 | 娶（全礼） | 纳（仪注减半，名分随之减半） |
| 她去不去亲迎 | 亲去 | 遣人代迎（合规，也是一记耳光） |
| 媵 | 有（贵族出嫁的标配） | 无（他出身寒门，第三日无人可排，这一日格外长） |
| 三日的成色 | 礼数无差错 | 出过一处小错（谁替他圆的，就是他日后能倚的人） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 亲迎那日她掀开轿帘的手 | 火盆那一步他迈得比礼官教的高 |
| 内心 | 三日里她真正做主的只有亲迎这一件 | 每一步都排好了，只有掀帘那一眼是多出来的 |
| 好的处理 | 她在礼官不看的地方多做一件小事 | 礼数一丝不错，错的那一处别人不知道 |
| 写崩 | 婚仪写成排场清单 | 当夜写成全部重点 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 领证、婚礼、回门三件事（[23-婚嫁](23-婚嫁.md) 全卷） |
| 修仙 | 结契大典、拜山门、道侣录留名 |
| 星际 | 登记、舰上典礼、权限交割三段 |

#### 写崩的三种方式

1. 三日压成一日。 三日各归一个人管，压掉两日就只剩排场。
2. 礼数写全而人不见。 礼单可以查典章，他吃了几口东西查不到，那一格才是写的人的活。
3. 媵侍当摆设。 第三日排的位次要在后面的条目里被援引，否则那一日白写。

## 二 · 和离与休夫

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：无独立节拍族（词条见 [02-术语百科 · 和离／休夫](../02-术语百科/02-女尊称谓与礼制体系.md)）

**骨架**｜同一天，同一张桌子，落笔的是两份完全不同的文书。和离书一式两份各执一份，休书只有一份。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 一件事逼到不能再拖（她要保他、她要弃他，或他自己要走） |
| 2 | 先查名目：休夫须占七出之一（不顺母父、无嗣、淫、忌、恶疾、多言、窃盗），和离只须两愿 |
| 3 | 三不去被翻出来（曾为婆公持丧、糟糠之夫、无家可归），占其一则休不得 |
| 4 | 文书由谁执笔，谁在场（族老、中人、官媒） |
| 5 | 落笔那一刻的差别：和离书一式两份，休书一份在她手里，另一份进官府存档 |
| 6 | 妆奁清点（原样带走、折半，还是一样不给） |
| 7 | 出门走哪道门（正门与侧门差一辈子的名声） |
| 8 | 之后的称呼：她如何提起他，他如何提起她 |

#### 时间轴

逼到眼前一天，走完一个月。查名目半日；三不去的核对要请族里最老的那位来说，一说就是一天；文书三易其稿，改的全是名目那一行；落笔用不了半炷香。妆奁清点两日，一件件对册子。最后是出门那一步，一步走完，先前的一个月才落地。

#### 两种落笔法

| | 她放手（和离） | 他求去（下堂） |
|---|---|---|
| 名目 | 两愿，不必写理由 | 要替她找一个说得出口的理由，理由多半栽在他自己身上 |
| 文书 | 一式两份 | 他求的是休书，只此一份，羞辱落在他这边 |
| 妆奁 | 原样归还是体面的下限 | 他常一样不取，好让那份文书更像她的正当处置 |
| 落点 | 她按住笔的那一下 | 他把拟好的理由推过去，说「照这个写」 |
| 后事 | 他还能再嫁 | 名声碎在名目那一行上，改嫁难 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 文书 | 和离书的措辞（各无怨怼、各自婚嫁）· 休书上的那一条七出 · 官府存档的骑缝印 |
| 三不去 | 他为婆公守过孝的那一年，这一条最常被拿来救人 |
| 在场的人 | 族老 · 中人 · 官媒 · 一个哭出声的下人 |
| 妆奁 | 册子上每一样都能对上，唯独一样对不上，那一样是他自己添的 |
| 门 | 正门 · 侧门 · 他从哪道门出去，第二天全城都知道 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提的 | 她 | 他（几乎无门，所以要绕道七出） |
| 名目的真假 | 真的 | 造的（造名目是替对方留路，也是把脏水泼给自己） |
| 妆奁 | 原样奉还 | 他一样不取 |
| 结局 | 各自婚嫁 | 若干年后一封信（走 [22-分手与复合](22-分手与复合.md) 的古代接口） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 名目那一行她改了三次 | 「照这个写」四个字说出口的语速 |
| 内心 | 写真的伤他名声，写假的伤她自己的 | 名目落在我身上，她才干净 |
| 好的处理 | 和离与休夫的分别写清楚，不混着用 | 求去的理由具体到能被官媒记录 |
| 写崩 | 休书当吵架的道具甩出来 | 潇洒转身，不算妆奁不问门 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 协议离婚与诉讼离婚的分别（[22-分手与复合 · 离婚这一场](22-分手与复合.md#十一--离婚这一场)） |
| 修仙 | 解契 · 道侣录除名 · 谁去宗门备的案 |
| 星际 | 关系解绑申请 · 权限回收的先后 |

#### 写崩的三种方式

1. 和离与休夫混用。 一个两愿一个单方，混用等于制度没写。
2. 七出只念不用。 条款列出来而情节不倚它，那就是死设定。
3. 妆奁不算。 财产清点是这场戏里唯一无法用感情糊过去的一段。

## 三 · 男德课

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：无独立节拍族（词条见 [02-术语百科 · 男德／男戒／男红](../02-术语百科/02-女尊称谓与礼制体系.md)）

**骨架**｜《男戒》他背了十几年，动作已经不过脑子。她第一次觉出这件事那天，她的处置就是她的价值观。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 婚前的功课交代：三从（未嫁从母、既嫁从妻、妻死从女）、四德（夫德、夫言、夫容、夫功） |
| 2 | 日常里的自动执行：她起他起，她坐他候，眼睛落在她鞋尖以上三寸 |
| 3 | 她第一次觉出那不是性格，是背出来的 |
| 4 | 她试着让他破一条（坐下、抬眼、先动筷） |
| 5 | 他做不到，或做到了但一晚没睡 |
| 6 | 她的态度定档：照旧沿用、挑着用，还是整套拆了 |
| 7 | 拆的代价：坐标系一撤他反而慌，得有人给他新的 |
| 8 | 多年后他偶尔还是退那半步，两个人都不提 |

#### 时间轴

他学这套用了十几年，改要按年算。试破一条当场就见分晓；真正改掉一条要半年；改到不再回头要三年。中间会有反复：她在时改了，她不在时又回去了，这一段反复本身就是内容。

#### 三种态度，三种人

| 她的态度 | 她是谁 | 他的处境 |
|---|---|---|
| 照旧沿用 | 制度里的得利者，且她认这套 | 安全，但他一辈子只是执行得好的那一个 |
| 挑着用 | 留礼数去规训，人前照旧人后不论 | 最常见，也最难写清界线在哪 |
| 整套拆了 | 她要一个能跟她说话的人 | 先慌后活，慌的那一段最好看 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 文本 | 《男戒》的抄本，他自己抄的那一部字迹前松后紧 · 「男子无才便是德」这句他背得最熟 |
| 男红 | 针黹是必修（[男红](../02-术语百科/02-女尊称谓与礼制体系.md)）；他做的活计在府里被当作评价他的凭据 |
| 自动化的动作 | 让路时先退半步 · 递东西双手 · 她开口他停口 · 自称「侍身」不假思索 |
| 她的试探 | 「坐着。」· 把筷子先递给他 · 问一个要他答长的问题 |
| 反复的证据 | 她出门半月，回来那顿饭他又站着 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他背这套的心情 | 认同（那是他的体面所在） | 早就不信，只是不敢不做 |
| 她的拆法 | 一次一条，给替代动作 | 一夜全免（他会以为自己失宠） |
| 男红 | 他厌恶（那是枷锁的具体形状） | 他喜欢（技艺是他为数不多能自己做主的事） |
| 后续 | 新规矩由两人定（[35-规矩的进阶 · 协商桌](35-规矩的进阶.md#二--协商桌) 的古代版） | 不立新规矩，两个人都不适应 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她让他坐下，他的膝盖先弯了一下才反应过来 | 「坐着」两个字听懂之后那半秒的空 |
| 内心 | 她拆的到底是一个人的骨架还是一副枷 | 不做那些动作，我不知道该拿手怎么办 |
| 好的处理 | 免一条给一条，别只免不给 | 慌写在手上，不写成台词 |
| 写崩 | 一夜全免，第二天他就活泼了 | 把顺从写成天生的乖 |

| 修仙 | 宗门给男弟子的仪轨课 · 出门必随师姐半步 |
| 星际 | 男性公民的礼仪学分 · 通行等级绑定的举止规范 |

#### 写崩的三种方式

1. 男德只在设定页出现。 背过的东西要在动作里长出来，否则那本书是道具。
2. 拆得太顺。 十几年的东西一晚上改掉，等于说它本来就不重。
3. 她拿这套当情趣用而不自知。 用可以，不自知不行；界线判据借 [35-规矩的进阶 · 协商桌](35-规矩的进阶.md#二--协商桌)。

## 四 · 守身这回事

`M` ｜ ⚠️训诫 ｜ 古代女尊 ｜ 语料频次：无独立节拍族（词条见 [02-术语百科 · 守身如玉](../02-术语百科/02-女尊称谓与礼制体系.md)）

**骨架**｜贞洁脚本整套性转到男身：婚前守、婚后验、失了就是名节问题。她信不信这一套，决定这条是压迫戏还是拆解戏。

#### 安全框架（承卷首）

| 项 | 说明 |
|---|---|
| 共识框架 | SSC · RACK · PRICK，全文见卷首 |
| 虚构与现实 | 验身与名节是幻想装置，不是现实模板 |
| 不写过程 | 只写制度存在与它的后果，不提供任何可复现的描写 |
| 全员成年 | 涉及的全部角色均为成年人 |

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 制度要求先于人物出场：婚前守身是议亲的硬条件 |
| 2 | 检验的形式落地（婚前的凭证、婚后的口舌）；过程不写，只写它存在 |
| 3 | 有人拿这件事说他（同席的一句话、下人的一句闲话） |
| 4 | 话传到她耳里，中间隔着下人掂量该不该报的那一日 |
| 5 | 她的处置分三档：信、查、不查 |
| 6 | 处置的方式当众可见，府里对他的评价随之改写 |
| 7 | 事后他自己那一关：被议论的是身体，抬不起头的是人 |

#### 时间轴

一句闲话半天传遍，洗掉要按年。话起于席间三十息；到她耳里隔一日；她的处置若快，三日内定调，若慢，一个月后就成了定论。他自己那一关最长，闲话早没人提了他还在意。

#### 可用细节

| 类 | 内容 |
|---|---|
| 凭证 | 议亲时男家出具的一纸 · 保人 · 那纸收在妆奁的哪一层 |
| 闲话的形状 | 半句 · 一个眼神 · 一句「听说」，说的人自己也没底 |
| 她的三档 | 信（当场把话堵回去）· 查（查了就是承认这套规矩）· 不查（最难，因为不查也要有个说法） |
| 他的处境 | 名节无法自证，凡自证皆更像坐实 |
| 收尾的物件 | 那一纸凭证后来怎么处置：烧了、还给他，还是照旧收着 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他守没守 | 守了（清白，仍要被议） | 没守（有过前事，这条才真正锋利） |
| 她信不信这套 | 信（她是制度里的人，写实但难写讨喜） | 不信（她得为不信付代价，族里会记这一笔） |
| 处置 | 公开 | 私下（快，但堵不住嘴） |
| 落点 | 那纸凭证被烧了 | 那纸还在，只是从此没人再提 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听完闲话之后先问的那一句是什么 | 他知道自己无从辩起的那一瞬 |
| 内心 | 查与不查都在承认这条规矩 | 干净不干净由别人的嘴定 |
| 好的处理 | 处置指向说话的人，不指向他的身体 | 他不自证，也不表演坦荡 |
| 写崩 | 检验写成场面 | 失贞写成他的道德污点 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 他的过去被翻出来当谈资（[15-秘密与坦白 · 前任出现](15-秘密与坦白.md#四--前任出现)） |
| 修仙 | 元阳与道基的说法 · 同门的窃语 |
| 星际 | 婚配档案里的既往记录 · 谁有权调阅 |

#### 写崩的三种方式

1. 把检验写成场面。 制度的重量在它存在，不在它怎么执行；写过程就越了卷首那条边界。
2. 让她也信这套却毫无代价。 信有信的后果，不信也有；两边都得付。
3. 用一句「我信你」收场。 信是态度，处置才是动作，堵住嘴的是后者。

## 五 · 通房与外室

`M` ｜ ⚠️训诫 ｜ 古代女尊 ｜ 语料频次：选侍 21.0% ＋ 位份 15.0%

**骨架**｜位阶表在一个府里每天怎么运行：谁能进正堂，谁的份例是几成，谁根本不在册上。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 一份份例单摊开（正夫与末位的份例比是可以写成数字的） |
| 2 | 早间请安的先后：媵在前、通房在末、外室不在场 |
| 3 | 通房的位置：收房而无名分，可上可下（[通房](../02-术语百科/02-女尊称谓与礼制体系.md) 词条） |
| 4 | 外室的位置：养在外宅，不入族谱，不能抚养她的子女（[外室](../02-术语百科/02-女尊称谓与礼制体系.md) 词条） |
| 5 | 一次具体的分配：一匹料子、一个医、一顿饭的座位 |
| 6 | 分配落地时有人被越过 |
| 7 | 正夫的处理：维持位阶，或替下面的人开口，两条路各有代价 |
| 8 | 她的裁定，与裁定之后一个月的余波 |

#### 时间轴

**位阶按日运行，按季结算。** 请安是日；份例是月；越份的事一旦发生，结算要等到季末的账，谁多领了谁被扣了，账上一目了然。外室的钟另计：她多久去一次，去的时辰是白天还是夜里，这两项就是外室的全部读数。

#### 位阶的日常读数

| 位阶 | 册上有无 | 日常可见处 |
|---|---|---|
| 正夫 | 族谱、婚书俱在 | 正堂 · 印信 · 代她见客 |
| 媵（陪嫁的同族兄弟或舅甥） | 有 | 位次紧随正夫，正夫亡故可议扶正 |
| 侧夫／臣室 | 有 | 有院 · 有份例 · 请安有座 |
| 通房 | 无名分 | 贴身伺候，能被抬举也能被发落 |
| 外室 | 不入族谱 | 不在府里出现，只在她的行程里出现 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 份例 | 料子的等次 · 用度的成数 · 病了请不请医，这一项最见位阶 |
| 请安的队形 | 谁站谁坐 · 谁先开口 · 谁不必来 |
| 通房的两条路 | 抬举（改籍、入册）· 发落（配人、遣出） |
| 外室的物件 | 一处外宅的钥匙 · 逢年过节从府里送出去的那份东西比谁都薄 |
| 正夫的分寸 | 他替谁开过一次口，那个人记一辈子 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 制度形态 | 一妻一夫多臣（有正侧之别） | 平夫制（地位相等，宅斗随之消失，转温情群像） |
| 通房的走向 | 被抬举 | 被发落（理由多半与他本人无关） |
| 外室的成因 | 家族不允 | 身份过低（他自己也知道进不来） |
| 正夫的态度 | 守位阶（守的是秩序） | 替下面的人说话（一次就够，多了她要疑） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 份例单上她改动的那一行 | 请安时他往旁边挪的半步 |
| 内心 | 每一次偏爱都是从别人那里挪来的 | 我站的位置是别人让出来的 |
| 好的处理 | 分配写成算术，别写成心意 | 位阶低的人也有自己的算盘，不只有委屈 |
| 写崩 | 写成宅斗争宠 | 把通房与外室写成没有内面的布景 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | np 关系里的时间与资源分配（[31-np与多人日常 · 位次的确立](31-np与多人日常.md#五--位次的确立) 是这一条的现代接口） |
| 修仙 | 道侣与双修伴侣的名录先后 · 洞府的远近 |
| 星际 | 权限等级 · 舱位分配 · 谁能进主控舱 |

#### 写崩的三种方式

1. 位阶只写在设定页。 份例、座次、请医，三样落到日常里位阶才成立。
2. 低位者只有委屈。 每个位阶上的人都在算自己的账，算盘写出来他们才是人。
3. 位阶词混用。 通房、侧夫、外室各有其义，混用一次读者就不信这个府了。

## 六 · 招赘与入赘

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：无独立节拍族（词条见 [02-术语百科 · 一妻多夫／平夫制／走婚](../02-术语百科/02-女尊称谓与礼制体系.md)）

**骨架**｜他嫁进来那天，户帖上要动三处：原籍除名、新户入册、姓与名的改动。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 议亲先问形态：招赘（他入她的户）、走婚（不产生法定配偶关系），还是各归各家 |
| 2 | 女户的成立：她是户主，这一条是后面所有权利的根 |
| 3 | 户帖办理，原籍那一行划掉，新户那一行添上 |
| 4 | 冠妻姓、改夫名。改到什么程度各派不一：只冠姓、连名一并改，或只在文书上改 |
| 5 | 他原家的账：少一个劳力，多一门亲，两边的算盘当场都打出来了 |
| 6 | 第一次被人以新名新姓叫住，他反应慢了半拍 |
| 7 | 子女随母姓，写进族谱那一日他在场 |
| 8 | 多年后他的本名只剩在一处：旧籍存档、他娘的口头，或者一件旧物上 |

#### 时间轴

户帖当日办完，名字要认好几年。划名添名一炷香；改称呼半年，下人先改，亲戚最后改；他自己在心里认下新名要更久，中间有一段他两个名字都答应。

#### 三种形态的分别

| 形态 | 他的身份 | 子女 | 他能不能走 |
|---|---|---|---|
| 招赘（入赘） | 入她的户，法定配偶 | 随母姓，入她家族谱 | 走要办和离（接 [二](#二--和离与休夫)） |
| 走婚 | 不入户，无法定配偶关系 | 归女方，父不在册 | 随时可止 |
| 各归各家 | 名义配偶，户籍不动 | 视约定 | 约定即效 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 文书 | 户帖 · 婚书 · 原籍的注销那一笔（笔画重，纸背都透了） |
| 名字 | 冠姓之后的全称 · 他签名时的停顿 · 旧名还在用的那一个场合 |
| 他原家 | 送出门时的话 · 逢年过节谁去谁不去 · 兄弟的态度 |
| 走婚版 | 她来与不来全凭意愿 · 门口的记号 · 他不问下次 |
| 收尾物 | 一件刻着旧名的东西，他没扔，也没拿出来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 形态 | 招赘（他把自己交出去） | 走婚（谁都不交，各自留一半） |
| 改名的深度 | 只冠姓 | 姓名一并改（改得越深，回头路越窄） |
| 他原家 | 得了聘礼，喜气洋洋 | 觉得丢人，从此少来往 |
| 他的接受度 | 认了，且认得干脆 | 一直没认，他在两个名字之间过了半辈子 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 户帖上她的名字下面添了一行 | 原籍那一笔划下去的声音 |
| 内心 | 他成了我户上的人，纸上这一行比婚书还实 | 从今天起我归谁管，纸上写得明明白白 |
| 好的处理 | 户籍在后面还要被用到，不是开场交代完就收 | 改名的别扭写在签名的停顿里 |
| 写崩 | 改姓写成浪漫仪式 | 招赘与走婚混着用 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 户口迁入 · 婚后随不随姓 · 孩子姓谁（[38-制度里的两个人 · 户口本](38-制度里的两个人.md#九--户口本)） |
| 修仙 | 入她的洞府门籍 · 道侣录上的先后 |
| 星际 | 户籍舱段变更 · 姓氏字段的写入权 |

#### 写崩的三种方式

1. 户籍只在开头交代。 后面若无一处用到它，那一笔白划。
2. 招赘与走婚混用。 一个入户一个不入户，混用等于两套制度都没有。
3. 改名写成情话。 改名是行政动作，情绪在停顿里，不在句子里。

## 七 · 扶正

`M` ｜ ⚠️训诫 ｜ 古代女尊 ｜ 语料频次：位份 15.0%（[02-术语百科 · 良籍／扶正／俾男](../02-术语百科/02-女尊称谓与礼制体系.md) 的场面化）

**骨架**｜正夫位空了。够得着这个位置的人身上都压着一样东西：籍。改籍在前，扶正在后，落印那一刻他还站在门外。

#### 安全框架（承卷首）

良贱之别是历史上真实的人身依附制度，这一条只写它在虚构世界里怎么运转、怎么被人绕开，不写任何可复现的实施细节。涉及的全部角色均为成年人。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 正夫位空出：亡故、和离，或被休（接 [二](#二--和离与休夫)） |
| 2 | 排资格：媵最优，良籍臣室次之，通房抬举再次，贱籍最末 |
| 3 | 卡在籍上。良贱不通婚，贱籍须先改良籍：赎身、销贱、入良册，这一道最长 |
| 4 | 族议。嫡庶森严的世家一概不许；不严的允许，但仪注减等 |
| 5 | 文书拟就，用印。印落在纸上那一声是全条的落点 |
| 6 | 仪注减等的那几处：办宴即可，不告祖，不从正门入 |
| 7 | 他从侧门进来，走到正堂站定 |
| 8 | 称呼当日全改，府里改口的快慢就是人心的读数 |

#### 时间轴

**改籍以年计，落印只一声。** 赎身与销贱要走官府，快则半年，慢则三年，中间要人担保、要钱，要她出面，而她一出面族里就记一笔；族议三次；文书拟稿几日；用印一瞬。之后是改口，下人三日改完，族里三年也改不齐。

#### 籍这一关

| 出身 | 能不能扶正 | 要先做什么 |
|---|---|---|
| 官宦养男 | 可 | 无 |
| 平民良籍（登记臣书） | 可 | 无 |
| 通房抬举 | 可 | 先入册给名分 |
| 赤贫卖身 | 须先改籍 | 赎身、销贱籍、入良册 |
| 戏子、伎男 | 须先改籍，且族议几乎必阻 | 同上，另加一场公议 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 文书 | 良册 · 臣书 · 扶正的那一纸 · 骑缝印 |
| 钱 | 赎身的价（写出数目比写「不菲」有用十倍）· 谁出的钱 · 出钱这件事日后会被人提起 |
| 减等的仪注 | 不告祖 · 不奏乐 · 不从正门入 · 宴请的桌数 |
| 那道侧门 | 他走过去的步子 · 门槛的高度 · 有没有人替他掀帘 |
| 改口 | 谁第一个改 · 谁最后改 · 有人改不过来，是真改不过来还是不肯 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的出身 | 良籍（顺，戏在族议） | 贱籍（戏全在改籍那一段） |
| 族议 | 过了 | 没过，她另辟一条（改宗规，走 [20-女尊制度场景 · 她改了规矩](20-女尊制度场景.md#七--她改了规矩)） |
| 仪注 | 减等（合规，也是一辈子的注脚） | 她硬要全礼（代价落在他身上，全府都知道那是破例） |
| 他的反应 | 平静受了 | 他自己请减等，不要她为此欠人情 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 印按下去她的手没抖 | 侧门那道门槛比正门矮，他记住了 |
| 内心 | 我给得起名分，给不起出身 | 名分有了，来路还在 |
| 好的处理 | 改籍与扶正分成两件事写，中间隔着时间 | 减等的每一处他自己数得清 |
| 写崩 | 一纸文书当场解决 | 感恩戴德的长段独白 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 从同居到领证 · 试用转正 · 名分与户籍的先后（[38-制度里的两个人](38-制度里的两个人.md)） |
| 修仙 | 记名弟子转入室 · 道侣录上的位次调整 · 血契改签 |
| 星际 | 临时权限转正式编制 · 档案里那条「原编制」永远删不掉 |

#### 写崩的三种方式

1. 跳过籍这一关。 名分是她给的，出身不是；跳过去这条就只剩一场仪式。
2. 仪注减等不写。 不告祖、不从正门入，这几处的省略正是制度开口说话的地方。
3. 落印之后皆大欢喜。 改口的快慢要写；人心不跟着印走。

## 八 · 一家子的称谓

`G` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：请安 25.0%（称谓在请安场里每日兑现）

**骨架**｜孩子第一次开口叫人，把全家的位阶念了一遍。他自称什么，把他自己的位置念了一遍。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 孩子开始学说话，府里先教哪一个称呼，教的顺序即位阶顺序 |
| 2 | 正夫是「爹爹／阿爹／父亲大人」，低位配偶是「小爹／叔爹／庶父」（[小爹](../02-术语百科/02-女尊称谓与礼制体系.md) 词条） |
| 3 | 孩子叫错一次 |
| 4 | 当场的处理：纠正的人是谁，语气多重，被叫错的那位什么脸色 |
| 5 | 他自己的自称在不同场合切换：对她、对长辈、对外客、对下人，四档 |
| 6 | 一次外客在场的当众叫错，收拾场面 |
| 7 | 孩子大了，称呼固化，某一个称呼他一辈子没听孩子改过口 |

#### 时间轴

**称呼学三年，用一辈子。** 孩子两岁到五岁是教的窗口，教什么就叫什么；叫错集中在这三年，之后极少。成年之后再改口，那是关系出了变化才会有的事，比如 [七 · 扶正](#七--扶正) 之后的全府改口。

#### 一家子怎么叫

| 关系 | 称呼 | 备注 |
|---|---|---|
| 子女→母 | 母亲 · 娘 | 语序倒置的总原则见 [母父](../02-术语百科/02-女尊称谓与礼制体系.md) 词条 |
| 子女→正夫 | 爹爹 · 阿爹 · 父亲大人 | 皇室作「父后」，与「君后」是同一人的两种叫法 |
| 子女→低位配偶 | 小爹 · 叔爹 · 庶父 | 用错等于当众划位阶 |
| 他→她 | 妻主 · 主子（视世界硬度取用） | 「妻主」出现频次越低越有力（[妻主](../02-术语百科/02-女尊称谓与礼制体系.md) 词条的语感提示） |
| 他→自称 | 在下／臣身／侍身／奴家 | 四级递降，等于身份条形码 |
| 并称 | 母父 · 妻夫 · 娘爹 · 婆公 · 奶爷 | 男先女后的语序全部翻转 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 教的现场 | 谁抱着孩子教 · 教的第一个称呼是哪一个 · 有人在旁边听着不说话 |
| 叫错 | 把「小爹」叫成「爹爹」，低位者的脸先红 · 反过来叫，正夫沉默，比发作更难写也更好看 |
| 纠正 | 由她纠正 · 由被叫错的那位自己纠正（他的分寸就在这一句里） |
| 自称的切换 | 他在她面前用哪一档，在外客面前又用哪一档，切换的那半秒 |
| 一辈子没改的那一声 | 孩子成年后仍旧那么叫，理由谁都不提 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 叫错的方向 | 往上叫（低位者受用又惶恐） | 往下叫（正夫被降了一格，全场静一息） |
| 教的人 | 她 | 乳母、长辈（教出来的称呼带着教的人的立场） |
| 他的自称 | 全程守规矩 | 私下用「我」，这一个字比任何情话都越界 |
| 收场 | 一句话带过 | 这次叫错成了后面某件事的引信 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 孩子叫错之后她先看的是谁 | 「爹爹」两个字落在别人身上那一瞬 |
| 内心 | 一个称呼就把一个人的位置钉住了 | 我的位置由一个三岁孩子念出来 |
| 好的处理 | 纠正的语气轻，位阶却没让 | 他自己纠正，纠正得比谁都快 |
| 写崩 | 称谓混用穿帮（写着写着把「父后」写成「母后」） | 把叫错写成无关紧要的插曲 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 孩子在外人面前怎么介绍他 · 他在她同事面前怎么自称（[38-制度里的两个人 · 家长会谁去](38-制度里的两个人.md#三--家长会谁去)） |
| 修仙 | 师叔与师尊之别 · 弟子对他的称呼随她的位次动 |
| 星际 | 家庭档案里的关系字段 · 系统播报时读出来的那个称谓 |

#### 写崩的三种方式

1. 称谓表只在设定页齐整。 每天要用的东西写在附录里，正文一开口就露馅。
2. 一套称谓混着两派用。 君系与夫系各自成体系，同一部书里只能取一派。
3. 叫错不留后果。 位阶靠称呼兑现，叫错一次而无人在意，等于位阶不存在。

## 九 · 她的仕途

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：告别 37.0%（外放与赴任）＋ 位份 15.0%

**骨架**｜放榜、授官、外放。她的名字往上走一格，他的品级跟着动一格。官眷是他这辈子唯一由外部授予的身份。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 她下场应试。男子不得应试是这套制度的另一半（[男德](../02-术语百科/02-女尊称谓与礼制体系.md) 词条的配套设定） |
| 2 | 放榜那日他在哪：在家、在榜下，还是被支开了 |
| 3 | 授官与封诰。朝廷给官员配偶的封赠落在他身上：冠服、品级、诰命的那一纸 |
| 4 | 外放的消息到，一府人的行装与交接 |
| 5 | 任上的官眷社交：同僚的夫郎们、席次、谁的品级高谁先开口 |
| 6 | 她任上出事（弹劾、亏空、下狱），官眷连坐的那条法就在纸上摆着 |
| 7 | 升迁或贬谪，他的品级随之动，冠服换一次，称呼换一次 |
| 8 | 她致仕那年，那一纸诰命还挂在他房里 |

#### 时间轴

她的钟按任期走，他的钟按行装走。三年一考，任满一迁；他这边的刻度是打包，外放一次打包一次，第三次他闭着眼就知道哪个箱子装书。中间会有一段两地：她先赴任、他后启程，或者他留守，那一段走 [09-分离与重逢](09-分离与重逢.md)。

#### 官眷这个身份

| 项 | 内容 |
|---|---|
| 来源 | 由她的官位派生，不由他自己挣 |
| 可见形式 | 诰命的那一纸 · 冠服 · 席次 · 出门的车驾规格 |
| 好处 | 他第一次在府门之外有了名分 |
| 代价 | 她的官位一动，他的一切跟着动；她下狱，官眷连坐 |
| 最难写的一格 | 官眷席上他既要替她挣脸，又不能越她的位 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 放榜 | 榜下的人潮 · 报喜的人走错门 · 他给报喜人的赏钱数目（多一分是得意，少一分是失礼） |
| 诰命 | 那一纸的装裱 · 挂在哪面墙 · 他多久去看一次，自己也没数 |
| 行装 | 书箱 · 药箱 · 一样每次都带的旧物 · 打包的顺序他记得比谁都熟 |
| 官眷席 | 同僚的夫郎们说话的分寸 · 谁在探她的底 · 他答与不答的那条线 |
| 出事那日 | 门口的封条 · 他先收的是账册还是孩子 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的态度 | 与有荣焉，且他知道这份荣是借的 | 别扭（他曾经也想应试，这条路对他关着） |
| 外放 | 同去 | 他留守（[20-女尊制度场景 · 她要出征](20-女尊制度场景.md#九--她要出征) 的文官版） |
| 她的仕途 | 顺 | 一次贬谪（他的品级跟着掉，掉的那天他做的第一件事是什么） |
| 极端 | 她下狱，官眷连坐 | 她致仕，两个人的品级第一次不再有用 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 报喜的人到门口那一刻他先看她 | 诰命挂上墙，他退后两步看了很久 |
| 内心 | 我往上走一格，他的一切跟着我动 | 我的品级是她的影子，影子也是有形状的 |
| 好的处理 | 她的官事写实，不只当背景板 | 他对她的官位有态度，且态度不止一种 |
| 写崩 | 仕途只是布景，考完就消失 | 官眷写成只会摆宴的空壳 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 她升职、外派、被调查（[12-工作与金钱 · 她是我上司](12-工作与金钱.md#二--她是我上司)） |

2. 官眷没有活儿。 席次、应酬、账、人情，这些是他的工作，写出来他才立得住。

## 十 · 制度的缝

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：位份 15.0% ＋ 请安 25.0%（收束条，不引新族）

**骨架**｜收束条。前九条各有一份可查的文书，这一条查不到。有一件事，翻遍典章找不到名目；没有条款就没有先例，也没有保护，于是他们自己立了一条。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 一件具体的小事出现：他想在她书房摆一张自己的桌子、他名下能不能有一处产业、他能不能替她见某个人 |
| 2 | 照例先问执事：这件事按什么办 |
| 3 | 执事去查，回来说查无此例 |
| 4 | 查无此例的两层含义同时成立：没禁，也没许 |
| 5 | 两条路：当这件事没发生（省事，且他会自己把话收回去），或者自己立一条 |
| 6 | 立的那一条谁写、写在哪：口头、家书，还是入了家规 |
| 7 | 执行的第一次。新条被援引的那一刻，它才算存在 |
| 8 | 若干年后有人拿这一条当先例来援引，这时它已经不是他们的私事 |

#### 时间轴

查无此例只用半天，立一条要看多少年后有人援引。问与查在一日之内；两个人商量那一晚不长；写下来那一刻很短。刻度在后面：第一次被援引隔一年到数年，被第三个人援引才算它进了制度。若一直无人援引，它就只是他们两个人之间的一句话，那也是一种结局。

#### 与 20 卷第十条的分别

| | [20 · 制度之外的那一刻](20-女尊制度场景.md#十--制度之外的那一刻) | 这一条 |
|---|---|---|
| 缺口的性质 | 暂时的真空 | 永久的空白，典章里根本没有 |
| 时长 | 几分钟，随时被收回 | 一件事，可能留几十年 |
| 收法 | 两人立刻恢复原样 | 两人自己写了一条 |
| 与制度的关系 | 躲开它 | 给它补一格 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 那件小事 | 越小越好：一张桌子、一把钥匙、一个可以自己决定的日子 |
| 查的过程 | 执事翻的那几本 · 翻到第三本时的语气 · 「回主子，查无此例」 |
| 立条的形态 | 口头（最轻，也最容易反悔）· 写进家书 · 入家规（最重，从此约束别人） |
| 第一次援引 | 谁援引的 · 援引时他在不在场 |
| 收尾 | 多年后那一条被人当作旧例引用，念的人不知道它是怎么来的 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提出立条 | 她 | 他（他提，代价更大，因为提本身就越了他的位） |
| 形态 | 口头 | 入家规（接 [20-女尊制度场景 · 她改了规矩](20-女尊制度场景.md#七--她改了规矩)：那条改旧文，这条补新格） |
| 影响面 | 只管他们两个 | 管到后来的人，有人因此受益，也有人因此受限 |
| 结局 | 被援引，进了制度 | 一直没人用，它只留在他们之间 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「查无此例」四个字之后的那一停 | 他没想到这么小的一件事居然要问 |
| 内心 | 没人规定，就是没人拦着，也没人担着 | 头一回，答案不在书上 |
| 好的处理 | 立的那一条写得像条文，不像情话 | 他提的那件事小到别人不会记 |
| 写崩 | 补的那一条从此再没出现 | 借这一条一路推翻整套制度 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 表格里没有他们那一栏（[38-制度里的两个人 · 表格里没有他们](38-制度里的两个人.md#四--表格里没有他们)） |
| 修仙 | 门规未载之事 · 掌门批的那一句「特许」 |
| 星际 | 条例外情形 · 舰长权限里的自由裁量条 |

#### 写崩的三种方式

1. 补的那一条只出现一次。 新条要被援引一次才算立住，否则与死设定无异。
2. 用这一条推翻整套制度。 一个缝就是一个缝，补一格不等于换一部典章。
3. 那件事挑得太大。 事越大越会撞上现成的条文，小事才可能真的无例可查。
