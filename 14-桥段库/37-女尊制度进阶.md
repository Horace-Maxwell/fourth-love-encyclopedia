## 安全框架（先读这一节）

这一族写的是古代女尊设定里的制度层，框架要在动笔前写全。婚仪、七出、男德、验身、位阶、籍、扶正、封诰——其中一半直接性转自现实历史上的人身依附制度。

### 三条社群共识

| 缩写 | 全称 | 含义 |
|---|---|---|
| SSC | Safe, Sane, Consensual | 安全、理智、双方同意 |
| RACK | Risk-Aware Consensual Kink | 知晓风险的前提下双方同意 |
| PRICK | Personal Responsibility, Informed Consensual Kink | 个人责任前提下的知情同意 |

这三样东西，是不同年代的读者们自己琢磨出来的说法。说到底就一个意思：同意这事，得是脑子清楚的大人，知道自己在干嘛，而且随时能反悔。

### 虚构与现实的分界

**古代那套人身依附规矩，是拿来玩梗的，不是拿来当真的。** 良贱、验身、家法、七出、籍没，历史上真压得人喘不过气。小说里把这套东西翻过来用，让读者换个角度看看它长什么样。但世界是作者说了算，后果也是作者说了算。它不是现实操作手册。

这一族不提供任何可复现的实施细节，只讨论叙事结构。

### 三条硬边界

| 边界 | 说明 |
|---|---|
| 全员成年 | 所有涉及婚配、依附与责罚的角色都是成年人 |
| 不写过程 | 验身、家法、责罚只写结果，不写过程。具体写法走 [06-尺度与写法/04-训诫与BDSM专论](../06-尺度与写法/04-训诫与BDSM专论.md) |
| 制度要被使用 | 写进设定的制度，正文里既没人用也没人犯，那就是白写（死设定检验法见 [02-术语百科 5.5](../02-术语百科/02-女尊称谓与礼制体系.md)） |

关于家法完整框架和越界判定的内容，在 [08-规训日常版 · 安全框架](08-规训日常版.md) 和 [20-女尊制度场景 · 家法](20-女尊制度场景.md#六--家法) 里。带 ⚠️训诫 的三条，分别是 [四 · 守身这回事](#四--守身这回事)、[五 · 通房与外室](#五--通房与外室)、[七 · 扶正](#七--扶正)。

## 一 · 大婚

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：婚礼仪式＋请安＋选侍 24 部 / 0.9%（[13-07 §四情境组合](../13-语料挖掘/07-桥段分布.md) 榜首）

**骨架**｜女娶男嫁，三天走完。头天她把他接回来，第二天他头回请安，第三天妾室按位次排好。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 议亲先定规格：娶（三书六礼全套）还是纳（仪注低一等），这一步定死后面所有名分（[纳夫／娶夫](../02-术语百科/02-女尊称谓与礼制体系.md) 词条） |
| 2 | 下聘。聘礼由她这边出，方向与现实相反，他家备嫁妆，妆册一式两份 |
| 3 | 迎娶那日她亲去接，他上轿，门槛、火盆、喜秤的性转版逐样过一遍 |
| 4 | 拜堂的次序：先告祖，再拜她的母父，最后交拜 |
| 5 | 当夜之前那半刻：她挑帕，他抬头，第一次在自己家里看她 |
| 6 | 次日五更，第一次晨昏定省：奉茶、改口、领见府中人（这一拍接 [20-女尊制度场景 · 晨昏定省](20-女尊制度场景.md#一--晨昏定省) 的第一天） |
| 7 | 第三日媵侍见礼，位次当场排定，妆册与人册一并入库 |
| 8 | 三日礼成，第四日起走日常的钟 |

#### 时间轴

**三天，一天一个说了算。** 第一天听礼官的，什么时辰做什么事，一秒都差不了。第二天听她爹娘的，茶烫不烫、话说几句、赏什么东西，全看长辈心情。第三天看位次，媵侍谁站前谁站后，排定了往后几十年都不带变的。他自己的时间就两段：坐轿子里那一个时辰，还有第三天晚上俩人单独待那一会儿。

#### 三日各写什么

| 日 | 制度动作 | 落点 |
|---|---|---|
| 第一日 | 聘、迎、拜 | 她亲自去接，去不去，差着整整一个台阶 |
| 第二日 | 奉茶、改口、请安 | 婆公接不接那杯茶，接了才算改了口 |
| 第三日 | 媵侍见礼、排位次 | 他往哪儿一站，全府上下就照那个位置看他 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 文书 | 聘书 · 妆册一式两份，男家留底 · 婚书上两个名字谁在前 |
| 器物 | 喜秤 · 火盆 · 那盏改口茶凉了要重换，重换过一次的人都记得 · 他袖里攥着的礼单 |
| 礼节 | 拜的次序 · 他跪的次数 · 谁扶他起来 |
| 媵 | 陪嫁的同族兄弟或舅甥（[媵](../02-术语百科/02-女尊称谓与礼制体系.md) 词条），他们的位次连着他的体面 |
| 破绽 | 三天里他几乎没吃东西 · 第二天嗓子哑了，茶太烫，话又不能少 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 规格 | 娶（全礼） | 纳，仪注减半，名分也跟着减半 |
| 她去不去亲迎 | 亲去 | 派人代迎，规矩上说得过去，但也是明摆着打脸 |
| 媵 | 有贵族出嫁的标配 | 无，他出身寒门，第三日没人可排，这一天特别难熬 |
| 三日的成色 | 礼数挑不出错 | 出过一处小错，谁替他兜的，就是他日后能靠的人 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 亲迎那日她掀开轿帘的手 | 火盆那一步他迈得比礼官教的高 |
| 内心 | 三天里她真正说了算的，就这一回 | 每一步都是安排好的，只有掀帘那一眼是多余的 |
| 好的处理 | 她在礼官没留神的地方，多做了件小事 | 礼数一点没错，错的那点别人看不出来 |
| 写崩 | 婚仪写成流水账 | 当夜写成重头戏 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 领证、婚礼、回门三件事（[23-婚嫁](23-婚嫁.md) 全卷） |
| 修仙 | 结契大典、拜山门、道侣录留名 |
| 星际 | 登记、舰上典礼、权限交割三段 |

#### 写崩的三种方式

1. 礼数写全了，人却不见了。礼单可以查书，他吃了几口饭查不到，那才是作者该下笔的地方。
2. 媵侍当摆设。第三天排的位次，后文得用上，不然那天就白写了。
3. 三日压成一日。三天分别由三个人负责，砍掉两天就只剩下表面功夫。

## 二 · 和离与休夫

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：无独立节拍族（词条见 [02-术语百科 · 和离／休夫](../02-术语百科/02-女尊称谓与礼制体系.md)）

**骨架**｜同一天，同一张桌子，写的是两份完全不一样的东西。和离书一人一份，休书只有一份。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 事到临头，非办不可。她非保他不可，她非丢他不可，再不然就是他自己待不下去 |
| 2 | 先翻规矩：休妻得占七出里一条，不孝父母、没儿子、偷人、善妒、重病、多嘴、偷东西，和离只要两边都点头 |
| 3 | 三不去被人翻出来，给公婆守过孝、从穷时候一起过来的、娘家没人了，占一条就休不动 |
| 4 | 字谁写，谁在旁边看着，族里长辈、中间人、官媒都算 |
| 5 | 落笔那一下不一样：和离书一人一份，休书就她手里一张，另一张进衙门存档 |
| 6 | 嫁妆怎么算，原样拿走、对半分，还是一分不给 |
| 7 | 出门走哪个门，正门侧门差的是往后一辈子的脸面 |
| 8 | 往后怎么叫人：她在外头怎么提他，他在外头怎么提她 |

#### 时间轴

逼到眼前一天，走完一个月。查名目半天，三不去的核对得请族里最老的那位来说，一说就是一天。文书改了三次，改的全是名目那一行，落笔用不了半炷香。妆奁清点两天，一件件对着册子。最后是出门那一步，一步走完，先前的一个月才算完。

#### 两种落笔法

| | 她放手（和离） | 他求去（下堂） |
|---|---|---|
| 名目 | 两边都点头，不用扯理由 | 得替他编个像样的说法，多半赖在他自己头上 |
| 文书 | 一式两份 | 他求的是休书，就一份，丢人的是他 |
| 妆奁 | 原样还回去，算给足面子 | 他常啥也不要，好让那纸文书看着像她占理 |
| 落点 | 她按住笔的那一下 | 他把编好的理由推过来，说“照这个写” |
| 后事 | 他还能再嫁 | 名声坏在名目那一行上，再嫁难了 |

| 类 | 内容 |
|---|---|
| 文书 | 和离书怎么写，各无怨怼、各自婚嫁 · 休书里那一条七出 · 官府盖的骑缝印 |
| 三不去 | 他给婆公守过孝那一年，这条最常拿来救人 |
| 在场的人 | 族老 · 中人 · 官媒 · 一个没忍住哭出来的下人 |
| 妆奁 | 册子上每样都对得上，就一样对不上，那一样是他自己添的 |
| 门 | 正门 · 侧门 · 他从哪道门出去，第二天全城都知道了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提的 | 她 | 他基本没戏，所以得借七出绕一下 |
| 名目的真假 | 真的 | 编的，编个名目是给对方台阶下，也是把不是揽到自己头上 |
| 妆奁 | 原样还回去 | 他一样都不拿 |
| 结局 | 各嫁各的 | 过几年来了封信（走 [22-分手与复合](22-分手与复合.md) 的古代接口） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 名目那一行她改了三次 | 「照这个写」四个字说出口的语速 |
| 内心 | 写真的伤他名声，写假的伤她自己的 | 名目落在我身上，她才干净 |
| 好的处理 | 和离与休夫的分别写清楚，不混着用 | 求去的理由具体到能被官媒记录 |
| 写崩 | 休书当吵架的道具甩出来 | 潇洒转身，不算妆奁不问门 |

#### 换皮

| 世界 | 等价物 |
|---|---|

2. 七出只念不用。条款列出来而情节不倚它，那就是死设定。
3. 妆奁不算。财产清点是这场戏里唯一无法用感情糊过去的一段。

## 三 · 男德课

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：无独立节拍族（词条见 [02-术语百科 · 男德／男戒／男红](../02-术语百科/02-女尊称谓与礼制体系.md)）

**骨架**｜《男戒》他干了十几年，手熟得不用想。她头回看出这点那天，怎么处理，就是她是什么人。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 结婚前那套规矩怎么教的：三从没出嫁听娘的，嫁了听媳妇的，媳妇没了听闺女的、四德，媳妇的德、媳妇的话、媳妇的样、媳妇干的活 |
| 2 | 平时根本不用想就做了：她一起床他也起，她坐着他就旁边站着，眼睛只敢看她脚尖往上三寸那块地儿 |
| 3 | 她头一回觉着这不是他脾气好，是背熟了的 |
| 4 | 她试过让他破一回例，坐下、抬头、先动筷子 |
| 5 | 他要么做不到，要么做到了，但一整宿没合眼 |
| 6 | 她心里定了主意：接着用、挑着用，还是全扔了 |
| 7 | 全扔了的麻烦：规矩一没他反而发慌，得有人给他立套新的 |
| 8 | 过了好些年他偶尔还是会退那半步，俩人谁都不提这事 |

#### 时间轴

试破一条，当场见效。可要真改掉一条，至少得半年，改到不再犯，得三年。中间反复是常态，她不在的时候，那些旧毛病就悄悄回来了——她在的时候改了，她不在的时候又回去。反复本身就是素材。他学这套东西花了十几年，改起来得按年算。

#### 三种态度，三种人

| 她的态度 | 她是谁 | 他的处境 |
|---|---|---|
| 照旧沿用 | 靠这套规矩上位的人，她信这套 | 安全，但一辈子也就是个干得好的 |
| 挑着用 | 面子上的礼数留着，背后不跟你讲这套 | 最常见，也最难说清分寸在哪儿 |
| 整套拆了 | 她要的是能跟她搭上话的人 | 先懵后缓过来，懵的那段最带劲 |

#### 可用细节

| 类 | 内容 |
|---|---|

## 四 · 守身这回事

`M` ｜ ⚠️训诫 ｜ 古代女尊 ｜ 语料频次：无独立节拍族（词条见 [02-术语百科 · 守身如玉](../02-术语百科/02-女尊称谓与礼制体系.md)）

**骨架**｜贞洁那套规矩整个搬到男人身上，婚前得守，婚后要验，丢了就是名节毁了。她信不信这套，决定这场戏是压人还是拆台。

#### 安全框架（承卷首）

| 项 | 说明 |
|---|---|
| 共识框架 | SSC · RACK · PRICK，全文见卷首 |
| 虚构与现实 | 验身、名节这类事，是故事里编出来的设定，别当成现实里的规矩 |
| 不写过程 | 只交代有这回事、带来什么后果，不写任何能照着学的细节 |
| 全员成年 | 出场角色全是成年人 |

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 规矩比人先到：没成亲前身子得干净，这是谈婚论嫁的硬杠杠 |
| 2 | 查不查看形式，婚前要凭证，婚后要堵嘴。过程不写，只写有没有这回事 |
| 3 | 有人拿这事挤兑他，酒桌上的一句话，下人嚼的一句舌根 |
| 4 | 话传进她耳朵，中间隔了下人掂量该不该报的那一天 |
| 5 | 她处理起来就三招：信、查、装没看见 |
| 6 | 怎么处置大家都看在眼里，府里人对他立马换了个看法 |
| 7 | 过后他自己过不去：被议论的是身子，抬不起头的是人 |

#### 时间轴

她听到那句闲话，隔了一日。话从席间起，三十息工夫传遍，洗掉却要按年。若处置得快，三日内定调，慢些，一个月后即成定论。他自己那一关最久，闲话早散尽了，他还在意。

#### 可用细节

| 类 | 内容 |
|---|---|
| 凭证 | 议亲时男家写的那张纸 · 保人是谁 · 那张纸收在妆奁哪一层 |
| 闲话的形状 | 半句话 · 一个眼神 · 一句“听说”，说的人自己心里也没底 |
| 她的三档 | 信，当场把话顶回去 · 查了就等于认了这套规矩 · 不查最难，因为不查也得有个说法 |
| 他的处境 | 名节这种事没法自证，越解释越像真的 |
| 收尾的物件 | 那张凭证最后怎么处理：烧了、还给他，还是照旧收着 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他守没守 | 守了，清白，照样有人说闲话 | 没守，有过前事，这话才真戳心 |
| 她信不信这套 | 信，她是规矩里长大的，写实但不容易让人喜欢 | 不信，她得自己扛后果，族里会记这笔账 |
| 处置 | 公开 | 私下，快，但堵不住别人的嘴 |
| 落点 | 那纸凭证烧了 | 那纸还在，只是没人再提了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她听完闲话先问出口的那句是啥 | 他明白自己怎么都说不清的那一下 |
| 内心 | 查不查，都等于认了这条规矩 | 干净不干净，全看别人那张嘴 |
| 好的处理 | 收拾的是传话的人，不是冲他身子去 | 他不急着洗白，也不装大度 |
| 写崩 | 检验写成了走场面 | 失贞写成了他人品有亏 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 他以前的事被人翻出来嚼舌根（[15-秘密与坦白 · 前任出现](15-秘密与坦白.md#四--前任出现)） |
| 修仙 | 元阳和道基那套说法 · 同门在背后嘀咕 |
| 星际 | 婚配档案里存着旧记录 · 谁能翻出来看 |

#### 写崩的三种方式

1. 把检验写成场面。 制度的分量在它摆在那儿，不在它怎么执行。真把过程写细了，就等于越过了卷首那条线。
2. 让她也信这套，但别让她付出代价。 信有信的代价，不信也有，两边都得还。
3. 用一句「我信你」收尾。 信是态度，处置才是动作，真正堵住嘴的是处置。

## 五 · 通房与外室

**骨架**｜一个府里每天怎么运转，谁能进正堂，谁拿几成月钱，谁压根不在册子上。

#### 节拍链

| 拍 | 内容 |

| 2 | 早间请安按顺序来：媵先进，通房最后，外室压根不露面 |
| 3 | 通房啥位置：收了房没名分，说高不高说低不低（[通房](../02-术语百科/02-女尊称谓与礼制体系.md) 词条） |
| 4 | 外室啥位置：养在外面，不进族谱，孩子也不能自己带（[外室](../02-术语百科/02-女尊称谓与礼制体系.md) 词条） |

| 侧夫／臣室 | 有 | 有院 · 有份例 · 请安有座 |
| 通房 | 无名分 | 贴身伺候，能抬举也能发落 |
| 外室 | 不入族谱 | 不进府里，只在她出门时见 |

| 类 | 内容 |
|---|---|
| 份例 | 料子啥档次 · 用度多少 · 病了给不给请大夫，最看得出地位 |
| 请安的队形 | 谁站谁坐 · 谁先开口 · 谁不用来 |
| 通房的两条路 | 抬举（改籍、入册）· 发落（配人、遣出） |
| 外室的物件 | 一处外宅的钥匙 · 逢年过节府里送来的东西比谁都薄 |

| 轴 | 一端 | 另一端 |
|---|---|---|
| 制度形态 | 一妻一夫多臣，有正侧之别 | 平夫制，地位相等，宅斗没了，改走温情群像 |
| 通房的走向 | 被抬举 | 被发落，理由多半跟他本人没关系 |
| 外室的成因 | 家里不让娶 | 身份太低，他自己也知道进不了门 |
| 正夫的态度 | 守着位份，守的是规矩 | 替下面的人说话，说一次就行，说多了她该起疑了 |

| | 四爱女笔下 | 四爱男笔下 |

| 世界 | 等价物 |

## 六 · 招赘与入赘

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：无独立节拍族（词条见 [02-术语百科 · 一妻多夫／平夫制／走婚](../02-术语百科/02-女尊称谓与礼制体系.md)）

**骨架**｜他嫁过来那天，户口本上得改三处：老家销户，新家上户，名字也得换。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 议亲先问清楚：是招赘（他进她家门）、走婚，不算正式两口子，还是各过各的 |
| 2 | 女户能立起来，靠的就是她当户主，这一条是后面所有事的根 |
| 3 | 办户帖的时候，原籍那行划掉，新户那行添上 |
| 4 | 冠妻姓、改夫名。各家改法不一样：有的只加姓，有的连名一起换，有的只在文书上动笔 |
| 5 | 他原来那家算账：少了个干活的人，多了门亲戚，两边心里都有小九九 |
| 6 | 头一回有人用新名新姓喊他，他愣了一拍才应 |
| 7 | 孩子随母姓，写进族谱那天他在旁边看着 |
| 8 | 多年后他本名就剩三个地方能见着：旧档案里、他娘嘴里、或者某件老物件上 |

#### 时间轴

户帖当天就能办完，名字却要认好几年。划掉旧名、添上新名，一炷香的功夫。下人先改口，亲戚最后改，改称呼得半年。他自己心里认下这个新名字，还要更久。中间有段时间，叫他哪个名字他都应。

#### 三种形态的分别

| 形态 | 他的身份 | 子女 | 他能不能走 |
|---|---|---|---|
| 招赘（入赘） | 入她的户，是法定配偶 | 随母姓，进她家族谱 | 想走就得和离（接 [二](#二--和离与休夫)） |
| 走婚 | 不入户，不算法定配偶 | 归女方，爹不上册 | 随时能断 |
| 各归各家 | 名义上的配偶，户口各是各 | 看两家怎么商量 | 说好就行 |

| 类 | 内容 |

| 他原家 | 送出门时撂下的话 · 逢年过节谁去谁不去 · 兄弟啥态度 |
| 走婚版 | 她来不来全看她 · 门口留个记号 · 他不问下次 |
| 收尾物 | 一件刻着旧名的东西，他没扔，也没拿出来 |

| 轴 | 一端 | 另一端 |
|---|---|---|
| 形态 | 招赘，他把自己交出去 | 走婚，谁都不交，各自留一半 |
| 改名的深度 | 只冠姓 | 姓名一并改，改得越深，回头路越窄 |
| 他原家 | 得了聘礼，喜气洋洋 | 觉得丢人，从此少来往 |
| 他的接受度 | 认了，且认得干脆 | 一直没认，他在两个名字之间过了半辈子 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 户帖上她名字底下多了一行 | 原籍那笔划下去的声音 |
| 内心 | 他算我户上的人了，这一行比婚书还顶用 | 往后我归谁管，纸上写得清清楚楚 |
| 好的处理 | 户籍后面还得用上，不是开头交代完就扔 | 改名的别扭搁在签名的停顿里 |
| 写崩 | 改姓整成求婚现场 | 招赘跟走婚搅成一锅粥 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 户口迁进来 · 婚后姓随不随她 · 孩子跟谁姓（[38-制度里的两个人 · 户口本](38-制度里的两个人.md#九--户口本)） |

1. 两套规矩都没立住。一个要男方入赘，一个不用，混着来，招赘和走婚搅在一起。

## 七 · 扶正

`M` ｜ ⚠️训诫 ｜ 古代女尊 ｜ 语料频次：位份 15.0%（[02-术语百科 · 良籍／扶正／俾男](../02-术语百科/02-女尊称谓与礼制体系.md) 的场面化）

**骨架**｜正夫位空着，够格的人身上都压着籍。改籍在前，扶正在后，落印时他还在门外站着。

#### 安全框架（承卷首）

虚构世界里，「良贱之别」如何运作、如何被钻空子，才是这故事真正要碰的东西。历史上那套人身依附确实存在，但具体怎么操作，不写，能照着搬的，也不碰。故事里所有角色，都是成年人。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 正夫位空出：人没了、和离了，或被休了（接 [二](#二--和离与休夫)） |
| 2 | 排资格：媵最够格，良籍臣室差一档，通房抬举再往后，贱籍垫底 |
| 3 | 卡在籍上。良贱不通婚，贱籍得先脱籍：赎身、销贱、入良册，这道手续最拖日子 |
| 4 | 族议。嫡庶分明的世家一概不准，不严的许，但礼数要降格 |
| 5 | 文书写好，盖印。印砸在纸上的那一声，整件事才算落地 |
| 6 | 礼数降格的那几处：办个宴就行，不告祖，不走正门 |
| 7 | 他从侧门进来，走到正堂站定 |
| 8 | 称呼当天全改，府里改口快慢，就是人心怎么倒的 |

#### 时间轴

**盖章就一秒钟，改籍却按年算。** 族里开会讨论三次，文书起草好几天，最后落章不过眨眼的事。可章盖完了，称呼还得换，下人三天就改完，族里三年都改不干净。赎身销贱得跑官府，快的话半年，慢的话三年，中间要人担保，要花钱，还得她亲自出面。她一露面，族里就记上一笔。

| 戏子、伎男 | 须先改籍，且族议几乎必阻 | 同上，另加一场公议 |

## 八 · 一家子的称谓

`G` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：请安 25.0%，称谓在请安场里每日兑现

**骨架**｜孩子第一次开口叫人，把家里辈分全喊了一遍。轮到自己，也把那辈儿报了个齐全。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 孩子刚学说话，府里先教哪个称呼、先教谁，谁位分就高 |
| 2 | 正夫叫「爹爹／阿爹／父亲大人」，低位分的叫「小爹／叔爹／庶父」（[小爹](../02-术语百科/02-女尊称谓与礼制体系.md) 词条） |
| 3 | 孩子叫错过一回 |
| 4 | 当场谁纠正的，语气多重，被叫错那人脸上挂不挂得住 |
| 5 | 他自己对不同人换称呼：对她、对长辈、对外客、对下人，四种说法 |
| 6 | 有回外客在场，孩子当众叫错，大人怎么把场面圆回来 |
| 7 | 孩子大了，称呼早定死了，有个称呼他一辈子没听孩子改过口 |

#### 时间轴

**孩子两岁到五岁，是称呼定型的窗口期。** 这段时期教什么就叫什么，叫错也集中在这三年，之后极少出错。成年之后改口，基本只发生在关系变动的时候，比如 [七 · 扶正](#七--扶正) 之后的全府改口。称呼学三年，用一辈子。

#### 一家子怎么叫

| 关系 | 称呼 | 备注 |
|---|---|---|
| 子女→母 | 母亲 · 娘 | 语序倒置的总原则见 [母父](../02-术语百科/02-女尊称谓与礼制体系.md) 词条 |
| 子女→正夫 | 爹爹 · 阿爹 · 父亲大人 | 皇室作「父后」，与「君后」是同一人的两种叫法 |
| 子女→低位配偶 | 小爹 · 叔爹 · 庶父 | 用错等于当众划位阶 |
| 他→她 | 妻主 · 主子，视世界硬度取用 | 「妻主」出现频次越低越有力（[妻主](../02-术语百科/02-女尊称谓与礼制体系.md) 词条的语感提示） |
| 他→自称 | 在下／臣身／侍身／奴家 | 四级递降，等于身份条形码 |
| 并称 | 母父 · 妻夫 · 娘爹 · 婆公 · 奶爷 | 男先女后的语序全部翻转 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 教的现场 | 谁抱着孩子教 · 教的第一个称呼是哪一个 · 有人在旁边听着不说话 |
| 叫错 | 把「小爹」叫成「爹爹」，低位者的脸先红 · 反过来叫，正夫沉默，比发作更难写也更好看 |
| 纠正 | 由她纠正 · 由被叫错的那位自己纠正，他的分寸就在这一句里 |
| 自称的切换 | 他在她面前用哪一档，在外客面前又用哪一档，切换的那半秒 |
| 一辈子没改的那一声 | 孩子成年后仍旧那么叫，理由谁都不提 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 叫错的方向 | 往上叫，低位的人听着受用，又有点慌 | 往下叫，正夫被降了一格，全场静一息 |
| 教的人 | 她 | 乳母、长辈，教出来的称呼带着教的人的立场 |
| 他的自称 | 全程守规矩 | 私下用「我」，这一个字比任何情话都越界 |
| 收场 | 一句话带过 | 这次叫错成了后面某件事的引信 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 孩子叫错之后她先看的是谁 | 「爹爹」两个字落到别人身上那一瞬 |
| 内心 | 一个称呼就把人钉死在位置上 | 我的位置，让一个三岁孩子念出来了 |
| 好的处理 | 嘴上轻轻纠正，但位份一点不让 | 他自己纠正，比谁都快 |
| 写崩 | 称谓混用穿帮，写着写着把「父后」写成「母后」 | 把叫错当成无关紧要的小插曲 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 孩子在外人面前怎么喊他 · 他在她同事跟前怎么自报家门（[38-制度里的两个人 · 家长会谁去](38-制度里的两个人.md#三--家长会谁去)） |
| 修仙 | 师叔和师尊差着辈分 · 弟子怎么叫他，得看她在门里排到哪 |
| 星际 | 档案里填的那栏关系 · 系统播报时念出来的那个称呼 |

#### 写崩的三种方式

1. 称谓表只在设定页齐整。每天要用的东西写在附录里，正文一开口就露馅。
2. 一套称谓混着两派用。君系与夫系各自成体系，同一部书里只能取一派。
3. 叫错不留后果。位阶靠称呼兑现，叫错一次而无人在意，等于位阶不存在。

## 九 · 她的仕途

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：告别 37.0%（外放与赴任）＋ 位份 15.0%

**骨架**｜放榜、授官、外放。她名字往上走一格，他品级跟着动一格。官眷是他这辈子唯一别人给的身份。

## 十 · 制度的缝

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：位份 15.0% ＋ 请安 25.0%（收束条，不引新族）

**骨架**｜收束条。前九条都有文书可查，这条查不到。有件事翻遍规矩也找不着说法，没条款就没先例，也没人管，于是他们自己定了条规矩。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 一件具体的小事冒出来：他想在她书房摆张自己的桌子、他名下能不能有处产业、他能不能替她去见个人 |
| 2 | 照老规矩，先问执事：这事该怎么弄 |
| 3 | 执事去翻旧档，回来说没翻到过这种事 |
| 4 | 没翻到，两头都占着：没说不让干，也没说能干 |
| 5 | 两条道：当没事发生，省心，他自己也会把话咽回去，或者自己定个规矩 |
| 6 | 这规矩谁来定、写在哪：嘴上说说、写进家书，还是直接入家规 |
| 7 | 头一回照这规矩办。真有人拿它说事的时候，它才算立住了 |
| 8 | 过些年有人拿这条当老例来用，到那时候，这早就不单是他们俩的事了 |

#### 时间轴

真正进入制度的刻度，不在写下那一刻。两个人商量那一晚不长，写下来更短。问和查都在一天里，查无此例只用半天。可立一条，要看多少年后有人援引。第一次被人援引，隔一年到数年，被第三个人援引，才算真进了制度。始终没人援引的话，它只是他们俩之间的一句话，也算一种结局。

#### 与 20 卷第十条的分别

| | [20 · 制度之外的那一刻](20-女尊制度场景.md#十--制度之外的那一刻) | 这一条 |
|---|---|---|
| 缺口的性质 | 暂时没人管 | 永远没这规矩，翻遍典章也找不着 |
| 时长 | 几分钟，说收就收 | 一件事，能留几十年 |
| 收法 | 两人马上回到原样 | 两人自己定了个规矩 |
| 与制度的关系 | 绕开它 | 给它添一笔 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 那件小事 | 越小越好：一张桌子、一把钥匙、一个自己说了算的日子 |
| 查的过程 | 执事翻的那几本 · 翻到第三本时的语气 · 「回主子，查无此例」 |
| 立条的形态 | 口头最轻，也最容易反悔 · 写进家书 · 入家规最重，往后谁都绕不开 |
| 第一次援引 | 谁先提的 · 提的时候他在不在场 |
| 收尾 | 多年后那一条被人当老规矩拿出来用，念的人不知道它是怎么来的 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提出立条 | 她 | 他，他提，代价更大，因为提本身就踩过了界 |
| 形态 | 口头 | 入家规（接 [20-女尊制度场景 · 她改了规矩](20-女尊制度场景.md#七--她改了规矩)：那条改旧文，这条补新格） |
| 影响面 | 只管他们两个 | 管到后来的人，有人沾光，也有人被卡住 |
| 结局 | 被援引，进了制度 | 一直没人用，只留在他们俩之间 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 写到“查无此例”就停住，不再往下说 | 他没想到这么小的事，还得开口问 |
| 内心 | 没人管，也没人拦，更没人替她兜底 | 头一回，书里也找不着答案 |
| 好的处理 | 立规矩那条，写得像条款，不像情话 | 他提的那件事，小到别人压根不会记 |
| 写崩 | 补的那条，之后再没提过 | 借这条，一路把整套规矩全掀了 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 制度里没给他们留位置（[38-制度里的两个人 · 表格里没有他们](38-制度里的两个人.md#四--表格里没有他们)） |
| 修仙 | 门规没写的事 · 掌门亲口批的「特许」 |
| 星际 | 条例没覆盖的情况 · 舰长权限里能自己说了算的那条 |

#### 写崩的三种方式

1. 补的那一条只出现一次。 新条得被人引用一回才算数，不然跟没写一样。
2. 用这一条推翻整套制度。 一个缝就是一个缝，补一格不等于换一部典章。
3. 那件事挑得太大。 事越大越会撞上现成的条文，小事才可能真的无例可查。
