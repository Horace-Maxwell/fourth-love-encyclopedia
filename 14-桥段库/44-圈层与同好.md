> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 现代（同人圈／网络圈层）
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)（基数 2,894 部独立作品）与 [10-藏书索引/文案标签统计](../10-藏书索引/文案标签统计.md)（5,668 篇作者自标口径，两套基数不通换）。文中百分比为编写时实测，权威数字以两处源文件为准（`run.py mine` 重跑更新）

## 这一族补的是什么

同人排在语料世界背景标签的第三位：388 篇，6.8%（文案标签统计），只排在现代都市和架空后面。词有整卷（[02-术语百科/04-尺度预警与社群黑话](../02-术语百科/04-尺度预警与社群黑话.md)），争议有整节（[01-总论/05-社群画像与内部争议](../01-总论/05-社群画像与内部争议.md)），平台有整卷（[08-平台生态](../08-平台生态/01-平台生态与发文指南.md)）。缺的是场面这层：圈层身份怎么落到两个人的饭桌上、深夜里、书评区里。

材料的分层：

| 层 | 在哪 | 这里写什么 |
|---|---|---|
| 词条（太太／排雷／双洁…） | [02-术语百科/04](../02-术语百科/04-尺度预警与社群黑话.md) | 这个词第一次被人说出口的那场戏 |
| 争议（正统之争／洁党之争） | [01-总论/05](../01-总论/05-社群画像与内部争议.md) | 争议闹到自家门口的那一天 |

十条通用的写法纪律有两条：

| 纪律 | 做法 |
|---|---|
| 黑话要有出口 | 圈外角色在场就是现成的解释机会：他问一句，她答一句，黑话就成了戏。没外人时，头回出现的词后头加个括注 |
| 争议两边都有理 | 排雷帖、洁党、正统之争写进故事时，别急着分好人坏人。现实里的圈内吵架，没有哪边全对 |

## 一 · 第一次说出口

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：坦白 6.5%，公开 33.4%（13-07）

**骨架**｜说“我是四爱”就一秒的事。可跟谁说、用哪个词、在哪儿说，这三件事得分开想。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 决定说（导火索通常很小：他又一次抢着拎了所有袋子） |
| 2 | 选人（对象、闺蜜、圈外老友，风险各不同） |
| 3 | 选词（「四爱」「我比较主动」「你看过这类文吗」，三个词三条路） |
| 4 | 选场（车里、并排走路、消息框，共同点是不用对视） |
| 5 | 说出口，然后是对方的三秒 |
| 6 | 当晚他的搜索记录 |
| 7 | 第二天的一句话（真正的答复在这里，不在当场） |

#### 时间轴

铺垫三周，说出口一秒，等答复一夜。**当场的反应不算数**：那三秒里人只来得及端出礼貌。真反应是对方消化一晚上，第二天开口那句话的措辞里藏着的。

#### 风险分层

| 说给谁 | 风险 | 能换到什么 |
|---|---|---|
| 对象 | 最高：关系当场变味或更进一步 | 一段不用再装的关系 |
| 闺蜜 | 中：友谊多半没事，但从此多一双盯着你的眼睛 | 一个能说掏心话的人 |
| 圈外老友 | 中低：多半换来一句「哦这样啊」，话没进脑子 | 练一遍的胆量 |
| 同事亲戚 | 高：传出去收不住，啥也落不着 | 基本没人这么干；对外人的说法走 [14-社交与公开 · 议论](14-社交与公开.md#二--议论) |

#### 可用细节

| 类 | 内容 |
|---|---|
| 选词学 | 「四爱」太准但得解释半天 · 「我喜欢主动一点」安全但容易被听岔 · 「有个词叫女攻」把定义权扔给搜索引擎 |
| 场地 | 副驾驶（红灯时说，绿灯打圆场）· 并排散步 · 打字打了删删了打 |
| 对方的三秒 | 手里的动作停了半拍 · 「嗯」得太快 · 反问的第一个字 |
| 他的当晚 | 搜索记录从词条页一路翻进贴吧 · 凌晨两点还亮着的屏 |
| 第二天那句话 | 「早上想喝什么」照旧＝接住了 · 「我查了一下」＝他真上心了 · 绕开话题＝没接住，别追 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先说 | 她说，赌的是这段关系 | 他说，赌的是对方信不信：男方自称四爱，先被当成来占便宜的（圈内称「骗炮男」，人群结构见 [01-总论/05](../01-总论/05-社群画像与内部争议.md)），他拿得出手的只有时间 |
| 词的精度 | 直接给词 | 先递一本文当探路石（接 [十 · 圈地自萌的分寸](#十--圈地自萌的分寸)） |
| 对方底色 | 完全圈外人 | 早听说过（他中学同桌就在贴吧潜水） |
| 结果 | 接住了 | 没接住但关系没散：这个词从此悬在两人中间，隔几个月碰一次 |

「他说」那一端的不对称是这条最深的地方：她说出口赌的是被拒绝，他说出口赌的是被怀疑。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 话出口前三周，反复琢磨怎么说 | 听懂那词的瞬间：原来有这词，原来不止他一个 |
| 内心 | 说完就后悔顺序：该先给他看文的 | 不敢再问第二句，怕问多了露馅自己查过 |
| 好的处理 | 说完不找补、不降调、不岔开，就等着 | 他第二天照常，外加一个多余的小动作 |
| 写崩 | 写成哭哭啼啼当众表白的场面 | 写成他秒懂，当场就接话表态 |

#### 写崩的三种方式

1. 对方秒懂。
没混过圈的人听到生词，正常反应是愣一下。秒懂的那种，是来安慰你的，不是真人。

2. 当场定生死。
真反应在第二天。当天晚上就摊牌，等于把一夜的戏全砍了。

3. 借她的嘴科普。
她要是解释这个词超过五句，场面就变成上课了。

## 二 · 她是太太

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：掉马 32.8%（13-07），同人背景 6.8%（文案标签统计）

**骨架**｜他随手点开一本小说，男主那点小毛病跟他一模一样。作者名字没见过，但更新时间他熟——就是她关灯后四十分钟。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 入坑（刷到推荐、群里有人安利，反正不是冲她来的） |
| 2 | 第一眼觉得眼熟：男主有个小动作，只有住一块的人才知道 |
| 3 | 再一琢磨：她更新的时间，跟他作息对得严丝合缝 |
| 4 | 实锤了（他不敢问，回头翻她以前写的东西和作者的话） |
| 5 | 追更那阵子：他成了自己故事的读者 |
| 6 | 实在憋不住那次（留长评、照着文里做、直接说破，三选一） |
| 7 | 她到底知不知道（也可能永远不知道） |

#### 时间轴

认出她只花了一晚上，确认又花了三天，然后装傻装了四个月。**追更这事，熬人是真熬人**：每周三、周日固定两更，他一周就指着这两天活。有一周她断更了，他坐立难安，憋了半天发了句「最近累不累」，她愣了下——这话平时都是她先问的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 认出的证据 | 递杯子先把杯柄转给她 · 有句话只有他说过，原样写在文里 · 那道疤的位置对得上 · 男主忌口跟他一模一样 |
| 时间的证据 | 她发完更新，四十分钟后他就看过 · 出差那周没更新 · 吵架那周，男主老实得不像话 |
| 太太的另一面 | 评论区里她话多得跟饭桌上不是一个人 · 读者喊「太太」她接得特别顺 · 作者的话里她老自嘲，这话他从没听她当面讲 |
| 文与现实的落差 | 文里他敢撒娇，现实里他不敢 · 文里都走到那一步了，现实还停在原地 |
| 他的追更装备 | 专门一个阅读 app 看 · 通知全关掉 · 书架上就这本没写备注 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 文里的他 | 被写高了（更帅更敢） | 被写得更让人心疼：文里的男主可以喊累，他看到那章，在楼道里坐了半天没缓过来 |
| 他的处理 | 一直装没看过 | 照着文里做（她写的那些事，他一件件在现实里做出来，先觉得不对劲的是她） |
| 说破方式 | 长评（用词露馅，被她认出来） | 不说破，把文里一个场景照搬到现实里，等她撞见 |
| 她的反应 | 停笔三个月 | 下一章换男主视角，全网只有一个人看得懂那是回信 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 被最不该看到的人看到了：那篇文是她藏着没敢做的事 | 他不敢开口要的，她其实都记着，只是写给了纸上的他 |
| 内心 | 写的时候没打算让他看，但每章都是照着他写的 | 吃醋的对象是纸上的自己：那个版本比他敢 |
| 好的处理 | 掉马后她不删也不解释，把下一更写成回答 | 他不点破，他把文里的场景一件件搬到现实里 |
| 写崩 | 写成她臊得删号跑路 | 写成他拿文开涮或拿捏她 |

#### 写崩的三种方式

1. 把文当罪证。文是她藏心事的地方，拿这个去审判她，等于把她心里那点东西全翻出来晒。
2. 掉马当场对质。一句「原来你写的是我」砸下来，两边都下不来台；真戏是那四个月装不知道。
3. 文里写太细。你写得越细，读者越容易跳戏，点到为止就行，文里的世界留着别填满。

## 三 · 排雷帖上有她

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列族，邻族社交网 33.9%（13-07）

**骨架**｜她的文被挂了排雷帖，截图截得没头没尾，楼越盖越高，可她今晚还有一更。

#### 节拍链

圈内群甩来链接 → 她读了三遍（第一遍找错处，第二遍找截图出处，第三遍看楼里都有谁）→ 后台掉收出现拐点 → 回应四选一 → 执行 → 数据止跌或没止 → 他察觉她不对

#### 时间轴

**舆情的一天有固定的钟**：上午被同好告知，中午楼层过百，下午掉收出现拐点，晚上决定回不回应。第二天热度腰斩，第三天有人歪楼吵起别的，原帖没人再提。烧满一轮七十二小时，但当事人过的是逐楼刷新的时间。

#### 被挂的高发罪名

「被挂」＝被公开发帖点名。GB 圈的指控自有一套（预警文化见 [02-术语百科/04](../02-术语百科/04-尺度预警与社群黑话.md)）：

| 指控 | 内情 |
|---|---|
| 「标了无反攻，第 40 章疑似反攻」 | 多半是姿势被误读成方向：谁在上不等于谁是攻 |
| 「精神四爱诈骗」 | 前三十章没写到身体层，严格派读者按定义判了 |
| 「男主不洁没预警」 | 男主有段前史，双洁党炸了（接 [六 · 洁与不洁之争](#六--洁与不洁之争)） |
| 「np 没标」 | 男二的戏份过了某条看不见的线 |

排雷（主动列出作品雷点）本身是圈内伦理，发帖人多半真踩过雷。指控可以不成立，痛可以是真的，两边同时成立。

#### 可用细节

| 类 | 内容 |
|---|---|
| 数据的体温计 | 掉收全挤在被挂后六小时 · 新长评全是来吵架的 · 收藏数她五分钟刷一次 |
| 回应四选一 | 下场解释（基本必输）· 文案补一句标注（最管用，但最不解气）· 不吭声 · 锁文（等于认输走人） |
| 她的动作 | 八百字回应写完又全删了 · 把争议章重读一遍，发现确实能读出那个意思 · 最后就改了文案 |
| 他在场时 | 她刷手机变勤了 · 饭没吃完就去回消息 · 夜里两点屏幕还亮着 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 指控成色 | 冤枉（截图断章） | 有点道理（她重读后自己也咯噔了一下） |
| 他知不知道她写文 | 知道，他是唯一知道笔名的人 | 不知道，她只能说「工作上的事」 |
| 他的动作 | 要注册小号替她吵，被按住 | 给她做了顿饭，问都没问 |
| 结局 | 补标之后火熄了 | 她从此多了一道自我审查，半年后才松回来 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 手指停在回复框上，那半分钟没动 | 他帮不上的地方：那个战场他连门都摸不着 |
| 内心 | 骂她文的人里，有几个昨天还在催更 | 她哄读者比哄自己还熟练 |
| 好的处理 | 补了标注，不道歉也不回嘴，第二天照常更新 | 他不问细节，只把水杯续满：陪着她，是圈外人唯一能做的 |
| 写崩 | 写成她下场跟人对骂，还骂赢了 | 写成他冲进评论区替她开团 |

#### 写崩的三种方式

1. 排雷帖写成反派据点。 发帖的是被雷过的读者，她自己找文的时候也看排雷帖，这东西就是个工具，没什么立场不立场的。
2. 下场必胜。 作者一下场基本就是输，圈里都懂：补标是灭火器，雄辩是浇油。
3. 数据不掉。 没掉收的被挂就是看个热闹，真疼的是她五分钟刷一次的那个收藏数。

## 四 · 奔现

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：初见 39.9% 邻族（13-07），要联系族微信提升度 1.7×

**骨架**｜网上聊了八个月，今天总算见着活人了。从头像到本人，从打字到语音，中间就隔着一顿饭钱没谈拢。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 约定（谁先开口的，说完俩人各自后悔了半天） |
| 2 | 安全流程（白天、商场、跟闺蜜报备行程：圈里都这么干，各弄各的） |
| 3 | 认人（先认出来多半靠声音或动作，跟照片对不上） |
| 4 | 前四十分钟冷场，到哪句话才活过来 |
| 5 | 买单（这拍考的就是这个） |
| 6 | 散场（送不送，下次还约不约） |
| 7 | 到家报平安，说话又变回网上那个调调 |

#### 时间轴

聊了八个月，见面两小时。**网上聊得再熟，见了面照样生**：开头十分钟俩人跟刚认识似的，到第四十分钟才把网上那个老梗用嘴说出来，八个月的默契这才算落了地。散场之后消息又是秒回，跟没事人一样，好像下午那两小时是替身去的。

#### 买单的三岔口

第一顿饭的账单是圈内金钱议题的具体化（结构见 [01-总论/05](../01-总论/05-社群画像与内部争议.md)金钱议题一节）：

| 走法 | 读出的意思 | 后患 |
|---|---|---|
| 她全付 | 攻方姿态，也是「软饭男」剧本的标准开场 | 她心里犯嘀咕：他让得也太顺了 |
| 他抢付 | 老套路抢着来 | 她皱眉：这套路网上都说好不演了 |
| AA | 看着公平 | 谁也没吭声，这事就拖到下一顿 |

写法上最好用的收束：各扫各的码，随后她把他那杯奶茶的钱转回去，备注「下顿你请」。**账没平，关系才有下一顿。**

#### 可用细节

| 类 | 内容 |
|---|---|
| 认人 | 头像是猫 · 真人比语音里高半头 · 认出对方靠回消息的手速和坐姿 |
| 各自的怕 | 她怕照骗、怕见光死，更怕对面压根没想认真处 · 他怕被当稀奇看，也怕对方只想找个好拿捏的 |
| 安全动作 | 她把定位发给闺蜜 · 他主动把桌号拍过去：「给你朋友报个坐标」 · 两人都懂这套，谁也没觉得被冒犯 |
| 破冰点 | 网上聊熟的旧梗第一次有了声音 · 对方笑起来跟想的不一样，反而更好 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 认识场景 | 同好群 | 她文的评论区（他是三年老读者，信息差巨大，接 [二 · 她是太太](#二--她是太太)的反向） |
| 见面成色 | 网上什么样线下什么样 | 判若两人（好的方向：打字冷淡的人，真人耳朵会红） |
| 买单 | 三岔口任一 | 他提前去洗手间把单买了：老习惯，饭后两人为这个笑着吵了一路 |
| 之后 | 有下顿 | 没有下顿，网上照聊：默契不提，关系退回文字并停在那里 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 见面前一晚把她俩聊天记录从头到尾翻一遍 | 进门扫一圈就认出她，跟头像没关系，就是认得出 |
| 内心 | 网上聊得再深，还是得看他吃饭啥样才踏实 | 她真人比字软，他反倒更放不开 |
| 好的处理 | 她把话挑明：转账备注写「下顿你请」 | 他接住了：三天后甩来一家店的定位 |
| 写崩 | 写成她审犯人 | 写成见光死，光看脸就下头 |

#### 写崩的三种方式

1. 删掉买单戏。 这顿饭除了结账没别的事，把结账删了，就剩干吃饭。
2. 安全流程写成互不信任。 报备和发桌号是圈里默认操作，两边都得做；写成一方防另一方跟防贼似的，人设就崩了。
3. 一顿饭定终身。 奔现的正确结局是「有下顿」，牵手回家那是另一种节奏，别混。

## 五 · 同担与同好

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：吃醋 43.1%，闺蜜在场 11.3%（13-07）

**骨架**｜同担秒懂她的频道，他进不去。他吃的是那零点五秒反应的醋，跟偶像本人没关系。

#### 节拍链

同担的动静天天往他生活里钻（吃饭时群消息震个没完）→ 他试着去搞明白 → 补课没补成 → 醋劲儿终于找到正主（气的是频道，人其实没毛病）→ 分工定了（同担管频道，他管人）→ 偶尔联动一次（她们冲前线，他管后勤）。

#### 时间轴

以偶像的日程表当钟使：官宣日、开票日、巡演周。**她的情绪跟着那张表走**，他摸清这个规律之后，很多「莫名其妙」提前三天就能猜个大概。

#### 同担与他：两套供给

| | 同担给的 | 他给的 |
|---|---|---|
| 响应速度 | 零点五秒接梗 | 慢半拍，还要问「这是新出的吗」 |
| 内容 | 同一个频道的共振 | 频道外的全部生活 |
| 强度 | 开票那晚人均手抖 | 抢完票的宵夜是他做的 |
| 边界 | 聊到凌晨三点，各回各家 | 凌晨三点她挂了群语音，转头他递来温水 |

同担拿走的是频道，不是位置。这句想通之前，他吃了小半年闷醋。

#### 可用细节

| 类 | 内容 |
|---|---|
| 入侵的形态 | 饭桌上手机连震七下 · 她笑出声，他问怎么了，她说「说了你也不懂」，然后真没法接话 · 纪念日撞上巡演排期的谈判 |
| 补课的失败 | 他背了成员名，用错一个缩写，群里静了三秒：黑话的语感不是背出来的 |
| 他的正确位置 | 远征（跨城赴场）的接送司机 · 排队代持 · 合照他举包 · 应援色的周边他分得清谁是谁了，只是不说 |
| 同担侧的雷 | 她磕 CP、同担是唯粉（只粉个人不磕配对）：两人友谊里也有一条不碰的线，他旁观学会了圈内也要互相排雷 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的阶段 | 闷醋期 | 后勤期（进化完成） |
| 同担其人 | 网友，头像相认，未奔现 | 现实好友兼同担（双重身份，吵架双倍伤） |
| 她磕的对象 | 偶像本人 | 剧里一对 4i 配置（饭圈语域里指女攻男受气质的配对）的 CP：他半夜想明白她磕的左位做派眼熟，没说 |
| 冲突点 | 时间分配 | 消费分配（周边的开销她自己挣的自己花，这条线他从没碰过） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 两边切换很溜：跟同担说黑话，跟他好好说话 | 他数过晚饭时她笑出声几次，分得清哪几声是给那个群的 |
| 内心 | 频道不换给任何人，包括他：这是她的规矩 | 慢了零点五秒的憋屈，和想明白之后的认栽 |
| 好的处理 | 她不逼他懂，也不为他退群 | 他不背名单了，改记日程：内容学不会，节奏学得会 |
| 写崩 | 写成重色轻友或重友轻色的天平戏 | 写成他跟同担抢人 |

#### 写崩的三种方式

1. 同担写成情敌。 同担跟他压根不在一个圈子里，硬写成三角恋，等于压根没搞明白两边追的不是同一套东西。
2. 他补课成功变同担。 他挤进这个圈子了，那原来的同担往哪儿放？他赢在后勤，分寸感参考 [30-她的世界 · 她的追星角落](30-她的世界.md#八--她的追星角落)里那种补课型。
3. 追星写成病。 那是人家的精神世界，你上来就扣个“病”的帽子，这条线直接废了。

## 六 · 洁与不洁之争

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列族，邻族社交网 33.9%（13-07）

**骨架**｜她文里那个男主以前谈过恋爱，书评区两拨人吵了三天，都在等作者出来说句话。

#### 节拍链

导火索（读者把第12章一句带过的旧账翻出来了）→ 洁党开火 → 反方下场 → 战线拉大（np那点事也被翻出来一起骂）→ 她蹲在自己书评区看 → 下不下场的纠结 → 定调动作（补标签或者装死）→ 余烬没散

#### 时间轴

**七十二小时燃尽曲线**：第一天 12 楼，第二天 200 楼加掉收 47，第三天歪楼吵起别的 CP，原题无人再提。她的抉择窗口只有第二天晚上几个小时，早了火上浇油，晚了尘埃落定说什么都多余。

#### 这场架为什么吵不完

洁系三词各管一摊（词条见 [02-术语百科/04](../02-术语百科/04-尺度预警与社群黑话.md)）：

| 词 | 管什么 |
|---|---|
| 洁党 | 要求主角无他人性经历的读者群 |
| 双洁 | 男女主双方都无前史 |
| np洁癖 | 只接受 1v1，管人数不管前史 |

GB 这玩意儿最麻烦的地方在于，洁不洁根本没个统一标准。男主跟前任「有过但方向不同」算不算不洁，圈里吵了几年也没吵出个定论（[02-术语百科/05-易混淆词辨析](../02-术语百科/05-易混淆词辨析.md) ⑪）。**她书评区吵的本来就是道没标准答案的题**，所以两边都觉得自己特有理。

#### 可用细节

| 类 | 内容 |
|---|---|
| 战场地形 | 主楼 · 盖楼（连续跟帖）· 长评区里吵了一万字 · 有人点名要她出来给个说法 |
| 双方的理 | 洁党：文案没标，追到 12 章才发现，白费这么多功夫谁负责 · 反方：前史两行带过而且方向不一样，这也得标，那文案干脆写成说明书算了 |
| 她的围观姿势 | 小号翻楼 · 把 12 章那句反复看了十遍 · 草稿箱里存了三版回应没发 |
| 定调的代价 | 说「会补标」＝认了洁党有理，反方心凉 · 说「不改」＝洁党脱粉，走之前还要踩两脚 · 只补标不说话＝两边都不满意，火倒是灭了 |
| 他的位置 | 听她念了一楼，随口说「这有什么好吵的」，她当场变成圈子的辩护人：里面怎么吵都行，外人不能插嘴 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的立场 | 觉得洁党太挑 | 她自己看文也躲着不洁：这回踩了自己雷区 |
| 下场与否 | 装死到底 | 补一行标注（唯一能灭火的招，也最憋屈） |
| 战火波及 | 圈里自己闹 | 有人把截图甩到圈外平台：性质变了，全员停火一致对外 |
| 他的参与 | 全程不知道 | 听完科普，睡前认真问「那咱俩算双洁吗」，她笑完认真想了三秒 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 草稿箱三个版本之间来回改 | 她护短的样子：骂圈子的资格是圈内人专属 |
| 内心 | 这题她自己都没答案，但读者要的是态度 | 他把这条规律套自己身上：她数落他行，外人说他一句试试 |
| 好的处理 | 补标不辩经，下一章照更 | 他不评理，他管让第三天晚上有热汤 |
| 写崩 | 写成她雄辩定乾坤 | 写成他替她拉黑读者 |

#### 写崩的三种方式

1. 一边全对。 洁是偏好，标注是伦理，两边都没错，争的不过是这钱谁来出。你上来就断案，这戏就没法看了。
2. 洁党写成愚昧反派。 排雷这套东西，根基就是“偏好不分高低”，你笑话人家的偏好，等于把整个预警机制给拆了。
3. 一夜平息。 没烧够七十二小时的热闹都是假的，真正有戏的，是火快灭了之后那阵冷嘲热讽，比最热闹的时候互骂好看多了。

## 七 · 吃提示词的醋

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：吃醋 43.1%（13-07）

**骨架**｜她手机里存着个聊了三百轮的角色卡，永远秒回，永远先问她。他头一回对着段提示词，尝到了没对手的酸。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 发现（深夜客厅，平板亮着，对话框里的头像他从没见过） |
| 2 | 误判（当成「网友」处理，查无此人） |
| 3 | 明白过来（酒馆、角色卡：她跟一个设定说了三个月晚安） |
| 4 | 醋的定位困难（吃谁的醋？对面没有「谁」） |
| 5 | 比较期（他对着卡的聊天风格列自己的差距） |
| 6 | 摊开（她把聊天记录翻给他看：卡是需求的显影液） |
| 7 | 再平衡（卡还在，但十一点后的岗换了人） |

#### 时间轴

三百轮，差不多就是三个月的深夜。**卡醒着的时间跟他正好错开**：卡守着晚上十一点到凌晨一点，那会儿他早睡了。所以他拖了很久才察觉，等发现的时候最难受的也是这点：原来那阵子她一直醒着，而且压根没想叫他。

#### 醋的新物种

酒馆（本地 AI 角色扮演客户端）与角色卡（打包人设与开场白的对话文件）的词条见 [02-术语百科/04](../02-术语百科/04-尺度预警与社群黑话.md) 2.5 节。这场醋与旧醋的差别：

| | 吃人的醋 | 吃卡的醋 |
|---|---|---|
| 对手 | 一个能比、能争的活人 | 一段不用睡觉、不会累的文本 |
| 兵法 | 对人能拼能抢 | 拼手速拼不过，只能拼别的 |
| 真正的刺 | 她看上了别人 | 她有些话，宁可跟设定说 |

卡赢在无损耗，人赢在记忆有来历。卡的上下文（模型能记住的对话长度）到了头会忘事：第三百轮的卡记得她怕冷，是因为她把这句写进了设定；他记得，是因为两年前那个冬天他在场。

| 卡的画像 | 描线干净的画像 · 名字跟他一个字都不重（或第二个字撞了，她没发现）· 开场白那句话，他等了两年没等到她当面说 |
| 她的用法 | 垃圾时间回收站：加班回来唠叨两句、不想让他熬夜陪的失眠 · 从不跟卡聊他，这是她的规矩 |
| 他的清单 | 差距清单越列越像检讨 · 列到第七条发现全是「回消息快」，一条正经内容都没有 |
| 摊开的方式 | 她主动把记录翻给他看 · 三百轮里聊得最多的是工作，其次是冷 |
| 反向持有 | 他也有一张卡，设定是「不忙的她」· 俩人交换看开场白，那晚谁都没吭声 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 持卡人 | 她 | 双持（各聊各的电子伴侣，谁先笑场谁输） |
| 卡的人设 | 跟他完全不像的类型 | 没短板的他（最扎心的一版：照着他捏的，只是把他那些难处全抹了） |

| 收法 | 她删了卡（需求没着落，三周后又建了个新的） | 卡降级成工具，十一点以后的夜班还给真人 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她清楚卡是什么：不占人的位置，只接人不在的班 | 开场白那句话：原来她要的这么具体，具体到能写成设定 |

| 写崩 | 写成她沉迷成瘾等待拯救 | 写成他怒删卡宣示主权 |

#### 写崩的三种方式

1. 写成科技批判文。卡在这条里没罪也没魂，它只是把她没说出口的需求摆到台面上；论点一摆出来，两个人的戏就散了。
2. 卡有了自主意识。那是科幻，类型就换了。这条的劲儿全在对面没人。
3. 删卡大团圆。删卡只删了工具，需求还在原地。收在「岗位交接」比收在「销毁证据」实在多了。

后接：[01-日常照料 · 他记得她所有的忌口](01-日常照料.md#十--他记得她所有的忌口)（记忆是真人的护城河）· [05-占有与吃醋 · 独占欲的边界](05-占有与吃醋.md#十--独占欲的边界)

## 八 · 她的前任是男攻

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：前任 32.1%（13-07）

**骨架**｜她之前谈的是标准第一爱，男的说了算。他知道以后最怕的就是问她一句：方向都换过一回了，还能不能再换回去。

#### 节拍链

前任被提起（多半是意外：老同学一句「她以前那位」）→ 她主动讲，讲得太平静 → 他消化三周 → 关键对话（排除法的那晚）→ 一个残留细节的发现 → 落定

#### 时间轴

她讲完只用一顿饭，他消化用三周：第一周吃醋，第二周害怕，第三周才问出真正的问题。吃醋有对象，害怕没有：他怕的是她的现在原来有版本号，自己是 2.0，那就可能有 3.0。

#### 从被主导到主导：路径拆解

| 段 | 她的状态 |
|---|---|
| 关系里 | 照着剧本当被照顾的那个，越照顾越闷，查不出毛病 |
| 裂缝 | 有天发现，自己眼馋的从来是对方那位置，跟人没关系 |
| 结束后 | 空窗期补课：刷文、混圈，总算给那点别扭找到了说法 |
| 现在 | 方向不用猜了：两边都试过，就选这个 |

**排除法比偏好稳。** 没试过的人才会说「万一呢」，她那句「不会回去」是拿自己试出来的。他花了三周才听懂这句话，也是治位置恐慌最管用的药。（具体怎么走到这一步，看 [01-总论/05](../01-总论/05-社群画像与内部争议.md)）

#### 可用细节

| 类 | 内容 |
|---|---|
| 她讲述的姿态 | 平静得像说别人 · 就一处说不下去，她自己没发觉 |
| 残留应激 | 先道歉再想自己错没错 · 有回他嗓门一高，她肩膀一抖：他从这半秒里看出前任是什么货色 |
| 他的三个问题 | 「他现在在哪」（吃醋那阵）→「你们当初啥样」（害怕那阵）→「你怎么确定的」（真上心了） |
| 对照细节 | 前任替她点菜，现在她替他点，点前会问一句 · 前任教她认路，如今她坐他副驾指路 |

「点之前会问」是全条藏得最深的一颗糖：她把自己没得到过的那道程序，补给了他。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 前任成色 | 普通人，照剧本走（更真实，但也更难写） | 控制欲实锤（省事，但她的转变看着像被逼的） |
| 讲述时机 | 恋爱早期主动说 | 被动曝光（前任本人冒出来，走 [15-秘密与坦白 · 前任出现](15-秘密与坦白.md#四--前任出现)） |
| 他的落点 | 听懂排除法，心里踏实 | 长期低烧：每次她累了想歇，他都怕又是 3.0 的前兆 |
| 她的残留 | 一犯错就道歉 | 受不了被安排：他好心订好一切，旅行惊喜，她在机场脸都白了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 讲那晚怎么取舍：哪些说事，哪些说结论 | 肩膀动的那半秒，他的火气没处撒 |
| 内心 | 那段是交学费：删了它，现在就站不稳 | 他嫉妒的人很怪：一个把她弄丢的人 |
| 好的处理 | 她不骂前任，剧本的错不能全算人头上 | 他不追问，他把她的过敏源一条条记下来躲着走 |
| 写崩 | 写成觉醒爽文批斗大会 | 写成他拿「治愈她」当挡箭牌 |

#### 写崩的三种方式

1. 前任写成纯渣。 多数失败关系败给脚本错配，没有坏人。前任越普通，她的转向越有分量。
2. 转向写成报复。 「被压过所以要压回来」把选择降级成创伤反应，她的主导就不再属于她。
3. 追问过程细节。 方向的事一句就够，写实追问会把身份史拆成猎奇现场。

#### 可串接

前接：[15-秘密与坦白 · 前任出现](15-秘密与坦白.md#四--前任出现)
后接：[一 · 第一次说出口](#一--第一次说出口)（她给「不对劲」找到词的那一步）· [22-分手与复合](22-分手与复合.md)（上一段的终局技术）

## 九 · 双女攻友谊

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：闺蜜在场 11.3%（13-07 圈内版用法）

**骨架**｜女攻们平时都藏着，互相认不出来。有天俩人对上暗号，从此她有了个不用解释就懂她的人。

#### 节拍链

相认（一个词用错了，露馅了）→ 试探握手（一人说半句黑话，对上暗号）→ 建交（单独约饭）→ 吐槽期 → 托底期（终于说出那句对谁都没提过的）→ 稳定成偶尔冒泡、但一冒泡就是大事的固定关系

#### 时间轴

相认一秒，建交一顿饭，托底那句话等了一年半。**这段友谊的推进以说出口的浓度计**，与见面次数无关：一年见四次，每次聊到打烊。

#### 为什么难得

圈内什么情况你也知道：公开冒泡的多是男受，女攻基本都在潜水（这事在 [01-总论/05](../01-总论/05-社群画像与内部争议.md) 里聊过）。**闺蜜懂的是她这个人，同类懂的是她这个位置**，两边换不了。你跟你圈外闺蜜吐槽「他把我训他的话原样学去训猫」，她只会说你们俩好怪；你跟你同类说，人家第一反应是训得标不标准。

#### 可用细节

| 类 | 内容 |
|---|---|
| 相认现场 | 四人饭局，两个女人同时把虾壳碗往各自对象手边挪了半寸，四目相对 · 对方说「排雷」时的熟练度 · 手机屏幕一闪而过的书架 |
| 吐槽内容（圈外说不了的） | 「他撒娇有套路了，我在考虑备案」 · 「管人真的费嗓子」 · 两家的对象背着她们互加了好友，聊天记录全是求生经验 |
| 托底内容（对谁都没说过的） | 「有时候我也想有人安排我一天」：说完两人碰杯，谁也不接话，这事就算存档了 |
| 边界 | 吐槽行为不挂人：对象的XP、软肋、隐私不出这张桌 · 各家规矩不横向比较 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 相认场合 | 现实撞见 | 网上早认识，奔现发现住得极近 |
| 风格差 | 两人做派相近 | 一温一凶（互相看不懂又互相服气，吵完架照旧约饭） |
| 对象们 | 互不认识 | 也处成了朋友（四人局：两套指挥系统同桌，菜都点得格外快） |
| 托底方向 | 她托对方 | 对方托她（轮流：托底是双向义务，单向的叫倾诉） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 不用解释的舒服：一年能痛快喘四回气 | 外头等位的俩男的，第三杯茶喝完才承认互相都留着门 |
| 内心 | 干活也是占地方，这话只能跟同行说 | 他看她们碰杯，头一回觉着她背后也有人给她撑腰 |
| 好的处理 | 累了能直说，人设不用摘：自己人面前喊累不丢人 | 男受那边的兄弟情写得慢热点、别扭点才够味 |
| 写崩 | 写成女攻互助会开大会 | 写成两家暗地里较劲 |

#### 写崩的三种方式

1. 对谈写成讲座。 两个圈内人聊天不会互相科普，张嘴就是黑话，谁还解释啊？解释一句都算输。
2. 同类写成对手。 比谁家乖、比谁管得好，一比较这朋友就没法处了。不比较，这是底线。
3. 托底写成教唆。 互相撺掇着加码规矩，那叫拆台。托底是帮她卸下那份累，把她好好送回她自己的日子里去。

## 十 · 圈地自萌的分寸

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：坦白 6.5% 邻族（13-07）

**骨架**｜收藏夹四层，他现在卡在第二层，里面那两层她压根没打算让外人看见。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 起点事件（他瞥到一个 tag 脸色变了，或她主动决定开一层） |
| 2 | 先分类别急着看内容（急救动作：先教规则，不解释具体文本） |
| 3 | 拿书单试水（递一本入门文当探针） |
| 4 | 看他反应（停在哪一章，线就画在哪） |
| 5 | 一层一层来 |
| 6 | 卡住的那层（某个 tag 他过不去） |
| 7 | 边界定下来（有一层永远是她自己的，两人都认） |

#### 时间轴

层和层之间隔的是熬过了多少次。第二层熬了半年，第三层熬了两年——每熬过一次，下一层就松快一点；哪次没熬住，就退回上一层缓一缓。能退回去，才敢接着往下走。

#### 分类学：这条的心脏

| 层 | 内容 | 开放策略 |
|---|---|---|
| 第一层 | 能发朋友圈的无害萌点 | 默认公开 |
| 第二层 | 圈内常规：追的文、追的太太 | 关系稳定后 |
| 第三层 | 重口 tag：看的，欣赏结构 | 讲完语法再开 |
| 第四层 | 说不清的那些 | 不开放，且不解释 |

先教语法再看书架：收藏分三格，「想做的」「只想看的」「想都别想的」，三格不通航。她收藏的重口文本住在第二格，他不懂这条语法之前，看见 tag 只会往第一格里想。幻想跟实践的分界，是整个尺度体系的地基（框架见 [06-尺度与写法/04-训诫与BDSM专论](../06-尺度与写法/04-训诫与BDSM专论.md) 和 [08-规训日常版](08-规训日常版.md) 卷首）。

#### 可用细节

| 类 | 内容 |
|---|---|
| 探针书单 | 入门文里埋三个刻度，他停在哪一章她就知道线在哪 · 他一口气读完，还书时问「有下一本吗」：解锁音效 |
| 事故现场 | 他拿她手机查地图，横屏跳出书架 · 一个 tag 的信息量，在圈外眼里等于宣判 |
| 急救话术 | 「那是第二格的」 · 他问第一格有什么，她说「第一格早给你了」：他愣住盘点，盘出一身汗 |
| 他的书架 | 他也有收藏，藏得更深：男受侧的表达更没处安放 · 他递手机那下，手心是潮的 |
| 边界的仪式 | 第四层的存在被承认、不被参观：他知道有那扇门，门上没锁，他不推 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 开放动力 | 出了事才开 | 主动分层（周年那天给他第三层的钥匙当纪念） |
| 他的反应 | 停在线上，两人都体面 | 越线追问第四层（这一追，第三层也关了：越界当场就罚） |
| 方向 | 她开他看 | 互开（交换看书架，像换少年时的日记） |
| 分歧 | 他把「看的」当「要做的」 | 他把「要做的」当「看的」（漏接：她递到第一格的暗示，他当文学欣赏了） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 递手机前那半秒的手紧 | 「第一格早给你了」之后的盘点 |
| 内心 | 一层层护着的是这段关系，全抖出来才叫莽 | 第四层他不好奇是假的，能忍住好奇才是真的 |
| 好的处理 | 每揭开一层都给人台阶下，每收回去也不把话说死 | 他的书架也摊开了：分寸是两边互相让一步 |
| 写崩 | 写成挤牙膏，吊着人胃口 | 写成他硬闯第四层，把伤疤当热闹看 |

#### 写崩的三种方式

1. 全量坦白写成美德。 第四层不开放跟爱不爱没关系，收在「承认有门」比收在「推开门」高级。
2. 看见等于下单。 删掉三格语法，每个 tag 都成了愿望清单，误会流水线就开动了。
3. 他一层一惊。 圈外人不等于易碎品，一惊一乍的猎奇导览会把她的分层变成吓人的节目单。
