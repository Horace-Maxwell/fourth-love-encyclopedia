## 这一族补的是什么

同人是语料世界背景标签的第三位：388 篇，6.8%（文案标签统计），排在现代都市与架空之后。词有整卷（[02-术语百科/04-尺度预警与社群黑话](../02-术语百科/04-尺度预警与社群黑话.md)），争议有整节（[01-总论/05-社群画像与内部争议](../01-总论/05-社群画像与内部争议.md)），平台有整卷（[08-平台生态](../08-平台生态/01-平台生态与发文指南.md)）。缺的是场面这一层：圈层身份怎么走进两个人的饭桌、深夜与书评区。

| 纪律 | 做法 |

## 一 · 第一次说出口

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：坦白 6.5%，公开 33.4%（13-07）

**骨架**｜「我是四爱」四个字只要一秒。对谁说、用哪个词、在哪说，是三道各自独立的选择题。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 决定说（导火索通常很小：他又一次抢着拎了所有袋子） |
| 2 | 选人（对象、闺蜜、圈外老友，风险各不同） |
| 3 | 选词（「四爱」「我比较主动」「你看过这类文吗」，三个词三条路） |
| 4 | 选场（车里、并排走路、消息框，共同点是不用对视） |
| 5 | 说出口，然后是对方的三秒 |
| 6 | 当晚他的搜索记录 |
| 7 | 第二天的一句话（真正的答复在这里，不在当场） |

#### 时间轴

铺垫三周，说出口一秒，等答复一夜。**当场的反应不算数**：那三秒里人只来得及调动礼貌。真反应在对方消化一晚之后，从第二天那句话的措辞里读。

#### 风险分层

| 说给谁 | 风险 | 能换到什么 |
|---|---|---|
| 对象 | 最高：关系当场变质或升级 | 一段不用再演的关系 |
| 闺蜜 | 中：友谊多半无恙，但从此多一双观察的眼睛 | 一个能说全话的人 |
| 圈外老友 | 中低：多半换来一句「哦这样啊」，词没进脑子 | 演习一遍的胆量 |
| 同事亲戚 | 高：扩散不可控，收益为零 | 基本无人这么选；对圈外世界的版本走 [14-社交与公开 · 议论](14-社交与公开.md#二--议论) |

#### 可用细节

| 类 | 内容 |
|---|---|
| 选词学 | 「四爱」精确但要解释半小时 · 「我喜欢主动一点」安全但会被听窄 · 「有个词叫女攻」把定义权交给搜索引擎 |
| 场地 | 副驾驶（红灯时说，绿灯解围）· 并排散步 · 打字打了删删了打 |
| 对方的三秒 | 手里的动作停了半拍 · 「嗯」得太快 · 反问的第一个字 |
| 他的当晚 | 搜索记录从词条页一路点进贴吧 · 凌晨两点还亮着的屏 |
| 第二天那句话 | 「早上想喝什么」照旧＝接住了 · 「我查了一下」＝他做了功课 · 绕开话题＝没接住，别追 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先说 | 她说，赌注是关系 | 他说，赌注是可信度：男方自称四爱，先被当成来占便宜的（圈内称「骗炮男」，人群结构见 [01-总论/05](../01-总论/05-社群画像与内部争议.md)），他的证明材料只有时间 |
| 词的精度 | 直接给词 | 先递一本文当探针（接 [十 · 圈地自萌的分寸](#十--圈地自萌的分寸)） |
| 对方底色 | 全然圈外 | 早有耳闻（他中学同桌就在贴吧潜水） |
| 结果 | 接住了 | 没接住但关系没散：这个词从此悬在两人之间，隔几个月碰一次 |

「他说」那一端的不对称是这条最深的地方：她说出口赌的是被拒绝，他说出口赌的是被怀疑。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 说出口前三周的措辞打磨 | 听懂那个词的瞬间：原来有个词，原来不止他一个 |
| 内心 | 说完就后悔了顺序：应该先给他看文的 | 不敢问第二句，怕问错暴露自己搜过 |
| 好的处理 | 说完不补救、不降级、不打岔，等 | 他的接法是第二天照常，外加一个多出来的动作 |
| 写崩 | 写成声泪俱下的宣言现场 | 写成他秒懂并当场表态 |

#### 写崩的三种方式

1. 对方秒懂。 没进过圈的人听到生词的正常反应是懵，秒懂型对象是安慰剂，不是人物。
2. 当场定生死。 真反应在第二天，当场摊牌等于把一夜的戏挤掉了。
3. 借她的嘴科普。 她解释这个词超过五句，场面就变成了讲座。

## 二 · 她是太太

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：掉马 32.8%（13-07），同人背景 6.8%（文案标签统计）

**骨架**｜他随手点开一本网文，男主角的小习惯是他自己的。作者笔名他不认识，更新时间他认识：她台灯熄灭之后的四十分钟。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 入坑（算法推的、群友安利的，与她无关的路径） |
| 2 | 第一层认出：男主角眼熟（一个只有同住者才知道的小动作） |
| 3 | 第二层认出：更新时间与她的作息严丝合缝 |
| 4 | 证实（他不敢问，他去翻作者的历史文与作者的话） |
| 5 | 追更期：他成了自己故事的读者 |
| 6 | 憋不住的那次（留长评、照着文里做、说破，三条路） |
| 7 | 她知道他知道（或永远不知道） |

#### 时间轴

认出用一晚，证实用三天，装不知道装了四个月。**追更是有周期的煎熬**：每周三、周日两更，他的一周从此有了两个锚点。断更那周他坐立不安，忍不住问了句「最近累不累」，她愣了一下：这话平时是她问的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 认出的证据 | 递杯子先转杯柄的习惯 · 只有他说过的一句话原样出现 · 文里那道疤的位置 · 男主的忌口与他一致 |
| 时间的证据 | 更新在她「睡后」四十分钟 · 出差那周停更 · 吵架那周的男主格外乖 |
| 太太的另一面 | 评论区的她比饭桌上的她话多 · 读者喊「太太」（对创作者的尊称）她答得熟练 · 作者的话里的自嘲，他从没听她当面说过 |
| 文与现实的落差 | 文里的他会撒娇，现实的他不敢 · 文里进展到的地方，现实还没到 |
| 他的追更装备 | 单独一个阅读 app · 通知全关 · 书架上这本没有备注名 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 文里的他 | 被写高了（更帅更敢） | 被写得更被疼：文里的男主被允许喊累，他读到那章在楼道里坐了十分钟 |
| 他的处理 | 永远装没看过 | 照着文里做（她笔下男主做过的事一件件出现在现实里，先起疑的是她） |
| 说破方式 | 长评（用词露馅，被她认出来） | 不说破，把文里的一个场景原样布置在现实里，等她自己撞见 |
| 她的反应 | 封笔三个月 | 下一章换男主视角，全网只有一个读者读得懂那是回信 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 被最不该看到的读者看到了：文是她存放「还没敢做」的地方 | 那些他不敢开口要的，她原来都惦记着，只是写给了纸上那个他 |
| 内心 | 写的时候没打算给他看，但每一章都是照着他写的 | 吃醋对象是纸上的自己：那个版本更勇敢 |
| 好的处理 | 掉马后她不删文不解释，把下一更写成回答 | 他不揭穿，他把文里的场景一件件过成现实 |
| 写崩 | 写成她羞愤删号 | 写成他拿文调笑或要挟 |

#### 写崩的三种方式

1. 把文当罪证。 文是她的愿望存放处，用它审判她，等于审判她的心事。
2. 掉马当场对质。 「原来你写的是我」一出口，两人都没有退路；装不知道的四个月才是戏。
3. 文的内容写太细。 文中文越多读者越出戏，点到证据即可，文里的世界留白。

后接：[15-秘密与坦白 · 掉马](15-秘密与坦白.md#二--掉马) · [三 · 排雷帖上有她](#三--排雷帖上有她)

## 三 · 排雷帖上有她

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列族，邻族社交网 33.9%（13-07）

**骨架**｜她的文进了排雷帖。指控带截图，截图没头没尾，楼越盖越高，而她今晚还有一更。

#### 节拍链

圈内群甩来链接 → 她读了三遍（第一遍找错处，第二遍找截图出处，第三遍看楼里都有谁）→ 后台掉收出现拐点 → 回应四选一 → 执行 → 数据止跌或没止 → 他察觉她不对

#### 时间轴

**舆情的一天有固定的钟**：上午被同好告知，中午楼层过百，下午掉收（收藏数下降）出现拐点，晚上决定回不回应。第二天热度腰斩，第三天有人歪楼吵起别的，原帖没人再提。烧满一轮七十二小时，但当事人过的是逐楼刷新的时间。

#### 被挂的高发罪名

「被挂」＝被公开发帖点名。GB 圈的指控自有一套（预警文化见 [02-术语百科/04](../02-术语百科/04-尺度预警与社群黑话.md)）：

| 指控 | 内情 |
|---|---|
| 「标了无反攻，第 40 章疑似反攻」 | 多半是姿势被误读成方向：谁在上不等于谁是攻 |
| 「精神四爱诈骗」 | 前三十章没写到身体层，严格派读者按定义判了 |
| 「男主不洁没预警」 | 男主有段前史，双洁党炸了（接 [六 · 洁与不洁之争](#六--洁与不洁之争)） |
| 「np 没标」 | 男二的戏份过了某条看不见的线 |

排雷（主动列出作品雷点）本身是圈内伦理，发帖人多半真踩过雷。指控可以不成立，痛可以是真的，两边同时成立。

#### 可用细节

| 类 | 内容 |
|---|---|
| 数据的体温计 | 掉收集中在被挂后六小时 · 新增长评全在吵架 · 收藏数她五分钟看一次 |
| 回应四选一 | 下场解释（几乎必输）· 文案补一行标注（最有效，最不解气）· 沉默 · 锁文（等于认输离场） |
| 她的动作 | 八百字回应打完全删 · 把争议章重读一遍，发现真的能那么读 · 最后只改了文案 |
| 他在场时 | 她刷手机的频率变了 · 饭吃一半去回消息 · 夜里两点屏幕还亮 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 指控成色 | 冤枉（截图断章） | 有几分道理（她重读后自己也咯噔了一下） |
| 他知不知道她写文 | 知道，他是唯一知道笔名的人 | 不知道，她只能说「工作上的事」 |
| 他的动作 | 要注册小号替她吵，被按住 | 给她做了顿饭，问都没问 |
| 结局 | 补标之后火熄了 | 她从此多了一道自我审查，半年后才松回来 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 指尖悬在回复框上的那半分钟 | 他帮不上的地方：那个战场他连门都找不到 |
| 内心 | 骂她文的人里，有几个昨天还在催更 | 她安慰读者比安慰自己熟练 |
| 好的处理 | 补了标注，不道歉也不反击，第二天照常更新 | 他不问细节，只把水杯续满：陪伴是圈外人唯一合法的参战方式 |
| 写崩 | 写成她下场舌战群儒大获全胜 | 写成他冲进评论区替她开团 |

#### 写崩的三种方式

1. 排雷帖写成反派据点。 发帖人是被雷过的读者，她自己找文时也看排雷帖，工具没有立场。
2. 下场必胜。 作者下场的胜率低到圈内有共识：补标是灭火器，雄辩是助燃剂。
3. 数据不掉。 没有掉收的被挂只是热闹，代价要落在她五分钟一看的那个数字上。

## 四 · 奔现

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：初见 39.9% 邻族（13-07），要联系族微信提升度 1.7×

**骨架**｜网上认识八个月，今天见真人。从头像到人，从打字到声音，中间隔着一顿谁买单没谈拢的饭。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 约定（谁先提的，提完两人各自后悔了半天） |
| 2 | 安全流程（白天、商场、行程报备闺蜜：圈内标准动作，双方各做各的） |
| 3 | 认人（先认出的多半是动作或声音，与照片无关） |
| 4 | 前四十分钟的尬，与破冰点 |
| 5 | 买单（这一拍是考题） |
| 6 | 散场方式（送不送、下顿约不约） |
| 7 | 到家报平安，语气回到网上那个频道 |

#### 时间轴

聊了八个月，见面两小时。**线上的熟与线下的生各算各的**：开场十分钟两人像初识，第四十分钟某个网上的旧梗被用声音说出来，八个月才接进线下。散场后消息框秒回如常，仿佛下午那两小时是别人替他们去的。

#### 买单的三岔口

第一顿饭的账单是圈内金钱议题的具体化（结构见 [01-总论/05](../01-总论/05-社群画像与内部争议.md)金钱议题一节）：

| 走法 | 读出的意思 | 后患 |
|---|---|---|
| 她全付 | 攻方姿态，也是「软饭男」剧本的标准开场 | 她心里存疑：他让得太顺了 |
| 他抢付 | 传统脚本抢跑 | 她皱眉：这套路数网上说好不演的 |
| AA | 表面公平 | 谁也没表态，题留到下顿 |

写法上最好用的收束：各扫各的码，随后她把他那杯奶茶的钱转回去，备注「下顿你请」。**账没平，关系才有下一顿。**

#### 可用细节

| 类 | 内容 |
|---|---|
| 认人 | 头像是猫 · 真人比语音里高半头 · 认出对方靠回消息的手速与坐姿 |
| 各自的怕 | 她怕照骗与见光死，更怕对面根本没打算好好谈 · 他怕被当猎奇标本，也怕对面要的只是个能摆布的人 |
| 安全动作 | 她把定位发给闺蜜 · 他主动把桌号拍过去：「给你朋友报个坐标」 · 双方都懂这些动作，谁都不觉得被冒犯 |
| 破冰点 | 网上的旧梗第一次有了声音 · 对方笑起来和想象的不一样，更好 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 认识场景 | 同好群 | 她文的评论区（他是三年老读者，信息差巨大，接 [二 · 她是太太](#二--她是太太)的反向） |
| 见面成色 | 网上什么样线下什么样 | 判若两人（好的方向：打字冷淡的人，真人耳朵会红） |
| 买单 | 三岔口任一 | 他提前去洗手间把单买了：传统脚本的肌肉记忆，饭后两人为这个笑着吵了一路 |
| 之后 | 有下顿 | 没有下顿，网上照聊：默契不提，关系退回文字并停在那里 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 见面前一晚翻完两人全部聊天记录 | 进门扫一圈就认出她，和头像毫无关系，就是知道 |
| 内心 | 网上聊得再深，仍要从「他吃饭什么样」重新验一遍 | 她真人比字温和，他反而更紧张 |
| 好的处理 | 她把考题摆在明处：转账备注写「下顿你请」 | 他接住了：三天后发来一家店的定位 |
| 写崩 | 写成她面试审犯人 | 写成见光死的外貌审判现场 |

#### 写崩的三种方式

1. 删掉买单戏。 这顿饭唯一的情节就是账单，删了它只剩吃饭。
2. 安全流程写成互不信任。 报备与桌号是圈内共识动作，双方都做才对；写成单方防贼，人设就歪了。
3. 一顿饭定终身。 奔现的正确终点是「有下顿」，牵手回家是另一个类型的节奏。

## 五 · 同担与同好

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：吃醋 43.1%，闺蜜在场 11.3%（13-07）

**骨架**｜同担（追同一个偶像的同伴）秒懂她的那个频道，他进不去。他吃的是那零点五秒反应速度的醋，跟偶像本人没关系。

#### 节拍链

同担的存在感入侵日常（饭桌上群消息连震）→ 他试图理解 → 补课失败 → 醋找到定位（对象是频道，人无辜）→ 分工成形（同担拿频道，他拿位置）→ 一次联动（她们的远征他当后勤）

#### 时间轴

以偶像的日程表为钟：官宣日、开票日、巡演周。**她的情绪波形跟着那张日程表走**，他学会看那张表之后，很多「莫名其妙」提前三天就能预报。

#### 同担与他：两套供给

| | 同担给的 | 他给的 |
|---|---|---|
| 响应速度 | 零点五秒接梗 | 慢半拍，还要问「这是新出的吗」 |
| 内容 | 同一个频道的共振 | 频道外的全部生活 |
| 强度 | 开票那晚人均手抖 | 抢完票的宵夜是他做的 |
| 边界 | 聊到凌晨三点，各回各家 | 凌晨三点她挂了群语音，转头他递来温水 |

同担拿走的是频道，不是位置。这句想通之前，他吃了小半年闷醋。

#### 可用细节

| 类 | 内容 |
|---|---|
| 入侵的形态 | 饭桌上手机连震七下 · 她笑出声，他问怎么了，她说「说了你也不懂」，然后真的没法解释 · 纪念日撞上巡演场次的排期谈判 |
| 补课的失败 | 他背了成员名，用错一个缩写，群里静了三秒：黑话的语感背不来 |
| 他的正确位置 | 远征（跨城赴场）的接送司机 · 排队代持 · 合照他举包 · 应援色的周边他分得清谁是谁了，只是不说 |
| 同担侧的雷 | 她磕 CP、同担是唯粉（只粉个人不磕配对）：两人友谊里也有一条不碰的线，他旁观学会了圈内也要互相排雷 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的阶段 | 闷醋期 | 后勤期（进化完成） |
| 同担其人 | 网友，头像相认，未奔现 | 现实好友兼同担（双重身份，吵架双倍伤） |
| 她磕的对象 | 偶像本人 | 剧里一对 4i 配置（饭圈语域里指女攻男受气质的配对）的 CP：他半夜想明白她磕的左位做派眼熟，没说 |
| 冲突点 | 时间分配 | 消费分配（周边的开销她自己挣的自己花，这条线他从没碰过） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 两边切频道的自如：对同担用缩写，对他用全称 | 他数过晚饭时她笑出声的次数，分得出哪几声属于那个群 |
| 内心 | 频道不换给任何人，包括他：这是她的规矩 | 输给零点五秒的挫败，和想通之后的服气 |
| 好的处理 | 她不逼他懂，也不为他退群 | 他从背名单改成记日程：懂内容学不会，懂节奏学得会 |
| 写崩 | 写成重色轻友或重友轻色的天平戏 | 写成他与同担争宠 |

#### 写崩的三种方式

1. 同担写成情敌。 同担与他不在一个赛道，写成三角恋等于没看懂两套供给。
2. 他补课成功变同担。 他挤进频道，同担放哪？他的胜利姿势是后勤，分寸见 [30-她的世界 · 她的追星角落](30-她的世界.md#八--她的追星角落)的补课型。
3. 追星写成病。 那是她的频道，治病叙事一出，这条直接报废。

## 六 · 洁与不洁之争

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：未单列族，邻族社交网 33.9%（13-07）

**骨架**｜她文里的男主有段前史。双洁党与不洁党在书评区开战，烧到第三天，两边都在等作者一句话。

#### 节拍链

导火索（读者扒出第 12 章一句带过的前史）→ 洁党发难 → 反方下场 → 战线扩大（np 疑云被翻出来连坐）→ 她围观自家书评区 → 下不下场的抉择 → 定调动作（补标或沉默）→ 余烬

#### 时间轴

**七十二小时燃尽曲线**：第一天 12 楼，第二天 200 楼加掉收 47，第三天歪楼吵起别的 CP，原题无人再提。她的抉择窗口只有第二天晚上几个小时，早了火上浇油，晚了尘埃落定说什么都多余。

#### 这场架为什么吵不完

洁系三词各管一摊（词条见 [02-术语百科/04](../02-术语百科/04-尺度预警与社群黑话.md)）：

| 词 | 管什么 |
|---|---|
| 洁党 | 要求主角无他人性经历的读者群 |
| 双洁 | 男女主双方都无前史 |
| np洁癖 | 只接受 1v1，管人数不管前史 |

GB 的特殊处在于洁的判定基准本就没有共识：男主与前任「有过但方向不同」算不算不洁，圈内无定论（[02-术语百科/05-易混淆词辨析](../02-术语百科/05-易混淆词辨析.md) ⑪）。**她书评区吵的正是一道圈内没有标准答案的题**，两边因此都振振有词。

#### 可用细节

| 类 | 内容 |
|---|---|
| 战场地形 | 主楼 · 盖楼（连续跟帖）· 长评区的万字论战 · 有人点名她出来给说法 |
| 双方的理 | 洁党：文案没标，追到 12 章才发现，时间成本谁赔 · 反方：前史两行带过且方向不同，这也要标，文案要比正文长了 |
| 她的围观姿势 | 小号翻楼 · 把 12 章那句读了十遍 · 草稿箱存了三版回应 |
| 定调的代价 | 说「会补标」＝认洁党有理，反方寒心 · 说「不改」＝洁党脱粉，走时还要踩两脚 · 只补标不说话＝两边各扣一半分，火熄 |
| 他的位置 | 听她念了一楼，随口说「这有什么好吵的」，她当场变成圈子的辩护人：对内吵归吵，外人不许说 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的立场 | 觉得洁党苛刻 | 她自己看文也避不洁：这次站到了自己雷点的对面 |
| 下场与否 | 沉默到底 | 补一行标注（唯一能灭火的动作，也最不解气） |
| 战火波及 | 圈内自理 | 有人把战场截图发到圈外平台：性质陡变，全员息战一致对外 |
| 他的参与 | 全程不知情 | 听完科普，睡前认真问「那咱们算双洁吗」，她笑完认真想了三秒 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 草稿箱三个版本之间的斟酌 | 她护短的样子：骂圈子的资格是圈内人专属 |
| 内心 | 这题她自己都没有答案，但读者要的是态度 | 他把这条规律迁移到自己身上：她数落他行，外人说他一句试试 |
| 好的处理 | 补标不辩经，下一章照更 | 他不评理，他负责让第三天晚上有热汤 |
| 写崩 | 写成她雄辩定乾坤 | 写成他替她拉黑读者 |

#### 写崩的三种方式

1. 一边全对。 洁是偏好，标注是伦理，两者都对，冲突只在成本落谁头上。裁判腔一出，戏就死了。
2. 洁党写成愚昧反派。 排雷文化立足于偏好无高下，嘲笑偏好等于拆掉整个预警体系。
3. 一夜平息。 没烧满七十二小时的舆情不真实，余烬期的冷嘲比高峰期的对轰更有戏。

## 七 · 吃提示词的醋

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：吃醋 43.1%（13-07）

**骨架**｜她手机里有个聊了三百轮的角色卡。那张卡永远不累、永远秒回、永远记得先问她。他对着一段提示词，第一次尝到没有对手的醋。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 发现（深夜客厅，平板亮着，对话框里的头像他不认识） |
| 2 | 误判（按「网友」处理，查无此人） |
| 3 | 明白过来（酒馆、角色卡：她跟一个设定说了三个月晚安） |
| 4 | 醋的定位困难（吃谁的醋？对面没有「谁」） |
| 5 | 比较期（他对着卡的聊天风格列自己的差距） |
| 6 | 摊开（她把聊天记录翻给他看：卡是需求的显影液） |
| 7 | 再平衡（卡还在，但十一点后的岗换了人） |

#### 时间轴

三百轮，约等于三个月的深夜。**卡的时间与他的时间错峰**：卡值守二十三点到一点，他睡着的那一段。所以他很久才发现，发现后最扎的也是这一点：原来那段时间她醒着，且没打算叫醒他。

#### 醋的新物种

酒馆（本地 AI 角色扮演客户端）与角色卡（打包人设与开场白的对话文件）的词条见 [02-术语百科/04](../02-术语百科/04-尺度预警与社群黑话.md) 2.5 节。这场醋与旧醋的差别：

| | 吃人的醋 | 吃卡的醋 |
|---|---|---|
| 对手 | 一个可以比较、可以竞争的人 | 一段没有睡眠、没有情绪成本的文本 |
| 兵法 | 对人可以雄竞 | 响应速度赢不了，只能赢别的 |
| 真正的刺 | 她看上了别人 | 她的某个需求，宁可说给设定听 |

卡赢在无损耗，人赢在记忆有来历。卡的上下文（模型能记住的对话长度）到了头会忘事：第三百轮的卡记得她怕冷，是因为她把这句写进了设定；他记得，是因为两年前那个冬天他在场。

#### 可用细节

| 类 | 内容 |
|---|---|
| 卡的画像 | 描线干净的画像 · 名字与他无一字重合（或第二个字撞了，她自己没发现）· 开场白里那句话，他等了两年没等到她当面说 |
| 她的用法 | 垃圾时间回收站：加班回来的碎碎念、不想让他熬夜陪的失眠 · 从不与卡聊他，这是她的分区 |
| 他的清单 | 差距清单越列越像检讨 · 列到第七条发现全是「响应速度」，一条内容都没有 |
| 摊开的方式 | 她主动把记录翻给他看 · 三百轮里出现最多的话题是工作，其次是冷 |
| 反向持有 | 他也有一张卡，设定是「不忙的她」· 两人交换看开场白，那晚谁都没说话 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 持卡人 | 她 | 双持（对坐各聊各的电子伴侣，先笑场的人输） |
| 卡的人设 | 与他无关的类型 | 无损耗版的他（最疼的一版：原型是他，减掉的全是他的难处） |
| 他的处理 | 闷头较劲 | 直接问「他哪句说到你了」，把卡当情报读 |
| 收法 | 她删了卡（需求悬空，三周后又建了新的） | 卡降级成工具，十一点后的岗还给真人 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她清楚卡是什么：不占人的位置，只接人不在的班 | 开场白那句话：原来她要的这么具体，具体到能写成设定 |
| 内心 | 被撞见时的心虚让她自己意外：明明只是个工具 | 跟一段文本抢功的荒谬感，和抢的时候的认真 |
| 好的处理 | 她不删卡表忠心，她把卡里的需求一条条搬回现实试 | 他不骂技术，他抄作业：卡会先问累不累，他学 |
| 写崩 | 写成她沉迷成瘾等待拯救 | 写成他怒删卡宣示主权 |

#### 写崩的三种方式

1. 写成科技批判文。 卡在这条里没有罪也没有魂，它只是把她没说出口的需求显影了；论点一上桌，两个人的戏就散了。
2. 卡有了自主意识。 那是科幻，类型就换了。这条的全部张力在于对面没有人。
3. 删卡大团圆。 删卡只删载体，需求还在原地。收在「岗位交接」比收在「销毁证据」诚实得多。

## 八 · 她的前任是男攻

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：前任 32.1%（13-07）

**骨架**｜她上一段是标准的第一爱（传统方向的异性恋），对方主导一切。他知道后最怕的问句只有一个：方向换过一次，会不会再换回去。

#### 节拍链

前任被提起（多半是意外：老同学一句「她以前那位」）→ 她主动讲，讲得太平静 → 他消化三周 → 关键对话（排除法的那晚）→ 一个残留细节的发现 → 落定

#### 时间轴

她讲完只用一顿饭，他消化用三周：第一周吃醋，第二周害怕，第三周才问出真正的问题。吃醋有对象，害怕没有：他怕的是她的现在原来有版本号，自己是 2.0，那就可能有 3.0。

#### 从被主导到主导：路径拆解

| 段 | 她的状态 |
|---|---|
| 关系里 | 按脚本当被照顾的一方，越照顾越憋闷，查不出病因 |
| 裂缝 | 某天发现自己羡慕的一直是对方的位置，与对方无关 |
| 结束后 | 空窗期补课：看文、进圈，给那点「不对劲」找到了词 |
| 现在 | 方向已然不靠猜：两个都试过，选了这个 |

**排除法比偏好稳。** 没试过的人才有「万一」，她的「不会回去」带着实验数据。这是他三周后终于听懂的一句，也是位置恐慌的标准解药（进入路径的结构见 [01-总论/05](../01-总论/05-社群画像与内部争议.md)）。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她讲述的姿态 | 平静得像讲别人 · 只有一处讲不平静，她自己没察觉 |
| 残留应激 | 先道歉再想有没有错的反射 · 某次他提高音量，她肩膀动了一下：他从这半秒里读完了前任是什么人 |
| 他的三个问题 | 「他现在在哪」（吃醋周）→「你们当时什么样」（害怕周）→「你怎么确定的」（真问题） |
| 对照细节 | 前任替她点菜，她现在替他点，点之前会问 · 前任教她认路，如今他坐她的副驾 |

「点之前会问」是全条藏得最深的一颗糖：她把自己没得到过的那道程序，补给了他。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 前任成色 | 普通人，照脚本行事（更真实，也更难写） | 控制欲实锤（省事，但把她的转向降级成了应激） |
| 讲述时机 | 恋爱早期主动交代 | 被动曝光（前任本人出现，走 [15-秘密与坦白 · 前任出现](15-秘密与坦白.md#四--前任出现)） |
| 他的落点 | 听懂排除法，落定 | 长期低烧：每次她累了想歇，他都疑心是 3.0 的前兆 |
| 她的残留 | 道歉反射 | 对「被安排」过敏：他好心订好一切的惊喜旅行，她在机场脸色发白 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 讲述那晚的取舍：哪些讲事实，哪些讲结论 | 肩膀动的那半秒，他的怒气找不到活人出口 |
| 内心 | 那段不是黑历史，是学费：删掉它就删掉了现在的坐标 | 他嫉妒的对象很怪：一个把她弄丢了的人 |
| 好的处理 | 她不控诉前任，脚本的错不全是人的错 | 他不追问，他把她的过敏源一条条记下来绕着走 |
| 写崩 | 写成觉醒爽文批斗大会 | 写成他以「治愈她」自居 |

#### 写崩的三种方式

1. 前任写成纯渣。 多数失败关系败给脚本错配，没有坏人。前任越普通，她的转向越有分量。
2. 转向写成报复。 「被压过所以要压回来」把选择降级成创伤反应，她的主导就不再属于她。
3. 追问过程细节。 方向的事一句就够，写实追问会把身份史拆成猎奇现场。

## 九 · 双女攻友谊

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：闺蜜在场 11.3%（13-07 圈内版用法）

**骨架**｜女攻在人堆里互相认不出来，因为都潜着。两个潜水员某天对上暗号，从此她有了一个不用翻译的人。

#### 节拍链

相认（一个词的用法露馅）→ 试探握手（各报一半黑话，确认频段）→ 建交（单独约饭）→ 吐槽期 → 托底期（说出那句对谁都没说过的）→ 稳定成低频高浓度的常线

#### 时间轴

相认一秒，建交一顿饭，托底那句话等了一年半。**这段友谊的推进以说出口的浓度计**，与见面次数无关：一年见四次，每次聊到打烊。

#### 为什么难得

圈内可见度的结构摆在那：公开场合活跃的多是男受侧，女攻大多潜水（可见性讨论见 [01-总论/05](../01-总论/05-社群画像与内部争议.md)）。**闺蜜懂她这个人，同类懂她这个位置**，两者不通换：圈外闺蜜听她吐槽「他把我训他的话原样学去训猫」只会说你们俩好怪，同类会问训得标不标准。

#### 可用细节

| 类 | 内容 |
|---|---|
| 相认现场 | 四人饭局，两个女人同时把虾壳碗往各自对象手边挪了半寸，四目相对 · 对方说「排雷」时的熟练度 · 手机屏幕一闪而过的书架 |
| 吐槽内容（圈外说不了的） | 「他撒娇有套路了，我在考虑备案」 · 「管人真的费嗓子」 · 两家的对象背着她们互加了好友，聊天记录全是求生经验 |
| 托底内容（对谁都没说过的） | 「有时候我也想有人安排我一天」：说完两人碰杯，谁也不接话，这事就算存档了 |
| 边界 | 吐槽行为不挂人：对象的 XP（性癖偏好）、软肋、隐私不出这张桌 · 各家规矩不横向比较 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 相认场合 | 现实撞见 | 网上早认识，奔现发现住得极近 |
| 风格差 | 两人做派相近 | 一温一凶（互相看不懂又互相服气，吵完架照旧约饭） |
| 对象们 | 互不认识 | 也处成了朋友（四人局：两套指挥系统同桌，菜都点得格外快） |
| 托底方向 | 她托对方 | 对方托她（轮流：托底是双向义务，单向的叫倾诉） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 不用翻译的松快：一年四次的深呼吸 | 外场等位的两个男人，第三杯茶之后才承认都会给对方留门 |
| 内心 | 位置也是劳动，这话只能对同行说 | 他看她们碰杯，第一次直观看到她身后也有人撑她 |
| 好的处理 | 疲劳可以说，人设不用摘：同类面前喊累不掉价 | 男受侧的镜像友谊写得更慢热、更羞怯才对味 |
| 写崩 | 写成女攻互助会公开课 | 写成两家暗中攀比 |

#### 写崩的三种方式

1. 对谈写成讲座。 两个圈内人不会互相科普，她们的对话全是省略：黑话密度顶格，解释密度为零。
2. 同类写成对手。 比谁家乖、比谁管得好，一比这段友谊就死了：不比较是它的地基。
3. 托底写成教唆。 互相怂恿升级规矩是拆台。托底的方向是替她卸下那份累，把她完整送回她自己的关系里。

## 十 · 圈地自萌的分寸

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：坦白 6.5% 邻族（13-07）

**骨架**｜圈地自萌（在圈内自娱、不推向圈外的自律）对外挡的是圈外人。对内呢？她的收藏夹分四层，他现在在第二层。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 起点事件（他瞥到一个 tag 脸色变了，或她主动决定开一层） |
| 2 | 分类学先行（急救动作：先教规则，不解释具体文本） |
| 3 | 书单测试（递一本入门文当探针） |
| 4 | 读他的反应（停在哪一章，线就画在哪） |
| 5 | 按层开放 |
| 6 | 卡住的一层（某个 tag 他过不去） |
| 7 | 边界落定（有一层永远是她自己的，两人都认） |

#### 时间轴

层与层之间隔的是兜住的次数，不是月份。第二层用了半年，第三层用了两年：每兜住一次，下一层就松一点；哪次没兜住，就退回上一层歇着。退得回去，才敢往下走。

#### 分类学：这条的心脏

| 层 | 内容 | 开放策略 |
|---|---|---|
| 第一层 | 能发朋友圈的无害萌点 | 默认公开 |
| 第二层 | 圈内常规：追的文、追的太太 | 关系稳定后 |
| 第三层 | 重口 tag：看的，欣赏结构 | 讲完语法再开 |
| 第四层 | 说不清的那些 | 不开放，且不解释 |

先教语法再看书架：收藏分「想做的」「只想看的」「想都别想的」三格，格与格不通航。她收藏的重口文本住在第二格，他不懂这条语法之前，看见 tag 只会往第一格里想。幻想与实践的分界是整个尺度体系的地基（框架见 [06-尺度与写法/04-训诫与BDSM专论](../06-尺度与写法/04-训诫与BDSM专论.md)与 [08-规训日常版](08-规训日常版.md)卷首）。

#### 可用细节

| 类 | 内容 |
|---|---|
| 探针书单 | 入门文里埋三个刻度，他停在哪一章她就知道线在哪 · 他一口气读完，还书时问「有下一本吗」：解锁音效 |
| 事故现场 | 他拿她手机查地图，横屏跳出书架 · 一个 tag 的信息量，在圈外眼里等于宣判 |
| 急救话术 | 「那是第二格的」 · 他问第一格有什么，她说「第一格早给你了」：他愣住盘点，盘出一身汗 |
| 他的书架 | 他也有收藏，藏得更深：男受侧的表达更没处安放 · 他递手机那下，手心是潮的 |
| 边界的仪式 | 第四层的存在被承认、不被参观：他知道有那扇门，门上没锁，他不推 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 开放动力 | 事故倒逼 | 主动分层（周年那天给他第三层的钥匙当纪念） |
| 他的反应 | 停在线上，两人都体面 | 越线追问第四层（这一追，第三层也关了：分寸的惩罚是即时的） |
| 方向 | 她开他看 | 互开（交换看书架，像交换少年时的日记） |
| 分歧 | 他把「看的」当「要做的」 | 他把「要做的」当「看的」（漏接：她递到第一格的暗示，被他当文学欣赏了） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 递手机前那半秒的手紧 | 「第一格早给你了」之后的盘点 |
| 内心 | 分层护的是这段关系，全倒出来才是鲁莽 | 第四层他不好奇是假的，忍住好奇是真的 |
| 好的处理 | 每层开放都有台阶，每次收回都有余地 | 他的书架也拿出来了：分寸是双向关税 |
| 写崩 | 写成挤牙膏式吊胃口 | 写成他闯第四层揭疮疤 |

#### 写崩的三种方式

1. 全量坦白写成美德。 第四层不开放与爱无关，收在「承认有门」比收在「推开门」高级。
2. 看见等于下单。 删掉三格语法，每个 tag 都成了愿望清单，误会流水线就开动了。
3. 他一层一惊。 圈外人不等于易碎品，一惊一乍的猎奇导览会把她的分层变成吓人的节目单。
