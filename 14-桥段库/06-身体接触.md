# 身体接触

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次出自[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，按 2,894 部独立作品统计。文中的百分比是编写时实测的，挖掘器扩充后节拍族会有小幅变动，数字以 13-07 当前的为准（`run.py mine` 重跑更新）
> 揉头、牵手、后颈、靠肩、膝枕、量身高、系扣子、被抱起来、睡姿，这些碰到身体的场面都归在这一族，第一次主动和第一次接吻也在里面。先伸手的人，要冒被拒绝的险。

---

## 谁先伸手

这一类的每次接触，都得先看清是谁伸的手、谁点的头。

| 组合 | 读作 |
|---|---|
| 她伸手，他接受 | 平常就这样，她做主他听 |
| 她伸手，他躲了一下 | 哪里不对，出事了 |
| 他伸手，她接住 | 他开口，她点头 |
| 他伸手，她没接 | [03-撒娇与讨哄 · 撒娇失败](03-撒娇与讨哄.md#十--撒娇失败) |
| 他伸手，她主动迎上 | 关系要变天了 |

「他伸手」这几种最难写。处在弱势的人先去碰对方，是要豁出去的。这份豁出去必须写到纸面上，读者才知道他冒了多大的险。

| 反应族 | 作品数 | 占比 |
|---|---:|---:|
| 拥抱 | 2,253 | 77.9% |
| 牵手 | 1,345 | 46.5% |

在所有反应族里，拥抱排第一，牵手只有它的一半。牵手要两个人同时愿意，所以比拥抱难写。

## 一 · 揉头

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：讨哄 68.5%

**骨架**｜最短的奖励，一秒钟，一句话都不用说。

#### 节拍链

他做对了事／难过了 → 她抬手 → 他不自觉低头 → 揉乱 → 把头发理回去

#### 时间轴

手上就一秒，心里热一整天。抬手、落下、揉乱、收回，四步分开写，别一句话带过去。他顶着这头乱发晃了一下午，谁提醒都不理。

#### 揉头的语义分层

同样是揉头，用多大劲、停多久，意思就全变了：

| 力度／时长 | 读作 |
|---|---|
| 快速拍两下 | 敷衍或调侃 |
| 揉乱 | 亲昵，带一点欺负 |
| 手停在头顶不动 | 郑重，几档里分量最重 |
| 顺着往下摸到后颈 | 一下亲近好几层 |
| 揉完把头发理回去 | 她顾着他的体面 |

「揉完把头发理回去」：揉乱是亲昵，再理整齐是尊重他。

#### 可用细节

| 类 | 内容 |
|---|---|
| 高度问题 | 他比她高，她要仰着头，或者他得低头，肯低头就看得出谁让着谁 |
| 他的配合 | 不知不觉就低了点头 · 这个习惯比什么话都顶用 |
| 场合 | 他办成了事 · 他难受 · 路过顺手 · 旁边有人他会愣一下 |
| 他的反应 | 眼睛眯一下 · 耳朵 ✓ 红 · 装没事接着干手里的活 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 私下 | 当众（他会僵） |
| 她的意图 | 奖励 | 安抚 |
| 高度处理 | 她踮脚 | 他低头 |
| 他的反应 | 享受 | 躲开（有事） |

放进古代女尊设定，「他低头」分量很重。个子高矮是天生的，低头却是他自己愿意配合。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他会自己低下头 | 她的手落下来的那一秒 |
| 好的处理 | 她揉完顺手把头发理平 | 他低了头，嘴上不认自己在等 |
| 写崩 | 写成摸宠物 | 写成幼儿化 |

别写成摸宠物。看他在这个动作里还留没留着自己的意志。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 抚发／替他正冠／指尖点在他额上 |
| 修仙 | 以灵力拂过他发顶／替他理正束发的簪 |
| 星际 | 隔着头盔的那一下／她摘了手套才摸 |

「她摘了手套才摸」：多摘这一次手套，就更郑重一层。

#### 写崩的三种方式

1. 写成宠物互动。 见上。
2. 每章都揉。 揉得太勤，就成了口头禅。
3. 不写他低头。 他下意识配合的那一下要留着。

## 二 · 牵手

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：牵手 46.5%

**骨架**｜牵手要两个人同时愿意，比抱一下难得多。

#### 节拍链

找借口（人多／天冷）→ 伸手 → 那一秒 → 她握紧一点作为回答 → 到路口谁都没松

#### 时间轴

借口早找好了，给自己打气却要好几分钟。人多的那段路一过就没机会了，他得赶在前面伸手。一直走到路口，这条路就算走完。路其实只有三百米，两个人走得像三站地那么长。

#### 牵法的语义

| 牵法 | 谁主导 | 读作 |
|---|---|---|
| 她握他手腕 ✓ | 她 | 带走人。劲最足，也最不像牵手 |
| 她握他手掌 | 她 | 常规 |
| 十指相扣 | 双方 | 平等，不容易松开 |
| 他勾她小指 | 他 | 试一试，她可以当作没察觉 |
| 他把手放进她口袋 ✓ | 他 | 求她收下他，也给她留了推开的余地 |
| 她把他的手塞进自己口袋 | 她 | 最黏糊的一种 |

「握手腕」和「握手掌」不一样，值得专门写一场。握手腕更像管着他，握手掌更像一起走。一个角色从握他的手腕变成握他的手，能拉成一条线慢慢写。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 口袋 ✓ · 手套 ✓ · 手腕 ✓ · 掌心 ✓ · 指尖 ✓ |
| 触发场合 | 过马路 · 人多 · 天冷 · 他心情不好 · 啥理由都不用找 |
| 松开的时机 | 谁先松手，谁心里有鬼 |
| 温度 | 他手凉／她手凉，谁把谁的手焐热 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先伸手 | 她 | 他（更难，也更重） |
| 借口 | 有（人多、天冷） | 没有 |
| 场合 | 私下 | 街上（他会紧张） |
| 松开 | 到了目的地自然松 | 谁都没松，走过了路口 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他的手在她掌心里动了一下 | 伸出去之前手心 ✓ 先出汗了 |
| 内心 | 他今天手好凉 | 她会不会甩开 |
| 好的处理 | 她稍微握紧一点，算是回答 | 他伸了手，连借口都没找 |
| 写崩 | 写成她不假思索 | 写成他扭捏很久 |

「她握紧了一点」最省笔墨。一句话不说，手上加点劲就是回答。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 隔着袖子拉手／她带他上马车／扶他那一把 |
| 修仙 | 踩剑时他搂她腰／她拽他迈过阵眼 |
| 星际 | 飘起来时互相抓手／同拴一根安全绳 |

#### 写崩的三种方式

1. 写得太随便。 牵手在这一类里分量重，想牵就牵，就不稀罕了。
2. 跳过犹豫。 他伸手前那一下要写。
3. 只写她主动。 难得的是他主动的那一版。

## 三 · 后颈

`T` ｜ 无预警 ｜ 全谱系（女A男O 尤强）｜ 语料频次：拥抱 77.9%

**骨架**｜她的手搭上他后颈，他一僵，自己把头低了下去。

#### 节拍链

她的手搭上去 → 他僵住 → 呼吸变了 → 拇指按一下 → 五指收拢 → 他自己低了头

#### 时间轴

手搭上去，第一拍他僵住，第二拍呼吸浅了，第三拍拇指按下去，第四拍五指收拢。拍和拍之间隔多久，由她定。想把烈度停在哪一档，就写到那一拍收手。这一段不看钟，只数呼吸。

#### 为什么是后颈

| 原因 | 说明 |
|---|---|
| 看不见 | 被碰的人防不了，只能信她 |
| 要低头才能被碰到 | 摆出这个姿势，就等于认了 |
| 猫的提法 | 谁都懂，意思是“随人摆弄” |
| ABO 设定 | 腺体长在这里，本来就是要害 |

四条叠在一起，手往后颈一放，什么都说了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 后颈 ✓ · 领口 ✓ · 发梢 ✓ · 手腕 ✓ |
| 她的动作梯度 | 手搭上去 → 拇指按一下 → 五指收拢 → 把他往下带 |
| 他的反应梯度 | 僵住 → 呼吸变了 → 低头 → 完全放松 |
| 场合 | 私下 · 有人在时手上轻，意思反而重 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 力度 | 轻轻搭着 | 使劲按住 |
| 意图 | 哄一哄 | 拦住他，他刚要张嘴就被她按住 |
| 他的反应 | 听话 | 愣住，两个人还没熟到那一步 |
| 设定 | 一般情况 | 女A男O（有腺体，见 [03-世界观设定](../03-世界观设定/)） |

「拦下来」那一头：他正要说一句不该说的话，她手一搭，他就停了。从头到尾没人开口。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 掌心 ✓ 底下先绷紧再松开 | 她的手放上来时我脑子里在想什么 |
| 好的处理 | 她手就放着，没用力 | 头是他自己低下去的 |
| 写崩 | 写成管人那种压法 | 写成身子自己不听使唤 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 摸他脖子／帮他整衣领／手指按在他喉结下面 |
| 修仙 | 神识压进他识海／后颈留个契印 |
| 星际 | 脖子后面有接口／她伸手盖上去 |
| 女A男O | 腺体 · 临时咬一口 · 放点信息素安他 |

#### 写崩的三种方式

1. 写成暴力压制。 力度要轻。
2. 回回都碰后颈。 用得多了就不稀罕了。
3. 后面跟一大段解释。 这个动作该说的都说了，再解释是多余。

## 四 · 靠肩

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 77.9%

**骨架**｜他试着靠过来，一点一点把身子的重量交给她。交出去几分重量，就有几分信她。

#### 节拍链

同乘／同坐 → 他试着挨过来 → 她没动 → 他把重量交出去 → 睡着头滑下来 → 她扶住

#### 时间轴

她没动。他先压上三成，过五分钟加到七成，等他睡着了才整个靠上去。重量是一批一批过来的。一上来就全压上的是装的，给得越慢越像真的，分三回慢慢靠过来，那是真撑不住了。

#### 重量的刻度

| 姿态 | 交出的重量 | 读作 |
|---|---|---|
| 头挨着，还使着劲 | 几乎没有 | 试探 |
| 完全靠上去 | 全部 | 放松 |
| 睡着了，头滑下来 | 无意识 | 最深的信任 |
| 她扶住那个滑下来的头 | — | 她接住了 |

「睡着了，头滑下来」这一档最好用。信不信她，他自己没拿主意，身体先替他拿了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 车里 · 沙发上 · 地铁上 · 看电视时 |
| 身高差处理 | 他高，要弯腰低头，她要踮脚仰头 · 这点别扭正好拿来写 |
| 她的反应 | 不动了 · 换个姿势让他靠得舒服点 · 手机举远点免得晃 |
| 时长 | 她胳膊麻了，但没挪 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁靠谁 | 他靠她 | 她靠他（少见，且极有力） |
| 有意无意 | 有意 | 睡着了 |
| 她的处理 | 让他靠 | 把他的头扶正（更亲昵） |
| 场合 | 私下 | 公共场所 |

「她靠他」在语料里很少见。写出来，就是她再强也有个歇脚的地方，值得一写。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 肩上压着的那股劲 | 靠过去之前那一下迟疑 |
| 好的处理 | 她胳膊麻了也没挪开 | 他靠上去了，也没说对不起 |
| 写崩 | 写成了她扛着累赘 | 写成了他黏着不放 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 车驾里靠着她／枕在她膝上／趴她案边睡着了 |
| 修仙 | 打坐时靠她背上／御剑时搂她腰 |
| 星际 | 长途飞行睡休眠舱／她肩甲被他靠出个坑 |

#### 写崩的三种方式

1. 写她嫌他重。 那就成了另一种关系。
2. 让他一靠就睡着。 犹豫的那一下得留。
3. 只写单向。 她也需要靠一次。

## 五 · 膝枕

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 77.9%

**骨架**｜他躺下，头枕着她的腿，这样躺着他什么也干不成。

#### 节拍链

她拍了拍腿 → 他犹豫 → 躺下 → 抓住她衣角 → 她的手放在他额头 → 闭眼 → 谁都不想起来

#### 时间轴

这个角度他看不了手机。躺下到起来有多久，就看她腿麻成什么样了还不喊他起来。

#### 姿势的语法

他躺着，看不到门，起不了身，眼里只有她的下巴。

| 附加动作 | 效果 |
|---|---|
| 她低头看他 | 对上眼，最亲 |
| 她看别处（手机、书） | 人陪着，不搭理他，更像过日子 |
| 她的手放在他额头 | 她说了算 |
| 他闭上眼 | 全交给她了 |
| 他抓着她的衣角 | 他还是怕 |

「他抓着她的衣角」：人整个交给她了，手上还攥着一点，看得出这份信任是他咬着牙自己给的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 沙发 ✓ · 膝盖 ✓ · 毯子 ✓ · 台灯 ✓ · 她手里的书或手机 ✓ |
| 触发 | 他累了 · 他难受 · 她拍拍自己的腿，招呼他过来 |
| 她的动作 | 摸他耳朵 ✓ · 拨他头发 · 什么都不干 |
| 收尾 | 他睡着了 · 她腿麻了 · 谁都不想动 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁发起 | 她先动的手 | 他自己凑过来 |
| 她做什么 | 光顾着看他 | 忙自己的 |
| 有没有话 | 聊几句闲天 | 一句不说 |
| 收尾 | 他睡着了 | 他醒了，又躺回去 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 腿上压着的感觉和热乎气 | 躺下去那一下臊得慌 |
| 好的处理 | 她拍了拍腿，啥也没说 | 他躺了老半天才合眼 |
| 写崩 | 写成当妈哄孩子 | 写成装嫩卖乖 |

母性化、幼儿化都不要写。他就是个累了的成年人，别写成要哄的小孩。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 枕在她膝上／她替他掏耳／榻上 |
| 修仙 | 靠着她入定／她替他梳理灵脉 |
| 星际 | 低重力舱里他浮着，头抵着她的膝 |

#### 写崩的三种方式

1. 写成哄孩子。 见上。
2. 加太多对话。 这条要静。
3. 非要让它引出别的。 它自己能单独成一场。

## 六 · 量身高

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 77.9%

**骨架**｜他比她高出一头，在这个设定里是个梗，也是一颗小糖。

#### 节拍链

起因（够不到／合照）→ 背靠背 → 他不动声色地屈膝 → 她假装没发现 → 他自己蹲下来

#### 时间轴

头一回量是闹着玩，量到第十回就成了家常。差的始终是那一头，回回量出来都一样，变的是他屈膝越来越熟练，一年比一年自然。

#### 为什么这条特别

这个类型好看的地方，就在“人高马大，但偏偏在下面”。他明明更高更壮，站的位置却低。一量身高，这件事就摆到了明面上，大家笑一笑也就过去了。

| 处理 | 效果 |
|---|---|
| 他弯腰配合 | 他把高出的那截让出来 |
| 她踮脚 | 她不介意示弱 |
| 她拉他下来 | 她直接拿他的身子来用 |
| 他自己蹲下 | 最好的一种 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 背靠背站着 · 在门框上比个子 · 她够不着高处的东西 · 拍合照时 |
| 道具 | 镜子 ✓ · 门框 · 椅子 ✓（她踩上去）· 她穿的鞋 |
| 他的配合 | 悄悄弯点腿 · 装自己也没多高 |
| 她的反应 | 不服气 · 要不就直接把他拽下来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 差距 | 一头 | 半个头 |
| 他的态度 | 得意，难得能显摆一下 | 小心着不让她觉得被压 |
| 她的反应 | 逗他玩 | 直接把他按矮 |
| 场合 | 私下 | 有外人在，他会挺直腰，摆出架势 |

「小心着不让她觉得被压」这份心思能写。他清楚自己块头大，怕她觉得被压着，就自己收着点。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|

| 写崩 | 写成她觉得自己配不上 | 写成他拿身高压人 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他侍立时总矮她半阶／跪坐时刚好跟她平视 |
| 修仙 | 他御剑时飞低一截／化形时把自己变小 |
| 星际 | 他把座椅调矮／在舱里老习惯低头 |

古代女尊版能写「跪坐时刚好跟她平视」：礼制规定的姿势，偏偏让两个人平起平坐。

#### 写崩的三种方式

1. 写成她的心病。 身高差在这儿是甜的。
2. 让他拿个子压人。 那他就出了这个类型。
3. 写得太长。 三句话的事。

## 七 · 系扣子

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 77.9%

**骨架**｜她伸手替他把衣服整好，放在哪儿都看得出「这人归我管」。

#### 节拍链

出门前 → 他打了两次都不对 → 她接过那一端 → 他低头 → 三次才打好 → 她拍拍他胸口

#### 时间轴

第一下打完，两个人谁也不急着走。第二下没打准，是真手生。他喉结一动，她分了神。第三下就是明着在磨蹭了。出门的点在催，迟到五分钟也值。

#### 为什么整理衣着这么有力

这个动作里，她默认自己有权摆弄他身上的东西，他就站着不动。

| 动作 | 力度 |
|---|---|
| 替他理领子 | 日常 |
| 替他系扣子 | 亲密 |
| 替他打领带 | 最有力，距离最近，时间最长 |
| 替他挽袖子 | 带一点占有 |
| 拽他领口把他拉近 | 从整理变成征用 |

最后一行是分界线。上面四种是照料，最后一种成了权力动作。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 扣子 ✓ · 领口 ✓ · 袖子 ✓ · 衬衫 ✓ · 外套 ✓ · 围巾 ✓ · 镜子 ✓ |
| 距离 | 打领带时俩人挨得特别近 · 他得低头 · 呼吸全扑在她额前的碎发上 |
| 他的动作 | 手垂着没处搁 · 气都不敢喘 · 眼神乱飘不知道看哪儿好 |
| 场合 | 出门前 · 要参加正式场合 · 她亲手给他挑的那件 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁给谁 | 她给他 | 他给她，手会抖 |
| 场合 | 私下 | 当着人，效果翻倍 |
| 熟练度 | 熟练 | 她头回打领带，打了三回 |
| 收尾 | 拍拍他胸口 | 拽住领带把他拉下来 |

「打了三回」比一次打好强。三回就是三分钟，他在那儿站了三分钟没动。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他心跳声隔着衬衫都能摸到 | 她指尖碰到喉结 ✓ 那一下 |
| 好的处理 | 她拍两下，说没事了 | 他半天没动弹 |
| 写崩 | 写成伺候人的老妈子 | 写成他像个摆件 |

方向写反，这段就废了。她给他整理，是他归她管，他给她整理，是在讨好她。两种都能写，读起来完全是两回事。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 替他正冠／系腰带／整衣襟，衣冠就是身份，她替他整理就是认了他 |
| 修仙 | 替他束发／系上她的剑穗 |
| 星际 | 替他扣上护甲／把他的徽章扶正 |

古代背景下，穿什么就是什么阶层。外人看一眼谁在替谁正衣冠、系腰带，就知道这两人谁说了算。见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。

#### 写崩的三种方式

1. 写成服务。 这是权力动作。
2. 不写他手没处放。 那份局促得留着。
3. 让他配合得太顺。 头一回就该笨手笨脚。

## 八 · 被抱起来

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 77.9%

**骨架**｜他抱她不费力，她抱他多半抱不起来，这段就写这个抱不起来。

#### 节拍链

他喝多了／受伤 → 她要抱 → 抱不动 → 改成搀 → 他悄悄用脚借力 → 两人一起摔进沙发

#### 时间轴

他手刚搭上来借力，步子就已经乱了。五拍一气呵成，从「我来」到摔进沙发，最多两分钟。一开始架势摆得十足，走三步就不行了，改成搀着反倒顺了，最后两个人一起倒下去。写慢了，好笑的劲儿就没了。

#### 三种解法

这一条有个难处：她多半抱不动他。解决的办法分三档：

| 解法 | 说明 | 适用 |
|---|---|---|
| 一 不抱，改姿势 | 她扶他、背他、半拖着他走 | 现实向，最好用 |
| 二 设定给力 | 修仙／星际／女A：她力气真够大，抱得动 | 幻想向 |
| 三 他配合 | 他本来能自己走，偏让她扶着 | 最有味道 |

第三档最好。他肯让她搀着，比她真能抱得动更看得出两人的关系。

#### 可用细节

| 类 | 内容 |
|---|---|
| 姿势 | 他胳膊搭她肩上 · 她手搂着他腰 · 他半边身子压过来，她心里有数 |
| 场合 | 他喝大了 · 他挂了彩 · 他睡着了她得把人弄床上去 · 他装的 |
| 她的动作 | 试了试抱不动 · 干脆改成拖 · 俩人都乐了 |
| 他的配合 | 偷偷拿脚蹬地 · 装得跟全靠她似的 |

「悄悄用脚借力」最要紧：他让她赢了，又没让她累着。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她抱不抱得动 | 抱得动（设定支撑） | 抱不动，改姿势 |
| 他配不配合 | 配合 | 真的失去意识 |
| 场合 | 家里 | 外面（有观众） |
| 收尾 | 顺利到床上 | 两个人一起摔在沙发 ✓ 上 |
| 方向 | 她抱他（本条正题） | 他背她（她喝醉、崴脚、犯困时常见的收尾，跟 [29-微小仪式拾遗 · 拧瓶盖与够高处](29-微小仪式拾遗.md#七--拧瓶盖与够高处)一样是按力气分活。她趴在他背上照样发号施令） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他比看着沉 | 她来抱我，我搭不搭手 |
| 好的处理 | 她试了，不成，换招，也不恼 | 他顺着借了力，没点破 |
| 写崩 | 写成她天生神力 | 写成他装软讨心疼 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她扶他上马车／唤人抬进去，她亲自扶着走完最后几步 |
| 修仙 | 御剑载他／灵力托起 |
| 星际 | 低重力下她真的抱得起来 |

星际有低重力，修仙有灵力，抱不动的问题都能解决。可这个问题一解决，第三档那点味道也就没了。两种都写。

#### 写崩的三种方式

1. 让她力大无穷，设定里又没交代来由。 读者会出戏。
2. 让他被抱得一点自尊都没有。 他得挣一下。
3. 写成公主抱换个性别图个爽。 该写的是他怎么配合。

## 九 · 睡姿与占地盘

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：就地睡着 55.9%

**骨架**｜睡一张床，身体会自己商量。

#### 节拍链

各睡各的 → 他往她那边挪 → 她伸手把他捞过来 → 半夜姿势变了 → 早上醒来两人都尴尬

#### 时间轴

以一夜为单位。睡前怎么躺、醒来成了什么样，能写实的就这两个时刻。中间怎么挪的，都发生在两个人睡着的时候。

#### 睡姿的关系图

| 睡姿 | 读作 |
|---|---|
| 各睡各的，中间有空隙 | 关系初期或者出事了 |
| 他往她那边挪 | 他在靠近 |

| 他整个人缠上来 | 完全的安全感 |
| 她睡在外侧（靠门） | 她在护着 |
| 他睡在外侧 | 他在护着她，意思不一样，值得写 |
| 醒来发现姿势变了 | 身体说的实话 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 被子 ✓ 谁抢走了 · 枕头 ✓ · 床 ✓ 的哪一侧 · 空调开几度吵一架 |

| 小摩擦 | 他睡觉不老实 · 她老踢被子 · 有人打呼噜 |
| 妥协的痕迹 | 她习惯了他的体温 · 他学会了躲开她头发 |

| 轴 | 一端 | 另一端 |

| 阶段 | 头一回同床，放不开 | 过了多少年，啥都不讲究了 |
| 谁靠近 | 他 | 她，睡着以后 |
| 位置 | 她睡里头 | 她睡外头，护着人的样 |
| 醒来 | 一晚上没动弹 | 俩人缠一块儿，醒了都臊得慌 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 半夜醒了，发现人已经被自己捞到怀里了 | 装睡，偷偷往她那边蹭了两寸 |
| 好的处理 | 她没把人推回去 | 他蹭完就僵住，怕露馅 |

1. 拿来给情欲铺路。 睡姿自己就是一整场戏。
2. 只写一次。 得拿第一次和半年后对着写。
3. 跳过睡着的那段。 人睡着以后的动作要写。

## 十 · 第一次主动

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 77.9% ＋ 牵手 46.5%

**骨架**｜他第一次主动碰她。

#### 为什么是顶点

前面九条里，绝大多数是她先动手。这一条反过来，换他。

处在弱势的一方去碰人，难处在于他拿不准自己配不配。所以他动手前那几秒的犹豫要写。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 他想 |
| 2 | 他找理由：人多、天冷、她东西拿不下 |
| 3 | 理由不成立，他也知道 |
| 4 | 他还是伸手了 |
| 5 | 那一秒的空白 |
| 6 | 她的反应 |
| 7 | 他松了一口气，或者把手收了回来 |

#### 时间轴

倒计时还在跳，绿灯一亮，她的手正好空了出来。人多的那一阵已经过去，他不能再拖。借口顶多撑几秒，得马上伸手。伸手之前，他那几秒要一秒一秒给够，碰到之后空一整拍，再等一拍，看她怎么反应。

#### 可用细节

| 类 | 内容 |
|---|---|
| 找理由的动作 | 假装拿东西 · 先碰她袖子 · 先扯句别的 |
| 手的状态 | 手心 ✓ 出汗 · 手指 ✓ 冰凉 · 伸出去有点抖 |
| 那一秒 | 周围一下没声了 · 他在看她会不会躲 |
| 她的三种反应 | 接住 · 愣一下才接住（最好）· 没反应（转 [03 卷撒娇失败](03-撒娇与讨哄.md#十--撒娇失败)） |

「愣一下才接住」：她愣那一下，是因为她也没想到，这事对她一样要紧。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 接触形式 | 牵手 | 抱住 |
| 有没有理由 | 有 | 没有，且他没找 |
| 她的反应 | 接住 | 反过来抱住他（她也在等） |
| 事后 | 谁都不提 | 她说了一句 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现这是他头一回主动 | 伸手之前那三秒 |
| 内心 | 我装得自然点行不行 | 她要躲开我咋收场 |
| 好的处理 | 她愣了下，还是握住了 | 他没找台阶下 |
| 写崩 | 写成她乐疯了 | 写成他一股脑冲上去不带犹豫 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他头一回拽她袖子／那下越了礼 |
| 修仙 | 他头回拿神识碰她／他先递了契约 |
| 星际 | 他头回没报备就解开安全索奔她来 |

古代版分量最重。越了礼要付代价，他明知不合规矩，还是做了。

#### 写崩的三种方式

1. 让她犹豫。 一犹豫，这一下就白费了。
2. 让她马上热情地回应。 那一下愣神一定要留着。
3. 用得太早。 这一下要放到关系中段，前面先攒够她主动追他的戏，到这里再反过来，才立得住。

#### 示例（本库自撰，可直接改写）

> 绿灯还有二十秒。
> 他的手在口袋里攥了一路，现在拿出来了，悬在两个人之间那一小段空里。
> 十五秒。
> 他给自己想好了台阶：她要是没反应，就当是去按那个按钮。
> 十二秒。
> 她低头看了一眼，愣了半秒，然后把手放进他掌心。
> 她的手比他凉。他握住的时候，力气大了一点，又赶紧松开一些。

## 十一 · 第一次接吻

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：留痕 46.0%（吻的可见后果族；吻本身无法用词表单测，以留痕为代理指标）

**骨架**｜谁先动，动之前对视的那半秒，分开以后谁先开口。

#### 节拍链

距离渐近，本卷前十条就是它的里程碑。然后对视超时，接着是那半秒，谁也没退。吻，分开，第一句话定调，之后的路就清楚了。

#### 时间轴

这一下要酝酿好几周，前面的揉头、牵手、靠肩都在铺路。平常对视两秒就移开，到第三秒就开始倒数了。吻的时候不看钟，分开后说第一句话，表才重新走。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 楼道声控灯灭的那一下 · 车 ✓ 里熄火之后 · 吵完架的静默里 · 门 ✓ 关上的瞬间 |
| 谁先动 | 她先动，终于肯松口答应自己 · 他先动，是[十 · 第一次主动](#十--第一次主动)的毕业考 |
| 写什么 | 过程不写，写周边：呼吸乱得没章法 · 距离清零前那一下停顿 · 手悬在半空不知往哪放 |
| 第一句话 | 玩笑型：「你睫毛刮到我了」· 确认型（「所以，现在算……」）· 她的专属型：「重来。刚才那个不算数，太仓促。」 |

说「重来」，是她连这件事也要一个合格的版本，他求之不得。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先动 | 她 | 他，他先动的版本要写足那半秒的等待：等她点头 |
| 之前的状态 | 甜着 | 吵着，吵到一半的吻是断句，动笔前想清楚这一下会怎么收场 |
| 场合 | 私下 | 被撞见（转 [14-社交与公开 · 公开](14-社交与公开.md#四--公开)的被动版） |
| 之后 | 顺理成章 | 有人慌了（落荒而逃的那个隔天得自己回来，接 [11-初遇与确立 · 试探边界](11-初遇与确立.md#七--试探边界)的回摆） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「重来」说出口，主动权就回来了 | 毕业考那一步迈出去的瞬间 |
| 内心 | 批准自己，比批准哪个项目都难 | 退路没了。太好了。 |
| 好的处理 | 她先动，也给他留了半步退路 | 他先动，那半秒的等待写满 |
| 写崩 | 写成走流程交差 | 写成猛虎扑食 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 帷帽掀起那一下 · 却扇礼不请宾客，她自己伸手把扇子挪开了 |
| 修仙 | 渡灵息本来是公事，偏做成了私事。「这不是功法里教的」「我知道」 |
| 星际 | 舱外作业隔着两层面罩碰了碰，算吻。真亲是在舱内重力恢复那刻，失重的头发落下来的时候 |

#### 写崩的三种方式

1. 吻本身写三段。 表停着，笔落在周围。
2. 跳过第一句话。 没有分开后那句话，这场戏收不了尾。
3. 当成全书的高潮。 它不过是这一卷的收尾。
