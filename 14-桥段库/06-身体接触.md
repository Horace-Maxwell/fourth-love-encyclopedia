# 身体接触

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**谁先伸手，谁承担被拒绝的风险。**

---

## 触碰的权力语法

这一类里，每一次身体接触都在回答两个问题：谁发起，谁允许。

| 组合 | 读作 |
|---|---|
| 她伸手，他接受 | 常态。掌控与顺从 |
| 她伸手，他躲了一下 | 有事发生了 |
| 他伸手，她接住 | 请求被批准 |
| 他伸手，她没接 | [03-撒娇与讨哄 · 撒娇失败](03-撒娇与讨哄.md#十--撒娇失败) |
| 他伸手，她主动迎上 | 关系的转折点 |

「他伸手」这一栏是这个类型的技术难点。 弱势方发起接触需要勇气，而这个勇气必须被写出来，否则读者感觉不到风险。

| 反应族 | 作品数 | 占比 |
|---|---:|---:|
| 拥抱 | 1,862 | 64.3% |
| 牵手 | 904 | 31.2% |

拥抱是全部反应族里最高的一族，牵手只有它的一半。牵手比拥抱难写，因为它需要双方同时同意。

## 一 · 揉头

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：讨哄 54.4%

**骨架**｜最短的奖励。一秒钟，什么都不用说。

#### 节拍链

他做对了事／难过了 → 她抬手 → 他不自觉低头 → 揉乱 → 把头发理回去

#### 时间轴

动作一秒，余温一天。 揉的时长永远短于他希望的时长，这个差值就是甜度。写法上把那一秒拆慢：抬手、落下、揉乱、收回，四拍；再让他顶着乱头发走完一下午，谁提醒都不理。

#### 揉头的语义分层

同一个动作，力度和时长完全改变含义：

| 力度／时长 | 读作 |
|---|---|
| 快速拍两下 | 敷衍或调侃 |
| 揉乱 | 亲昵，带一点欺负 |
| 手停在头顶不动 | 郑重。这一档最重 |
| 顺着往下摸到后颈 | 亲密度跃升 |
| 揉完把头发理回去 | 她在意他的体面 |

「揉完理回去」是最好的一个细节。 揉乱是亲昵，理回去是尊重，两个动作连在一起就把关系说完了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 高度问题 | 他比她高，所以她要抬手／他要低头（低头这个动作本身就是让渡） |
| 他的配合 | 他会不自觉地低一点头 · 这个下意识动作比任何台词都能说明习惯 |
| 场合 | 他做对了事 · 他难过 · 路过时随手 · 有人在（他会僵一下） |
| 他的反应 | 眼睛眯一下 · 耳朵 ✓ 红 · 假装没事继续手上的事 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 私下 | 当众（他会僵） |
| 她的意图 | 奖励 | 安抚 |
| 高度处理 | 她踮脚 | 他低头 |
| 他的反应 | 享受 | 躲开（有事） |

「他低头」这个动作在古代女尊设定里权重极高：身高差本是生理事实，低头是主动配合，那是自愿的姿态。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他会自动低头 | 她手放上来那一秒 |
| 好的处理 | 她揉完把头发理平 | 他低头了，但不承认自己在等 |
| 写崩 | 写成摸宠物 | 写成幼儿化 |

宠物化是这一族最大的雷。判据：这个动作里他有没有保留自己的意志。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 抚发／替他正冠／指尖点在他额上 |
| 修仙 | 以灵力拂过他发顶／替他理正束发的簪 |
| 星际 | 隔着头盔的那一下／她摘了手套才摸 |

「她摘了手套才摸」是星际版的最强写法：多一个动作，就多一层郑重。

#### 写崩的三种方式

1. 写成宠物互动。 见上。
2. 每章都揉。 高频会让它贬值成口头禅。
3. 省略他低头。 那个下意识的配合是全条最好的东西。

## 二 · 牵手

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：牵手 31.2%

**骨架**｜牵手需要双方同时同意，所以它比拥抱难。

#### 节拍链

找借口（人多／天冷）→ 伸手 → 那一秒 → 她握紧一点作为回答 → 到路口谁都没松

#### 时间轴

从借口成立到路口，就是这条的全程。 伸手前的酝酿以分钟计（人多的那段路走完就没机会了，倒计时压着他）；牵上之后时间换了流速，到路口的路程明明三百米，两个人都走出了三站地的时长。

#### 牵法的语义

| 牵法 | 谁主导 | 读作 |
|---|---|---|
| 她握他手腕 ✓ | 她 | 带走。最有力，也最不像牵手 |
| 她握他手掌 | 她 | 常规 |
| 十指相扣 | 双方 | 平等，且不容易松开 |
| 他勾她小指 | 他 | 试探，可以被忽略 |
| 他把手放进她口袋 ✓ | 他 | 请求，且给了她拒绝的余地 |
| 她把他的手塞进自己口袋 | 她 | 最亲密的一种 |

「握手腕」和「握手掌」的差别值得单独写一场。 握手腕是控制，握手掌是同行。一个角色从握他手腕改成握他的手，这个变化可以承载一整条成长线。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 口袋 ✓ · 手套 ✓ · 手腕 ✓ · 掌心 ✓ · 指尖 ✓ |
| 触发场合 | 过马路 · 人多 · 天冷 · 他心情不好 · 什么理由都没有 |
| 松开的时机 | 谁先松，说明什么 |
| 温度 | 他手凉／她手凉，谁把谁的手捂热 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先伸手 | 她 | 他（更难，也更重） |
| 借口 | 有（人多、天冷） | 没有 |
| 场合 | 私下 | 街上（他会紧张） |
| 松开 | 到了目的地自然松 | 谁都没松，走过了路口 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他的手在她掌心里动了一下 | 伸出去之前手心 ✓ 先出汗了 |
| 内心 | 他今天手好凉 | 她会不会甩开 |
| 好的处理 | 她握紧了一点作为回答 | 他伸手了，且没有找借口 |
| 写崩 | 写成她不假思索 | 写成他扭捏很久 |

「她握紧了一点」是最经济的回应：不用说话，一个力度就是答复。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 隔着衣袖握住／她牵他上马车／扶他的那只手 |
| 修仙 | 御剑时他扶她的腰／她拉他跨过阵法 |
| 星际 | 失重时抓住彼此的手／共用一条安全索 |

#### 写崩的三种方式

1. 写得太随意。 牵手在这一类里是有分量的动作，随手牵会让它贬值。
2. 省略犹豫。 他伸手之前那一下，就是这条的内容。
3. 只写她主动。 他主动的那一版才是难得的。

## 三 · 后颈

`T` ｜ 无预警 ｜ 全谱系（女A男O 尤强）｜ 语料频次：拥抱 64.3%

**骨架**｜后颈是这个类型里最有讲究的一个部位。

#### 节拍链

她的手搭上去 → 他僵住 → 呼吸变了 → 拇指按一下 → 五指收拢 → 他自己低了头

#### 时间轴

手搭上去之后，以呼吸为拍。 第一拍他僵住，第二拍呼吸变浅，第三拍拇指按下，第四拍五指收拢，每一拍之间的间隔她说了算。这条没有分钟数，只有呼吸数；写到第几拍收手，烈度就停在第几档。

#### 为什么是后颈

| 原因 | 说明 |
|---|---|
| 看不见 | 被碰的人无法预判，只能信任 |
| 要低头才能被碰到 | 姿势本身就是让渡 |
| 猫的提法 | 文化联想里带着「被处置」的意味 |
| ABO 设定 | 腺体在这里，生理上就是要害 |

这四条叠加，让后颈成为这个类型里最短的权力宣言。 碰一下，什么都说了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 后颈 ✓ · 领口 ✓ · 发梢 ✓ · 手腕 ✓ |
| 她的动作梯度 | 手搭上去 → 拇指按一下 → 五指收拢 → 把他往下带 |
| 他的反应梯度 | 僵住 → 呼吸变了 → 低头 → 完全放松 |
| 场合 | 私下 · 有人在（力度要轻，含义更重） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 力度 | 轻搭 | 收紧 |
| 意图 | 安抚 | 制止（他正要说什么，她按住了） |
| 他的反应 | 顺从 | 僵住（说明关系还没到） |
| 设定 | 普通 | 女A男O（腺体，走 [03-世界观设定](../03-世界观设定/)） |

「制止」这个用法很好：他正要说一句不该说的话，她的手搭上去，他就停了。 全程没有台词。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 掌心 ✓ 下面那一下绷紧然后松开 | 她的手放上来的时候我在想什么 |
| 好的处理 | 她只是放着，没有用力 | 他低了头，是他自己低的 |
| 写崩 | 写成制服式的压制 | 写成生理性的失控 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 抚他的颈侧／替他理衣领／指尖压在他喉结 ✓ 下方 |
| 修仙 | 神识按在他识海／契印在后颈 |
| 星际 | 神经接口在颈后／她的手覆上去 |
| 女A男O | 腺体 · 临时标记 · 安抚信息素 |

#### 写崩的三种方式

1. 写成暴力压制。 力度要轻，含义才重。
2. 每次接触都用后颈。 用多了就没有分量。
3. 配大段解释。 这个动作自带全部信息，解释是浪费。

## 四 · 靠肩

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 64.3%

**骨架**｜他把重量交出去。交多少，说明信任到什么程度。

#### 节拍链

同乘／同坐 → 他试着挨过来 → 她没动 → 他把重量交出去 → 睡着头滑下来 → 她扶住

#### 时间轴

重量是分批交付的。 先挨着（试探价），过五分钟给三成重量，她没动，再给到七成；睡着是全款。交付节奏越慢越真，一上来就全靠的是演的，分三批靠过来的是熬不住的。

#### 重量的刻度

| 姿态 | 交出的重量 | 读作 |
|---|---|---|
| 头挨着，还使着劲 | 几乎没有 | 试探 |
| 完全靠上去 | 全部 | 放松 |
| 睡着了，头滑下来 | 无意识 | 最深的信任 |
| 她扶住那个滑下来的头 | — | 她接住了 |

「睡着了头滑下来」这一档最好用，因为它是无意识的：他没有决定信任她，他的身体替他决定了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 车 ✓ 里 · 沙发 ✓ 上 · 地铁 ✓ 上 · 看电视时 |
| 身高差处理 | 他高，所以他要往下缩／她要往上抬肩 · 这个不便本身就是细节 |
| 她的反应 | 不动了 · 换个姿势让他靠得舒服 · 手机 ✓ 举得远一点免得晃 |
| 时长 | 她的胳膊麻了但没动 |

「胳膊麻了但没动」是这条最好的一句。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁靠谁 | 他靠她 | 她靠他（少见，且极有力） |
| 有意无意 | 有意 | 睡着了 |
| 她的处理 | 让他靠 | 把他的头扶正（更亲昵） |
| 场合 | 私下 | 公共场所 |

「她靠他」在语料里罕见。它不削弱她的位置，反而说明她累了也有地方放。强势方需要一个可以卸力的地方，这件事该被写。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 肩上那个重量 | 靠上去之前那一下犹豫 |
| 好的处理 | 她的胳膊麻了没动 | 他靠上去了，且没有说抱歉 |
| 写崩 | 写成她的负担 | 写成他的黏附 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 车驾里靠着／她的膝上／伏在她案边睡着 |
| 修仙 | 打坐时靠着她的背／御剑时环着她的腰 |
| 星际 | 长途航行的休眠舱／她的肩甲被他靠出一个印 |

#### 写崩的三种方式

1. 写成她嫌重。 那是另一种关系。
2. 让他一靠就睡。 犹豫的那一下要留。
3. 只写单向。 她也需要靠一次。

## 五 · 膝枕

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 64.3%

**骨架**｜他躺下，把头放在她腿上。这个姿势里他什么都做不了。

#### 节拍链

她拍了拍腿 → 他犹豫 → 躺下 → 抓住她衣角 → 她的手放在他额头 → 闭眼 → 谁都不想起来

#### 时间轴

从躺下到起身，中间的时长全是奢侈品。 这个姿势没有任何产出，他不能看手机（角度不对），她的腿会麻，所以每多一分钟都是两个人合谋浪费掉的。她的腿麻到什么程度还不叫他起来，麻的程度就是爱的计量。

#### 姿势的语法

膝枕是这一族里唯一一个完全放弃视野和行动力的姿势。他躺着，看不见门，起不来，只能看见她的下巴。

| 附加动作 | 效果 |
|---|---|
| 她低头看他 | 视线交汇，最亲密 |
| 她看别处（手机、书） | 陪伴而非互动，更日常 |
| 她的手放在他额头 | 掌控 |
| 他闭上眼 | 完全交付 |
| 他抓着她的衣角 | 他还是不放心 |

「他抓着衣角」是这条最好的一个细节。 完全交付的姿势里保留了一个小小的抓握，说明这个信任是他努力给的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 沙发 ✓ · 膝盖 ✓ · 毯子 ✓ · 台灯 ✓ · 她手里的书或手机 ✓ |
| 触发 | 他累了 · 他难受 · 她拍了拍自己的腿（这个动作就是邀请） |
| 她的动作 | 摸他耳朵 ✓ · 拨他头发 · 什么都不做 |
| 收尾 | 他睡着了 · 她腿麻了 · 谁都不想起来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁发起 | 她拍腿 | 他自己躺过去 |
| 她做什么 | 专心看他 | 做自己的事 |
| 有没有话 | 有一搭没一搭 | 全程无话 |
| 收尾 | 他睡着 | 他起来了，然后又躺回去 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 腿上的重量和体温 | 躺下去那一下的羞耻感 |
| 好的处理 | 她拍了拍腿，什么都没说 | 他躺了很久才闭眼 |
| 写崩 | 写成母性泛滥 | 写成幼儿化 |

母性化和幼儿化是这条的双雷。 判据：他是一个累了的成年人，不是一个需要哄的孩子。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 枕在她膝上／她替他掏耳／榻上 |
| 修仙 | 靠着她入定／她替他梳理灵脉 |
| 星际 | 低重力舱里他浮着，头抵着她的膝 |

#### 写崩的三种方式

1. 写成哄孩子。 见上。
2. 加太多对话。 这条要静。
3. 让它必然通向别的。 它可以自成一场。

## 六 · 量身高

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 64.3%

**骨架**｜他比她高很多，这件事在这一类里是个笑话，也是个甜点。

#### 节拍链

起因（够不到／合照）→ 背靠背 → 他不动声色地屈膝 → 她假装没发现 → 他自己蹲下来

#### 时间轴

身高差是常量，量的仪式是变量。 差那么多公分年年不变，但每次量都有新的作弊手法：他屈膝的角度一年比一年熟练。写作时把「第几次量」标出来，第一次是笑话，第十次是惯例，惯例才是家。

#### 为什么这条特别

这个类型的核心张力是生理优势与关系位置的错位：他更高、更强壮，但位置在下。量身高这个动作把这个错位摆到台面上，然后一笑而过。

处理这个错位的方式，暴露了作者的功力。

| 处理 | 效果 |
|---|---|
| 他弯腰配合 | 他把优势主动交出来 |
| 她踮脚 | 她不介意示弱 |
| 她拉他下来 | 她直接征用他的身体 |
| 他自己蹲下 | 最好的一种 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 背靠背 · 门框上划线 · 她够不到高处的东西 · 合照时 |
| 道具 | 镜子 ✓ · 门框 · 椅子 ✓（她站上去）· 她穿的鞋 |
| 他的配合 | 不动声色地屈膝 · 假装自己没那么高 |
| 她的反应 | 不服 · 或者直接拉他下来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 差距 | 一头 | 半个头 |
| 他的态度 | 得意（少数能得意的场合） | 小心翼翼地不让她觉得被压 |
| 她的反应 | 逗他 | 直接把他按矮 |
| 场合 | 私下 | 有人在（他会站直，宣示） |

「他小心翼翼地不让她觉得被压」这个心理很值钱：他知道自己的身体优势可能构成压迫，所以他主动收着。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他在偷偷屈膝 | 唯一能光明正大占上风的一件事 |
| 好的处理 | 她假装没发现 | 他得意了三秒，然后自己蹲下来 |
| 写崩 | 写成她自卑 | 写成他借身高压制 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他侍立时刻意站低半阶／跪坐时正好与她平视 |
| 修仙 | 他御剑时降低高度／化形时缩小体型 |
| 星际 | 他调低座椅／舱内他习惯性低头 |

古代女尊版的「跪坐时正好与她平视」是极佳的写法：礼制要求的姿势，恰好制造了平等。

#### 写崩的三种方式

1. 写成她的痛点。 身高差是甜点不是伤口。
2. 让他用身高压人。 那会让他离开这个类型的位置。
3. 写得太长。 三句话的事。

## 七 · 系扣子

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 64.3%

**骨架**｜她替他整理衣着。这个动作在任何设定里都是所有权的宣示。

#### 节拍链

出门前 → 他打了两次都不对 → 她接过那一端 → 他低头 → 三次才打好 → 她拍拍他胸口

#### 时间轴

三次打不好，就是三倍的时长。 她第一次打歪是真手生，第二次是他喉结动了她分了神，第三次两个人都知道在拖时间。出门的时刻表在催，玄关的这三分钟偏偏谁都不赶，迟到五分钟，值。

#### 为什么整理衣着这么有力

因为它默认了她有权处置他身上的东西，而他站着不动。

| 动作 | 力度 |
|---|---|
| 替他理领子 | 日常 |
| 替他系扣子 | 亲密 |
| 替他打领带 | 最有力（距离最近，时间最长） |
| 替他挽袖子 | 带一点占有 |
| 拽他领口把他拉近 | 从整理变成征用 |

最后一行是分界。 前四个是照料，最后一个是权力动作。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 扣子 ✓ · 领口 ✓ · 袖子 ✓ · 衬衫 ✓ · 外套 ✓ · 围巾 ✓ · 镜子 ✓ |
| 距离 | 打领带时两人的距离 · 他要低头 · 他的呼吸落在她额发上 |
| 他的动作 | 手垂着不知道往哪儿放 · 屏住呼吸 · 眼睛不知道该看哪里 |
| 场合 | 出门前 · 有正式场合 · 她给他挑的那件 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁给谁 | 她给他 | 他给她（他的手会抖） |
| 场合 | 私下 | 当着人（宣示效果翻倍） |
| 熟练度 | 熟练 | 她第一次打领带，打了三次 |
| 收尾 | 拍拍他胸口 | 拽着领带把他拉下来 |

「打了三次」比「熟练地打好」好：三次意味着三分钟，三分钟意味着他站着不动了三分钟。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他的心跳（隔着衬衫能感觉到） | 她的手指碰到喉结 ✓ 那一下 |
| 好的处理 | 她拍了拍，说好了 | 他一直没动 |
| 写崩 | 写成家庭主妇式服务 | 写成他被物化 |

方向搞反了这条就废了。她整理他是所有权，他整理她是讨好，两种都能写，但读感完全不同。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 替他正冠／系腰带／整衣襟（衣冠在礼制里是身份，代整就是代认） |
| 修仙 | 替他束发／系上她的剑穗 |
| 星际 | 替他扣上护甲／调整他的徽章位置 |

古代版最强：衣冠即身份，替他整衣冠等于对外宣告归属。 见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。

#### 写崩的三种方式

1. 写成服务。 这是权力动作不是家务。
2. 省略他不知道手往哪儿放。 那个局促是全条最好的东西。
3. 让他配合得太自然。 第一次要笨拙。

## 八 · 被抱起来

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 64.3%

**骨架**｜体格上他能轻易抱起她，反过来通常不能。这条处理的就是这个「通常」。

#### 节拍链

他喝多了／受伤 → 她要抱 → 抱不动 → 改成搀 → 他悄悄用脚借力 → 两人一起摔进沙发

#### 时间轴

从「我来」到摔进沙发，不超过两分钟，节奏是滑稽的。 起势雄心勃勃，三步之内破产，改搀，他借力，最后一起摔，五拍连贯不停顿，这条的钟是喜剧节拍器，慢下来就不好笑也不好哭了。

#### 三种解法

这条在这一类里有一个物理难题：她多半抱不动他。处理方式分三档：

| 解法 | 说明 | 适用 |
|---|---|---|
| 一 不抱，改姿势 | 她扶、她背、她半拖着 | 现实向，最好用 |
| 二 设定给力 | 修仙／星际／女A：她真的能抱起来 | 幻想向 |
| 三 他配合 | 他其实能自己走，但他让她扶着 | 最有味道 |

第三档最好。 他配合被搀扶这件事，比她真的抱得动更能说明关系。

#### 可用细节

| 类 | 内容 |
|---|---|
| 姿势 | 他的胳膊搭在她肩上 · 她的手环着他的腰 · 他把重量分掉一半（她知道） |
| 场合 | 他喝多了 · 他受伤 · 他睡着了要挪到床上 · 他装的 |
| 她的动作 | 试了一下抱不动 · 于是改成拖 · 两个人都笑了 |
| 他的配合 | 悄悄用脚借力 · 装作全靠她 |

「悄悄用脚借力」是这条的技术核心：他既让她赢了，也没让她累着。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她抱不抱得动 | 抱得动（设定支撑） | 抱不动，改姿势 |
| 他配不配合 | 配合 | 真的失去意识 |
| 场合 | 家里 | 外面（有观众） |
| 收尾 | 顺利到床上 | 两个人一起摔在沙发 ✓ 上 |
| 方向 | 她抱他（本条正题） | 他背她（她喝醉、崴脚、困倦的标准收尾——少数循传统脚本运行的搬运方向，与 [29-微小仪式拾遗 · 拧瓶盖与够高处](29-微小仪式拾遗.md#七--拧瓶盖与够高处)同属「力气分工保留区」；她在他背上照旧发号施令，位置换了，语法没换） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他比看上去沉 | 她要抱我的时候我该不该帮忙 |
| 好的处理 | 她试了，不行，换个办法，没有沮丧 | 他借了力，且不说破 |
| 写崩 | 写成她大力金刚 | 写成他装弱博怜 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她扶他上马车／唤人抬进去（她亲自扶着走完最后几步） |
| 修仙 | 御剑载他／灵力托起 |
| 星际 | 低重力下她真的抱得起来 |

星际低重力和修仙灵力都能解决物理问题，但解决了物理问题就失去了第三档的味道。两种都写。

#### 写崩的三种方式

1. 给她非人的力气而不给设定支撑。 会出戏。
2. 让他毫无自尊地被抱。 他要有那一下挣扎。
3. 写成公主抱的性别反转爽点。 反转本身不是内容，配合才是。

## 九 · 睡姿与占地盘

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：就地睡着 52.8%

**骨架**｜两个人睡在一张床上，身体会替他们谈判。

#### 节拍链

各睡各的 → 他往她那边挪 → 她伸手把他捞过来 → 半夜姿势变了 → 早上醒来两人都尴尬

#### 时间轴

以夜为单位的长期谈判。 单场只有两个时点有戏：入睡前的排兵布阵、早上醒来的现场勘验，中间的挪移全部发生在两人都不在场（睡着）的时候。身体连夜谈成的条款，早上由意识追认。

#### 睡姿的关系图

| 睡姿 | 读作 |
|---|---|
| 各睡各的，中间有空隙 | 关系初期或者出事了 |
| 他往她那边挪 | 他在靠近 |
| 她伸手把他捞过来 | 她接受了 |
| 他整个人缠上来 | 完全的安全感 |
| 她睡在外侧（靠门） | 她在护着 |
| 他睡在外侧 | 他在护着（性质不同，值得写） |
| 醒来发现姿势变了 | 无意识的真相 |

「醒来发现姿势变了」是最好用的一条。 睡着之后身体做的决定，比醒着时的所有对话都诚实。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 被子 ✓（谁抢走了）· 枕头 ✓ · 床 ✓ 的哪一侧 · 空调温度的分歧 |
| 长期证据 | 床垫上两边的凹陷 · 谁的那侧床头堆着东西 |
| 小摩擦 | 他手脚不老实 · 她踢被子 · 谁打呼 |
| 妥协的痕迹 | 她习惯了他的体温 · 他学会了不压着她的头发 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 阶段 | 第一次同床（拘谨） | 老夫老妻（各种不讲究） |
| 谁靠近 | 他 | 她（睡着之后） |
| 位置 | 她在里侧 | 她在外侧（护着的姿态） |
| 醒来 | 姿势没变 | 缠成一团，两个人都尴尬 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 半夜醒来发现自己把他捞过来了 | 装睡往她那边挪了两寸 |
| 好的处理 | 她没有推开 | 他挪完就不动了，怕被发现 |
| 写崩 | 写成她全程主导 | 写成他黏得没有边界 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她睡里侧他睡外侧／同榻不同衾／他值夜守在榻边 |
| 修仙 | 双修时的位置／她的洞府他有没有钥匙 |
| 星际 | 休眠舱的排列／谁的舱位靠近逃生口 |

#### 写崩的三种方式

1. 写成情欲铺垫。 睡姿本身就是一整场戏。
2. 只写一次。 这条要靠对比：第一次 vs 半年后。
3. 省略无意识的部分。 睡着之后的动作才是这条的价值。

## 十 · 第一次主动

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 64.3% ＋ 牵手 31.2%

**骨架**｜他第一次主动碰她。这条是这一族的顶点。

#### 为什么是顶点

前面九条里，绝大多数动作是她发起的。这条反过来。

弱势方主动发起身体接触，难在位置，不在害羞。他不确定自己有没有这个资格。所以这个动作的重量，全部来自他要不要做的那段犹豫。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 他想 |
| 2 | 他找理由（人多、天冷、她东西拿不下） |
| 3 | 理由不成立，他也知道 |
| 4 | 他还是伸手了 |
| 5 | 那一秒的空白 |
| 6 | 她的反应 |
| 7 | 他的松一口气／或者他把手收回来 |

#### 时间轴

理由的保质期只有几秒。 人多的那阵会过去、红灯会变绿、她自己腾出手，他找的每个借口都带过期时间。倒计时逼他出手。伸手前的时间以秒计给足，碰到之后的空白给一整拍，她的回应再等一拍。

#### 可用细节

| 类 | 内容 |
|---|---|
| 找理由的动作 | 先假装要拿东西 · 先碰她袖子 · 先说一句无关的话 |
| 手的状态 | 手心 ✓ 出汗 · 手指 ✓ 是凉的 · 伸出去的时候有点抖 |
| 那一秒 | 环境音全部消失 · 他在数她会不会躲 |
| 她的三种反应 | 接住 · 愣一下才接住（最好）· 没反应（转 [03 卷撒娇失败](03-撒娇与讨哄.md#十--撒娇失败)） |

「愣一下才接住」是最好的一版：那一愣说明她也没料到，也说明这件事对她也有分量。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 接触形式 | 牵手 | 抱住 |
| 有没有理由 | 有 | 没有，且他没找 |
| 她的反应 | 接住 | 反过来抱住他（她也在等） |
| 事后 | 谁都不提 | 她说了一句 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她意识到这是他第一次主动 | 伸手前的那三秒 |
| 内心 | 我要不要表现得很自然 | 她要是躲开我怎么收场 |
| 好的处理 | 她愣了一下，然后握住 | 他没有找借口 |
| 写崩 | 写成她欣喜若狂 | 写成他一鼓作气毫不犹豫 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他第一次拉住她的衣袖／越礼的那一下 |
| 修仙 | 他的神识第一次主动碰她／他先递出契约 |
| 星际 | 他第一次未经许可解开安全索走向她 |

古代版最有力，因为越礼是有代价的：他知道这不合规矩，他还是做了。

#### 写崩的三种方式

1. 省略犹豫。 犹豫就是这条的全部。
2. 让她立刻热烈回应。 那一愣要留。
3. 让它发生得太早。 这条应该在关系中段，前面要有足够多的「她主动」作为对照。

#### 示例（本库自撰，可直接改写）

> 绿灯还有二十秒。
> 他的手在口袋里攥了一路，现在拿出来了，悬在两个人之间那一小段空里。
> 十五秒。
> 他给自己想好了台阶：她要是没反应，就当是去按那个按钮。
> 十二秒。
> 她低头看了一眼，愣了半秒，然后把手放进他掌心。
> 她的手比他凉。他握住的时候，力气大了一点，又赶紧松开一些。

## 十一 · 第一次接吻

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：留痕 46.0%（吻的可见后果族；吻本身无法用词表单测，以留痕为代理指标）

**骨架**｜谁先动的，动之前那半秒的对视，和分开之后谁先说话。

#### 节拍链

距离渐近（本卷前十条就是它的里程碑）→ 对视超时 → 那半秒（谁也没退）→ 吻 → 分开 → 第一句话（定调）→ 之后的路

#### 时间轴

对视超时是引信：正常对视两秒，第三秒起进入倒计时。 吻本身不计时，写作时把表停了；重新走表的时刻是分开后的第一句话。往前看，这条的酝酿以周计：揉头、牵手、靠肩，每一条都是它的铺垫里程。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 楼道声控灯灭的那一下 · 车 ✓ 里熄火之后 · 吵完架的静默里 · 门 ✓ 关上的瞬间 |
| 谁先动 | 她先动，是她终于给自己批了这个准 · 他先动，是[十 · 第一次主动](#十--第一次主动)的毕业考 |
| 写什么 | 过程不写，写周边：呼吸的乱拍 · 距离清零前的迟滞 · 手停在半空不知道放哪 |
| 第一句话 | 玩笑型（「你睫毛刮到我了」）· 确认型（「所以，现在算……」）· 她的专属型：「重来。刚才那个不算数，太仓促。」 |

「重来」是她风格的定调句：连这件事她都要一个合格版本，而他求之不得。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先动 | 她 | 他（他先动的版本要写足那半秒的等待：等她的默许） |
| 之前的状态 | 甜着 | 吵着（吵到一半的吻是断句手段，用之前想清楚这一笔的后果） |
| 场合 | 私下 | 被撞见（转 [14-社交与公开 · 公开](14-社交与公开.md#四--公开)的被动版） |
| 之后 | 顺理成章 | 有人慌了（落荒而逃的那个隔天要自己回来，接 [11-初遇与确立 · 试探边界](11-初遇与确立.md#七--试探边界)的回摆机制） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「重来」出口时主导权的回收 | 毕业考那一步迈出去的瞬间 |
| 内心 | 批准自己，比批准任何一个项目都难 | 退路没了。太好了。 |
| 好的处理 | 她先动，也给他留了后退的半步 | 他先动，那半秒的等待写满 |
| 写崩 | 写成流程验收 | 写成猛虎扑食 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 帷帽掀起的那一下 · 却扇礼的私人版：没有宾客，她自己伸手挪开了那柄扇 |
| 修仙 | 渡灵息的公事规格被做成了私事；「这不是功法里的渡法」「我知道」 |
| 星际 | 舱外作业两层面罩相抵的「吻」先来；真的那次留在舱内重力恢复的瞬间，失重的头发落下来的时候 |

#### 写崩的三种方式

1. 吻本身写三段。 表停着，笔写周边。
2. 跳过第一句话。 定调句是这条的下半场，缺了它这场戏就没有收尾。
3. 当成全书高潮。 它是本卷的毕业礼，不是故事的终点站。
