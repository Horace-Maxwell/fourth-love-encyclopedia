# 身体接触

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**谁先伸手，谁承担被拒绝的风险。**

---

## 触碰的权力语法

这一类里，每一次身体接触都在回答两个问题：谁发起，谁允许。

| 组合 | 读作 |
|---|---|
| 她伸手，他接受 | 常态。她说了算，他听 |
| 她伸手，他躲了一下 | 不对劲，出事了 |
| 他伸手，她接住 | 他开口，她点头 |
| 他伸手，她没接 | [03-撒娇与讨哄 · 撒娇失败](03-撒娇与讨哄.md#十--撒娇失败) |
| 他伸手，她主动迎上 | 关系要变天了 |

「他伸手」这一栏最难写。弱势那方主动碰人，得豁出去。这股劲儿你必须写到字面上，不然读者根本不知道他冒了多大险。

| 反应族 | 作品数 | 占比 |
|---|---:|---:|
| 拥抱 | 1,862 | 64.3% |
| 牵手 | 904 | 31.2% |

拥抱是全部反应族里最高的一族，牵手只有它的一半。牵手比拥抱难写，因为得双方同时同意。

## 一 · 揉头

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：讨哄 54.4%

**骨架**｜最短的奖励。一秒钟，什么都不用说。

#### 节拍链

他做对了事／难过了 → 她抬手 → 他不自觉低头 → 揉乱 → 把头发理回去

#### 时间轴

他顶着这头乱发晃一下午，谁提醒他都不听，写的时候让这个细节自己发酵。抬手、落下、揉乱、收回，四步拆开写，别一笔带过。动作一秒，余温一天，差出来的那点时间就是甜味。真正揉他头发那一下，才落得下去。

#### 揉头的语义分层

同一个动作，力度和时长完全改变含义：

| 力度／时长 | 读作 |
|---|---|
| 快速拍两下 | 敷衍或调侃 |
| 揉乱 | 亲昵，带一点欺负 |
| 手停在头顶不动 | 郑重。这一档最重 |
| 顺着往下摸到后颈 | 亲密度跃升 |
| 揉完把头发理回去 | 她在意他的体面 |

「揉完理回去」是最好的一个细节。 揉乱是亲昵，理回去是尊重，两个动作连在一起就把关系说完了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 高度问题 | 他比她高，所以她得仰头／他得低头，低头这动作本身就说明谁让着谁 |
| 他的配合 | 他会不自觉低一点头 · 这习惯比说啥都管用 |
| 场合 | 他办成了事 · 他难受 · 路过顺手 · 旁边有人他会愣一下 |
| 他的反应 | 眼睛眯一下 · 耳朵 ✓ 红 · 装没事接着干手里的活 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 场合 | 私下 | 当众（他会僵） |
| 她的意图 | 奖励 | 安抚 |
| 高度处理 | 她踮脚 | 他低头 |
| 他的反应 | 享受 | 躲开（有事） |

「他低头」这个动作在古代女尊设定里权重极高。身高差本是生理事实，低头是主动配合，那是自愿的姿态。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他会自动低头 | 她手放上来那一秒 |
| 好的处理 | 她揉完把头发理平 | 他低头了，但不承认自己在等 |
| 写崩 | 写成摸宠物 | 写成幼儿化 |

宠物化是这一族最大的雷。判据：这个动作里他有没有保留自己的意志。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 抚发／替他正冠／指尖点在他额上 |
| 修仙 | 以灵力拂过他发顶／替他理正束发的簪 |
| 星际 | 隔着头盔的那一下／她摘了手套才摸 |

「她摘了手套才摸」是星际版的最强写法：多一个动作，就多一层郑重。

#### 写崩的三种方式

1. 写成宠物互动。 见上。
2. 每章都揉。 高频会让它贬值成口头禅。
3. 省略他低头。 那个下意识的配合是全条最好的东西。

## 二 · 牵手

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：牵手 31.2%

**骨架**｜牵手得两个人同时点头，所以比抱一下难多了。

#### 节拍链

找借口（人多／天冷）→ 伸手 → 那一秒 → 她握紧一点作为回答 → 到路口谁都没松

#### 时间轴

借口找好了，心理建设按分钟算。人多那段路走完，就没机会了。倒计时一直压着他，直到牵上之前。到路口，就是这条路的全程。牵上之后，时间变了流速。明明只有三百米，两个人硬是走出了三站地的感觉。

#### 牵法的语义

| 牵法 | 谁主导 | 读作 |
|---|---|---|
| 她握他手腕 ✓ | 她 | 带走。最有力，也最不像牵手 |
| 她握他手掌 | 她 | 常规 |
| 十指相扣 | 双方 | 平等，不容易松开 |
| 他勾她小指 | 他 | 试探，她可以装作没感觉 |
| 他把手放进她口袋 ✓ | 他 | 求她收留，还留了拒绝的余地 |
| 她把他的手塞进自己口袋 | 她 | 最黏糊的一种 |

「握手腕」和「握手掌」的差别值得单独写一场。 握手腕是控制，握手掌是同行。一个角色从握他手腕改成握他的手，这个变化可以承载一整条成长线。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 口袋 ✓ · 手套 ✓ · 手腕 ✓ · 掌心 ✓ · 指尖 ✓ |
| 触发场合 | 过马路 · 人多 · 天冷 · 他心情不好 · 啥理由都不用找 |
| 松开的时机 | 谁先松手，谁心里有鬼 |
| 温度 | 他手凉／她手凉，谁把谁的手焐热 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先伸手 | 她 | 他（更难，也更重） |
| 借口 | 有（人多、天冷） | 没有 |
| 场合 | 私下 | 街上（他会紧张） |
| 松开 | 到了目的地自然松 | 谁都没松，走过了路口 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他的手在她掌心里动了一下 | 伸出去之前手心 ✓ 先出汗了 |
| 内心 | 他今天手好凉 | 她会不会甩开 |
| 好的处理 | 她握紧了一点作为回答 | 他伸手了，且没有找借口 |
| 写崩 | 写成她不假思索 | 写成他扭捏很久 |

「她握紧了一点」是最经济的回应：不用说话，一个力度就是答复。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 隔着袖子拉手／她带他上马车／扶他那一把 |
| 修仙 | 踩剑时他搂她腰／她拽他迈过阵眼 |
| 星际 | 飘起来时互相抓手／同拴一根安全绳 |

#### 写崩的三种方式

1. 写得太随意。牵手在这一类里是有分量的动作，随手牵会让它贬值。
2. 省略犹豫。他伸手之前那一下，就是这条的内容。
3. 只写她主动。他主动的那一版才是难得的。

## 三 · 后颈

`T` ｜ 无预警 ｜ 全谱系（女A男O 尤强）｜ 语料频次：拥抱 64.3%

**骨架**｜后颈在这个类型里最有讲究。

#### 节拍链

她的手搭上去 → 他僵住 → 呼吸变了 → 拇指按一下 → 五指收拢 → 他自己低了头

#### 时间轴

手搭上去之后，第一拍他僵住，第二拍呼吸变浅，第三拍拇指按下，第四拍五指收拢。每拍之间隔多久，她说了算。烈度停在第几档，写到第几拍收手就行。这段不掐分钟，只数呼吸。以呼吸为拍。

#### 为什么是后颈

| 原因 | 说明 |
|---|---|
| 看不见 | 被碰的人没法防备，只能信你 |
| 要低头才能被碰到 | 光这个姿势，就已经是认了 |
| 猫的提法 | 大家一听就懂，是“随人摆弄”的意思 |
| ABO 设定 | 腺体就在那儿，天生就是要害 |

这四条叠加，让后颈成为这个类型里最短的权力宣言。 碰一下，什么都说了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 后颈 ✓ · 领口 ✓ · 发梢 ✓ · 手腕 ✓ |
| 她的动作梯度 | 手搭上去 → 拇指按一下 → 五指收拢 → 把他往下带 |
| 他的反应梯度 | 僵住 → 呼吸变了 → 低头 → 完全放松 |
| 场合 | 私下 · 有人在，力度轻，意思更重 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 力度 | 轻轻搭着 | 使劲按住 |
| 意图 | 哄一哄 | 拦下来，他刚要开口就被她一把按住 |
| 他的反应 | 听话 | 愣住，说明俩人还没那么熟 |
| 设定 | 一般情况 | 女A男O（有腺体，见 [03-世界观设定](../03-世界观设定/)） |

「制止」这个用法很好：他正要说一句不该说的话，她的手搭上去，他就停了。 全程没有台词。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 掌心 ✓ 下面那一下绷紧然后松开 | 她的手放上来的时候我在想什么 |
| 好的处理 | 她只是放着，没使劲 | 他低了头，是他自己低的 |
| 写崩 | 写成管人那种压法 | 写成身子自己不听使唤 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 摸他脖子／帮他整衣领／手指按在他喉结下面 |
| 修仙 | 神识压进他识海／后颈留个契印 |
| 星际 | 脖子后面有接口／她伸手盖上去 |
| 女A男O | 腺体 · 临时咬一口 · 放点信息素安他 |

#### 写崩的三种方式

1. 写成暴力压制。力度要轻，含义才重。
2. 每次接触都用后颈。用多了就没分量了。
3. 配大段解释。这个动作自带全部信息，解释是浪费。

## 四 · 靠肩

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 64.3%

**骨架**｜他把自己交出去多少，就是信你多少。

#### 节拍链

同乘／同坐 → 他试着挨过来 → 她没动 → 他把重量交出去 → 睡着头滑下来 → 她扶住

#### 时间轴

她没反应。先给三成，过五分钟再给到七成。等她睡着了才算全款。重量是分批次靠过来的，不是一次给完的。一上来就全给的那是装。挨着试一下价。给得越慢越像真的。分三批慢慢靠过来的，才是真扛不住。

#### 重量的刻度

| 姿态 | 交出的重量 | 读作 |
|---|---|---|
| 头挨着，还使着劲 | 几乎没有 | 试探 |
| 完全靠上去 | 全部 | 放松 |
| 睡着了，头滑下来 | 无意识 | 最深的信任 |
| 她扶住那个滑下来的头 | — | 她接住了 |

「睡着了头滑下来」这一档最好用，因为它是无意识的：他没有决定信任她，他的身体替他决定了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 车里 · 沙发上 · 地铁上 · 看电视时 |
| 身高差处理 | 他高，就得弯腰低头／她得踮脚仰头 · 这点不方便本身就是戏 |
| 她的反应 | 不动了 · 换个姿势让他靠得舒服点 · 手机举远点免得晃 |
| 时长 | 她胳膊麻了，但没挪 |

「胳膊麻了但没动」是这条最好的一句。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁靠谁 | 他靠她 | 她靠他（少见，且极有力） |
| 有意无意 | 有意 | 睡着了 |
| 她的处理 | 让他靠 | 把他的头扶正（更亲昵） |
| 场合 | 私下 | 公共场所 |

「她靠他」在语料里很少见。这写法不掉她的价，反而说明她再强也有个能歇口气的地方。强势那方也得有个能靠一靠的肩膀，这事值得写。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 肩上压着的那股劲 | 靠过去之前那一下迟疑 |
| 好的处理 | 她胳膊麻了也没挪开 | 他靠上去了，也没说对不起 |
| 写崩 | 写成了她扛着累赘 | 写成了他黏着不放 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 车驾里靠着她／枕在她膝上／趴她案边睡着了 |
| 修仙 | 打坐时靠她背上／御剑时搂她腰 |
| 星际 | 长途飞行睡休眠舱／她肩甲被他靠出个坑 |

#### 写崩的三种方式

1. 写成她嫌重。 那是另一种关系。
2. 让他一靠就睡。 犹豫的那一下要留。
3. 只写单向。 她也需要靠一次。

## 五 · 膝枕

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 64.3%

**骨架**｜他躺下来，头枕在她腿上。这姿势，他啥也干不了。

#### 节拍链

她拍了拍腿 → 他犹豫 → 躺下 → 抓住她衣角 → 她的手放在他额头 → 闭眼 → 谁都不想起来

#### 时间轴

这个姿势没有任何产出。他不能看手机，角度不对。她腿会麻。从躺下到起身，这段时间全是奢侈品。每多躺一分钟，都是两个人合谋浪费掉的。她腿麻到什么程度还不叫他起来，这个程度，就是爱的计量。

#### 姿势的语法

膝枕是这一族里唯一一个完全放弃视野和行动力的姿势。他躺着，看不见门，起不来，只能看见她的下巴。

| 附加动作 | 效果 |
|---|---|
| 她低头看他 | 对上眼，最亲 |
| 她看别处（手机、书） | 陪着，但不搭理，更日常 |
| 她的手放在他额头 | 她说了算 |
| 他闭上眼 | 全交给她了 |
| 他抓着她的衣角 | 他还是怕 |

「他抓着衣角」这个细节，全篇最好。整个人都交出去了，手里还留着那么一点攥着，说明这信任是他自己咬牙给的，是他自己挣来的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 沙发 ✓ · 膝盖 ✓ · 毯子 ✓ · 台灯 ✓ · 她手里的书或手机 ✓ |
| 触发 | 他累了 · 他难受 · 她拍拍自己的腿，招呼他过来 |
| 她的动作 | 摸他耳朵 ✓ · 拨他头发 · 什么都不干 |
| 收尾 | 他睡着了 · 她腿麻了 · 谁都不想动 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁发起 | 她先动的手 | 他自己凑过来 |
| 她做什么 | 光顾着看他 | 忙自己的 |
| 有没有话 | 聊几句闲天 | 一句不说 |
| 收尾 | 他睡着了 | 他醒了，又躺回去 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 腿上压着的感觉和热乎气 | 躺下去那一下臊得慌 |
| 好的处理 | 她拍了拍腿，啥也没说 | 他躺了老半天才合眼 |
| 写崩 | 写成当妈哄孩子 | 写成装嫩卖乖 |

母性化和幼儿化是这条的双雷。 判据：他是一个累了的成年人，不是一个需要哄的孩子。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 枕在她膝上／她替他掏耳／榻上 |
| 修仙 | 靠着她入定／她替他梳理灵脉 |
| 星际 | 低重力舱里他浮着，头抵着她的膝 |

#### 写崩的三种方式

1. 写成哄孩子。 见上。
2. 加太多对话。 这条要静。
3. 让它必然通向别的。 它可以自成一场。

## 六 · 量身高

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 64.3%

**骨架**｜他比她高一头，在这设定里算个梗，也是颗小糖。

#### 节拍链

起因（够不到／合照）→ 背靠背 → 他不动声色地屈膝 → 她假装没发现 → 他自己蹲下来

#### 时间轴

把「第几次量」记下来，第一次是玩笑，第十次成了日常。日常就是归处。身高差始终是那几公分，每次量，数字不变，变的是他屈膝的熟练度，一年比一年自然。仪式感换了千百种，归处还是那几公分的距离。

#### 为什么这条特别

这个类型的看点，说白了，就是“人高马大，但偏偏在下面”那层反差。他明明更高更壮，位置却偏偏是低的。量身高这个动作，恰好把这层反差一下摆到明面上来，笑一笑也就带过去了。

处理这个错位的方式，暴露了作者的功力。

| 处理 | 效果 |
|---|---|
| 他弯腰配合 | 他把优势主动交出来 |
| 她踮脚 | 她不介意示弱 |
| 她拉他下来 | 她直接征用他的身体 |
| 他自己蹲下 | 最好的一种 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 背靠背站着 · 在门框上比个子 · 她够不着高处的东西 · 拍合照时 |
| 道具 | 镜子 ✓ · 门框 · 椅子 ✓（她踩上去）· 她穿的鞋 |
| 他的配合 | 悄悄弯点腿 · 装自己也没多高 |
| 她的反应 | 不服气 · 要不就直接把他拽下来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 差距 | 一头 | 半个头 |
| 他的态度 | 得意，难得能显摆一下 | 小心着不让她觉得被压 |
| 她的反应 | 逗他玩 | 直接把他按矮 |
| 场合 | 私下 | 有外人在，他会挺直腰，摆出架势 |

「他小心翼翼地不让她觉得被压」这个心理很值钱。他知道自己的身体优势可能构成压迫，所以主动收着。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看见他偷偷屈膝 | 就这一件事能让他乖乖低头 |
| 好的处理 | 她当没看见 | 他得意三秒，自己蹲下了 |
| 写崩 | 写成她觉得自己配不上 | 写成他拿身高压人 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他侍立时总矮她半阶／跪坐时刚好跟她平视 |
| 修仙 | 他御剑时飞低一截／化形时把自己变小 |
| 星际 | 他把座椅调矮／在舱里老习惯低头 |

古代女尊版的「跪坐时正好与她平视」是极佳的写法：礼制要求的姿势，恰好制造了平等。

#### 写崩的三种方式

1. 写她的痛点。 身高差是甜点，不是伤口。
2. 让他用身高压人。 那他就不是这个类型了。
3. 写得太长。 三句话的事。

## 七 · 系扣子

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 64.3%

**骨架**｜她替他整了整衣服，这动作搁哪儿都是明摆着「这人归我管」。

#### 节拍链

出门前 → 他打了两次都不对 → 她接过那一端 → 他低头 → 三次才打好 → 她拍拍他胸口

#### 时间轴

喉结动那一下，她分了心。第二下没打准，确实手生。第一下打下去，俩人都没急着走。出门的时间表在催，迟到五分钟，值。第三下，磨蹭得明明白白。三次打不好，时间翻了三倍。

#### 为什么整理衣着这么有力

因为它默认了她有权处置他身上的东西，而他站着不动。

| 动作 | 力度 |
|---|---|
| 替他理领子 | 日常 |
| 替他系扣子 | 亲密 |
| 替他打领带 | 最有力，距离最近，时间最长 |
| 替他挽袖子 | 带一点占有 |
| 拽他领口把他拉近 | 从整理变成征用 |

最后一行是分界。 前四个是照料，最后一个是权力动作。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 扣子 ✓ · 领口 ✓ · 袖子 ✓ · 衬衫 ✓ · 外套 ✓ · 围巾 ✓ · 镜子 ✓ |
| 距离 | 打领带时俩人挨得特别近 · 他得低头 · 呼吸全扑在她额前的碎发上 |
| 他的动作 | 手垂着没处搁 · 气都不敢喘 · 眼神乱飘不知道看哪儿好 |
| 场合 | 出门前 · 要参加正式场合 · 她亲手给他挑的那件 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁给谁 | 她给他 | 他给她，手会抖 |
| 场合 | 私下 | 当着人，效果翻倍 |
| 熟练度 | 熟练 | 她头回打领带，打了三回 |
| 收尾 | 拍拍他胸口 | 拽住领带把他拉下来 |

「打了三次」比「熟练地打好」好：三次意味着三分钟，三分钟意味着他站着不动了三分钟。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他心跳声隔着衬衫都能摸到 | 她指尖碰到喉结 ✓ 那一下 |
| 好的处理 | 她拍两下，说没事了 | 他半天没动弹 |
| 写崩 | 写成伺候人的老妈子 | 写成他像个摆件 |

方向搞反了这条就废了。她整理他是所有权，他整理她是讨好，两种都能写，但读感完全不同。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 替他正冠／系腰带／整衣襟，衣冠代表身份，替他整就是认他 |
| 修仙 | 替他束发／系上她的剑穗 |
| 星际 | 替他扣上护甲／把他的徽章扶正 |

放到古代背景里，衣服即阶层。外人扫一眼，谁替谁正衣冠、系腰带，便知这段关系里谁说了算。见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。

#### 写崩的三种方式

1. 写成服务。这是权力动作，不是家务活。
2. 省略他不知道手往哪儿放。那种局促是全篇最出彩的地方。
3. 让他配合得太顺溜。头一回得笨手笨脚才像话。

## 八 · 被抱起来

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 64.3%

**骨架**｜他能轻松把她抱起来，反过来基本不行，这段写的就是这个不行。

#### 节拍链

他喝多了／受伤 → 她要抱 → 抱不动 → 改成搀 → 他悄悄用脚借力 → 两人一起摔进沙发

#### 时间轴

他借力的时候，手刚搭上来，步子已经乱了。五拍一气呵成，从「我来」到摔进沙发，前后顶多两分钟。俩人一块儿倒，先头架势拉满，走三步就废，改成搀着，反倒顺了。笑点全压在这节奏上，一慢，喜感就漏了，泪点也砸不出来。这场的节拍，就是喜剧的命根子。

#### 三种解法

这条在这一类里有一个物理难题：她多半抱不动他。处理方式分三档：

| 解法 | 说明 | 适用 |
|---|---|---|
| 一 不抱，改姿势 | 她扶他、背他、半拖着他走 | 现实向，最好用 |
| 二 设定给力 | 修仙／星际／女A：她力气真够大，抱得动 | 幻想向 |
| 三 他配合 | 他本来能自己走，偏让她扶着 | 最有味道 |

第三档最好。 他配合被搀扶这件事，比她真的抱得动更能说明关系。

#### 可用细节

| 类 | 内容 |
|---|---|
| 姿势 | 他胳膊搭她肩上 · 她手搂着他腰 · 他半边身子压过来，她心里有数 |
| 场合 | 他喝大了 · 他挂了彩 · 他睡着了她得把人弄床上去 · 他装的 |
| 她的动作 | 试了试抱不动 · 干脆改成拖 · 俩人都乐了 |
| 他的配合 | 偷偷拿脚蹬地 · 装得跟全靠她似的 |

「悄悄用脚借力」是这条的技术核心：他既让她赢了，也没让她累着。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她抱不抱得动 | 抱得动（设定支撑） | 抱不动，改姿势 |
| 他配不配合 | 配合 | 真的失去意识 |
| 场合 | 家里 | 外面（有观众） |
| 收尾 | 顺利到床上 | 两个人一起摔在沙发 ✓ 上 |
| 方向 | 她抱他（本条正题） | 他背她（她喝醉、崴脚、困倦的标准收尾——少数循传统脚本运行的搬运方向，与 [29-微小仪式拾遗 · 拧瓶盖与够高处](29-微小仪式拾遗.md#七--拧瓶盖与够高处)同属「力气分工保留区」。她在他背上照旧发号施令，位置换了，语法没换） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他比看着沉 | 她来抱我，我搭不搭手 |
| 好的处理 | 她试了，不成，换招，也不恼 | 他顺着借了力，没点破 |
| 写崩 | 写成她天生神力 | 写成他装软讨心疼 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她扶他上马车／唤人抬进去，她亲自扶着走完最后几步 |
| 修仙 | 御剑载他／灵力托起 |
| 星际 | 低重力下她真的抱得起来 |

星际低重力和修仙灵力，都能解决物理问题。但物理问题一解决，第三档的味道就没了。两种都写。

#### 写崩的三种方式

1. 给她非人的力气，却不给设定支撑。会出戏。
2. 让他毫无自尊地被抱。他得有那一下挣扎。
3. 写成公主抱的性别反转爽点。反转本身不是内容，配合才是。

## 九 · 睡姿与占地盘

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：就地睡着 52.8%

**骨架**｜睡一张床，身体自己会谈判。

#### 节拍链

各睡各的 → 他往她那边挪 → 她伸手把他捞过来 → 半夜姿势变了 → 早上醒来两人都尴尬

#### 时间轴

入睡前排好的阵，醒来才知道结果。单场谈判以夜为单位，真正落定的只有两个时点。其他的挪移，都发生在两人都不在场的时候，也就是睡着的时候。身体连夜谈成的条款，意识醒来后照单全收，像一份清晨的勘验报告。

#### 睡姿的关系图

| 睡姿 | 读作 |
|---|---|
| 各睡各的，中间有空隙 | 关系初期或者出事了 |
| 他往她那边挪 | 他在靠近 |
| 她伸手把他捞过来 | 她接受了 |
| 他整个人缠上来 | 完全的安全感 |
| 她睡在外侧（靠门） | 她在护着 |
| 他睡在外侧 | 他在护着，性质不同，值得写 |
| 醒来发现姿势变了 | 无意识的真相 |

「醒来发现姿势变了」是最好用的一条。 睡着之后身体做的决定，比醒着时的所有对话都诚实。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 被子 ✓ 谁抢走了 · 枕头 ✓ · 床 ✓ 的哪一侧 · 空调开几度吵一架 |
| 长期证据 | 床垫两边睡出坑了 · 他那侧床头堆满杂物 |
| 小摩擦 | 他睡觉不老实 · 她老踢被子 · 有人打呼噜 |
| 妥协的痕迹 | 她习惯了他的体温 · 他学会了躲开她头发 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 阶段 | 头一回同床，放不开 | 过了多少年，啥都不讲究了 |
| 谁靠近 | 他 | 她，睡着以后 |
| 位置 | 她睡里头 | 她睡外头，护着人的样 |
| 醒来 | 一晚上没动弹 | 俩人缠一块儿，醒了都臊得慌 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 半夜醒了，发现人已经被自己捞到怀里了 | 装睡，偷偷往她那边蹭了两寸 |
| 好的处理 | 她没把人推回去 | 他蹭完就僵住，怕露馅 |
| 写崩 | 写成她从头到尾说了算 | 写成他缠人缠得没分寸 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她睡里侧他睡外侧／同榻不同衾／他值夜守在榻边 |
| 修仙 | 双修时谁在上谁在下／她的洞府他有没有钥匙 |
| 星际 | 休眠舱挨着谁／谁的舱位离逃生口近 |

#### 写崩的三种方式

1. 写成情欲铺垫。睡姿本身就是一整场戏。
2. 只写一次。这条要靠对比：第一次 vs 半年后。
3. 省略无意识的部分。睡着之后的动作才是这条的价值。

## 十 · 第一次主动

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：拥抱 64.3% ＋ 牵手 31.2%

**骨架**｜他第一次主动碰她，这在族里算是最高那一档了。

#### 为什么是顶点

前面九条里，绝大多数动作是她发起的。这条反过来。

弱势方主动碰人，难点不在脸皮薄，在于他拿不准自己有没有这个资格。所以这个动作的分量，全压在他做之前那几秒的犹豫上。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 他想 |
| 2 | 他找理由：人多、天冷、她东西拿不下 |
| 3 | 理由不成立，他也知道 |
| 4 | 他还是伸手了 |
| 5 | 那一秒的空白 |
| 6 | 她的反应 |
| 7 | 他的松一口气／或者他把手收回来 |

#### 时间轴

倒计时还在走，绿灯亮起的那一刻，她刚好腾出手。人多的那阵子已经过去了，容不得他再拖。借口撑不过几秒，保质期一过，就得动手。伸手之前，他把时间按秒给够，碰完之后留一整拍的空白，再等一拍，看她的反应。

#### 可用细节

| 类 | 内容 |
|---|---|
| 找理由的动作 | 假装拿东西 · 先碰她袖子 · 先扯句别的 |
| 手的状态 | 手心 ✓ 出汗 · 手指 ✓ 冰凉 · 伸出去有点抖 |
| 那一秒 | 周围一下没声了 · 他在看她会不会躲 |
| 她的三种反应 | 接住 · 愣一下才接住（最好）· 没反应（转 [03 卷撒娇失败](03-撒娇与讨哄.md#十--撒娇失败)） |

「愣一下才接住」是最好的一版：那一愣说明她也没料到，也说明这件事对她也有分量。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 接触形式 | 牵手 | 抱住 |
| 有没有理由 | 有 | 没有，且他没找 |
| 她的反应 | 接住 | 反过来抱住他（她也在等） |
| 事后 | 谁都不提 | 她说了一句 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现这是他头一回主动 | 伸手之前那三秒 |
| 内心 | 我装得自然点行不行 | 她要躲开我咋收场 |
| 好的处理 | 她愣了下，还是握住了 | 他没找台阶下 |
| 写崩 | 写成她乐疯了 | 写成他一股脑冲上去不带犹豫 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他头一回拽她袖子／那下越了礼 |
| 修仙 | 他头回拿神识碰她／他先递了契约 |
| 星际 | 他头回没报备就解开安全索奔她来 |

古代版最有力，因为越礼是有代价的：他知道这不合规矩，他还是做了。

#### 写崩的三种方式

1. 这招得放在关系中间用，前面得攒够了她主动追你的戏份，到这儿再翻过来，才有效果。
2. 别用太早。那个愣神必须留着，让她马上热情接住。
3. 但一犹豫，这招就废了，所以别让她犹豫。

#### 示例（本库自撰，可直接改写）

> 绿灯还有二十秒。
> 他的手在口袋里攥了一路，现在拿出来了，悬在两个人之间那一小段空里。
> 十五秒。
> 他给自己想好了台阶：她要是没反应，就当是去按那个按钮。
> 十二秒。
> 她低头看了一眼，愣了半秒，然后把手放进他掌心。
> 她的手比他凉。他握住的时候，力气大了一点，又赶紧松开一些。

## 十一 · 第一次接吻

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：留痕 46.0%（吻的可见后果族；吻本身无法用词表单测，以留痕为代理指标）

**骨架**｜谁先动的手，动手前那半秒的对视，还有分开后谁先开口。

#### 节拍链

距离渐近，本卷前十条就是它的里程碑。然后对视超时，接着是那半秒，谁也没退。吻，分开，第一句话定调，之后的路就清楚了。

#### 时间轴

揉头、牵手、靠肩，每一条都算铺垫里程。真正引信是对视超时。正常对视两秒，第三秒起进入倒计时。吻本身不计时，写作时把表停了。重新走表的时刻，是分开后的第一句话。这条的酝酿以周计。从肢体接触一路堆到临界点。

「重来」是她风格的定调句：连这件事她都要一个合格版本，而他求之不得。

#### 写崩的三种方式

1. 吻本身写三段。表停着，笔写周边。
2. 跳过第一句话。定调句是这条的下半场，缺了它这场戏就没有收尾。
3. 当成全书高潮。它是本卷的毕业礼，不是故事的终点站。
