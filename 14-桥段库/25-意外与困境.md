# 意外与困境

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**意外不给人思考时间，而不经思考的反应是关系的测谎仪。**

---

## 这一族的两种用法

意外场面在本类型里干两件事：

| 用法 | 原理 | 代表 |
|---|---|---|
| 关门 | 把两个人锁进一个出不去的空间，日常的缓冲全部失效 | 停电、电梯、台风 |
| 测谎 | 危险的第一秒里，身体比脑子先动，动作暴露真实的优先级 | 地震、摔倒、急刹车 |

**测谎类要特别注意方向**：传统脚本的默认是「危险一来男人挡在前面」，这个本能在 GB 里不必消灭——他护她的身体反应和她拽他的判断反应可以同时发生，两种本能都是保护，谁也不高谁一头。写清这一点，这一族就不会滑回旧脚本。

| 节拍族 | 占比 |
|---|---:|
| 危险 | 18.0% |
| 停电 | 10.1% |
| 失联 | 23.0% |
| 困电梯 | 0.3% |

「困电梯」实测只有 0.3%——语料里几乎没人写。经典的强制独处装置竟然是片空地，低竞争位里的低竞争位。

## 一 · 停电的晚上

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：停电 10.1%

**骨架**｜整栋楼黑了。现代生活退回烛光时代，权力的道具全部断电。

#### 节拍链

灯灭（三秒的静）→ 确认范围（整栋都黑）→ 找光源 → 蜡烛点起来 → 无事可做的两个小时 → 来电的瞬间反而失落

#### 时间轴

手机 ✓ 电量就是沙漏。从 80% 一路往下掉，掉到 20% 时两个人做了个决定：关机，省着报修用。关机之后，这个夜晚才真正开始。

#### 为什么停电对这个类型特别好用

她的权力有一半架在现代性上：工作电话、日程、随时待命的处理能力。**停电把这些全部下线**：不能加班、不能回消息、连灯都要两个人一起找。这两个小时里她不是任何人的上司，只是黑暗里的另一半呼吸。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 蜡烛 ✓（去年生日剩的）· 手电 ✓ 在抽屉最里面 · 充电宝 ✓ 忘了充 · 冰箱 ✓ 停了嗡声，屋里静得陌生 |
| 找光源 | 两个人摸黑撞在一起 · 手机电筒对照 · 蜡烛点燃那下，脸在光里晃 |
| 无事可做 | 讲小时候停电的事 · 影子游戏 · 楼道里邻居的抱怨声成了背景乐 |
| 温度 | 夏天停电：热，摇扇子，扇着扇着扇到对方那边去了 |
| 来电 | 灯全亮，两个人对视，谁都没去关蜡烛 |

「来电了反而失落」是这条的落点：黑暗替他们推掉了全世界，灯一亮，世界回来了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时长 | 两小时 | 一整夜（夏夜阳台打地铺） |
| 阶段 | 热恋期 | 冷战期（黑暗里憋不住先开口的那个，接 [04-委屈与破防 · 冷战](04-委屈与破防.md#八--冷战)） |
| 谁怕黑 | 都不怕 | 有一方怕（且是她——她的怕只在停电夜暴露过这一次） |
| 收尾 | 来电 | 蜡烛烧完，摸黑睡去 |

「怕黑的是她」这一端值得写：她的所有恐惧都被白天的能干盖住了，黑暗面前人人平等。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 关机那一下，她二十年没关过机 | 烛光里她的脸比灯光里近 |
| 内心 | 天塌下来也得等来电再塌 | 别来电。再晚一点来电。 |
| 好的处理 | 她讲了一件小时候的事，他从没听过的 | 他把蜡烛往她那边挪了挪 |
| 写崩 | 写成她焦躁报修催电 | 写成刻意的烛光晚餐 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 风雨夜烛灭，府里灯火管制；她夜批的公文看不成了，第一次早睡 |
| 修仙 | 灵脉枯竭期，阵法全暗；满山修士第一次过凡人的夜 |
| 星际 | 舰船主电源检修，应急灯昏红；人工重力还在，喧嚣没了，第一次听见彼此的呼吸声 |

#### 写崩的三种方式

1. 停电十分钟就来电。 至少两小时，让无聊真的发生。
2. 拿蜡烛摆浪漫。 蜡烛是去年生日剩的，凑合用，才对。
3. 她全程焦虑工作。 关机那个决定必须做出来。

## 二 · 困在电梯

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：困电梯 0.3%（语料几乎空白的低竞争位）

**骨架**｜电梯停在九层半。一平方米出头的空间，出不去的四十分钟。

#### 节拍链

一顿（灯闪）→ 停住 → 按警铃 → 物业说四十分钟 → 空间开始变小 → 有人不对劲 → 撑过去 → 门开的白光

#### 时间轴

**警铃回复的「四十分钟」是明牌倒计时**。前十分钟还能说笑，二十分钟后空气变稠，最后十分钟一秒一秒过。

#### 谁不对劲，两个版本

| 版本 | 戏 |
|---|---|
| 他幽闭恐惧 | 平时什么都能扛的人，在一平米里出汗、呼吸变短；她把他的手按在自己手心，让他跟着她的呼吸数拍子 |
| 她幽闭恐惧 | 她死撑着不说，指节发白被他看见；他做了他这辈子最果断的一件事：把她的头按进自己肩窝，说「闭眼，我报时」 |

**第二版更值得写。** 她的怕从不示人，电梯不给她退场的空间——而他第一次当了那个报时的人。

#### 可用细节

| 类 | 内容 |
|---|---|
| 空间 | 镜面墙（到处是两个人的影子）· 楼层数字停在 9 · 警铃的电流声 |
| 物理 | 越来越闷 · 外套 ✓ 脱了垫在地上坐 · 共享一瓶没喝完的水 |
| 报时 | 「还有二十分钟」「你三分钟前就这么说」「……对，还有二十分钟」 |
| 门开 | 白光进来，两个人在地上坐着，维修工愣了一下 |
| 之后 | 从此她爬楼梯他也跟着爬，谁都不说为什么 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 关系阶段 | 已在一起 | 还是同事（这四十分钟顶三个月推进） |
| 谁不对劲 | 他 | 她 |
| 时长 | 四十分钟 | 两小时（手机没信号，家里人开始找，出去后一堆未接 ✓） |
| 之后 | 都爬楼梯 | 一起去坐了一次商场观光电梯（他提的，脱敏训练式的浪漫） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 肩窝里数着他报的时 | 她指节发白那一下，他决定装没看见并接管一切 |
| 内心 | 原来我可以把眼睛闭上 | 这一次轮到我说「有我在」以外的话 |
| 好的处理 | 她事后没有解释那四十分钟，他也没提 | 他报时报得极稳，出去后自己腿软 |
| 写崩 | 写成她全程冷静指挥 | 写成他惊慌失措靠她安抚（若写他怕，怕要写得有尊严） |

「出去后自己腿软」与 [16-危机与保护 · 她受伤了](16-危机与保护.md#四--她受伤了)的「做完才开始抖」同一条肌理：撑住是当下的，垮是事后的。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 地宫机关困住／山道塌方堵在山洞一夜 |
| 修仙 | 困阵之中灵力被封，两个修士变回两个凡人 |
| 星际 | 气闸舱故障，氧量倒计时——把「四十分钟」换成氧气表，压强翻十倍 |

#### 写崩的三种方式

1. 困五分钟就获救。 空气变稠需要时间。
2. 借机推进亲密。 电梯里只发生信任，别的出去再说。
3. 怕的一方写丢尊严。 怕要怕得具体，扛要扛得可见。

## 三 · 台风天

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：雨雪 ＋ 停电 10.1%

**骨架**|台风登陆前十二小时。囤菜、封窗、等它来。

#### 节拍链

预警发布 → 超市抢购 → 封窗胶带打米字 → 阳台的花搬进来 → 台风夜 → 风眼的诡异安静 → 过境后的清晨

#### 时间轴

**气象台的路径图就是钟**：距离登陆 12 小时、6 小时、登陆、风眼、离境。全城和他们一起等同一件事，这种「全城共时」是别的意外没有的氛围。

#### 可用细节

| 类 | 内容 |
|---|---|
| 抢购 | 超市泡面架空了 · 她拿了一把青菜，他拿了一兜零食，互相看了看对方的篮子 |
| 封窗 | 胶带米字谁贴得正 · 他够高处她指挥角度 · 贴完两个人隔着玻璃看云跑 |
| 台风夜 | 风声像有人在楼外喊 · 窗户每响一声两个人同时看过去 · 手机 ✓ 里的台风实时路径刷个不停 |
| 风眼 | 突然的安静，出太阳了 · 「结束了？」「还有后半场」 |
| 次晨 | 满街断枝 · 楼下那棵树倒了 · 两个人下楼帮忙抬树的邻里时刻 |

「互相看了看对方的篮子」，青菜与零食，一个抢购镜头写完两种人。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 强度 | 擦边过境（虚惊，零食白囤，欢乐向） | 正面登陆（停电停水，全套生存模式） |
| 状态 | 两人都在家 | 一方被困在公司回不来（台风版 [02-等待与错过](02-等待与错过.md#一--等门与热菜)，等待加上担忧的倍率） |
| 意外 | 无 | 窗被吹开一条缝，两人半夜合力堵（湿透，狼狈，笑场） |
| 次晨 | 帮邻里 | 补觉到中午，醒来世界如新 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 风最大的那一阵他把她的椅子往里挪了挪 | 她盯路径图的认真程度和看项目报表一样 |
| 内心 | 全城停摆。合法的停摆。 | 风再大点，明天也别上班了吧 |
| 好的处理 | 她把「合法停摆」过得心安理得 | 他半夜起来查了三次窗 |
| 写崩 | 写成她远程办公一整夜 | 写成灾难片式惊险 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 汛期洪讯，闭城三日；她的衙门口封了，头一回连过三日晨昏 |
| 修仙 | 天地灵潮过境，全山闭阵；阵里的人反而闲下来 |
| 星际 | 离子风暴过境，全舰静默航行；娱乐系统停摆，人和人只好互相说话 |

「娱乐系统停摆，人只好互相说话」，星际版一句话说破了这一族的原理。

#### 写崩的三种方式

1. 写成灾难片。 台风天的主体是等，不是险。
2. 略过风眼。 那段诡异的安静是天然的戏剧停顿。
3. 忽略全城共时感。 朋友圈 ✓ 里全城都在晒同一个米字窗，这个背景音要有。

## 四 · 地震那几秒

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：危险 18.0%

**骨架**｜摇晃只有十几秒。十几秒里做的事，两个人记一辈子。

#### 节拍链

第一下晃（是错觉吗）→ 确认（吊灯在晃）→ 那几秒的本能动作 → 停了 → 余震预期下的对峙 → 楼道或楼下 → 回家后的复盘

#### 时间轴

主震十几秒，余震预期两小时，复盘一辈子。三个时间尺度分开写：第一段只有动作，第二段只有神经，第三段才有语言。

#### 那几秒的本能，逐帧

开卷说过这一族的测谎原理，这条是主考场：

| 帧 | 他 | 她 |
|---|---|---|
| 第 1 秒 | 愣 | 愣 |
| 第 2 秒 | 扑过来把她压向桌下 | 拽着他的手腕往承重墙拖 |
| 第 3-10 秒 | 手护着她的头 | 反手把他的头也按下去 |
| 结果 | 两个人在桌子底下抱成一团，各自护着对方的头 | 同左 |

他的本能是用身体挡，她的本能是用判断带。两种保护在桌子底下撞在一起，谁也没让谁——这十秒是整个类型对「保护」一词的最终解释。

#### 可用细节

| 类 | 内容 |
|---|---|
| 物证 | 吊灯晃 · 杯子走到桌边 · 书倒了一排 · 猫先炸毛（宠物预警，接 [13-家庭与亲属 · 养一只](13-家庭与亲属.md#八--养一只)） |
| 桌下 | 两个人的呼吸都太响 · 他的手一直按在她后脑 · 她攥着他手腕的力道留了印 |
| 余震等待 | 楼道里的邻居 · 头盔、水、充电宝 ✓ 塞进一个包（她三分钟收好应急包，他看呆） |
| 复盘 | 「你刚才第一下是想干嘛」「压你桌底下」「我是想拖你去墙角」「……那咱们刚才在互相较劲？」笑场 |

「复盘笑场」是这条的出口：十秒钟的生死本能，用一场笑收进日常。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 震级 | 有感无损（虚惊为主） | 真出事（转 [16-危机与保护](16-危机与保护.md)，本条只管十秒与两小时） |
| 在哪 | 家里 | 各在两处（互相拨电话 ✓ 全线拥堵的那二十分钟，失联 23% 的极限版） |
| 本能 | 互相护 | 有一方那几秒懵在原地被另一方拽走（懵的可以是任何一方，别写成罪） |
| 复盘 | 笑场 | 有人后怕到半夜睡不着（接 [25-十 · 半夜的噩梦](#十--半夜的噩梦)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 后脑上他手掌的重量 | 手腕上她攥出的印子 |
| 内心 | 他扑过来的速度，比我的判断还快半秒 | 那半秒我什么都没想 |
| 好的处理 | 她承认他快了半秒，且不觉得这有什么问题 | 他没把那半秒当功劳 |
| 写崩 | 写成她淡定他慌乱 | 写成他护她护成单方面英雄 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 地动，梁上落灰；她拖他出屋的路线是每晚睡前默过的 |
| 修仙 | 灵脉震荡，护山大阵闪烁；两人第一反应都是先罩住对方 |
| 星际 | 舰体遭流星群，警报三秒；他把她按进缓冲椅的同时她把他的安全扣按死了 |

「同时给对方系安全扣」，星际版十秒本能的最佳镜头。

#### 写崩的三种方式

1. 十秒写成三页。 本能没有心理描写，只有动作。
2. 一方全程被保护。 两种本能要相撞。
3. 略过复盘。 笑场那段是十秒的着陆垫。

## 五 · 车子半路抛锚

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：危险 18.0% ＋ 旅行 35.0%

**骨架**｜前不着村后不着店，引擎盖冒烟。修不好，只能等。

#### 节拍链

异响（谁先听见）→ 靠边 → 开引擎盖（看不懂，但都看了）→ 打救援电话 → 等待的一小时 → 拖车来 → 后续

#### 时间轴

**救援电话说「一小时」，实际一个半**。这多出来的半小时是全条的赠品：荒路、暮色、双闪一下一下地闪。

#### 谁懂车，三种分配

| 配置 | 戏 |
|---|---|
| 她懂 | 她挽袖查线路，他举手机照明；路过司机摇窗喊「要帮忙吗美女」，被她一句「不用，水温传感器」怼回去 |
| 他懂 | 全书他专业领域高光之一（接 [16-危机与保护 · 他能做到的那件事](16-危机与保护.md#九--他能做到的那件事)）：平时安静的人趴进引擎舱，十分钟后车活了 |
| 都不懂 | 两个人对着引擎盖研究说明书，最没用但最好笑的一版 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 双闪的嗒嗒声 · 三角牌摆多远吵了一句 · 后备箱翻出来的全部家当 |
| 等待 | 坐在护栏上分一包饼干 · 暮色把影子拉长 · 手机 ✓ 信号一格 |
| 荒路 | 过路车的灯扫过来又扫过去 · 远处有狗叫 |
| 拖车 | 师傅一路唠嗑，两个人在后座挤着，莫名像逃难又像春游 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 地点 | 城郊 | 无人区（信号都没有，等待升格成小型生存戏） |
| 时机 | 平常周末 | 赶重要行程的路上（误事的焦虑压在等待上，谁先说「算了，误就误了」） |
| 修没修好 | 拖走 | 他修好了 |
| 后续 | 换车 | 没换，这台破车成了共同回忆载体，谁提卖车谁被瞪 |

「谁先说算了误就误了」是这条藏的考题：**放弃重要行程的决定由谁做出**：她做，是她第一次把「误事」二字说得轻松。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 护栏上那包分着吃的饼干 | 她说「误就误了」的轻松，装的，但她装了 |
| 内心 | 三个会议。算了，天挺好看。 | 我要是会修车就好了。回去学。 |
| 好的处理 | 她怼路人那句专业术语 | 他真的回去报了个班（多年后另一次抛锚，他修好了，闭环） |
| 写崩 | 写成她暴躁催救援 | 写成荒野遇险大逃亡 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 马车轴断在官道，前村后店都是三十里；车夫去借工具，两人守着车看了半宿星星 |
| 修仙 | 飞舟灵石耗尽迫降荒山；等传讯回音的一夜，生了火 |
| 星际 | 穿梭机引擎故障漂在航线外；救援 ETA 六小时，舱里只有彼此和一副旧扑克 |

#### 写崩的三种方式

1. 立刻获救。 多出来的那半小时才是正文。
2. 荒路写成惊悚。 狗叫就只是狗叫。
3. 懂车的一方炫技。 十分钟修好，一句「好了」，收。

## 六 · 迷路

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：旅行 35.0%

**骨架**｜导航说「已重新规划路线」第七遍。两个人对方向的分歧终于摆上了台面。

#### 节拍链

第一个错转弯 → 导航重规划 → 分歧出现（听导航还是听直觉）→ 越走越偏 → 停下承认迷路 → 问路或回头 → 意外发现

#### 时间轴

导航的「重新规划」次数是钟。第一遍是插曲，第四遍是分歧，第七遍是摊牌。

#### 分歧的结构

| 主张 | 谁 | 潜台词 |
|---|---|---|
| 「听导航」 | 通常是他 | 相信系统 |
| 「导航绕远了，往这边」 | 通常是她 | 相信判断 |
| 结果 | 谁对都行，关键在错的那方怎么认 | 认错的姿势是这条的正文 |

**她认错的样子是稀缺镜头**：判断错了方向的她停下车，沉默三秒，说「你导吧」，把方向盘边的决定权交出去，比十句道歉重。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 导航的机械女声 · 越来越窄的路 · 倒车入库都难的死胡同 |
| 气氛曲线 | 好笑 → 有点烦 → 沉默 → 有人先笑出声，气氛破冰 |
| 问路 | 谁下去问（下去的那个买了两瓶水回来递一瓶，和解仪式） |
| 意外发现 | 迷出来一家苍蝇馆子好吃到离谱 · 一片没开发的海 · 从此这条错路成了「我们的路」 |

「错路变成我们的路」是这条的落点：计划外的收获只属于迷过路的人。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁的错 | 她的判断 | 他的粗心（错峰认错，各有姿势） |
| 气氛 | 全程好笑 | 吵了一小场（迷路是压力测试的青春版） |
| 意外发现 | 有 | 没有，纯白跑，但白跑本身被过成了段子 |
| 场景 | 自驾 | 徒步山道（天色变暗，性质开始向险滑，及时收住） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「你导吧」三个字 | 她认错的三秒沉默，他没趁机说教 |
| 内心 | 我的方向感第一次输给机器 | 别笑。忍住。没忍住。 |
| 好的处理 | 她把那家苍蝇馆子记进了收藏 | 他笑完立刻找了台阶：「其实这条路风景好」 |
| 写崩 | 写成她死不认错 | 写成他阴阳怪气 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 官道岔口舆图对不上；她坚持走的近道遇上溪水暴涨，回头时他一句没提 |
| 修仙 | 秘境幻阵，方向感全废；她的剑气标记全被阵吞了，最后靠他数步子走出来 |
| 星际 | 跳跃坐标偏移，星图重算第七遍；偏出来的航线上撞见一片星云，全舰静默看了十分钟 |

「偏出来的航线撞见星云」，星际版的苍蝇馆子。

#### 写崩的三种方式

1. 迷路秒解。 重规划要攒到第七遍。
2. 分歧上升成大吵。 这条的吵是小火慢炖，笑声灭火。
3. 意外发现太神。 苍蝇馆子刚刚好，仙境就过了。

## 七 · 末班车没赶上

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：接送 37.0% ＋ 夜深 37.0%

**骨架**｜地铁口的卷帘门拉下来了。回家的路突然变成一个需要共同解决的问题。

#### 节拍链

狂奔 → 差三十秒 → 卷帘门 → 站在门口喘 → 盘点选项（打车排队一百多号·代驾·走回去）→ 做了个不理性的决定：走回去 → 五公里的夜路 → 到家天快亮

#### 时间轴

**五公里，一小时四十分钟的步行**。城市后半夜的时段感极强：烧烤摊收摊、洒水车、第一班环卫工——夜越走越深，再走着走着天边泛白。

#### 为什么「走回去」是对的决定

打车二十分钟能到，走路要两小时——**选慢的那个，等于给这个夜晚续了两小时**。谁提议走的，谁就是那个不想让今晚结束的人。

#### 可用细节

| 类 | 内容 |
|---|---|
| 门口 | 隔着卷帘门看见最后一班车开走 · 两个人喘得说不出话，先笑了 |
| 夜路 | 烧烤摊最后一单 · 便利店买的关东煮边走边吃 · 高跟鞋换成了便利店拖鞋（鞋拎在他手里） |
| 声音 | 洒水车 · 远处的货车 · 两个人的脚步声从错拍走到同拍 |
| 话题 | 走路时说的话和坐着说的不一样：第三公里说到了从没说过的事 |
| 天亮 | 到楼下时天边有点白，谁都不困 |

「脚步声从错拍走到同拍」，不用写一句心理，节奏自己完成了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提议走 | 他 | 她（她的不理性决定,一年一遇） |
| 距离 | 五公里 | 十二公里（走到一半后悔，出租车空车路过，两人对视，没拦） |
| 阶段 | 暧昧期（这一夜顶三个月） | 老夫老妻（重走年轻时那条路） |
| 天气 | 晴 | 走到一半下雨（接 [18-节令与天候 · 下雨](18-节令与天候.md#一--下雨)，狼狈翻倍，快乐翻倍） |

「空车路过没拦」是这条的钻石细节：理性给了第二次机会，两个人一致放弃。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 便利店拖鞋踩在马路上的声音 | 她的高跟鞋在他手里晃 |
| 内心 | 明早的会已经不重要到可笑 | 第三公里她说的那件事，她清醒时从没说过 |
| 好的处理 | 她把那双便利店拖鞋留下了 | 他没有点破第三公里那件事，走完了才提 |
| 写崩 | 写成她抱怨全程 | 写成他刻意制造错过末班车 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 宵禁鼓响，城门落锁；绕城根走到东门等启，一夜的城墙根 |
| 修仙 | 传送阵酉时关闭；山路四十里，御剑三刻钟，走路一夜——她说「走吧」 |
| 星际 | 末班摆渡舱错过；沿观景廊道步行穿过整个空港，舷窗外星河跟着走了一路 |

「御剑三刻钟，她说走吧」，修仙版把这条的选择题出得最直白。

#### 写崩的三种方式

1. 打车回家。 那就没有这条了。
2. 夜路写成危险。 后半夜的城市在这条里是温柔的。
3. 第三公里的话题点破。 让它说完就搁下，天亮再捡。

## 八 · 锁在门外

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：归家 46.0% ＋ 停电 10.1%

**骨架**｜钥匙在门里，人在门外。开锁师傅还有四十分钟到。

#### 节拍链

摸口袋（第一遍）→ 摸所有口袋（第三遍）→ 确认锁在里面 → 互相追责三十秒 → 找开锁 → 楼道里的四十分钟 → 门开

#### 时间轴

开锁师傅的「四十分钟」与 [二 · 困在电梯](#二--困在电梯)同构，但**气氛完全相反**：电梯是密闭恐惧，楼道是开放的无聊。同一个等待，两种质地。

#### 可用细节

| 类 | 内容 |
|---|---|
| 追责 | 「你出门没检查？」「钥匙 ✓ 一直归你管」——三十秒后同时收声，追责无意义 |
| 楼道 | 坐台阶上 · 声控灯 ✓ 隔两分钟熄一次，谁跺一下脚 · 邻居出门倒垃圾，打了个微妙的招呼 |
| 消磨 | 分吃包里仅有的半包饼干 · 翻手机 ✓ 相册杀时间，翻到了老照片 ✓（意外的回忆杀入口） |
| 门开 | 师傅三十秒开锁，两人看着那扇为难了他们一小时的门陷入沉思 |

「声控灯熄了谁跺脚」是这条的节拍器：每两分钟一次的小动作，把四十分钟数得见。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁忘的 | 他 | 她（她从不忘事，这次忘了——为什么忘，背后有事） |
| 时段 | 傍晚 | 凌晨两点（不敢叫师傅，蹲到天亮，狼狈加倍） |
| 等待质量 | 相册回忆杀 | 冷战期被锁在同一片楼道（想不和好都难） |
| 门开后 | 进门瘫倒 | 进门第一件事：配了三把备用钥匙，一把埋在花盆里（多年后花盆钥匙救过一次急，闭环） |

「她从不忘事这次忘了」，钥匙是引子，她最近的心不在焉才是正文。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 相册翻到三年前那张 | 声控灯又熄了，这次她先跺的脚 |
| 内心 | 我为什么会忘钥匙。我最近怎么了。 | 楼道也挺好，她哪儿都好 |
| 好的处理 | 她顺着照片说起了三年前 | 他把外套垫在台阶上那下很自然 |
| 写崩 | 写成互相埋怨升级 | 写成他破门而入显身手 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 门房睡死叫不开角门；两人翻墙未遂，坐门槛上等打更的 |
| 修仙 | 洞府禁制误触反锁；解阵要一炷香，两人坐在山门石阶看月亮 |
| 星际 | 舱门生物识别故障；工程组排队处理，两人坐在廊道地板上共享一副耳机 ✓ |

#### 写崩的三种方式

1. 追责追出真火。 三十秒封顶，然后一致对门。
2. 跳过等待直接开门。 楼道四十分钟才是正文。
3. 让等待太有内容。 这条的美德是无聊，回忆杀点到即止。

## 九 · 手机摔了

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.0%

**骨架**｜屏幕蛛网状裂开。慌的是里面的东西，跟钱没关系。

#### 节拍链

脱手（慢镜头的半秒）→ 捡起来（屏碎，还亮）→ 抢救式备份 → 彻底黑屏 → 送修 → 数据保住了没 → 换新机之后

#### 时间轴

**「还亮着」到「黑屏」之间的抢救窗口**是这条的心脏：十几分钟里优先备份什么，就是给手机里的东西排身价。

#### 抢救优先级暴露的东西

| 他先备份的 | 说明 |
|---|---|
| 相册 ✓ 里的一个加密文件夹 | 里面全是她（接 [19-玩闹与网络 · 拍照](19-玩闹与网络.md#九--拍照)：三百张的那批） |
| 一段聊天记录 | 从第一条「在吗」开始的全部（接 [19-二 · 聊天记录](19-玩闹与网络.md#二--聊天记录)） |
| 一条六十秒语音 | 她某年生日说的，他从没舍得开免提听 |

慌到手抖时先救什么，什么就是命根。她在旁边看着他的抢救顺序，比看十年日记还清楚。

#### 可用细节

| 类 | 内容 |
|---|---|
| 摔的瞬间 | 半空中试图接住的徒劳一抓 · 落地声全楼道都听得见 |
| 屏碎 | 蛛网纹里她的头像裂成三块 · 触屏半灵，滑动要用巧劲 |
| 维修店 | 「数据不保证」六个字让他脸白了 · 她在旁边补了句「多少钱都修」 |
| 结局 | 数据全回来了（他长出的那口气）· 或没回来（他盯着新手机空白相册的那一晚） |
| 新机 | 第一件事不是贴膜，是把她的号码存成第一个联系人 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁的手机 | 他的 | 她的（她的备份习惯完美，唯一没备份的是一段他的语音——她自己都不知道为什么单留在本地） |
| 数据 | 保住 | 没保住（那批照片没了，他说没事，半年后她偷偷重拍了一批同角度的） |
| 摔的场合 | 日常失手 | 为了接住摔倒的她，手机替她着了地（英雄事迹的最小单位） |
| 换机 | 换了 | 修好继续用，裂纹留着（「裂了才是我的」） |

「她偷偷重拍同角度的照片」，数据救不回来，人可以重演给他存。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他抢救备份的顺序 | 「数据不保证」那六个字 |
| 内心 | 排第一的那个文件夹是什么 | 三年的东西，三年的东西 |
| 好的处理 | 她那句「多少钱都修」没问修的是什么 | 他数据丢了没迁怒任何人 |
| 写崩 | 写成她趁机查手机 | 写成他崩溃三章 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 随身的木匣落水；晒干的信纸字迹晕开，他逐字重描 |
| 修仙 | 储物袋破了；散落的东西里他先扑向那枚她给的旧符 |
| 星际 | 个人终端损毁；数据舱恢复排期七天，那七天他魂不守舍像丢了半个人 |

#### 写崩的三种方式

1. 只写手机贵。 钱在这条里一文不值。
2. 抢救顺序不写。 那是全条的信息所在。
3. 数据丢失轻轻放过。 丢了就是丢了，重量要给足，然后用重拍那批照片来接。

## 十 · 半夜的噩梦

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：睡着 54.0% ＋ 夜深 37.0%

**骨架**｜凌晨三点，有人从梦里挣出来。另一个人醒了，或者装作没醒。

#### 节拍链

梦里（不写内容，只写外部）→ 挣醒 → 坐起来喘 → 确认现实（摸到身边的人）→ 对方的反应 → 三点钟的对话或沉默 → 重新睡去或等天亮

#### 时间轴

凌晨三点是一天里防线最低的时刻。白天说不出的话到了这个钟点自动降低门槛——这条本质上是一台「真话时间机」，噩梦只是启动键。

#### 梦的内容学

梦不用写全，梦醒后的只言片语就够：

| 他梦见的 | 泄露的 |
|---|---|
| 「梦见你走了」 | 深层不安全感（接 [04-委屈与破防 · 我是不是不够好](04-委屈与破防.md#九--我是不是不够好)） |
| 梦回某段旧事 | 原生家庭的债（接 [13-家庭与亲属 · 他的原生家庭](13-家庭与亲属.md#六--他的原生家庭)） |
| 说不出内容，只是抖 | 有些东西语言够不到 |

| 她梦见的 | 泄露的 |
|---|---|
| 白天那场事故重演 | 她的后怕全在夜里结账（接 [四 · 地震那几秒](#四--地震那几秒)） |
| 她极少做梦，这次醒来沉默 | 她的梦她自己消化，他只负责把水递过去 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 醒的瞬间 | 倒吸气 · 一把攥住被子 ✓ · 心跳声大到自己能听见 |
| 对方 | 其实早被惊醒，装睡三秒决定开口 ·「做噩梦了？」声音哑着 |
| 三点的对话 | 灯不开 · 声音都压着 · 说的话第二天都默契不提 |
| 动作 | 递水 · 把人往怀里带 · 手在背上一下一下拍，拍的节奏是哄的本能 |
| 重新入睡 | 换了个姿势，手被攥着睡到天亮，麻了也没抽 |

「手麻了也没抽」，这条的全部温柔浓缩在一只麻掉的手上。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁做梦 | 他 | 她（罕见，因此每次都重） |
| 说不说 | 三点真话 | 什么都不说，只是靠着（语言够不到的那种梦） |
| 频率 | 偶发 | 一段时期反复做（背后有事没解决，梦是催单） |
| 第二天 | 默契不提 | 她白天约了个心理咨询——把梦当成该处理的事处理，非常她 |

「她把噩梦当待办事项处理」是她的性格签名：**连脆弱都要立项解决。** 而他默默把这一条也记进了「她可爱的地方」清单。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他梦里喊的那半个字 | 她醒来后那反常的十分钟沉默 |
| 内心 | 白天的他从来不提这些 | 别问内容。递水。拍背。 |
| 好的处理 | 她听完那句「梦见你走了」，回答是往里挪了半个身位 | 他学会了不问「梦见什么」只问「要水吗」 |
| 写崩 | 写成三点钟深度谈心 | 写成他夜夜噩梦卖惨 |

「回答是挪了半个身位」，三点钟的语言是身位不是句子。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 更漏三响，帐里挣醒；她只低声说了句「有我」，这两个字白天她从不说 |
| 修仙 | 心魔入梦，修为越高梦越凶；他守着她入定，替她挡了一夜的梦 |
| 星际 | 冬眠舱苏醒后的梦境残留；舱内灯自动调到最柔，系统这点比人贴心 |

#### 写崩的三种方式

1. 把梦的内容写全。 梦只许露一角。
2. 三点钟聊到五点。 三句封顶，剩下的交给身位。
3. 噩梦当廉价虐点反复用。 反复做梦必须指向一件待解决的实事。
