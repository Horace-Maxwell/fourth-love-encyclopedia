# 意外与困境

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次数据来自[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，统计基数是 2,894 部独立作品。文里的百分比是编写时实测的，挖掘器扩充后节拍族会有小幅变动，最新数字以 13-07 为准（用 `run.py mine` 重跑更新）
> 这一族写意外里的两个人：停电、困电梯、台风、地震、抛锚、迷路、错过末班车、被锁在门外、摔坏手机、半夜做噩梦。意外来得急，人来不及想，下意识做出的反应最能看出这段关系是什么样。

## 这一族的两种用法

意外场面在这个类型里有两种用处：

| 用法 | 原理 | 代表 |
|---|---|---|
| 关门 | 把两个人关进一个出不去的地方，平常那些缓冲全都用不上 | 停电、电梯、台风 |
| 测谎 | 危险来的第一秒，身体比脑子先动，谁最要紧，动作一下就露了 | 地震、摔倒、急刹车 |

他护住她是身体先动，她拽开他是判断先动，两件事可以同时发生。老脚本默认「危险一来男人挡在前面」，这种本能在 GB 里用不着删掉。两种本能都是在保护对方，分不出高低。把这层写明白，故事就不会退回老脚本，测谎类尤其要看清方向。

| 节拍族 | 占比 |
|---|---:|
| 危险 | 18.0% |
| 停电 | 10.1% |
| 失联 | 23.0% |
| 困电梯 | 0.3% |

「困电梯」实测只有 0.3%。这么经典的强制独处桥段，语料里几乎没人写，竞争很小。

## 一 · 停电的晚上

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：停电 10.1%

**骨架**｜整栋楼突然停电，灯和电脑全灭了，门禁也失灵，只能摸黑点蜡烛。

#### 节拍链

灯灭（安静三秒）→ 看看是哪儿停了（整栋都黑）→ 找光 → 点上蜡烛 → 两个小时无事可做 → 来电那一刻反倒有点失落

#### 时间轴

盯着手机电量从 80% 往下掉，掉到 20% 时两人商量好：关机，留着电报修。手机一关，这个晚上才算开始。

#### 为什么停电对这个类型特别好用

这两个小时里她不是谁的上司，只是黑暗里另一个在喘气的人。她平时的权力全靠手机撑着：工作电话、日程、随叫随到。**一停电全没了**，灯要两个人一起摸黑找，加班和回消息更别想。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 蜡烛 ✓ 去年生日剩的 · 手电 ✓ 在抽屉最里面 · 充电宝 ✓ 忘了充 · 冰箱 ✓ 不响了，屋里静得发慌 |
| 找光源 | 摸黑撞到一块 · 拿手机电筒互相照 · 蜡烛点着的那一下，两张脸在火光里晃 |
| 无事可做 | 讲小时候停电的事 · 玩手影 · 楼道里邻居骂骂咧咧，听久了也就惯了 |
| 温度 | 夏天停电又热又闷，拿扇子扇，扇着扇着风就往对方那边去了 |
| 来电 | 灯一下全亮，两人对看着，谁都没去吹蜡烛 |

来电了，两人反而有点失落。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时长 | 两小时 | 一整夜，夏天在阳台打地铺 |
| 阶段 | 热恋期 | 冷战期（看黑暗里谁先憋不住开口，接 [04-委屈与破防 · 冷战](04-委屈与破防.md#八--冷战)） |
| 谁怕黑 | 都不怕 | 有一方怕，而且是她，她的怕只在停电这一晚露过一次 |
| 收尾 | 来电 | 蜡烛烧完，两人摸黑睡着 |

「怕黑的是她」这一端值得写，她所有的害怕都被白天的能干遮住了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 关机那一下，她已经二十年没关过机 | 烛光下她的脸比开灯时更近 |
| 内心 | 天塌下来也得等来电再塌 | 别来电。再晚一点来电。 |
| 好的处理 | 她讲了一件小时候的事，他从没听过 | 他把蜡烛往她那边推了推 |
| 写崩 | 写成她急着报修催来电 | 写成刻意摆的烛光晚餐 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 风雨夜里烛火全灭，府中宵禁，她熬夜要批的折子看不了，头一回一沾枕头就睡着 |
| 修仙 | 灵脉枯竭，护山大阵整个暗下去，满山修士头一回像凡人那样摸黑过夜 |
| 星际 | 舰船主电源检修，应急灯泛着红，重力还在，没人说话，两人头一回听见彼此的呼吸 |

#### 写崩的三种方式

1. 停电十分钟就来电。 至少停两小时，让人真的闲到发慌。
2. 用蜡烛营造浪漫。 蜡烛该是去年生日剩下的，凑合着用。
3. 她从头到尾惦记工作。 关机这个决定一定要做。

#### 可串接

前接：[17-同居与身体日常 · 两个人的作息](17-同居与身体日常.md#九--两个人的作息)
后接：[19-玩闹与网络 · 无聊的下午](19-玩闹与网络.md#十--无聊的下午)，那是有电时同样的一段空白。

#### 示例（本库自撰，可直接改写）

> 灯灭的那一秒，冰箱的嗡声也停了。屋子静得像被人捂住了耳朵。
> 「别动。」她说，「蜡烛在电视柜第二个抽屉。」
> 「你怎么知道？」
> 「去年你生日剩的。」
> 火柴划了三根才着。烛光晃起来的时候，他看见她把手机摁灭了，屏幕上还有十几条未读。
> 「不看了？」
> 「停电了。」她说得理直气壮，好像那些消息也跟着停了电。
> 蜡烛在茶几上淌下第一滴蜡的时候，谁都没说话。楼道里有邻居在骂物业，骂得字正腔圆，两个人同时笑出了声。

## 二 · 困在电梯

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：困电梯 0.3%（语料几乎空白的低竞争位）

**骨架**｜电梯卡在九楼半，地方不到两平米，四十分钟出不去。

#### 节拍链

一顿（灯闪）→ 停住 → 按警铃 → 物业说要四十分钟 → 空间好像变小 → 有人不对劲 → 撑过去 → 门开时的白光

#### 时间轴

警铃那头说要「四十分钟」，就照这个倒数。头十分钟还能说笑，过了二十分钟空气发稠，最后十分钟是一秒一秒熬过去的。

#### 谁不对劲，两个版本

| 版本 | 戏 |
|---|---|
| 他幽闭恐惧 | 平时再能扛，关进一平米也会冒汗、喘不过气，她攥住他的手，带他一拍一拍数呼吸 |
| 她幽闭恐惧 | 她硬撑着不说，手指捏得发白，被他看见了。他这辈子头一回这么干脆，直接把她的头按进自己肩窝，说“闭上眼，我数数” |

**第二版更值得写。** 她从不让人看见她害怕，电梯里却没地方躲，这回报时的人头一次换成了他。

#### 可用细节

| 类 | 内容 |
|---|---|
| 空间 | 镜面墙照着两个人 · 楼层数字停在9 · 警铃滋滋地响 |
| 物理 | 越来越闷 · 脱下外套垫在地上坐 · 一瓶水两人轮流喝 |
| 报时 | 「还有二十分钟」「你三分钟前也这么说」「……嗯，还有二十分钟」 |
| 门开 | 门一开，白光涌进来，两人还坐在地上，维修工愣了一下 |
| 之后 | 后来她爬楼梯，他也跟着爬，谁都没问为什么 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 关系阶段 | 已在一起 | 还是同事，四十分钟抵三个月进展 |
| 谁不对劲 | 他 | 她 |
| 时长 | 四十分钟 | 两小时，手机没信号，家里人开始找，出来后一堆未接 ✓ |
| 之后 | 都改爬楼梯 | 两人一起去坐了一回商场观光电梯，是他提的，算脱敏练习 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 靠在他肩窝里，听他一下一下报时 | 她指节发白那一下，他决定装没看见，一切由他来管 |
| 内心 | 原来我可以把眼睛闭上 | 这回轮到我说「有我在」以外的话 |
| 好的处理 | 事后她没提那四十分钟，他也没问 | 他报时报得特别稳，出去以后自己腿软了 |
| 写崩 | 写成她全程冷静指挥 | 写成他慌了神，全靠她安抚。要写他怕，就把怕写得有尊严 |

「出去后自己腿软」和 [16-危机与保护 · 她受伤了](16-危机与保护.md#四--她受伤了)里的「做完才开始抖」是一回事：当时撑得住，事后才垮下来。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 被地宫机关困住／山道塌方，在山洞里堵了一夜 |
| 修仙 | 困阵封住了灵力，两个修士跟普通人一样 |
| 星际 | 气闸舱故障，氧气表往下掉，「四十分钟」换成了氧气表 |

#### 写崩的三种方式

1. 困了五分钟就获救。 空气发稠是要时间的。
2. 趁机推进亲密。 电梯里只长信任，别的出去再说。
3. 怕的一方写得没尊严。 怎么怕、怎么扛，都要写清楚。

前接：[12-工作与金钱 · 加班到深夜的办公室](12-工作与金钱.md#九--加班到深夜的办公室)
后接：[16-危机与保护 · 一起扛](16-危机与保护.md#十--一起扛)

## 三 · 台风天

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：雨雪 ＋ 停电 10.1%

**骨架**|台风登陆前的十二个小时，囤菜，封窗，等着它来。

#### 节拍链

发布预警 → 去超市抢购 → 窗上用胶带贴米字 → 把阳台的花搬进屋 → 台风夜 → 风眼里怪异的安静 → 台风过境后的早晨

#### 时间轴

照气象台的路径图走：离登陆 12 小时、6 小时、登陆、风眼、离境。全城都在等同一件事，这种“全城一块儿等”的气氛，别的意外给不了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 抢购 | 超市的泡面架空了 · 她抓了把青菜，他拎了兜零食，两人看看对方的篮子 |
| 封窗 | 米字胶带比谁贴得正 · 他贴高处她喊往左往右 · 贴完两人隔着玻璃看云跑 |
| 台风夜 | 风声像有人在楼外喊 · 窗户每响一下，两人同时抬头 · 手机上的台风路径刷个没完 |
| 风眼 | 突然没了声音，太阳出来了 · 「完了？」「还有后半场呢」 |
| 次晨 | 满街断枝 · 楼下那棵树倒了 · 两人下楼帮邻居一起抬树 |

「互相看了看对方的篮子」，青菜和零食，一个抢购镜头写出两种人。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 强度 | 擦边过境，虚惊一场，零食白囤了，图个乐 | 正面登陆，停水停电，一家人进入求生模式 |
| 状态 | 两人都在家 | 有一个困在公司回不来（台风版的 [02-等待与错过](02-等待与错过.md#一--等门与热菜)，等人之外还揪着心，更没底） |
| 意外 | 没有 | 窗被吹开一条缝，半夜两人一起去堵，浑身湿透，狼狈得忍不住笑 |
| 次晨 | 帮邻居收拾 | 一觉睡到中午，起来看世界像是新的 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 风最大那一阵，他把她的椅子往里挪了挪 | 她盯台风路径图，认真得像在看项目报表 |
| 内心 | 全城停摆。合法的停摆。 | 风再大点，明天也别上班了吧 |
| 好的处理 | 她把「合法停摆」过得心安理得 | 他半夜起来检查了三次窗户 |
| 写崩 | 写成她远程办公了一整夜 | 写成灾难片那种惊险 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 汛期发大水，城门关了三天，她的衙门也关了，她头一回连着三天看日出日落 |
| 修仙 | 天地灵气大潮过境，全山封阵，阵里的人反倒闲得发慌 |
| 星际 | 离子风暴来袭，全舰静默航行，娱乐系统全停，大家没事做，只好互相聊天 |

#### 写崩的三种方式

1. 写成灾难片。 台风天大半时间是在等。
2. 跳过风眼。 那段怪异的安静本身就是一个戏剧停顿。
3. 没写出全城同时在等的感觉。 朋友圈里全城都在晒同一种米字窗，这层背景声要有。

## 四 · 地震那几秒

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：危险 18.1%

**骨架**｜地震只晃了十几秒，那十几秒里各自做了什么，两个人记了一辈子。

#### 节拍链

第一下晃（是错觉吧）→ 确认（吊灯在晃）→ 那几秒的本能动作 → 停了 → 等余震时的僵持 → 去楼道或楼下 → 回家后复盘

#### 时间轴

主震十几秒，余震按两小时算，复盘能讲一辈子。这三段要分开写：第一段只写动作，第二段只写神经绷着的反应，第三段才开口说话。

#### 那几秒的本能，逐帧

| 帧 | 他 | 她 |
|---|---|---|
| 第 1 秒 | 愣 | 愣 |
| 第 2 秒 | 他扑过来把她按到桌子底下 | 她拽住他手腕往承重墙那边拖 |
| 第 3-10 秒 | 他手护着她的头 | 她反手把他头也按下去 |
| 结果 | 两人挤在桌子底下互相搂着，都在护对方的头 | 同左 |

「保护」这两个字在这类文里能有多少种答案，十秒钟就演完了。桌子底下两只手较着劲，谁都不肯先松，她靠判断带人，他用身体去挡，两种护法撞在一起，僵了十秒。

#### 可用细节

| 类 | 内容 |
|---|---|
| 物证 | 吊灯晃 · 杯子挪到了桌边 · 书倒了一排 · 猫先炸了毛（宠物预警，接 [13-家庭与亲属 · 养一只](13-家庭与亲属.md#八--养一只)） |
| 桌下 | 两个人的呼吸声都太响 · 他的手一直按着她的后脑 · 她攥他手腕攥出了印子 |
| 余震等待 | 楼道里的邻居 · 头盔、水、充电宝 ✓ 塞进一个包，她三分钟就收好了应急包，他看呆了 |
| 复盘 | 「你刚才第一下是想干嘛」「压你桌底下」「我是想拖你去墙角」「……那咱们刚才在互相较劲？」笑场 |

复盘时笑场，十秒的生死本能被一场笑收回日常。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 震级 | 没什么事，只是吓一跳 | 真出了事（转 [16-危机与保护](16-危机与保护.md)，这里只写那十秒和两个钟头） |
| 在哪 | 家里 | 两人分在两处（互相打电话 ✓，全城线路堵死那二十分钟，语料里 23% 写到联系不上，最狠的情况） |
| 本能 | 互相护着 | 有一方那几秒愣住了，被另一方一把拽走，愣住的是谁都可以，别写成谁的错 |
| 复盘 | 当笑话讲 | 有人后怕到大半夜睡不着（接 [25-十 · 半夜的噩梦](#十--半夜的噩梦)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 后脑上他手掌的分量 | 手腕上她攥出的印子 |
| 内心 | 他扑过来比我的判断还快了半秒 | 那半秒我什么都没想 |
| 好的处理 | 她承认他快了半秒，也不觉得有什么 | 他没把那半秒当回事 |
| 写崩 | 写成她像没事人，他倒慌得不行 | 写成他一个人唱护她的独角戏 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 地动了，房梁往下掉灰，她拽着他往外跑，那条路线她每晚睡前都默背一遍 |
| 修仙 | 灵脉震动，护山大阵一闪一闪，两人谁也没跑，先伸手护住了对方 |
| 星际 | 舰船遭遇流星雨，警报响了三秒，他把她按进缓冲椅，她顺手把他的安全扣也扣死了 |

两人同时给对方扣安全扣，星际版的十秒本能就这么写。

#### 写崩的三种方式

1. 十秒写成三页。 本能戏不用写心理，只写动作就行。
2. 只有一方一直被护着。 两种本能一定要撞上。
3. 跳过复盘。 那十秒靠笑场那一段收尾。

## 五 · 车子半路抛锚

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：危险 18.1% ＋ 旅行 35.7%

**骨架**｜前不着村后不着店，引擎盖一直冒烟。车修不好，只能等。

#### 节拍链

有异响（谁先听见）→ 靠边 → 打开引擎盖，看不懂，都看了 → 打救援电话 → 等一小时 → 拖车来 → 后来

#### 时间轴

**救援电话里说「一小时」，实际等了一个半**。多出来的这半小时里，是荒路、暮色，双闪一下一下地亮。

#### 谁懂车，三种分配

| 配置 | 戏 |
|---|---|
| 她懂 | 她挽袖查线路，他举手机照明。路过司机摇窗喊「要帮忙吗美女」，她一句「不用，水温传感器」顶了回去 |
| 他懂 | 这是全书里他专业上的高光之一，接 [16-危机与保护 · 他能做到的那件事](16-危机与保护.md#九--他能做到的那件事)：平时不声不响的人钻进引擎舱，十分钟后车又能开了 |
| 都不懂 | 两人对着引擎盖翻说明书，这一版最没用，也最好笑 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 双闪嗒嗒响 · 三角牌摆太远，两人拌了句嘴 · 后备箱家当全翻出来 |
| 等待 | 坐护栏上分一包饼干 · 暮色把影子拉长 · 手机 ✓ 只剩一格信号 |
| 荒路 | 过路车灯扫来扫去 · 远处狗叫 |
| 拖车 | 师傅一路唠嗑，两人挤在后座，像逃难，又像春游 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 地点 | 城郊 | 无人区，手机没信号，等着等着就成了一场小型求生戏 |
| 时机 | 平常的周末 | 赶着办要紧事，怕误事的焦急全压在等待上，看谁先松口说「算了，误就误了」 |
| 修没修好 | 拖走 | 他给修好了 |
| 后续 | 换车 | 没换，这辆破车成了两人共同的念想，谁提卖车就挨瞪 |

放弃要紧行程这个决定由谁来做，就看谁先说「算了，误就误了」。要是她说，那是她头一回把「误事」说得这么轻松。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 护栏上分着吃的那包饼干 | 她说「误就误了」时的轻松是装的，可她肯装 |
| 内心 | 三个会要开。算了，天还行。 | 我要是会修车就好了。回去学。 |
| 好的处理 | 她顶路人的那句专业术语 | 他回去真报了个班，多年后又一次抛锚，是他修好的 |
| 写崩 | 写成她急躁地催救援 | 写成荒野遇险大逃亡 |

| 世界 | 等价物 |
|---|---|

## 六 · 迷路

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：旅行 35.7%

**骨架**｜导航第七次说「已重新规划路线」，两人总算把方向的事摊开来讲了。

#### 节拍链

第一个转错的弯 → 导航重新规划 → 出现分歧：听导航还是听直觉 → 越走越偏 → 停车承认迷路了 → 问路或掉头 → 意外的发现

#### 时间轴

数导航的「重新规划」：第一遍是插曲，第四遍有分歧，第七遍要摊牌。

#### 分歧的结构

| 主张 | 谁 | 潜台词 |
|---|---|---|
| 「听导航」 | 通常是他 | 信系统 |
| 「导航绕远了，往这边」 | 通常是她 | 信自己 |
| 结果 | 谁对都可以，要看的是错的那个人怎么低头 | 认错怎么认，这条就怎么写 |

方向判断错了的她把车停下，沉默三秒，说「你导吧」。她把方向盘旁边的决定权让了出去，这比道十次歉都管用。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 导航里那个机械女声 · 路越开越窄 · 开进连倒车都费劲的死胡同 |
| 气氛曲线 | 好笑 → 有点烦 → 谁都不说话 → 有人先笑出声，这事就算过去了 |
| 问路 | 谁下车去问。下车的那个顺手买了两瓶水，递过来一瓶，就算和好了 |
| 意外发现 | 走错路撞见一家苍蝇馆子，好吃得不像话 · 一片没被开发的海 · 从此这条错路成了「咱俩的路」 |

错路成了「咱俩的路」，计划之外的收获，只有迷过路的人才有。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁的错 | 她没看准 | 他太马虎，两人轮流认错，各说各的理 |
| 气氛 | 一路笑到底 | 拌了几句嘴 |
| 意外发现 | 有 | 没有，白跑一趟，后来也讲成了笑话 |
| 场景 | 开车 | 走山路，天快黑了，事情开始往危险的方向去，就此打住 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「你导吧」这三个字 | 她认错时那三秒沉默，他没趁机教育她 |
| 内心 | 我的方向感第一次输给机器 | 别笑。忍住。没忍住。 |
| 好的处理 | 她把那家苍蝇馆子加进了收藏 | 他笑完马上给台阶：「其实这条路风景好」 |
| 写崩 | 写成她死不认错 | 写成他说话阴阳怪气 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 官道岔口和舆图对不上，她坚持走近路，结果碰上溪水暴涨，掉头时他一个字都没提 |
| 修仙 | 秘境里有幻阵，方向感全失。她留下的剑气标记都被阵吞了，最后靠他数步子才走出来 |
| 星际 | 跳跃坐标偏了，星图重算了七遍。偏出去的航线上撞见一片星云，全舰没人出声，看了十分钟 |

「偏出来的航线撞见星云」，是星际版的苍蝇馆子。

#### 写崩的三种方式

1. 迷路一下就解了。 重规划要攒到第七遍才管用。
2. 分歧升级成大吵。 这里的吵是小火慢炖，一笑就灭。
3. 意外发现太神奇。 苍蝇馆子正好，找到仙境就过了。

## 七 · 末班车没赶上

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：接送 37.1% ＋ 夜深 37.5%

**骨架**｜地铁口的卷帘门拉下来了，怎么回家，一下成了两个人得一起想的事。

#### 节拍链

五公里夜路走完，天都快亮了。到家门口的时候，卷帘门已经拉下一半，差三十秒没赶上。站门口喘成狗，脑子里盘算着打车排队一百多号，代驾，或者走回去。脑子一抽选了最蠢的：走回去。

#### 时间轴

**五公里，走了一小时四十分钟**。后半夜的城市里，烧烤摊在收摊，洒水车开过，第一班环卫工上了街，夜一路走深，走着走着天边发了白。

#### 为什么「走回去」是对的决定

打车二十分钟就到，走路要一小时四十分钟。**选走路，就是想把这一夜多拖一个多小时**。提议走路的那个，就是舍不得今晚散场的人。

#### 可用细节

| 类 | 内容 |
|---|---|
| 门口 | 隔着卷帘门看末班车开走 · 两人喘得不行，先笑出来了 |
| 夜路 | 赶上烧烤摊收摊前最后一单 · 便利店买的关东煮边走边吃 · 她的高跟鞋换成便利店拖鞋，鞋由他拎着 |
| 声音 | 洒水车 · 远处的货车 · 两人的脚步声从乱走到齐 |
| 话题 | 边走边聊和坐着聊不一样：走到第三公里，说起了从没提过的事 |
| 天亮 | 走到楼下，天边有点白了，谁都不困 |

「脚步声从错拍走到同拍」，一句心理都不用写，节奏自己就把话说了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提议走 | 他 | 她一时兴起，一年就这么一回 |
| 距离 | 五公里 | 十二公里，走到一半后悔了，一辆空出租车开过，两人对看一眼，没拦 |
| 阶段 | 暧昧期，这一夜抵得上三个月 | 老夫老妻，重走年轻时那条路 |
| 天气 | 晴 | 走到一半下起雨（接 [18-节令与天候 · 下雨](18-节令与天候.md#一--下雨)，狼狈加倍，快乐也加倍） |

空车开过去，两人对看一眼，没拦。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 便利店拖鞋踩在马路上的声音 | 她的高跟鞋在他手里晃着 |
| 内心 | 明早的会已经无所谓到可笑 | 第三公里她说的那件事，清醒的时候她从没说过 |
| 好的处理 | 她把那双便利店拖鞋留着了 | 第三公里那件事他当时没点破，走完才提 |
| 写崩 | 写成她抱怨了一路 | 写成他故意错过末班车 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 宵禁鼓响，城门落锁，两人沿城根走到东门等开门，城墙根下过了一夜 |
| 修仙 | 传送阵酉时关闭，山路四十里，御剑三刻钟，走路要一夜，她说「走吧」 |
| 星际 | 错过末班摆渡舱，沿观景廊道走过整个空港，舷窗外的星河陪了一路 |

「御剑三刻钟，她说走吧」，修仙版就是这么选的。

#### 写崩的三种方式

1. 打车回家。 那这条就没了。
2. 把夜路写得很危险。 后半夜的城市在这里是温柔的。
3. 把第三公里的话题点破。 话说完就放下，等天亮再捡起来。

## 八 · 锁在门外

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：归家 46.2% ＋ 停电 10.1%

**骨架**｜钥匙锁在屋里，人在门外，开锁师傅要四十分钟才到。

#### 节拍链

摸口袋（第一遍）→ 把所有口袋都摸一遍（第三遍）→ 确定锁在里面了 → 互相怪对方三十秒 → 找开锁的 → 楼道里的四十分钟 → 门开

#### 时间轴

开锁师傅说的四十分钟，和[二 · 困在电梯](#二--困在电梯)里那四十分钟是同一个数，等的滋味不同：楼道里是干等着无聊，电梯里是闷得难受。

#### 可用细节

| 类 | 内容 |
|---|---|
| 追责 | 「你出门没检查？」「钥匙 ✓ 一直你管着」，三十秒后两人同时闭嘴，吵了也没用 |
| 楼道 | 坐在台阶上 · 声控灯 ✓ 两分钟灭一回，谁跺一脚就亮 · 邻居出来倒垃圾，点点头算打了招呼 |
| 消磨 | 分着吃完包里剩的半包饼干 · 翻手机 ✓ 翻相册打发时间，翻到老照片 ✓，回忆一下涌上来 |
| 门开 | 师傅三十秒就打开了，两人看着这扇折腾了他们一小时的门，半天没出声 |

声控灯一灭就有人跺脚，两分钟一次的小动作，让人数得出这四十分钟。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁忘的 | 他 | 她从来不忘事，这回偏偏忘了，为什么忘，后面有文章 |
| 时段 | 傍晚 | 凌晨两点，不敢叫师傅，蹲到天亮，狼狈地进了家 |
| 等待质量 | 翻相册想起旧事 | 冷战中被关在同一个楼道里（想不说话都难） |
| 门开后 | 一进门就瘫倒 | 进门第一件事是配三把备用钥匙，一把埋进花盆，多年后花盆里那把真救了一回急，前后接上了 |

她从不忘事，这次却忘了。她这阵子心不在焉，钥匙只是先露出来的一角。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 相册翻到三年前那一张 | 声控灯又灭了，这回是她先跺的脚 |
| 内心 | 我怎么把钥匙忘了。我这阵子不对劲。 | 在楼道待着也行，她怎么样都好 |
| 好的处理 | 她看着照片，说起那年的事 | 他把外套垫在台阶上，动作很自然 |
| 写崩 | 写成两人越吵越凶 | 写成他踹门耍帅 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 门房睡死了，角门叫不开，两人翻墙没翻过去，蹲在门槛上等打更的 |
| 修仙 | 碰错洞府禁制把自己反锁在外，解阵要等一炷香，两人坐在山门台阶上看月亮 |
| 星际 | 舱门的刷脸坏了，工程组要排队修，两人坐在走廊地上分一副耳机 ✓ |

#### 写崩的三种方式

1. 互相怪罪怪出真火。 三十秒封顶，然后一起对付门。
2. 跳过等待直接开门。 正文就是楼道里那四十分钟。
3. 让等待太充实。 这条写的就是无聊，回忆点一下就收。

## 九 · 手机摔了

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：社交网 33.9%

**骨架**｜屏幕裂成了蜘蛛网。他慌的是手机里的东西，心疼的不是钱。

#### 节拍链

脱手（慢镜头般的半秒）→ 捡起来（屏碎了，还亮着）→ 抢着备份 → 彻底黑屏 → 送修 → 数据保没保住 → 换了新手机以后

#### 时间轴

要写的时间就是从「还亮着」到「黑屏」的那十几分钟。他先备份什么，什么就是他心里最要紧的。

| 他先备份的 | 说明 |

| 一段聊天记录 | 从第一句「在吗」到后来所有的话，接 [19-二 · 聊天记录](19-玩闹与网络.md#二--聊天记录) |
| 一条六十秒语音 | 她某年生日时录的，他一直舍不得外放来听 |

慌到手抖时先救什么，什么就是他的命根子。她在旁边看他按什么顺序抢救，比读十年日记看得还清楚。

| 数据 | 保住了 | 没保住，那批照片没了，他说没关系，半年后她偷偷按一模一样的角度又拍了一批 |
| 摔的场合 | 平常手滑 | 为了接住摔倒的她，手机替她摔了，算英雄事迹里最小的一桩 |
| 换机 | 换了新的 | 修好继续用，裂纹留着（「裂了才是我的」） |

「她偷偷重拍同角度的照片」：数据救不回来，人还可以重演一遍让他再存。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他最先抢救哪个备份 | 「数据不保证」那五个字 |
| 内心 | 排第一的文件夹是啥 | 三年的东西，三年的东西 |
| 好的处理 | 她说「多少钱都修」，没问修的是什么 | 数据丢了，他没冲谁发火 |
| 写崩 | 写成她趁机翻他手机 | 写成他崩溃了三章 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 随身的木匣掉进水里，信纸晒干后字都洇开了，他一个字一个字描着认 |
| 修仙 | 储物袋破了，东西撒了一地，他先扑过去捡她送的那枚旧符 |
| 星际 | 个人终端坏了，数据舱排队要七天才能修好，那七天他整个人都蔫了，像丢了魂 |

#### 写崩的三种方式

1. 只写手机有多贵。 在这里钱一文不值。
2. 不写抢救顺序。 他先救哪一样，要写出来。
3. 数据丢了就轻轻带过。 丢了就是丢了，这一下要写够，再用重拍的那批照片接上。

## 十 · 半夜的噩梦

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：睡着 55.9% ＋ 夜深 37.5%

**骨架**｜凌晨三点，一个人从梦里惊醒，另一个也醒了，或者干脆装睡。

#### 节拍链

梦的内容不写，只写外面：挣醒，坐起来喘。确认是现实，摸到身边的人。对方的反应。三点钟说几句，或者不说。再睡过去，或者等天亮。

#### 时间轴

凌晨三点是人一天里防备最松的时候，白天憋着不敢说的话，这个点会自己跑出来。

#### 梦的内容学

梦不必写全，醒来后漏出的几个字就够了：

| 他梦见的 | 泄露的 |
|---|---|
| 「梦见你走了」 | 心里不踏实，怕她哪天真的走（接 [04-委屈与破防 · 我是不是不够好](04-委屈与破防.md#九--我是不是不够好)） |
| 梦回某段旧事 | 家里欠下的旧账（接 [13-家庭与亲属 · 他的原生家庭](13-家庭与亲属.md#六--他的原生家庭)） |
| 说不出内容，只是抖 | 有些事到了嘴边也说不清 |

| 她梦见的 | 泄露的 |
|---|---|
| 白天那场事故重演 | 她白天吓成那样，夜里全回到梦里了（接 [四 · 地震那几秒](#四--地震那几秒)） |
| 她极少做梦，这次醒来沉默 | 梦见了什么她自己咽下去，他也只递一杯水，不多问 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 醒的瞬间 | 倒吸一口气 · 一把攥紧被子 ✓ · 心跳响到自己都听得见 |
| 对方 | 其实早被惊醒了，装睡三秒后决定开口 ·「做噩梦了？」嗓子是哑的 |
| 三点的对话 | 不开灯 · 声音压得很低 · 说过的话第二天默契不提 |
| 动作 | 递水 · 把人往怀里带 · 手在背上一下一下地拍，是哄人的节奏 |
| 重新入睡 | 换了个姿势，手被攥着一直睡到天亮，麻了也没抽出来 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁做梦 | 他 | 她很少做，所以每次都很重 |
| 说不说 | 说几句实话 | 一个字也不提，写那种说不出口的梦 |
| 频率 | 偶尔 | 有一阵子总做，心里有事没过去，梦是来催的 |
| 第二天 | 都当没发生过 | 她白天约了心理咨询，把梦当正事办，很像她会做的事 |

她约了心理咨询，把噩梦当成一项待办来处理，很像她。他嘴上不说，心里把这一条也添进了「她可爱的地方」那张单子。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他梦里漏出来的那半声 | 她醒后那十分钟不太对劲 |
| 内心 | 白天他一个字也不提 | 别问梦见了什么。递水，拍背。 |
| 好的处理 | 听他说「梦见你走了」，她没接话，往他那边挪了挪 | 他学会了不问「梦见啥了」，只问「喝不喝水」 |
| 写崩 | 写成半夜三点掏心掏肺 | 写成天天做噩梦，只顾着卖惨 |

她什么也没说，往他那边挪了半个身子。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 更漏响过三声，帐中有人挣醒。她只低声说了一句「有我」，这话她白天从来不说 |
| 修仙 | 心魔入梦，修为越高梦越凶。他守着入定的她，替她挡了一夜的梦 |
| 星际 | 从冬眠舱醒来的那阵恍惚里，舱内灯光自动调暗，这一点系统比人还体贴 |

#### 写崩的三种方式

1. 梦的内容全写出来。 梦只能露出一角。
2. 从三点聊到五点。 最多三句话，其余交给姿势和动作。
3. 把噩梦当廉价虐点反复用。 反复做同一个梦，背后一定要有一件还没解决的实事。
