# 意外与困境

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**意外不给人思考时间，而不经思考的反应是关系的测谎仪。**

## 这一族的两种用法

意外场面在本类型里干两件事：

| 用法 | 原理 | 代表 |
|---|---|---|
| 关门 | 把两个人锁进一个出不去的空间，日常的缓冲全部失效 | 停电、电梯、台风 |
| 测谎 | 危险的第一秒里，身体比脑子先动，动作暴露真实的优先级 | 地震、摔倒、急刹车 |

**这一族的关键在于「两种本能并行」**：他护她的身体反应，她拽他的判断反应，可以同时发生。传统脚本默认「危险一来男人挡在前面」，这个本能在 GB 里不必消灭。两种本能都是保护，谁也不高谁一头。写清这一点，就不会滑回旧脚本，测谎类尤其要留意方向。

| 节拍族 | 占比 |
|---|---:|
| 危险 | 18.0% |
| 停电 | 10.1% |
| 失联 | 23.0% |
| 困电梯 | 0.3% |

「困电梯」实测只有 0.3%——语料里几乎没人写。经典的强制独处装置竟然是片空地，低竞争位里的低竞争位。

## 一 · 停电的晚上

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：停电 10.1%

**骨架**｜整栋楼突然停电，手机电脑全黑，门禁也失灵了，只能摸黑点蜡烛。

#### 节拍链

灯灭（静三秒）→ 确认范围（整栋都黑）→ 找光源 → 蜡烛点起来 → 没事干的两个小时 → 来电那一刻反而有点失落

#### 时间轴

手机 ✓ 电量就是沙漏。从 80% 一路往下掉，掉到 20% 时两个人做了个决定：关机，省着报修用。关机之后，这个夜晚才真正开始。

#### 为什么停电对这个类型特别好用

这两个小时里，她谁的上司都不是，就是黑暗里另一口喘气的人。平时那半壁权力全攥在手机里：工作电话、日程、随时待命。**一停电全完蛋**——灯得两个人一起找，加班和回消息更是想都别想。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 蜡烛 ✓ 去年生日剩的 · 手电 ✓ 在抽屉最里面 · 充电宝 ✓ 忘了充 · 冰箱 ✓ 不响了，屋里静得发慌 |
| 找光源 | 两个人摸黑撞一块儿 · 手机电筒对着照 · 蜡烛点着那一下，脸在光里晃 |
| 无事可做 | 讲小时候停电的事 · 玩影子 · 楼道里邻居骂骂咧咧，听着听着也习惯了 |
| 温度 | 夏天停电：热，扇扇子，扇着扇着就扇到对方那边去了 |
| 来电 | 灯全亮，俩人你看我我看你，谁也没去吹蜡烛 |

「来电了反而失落」是这条的落点：黑暗替他们推掉了全世界，灯一亮，世界回来了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时长 | 两小时 | 一整夜，夏夜阳台打地铺 |
| 阶段 | 热恋期 | 冷战期（黑暗里憋不住先开口的那个，接 [04-委屈与破防 · 冷战](04-委屈与破防.md#八--冷战)） |
| 谁怕黑 | 都不怕 | 有一方怕，且是她——她的怕只在停电夜露过这一回 |
| 收尾 | 来电 | 蜡烛烧完，摸黑睡去 |

「怕黑的是她」这一端值得写：她的所有恐惧都被白天的能干盖住了，黑暗面前人人平等。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 关机那一下，她二十年没关过机 | 烛光里她的脸比灯光里近 |
| 内心 | 天塌下来也得等来电再塌 | 别来电。再晚一点来电。 |
| 好的处理 | 她讲了一件小时候的事，他从没听过 | 他把蜡烛往她那边挪了挪 |
| 写崩 | 写成她焦躁报修催电 | 写成刻意的烛光晚餐 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 风雨夜烛火全灭，府里下了宵禁，她熬夜批的折子没法看了，头一回沾枕头就睡着 |
| 修仙 | 灵脉枯了，护山大阵全暗，满山修士头一回像凡人一样摸黑过夜 |
| 星际 | 舰船主电源检修，应急灯泛红，重力还在，但没人说话，头一回听见彼此的呼吸声 |

#### 写崩的三种方式

1. 停电十分钟就来电。至少两小时，让无聊真的发生。
2. 拿蜡烛摆浪漫。蜡烛是去年生日剩的，凑合用，才对。
3. 她全程焦虑工作。关机那个决定必须做出来。

后接：[19-玩闹与网络 · 无聊的下午](19-玩闹与网络.md#十--无聊的下午)，有电版的同款空白。

> 「你怎么知道？」

## 二 · 困在电梯

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：困电梯 0.3%（语料几乎空白的低竞争位）

**骨架**｜电梯卡在九楼半，不到两平米的地方，困了四十分钟出不去。

#### 节拍链

一顿（灯闪）→ 停住 → 按警铃 → 物业说四十分钟 → 空间开始变小 → 有人不对劲 → 撑过去 → 门开的白光

#### 时间轴

**警铃回复的「四十分钟」是明牌倒计时**。前十分钟还能说笑，二十分钟后空气变稠，最后十分钟一秒一秒过。

#### 谁不对劲，两个版本

| 版本 | 戏 |
|---|---|
| 他幽闭恐惧 | 平时再能扛的人，关进一平米也得冒汗、喘不上气，她攥住他的手，带他数呼吸，一拍一拍来 |
| 她幽闭恐惧 | 她硬扛着不说，手指头捏得发白让他瞅见。他这辈子头一回这么干脆，直接把她脑袋按进肩窝里，说“闭上眼，我数数” |

**第二版更值得写。** 她的怕从不示人，电梯不给她退场的空间——而他第一次当了那个报时的人。

#### 可用细节

| 类 | 内容 |
|---|---|
| 空间 | 镜面墙映着两个人 · 楼层数字卡在9 · 警铃滋滋响 |
| 物理 | 越来越闷 · 外套脱了垫地上坐 · 一瓶水两人轮着喝 |
| 报时 | 「还有二十分钟」「你三分钟前也这么说」「……嗯，还有二十分钟」 |
| 门开 | 门一开白光涌进来，俩人坐地上，维修工愣了愣 |
| 之后 | 后来她爬楼梯他也跟着爬，谁也没问为啥 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 关系阶段 | 已在一起 | 还是同事，四十分钟顶三个月推进 |
| 谁不对劲 | 他 | 她 |
| 时长 | 四十分钟 | 两小时，手机没信号，家里人开始找，出去后一堆未接 ✓ |
| 之后 | 都爬楼梯 | 一起去坐了一次商场观光电梯，他提的，当脱敏训练 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 肩窝里数着他报的时 | 她指节发白那一下，他决定装没看见并接管一切 |
| 内心 | 原来我可以把眼睛闭上 | 这一次轮到我说「有我在」以外的话 |
| 好的处理 | 她事后没提那四十分钟，他也没问 | 他报时报得极稳，出去后自己腿软 |
| 写崩 | 写成她全程冷静指挥 | 写成他惊慌失措靠她安抚。若写他怕，怕要写得有尊严 |

「出去后自己腿软」跟 [16-危机与保护 · 她受伤了](16-危机与保护.md#四--她受伤了)里「做完才开始抖」是一个道理。当时能撑住，事后才垮。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 地宫机关困住／山道塌方堵在山洞一夜 |
| 修仙 | 困阵封了灵力，两个修士跟普通人没两样 |
| 星际 | 气闸舱坏了，氧气表往下掉——把「四十分钟」换成氧气表，压强翻十倍 |

#### 写崩的三种方式

1. 困五分钟就获救。空气变稠需要时间。
2. 借机推进亲密。电梯里只发生信任，别的出去再说。
3. 怕的一方写丢尊严。怕要怕得具体，扛要扛得可见。

## 三 · 台风天

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：雨雪 ＋ 停电 10.1%

**骨架**|台风登陆前十二小时。囤菜、封窗、等它来。

#### 节拍链

预警发布 → 超市抢购 → 封窗胶带打米字 → 阳台的花搬进来 → 台风夜 → 风眼的诡异安静 → 过境后的清晨

#### 时间轴

**气象台的路径图就是钟**：距离登陆 12 小时、6 小时、登陆、风眼、离境。全城的人都在等同一件事。这种“全城一块儿等”的氛围，别的意外真比不上。

#### 可用细节

| 类 | 内容 |
|---|---|
| 抢购 | 超市泡面架空了 · 她抓把青菜，他拎兜零食，俩人互相瞅瞅对方的篮子 |
| 封窗 | 胶带米字谁贴得正 · 他够高处她喊往左往右 · 贴完俩人隔着玻璃看云跑 |
| 台风夜 | 风声像有人在楼外喊 · 窗户每响一声俩人同时抬头看 · 手机里的台风路径刷个不停 |
| 风眼 | 突然没声了，太阳出来了 · 「完了？」「还有后半场呢」 |
| 次晨 | 满街断枝 · 楼下那棵树倒了 · 俩人下楼搭把手抬树的邻里时刻 |

「互相看了看对方的篮子」，青菜与零食，一个抢购镜头写完两种人。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 强度 | 擦边过境，虚惊一场，零食白囤，图个乐子 | 正面登陆，停水停电，全家进入求生模式 |
| 状态 | 两人都在家 | 一个被困在公司回不来（台风版 [02-等待与错过](02-等待与错过.md#一--等门与热菜)，等人加上担心，心里更没底） |
| 意外 | 没有 | 窗被吹开一条缝，半夜两人一起堵，浑身湿透，狼狈，忍不住笑 |
| 次晨 | 帮邻居收拾 | 睡到中午才醒，起来一看世界跟新的一样 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 风最大的那一阵他把她的椅子往里挪了挪 | 她盯路径图的认真程度和看项目报表一样 |
| 内心 | 全城停摆。合法的停摆。 | 风再大点，明天也别上班了吧 |
| 好的处理 | 她把「合法停摆」过得心安理得 | 他半夜起来查了三次窗 |
| 写崩 | 写成她远程办公一整夜 | 写成灾难片式惊险 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 汛期发大水，城门关三天，她衙门也关了，头一回连着三天看日出日落 |
| 修仙 | 天地灵气大潮过境，全山封阵，阵里人反倒闲得慌 |
| 星际 | 离子风暴来了，全舰静默航行，娱乐系统全停，大家没事干，只能互相唠嗑 |

「娱乐系统停摆，人只好互相说话」，星际版一句话说破了这一族的原理。

#### 写崩的三种方式

1. 朋友圈里全城都在晒同一个米字窗，这个背景音要有。
2. 那段诡异的安静，是天然的戏剧停顿，别略过风眼。
3. 台风天的主体是等，不是险，写成灾难片就错了。

## 四 · 地震那几秒

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：危险 18.0%

**骨架**｜摇晃就十几秒，可那十几秒里干的事，俩人都记了一辈子。

#### 节拍链

第一下晃（是错觉吗）→ 确认（吊灯在晃）→ 那几秒的本能动作 → 停了 → 余震预期下的对峙 → 楼道或楼下 → 回家后的复盘

#### 时间轴

主震就那十几秒，余震按两小时算，复盘能念叨一辈子。这三个时间段得分开写。第一段光写动作，第二段只写神经反应，第三段才轮到说话。

#### 那几秒的本能，逐帧

开卷说过这一族的测谎原理，这条是主考场：

| 帧 | 他 | 她 |
|---|---|---|
| 第 1 秒 | 愣 | 愣 |
| 第 2 秒 | 扑过来把她按到桌底下 | 拽着他手腕往承重墙那边拖 |
| 第 3-10 秒 | 手护着她脑袋 | 反手把他头也摁下去 |
| 结果 | 俩人挤在桌底下，互相搂着，都顾着对方脑袋 | 同左 |

「保护」这俩字在这类文里能给出多少种答案，十秒就够了。桌子底下两只手较着劲，谁也不肯先撤，她拿脑子去带，他拿身体去挡，两种护法撞一块儿，僵了十秒。答案全在里面。

#### 可用细节

| 类 | 内容 |
|---|---|
| 物证 | 吊灯晃 · 杯子走到桌边 · 书倒了一排 · 猫先炸毛（宠物预警，接 [13-家庭与亲属 · 养一只](13-家庭与亲属.md#八--养一只)） |
| 桌下 | 两个人的呼吸都太响 · 他的手一直按在她后脑 · 她攥着他手腕的力道留了印 |
| 余震等待 | 楼道里的邻居 · 头盔、水、充电宝 ✓ 塞进一个包，她三分钟收好应急包，他看呆 |
| 复盘 | 「你刚才第一下是想干嘛」「压你桌底下」「我是想拖你去墙角」「……那咱们刚才在互相较劲？」笑场 |

「复盘笑场」是这条的出口：十秒钟的生死本能，用一场笑收进日常。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 震级 | 没啥事，就是吓一跳 | 真出事了（转 [16-危机与保护](16-危机与保护.md)，这条只管那十秒和俩钟头） |
| 在哪 | 家里 | 俩人各待一处（互相打电话 ✓ 全城堵死那二十分钟，23% 的人联系不上，最狠的情况） |
| 本能 | 互相护着 | 有一方那几秒愣住，被另一方一把拽走，愣的可以是随便谁，别写成谁的错 |
| 复盘 | 当笑话讲 | 有人后怕得大半夜睡不着（接 [25-十 · 半夜的噩梦](#十--半夜的噩梦)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 后脑上他手掌的重量 | 手腕上她攥出的印子 |
| 内心 | 他扑过来的速度，比我的判断还快半秒 | 那半秒我什么都没想 |
| 好的处理 | 她认了他快半秒，也没觉得这有啥 | 他没把那半秒当回事 |
| 写崩 | 写成她没事人似的，他倒慌得不行 | 写成他护她，护得跟独角戏似的 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 地动，房梁掉灰，她拽他往外跑，那条路她每晚睡前都默背一遍 |
| 修仙 | 灵脉震了，护山大阵直闪，俩人谁也没跑，先伸手把对方护住 |
| 星际 | 舰船挨了流星雨，警报响三秒，他把她按进缓冲椅，她顺手把他安全扣也扣死了 |

「同时给对方系安全扣」，星际版十秒本能的最佳镜头。

#### 写崩的三种方式

1. 十秒写成三页。本能戏不用写心理，光写动作就行。
2. 一方全程被护着。两种本能必须撞上。
3. 复盘直接跳过。笑场那段就是给十秒收尾的。

## 五 · 车子半路抛锚

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：危险 18.0% ＋ 旅行 35.0%

**骨架**｜前不着村后不着店，引擎盖直冒烟。车是修不好了，只能干等。

#### 节拍链

异响（谁先听见）→ 靠边 → 开引擎盖，看不懂，但都看了 → 打救援电话 → 等待的一小时 → 拖车来 → 后续

#### 时间轴

| 类 | 内容 |

| 道具 | 双闪嗒嗒响 · 三角牌摆太远吵了一嘴 · 后备箱翻出所有家当 |

## 六 · 迷路

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：旅行 35.0%

**骨架**｜导航第七遍说「已重新规划路线」，两个人终于把方向这事摊开说了。

#### 节拍链

第一个错转弯 → 导航重规划 → 分歧出现，听导航还是听直觉 → 越走越偏 → 停下承认迷路 → 问路或回头 → 意外发现

#### 时间轴

导航的「重新规划」次数是钟。第一遍是插曲，第四遍是分歧，第七遍是摊牌。

#### 分歧的结构

| 主张 | 谁 | 潜台词 |
|---|---|---|
| 「听导航」 | 通常是他 | 信系统 |
| 「导航绕远了，往这边」 | 通常是她 | 信自己 |
| 结果 | 谁对都行，关键看错的那方怎么低头 | 怎么认错，这条就怎么写 |

**她认错的样子是稀缺镜头**：判断错了方向的她停下车，沉默三秒，说「你导吧」，把方向盘边的决定权交出去，比十句道歉重。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 导航里那个机械女声 · 路越开越窄 · 倒个车都费劲的死胡同 |
| 气氛曲线 | 好笑 → 有点烦 → 没人说话 → 有人先笑出来，这事就过去了 |
| 问路 | 谁下去问。下去那个顺手买了两瓶水，递一瓶过来，就算和好了 |
| 意外发现 | 走错路撞见一家苍蝇馆子，好吃得不像话 · 一片没人开发的海 · 打那以后这条错路就成了「咱俩的路」 |

「错路变成我们的路」是这条的落点：计划外的收获只属于迷过路的人。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁的错 | 她没看准 | 他太马虎，两人轮流认账，各有各的说法 |
| 气氛 | 从头乐到尾 | 拌了几句嘴，走错路算小号的压力测试 |
| 意外发现 | 有 | 没有，白跑一趟，但白跑也讲成了笑话 |
| 场景 | 开车去 | 走山路，天擦黑，事情开始往险处走，赶紧打住 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「你导吧」三个字 | 她认错的三秒沉默，他没趁机说教 |
| 内心 | 我的方向感第一次输给机器 | 别笑。忍住。没忍住。 |
| 好的处理 | 她把那家苍蝇馆子记进了收藏 | 他笑完立刻找台阶：「其实这条路风景好」 |
| 写崩 | 写成她死不认错 | 写成他阴阳怪气 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 官道岔口舆图对不上，她坚持抄近道，结果溪水暴涨，回头时他一句没提 |
| 修仙 | 秘境幻阵，方向感全废。她留的剑气标记全被阵吞了，最后靠他数步子才走出来 |
| 星际 | 跳跃坐标偏了，星图重算七遍。偏出来的航线上撞见一片星云，全舰没人说话，看了十分钟 |

「偏出来的航线撞见星云」，星际版的苍蝇馆子。

#### 写崩的三种方式

1. 迷路秒解。重规划得攒到第七遍才管用。
2. 分歧上升成大吵。这条的吵是小火慢炖，笑声能灭火。
3. 意外发现太神。苍蝇馆子刚刚好，仙境就过了。

## 七 · 末班车没赶上

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：接送 37.0% ＋ 夜深 37.0%

**骨架**｜地铁口的卷帘门拉下来了。回家的路，突然变成两个人得一起琢磨的事。

#### 节拍链

五公里夜路走完，天都快亮了。到家门口的时候，卷帘门已经拉下一半，差三十秒没赶上。站门口喘成狗，脑子里盘算着打车排队一百多号，代驾，或者走回去。脑子一抽选了最蠢的：走回去。

#### 时间轴

**五公里，一小时四十分钟的步行**。城市后半夜的时段感极强：烧烤摊收摊、洒水车、第一班环卫工——夜越走越深，再走着走着天边泛白。

#### 为什么「走回去」是对的决定

打车二十分钟能到，走路得俩小时——**选走路的，就是想让这夜再拖长两小时**。谁提的走路，谁就是舍不得今晚散场的人。

#### 可用细节

| 类 | 内容 |
|---|---|
| 门口 | 隔着卷帘门看末班车开走 · 俩人喘得不行，先笑了 |
| 夜路 | 烧烤摊收摊前最后一单 · 便利店买的关东煮边走边吃 · 高跟鞋换成了便利店拖鞋，鞋他拎着 |
| 声音 | 洒水车 · 远处货车 · 俩人脚步声从乱到齐 |
| 话题 | 走路聊的和坐着聊的不一样：走到第三公里，说了从来没提过的事 |
| 天亮 | 到楼下天边有点发白，谁也没困 |

「脚步声从错拍走到同拍」，不用写一句心理，节奏自己完成了。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁提议走 | 他 | 她一年就这一回，她一时兴起 |
| 距离 | 五公里 | 十二公里，走到一半后悔，出租车空车路过，两人对视，没拦 |
| 阶段 | 暧昧期，这一夜顶三个月 | 老夫老妻，重走年轻时那条路 |
| 天气 | 晴 | 走到一半下雨（接 [18-节令与天候 · 下雨](18-节令与天候.md#一--下雨)，狼狈翻倍，快乐翻倍） |

「空车路过没拦」是这条的钻石细节：理性给了第二次机会，两个人一致放弃。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 便利店拖鞋踩在马路上的动静 | 她的高跟鞋在他手里晃 |
| 内心 | 明早的会已经不重要到可笑 | 第三公里她说的那件事，她清醒时从没说过 |
| 好的处理 | 她把那双便利店拖鞋留下了 | 他没点破第三公里那件事，走完了才提 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 宵禁鼓响，城门落锁，绕城根走到东门等启，一夜的城墙根 |
| 修仙 | 传送阵酉时关，山路四十里，御剑三刻钟，走路一夜——她说「走吧」 |
| 星际 | 末班摆渡舱错过，沿观景廊道步行穿过整个空港，舷窗外星河跟着走了一路 |

2. 夜路写成危险。后半夜的城市在这条里是温柔的。
3. 第三公里的话题点破。让它说完就搁下，天亮再捡。

## 八 · 锁在门外

`G` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：归家 46.0% ＋ 停电 10.1%

**骨架**｜钥匙锁屋里了，人还在门外，开锁的得四十分钟才能到。

#### 节拍链

摸口袋（第一遍）→ 摸所有口袋（第三遍）→ 确认锁在里面 → 互相追责三十秒 → 找开锁 → 楼道里的四十分钟 → 门开

#### 时间轴

同样是等，楼道里是干等着无聊，电梯里是憋得慌，这俩「四十分钟」的**味道完全不一样**——虽然开锁师傅说的跟[二 · 困在电梯](#二--困在电梯)里那个时间是一回事。等法天差地别。

#### 可用细节

| 类 | 内容 |
|---|---|
| 追责 | 「你出门没检查？」「钥匙 ✓ 一直你管着」——三十秒后同时闭嘴，吵也没用 |
| 楼道 | 坐台阶上 · 声控灯 ✓ 两分钟灭一次，谁跺一脚就亮 · 邻居出来倒垃圾，点个头算是打过招呼 |
| 消磨 | 分着吃完包里剩的半包饼干 · 翻手机 ✓ 翻相册打发时间，翻到老照片 ✓，回忆杀就这么来了 |
| 门开 | 师傅三十秒就弄开了，俩人看着那扇折腾了他们一小时的门，半天没说话 |

「声控灯熄了谁跺脚」是这条的节拍器：每两分钟一次的小动作，把四十分钟数得见。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁忘的 | 他 | 她从来不记事，这回偏偏忘了——为啥忘，背后有文章 |
| 时段 | 傍晚 | 凌晨两点，不敢喊师傅，蹲到天亮，狼狈到家 |
| 等待质量 | 翻相册想旧事 | 冷战被关在同一个楼道（想不搭话都难） |
| 门开后 | 进门就瘫倒 | 进门头件事：配了三把备用钥匙，一把埋花盆里，多年后花盆钥匙救过一回急，兜回来了 |

「她从不忘事这次忘了」，钥匙是引子，她最近的心不在焉才是正文。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 相册翻到三年前那张 | 声控灯又熄了，这次她先跺的脚 |
| 内心 | 我咋把钥匙忘了。我这阵子不对劲。 | 楼道待着也行，她咋样都好 |

| 写崩 | 写成了俩人越吵越凶 | 写成了他踹开门耍帅 |

#### 换皮

1. 追责追出真火。三十秒封顶，然后一致对门。
2. 跳过等待直接开门。楼道四十分钟才是正文。

## 九 · 手机摔了

| 摔的场合 | 平时手滑 | 为了接住摔倒的她，手机替她摔了，英雄事迹里最小的一件 |
| 换机 | 换了新的 | 修好接着用，裂纹留着（「裂了才是我的」） |

「她偷偷重拍同角度的照片」，数据救不回来，人可以重演给他存。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他先救哪个备份 | 「数据不保证」那六个字 |
| 内心 | 排第一的文件夹是啥 | 三年的东西，三年的东西 |
| 好的处理 | 她一句「多少钱都修」没问修啥 | 他数据丢了没冲谁发火 |
| 写崩 | 写成她借机翻手机 | 写成他崩溃三章 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 随身的木匣掉进水里，晒干的信纸字洇开了，他一个字一个字描着看 |
| 修仙 | 储物袋漏了，东西散了一地，他先扑过去捡她给的那枚旧符 |
| 星际 | 个人终端坏了，数据舱要排七天才能修，那七天他整个人都蔫了，跟丢了魂似的 |

#### 写崩的三种方式

1. 只写手机贵。钱在这条里一文不值。
2. 抢救顺序不写。那是全条的信息所在。
3. 数据丢失轻轻放过。丢了就是丢了，重量要给足，然后用重拍那批照片来接。

## 十 · 半夜的噩梦

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：睡着 54.0% ＋ 夜深 37.0%

**骨架**｜凌晨三点，有人从梦里醒过来，另一个也醒了，或者干脆装睡。

#### 节拍链

梦里不写内容，只写外部。挣醒，坐起来喘。确认现实，摸到身边的人。对方的反应。三点钟的对话，或者沉默。重新睡去，或者等天亮。

#### 时间轴

凌晨三点是人一天里防线最松的时候。白天憋着不敢说的话，到这个点自己就溜出来了。这玩意儿说白了就是台「真话时间机」，噩梦只是个开关。

#### 梦的内容学

梦不用写全，梦醒后的只言片语就够：

| 他梦见的 | 泄露的 |
|---|---|
| 「梦见你走了」 | 心里不踏实，怕你哪天真走了（接 [04-委屈与破防 · 我是不是不够好](04-委屈与破防.md#九--我是不是不够好)） |
| 梦回某段旧事 | 家里欠下的旧账（接 [13-家庭与亲属 · 他的原生家庭](13-家庭与亲属.md#六--他的原生家庭)） |
| 说不出内容，只是抖 | 有些事，话到嘴边也说不清 |

| 她梦见的 | 泄露的 |
|---|---|
| 白天那场事故重演 | 她白天吓成那样，晚上全在梦里算账（接 [四 · 地震那几秒](#四--地震那几秒)） |
| 她极少做梦，这次醒来沉默 | 她做梦的事自己咽了，他也就递杯水，不多问 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 醒的瞬间 | 倒吸气 · 一把攥住被子 ✓ · 心跳声大到自己能听见 |
| 对方 | 其实早被惊醒，装睡三秒决定开口 ·「做噩梦了？」声音哑着 |
| 三点的对话 | 灯不开 · 声音都压着 · 说的话第二天都默契不提 |
| 动作 | 递水 · 把人往怀里带 · 手在背上一下一下拍，拍的是哄人的节奏 |
| 重新入睡 | 换了个姿势，手被攥着睡到天亮，麻了也没抽 |

「手麻了也没抽」，这条的全部温柔浓缩在一只麻掉的手上。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁做梦 | 他 | 她少见，所以每次都很重 |
| 说不说 | 说几句实在话 | 一个字不提，就靠着话到不了的那种梦 |
| 频率 | 偶尔 | 一阵子老做，心里有事没过去，梦是来催的 |
| 第二天 | 都当没这回事 | 她白天约了个心理咨询，拿梦当正经事办，特别像她 |

「她把噩梦当待办事项处理」——这就是她的性格签名：**连脆弱都要立项解决。** 而他呢，嘴上不说，心里默默把这条也记进了「她可爱的地方」那张单子。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他梦里漏出的那半声 | 她醒后那不对劲的十分钟 |
| 内心 | 白天他一个字都不提 | 别问梦见了啥。递水，拍背。 |
| 好的处理 | 她听他说「梦见你走了」，没接话，往他那边挪了挪 | 他学会了不问「梦见啥了」，就问「喝不喝水」 |
| 写崩 | 写成半夜三点掏心窝子 | 写成天天做噩梦，光顾着卖惨 |

「回答是挪了半个身位」，三点钟的语言是身位不是句子。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 更漏三响，帐里挣醒。她只低声说了句「有我」，这话白天她从不出口 |
| 修仙 | 心魔入梦，修为越高梦越凶。他守着她入定，替她挡了一夜梦 |
| 星际 | 冬眠舱醒来的那阵恍惚，舱内灯自动调暗，系统这点比人贴心 |

#### 写崩的三种方式

1. 三点聊到五点，三句话封顶，剩下的靠站位和动作。
2. 梦只能露一角，内容却得写全。
3. 反复做同一个梦，必须指向一件还没解决的实事。噩梦拿来当便宜虐点反复用，行不通。
