# 末世与废土

> **分级** 分级见各条，分级上限 `M` ｜ 预警 ⚠️暴力 ⚠️致郁（第五、七条另标） ｜ 亚型 末世／废土（现代或科幻）
> 频次来源：未单列族，邻族受伤 52.8%、离世 29.4%（13-07），基数 2,894 部独立作品。文案标签口径见 [10-藏书索引-公开/语料统计](../10-藏书索引-公开/语料统计.md)。本族未单独跑挖掘，各条频次栏标注最近的邻族
> 这一族写末世里东西怎么分：口粮、规矩、子弹、一票。那一份她给了谁，旁人都盯着。

## 和邻族的分工

危机与保护族写的危险是一次性的，末世里的危险一直都在，成了背景。所有的温柔都只能从口粮、弹药、床位里一点点省出来。

## 一 · 最后一份口粮

`M` ｜ ⚠️暴力 ⚠️致郁 ｜ 末世／废土 ｜ 语料频次：未单列族，邻族受伤 52.8%、离世 29.4%（13-07）

**骨架**｜队里只剩一份口粮，她当众给了他。在场的人都看见了。心里各有各的数。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 弹尽粮绝的第三天，队伍搜出一份密封口粮 |
| 2 | 所有人都盯着那份口粮，谁也没先伸手 |
| 3 | 她拿起来，递给他，一句多余话没说 |
| 4 | 旁边有人喉结滚了一下，有人把脸转开 |
| 5 | 他接过来，没吃，揣进怀里 |
| 6 | 当晚有人来找她谈「分配公平」，她一笔一笔把账摆了出来 |

#### 时间轴

弹尽粮绝的第三天。口粮搜出来，大家都看着，她递给了他，当晚就有人找她谈「分配公平」。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他这边 | 接过来时没问「那你呢」 · 口粮揣进内袋，贴着胸口放 · 夜里趁没人留意，把口粮掰成两半，一半塞回她包里 |
| 她这边 | 递过去时一点没犹豫，跟递一把螺丝刀没两样 · 后来那人找她谈，她只回了一句「他背物资的时候你们谁也没问过公平」 |
| 物件 | 那份口粮是军绿色包装，密封条被反复贴过三次 · 旁边那人腰上的水壶晃了一下 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他吃不吃 | 当场就吃了，吃得飞快，好像怕她反悔 | 一直留着没吃，等到她喊饿那天 |
| 队里的人 | 当面不吭声，背后传闲话 | 有人学她，也把东西分给和自己亲近的人 |
| 她的态度 | 谁来问都不解释 | 当着大家讲明白：这份口粮是他前三天省下的，现在不过是还给他 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她给了就算给了，不图他记着这份恩，也不怕别人议论 | 他接过来没吃，揣进了怀里 |
| 内心 | 她在估队伍还能撑几天，这份口粮给谁最稳得住局面 | 他在想自己配不配得上这份口粮，往后拿什么还 |
| 好的处理 | 她给完转身就忙别的去了，跟没这回事一样 | 他没说谢，把口粮收好，下回放哨多站了一班 |
| 写崩 | 她当众表白「你对我来说最重要」 | 他当场红了眼眶，哽咽着说「从来没人对我这么好」 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 最后半块干粮饼／她当众塞进他怀里／他揣进袖袋，没掰 |
| 修仙 | 最后一枚辟谷丹／她当着同门递给他／他收进储物袋，没吞 |
| 星际 | 最后一管营养膏／她当众推到他面前／他扣进腰包，没拆 |

#### 写崩的三种方式

1. 让他拒绝这份口粮。 末世里推来让去地让粮食，是偶像剧的路数，还会让她当众下不来台。她给了，他就该接。规矩如此。
2. 让旁观者集体沉默。 他们不可能一声不出。有人眼红，有人打算盘，有人冷眼看着，这些都要写出来，别让场面空着。
3. 让这份口粮成为转折点。 这算不上主线上的大事。往下要写的，是之后东西怎么分、队里的人怎么重新站队。

#### 可串接

前接：末世／废土族
后接：末世／废土族
对照：现代都市族。都是分东西。那边分外卖，这边分的是命。

#### 示例（本库自撰，可直接改写）

> 铁皮桌上那盒口粮，密封条完好，压着半张旧报纸。三天没生火，炉膛里灰是凉的。她伸手拿起来，递过去。他接了，没看四周，把盒子揣进大衣内袋，拉链拉到顶。
> 旁边有人喉结动了一下，随即扭过头去拨弄枪栓。另一个把水壶从左手换到右手，没喝。
> 夜里，火堆重新点起来。她蹲着添柴，那人站在三步外问：「分配公平吗？」她没抬头，从兜里掏出一张纸，折痕很深，上面三行字，两行是日期和名字，一行是份量。
> 「第三天，老七的份额让给老五，第五天，老五的份额让给你。」她说完把纸塞回兜里，继续添柴。
> 那人站了一会儿，走了。火堆噼啪响了一声，她听见身后帐篷拉链拉开又合上，像呼吸漏了一拍。

## 二 · 庇护所的规矩

`M` ｜ ⚠️暴力 ⚠️致郁 ｜ 末世／废土 ｜ 语料频次：未单列族，邻族受伤 52.8%、离世 29.4%（13-07）

**骨架**｜她定了新规矩，头一条就跟他有关。整个庇护所都传遍了。他自己最后一个知道。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 物资按人头发，她那份总是多出一截，没人问过为什么 |
| 2 | 有人半夜溜进他棚子翻东西，被巡逻的人押到她跟前 |
| 3 | 她当时什么也没说，第二天贴出一张手写告示：庇护所新规矩，第一条，动他的，扣当天口粮 |
| 4 | 告示就贴在门口，他经过时看到了，对着那行字看了很久 |
| 5 | 他找到她，说这么做不合规矩，别人会有意见 |
| 6 | 她说规矩是她定的，有意见留到吃饭的时候说 |

#### 时间轴

先是有人摸进他棚子，第二天告示贴了出来，他经过时看见，对着那行字看了好久，才去找她。那张告示一贴就是两个月。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他这边 | 棚子门帘上加了一块从仓库翻出的帆布 · 领饭时旁人会让出半个身位 · 他话比以前更少了 |
| 她这边 | 告示是铅笔写的，纸边撕得歪歪扭扭 · 那条规矩她从没跟他解释过 · 有人嘀咕，她只抬了抬眼皮 |
| 物件 | 那张告示在门口贴了两个月，淋过雨，字都洇开了，也没人敢揭 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 规矩的尺度 | 只护着他一个 | 连他那个小圈子一起护 |
| 他的反应 | 认下了，从此把自己当成她的附属 | 想着还她，找机会替她挡事 |
| 周围人的态度 | 当面服气，背后说闲话 | 此后对他客客气气，也不敢去惹他 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她护他护得天经地义，别人怎么看她根本不管 | 被人护着，他先觉得自己不配，接着又怕连累她 |
| 内心 | 她想的是：一条规矩够不够用，要不要再添一条 | 他想的是：自己得对得起这个价，不能白占着 |
| 好的处理 | 那条规矩她始终没跟他提过，是他自己看见的 | 他没去道谢，只是此后每回领饭都站在她旁边 |
| 写崩 | 她当众表白，庇护所的规矩成了情书 | 他哭哭啼啼地推辞，非要她撤掉规矩 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她月例多出一份银子／他柜子被人翻动／告示贴出：动他的，罚三月月钱 |
| 修仙 | 她灵石份额多出几块／有人潜进他洞府翻找／她立门规：犯他者，逐出山门 |
| 星际 | 她配给卡额度高出标准／他宿舍舱门被撬／她签发新条例：碰他物资的，扣一周氧气配额 |

#### 写崩的三种方式

1. 让他跑去质问她。 他没这么大的胆子，也没这么蠢，他知道这条规矩是保命用的。真写他去质问，他就成了不知好歹的蠢人。

2. 把她写成霸道总裁式的宣示主权。 他是她的，这事她用不着向谁证明，定一条规矩最省事。写她拍桌子吼人，一个末世里掌权的人就被写成了偶像剧配角。

3. 让这条规矩立刻产生戏剧性后果。 有人不服、有人挑衅、规矩受到挑战，那是另一个故事。这里写的是规矩立住了，之后什么事也没出，日子照旧过，只是大家都知道他有人管了。

#### 可串接

前接：末世与废土族
后接：末世与废土族
对照：日常照料族

#### 示例（本库自撰，可直接改写）

> 物资车到的时候，他照例去领自己那份，发现袋子里多了一罐午餐肉，没动，放回原处。
> 半夜有人掀他棚子的帘子，被巡逻的揪到她那，她看了一眼，说记下，放人。
> 第二天告示贴出来，第一条写的是「动他东西的，扣当天口粮」，底下签了她的名字，字很大。
> 他站在告示前，把那一行反复看了几遍，手指在「他」那个字上停了一下，没说话。
> 他去找她，说这么写不合规矩，别人会嘀咕。她正擦枪，没抬头，说嘀咕就嘀咕，规矩我定的，有意见吃饭的时候说。
> 他站在门口，看她把擦完的枪搁回架上，想了想，说那午饭给我留一副碗筷。

## 三 · 他被分配给她

`M` ｜ ⚠️暴力 ⚠️致郁 ｜ 末世／废土 ｜ 语料频次：未单列族，邻族受伤 52.8%、离世 29.4%（13-07）

**骨架**｜「分配」这个词说出口，两个人都愣住了。她没想到自己会这么说，他没想到她肯解释。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 清点完物资，她指着那袋净水片和半盒消炎药说「这批给他」 |
| 2 | 旁边有人问「按什么标准分的」，她回「按我的标准」 |
| 3 | 她一转头，见他正看着自己，又补了一句「你归我这一份」 |
| 4 | 「分配」两个字一出口，两个人都静了一下 |
| 5 | 他没接话，低着头轻轻把那袋东西收进自己的背囊 |
| 6 | 夜里她值完岗回来，那袋净水片原封不动地搁在她帐门口，一片没少，上面压着张纸：队里比我伤重的还有两个 |

#### 时间轴

白天她说了「这批给他」，他收进背囊。夜里她值岗回来，那袋净水片原样摆在她帐门口。天亮前，她把消炎药化进了他的水壶。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他这边 | 消炎药数了三遍，队里还有哪三个人缺这个，他都记着 · 净水片一片没拆，铝箔包装的边角压平了才放回去 · 纸条是物资清单的废页翻过来写的，字很小 |
| 她这边 | 先想的是「退回来是什么意思」，接着想「他是不是觉得我拿他当自己人才这么分的」 · 后半夜睡不踏实，天亮前把那两片消炎药碾碎，化进他的水壶 |
| 物件 | 退回来的那袋物资，铝箔纸上有他指甲压出的印子 · 水壶里化开的药粉，喝不出味道 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她的处置 | 退就退了，下回照样分，也不解释 | 叫他到跟前，把「你归我这一份」原话又说了一遍 |
| 他的回应 | 收下了，不再退，可队里有谁受伤他先匀出去 | 那袋物资他一直留到过期，一片没用，也没扔掉 |
| 旁人的眼光 | 都装作没看见，背地里说「她是把他划进自己人了」 | 有人不服气，她当着大家问那人「他那一份是我从自己配额里扣的，你有意见？」 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 那句「归我这一份」比那袋药还管用，后来他跟人拼命时心里有底 | 他退回去，是想让她知道他不愿只做「被分配的那一份」 |
| 内心 | 她在算这袋物资分出去以后，自己的伤还撑得了几天，撑得住就不改 | 他在算自己值几片药，算不明白，只好退回去 |
| 好的处理 | 她没追着他讨说法，只在下回清点物资时当众说「我和他的是同一份」 | 他没说「我想归你」，只说「药你留着，我皮实」，第二天替她挡了一刀 |
| 写崩 | 她当众宣示主权，分东西分成了秀恩爱 | 他委委屈屈地问「你是不是可怜我」 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 金疮药／账房钥匙／他半夜把药放回她门口，压了张字条：府里比我伤重的还有两个 |
| 修仙 | 培元丹／止血符／他原样放回她洞府门口，符纸下压着传音符：同门比我根基差的还有两个 |
| 星际 | 净水片／医疗胶／他放回她舱室门口，胶管下压着数据板：舰上比我烧伤深的还有两个 |

#### 写崩的三种方式

1. 让他当场表忠心。 比如说「我愿意归你」「我这辈子都是你的」。废土上没人这样讲话。讲了也不值钱。他真认了这份分配的话，退药时就不会对自己的伤只字不提。
2. 把她写成没察觉退药这回事。 东西退回来是什么意思，她不可能不懂。真没当回事，她就不会半夜起来把药化进水壶。她用自己的办法收下了这件事。
3. 让「分配」变成一条感情线的定情信物。 在这个世界里，分配先是一个关乎活命的决定。她把配额匀给他，她自己就少一份。这一点写没了，整条戏就只剩暧昧。

#### 可串接

前接：末世族
后接：废土族
对照：邻族。同样一个「给」字，那边给出去的是命，这边给出去的是活路。

## 四 · 出去搜物资

`M` ｜ ⚠️暴力 ⚠️致郁 ｜ 末世／废土 ｜ 语料频次：未单列族，邻族受伤 52.8%、离世 29.4%（13-07）

**骨架**｜门里门外只隔着一道铁皮。带谁出去由她定。定之前她把人一个个看了一遍。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 物资点摸清了，队伍只够出两个人，她手下能用的有三个 |
| 2 | 她把他们一个个看过去，看装备，看伤，看眼神 |
| 3 | 走到他跟前她停下，问他上回换药的地方拆线没有 |
| 4 | 他说拆了。她伸手在他肋侧按了一下，他绷住了没出声 |
| 5 | 她转头叫了另一个人 |
| 6 | 他留在原地，攥着那块磨石，指节都发白了 |

#### 时间轴

没有时间轴。整条靠她一个个看人往前走。她在他面前停下，问拆线没有，在他肋侧按了一下，回头叫了另一个人，铁皮门外的脚步声越走越远。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他这边 | 背包里多捆了一圈伞绳 · 换了新鞋带 · 头天夜里没睡，刀磨了三遍 |
| 她这边 | 查他伤口时手很轻 · 按下去那一下却一点没留情 · 走的时候没回头 |
| 物件 | 门边那块磨石 · 两张写了一半的物资清单 · 她留给他的一整盒抗生素 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她留他的原因 | 他伤还没好利索，带出去会拖慢速度 | 伤是好了，可他太听话，听话的人出去了回不来 |
| 她怎么处理留下的他 | 走之前给他一道明确的指令 | 一句话不说，把东西留在门口 |
| 他的反应 | 当场请战，说自己行 | 一声不出，把她留下的东西收起来 |

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把他留下，跟心软扯不上，心软的人活不到这个物资点 | 她在他伤口上按的那一下，让他发觉自己还怕死 |
| 内心 | 她在算：带个伤号出去，回来时可能就是两具尸体 | 他在算：要是她带回来的人里有伤员，她会不会后悔没带他 |
| 好的处理 | 她和另一个人出门时，叫那人脱下外套扔给他 | 等她走远了，他才放下磨石，开始清点她留下的药 |
| 写崩 | 她看他眼神可怜，就改了人选 | 他追出去抱住她的腿不放她走 |

#### 换皮

| 世界 | 等价物 |

| 古代女尊 | 她按他佩刀旧伤，他没出声，她点走旁人，他攥着磨刀石 |
| 修仙 | 她按他丹田旧伤，他没出声，她点走旁人，他攥着灵石 |
| 星际 | 她按他肋侧旧疤，他没出声，她点走旁人，他攥着维修扳手 |

#### 写崩的三种方式

1. 让她解释。 在废土上，她选谁不选谁用不着理由。一解释，决定权就交到了被拒的人手里。她说完就走。理由让读者自己猜。
2. 写他哭。 他是没被挑上的兵。没有退路，只能把磨石攥到出血。
3. 让这个决定马上被证明错了。 她带出去的人死在半路，她回来后悔没带他，那是爽文的写法。废土上选对选错都没机会反悔。她选了就认，他也认。

#### 写崩的三种方式

1. 让她当众许诺「我们会活下去」。 末世里谁也不信口号。她话越少，别人越踏实。让她只管做事，意思别人自己看得出来。

2. 让他第一天就受伤。 头一天他就伤了，说明她连自己的人都护不住，这个领头的就立不起来。

3. 让所有人都理解她。 总得有人嘀咕，有人不服，有人夜里想走。她要压住的，是自己人的心。

## 十 · 记住名字的人

`M` ｜ ⚠️暴力 ⚠️致郁 ｜ 末世／废土 ｜ 语料频次：未单列族，邻族受伤 52.8%、离世 29.4%（13-07）

**骨架**｜全族死了那么多人，他把名字一个个记下来。她发现那份名单上她排在第一个，旁边画了一道杠，意思是「还活着」。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 她带队出去，回来少了两个人。她把名字报了一遍，没再提。 |
| 2 | 她看见他在营地角落的土墙上刻着什么，走近一看，是一排名字。 |
| 3 | 她问这是什么，他说是死了的人，记一下。 |
| 4 | 她看见上面也有自己的名字，后头跟着一道短杠，就问这杠是什么意思。 |
| 5 | 他说活着的画一道，死了的画叉。 |
| 6 | 她数了一下，满墙都是名字，她的在最上面，那道杠比谁的都深。 |

#### 时间轴

她每出去一趟，回来少了人，他就在墙上添上名字。最上面一直是她的名字，后头那道杠始终没变成叉。

#### 可用细节

| 类 | 内容 |
|---|---|
| 他这边 | 挑的是雨淋不到的那面土墙 · 名字按死的先后排，不按姓氏 · 每添一个名字，他都把那块土拍平了重刻 |
| 她这边 | 先问「有我吗」，再问「我在哪」 · 见自己的名字排在第一，她半天没说话 · 说了句「我死不了」，说完自己都不信 |
| 物件 | 那面土墙 · 他刻名字用的钉子，本是一把匕首的尖，已经磨秃了 · 最后那道杠是他用指甲重新划过的 |

| 轴 | 一端 | 另一端 |

| 她问不问 | 当场就问「为什么我排第一个」 | 不问，后来自己半夜去看那面墙 |

| 结局 | 她活到了最后，墙上刻满全族人的名字，唯独她的后面没有叉 | 她死在他前头，他把她名字后的杠改成叉，再补上自己的名字 |

#### 双向写法

| 落点 | 她发觉自己怕死的理由变了，她怕的是他的名字后面多出一个叉 | 他能替她分担的只有记名字这一件，她可以死，他不能让她死得没名没姓 |
| 内心 | 她在算自己还欠着多少人，算来算去，只有他这一笔她不想还 | 他想着哪天这面墙刻满了，就换一面接着刻，只要她活着，他就有地方刻 |
| 好的处理 | 她开始在每次出任务前报一遍名字，只报给他一个人听 | 他不说「你活着回来」，只在她走后去墙边，把她名字后的杠再描一遍 |
| 写崩 | 她当众夸他重情重义 | 他哭着求她别死 |

| 修仙 | 玉简名录／他在洞府石壁上刻字／她的名字在首位，笔画入石三分 |
| 星际 | 舰船舱壁刻痕／他在金属板上划名字／她的代号在最上方，划痕磨得发亮 |

#### 写崩的三种方式

1. 让他说「我怕你死」。 一说出这个怕字，他就从记录的人成了求告的人。让他动手。别让他开口。

2. 让她感动到改主意。 被人记住了，她也照样会去拼命。末世里被记住的人多的是。活下来的没几个。该出的任务她还是出。只是出发前会多看他一眼。

3. 把名字数量当卖点。 写他记了三百个、五百个、上千个名字，数字一报出来反倒显得假。死了多少人他并不知道，只知道一个接一个地刻，刻到后来钉子都磨短了，换过多少次手他也记不清。

对照：现代都市，他记着她的班表。那边记下的是日子，这边记下的是生死。
