# 文体与视角实验

> **分级** 分级见各条，分级上限 `T` ｜ 预警 ⚠️BE（限第九条）｜ 亚型 全谱系通用（文体层）

## 这一族收的是场景

十条都从一件白纸黑字的东西起手：一封信、一叠病历、一页谱、一行日志、一份判决、一屏聊天、一张清单、一本日记、一篇悼词、一份大纲。每一件东西都有人、有时刻、有前后。信是他写的那晚，病历是她在收费窗口翻到的那次，判决书是她在律所走廊读的那二十分钟。写法学在 07 卷，具体那一场戏在这里。

材料的分层：

| 第二人称的十三条规则、四篇实测 | [07-语言风格/02-第二人称写作专论](../07-语言风格/02-第二人称写作专论.md) | 规则被一个人在一个夜里用出来的那一场 |
| 施动语法、名字的驱逐与发放 | [07-语言风格/01-女攻叙事语感](../07-语言风格/01-女攻叙事语感.md) | 语法纪律落到一封信、一份文书上的样子 |
| 聊天的内容与人在聊天时的心情 | [19-玩闹与网络 · 聊天记录](19-玩闹与网络.md#二--聊天记录) | 撤掉叙述层，界面独自承担全部叙事 |
| 文书类文本（判决、病历、谱牒、日志） | 全库此前无场景条目 | 从零起 |

两条通用纪律：

| 纪律 | 做法 |
|---|---|
| 文体只是取景框 | 换文体的收益来自它挡掉了什么。挡掉的东西必须是这场戏本来最想说的那句，戏才立得住 |
| 冷文书不许自己动情 | 病历、判决、日志的语言一旦开始抒情，它就退化成旁白。情绪由读者在栏与栏之间自己补 |

十种文体的三项参数，开写前先定死：

| 条 | 文体 | 叙述者是谁 | 结构性沉默（它说不出的那类东西） |
|---|---|---|---|
| 一 | 书信（第二人称） | 写信的人，对着一个不在场的收信人 | 收信人的内心 |
| 二 | 病历与护理单 | 无人称的医疗机构 | 关系、动机、疼的程度 |
| 三 | 谱牒正文＋批注 | 修谱人（正文）与批注者（小字） | 感情，除非借批注偷渡 |
| 四 | 系统日志 | 一台只记可量化项的机器 | 「为什么」这个字段不存在 |
| 五 | 判决书 | 合议庭，只认可举证的事实 | 起因、私下的账、当天的天气 |
| 六 | 聊天记录 | 无（界面本身） | 表情之外的一切表情 |
| 七 | 清单 | 写清单的人，写给三天后的自己 | 完整句子，因而也说不出因果 |
| 八 | 日记＋目击 | 写的人一层，读的人一层 | 写日记者不打算写下来的那一半 |
| 九 | 讣告与悼词 | 家属署名的集体口径 | 关系的实情、他最后一句话 |
| 十 | 作者的大纲与稿 | 她，正在把一个活人转写成人物 | 那个活人自己的版本 |

这一族的三种通病，十条各自还有各自的：

| 通病 | 症状 | 判据 |
|---|---|---|
| 文体噱头盖过戏 | 形式花样每页一个，人物两千字没动过 | 把文体换回常规叙述，戏若照样成立，形式就只是包装 |
| 第三段破功 | 前两段文书腔守得住，第三段忍不住滑回小说腔，出现「他心里一酸」 | 通读时只找形容心理的词，文书里出现一个就是破口 |
| 通篇不换气 | 第二人称从头「你」到尾，密度不变，读者被摁住 | 数任意一页里「你」字的行占比，全篇曲线是平的就是没换气 |

## 一 · 写给你

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：坦白 6.5% ＋ 夜深 37.5%（第二人称未进入人称统计口径）

**骨架**｜她写了一封不打算寄的信。第一句用了「你」，写到第三段发现这个字每句都在，读着像审问，于是她开始一个一个往下删。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 起意（导火索很小：他在电话里说没事，她听出来有事，当面问不出口） |
| 2 | 抬头（写「你」还是写名字：名字一落笔，信就变成了公文） |
| 3 | 第一段写事实，安全，也没用 |
| 4 | 中段失控（「你」字每句都出现，写的人自己先觉得刺耳） |
| 5 | 删（删掉一半「你」之后，句子反而离得更近） |
| 6 | 写到不能寄的那一句（写出来才知道为什么不能寄） |
| 7 | 装信封、写地址、不贴邮票 |
| 8 | 存放（书里、抽屉夹层、云端草稿箱：三个位置三种打算） |

#### 时间轴

写两小时，删到天亮，存了六年。**信的时间是三段式的**：写的那一夜、每年翻出来看一次的那几分钟、决定处理掉的那一天。第三段最短，多半只有一个动作：不烧，原样放回去。

#### 「你」字密度怎么控制

| 密度 | 读起来 | 放在哪一段 |
|---|---|---|
| 每句都有 | 逼视，像质问 | 只留给最后三行 |
| 三句一次 | 陪着说话 | 主体段落 |
| 整段不出现 | 写信的人在自言自语 | 事实段与回忆段 |
| 只出现在一句里 | 那一句被抬到全信之上 | 收尾 |

换气的做法是让密度成为一条曲线：事实段近乎零，中段回到三句一次，末尾三行连着落。全篇平铺的高密度会把读者摁住，专论第十条的短行要求同理（[07-语言风格/02 · 九](../07-语言风格/02-第二人称写作专论.md)）。

#### 可用细节

| 类 | 内容 |
|---|---|
| 物 | 从别处撕下来的纸 · 中途换过一支笔 · 写坏三张的抬头 · 没贴的邮票 |
| 语气破口 | 一句写到一半改成疑问句 · 中间插进一件毫不相干的小事（今天楼下修路） · 一处涂黑，涂得看不出原字 |
| 不能寄的那句 | 通常是一个请求，且是她这辈子没对任何人提过的那一类 |
| 存放处的含义 | 夹在他送的书里＝还打算给他看 · 抽屉夹层＝给自己留证据 · 云端草稿＝会被同步到共用平板（接第八条） |
| 收信人不知道的证据 | 信封上写了地址，门牌号错了一位 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁是「你」 | 他是「你」：一封写给他的信 | 她是「你」：整篇小说的读者代入位，四种规定度配置见 [07-语言风格/02 · 一](../07-语言风格/02-第二人称写作专论.md) |
| 信的去处 | 永不寄出 | 寄了，寄到一个已经搬空的地址，一个月后原样退回 |
| 被读到 | 他这辈子没读到 | 他读到了，且在她不知道的时候（接 [八 · 日记被看见](#八--日记被看见)） |
| 时态取向 | 同步型（今晚，此刻，笔在手上） | 追忆型（那年冬天）；两种混在一篇里，读者就找不到自己站在哪 |
| 文体纯度 | 整章只有信，零叙述层 | 信做插入件，前后有常规叙述包着（长篇里更稳） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 删「你」的那道工序：删一个字近一分 | 他写信时的抬头困难：叫她什么都不对，敬称太远，昵称写不出手 |
| 内心 | 写的时候她在替他说话，写完发现替错了 | 他信里的施动位是空的，全篇没有一个他做主语的动词 |
| 好的处理 | 不能寄的那句照写，然后把信收起来 | 他写完不寄，第二天照常做饭，那句话换成一个动作交出去 |
| 写崩 | 写成情书朗诵 | 写成卑微陈情表 |

#### 写崩的三种方式

1. 通篇不换气。 「你」字每句压着，读者被摁住两千字，亲近就变成了压迫。密度要有起伏。
2. 叙述者比收信人更懂收信人。 信里写「你其实早就……」，收信人当场有权反驳，整封信随即失效。
3. 信写成总结陈词。 真信有一半在讲无关的事：修路、账单、猫。全是要点的信像遗书，不像信。

前接：[15-秘密与坦白 · 说不出口的那件](15-秘密与坦白.md#十--说不出口的那件) · [04-委屈与破防 · 憋着不说](04-委屈与破防.md#二--憋着不说)
后接：[八 · 日记被看见](#八--日记被看见) · [十 · 她写他](#十--她写他)
对照：[29-微小仪式拾遗 · 电话里的声音](29-微小仪式拾遗.md#十--电话里的声音)（同一句话用声音交出去的版本）

#### 示例（本库自撰，可直接改写）

> 那晚她写的第三段是这样的：楼下从上周三开始修路，早上六点就砸。你走之后我才发现自己一直没换过闹钟。豆浆机的滤网卡了，我拆了半小时，你以前是怎么拆的。
> 前两句里没有「你」，第三句一个，第四句一个。她数了数，把第四句划掉了。
> 最后三行她一个也没删。三行里「你」出现了五次，她读了一遍，把纸对折，塞进他上个月留在书架上的那本书。

## 二 · 病历上的他

`T` ｜ 无预警 ｜ 现代都市（古代脉案、修仙丹方同构） ｜ 语料频次：生病 49.4% ＋ 上药 45.2%

**骨架**｜出院那天她去结账，柜台把病历本推回来让她自己核对。入院记录一页，护理单二十三页。二十三页里没有一个字提到她，每一页都是她按铃按出来的。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 起点（办手续的间隙，本子摊在窗口的不锈钢台面上） |
| 2 | 第一页：主诉、现病史、既往史，用第三人称把他的一生压成六行 |
| 3 | 「陪护人」那一栏（关系填的是什么，是谁填的） |
| 4 | 护理单的时间列（02:15 换药 · 03:40 体温 38.2 · 05:10 患者入睡） |
| 5 | 她在时间列里认出自己（那些时间点全是她按铃的时间） |
| 6 | 一处笔误或一句手写（护士在页脚补的一行，格式外的唯一一句人话） |
| 7 | 出院小结的「转归」栏 |
| 8 | 她把本子收进抽屉，和其他不会再打开的证件放一起 |

#### 时间轴

住院九天，病历二十四页，她读完用二十分钟。**文书的钟比人的钟快**：一页顶一天，翻页就是过日子；而那九天里她按了四十次铃，纸上只剩四十个时间点。落差在这里，戏也在这里。

#### 栏位与它底下的那件事

| 栏位 | 文书怎么写 | 底下是什么 |
|---|---|---|
| 主诉 | 「反复腹痛三月余」 | 他忍了三个月没说 |
| 既往史 | 「否认外伤史」 | 连旧伤都瞒了，且瞒的是医生（接 [41-他的身体与年岁 · 旧伤](41-他的身体与年岁.md#一--旧伤)） |
| 陪护人 | 「朋友」 | 关系还没走到能填的那一栏 |
| 护理记录 02:15 | 「换药，患者配合」 | 他咬着毛巾没出声 |
| 护理记录 05:10 | 「患者入睡」 | 她还没睡，她在等这一行出现 |
| 转归 | 「好转」 | 出院不等于好，只等于不用再占床位 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 物 | 塑封的封面 · 手写与打印混排的页 · 腕带剪断后留在床头柜 · 缴费单折成小方块塞在夹层 |
| 格式的硬度 | 每一栏都有字数上限 · 关系栏是下拉选项，没有她要的那一项 · 签字栏一天要签三次，名字越签越潦草 |
| 唯一不冷的地方 | 页脚一行手写：夜间家属未离开 · 某页的字迹换了人，那天换了值班护士 |
| 他这一侧 | 他从头到尾没看过这本 · 他记得的是天花板上的一块水渍，纸上没有这一栏 |
| 事后 | 她按日期把二十四页重排了一遍 · 复印件她留了一份，正本交回医院 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁在翻 | 她翻（她不在场的那些小时显影出来） | 他多年后翻自己的旧病历，看见当年是谁签的字 |
| 关系栏 | 填「朋友」，一路填到出院 | 填「配偶」被拦下，需要证件（接 [23-婚嫁 · 领证那天](23-婚嫁.md#三--领证那天)） |
| 文书成色 | 全程冷到底 | 只有一处不冷，且那一处是外人写的 |
| 病的成色 | 小病，戏全在关系栏 | 大病，戏在转归栏（走 [41-他的身体与年岁](41-他的身体与年岁.md)） |
| 文体纯度 | 整节只有文书，不给现场 | 文书与现场交替，一页纸一段回忆 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 关系栏那一格的停顿：笔悬在下拉选项上 | 时间列里的 02:15：他记得那一下有多疼，纸上写的是「配合」 |
| 内心 | 她在纸上找自己，找了二十分钟，一个字也没有 | 他不知道她按过四十次铃，他以为护士是自己来的 |
| 好的处理 | 她不解释也不修改，把本子收好，出门给他买粥 | 他后来去调了一次病历，只为了看陪护人那一栏她填的什么 |
| 写崩 | 写成她在医院哭给读者看 | 写成他在病床上大段独白 |

#### 写崩的三种方式

1. 文书自己动情。 病历开始抒情，它就成了旁白，冷文书的全部力气来自它不许说。
2. 只贴文书不给现场。 文书是证物，必须有一个人在某个具体时刻翻开它，否则那是道具展。
3. 医学细节考据过头。 术语精确到第三行，读者就退开了。三个栏位顶三十个术语。

前接：[01-日常照料 · 半夜发烧](01-日常照料.md#三--半夜发烧) · [41-他的身体与年岁 · 他不肯去医院](41-他的身体与年岁.md#四--他不肯去医院)
后接：[41-他的身体与年岁 · 他的体检报告](41-他的身体与年岁.md#三--他的体检报告) · [九 · 讣告与悼词](#九--讣告与悼词)

## 三 · 族谱那一页

`T` ｜ 无预警 ｜ 古代女尊（现代户口本、家谱软件同构） ｜ 语料频次：请安 26.6%（谱牒段无独立族）

**骨架**｜他上谱那天，正文只有十一个字，格式是几百年不动的。右下角那行小字批注是她加的，三代之后重修族谱的人照抄了正文，也照抄了那行小字，且不知道原委。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 开谱（纸、墨、一格空行，落笔前要先请人研墨） |
| 2 | 正文格式（某氏第几女，某年某月纳某氏子，十一个字，一个也不能多） |
| 3 | 批注权的争夺（正文归修谱人，批注归谁：族长、书吏、还是她） |
| 4 | 她要的不是改格式，是那行小字的位置 |
| 5 | 落笔（写了什么，删了什么，删掉的那句她记了一辈子） |
| 6 | 他看见（他这辈子看那一行看了多少次，他自己数不清） |
| 7 | 重修（三代后的抄写者一并抄下，小字成了正文的一部分） |

#### 时间轴

上谱一炷香，那行小字十四个字，写完花了她一个下午。**批注的时间尺度是代际**：正文管的是名分，一次落定；小字管的是这个人被后来的人怎么想象，它的生效期从他死后才开始。

#### 正文与批注：两套语言

| | 正文 | 批注 |
|---|---|---|
| 谁写 | 修谱人，照例 | 有资格的人，视礼制而定 |
| 字数 | 固定，模板化 | 无定式，通常一行以内 |
| 能说 | 姓氏、生卒、位序、所出 | 才艺、病、一件小事、一句评语 |
| 不能说 | 感情 | 感情，但可以借「一件小事」偷渡 |
| 生效 | 当场 | 三代之后 |

批注偷渡感情的三种成法：记一件他做过的小事、记一句他说过的话、记一个只有她知道的日期。三者都不违格式，且都不可撤销。

#### 可用细节

| 类 | 内容 |
|---|---|
| 物 | 谱牒的纸有年份 · 新添的一行墨色比周围深 · 装订线在这一页被拆过一次 · 印章压在骑缝上 |
| 格式细节 | 名字前的位序字 · 归入哪一房 · 无出者的空栏怎么处理 · 女方名字用讳还是用字 |
| 现代同构 | 户口本「与户主关系」栏 · 家谱软件的备注字段有 200 字上限 · 墓碑落款的排序 |
| 谁不入谱 | 未过明路的、无出的、被除名的：除名用刀刮，刮痕比字还显眼 |
| 他这一侧 | 他不识那几个字，是别人念给他听的 · 他记住的是纸的味道 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 批注谁写 | 她写（用了她的权，且是她唯一能用在他身上的权） | 族里书吏代笔，她只能口述，一句话被改了三个字 |
| 内容 | 记功（他做过的一件事） | 记日期（一个只有他们俩知道的日子，全族当作生辰） |
| 他知不知道 | 他在场，看着她写 | 他到死不知道那行小字存在 |
| 三代后 | 照抄，成了家训里的一句 | 被删（重修时觉得不合体例），她的字迹只在旧本上留着 |
| 文体纯度 | 整节由谱牒条目与批注构成 | 谱牒只出现一页，前后是常规叙述 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她在格式里找那道缝：正文改不了，小字能写 | 他被念到自己名字的那一刻，第一次听见自己有位序 |
| 内心 | 她要的是不可撤销，感情靠不住，纸靠得住 | 上谱是安稳，也是从此有了要守的东西 |
| 好的处理 | 写完不给他看，等他自己听说 | 他后来学认字，第一个学会写的是自己在谱上的那个名 |
| 写崩 | 写成她大闹祠堂改祖制 | 写成他感激涕零跪谢 |

#### 写崩的三种方式

1. 格式随便改。 谱牒的分量全在它几百年不动，一改就成了寻常告示，那行小字也随之不值钱。
2. 批注写成情书。 批注是给后人看的公开文本，写热了立刻失格，冷着写才刺人。
3. 上谱当作大团圆。 名分落定不解决任何具体问题，第二天他仍要去请安，制度面接 [20-女尊制度场景](20-女尊制度场景.md)。

## 四 · 系统日志

`T` ｜ 无预警 ｜ 系统 · 穿书 ｜ 语料频次：系统 7.0%（26 卷口径）

**骨架**｜任务面板每天零点刷新。第 214 天的日志里多了一条没有编号的记录：门外停留 11 秒，未进入。没有奖励，没有惩罚，也没有说明。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 日志的常规格式（时间戳＋事件码＋参数，她早就不看了） |
| 2 | 异常条目出现（无编号，无积分变动） |
| 3 | 她去查（这条是谁记的，系统的记录粒度到底到哪一层） |
| 4 | 系统的口径（它只登记可量化项：时长、距离、心率、语速） |
| 5 | 她从数字里读出情绪（11 秒是她犹豫的长度，她自己也是这时才知道） |
| 6 | 系统给不出解释（面板上没有「为什么」这个字段） |
| 7 | 她开始用日志读自己，读了一个月 |
| 8 | 结算日（日志封存、清空，或者移交给她） |

#### 时间轴

任务周期以日计，日志以秒计。**机器的时间没有轻重**：它把她犹豫的 11 秒和她洗手的 11 秒记成同一种长度，重量由读日志的人自己加。她加重量的那一刻，日志就从工具变成了镜子。

#### 字段与它测不到的东西

| 字段 | 日志记了什么 | 它测不到 |
|---|---|---|
| duration | 门外停留 11 秒 | 她在等他先开口 |
| distance | 0.4 米 | 这是她第一次没有先伸手 |
| heart_rate | 峰值 118 | 峰值出现在他说「随你」之后 |
| voice_len | 她 3 字，他 27 字 | 那三个字是她全天说得最艰难的 |
| task_status | 未触发 | 任务没触发，因为她临时改了主意 |
| — | 无此项 | 他站在门里也没动，日志不记录 NPC |

最后一行是这条的机关：系统只给她装了传感器，没给他装。她要什么都能量到自己，量不到他，于是她第一次开始猜。

#### 可用细节

| 类 | 内容 |
|---|---|
| 界面 | 面板半透明，只有她能看见 · 提示音在耳后 · 日志导出是一段纯文本，没有排版 |
| 机器口吻 | 不用形容词 · 一律被动或无主语 · 数值精确到小数点后一位 · 判定结果只有三种：达成、未达成、无效 |
| 异常的形态 | 编号缺位 · 时间戳早于任务开始 · 同一秒有两条记录 · 一条记录的执行者写的是他 |
| 她的对策 | 把三个月的日志按小时重排 · 找出她心率超过 110 的全部事件，发现里面没有一件是任务 |
| 收束物 | 结算那天面板消失，她手写了一遍最后七行 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 日志是谁的 | 她的（他被系统当作 NPC，无字段） | 双方都有（他也绑了系统，两份日志对同一晚的记录不一致） |
| 系统的诚实度 | 只记事实，不解释 | 会漏记：凡与她真心相关的条目一律缺号，缺号本身成了线索 |
| 日志能否修改 | 只读 | 可删，删了会留一条「已删除」的空记录，比原记录更响 |
| 结算 | 面板消失，日志作废 | 日志留在她脑子里，她此后一辈子按秒计自己的犹豫 |
| 文体纯度 | 整节由日志行构成 | 日志与她的现场交替，一行日志一段人话 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她拿机器的口径去量自己，量出一个她没准备好承认的答案 | 他不知道有系统，他只知道那晚她在门外站了一会儿才进来 |
| 内心 | 数字不会安慰人，也不会撒谎，她因此信它多过信自己 | 他的部分在日志里是空白，这空白就是他的位置 |
| 好的处理 | 她不跟系统辩论，她改自己的动作，让下一条数据好看 | 他后来提过一句「那天你在门口站了挺久」，她当场愣住 |
| 写崩 | 写成她和系统对骂争主权 | 写成他能看见面板 |

#### 写崩的三种方式

1. 系统开口讲道理。 机器一旦解释、劝导、共情，它就成了配角，冷口径那点劲儿立刻就没了。
2. 日志堆成数据墙。 三十行日志读者跳过二十九行。一屏之内只留能被读出情绪的那三行。
3. 用日志代替戏。 日志是量出来的影子，影子之外必须有一个真实的夜晚，否则读者只看见参数。

## 五 · 判决书

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：分手 8.4% ＋ 婚仪 38.8% 的交集（语料罕见）

**骨架**｜判决书四千三百字，写清了七年里每一笔钱的去向，写清了房子归谁、车归谁、猫归谁，没有一个字写他们为什么开始。她在律所走廊读完，用了二十分钟。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 当事人信息栏（职业、住址：两个地址已经不一样了） |
| 2 | 「经审理查明」段（法院复述这段关系，只留可举证的部分） |
| 3 | 财产分割（房、车、共同还贷期数、一只猫） |
| 4 | 「本院认为」（法律语言对感情下的唯一判断，一共六个字） |
| 5 | 判项一二三（用「限……日内」这种时限语，把余生切成期限） |
| 6 | 落款、日期、骑缝章 |
| 7 | 谁在读（她读、他读、或者很多年后另一个人读） |

#### 时间轴

婚姻七年，庭审两次共一百分钟，判决书四千三百字，读完二十分钟。**法律的时间单位是「日内」**：十五日内上诉，三十日内腾房，六十日内履行。感情没有期限，判决书给它安了一堆期限，这就是这条最刺人的落差。

#### 查明的与查不明的

| 栏位 | 文书查明了 | 它查不明 |
|---|---|---|
| 婚姻状况 | 某年某月某日登记结婚 | 登记那天下雨，谁打的伞 |
| 共同财产 | 房产一套，共同还贷 79 期 | 79 期里有 11 期是他一个人还的，他没让她知道 |
| 感情状况 | 「感情确已破裂」 | 破裂发生在哪一天，两人各有各的答案，且都不是那一天 |
| 家务贡献 | 无此项，或折算成一个数字 | 七年的早饭 |
| 宠物归属 | 判归原告 | 猫认的是他 |
| 子女抚养 | 随母生活，父方每月给付 | 判决当天孩子在门外的走廊上站着 |

判决书写的全是真的，合起来却不是那件事。这条戏的全部张力在这句落差上，不在庭审现场。

#### 可用细节

| 类 | 内容 |
|---|---|
| 物 | 骑缝章盖歪了 · 纸有静电，翻页粘手 · 装在牛皮纸信封里，信封上是打印的姓名 |
| 法律腔 | 「经本院合法传唤」 · 「无正当理由拒不到庭」 · 「本判决为终审判决」 · 判项之间用一二三分条，句尾一律句号 |
| 她的读法 | 先翻到最后一页看判项 · 再回头逐段读查明段 · 在「共同还贷 79 期」那行停住 |
| 他的读法 | 只看孩子那一条 · 其余部分他没读完，收进了抽屉 |
| 事后 | 一份留档，一份复印去办过户 · 三年后办别的事又要用到它，从抽屉里翻出来，纸已经发脆 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁是原告 | 她起诉（女尊设定里这是常态，现代设定里这一栏本身有信息） | 他起诉（这一栏一出现，读者立刻知道这七年发生过什么） |
| 文书成色 | 全篇冷 | 有一处不冷：审理查明段里保留了一句当事人陈述的原话 |
| 争议焦点 | 财产 | 抚养权（走 [13-家庭与亲属](13-家庭与亲属.md)） |
| 读的人 | 她 | 很多年后孩子调档，第一次读到父母的这段 |
| 文体纯度 | 整节只有判决书正文 | 判决书与她的走廊二十分钟交替 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「共同还贷 79 期」这一行：她算了一遍，多出来 11 期 | 判项第三条的时限：他有三十日搬走，他第一天就搬了 |
| 内心 | 她被判赢了，走廊上没有一点赢的感觉 | 他要的那一条没写进去，因为那一条不可举证 |
| 好的处理 | 她把复印件收好，猫的那一条她自己反悔了 | 他不上诉，他在最后一天才搬，多住的那些天没告诉任何人 |
| 写崩 | 写成她在法庭上慷慨陈词 | 写成他签字时泪洒当场 |

#### 写崩的三种方式

1. 法律腔第三段破功。 前两段守得住格式，第三段冒出「他心里一沉」，文书立刻降级成小说旁白。
2. 把庭审写全。 庭审有对手戏，判决书没有，两者选一种。写了庭审，判决书就只剩注脚。
3. 文书造假。 判项写得不合规、术语用错，懂行的读者第一眼出戏，这类文体的门槛就在此。

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她打完删、删完打的那三次「正在输入」 | 他连发四条，第五条打了一半，改成一个句号 |
| 内心 | 她的克制体现在字数上：越在意，回得越短 | 他的紧张体现在标点上：句号变成了三个字的短句 |
| 好的处理 | 她的最后一条不带问号，把选择权交出去 | 他隔了六小时才回，回的那条只有两个字，且是对的那两个 |
| 写崩 | 写成她句句机锋的辩论赛 | 写成他刷屏卖惨 |

#### 写崩的三种方式

1. 加旁白。 一行「她盯着屏幕，心里一紧」就把这条废掉了：形式的全部力气来自没有叙述层。
2. 撤回内容给出来。 撤回是留白装置，填上它就只剩一条普通消息，还多了一次多余的解释。
3. 气泡写成剧本。 完整长句、零错字、不分条发、没有表情包，那是话剧台词，不是聊天。

## 七 · 清单体

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：做饭 48.4% ＋ 投喂 25.3%

**骨架**｜她备忘录里有一份从不删的清单，标题只有一个字：买。一年之后往回翻，清单上的东西换过三轮，每一轮都对着他身上的一件事。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 起点（最普通的一条：牛奶、垃圾袋，谁都会写的那种） |
| 2 | 第一次品类漂移（低钠盐出现在他体检之后） |
| 3 | 待办清单的另一条线（周三取药、换滤芯、给他妈打电话） |
| 4 | 一条被划掉又写回来的 |
| 5 | 一条永远没划掉的 |
| 6 | 他看见了这份清单（她递手机让他看别的，屏幕停在这一页） |
| 7 | 他建了自己的一份，第一条抄的是她的第三条 |

#### 时间轴

单条清单三十秒写完，整份清单读的是一年。**清单的时间靠版本堆出来**：同一个标题下的内容全换过了，标题没动。翻到最早那一版，上面还写着他不吃的东西，那时她还不知道。

#### 条目的五种密度

| 类型 | 例 | 读出的 |
|---|---|---|
| 通用条目 | 抽纸、垃圾袋、灯泡 | 无信息，做背景，密度不够读者不信 |
| 定制条目 | 无糖的那款、他能咽得下去的那个牌子 | 一次试错的结果，试错过程不写 |
| 时限条目 | 周四之前、下次别忘 | 责任分配，谁写谁认领 |
| 划掉又写回 | 一盒烟 | 戒过三次，划掉三次，写回三次 |
| 永不划掉 | 一件他两年前随口说过想要的东西 | 攒着，等一个日子（接 [07-馈赠与仪式 · 藏了很久的礼物](07-馈赠与仪式.md#一--藏了很久的礼物)） |

清单体的语法是残句：没有主语，没有因果，全是名词加数量。**因果被格式挡在外面，读者只能自己接**，这是它比叙述更狠的地方。

#### 可用细节

| 类 | 内容 |
|---|---|
| 物 | 冰箱贴条 · 手机备忘录 · 购物 app 的常买列表 · 超市小票背面 |
| 格式痕迹 | 前三条打了勾，第四条没有 · 中间插了一条与购物无关的 · 一条只写了两个字，她后来自己也没看懂 |
| 版本 | 同一份清单被复制成「买 2」「买 3」 · 云端历史版本可回看 · 纸质清单她按月夹在一个铁夹子里 |
| 他那一份 | 更长、更碎、带时间 · 有一条写着「问她今天累不累」，排在买菜后面 |
| 被看见的方式 | 她递手机时忘了退出 · 他借手机扫码 · 清单同步到了共用平板 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 清单在谁手里 | 她的（照顾方向的默认位） | 他的（他的清单更细，且有一整栏是关于她的作息） |
| 清单的性质 | 购物 | 说明书：他病了那阵她写的《怎么照顾他》，一共十七条，条条像操作规程 |
| 被看见 | 他看见了，什么也没说 | 他看见了，第二天照着买回来一半，另一半故意留给她 |
| 收尾 | 清单还在用 | 清单停更在某一天，后面全是空白 |
| 文体纯度 | 整节由三份清单构成，跨度一年 | 清单只在一处出现，长度七行 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 品类漂移：她自己是翻旧版本时才发现的 | 那条「问她今天累不累」排在第三位，前两条是米和油 |
| 内心 | 照顾在她这里是可执行项，写不出的部分她不写 | 他抄她的清单，抄的时候把「他」改成「她」 |
| 好的处理 | 永不划掉的那条她不解释，留着 | 他不问那条为什么一直在，他自己也有一条一直在 |
| 写崩 | 写成她事无巨细的完美主妇秀 | 写成他照单执行的机器人 |

#### 写崩的三种方式

1. 清单写成完整句。 一旦出现主语和因果，它就退回叙述，说明书式的钝感全丢。
2. 条目全是定制条。 定制条要靠通用条垫着才显眼，全是灯泡和纸巾里冒出来的那一条才有力气。
3. 当场解释清单。 谁一开口讲这份清单意味着什么，读者就不用读清单了。

## 八 · 日记被看见

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：隐瞒 4.7% ＋ 掉马 32.8%

**骨架**｜日记体加目击，两层。第一层是她写给自己的流水账，第二层是他坐在那儿读，且读者知道他在读。同一行字被读两遍，第二遍才有戏。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 日记的常态（写了几年，格式固定：日期、天气、三行） |
| 2 | 他撞见（本子摊在桌上，或云端笔记同步到了共用平板） |
| 3 | 第一层：他读到的字面（全是流水账，没有一个字提到他的名字） |
| 4 | 第二层：他知道的上下文（那天他记得，她写的与他记得的对不上） |
| 5 | 一条空白日（那天她什么都没写，那天是他们吵架） |
| 6 | 他合上本子（放回原位，角度差了两度） |
| 7 | 她发现有人读过（或者永远没发现） |
| 8 | 下一篇日记的文体变了 |

第 8 拍是这条的心脏：日记一旦有了第二个读者，它就不再是日记，它变成了一封不承认自己是信的信（接 [一 · 写给你](#一--写给你)）。

#### 时间轴

日记跨三年，他读了四十分钟。**双层结构的钟是错开的**：她一天写三行，他一小时读三年，压缩比造成的失真是这条的全部内容。他读到的她比真实的她更连贯、更冷静，因为流水账天然删掉了摇摆。

#### 同一行的两层读法

| 她写的（给自己看） | 他读出的 |
|---|---|
| 今天下雨。加班到十点。 | 十点，他那天在楼下等了四十分钟，她一个字没提 |
| 他今天很乖。 | 那天他摔了杯子，这也算乖，那她的尺子松到什么程度 |
| 领了钱。买了鱼。 | 发薪日她买了他爱吃的那种鱼，日记里不写为谁买 |
| （空白） | 吵架那天 |
| 阴。 | 只有一个字的日子，一年里有十一天，他数了 |

空白日与一字日是这条最好用的两格：**日记的信息量在它不写的地方**，而只有第二个读者才知道那天发生过什么。

#### 可用细节

| 类 | 内容 |
|---|---|
| 物 | 本子的橡皮筋 · 中间撕掉的一页，撕口留在装订处 · 夹着的干花 · 后半本全是空的 |
| 格式 | 日期用数字，天气用一个字 · 每篇不超过三行，是她给自己定的规矩 · 从不换行分段 |
| 他的动作 | 只翻，不动笔 · 想拍照又放下 · 合上时对了一下书脊与桌沿的角度 · 出门前又回头看了一眼 |
| 破绽 | 他放回去时角度差了两度 · 橡皮筋换了个方向 · 那晚他反常地不问她今天怎么样 |
| 她发现的方式 | 她注意到角度 · 她翻到某页发现被压出了折痕 · 她什么也没说，下一篇日记开始写得更完整 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 日记归谁 | 她的（他读到她的口径，包括她怎么称呼他） | 他的（她读到自己在他笔下的样子，通常更好看，好看到她不敢认） |
| 目击方式 | 无意撞见 | 她故意留在桌上（那就不是日记了，走 [一 · 写给你](#一--写给你)） |
| 读者知情度 | 读者与他同步（跟着读，跟着补） | 读者早知道空白日发生了什么，看着他一格格猜，痛感翻倍 |
| 事后 | 谁也不提，日记照写 | 她换了本子，新本子里没有一个字提到那件事 |
| 文体纯度 | 整节由日记条目与他的旁观交替 | 只贴三条日记，其余走常规叙述 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她给自己写字时的口径：省略、克制、从不写委屈 | 他读到自己被写成两个字「很乖」时的那一下 |
| 内心 | 日记是她唯一不用当主导的地方 | 他在三年里只被写到过十七次，他数完了 |
| 好的处理 | 她发现了不追问，她把下一篇写长了两行 | 他不揭穿，他把那十一个一字日的日期记在自己手机里 |
| 写崩 | 写成她日记里满是深情告白 | 写成他读完当场质问 |

#### 写崩的三种方式

1. 日记写成抒情散文。 真日记是流水账，越平淡第二层越响。写满心事的日记不需要第二个读者。
2. 只有一层。 光贴日记不给目击者，那是内心独白换了排版，双层结构垮掉。
3. 当场对质。 「原来你是这么想的」一出口，装不知道的那几个月全被挤掉了，戏就没了。

前接：[15-秘密与坦白 · 她的秘密](15-秘密与坦白.md#五--她的秘密)
后接：[15-秘密与坦白 · 掉马](15-秘密与坦白.md#二--掉马) · [一 · 写给你](#一--写给你)

## 九 · 讣告与悼词

`T` ｜ ⚠️BE·死亡向 ｜ 全谱系 ｜ 语料频次：离世 29.4%

**骨架**｜讣告三百字，格式是现成的，填空即可。悼词她写了七版，最后念出来的那版里少了一段，因为那一段一开口就要先解释他们是什么关系。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 讣告起草（姓名、生卒、享年、治丧安排，模板不用想） |
| 2 | 家属署名那一行（她排在哪个位置，或者不在上面） |
| 3 | 悼词第一版（三千字，写了一整夜） |
| 4 | 逐版削（七版，越删越短，删的都是同一类东西） |
| 5 | 最后一版定稿（八百字，能被所有人签收） |
| 6 | 现场念（谁念，念到哪一句停住，停多久） |
| 7 | 没念的那一版（她揣在口袋里，散场时还在） |
| 8 | 后来（一年后她怎么处理那份底稿） |

#### 时间轴

一生压进三百字，用了她三个晚上。**悼词的时间是倒着走的**：从最长写到最短，从全部真话写到能公开的真话。第七版与第一版之间差掉的两千二百字，就是这段关系不被承认的那一部分。

#### 三种文本，三种能说的量

| 文本 | 读者 | 能说什么 | 不能说什么 |
|---|---|---|---|
| 讣告 | 所有人 | 生卒年、职务、治丧安排、家属称谓 | 一切具体的人 |
| 悼词（念出来的） | 到场的人 | 他的好，用在场每个人都能签收的说法 | 他们怎么开始的 |
| 底稿（没念的） | 一个人 | 谁听谁的、他最后一句话、她欠他的那件事 | 无 |

#### 署名那一行

| 关系 | 署名位置 | 代价 |
|---|---|---|
| 有法律关系 | 配偶栏，第一位 | 无 |
| 无法律关系但公开 | 「生前友好」，姓名排在末行 | 一生的位置被压进四个字 |
| 未公开 | 不署名，以同事身份到场 | 她要在门口向每一个人解释自己是谁，解释一次少一分 |
| 制度否认（女尊设定的反向世界） | 不得署名，家中另有正式排位 | 走 [38-制度里的两个人](38-制度里的两个人.md) |

#### 可用细节

| 类 | 内容 |
|---|---|
| 物 | 打印店的模板文件 · 黑边的纸 · 折了四折的底稿 · 讣告上的手机号是她的 |
| 格式的硬 | 享年要按虚岁还是周岁 · 「因病医治无效」是通用句，具体病名不写 · 时间精确到分，来源是病历（接 [二 · 病历上的他](#二--病历上的他)） |
| 现场 | 念到第三段她停了七秒 · 有人以为她忘词，替她翻页 · 最后一句她念快了，快到没人听清 |
| 底稿留下的痕迹 | 折痕、口袋里的手汗、一处被划掉又用括号补回来的 |
| 一年后 | 她没烧，她把它夹进了那本一直没读完的书 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先走 | 他先走（她写悼词，走 [42-岁月与身后 · 他先走了](42-岁月与身后.md#九--他先走了)） | 她先走（他写，且他多半没有署名权，走 [42-岁月与身后 · 她先走了](42-岁月与身后.md#八--她先走了)） |
| 关系公开度 | 全部公开，她主持治丧 | 完全未公开，她的位置在最后一排 |
| 底稿的去向 | 烧了 | 留着，且在很多年后被另一个人读到 |
| 现场变数 | 她念完了 | 她念不下去，换人念，那人念的是删节版的删节版 |
| 文体纯度 | 讣告全文加悼词全文 | 只给讣告与底稿的落差，现场不写 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 第七版删掉的那两千二百字：她记得每一句删在哪 | 署名那一行，他连争的资格都没有，只能在门口站着 |
| 内心 | 公开的语言里没有一个词能装下他，她只好用最普通的那几个 | 他要用「朋友」两个字送她走，这两个字是他自己当年同意的 |
| 好的处理 | 她照稿念完，底稿一个字不改地揣回去 | 他不闹、不认亲，他做的是散场后留下来收椅子 |
| 写崩 | 写成她灵堂宣告关系 | 写成他被赶出场的苦情戏 |

#### 写崩的三种方式

1. 悼词全文照登。 力气在删掉的那两千多字，七版都写出来，读者就无从想象第八版。
2. 灵堂摊牌。 追悼会不是公开场，一句宣告会把这场戏从悼念变成事件，重心当场偏掉。
3. 讣告写得情深。 讣告是格式文，情绪写进去就失格。痛感来自格式与人之间那道缝。

## 十 · 她写他

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：掉马 32.8%

**骨架**｜她给他写了三年。第 187 章要写他哭，她坐在客厅里看着真人洗碗，忽然分不清自己等的是那一章，还是那个人。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 取材（他的一个动作进了大纲的备注栏，她当时没多想） |
| 2 | 命名（她给纸上那个人取名，那个名字和他差一个字） |
| 3 | 加工（现实的他不敢，纸上的他敢：她替他补了勇气） |
| 4 | 预演（她把还没发生的事先写出来，然后在现实里等它发生） |
| 5 | 反噬（她开始按纸上那个版本要求真人） |
| 6 | 察觉（她发现自己很久没在看他，只在校对他） |
| 7 | 处理（把他从主角降为配角、完结、或者写一章他完全不在的部分） |

第 4 拍是这条的关节：**写在前，活在后。** 写过的场景在现实里发生时，她的第一反应是核对，不是惊喜。这一秒她知道自己出了问题。

#### 时间轴

写三年，二百章，日更两千字。**她的一天有两个他**：白天那个会洗碗、会烦、会说随便；深夜那个说她想让他说的话，且从不累。深夜的版本每天准时到岗，白天的版本要她自己去哄。

#### 三个他

| 版本 | 谁能改 | 谁在爱他 | 她的心力去向 |
|---|---|---|---|
| 现实的他 | 谁都改不了 | 她，在她还有力气的时候 | 剩下的那点 |
| 大纲里的他 | 她一句话改一次 | 她，随时，且不费劲 | 大部分 |
| 已发表的他 | 改不了了，读者记着 | 三千个人 | 维护成本 |

三个版本互相拆台：她越写第二个，第一个越显得不体贴；读者越爱第三个，她越不敢改设定。这条戏的病灶在第二栏那句「不费劲」上。

#### 可用细节

| 类 | 内容 |
|---|---|
| 工序 | 大纲的备注栏 · 素材文档里贴着他的原话，标着日期 · 人物小传里有一栏叫「不能碰的」 |
| 命名 | 差一个字的名 · 生日改了一天 · 那道疤挪到了另一边，是她唯一做的伪装 |
| 预演的物证 | 第 92 章写过的那顿饭，四个月后真的发生 · 她当场愣了三秒，被他问怎么了 |
| 反噬的形态 | 她说「你上次不是这样的」，而上次是纸上的 · 她对真人的容错率在下降 |
| 察觉的那一刻 | 他洗碗时哼了一句跑调的歌，她第一反应是这个细节可以用 |
| 处理 | 她写了一章他完全不在的，写完发现自己写得很吃力 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他知不知道 | 不知道（他这一侧的戏走 [44-圈层与同好 · 她是太太](44-圈层与同好.md#二--她是太太)） | 知道，且在追更，两人各装各的 |
| 加工方向 | 写高（更帅更敢） | 写低（她把他写得更可怜，写完自己不舒服了很久） |
| 反噬程度 | 只是偶尔恍惚 | 她开始用纸上的进度表要求现实进度 |
| 收法 | 完结，把他还给他自己 | 不完结，改成她自己当主角，他退到配角位（这一改读者立刻察觉） |
| 文体纯度 | 大纲、素材文档、正文片段三层文本交替 | 只在一处贴出一页大纲，其余常规叙述 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 备注栏里那句她自己都忘了记过的原话，标着两年前的日期 | 他被写成一个更敢的人，而他这辈子没敢过 |
| 内心 | 她怕的是自己更爱那个改得动的版本 | 他若知道，第一个反应是想去当那个纸上的人 |
| 好的处理 | 她把「不能碰的」那一栏一条条搬回现实去问他 | 他若知道也不揭穿，他挑一件纸上的事，在现实里做一遍 |
| 写崩 | 写成她创作至上牺牲一切 | 写成他拿这件事拿捏她 |

#### 写崩的三种方式

1. 写成创作论。 一谈虚构与真实的关系，两个人就从场景里消失了，剩下作者在讲课。
2. 纸上的内容写太细。 引用超过三行，读者就去读那本书了。给证据，不给全文。
3. 一觉醒来分清了。 恍惚是慢性的，靠一个顿悟收场等于承认前面二百章没发生过。
