# 文体与视角实验

> **分级** 分级见各条，分级上限 `T` ｜ 预警 ⚠️BE（限第九条）｜ 亚型 全谱系通用（文体层）
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）

## 这一族收的是场景

每件东西都得有来处、有人碰过、有时间点。信是他写的那晚，病历是她在收费窗口翻到的那次，判决书是她在律所走廊读的那二十分钟。十条都是从一件看得见摸得着的东西起手：一封信、一叠病历、一页谱、一行日志、一份判决、一屏聊天、一张清单、一本日记、一篇悼词、一份大纲。每样东西都得有人、有时间、有前因后果。写法学在 07 卷，具体那一场戏在这里。

材料的分层：

|---|---|---|
| 第二人称的十三条规则、四篇实测 | [07-语言风格/02-第二人称写作专论](../07-语言风格/02-第二人称写作专论.md) | 一个人熬夜把规则全用出来那一场 |
| 施动语法、名字的驱逐与发放 | [07-语言风格/01-女攻叙事语感](../07-语言风格/01-女攻叙事语感.md) | 语法规矩落进一封信、一份文书里的样子 |
| 聊天的内容与人在聊天时的心情 | [19-玩闹与网络 · 聊天记录](19-玩闹与网络.md#二--聊天记录) | 不写叙述层，光靠聊天界面把事讲完 |
| 文书类文本，如判决、病历、谱牒、日志 | 全库此前无场景条目 | 从零开始搭 |

两条通用纪律：

| 纪律 | 做法 |
|---|---|
| 文体只是取景框 | 换文体图的是它替你挡掉哪些话。挡掉的得是这场戏最想说的那句，戏才立得住 |
| 冷文书不许自己动情 | 病历、判决、日志一旦开始煽情，就变回旁白了。情绪让读者自己在行与行之间补 |

十种文体的三项参数，开写前先定死：

| 条 | 文体 | 叙述者是谁 | 结构性沉默，它说不出的那类东西 |
|---|---|---|---|
| 一 | 书信（第二人称） | 写信的人，对着一个不在场的收信人 | 收信人心里到底怎么想 |
| 二 | 病历与护理单 | 没人格的医院记录 | 关系、动机、疼到什么程度 |
| 三 | 谱牒正文＋批注 | 修谱人（正文）与批注者（小字） | 感情，除非借批注偷偷塞进去 |
| 四 | 系统日志 | 一台只记数字的机器 | 「为什么」这栏压根不存在 |
| 五 | 判决书 | 合议庭，只认拿得出证据的事 | 起因、私下的账、当天什么天气 |
| 六 | 聊天记录 | 无（界面本身） | 表情包盖住的所有表情 |
| 七 | 清单 | 写清单的人，写给三天后的自己 | 完整句子，所以也说不清因果 |
| 八 | 日记＋目击 | 写的人一层，读的人一层 | 写日记者死活不肯写的那一半 |
| 九 | 讣告与悼词 | 家属署名，集体口径 | 关系到底咋样、他最后说了句啥 |
| 十 | 作者的大纲与稿 | 她，正把一个活人写成人物 | 那个活人自己嘴里的版本 |

这一族的三种通病，十条各自还有各自的：

| 通病 | 症状 | 判据 |
|---|---|---|
| 文体噱头盖过戏 | 形式花样每页一个，人物两千字没动过 | 把文体换回常规叙述，戏若照样成立，形式就只是包装 |
| 第三段破功 | 前两段文书腔守得住，第三段忍不住滑回小说腔，出现「他心里一酸」 | 通读时只找形容心理的词，文书里出现一个就是破口 |
| 通篇不换气 | 第二人称从头「你」到尾，密度不变，读者被摁住 | 数任意一页里「你」字的行占比，全篇曲线是平的就是没换气 |

## 一 · 写给你

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：坦白 6.5% ＋ 夜深 37.5%（第二人称未进入人称统计口径）

**骨架**｜她写了封信，没打算寄。开头写了个「你」，写到第三段发现每句都有这字，读着跟审犯人似的，就一个一个删了。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 起意：事很小，他在电话里说没事，她听出来有事，当面问不出口 |
| 2 | 抬头：写「你」还是写名字，名字一落笔，信就变成了公文 |
| 3 | 第一段写事实，安全，也没用 |
| 4 | 中段失控，「你」字每句都出现，写的人自己先觉得刺耳 |
| 5 | 删掉一半「你」之后，句子反而离得更近 |
| 6 | 写到不能寄的那一句，写出来才知道为什么不能寄 |
| 7 | 装信封、写地址、不贴邮票 |
| 8 | 存放书里、抽屉夹层、云端草稿箱：三个地方三种打算 |

#### 时间轴

写两小时，删到天亮，存了六年。**信的时间线分三段**：写的那一夜，每年翻出来看一次的那几分钟，决定处理掉的那一天。第三段最短，多半只有一个动作：不烧，原样放回去。

#### 「你」字密度怎么控制

| 密度 | 读起来 | 放在哪一段 |
|---|---|---|
| 每句都有 | 盯着你看，像在追问 | 只留给最后三行 |
| 三句一次 | 像在旁边搭话 | 主体段落 |
| 整段不出现 | 像写信的人在跟自己念叨 | 事实段与回忆段 |
| 只出现在一句里 | 那一句被顶到整封信上面 | 收尾 |

换气的做法是让密度变成一条曲线：事实段几乎不喘气，中段回到三句一停，末尾三行连着砸下来。全篇一直高密度会把读者摁在椅子上喘不过气，专论第十条的短行要求也是这个道理。相关讨论见[07-语言风格/02 · 九](../07-语言风格/02-第二人称写作专论.md)。

#### 可用细节

| 类 | 内容 |
|---|---|
| 物 | 从别处撕下来的纸 · 中途换过一支笔 · 写坏三张的抬头 · 没贴的邮票 |
| 语气破口 | 一句写到一半改成疑问句 · 中间插进一件毫不相干的小事（今天楼下修路） · 一处涂黑，看不出原字 |
| 不能寄的那句 | 通常是一个请求，且是她这辈子没对任何人提过的那一类 |
| 存放处的含义 | 夹在他送的书里＝还打算给他看 · 抽屉夹层＝给自己留证据 · 云端草稿＝会被同步到共用平板（接第八条） |
| 收信人不知道的证据 | 信封上写了地址，门牌号错了一位 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁是「你」 | 他是「你」：一封写给他的信 | 她是「你」：整篇小说的读者代入位，四种规定度配置见 [07-语言风格/02 · 一](../07-语言风格/02-第二人称写作专论.md) |
| 信的去处 | 永不寄出 | 寄了，寄到一个已经搬空的地址，一个月后原样退回 |
| 被读到 | 他这辈子没读到 | 他读到了，且在她不知道的时候（接 [八 · 日记被看见](#八--日记被看见)） |
| 时态取向 | 同步型：今晚，此刻，笔在手上 | 追忆型（那年冬天），两种混在一篇里，读者就找不到自己站在哪 |
| 文体纯度 | 整章只有信，零叙述层 | 信做插入件，前后有常规叙述包着（长篇里更稳） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 删「你」的那道工序：删一个字近一分 | 他写信时的抬头困难：叫她什么都不对，敬称太远，昵称写不出手 |
| 内心 | 写的时候她在替他说话，写完发现替错了 | 他信里的施动位是空的，全篇没有一个他做主语的动词 |
| 好的处理 | 不能寄的那句照写，然后把信收起来 | 他写完不寄，第二天照常做饭，那句话换成一个动作交出去 |
| 写崩 | 写成情书朗诵 | 写成卑微陈情表 |

#### 写崩的三种方式

1. 收信人比叙述者自己更被看透。信里写「你其实早就……」，收信人随时能反驳，这封信当场就废了。
2. 信里全是总结陈词。真信一半在讲无关的琐事：修路、账单、猫。整封信都在摆要点，读起来像遗书，不像信。
3. 通篇不换气的写法，把「你」压在每个句子里，读者被摁住两千字，亲近变成压迫。密度得留出喘息的空当。

#### 可串接

前接：[15-秘密与坦白 · 说不出口的那件](15-秘密与坦白.md#十--说不出口的那件) · [04-委屈与破防 · 憋着不说](04-委屈与破防.md#二--憋着不说)
后接：[八 · 日记被看见](#八--日记被看见) · [十 · 她写他](#十--她写他)
对照：[29-微小仪式拾遗 · 电话里的声音](29-微小仪式拾遗.md#十--电话里的声音)，同一句话用声音交出去的版本

#### 示例（本库自撰，可直接改写）

> 那晚她写的第三段是这样的：楼下从上周三开始修路，早上六点就砸。你走之后我才发现自己一直没换过闹钟。豆浆机的滤网卡了，我拆了半小时，你以前是怎么拆的。
> 前两句里没有「你」，第三句一个，第四句一个。她数了数，把第四句划掉了。
> 最后三行她一个也没删。三行里「你」出现了五次，她读了一遍，把纸对折，塞进他上个月留在书架上的那本书。

## 二 · 病历上的他

`T` ｜ 无预警 ｜ 现代都市（古代脉案、修仙丹方同构） ｜ 语料频次：生病 49.4% ＋ 上药 45.2%

**骨架**｜出院那天她去结账，柜台把病历本推回来让她自己核对。入院记录一页，护理单二十三页，里面没一个字提她，全是她按铃按出来的。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 起点，办手续的间隙，本子摊在窗口的不锈钢台面上 |
| 2 | 第一页：主诉、现病史、既往史，用第三人称把他这一辈子压成六行 |
| 3 | 「陪护人」那一栏，关系填的是什么，是谁填的 |
| 4 | 护理单的时间列（02:15 换药 · 03:40 体温 38.2 · 05:10 患者入睡） |
| 5 | 她在时间列里认出自己，那些时间点全是她按铃的时间 |
| 6 | 一处笔误或一句手写，护士在页脚补的一行，格式外唯一一句人话 |
| 7 | 出院小结的「转归」栏 |
| 8 | 她把本子收进抽屉，和其他不会再打开的证件放一起 |

#### 时间轴

住院九天，病历二十四页，她读完用二十分钟。**病历上的日子过得比人快**：一页顶一天，翻页就是过日子。那九天里她按了四十次铃，纸上只剩四十个时间点。落差在这，戏也在这。

#### 栏位与它底下的那件事

| 栏位 | 文书怎么写 | 底下是什么 |
|---|---|---|
| 主诉 | 「反复腹痛三月余」 | 他忍了三个月没说 |
| 既往史 | 「否认外伤史」 | 连旧伤都瞒了，瞒的还是医生（接 [41-他的身体与年岁 · 旧伤](41-他的身体与年岁.md#一--旧伤)） |
| 陪护人 | 「朋友」 | 关系还没到能填那一栏的地步 |
| 护理记录 02:15 | 「换药，患者配合」 | 他咬着毛巾没吭声 |
| 护理记录 05:10 | 「患者入睡」 | 她没睡，她在等这行字出现 |
| 转归 | 「好转」 | 出院不等于好了，只是不用再占床 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 物 | 塑封的封面 · 手写和打印混着来的页 · 腕带剪断了扔床头柜上 · 缴费单叠成小方块塞夹层里 |
| 格式的硬度 | 每栏都限字数 · 关系栏是下拉菜单，没她想要那项 · 签字栏一天签三回，名字越签越潦草 |
| 唯一不冷的地方 | 页脚有行手写：夜里家属没走 · 某页字迹换了人，那天值班护士换了 |
| 他这一侧 | 他压根没翻过这本 · 他记得的是天花板上那块水渍，纸上没这一栏 |
| 事后 | 她按日子把二十四页重新排了一遍 · 复印件自己留了份，正本交回医院 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁在翻 | 她翻，她没露面的那几年全露出来了 | 他多年后翻自己的旧病历，才看见当年是谁签的字 |
| 关系栏 | 填「朋友」，一直填到出院 | 填「配偶」被拦下，要证件（接 [23-婚嫁 · 领证那天](23-婚嫁.md#三--领证那天)） |
| 文书成色 | 从头冷到尾 | 只有一处不冷，而且那处是外人写的 |
| 病的成色 | 小病，戏全在关系栏 | 大病，戏在转归栏（走 [41-他的身体与年岁](41-他的身体与年岁.md)） |
| 文体纯度 | 整节只有文书，不给现场 | 文书和现场来回切，一页纸一段回忆 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 关系栏那格停住：光标悬在下拉选项上 | 时间列里的 02:15：他记得那一下有多疼，纸上写的是「配合」 |
| 内心 | 她在纸上找自己，找了二十分钟，一个字也没写出来 | 他不知道她按过四十次铃，他以为护士是自己来的 |
| 好的处理 | 她不解释也不改，把本子收好，出门给他买粥 | 他后来去调了一次病历，就为看陪护人那栏她填的啥 |
| 写崩 | 写成她在医院哭给读者看 | 写成他在病床上大段独白 |

#### 写崩的三种方式

1. 文书自己动情。病历一抒情，就成了旁白，冷文书的劲儿全在它憋着不说。
2. 只贴文书不给现场。文书是证物，得有人在某个具体时候翻开它，不然就是摆道具。
3. 医学细节考据过头。术语堆到第三行，读者就跑了。三个栏位顶三十个术语。

#### 可串接

前接：[01-日常照料 · 半夜发烧](01-日常照料.md#三--半夜发烧) · [41-他的身体与年岁 · 他不肯去医院](41-他的身体与年岁.md#四--他不肯去医院)
后接：[41-他的身体与年岁 · 他的体检报告](41-他的身体与年岁.md#三--他的体检报告) · [九 · 讣告与悼词](#九--讣告与悼词)
对照：[30-她的世界 · 她的体检报告](30-她的世界.md#十--她的体检报告)。同一种文书，方向反过来。

#### 示例（本库自撰，可直接改写）

> 护理记录第十七页，02:15，换药，患者配合。
> 那一栏她看了很久。02:15 是她按铃的时间。铃按下去到护士进门，隔了六分钟。那六分钟他一直在数天花板上的格子，数到第四十格，人才进来。这些纸上都没有。
> 页脚有一行手写的字，斜着，笔画很轻：夜间家属未离开。
> 全本二十四页，提到她的只有这七个字。写的人还不认识她。

## 三 · 族谱那一页

`T` ｜ 无预警 ｜ 古代女尊（现代户口本、家谱软件同构） ｜ 语料频次：请安 26.6%（谱牒段无独立族）

**骨架**｜她在那页右下角留了行批注，正文只有十一个字，格式照旧。三代后重修族谱的人，连批注带正文一并抄了进去，压根没想过那行字出自谁手。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 开谱：纸、墨、留一行空，动笔前得先请人研墨 |
| 2 | 正文格式，某氏第几女，某年某月纳某氏子，十一个字，一个也不能多 |
| 3 | 批注权争来争去，正文归修谱的，批注归谁：族长、书吏、还是她 |
| 4 | 她不是要改格式，是要那行小字待的地方 |
| 5 | 落笔写了什么，划了什么，划掉的那句她记了一辈子 |
| 6 | 他看见那行字他这辈子看了多少回，自己都数不清 |
| 7 | 重修，三代后抄谱的人连小字一起抄，小字就成了正文 |

#### 时间轴

批注这东西，隔代才见效。小字管的是后人怎么想这个人，得等他死了，才开始起作用。正文管的是名分，写上去就定了。上谱一炷香，那行小字十四个字，写完花了她一个下午。

#### 正文与批注：两套语言

| | 正文 | 批注 |
|---|---|---|
| 谁写 | 修谱人，照例 | 有资格的人，看规矩来 |
| 字数 | 固定，照着模板填 | 没准，一般一行以内 |
| 能说 | 姓什么、啥时候生啥时候死、排行老几、谁生的 | 会点啥、得过啥病、碰上一件小事、撂一句评语 |
| 不能说 | 感情 | 感情，但能借「一件小事」夹带私货 |
| 生效 | 当场 | 三代以后 |

写一句他说过的话，记一个只有她知道的日期，再添一件他做过的小事。批注偷感情，靠的就是这三招，格式上一点痕迹都不留，可一旦写上去，删都删不掉。

#### 可用细节

| 类 | 内容 |
|---|---|
| 物 | 谱牒的纸有年份 · 新添的一行墨色比周围深 · 装订线在这一页被拆过一次 · 印章压在骑缝上 |
| 格式细节 | 名字前的位序字 · 归入哪一房 · 无出者的空栏怎么处理 · 女方名字用讳还是用字 |
| 现代同构 | 户口本「与户主关系」栏 · 家谱软件的备注字段有 200 字上限 · 墓碑落款的排序 |
| 谁不入谱 | 未过明路的、无出的、被除名的：除名用刀刮，刮痕比字还显眼 |
| 他这一侧 | 他不识那几个字，是别人念给他听的 · 他记住的是纸的味道 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 批注谁写 | 她写，用的是她自己的权，也是她唯一能压在他身上的权 | 族里书吏代笔，她只能动嘴，一句话被改了三个字 |
| 内容 | 记功，他干过的一件事 | 记日期，一个只有他俩知道的日子，全族当生辰过 |
| 他知不知道 | 他在场，看着她写 | 他到死不知道那行小字 |
| 三代后 | 照抄，成了家训里的一句 | 被删，重修时觉得不合规矩，她的字只留在旧本上 |
| 文体纯度 | 整节全是谱牒条目加批注 | 谱牒就一页，前后都是正常叙述 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她在规矩里找空子：正文动不了，小字能钻 | 他听到自己名字那一下，头一回觉着自己有位置 |
| 内心 | 她要的是板上钉钉，感情说变就变，纸不会 | 上谱是踏实，也是打今儿起有了要护的东西 |
| 好的处理 | 写完不给他看，等他自个儿听人说 | 他后来学认字，头一个会写的是自己在谱上那个名 |
| 写崩 | 写成她砸祠堂改规矩 | 写成他感动得不行跪下来谢 |

#### 写崩的三种方式

1. 格式随便改。谱牒这东西，值钱就值在它几百年没变过样。你一改，它就跟路边贴的告示没区别了，那行小字也跟着废了。
2. 批注写成情书。批注是留给后人看的，你写热了，当场就掉价。冷着写，才扎心。
3. 上谱当作大团圆。名分定了，事儿没完。第二天该请安还是得请安，制度摆在那儿呢，[20-女尊制度场景](20-女尊制度场景.md)。

## 四 · 系统日志

`T` ｜ 无预警 ｜ 系统 · 穿书 ｜ 语料频次：系统 7.0%（26 卷口径）

**骨架**｜任务面板每天零点刷新。第214天的日志里多了一条没编号的记录：在门口站了11秒，没进去。没奖励，没惩罚，也没解释。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 日志平时就那样，时间加事件加参数，她早懒得看 |
| 2 | 突然冒出一条怪的，没编号，积分也没动 |
| 3 | 她去查，谁记的，系统到底能记到多细 |
| 4 | 系统只管记能算数的：时长、距离、心率、语速 |
| 5 | 她居然从数字里看出情绪，11 秒是她犹豫了那么久，她自己都没发觉 |
| 6 | 系统答不上来，面板上压根没有“为什么”这一栏 |
| 7 | 她开始拿日志当镜子，照自己，照了一个月 |
| 8 | 结算那天，日志要么封存，要么清空，要么归她 |

#### 时间轴

日志里，她洗手的那 11 秒，和她犹豫的那 11 秒，长得一模一样。**机器的钟表没有轻重之分**，任务周期按天算，日志按秒记。读日志的人自己心里怎么掂量，谁重谁轻，才有分别。这一掂量，日志就不再是记录工具，成镜子了。

#### 字段与它测不到的东西

| 字段 | 日志记了什么 | 它测不到 |
|---|---|---|
| duration | 门外停留 11 秒 | 她在等他先开口 |
| distance | 0.4 米 | 这是她第一次没先伸手 |
| heart_rate | 峰值 118 | 峰值出现在他说「随你」之后 |
| voice_len | 她 3 字，他 27 字 | 那三个字是她全天说得最艰难的 |
| task_status | 未触发 | 任务没触发，她临时改了主意 |
| — | 无此项 | 他站在门里也没动，日志不记录 NPC |

最后一行才是这招真正的机关：系统只给她装了传感器，没给他装。她自己的什么都能量到，唯独量不到他。于是她头一回开始猜了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 界面 | 面板半透明，只有她能看见 · 提示音在耳朵后头响 · 日志导出来就是纯文本，没排版 |
| 机器口吻 | 不用形容词 · 句子全是被动或没主语 · 数值精确到小数点后一位 · 判定结果就三种：达成、未达成、无效 |
| 异常的形态 | 编号缺了一个 · 时间戳比任务开始还早 · 同一秒记了两条 · 有一条记录的执行者写的是他 |
| 她的对策 | 把三个月的日志按小时重新排了一遍 · 把她心率过110的那些事全挑出来，发现没一件跟任务沾边 |
| 收束物 | 结算那天面板没了，她拿手把最后七行抄了一遍 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 日志是谁的 | 她的，他被系统当成NPC，没字段 | 双方都有，他也绑了系统，两份日志对同一晚记的不一样 |
| 系统的诚实度 | 只记事实，不解释 | 会漏记：凡跟她真心有关的条目全缺号，缺号本身就是线索 |
| 日志能否修改 | 只读 | 能删，删了留一条「已删除」的空记录，比原来那条还扎眼 |
| 结算 | 面板消失，日志作废 | 日志留她脑子里，她这辈子按秒算自己犹豫了多久 |
| 文体纯度 | 整节全是日志行 | 日志和她的现场穿插，一行日志一段人话 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她拿机器的尺子量自己，量出一个她没敢认的答案 | 他不知道有系统，他只知道那晚她在门外站了一会儿才进来 |
| 内心 | 数字不哄人也不骗人，她信它多过信自己 | 他的部分在日志里是空白，这空白就是他的位置 |
| 好的处理 | 她不跟系统吵，她改自己的动作，让下一条数据好看 | 他后来提过一句「那天你在门口站了挺久」，她当场愣住 |
| 写崩 | 写成她和系统对骂争谁说了算 | 写成他能看见面板 |

#### 写崩的三种方式

1. 系统开口讲道理。 机器一旦开始解释、劝人、共情，它就成了配角，冷口径那点劲儿立刻就没了。
2. 日志堆成数据墙。 三十行日志读者跳过二十九行。一屏之内只留能看出情绪的那三行。
3. 用日志代替戏。 日志是量出来的影子，影子之外必须有一个真实的夜晚，否则读者只看见参数。

## 五 · 判决书

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：分手 8.4% ＋ 婚仪 38.8% 的交集（语料罕见）

**骨架**｜判决书四千三百字，七年每一笔钱去哪了、房子车猫归谁，全写清楚了，就是没写他们为啥开始。她在律所走廊看了二十分钟。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 当事人信息栏：职业、住址，俩地址已经对不上了 |
| 2 | 「经审理查明」段，法院复述这段关系，只留拿得出证据的 |
| 3 | 财产分割：房、车、一起还贷还了多少期、一只猫 |
| 4 | 「本院认为」法律语言给这段感情下的定论，就六个字 |
| 5 | 判项一二三，用「限……日内」这种话，把剩下的日子切成一段段 |
| 6 | 落款、日期、骑缝章 |
| 7 | 谁在看：她看、他看、或者很多年后另一个人看 |

#### 时间轴

七年婚姻，两次庭审，一百分钟，四千三百字的判决书，二十分钟读完。**法律的时间单位跟人不一样**：十五日上诉期，三十日腾房期限，六十日履行宽限。最让人心里发紧的是，感情从来没法量化，可判决书一出来，全都按天给你排得明明白白。

#### 查明的与查不明的

| 栏位 | 文书查明了 | 它查不明 |
|---|---|---|
| 婚姻状况 | 某年某月某日登记结婚 | 登记那天下雨，谁打的伞 |
| 共同财产 | 房产一套，共同还贷 79 期 | 79 期里有 11 期是他一个人还的，他没让她知道 |
| 感情状况 | 「感情确已破裂」 | 破裂发生在哪一天，两人各有各的答案，且都不是那一天 |
| 家务贡献 | 没这一项，顶多算个数字 | 七年的早饭 |
| 宠物归属 | 判给原告 | 猫认的是他 |
| 子女抚养 | 跟妈过，爸每月给钱 | 判决当天孩子在门外的走廊上站着 |

判决书写的全是真的，合起来却不是那件事。这条戏的全部张力在这句落差上，不在庭审现场。

#### 可用细节

| 类 | 内容 |
|---|---|
| 物 | 骑缝章盖歪了 · 纸有静电，翻页粘手 · 装在牛皮纸信封里，信封上是打印的姓名 |
| 法律腔 | 「经本院合法传唤」 · 「无正当理由拒不到庭」 · 「本判决为终审判决」 · 判项用一二三分条，句尾一律句号 |
| 她的读法 | 先翻到最后一页看判项 · 再回头逐段读查明段 · 在「共同还贷 79 期」那行停住 |
| 他的读法 | 只看孩子那一条 · 其余部分没读完，收进了抽屉 |
| 事后 | 一份留档，一份复印去办过户 · 三年后办别的事又要用到它，从抽屉里翻出来，纸已经发脆 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁是原告 | 她起诉，女尊设定里常见，现代设定里这栏本身有信息 | 他起诉，这栏一出现，读者立刻知道这七年发生过什么 |
| 文书成色 | 全篇冷 | 有一处不冷：审理查明段里保留了一句当事人陈述的原话 |
| 争议焦点 | 财产 | 抚养权（走 [13-家庭与亲属](13-家庭与亲属.md)） |
| 读的人 | 她 | 很多年后孩子调档，第一次读到父母的这段 |
| 文体纯度 | 整节只有判决书正文 | 判决书与她的走廊二十分钟交替 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「一起还贷 79 期」那行：她算了好几遍，多出 11 期 | 判项第三条的期限：让他三十天内搬走，他第一天就搬了 |
| 内心 | 她赢了官司，走廊上却一点也高兴不起来 | 他想要的那条没写进去，因为那条根本没法证明 |
| 好的处理 | 她把复印件收好，猫那条她自个儿反悔了 | 他没上诉，拖到最后一天才搬，多住的日子谁也没告诉 |
| 写崩 | 写成她在法庭上滔滔不绝讲大道理 | 写成他签字时哭得稀里哗啦 |

#### 写崩的三种方式

1. 判决书里冒出「他心里一沉」，前两段守住的格式，到第三段落回小说旁白，文书腔调当场破功。
2. 判项用得不对、术语写得外行，懂行的读者一眼出戏。这类文体的门槛恰恰卡在这，文书造假最露怯。
3. 庭审和判决书只能选一样。庭审有对手戏可写，判决书没有，两边都写，判决书只会退成注脚。

## 六 · 聊天记录体

| 双方节奏 | 秒回对秒回 | 一个秒回，一个隔天回：这时间差本身就是关系远近 |
| 撤回归属 | 她撤回 | 他撤回，他撤的八成是句软话 |
| 记录的来源 | 实时 | 有人翻出两年前的聊天记录（走 [02-等待与错过 · 消息已读不回](02-等待与错过.md#三--消息已读不回)） |
| 文体纯度 | 整章不带一句叙述 | 界面当插片，一屏截图塞进正常叙述里 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她打完又删、删完又打，来回三次「正在输入」 | 他连发四条，第五条打了一半，改成句号 |
| 内心 | 她越在乎，回得越短，字数就是她的克制 | 他越紧张，标点越乱，句号都缩成三个字的短句 |
| 好的处理 | 她最后一条不带问号，把选择权留给对方 | 他隔了六小时才回，只回两个字，而且正好是对方想听的那两个 |
| 写崩 | 写成她句句带刺，跟人抬杠 | 写成他刷屏哭惨，没完没了 |

#### 写崩的三种方式

1. 气泡写成剧本。 完整长句、零错字、不分条发、没有表情包，那是话剧台词，不是聊天。
2. 加旁白。 一行「她盯着屏幕，心里一紧」就把这条废掉了。这玩意的全部效果，就靠没有旁白撑着。
3. 撤回内容给出来。 撤回就是留白用的，你把它填上，那就只是一条普通消息，还多解释了一遍，纯属多余。

## 七 · 清单体

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：做饭 48.4% ＋ 投喂 25.3%

**骨架**｜她备忘录里躺着张从不删的清单，标题就一个字：买。过一年翻回去看，上头东西早换过三茬，茬茬都对应他身上的一个毛病。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 起点：最普通的那种，牛奶、垃圾袋，谁都会写 |
| 2 | 第一次变味，低钠盐出现在他体检之后 |
| 3 | 待办清单的另一条线：周三取药、换滤芯、给他妈打电话 |
| 4 | 一条划掉又写回来的 |
| 5 | 一条一直没划掉的 |
| 6 | 他看见了这份清单，她递手机让他看别的，屏幕停在这一页 |
| 7 | 他建了自己的一份，第一条抄的是她的第三条 |

#### 时间轴

标题底下的内容换了又换，最早那版还记着他忌口的东西。**单条清单三十秒写完，但整份清单看的是这一年**。同一个标题一直没动，可底下内容早换过好几轮了，翻到最早那版，上面还留着他忌口的记录——那时候她压根没想过后来会变。

#### 条目的五种密度

| 类型 | 例 | 读出的 |
|---|---|---|
| 通用条目 | 抽纸、垃圾袋、灯泡 | 没啥可说的，当背景用，光堆这些，读者不信 |
| 定制条目 | 无糖的那款、他能咽得下去的那个牌子 | 这是试出来的，试的过程不用写 |
| 时限条目 | 周四之前、下次别忘 | 谁记着就是谁的事，写谁谁认领 |
| 划掉又写回 | 一盒烟 | 戒了三回，划了三回，又写回三回 |
| 永不划掉 | 一件他两年前随口说过想要的东西 | 一直攒着，等个日子送，见 [07-馈赠与仪式 · 藏了很久的礼物](07-馈赠与仪式.md#一--藏了很久的礼物) |

清单体写出来就是断句：没主语，没前因后果，全是名词往那儿一摆。**因果被格式隔开了，读者只能自己脑补**，所以它比正经叙述更扎人。

#### 可用细节

| 类 | 内容 |
|---|---|
| 物 | 冰箱贴条 · 手机备忘录 · 购物 app 的常买列表 · 超市小票背面 |
| 格式痕迹 | 前三条打了勾，第四条没有 · 中间插了一条与购物无关的 · 一条只写了两个字，她后来自己也没看懂 |
| 版本 | 同一份清单被复制成「买 2」「买 3」 · 云端历史版本可回看 · 纸质清单她按月夹在一个铁夹子里 |
| 他那一份 | 更长、更碎、带时间 · 有一条写着「问她今天累不累」，排在买菜后面 |
| 被看见的方式 | 她递手机时忘了退出 · 他借手机扫码 · 清单同步到了共用平板 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 清单在谁手里 | 她的，平时都是她管这事 | 他的，他的清单更细，还有一整栏记着她的作息 |
| 清单的性质 | 购物 | 说明书：他病的时候她写的《怎么照顾他》，一共十七条，条条像操作规程 |
| 被看见 | 他看见了，什么也没说 | 他看见了，第二天照着买回来一半，另一半故意留给她 |
| 收尾 | 清单还在用 | 清单停更在某一天，后面全是空白 |
| 文体纯度 | 整节由三份清单构成，跨度一年 | 清单只在一处出现，长度七行 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 品类漂移：她自己翻旧版本时才看出来 | 那条「问她今天累不累」排在第三位，前两条是米和油 |
| 内心 | 照顾在她这儿是能做的事，写不出来的她就不写 | 他抄她的清单，抄的时候把「他」改成「她」 |
| 好的处理 | 永不划掉的那条她不解释，留着 | 他不问那条为什么一直在，他自己也有一条一直在 |
| 写崩 | 写成她什么都管、样样都顾的主妇秀 | 写成他照着单子全做一遍的机器人 |

#### 写崩的三种方式

1. 清单写成完整句。 一旦出现主语和因果，它就退回叙述，说明书式的钝感全丢。

2. 条目全是定制条。 定制条要靠通用条垫着才显眼，全是灯泡和纸巾里冒出来的那一条才有力气。

3. 当场解释清单。 谁一开口讲这份清单意味着什么，读者就不用读清单了。

## 八 · 日记被看见

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：隐瞒 4.7% ＋ 掉马 32.8%

**骨架**｜日记体加目击，两层。她写给自己看，他坐在旁边读，读者也知道他在读。同一行字读两遍，第二遍才有戏。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 日记的常态：写了几年，格式固定：日期、天气、三行 |
| 2 | 他撞见本子摊在桌上，或云端笔记同步到了共用平板 |
| 3 | 第一层：他读到的字面，全是流水账，没有一个字提到他 |
| 4 | 第二层：他知道的上下文，那天他记得，她写的和他记得对不上 |
| 5 | 一条空白日，那天她什么都没写，那天是他们吵架 |
| 6 | 他合上本子，放回原位，角度差了两度 |
| 7 | 她发现有人读过，或者永远没发现 |
| 8 | 下一篇日记的文体变了 |

第 8 拍是这条的核心：日记一旦有了第二个读者，它就不再是日记，它变成了一封不承认自己是信的信。接 [一 · 写给你](#一--写给你)。

#### 时间轴

她一天就写三行，他一个小时把三年全看完。**这双层结构的时间是错开的**，压缩比不一样，读出来的味儿肯定不对。他花了四十分钟读完这本跨了三年的日记，看到的她，比真实的她更连贯、更冷静。流水账本身就自动删掉了那些犹豫反复，所以这层印象是带着误差的。

#### 同一行的两层读法

| 她写的（给自己看） | 他读出的 |
|---|---|
| 今天下雨。加班到十点。 | 十点，他那天在楼下等了四十分钟，她一个字没提 |
| 他今天很乖。 | 那天他摔了杯子，这也算乖，那她的尺子松到什么程度 |
| 领了钱。买了鱼。 | 发薪日她买了他爱吃的那种鱼，日记里不写为谁买 |
| （空白） | 吵架那天 |
| 阴。 | 只有一个字的日子，一年里有十一天，他数了 |

空白日和一格日，是这条时间线里最好用的两个格子。**日记真正值钱的地方，是它没写的那部分**，只有后来翻到的人才清楚那天到底出了什么事。

#### 可用细节

| 类 | 内容 |
|---|---|
| 物 | 本子上的橡皮筋 · 中间那页被撕掉，撕口留在装订线那儿 · 里头夹着干花 · 后半本全是白纸 |
| 格式 | 日期写数字，天气写一个字 · 每篇不超过三行，她自己定的规矩 · 从来不换行，也不分段 |
| 他的动作 | 光翻，不动笔 · 想拍张照，又放下了 · 合上时把书脊跟桌沿对齐了一下 · 出门前又回头看了一眼 |
| 破绽 | 他放回去时，角度偏了两度 · 橡皮筋换了个方向 · 那晚他不对劲，没问她今天过得怎么样 |
| 她发现的方式 | 她看出角度不对 · 她翻到某一页，发现被压出了折痕 · 她什么也没说，但下一篇日记，开始写得更细了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 日记归谁 | 她读到她的版本，包括她怎么叫他 | 他的，她看到自己在他笔下啥样，通常更好看，好看到她不敢认 |
| 目击方式 | 无意撞见 | 她故意放桌上（那就不是日记了，走 [一 · 写给你](#一--写给你)） |
| 读者知情度 | 读者跟他一起看（边读边补） | 读者早知道空白那几天出了啥事，看他一条条猜，心里更揪得慌 |
| 事后 | 谁都不提，日记接着写 | 她换了个本子，新本子一个字都没提那事 |
| 文体纯度 | 整节日记和他插话轮流来 | 只放三条日记，剩下全用正常写法 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她给自己写字时的口径：省略、克制、从不写委屈 | 他读到自己被写成两个字「很乖」时的那一下 |
| 内心 | 日记是她唯一不用当主导的地方 | 他在三年里只被写到过十七次，他数完了 |
| 好的处理 | 她发现了不追问，她把下一篇写长了两行 | 他不揭穿，他把那十一个一字日的日期记在自己手机里 |
| 写崩 | 写成她日记里满是深情告白 | 写成他读完当场质问 |

#### 写崩的三种方式

1. 只有一层。光贴日记不给目击者，那是内心独白换了排版，双层结构垮掉。
2. 当场对质。「原来你是这么想的」一出口，装不知道的那几个月全被挤掉了，戏就没了。
3. 日记写成抒情散文。写满心事的日记不需要第二个读者，真日记是流水账，越平淡第二层越响。

后接：[15-秘密与坦白 · 掉马](15-秘密与坦白.md#二--掉马) · [一 · 写给你](#一--写给你)

## 九 · 讣告与悼词

`T` ｜ ⚠️BE·死亡向 ｜ 全谱系 ｜ 语料频次：离世 29.4%

**骨架**｜讣告三百字，套模板就行。悼词她改了七遍，最后念的那版删了一段——那段一开口，就得先解释他俩啥关系。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 讣告起草：姓名、生卒、享年、治丧安排，模板不用想 |
| 2 | 家属署名那一行，她排在哪里，或者不在上面 |
| 3 | 悼词第一版，三千字，写了一整夜 |
| 4 | 逐版削，七版越删越短，删的都是同一类东西 |
| 5 | 最后一版定稿，八百字，能被所有人签收 |
| 6 | 现场念谁念，念到哪一句停住，停多久 |
| 7 | 没念的那一版，她揣在口袋里，散场时还在 |
| 8 | 后来一年后她怎么处理那份底稿 |

#### 时间轴

她写了三个晚上，把一生压进三百字。**悼词是倒着写的**，从最长写到最短，从全真话写到能拿出去的真话。第七版比第一版少了两千二百字，少掉的那部分，就是这段关系没法让人知道的那点东西。

#### 三种文本，三种能说的量

| 文本 | 读者 | 能说什么 | 不能说什么 |
|---|---|---|---|
| 讣告 | 所有人 | 生卒年、职务、办后事的时间地点、家属是谁 | 具体的人名和事 |
| 悼词（念出来的） | 到场的人 | 他做过的好事，说成大家都能认的 | 他俩怎么好上的 |
| 底稿（没念的） | 一个人 | 谁听谁的、他最后说了啥、她欠他那笔账 | 无 |

#### 署名那一行

| 关系 | 署名位置 | 代价 |
|---|---|---|
| 有法律关系 | 配偶栏，第一位 | 无 |
| 无法律关系但公开 | 「生前友好」，姓名排在末行 | 一生的位置被压进四个字 |
| 未公开 | 不署名，以同事身份到场 | 她要在门口向每一个人解释自己是谁，解释一次少一分 |
| 制度否认女尊设定的反向世界 | 不得署名，家中另有正式排位 | 走 [38-制度里的两个人](38-制度里的两个人.md) |

#### 可用细节

| 类 | 内容 |
|---|---|
| 物 | 打印店的模板文件 · 黑边的纸 · 折了四折的底稿 · 讣告上的手机号是她的 |
| 格式的硬 | 享年按虚岁还是周岁 · 「因病医治无效」是套话，具体病名不写 · 时间精确到分，从病历上抄的（接 [二 · 病历上的他](#二--病历上的他)） |
| 现场 | 念到第三段她停了七秒 · 有人以为她忘词，替她翻页 · 最后一句她念快了，快到没人听清 |
| 底稿留下的痕迹 | 折痕、口袋里的手汗、一处被划掉又用括号补回来的 |
| 一年后 | 她没烧，她把它夹进了那本一直没读完的书 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先走 | 他先走，她写悼词，走 [42-岁月与身后 · 他先走了](42-岁月与身后.md#九--他先走了) | 她先走，他写，而且多半没资格署名，走 [42-岁月与身后 · 她先走了](42-岁月与身后.md#八--她先走了) |
| 关系公开度 | 全摊开了，她来操办后事 | 压根没露过，她只能坐最后一排 |
| 底稿的去向 | 烧掉 | 留着，很多年后被另一个人翻出来 |
| 现场变数 | 她顺顺当当念完 | 她卡住了，换人念，那人念的还是删了又删的版本 |
| 文体纯度 | 讣告和悼词都齐活 | 只留讣告和底稿的落差，现场不写 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 第七版删掉的那两千二百字，她记得每句删在哪 | 署名那一行，他连争的资格都没有，只能在门口站着 |
| 内心 | 公开的话里没一个词能装下他，她只好挑最普通的几个说 | 他要用「朋友」两个字送她走，这两个字是他自己当年点头认的 |
| 好的处理 | 她照稿念完，底稿一个字不改地揣回去 | 他不闹、不认亲，散场后留下来收椅子 |
| 写崩 | 写成她灵堂宣告关系 | 写成他被赶出场的苦情戏 |

#### 写崩的三种方式

1. 删掉的那两千多字才是力气所在，七版如果都摆出来，第八版读者反而无从想象。
2. 讣告写得越深，越失格，因为它是格式文。痛感恰恰来自格式与人之间那道缝。
3. 灵堂摊牌那一下，等于把追悼会从悼念变成事件，重心当场偏掉，毕竟那不算公开场合。

## 十 · 她写他

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：掉马 32.8%

**骨架**｜她给他写了三年。第187章要写他哭，她坐在客厅里看真人洗碗，突然分不清自己等的是那章更新，还是那个人。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 取材：他一个动作被她记进大纲备注里，当时她没当回事 |
| 2 | 命名，她给纸上那人起了个名，跟他只差一个字 |
| 3 | 加工：现实里他不敢，纸上他敢，她替他补了胆 |
| 4 | 预演：她先把没发生的事写出来，再在现实里等它发生 |
| 5 | 反噬，她开始拿纸上那套去要求真人 |
| 6 | 察觉，她发现自己很久没看他了，光顾着挑他毛病 |
| 7 | 处理把他从主角降成配角、直接完结、或者写一章他完全不出现的 |

她写过的场景，在现实里真发生的时候，她一下就明白了。这个反应让她知道自己不对劲了——她第一反应是去对一遍，不是高兴。第 4 拍才是这条的关键。**先写出来，后面才发生**。

#### 时间轴

写三年，二百章，日更两千字。**她的一天有两个他**：白天那个会洗碗、会烦、会说随便。深夜那个说她想让他说的话，而且从来不累。深夜的版本每天准时到岗，白天的版本得她自己哄。

#### 三个他

| 版本 | 谁能改 | 谁在爱他 | 她的心力去向 |
|---|---|---|---|
| 现实的他 | 谁都改不了 | 她，在她还有力气的时候 | 剩下的那点 |
| 大纲里的他 | 她一句话改一次 | 她，随时，且不费劲 | 大部分 |
| 已发表的他 | 改不了了，读者记着 | 三千个人 | 维护的事 |

三个版本互相打架：她越写第二个，第一个就越显得不贴心。读者越吃第三个，她越不敢动设定。这戏的毛病就出在第二栏那句「不费劲」上。

#### 可用细节

| 类 | 内容 |
|---|---|
| 工序 | 大纲的备注栏 · 素材文档里贴着他的原话，标着日期 · 人物小传里有一栏叫「不能碰的」 |
| 命名 | 差一个字的名 · 生日改了一天 · 那道疤挪到了另一边，是她唯一做的伪装 |
| 预演的物证 | 第 92 章写过的那顿饭，四个月后真的发生 · 她当场愣了三秒，被他问怎么了 |
| 反噬的形态 | 她说「你上次不是这样的」，而上次是纸上的 · 她对真人的容错率在下降 |
| 察觉的那一刻 | 他洗碗时哼了一句跑调的歌，她第一反应是这个细节可以用 |
| 处理 | 她写了一章他完全不在的，写完发现自己写得很吃力 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他知不知道 | 不知道（他这边走 [44-圈层与同好 · 她是太太](44-圈层与同好.md#二--她是太太)） | 知道，还在追更，俩人各装各的 |
| 加工方向 | 往好里写（更帅更敢） | 往惨里写，她把他写得更可怜，写完自己难受半天 |
| 反噬程度 | 顶多偶尔走神 | 她开始拿纸上的进度表催现实里的他 |
| 收法 | 写完，把他还给他自己 | 不写完，改成她自己当主角，他退到配角，读者立马发现不对 |
| 文体纯度 | 大纲、素材、正文片段三种混着来 | 就贴一页大纲，其余正常写 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 备注栏里那句她自己都忘了记过的原话，标着两年前的日期 | 他被写成一个更敢的人，而他这辈子没敢过 |
| 内心 | 她怕的是自己更爱那个改得动的版本 | 他若知道，第一个反应是想去当那个纸上的人 |
| 好的处理 | 她把「不能碰的」那一栏一条条搬回现实去问他 | 他若知道也不揭穿，他挑一件纸上的事，在现实里做一遍 |
| 写崩 | 写成她创作至上牺牲一切 | 写成他拿这件事拿捏她 |

#### 写崩的三种方式

1. 引文一多，读者就跳去翻原书了。纸上写太细，超过三行，人就没影了。
2. 一觉醒来就分清了，恍惚是慢慢来的。靠一个顿悟收场，等于前头二百章白写。
3. 聊到虚构和真实，人物就没了，剩作者在那儿上课。这该写成创作论。
