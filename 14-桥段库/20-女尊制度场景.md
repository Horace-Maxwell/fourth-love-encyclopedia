# 女尊制度场景

> **分级** 分级见各条，分级上限 `T` ｜ 预警 ⚠️训诫（限第六、七条）｜ 亚型 古代女尊 · 架空
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**在别的设定里权力要靠人建立，在这里权力是空气——所有的戏都发生在制度的缝里。**

## 这一卷与前十九卷的根本区别

前面十九卷写的是**两个人怎么谈成一种权力关系**。这一卷不用谈：制度已经把它写好了。

于是戏的来源完全变了：

| | 现代设定 | 女尊设定 |
|---|---|---|
| 张力来自 | 制造反差 | 反差里较劲 |
| 他的困境 | 我配不配 | 我不敢再要 |
| 她的困境 | 我凭什么 | 我能不能破例 |
| 冲突对象 | 外人眼光 | 规矩本身 |
| 最好的戏 | 试探着越线 | **守着规矩干出格的事** |

十条场景翻来覆去就靠同一个机关：合规的越界。她不把规矩废了，她就在规矩允许的最边上，多给他那么一点。旁边的人心里都门儿清。

制度设计的完整方法见 [03-世界观设定/01-女尊世界构建全书](../03-世界观设定/01-女尊世界构建全书.md)，称谓与礼制见 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。这一卷只写场面。

## 一 · 晨昏定省

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：请安 25.0%（请安＋受伤、请安＋起哄高频同现）

**骨架**｜每天到点他就来请安，动作都差不多，但每次那点不一样的地方，才是重点。

#### 节拍链

卯时到 → 廊下候着 → 行礼 → 她抬眼或没抬 → 让起的快慢 → 三两句话 → 退出（在重复中变化）

#### 时间轴

单次请安五分钟，但这条线的钟是按年走的。每天同一个时辰，同一套动作，重复本身就是刻度。第一年他行礼一丝不苟，第三年她的「起来吧」已经赶在他膝盖弯下去之前，第五年这请安就成了俩人默认的早间碰头。变化全藏在毫米级里，让起的快慢，多问的那半句。写这条，其实就是写同一场戏演到第一千次。

#### 重复是这条的技术

请安是**每天都发生的事**，所以它是最好的变化刻度尺：

| 观察点 | 变化说明什么 |
|---|---|
| 他来的时辰 | 早了／迟了 |
| 站还是跪 | 她有没有免过 |
| 她让不让起 | 让得多快 |
| 她有没有抬头看他 | 注意力 |
| 说几句话 | 从三句到三十句 |
| 有没有赐座 | 位置的变化 |
| 旁人在不在 | 私下与人前的差别 |

「同一套动作写三次，每次改一个细节」是这条的标准用法。第一次全套规矩，第二次她免了跪，第三次她让他坐下了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 时辰 | 卯时／辰时 · 更漏 · 天还没亮 |
| 空间 | 廊下候着 · 帘子 · 阶下 · 她在上首 |
| 道具 | 茶（谁先上）· 垫子（给没给他）· 他袖口的褶 |
| 他的动作 | 行礼规不规范 · 起身时膝盖 ✓ 的僵 |
| 她的动作 | 手里的东西没放下 · 或者她放下了 |

「她放下了手里的东西」是最省字的态度变化。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 阶段 | 关系初期（全套规矩） | 后期（形同虚设） |
| 她的态度 | 严格 | 免了 |
| 旁人 | 有 | 无 |
| 他的心态 | 例行公事 | 他其实盼着这一刻 |

「他其实盼着这一刻」是这条最好的内心设定。 一天里唯一能名正言顺见到她的时候。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她今天让他起得比昨天快 | 这是今天唯一能见她的时候 |
| 内心 | 免了他的规矩，别人会怎么说 | 多站一会儿也好 |
| 好的处理 | 她按规矩来，但记住了他袖口的破处 | 他没有借请安讨好 |
| 写崩 | 写成她当众破例 | 写成他跪着受宠 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 每天早上的固定汇报／她的日程里那五分钟 |
| 修仙 | 每日的问安／弟子拜见 |
| 星际 | 每日例行报到 |

#### 写崩的三种方式

1. 只写一次。重复才有刻度。
2. 让她一开始就免规矩。免的过程才是戏。
3. 写成他享受跪拜。见下面的通用红线。

#### 示例（本库自撰，可直接改写）

> 卯时三刻。天还没全亮。他在廊下站了一会儿才进去。
> 「主君安。」他行礼，膝盖落到垫子上。那垫子是上个月才添的。
> 她「嗯」了一声，手里的折子没放下。
> 第三日，她说：「起来吧。」比前两日快了半句。
> 第七日，他刚要跪，她抬手：「免了。」
> 第十五日，他进门的时候，案边多了一张椅子。她没有抬头，只说了两个字：「坐着。」

## 二 · 位份

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：位份 15.0%（世界设定族）

**骨架**｜他在这个家的位次，就是个能写出来、贴墙上、随时能改的数字。

#### 节拍链

位份现状 → 变动的由头 → 她的两难，给不了，或给了他担 → 文书压了几天 → 定了 → 全府反应 → 他的真实反应

#### 时间轴

文书压了几天，就是她犹豫了几天。由头出现到她动念一夜，拟文一天，用印前压了五天，这五天全府都在猜，只有他照常过日子，或者装作照常。公示当天全府反应两小时内到位：有来道贺，有当场变脸，也有观望不动。他的真实反应在当晚无人时才出现，比公示晚十二个小时，这个时间差就是他的教养。

#### 位份为什么是最好的冲突装置

因为它把感情量化了：

| 特性 | 后果 |
|---|---|
| 可见 | 全府都知道 |
| 可比 | 有人在他之上 |
| 可变 | 升与降都可能 |
| 与待遇挂钩 | 衣料、车驾、进正堂的资格、生病请医的待遇 |
| 与她的意志挂钩 | 但她得看外面脸色 |

「与她的意志挂钩，但她要顾及外部」是这条的全部张力。她想给，但她给不了。或者她给了，代价由他承受。

#### 可用细节

| 类 | 内容 |
|---|---|
| 物质标记 | 穿什么料子 · 坐什么车 · 花多少钱 · 住哪边 |
| 仪式标记 | 请安谁先谁后 · 坐哪儿 · 走路谁让谁 |
| 变动 | 升位分 · 降位分 · 他自己说不干了 |
| 无名分 | 人住在正院，族谱上没她（见 [11 卷第十条](11-初遇与确立.md#十--没有表白)） |
| 他的态度 | 在不在意 · 嘴上说不在意，多半骗人 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的位份 | 最高（正君） | 无名分 |
| 她想不想给 | 想给但给不了 | 她故意不给（要有理由） |
| 他在不在意 | 明说在意 | 嘴上说不在意 |
| 变动 | 升 | 降（更有戏） |

**「降位」是这一族里最狠的一个动作**，且它可以是她被迫做的。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 册封文书她压了三天 | 我的名字排在第三 |
| 内心 | 给了他，等于把他推到风口 | 说不在意是假的 |
| 好的处理 | 她给了，也扛住了事 | 他认了，说在意 |
| 写崩 | 写成位份高就是爱得多 | 写成他为了位份啥都干 |

**「位份 ≠ 爱的多少」这一点必须在文本里被说清楚**，否则整个制度层会退化成宫斗。

#### 写崩的三种方式

1. 让位份等同于感情。 制度与感情要分开写。
2. 让她轻易破例。 破例要有代价。
3. 让他完全不在意。 那是假的。

## 三 · 宫宴上的坐次

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：宫宴 21.0%（宫宴＋请安＋起哄为高频三元组合）

**骨架**｜一张桌子，座位早就定好了。他坐哪儿，全场都盯着。

#### 节拍链

坐次表出来 → 他看到自己的位置 → 走过去那几步 → 席间敬酒与打趣 → 她布了一箸 → 散席车上

#### 时间轴

坐次表提前三天出，宴席三个时辰，走过去那几步最长。三天里各府都在琢磨表上的位置，谁挨着谁，谁被挪了，门道都在里头。席上的钟是按敬酒轮次走的，第二轮准有人借着酒劲说点有的没的。她夹那一筷子，正好卡在全场目光的缝隙里，三秒，比什么声明都管用。散席上车那会儿的复盘，一刻钟，说的话比三个时辰的宴席都实在。

#### 坐次即公告

这是这一族里最经济的场面：不需要任何人说话，坐次表已经把一切公布了。

| 位置 | 含义 |
|---|---|
| 她身侧 | 最高，且是宣告 |
| 她下首第一位 | 正式的第一位 |
| 与其他侍君同列 | 平等，也就是没有特殊 |
| 末位 | 明确的冷落 |
| 不在席上 | 最狠 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 坐次表 | 谁定的 · 后来改没改过 · 改哪儿了 |
| 现场 | 他走过去那几步 · 全场都在看 |
| 敬酒 | 先敬谁后敬谁 · 谁替他挡酒 |
| 起哄 | 桌上人拿他俩逗乐（见 [14-社交与公开 · 被起哄](14-社交与公开.md#一--被起哄)） |
| 她的动作 | 她给他夹了一筷子菜（见 [01-日常照料 · 一口一口喂](01-日常照料.md#二--一口一口喂)） |
| 散席后 | 车上谁都没说话 |

「他走向自己位置的那几步」是这条的核心镜头。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 坐次 | 高 | 低 |
| 谁定的 | 她 | 长辈／礼官（她改不了） |
| 席间 | 平安无事 | 有人当众发难 |
| 她的处理 | 当场改了坐次 | 她忍了，事后处理 |

**「她当场改坐次」是极强的一个动作**，但代价要写：改一个位置等于打了定坐次那个人的脸。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看见坐次表时愣了一下 | 我坐第七排 |
| 内心 | 改了就是跟礼官过不去 | 站起来走过去，别低头 |
| 好的处理 | 她记下了，回头收拾了那礼官 | 他步子没乱 |
| 写崩 | 写她当场掀桌 | 写他当众绷不住 |

#### 写崩的三种方式

1. 让她当众翻脸。 制度戏的力量在克制。
2. 别管坐次表本身。 那张纸才是这条的主角。
3. 只写宴会热闹。 坐次是唯一要写的。

## 四 · 她要纳新人

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：选侍 21.0%（选侍＋请安、选侍＋戒指高频同现）

**骨架**｜制度上她可以多娶，他根本没资格拦。

#### 节拍链

旨意或族议 → 他领命操办 → 办得比谁都周到 → 破绽（睡得少）→ 进门那晚 → 她私下的交代 → 长期共处开始

#### 时间轴

从接到旨意到进门，整整一个月。他筹备得越久，露出的破绽就越多。头两周还能撑住，账目清清楚楚，礼数也挑不出毛病。到第三周就开始失眠，下人们先看出来的。进门那天晚上是最关键的一关，他该站哪儿就站哪儿，一步没走错。三天后她单独把他叫去，屏退左右，聊了大概一炷香的工夫。就这一炷香里说的话，往后几十年这个府里是冷是热，全看它了。

#### 这一族里最狠的一条

现代设定里，吃醋是可以表达的（哪怕拐弯抹角）。在这里连吃醋都是不合规矩的。

| 他能做的 | 他不能做的 |
|---|---|
| 照规矩迎新人进门 | 表达不满 |
| 安排一切 | 拒绝 |
| 做得比谁都好 | 提出异议 |
| 病一场 | 争 |

**「做得比谁都好」是他唯一的抗议形式**：把新人安顿得无可挑剔，让所有人看见他的体面，然后回到自己房里。

#### 可用细节

| 类 | 内容 |
|---|---|
| 事务 | 聘礼怎么下 · 院子怎么分 · 他得出面张罗 |
| 他的表现 | 都照办 · 还办得比平时更上心 |
| 破绽 | 那几天他几乎没怎么睡 · 还给自己揽了件新差事忙个不停 |
| 她的处理 | 她心里明白 · 但没法开口 |
| 那一夜 | 新人进门那晚，他人在哪儿、在干嘛 |

「新人进门那晚他在做什么」是这条唯一需要写透的一场。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她想不想纳 | 被逼的，政治联姻 | 她自己乐意 |
| 他知不知道原因 | 知道她是被逼的 | 完全蒙在鼓里 |
| 他的表现 | 办得漂漂亮亮 | 出过一次岔子 |
| 结局 | 她后来给推了 | 纳了，还得长期处着 |

**「纳了，且要长期共处」是最难写也最有价值的一版**，它把这条从一场戏变成了一条长线。走 [04-人设原型/03-配对化学反应矩阵](../04-人设原型/03-配对化学反应矩阵.md) 的 np 结构。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看见他把新人的院子安排在最远的一处 | 这件事我要办得漂亮 |
| 内心 | 他一句话都没说 | 说了就是不懂规矩 |
| 好的处理 | 她私下给了他一个交代 | 他办完之后自己病了一场 |
| 写崩 | 写成他大闹 | 写成他毫无波澜 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 她的应酬对象／联姻式的合作／一个必须维持的关系 |
| 修仙 | 双修伴侣／宗门指派的道侣 |
| 星际 | 政治婚配／基因配对指令 |

#### 写崩的三种方式

1. 让他大闹。这不合规矩，而且会把他自己的位置搞砸。
2. 让他毫无波澜。那是没心没肺。
3. 让她轻易推掉。制度的压力得是真的，不能是摆设。

## 五 · 他的院子

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：位份 15.0% ＋ 请安 25.0%

**骨架**｜他住那院子，地段、大小、翻修，全按他身份来。

#### 节拍链

分院 → 距离与用度 → 她来的频率 → 摆驾或悄悄来 → 他种的那株 → 不再让人守门的那天

#### 时间轴

**院子的读数按季更新。** 分院那天定了起点，离正院三进，中规中矩。之后每季都有变化可读：修缮的批复快了，用度单上多了新项，她来的频率从月一变成旬一。他种的那株是慢变量，两年才成气候。「不再让人守门」发生在第三年。从那天起，这个院子从「他住的地方」变成了「他们常在的地方」。

#### 空间即位份

与 [17-同居与身体日常 · 家的形状](17-同居与身体日常.md#十--家的形状) 是同一个技法，但在这里它被制度化了。

| 观察点 | 读作 |
|---|---|
| 离正院多远 | 亲疏 |
| 院子的大小 | 位份 |
| 有几个人伺候 | 用度 |
| 她多久来一次 | 实际的宠 |
| 修不修缮 | 她记不记得 |
| 他院里种了什么 | 他自己的东西 |

「他院里种了什么」是唯一一项属于他自己的。在一个全由制度分配的空间里，他自己种的那一株，就是他自己的意志。

#### 可用细节

| 类 | 内容 |
|---|---|
| 距离 | 从正院走到他院子得走多久 |
| 变化 | 他换过院子，升了还是降了 |
| 她的来访 | 白天来还是夜里来 · 是不是摆驾过来，惊动全府 |
| 他的等待 | 见 [02-等待与错过](02-等待与错过.md) 里那些条目，放这儿全用得上 |
| 他的痕迹 | 一株他自己种的 · 一样她给的东西搁在哪儿 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 院子 | 离正院最近 | 最偏 |
| 她来的频率 | 常来 | 很久没来 |
| 来的方式 | 摆驾（全府皆知） | 悄悄来，更亲密，但也更暧昧 |
| 他的态度 | 盼着 | 已经不盼了 |

**「他已经不盼了」是这条最疼的一版**，且它可以只用一个细节表现：他不再让人守着门。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他院里那株已经长得很高了 | 她上次来是四十天前 |
| 好的处理 | 她记得他种的是什么 | 他没让人去打听她去了哪 |
| 写崩 | 写成宅斗和争宠那套 | 写成他天天干等着她来 |

#### 写崩的三种方式

1. 写成争宠。那是宫斗，不是这一条。
2. 忽略他自己的东西。那株植物是他的人格。
3. 只写空间不写时间。「上次来是四十天前」才是重点。

## 六 · 家法

`T` ｜ ⚠️训诫 ｜ 古代女尊 ｜ 语料频次：请安 25.0% ＋ 罚（见 [08 卷](08-规训日常版.md)）

**骨架**｜他犯了规矩。这回动家法，她没拦。

#### 节拍链

犯了规矩 → 执法定下 → 祠堂或中庭 → 她在场不能言 → 他不看她 → 受完 → 事后她去改规矩或私下补偿

#### 时间轴

执法那柱香烧完，前后还有更难受的。定罚那天到行刑，中间隔了一整天。这一天里谁都能来求情，可谁也没来，他自己也没求。祠堂里点香那会儿，她从头站到尾，一句话不能说。这规矩把她钉在椅子上，动弹不得。事后再算账，就分两条线了。他养伤，少说十天半个月。她改规矩，拖了快一个月。改完那天，她把新条文直接送到他院子里，一个字没多讲。

#### 安全框架

本条与 [08-规训日常版](08-规训日常版.md) 共用同一套底线，此处不重复全文，只列要点：

| 项 | 说明 |
|---|---|
| 共识框架 | SSC（安全、理智、双方同意）· RACK（知情且接受风险）· PRICK（自己负责的知情同意） |
| 虚构与现实 | 小说里的家法是**编出来的设定**，活在作者说了算的世界里，**别当现实操作手册** |
| 全员成年 | 出场角色全都成年了 |
| 不写实施细节 | 这条只聊故事怎么写，不给能照搬的操作过程 |

完整框架跟越界判据在 [08-规训日常版 · 安全框架](08-规训日常版.md) 和 [十 · 规矩的边界](08-规训日常版.md#十--规矩的边界) 里。重度实践看 [06-尺度与写法/04-训诫与BDSM专论](../06-尺度与写法/04-训诫与BDSM专论.md)。

#### 「制度在罚」与「她在罚」的区别

这是这条与 [08 卷](08-规训日常版.md) 的根本差异：

| | 她在罚 | 家法在罚 |
|---|---|---|
| 谁决定 | 她 | 规矩 |
| 她能不能免 | 能 | 免了就是坏规矩 |
| 他的对象 | 她 | 制度 |
| 最有戏的点 | 罚完之后 | **她想免而免不了** |

「她想免而免不了」是这条唯一值得写的困境。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 祠堂 · 中庭 · 有执法的人在 · 全府旁观 |
| 她的位置 | 她也得在，但不能开口 |
| 他的表现 | 他不看她，怕她难做 |
| 她的动作 | 她攥着扶手的手 |
| 事后 | 见 [08-规训日常版 · 罚完之后](08-规训日常版.md#九--罚完之后) |

「他不看她，怕她为难」是这条最好的一笔。 受罚的人在体谅执法现场的另一个人。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁执法 | 她 | 长辈／执事 |
| 她能不能免 | 能但代价大 | 完全不能 |
| 他犯的是什么 | 小错 | 为她扛的错 |
| 事后 | 她私下补偿 | 她公开改了那条规矩（最重） |

「她公开改了那条规矩」是这条的最高解法。免他这一次不算什么，以后都没有这条了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她在场，但话轮不到她说 | 别看她，看了她会难做 |
| 内心 | 免了他，府里的规矩就全松了 | 这是我该受的 |
| 好的处理 | 她事后悄悄把那条规矩改了 | 他受完了，也没怪她 |
| 写崩 | 写成她当众跟规矩对着干 | 写成他挨罚挨得挺享受 |

#### 写崩的三种方式

1. 让她当众废掉家法。规矩得真罚，不然没压力。
2. 写成受罚的快感。见安全框架。
3. 别忽略「她在场却不能说话」。这条全靠这个撑着。

## 七 · 她改了规矩

`T` ｜ ⚠️训诫 ｜ 古代女尊 ｜ 语料频次：位份 15.0% ＋ 请安 25.0%

**骨架**｜她动了祖上定下的规矩，可这代价，她一个人扛不住。

#### 节拍链

一件事逼到眼前 → 她动念 → 他先反对 → 她把私恩写成公义 → 阻力 → 成了或收回 → 多年后成了常态

#### 时间轴

从动念头到真办成，一年打底。那事儿真逼到跟前，一天都等不了。可要改一条祖上传下来的规矩，那真是磨人。他先跳出来反对，一晚上长谈。她把私底下的人情说成是公家的大义，几个月慢慢铺。族老那边死活不松口，开了三次族会。每一步都得花够时间，你想省哪一段，立马就假了。最后就是「多年后成了常态」。新规矩旧到没人还记得它当初是新的，她的名字就剩在批注里留着。

#### 这条是这一卷的顶点

前面六条写的都是**制度之内**的挣扎。这一条写改变制度本身。

而它的关键不在她有没有权力改（她有），在改了之后谁付代价：

| 代价 | 落在谁身上 |
|---|---|
| 族中的非议 | 她 |
| 「他恃宠而骄」的评价 | 他 |
| 其他侍君的处境变化 | 别人 |
| 后来者的先例 | 未来 |

**第三行最要紧。** 她为他破的例，会改变府里所有人的处境，而其中有人因此受损。

#### 可用细节

| 类 | 内容 |
|---|---|
| 改的是什么 | 一件小事，他能进正堂／能旁听／不用跪 |
| 阻力 | 族里长辈 · 管事 · 连别的侍君也拦着 |
| 她的做法 | 先不吭声，直接做 · 要么就正式写进规矩里 |
| 他的反应 | 他头一个跳出来反对，他清楚要付什么代价 |
| 落点 | 过了好些年，这条新规矩大家早习惯了 |

「他第一个反对」是这条最好的一笔。 他不要她为他付这个代价。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 改的大小 | 一条小规矩 | 制度性的 |
| 阻力 | 小 | 她被迫收回 |
| 他的态度 | 感激 | 反对 |
| 结果 | 成了 | 没成，但她试过（他记住了） |

「没成，但她试过」比成功更动人。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她写那行字时，手顿了一下 | 她不该为我这样 |
| 内心 | 这话不光说给他听 | 这代价我担不起 |
| 好的处理 | 她把改规矩说成制度的事，不往他身上扯 | 他顶回去，还说了为啥 |
| 写崩 | 写成她为爱扔了规矩 | 写成他心安理得地受了 |

**「说成是制度问题，不是为他」是她最聪明的一步：** 把私恩变成公义，代价一下就下来了。这也是女尊文里最值得写的政治手腕。

#### 写崩的三种方式

1. 写成为爱废法。那是把制度当成了道具。
2. 忽略别人的代价。破例会伤到第三方。
3. 让他坦然受之。他要看见代价。

## 八 · 他上了族谱

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：位份 15.0% ＋ 选侍 21.0%

**骨架**｜一支笔，一行字，不可撤销。

#### 节拍链

定了 → 祠堂设仪 → 族老在场 → 她提笔 → 那一行字 → 他盯着笔尖 → 出祠堂之后

#### 时间轴

仪式折腾了半个时辰，真正落笔就那十秒。祠堂摆开、族老坐齐、上香禀告祖宗，一套流程又庄重又磨人，全是为了这十秒准备的。她提笔、蘸墨、写下他的名字。他盯着笔尖那十秒，眼睛都不敢眨一下，生怕错过。出了祠堂，时间突然就松下来了。日头正好，他走路的姿势跟进去时不一样了，身上多了一个能被记住的位置。

#### 为什么这是这个类型最重的一个动作

| 特性 | 说明 |
|---|---|
| 公开 | 全族都能看见 |
| 正式 | 白纸黑字，认账 |
| 不可撤销 | 想反悔？除非被除名，那事更大 |
| 涉及后代 | 孩子归谁家，得说清 |
| 不需要爱 | 走程序，跟感情没关系，也正因为这样，它才沉 |

「不需要爱」是这一条的关键。上族谱这件事，本来不带感情也能做。正因如此，带着感情去做，才有分量。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 祠堂 · 族老在场 · 香烛 · 一支笔 |
| 那一行 | 写的是什么名字（本名还是别的）· 排在谁后面 |
| 他的状态 | 他一直盯着笔尖 · 手在袖子里攥着 |
| 她的动作 | 她自己写的 · 还是族老代笔 |
| 之后 | 他一遍遍翻回那一页看 |

「他反复去看那一页」是这条的收尾。 写下来的东西他要确认很多次才敢信。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁写 | 她亲笔 | 族老代笔 |
| 排位 | 第一 | 靠后 |
| 阻力 | 无 | 有人反对到最后一刻 |
| 他的反应 | 平静 | 出了祠堂才失态 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她写完，吹了吹墨 | 那一行字 |
| 内心 | 这是我拿得出手的东西 | 我有名字了 |
| 好的处理 | 她亲手写的 | 他出了祠堂才掉眼泪 |
| 写崩 | 搞成一场大场面 | 写成他感激涕零 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 领证／房产证加名／户口本 |
| 修仙 | 道侣录／宗门名册／本命契 |
| 星际 | 正式登记／权限永久绑定 |

#### 写崩的三种方式

1. 写成盛大仪式。一支笔一行字就够。
2. 忽略「不可撤销」。那是它的全部分量。
3. 让他感恩戴德。他是被承认，不是被施舍。

## 九 · 她要出征

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：告别 37.0% ＋ 位份 15.0%

**骨架**｜她走了，而这个家由他守着。

#### 节拍链

军令到 → 交印信 → 三件交代 → 她走 → 他当家（有人上门试探）→ 消息断续 → 她回来看到的府

#### 时间轴

军令到出发只有三天，她走后的钟以「信」为拍。三天里交印、交人、交那三件事，每件半天。她走后他当家，时间按信件计，一旬一封、断了两旬、再来时字迹潦草。试探上门的人专挑消息断了的时候，他一一接下。她回来那天看到的府，账册齐、人心稳、她种在他院里的那株开了花。三季的答卷。

#### 这条的结构价值

它是 [09-分离与重逢](09-分离与重逢.md) 的女尊版，但多了一层：**他不只是等，他要当家。**

| 他要做的 | 难点 |
|---|---|
| 主持府中事务 | 他说话算不算数 |
| 应对上门的人 | 有人借机来摸底 |
| 管住其他人 | 比他小的、比他大的 |
| 递消息 | 坏消息要不要跟她说 |
| 等 | 见 [02-等待与错过](02-等待与错过.md) |

「有人趁机来试探」是这条的主要情节来源。

#### 可用细节

| 类 | 内容 |
|---|---|
| 出征前 | 她把印信／对牌塞给他 · 这动作一出来，后面全得跟着走 |
| 交接 | 她临走前交代了三件事 |
| 他的处境 | 底下有人不服 · 有人跑来探口风 · 还有人往他屋里送东西 |
| 消息 | 前线的信断了多少天 |
| 她回来时 | 府里乱成什么样了 |

「她把印信交给他」与 [12-工作与金钱](12-工作与金钱.md) 的授权是同一个动作，但在这里它可见、可触，也可以被夺走。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她给不给权 | 全给 | 分给几个人，他只是其中一个 |
| 他撑得住吗 | 撑住了 | 出了岔子 |
| 消息 | 通畅 | 断了三个月 |
| 她回来 | 平安 | 带伤，见 [16 卷第四条](16-危机与保护.md#四--她受伤了) |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把印信放他手里 | 这个家现在归我管 |
| 内心 | 他扛不扛得住 | 别让她回来看到家里乱糟糟 |
| 好的处理 | 她把权给了，也没留一手 | 他扛住了，也没趁机多要 |
| 写崩 | 写成她全安排好了，人在远处盯着 | 写成他借这机会把权抓死 |

#### 写崩的三种方式

1. 让她远程遥控一切。交出去就是交出去。
2. 让他毫无阻力地当家。试探是必然的。
3. 忽略印信这个物件。它是这条的锚。

## 十 · 制度之外的那一刻

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：请安 25.0% ＋ 宫宴 21.0%

**骨架**｜那几分钟里，没别人，没规矩，也没名分。

#### 节拍链

场合封闭，深夜书房·马车·病中 → 规矩松开 → 称呼变了 → 一句不合身份的话 → 外面有动静或他自己起身 → 立刻恢复

#### 时间轴

**就几分钟，而且随时可能被打断。** 深夜书房、马车里，规矩松开的窗口极短。称呼变了，坐姿变了，那句不合身份的话说出口，全程不超过一炷香。外面一有动静，两个人半秒内各归各位，衣冠、语气无缝切换。这招的劲儿全在窗口短。正因为几分钟后一切照旧，这几分钟才值钱。

#### 这条是全卷的收束

前面九条写的全是制度。这一条写制度够不到的地方。

**它的价值在于对照：** 前面写得越严，这几分钟越贵。

#### 制度之外的场合

| 场合 | 为什么制度够不到 |
|---|---|
| 深夜的书房 | 没人看见 |
| 出行路上的马车里 | 门一关就与世隔绝 |
| 他病着的时候 | 规矩也得给病让路 |
| 一场大雨困住的地方 | 天意弄人 |
| 她卸了钗环之后 | 一身轻松，不用端着了 |
| 只有他们两个的一顿饭 | 没那么多讲究 |

**「只有他们两个的一顿饭」是最有效的一个：** 没有坐次表，就没有位份。

#### 可用细节

| 类 | 内容 |
|---|---|
| 称呼的变化 | 这几分钟里他喊她什么 |
| 姿势 | 他没站着 · 坐下了 · 或者躺下了 |
| 语气 | 他说了句不像他会说的话 |
| 时间感 | 俩人都明白这几分钟迟早要完 |
| 结束 | 外面有人喊了一声 · 俩人马上装没事 |

**「两人立刻恢复原样」是这条的收尾**，而恢复的速度本身就是这个世界的重量。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时长 | 几分钟 | 一整夜 |
| 谁先松 | 她 | 他 |
| 说了什么 | 一句不该说的 | 什么都没说 |
| 结束方式 | 被打断 | 自己结束的（更疼） |

**「自己结束的」比「被打断」更疼：** 没有人来叫，是他自己站起来重新行了礼。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他今天坐下了，没站着 | 这几分钟不算数 |
| 内心 | 想让他坐着 | 待会儿还得跪 |
| 好的处理 | 她没说「以后都这样」，她办不到 | 他自己站起来了 |
| 写崩 | 写成她答应废了规矩 | 写成他赖着不想起来 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 电梯门关上的那三十秒／车里／下班之后 |
| 修仙 | 结界之内／神识相通的一瞬 |
| 星际 | 关掉记录仪的那段／舷窗前 |

#### 写崩的三种方式

1. 让她承诺废掉规矩。她做不到，说了就是失信。
2. 写得太长。几分钟的事。
3. 前面的制度写得不够严。这条的价值全靠跟后面那几条对照着看。
