# 女尊制度场景

> **分级** 分级见各条，分级上限 `T` ｜ 预警 ⚠️训诫（限第六、七条）｜ 亚型 古代女尊 · 架空
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一卷写女尊制度下的日常场面：请安、位份、坐次、纳新人、院子、家法、改规矩、上族谱、出征，还有制度够不到的那几分钟。别的设定里，谁说了算得靠两个人自己处出来，这里是制度定好的，戏就出在制度管不到的缝里。

## 和前面各卷的区别

前面十九卷写的是**两个人怎么谈出一种权力关系**。这一卷不用谈，制度早就替他们定好了。

于是戏的来源完全变了：

| | 现代设定 | 女尊设定 |
|---|---|---|
| 张力来自 | 制造反差 | 反差里较劲 |
| 他的困境 | 我配不配 | 我不敢再要 |
| 她的困境 | 我凭什么 | 我能不能破例 |
| 冲突对象 | 外人眼光 | 规矩本身 |
| 最好的戏 | 试探着越线 | **守着规矩干出格的事** |

这十个场景翻来覆去写的，都是在规矩以内越界。她不废规矩，只在规矩允许的最边上，多给他一点。旁边的人心里都门儿清。

| 节拍族 | 作品数 | 占比 |
|---|---:|---:|
| 请安 | 771 | 26.6% |
| 宫宴 | 640 | 22.1% |
| 选侍 | 633 | 21.9% |
| 位份（世界设定族） | 478 | 16.5% |

制度怎么设计，全套方法在 [03-世界观设定/01-女尊世界构建全书](../03-世界观设定/01-女尊世界构建全书.md)，称谓和礼制在 [02-术语百科/02-女尊称谓与礼制体系](../02-术语百科/02-女尊称谓与礼制体系.md)。这一卷只管场面。

## 一 · 晨昏定省

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：请安 26.6%（请安＋受伤、请安＋起哄高频同现）

**骨架**｜他每天到点来请安，动作大同小异，要写的是每回不同的那一点。

#### 节拍链

卯时到 → 廊下候着 → 行礼 → 她抬眼或没抬 → 让起的快慢 → 三两句话 → 退出（在重复中变化）

#### 时间轴

一次请安五分钟，时间线却要按年拉。每天同一个时辰，同一套动作。第一年他行礼一丝不苟，到第三年，她那句「起来吧」已经抢在他膝盖弯下去之前，到第五年，请安成了两人心照不宣的早上碰头。变的只有让起的快慢，和多问的那半句。

#### 重复是这条的技术

请安**天天都有**，所以一点变化都看得出：

| 观察点 | 变化说明什么 |
|---|---|
| 他来的时辰 | 早了／迟了 |
| 站还是跪 | 她有没有免过 |
| 她让不让起 | 让得多快 |
| 她有没有抬头看他 | 注意力 |
| 说几句话 | 从三句到三十句 |
| 有没有赐座 | 位置的变化 |
| 旁人在不在 | 私下与人前的差别 |

同一套动作写三遍，每遍改一处：头一遍规矩全套，第二遍她免了他跪，第三遍她让他坐下了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 时辰 | 卯时／辰时 · 更漏 · 天还没亮 |
| 空间 | 廊下候着 · 帘子 · 阶下 · 她在上首 |
| 道具 | 茶（谁先上）· 垫子（给没给他）· 他袖口的褶 |
| 他的动作 | 行礼规不规范 · 起身时膝盖 ✓ 的僵 |
| 她的动作 | 手里的东西没放下 · 或者她放下了 |

她放下手里的东西，态度就变了，不必多写。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 阶段 | 关系初期（全套规矩） | 后期（形同虚设） |
| 她的态度 | 严格 | 免了 |
| 旁人 | 有 | 无 |
| 他的心态 | 例行公事 | 他其实盼着这一刻 |

他其实盼着这会儿，一天里能名正言顺见她的，只有这几分钟。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她今天让他起得比昨天快 | 这是今天唯一能见她的时候 |
| 内心 | 免了他的规矩，别人会怎么说 | 多站一会儿也好 |
| 好的处理 | 她按规矩来，但记住了他袖口的破处 | 他没有借请安讨好 |
| 写崩 | 写成她当众破例 | 写成他跪着受宠 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 每天早上的固定汇报／她的日程里那五分钟 |
| 修仙 | 每日的问安／弟子拜见 |
| 星际 | 每日例行报到 |

#### 写崩的三种方式

1. 只写一次。 重复才有刻度。
2. 让她一上来就免了规矩。戏在免的过程里。
3. 写成他享受下跪。看下面的通用红线。

#### 示例（本库自撰，可直接改写）

> 卯时三刻。天还没全亮。他在廊下站了一会儿才进去。
> 「主君安。」他行礼，膝盖落到垫子上。那垫子是上个月才添的。
> 她「嗯」了一声，手里的折子没放下。
> 第三日，她说：「起来吧。」比前两日快了半句。
> 第七日，他刚要跪，她抬手：「免了。」
> 第十五日，他进门的时候，案边多了一张椅子。她没有抬头，只说了两个字：「坐着。」

## 二 · 位份

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：位份 16.5%（世界设定族）

**骨架**｜他在这个家排第几，是写得出来、贴得上墙、随时能改的一个数。

#### 节拍链

位份现状 → 变动的由头 → 她的两难，给不了，或给了他担 → 文书压了几天 → 定了 → 全府反应 → 他的真实反应

#### 时间轴

由头一出来，她想了一夜，拟文用了一天，盖印前又压了五天。这五天全府都在猜，文书迟迟不下，谁都看得出她在犹豫。他照常过日子，至少面上是这样。公示那天，不到两小时全府的反应就齐了：有人来道贺，有人当场变了脸，也有人按兵不动。他真实的反应，要到当晚一个人待着时才露出来，比公示晚了整整十二个小时。

#### 位份为什么是最好的冲突装置

因为它把感情量化了：

| 特性 | 后果 |
|---|---|
| 可见 | 全府都知道 |
| 可比 | 有人在他之上 |
| 可变 | 升与降都可能 |
| 与待遇挂钩 | 衣料、车驾、进正堂的资格、生病请医的待遇 |
| 与她的意志挂钩 | 但她得看外面脸色 |

她想给，却给不了。要么给了，后果落在他身上。

#### 可用细节

| 类 | 内容 |
|---|---|
| 物质标记 | 穿什么料子 · 坐什么车 · 花多少钱 · 住哪边 |
| 仪式标记 | 请安谁先谁后 · 坐哪儿 · 走路谁让谁 |
| 变动 | 升位分 · 降位分 · 他自己说不干了 |
| 无名分 | 人住在正院，族谱上没他（见 [11 卷第十条](11-初遇与确立.md#十--没有表白)） |
| 他的态度 | 在不在意 · 嘴上说不在意，多半骗人 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他的位份 | 最高（正君） | 无名分 |
| 她想不想给 | 想给但给不了 | 她故意不给（要有理由） |
| 他在不在意 | 明说在意 | 嘴上说不在意 |
| 变动 | 升 | 降（更有戏） |

「降位」够狠，还可以是她不得已才做的。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 册封文书她压了三天 | 我的名字排在第三 |
| 内心 | 给了他，等于把他推到风口 | 说不在意是假的 |
| 好的处理 | 她给了，也扛住了事 | 他认了，说在意 |
| 写崩 | 写成位份高就是爱得多 | 写成他为了位份啥都干 |

文里得有个人把「位份 ≠ 爱的多少」说出口，不然整套制度写着写着就成了宫斗。

#### 写崩的三种方式

1. 把位份当成感情。制度和感情得分开写。
2. 让她轻易破例。破例得付代价。
3. 让他完全不在意。 那是假的。

## 三 · 宫宴上的坐次

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：宫宴 22.1%（宫宴＋请安＋起哄为高频三元组合）

**骨架**｜一桌的座位早排好了，他坐在哪儿，满场的人都盯着。

#### 节拍链

坐次表出来 → 他看到自己的位置 → 走过去那几步 → 席间敬酒与打趣 → 她布了一箸 → 散席车上

#### 时间轴

坐次表提前三天出，宴席三个时辰，最长的是他走过去那几步。这三天各府都在琢磨表上的位置，谁挨着谁，谁被挪了，门道全在里头。席上按敬酒一轮轮算，到第二轮，准有人借着酒劲说些有的没的。她夹的那一筷子，正好卡在众人目光错开的空当，三秒。散席后上车那一刻钟，谁都没说话，却比三个时辰的宴席都实在。

#### 坐次即公告

这场戏用不着谁开口，坐次表已经把话全说了。

| 位置 | 含义 |
|---|---|
| 她身侧 | 最高，且是宣告 |
| 她下首第一位 | 正式的第一位 |
| 与其他侍君同列 | 平等，也就是没有特殊 |
| 末位 | 明确的冷落 |
| 不在席上 | 最狠 |

#### 可用细节

| 类 | 内容 |
|---|---|
| 坐次表 | 谁定的 · 后来改没改过 · 改哪儿了 |
| 现场 | 他走过去那几步 · 全场都在看 |
| 敬酒 | 先敬谁后敬谁 · 谁替他挡酒 |
| 起哄 | 桌上人拿他俩逗乐（见 [14-社交与公开 · 被起哄](14-社交与公开.md#一--被起哄)） |
| 她的动作 | 她给他夹了一筷子菜（见 [01-日常照料 · 一口一口喂](01-日常照料.md#二--一口一口喂)） |
| 散席后 | 车上谁都没说话 |

他走过去那几步要写。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 坐次 | 高 | 低 |
| 谁定的 | 她 | 长辈／礼官（她改不了） |
| 席间 | 平安无事 | 有人当众发难 |
| 她的处理 | 当场改了坐次 | 她忍了，事后处理 |

她当场改坐次，得把后果写出来：改一个位置，就是打了排坐次那人的脸。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看见坐次表时愣了一下 | 我坐第七席 |
| 内心 | 改了就是跟礼官过不去 | 站起来走过去，别低头 |
| 好的处理 | 她记下了，回头收拾了那礼官 | 他步子没乱 |
| 写崩 | 写她当场掀桌 | 写他当众绷不住 |

#### 写崩的三种方式

1. 让她当场翻脸。她忍下，事后再处理。
2. 不写坐次表本身。要写的就是那张纸。
3. 光写宴会热闹。热闹一笔带过，坐次要写细。

## 四 · 她要纳新人

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：选侍 21.9%（选侍＋请安、选侍＋戒指高频同现）

**骨架**｜按制度她能再娶，他根本没资格拦。

#### 节拍链

旨意或族议 → 他领命操办 → 办得比谁都周到 → 破绽（睡得少）→ 进门那晚 → 她私下的交代 → 长期共处开始

#### 时间轴

从接旨到新人进门，他操办了整整一个月。日子拖得越久，破绽越藏不住。头两周还撑得住，账目清清楚楚，礼数也挑不出错。第三周他开始睡不着，头一个发觉的是下人。进门那晚最要紧，他一步没错，该站哪儿站哪儿。三天后，她单独叫他过去，屏退左右，谈了一炷香的工夫。这一炷香里说的那几句话，定了往后几十年这府里是冷是热。

#### 这一族里最狠的一条

现代设定里，吃醋还能说出来（哪怕拐着弯说）。到这里，连吃醋都不合规矩。

| 他能做的 | 他不能做的 |
|---|---|
| 照规矩迎新人进门 | 表达不满 |
| 安排一切 | 拒绝 |
| 做得比谁都好 | 提出异议 |
| 病一场 | 争 |

他能抗议的方式，也就是「做得比谁都好」：新人安顿得挑不出错，让所有人看见他的体面，然后回自己房里去。

#### 可用细节

| 类 | 内容 |
|---|---|
| 事务 | 聘礼怎么下 · 院子怎么分 · 他得出面张罗 |
| 他的表现 | 都照办 · 还办得比平时更上心 |
| 破绽 | 那几天他几乎没怎么睡 · 还给自己揽了件新差事忙个不停 |
| 她的处理 | 她心里明白 · 但没法开口 |
| 那一夜 | 新人进门那晚，他人在哪儿、在干嘛 |

新人进门那晚他在干什么，这场要写足。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她想不想纳 | 被逼的，政治联姻 | 她自己乐意 |
| 他知不知道原因 | 知道她是被逼的 | 完全蒙在鼓里 |
| 他的表现 | 办得漂漂亮亮 | 出过一次岔子 |
| 结局 | 她后来给推了 | 纳了，还得长期处着 |

纳了以后还得长期处着，这一条就从一场戏拉成了一条长线，按 [04-人设原型/03-配对化学反应矩阵](../04-人设原型/03-配对化学反应矩阵.md) 里的 np 结构来写。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她看见他把新人的院子安排在最远的一处 | 这件事我要办得漂亮 |
| 内心 | 他一句话都没说 | 说了就是不懂规矩 |
| 好的处理 | 她私下给了他一个交代 | 他办完之后自己病了一场 |
| 写崩 | 写成他大闹 | 写成他毫无波澜 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 她的应酬对象／联姻式的合作／一个必须维持的关系 |
| 修仙 | 双修伴侣／宗门指派的道侣 |
| 星际 | 政治婚配／基因配对指令 |

#### 写崩的三种方式

1. 让他大闹一场。这不合规矩，还会砸了他自己的位置。
2. 让他毫无波澜。那成了没心没肺。
3. 让她轻轻松松推掉。制度的压力得是真的，别写成摆设。

## 五 · 他的院子

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：位份 16.5% ＋ 请安 26.6%

**骨架**｜他住的院子在哪、多大、修不修，全看他的身份。

#### 节拍链

分院 → 距离与用度 → 她来的频率 → 摆驾或悄悄来 → 他种的那株 → 不再让人守门的那天

#### 时间轴

**到第三年，院子里不再让人守门。** 他种的那株树，两年才长成样子。分院那天是起点，离正院三进，中规中矩。之后修缮的批复下得快了，用度单上添了新项，她从一月来一次变成一旬来一次，这些都是一季一季变的。从「不再让人守门」那天起，院子从「他住的地方」变成了「他们常在的地方」。

#### 空间即位份

写法和 [17-同居与身体日常 · 家的形状](17-同居与身体日常.md#十--家的形状) 一样，只是到这里有制度管着。

| 观察点 | 读作 |
|---|---|
| 离正院多远 | 亲疏 |
| 院子的大小 | 位份 |
| 有几个人伺候 | 用度 |
| 她多久来一次 | 实际的宠 |
| 修不修缮 | 她记不记得 |
| 他院里种了什么 | 他自己的东西 |

院子是按制度分的，只有院里那一株是他自己挑来种的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 距离 | 从正院走到他院子得走多久 |
| 变化 | 他换过院子，升了还是降了 |
| 她的来访 | 白天来还是夜里来 · 是不是摆驾过来，惊动全府 |
| 他的等待 | 见 [02-等待与错过](02-等待与错过.md) 里那些条目，放这儿全用得上 |
| 他的痕迹 | 一株他自己种的 · 一样她给的东西搁在哪儿 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 院子 | 离正院最近 | 最偏 |
| 她来的频率 | 常来 | 很久没来 |
| 来的方式 | 摆驾（全府皆知） | 悄悄来，更亲密，但也更暧昧 |
| 他的态度 | 盼着 | 已经不盼了 |

他已经不盼了，一个细节就写得出来：他不再让人守着门。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现他院里那株已经长得很高了 | 她上次来是四十天前 |
| 好的处理 | 她记得他种的是什么 | 他没让人去打听她去了哪 |
| 写崩 | 写成宅斗和争宠那套 | 写成他天天干等着她来 |

#### 写崩的三种方式

1. 写成争宠。 那是宫斗。
2. 不写他自己的东西。那株是他亲手种的，别漏了。
3. 只写地方，不写时间。要写的是「上次来是四十天前」。

## 六 · 家法

`T` ｜ ⚠️训诫 ｜ 古代女尊 ｜ 语料频次：请安 26.6% ＋ 罚（见 [08 卷](08-规训日常版.md)）

**骨架**｜他犯了规矩，要动家法，这回她没拦。

#### 节拍链

犯了规矩 → 执法定下 → 祠堂或中庭 → 她在场不能言 → 他不看她 → 受完 → 事后她去改规矩或私下补偿

#### 时间轴

从定罚到行刑，中间隔了一整天。这一天谁都能来求情，可没人来，他自己也没求。祠堂里点香时，她从头站到尾，一句话不能说，规矩把她钉在原地，动弹不得。事后分成两条线。她去改规矩，拖了快一个月，改完那天，把新条文直接送到他院里，一个字没多说。他养伤，少说也得十天半个月。

#### 安全框架

本条与 [08-规训日常版](08-规训日常版.md) 共用同一套底线，此处不重复全文，只列要点：

| 项 | 说明 |
|---|---|
| 共识框架 | SSC（安全、理智、双方同意）· RACK（知情且接受风险）· PRICK（自己负责的知情同意） |
| 虚构与现实 | 小说里的家法是**编出来的设定**，活在作者说了算的世界里，**别当现实操作手册** |
| 全员成年 | 出场角色全都成年了 |
| 不写实施细节 | 这条只聊故事怎么写，不给能照搬的操作过程 |

完整框架跟越界判据，放在 [08-规训日常版 · 安全框架](08-规训日常版.md) 和 [十 · 规矩的边界](08-规训日常版.md#十--规矩的边界) 这两处。重度实践的尺度问题，则在 [06-尺度与写法/04-训诫与BDSM专论](../06-尺度与写法/04-训诫与BDSM专论.md) 里单独展开。

#### 「制度在罚」与「她在罚」的区别

这一条和 [08 卷](08-规训日常版.md) 最根本的不同在这里：

| | 她在罚 | 家法在罚 |
|---|---|---|
| 谁决定 | 她 | 规矩 |
| 她能不能免 | 能 | 免了就是坏规矩 |
| 他的对象 | 她 | 制度 |
| 最有戏的点 | 罚完之后 | **她想免而免不了** |

难就难在她想免，却免不了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 祠堂 · 中庭 · 有执法的人在 · 全府旁观 |
| 她的位置 | 她也得在，但不能开口 |
| 他的表现 | 他不看她，怕她难做 |
| 她的动作 | 她攥着扶手的手 |
| 事后 | 见 [08-规训日常版 · 罚完之后](08-规训日常版.md#九--罚完之后) |

他不看她，是怕她难做。挨罚的人反倒在替现场另一个人着想。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁执法 | 她 | 长辈／执事 |
| 她能不能免 | 能但代价大 | 完全不能 |
| 他犯的是什么 | 小错 | 为她扛的错 |
| 事后 | 她私下补偿 | 她公开改了那条规矩（最重） |

她把那条规矩公开改了。免他一次算不了什么，这下以后都没这一条了。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她在场，但话轮不到她说 | 别看她，看了她会难做 |
| 内心 | 免了他，府里的规矩就全松了 | 这是我该受的 |
| 好的处理 | 她事后悄悄把那条规矩改了 | 他受完了，也没怪她 |
| 写崩 | 写成她当众跟规矩对着干 | 写成他挨罚挨得挺享受 |

#### 写崩的三种方式

1. 让她当众废了家法。规矩得真罚，不然没压力。
2. 写成受罚的快感。 见安全框架。
3. 漏掉「她在场却不能说话」。这一点要写。

## 七 · 她改了规矩

`T` ｜ ⚠️训诫 ｜ 古代女尊 ｜ 语料频次：位份 16.5% ＋ 请安 26.6%

**骨架**｜她改了祖上的规矩，代价却不是她一个人扛得住的。

#### 节拍链

一件事逼到眼前 → 她动念 → 他先反对 → 她把私恩写成公义 → 阻力 → 成了或收回 → 多年后成了常态

#### 时间轴

那件事逼到跟前，一天都等不了，可从动念头到真办成，少说一年。他先跳出来反对，两人谈了一整晚。她私下把人情说成公家的大义，花了几个月慢慢铺垫。族老那边死活不松口，族会开了三回。改一条祖上传下来的规矩就是这么磨人，每一步都得耗够时间。又过了些年，府里没人记得这条规矩当初是新改的，她的名字只留在批注里。

#### 这条是这一卷的顶点

前面六条，写的都是在**制度之内**挣扎。这一条写的是去改制度。

改，她有这个权。难的是改完谁付代价：

| 代价 | 落在谁身上 |
|---|---|
| 族中的非议 | 她 |
| 「他恃宠而骄」的评价 | 他 |
| 其他侍君的处境变化 | 别人 |
| 后来者的先例 | 未来 |

**第三行最要紧。** 她为他破一回例，府里每个人的处境都跟着变，其中就有人要吃亏。

#### 可用细节

| 类 | 内容 |
|---|---|
| 改的是什么 | 一件小事，他能进正堂／能旁听／不用跪 |
| 阻力 | 族里长辈 · 管事 · 连别的侍君也拦着 |
| 她的做法 | 先不吭声，直接做 · 要么就正式写进规矩里 |
| 他的反应 | 他头一个跳出来反对，他清楚要付什么代价 |
| 落点 | 过了好些年，这条新规矩大家早习惯了 |

他头一个跳出来反对，因为他不愿让她为他付这个代价。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 改的大小 | 一条小规矩 | 制度性的 |
| 阻力 | 小 | 她被迫收回 |
| 他的态度 | 感激 | 反对 |
| 结果 | 成了 | 没成，但她试过（他记住了） |

「没成，但她试过」，比办成了更打动人。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她写那行字时，手顿了一下 | 她不该为我这样 |
| 内心 | 这话不光说给他听 | 这代价我担不起 |
| 好的处理 | 她把改规矩说成制度的事，不往他身上扯 | 他顶回去，还说了为啥 |
| 写崩 | 写成她为爱扔了规矩 | 写成他心安理得地受了 |

她只说这是制度的问题，不提是为了他，私恩成了公义，代价一下就下来了。

#### 写崩的三种方式

1. 写成为了爱废掉规矩。这样制度就成了道具。
2. 不管别人的代价。破例会伤着第三方。
3. 让他心安理得。他得看见代价。

## 八 · 他上了族谱

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：位份 16.5% ＋ 选侍 21.9%

**骨架**｜一支笔写下一行字，撤不回来。

#### 节拍链

定了 → 祠堂设仪 → 族老在场 → 她提笔 → 那一行字 → 他盯着笔尖 → 出祠堂之后

#### 时间轴

仪式前后折腾了半个时辰，族老坐齐，上香，禀告祖宗，一整套又庄重又磨人。她提笔，蘸墨，写下他的名字，真落笔也就十秒。这十秒他一直盯着笔尖，眼都不敢眨，怕错过了。出祠堂时日头正好，他走路的样子和进去时不同了，身上多了一个会被记住的位置。

#### 为什么这是这个类型最重的一个动作

| 特性 | 说明 |
|---|---|
| 公开 | 全族都能看见 |
| 正式 | 白纸黑字，认账 |
| 不可撤销 | 想反悔？除非被除名，那事更大 |
| 涉及后代 | 孩子归谁家，得说清 |
| 不需要爱 | 走程序，跟感情没关系，也正因为这样，它才沉 |

上族谱本来不带感情也办得成，她偏偏是带着感情办的。

#### 可用细节

| 类 | 内容 |
|---|---|
| 场合 | 祠堂 · 族老在场 · 香烛 · 一支笔 |
| 那一行 | 写的是什么名字（本名还是别的）· 排在谁后面 |
| 他的状态 | 他一直盯着笔尖 · 手在袖子里攥着 |
| 她的动作 | 她自己写的 · 还是族老代笔 |
| 之后 | 他一遍遍翻回那一页看 |

他一遍遍翻回那一页，白纸黑字的东西，他得看上好多回才敢信。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁写 | 她亲笔 | 族老代笔 |
| 排位 | 第一 | 靠后 |
| 阻力 | 无 | 有人反对到最后一刻 |
| 他的反应 | 平静 | 出了祠堂才失态 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她写完，吹了吹墨 | 那一行字 |
| 内心 | 这是我拿得出手的东西 | 我有名字了 |
| 好的处理 | 她亲手写的 | 他出了祠堂才掉眼泪 |
| 写崩 | 搞成一场大场面 | 写成他感激涕零 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 领证／房产证加名／户口本 |
| 修仙 | 道侣录／宗门名册／本命契 |
| 星际 | 正式登记／权限永久绑定 |

#### 写崩的三种方式

1. 写成盛大的仪式。一支笔、一行字就行。
2. 漏掉「不可撤销」。写上去就撤不掉了，这一点要写。
3. 让他感恩戴德。他得到的是承认。

## 九 · 她要出征

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：告别 38.9% ＋ 位份 16.5%

**骨架**｜她出征了，家里交给他守。

#### 节拍链

军令到 → 交印信 → 三件交代 → 她走 → 他当家（有人上门试探）→ 消息断续 → 她回来看到的府

#### 时间轴

她一走，他当家的日子就按来信算。从军令到出发只有三天，这三天交印、交人、交代那三件事，每件花半天。来试探的人专挑消息断了的时候上门，他一个个接下。信一旬一封，断过两旬，再来时字迹潦草。三季过去，她回府那天看到的是：账册齐整，人心安稳，他种在院里的那株开了花。

#### 这条的结构价值

这是 [09-分离与重逢](09-分离与重逢.md) 的女尊版，只是他除了等，还得当家。

| 他要做的 | 难点 |
|---|---|
| 主持府中事务 | 他说话算不算数 |
| 应对上门的人 | 有人借机来摸底 |
| 管住其他人 | 比他小的、比他大的 |
| 递消息 | 坏消息要不要跟她说 |
| 等 | 见 [02-等待与错过](02-等待与错过.md) |

戏主要出在有人趁机上门试探。

#### 可用细节

| 类 | 内容 |
|---|---|
| 出征前 | 她把印信／对牌塞给他 · 这动作一出来，后面全得跟着走 |
| 交接 | 她临走前交代了三件事 |
| 他的处境 | 底下有人不服 · 有人跑来探口风 · 还有人往他屋里送东西 |
| 消息 | 前线的信断了多少天 |
| 她回来时 | 府里乱成什么样了 |

「她把印信交给他」，和 [12-工作与金钱](12-工作与金钱.md) 里的授权是一回事，只是在这里，权握在手里看得见摸得着，也能被人夺走。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 她给不给权 | 全给 | 分给几个人，他只是其中一个 |
| 他撑得住吗 | 撑住了 | 出了岔子 |
| 消息 | 通畅 | 断了三个月 |
| 她回来 | 平安 | 带伤，见 [16 卷第四条](16-危机与保护.md#四--她受伤了) |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她把印信放他手里 | 这个家现在归我管 |
| 内心 | 他扛不扛得住 | 别让她回来看到家里乱糟糟 |
| 好的处理 | 她把权给了，也没留一手 | 他扛住了，也没趁机多要 |
| 写崩 | 写成她全安排好了，人在远处盯着 | 写成他借这机会把权抓死 |

#### 写崩的三种方式

1. 让她在远处遥控一切。交出去，就别再攥着。
2. 让他当家当得一帆风顺。一定会有人来试探。
3. 不写印信这件东西。印信得放进戏里。

## 十 · 制度之外的那一刻

`T` ｜ 无预警 ｜ 古代女尊 ｜ 语料频次：请安 26.6% ＋ 宫宴 22.1%

**骨架**｜就那几分钟，没有旁人，没有规矩，也没有名分。

#### 节拍链

场合封闭，深夜书房·马车·病中 → 规矩松开 → 称呼变了 → 一句不合身份的话 → 外面有动静或他自己起身 → 立刻恢复

#### 时间轴

**随时会被打断，也就几分钟。** 衣冠、语气说换就换，外面一有动静，两个人半秒内各回各位。深夜的书房里，马车里，规矩松开的时候很短：称呼变了，坐姿变了，说了那句不合身份的话，前后不过一炷香。几分钟后一切照旧，两个人心里都清楚，所以这几分钟才值钱。

#### 这条是全卷的收束

前面九条写的都是制度，这一条写制度够不着的地方。

前面越严，这几分钟越难得。

#### 制度之外的场合

| 场合 | 为什么制度够不到 |
|---|---|
| 深夜的书房 | 没人看见 |
| 出行路上的马车里 | 门一关就与世隔绝 |
| 他病着的时候 | 规矩也得给病让路 |
| 一场大雨困住的地方 | 天意弄人 |
| 她卸了钗环之后 | 一身轻松，不用端着了 |
| 只有他们两个的一顿饭 | 没那么多讲究 |

只有他们俩吃的一顿饭，用不着坐次表，也就没了位份。

#### 可用细节

| 类 | 内容 |
|---|---|
| 称呼的变化 | 这几分钟里他喊她什么 |
| 姿势 | 他没站着 · 坐下了 · 或者躺下了 |
| 语气 | 他说了句不像他会说的话 |
| 时间感 | 俩人都明白这几分钟迟早要完 |
| 结束 | 外面有人喊了一声 · 俩人马上装没事 |

收尾是两人立刻恢复原样。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 时长 | 几分钟 | 一整夜 |
| 谁先松 | 她 | 他 |
| 说了什么 | 一句不该说的 | 什么都没说 |
| 结束方式 | 被打断 | 自己结束的（更疼） |

「自己结束的」比「被打断」更疼：没人来叫，是他自己起身，重新行了礼。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他今天坐下了，没站着 | 这几分钟不算数 |
| 内心 | 想让他坐着 | 待会儿还得跪 |
| 好的处理 | 她没说「以后都这样」，她办不到 | 他自己站起来了 |
| 写崩 | 写成她答应废了规矩 | 写成他赖着不想起来 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 现代 | 电梯门关上的那三十秒／车里／下班之后 |
| 修仙 | 结界之内／神识相通的一瞬 |
| 星际 | 关掉记录仪的那段／舷窗前 |

#### 写崩的三种方式

1. 让她许诺废了规矩。她办不到，说出口就是失信。
2. 写得太长。 几分钟的事。
3. 前面的制度写得不够严。这几分钟好看，全靠跟前面那几条对照。
