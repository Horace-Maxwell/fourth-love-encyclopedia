# 位置的流动

> **分级** 分级见各条，分级上限 `M` ｜ 预警 ⚠️反攻（纯攻党慎入，tag 必须前置）｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品；标签数字来自 [10-藏书索引-公开/语料统计](../10-藏书索引-公开/语料统计.md)（下限口径）。文中百分比为编写时实测，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族的共同机关：**位置是两个人的约定，不是两个人的牢房。** 谁能提议换、换完还能不能换回来，比谁在上面更能说明这段关系的结实程度。

## 先把词说清楚

「换」这个字在圈里其实有三种意思，大家经常混着用，吵起来的次数比别的词都多。具体哪三层，拆开讲。词条见 [02-术语百科/01-核心身份与权力动态](../02-术语百科/01-核心身份与权力动态.md)。

| 层 | 流动的是什么 | 对应词 | 对纯攻党 |
|---|---|---|---|
| 权力层 | 谁说了算、谁带节奏 | 主导权换人 · power bottom | 没雷，能看 |
| 方向层·事件 | 这回谁进谁 | 反攻（GB 义：退回男攻女受） | 大雷，tag 必须放前面 |
| 方向层·模式 | 这俩人平时是不是互相来 | 互攻互受，个人属性叫 switch | 大雷，得先打招呼 |

纯攻党：只接受女攻男受单一方向的读者群，见「纯攻纯受」词条。

「⚠️反攻」这个标记，只在涉及方向层的条目里出现。方向学这边，权力流动和商量着来的日常戏都归在「换」「流动」名下，这类默认发生在权力层。GB 里说的「逆推」，在语境里也可能指反攻（[05-易混淆词辨析 ⑩](../02-术语百科/05-易混淆词辨析.md)）。全族共用一条规矩：**GB 的「反攻」指回到男攻女受，和 BL 圈同名词相反**。涉及方向层时，条目前面加个 ⚠️反攻。

「13-07 情境族」里没有「方向事件」这一族，所以各条都不标族级频次。能借的邻族数字，会在条目里写明出处。书级 tag 的方向核对，走 [05-剧情套路/01-经典套路库](../05-剧情套路/01-经典套路库.md) 附录一，那张表管文案层，这一族管场面层怎么写。文案标签统计里，「互攻」60 篇，「反攻」22 篇，「无反攻」8 篇——这些数都是下限口径，只说明谁觉得有必要标，但已经够看出这事在圈里多敏感。

## 一 · 她不想主导的那一天

`T` ｜ 无预警 ｜ 全谱系 ｜ 权力层流动，方向不动

**骨架**｜她累得不想再拿主意了，这晚全交给他管，第二天又把主导权拿回来了。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 白天她在外面栽了跟头，项目黄了、官司输了，脸上一点没露 |
| 2 | 到家，平时使唤人的话卡在嗓子眼，「晚上吃啥」都接不上茬 |
| 3 | 他看出来了，没吭声，自己就把事办了：粥订好，洗澡水放好 |
| 4 | 她随他摆弄，一晚上没支使他一句 |
| 5 | 睡前她说了句「就今晚」，或者干脆啥也没说 |
| 6 | 第二天早上她照常安排周末的活，他照常答应 |
| 7 | 谁也没提昨晚。他把那一晚单独搁心里了 |

#### 时间轴

移交的期限写死在一晚之内，天亮自动失效。期限越明确，她交得越干净。没有期限的移交，她根本不敢开始。

#### 可用细节

| 类 | 内容 |
|---|---|
| 她卸下来的记号 | 换鞋时扶了一下墙 · 头在门上靠三秒再进屋 · 手机反扣在玄关柜上 |
| 他接住的动作 | 不问「怎么了」 · 把她手里的外卖菜单抽走 · 只说「先吃饭」这种短句 · 水温先试好 |
| 移交的边界 | 只交生活上的事，不交关系上的事。真出大事他还是会来问她 |
| 次日归还的记号 | 她早起先列了清单 · 餐桌上又给他夹菜 · 说话回到吩咐的口气 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 说没说破 | 直接讲「今晚你安排」 | 一个字不提，他自己就懂了 |
| 他接得怎么样 | 稳稳接住 | 手忙脚乱，但也没把事推回来 |
| 频率 | 一年一回 | 慢慢有了固定的休息日（通往 [三](#三--提前说好的信号)） |
| 次日 | 照旧还回去 | 她多躺了一天，两人都当没这回事 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 承认「今天我不行」比撑完一整晚还难 | 他做的第一件事，是把她工作群的消息提醒关了 |
| 内心 | 交出去那一下，人反而松了 | 这一晚他不是替补，是正经值班 |
| 好的处理 | 她不认错，也不解释 | 第二天他把主导权还回去，像借了东西用完就还 |
| 写崩 | 写成人设塌了，哭一场 | 写成他借机上位 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她今晚免他问安，让他备好饭食热水，第二天照常升堂理事 |
| 修仙 | 打完大仗灵力耗光，护法的位子让他顶一宿 |
| 星际 | 舰桥连值三班下来，舱里排班表交他管一晚 |

#### 写崩的三种方式

1. 让这一晚把两人的关系重新洗牌。 这条的前提是事后能收场，真把关系翻个底朝天的戏，归 [八](#八--他也想试试)、[九](#九--流动失败) 管。
2. 让他一直问。 当班那个人不会问，他每问一句，就是把决定权又递回她手里。
3. 让她第二天说谢谢。 还回去本身就是谢，说出口反而生分。

## 二 · 他撑起来的那一次

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：醉酒 32.1%、发烧生病 45.7%（13-07 实测，族口径不分谁倒下）

**骨架**｜她烧到三十九度，或者喝断片了，可有个决定不能拖。他做了。完事俩人得把话说清楚，这次到底算啥。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 她倒下的当晚，事全赶一块儿了：医院要签字、她妈来电话、工作上的急件一直响 |
| 2 | 他先试着问她，她那儿问不出个准话 |
| 3 | 他直接定了：挂号、回绝、替她回消息，一件一件办 |
| 4 | 定的时候他心里也在嘀咕：这算是帮忙，还是管太宽 |
| 5 | 她醒了，张嘴先问出了什么事 |
| 6 | 他老老实实全说了，包括自己拿不准的那两处 |
| 7 | 俩人把话摊开聊：这回算怎么回事，下回再碰上怎么办 |

#### 时间轴

空位只留了几个小时，从她倒下到她醒来。**他动手的窗口越窄，越位的嫌疑越小**。拖着不决才是真的失职。

#### 可用细节

| 类 | 内容 |
|---|---|
| 道具 | 体温计 ✓（1.8×，发烧生病族）· 响个不停的她的手机 · 挂号单 · 醒酒的温水 · 他记事项的便签 |
| 他的决定清单 | 替她请假 · 替她回绝一个饭局 · 把她的医保卡递给护士 · 挂断她妈的电话又回拨过去解释 |
| 报账的形态 | 按时间顺序讲 · 替她发的消息原样给她看 · 「这两件我拿不准，先斩后奏了」 |
| 她的反应层次 | 先核对事实 → 再看处理对不对 → 最后才给情绪 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他做得对不对 | 全对 | 错了一件，看她怎么处理那一件 |
| 她的定性 | 「应急，不算越位」 | 「这类事以后你直接定」（授权扩大） |
| 报账时机 | 她一醒就报 | 捂了半天才说，捂就是心虚，另一条戏 |
| 有没有外人 | 没人知道 | 她家人看见了他拍板（叠 [六](#六--外人看不出来) 的对外秩序） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 听报账时发现他的决定和她会做的几乎一样 | 签字那一秒的笔感 |
| 内心 | 空了几个小时，天没塌 | 这不在我的位置上，但这是我的事 |
| 好的处理 | 错的那件她指出来，对的那些她记下来 | 他不邀功，报完账就去热粥 |
| 写崩 | 醒来先发火，把应急审成夺权 | 写成他借机证明自己也能当家 |

#### 写崩的三种方式

1. 把应急写成转折。 他撑住一晚说明关系结实，写成「从此他站起来了」，读者会以为他要反攻，方向直接带偏。
2. 让他不敢做任何决定。 干等她醒的版本没戏可看，成年人守在现场就得拿主意。
3. 省掉报账。 决定可以越位，信息不能私藏，报账那几句才是这条线的定性段。

前接：[30-她的世界 · 她喝醉](30-她的世界.md#四--她喝醉) · [17-同居与身体日常 · 她的生理期](17-同居与身体日常.md#六--她的生理期)

## 三 · 提前说好的信号

`M` ｜ ⚠️反攻（信号可指向方向层） ｜ 全谱系 ｜ 无对应挖掘族

**骨架**｜哪个词、哪个动作代表「今晚换你」。定暗号那晚，和头一回有人用那晚。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 起因：上次想找人全靠猜，结果猜岔了 |
| 2 | 有人说「定个暗号吧」，谁开口都行，但费劲程度不一样 |
| 3 | 挑信号：得平常到外人听不出，又特别到俩人不会漏 |
| 4 | 顺手把规矩说清：只管今晚 · 可以不接 · 别问为啥 |
| 5 | 信号搁那儿，好几周没人碰 |
| 6 | 头一回用：一方发了，另一方愣一下，接住 |
| 7 | 事后谁也没提这茬。但打那以后，它就算数了 |

#### 时间轴

从定下到第一次用，隔得越久越好。**搁置期是信任的发酵期**，当晚就用像预谋，条款的分量也立不起来。

#### 可用细节

| 类 | 内容 |
|---|---|
| 信号的形态 | 一个词「明天喝什么茶」这种家常话 · 一个动作，左手边的杯子挪到右手边 · 一件东西，某条毛巾挂上门把 |
| 借来的骨架 | 「可以不接、不问理由」是从字母圈那套协商规矩里借来的（[06-尺度与写法/04-训诫与BDSM专论](../06-尺度与写法/04-训诫与BDSM专论.md)），只借架子，不碰实际玩法 |
| 配套条款 | 只管今晚 · 天亮就作废 · 连着用两次就得坐下来聊一次 |
| 失败形态 | 发了对方没看见 · 看见了装没看见，遇上这种必须摊开谈 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 信号管哪层 | 只换主导权 | 连方向一起换，⚠️反攻，书级 tag 必须前置 |
| 谁能发 | 只有她能发 | 两个人都能发，深浅由对称性决定 |
| 显隐 | 两人明定的正式暗号 | 从没说破但都懂的默契，前者靠制度，后者靠运气 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 定规矩时她非加上一句「可以不接」 | 那个词他嘴里滚了几十遍才头一回说出口 |
| 内心 | 给他开口的资格，比给他一晚上还难 | 拒绝不会挨罚，这条他翻来覆去问了好几遍 |
| 好的处理 | 他头一回递话，她接得一点没犹豫 | 他也接过她的话头，两边都递过才算数 |
| 写崩 | 信号成了她单方面摁的开关 | 写成他得了新鲜玩意儿天天摆弄 |

#### 写崩的三种方式

1. 商量一下就变成了走个过场，搁置期一设，条款一条都立不住，信号一定就用。
2. 这一族就塌回单向管束了，不能拒绝的信号那就是命令，别写「可以不接」。
3. 日常伪装是两人世界的墙，外人看出破绽就得出险，识破暗号的戏归 [六](#六--外人看不出来) 管。

## 四 · 强势的受

`M` ｜ 无预警 ｜ 全谱系 ｜ AO3 `Power Bottom` 23,756 篇（02-01 词条转引）

**骨架**｜他躺着就把事办了，屁股都没挪一下。看着像躺赢，其实离反攻还差着十万八千里。

在 [02-术语百科/01-核心身份与权力动态](../02-术语百科/01-核心身份与权力动态.md) 里，power bottom 和 topping from the bottom 各自都有词条，指的是同一种现象：名义上在下面，实际节奏全由ta掌控。中文攻受这套体系里这块基本是空的，谁先写谁占，目前没有对应的现成说法。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 白天她说了算，晚上什么时候停、怎么停，都是他定 |
| 2 | 他说话从不啰嗦：「慢点」「灯关了」「今天就到这儿」 |
| 3 | 她也听话，而且发现自己挺乐意听 |
| 4 | 有天晚上她突然反应过来，没忍住笑了 |
| 5 | 这事他俩要么摊开聊一次，要么一辈子不提，都行 |
| 6 | 第二天照样：外人面前他让着她，关了门她让着他 |

#### 时间轴

无单场时间。这条靠反差的两个时段轮流上镜：白天一格，夜里一格，格与格之间不解释。

#### 可用细节

与反攻的分界线，三问定案：

| 判据 | power bottom | 反攻 |
|---|---|---|
| 位置 | 不动，他仍是受 | 反转，退回男攻女受 |
| 他主导的 | 节奏与尺度 | 方向本身 |
| tag 义务 | 无需前置 | 必须前置 |

| 类 | 内容 |
|---|---|
| 他的指令句 | 全是短命令，不喊名字，不解释 · 声音比白天轻 |
| 她的体验 | 有人接管的这几十分钟 · 难得不用自己拿主意 |
| 语域差 | topping from the bottom 在字母圈算减分（没真交权），搁 GB 里是加分项（02-01 词条） |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 挑明没有 | 挑明了，俩人拿这开玩笑 | 一直没捅破 |
| 范围 | 就床上那点事 | 连点菜选片都绕不开（再往前就成 [六](#六--外人看不出来) 那两套规矩了） |
| 她的态度 | 挺享受的 | 有时候故意抢回主动权，抢着抢着反而更有意思 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 发现自己正在听令的那一秒 | 白天低头、夜里抬眼的切换 |
| 内心 | 位置是我的，节奏给他，这买卖不亏 | 我没想抢她的位置，就要这段日子 |
| 好的处理 | 她配合，但随时能喊停 | 指令都短，也总留着她不答应的余地 |
| 写崩 | 写成她被拿捏 | 写成床上暴君 |

#### 写崩的三种方式

1. 把节奏主导写成方向反转。方向学纪律在这条上最容易失守，位置一动，这条就成了 [五](#五--一次反攻之后)。
2. 指令写长。一长就成了说教，权力味全散。
3. 白天的顺从写成演的。白天真顺从、夜里真主导，两头都真才成立。一头是假的就塌成心机戏。

## 五 · 一次反攻之后

`M` ｜ ⚠️反攻（写的就是那次之后） ｜ 全谱系 ｜ 标签口径：「反攻」22 篇（文案标签统计，下限）

**骨架**｜那一夜位置真换了。第二天早饭桌上，这事才算定了性，是事故，是礼物，还是新日子的头一天。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 前夜收尾：谁先睡着，谁盯着天花板到两点 |
| 2 | 早晨第一个动作：谁先起、谁做的早餐，做饭权是这张桌上的第一句话 |
| 3 | 第一句台词绕开正题：「粥要不要加蛋」 |
| 4 | 「昨晚」两个字，看谁先说出口 |
| 5 | 三种定性当场选一种：事故（下不为例）、礼物（偶尔为之）、常态的开端 |
| 6 | 定性说完，各自上班，关门的力度和平时一样 |
| 7 | 晚上回家，有人把这事又提了一次，或者谁都没提，定性开始生效 |

#### 时间轴

全条压在一顿早餐的长度里。**粥凉之前要有一个说法**。拖过这顿饭，「不提」自己会长成定性，而且是最坏的那种。

#### 可用细节

| 类 | 内容 |
|---|---|
| 桌上的物证 | 两副碗筷摆位和平时一样 · 她先坐了他惯坐的那把椅子，试探 · 粥、蛋、豆浆这类最日常的菜单 |
| 三种定性的台词形态 | 「下不为例」加一筷子菜，事故 · 「偶尔也行」加对视一笑，礼物 · 「以后看情况」加三秒沉默，常态开端，最重 |
| 绕圈的话题 | 天气 · 楼下的装修 · 谁去缴物业费 |
| 收尾动作 | 那天抢着洗碗的人，心里没底 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 定性 | 事故 ／ 礼物 | 新常态，后面整个走向都不一样，书的标签也得改 |
| 谁先提 | 她先提，这事她说了算 | 他先提，他不想拖着 |
| 都不提 | 先放着，慢慢变味，通向 [九](#九--流动失败) | 放着放着成了默契，半年后才又有第二次 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她发现自己不后悔，这个发现比那一夜本身更大 | 他等那句定性，等得比昨夜任何时刻都紧张 |
| 内心 | 位置让出去一晚，天没塌，可身份呢 | 我要的从来就一件事：把话说清楚 |
| 好的处理 | 定性她给得干脆，不让他悬着 | 定性是什么他都接得住 |
| 写崩 | 一早冷脸，把那夜审成他的罪 | 得寸进尺，当场开始谈下一次 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 第二天早上请安，嬷嬷照常摆饭，她说了句「昨晚的事，府里别记了」，这事就算翻篇了 |
| 修仙 | 双修的路子换了一回，第二天论道谁都不提这茬，后来她递了杯茶，才算缓过来 |
| 星际 | 舱里的日志她亲手改了权限：那晚的记录，就他俩能看 |

#### 写崩的三种方式

1. 02-01 反攻词条给过两条路：要么删掉，要么顶格标注写成转折点。夹在中间不标，风险最大。文案标签跟不上关系变化，最容易翻车。
2. 早餐桌底下吵起来，这条的劲儿全在暗处。真掀了桌，反而啥也没了。
3. 第二天得给个交代，老吊着不写，等于给后文埋雷。那一夜的细节不必急着写实，含糊带过可以。

## 七 · 精神四爱的日常

`T` ｜ 无预警（文案标注义务见正文） ｜ 全谱系 ｜ 无对应挖掘族

**骨架**｜纯气质上的女攻男受，不碰身体。「直攻直受」这俩词，搁牙刷和账单上就特别有那味儿。

精神四爱不带 pegging，纯情感和关系层面的女攻男受，跟直攻直受其实是一回事。俩名字一个带贬义一个中性，你选哪个词，基本就是在表态。[02-术语百科/01-核心身份与权力动态](../02-术语百科/01-核心身份与权力动态.md)，[05-易混淆词辨析 ⑨](../02-术语百科/05-易混淆词辨析.md)

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 晨间：她定今天干啥，他应一声“好”，这声“好”听着就踏实 |
| 2 | 通勤：车她开，路线他递，一个管开，一个管看，各干各的 |
| 3 | 晚间分歧：他有意见就说，说了归说，最后拿主意的还是她 |
| 4 | 床笫一拍只需一句：方向传统，气质纹丝不动，镜头停在门口 |
| 5 | 深夜：他先躺下，最后检查门锁的是她 |
| 6 | 第三人问“你们谁说了算”，两人同时指她，同时笑 |

#### 时间轴

无单场时间，按一整天铺。主导权在每个时段的落点连成一条不断的线，断在哪一格，哪一格就是失真。

#### 可用细节

| 类 | 内容 |
|---|---|
| 气质落地的格子 | 遥控器谁拿着 · 点外卖谁勾单 · 吵架谁先喊停 · 家庭群里谁出头说话 |
| 床笫的写法边界 | 虚写最稳。实写就得让画面跟人设对得上，路子见 [06-尺度与写法/03-情欲场景结构](../06-尺度与写法/03-情欲场景结构.md) |
| 文案义务 | 中立写法就是「不含生理逆转的 GB」，不标出来被读者撞破，圈里直接算「诈骗」（02-01 词条引） |
| 两派地基 | 大陆主流不认这套，台湾那边宽松，两边吵什么看 02-01。写的时候其实就一条：标明白 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 床笫方向的处理 | 全书不写 | 实写传统方向，或全书没感情线，三版都行 |
| 「直攻直受」的成色 | 天生就这样 | 两人处出来的，处的过程就是整本书 |
| 圈层态度进不进文 | 角色不知道圈里吵啥 | 角色自己就在圈里（叠 [44-圈层与同好](44-圈层与同好.md)） |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 主导是气质，她从没怀疑过 | 那声「好」是选择，他每天重新选一次 |
| 内心 | 拍板有程序：先听他的异议，再落她的锤 | 位置传统，腰杆不弯，顺从和男受在他身上能共存 |
| 好的处理 | 异议被采纳的那几次要写足 | 他的反对越有分量，他的「好」越值钱 |
| 写崩 | 写成事事碾压的一言堂 | 写成没意见的应声虫 |

#### 写崩的三种方式

1. 纯攻读者和精神四爱的读者本来就不该混在一起，tag不改，写到一半突然来生理逆转，两边都得罪。
2. 选了这设定，就别一提「精神」就阴阳怪气。你既然走了四爱的路，就得当正经四爱写，自己先看低自己，整本书的基调就垮了。
3. 床戏最忌写一半藏一半，要么就虚写到底，露半张牌，读者脑子里补出来的永远是最糟的那半张。

#### 可串接

## 八 · 他也想试试

`M` ｜ ⚠️反攻 ｜ 全谱系 ｜ 无对应挖掘族

**骨架**｜他开口那晚，把话说透了。她第一反应是算账，试或不试，怎么都说得通。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 这话他憋了好几周，三回到嘴边又咽回去 |
| 2 | 挑时候：不在床上说，趁洗碗时提，手里有活儿，眼睛有地方搁 |
| 3 | 开口：一句练了无数遍的话，真说出来还是走了样 |
| 4 | 冷场：她接话前，俩人都觉得那几秒特别长 |
| 5 | 她先不急着接，确认一下没听岔，「你是说……」，再往下聊 |
| 6 | 掰扯清楚：他要的是哪一层，就一回还是长期，界限一条条捋明白 |
| 7 | 结果就三种：试（通往 [五](#五--一次反攻之后)）· 不试 · 「让我想想」 |
| 8 | 不试那版：她说了不行，他答了成。这话一出口，俩人就不一样了 |

#### 时间轴

从起念到开口以周计，从开口到答复以天计。**答得太快，答什么都显得没掂出这句话的重量。**

#### 可用细节

| 类 | 内容 |
|---|---|
| 开口的场地 | 洗碗池边 · 等红灯的马路牙子前 · 关了灯之后的黑里，黑咕隆咚最好说话 |
| 他的措辞样本 | 「有件事想跟你商量」（最稳）· 「如果我说……你会不会」（试探型）· 拿一篇文当话头，风险是像在点她看过同款 |
| 她的反应分档 | 接住：点头，接着聊 · 不答应但没摔脸：「不试，但谢谢你肯说」 · 愣住：当晚没接话，第二天她自个儿又提起来 |
| 成本清单 | 他豁出去的是「乖」这个人设 · 她掂量的是自己几斤几两，接不接得住 · 两边都搭进去的：话一挑明，就装不回不知道了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 他要的层 | 只想说了算一晚（权力那层，[一](#一--她不想主导的那一天) 反过来） | 奔着过日子去的（⚠️反攻，tag 先标上） |
| 结果 | 试 ／ 吊着 | 不试，三条路都走得通，写砸的只有不谈 |
| 她的私心 | 她其实也想知道啥滋味 | 她是真不想要，两版拒绝的话完全两码事 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她先反应过来这话他练了多少遍，光这点就比话本身更戳她 | 话到嘴边，最后一秒他又差点咽回去 |
| 内心 | 答应也好，拒绝也好，最难的是接住这句话 | 开口的代价扛得住，扛不住的是这辈子都不说 |
| 好的处理 | 拒绝时，她把「不行」和「你没做错」分开讲明白 | 被拒了也不躲，第二天照常来往，说明这段关系经得起一次「不」 |
| 写崩 | 笑话他，或者转头拿这事当谈资 | 低声下气地试探，然后当场崩了 |

#### 写崩的三种方式

1. 静默、确认、对边界，一步都不能跳。跳了，协商就成了开关，「不」之后的日常必须照旧。
2. 拒绝写成关系降级，后文怎么圆都亏。夸张的震惊等于把他的勇气定价成鲁莽，拒绝安放不好，这条就从流动跌进危机。
3. 她的反应写成惊悚，一提就成。

## 九 · 流动失败

`M` ｜ ⚠️反攻 ｜ 全谱系 ｜ 无对应挖掘族

**骨架**｜换了个位置，俩人都别扭。认了，又换回来，也算想明白了。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 换了（接 [五](#五--一次反攻之后) 或 [八](#八--他也想试试)），过程没出岔子 |
| 2 | 别扭不在当场，是之后几天的小事：他不敢看她，她叫人干活时多了句「麻烦」 |
| 3 | 两人都以为只有自己别扭，都在装「没事啊」 |
| 4 | 戳破：她问「今晚还……吗」时，自己都听出声音不对劲 |
| 5 | 认了：先说「要不就算了」的人，胆子跟当初提的人一样大 |
| 6 | 换回来：当晚一切照旧，两人在熟悉的位置上同时松口气 |
| 7 | 事后谁总结都行：「试过了，不行」 |

#### 时间轴

别扭有潜伏期，三天到两周。**当场反悔是事故，潜伏期后的承认才是成熟**。这条的年轮就长在潜伏期里。

#### 可用细节

| 类 | 内容 |
|---|---|
| 别扭的迹象 | 又开始说「谢谢」「麻烦你了」 · 洗漱故意错开时间 · 命令句变成问句 |
| 演「挺好的」的破绽 | 「挺好的」说三遍以上 · 没人问就自己说「我觉得不错」 |
| 承认的措辞 | 「要不还是算了」 · 「我更喜欢原来的」 · 最狠的一句：「你也别扭吧」，把对方也拉下水 |
| 归位的仪式 | 那晚谁先伸手的 · 回到老地方说的第一句话，俩人都笑了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先承认 | 提议的那个人，体面加倍 | 另一个人，体贴加倍。同时开口则收成喜剧 |
| 失败的层 | 方向层试了不合适（⚠️反攻） | 权力层移交也会失败：她躺不平，一晚上遥控他的每个安排 |
| 之后 | 一次封存，偶尔当梗 | 留一条缝，半年后再试，是另一条新戏 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她开始惦记当初让出去的那点东西 | 归位那晚他松口气的样子骗不了人 |
| 内心 | 承认自己不行和承认自己想要，一样难开口 | 不合适跟不爱是两码事，这点他比她先看明白 |
| 好的处理 | 说「换回来」时不觉得亏欠，就是选了个路 | 他把这事说成俩人一块儿试，张口闭口都是「我们」 |
| 写崩 | 一直憋着，最后炸了，新账旧账一块儿算 | 面子碎了一地，往后啥要求都不再提 |

#### 写崩的三种方式

1. 别扭的尺寸是「谢谢」二字的回流，写成冷战就过载了。该收的时候收，别让情绪漫过去。
2. 失败没人担责，一旦追责，实验就成了事故，往后谁都不敢再提任何事。所以先找一个罪人，把锅落定。
3. 封存要有封条，「试过了」必须说出口。换回来之后闭口不提，不然它会以疙瘩的形态永久留在文里。

## 十 · 位置这个词不够用

`T` ｜ 无预警 ｜ 全谱系 ｜ 无对应挖掘族

**骨架**｜攻受这俩字早就不够用了，他俩自己造词，谁家起的名字，就能看出这关系处到啥年头了。

#### 节拍链

| 拍 | 内容 |
|---|---|
| 1 | 一次聊天卡住：想说上周谁主动、谁接着、谁换着来，发现哪个说法都不对劲 |
| 2 | 一个人随口编了个词，拿家里东西或俩人旧事打比方，越土越好使 |
| 3 | 另一个人乐了，乐完一想，嘿，还真是这么回事 |
| 4 | 词就这么用开了：「今晚谁掌勺」这种暗话，慢慢替掉了平时那些正经说法 |
| 5 | 词开始长新芽，一个词带出一串，外人听他们说话跟听天书似的 |
| 6 | 某天回头一琢磨，攻受这俩老词，在他们家早没人提了 |

#### 时间轴

无单场，以月计。词从诞生到把公共词送退休，中间隔着几十次日用，每次日用都是一次续约。

#### 可用细节

| 类 | 内容 |
|---|---|
| 造词的原料 | 厨房词（掌勺／配菜）· 驾驶词（谁开车／谁看路）· 游戏词（P1／P2）· 没道理的音节，最私密的一档 |
| 词的语法 | 能进问句：「今晚谁掌勺？」 · 能当形容：「你今天很 P2」 · 得能接住拒绝：「今晚都不」 |
| 退休的公共词 | 攻受 · 上下 · 主导顺从，退休只在自己家里算数，发文时还得拿出来用，tag 是写给外人看的 |
| 命名权的分布 | 词谁起的没那么要紧，两个人都在用才算数。词典得两个人一起编 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 词的来源 | 一次事故的纪念（[九](#九--流动失败) 栽了跟头才长出来的词） | 甜到冒泡时攒下的暗号 |
| 外露度 | 只在自己人跟前说 | 当众漏出一个，外人听不懂，俩人也不慌（对照 [六](#六--外人看不出来)） |
| 词典规模 | 一个词能顶十年用 | 一整套黑话。话说得多不代表心里有数，有时候一个词反而更戳人 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 新词说出口比「我攻你受」顺嘴，顺嘴才说明对路 | 他造的词被她哪天用上了，这事就成了 |
| 内心 | 公共词是圈里发的工服，这个词是他亲手做的 | 词是我提的，意思是我们俩处出来的 |
| 好的处理 | 对外发文、跟闺蜜说话还用公共词，哪个词给谁心里门儿清 | 他用这个词拒过一回人，词从此才算立住了 |
| 写崩 | 把私房词又整成一套上下级 | 词成了只有他一个人当回事的规矩 |

#### 写崩的三种方式

1. 私有词一造就完美。
词要磨，第一版肯定不好使，改过几遍的词才像人话。

2. 跟读者反复解释词义。
解释一回就够，往后靠上下文自己体会。解释多了这词就废了。

3. 用私有词躲掉公共标注。
你自己家里词典编得再全，发出去的时候该打的 tag 一个都别省，两套东西各管各的。
