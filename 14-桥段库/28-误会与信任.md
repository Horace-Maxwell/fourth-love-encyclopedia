# 误会与信任

> **分级** 分级见各条，分级上限 `T` ｜ 预警 无 ｜ 亚型 全谱系通用
> 频次来源：[13-语料挖掘/07-桥段分布](../13-语料挖掘/07-桥段分布.md)，基数 2,894 部独立作品。文中百分比为编写时实测；节拍族会随挖掘器扩充小幅变动，当前权威数字以 13-07 为准（`run.py mine` 重跑更新）
> 这一族写误会：看见一半、听见一半、发错消息，写到解开以后还留下的话。合不合格只看一条：两边做的都是合理的事，误会出在各自看到的不一样，谁都没犯蠢。

## 为什么单开一卷写误会

「靠误会推动」在「写崩的三种方式」那几卷里一再被拿出来当反面教材。读者骂误会狗血，作者照写，读者也照看。翻数据看，「误会」这一族出现在 **35.1%** 的作品窗口里，在全部情境族里排第六。误会本身没错，出问题的是写法。

狗血的误会和合格的误会怎么分：

| | 狗血误会 | 合格误会 |
|---|---|---|
| 起因 | 有人突然犯蠢，不看、不问、不听 | 两边都按自己知道的情况，做了正常的判断 |
| 维持 | 靠巧合堆，一要解释就被打断 | 靠两个人各自的毛病撑着，他不敢问，她懒得辩 |
| 解开 | 撞大运，刚好听到了真相 | 得有一个人先低头，拉下脸去问清楚 |
| 解开后 | 当没发生过 | 后劲还在，误会那阵说过的狠话也还在 |

这一卷的十条都照右边那列写。

| 节拍族 | 占比 |
|---|---:|
| 误会 | 35.1% |
| 闺蜜 | 11.3% |
| 失联 | 23.0% |

## 一 · 看见的那一半

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：误会 35.1%

**骨架**｜她撞见他和一个陌生女人从酒店里出来，她看到的每个画面都是真的。

#### 节拍链

撞见画面完整，信息残缺 → 站在原地没上前 → 各自回家 → 她的反刍 → 他毫无察觉的日常 → 她的求证或发酵 → 揭晓

#### 时间轴

她不对劲，他其实早就察觉了。撞见到求证隔了多久，伤就有多深。当天就问，只是个插曲。憋上一周，就裂了缝，到那时两人吵的已经是「你为什么不问我」，误会本身反倒没人提了。

#### 「看见」的合理性设计

她没上前问，当场得有说得过去的理由，不能靠降智：

| 她没问的理由 | 合理性 |
|---|---|
| 她在马路对面，赶着去开会 | 物理限制 |
| 对方挽了他手臂，她愣住的三秒里人已进了电梯 | 时机错过 |
| 她的第一反应是「我不该查岗」——她的骄傲不允许当场对质 | 性格使然，这种写得最高明 |

**真相侧同样要合理**。那人可以是他表姐、客户，或者来求他办事的旧识。揭晓时要让读者服气「确实只能这样」，别让人看出是编不下去了硬圆回来。

#### 可用细节

| 类 | 内容 |
|---|---|
| 画面 | 他替她挡了下旋转门 · 顺手得像本能，他对谁都这样，她以前没在意，今天看着有点扎眼 |
| 反刍 | 那三秒在她脑子里反复放，每放一遍就多一个细节，多出来的有一半是她自己补的 |
| 她的反常 | 当晚对他冷了一点 · 他问「怎么了」，她说「没事」，头一回用他的话堵他（接 [04-委屈与破防 · 憋着不说](04-委屈与破防.md#二--憋着不说)的镜像） |
| 求证 | 最后她干脆直接问，挑吃饭时开口，装作随口闲聊 |

惯会让别人坦白的人，自己憋着反倒更狼狈。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 看见的人 | 她 | 他看见她跟旧识吃饭，反应完全两样，他没冷下来，反倒加倍体贴，体贴得她心里发毛 |
| 时长 | 当天问清楚 | 憋成心病 |
| 真相 | 完全无辜 | 半灰：旧识是真来纠缠了，他也真没提，为什么没提，就引出了下一轮 |
| 解开方式 | 她直接问 | 还没等她撞破，他先说了，他早觉出她不对劲，顺着摸到了那天的事 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 她拿「我不该查岗」管住自己 | 她冷下来的那半度，他当晚就察觉了 |
| 内心 | 我看见的是真的。可「真的」不等于「全部」。 | 他加倍对她好，是在一处处试，看到底哪里出了错 |
| 好的处理 | 她问的时候只讲看到的画面，自己脑补的那部分不说 | 他答完又补了一句「你当时怎么不叫我」，听得出遗憾，听不出责备 |
| 写崩 | 写成她连环脑补三章 | 写成他解释被打断七次 |

「解释被打断七次」，一看就是狗血误会，这种打断一次都别写。

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她撞见他在茶楼跟个姑娘说话，那是替他娘捎话的亲戚。那天晚上她多批了一个时辰的折子 |
| 修仙 | 她神识一扫，他正和老同门待在一间屋里，后半间被结界遮着，里头还坐着三个长老 |
| 星际 | 监控 ✓ 拍到他进了别人的舱，画面到舱门就断了。完整记录要用她的权限才调得出来，她对着那个页面看了十分钟，没点 |

「她盯着权限页面十分钟没按」，到了星际版，「查不查」真成了一个按钮。她最后没按，选了当面问。

#### 写崩的三种方式

1. 她当场扭头就走，连夜冷战。 她骄傲，不问，可也不躲。
2. 真相得靠别人捅破。 要求证，她得自己花功夫，自己拉下脸。
3. 说开了就好了。 「你当时怎么不叫我」这类话，要过几天再说出来，才有分量。

## 二 · 听见的那一半

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：误会 35.1%

**骨架**｜他从门口经过，听见她在电话里说，跟他在一起本来就不是因为喜欢。后半句他没听清。

#### 节拍链

无意路过 → 那半句钻进耳朵 → 僵在原地 → 走开（没听下半句）→ 独自消化 → 行为变形 → 被她察觉 → 对质与还原

#### 时间轴

头一天他睡不着。第三天开始翻旧事给自己找证据，心里一遍遍转着「所以那次她……原来是这个意思」。到第七天，三年的相处他全按那半句话重新过了一遍。

#### 断章的技术规格

**那半句必须真的能歪**：

| 完整句 | 被听到的一半 |
|---|---|
| 「跟他在一起本来就不是因为喜欢——是因为离不开。喜欢太轻了。」 | 前半 |
| 「我妈问我图他什么。我说不图什么——」（下半句：「图什么啊，人又不是投资。」） | 前半 |
| 「说实话我也后悔过——」（下半句：「后悔没早点遇到。」） | 前半 |

**下半句要比上半句重一个量级**，揭晓的时候，读者挨的那一下跟他挨的才是同一下。

#### 可用细节

| 类 | 内容 |
|---|---|
| 听见现场 | 门缝 · 风把声音从阳台送进来 · 她开着免提在厨房来回走 |
| 走开 | 他退回去时脚步放得极轻，轻得像做贼，连他自己都嫌太轻 |
| 行为变形 | 他不吵不问，开始“懂事”：早上不再赖着多睡十分钟，也不再说想吃什么，**懂事就是他流血的方式**（接 [04-委屈与破防 · 我是不是不够好](04-委屈与破防.md#九--我是不是不够好)） |
| 察觉 | 他一“懂事”，她比他吵闹时警觉十倍 |
| 还原 | 她把他听到的那句话原样说给他听，说到后半句，他别过了头 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁听见 | 他 | 她听见他跟兄弟说“累”，没听见后半句“但她值得”。她那边就变了味，对他客客气气的，像在躲他 |
| 变形时长 | 一周 | 一个月，她出差回来，他懂事得像换了个人 |
| 还原方式 | 把整句话再说一遍 | 请电话那头的人出来作证，闺蜜也好，他兄弟也好，旁人说的比当事人解释更让人信 |
| 残留 | 他别过头去就算过去了 | 那前半句他偶尔还会想起来，她知道，所以隔一阵就把后半句再说给他听 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「懂事」让人心里一紧 | 退回去时那极轻的脚步 |
| 内心 | 他这么乖，怕是哪儿在流血 | 原来如此。原来一直如此。半句话就能让人把「原来」说得这么顺 |
| 好的处理 | 她还原的时候不怪他偷听，先认那半句确实难听 | 他变了样，看得出来，可他没拿这个去惩罚她 |
| 写崩 | 写成她一个月都没察觉 | 写成他质问摔门 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他在廊下听见她和母亲商议亲事，只听到前半段，后半句「儿要的就是他」隔着一进院子飘了过来 |
| 修仙 | 传音入密他只截到一丝，要听全只能等她再传一遍。她真又传了一遍，一字不落 |
| 星际 | 频道串线，他听到半截通话。完整录音就在服务器上，他有权限调，没调，等她亲口说 |

星际版这条跟上一条一样，真相伸手就拿得到，两个人都没绕开对方去拿，都等对方亲口说。

#### 写崩的三种方式

1. 半句没写歪。 上下半句差得不够，这条就立不住。
2. 变形写成作妖了。 他是懂事地流着血，没闹。
3. 还原完就不管了。 下半句要拆开，往后再一点点补。

## 三 · 发错的消息

`T` ｜ 无预警 ｜ 现代都市 ｜ 语料频次：误会 35.1% ＋ 社交网 33.9%

**骨架**｜吐槽她的那条消息，他手一滑发进了她的对话框，想撤回已经晚了。

#### 节拍链

吐槽输入（发给兄弟的）→ 手滑 → 已发送 → 撤回超时 → 已读 → 长达四分钟的对话框沉默 → 她的回复 → 处理

#### 时间轴

**「对方已读」到她回消息那四分钟**里，他写了七版解释，没有一版发出去。

#### 错发内容的分级

| 内容 | 等级 | 处理难度 |
|---|---|---|
| 「她今天又点香菜，服了」 | 青铜 | 一个表情包就能救 |
| 「她最近好凶，怕了」 | 白银 | 得正经谈一次，这句是真话 |
| 「有时候觉得好累」 | 黄金 | 这是他的真实状况，发错了就等于提前坦白了（接 [04-委屈与破防 · 憋着不说](04-委屈与破防.md#二--憋着不说)的意外泄洪） |
| 给前任的未发旧草稿手滑发出 | 王者 | 内容本来没什么，可「存着草稿」这件事本身就成了问题 |

**黄金级的写法**：发错的那句真话，他从不敢当面说，憋着的就借这次事故泄了出来。

#### 可用细节

| 类 | 内容 |
|---|---|
| 事故现场 | 撤回键按慢了 · 手机 ✓ 差点摔了 · 他腾地一下从工位站起来 |
| 四分钟 | 「对方正在输入」亮了又灭，来回三次，她那边也在斟酌怎么说 |
| 她的回复 | 青铜级她甩了个「呵」 · 黄金级她就一句：「下班说。当面。」 |
| 当面 | 「累是真的累？」「……有时候吧。」「说这事不用靠发错消息。」她顺着这次事故，给他递了个台阶 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁发错 | 他 | 她手滑把跟闺蜜的聊天记录发给了他，里面全是对他这个人的冷静分析，理性得吓人。后来她补发了一段感性的话，算是道歉 |
| 等级 | 青铜（喜剧向） | 黄金（正剧向） |
| 她的处理 | 当面谈 | 她装没看见，三天后他憋不住自己招了，她说「我等你主动提呢」 |
| 后续 | 有了发泄出口 | 落下个后遗症，他从此发消息前都要检查三遍，写出来挺好笑 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「下班聊。当面。」那五个字 | 撤回失败的灰色按钮 |
| 内心 | 「好累」两个字我看了四分钟 | 完了。不对——也许这样也好。不对，完了。 |
| 好的处理 | 她气的是他「不敢当面说」，他说了什么她倒不计较 | 当面再说一遍时，他没把话说软 |
| 写崩 | 写成她翻脸冷战 | 写成撤回成功，当啥也没发生 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 他写给友人的信装错了封，她拆开看完，照原样封好，附上一张字条：「字不错。话也是。」 |
| 修仙 | 传音符认错了主，那缕吐槽到了她手里，她回了一缕：「累就说。」 |
| 星际 | 频道选错了，吐槽发进了两人的加密频道，系统还贴心地给标了「重要」 |

#### 写崩的三种方式

1. 撤回成功。 事故得真出了，后面那条路才打得开。
2. 内容真的恶毒。 吐槽只能落在「真但不毒」这一小段里。
3. 四分钟略过。 那七版没发出去的解释要写出来。

## 四 · 不解释的人

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：误会 35.1%

**骨架**｜她被冤枉了，大家都等着她开口解释，她偏不说。

#### 节拍链

指控出现，外头有人说，或者他自己起了疑 → 她不肯自辩 →「你不解释就是默认」→ 她还是不解释 → 僵局 → 他要么信，要么自己去查 → 真相自己浮出来 → 她那句解释才姗姗来迟

#### 时间轴

按天算。她不出声多久，他就被晾多久。她稳得住，就看他无凭无据的信任能撑几天。

#### 她不解释的三层理由

| 层 | 内容 |
|---|---|
| 表层 | 骄傲：「解释就输了」，她一向这么做事，对客户、对对手都一样 |
| 中层 | 试探：她就想看看，他信她这个人，还是信那些证据 |
| 深层 | 害怕：要是解释了他还不信，就真没有退路了，不解释，好歹给自己留着最后一步 |

**深层要到最后才露**。她不解释不全是因为强硬，也有一小块是不敢。

#### 可用细节

| 类 | 内容 |
|---|---|
| 指控 | 职场构陷（挪用·泄密）· 或私人的：旧照片 ✓ 被翻出，配了个故事 |
| 她的姿态 | 照常上班照常吃饭 · 唯一的破绽是烟灰缸／茶杯的消耗量 |
| 他的煎熬 | 证据全都指向她「有问题」· 他能拿来信她的，只有三年的相处 |
| 他的选择 | 他没催她解释，转身去把真相挖了出来，**信她就自己动手去证，不干等** |
| 迟到的说明 | 事情了结以后她只说了一句：「你没问我第二遍。」她能给的认可，这已经是最高的了 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 不解释的人 | 她 | 他被人传闲话，一声不吭。她正相反，一小时内查清源头，当众说开，两人表达爱的方式不一样 |
| 他的表现 | 满分（没问第二遍） | 及格，他问了第二遍，她答了，可这一遍两人都记着 |
| 真相浮出 | 他挖的 | 真相自己露出来，那阵子他日子照常过，日子没走样，本身也是一种证明 |
| 深层恐惧 | 露了 | 没露，她带着那一步悬崖接着走，成了这个人物长线的暗面 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「你没问我第二遍」 | 证据跟直觉拧着来的那几晚 |
| 内心 | 解释这事，我做不到——开了头就收不住 | 所有人都说是她。三年对三天，我赌三年。 |
| 好的处理 | 她怕到骨头里那点东西，只让读者看见，不让她说出口 | 他查真相时不声张，查完也不邀功 |
| 写崩 | 写成她端着架子装冷淡 | 写成他嘴上说信，脚底下却来回晃 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 朝堂上有人告她通敌，全家都等着她写折子辩白，她照常上朝。他连夜把账册原件翻了出来 |
| 修仙 | 长老会咬定她练了禁术。她不肯开识海给人看，开了就是受辱。他懂这一点，就去把真正练禁术的人揪了出来 |
| 星际 | 军事法庭传她问话，她不肯交出私人日志自证。他主动出庭作证，只说了一句：「她飞哪，我都在旁边。」 |

修仙版里「解释就输了」成了明文规矩，开识海自证就是受辱，越证越掉价。她不出声，有性格的缘故，也有原则。

#### 写崩的三种方式

1. 不解释，就成了无理取闹。 三层理由都要立得住，少一层她就成了作。
2. 他被烤三天就动摇。 可以动摇，不能倒戈。
3. 真相靠反派自爆。 要么他挖，要么靠日子作证，真相不会自己掉下来。

## 五 · 她的处理是先查证

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：误会 35.1%

**骨架**｜有人给她递来一份他的黑料，她道了声谢，当场点开看。

#### 节拍链

她没当场发作，先按步骤走。递料的人冒出来，拿出有图有时间线的东西，她当场查证，料要么是假的，要么半真半假。接着看她怎么处置递料的人，怎么收拾他。

#### 时间轴

**她的查证按小时算。** 别人的误会是慢慢发酵的，她的在流程里就被拦下了：接报、验真、定性、处置，一个下午走完，言情场面被她弄成了尽调现场。

#### 她的流程美学

| 步骤 | 动作 |
|---|---|
| 接报 | 面无表情：「照片给我看看。」递料人备好的那套说辞一句都用不上 |
| 验真 | 放大看细节 · 对时间线，那天他在哪她本来就清楚 · 当场打给他，开免提：「你上周三下午在哪？」「陪你妈挑沙发。怎么了？」「没事。」挂断 |
| 定性 | 跟递料人说：「图是真的，事是拼的。你还有第二份吗？」 |
| 处置 | 递料人打的什么算盘，她当场问个底朝天，这一段是她的主场，火力全开 |

她开着免提当场对时间线，验的是他，也让递料人在旁边听着她怎么验。

#### 可用细节

| 类 | 内容 |
|---|---|
| 递料人 | 情敌 · 反对这段关系的长辈 · 「为你好」的老同学 |
| 那通免提电话 | 他稀里糊涂报完行程，最后问了句「你声音怎么这么冷」，半度的差别他也听得出来 |
| 事后 | 她本来不打算告诉他，想了想，晚上还是照实说了，**流程里多了一步：同步** |
| 他的反应 | 「你当时信了几成？」「零成。查证是给她看的。」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 料的真伪 | 全假 | 半真半假（真的那部分是他没提过的旧事，转 [15-秘密与坦白 · 他有一件事没说](15-秘密与坦白.md#一--他有一件事没说)，她照样先听他说完） |
| 同步 | 当晚就说了 | 没说，他从别人那里听说了：「你替我挡了这种事都不告诉我？」她护得太狠，这本身又成了新问题 |
| 递料人 | 外人 | 她亲妈（这下难办了，接 [13-家庭与亲属](13-家庭与亲属.md)） |
| 他的对照版 | —— | 有人给他递她的料，他听完直接撕了，真假都不看。两人都是满分，路子正好相反 |

她查，是查给递料人看的。他干脆连验都不验。两个人都信得过对方。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「零成。查证是给她看的。」 | 免提里她那半度冷的嗓音 |
| 内心 | 光着急没用，递料的人认流程不认情绪 | 她在忙正事，回家再问。现在先把沙发款式说清楚。 |
| 好的处理 | 流程冷，说话热，两样拧在一起才好看 | 他行程报得干脆，没有一点别扭 |
| 写崩 | 写成她在审他 | 写成他因为查证的话下不来台 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 有人呈上他「私会外男」的认罪状，她当堂验墨，墨还没干，事情却说是三年前的，递状子的人挨了二十杖 |
| 修仙 | 有人送来他「暗通魔修」的传讯玉简，她当场拿本命法器验，法器从不说谎，一验就露了馅，送信的同门脸色比玉简还难看 |
| 星际 | 有匿名数据包指控他伪造履历，她十五分钟查出发件人的IP，转手把溯源报告发给了对方的顶头上司 |

#### 写崩的三种方式

1. 她先信了再查。 顺序一反，人设就崩了，她是从零成开始查的。
2. 流程写得冷冰冰的。 挂免提电话之前那半度的温差要留着。
3. 同步工序省了。 「都不告诉我」这件事，一定要单独写一遍。

## 六 · 他的处理是先自我怀疑

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：误会 35.1%

**骨架**｜碰上同一条可疑线索，她头一个念头是去查，他头一个念头是果然，我就知道。

#### 节拍链

线索出现（她的反常）→ 他跳过验证直达结论（她后悔了）→ 结论反推证据（一切都对上了）→ 行为收缩 → 她发现他在「预备撤离」→ 强制对质 → 拆弹

#### 时间轴

他心里一直搁着「她总有一天会后悔」，一点风吹草动就点着了，用不着误会慢慢发酵。然后看他退到哪一步：还书，把牙刷挪回「客用」的位置，嘴里「咱家」变成「你家」，再到看好了搬出去住的房子。

#### 「果然式误会」的运行机制

| 环节 | 内容 |
|---|---|
| 底层预设 | 「我配不上她」的老毛病（接 [04-委屈与破防 · 我是不是不够好](04-委屈与破防.md#九--我是不是不够好)），平常好好的，不发作 |
| 触发 | 她一连一周晚回家，有一回话到嘴边又咽了回去，手机总是扣着放，三件小事，单拎哪件出来都不算什么 |
| 脑补链 | 他没往出轨上想，他想的是「她总算想明白了」，这更看轻自己，也更顺着他那个老毛病 |
| 收缩 | 他开始收拾自己的东西，借她的书也还了，那副「随时准备走人」的样子比吵架还让人难受 |

他把关系里的「暂借物」一样样归还，头一样是书。她看见书回到书架上的那一刻，全明白了。

#### 可用细节

| 类 | 内容 |
|---|---|
| 三件小事的真相 | 晚归=给他准备生日惊喜 · 话说到一半=差点说漏嘴 · 手机反扣=在跟他兄弟商量事 |
| 收缩清单 | 还书 · 他的牙刷从她那边挪回「客用」位置 · 说话开始说「你家」不说「咱家」 |
| 她的拆弹 | 三件小事先不解释，先拆程序：「你脑子里那个『总有一天』，今天必须删掉。」 |
| 拆完 | 惊喜照样办，可那晚真正要紧的是删程序的那场谈话 ✓ |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 收缩深度 | 还书级 | 他连搬出去的房子都看好了，拆弹就成了抢救 |
| 拆弹方式 | 谈话删程序 | 删不掉，只能跟它共处。她学会了要反常之前先打招呼：「这周我会晚归，不许胡想」，恩爱里带着点管人的手法 |
| 触发频率 | 一次 | 复发。第二次他自己先发现了：「程序又启动了，给我十分钟」，他学会了给自己拆弹 |
| 镜像 | —— | 她也有自己的「果然」：「他总有一天会烦」。某个深夜两套程序被彼此撞破，互相删掉 |

误会体质治不好，可以学着带着它过。

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 合上书那一下 | 「今天非删不可」没得商量 |
| 内心 | 他没有不信我，他是顺着我想的那套在演 | 果然。……不对，她说「果然」是毛病。十分钟。 |
| 好的处理 | 她拆的是程序，没冲着人：先拿掉「总有一天」，再解释三件小事 | 他给自己拆弹要一回比一回熟，别一步登天 |
| 写崩 | 写成她骂他不信她 | 写成自我怀疑绕圈当虐点 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她一连几天睡在书房，他把她赏的东西一件件记上册子，打算哪天还回去。她看见那本册子，当晚就烧了，连同他那句「总有一天」 |
| 修仙 | 她闭关前有话没说出口，他就把她给的本命符收进了匣子最底下。她一出关，头一件事是把符重新系回他脖子上：「这个不收回。永远。」 |
| 星际 | 外面都在传她要调走，他偷偷去查单人舱的申请表。她直接把两人舱的续约单拍到他桌上，年限一栏写着「服役期全包」 |

#### 写崩的三种方式

1. 脑补链写成出轨怀疑。 他想得更卑微，他怕的是她清醒过来，背叛根本轮不上。
2. 拆弹只拆表层。 解释三件小事只能治标，把程序删了才治本。
3. 复发写成原地踏步。 第二次一定要有那句「给我十分钟」。

## 七 · 好心办坏事的人

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：误会 35.1% ＋ 闺蜜 11.3%

**骨架**｜闺蜜替她试了他一回，局设得很周全，只是忘了跟她说。

#### 节拍链

好心人设局试探他，一开始是真心为她好。他确实上了套，可他的反应要么被掐头去尾，要么被读歪了。她看到「结果」时的反应，和好心人想的不一样。三个人坐下来把话说开之前，关系一度冷到冰点，到边界重新划清，才算修好。

#### 时间轴

被试探的人回头再想那天，每个动作、每句话都变了味。疼就疼在「原来那天的一切都是排练好的」。局设了多久，信任就被耗掉多久。

#### 局的类型学

| 局 | 设计 | 误读点 |
|---|---|---|
| 忠诚测试 | 找人加他微信 ✓ 撩他 | 他客气回了一句就拉黑了，截图只截了「礼貌回的那句」 |
| 财力测试 | 长辈安排「借钱」试探 | 他真去借了一圈，被看成「果然没钱」，其实当晚他就凑齐了 |
| 底线测试 | 酒局灌他看酒品 | 他喝多了，只是一个劲给她发消息，这反倒替他洗白了，局翻了车，成了助攻 |
| 反向局 | 他兄弟试探她「配不配得上」 | 她三句话就让试探的人当场服气转粉 |

局翻车成助攻走喜剧，截图剪辑走正剧。挑一条，别混用。

#### 可用细节

| 类 | 内容 |
|---|---|
| 好心人的逻辑 | 「你眼里进了人，总得有人替你看着」，用心挑不出错，办法一塌糊涂 |
| 她的反应 | 「结果」她先不看，先问经过：「你们哪天设的局？」日子一说出来，她就想起他那天回家时欲言又止的样子 |
| 他知道后 | 比起被试探，他最在意的是「她当时信了几秒」。她的回答是：「我在等你自己提那天的事。」 |
| 边界重立 | 她对闺蜜说：「谢谢。下不为例。他归我看。」三句话，一句道谢，一句划线，一句认领 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 好心人 | 闺蜜 | 他的兄弟（反着来）· 两边老人（最难办，接 [13-家庭与亲属](13-家庭与亲属.md)） |
| 局的结果 | 他满分过关 | 他露了点小毛病，喝多了说错半句话，这毛病怎么算，看她怎么出题 |
| 她的立场 | 事前不知道 | 知道一半，她撂过一句「你们看着办」，就因为这句，她得低头认错，这一版最难写 |
| 修复 | 三方吃顿饭说开 | 闺蜜和他成了自己人，当初考他的人转过头来比她还护着他，可以写成喜剧长线 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 「他归我了」这话得说出口 | 问她当时信了几秒，这话他到嘴边又咽了回去 |
| 内心 | 局是别人设的，我装不知道，那半句是我递的 | 那天的话我翻来覆去地想，哪句是真说给我听的 |
| 好的处理 | 她那三句话顺序不能乱，先谢，再划线，最后说他归我 | 他不恨设局的人，只记着那天的事，分得清 |
| 写崩 | 写成她为了闺蜜把男人卖了 | 写成他考过了关，乐得跟捡了便宜似的 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她母亲派人试他的品性，试了三回，三回都过了。她知道以后给母亲行了大礼：「谢母亲。今后他的品性，儿自己担保。」 |
| 修仙 | 师姐布幻阵试他的道心，他在阵里认出那个「她」是幻化的，因为太温柔了：「她凶我的时候才是真的。」 |
| 星际 | 她的副官伪造了一份他的「风险评估」，想看她什么反应，她的批示只有一行：「评估人调岗。」 |

#### 写崩的三种方式

1. 好心人写成反派。 用心得是真的好，办法才有资格出错。
2. 局的过程比后果长。 设局占三分，摊牌占七分。
3. 边界重立喊口号。 就三句：道谢、划线、认领，多一句都不要。

## 八 · 解开的成本

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：误会 35.1%

**骨架**｜误会不会自己散，总要有人先低头，放下的是面子。

#### 节拍链

僵持，俩人都不肯先低头 → 算账期，谁先开口谁就输了 → 突然有人想明白了另一件事 → 认栽（低头、摊牌、道歉）→ 松绑 → 认栽那个人身上发生的变化

#### 时间轴

**先低头的那个人，往往要付更多代价。** 头一天服软，顶多丢点面子。拖到第十天再开口，新的旧的叠在一起，要搭进去的就多了。多僵一天就多亏一天，最后都落在他身上。

#### 「另一笔账」的算法

先低头的人是换了个想法，算不上认输：

| 原来想的 | 后来想的 |
|---|---|
| 谁先低头谁输 | 僵到第十天，两个人各瘦了两斤，这算谁的？ |
| 我没错凭什么我先 | 对错已经翻过去了，现在只问值不值 |
| 他/她该先来 | 等着对方先来，这份指望一天比一天不值钱 |

**想法换得踏不踏实，看的是那一瞬间**：她加完班回来，对着冷锅站了几秒，或者他睡在沙发上蜷成一团的样子。引出转念的事越小，读者越信，往往一件小事就行。

#### 可用细节

| 类 | 内容 |
|---|---|
| 僵持的日常 | 同住一个屋檐下，各过各的 · 冰箱 ✓ 里的菜都分开买，连菜都分居了 |
| 支付现场 | 话很难开口：「那个……」「嗯。」「没什么。」（第一次没说成）· 半小时后又回来：「刚才那句『那个』，是想说对不起。」 |
| 支付方式差 | 他用嘴说，嘴笨，可道歉说得完整 · 她用手做，他那份菜又出现在冰箱里，**她道歉从来不靠嘴** |
| 账面变化 | 先低头的人这一回「亏」了，换回来的是往后十年，这一层让读者自己去想，别点破 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁先低头 | 他（常态） | 她一年才低一回头，每回都是大事 |
| 代价 | 一句道歉 | 当众道歉（误会是在人前闹的，解开也得在人前，代价翻倍，接 [14-社交与公开](14-社交与公开.md)） |
| 对方接不接 | 当场接了 | 第一次对方没接住，那次也算数，要写进去 |
| 两边都低头 | 单方 | 难得两边一起：半夜两人都起来了，在客厅撞个正着，都憋着话，谁也没开口，先笑了场，误会就这么糊弄过去了 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 那盘菜又自己回到了冰箱 | 那句“刚才那个”又绕回来了 |
| 内心 | 对错我没让，值不值我认了 | 头一回没接住不算砸，算预演 |
| 好的处理 | 她用东西赔不是，话少，可意思到了，不用人猜 | 他道歉说得完整也不啰嗦，说完不逼她表态 |
| 写崩 | 写成她死犟到底 | 写成他跪习惯了 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 僵了七天，她下朝绕到东市，买了他念叨过的蜜饯，多走的两条街就算递了台阶 |
| 修仙 | 冷战那阵两人灵力乱窜，修炼全荒了，修为替他们记下了这一笔，掌门对着两份功课单直叹气 |
| 星际 | 分舱住到第九天，她把温度调回他习惯的那一档，参数一改，就是她先低头了 |

#### 写崩的三种方式

1. 误会自动过期。 没人低头就没人去解，拖黄了的误会会变成裂痕。
2. 代价一句话带过。 第一次没说出口，第二次又回来，前后搭进去多少，都被一句话带过去了。
3. 低完头马上两清。 别问「你原谅了吗」，下一顿饭就是回答。

## 九 · 误会期间说的话

`T` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：误会 35.1% ＋ 吵架 15.7%

**骨架**｜误会解开了，大家也高兴了。最难熬那几天说过的话，却不会跟着误会一块儿没了。

#### 节拍链

误会高烧期 → 口不择言（各说一句）→ 误会解开（表面全剧终）→ 平静期 → 某个瞬间那句话自己回放 → 处理残留 → 真正的剧终

#### 时间轴

那句话通常比误会活得长，真相大白那一刻它不会跟着失效。误会往往撑不过一个星期，那句话三个月后还会在半夜发呆时自己一遍遍重放。

#### 残留话语的类型

| 那句话 | 为什么注销不掉 |
|---|---|
| 「我早就知道你是这种人」 | 「早就」两个字露了底，原来你一直这么看我，误会只是让人憋不住说了出来 |
| 「跟你在一起我从来没安心过」 | 「从来」两个字把三年全否了，就算是气话，也太重了 |
| 「你和他们说的一样」 | 他记住的是「他们」，原来外面那些话你全听过，还都记着 |
| 「行，反正你迟早要走」 | 他「果然如此」的老毛病（见[六 · 先自我怀疑](#六--他的处理是先自我怀疑)）当场又犯了 |

**残留下来的，是「原来那个念头一直在」的证据，跟恶意无关**。误会像退潮，把平时淹在水下的礁石露了出来。

#### 可用细节

| 类 | 内容 |
|---|---|
| 回放时刻 | 和好以后某顿平常的晚饭，他忽然停了筷子，她知道他又想起那句话了 |
| 处理的两派 | 当没说过派：事情过去了，刺还扎在心里，说不定哪天又冒出来。摊开说派：挑一个两人都轻松的日子提一句：「那天你说『从来没安心』，咱聊聊呗」 |
| 打捞现场 | 说的人先把话往回收：「不是从来。是那几天。」「从来」换成「那几天」，刺就软了一半 |
| 剩下的半块 | 「那几天为啥会那么想」，聊到这一步，才真算翻篇 |

气话伤人，伤在从来、永远、早就、根本这几个词上，要解开也从这几个词下手。

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 谁说的重话 | 他 | 她很少说重话，一旦说了，对方会记很久，她平时不乱讲，所以每个字都被当真 |
| 处理 | 打捞 | 没打捞，三年后吵架翻旧账，那句话原封不动又冒了出来，要写长线裂痕就这样写 |
| 打捞时机 | 主动挑日子 | 被动触发，撞上某句台词或某个场景，当场就翻了出来 |
| 残留归宿 | 解毒清零 | 解了也留疤：那个话题两人从此都绕着走，怎么绕倒成了默契，不完美，可是真实 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 他放下筷子那一下，她就懂了 | 「不是一直。是那几天。」 |
| 内心 | 我说「早就知道」的时候，是赌气还是露了底，我自己也得想想 | 那句话我存了三个月，原来她也存着 |
| 好的处理 | 她不等他开口，自己先把说过的话捡回来 | 他捡的时候不翻旧账，一回只捡一句 |
| 写崩 | 写成说开了就全好了 | 写成旧账翻来覆去地算 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 她气头上说过「当初就不该聘你」。三个月后他过生辰，她在贺词里补了一句：「当初聘你，是我此生最不悔的一笔。」满座只有他听出来这是道歉 |
| 修仙 | 吵起来神识相撞，有些念头没说出口，也被对方「听」见了。修仙版留下来的东西更狠，连没说的都记下了 |
| 星际 | 吵架时舱段的记录仪开着，那段音频谁都没删。有一天她当着他的面删了，删这个动作本身就是仪式 |

#### 写崩的三种方式

1. 解开就清零。 要写的正是那些留下来的。
2. 打捞变成二次审判。 一回只捞一句，捞完就收。
3. 重话写得太毒。 狠就狠在从来、早就这几个词上，用不着脏字。真骂出脏话，要修补的就成了人品。

## 十 · 没有发生的误会

`G` ｜ 无预警 ｜ 全谱系 ｜ 语料频次：误会 35.1%（反向用法）

**骨架**｜狗血剧开头那三样都齐了：深夜不归、陌生口红印、查无此人的「加班」。她扫了一眼，问：「说吧，给我准备了什么惊喜？」

#### 节拍链

起因是他在偷偷准备惊喜，露了馅。可疑的迹象全摆到她眼前，她偏不按套路来，直接摊开问清楚，真相这才浮出来。等两人聊起「刚才差点就误会了」，反倒觉得更信得过对方了。

#### 时间轴

无。全靠她直接摊牌往前推。她只在第七秒怀疑了一下，第八秒就过去了，六十秒的通牒走到第四十秒，他就招了。

#### 「偏不入局」的三种姿势

| 姿势 | 台词 |
|---|---|
| 拆台式 | 「口红印在领子后面，自己蹭不到那个角度——所以是谁抱了你？按身高排查，你妹？」她推理比吃醋来得快 |
| 通牒式 | 「三个可疑点，给你六十秒自首，超时按惊喜处理。」 |
| 摆烂式 | 「我选择相信是惊喜。如果不是，你自己想办法把它变成。」举证的责任被她体面地扔了回去 |

**三种姿势的前提一样：她的第一反应是「这不合理」**。[六 · 先自我怀疑](#六--他的处理是先自我怀疑) 里的「果然式」正好反过来，那边往死里拧巴，这边直接掀桌。

#### 可用细节

| 类 | 内容 |
|---|---|
| 剧本级迹象 | 他手机 ✓ 屏幕朝下 · 陌生号码来电他去阳台接 · 周末「加班」但工牌 ✓ 在家 |
| 穿帮现场 | 六十秒通牒走到第四十秒，他绷不住了：「求婚场地在改第三版你满意吗！」剧透是他吼出来的 |
| 复盘 | 「你就没怀疑过？」「怀疑过，第七秒。第八秒想起来你连点外卖都要跟我报备。」平日的实据赢了剧本 |
| 定心丸 | 这场没成的误会成了两人常讲的段子：「上次你差点被我误会……」「那叫差点吗，你第七秒就破案了」 |

#### 变体轴

| 轴 | 一端 | 另一端 |
|---|---|---|
| 真相 | 惊喜筹备（喜剧收尾） | 真有事但无害（他偷偷做兼职攒钱，她不掺和，最后挖出来的是他攒着的自尊，接 [12-工作与金钱](12-工作与金钱.md#五--他要证明自己)） |
| 方向 | 她不掺和 | 他不掺和。她看着「可疑」，他说：「你要真有事，不会留破绽。留了破绽就是想让我问。问：怎么了？」他走的是感情这条路 |
| 段位来源 | 天生冷静 | 练出来的，前作有过一次真误会［本卷一至九条任一］，这次忍得住，靠的是上次留下的疤，两条连着用，能写出成长 |
| 复盘归宿 | 段子 | 一句正经的：「谢谢你没按剧本走。」 |

#### 双向写法

| | 四爱女笔下 | 四爱男笔下 |
|---|---|---|
| 落点 | 第七秒到第八秒之间的那次转念 | 「留了破绽就是想让我问」 |
| 内心 | 剧本给我递了三次刀，我用它切了个苹果 | 她连怀疑都带着尽调格式，我居然觉得安心 |
| 好的处理 | 她不入局，可那一秒的动摇是真的，免疫了也还有知觉 | 他那四个字「问：怎么了」，把千层套路还原成了一句人话 |
| 写崩 | 写成她全知无敌 | 写成刻意炫耀信任 |

#### 换皮

| 世界 | 等价物 |
|---|---|
| 古代女尊 | 满府都在传他和新来的乐师走得很近，她听完只问「乐师会教琵琶吗，正好他生辰想学」，流言到她这儿只算一条消息 |
| 修仙 | 有人看见他深夜进出禁地，她掐指算了算日子：「离我生辰还有九日。禁地里那株花要开了。」她推了半炷香，比长老会快了三天 |
| 星际 | 他的航行日志隔一阵就空一段，她看着那些空白笑了，每段都正好避开她的休眠期：「这人连惊喜都排班。」 |

#### 写崩的三种方式

1. 不入局写成不在乎。 第七秒那一下动摇得是真的，要让读者感觉到她心里咯噔了一下。
2. 每次都免疫。 只有剧本级的套路才免疫得了，真有裂缝就回到前九条，该疼就疼，别硬扛。
3. 复盘吹成信任宣言。 最多一句「谢谢你没按剧本走」，再多一句就腻了。
