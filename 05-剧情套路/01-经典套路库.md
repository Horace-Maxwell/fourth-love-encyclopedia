## 怎么用这一卷

每个条目都照 [00-编纂规约/02-条目写作模板](../00-编纂规约/02-条目写作模板.md) 3.4 节的模板写，分七个小节，每节一个四级标题，一节都不省。

| 小节 | 干什么 |
|---|---|
| 结构公式 | 用箭头串成一行的节拍，最小的一块，可以直接抄进大纲 |
| 为什么有效 | 它打中了读者哪种心理需求。写这一段，是为了让套路能变着用 |
| 节拍表 | 拍号｜发生什么｜篇幅占比｜情绪目标。标 `实测` 的占比是精读时量的，标 `建议` 的是估的常见值 |
| 常见变体 | 2–5 个，每个都说明和主形差在哪 |
| 写崩的三种方式 | 必写。要防手滑，反面清单比正面指南管用 |
| 可直接用的素材 | 拿走就能用的具体零件 |
| 相关条目 | 同卷里可以对着看的套路 |

标题带 `↺` 的条目会多出一节「↺ GB 方向反转」，讲这个套路到了 GB 里，方向和 BG／BL 圈正好相反。

每个梯队开头有一张总表，这一梯队每个套路的词频、一行公式、关键拍和最容易写崩的地方，都放在一屏之内，扫一眼就有数。

⚠️ 方向反转标记：标题带 `↺` 的条目，说明这个套路在 GB 语境下和 BG／BL 圈方向相反。
见到 `↺` 要多留神。这些地方最容易打错 tag、写反方向，引战挨骂也基本由此而来。
方向反转的完整清单在本卷末尾「附录一」。术语上的区别见 [02-术语百科/05-易混淆词辨析](../02-术语百科/05-易混淆词辨析.md)。

### 穿越

`T` `△误会流`
`现代都市→古代女尊／架空王朝` `女尊制／现实性别制度` `1v1／np` `强势主导` `敌对转化`
来源：`【圈内共识】` + 词频 443 篇 / 7.3%（全库套路词第一位）

#### 结构公式

落地（啥都不知道）→ 认知错位，这世界的规矩怎么全是反的 → 拿前世的本事换口饭吃 → 原主欠的烂账找上门 → 归属选择（回不回去）

#### 为什么有效

想让女主一出场就镇得住，穿越是最省事的理由。她的本事是从另一套规矩里带过来的，这个世界不用解释她为什么强，这边的制度也不用替她背书。穿越能压过重生、快穿、穿书成为第一高频词，就因为这一条同时回答了两个问题：她凭什么强，读者凭什么看得懂这个世界。

女尊文最卡人的是「权力从哪来」，见 [03-世界观设定](../03-世界观设定/) 的制度三问。穿越把这个问题直接绕开了：她用不着去争这个世界的权，她自己带了一套来。

| 2 | 头一回吃规矩的亏：她照老习惯办事，挨了罚 | 3–8% | 这地方来真的 |
| 3 | 第一次亮出从别处带来的本事，换到第一个落脚的位置 | 8–15% | 痛快 |
| 4 | 原主欠下的账找来了，仇家、婚约、亏空，还有个从没见过的人用某个称呼叫她 | 15–25% | 她不是白来的 |
| 5 | 带来的本事不灵了，只能照这里的规矩赢一次 | 40–60% | 真长本事了 |

#### 写崩的三种方式

1. 金手指代替人物。每回遇到难处都靠「我知道这个／我会这个」过关，五章以后，读者就只等着看她下一次亮本事。正解：第 5 拍必须有一场戏，她从异世带来的优势全不管用，只能按这个世界的规则赢。
2. 原身留下的烂摊子不收拾。人家的身体、名字、亲人、婚约都占了，原身的关系和责任却从头到尾不管。这样一来，穿越不过是白捡了一次身份升级，读者对主角的好感会一点点漏掉。
3. 现代性优越感变成说教。女主每章都在心里笑这个世界落后，配角于是全被降了智，「她的强」也从能力缩成了时代差。正解：这个世界至少要有一条规矩比她原来那边更合理，并且让她被这条规矩说服一次。

#### 可直接用的素材

- 落地第一拍的钩子：别写她醒过来盯着天花板，写她一个日常动作做错了，用错了手，坐错了位置，叫错了人，给了不该给的东西。一个动作就交代了「她是外来者」，也交代了「这个世界的规矩是什么」。

- 原身的债卡：一个仇家，一个婚约，一笔亏空，一个用某个称呼叫她、她却不认识的人。四格开局就全填上，全书一格一格清算。

- 转场句式：「在她原来那个地方，这件事是……」。一卷最多用两次，多了就成说教。

### 年下 ↺

`T` `△年龄差`
`现代都市／校园／古代女尊` `全制度` `1v1／np` `温和主导／双向拉扯` `年下`
来源：`【圈内共识】` + 词频 268 篇 / 4.4%（第二位）；人设词「竹马」130 / 「奶狗」21 / 「狼狗」26

#### ↺ GB 方向反转

BG 圈说「年下」，主流是年下男攻（狼狗攻、小狼狗），年龄差和主导权方向相反，两头拧着劲。
GB 圈的「年下」是年下男受，年纪小的那个也是被主导的那个，两层落差往同一个方向叠。
这一组 tag 最容易被看错：BG 读者看到「年下」，想的是他攻，GB 读者想的是他受。
所以文案里「年下」必须和「女攻男受」一起出现，只打「年下」会招来不对路的读者。

#### 结构公式

`她拿年龄当界线，想把关系推回安全距离。可他越界一次，越得漂亮。后来他在她专业领域帮上真忙，外部压力又逼她表态。她最终自己动手，废了那条年龄线。`

#### 为什么有效

情欲里谁上谁下，这层本来是现成的。不用多说。可叠得太满，味道就变了：性张力磨没了，只剩照护，她成了监护人，他成了被养大的那个。

所以写姐狗，「狗」身上必须有一处不忠。见 [02-术语百科/05-易混淆词辨析](../02-术语百科/05-易混淆词辨析.md) ⑦ 的犬系吸引力排序 `忠犬 < 狼犬 < 暴娇犬 < 狂犬`，以及「纯忠犬因为缺乏冲突容易把故事写平」。

#### 写崩的三种方式

1. 把年下写成照护。她给他做饭，管他作息，替他收拾烂摊子，全书找不出一件他为她做的事，性张力就这样归零了。第 4 拍必须让他在她真正在意的领域里帮上忙，不然关系会从情欲滑成亲职。

2. 只会点头的角色撑不起一条感情线。他没有一处不服从、不理解、不同意，纯忠犬的设定让冲突没地方长出来。给他一处明确的「不忠」，一件瞒着她做的事，或者一条他死活不让步的原则。

3. 年龄差只在文案里存在。标着「年下 5 岁」，正文里两人说话的方式、社会位置、见识却看不出任何落差。检验法出自《风起云涌》第八节「死设定检验法」：把年龄数字删了，故事有没有哪一处要改？一处都没有，这条设定就是死的。

#### 可直接用的素材

- 界线句式：她划界时别搬出年龄，要拿一件具体的事堵他：「你连这个都还没经历过」。拿年龄当理由，听起来是嫌他小，显得刻薄。拿具体的事说，反倒像在护着他。

- 越界卡：`他第一次越界的方式：撒娇 / 沉默 / 专业能力 / 身体 / 情报`。五种里「专业能力」最耐看，也最容易翻车，写好了是真带劲。

- 状态板字段：`【他年龄】｜【她给他的称呼】小X→全名→昵称，这就是进度条｜【他死也不让的那件事】

### 生子 ↺

`M` `⚠️生子` `⚠️双性(视机制)` `△虐身`
`古代女尊／星际／架空` `女尊制／女A男O` `1v1／np` `强势主导` `甜宠／虐恋`
来源：`【圈内共识】` + 词频 187 篇 / 3.1%；排雷段实证中「生子」被排 37 次（第 4 高雷点）

#### ↺ GB 方向反转

生孩子的是男方。GB 里方向反转得最彻底、也最容易踩雷的就是这一条。
排雷段统计中，「生子」是排第四的高频雷点（37 次），前三是「虐」「双性」「洁」。一定要在前面声明。不能埋到中段。

#### 结构公式

机制被使用 → 怀孕落地 → 社会代价露头 → 孕期不冻结 → 风险真的落下来 → 孩子的归属

#### 为什么有效

GB 把生育从女方身上整个搬到男方身上，身体失控、被人指指点点、事业断档、拿命去赌，这一整套代价都落到男角色头上，读者看到的是一次完整的处境互换。制度可以推翻，称呼可以改，怀孕改不了，角色怎么逃都逃不掉。权力关系就这样直接写进了身体。

##### 四种机制与代价

出自 《风起云涌》 2.2⑦「生育四解法」

| 机制 | 做法 | 收益 | 代价 |
|---|---|---|---|
| ① 男性生育为常态 | ABO／双性／幻想生理 | 女尊设定最带感 | 生理设定费劲，还自带 `⚠️生子`+`⚠️双性` 两个雷 |
| ② 女性生育、男性育儿 | 现实生理 + 分工反转 | 读者最容易懂 | 女尊味最淡，一不小心就成了「换了个称呼的现实」 |
| ③ 可选择制 | 吃样东西就能怀上，男女都可以 | 一句话就交代清楚，不用费劲写生理 | 生育成不了权力来源，只剩一种普通风俗 |
| ④ 外置生育 | 人工容器／术法／法宝 | 分得彻底，科幻、修真都用得上 | 亲缘关系要重新理一遍，家族戏不好下笔 |

#### 写崩的三种方式

1. 怀孕即退场。角色一怀上就从情节里消失了，只剩养胎、被保护、等人来接。正解：留一条解绑的路，比如外置容槽、术法转移、代理执行，或者干脆让孕期成为他行使权力的场合。

2. 机制写在设定卡上，正文里一次都没用过。《风起云涌》里「育国树／育果」各出现1次，全在第一节的说明书里。38.5万字的正文中，怀孕就是普通的怀孕，还冒出一个和设定对不上的「能生育的药」。检验办法很简单：删掉这条设定，看故事有没有哪里要改。

3. 生育只拿来推床戏，跟社会线不挂钩。写了男性生育，继承、税役、婚配、军役却没有一条规矩用得上它。至少得有一条继承或婚配的规矩建立在它上面，否则它就只是个生理设定。

#### 可直接用的素材

- 设定卡字段：改自《风起云涌》十节。
  ```
  生育机制: [男性常态 | 女性常态 | 服食可选 | 外置]
  社会禁忌: 谁生育会掉价？          # 这一格空着 = 生育设定是死的
  本机制在正文中被使用/违反的场次: []  # 空数组 = 删掉这条设定
  孕期解绑通道: [无 | 外置容槽 | 术法 | 代理执行]
  孩子的继承顺位由谁决定:
  ```
- 信息差钩子：孕情先让第三方知道，医官、军医、系统都可以，男女主反倒蒙在鼓里。读者跟着第三方看一段，干着急。这种“就你不知道”的写法，能撑起10%的篇幅。
- 代价钩子：后果得真留下来，伤了就是伤了，残了就是残了，之后的行为必须跟着变。出了事还像没事人一样，就是假结账，见[[训诫循环]]写崩第2条。

### 训诫循环（含请罚循环／惩罚经济学／恩典的收回）

`M` `⚠️非自愿(边界情形)` `⚠️主奴` `△虐身` `△虐心`
`古代女尊／现代都市／修仙` `女尊制／现实性别制度` `np／1v1` `训诫系／调教系／主奴` `契约关系`
来源：`【一家之言】`+`【圈内共识】` + 《墨氏家规》 2.3 全节
词频：训诫 137 / 2.3%、调教 164 / 2.7%、BDSM 312 / 5.2%、sp 72 / 1.2%、主奴 59 / 1.0%

#### 结构公式

下表第一行是教科书的写法，撑不起长篇。后三行是《墨氏家规》里实际在用的。

| 循环 | 公式 | 在长篇里的作用 |
|---|---|---|
| 教科书版（要否定的那个） | `违规 → 发现 → 执行 → 修复` | 事件总会用完，到第五次以后，每一场读者都猜得到 |
| A 请罚循环 | `受训者察觉不悦 → 主动请罚 → 施训者顺水推舟 → 执行 → 谢恩 → 关系确认` | 施训者不用站在「加害者」的位置上，罗曼司就读得下去 |
| B 惩罚经济学 | `注意力稀缺 → 受罚是获取注意力最可靠的方式 → 惩罚从代价变成好处 → 竞相求罚 → 雄竞` | 规矩自己转起来，作者不必再编违规事件 |
| C 恩典的收回 | `某项破例施行日久 → 成为默认 → 某日不给 → 落差本身即最重一击` | 到中后期实在加不上去了就用它，尺度一点都不用提 |

#### 为什么有效

《墨氏家规》 的硬数据：全书 47 次惩罚，真由违规引出的不到三分之一。教科书那套循环几乎没在转。

读者盯着的是「这一次她会不会破例」。违规只是一件事，事情会过去，「他会不会被抓」也没有悬念。一定会抓。训诫文和犯罪文就在这里分开：看点从「他犯没犯规」移到了「她这回怎么发落」。

循环 A 要紧的是，惩罚由受训者自己提出来。这样施训者就脱掉了「加害者」的身份，这类题材的罗曼司才读得下去。

「为什么训诫文那么爱写 np」，答案就在循环 B 里。挨罚本身成了得宠的凭证，规矩一转起来就停不下，作者用不着再费心编违规事件。详见 [[03-开篇钩子与节奏控制]] 的惩罚经济学专论。这里不展开。

循环 C 最省力。效果却常常出人意料。作者被平台尺度卡着，写到中后期没得可罚了，就别再加码，把一项对方早已习惯的好处收回来。这一招比加码狠十倍，尺度一点都不用动。

##### 规则的真正功能

先定一条很严的底线，之后哪怕松一点点，读者都会读成爱。

#### 写崩的三种方式

1. 用教科书循环撑长篇。光靠「违规-发现-执行」往前推，事件迟早用完，到第五次，读者闭着眼都能猜出下一场。正解：先立一条24小时都生效、加减算得清的日常规矩，再把事件挂上去。规矩是炉子，事件是柴，没有炉子，柴烧完也就完了。

2. 后果被系统性抹除。神医、灵药、异能、系统面板把伤害一概清零，惩罚想加多重就加多重，反正叙事上不用付代价。《墨氏家规》全书只有一次让伤害真正留下了后果，主角出事后只拿它当愧疚的材料，做法一点没变，到最后连这个后果也被推翻了，这就是假结账。正解：至少有一次伤害真的留下后果，并且之后的行为要变。

3. 叙述和施训者的自我合理化完全同一个调子。她每次动手前都在心里给自己找个「为他好」的理由，文本从头到尾不露一点反讽，作品根本不知道自己写的是个加害者。读者没处站，情感上只能「认同」，张力反而越写越窄。正解：让文本知道她不好，她本人不必变好。一个知情的旁观者，一段事后的迟疑，一次被拆穿的自辩。有一样就够。

#### 可直接用的素材

- 四层授权链模板：《墨氏家规》2.1，哪个时代都能用。
  ```
  外部胜负／权势差 → 有权者的一次「授予」 → 家族/组织的既有礼法 → 当事人自定的日常细则
  现代版：并购成功 → 董事会授权 → 集团规章 → 上司的私人要求
  修真版：宗门战胜 → 掌门赐下 → 门规 → 师尊的日课
  系统版：主神发布 → 权限开通 → 任务守则 → 她随口加的一条
  ```
- 不可豁免条款：在整套规矩的最上头放一条施训者自己也改不了的规则。有了它，她的权力才有边，他的绝望才有底。少了这一条，全书就只是一个人在任性。
- 规则的认知不透明：受训者分不清哪条规矩能求情、哪条不能。「不知道这条规则能不能求得回来」，比规矩本身更叫人害怕。
- 嬷嬷位（中层执行者）：日常重复的施刑交给别人，主角只在有情感分量的节点亲自出场。不然女主就成了全职刑吏，当恋爱对象就不可信了。
- 抹布位：最极端的内容交给一个被排除在情感契约之外的角色来承受，留在关系里的角色就还能读出「被爱着」。要判断一篇训诫文的尺度上限，找出这个位置最快。

### 重生

`T` `△虐心` `△复仇`
`古代女尊／现代都市／修仙` `全制度` `1v1／np` `强势主导` `重生／复仇／救赎`
来源：`【圈内共识】` + 词频 155 篇 / 2.6%

#### 结构公式

死，而且死得清清楚楚，谁死了、失去了什么都要写明 → 醒于某个精确时点 → 第一个改动（必须小）→ 蝴蝶效应 → 原剧本失效 → 一个上一世不存在的新威胁

#### 为什么有效

重生给她的是「她提前知道」。这种金手指最好写，上手最快。贬值也最快。它真正有用的地方是逼她做选择：后果她都清楚，所以做什么、不做什么，全是她自己挑的。

GB 语境里，重生后不爱了是最值钱的一支：她带着记忆回来，偏偏不救他，让他自己爬上来。重生就从「报仇工具」变成了「重新谈条件」，和 [[追妻火葬场]] 正好互为镜像，一个是他欠她，一个是她欠他。

#### 写崩的三种方式

1. 原剧本永不失效。她改了三十章，未来还是照着上一世走，她做什么都没有后果。正解：第 5 拍必须有那么一刻，她发现自己再也不知道接下来会发生什么，而且这一刻要来得早（建议不晚于 55%）。
2. 仇人降智。上一世能弄死她的人，这一世一步一个空。她有信息优势，对方并不会因此变笨。正解：给对手也配一样这一世才有的新资源，两边增加的东西对等。
3. 前世的情绪原封不动。她死过一回，反应速度、说话方式、软肋却跟上一世一模一样。正解：重生的人最该变的是反应，能力反倒不必变。同一件事，她的反应要明显比常人快，快到别人觉得不对劲。这一点既立了人物，也是马甲的破绽。

| 不知情骨科 | 在一起之后才发现有血缘，第 4 拍换成一次身份揭晓，跟 [[马甲掉马]] 很近 | 不限 |
| 跨辈分 | 多数人把它归为「年龄差 + 亲属」，不当骨科看，打 tag 时要写明白 | 不限 |

#### 写崩的三种方式

1. 禁忌被环境直接抹平，绷着这段关系的唯一一根弦也就断了。父母死光了，家族搬走了，没人知道。也没人在乎。正解：身边留一个知情又不赞成的人，而且这个人不能是纯反派。
2. 血缘只在文案里写写。标着骨科，正文里两人相处跟普通青梅竹马一样，家里人不出场，亲戚不出场，族谱连提都没提。血缘要紧，是因为它连着一大家子人。正解：至少安排三个配角，因为这层关系对主角有明确的态度。
3. 拿「其实没血缘」当解药。前面 90% 都靠禁忌撑着，最后揭晓是抱错了。读者最恨这一招，前面受的苦等于全白受了。正解：要写伪骨科，就老老实实按伪骨科写。文案里写清楚。

#### 可直接用的素材

- 框架钩子：用一件具体的事把血缘关系摆到明面上，比如代签一份文件，办一个只有直系亲属才能办的手续，或者在医院被护士当面问一句“你们是什么关系”。这样一件事，比一百句煽情话都管用。

- 称谓阶梯：`哥/姐 → 全名 → 昵称 → 无称呼（只用「你」）`。骨科文里第四格最狠：他突然什么称呼都不用了，因为叫哪一个，都是在提醒两个人到底是什么关系。

- 状态板字段：`【关系类型】亲/继/义/表｜【知情者】n 人｜【知情者立场】｜【走得掉吗】留下失去__ / 离开失去__`

### 快穿

`T` `△误会流`
`无限流/快穿` `全制度` `1v1（多世界同人）／np` `强势主导` `系统／救赎`
来源：`【圈内共识】` + 词频 101 篇 / 1.7%（与「系统」99 篇高度共现）

#### 结构公式

绑定（代价必须写死）→ 世界 1（教学关）→ 世界 2–N，每关一个套路，且必须有累积项 → 系统的算盘暴露 → 主世界回收

#### 为什么有效

GB 圈用「快穿」图省事：一本书能塞进十种关系模式，世界观怎么变也不用解释。女总裁×男下属、将军×和亲皇子、师尊×徒弟，今天、明天、后天轮着换，读者也不觉得跳戏。快穿就是个装套路的筐，作者想一口气塞十个梗，又懒得圆逻辑。用它正合适。

同一个灵魂换了十个身体、十种制度，一遍遍回答「她凭什么在上」。每到一个世界，攻受位都得重新谈一次，普通言情玩不了这个。

#### 节拍表

口径：`建议`，单元剧结构，这里给全书骨架和单个世界内部的节拍

| 拍号 | 发生什么 | 篇幅占比（全书） | 情绪目标 |
|---|---|---:|---|
| 0 | 绑定。系统的代价必须写死：失败会怎样，退出又会怎样 | 0–3% | 签了合同的感觉 |
| 1 | 世界 1 = 新手村。演示规则，要短要爽，结尾留下一样本不该留下的东西 | 3–15% | 上手 |
| 2 | 世界 2–3。套路各不相同，攒下的东西开始冒头：同一个灵魂／同一件物品／同一句话一再出现 | 15–45% | 眼熟但不对 |
| 3 | 中点：某个世界的任务违背了她的良心，她头一回不听系统的 | 45–55% | 她说了算 |
| 4 | 系统的算盘露馅：它有它的好处 | 60–70% | 翻盘 |
| 5 | 世界 N：最难的一关，之前攒下的东西都得用上 | 70–90% | 高潮 |
| 6 | 主世界收尾：她带回来的东西 / 她留在各世界的东西 | 90–100% | 尘埃落定 |

#### 常见变体

| 变体 | 与主形的差别 | 适用体量 |
|---|---|---|
| 同一个男主的多个投影 | 他在每个世界都换一个身份，灵魂却是同一个。快穿要写长线感情就得靠这个，强烈推荐 | 不限 |
| 反派系统／恶毒女配任务 | 任务本身就要她去做坏事，主线于是成了道德压力 | 不限 |
| 无限流化 | 世界和世界之间有幸存者、排行榜和别的玩家，容易滑成群像，群像怎么管见 [[03-开篇钩子与节奏控制]] | 不限 |
| 不带系统的快穿 | 动机出自角色自己，比如找人、还债、寻死。比系统版难写，上限也更高 | 不限 |

#### 写崩的三种方式

1. 世界之间没有累积。十个世界就是十个各自独立的故事，删掉哪个都不影响别的。读者读到第四个世界就会放下，因为第五个是什么样，他已经猜到了。正解：从世界 2 起就埋累积项，一件跨世界存在的物品，一个反复出现的名字，或者一件她每次都会做错的事。
2. 系统没有自己的算盘。它只管发任务、报数值，需要时给点方便。《墨氏家规》 第八节第 6 条有一条通用判据：授权者没有自己的算盘，授权就不值钱。系统在快穿里是授权链的第二环，这一环是空的，整条链就没用了。
3. 每个世界的男主是同一个人，却看不出区别。说话方式、破防点、顺从性质全都一样，换掉的只有职业标签。正解：每个世界给他换一种顺从性质，赎罪／内化／苦行／博弈／驯化外壳／自我量刑／交易伪装。（顺从性质的分类见 《墨氏家规》 三节受训者五型 + 《失忆后你和霸总破镜重圆了》 的「自我量刑」+ 《风起云涌》 的「交易伪装」）

#### 可直接用的素材

- 世界卡模板：
  ```
  世界 __ ｜ 背景：____ ｜ 制度：____ ｜ 套路：____
  她的身份：____   他的身份：____
  权力落差来源：[生理 / 制度 / 能力 / 情感]  ← 每个世界换一格
  他的顺从性质：____                        ← 每个世界换一种
  累积项：本世界留下什么带进下一个：____
  ```
- 累积钩子：安排一样东西，每卷换个样子出现，一颗扣子、一句方言、一个手势都行。主角没察觉，读者心里清清楚楚。
- 抗命拍：第 3 拍她抗命，就必须真丢点东西，扣积分，少一次机会，或者直接被踢出去。否则抗命只是一场白送的表演。没人会当真。

### 系统

`T` `△误会流`
`穿书/系统／无限流` `全制度` `1v1／np` `强势主导／训诫系` `契约关系`
来源：`【圈内共识】` + 词频 99 篇 / 1.6%

#### 结构公式

`绑定 → 第一条任务（教学）→ 惩罚机制首次生效 → 她开始钻规则的空子 → 系统有自己的目的 → 解绑或收编`

#### 为什么有效

系统相当于一条外挂的授权链，一句话就解决了 GB 最麻烦的两件事：她凭什么能这么做（系统给了权力），她为什么非做不可（有任务压着）。

放进 《墨氏家规》 的四层授权链里一对，它在哪一环马上就清楚了：

```
外部胜负／权势差  →  有权者的一次「授予」  →  既有礼法  →  当事人自定的细则
（主神／末日／穿越）   （系统绑定）          （任务守则）   她随口加的一条
```

系统文最常见的死法就在这里。见写崩第 1 条。系统在故事里占第二层，就是那个「盖章的人」。这一层要是空的，系统自己既没利益也没所求，整条授权链就废了。

#### 节拍表

口径：`建议`

| 拍号 | 发生什么 | 篇幅占比 | 情绪目标 |
|---|---|---:|---|
| 1 | 绑定。先把代价说清楚，再讲权限。失败会怎样，比能做什么更要紧 | 0–4% | 签了卖身契的感觉 |
| 2 | 第一个任务。不难，做得完，奖励和惩罚都亮出来给人看 | 4–12% | 上手 |
| 3 | 惩罚真落下来了，落在她本人身上，扣数字那种不算 | 15–25% | 这系统来真的 |
| 4 | 她开始钻空子，只照字面去做，偏不顺着系统的意思 | 30–45% | 自己说了算 |
| 5 | 系统到底想要什么，这时露了底，它原来是有感情的 | 55–70% | 没想到 |
| 6 | 最后一个任务和她自己的意愿正面撞上 | 80–90% | 选哪边 |
| 7 | 解绑（付代价）或者收编（她变成新系统） | 92–100% | 尘埃落定 |

#### 常见变体

| 变体 | 与主形的差别 | 适用体量 |
|---|---|---|
| 任务型，攻略／改剧情／积分 | 最常见，与 [[穿书]] [[快穿]] 高度共现 | 不限 |
| 面板型，属性／好感度／状态栏 | 关系被量化成数值。放在 GB 里好用在：好感度和「主导权归属」可以分成两栏，两栏对不上的时候最有戏 | 不限 |
| 训诫型系统 | 施训者的活由系统来干，见 [[训诫循环]]。系统 = 立法者，她 = 执法者，权这样一分，就能避开「作品不知道自己写了加害者」这个老问题 | 不限 |
| 拟人化系统 | 它有情绪，会撒谎，会偏心。上限最高，也最容易写崩，变成第二个男主 | 不限 |

#### 写崩的三种方式

1. 系统只发任务，不设边界。权限、情报、道具它都给，却从来不拒绝、不索取、不为难人，这种系统只是金手指外面包的一层纸。正解：系统至少要有一次明确拒绝主角的合理请求，还得给出一个她驳不倒的理由。

2. 惩罚是纯数值。「扣 500 积分」压不住人，读者对积分没感觉。正解：惩罚必须落在身体、关系或时间上。比如扣掉一段记忆，收回一项她已经习惯的便利，就是 [[训诫循环]] 说的「恩典的收回」，或者让她在关键场合失声三分钟。

3. 系统最后被证明是善意的。结局揭晓它一直在帮她，它是她自己的执念，是未来的自己，是爱她的人。这一笔等于宣布前面的压迫全是假的，全书绷着的劲一下子全泄了。正解：就算它是善意的，这份善意本身也得伤到她，它替她做了本该由她自己做的选择。

#### 可直接用的素材

- 状态板字段：`【任务】｜【剩余时限】｜【好感度】｜【主导权归属】｜【已钻空子次数】`，最后两栏是 GB 专用的。好感度高、主导权却旁落的时候，戏最足。
- 钻空子钩子：给她一条措辞有漏洞的任务，她照字面完成，却违背了本意，系统判她通过，明显不高兴。这一场既显出她聪明，也让系统有了脾气。两边就对上了。
- 绑定条款卡，开篇500字以内交代清楚：
  ```
  权限：____              代价：____
  失败后果：____          退出条件：____（若「无」，写明「无」比留白有力）
  系统的自称与语气：____   ← 语气就是人格，第一句话定终身
  ```

### 双向暗恋

`T` `△误会流`
`现代校园／现代职场／古代` `全制度` `1v1` `双向拉扯` `双向暗恋／日久生情`
来源：`【圈内共识】` + 词频 暗恋 79 篇 / 1.3%

#### 结构公式

`两条互不相通的内心线 + 一条共同的外部事件线 → 三次错过（每次原因不同）→ 一个不得不表态的外部压力 → 同时说破`

#### 为什么有效

递一杯水，让一次路，记得对方不吃香菜，日常里处处是戏。它最适合中短篇，同样的字数里装的信息最多。两个主角各自蒙在鼓里一半，读者全都知道，双向暗恋的信息差就在这里。作者不用费劲编事件，随便一个动作都有弦外之音。

#### ↺ GB 语境的关键改写

暗恋的一方如果是女攻，「不敢说」的理由不能是害羞。一害羞，她马上退回言情女主的老位置，主导感一下子没了。

她真正的软肋是这样一个念头：他再听话，她也分不清那是自愿还是被迫。她强是强，偏偏强里留着这么一块，让她开不了口。她怕「这话一出口，他俩的权力关系就变了」，怕自己手里的那点掌控力，把他那句“我愿意”弄脏。

|---|---|---:|---|
| 1 | 两条心思分头铺开，用同一件小事的两种说法开场 | 0–8% | 读者觉得自己看明白了 |
| 2 | 错过一：时机不对，一方正要开口，被别的事打断了 | 15–22% | 可惜 |
| 3 | 错过二：听岔了，一番好意被对方照自己的理解读歪 | 35–45% | 揪心 |
| 4 | 错过三：装没看懂。一方心里明白，偏不接茬，而且不接也说得通 | 55–65% | 最难受 |
| 5 | 外面的事逼人表态：调职、婚约、离开、有别人来表白 | 70–80% | 像在倒计时 |

| 变体 | 与主形的差别 | 适用体量 |
|---|---|---|
| 一方先知 | 一方半路发现对方也喜欢自己，从此这一方心里有底。拉扯感弱了一半，却能写出一段很好看的「他明知故问」戏。 | 不限 |

| 多年后重逢式双向暗恋 | 跟 [[破镜重圆]] 是一路 | 不限 |

#### 写崩的三种方式

1. 三次错过原因都一样，都是「刚要说就被打断」。同一种套路读者最多忍两回。正解：时机错／解码错／主动错，三种各用一次，第三次必须是主动的。

2. 误会一句话就能解开。角色偏偏不说。角色显得像智障，读者也被逼得暴躁。正解：给「不说」一个读者认可的理由，GB 里最好用的就是上面讲的「说了会污染他的同意」。

3. 说破之后没有第二幕。一表白就完结，后面全是糖。双向暗恋的说破点要是放在 90% 以后，那就是短篇的结构。写长篇的话，说破必须落在 55–65%，说破之后马上要冒出新问题，通常是「现在权力关系怎么算」。

#### 可直接用的素材

- 主动错的句式：她看懂了，却说一句明显在敷衍、对方又没法反驳的话，转身走掉。收尾写身体的反应，别写心理活动，例子见《失忆后你和霸总破镜重圆了》六节。
- 对照开场：同一件小事写两遍，一遍从她的视角，一遍从他的视角，两段的理解完全相反。500 字之内，就把全书的信息差定下来。
- 状态板字段：`【她以为他】｜【他以为她】｜【读者知道】｜【错过计数】__/3`，信息差就这样摊到明面上。

#### ↺ GB 方向反转

GB 圈里的“下嫁”，说的是女方屈尊娶了门第低的男方，或者高门第的男方嫁进女方家，和 BG 圈的用法正好相反。
婚是她来娶，婚书出自女方家，聘礼也是女方备。男方进门。
女尊设定里更狠，叫“嫁妻随妻”，进了妻家的门，人就归妻家管，见《墨氏家规》2.1 皇权层。
打 tag 时不写明谁娶谁嫁，读者会照 BG 的习惯，从第一章起就读反。

#### 结构公式

婚约成立，双方各自的理由 → 同居第一条规矩 → 第一次真正的合作 → 第一次真正的冲突 → 重新签一次（自愿版）

#### 为什么有效

先婚后爱把恋爱小说的顺序倒了过来，先有结构，后有感情。图的就是「不能走」：两个人被合法地关在同一个空间里，一次沉默、一次让步、一件多做的小事，都会被放大。它算是合法版的 [[骨科]]，一样难走，只是还没到走不掉的程度，也算是社会化了的 [[契约关系]]。

婚姻本来就是一套现成的权力制度，读者不用教就懂：谁掌家，谁管账，谁上族谱，谁给谁行礼，这些规矩一摆出来，等级自己就立住了，放在 GB 里尤其好用。作者想省事，直接把坐在位子上的人换个性别，制度的实感马上就有。不用多花力气。《墨氏家规》第八节第4条讲的「性别倒置式女尊」就是这个，判定标准写在那里。代价是这份权威来自现成的制度，作者没有自己搭。

#### 写崩的三种方式

1. 婚只是背景。领了证／拜了堂以后，两人相处跟普通同居一样，没有一条规矩、一个亲戚、一场仪式是因为「已婚」才出现的。正解：婚姻值钱，是因为它带来了第三方，公婆、族老、同僚、下人。至少让三个配角因为这层关系对主角有立场。

2. 两个理由都是「家里逼的」。动机一样，冲突就没了。正解：两人的理由性质要不同，一个防守，为了躲开更糟的婚事，一个进攻，冲着某样资源去。这样撞到一起才有真戏。

3. 第 7 拍缺席。感情一到位就直接 HE，从头到尾没有一次形式上的重签。先婚后爱好看，好看在那次重签：同一套仪式，第一次是被安排的，第二次是自己选的。少了它，前面铺的制度全白费。

#### 写崩的三种方式

1. 作品根本不知道自己写的是个加害者。叙述视角和施害者的自我洗脑捆死在一起，她每次越界前都能在心里找个「为他好」的借口，文本也不露一点反讽。读者没了判断的依据，情感只能跟着主角走，除了「认同」别无选择。正解：加一个知情的旁观者，或者一段事后的迟疑，或者一次被拆穿的自辩。

2. 后果被抹掉了。神医／灵药／异能／系统面板把伤害一笔勾销，想加多重就加多重。正解：至少有一次伤害真正留下后果，之后的做法也跟着变。

3. 把「非自愿的自愿化」当成关系的证据。角色起初被迫，半路变成享受，作品就回过头把整段关系改判为「他其实是愿意的」。这是这一类型的核心幻想，不必、也没法从题材里拿掉。作者得知道这是幻想，别把它当成两人真心相爱的证据。知道的作者能写出层次，角色怎么说服自己，本身就有大量内心戏可写。不知道的作者，写出来的就是一个自以为深情的加害者。

#### 可直接用的素材

- 合法性来源卡：`战胜 / 皇命 / 债务 / 契约 / 生理设定 / 家族授予`，用在第 1 拍，一行交代完。选定了全书就不准再换，换了就是作者在给自己找台阶。
- 顺从合法性卡（第 4 拍，决定全书基调）：`赎罪型 / 内化型 / 苦行型 / 博弈型 / 驯化外壳型 / 自我量刑型 / 交易伪装型`。前五型出自《墨氏家规》三节，第六型出自《失忆后你和霸总破镜重圆了》，第七型出自《风起云涌》。
- 叙述距离开关：她每自我合理化一次，就接一段知情配角的沉默。不用台词。一个没接话的下属就够。

#### ↺ GB 语境的方向与它的学理陷阱

这里被救的是男方。救人的是女方。
这样配正好撞上 Huang et al. (2026) 对第四爱问得最狠的一句：男方能露怯，是因为女方替他兜着底，还是女方其实在当传统的照护者？原话是 "the male partner's ability to embrace vulnerability may be contingent on the female partner providing a 'safe space'"，见 [01-总论/03-研究文献与理论框架](../01-总论/03-研究文献与理论框架.md) 1.3。
所以纯救赎文里的女主表面再强势，写到底干的还是照顾人这份老活儿。这可以写。但这个矛盾是结构里自带的，有社会学上的依据。作者可以把它当缺陷来写，也可以干脆拿它当主线。
怎么用，见 [[04-关系张力设计]] 里「内建的关系裂缝」那一节。

#### 结构公式

`症状先于病因 → 一次不带条件的善意 → 他试探这份善意的底 → 病因揭晓 → 复发（必须有）→ 他自己走出来的那一步`

#### 为什么有效

救赎文满足的是「我能修好一个人」这份幻想，代价是两边付出不对等。一个人有东西可给，另一个人还不上，这中间就有了权力差，所以救赎跟 GB 天生合得来。

也因为这份不对等，救赎在道德上最经不起细看。他要是从头到尾只管接受，就成了一件待办事项。

#### 写崩的三种方式

1. 救赎写成了单方面治病：她一直给，他一直收，全书找不出一件他为她做的事。两个人成了医生和病人，算不上伴侣，女主也被结构钉死在照护者的位置上，Huang et al. 批的正是这一点。正解：第 7 拍他必须为她做一件她自己做不到的事，而且要趁他还没「好」的时候做。少了这件事，这场救赎就是假的。

2. 病只在剧情需要时发作：该虐了他就崩溃，该甜了他就正常，该办正事了他一点症状都没有。比闹钟还准。正解：给症状定一个跟情节无关的固定触发条件，比如某种气味、某个钟点、某种声音，再挑一个最不该发作的时候让它发作一次。读者等的就是这一下。

3. 救赎写完，人也没了。他的人格全是那点创伤，病一好，人就空了，后面再没他什么事。正解：第 1 拍之前先给他一个跟创伤无关的欲望，可以是事业上的目标、一门手艺、一个他想赢过的人。创伤治好了，他还能靠这个欲望接着行动，不然写出来的只是一份病历。

#### 可直接用的素材

- 症状卡「他不吃的东西｜他不进的房间｜让他过度反应的那句话｜他睡觉的姿势」四格都填上，一格也不解释，读者自己会往下追。
- 状态板字段：`【症状】｜【触发条件】｜【病因知情者】｜【他为她做过的事】n 件｜【复发计数】`。这些字段全书都不做解释。
- 反向照护钩子：他替她做的那件事，最好挑她下属都不敢做的。这比直接写他对她好更扎人。
- 她做完就走，不看他反应，不等他道谢。要紧的是事后不提。不附任何条件。

#### 写崩的三种方式

1. 职场只当了背景板：写了公司，可一个业务问题、一次真做的决策、一场因工作起的冲突都没有。正解：至少有一次感情转折是业务决定引出来的，比如她否掉了他的方案，或者她做错的事他做对了。

2. 权力差只拿来调情，从不让谁付出代价：办公室里暧昧了半天，没人发觉，没人举报。也没人吃亏。正解：第 5 拍必须有第三方因为这段关系吃了亏，或者站出来质疑，而且质疑得站得住脚。

3. 一辞职什么都解决了：感情要往前走，他就辞职，或者她就调走，权力差说没就没。这段关系里唯一绷着的那根弦被剪掉，换来一颗糖。正解：第 6 拍的放手必须付出看得见的代价，比如他的项目、她的考评、某个第三人的机会。第 7 拍要写的是：职权关系没了，感情里的主导权还在原处。

### 复仇

`T` `△虐心` `△虐身`
`古代女尊／现代都市／架空` `全制度` `1v1／np` `强势主导` `复仇／重生`
来源：`【圈内共识】` + 词频 36 篇 / 0.6%

#### 结构公式

仇要具体到能一件件数出来 → 拿到手段 → 第一次动手（必须爽）→ 代价露头 → 仇的对象转移 → 清算或放下，选哪样都得付出东西。

#### 为什么有效

复仇文难在第二幕以后容易空转。读者从第一章起就盯着那个结局，目标越清楚，到手那一刻越容易泄气：仇报完了，接下来写什么？

GB 里最值得写的一种配法：她的仇冲着一套制度去，男主偏偏是这套制度养出来的。她要拆的东西成就了他，她赢的那天，他会丢掉自己的全部位置。这么一配，复仇线和感情线就拧在了一起，分不开。

| 3 | 第一次动手必须解气，后面付代价的时候才有落差 | 22–32% | 解气 |
| 4 | 代价第一次露出来：她为报仇搭进去了一样本来没打算丢的东西 | 40–52% | 心里发沉 |

| 变体 | 与主形的差别 | 适用体量 |

| 重生复仇 | 靠预知后事抢先手，见 [[重生]] | 不限 |
| 马甲复仇 | 她换个身份去接近仇家，见 [[马甲掉马]] | 不限 |
| 复仇对象是恋人的家族 | 想把两条线拧成一股，这样最省事 | 不限 |
| 代理复仇 | 她替死人报仇，真主线是她跟死者什么关系 | 不限 |

#### 写崩的三种方式

1. 仇人变蠢：一个能灭她满门的人，之后每一步都踩空。正解：给对手一样她没有的资源，时间、位置、一个她在乎的人质都可以，而且让他起码赢一个回合。
2. 仇报完了，后面没有第二幕：要么报完仇书就完，要么完不了只能硬拖。正解：第 5 拍的对象转移必须落在 55–68%，给下半本一条新主线。也可以把复仇本身设计成到最后一刻会失去意义的事。
3. 复仇线和感情线各走各的：她白天报仇，晚上谈恋爱，两条线从来不碰。正解：让男主跟仇家之间有一层她割不断的关系，比如他是仇家的儿子，欠着仇家一条命，或者是仇家一手养大的。这样第 6 拍就有着落了。

### 追妻火葬场 ↺★

`M` `△追妻火葬场` `△虐心` `△失忆(常见)`

#### ↺ GB 方向反转（套路名里的「妻」在 GB 语境指男性）

GB 里说「追妻」，追的人是女方，被追的是男方，字面上那个「妻」指的是男的。

这跟 BG 正好反过来。BG 的追妻火葬场是男主追女主，GB 的追妻火葬场是女攻追男受。
加害的是她，被辜负的是他。有的作者怕读者误会，会标成「追夫火葬场」，但库里还是标「追妻火葬场」的多。
比如《失忆后你和霸总破镜重圆了》标的就是 `△追妻火葬场`，整本书其实是女方在追，书里他被辜负了七年。

[02-术语百科/05-易混淆词辨析](../02-术语百科/05-易混淆词辨析.md) 的 tag 自查清单把它单列成第 7 条：
「火葬场是谁追谁？GB 语境下「追妻/追夫」的指向与 BG 圈相反。极易读反。」
所以文案里必须写清楚谁追谁，这个套路最常出的事故就在这儿。

#### 结构公式

建立愧疚，读者先知道他受了什么，再知道她是谁 → 罪证列成清单 → 逐件覆写 → 幕间断裂（抽走对手戏）→ 独自证明 → 重逢 → 裁决权交还

#### 为什么有效

火葬场让人上头的是「后悔也来不及了」。光有悔意没什么看头，好看的是悔意撞上了墙：对方已经学会不再期待。

这个套路最要紧的手法是**把罪证列成清单**，《失忆后你和霸总破镜重圆了》第三节末尾那段原话讲得很清楚。篇幅撑不下去，多半是「追」没有具体的对象，只能靠情绪来回拉扯。

GB 还多一道难题：女攻天生带着「主动、掌控、施加」这些属性，一越界就成了加害，偏偏这个类型又爱写越界。
下方素材段那套「渣女从良」六步豁免程序，就是专门给 GB 配的解法。

##### ★ 转折点位置：全书 4%

`实测`。极早，教科书级。

两人第一次通话，她说「我没签离婚协议书」，他听成了「你要在离婚前最后折磨我一次」，就跟她讨价还价，请几天假，玩几种道具，说到最后几乎是在求她。
这一下同时做了四件事：不用直写就交代了过去七年的虐待，让读者心疼男主，让读者第一次尝到罪的滋味，也把「失忆」从一个设定变成了痛处。
位置怎么定，细则见 [[03-开篇钩子与节奏控制]]。

#### 写崩的三种方式

下面前两条，是《失忆后你和霸总破镜重圆了》第九节实测出来的崩点

1. 加害跟赎罪分量差得太远。把这篇两边的事列出来，恶行一栏全是刑事案件的级别，赎罪一栏全是鸡毛蒜皮。作者让加害者失忆，把一个人切成两个，好躲开这些罪，可读者的记性没被切掉。正解：要么把恶行写轻一点，要么让赎罪付出同样重的代价——放弃权力、坐牢、失去一样她真正在乎的东西。

2. 受害者原谅得太快。这篇里两人重逢，他听了四句话就答应再给一次机会，作者自己在文中也点了出来，等于承认是在赶进度。一个人花七年学会「接受、容忍、退缩」，这套防御不可能在街头一次谈话里就塌掉。正解：把复合的门槛写成一套流程，考核期、条件清单、第三方担保，用哪个都行。

3. 拿失忆当全套免罪：主角对自己「记得的事」从来不担责任。正解：留一笔没还完的债，比如记忆别全恢复，父亲的诘问不给答案，或者她给自己设一个随时可能被判不及格的考核期。有这一笔欠着，读者才不会觉得作者在硬洗白。

| 恶行 | 在身上纹字羞辱人 | 刑事级 |

### 马甲掉马 ★

`T` `△误会流`
`星际科幻／现代都市／古代` `全制度` `1v1／np` `势均力敌／双向拉扯` `马甲掉马／身份替换`
来源：《女Alpha掉马后果很严重》 第九节全节 + 词频 30 篇 / 0.5%

#### 结构公式

立马甲 → 埋暗雷 → 擦边 → 成本显形 → 制度性对手上线 → 偶然证据 → 陷阱 → 掉马 → 权力翻转 → 克制 → 单方付出 → 对照组 → 对方破译 → 补完 → 合伙 → 代价结算

#### 为什么有效

掉马文好看在她一直硬撑，读者每时每刻都觉得「她快撑不住了」。

她装下去要付的代价，由两样东西拼成：她最珍视的人，她最擅长的事。
马甲想撑得住戏，就得把自己最厉害的那一手藏起来，还得躲着最想亲近的人，两条少一条都不行，少了马甲就只是个摆设。

##### 四层马甲结构

《女Alpha掉马后果很严重》 9.1

马甲一层套一层。
有几层马甲，就能写几次掉马。单层的只能掉一次。掉完戏就散了。四层马甲能把「掉马」拉成一条贯穿后半本、一步步往深里解的线。

| 层 | 内容 | 该篇何时破 |
|---|---|---|
| 1 | 我不是原来那个人（身份） | 55.9% |
| 2 | 我从别的世界来（来历） | 65%，被骗的人自己琢磨出来的 |
| 3 | 我身上有你们没有的东西（生理） | 31%，比身份马甲先露馅 |
| 4 | 我来就是为了弄垮你（意图） | 76%+，压到最后才说 |

##### 五路人推着他往前查

9.3

她身边能推着他往下查的有五类人：爱她的，跟她过不去的，不相干的第三方，照规矩办事的，还有她本人。五类里至少凑齐三类，掉马才不生硬。

推得最狠的那个必须是恋人，否则掉马伤不到感情。

##### 三条铁律

原文照录。

| 铁律 | 理由 | 跳过的后果 |
|---|---|---|
| 第 6 拍（陷阱）不能用证据 | 拿出证据就成了审讯，设个陷阱才有戏 | 被骗的人没能亲手确认自己被骗，疼就少了一半 |
| 第 9 拍（克制）是全表的枢纽 | 让读者看到施压的人明明能用，却选了不用 | 被骗者成了施虐者，之后怎么和解都没说服力 |
| 第 12 拍必须给被骗者 | 真相得由他自己拼出来，他才找得回主体性 | 要是主角哭着把真相交代了，被骗者就一直被动，权力关系再也扶不正 |

##### 掉马方式的三种基础模式

9.4

| 方式 | 效果 | 代价 |
|---|---|---|
| 主动坦白 | 读者不会因此给主角扣分，也不讨厌她 | 冲突弱。一句“我本来就没想瞒你”就把事说轻了，像聊天 |
| 被动暴露 | 冲突最猛，最丢面子 | 主角显得窝囊或者心眼多，后面要找补 |
| 第三方揭穿 | 能把水搅浑，适合群像和朝堂戏 | 两个主角只能被动挨着，感情线被冲淡 |

> 读者给掉马打的道德分，看「不说」的理由是自保还是护人。同一个情节，理由从自保换成护人，观感就整个翻过来。

| 变体 | 与主形的差别 | 适用体量 |
|---|---|---|
| 身份替换 | 她顶了一个真人的位置，叠加 [[替身]] | 不限 |
| 能力马甲 | 藏起来的是本事，身份照旧，算大佬马甲，马甲文的轻量版 | 不限 |
| 多马甲 | 她有 N 个身份，一个个被揭开。多马甲 ≠ 多层马甲：前者并列，后者一层套一层，套着的才能递进 | 不限 |
| 马甲 + 女扮男装 | 性别和身份走同一套证据，见 [[女扮男装]] | 不限 |
| 他也有马甲 | 双向掉马，翻两次 | 不限 |

#### 写崩的三种方式

1. 掉马来得太晚。《女Alpha掉马后果很严重》书名许下的那件事，拖到 55.9% 才发生，掉马之前将近 18% 的篇幅在写支线，「她随时会露馅」的紧张感被冲得很淡，读者的耐心也早磨没了。这是该篇第八节第 1 条自己承认的。教训：马甲文的掉马点别晚于全书 45%。
2. 破绽只出在「失误」上，从不出在「好习惯」上：让她说错一句话就露馅，这种写法最廉价。正解：让她输给自己的优秀，比如车太干净，后备箱里放着生存装备，在拘留室里背了一夜军事史。好的伪装者栽在自己的优秀上，比栽在失误上高明得多。
3. 跳过第 9 拍或第 12 拍。少了克制，被骗者就成了施虐者，少了破译，被骗者就一直被动。这个套路跟别的套路就分在这两拍上，宁可砍掉别的，也不能砍它们。

#### 可直接用的素材

- 状态板字段（马甲文用）：
  ```
  【马甲层数】身份 / 来历 / 生理 / 意图   已破：__ 层
  【装下去要付什么】本回合被迫藏起来的本事：____
  【逼近度】恋人 __ ／ 忠仆 __ ／ 第三方 __ ／ 制度 __ （0-5）
  【倒计时】____ 剩余：__
  【主动权】本场归属：女 / 男   累计比分：__ : __

### 破镜重圆

`T` `△虐心` `△误会流`
`现代都市／古代／娱乐圈` `全制度` `1v1` `双向拉扯` `破镜重圆／追妻火葬场`
来源：`【圈内共识】` + 词频 29 篇 / 0.5%

#### 结构公式

破镜发生在开篇之前 → 空白期的证据 → 被迫重逢 → 各自亮出这些年的变化 → 旧账被翻出 → 谈重圆的条件 → 同一个场景重演

#### 为什么有效

破镜重圆跟普通恋爱只差一件事：这两个人早把对方的底摸透了。初见时的试探、误判、猜来猜去全都省了，换来的东西更难写，也更带劲。他们太清楚对方会怎么接，所以每句话出口之前，心里都先掂量了三遍。

结构上的头一条硬规矩：破镜重圆从重逢那一刻开篇。要是从相爱写起，写到分手，再写复合，就成了一本恋爱小说加一本破镜重圆。两头都散。所以重逢必须放在开头，当初怎么破的，用闪回补上。

#### 节拍表

口径：`建议`

| 拍号 | 发生什么 | 篇幅占比 | 情绪目标 |
|---|---|---:|---|
| 1 | 开篇就重逢。为什么分手先不交代，只让读者知道「已经分了」 | 0–5% | 悬念 |
| 2 | 分开那段时间留下的痕迹露出来：他哪儿变了，身边多了谁，哪些事不再做了 | 5–15% | 心惊 |
| 3 | 两人有了非待在一起不可的理由：工作、家里、孩子，或一件躲不开的事 | 15–25% | 锁死 |
| 4 | 分手的真正原因头一回揭开一半 | 30–42% | 重估 |
| 5 | 旧事翻出来，两人记得的却对不上 | 50–62% | 痛 |
| 6 | 把复合的条件摆到桌面上谈 | 70–82% | 现实感 |
| 7 | 同一个场景重演一遍，这回结果变了 | 88–98% | 兑付 |

#### 常见变体

| 变体 | 与主形的差别 | 适用体量 |
|---|---|---|
| 多年后重逢 | 分开得越久，第 2 拍越好写得实在 | 不限 |
| 破镜重圆 + 追妻火葬场 | 一方理亏，见 [[追妻火葬场]] | 不限 |
| 破镜重圆 + 失忆 | 一方忘了为啥分，见 [[失忆]] | 不限 |
| 未离婚的破镜重圆 | 证还在，情没了，制度和感情反着拧，GB 里最好用的一种 | 不限 |
| 破镜不重圆 | 带 `⚠️BE` | 不限 |

#### 写崩的三种方式

1. 拿误会当分手的原因。一句话就说得清的误会，撑不起分开的那些年，读者只会怀疑这两人脑子有问题。正解：分开必须出于真实的分歧，两个人要的东西不一样，当时谁也没做错。这就是 [[04-关系张力设计]] 里讲的「内建的关系裂缝」，用好了比什么招都强。
2. 空白期里两人一点没变，重逢时还是当年那副样子，分开的这几年就白写了。这个套路就靠空白期撑着。正解：第 2 拍至少给出三处看得见的变化，其中必须有一处是变坏了。
3. 靠外力重圆：孩子、绝症、车祸，硬把两人凑到一起。这等于拿走了他们自己选的权利，重圆还有什么意思。正解：第 6 拍必须是一场谈判，复合要写成一份有条件、讨价还价谈出来的协议，抱头痛哭一场不算数。

#### 可直接用的素材

- 第 7 拍的重演钩子：第 1 拍重逢那场戏原样再演一遍，只改一个动作，其余的情绪留给读者自己补。
- 空白期证据卡：`他现在不吃的东西 ｜ 他现在会做的事（以前不会）｜ 他身边多了谁 ｜ 他删掉/留下的一样东西`，四格里至少要有一格是坏事。
- 第 5 拍写记忆对不上：同一件事让两人各讲一遍，细节有出入，不判谁对谁错，留给读者去琢磨。

### 师生 ↺

`T` `△师生` `△年龄差` `⚠️骨科(拟制亲属情形)`
`现代校园／修仙玄幻／古代` `全制度` `1v1` `强势主导／训诫系` `师生`
来源：`【圈内共识】` + 词频 28 篇 / 0.5%；人设词「师尊」47 / 0.8%

#### ↺ GB 方向反转

修仙版是「女师尊 × 男徒弟」，当师父的是女的，徒弟或学生是男的。攻受方向跟耽美圈常见的「男师尊 × 男徒弟」一样，男女位置却整个反了，所以发文时必须带上「女攻男受」的 tag。
师徒算拟制亲属，有些圈子把它算作 `⚠️骨科`，要标清楚，修真师徒尤其别漏，见 [02-术语百科/05-易混淆词辨析](../02-术语百科/05-易混淆词辨析.md) ⑥。

#### 结构公式

授业关系落地 → 她教的东西他学会了 → 权威第一次被检验 → 她被证明错了一次 → 师徒名分成了障碍 → 出师，关系得换个名字才能继续

#### 为什么有效

师生之间的权力来自知识本身，所以他学得越好，她手里的筹码就越少。这种倒计时只有师生关系才有，别的权力结构里找不到。

她凭什么说了算？凭她教得对。哪天她被证明错了，她在这段关系里就站不住。

所以第 4 拍没得商量，她必须真真切切错一次。她怎么接住这次错、怎么收拾，整本书都看这一下。

|---|---|---|
| 女师尊 × 男徒弟（修仙） | 多出寿命差、心魔、双修这些戏，是库里最经得起写的一类 | 不限 |
| 女教授 × 男学生（现代校园，249 篇校园背景 / 4.1%） | 多一层学术地位和师生规矩的麻烦 | 不限 |

#### 写崩的三种方式

1. 教学只是个空架子：说她是师父，却一次真正的教学都没写，教了什么、怎么教、他哪里没学会，都没有。权威不落在具体的知识上，师生就只剩一个称呼。正解：第 1 拍必须是一场具体的教学，里面要有他做错一个动作、被她纠正。

2. 她从来不出错。全书她一直是对的，他一直在追。这样的关系写不出转折，只能靠外面的阻碍往前推。正解：第 4 拍让她错一次，而且错在她最拿手的领域。

3. 名分靠大家忘掉来解决：到了要在一起的时候，师徒这层关系就悄悄没人提了。正解：第 6 拍必须正式给关系改一次名，出师礼、毕业、逐出师门、改换称谓都行。称谓改了，关系才算变了，见《墨氏家规》第六节。

#### 可直接用的素材

- 称谓阶梯：`师尊/老师 → 全名 → 昵称 → 无称呼`。修真版也能拿自称走同一条线，「弟子/学生」这个自称怎么变，身份就跟着怎么变，见《风起云涌》第六节。
- 教学卡：`她教的第一样东西 ｜ 他最先学会的 ｜ 他至今学不会的 ｜ 他后来超过她的那一项`
- 出师钩子：出师那天，让他用她教的技法赢她一个回合。不用台词，直接打。

### 囚禁 ↺

`M` `⚠️囚禁` `⚠️非自愿` `⚠️主奴(常见)` `△虐身` `△虐心`
`现代都市／古代女尊／架空` `全制度` `1v1／np` `强势主导／调教系／主奴` `虐恋`
来源：`【圈内共识】` + 词频 27 篇 / 0.4%；排雷段中「囚禁」被排 2 次；权力动态 × 尺度交叉表：囚禁 27 篇中 E 级 19 篇

#### ↺ GB 方向反转

关人的是女方，被关的是男方，圈里一般直接叫「圈养」。

「圈养」比「囚禁」更贴 GB 这边的写法：给他一个舒舒服服的地方住，吃穿都不愁，只是别想出门。

放到 BG 那边，「圈养」基本说不通。性别一倒过来，说法也跟着换了一套，这个词是 GB 这边独有的反转词。

#### 结构公式

剥夺行动自由 → 空间成为唯一的世界 → 常态管束加载 → 他能走而不走 → 空间被打破

#### 为什么有效

囚禁把两个人关进一个封闭的地方，社会关系清得干干净净：没有工作，没有亲戚，没有第三个人，剩下的每一次来往都直接是权力上的来往。

不过它在结构上有一条要求，几乎人人都会漏掉：

> 囚禁里必须有「可以离开却不离开」的那一刻，少了它，就只是监禁。

少了这一刻，读者就判断不了被关的人的反应：他是真爱上她了，还是根本没得选。这一拍一般放在全文70–80%的位置，是全书最要紧的一拍。

##### 软囚禁 = 常态管束

《墨氏家规》2.2③那套「身体权收归许可制」，说到底是不砌墙的关人，细节比有墙的囚禁还细。配额卡死，排泄、进食、穿衣、居住、说话都得申请，一天二十四小时都在场，次数数得清，往上升一档不用加尺度，还自带内心戏。写囚禁不用它，可惜了。

口径：`建议`

| 拍号 | 发生什么 | 篇幅占比 | 情绪目标 |
|---|---|---:|---|
| 1 | 把人扣下，不让走，扣他的理由当场交代：战俘、欠债、皇命、签了契，或者他自己点了头 | 0–8% | 定性 |
| 2 | 立下这里的规矩：哪儿能去，哪儿不能去，什么时候才轮到他开口 | 8–18% | 秩序 |
| 3 | 日常管束开始：一件天天要做的事，从此得申请，按定量给 | 15–25% | 24 小时有人盯着 |
| 4 | 他逃过一次，没逃成，代价摆在眼前 | 28–38% | 绝望 |
| 5 | 破例：她第一次松口，他把这次当成念想 | 40–55% | 分母/分子 |

#### 常见变体

| 变体 | 与主形的差别 | 适用体量 |
|---|---|---|
| 金丝雀式圈养 | 住处漂亮，伺候周到，就是出不了门，GB 里最常见 | 不限 |

#### 写崩的三种方式

循环 C 里《墨氏家规》的张力，并不靠第 3 拍继续加码。关得更严、罚得更狠、锁得更死，这种痛感撑不了几轮就麻木。真正让读者心头一紧的，是「恩典的收回」——某项破例早已成了默认，某天突然不给，什么都不用多做，效果反而翻十倍。

第 2 拍的毛病是囚禁不费事：关一个人不用人手，不用花钱，不会被人撞见，也没人来找。正解：给囚禁配几样躲不掉的麻烦，比如一个得花钱收买的看守，一个会上门来问的亲戚，一笔每月都要出的开销，一个必须编谎话填上的空缺。情节会从这些麻烦里自己长出来。

第 6 拍一定要硬。这是全书唯一的出口，读者得亲眼看见门是开着的。要是第 1 拍没有「可以走而不走」的那一刻，他后面一直没得选，他的顺从就说不清从哪来，是爱还是斯德哥尔摩，读者也判断不了。正解就是让门开着。

#### 可直接用的素材

- 状态板字段：`【空间范围】｜【常态管束配额】今日 __/__｜【已破例记录】｜【他能走的机会】已出现 n 次｜【关一个人要打点什么】人手 __ / 开销 __ / 待解释的空缺 __`
- 空间卡：`他能去的地方 ｜ 他不能去的地方 ｜ 唯一一扇能看见外面的窗 ｜ 他每天必须做的一件事`
- 能走的那一刻：门开着，看守不在，他就站在门口。接下来写他去做了件别的事，把桌子收拾干净，或者把一样东西放回原处。他心里怎么想，一个字也别写。
- 配额钩子：挑一件生理必需、天天要做的事改成许可制，写明配额，比如「每日两次」。数字加减就是奖惩，不用新道具、新场景。

> 必读附件：跟 [[强取豪夺]] [[训诫循环]] 一样，要和《墨氏家规》的「虚构与现实的区分」附节一起读。把排泄、进食、睡眠、就医这些生理必需的事改成许可制，在小说里是一天 24 小时都绷着的戏，放到现实中就是有明确医学危害的虐待，「他同意」也改变不了这一点。

### 失忆

`T` `△失忆` `△虐心`
`现代都市／古代／架空` `全制度` `1v1` `双向拉扯` `失忆／破镜重圆／追妻火葬场`
来源：《失忆后你和霸总破镜重圆了》 七节·三 + 词频 26 篇 / 0.4%

#### 结构公式

`清空 → 零信息的第一次互动（必须出错）→ 碎片式回归 → 旧我与新我的第一次冲突 → 一个只有旧我知道的秘密 → 不完全恢复`

#### 为什么有效

失忆常被拿来制造误会，这是它最低级的用法。

失忆真正好用的地方，是一个设定能办成三件事。《失忆后你和霸总破镜重圆了》第八节第 2 条把它当作「设定经济性的范本」：

| 办了哪件事 | 怎么办到的 | 省掉了什么 |
|---|---|---|
| 信息缺口 | 主角蒙在鼓里，读者跟着她一点点弄明白 | 悬念不必靠全知视角来埋 |
| 罪的豁免 | 害人的和赎罪的拆成两个人格 | 读者可以心安理得地站在加害者一边读到底 |
| 让读者钻得进去 | 主角被清空了，跟读者一样什么都不知道 | 读者用不着费劲往里挤 |

同卡七节·三·4 写道：「第二人称与主角信息不足这个设定是绑定销售的。」第二人称作品几乎都靠这一点活着。要是「你」什么都知道，叙事只能退回全知视角，视角一全知，第二人称的代入感就没了。

口径：`建议`，关键位置参考 《失忆后你和霸总破镜重圆了》 `实测` 值

| 拍号 | 发生什么 | 篇幅占比 | 情绪目标 |
|---|---|---:|---|
| 1 | 清空。别写她醒来盯着天花板，写她做一件只有从前的她才做得对的日常小事 | 0–3% | 错位 |
| 2 | 第一次打交道，双方都不知底细，而且必须搞砸：她出于好意，对方按老眼光一读，就成了恶意 | ≈4% `实测` | 痛点成立 |
| 3 | 安排一个明白人，管家、助理、医生或同僚都可以，要知道内情，又不站队 | 5–12% | 世界可读 |
| 4 | 零碎地想起来，一律写成“她看见／她听见自己的声音”，像在看别人 | 13–50% | 罪的旁观 |
| 5 | 旧我和新我第一次撞上：她做了一件从前绝不会做的事，被人看出不对 | 30–45% | 她是谁 |
| 6 | 有个秘密只有从前的她知道，它是打开全书最大反转的钥匙 | 60–92% | 悬念 |

#### 常见变体

| 变体 | 与主形的差别 | 适用体量 |
|---|---|---|
| 失忆 + 追妻火葬场 | 最主流的复合，见 [[追妻火葬场]] | 不限 |
| 他失忆 | 方向倒过来：只有她还记得，整本书靠她一个人扛着这份记忆往前走。少见，好写 | 不限 |
| 双失忆 | 两人都忘了，从头开始，冲突最少，最甜 | 不限 |
| 选择性失忆 | 只忘了一个人，或一段日子，忘得越准，戏越集中 | 不限 |
| 假失忆 | 她装的。叠一个 [[马甲掉马]] | 不限 |

#### 写崩的三种方式

1. 拿失忆当免死金牌：主角对自己「记得的事」一概不认，一句「我不记得了」，旧事就全抹干净了。正解：留一笔没还完的债，记忆别全恢复，至少留一件旧罪，她想起来以后还得接着扛。

2. 把「恢复记忆」写成大结局：全书都在等她想起来，一想起来就 HE，前面攒下的感情全白费了。旧我回来了，新我这几十万字又算什么？正解：中后段让「恢复记忆」这个话题干脆消失，该篇 58% 以后就再没提过。焦点从「她会不会想起」挪到「她会不会又变回去」。

3. 失忆时的她和恢复后的她是两个人，作品却当没这回事：她一想起来，前面那个温柔的她就凭空没了。谁也不提。正解：让第 5 拍的冲突一直延续到结局，必须有一个人，通常是男主，说明白他爱的是哪一个，并为这个选择付出代价。

#### 可直接用的素材

- 状态板字段：`【记忆恢复度】x / 10（永不到 10）｜【解说员】｜【只有旧我知道的事】｜【恢复后仍要承担的旧罪】`
- 解说员这么设：有理由知道内情 + 没有立场 + 兼当共谋，替她背锅，替她圆场。失忆故事和第二人称故事都少不了这个位置。
- 清空钩子：挑一个只有旧我才做得对的日常动作，让她做错，用错手，坐错位置，给了不该给的东西，对熟人用了生分的称呼。
- 旁观化闪回句式：`她看见 / 她听见自己的声音 / 梦里的那个她`。语法上，动作算在「梦里的她」头上，没算在「她」头上，读者也就从亲历者退成了观众。

### 替身 ↺

`T` `△虐心` `△第三者`
`现代都市／古代／星际` `全制度` `1v1／np` `双向拉扯` `替身／马甲掉马`
来源：`【圈内共识】` + 词频 21 篇 / 0.3%

#### ↺ GB 把方向反过来，而且有两种完全不同的写法

| 哪一种写法 | 谁是替身 | 与 BG 圈的关系 | 库内状况 |
|---|---|---|---|
| 写法一（GB 主流） | 男受当替身，她在他身上找另一个人的影子 | 跟 BG 圈「女主当替身」的方向相反 | 主流 |
| 写法二（更稀缺、也更狠） | 女攻当替身，她占了一个真实存在的人的位置 | 见《女Alpha掉马后果很严重》：主角顶了本尊的身份，本尊爱着男主，被杀后只剩一颗冷冻大脑，眼看着自己的替身得到她想要的一切 | 精读时这个角色被评为「全书最有潜力的悲剧，却被浪费了」，库里已经验证过，这个空位有价值 |

这两种写法不能混用，混了读者就不知道该替谁难过。

#### 结构公式

`正主的位置被写明 → 替代关系成立 → 替身开始偏离正主 → 有人指出这个偏离 → 正主（或其证据）现身 → 「我爱的是你不是他」必须由行动交付`

#### 为什么有效

替身的痛说不出口，也没处讲理：他明明被爱着，她爱的却是另一个人。他越用力，越像那个被拿来比的人，想靠“我做得更好”翻身，是翻不过来的。

| 2 | 替身关系成立，替身自己也心里有数，他要是不知道，劲儿就少一半 | 8–18% | 定调子 |
| 3 | 替身开始跟正主不像了：他做了一件正主绝不会做的事 | 25–38% | 露真身 |

#### 写崩的三种方式

1. 正主没有人格：只是一个符号、一张照片、一个名字，从头到尾没被写成有缺点的活人，全书的痛也就都是假的。为一个不存在的人吃醋，读者跟不上。正解：给正主至少一个具体的缺点，这个缺点要是替身身上没有的优点的反面。

2. 替身怎么看自己，从头到尾没变过，第一章到最后一章，他都是那个卑微的、知情的替身。正解：第 3 拍他必须主动做一件正主绝不会做的事，让她因为这件事第一次看见了他。

3. 「我爱的是你不是他」只靠一句台词来说，一句表白就把替身的痛全打发了。读者不会信，这句话太好说了。正解是用行动。第 5 拍的「对照组现身」就是现成的办法：把一个更合适的人选送到她面前，让她当面拒绝。《女Alpha掉马后果很严重》场面 C 里，对方还没开口，她就先说了「我反对」。

### 雄竞 ↺

`M` `⚠️np` `△虐心`
`古代女尊／现代都市／星际` `女尊制／现实性别制度` `np（一女多男）／逆后宫` `训诫系／强势主导` `虐恋`
来源：《墨氏家规》 2.3 循环 B + 词频 18 篇 / 0.3%；关系结构：np 1,212 篇 / 20.0%、逆后宫 31 篇

#### ↺ GB 方向反转

跟 BG 和宅斗里的雌竞正好反过来，这边是男的去争，女的被争。

「统御众多男性」图的是权柄，女主在制度里说一不二。英文圈的 reverse harem 另是一回事：那里的女主「并非凌驾于她的男人们之上，而是与他们并列」，她求的是「被众多男性珍视」，图的是丰盛。女尊后宫要的是掌控。

拿 np 女尊当 why choose 去卖，读者的预期对不上。一看就炸。[01-总论/04-英文圈生态与出版市场](../01-总论/04-英文圈生态与出版市场.md) 7.2 讲过这件事。

#### 结构公式

`位序表落地 → 点明大家在争什么 → 第一次位序变动 → 竞争产生同盟 → 有人退出竞争 → 位序最后怎么收`

#### 为什么有效

雄竞能真正转起来，靠的是《墨氏家规》 2.3 循环 B 讲的惩罚经济学：

```
妻主的注意力是稀缺资源 → 受罚是获得注意力最可靠的方式
→ 惩罚从「代价」变成「货币」→ 五个男人竞相求罚 → 雄竞
```

这套怎么往下推、群像怎么照应，见 [[03-开篇钩子与节奏控制]] 的「np 结构专论」。

##### 位序设计的三条规则

《墨氏家规》 2.2①
位序要分奇数级，中间那层得能升能降，最顶上和最底下各留一个谁也抢不走的位置。有人升了或降了，其他人都得马上跟着有反应。

#### 写崩的三种方式

1. 位序中间没有能动的层：谁上谁下，从第一章定到最后一章。位置不动，就只剩站队，谈不上竞争。正解：级数取奇数，中间几级设成能升能降，顶层和底层各留一个谁也争不走的位置。

2. 谁得宠谁失宠，没有一个看得见的数，全靠读者自己去体会。正解：给一个看得见的量，位份、份例的数目、座次，或者只有第一名才拿得到的一样东西。《风起云涌》里，管家当场按 1:10 给女主算份例，还说提到 1:2 就「不合情理」。

3. 男配彼此之间没有关系：每个人只跟女主连着线，互相之间一点来往都没有，群像就成了 N 条平行的 1v1，读到第三条就腻了。正解：至少给两组男配安排各自的关系，旧交、宿仇、师承、亲缘都行，这层关系从头到尾不用女主在场。

### 契约关系

`T` `△职场权力差`
`现代都市／古代／星际` `全制度` `1v1／np` `势均力敌／强势主导` `契约关系／先婚后爱`
来源：`【圈内共识】` + 词频 15 篇 / 0.2%（注意：这个数字严重低于实际：「契约」常被写进文案正文而非标签区，属于统计口径漏抓）

#### 结构公式

签协议 → 头一回照办 → 头一回越界 → 有人钻空子 → 日子快到了 → 重谈或者撕掉

#### 为什么有效

契约把一段关系写成了白纸黑字。白纸黑字能被引用，能被曲解，能被钻空子，也能被撕掉，这个套路的戏就出在这四件事上。作者因此多了一样别的套路没有的便利：冲突可以全从「条款怎么解释」里长出来，用不着外面出事。

GB 里的规矩一落到纸上，戏就容易写死。反过来说，契约把「谁说了算」直接摆了出来，读者也就不再追问「女主凭什么压男主一头」，[[强取豪夺]] 要背的那份道德负担也免了。代价是上限低，《墨氏家规》2.4 就写明了：规矩别写死，留在嘴上，权力才没有边。

#### 节拍表

| 拍号 | 发生什么 | 篇幅占比 | 情绪目标 |
|---|---|---:|---|
| 1 | 立约，条款一条条写清楚，至少四条，其中一条以后要出事 | 0–8% | 契约感 |
| 2 | 第一次照章办事，两边都守规矩 | 10–18% | 秩序 |
| 3 | 第一次钻空子：一方字面上守了约，实际没照约办 | 25–35% | 智斗 |
| 4 | 一方拿条款当枪使，另一方被噎住 | 42–55% | 权力显形 |
| 5 | 约定以外的事冒出来：感情、第三方，或一件条款没写到的岔子 | 58–70% | 越界 |
| 6 | 到期的日子越来越近，倒计时压上来 | 72–85% | 压力 |
| 7 | 重新谈约、加新条款，或者撕约，撕要写得实打实 | 88–100% | 定调 |

#### 常见变体

| 变体 | 与主形的差别 | 适用体量 |
|---|---|---|
| 契约婚 | 跟 [[先婚后爱]] 基本是一回事 | 不限 |
| 雇佣契约 | 她当老板，他给她打工，跟 [[上下级]] 的区别是这份工有明确的到期日 | 不限 |
| 债务契约 | 他欠她钱，还不上就拿人抵，见 [[救才子收房]] | 不限 |
| 血契／灵魂契约／标记 | 契约直接写进设定，想反悔都难，但别掉进「生理反应所以不算数」的坑。正解见《女Alpha掉马后果很严重》：单方面占有改成两边互相给，动手的人开始前先跟对方讲明「这玩意儿也会把我绑给你」，再问一句行不行。只改一个词，双向，整套设定的权力关系就变了。ABO 能这么改，契约、血契、灵魂绑定、婚书也都能。 | 不限 |
| 不平等条约 | 条款明摆着偏向一边，吃亏的那方是自己愿意签的。要写「顺从得合理」就用这个，最好写 | 不限 |

#### 写崩的三种方式

1. 条款太含糊。「你要听我的」「你要陪我一年」这种话，违没违反根本判不了。戏也就起不来。正确的做法：条款要具体到能逐条核对，至少写四条，每条边界都清楚，其中一条必须埋雷，后面一定会炸。

2. 到期日压不住人：开头写了「一年之约」，后面整本书没人记得还剩几个月，读者也跟着忘了。正确做法：把倒计时摆到明面上，隔几章报一次还剩多久，或者让配角出来提一句「还有三个月了」。

3. 感情一到位，契约就没人提了。这种崩法最常见，等于把全书最好用的东西白扔了。正确做法：第 7 拍必须有一个具体的动作，重签、撕毁、烧掉、当众宣布作废，或者明知已经没必要，还是一丝不差地履行到最后一天，最后这种最有力。

- 条款卡（第 1 拍，四条起）：

  二、义务方 A：____   义务方 B：____
三、禁止事项：____，这一条日后会出事。
  四、解约条件：____   违约后果：____
  ```
- 擦边钩子，第 3 拍：让一方按字面把约守得滴水不漏，干的却完全是另一码事，对方挑不出错，只能干瞪眼。这一场戏，两个人有多聪明、这段关系是什么性质，都一起立住了。
- 双向化句式，什么单向绑定都能拿它改：「这道程序是双向的，在此之后，我也会彻底地属于你」+ 动手前征求同意，问两遍，先问「我可以吗」，再问「你想要我吗」。
- 状态板字段：`【条款】1–4｜【剩余期限】｜【已擦边】n 次｜【被利用的条款】｜【契约外的事】`

#### ↺ GB 语境的双层反转

女扮男装放进 GB，会同时反转两次，所以比放在别的类型里都复杂：

| 层 | 发生什么 | 读者眼里是什么 |
|---|---|---|
| 第一层 | 她扮成男人 → 男主以为爱上的是男人 | BL 的擦边 |
| 第二层 | 掉马 → 回到 GB（女攻男受）→ 但攻受位不变 | GB 特有的那一下 |

掉马以后位置还在不在，才是 GB 文真正的分水岭。女主女扮男装，身份被揭穿了，她说了算的格局不会跟着性别一起塌。BG 里身份一暴露，基本就退回男攻女受的老框架，GB 里掉马只揭身份，不换上下。「性别变了，但位置没变」最难得，新手也最容易在这里写崩。

另外，这个套路和「男扮女装」在 GB 圈是一对镜像，男扮女装在库里极少。

装要付什么必须写明 → 他被「他」吸引 → 他的自我怀疑 → 性别与身份共用一套证据链 → 掉马 → 主导权不变的确认

这个套路里性别和身份走同一条线。《女Alpha掉马后果很严重》讲的「马甲与信息素是同一套证据链」，用的也是这个办法。

这个套路的掉马总是双份的：她藏身份时，每个动作都得顺带把性别也藏住，所以证据天生比普通马甲文密一截。破绽露一次，身份和性别就一起现了形，两件事同时兜不住。

| 6 | 掉马。设个套等他钻，别拿证据往脸上砸 | 58–68% | 崩塌 |
| 7 | 说了算的人还是她，性别换了，位子没换 | 75–90% | ★ 本套路的题眼 |
| 8 | 外面来追究了：欺君、宗族、军法、单位查岗 | 88–100% | 代价 |

#### 常见变体

| 变体 | 与主形的差别 | 适用体量 |
|---|---|---|
| 科举／从军／继承家业 | 装的理由出在制度上，女子不能科举、不能掌军。理由越是制度定下的，掉马的社会代价越重，制度怎么设计见《风起云涌》2.2⑤⑥ | 不限 |
| 女尊世界里的女扮男装 | 反着用：女尊世界里扮男人是自降身份，动机必须非常强。极少见，价值高 | 不限 |
| 他早就知道 | 第 3 拍改成「他知道且装作不知道」，这种戏最紧，也能躲开「他爱上了男人」的伦理歧义 | 不限 |
| 她扮男装 + 他扮女装 | 双向，喜剧向 | 不限 |

#### 写崩的三种方式

1. 装得毫不费力：束胸、变声、独居、躲体检、每个月那几天、军营里一起洗澡，全书一件都没写。这个套路装得越难越好看，不难的话，马甲就只是个摆设。正解：给她定三条每天必须执行的规矩，再让其中一条在要紧关头掉链子。

2. 掉马以后关系直接变回普通男女：一揭穿，男主就抢过主导权，最后二十章攻受位整个倒了过来。GB 圈最容易为这个骂人，读者会直接说作者诈骗。正解：第 7 拍不能省，掉马之后必须有一场戏讲清楚，她就算不是男的，位置也不变。

3. 他发现自己动了心，然后一点想法都没有，掉马后一句「原来你是女的，太好了」就打发过去，这个套路最好看的那 15% 就这么扔了。正解：第 3 拍要写透，他怎么琢磨自己那点反应，打算怎么办，又因此改了什么。

#### 可直接用的素材

- 第 7 拍的写法：掉马后的头一场戏，她照旧下命令，他照旧去做，别的一句不用多说。
- 装下去要花什么代价：`每天雷打不动要做的三件事 ｜ 打死也不能碰的三件事 ｜ 每个月或每季度躲不掉的一次麻烦 ｜ 一旦被发现要吃几年牢饭`
- 双料破绽钩子：让性别和身份栽在同一个破绽上，一起露馅。可以是签字必须按手印，进军营必须验身，或者一件只有那个身份的人才穿得起的内衣。

### 欢喜冤家

`T`
`现代都市／现代职场／武侠江湖／星际` `全制度` `1v1` `势均力敌／双向拉扯` `敌对转化`
来源：`【圈内共识】` + 词频 10 篇 / 0.2%

#### 结构公式

`利益对撞（得是真利益）→ 互相使绊子 → 被迫合作 → 各自让步一次 → 敌意被证明是别的东西 → 敌意的残留物成了亲密语法`

#### 为什么有效

GB 里最偷懒的写法是「女主全能男主全弱」，欢喜冤家天生就绕开了这个坑：不靠制度，不靠生理设定，也不靠能力碾压，戏照样撑得起来。GB 这个分类里，只有它天生势均力敌。所以格外难得。

到最后一拍，敌意消不掉，得把它换成亲密的说法：两人和好了，嘴上照样互相挤兑，话里的意思却早变了。这个套路耐人咂摸，靠的就是「同一句话，两个阶段两种意思」这个双关。

口径：`建议`

| 2 | 互相使绊子，各占一次上风 | 10–25% | 看得过瘾 |

| 4 | 两边各退一步，退的分量要相当 | 45–58% | 读者重新看这两个人 |
| 5 | 那股敌意底下另有东西：佩服、不甘，或者早年的误会 | 62–75% | 大转弯 |
| 6 | 老矛盾又冒了出来，这回非选边不可 | 78–88% | 逼到墙角 |
| 7 | 敌意还剩一点，成了两人之间的暗号 | 90–100% | 咂摸出味儿来 |

#### 写崩的三种方式

1. 敌意只停在嘴上：两人互相讽刺了三十章，却没有一件事因为这份敌意真的变糟。正解：第 1 拍的利益冲突必须是真的，第 2 拍还要让一方真输掉点什么。
2. 靠一场意外和解：车祸、落难、大雨，两人往一处一凑，敌意就没了。正解：第 4 拍的让步要主动、清醒、有代价，两边让的还得对等。
3. 和解以后两人像换了个人，从此互相体贴，说话温柔，一句挖苦都没有，读者喜欢的那两个角色就这么被换掉了。正解：第 7 拍把挖苦的句式全留着，只换掉它们的意思。

#### 可直接用的素材

- 对撞卡：`他们争的那一样东西 ｜ 第一回合谁赢 ｜ 输的一方失去了什么（要具体）`

- 双关句式，第 7 拍：第 2 拍里那句挖苦话，到第 7 拍原样再说一遍，一个字都不改，意思已经全拧过来了。

### 双重生

`T` `△虐心`
`古代／现代都市／修仙` `全制度` `1v1` `双向拉扯` `双重生／重生`
来源：`【圈内共识】` + 词频 7 篇 / 0.1%（全库套路词倒数第二，真蓝海）

#### 结构公式

`各自重生 → 各自改变行为 → 互相察觉异常 → 三回合试探，都不说破 → 一方先确认 → 揭盖 → 上一世的账必须结`

#### 为什么有效

双重生好看，全在一件事上：

> 两人心里都有数，又都以为对方不知道。

于是有了别处见不到的场面：两边都在装，又都盯着对方怎么装。每句话里藏着三层意思，表面一层，心里一层，还有一层是“我看看你到底知不知道我在装”。所有套路里，这种对话最费脑子，也最带劲。

##### 低词频的解读

只有 7 篇，是因为这个结构太难撑，未必是题材没人看。试探期拖长了就腻，缩短了又可惜，这是「难写所以产量低」。

#### 节拍表

口径：`建议`

| 拍号 | 发生什么 | 篇幅占比 | 情绪目标 |
|---|---|---:|---|
| 1 | 两人各自死去，一睁眼都回来了。两边都让读者看到，别瞒，瞒了那层意思就没了 | 0–6% | 读者觉得自己最懂 |
| 2 | 两人都换了做法，一个躲，一个追，方向正好相反 | 6–18% | 别扭 |
| 3 | 察觉不对：对方随口说出一件只有上辈子才知道的事 | 20–30% | 心里一紧 |
| 4 | 来回试三次，谁也不说破，三次各换一种法子：提一件旧事，换一个叫法，做一个上辈子的动作 | 32–58% | 信息量拉满 |
| 5 | 一方先确认对方也带着记忆，还是不说破，但开始拿这件事做文章 | 60–70% | 主动权换人 |
| 6 | 摊牌。先捅破这层纸的人，后面说了算 | 72–82% | 松口气 |
| 7 | 上辈子的事要有个了结：谁欠谁，怎么还，还不还 | 85–100% | 给个交代 |

#### 常见变体

| 变体 | 与主形的差别 | 适用体量 |
|---|---|---|
| 只有一方重生，另一方是被穿／被夺舍 | 假双重生，第 6 拍变成二次反转 | 不限 |
| 两人重生到不同时点 | 一个早回来几年，两人手里的信息不对等，难写，上限高 | 不限 |
| 上一世是仇人，这一世都想避开对方 | 躲避型双重生，稀缺 | 不限 |
| 双重生 + 追妻火葬场 | 她记得上一世怎么待他，他也记得，旧账开篇就摆上了桌 | 不限 |

#### 写崩的三种方式

1. 一方在第 3 拍就把话挑明，结构当场就废了：三层对话缩回一层，后面只能拿普通恋爱硬撑，没人爱看。正确做法：说破的位置不能早于 70%，前面撑着的就是那个「不说」。

2. 上一世知道的事，对两人的做法毫无影响：都是重生的，干的事却跟第一回一模一样，读者看不出重生在哪。正确做法：第 2 拍必须硬，两人改变的方向要相反。往同一个方向改，两人立刻就凑到一块了，戏也就唱不下去。

3. 两份前世记忆对不上，作品却不管：她记得的版本和他记得的完全两样。书里当没看见。这个套路里最好用的东西就这么放过了。正确做法：把矛盾留到第 6 拍再揭开。他们发现两人记得的上一世对不上，那就至少有一个人被骗过。

#### 可直接用的素材

- 反向改变钩子，第 2 拍：这一世他铁了心往她身边凑，她却打定主意躲，两人重生后的方向正好拧着，故事自己就往前滚了。
- 试探他分三个回合，一回合一种，别重复用：`回合三：做一个上一世的固定动作，看他会不会下意识配合｜回合一：提一件上一世才发生的旧事，看他反应｜回合二：用一个上一世才有的称呼，看他接不接`。
- 状态板字段也要跟着记：`【两人记忆的矛盾点】｜【已试探】n/3｜【她知道他重生】否/疑/确认｜【上一世的账】谁欠谁 __｜【他知道她重生】否/疑/确认`。

### 日久生情

`T`
`现代都市／古代女尊／修仙` `全制度` `1v1` `温和主导／势均力敌` `日久生情`
来源：《墨氏家规》 2.3 循环 C + 词频 2 篇 / 0.0%（全库套路词最低）

##### 关于这个 2

日久生情很难当卖点写进文案，文案没法向读者保证“看这个一定爽”。所以没人标它。

这里词频低，意思是“没法拿来打广告”，算不上“没人爱看”。它在所有套路里词频最低，正好拿来检验“作者自己标的标签”这个口径到底有多准。

#### 结构公式

`共处的理由 → 习惯的累积（无转折点）→ 一次撤走 → 落差暴露依赖 → 归位 → 一个只有他们懂的日常动作`

#### 为什么有效

日久生情没有单一的转折点，靠两件事：攒，和撤走。

「撤走」这一拍，正好对上《墨氏家规》里提炼出来的循环 C · 恩典的收回：

```
某项破例施行日久 → 成为默认 → 某日不给
→ 无需任何新刺激，落差本身即是最重的一击
```

被平台尺度卡住的作者，可以先拿这一招练手，尺度一点都不用加。
这套动作链要靠铺垫，至少铺两次，越不起眼越好，精读得出的那套结论也可以直接搬来用。
动作链是「按惯例行事 → **不作为**，不是加害，是不施救／不制止／不出声 → 独自完成整个流程 → 落差在他自己心里完成打击」。
收尾用一个极小的动作把它解开，一句「够了」，或者一下轻轻的肢体接触，落差就反弹成了感激。

#### 节拍表

口径：`建议`

| 拍号 | 发生什么 | 篇幅占比 | 情绪目标 |
|---|---|---:|---|
| 1 | 找个理由让两人住到一块：合租、同事、契约、差事、借住 | 0–8% | 定调 |
| 2 | 养成习惯 A：她每天顺手做的一件小事 | 10–20% | 日常 |
| 3 | 习惯 B、C 接着养成，铺垫要藏好，别急着煽情 | 20–45% | 攒着 |
| 4 | 撤走：某一天她突然不做了，不解释，也不使坏，只是不做 | 50–60% | ★ 全篇最顶 |
| 5 | 落差显出来：他自己把整套流程走了一遍，觉出哪里不对 | 60–70% | 懵了 |
| 6 | 归位，一个很小的动作就把事情解开 | 72–82% | 转成念她的好 |
| 7 | 只有他们俩懂的一个日常小动作，成了这段关系的记号 | 90–100% | 留味儿 |

#### 常见变体

| 变体 | 与主形的差别 | 适用体量 |
|---|---|---|
| 同居型 | 最常用的写法 | 不限 |
| 上下级型 | 平常抬头不见低头见，见 [[上下级]] | 不限 |
| 契约型 | 在契约期里慢慢处出感情，到期那天多一重纠结，见 [[契约关系]] | 不限 |
| 重复撤走 | 第 4–6 拍反复两三轮，每轮撤走的东西更小，伤得却更狠，长篇这样写 | 长篇 |
| 他先撤走 | 方向倒过来，尝到落差的是她。GB 里少见，能免得女主总在主动 | 不限 |

#### 写崩的三种方式

1. 拿时间跳跃顶替积累：「三个月后，他们已经很熟了」。日久生情全靠那些日常，日常跳过去，整本书也就跳过去了。正解：至少写三个具体的习惯，每个至少出现三次，第三次出现时不用解释，读者自己就明白。

2. 少了「撤走」这一拍：全书一直在加。从来不减。攒下多少，只有失去时才量得出来，所以读者感觉不到。正解：第 4 拍必须写，放在 50–60%，早了分量不够，晚了来不及反弹。

3. 日常戏里看不出谁说了算：两人吃饭、散步、聊天，谁做主完全看不出来，GB 写日常最容易在这里翻车。正解：每个日常动作都带上一点权力信息，谁先动筷，谁定去哪，谁记得对方忌口，谁在等谁。动作里有了权，就不用再堆形容词。

#### 可直接用的素材

- 撤走钩子，第 4 拍：不写她为什么不做了，只写他等到平常那个钟点，事没有发生，他就自己做了，一个字也不解释。
- 习惯卡，至少三条：`她每天为他做的一件小事 ｜ 他每天为她做的一件小事 ｜ 一件他们共同做的事`，第三条就是第 7 拍的种子。
- 签名动作，第 7 拍：一个外人看不懂的动作，比如递东西时手放在哪，进门时谁先开灯，一句没头没尾的话。全文最后一个字，就该落在这个动作上。

### 假戏真做

`T` `△误会流`
`现代娱乐圈／现代都市／古代` `全制度` `1v1` `势均力敌／双向拉扯` `契约关系／敌对转化`
来源：`【待核实】`（[文案标签统计](../10-藏书索引-公开/语料统计.md) 无对应标签词；检索路径：已查「套路」「关系结构」两表全部 31+6 项，无「假戏」「假扮」「协议」条目。属统计口径未覆盖，非不存在）

#### 结构公式

`戏的规则先定死 → 观众到场 → 戏里的动作漏到戏外 → 有人先当真了 → 观众散场（戏没了理由）→ 不用演了之后干的第一件事`

#### 为什么有效

假戏真做全靠一样常被忽略的东西：观众。

> 没有第三方看着，「假戏」就无从谈起。

关起门来两个人做的事，本来谈不上真假，「假」这个字只有对着观众才成立。所以这一招牵涉的其实是三方：她，他，还有那些必须骗过去的人。观众在，两个人就一直有台阶可下，可以说我们只是演演。观众一散，台阶就撤了。

所以第 5 拍观众散场，是全篇的高点：“接着演”的路一下被堵死，就看两人还愿不愿意往下走。

#### ↺ GB 里怎么写

他是被塞进这场戏里的那个，出钱的是她，说了算的也是她。
GB 里最常见的三种：两人签一份对外的假关系协议，她让他装成下属／未婚夫去演一场局，她花钱雇他假扮男朋友回去应付爸妈。
“她是说了算的那个”这位置必须坐实，不然这套路一飘就滑回BG老路上去了。

#### 写崩的三种方式

1. 规矩没定死：演什么、演给谁、演多久都没写明，第 3 拍那个“外溢”也就算不上外溢。正解：第 1 拍就像签合同那样把规矩列清楚，见 [[契约关系]] 的条款卡。尤其要写明“不演什么”，以后要越的就是这条界。

2. 观众只是背景板：那些必须骗过去的人，从没被写得像会动脑子，没起过疑，也没差点看穿。观众越精明，演起来越难，外溢也越说得通。正解：观众里至少得有一个人长了眼睛，问出一个两人都答不上的问题。

3. 少了第 5 拍。一直演到最后，接着表白。戏从头到尾没被叫停，“假”和“真”的那条线也就从来没真碰过。正解：必须有一刻观众散了，戏没理由再演，两个人却还站在原地。他们那一刻做了什么，就是这本书的答案。

#### 可直接用的素材

- 戏规卡（第 1 拍）：`演给谁看 ｜ 演到什么时候 ｜ 演什么（三项）｜ 不演什么（一项，日后要越）｜ 结束的信号`
- 外溢钩子，第 3 拍：一个只该当着观众做的动作，没人时也做了，比如牵手，整理衣领，叫那个假的称呼。不解释，两人谁都别提。
- 散场钩子，第 5 拍：观众走得平平淡淡，又走得干干净净，事办完了，老人走了，局做成了。别拿戏剧性的事件收场，散得越平淡，两人越觉得无处可躲。

### 和亲娶夫 ↺

`T` `⚠️年龄差(常见)` `△虐心`
`古代女尊／架空王朝` `女尊制` `1v1／np` `势均力敌／女强男也强` `契约关系／先婚后爱／敌对转化`
来源：《风起云涌》 2.3① 「进口丈夫」法（全卡评为「最优雅、最值得整套偷走的设计」）

#### ↺ GB 方向反转

婚礼上坐着受礼的是女方，娶人、收人的也是她。被送去和亲的是男方，皇子成了一件被送来的物件。BG 和历史题材里常见的和亲，正好跟这个反过来。

#### 结构公式

制度梯度先立 → 进口 → 下马威，制度 vs 程序的对打 → 合伙期 → 他的真实目的显形 → 走或留（代价必须具体）

#### 为什么有效

女尊世界最难的是这个：

> 女尊世界里想要一个真正强势的男主，该怎么写？
> 在本国制度里硬造一个，设定当场就破了：他能这么强，这套制度凭什么还立得住？

办法是写一个邻国，那里的性别制度比本国松一档，男子能科举、能经商、能休妻，没有皇女时还能继位，再从那边弄一个人过来。

##### 三重收益

《风起云涌》 2.3①

| 收益 | 理由 |
|---|---|
| 他的强不违反本国法 | 他不是本国人 |
| 他的强不需要解释 | 他祖国就是那样 |
| 他的强对本国是威胁 | 本国人知道他祖国是那样 |

##### 免费附赠一个设定交代机制

挑一场宴席，让一个本来就防着他的上位者坐在对面，当众把邻国那套制度念出来。
这一句话里，背景交代了，对方也敲打到了，主角当场脸上挂不住。
把设定裹进带刺的话里扔出去，这一招最省事，也最容易翻车。

##### ⚠️ 必须知道的代价

这条路从一开头就是奔着分开去的，外面来的人，迟早要回去。
要走 HE，开篇就得给他一个「回不去」的理由，国灭了，被通缉了，或者他一把火把船烧了。没有这个，写到结尾就只能像原作那样，眼睁睁送他走。

#### 写崩的三种方式

1. 邻国只有一个名字：说那边制度不一样，到底哪儿不一样，三条都说不出来，也没有谁因为这点不同怕他、算计他。正解：写出三条具体、能拿来对比的规矩，比如男子可科举、可经商、可休妻，无皇女时可继位，再让至少一个本国角色因为这几条对他起了戒心。

2. 没给他回不去的理由，最后硬凑 HE，结尾只好拿一句「他决定留下」糊弄过去。正解：动笔前就定下这本书是分离还是 HE，别写到结尾才想，前 20% 埋好对应的伏笔。

3. 他的强只停在嘴上：都说他厉害，全书却没有一件事是他自己办成的，胜仗全记在女主名下。正解：第 5 拍给他一场政治首秀，完全由他主导。女主只能配合。

- 反向下马威句式，出自《风起云涌》第六节，全卡只引了这一处。新人物登场时，让他去打量主角，别让主角打量他。先复述一条制度，「自古以来……都是……」，再用一个「却」当场把它掀翻。
  > 复用时把前半句换成别的制度就行，句式照搬。
  > 这个句式好用在顺序上：先立规矩，再当场破掉，一行字就能把强势角色立起来。

### 救才子收房 ↺

`T` `△虐心` `⚠️主奴(边界)`
`古代女尊／架空王朝` `女尊制` `np／1v1` `温和主导／女强男弱` `救赎／契约关系`
来源：《风起云涌》 2.3③「报恩依附」+ 九节回填清单

#### ↺ GB 方向反转

施恩的是女方，被救的是男方，他报恩的办法是把自己整个人交出去，当妾，入籍，或者一辈子替她干活。

这一招把 BG 里“英雄救美然后娶回家”整个翻过来用，还更狠一层：“恩”直接成了“我该归你管”的合法理由。

#### 结构公式

落难 → 施救，她当时没想收人 → 他一个人认定这份恩要还一辈子 → 入身 → 才华被消耗成家务能力 → 她必须为他付一次政治代价 → 他的价值被重新判定

#### 为什么有效

这个套路靠两边看法不对称：施恩的人觉得是小事，受恩的人觉得是一生。

越往后写，这份不对称越残忍。她越说「不必」，他越觉得非还不可，她的善意堆得越高，他陷得越深。欠了恩的人会自己把自己放低，觉得只有把自己当成她的人，才算还上了。在这个局里，她对他再好也没用。

##### 配角用法

《风起云涌》第三节把它评为「很高效的配角用法」

报恩型角色不推情节，他的用处是逼着女主一遍遍选「值不值得」。她每为他付出一次，就耗掉一些政治资本。一个没本事的角色，就靠「让主角必须为他付代价」站稳了位置。

| 4 | 入身：办一道没法反悔的手续，入籍、上族谱、签下身契 | 15–22% | 锁死 |

1. 她救他时就在盘算怎么把人收下，报恩成了买卖，后面那套感情逻辑全塌了。正解：第 2 拍必须写清楚她当时根本没这个念头，最好还嫌麻烦。
2. 才子的设定只是摆设：说他有才，全书一次没用上，也没人觉得可惜，他既没帮她办成一件事，也没因为困在内宅而惋惜。正解：第 5 拍让他的才华被具体地耗掉，诗才拿来记账，谋略拿来管家，而且至少有一个人为此叹气。
3. 她付出得太轻松：救他、护他、给他名分，一点代价都没有。设这个角色，就是为了让主角付出点什么，她不付，这个角色就白设了。正解：第 6 拍她为他付出的，必须是政治资本、人情，或者一个她本来能拿到的机会。

### 诈死离场 ↺

`T` `△死遁` `△虐心`
`古代女尊／架空王朝／现代都市` `全制度` `1v1／np` `势均力敌` `破镜重圆／敌对转化`
来源：《风起云涌》 十节·关系钩子 9（原作 84–96% 的「二次剥离」段）

#### ↺ GB 里怎么写

诈死的是男方，留下来的是女方。他从自己国家弄来一张「主角已亡故」的文书，拿回去交差，这下她不能死，还得替自己办一场葬礼。
BG 里常见的是「女主诈死躲渣男」，这里正好反过来。它跟「男主假死试真心」那套也两样，这里的诈死只是给第三方交差的行政手续，根本没有试探的意思。

#### 结构公式

`第三方需要一份死亡证明 → 死亡被行政化生产 → 活人为自己办葬礼 → 「死后」的行动空间 → 死讯的副作用 → 复活的代价`

#### 为什么有效

诈死比真死好写，好处两头都占：死的时候有情感冲击，活过来还能接着搞事。可多数诈死写崩，都是漏了一根要紧的支柱：

> 必须有一个第三方需要这份「死亡证明」，诈死才成立。

没人需要这张纸，诈死就只是躲起来，躲起来哪用得着办葬礼。有人需要它，一次逃跑才成了一次交差，主角也从「逃兵」成了「同伙」。

最狠的一招是活人给自己办葬礼：她得自己主持丧事，自己接待吊唁的客人，眼睁睁看着自己的牌位摆上去。

这个画面放进哪个题材都好用，而且几乎没人写过。

#### 写崩的三种方式

1. 没人需要那份死亡证明，诈死成了“躲起来”的体面说法，没人因此得到好处，也没人吃亏。正解：第1拍必须提前，诈死发生之前很久就要写明，有一个人特别需要这个“死”的结果。

3. 复活不用付任何代价：他一回来，大家该干什么干什么，没人追究那份文书，也没人因为被骗翻脸。正解：给复活定个价——可以是法律上的，诈死是罪，可以是关系上的，看谁被骗得最狠，也可以是制度上的，他的位子早被人占了，回不去了。

### 临终改称谓

`T` `△虐心` `⚠️BE(局部)`
`古代女尊／架空王朝／任何有等级的世界` `女尊制／女A男O／现实性别制度` `np／1v1` `强势主导` `虐恋`
来源：《风起云涌》 场面 C（≈62%，全卡评为「本篇**最锋利**的一场，也是女尊/等级世界最值得偷走的一招」）

这条暗线要铺满全书，靠的是一条从第一章就开始执行的约束：

> 前 60% 严格只用头衔称呼这个角色，叙述层也算在内，名字一次都不给。
> 读者中途要是知道了他的名字，这个收尾就全废了。

#### 结构公式

`名字被爵位/头衔吃掉（全程执行）→ 他一生被称作「某位某氏」→ 失去一切的时刻 → 他自己把名字抢回来 → 不断重复 → 不给回应`

#### 为什么有效

在等级世界里，称谓最不费事，也最扎人。一个人被头衔叫了一辈子，就是被制度整个吞了，他不再是他自己。只是那个位子。

写到这里，前面几十万字都值了。不用铺垫，不用控诉，也不用解释，这个人一辈子只有一次不顶着位子说话，就是「说出自己的名字」这一下。

铺的时候几乎不费力，从头到尾只是不写某个词，砸下来却极重。

2. 全程只用头衔，叙述层也不例外。

#### 写崩的三种方式

1. 名字中途漏了出来，哪怕只有一次，配角随口叫了，文书上写了，叙述层用了。这一招就废了。正解：写的时候把这个角色的名字单独记在一张纸上，用全文检索确认，到第 6 拍之前一次都没出现。
2. 改称谓时给了回应：上位者马上接话，落泪，也报上自己的名字，或者说一句「我知道」。一次单方面的夺回就成了双向的和解，力道一下少了一半。正解：不给回应。她可以有反应，手抖，闭眼，回握，但不能有台词。

### 记忆覆写

`T` `△虐心` `△失忆`
`现代都市／古代／架空` `全制度` `1v1` `温和主导／双向拉扯` `追妻火葬场／救赎／破镜重圆`
来源：《失忆后你和霸总破镜重圆了》 三节末 + 十一节「记忆覆写节拍模板」

记忆覆写是一张能一条条照着做的任务清单，所以它是所有套路里最好上手、也最容易照抄的。
《失忆后你和霸总破镜重圆了》干脆把它写进了正文：

> 「你现在要做的事情，就是不动声色地，在这些不美好的回忆之地上，重新覆盖一段美好的回忆。」
> （出自《失忆后你和霸总破镜重圆了》第 165 节）

第二幕就是照这句话写的：办公室、床、果汁、拖鞋、女儿的名字、纹身，每一件旧罪证都配了一个覆写的动作。

#### 结构公式

罪证清单化，每件绑定一个地点/物件/习惯 → 逐件处理：回到原地 → 闪回旧罪 → 当场做一个相反的动作 → 覆写不等于抹除 → 最后一件由对方解除

#### 为什么有效

追妻火葬场最难写的是「追」：手上没有一张要追的对象清单，篇幅就只能靠情绪一遍遍重复来撑。罪证清单补上的就是这一块。

列十件，每件都有自己的起承转合，拆出来单看也站得住。铺满二十章，节奏自己就匀了。不用刻意去调。「我得补偿他」原本只是个模糊的念头，有了清单，就落到「第7件：那双拖鞋」这样具体的动作上。

「覆写」比「补偿」高明，因为它先认下了这件事：坏回忆不会消失，只能拿新的东西把它压下去。「补偿」想的是把旧的抵掉。可旧的抵不掉。这两种写法读者分得清，也更买覆写的账。

#### 写崩的三种方式

1. 清单要露在读者眼前。她在补偿，读者却不知道总共几件、补到了哪一件、还剩哪些，这样的清单看不见，也就跟没有一样。正解：让清单在文里露面。不必真列一张表，让读者心里有个数就行，一个反复出现的「还有」、一个物件柜、一本日记、一张地图都可以。

2. 把覆写写成抹干净。痕迹一点不留，好像什么都没发生过。这样一来，全书攒下的痛感全打了水漂，读者会觉得前面白看了。正解：旧回忆一定要留着，压到最底下也得在。纹身洗掉了还有疤，名字改了户口本上还有旧名，房间重新装了格局还是老样子。

3. 每件都成功。十件覆写十次都顺，读者看到第四件就开始跳着读。正解：中间安排一次失败——她做错了、做过头了，或者他直接说不要。而且失败的那一件留到最后，让他自己来解。

#### 可直接用的素材

- 清单得有个东西装着：一本记满他日常的本子、一个抽屉，或者一张标好位置的地图。有了它，读者自己就会去数。
- 状态板字段：`【罪证清单】已覆写 n / 总 m 项｜【失败项】｜【留给他解除的那一件】｜【仍然可见的旧痕】`
- 罪证清单模板（可整块搬）：
  ```
  1. 列出罪证清单：每一件旧罪都绑定一个具体的地点／物件／习惯
  2. 每一拍处理一件：回到原地 → 闪回旧罪 → 当场做一个相反的动作
  3. 覆写不等于抹除：旧回忆必须仍然可见，只是被压在下面
  4. 留最后一件到高潮处，由对方而非主角来解除
  ```

| 1 | 先立住原来的关系，写得越日常越好，要让人心疼这段感情 | 0–15% | 让读者觉得有东西可失去 |
| 2 | 第三者登场，手上得有自己要办的事，光为搅局而来可不行 | 15–25% | 让读者觉得这人真能构成威胁 |
| 3 | 第一次越界，要小到当事人能骗自己说没看见 | 25–35% | 心里发毛 |
| 4 | 事情坐实。读者先知道是钝刀子割肉，每次同框都难熬，当事人先知道是一记闷雷 | 35–55% | 钝痛或惊雷 |
| 5 | 挑明。可以当面戳破，也可以私下知道了不说，两种写法味道不同 | 55–70% | ★ 全书最揪心的地方 |
| 6 | 算总账。原谅、离开还是反客为主，每一笔都要算明白 | 70–85% | 给个说法 |
| 7 | 重建或散伙。HE 要真刀真枪重建一回，BE 要把余波交代清楚 | 85–100% | 收得住 |

#### 常见变体

| 变体 | 与主形的差别 | 适用体量 |
|---|---|---|
| 伪NTR（误会流） | 看着是出轨，真相另有其事。该疼的照样疼，最后再全还回来。tag 照样要标，读者会按 NTR 避雷 | 不限 |
| NTR 未遂 | 第三者确实攻过来了，但没得手，停在第 3 拍。独占的关系受了考验，没被打穿 | 中短篇 |
| 报复性出轨 | 一方先越界，另一方越界还回去。雷是双份的，清算拍两边都必须算 | 长篇 |
| 破镜不重圆 | 算完账不复合，各走各的。和 [[破镜重圆]] 正好相反，BE 预警要放在前面 | 不限 |

#### 写崩的三种方式

1. tag 标晚了或藏起来。⚠️NTR 拖到中段才露面，文案里一个字没提，读者当甜文点进来，到第 4 拍被打个措手不及。这样写，弃文和差评是躲不掉的，文笔再好也改变不了。正解：预警写在文案第一行，写明方向和结局倾向。「后期高能」这类暗示不算预警。
2. 第三者只是个工具人。没有自己的动机，剧情要冲突了才冒出来，出轨就像天上掉下来的事故。被出轨的一方疼都不知道该冲谁，到了清算那拍也没人可算。正解：给第三者一条不靠主角的动机线，第 2 拍就让它露出来。
3. 清算不付代价。哭一场就把前面全抹平，关系回到原点，好像什么都没发生。读者记着这笔账，文里却不记，后面每一场甜戏都在提醒读者还有件事没了结。正解：清算的代价要看得见——一件收不回的东西、一条改掉的规矩、一个再也不用的称呼。HE 光重建就至少要占一拍。

#### 可直接用的素材

- 前置预警模板：`⚠️NTR，方向：她出轨/他出轨/逆NTR/她被夺｜结局：HE/BE｜是否原谅：____`，填好放文案首行
- 越界信号清单（第 3 拍）：一条回晚了的消息、一个改过的备注、家里多出一件不属于这段关系的东西。信号要小，小到当事人能说服自己没看见
- 清算清单（第 6 拍）：`收不回的东西：____｜改掉的规矩：____｜再也不用的称呼：____｜留给重建的那一拍：____`
- 场面级节拍链、可用细节与双向写法：[14-桥段库/34-NTR与出轨危机](../14-桥段库/34-NTR与出轨危机.md)
