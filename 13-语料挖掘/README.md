> 全量通读 2,894 部独立作品的正文，抽出可直接查用的创作元素。

## 这一卷和别卷的区别

| | 内容来自 | 回答什么 |
|---|---|---|
| 其余各卷 | 编者的归纳 | 该怎么写 |
| 本卷 | 脚本对语料的频次统计 | 别人都怎么写 |

两者不一致处往往就是空档。

## 数据纪律

| 项 | 做法 |
|---|---|
| 可复跑 | `python3 _脚本/mine_text.py && python3 _脚本/render_mining.py`（桥段层加跑 `mine_vignette.py` 与 `render_vignette.py`，或直接 `run.py mine`） |
| 挖掘基准 | 按独立作品（2,894 部），不按文件 |
| 逐字串上限 | 称谓实例与命令句 ≤16 字且跨 ≥5 部 |
| 首句 | 不展示原文，只给结构骨架与自写示范 |
| 章节标题 | ≤12 字，剔除露骨字面 |

约束的完整理由见 [00-编纂规约/03-版权与内容红线](../00-编纂规约/03-版权与内容红线.md) 1.2c。
