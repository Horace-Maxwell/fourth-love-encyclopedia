# 条目写作模板与文风规约

> 本卷规定库内所有条目的写法。新增素材前先读这一份。
> 版本：v1.0

---

## 一、双轨文风（本库的核心文风约定）

本库要同时被两类人读：

- 圈外/研究者视角：需要精确定义、可检索的术语、清楚的分类
- 圈内创作者视角：需要熟悉的黑话、能直接上手的实操细节

解决办法不走折中，走双轨：正文用严谨百科体保证信息密度与可检索性，圈内俗称与黑话在首次出现时同步括注。

正例：
> 女攻（圈内多称「女A」，早期论坛也写作「攻方女性」）指在关系中承担主导位置的女性角色。此处的「攻」承自耽美圈的攻受术语，但在第四爱语境中发生了含义偏移。它更多指向关系主导权而非性行为体位，这一点与耽美圈原义有别。

反例 A（纯学术，圈内人读着累）：
> 支配性女性角色（dominant female protagonist）系指于亲密关系权力结构中占据上位之角色类型。

反例 B（纯黑话，圈外人读不懂，也无法检索）：
> 女A就是攻的那个，懂的都懂。

## 二、通用条目模板

所有素材条目遵循以下骨架。不适用的段落直接删掉，不要留空标题。

```markdown
### 条目名（圈内俗称：xxx）

`分级` `预警标签…`
`亚型标签（A背景 B性别制度 C关系结构 D权力动态 E情感套路）`
来源：`可信度标记` + 具体出处

**是什么**
一到三句话讲清楚。第一句必须能独立成立。这句会被抽出来做速查表。

**怎么运作**
机制、结构、内在逻辑。这是条目的主体。用小标题、编号、表格来组织，不要写成一大段。

**为什么有效**
这个设定/套路击中的是什么心理需求。写这一段的目的是让使用者能**变形**而不只是照抄。理解了为什么有效，才能在新语境下重造一个。

**常见变体**
列 2-5 个变体，每个一句话。

**写崩的三种方式**
这是本库的特色段落，必写。反面清单比正面指南更能防止失手，也最能防 AI 味。

**可直接用的素材**
钩子句、设定卡、状态板字段、世界书条目片段。能被复制走的具体东西。

**相关条目**
`[[条目名]]` 形式互链。
```

## 三、各卷的专用变体

### 3.1 术语条目（02 卷）

```markdown
#### 词条名

- **别称**：｜**英文**：｜**分级**：｜**预警**：
- **定义**：一句话
- **在 GB 语境中的偏移**：（从别处借来的词必写）
- **用法示例**：一句圈内实际会说的话
- **易混**：与谁混，怎么区分
- **创作提示**：（可选）
```

### 3.2 世界观设定条目（03 卷）

必须回答制度三问，这是判断一个女尊/ABO 设定站不站得住的三根柱子：

1. 权力从哪来。女性主导的物质基础是什么（生育控制？武力？灵力？经济？神权？）。没有基础的女尊只是换了称呼的男权社会。
2. 制度怎么执行。继承、婚姻、财产、法律、军事、教育各是什么规矩，如何自洽。
3. 反例怎么处理。强势男性、不服从的男性、女性弱者在这套制度里怎么活。一个只有"男人都很乖"的世界是纸糊的。

### 3.3 人设原型条目（04 卷）

```markdown
### 原型名

`分级` `标签`

**一句话画像**
**核心矛盾**（这个原型的内在张力；没有内在矛盾的角色是纸片）
**外显特征**（说话方式/身体语言/习惯动作，各 3 条具体的）
**在关系中的位置**（对上/对下/对等时分别什么反应）
**破防点**（什么能让他/她破防；这是所有名场面的燃料）
**成长弧线**（起点→拐点→终点的三段）
**配对化学**（与哪些原型撞出什么效果，列 3 组）
**写崩的三种方式**
**可直接用的素材**（口头禅、开场白、状态板字段）
```

### 3.4 剧情套路条目（05 卷）

```markdown
### 套路名

`分级` `标签`

**结构公式**（用箭头写出节拍：设置 → 触发 → 升级 → 转折 → 落点）
**为什么有效**
**节拍表**（表格：拍号｜发生什么｜篇幅占比｜情绪目标）
**常见变体**
**写崩的三种方式**
**可直接用的素材**（关键场景的钩子、转场句式）
```

## 四、写作的七条硬规矩

1. 第一句话必须能独立成立。它会被抽进速查表，脱离上下文也要读得通。
2. 能用表格就不用段落，能用清单就不用长句。这是工具书不是散文集。
3. 每一段都要有具体信息。删掉所有 `非常重要` `值得注意的是` `众所周知` 一类的填充句。检验方法：把一段话里的形容词全删掉，如果剩不下东西，这段就是水。
4. 必写「写崩的三种方式」。这是本库区别于普通设定集的地方。正面清单谁都会写，反面清单需要真的读过大量作品。
5. 具体到能用。不写「男主要有层次感」，写「男主的三层：人前的X / 独处时的Y / 破防后的Z，用同一个动作在三种状态下的不同做法来演示（例：递东西的手，人前稳、独处时快、破防时抖）」。
6. 不复制藏书原文。所有从藏书提炼的内容必须是模式（套路名、结构、原型、语感规律），单篇引用不超过一句且注明出处。详见 [03-版权与内容红线](03-版权与内容红线.md)。
7. 不确定就标，不要为了看起来完整而编。`【待核实】` 不丢人，编造才丢人。

## 五、互链约定

用 `[[条目名]]` 做库内互链。这个语法与酒馆书房、Obsidian 都兼容，导出时可批量转换。

链得越密越好：一个 `[[尚不存在的条目]]` 不是错误，它是一张待办便签，标记着「这里应该有个条目」。

## 六、文件命名约定

- 卷号目录：`NN-卷名/`
- 卷内文件：`NN-文件名.md`，两位序号方便排序
- 拆解卡：`09-拆解卡/作品名.md`（作品名去掉书名号与作者后缀）
- 模板文件：下划线开头（`_模板`），排序时沉底

## 七、更新纪律

- 每轮增补后必须同步更新 [INDEX.md](../INDEX.md) 的完成度标记
- 新素材先落 `_收件箱/`，消化后归入正卷并在收件箱留一行归档记录
- 修订重要条目时在文末加一行 `> 修订：YYYY-MM 什么变了`
