> 库里所有条目照这一卷写。加新素材前，先读这份。
> 版本：v1.0

## 一、双轨文风（本库的核心文风约定）

本库要同时被两类人读：

- 圈外人和研究者要的是：定义精确，术语查得到，分类清楚
- 圈内创作者要的是：熟悉的黑话，拿来就能上手的实操细节

所以走双轨：正文用严谨的百科体，信息密、好检索，圈内俗称和黑话头一次出现时，用括号直接注在旁边。

正例：
> 女攻（圈内多称「女A」，早期论坛也写作「攻方女性」）指在关系中承担主导位置的女性角色。此处的「攻」承自耽美圈的攻受术语，但在第四爱语境中发生了含义偏移。它说的多是关系主导权，不太管性行为体位，这一点与耽美圈原义有别。

反例 A：纯学术，圈内人读着累。
> 支配性女性角色（dominant female protagonist）系指于亲密关系权力结构中占据上位之角色类型。

反例 B：通篇黑话，圈外人看不懂，也搜不到。
> 女A就是攻的那个，懂的都懂。

## 二、通用条目模板

素材条目都按下面这个骨架写。用不上的段落整段删掉，别留着空标题。

```markdown
### 条目名（圈内俗称：xxx）

`分级` `预警标签…`
`亚型标签（A背景 B性别制度 C关系结构 D权力动态 E情感套路）`
来源：`可信度标记` + 具体出处

**是什么**
一到三句话讲清楚。第一句必须能独立成立。这句会被抽出来做速查表。

**怎么运作**
机制、结构、内在逻辑。这是条目的主体。用小标题、编号、表格来组织，不要写成一大段。

**为什么有效**
这个设定/套路击中的是什么心理需求。写这一段的目的是让使用者能**变形**而不只是照抄。理解了为什么有效，才能在新语境下重造一个。

**常见变体**
列 2-5 个变体，每个一句话。

**写崩的三种方式**
这是本库的特色段落，必写。反面清单比正面指南更能防止失手，也最能防 AI 味。

**可直接用的素材**
钩子句、设定卡、状态板字段、世界书条目片段。能被复制走的具体东西。

**相关条目**
`[[条目名]]` 形式互链。
```

## 三、各卷的专用变体

### 3.1 术语条目（02 卷）

```markdown
#### 词条名

- **别称**：｜**英文**：｜**分级**：｜**预警**：
- **定义**：一句话
- **在 GB 语境中的偏移**：从别处借来的词必写
- **用法示例**：一句圈内实际会说的话
- **易混**：与谁混，怎么区分
- **创作提示**：（可选）
```

### 3.2 世界观设定条目（03 卷）

必须答出下面的制度三问，用来判断女尊/ABO 设定站不站得住：

1. 权力从哪来。女性能主导，靠的是什么实打实的基础：控制生育、武力、灵力、经济，还是神权？没有这个基础，女尊只是把称呼换了的男权社会。
2. 制度怎么执行。继承、婚姻、财产、法律、军事、教育各有什么规矩，彼此能不能对得上。
3. 反例怎么处理。强势的男人、不服管的男人、弱势的女人，在这套制度下怎么过日子。只写得出"男人都很乖"的世界，是纸糊的。

### 3.3 人设原型条目（04 卷）

```markdown
### 原型名

`分级` `标签`

**一句话画像**
**核心矛盾**：这个人自己跟自己拧着的地方，没有这一条，角色就是纸片
**外显特征**：说话方式、身体语言、习惯动作，各 3 条具体的。
**在关系中的位置**：对上、对下、对等时分别什么反应。
**破防点**：什么能让他/她破防
**成长弧线**：起点→拐点→终点的三段
**配对化学**：与哪些原型撞出什么效果，列 3 组
**写崩的三种方式**
**可直接用的素材**：口头禅、开场白、状态板字段
```

### 3.4 剧情套路条目（05 卷）

```markdown
### 套路名

`分级` `标签`

**结构公式**：用箭头写出节拍：设置 → 触发 → 升级 → 转折 → 落点
**为什么有效**
**节拍表**：表格里是拍号、发生什么、篇幅占比、情绪目标。
**常见变体**
**写崩的三种方式**
**可直接用的素材**：关键场景的钩子、转场句式
```

### 3.5 精读笔记（本地，不入库）

精读笔记是一部一部作品读下来记的。从里面提炼出的手法和规律，已经回填进 03–07 各卷，来源行写了出处。笔记本身留在本机，`.gitignore` 排除掉了，不进仓库。原因是这种笔记逐部展开，节拍占比、章节机制、名场面在哪，一路记到底，攒起来差不多就是一份能顶替读原作的详细梗概，放出去侵权的风险比它对外的用处大。

本地笔记还按原来的体例记，红线 1.4 的约定照样管它们，`check_compliance.py` 的 H 项在本机照常检查。体例是卷首一个两列信息框，填作者｜体量｜分级｜预警｜亚型｜锚定价值｜精读日期，下面接十节正文（一句话定位 → 世界观提炼 → 人设骨架 → 结构与节奏 → 名场面结构 → 语言与技法 → 这篇的独到之处 → 它写崩的地方 → 回填清单 → 可直接用的素材）。

## 四、写作的七条硬规矩

1. 第一句必须能单独成立。这句会被抽进速查表，离了上下文也得读得懂。
2. 能画表就别写段落，能列清单就别写长句，毕竟这是工具书。
3. 每段都得有具体信息。`非常重要` `值得注意的是` `众所周知` 这类填充句，统统删掉。检验方法：把一段话里的形容词全删掉，如果剩不下东西，这段就是水。
4. 必写「写崩的三种方式」。这是本库区别于普通设定集的地方。正面清单谁都会列，反面清单得真读过大量作品才写得出来。
5. 要具体到拿来就能用。别写「男主要有层次感」，要写「男主的三层：人前的X / 独处时的Y / 破防后的Z，用同一个动作在三种状态下的不同做法来演示，比如递东西的手，人前稳、独处时快、破防时抖」。
6. 藏书原文不能复制。从藏书里提炼出来的东西必须是模式：套路名、结构、原型、语感规律。引某一篇最多一句，还要注明出处。详见 [03-版权与内容红线](03-版权与内容红线.md)。
7. 拿不准就标出来，别为了显得完整去编。标 `【待核实】` 不丢人，编出来的才丢人。

## 五、互链约定

库内互相链接用 `[[条目名]]`。酒馆书房和 Obsidian 都认这个写法，导出时可以批量转换。

链接越多越好。链到 `[[尚不存在的条目]]` 也没关系，就当贴了张待办便签，提醒「这里应该有个条目」。

## 六、文件命名约定

- 卷内文件：`NN-文件名.md`，两位序号是为了好排序
- 卷号目录：`NN-卷名/`
- 模板文件：用下划线开头（`_模板`），排序时落到最后
- 精读笔记（只在本地，不入库）：`作品名.md`，作品名不带书名号，也不带作者后缀
