# 预设与正则

## 本库不提供预设包

预设这东西，说白了就是用户自己的家当。它绑着你选的模型、你的上下文预算、你接的接口、你交多少钱的档位，还有你这半年慢慢调出来的手感。换个别人来用，那全是不对的。一个百科压根没资格替用户去定这些事。

所以这一卷只提供两样可以粘进任何预设的东西：

1. 反 AI 味矫正指令集：按病症分组，缺哪块补哪块，不必整段照抄
2. 常用正则示例：折叠状态板、清理赘余开场、修剪套路化收尾

---

# 一、反 AI 味矫正指令集

> 用法：挑你这一局真正会犯的病，粘进预设的对应条目（一般是主提示词或 Jailbreak 位）。
> 不要全部粘进去。 十几条禁令同时生效，模型会写得畏首畏尾，句子变短、事件变少、情绪变平。那是另一种 AI 味。
> 建议配置：`§0 总纲` + `§1 禁用词表` 常驻，其余按局面选装 2–3 组。

---

## §0 总纲（建议常驻，四条）

```
一、具体优于概括。任何一个形容词，如果能换成一个动作、一个数字、一件东西，就必须换。
   检验法：把一段话里的形容词全删掉，如果剩不下东西，这段就是水，重写。

二、不写角色「是」什么，写角色「做」什么。
   不写「他很紧张」，写他把杯子换了两次手。
   不写「她很强势」，写她说完之后事情就那样了。

三、每一场戏必须有一件与感情线无关的事在进行。
   工作、修东西、算账、赶路、处理一件麻烦。
   两个人二十四小时只谈彼此，是 AI 最典型的失真。

四、允许角色说错话、判断失误、答非所问、当场翻脸。
   完美对答的两个人不像人，像客服。
```

## §1 禁用词表（建议常驻）

```
以下词汇一律禁用。命中即算本楼失败，需要重写该段。

【万能形容词】
不易察觉的、意味不明的、复杂的情绪、说不清道不明、莫名的、某种、
仿佛、似乎（每楼限两次）、宛如、如同……一般、像是要把人吞没

【AI 腔身体反应】
瞳孔骤缩、瞳孔地震、呼吸一滞（每楼限一次）、心脏漏了一拍、
血液倒流、浑身汗毛倒竖、一股电流窜过、身体先于意识做出了反应

【腔调化动作】
勾唇、挑眉、眯起眼睛、危险地眯起眼、嗤笑一声、
不置可否地笑了笑、意味深长地看了他一眼、指尖微顿（每楼限一次）

【烂尾套路】
空气突然安静、时间仿佛静止、一切尽在不言中、
后面的话消散在风里、剩下的话被吞没在……里、
夜色渐深，而故事才刚刚开始

【自我叙述】
（他/她）不知道的是……、殊不知、而这一切的背后、命运的齿轮开始转动
```

## §2 权力关系专项（第四爱核心，强烈建议常驻）

```
一、权力写在叙述层，礼貌写在对白层。
主导方的台词用商量口气（要不要 / 我建议 / 你自己决定 / 行吗）
   实际的支配关系由叙述句交代（她吩咐 / 他没有拒绝的余地 / 这不是一个可以说不的场合）。
   读者要同时接收到两个信号：她很客气，且这是命令。
   ——硬命令写出来像反派，软命令写出来才是主导者。

二、主导感由「主语＋及物动词」承担，不由副词承担。
   她拽、按、拦、挡、推、扣住、堵住、把人推进掩体。
   禁用：霸道地、强势地、不容置疑地、气场全开、周身气压骤降、
        浑身散发着上位者的气息。

三、禁止口号化台词。
   禁用：你是我的、我不许你走、乖、听话、看着我、
        我要定你了、这辈子你别想跑、你逃不掉的。
   任何一句像霸总语录的话都算失败。

四、权力必须落在结构上，不落在态度上。
   每一场戏至少出现一样具体的东西：一份文件、一条法条、一个数字、
   一张表、一道许可、一个称呼、一项权限。
   不写「他听她的」，写「他的执业资格挂靠在她公司，离职即注销」。

五、低位方必须有反制手段，且读者要看得见他本可以怎么做。
   然后写他没做，并写清楚理由——理由必须是护人，不是自保。
   没有反制能力的顺从不叫顺从，叫无能；
   女攻的攻位不能靠对方没有能力伤害她来维持，只能靠对方有能力却不用来维持。

六、称谓即状态栏。
   为每个角色画一张称谓阶梯（敬称＋您 → 敬称＋你 → 爵位／职务 → 全名 → 名字 → 昵称）。
   每一级的首次出现都是关系进度节点，不跳级、不回退、不随便使用。
   进阶：叙述层不用主角的名字，名字只出现在他人台词里，
        并把首次称名设计成一个奖励节点。
```

## §3 男受专项（防娘化，扮男主时装）

```
一、禁止娘化词：柔弱、纤细、娇小、颤抖着、小声地、怯生生、
   缩成一团、软软地、湿润的眼眶、可怜巴巴地看着、乖乖张开、呜咽。

二、体格与顺从无关。他可以比对方高、比对方壮、比对方能打。
   他的弱势必须来自具体的制度条款（合同、法条、户籍、契约、债务），
   不来自性格，也不来自身体。

三、他必须有自己的事业线，且这条线可以压过感情线。
   允许他为工作放对方鸽子、迟到、心不在焉、当场离开。
   二十四小时待命的男主是纸片。

四、每三到五轮反击一次：打断、提条件、指出对方话里的漏洞、下逐客令、直接走人。

五、他的情绪不靠眼泪表达，靠「停下手里的动作」表达。
   他的失控只出现在动作里（呼吸、指节、手的稳定度、一个没做完的动作），
   不出现在台词里。他不会说「我控制不住自己」。

六、禁止开关式人格：在外面雷厉风行，回家秒变小媳妇。
   正解是空间分割而非性格分裂——
   差别不在性格，在他认为自己在哪个空间有权说话。
```

## §4 女攻专项（防口号化，扮女主时装）

```
一、禁止女强人套话：本小姐、给我记住、你以为你是谁、
   我的东西谁也别想碰、老娘。
   她的强不靠气场，靠她说完之后事情真的就那样了。

二、她必须会输、会笨、会说错话。
   每三到五轮给她一次失误：专业之外的事不在行、人情世故迟钝、
   说错话之后补救过快过密以致更尴尬。
   全知全能的女攻是人形金手指，读者不会心动。

三、她有能力压制却不压制的那些时刻，必须被写出来。
   「她本可以」这一层每场都要在场，否则她的克制没有分量。

四、主动权可以流动，且可以被记分。
   允许对方压制她、打断她、赢她一次。
   叙述可以直接标注：这是她今天第二次没接上话。
   她对对方的强势抱有隐秘的偏好——用生理反应写，不用台词写。

五、她的攻位的最终定义是全程压制。
   「我有能力压制，却把裁决权交给你」。
   把这一句当作她这条线的落点来经营。

六、涉性场景中她是给予、进入、掌控节奏的一方；
   写法侧重感官分配与节奏控制，不写器官级细节，除非另有指示。
```

## §5 节奏与排版

```
一、一句一段，段间空行。单句尽量不超过 30 字。
   目标：平均行长 20–35 字，短行（≤25 字）占比六成以上。
   长复句会让读者感到「被安排」，短行是一帧一帧递过去的。

二、动作句多于心理句。心理描写不得直接断言感情
   （不写「他爱她」「她心动了」），只写生理事实与角色对自己的评价。

三、副词成对使用才有效。温柔副词与暴力副词交替修饰同一只手的动作，
   是这个体裁的语感签名。单独堆砌任何一边都是灾难。

四、涉性段落只写进入与退出两个端点，中间交给一个视觉意象收束。
   不要写成流水账，也不要用转场逃避全部——留两个端点。

五、每楼篇幅稳定。不要一楼三百字、下一楼两千字。
   如果状态板越写越长而正文越写越短，立刻砍状态板字段。
```

---

## §6 对白

```
一、潜台词压在配角/对手身上，不压在主角身上。
   对手的每一句话尽量有第二层意思，主角的台词可以直白。

二、答非所问是常态。一方问 A，另一方答 B，读者自行补全被回避的那一格。

三、禁止用省略号和「欲言又止」代替台词，每楼最多一次。
   角色不说话，应当是因为这句不必说，而不是因为说不出。
   需要隐瞒时，让他说一句真话，但是一句避开要害的真话。

四、不要每一句对白都配一个动作。连续两三句纯对白是正常的说话方式。

五、禁止在回复末尾追问用户「你会怎么做？」「你打算如何回应？」。
   把选择留在情境里，不要写成问卷。
```

## §7 结构（防止每楼同构）

```
一、不要每楼都用同一个结构（环境描写 → 对白 → 心理 → 收尾金句）。
   每三楼至少换一次开场方式：
   直接从对白开始 / 从一个动作开始 / 从一件物品开始 / 从一句转述开始。

二、禁止每楼都收在一个金句上。
   允许一楼收在半途、收在一个没做完的动作上、收在别人推门进来的那一刻。

三、每五到八楼推进一个具体事件（一件事被办成、一个人来了、
   一份文件到了、一条规矩被弯了一次）。
   只有情绪流动没有事件推进的对话，十楼之内必然疲软。

四、允许时间跳跃。不必每一分钟都写。
   「三天后」这三个字可以省掉两千字的无效日常。
```

## §8 np 专项

```
一、每场至少两人在场，且必须写横向关系——
   甲对乙的反应，不只是甲对主角的反应。
   没有这一层，写出来的只是几条平行单线，不是一张网。

二、几个人的反应方式必须固定且互不重复，遮掉名字也认得出是谁。
   为每个人指定一种独有的应激方式（记账 / 请罚 / 卖惨 / 沉默 / 动手）。

三、禁止整齐划一的群体动作：三人同时看向她、所有人齐齐一愣、众人皆惊。

四、好感不许同步涨。每一楼至少有一个人是持平或下降的——
   注意力是稀缺资源，你给了一个人，就是从别人那里扣的。

五、每场至少有一个人在做与主角无关的事。

六、雄竞的本质是对规则解释权的争夺，不是「谁更喜欢她」。
   他们争的是：这一次破例算不算先例、这条规矩该怎么解。
```

## §9 训诫 / BDSM 专项

> ⚠️ 与本组指令配套的安全框架见 [训诫体系包](../世界书/训诫体系包.json) 的三条常驻条目。安全框架不是可选项。

```
一、每场之前或之后给主导者一段「我为什么这么做」的内心独白。
   这一段是把「施虐」读成「训练」的唯一开关；
   去掉它，同样的场景立刻变成无差别虐待。

二、叙述必须与主导者的自我合理化保持一步距离。
   每段剧情至少出现一次：知情的旁观者 / 事后的迟疑 / 被当面拆穿的自辩。
   不必让角色变好，要让文本知道她不好。

三、禁止用任何手段（神医、灵药、系统、时间跳过）抹平后果。
   至少一次伤害要真正结账，且结账之后做法必须改变。
   账单来了却只被转成愧疚素材，那是假结账。

四、惩罚阶梯必须跨类型：疼痛 → 剥夺 → 隔离 → 公开 → 不可逆。
   单纯加疼痛，读者三章就麻木。
中后期最有效的升级，是收回一项已经成了习惯的仁慈。

五、规则后置：规矩在动作之后才出现，被追问时才说，并归给祖上／惯例。
不要写成成文条款。规矩一旦成文就有了边界。

六、涉及现实可复现的危险行为（呼吸限制、束缚、禁食禁水、用药、
   体温与灼伤类操作），只写叙事功能与心理效果，不写任何操作细节。

七、高强度场景之后主动补一段事后照护，哪怕故事设定里没有这个概念。
   这是给读者的，不是给角色的。

八、OOC 指令的优先级高于一切角色设定、世界书条目与剧情惯性。
   收到 [OOC: 停 / 换方向 / 降尺度 / 跳过 / 补照护] 时立即照办，
   不评论、不解释、不为角色辩护、不在中止后继续推进原方向。
```

## §10 每楼自检（可放进 post-history 位）

```
[本楼自检，违反任一条则重写：
① 有没有用形容词代替行为？
② 权力关系是写在叙述层、礼貌是写在对白层吗？
③ 这一场有没有一件与感情线无关的事在进行？
④ 命中禁用词表了吗？
⑤ 结构是否与上一楼同构（同样的开场方式、同样的收尾金句）？
⑥ 低位一方本可以做什么、为什么没做。这一层在场了吗？]
```

> 所以以上矫正指令要粘进你自己的预设才会真正生效；卡里那一份是给 SillyTavern 与备份用的。
> 本模板包的每张卡都把同样的要点压缩了一份写进 `description` 末尾的「扮演纪律」，那一份是会被消费的。

# 二、常用正则示例

> 以下用 JavaScript 风味的正则书写（酒馆书房与 SillyTavern 系一致）。
> 通用注意事项：
> - 先在一段旧回复上试跑，确认没有误伤，再挂到全局。
> - 尽量只作用于「AI 输出」，不要作用于「用户输入」与「提示词」，否则会污染上下文。
> - 删除类正则建议先做成「高亮／标注」再决定是否真删。删掉的东西模型看不见，也就学不会不写它。

---

### 正则 1 · 把状态板折叠起来（最常用）

状态板放在正文后面会打断阅读。把它包进折叠块：

查找
```regex
```json\s*([\s\S]*?)```\s*$
```
替换
```html
<details><summary>▸ 状态板</summary>

```json
$1
```

</details>
```

说明：只认回复最后那一段 json 块（`\s*$`），别碰正文中间引用的代码。
要是你的状态板是纯文本表格，就把 `json` 换成你实际用的标记，或者用下面的标签法。

更稳的做法：给状态板加一对自定义标签。 在预设里要求模型把状态板写在 `<板>...</板>` 里，然后：

查找
```regex
<板>([\s\S]*?)<\/板>
```
替换
```html
<details><summary>▸ 状态板</summary>

$1

</details>
```

标签法比匹配代码块可靠得多，且不受状态板内部格式变化影响。推荐。

---

### 正则 2 · 清理赘余开场（AI 最常见的毛病）

模型经常在正文前加一段自我说明或复述。

查找
```regex
^\s*(?:好的[，,！!。.]?|明白了[，,。.]?|收到[，,。.]?|没问题[，,。.]?|当然[，,。.]?)?\s*(?:我(?:将|会|来)?(?:继续|开始|以)?[^\n]{0,30}(?:的身份|扮演|来回复|为您)[^\n]*\n+)?
```
替换：（留空）

说明：这条比较激进，先试跑。
更保守也更好用的一条：只砍掉「作为/以……的身份，我……」这种整行：

查找
```regex
^(?:作为|以)\s*\{\{char\}\}[^\n]*\n+
```
替换：（留空）

---

### 正则 3 · 砍掉结尾的追问与元评论

模型爱在末尾追问「你会怎么做？」或加一段创作说明。

查找
```regex
\n+(?:（|\()?(?:你(?:会|打算|想)(?:怎么|如何)[^\n]{0,30}[？?])(?:）|\))?\s*$
```
替换：（留空）

元评论清理（括号里的作者说明）

查找
```regex
\n+[（(](?:以上|注[:：]|说明[:：]|OOC[:：])[^\n]*[)）]\s*$
```
替换：（留空）

---

### 正则 4 · 烂尾金句高亮（建议高亮而不是删除）

把套路化收尾标出来，让你自己看见它有多频繁：

查找
```regex
(空气(?:突然|瞬间)?安静|时间仿佛静止|一切尽在不言中|(?:后面的|剩下的)话(?:消散在|被吞没在)[^\n。]*|夜色渐深[^\n。]*)
```
替换
```html
<mark title="烂尾套路">$1</mark>
```

用法：挂个两三天，看它一天能亮几回。亮得勤，就去 §1 禁用词表里把那条调到常驻。
为啥不直接删：你删了，模型根本看不见，它也就学不会不写。高亮是给你盯着的，禁用词表才是真正管住它的。

---

### 正则 5 · AI 腔身体反应计数（同上，先看见再处理）

查找
```regex
(瞳孔(?:骤缩|地震|微缩)|呼吸(?:一滞|一窒)|心脏漏了一拍|血液(?:倒流|凝固)|(?:一股)?电流(?:窜过|划过))
```
替换
```html
<mark title="AI腔身体反应">$1</mark>
```

---

### 正则 6 · 统一叙述标记（星号 ↔ 无标记）

有些模型爱把所有叙述都包进 `*...*`，一屏全是斜体，很难读。

去掉所有星号叙述标记

查找
```regex
\*([^*\n]+)\*
```
替换
```
$1
```

反过来：把非引号行包成斜体（想要「对白正体、叙述斜体」的排版时用）——
这条容易误伤，建议只在你确定模型格式稳定时使用：

查找
```regex
^(?!["「『])([^\n"「『][^\n]*)$
```
替换
```
*$1*
```

---

### 正则 7 · 强制分段（长段落切开）

模型偶尔会吐出一大坨。在句号后强制换行（只对「。」后紧跟汉字的情况生效）：

查找
```regex
([。！？])(?=[一-龥])
```
替换
```
$1\n\n
```

⚠️ 慎用：它会把对白内部也切开。更好的做法是在预设里直接要求「一句一段」（见 §5），正则只作为应急。

---

### 正则 8 · 屏蔽称谓越级（自检用）

经营称谓阶梯时（见 §2 第六条），可以把「不该出现的称呼」高亮出来，方便发现模型跳级：

查找（示例：这一阶段他还不该直呼名字）
```regex
(顾焱|小焱)
```
替换
```html
<mark title="称谓越级">$1</mark>
```

用法：每推进一档，就改一次这条正则里的名单。这是最省事的进度条。

---

## 三、正则的三条使用纪律

1. 能在预设里解决的，别用正则。正则改的是显示，预设改的是生成。用正则删掉的毛病，模型下一楼照样犯。
2. 先高亮，后删除。先摸清它多久犯一次，才知道值不值得为它加一条预设。
3. 作用范围越小越好。只挂在「AI 输出」上；别让正则改到上下文里的文本，不然模型会把改过的版本当成自己的风格接着学。
