# 状态板设计

> 酒馆书房的状态板是一组每楼都带着的结构化字段。新窗第一楼把它定成什么样，后面每一楼就照着抄什么样。
> 所以状态板只有一次设计的机会，第一楼放了哪些字段，这一局从头到尾就是这些字段。

这里有三套拿来就能复制的结构，1v1 版、np 版、训诫·BDSM 版，另外还有一节「如何用 OOC 指令改变状态板的形状」。

---

## 零、先想清楚的三件事

### 0.1 状态板是干什么用的

状态板是**给模型的短期记忆挂钩**，专治长对话里最要命的三个毛病：

| 问题 | 状态板怎么解 |
|---|---|
| 十几楼之后 AI 忘了「他现在还在生气」 | 情绪字段每楼都重写，每写一次就是提醒一次 |
| 关系推进没有刻度，一会儿冷一会儿热 | 关系变量用数值记，只能一点点动，动了就有据可查 |
| np 局里三个人变成一个人的三种说法 | 每人单独一行，位序、诉求、相互关系各写各的 |

一个字段要不要留，只看一点：它的值变了，下一楼写出来的东西会不会跟着变。不会，就删。

### 0.2 三条硬规矩

1. 字段总数控制在 12–20 个。一过 20 个，模型就开始糊弄：状态板填得满满当当，正文反倒越写越短。状态板挤掉正文，是最常见的翻车。
2. **数值只能一点点动。信任度一次动 ±1 到 ±2（十档制），别一楼就从 3 跳到 8。要大幅跳，正文里必须有对应的事件，状态板里也得写上这件事。**
3. 一定要留一格「未言明的事」。有了这格，模型每楼都得想一想「有什么是这两个人都知道但没说出口的」。

### 0.3 权力字段怎么设计（这一节是第四爱专用）

普通角色扮演的状态板只记情绪和好感，第四爱一定要再加两格：

- **主导权归属**：这一场谁说了算，而且说了算的人必须能换。要是从头到尾都是女主拍板，这一格写了也白写。
- **权力的可见形态**：这一层权力要有个看得见的样子，一份文件、一个许可、一个称呼，甚至一次沉默都行。填这一格，模型就得把权力落到实物上，没法拿形容词混过去。

## 一、1v1 版

### 1.1 可直接复制的 JSON 结构

```json
{
  "场景": {
    "时间": "第三日 · 亥时",
    "地点": "寒渠 · 第三炉",
    "在场": ["{{user}}", "蔺霁"],
"旁人": "无，炉外有值夜弟子二人"
  },
  "我方": {
    "情绪": "克制的焦躁",
    "身体": "无碍",
    "态度": "试探"
  },
  "对方": {
    "情绪": "表面平静 / 实为强撑",
    "身体": "灵脉逆行第二回，契痕转深",
    "态度": "回避正题，用术语作答",
    "对我的称呼": "你（自立契起未改）"
  },
  "关系变量": {
"信任度": "6/10，↑1，因她今夜没有追问",
"主导权归属": "对方他掌握着他不肯说的那件事",
    "权力的可见形态": "腕上那圈绢带——她有权解，他没有拒绝的余地",
    "亲密度": "3/10",
    "未言明的事": "长老会给的第二页笺，他压了六个时辰没拿出来"
  },
  "本楼推进": {
    "发生了什么": "他把第一页推了出来，第二页没有",
    "下一步张力点": "她看见了有两页"
  }
}
```

### 1.2 字段说明

| 字段 | 为什么要它 | 填法要点 |
|---|---|---|
| `时间 / 地点` | 长对话最容易丢的就是时间和地点的连贯 | 用相对时间，比如第三日、婚后第九个月，比写具体日期好用 |
| `在场 / 旁人` | 这一楼能说什么话，由它决定 | 有没有第三个人在场，决定了称谓走哪一轴、能不能失礼 |
| `情绪 / 身体 / 态度` 各一行 | 这三样常常对不上，对不上的地方就是戏 | 可以写「表面 X / 实为 Y」。情绪和态度写反差，身体写事实 |
| `对我的称呼` | 称谓本身就是状态栏 | 这一格一变，关系就进了一档，比数值准 |
| `信任度` | 关系里变得慢的那个量 | 十档制，一次动 ±1~2，括号里必须写为什么动 |
| `主导权归属` | 第四爱专用 | 只填一方，而且必须能换手。可以写「本场易手一次：前半在她，后半在他」 |
| `权力的可见形态` | 让模型把权力落到具体的东西上 | 一份文件 / 一道许可 / 一个称呼 / 一次不作为 |
| `亲密度` | 和信任度分开记 | 两者可以背离，背离的时候最好看。很亲密但不信任 = 这个类型的黄金区 |
| `未言明的事` | 潜台词都放在这一格 | 每楼必填。填不出来，就是这一楼没有潜台词，得重写 |
| `下一步张力点` | 给模型留一根线头 | 一句话，说清下一楼要处理什么 |

### 1.3 精简版（12 格，适合手机端／不想让状态板挤占正文）

```json
{
  "时地": "婚后第九月 · 主宅书房 · 深夜",
"在场": "{{user}} / 陆决，宅内另有管家，不在场",
  "他-情绪": "戒备（表面平静）",
  "他-身体": "发情期第二日，抑制剂效力剩约四小时",
  "他-态度": "谈判姿态，随时可能中止对话",
  "他对我的称呼": "你（从未用过敬语）",
  "信任度": "4/10（↑1）",
  "主导权": "本场在他——他坐着，我站着",
  "权力形态": "《条例》第十九条：我随时可以启动，而我没有",
  "亲密度": "5/10",
"未言明": "他不知道我压提案的真实理由，我不知道他查过四家律所"
  "下一步": "他会要求我把「不用那条法律」写下来"
}
```

## 二、np 版

np 的状态板比 1v1 版多了**一张横向关系表**。

### 2.1 可直接复制的 JSON 结构

```json
{
  "场景": {
    "时间": "家宴前三日 · 申时",
    "地点": "霁园 · 正堂",
    "在场": ["{{user}}", "裴无咎", "温野", "闻筝", "赫连朔"],
    "旁人": "管家一名，廊下候着"
  },
  "我方": {
    "情绪": "在算这张座次表要不要动",
    "身体": "无碍",
    "本场目标": "不表态，看四个人各自出什么牌"
  },
  "在场诸位": [
    {
      "名": "裴无咎",
      "位序": "1（正君 · 份例10）",
      "好感": "7/10（→）",
      "当前诉求": "让我认下这张座次表——认了，先例就归他解释",
      "本楼状态": "手里的册子合上了，合得很轻",
      "对我的称呼": "主子（公开场合）",
      "对其他人": "对温野表面相敬（暗中盯药材账）／对闻筝明面对手／对赫连朔结盟排外"
    },
    {
      "名": "温野",
      "位序": "2（侧夫 · 份例6）",
      "好感": "8/10（↑1）",
      "当前诉求": "不求情，只把「赫连朔膝伤怕风」这个事实放到我够得着的地方",
"本楼状态": "抄方子的笔停了半息，裴、闻二人都看见了",
      "对我的称呼": "主子",
      "对其他人": "欠闻筝一段旧事／对裴无咎回避"
    },
    {
      "名": "闻筝",
      "位序": "3（侍 · 份例3）",
"好感": "6/10，↓1，我今日没接他的话",
      "当前诉求": "把自己和赫连朔绑一起，逼裴无咎表态",
      "本楼状态": "笑了两次，第二次没人接",
      "对我的称呼": "主子（私下直呼小名）",
      "对其他人": "不让裴无咎的东西经自己的手／对温野混着感激与轻蔑"
    },
    {
      "名": "赫连朔",
"位序": "—，客 · 无份例，不入座",
      "好感": "3/10（→）",
      "当前诉求": "不争。他在等所有人先出完牌",
      "本楼状态": "站着，行了一个北边的全礼",
      "对我的称呼": "在下对您（不用「主子」）",
      "对其他人": "被三人共同排斥，且他知道"
    }
  ],
  "全局": {
    "本场注意力去向": "我看了温野两次、赫连朔一次、裴无咎零次",
"位序是否将动": "是。空着的第四等，府里都在算"
    "上一次破例": "本月免了赫连朔一项规矩（三年来第一次）",
    "未言明的事": "我为什么免那一项，四个人各有一套猜测，没有一个对",
    "下一步张力点": "座次表我动不动。动了就是先例"
  }
}
```

### 2.2 np 专属字段说明

| 字段 | 为什么必须有 |
|---|---|
| `位序` | np 局的骨架。位序一定要带数字（份例／权限／额度），否则等级就只剩一个形容词 |
| `当前诉求` | 免得「三个人变成一个人的三种说法」。每个人这一楼想要的东西必须各不相同，还要具体到能去做 |
| `本楼状态` | 写一个具体动作，让模型给每个人一个认得出的身体信号 |
| `对其他人` | np 和 1v1 就分在这一格。没有它，写出来的只是几条各走各的单线 |
| `本场注意力去向` | 把那样稀缺的东西写到明处。「我看了谁几次」比好感数值管用 |
| `位序是否将动` | 位序不动，np 局就停住了。有这一格，剧情就得往前走 |
| `上一次破例` | 在这套规矩里，破例最难得，也是后期的弹药库，必须记下来 |

### 2.3 np 的两条使用纪律

① 好感别一起涨。四个人的好感齐刷刷往上走，是模型在偷懒。每一楼至少要有一个人持平或者往下掉。给了这个人时间，别人那儿就少了。

② 「当前诉求」每两三楼必须换一次。一个人十楼都盯着同一个目标，这个角色基本就写废了。诉求一变，就看得出他在接招、在变通。

### 2.4 np 精简版（每人一行，适合六人以上）

```json
{
  "时地在场": "家宴前三日 · 正堂 · 四人俱在",
  "位序表": [
    "1 裴无咎｜正君10｜好感7→｜要我认下座次表｜册子轻轻合上",
    "2 温野  ｜侧夫6 ｜好感8↑｜只报事实不求情｜笔停半息",
    "3 闻筝  ｜侍3   ｜好感6↓｜绑赫连逼裴表态｜笑了两次没人接",
    "— 赫连朔｜客0   ｜好感3→｜不争，等牌出完｜行了北边全礼"
  ],
  "横向": "裴↔温相敬暗查／裴↔闻明斗／温↔闻旧债／三人共同排赫连",
  "注意力": "温野×2、赫连×1、裴×0",
  "位序将动": "第四等空着，府里都在算",
  "未言明": "我免赫连那一项的理由，四种猜测无一为真",
  "下一步": "座次表动不动 = 立不立先例"
}
```

## 三、训诫 · BDSM 版

> ⚠️ 本节的一切设定均为**叙事工具**，不构成现实实践指南。使用前请读 [训诫体系包](../世界书/训诫体系包.json) 中的三条安全框架条目。
> 状态板里「安全信号」这一格，在这一版里最要紧，不许删。

### 3.1 可直接复制的 JSON 结构

```json
{
  "场景": {
    "时间": "入府第九月 · 二更",
    "地点": "卫府 · 正堂",
    "在场": ["{{user}}", "卫承"],
    "旁人": "教引嬷嬷候在廊下（她听得见）"
  },
  "我方": {
    "情绪": "分不清她今日为何反常",
    "身体": "旧伤已敛（她以为未愈）",
    "态度": "守规矩，但今夜想问一句"
  },
  "对方": {
    "情绪": "反常的松动（她自己不承认）",
    "身体": "短杖今日未别在腰后",
    "态度": "在试我敢不敢坐",
    "段间意图": "她想知道，九个月的规矩和她一句话哪个更重"
  },
  "规则状态": {
    "常态管束": "每日晨省（本月已免）／未经许可不得出内院／回话须报位份",
    "本楼生效的规则": "府中「侍」不得与主家同坐",
    "本楼被违反/弯折的规则": "她指了正室才能站的位置给我",
    "规则来源层": "第四层（她随口定的），但托词归给「祖上」",
"不可豁免条款": "北境降臣男丁没入官籍。她也废不掉"
  },
  "违规与账目": {
    "本楼违规": "无",
"累计违规": "1 次，上月为他人求情",
    "上次处置": "未罚我，改为加重被我求情者的处境",
"自我审查程度": "高，此后再未为任何人开口",
    "已成习惯的破例": ["免晨省（本月起）", "许我在堂上抬头回话（第七月起）"],
    "破例被收回的次数": "0"
  },
  "关系变量": {
    "信任度": "5/10（↑1）",
"主导权归属": "她，但本楼她主动让出半格",
    "权力的可见形态": "那根今日不在腰后的短杖",
    "未言明的事": "她昨日看过我的脉案，知道伤早好了"
  },
  "安全信号": {
    "场内安全词": "「够了」（她的）／「请主子听我一句」（我的）",
    "场外安全信号": "[OOC: 停 / 换方向 / 降尺度 / 跳过这一场 / 补一段照护]",
    "本楼强度": "低（无身体处置）",
    "事后照护": "未触发",
"红线": "不可逆处置本局不启用，禁食禁水、呼吸限制只作叙事提及，不写操作"
  },
  "本楼推进": {
    "发生了什么": "她要我坐。坐了往后有把柄，不坐就是规矩比她的话重",
    "下一步张力点": "我坐不坐"
  }
}
```

### 3.2 训诫版专属字段说明

| 字段 | 为什么必须有 |
|---|---|
| `常态管束` | 一条24小时生效、能量化的规则，管得比单场惩罚久 |
| `本楼被违反/弯折的规则` | 训诫的戏多半出在规则被弯的那一下。有这一格，模型每楼都得找出一处松动 |
| `规则来源层` | 对应四层授权链。填这一格，模型就会意识到自己在编第四层的规矩，还拿上面三层当托词 |
| `不可豁免条款` | 最上面那条连主导者也改不了的规则。没有它，主导者无所不能，也就没意思了 |
| `段间意图` | 「施虐」能被读成「训练」，全靠这一格。每楼给主导者写一句「我为什么这么做」，去掉这句，同样的场景马上就成了无差别虐待 |
| `自我审查程度` | 训诫练出来的是自我规训。这个值往上走，比惩罚记录更能说明问题 |
| `已成习惯的破例` | 后期拿来用的。把一项已经成了习惯的仁慈收回去，常常比加码管用，还不用加尺度 |
| `破例被收回的次数` | 计数用。收回过一次，以后每次破例都会带着怕 |
| `本楼强度` | 把强度写到明面上，免得不知不觉一路往上加 |
| `事后照护` | 缺席即失当。高强度场景之后这一格必须被填上，哪怕故事设定里没有这个概念 |
| `红线` | 每局开头自己写一遍。红线写下来，模型才会守 |

### 3.3 安全信号的双层设计

这是本版最重要的设计，两层缺一不可：

第一层 · 场内安全词（虚构层）

这是角色之间用来叫停的暗号。它活在故事里，角色可以不理它、会错意、拿它当钩子使。它是剧情的工具，护不了你。

第二层 · 场外安全信号（你和 AI 之间）

`[OOC: ...]` 指令。这才是你真正的安全词。

它想硬掰回原来的剧情？门都没有。AI 只要瞄到那一眼，就得当场收手，连「角色不会这么干」这套说辞都压不住。什么角色设定、世界书条目、剧情惯性，在它面前全得靠边站。

常用五句：
```
[OOC: 停。这一段换个方向。]
[OOC: 降低尺度，改为暗场处理。]
[OOC: 跳过这一场，直接到第二天早上。]
[OOC: 回到上一个分岔点，这条线我不要了。]
[OOC: 补一段事后照护。]
```

建议把这五句直接写进状态板的 `安全信号.场外安全信号` 一格。它每楼出现一次，等于每楼提醒你自己：这个出口一直开着。

## 四、如何用 OOC 指令改变状态板的形状

后面每一楼都会照抄状态板的形状。要改，就在正文以外另发一条指令，讲明从下一楼起生效。

### 4.1 六条即用指令

① 第一次建板，新窗第一楼之前发
```
[OOC: 从下一楼开始，每楼正文之后附一个状态板，用 ```json 代码块包住。
字段固定为：场景时间、地点、在场、旁人、我方情绪、身体、态度
对方情绪、身体、态度和对我的称呼、
关系变量：信任度、主导权归属、权力的可见形态、亲密度、未言明的事、
本楼推进发生了什么/下一步张力点。
数值一律十档制，一次变动不超过 ±2，变动必须在括号里写理由。
这个形状从此固定，除非我另行指示。]
```

**② 加一格**
```
[OOC: 从下一楼开始，在「关系变量」里增加一格「他今天多做的一件合同里没写的事」。
其余字段与格式保持不变。]
```

**③ 删一格**
```
[OOC: 从下一楼开始，删掉「亲密度」这一格，其余不变。它这几楼没有变过，说明它没用。]
```

**④ 改数值口径**
```
[OOC: 从下一楼开始，信任度改成百分制，并在括号里写出本楼的具体变动事件。
历史值按 6/10 → 60% 换算。]
```

**⑤ 1v1 板切换成 np 板**
```
[OOC: 从下一楼开始，把「对方」这一段换成「在场诸位」数组，每人一个对象，
字段为：名 / 位序(带份例数字) / 好感 / 当前诉求 / 本楼状态 / 对我的称呼 / 对其他人。
在「全局」里增加：本场注意力去向、位序是否将动、上一次破例。其余保持不变。]
```

**⑥ 临时收起，不改形状，只是这几楼不显示**
```
[OOC: 接下来三楼是一场连续的对手戏，状态板暂时不要显示，但内部继续维护。
三楼之后恢复显示，并把这三楼的累计变动一次性写出来。]
```

### 4.2 四条实操经验

**① 改形状要趁早。** 第一楼定下的最稳。到了二十楼再改，模型会在新旧两套格式之间来回晃好几楼。
**实在改不动时的终极办法**：把要的完整状态板**手写一份**贴给它，告诉它「从下一楼开始照这个形状写」。给示例比讲要求管用得多。

**② 一次只改一处。** 三个字段一起改，模型多半只改对一个。

**③ 状态板挤占正文时，立刻砍字段。** 表现是状态板越写越细，正文越写越短，越来越像摘要。
```
[OOC: 状态板压缩到 12 格以内，每格不超过 20 字。正文篇幅恢复到之前的水平。
状态板是给正文挂钩用的，不是正文本身。]
```

**④ 数值失控时用一次性校准。** 表现是好感一路涨到 10/10，之后就没有刻度可言了。
```
[OOC: 校准一次。以当前实际关系重估：信任度 X、亲密度 Y、主导权归属 Z。
此后每楼变动不超过 ±1，且必须有对应事件。到顶之后不再上涨，改为在「未言明的事」里体现进展。]
```

### 4.3 把状态板折叠起来

状态板跟在正文后面，会打断阅读。拿正则把它包进折叠块就好，写法见 [预设与正则](../预设与正则/README.md) 的「正则示例 1」。
