# 去 AI 味模板包

给拿这个库去写小说的人。三份成品加一份说明，管三件事：动笔前给模型定规矩，写的时候让规矩一直在线，写完拿尺子量。

本库自己的文风规矩写在 [00-编纂规约/05-去AI化写作铁律](../../00-编纂规约/05-去AI化写作铁律.md)，写东西容易犯的十七种毛病和十二条改法在 [07-语言风格/04-反AI味指南](../../07-语言风格/04-反AI味指南.md)。那两处讲过的这儿不重复，直接给链接。

## 三份成品

| 文件 | 管什么 | 什么时候用 |
|---|---|---|
| [写作预设.md](写作预设.md) | 模型不知道哪些词、哪些句式是机器腔 | 开局前粘进 system prompt 或酒馆的主提示词位 |
| [世界书-去AI味.json](世界书-去AI味.json) | 预设位被别的东西占满，或者换了前端 | 导入 SillyTavern，四条全部常驻 |
| [自查清单.md](自查清单.md) | 稿子写完了，不知道哪里露馅 | 每章跑一次机器查，每十万字过一次人工查 |

预设跟世界书其实是同一套规矩的两种装法，内容都是重叠的。装一样就够用了。两样都装，上下文占两份，模型也不会因此更听话。

## 怎么配合

| 场景 | 配置 |
|---|---|
| 快速见效 | 全文直接塞进 system prompt，别的啥也不管 |
| 上下文吃紧 | 世界书只留四条常驻，预设砍到只剩「禁止」那一段 |
| 长篇改稿 | 预设一直挂着，每章跑一遍机器查，每十万字人工过一遍 |
| 已经写完的旧稿 | 只用自查清单。预设管不了已经写出来的字 |

机器查的命令是 `python3 _脚本/ai_taste.py --narrative 稿子.txt`，十九项指标的含义与超标改法在 [自查清单.md](自查清单.md)。

## 每条禁令是从哪儿来的

每条禁令都标了出处。先信实测。研究次之，一家之言只当参考。

| 标记 | 含义 |
|---|---|
| 实测 | 从库外 5,668 篇真人小说里抽 100 篇，每篇切两万字，算出来的分布 |
| 研究 | 外部论文或大规模人工标注沉淀，包括超额词汇统计、slop 三元组表、维基百科 AI 写作特征清单、余光中反西化清单 |
| 一家之言 | 一个人看着琢磨的。方向能参考，数字别当真 |

词表是最先过期的。英文圈那边 `delve` 被公开点名之后，用的人立马就少了，词表基本等于废了。但句长分布和句式偏好不会因为被点名就变，所以四份文件里，节奏和句法这两层，比词表层靠谱得多。

## 三条别当规矩

流传最广的三条反 AI 味建议，实测方向是反的。

| 常见说法 | 实测 |
|---|---|
| 三项并列是 AI 特征 | 真人小说中位数 7.16 处/千字，比库内文本高五倍。中文本来就爱用顿号列举 |
| 破折号多就是机器写的 | 已出版文学 4.76/千词，《哈克贝利·费恩》10.13/千词，GPT-4.1 10.62/千词。告警线在 20/千词 |
| 被动语态是 AI 标志 | 2026 年的模型用得比人少 |

按这三条改稿，会把正常的中文改坏。

## 格式说明

世界书是 SillyTavern 格式（`{"entries": {…}}`，条目为对象）。[`../世界书/`](../世界书/) 里的五个包是酒馆书房格式（`entries` 为数组），两者导入口不同，别混用。

四条全部 `constant: true`，导入后无需配触发词，也不必写关键词。想省上下文就整条停用。别删字。
