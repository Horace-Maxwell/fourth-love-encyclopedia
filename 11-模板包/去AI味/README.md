# 去 AI 味模板包

这个包是给拿本库写小说的人用的。里面三份成品、一份说明：动笔前给模型立规矩，写的过程中让规矩一直生效，写完再拿尺子量一遍。

本库的文风规矩在 [00-编纂规约/05-去AI化写作铁律](../../00-编纂规约/05-去AI化写作铁律.md)，写东西常犯的十七种毛病和十二条改法在 [07-语言风格/04-反AI味指南](../../07-语言风格/04-反AI味指南.md)。那两处写过的，这里只给链接，不再重复。

## 三份成品

| 文件 | 管什么 | 什么时候用 |
|---|---|---|
| [写作预设.md](写作预设.md) | 模型分不清哪些词、哪些句式带机器腔 | 开局前贴进 system prompt，或者酒馆的主提示词位 |
| [世界书-去AI味.json](世界书-去AI味.json) | 预设位已经被别的东西占满，或者换了前端 | 导入 SillyTavern，四条都是常驻 |
| [自查清单.md](自查清单.md) | 稿子写完，看不出哪里露了馅 | 机器查每章跑一次，人工查每十万字过一次 |

预设和世界书装的是同一套规矩，内容重叠，装一样就够。两样都装，上下文要占两份，模型也不会因此更听话。

## 怎么配合

| 场景 | 配置 |
|---|---|
| 快速见效 | 把全文塞进 system prompt，其余都不用管 |
| 上下文吃紧 | 世界书留四条常驻，预设只保留「禁止」那一段 |
| 长篇改稿 | 预设全程挂着，每章机器查一遍，每十万字人工查一遍 |
| 已经写完的旧稿 | 只能用自查清单，写出来的字预设管不到 |

机器查的命令是 `python3 _脚本/ai_taste.py --narrative 稿子.txt`。十九项指标各自量什么、超标了怎么改，写在 [自查清单.md](自查清单.md)。

## 每条禁令是从哪儿来的

每条禁令都注了出处。实测的最可信，研究次之，一家之言只作参考。

| 标记 | 含义 |
|---|---|
| 实测 | 从库外 5,668 篇真人小说里抽出 100 篇，每篇截两万字，统计出的分布 |
| 研究 | 来自外部论文或大规模人工标注，有超额词汇统计、slop 三元组表、维基百科的 AI 写作特征清单、余光中的反西化清单 |
| 一家之言 | 个人观察琢磨出来的，方向可以参考，数字别当真 |

句长分布、句式偏好，不会因为被人点了名就改，所以节奏和句法这两层比词表层可靠得多。词表层最不抗造：英文圈公开点名 `delve` 之后，这个词基本没人用了，那份词表也就作废了。

## 三条别当规矩

流传最广的三条反 AI 味建议，实测下来方向都是反的。

| 常见说法 | 实测 |
|---|---|
| 三项并列是 AI 特征 | 真人小说的中位数是 7.16 处/千字，比库内文本高五倍。中文本来就爱拿顿号列举 |
| 破折号多就是机器写的 | 已出版的文学作品是 4.76/千词，《哈克贝利·费恩》10.13/千词，GPT-4.1 是 10.62/千词。到 20/千词才告警 |
| 被动语态是 AI 标志 | 2026 年的模型反倒比人用得少 |

照这三条去改稿，好好的中文会被改坏。

## 格式说明

这份世界书是 SillyTavern 格式（`{"entries": {…}}`，条目是对象）。[`../世界书/`](../世界书/) 里那五个包是酒馆书房格式（`entries` 是数组），导入口不一样，别混用。

四条都是 `constant: true`，导入后不用配触发词，也不用写关键词。要省上下文，就把整条停掉，别去删里面的字。
