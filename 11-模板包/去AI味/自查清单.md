# 自查清单

人工查至少要半小时，查对白、人物、一致性三层。机器查五分钟出结果，查词表、句法、节奏三层。两样都要过，机器查不出结构上的病，人工也看不出分布上的病。

预设和世界书在生成时起作用，清单用来验收。旧稿已经写完，只能靠清单，预设改不了写出来的字。

# 一 · 机器查

## 命令

```bash
# 单篇，最常用
python3 _脚本/ai_taste.py --narrative 稿子.txt

# 管道：只印七个主指标与结论行，最好读
cat 稿子.txt | python3 _脚本/ai_taste.py -

# 一整卷
python3 _脚本/ai_taste.py --narrative 稿子目录/
```

## 四个坑

| 坑 | 说明 |
|---|---|
| 忘了加 `--narrative` | 不加的话按说明文的口径查，上限宽一倍，小说要漏掉一半 |
| 目录模式只收 `.md` | 目录里的 `.txt` 一篇也扫不到，txt 得一个个传，或者走管道 |
| 短片段不出节奏指标 | 句长变异系数和短句占比至少要八句才算得出，段长变异系数至少要四段。片段攒够两千字再查 |
| 引文照样计入 | 表格、代码块、行内反引号会先剥掉再算，引号里的引文照算 |

最后一条这样处理：命中的要是别人的原话，就跳过，引文别改。

## 指标表

合格线用的是 `--narrative` 口径，全部取 100 篇真人小说的 P90。表里越靠上的项，超标了越难改，越往下越好改。改的时候从上往下。

| 指标 | 量什么 | 合格线 | 超了怎么改 |
|---|---|---|---|
| 句长CV | 句子长短起伏有多大，越参差越像人写的 | ≥0.55 | 找到连着三句长短差不多的地方，把中间那句砍到六字以内，或者拉到四十字以上。这一项换词没用，只能动长度 |
| 短句占比 | 六字以内的句子在全部句子里占多少 | ≥0.04 | 每页放一两句短的，对白里最容易加，动作句其次 |
| 长括号/千字 | 带主谓的括号旁白，话说到一半拿括号补上一句 | ≤0.21 | 并进句子、删掉、另起一句，三种改法任选。给术语加三五个字的注解是正常用法，不算 |
| 分号 | 分号在中文里是公文用的标点，网上写东西几乎没人用 | 越少越好 | 全部改成句号或逗号 |
| 段长CV | 段落长短起伏有多大 | 只测不判 | 段落长得一样齐，和句子一样齐是同一个病，要跟句长CV放在一起看 |
| 不是X是Y/千字 | `不是……，而是……` | ≤0.18 | 真人写东西基本不用这句式，一百篇里过半一次都不写。删掉“不是”那半句，直接说后半句 |
| 破折号插入/千字 | `——` 后面跟了四字以上 | ≤1.10 | 改成句号另起一句，或者换回逗号。别一下全删光，真人用的比想的多 |
| 特殊用法引号/千字 | 普通词加了引号来强调 | ≤0.31 | 把引号删掉，只有真术语才该加引号 |
| 高危词/千字 | 命中报告腔词表的次数 | ≤0.18 | 一个个换成具体的说法。这一层改起来最容易，也最容易复发 |
| 物理隐喻/千字 | 拿物理动作写思考，比如接住、击穿、收口、扛住… | ≤0.24 | 改成直说。「三条反馈我都接住了」→「三条我都记下了」 |
| 弱动词/千字 | 作出、进行、加以、给予、予以、开展 | ≤0.26 | 把后面跟着的名词改成动词。「作出决定」→「决定」 |
| 的字连用/千字 | 一句话里连着用了三个「的」 | ≤0.43 | 删到只剩一个，或者把中间那个换成「而」。「参差的斑驳的黑影」→「参差而斑驳的黑影」 |
| 介词开头/千字 | 整行用 关于／对于／作为／基于 开头 | ≤0.06 | 多数时候把这个词删了，句子就顺了 |
| 之一/千字 | 「……名著之一」 | ≤0.07 | 删掉，中文原本没有这种说法 |
| 当X之后/千字 | 「当……的时候／之后／以后」 | ≤0.12 | 「当他把稿子写好之后」→「他稿子一写好」 |
| 小说套话/千字 | 14 条模板句，像眉头紧锁、瞳孔骤缩… | ≤0.12 | 换成这个人物自己才有的反应。同一个动作全书最多出现两次 |
| 形容词冒号/千字 | 「问题很直接：」「结论很明确：」 | 0 | 一次都不许有，100 篇真人小说里一回也没出现过。把冒号前那半句删掉 |
| 情绪点名/千字 | 「他感到一阵…」「她心中一丝…」 | ≤0.06 | 写成动作或物件，不写他很紧张，写他把杯子换了两次手 |
| 性度化/千字 | 「具有很高的知名度」 | ≤0.06 | 「很有名」 |
| 整句加粗/千字 | 整句话被 `**` 包住 | ≤1.0 | 摘掉星号，一个字都不用删。加粗超标的稿子，超的几乎全是这一种 |
| 加粗/千字 | 全部加粗 | ≤10.0 | 同上 |

报表里单列了一组参照数据，不标红，不划线，只作记录：长句占比、括号和分号出现频率、低危词出现次数。三种句式各数了多少回，也一并放进去。`并非X而是Y`、`与其说……不如说`、`自问自答`，都只留在那儿，供对照，不下评判。

## 只有时间看三个

| 指标 | 为什么排在前面 |
|---|---|
| 句长CV | 只有这项指标换词绕不过去。好几个独立来源都认定它是单项里最明显的痕迹 |
| 不是X是Y | 真人中位数是零，中英文症状同构，一条规则通吃 |
| 形容词冒号 | 100 篇真人小说一次没中，不分文体 |

哪几条流行建议照做反而会把中文改坏，见 [README](README.md) 里的「三条别当规矩」。

# 二 · 人工查

机器查不出来的病都在结构层。下面的判定方法逐条照抄反 AI 味研究里的结构判据，每条只答是或否。

## 对白

| # | 症状 | 判定方法 | 不合格线 |
|---:|---|---|---|
| 1 | 每个人物都说完整句 | 数一数对白里中断的、带口头禅的、语法不全的、答非所问的句子各占多少 | 合计 <20% |
| 2 | 所有人物同一个声音 | 把说话人标签遮住，请旁人认每句是谁说的 | 指认率 <60% |
| 3 | 对话全在推进情节 | 一句句删掉对白，看情节受不受影响 | 删哪句都有影响 |
| 4 | 零潜台词 | 在每场重要对话里找「说的不是想的」那一处 | 一处都找不到 |
| 5 | 对白比例失衡 | 算对白字数在全文里占多少 | 不在 5%–65% 之间 |

第 2 条通常在第三章露馅：老太太跟十九岁的少年用一样的句式说话，连迟疑的方式都一样。

## 人物与情节

| # | 症状 | 判定方法 | 不合格线 |
|---:|---|---|---|
| 6 | 人物被动 | 数主角自己动手和被人推着走各有几次 | 被人推着走 >50% |
| 7 | 矛盾当场就解决 | 看每章结尾留没留钩子 | 有一章结尾收得干干净净 |
| 8 | 主角干啥都成 | 数主角试过却没做成的事 | 全书不到 3 回 |
| 9 | 每章都按模板走 | 把每章冲突的起伏画成线，看是不是一个模子出来的 | 线型差不多 |
| 10 | 感官细节堆一堆但没用 | 每处描写都问一句「删了会影响哪个情节」 | 答不上来 |
| 11 | 内心戏没内容 | 找「他忽然意识到」「某种感觉涌上来」这类写法 | 满屏都是，剧情却没动 |

## 一致性

| # | 症状 | 判定方法 | 不合格线 |
|---:|---|---|---|
| 12 | 场景糊成一团 | 试着画张平面图，标出每个人站在哪 | 画不出来，或者同一段里有人像是分了身 |
| 13 | 伤好得太快 | 跟着日子看伤势轻重 | 前头还躺着，后头就下地跑了 |
| 14 | 写着写着就忘 | 列张单子记下发色、称呼、天气、伤口、日期，每章对一遍 | 有一处对不上 |

## 正面特征在不在

前十四条查有没有病，这四条查有没有活人写的痕迹，至少要中三条。

| 特征 | 判定方法 |
|---|---|
| 重复同一个词而不换同义词 | 关键概念从头到尾只有一个叫法。主人公、主要角色、中心人物换着用，就露了马脚 |
| 允许悬而未决 | 至少有一条线提起来就搁下，不解释，也不预告 |
| 不均衡的详略 | 最长的一段至少有最短的三倍长，写得细的地方也不一定是重点 |
| 开头不是钩子，结尾不升华 | 第一句写一件具体的事或一个画面，不交代背景，不提问。最后一句落在一个具体的物件或动作上 |

## 查的频率

| 什么时候 | 查什么 |
|---|---|
| 每章写完 | 机器查，只看句长CV、`不是X是Y`、形容词冒号三项 |
| 每五章 | 机器查全指标 |
| 每十万字 | 人工查全表，机器跑全部指标 |

十七种病怎么轮着查，还有「一次全查就写不出东西」这个教训，都在 [反AI味指南](../../07-语言风格/04-反AI味指南.md) 第三节。
