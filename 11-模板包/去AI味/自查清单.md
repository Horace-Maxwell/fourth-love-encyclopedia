# 自查清单

两部分。机器查五分钟出结果，管词表、句法、节奏三层；人工查半小时起步，管对白、人物、一致性三层。机器查不出结构病，人工查不出分布病。两样都要过。

预设与世界书管的是生成，清单管的是验收；已经写完的旧稿只能靠清单，因为预设改不了已经生成的字。

# 一 · 机器查

## 命令

```bash
# 单篇，最常用
python3 _脚本/ai_taste.py --narrative 稿子.txt

# 管道：只印七个主指标与结论行，最好读
cat 稿子.txt | python3 _脚本/ai_taste.py -

# 一整卷
python3 _脚本/ai_taste.py --narrative 稿子目录/
```

## 四个坑

| 坑 | 说明 |
|---|---|
| 忘了加 `--narrative` | 不加就按说明文口径查，上限放宽一倍，小说会漏检一半 |
| 目录模式只收 `.md` | 目录里的 `.txt` 一篇都不会被扫。txt 要逐个传，或者走管道 |
| 短片段不出节奏指标 | 句长变异系数与短句占比要至少八句才算，段长变异系数至少要四段。片段先攒够两千字再查 |
| 引文照样计入 | 表格、代码块、行内反引号会被剥掉，引号里的引文不会 |

最后一条的处理办法：命中的若是别人的原话，跳过它。别改引文。

## 指标表

阈值是 `--narrative` 口径，全部取自 100 篇真人小说的 P90。上面几项超标改起来最贵，下面几项最便宜。从上往下改。

| 指标 | 量什么 | 阈值 | 超了怎么改 |
|---|---|---|---|
| 句长CV | 句子长度的变异系数，越高越像人写的 | ≥0.55 | 找连续三句长度相差不到两成的段落，把中间那句砍到六字以内，或者扩到四十字以上。换词没用，只能改长度 |
| 短句占比 | 六字以内的句子占全部句子的比例 | ≥0.04 | 每页甩一两句短的。对白里最容易加，动作句次之 |
| 段长CV | 段落长度的变异系数 | 只测不判 | 段落一样长是同一个病的另一张脸，与句长CV 一起看 |
| 不是X是Y/千字 | `不是……，而是……` | ≤0.18 | 真人中位数是零，一百篇里过半一次都不用。删掉否定的前半句，直接说后半句 |
| 破折号插入/千字 | `——` 后面跟四字以上 | ≤1.10 | 改成句号另起一句，或者退回逗号。别一刀切清零，人类作者用得比想象中多 |
| 特殊用法引号/千字 | 给普通词加引号当强调 | ≤0.31 | 删引号。真术语才配引号 |
| 高危词/千字 | 报告腔词表命中数 | ≤0.18 | 逐个换成具体说法。这一层最容易改，也最容易复发 |
| 物理隐喻/千字 | 用物理动作写思考（接住、击穿、收口、扛住…） | ≤0.24 | 改直述。「三条反馈我都接住了」→「三条我都记下了」 |
| 弱动词/千字 | 作出、进行、加以、给予、予以、开展 | ≤0.26 | 把后面那个名词改成动词。「作出决定」→「决定」 |
| 的字连用/千字 | 一句里连用三个「的」 | ≤0.43 | 删到一个，或者中间那个改成「而」。「参差的斑驳的黑影」→「参差而斑驳的黑影」 |
| 介词开头/千字 | 整行以 关于／对于／作为／基于 起头 | ≤0.06 | 多数情况下删掉这个词，句子就通了 |
| 之一/千字 | 「……名著之一」 | ≤0.07 | 删掉。中文本来不这么说 |
| 当X之后/千字 | 「当……的时候／之后／以后」 | ≤0.12 | 「当他把稿子写好之后」→「他稿子一写好」 |
| 小说套话/千字 | 14 条模板句（眉头紧锁、瞳孔骤缩…） | ≤0.12 | 换成这个人物特有的反应。同一个动作全书别超过两次 |
| 形容词冒号/千字 | 「问题很直接：」「结论很明确：」 | 0 | 零容忍。100 篇真人小说里一次都没出现过。删掉冒号前那半句 |
| 情绪点名/千字 | 「他感到一阵…」「她心中一丝…」 | ≤0.06 | 改成动作或物件。不写他很紧张，写他把杯子换了两次手 |
| 性度化/千字 | 「具有很高的知名度」 | ≤0.06 | 「很有名」 |
| 整句加粗/千字 | 整句话被 `**` 包住 | ≤1.0 | 摘掉星号，一个字都不用删。加粗超标的稿子，超的几乎全是这一种 |
| 加粗/千字 | 全部加粗 | ≤10.0 | 同上 |

报表里还有几项只测不判：分号密度、括号密度、低危词密度、长句占比，以及 `并非X而是Y`、`与其说……不如说`、`自问自答` 三种句式的计数。它们没有阈值，当参照看。

## 只有时间看三个

| 指标 | 为什么排在前面 |
|---|---|
| 句长CV | 唯一无法靠换词绕过的指标。多个独立来源都指认它是最强的单一痕迹 |
| 不是X是Y | 真人中位数为零，且中英文症状同构，一条规则通吃 |
| 形容词冒号 | 真人 100 篇零命中，没有文体例外 |

哪几条流行建议反而会把中文改坏，见 [README](README.md) 的「三条别当规矩」。

# 二 · 人工查

机器查不到的病全在结构层。判定方法逐条照抄自反 AI 味研究的结构性判据。只答是或否。

## 对白

| # | 症状 | 判定方法 | 不合格线 |
|---:|---|---|---|
| 1 | 每个人物都说完整句 | 统计对白里的中断句、口头禅、语法不完整句、答非所问各占多少 | 合计 <20% |
| 2 | 所有人物同一个声音 | 遮住说话人标签，让第三方指认每句是谁说的 | 指认率 <60% |
| 3 | 对话全在推进情节 | 逐句删对白，看情节受不受影响 | 每一句删了都有影响 |
| 4 | 零潜台词 | 每场重要对话里找「说的不是想的」那一处 | 一处也找不到 |
| 5 | 对白比例失衡 | 数对白字数占全文的比例 | 落在 5%–65% 之外 |

第 2 条的崩点通常在第三章：老太太与十九岁少年用同样的句式、同样的迟疑方式说话。

## 人物与情节

| # | 症状 | 判定方法 | 不合格线 |
|---:|---|---|---|
| 6 | 人物被动 | 统计主角作为施事与作为受事的比例 | 受事 >50% |
| 7 | 张力立刻解决 | 逐章看末尾有没有留下不解决的线索 | 有任一章收得干干净净 |
| 8 | 主角问题总是顺利解决 | 数主角尝试并失败的次数 | 全书 <3 次 |
| 9 | 节拍卡在结构模板上 | 画出每章冲突强度曲线，看周期 | 周期高度一致 |
| 10 | 过量却无用的感官细节 | 每处感官描写问一句「删掉之后哪个情节点会断」 | 答不上来 |
| 11 | 无深度的内心戏 | 搜「他发现自己在想」「某种东西攫住了他」这类写法 | 大量出现却不承担任何叙事负担 |

## 一致性

| # | 症状 | 判定方法 | 不合格线 |
|---:|---|---|---|
| 12 | 物理空间含混 | 试着画出场景平面图，标出每个人物的位置 | 画不出来，或者同一段里人物像在两个地方 |
| 13 | 伤情与时间不守恒 | 追踪伤势严重度与时间线 | 前面写重伤，后面立刻改口 |
| 14 | 超过几段就忘 | 建一张事实表（发色、称谓、天气、伤口、日期）逐章核对 | 有一处对不上 |

## 正面特征在不在

前十四条查有没有病。这四条查有没有活人的痕迹。至少中三条。

| 特征 | 判定方法 |
|---|---|
| 重复同一个词而不换同义词 | 关键概念全程一个说法。主人公→主要角色→中心人物，是刻意堆词汇量留下的痕迹 |
| 允许悬而未决 | 至少一条线索提出后没解决，而且不道歉、不预告 |
| 不均衡的详略 | 最长的场景至少是最短场景的三倍，且详写的地方不必是最要紧的地方 |
| 开头不是钩子，结尾不升华 | 第一句是具体事实或场景，不是时代背景、不是问句；最后一句回到具体的物件或动作 |

## 查的频率

| 什么时候 | 查什么 |
|---|---|
| 每章写完 | 机器查，只看句长CV、`不是X是Y`、形容词冒号三项 |
| 每五章 | 机器查全指标 |
| 每十万字 | 人工查全表，加机器查全指标 |

十七种病的轮换查法，以及「一次全查就写不出东西」的教训，见 [反AI味指南](../../07-语言风格/04-反AI味指南.md) 第三节。
