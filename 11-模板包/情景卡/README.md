# 情景卡

> **分级** 分级见各卡，分级上限 `M` ｜ 预警 ⚠️训诫（限三张）｜ 亚型 现代都市
> 由 [`_脚本/build_scene_cards.py`](../../_脚本/build_scene_cards.py) 生成，**可重跑**
> 三十张，两个方向各十五张。

---

## 与角色卡的分工

| | [角色卡](../角色卡/) | 情景卡（这里） |
|---|---|---|
| 给的是 | 一个**人** | 一个**时刻** |
| 内容 | 他是谁、心里过不去的事、说话啥样 | 现在几点、桌上摆着啥、接下来该干啥 |
| 开场 | 通用 | 卡在崩之前那一下 |
| 长度 | 长 | 短 |
| 出处 | 精读拆解 | [14-桥段库](../../14-桥段库/README.md) |

角色卡解决「跟谁演」，情景卡解决「从哪开始」。两张可以叠。开场白放出来的时候，戏已经在走了。

## 怎么用

| 步 | 做什么 |
|---|---|
| 1 | 挑一个（按上表，或按 [14-桥段库/00-总表](../../14-桥段库/00-总表.md) 里的情绪索引） |
| 2 | 扔进酒馆书房或 SillyTavern，导入方法看 [模板包 README](../README.md) |
| 3 | 直接开写。开场白已经卡在崩点前一步，不用铺垫 |
| 4 | 想换条路走，翻出处条目的「变体轴」那格 |

### 想改角色名

情景卡里的名字（沈砚、祁言、顾知微）只是占位。把 `name`、`description`、`first_mes`、`mes_example` 四处的名字替换掉即可，其余字段与人名无关。

### 想接自己的角色卡

情景卡与角色卡可以叠用：角色卡给人，情景卡给时刻。把情景卡的 `scenario` 与 `first_mes` 复制到角色卡里，人物设定用角色卡的。

## 三条设计约束

| 约束 | 说明 |
|---|---|
| 一次一拍 | 提示词里写清楚，别一口气把整场戏演完 |
| 时间靠物件显 | 菜热了几遍、灯亮到几点，别写「过了很久」 |
| 不替 `{{user}}` 决定 | 不写用户的情绪和动作，不给选项，也别问「你想咋办」 |

提示词层不归 [去 AI 化铁律](../../00-编纂规约/05-去AI化写作铁律.md) 管，加粗限制在这儿不适用（加粗在提示词里是给模型看的信号），但**元评论照样禁**。上一轮实测，18 张角色卡在 `system_prompt` 里聊卡自己，纯属浪费上下文。

---

## 带 ⚠️ 的三张

10、24、25 这三张写的是日常里那种低强度的规矩和责罚，`system_prompt` 里把边界都写清楚了：成年、自愿、不写身体伤害、不给可操作细节，{{user}} 一说停就立刻退出，还点名了 SSC / RACK / PRICK 这套原则。

小说与角色扮演里的规矩是**幻想装置**，不是现实指南。完整框架见 [14-桥段库/08-规训日常版](../../14-桥段库/08-规训日常版.md)。

## 重新生成

```bash
python3 _脚本/build_scene_cards.py
```

卡的内容写在脚本的 `CARDS` 表里。改内容改那张表，不要直接改 JSON——下次重跑会被覆盖。
